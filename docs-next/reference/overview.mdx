## Connect an agent and verify data

<Tabs>
  <Tab title="Dashboard">
    1. Open **Administration → Keys** and select **Create key**.
    2. Enable both the **collector** and **policies** presets, name the key after its environment, and copy the secret when it is shown. Use only **collector** when the integration will never pull enforcement policies.
    3. Configure the integration using the matching page above.
    4. Open **Observe → Events** to confirm individual events arrive, then **Observe → Sessions** to confirm they are grouped into complete runs.
    5. Filter to the integration's environment and open one session. Check that model calls, tools, errors, and policy decisions contain the fields you need for audits.

    ![The Sessions list used to verify that a newly connected integration is reporting complete agent runs.](/images/dashboard/sessions-list.png)

    <Info>Screenshot placeholder: Administration → Keys with the collector and policies presets.</Info>
  </Tab>
  <Tab title="CLI">
    Create a collector key, configure the local runtime, and verify the first session.

    ```bash
    fp keys create collector-production \
      --add events:add \
      --add policies:pull

    failproofai config \
      --connect https://app.befailproof.ai \
      --token <collector-key>

    failproofai flush --wait
    fp sessions --since 1h --env production
    fp events --since 1h --env production --limit 20
    ```

    Use `fp --json sessions ...` when another tool will consume the result. Global flags such as `--json`, `--org`, and `--base-url` must come before the command.
  </Tab>
</Tabs>
