---
title: Session evaluations
description: Score completed agent sessions with a customer-owned evaluator.
icon: chart-line
---

AgentEye can send a completed session's event transcript to your evaluator service. The evaluator returns named scores and optional reasoning, which AgentEye stores and displays with the session.

```text
agent_end -> AgentEye server -> POST /evaluate -> evaluator service
                              <- done or pending <-
```

## Evaluator routes

Your evaluator implements these routes:

| Route | Purpose |
| --- | --- |
| `GET /health` | Health check |
| `GET /config` | Polling and inactivity settings |
| `POST /evaluate` | Start an evaluation for a session transcript |
| `GET /evaluate/{id}` | Poll an asynchronous evaluation |

An evaluator can return a result immediately:

```json
{
  "status": "done",
  "scores": {
    "helpfulness": 0.93,
    "tool_efficiency": 0.87
  },
  "summary": "The agent completed the task successfully."
}
```

Or it can defer work and provide a job ID:

```json
{
  "status": "pending",
  "job_id": "eval-123",
  "next_poll_secs": 10
}
```

AgentEye retries transient failures and supports repeated evaluations as a session continues over time.
