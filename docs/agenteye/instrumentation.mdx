title: Instrument an agent
description: Emit structured AgentEye events from Python.

The AgentEye Python SDK records an agent's lifecycle as structured events. Events are written to a local JSONL spool, and the AgentEye collector uploads them asynchronously.

## Basic session

```python
import agenteye

agenteye.configure(environment="production")

agenteye.event.agent_start(
    session_id="run-001",
    agent_id="planner",
    goal="answer the user query",
)

# Run your agent here.

agenteye.event.agent_end(
    session_id="run-001",
    agent_id="planner",
    outcome="success",
)
```

Use the same `session_id` for every event in a run. Use `agent_id` to distinguish agents inside a multi-agent session.

## Record a tool call

```python
agenteye.event.tool_use(
    session_id="run-001",
    agent_id="planner",
    tool_name="web_search",
    tool_call_id="toolu_01",
    input={"query": "latest AI research"},
)

agenteye.event.tool_result(
    session_id="run-001",
    agent_id="planner",
    tool_name="web_search",
    tool_call_id="toolu_01",
    output={"results": ["..."]},
)
```

## Configure the spool

By default, the SDK and collector share `~/.agenteye`. Set `AGENTEYE_HOME` when they need to use another shared location, such as a mounted volume in a sidecar deployment.

```bash
export AGENTEYE_HOME=/var/lib/agenteye
export AGENTEYE_ENVIRONMENT=production
```
