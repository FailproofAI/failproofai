تحتوي الإدارة على عناصر التحكم اللازمة لتشغيل Failproof AI عبر فريق العمل. يمكن لمعظم المستخدمين البقاء في أقسام الجلسات والتدقيق والسياسات؛ يستخدم المسؤولون هذا القسم لإدارة الوصول والحدود التشغيلية.

<Tabs>
  <Tab title="Dashboard">
    استخدم قسم **Admin** في الشريط الجانبي للسحابة للوصول إلى **محرر السياسات** و**الإنفاذ** و**الاستخدام** و**المفاتيح** و**المستخدمون** و**الإعدادات**. يشير العنصر المقفول إلى أن حسابك يفتقد إذن القراءة له.

    ![قسم Admin في الشريط الجانبي للسحابة يتضمن محرر السياسات والإنفاذ والاستخدام والمفاتيح والمستخدمون والإعدادات.](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    ضع الخيارات العامة قبل الأمر، على سبيل المثال `fp --org reliability-team --json usage`.
  </Tab>
</Tabs>
