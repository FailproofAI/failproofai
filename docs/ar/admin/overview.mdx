تحتوي الإدارة على المراقبات المطلوبة لتشغيل Failproof AI عبر الفريق. يمكن لمعظم المستخدمين البقاء في الجلسات والتدقيقات والسياسات؛ يستخدم المسؤولون هذا القسم لإدارة الوصول والحدود التشغيلية.

<Tabs>
  <Tab title="Dashboard">
    استخدم قسم **Admin** في شريط جانب Cloud للوصول إلى **محرر السياسات** و**الفرض** و**الاستخدام** و**المفاتيح** و**المستخدمين** و**الإعدادات**. العنصر المقفل يشير إلى أن حسابك يفتقد إذن القراءة.

    ![قسم الإدارة في شريط جانب Cloud يعرض محرر السياسات والفرض والاستخدام والمفاتيح والمستخدمين والإعدادات.](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    ضع الخيارات العامة قبل الأمر، على سبيل المثال `fp --org reliability-team --json usage`.
  </Tab>
</Tabs>
