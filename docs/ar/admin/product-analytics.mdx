يرسل Failproof AI Cloud بيانات استخدام **عن البرنامج نفسه** إلى المسؤولين عنه. لا يشمل أبداً بيانات وكلائك. في التثبيت المستضاف ذاتياً، يكون مفعلاً بشكل افتراضي، ويمكنك إيقاف تشغيله.

## ما يتم جمعه

كل حدث يحمل خمسة أبعاد ولا شيء يعرف الشخص:

| البُعد | مثال | التعريف |
| --- | --- | --- |
| `product` | `agenteye` | أي منتج أرسله |
| `component` | `dashboard`, `server`, `cli` | أي جزء من المنتج أرسله |
| `app_version` | `0.0.1-beta.81` | الإصدار الذي تشغله |
| `deployment_kind` | `self_hosted` | ما إذا كان هذا تثبيتاً للعميل أو عرضنا التوضيحي أو اختبار الجودة أو آلة تطوير |
| `org_id` | معرّف فريد عالمي | المنظمة التي حدث فيها الإجراء، كمعرّف معتم |

بالإضافة إلى ذلك، تسجل الأحداث **ما تم استخدامه، وليس ما كان فيه أبداً**: الصفحة التي تم عرضها (كنمط مسار مثل `/:org/sessions/:id`، وليس عنوان URL الفعلي)، وعدد التصفيات من كل نوع التي تم تطبيقها، وما إذا نجح الإجراء، والوقت المستغرق.

يسجل تطبيق Slack اتصالات مساحة العمل والقطع، وربط الحسابات، والأسئلة المطروحة، والمخططات المنشورة، وقرارات الموافقة، والإخفاقات حسب فئة ثابتة. لا يشمل أبداً معرّفات مساحة عمل Slack أو المستخدم أو القناة، أو البريد الإلكتروني، أو الأسئلة، أو الإجابات، أو SQL، أو الرموز.

### اسم منظمتك

إلى جانب معرّف `org_id` المعتم، نسجل اسم منظمتك وعنوان URL الخاص بك وعنوان لوحة التحكم مرة واحدة، على سجل المنظمة بدلاً من كل حدث. يتيح لنا معرفة الحساب الذي ينتمي إليه النمط عندما ننظر إلى الاعتماد أو نحقق في مشكلة أبلغت عنها. هذه هي المعلومة المعرّفة الوحيدة التي يرسلها المنتج عنك.

### إجمالي استخدامك

يقدم الخادم إجمالي استخدام كل منظمة بالعداد، نفس الأرقام التي تراها في صفحة الاستخدام. هذه عبارة عن أرقام فقط: الأحداث والجلسات والوكلاء والبيئات وتشغيلات التقييم والنقاط وتشغيلات التدقيق والاستعلامات المحفوظة ولوحات التحكم والتنبيهات والمشاكل ومفاتيح API والأعضاء، بالإضافة إلى تواريخ نافذة الفترة المقاسة. لا تحتوي على معرّفات أو أسماء أو نصوص استعلام، وتصل سواء كان أي شخص قيد تسجيل الدخول أم لا.

## ما لا يتم جمعه أبداً

- **لا توجد توجيهات أو استجابات نموذجية أو محتوى حدث**، وليس كنص أو بادئة أو تجزئة
- **لا توجد معرّفات جلسة أو وكيل أو تتبع**
- **لا توجد أسماء نقاط المقيّم**
- **لا توجد رسائل خطأ أو نصوص استثناء أو أجسام استجابة**، فقط رمز الحالة وفئة من قائمة ثابتة
- **لا توجد حجج أداة أو SQL أو نصوص استعلام**
- **لا توجد تفاصيل التطبيق المتصل.** يرسل الاتصال أو إلغاء إذن عميل MCP عدد الأذونات على الأكثر، وليس أبداً اسم التطبيق أو أي رمز
- **لا توجد عناوين بريد إلكترونية**
- **لا توجد عناوين URL أو سلاسل استعلام للمرجع**
- **لا توجد تسجيلات الشاشة أو التقاط DOM أو تتبع النقرات والمؤشر**

## أيقفه على التثبيت المستضاف ذاتياً

اضبط `DO_NOT_TRACK=1` على لوحة التحكم والخادم كليهما. يقررون بشكل منفصل، لذا فإن ضبطه على واحد فقط يترك الآخر يقدم تقارير. أعد تشغيل الخادم حتى يتم تطبيق التغيير.

يصف ملف README للإصدار إعدادات إلغاء الاشتراك الأخرى وكيفية تأكيد إيقاف تشغيل بيانات الاستخدام.

## ping واحد عند إيقافك

إذا قمت بإيقاف التشغيل باستخدام إعداد المنتج بدلاً من `DO_NOT_TRACK`، فقد ترسل لوحة التحكم **ping مجهول واحد** تسجيل ذلك، باحتمالية 1 من أصل 1000 لكل بدء عملية. يخبرنا عن عدد المشغلين الذين يقللون بيانات الاستخدام. لا يحتوي على معرّفات: لا توجد منظمة أو مستخدم أو اسم مضيف أو عنوان URL أو عنوان IP، فقط المنتج والمكون والإصدار ونوع النشر والسبب. لا يرسل الخادم المُسلم عن شيء.

لا يتم إرساله أبداً عند استخدام `DO_NOT_TRACK`، وهذا هو السبب في أن هذا هو الإعداد الذي يجب استخدامه إذا كانت سياستك تحظر أي بيانات تلقائية خارجة.
