ترسل Failproof AI Cloud بيانات التلمترى الخاصة بالاستخدام **حول البرنامج نفسه** إلى فريق الصيانة. لا تتضمن أبداً بيانات وكلائك. في التثبيت ذاتي الاستضافة، يكون مفعلاً افتراضياً، ويمكنك تعطيله.

## ما يتم جمعه

تحمل كل حدث خمسة أبعاد ولا شيء يحدد شخصاً:

| البعد | مثال | ما هو |
| --- | --- | --- |
| `product` | `agenteye` | أي منتج أرسله |
| `component` | `dashboard`, `server`, `cli` | أي جزء من المنتج أرسله |
| `app_version` | `0.0.1-beta.81` | الإصدار الذي تقوم بتشغيله |
| `deployment_kind` | `self_hosted` | ما إذا كان هذا تثبيتاً للعميل، أو عرضنا التوضيحي، أو فحص الجودة لدينا، أو جهاز تطوير |
| `org_id` | UUID | المنظمة التي حدث الإجراء بها، كمعرّف معتم |

بالإضافة إلى تلك الأبعاد، تسجل الأحداث **ما تم استخدامه، وليس أبداً ما كان بداخله**: أي صفحة تم عرضها (كنمط مسار مثل `/:org/sessions/:id`، وليس أبداً العنوان الفعلي)، كم عدد المرشحات من أي نوع تم تطبيقها، ما إذا نجح الإجراء، والوقت الذي استغرقه.

يسجل تطبيق Slack اتصالات مساحات العمل والقطع، وربط الحسابات، والأسئلة المطروحة، والمخططات المنشورة، وقرارات الموافقة، والأعطال حسب فئة ثابتة. لا يتضمن أبداً معرفات مساحة عمل Slack أو المستخدم أو القناة، أو البريد الإلكتروني، أو الأسئلة، أو الإجابات، أو SQL، أو الرموز.

### اسم منظمتك

إلى جانب `org_id` المعتم، نسجل اسم منظمتك وعنوان URL المختصر وعنوان لوحة المعلومات مرة واحدة، في سجل المنظمة وليس في كل حدث. يتيح لنا معرفة الحساب الذي تنتمي إليه نمط عند النظر في الاعتماد أو البحث عن مشكلة أبلغت عنها. هذه هي المعلومة الوحيدة التي تحدد هويتك والتي يرسلها المنتج عنك.

### إجمالي استخدامك

يبلغ الخادم عن إجمالي استخدام كل منظمة المقننة، وهي نفس الأرقام التي تراها في صفحة الاستخدام. هذه أرقام فقط: الأحداث والجلسات والوكلاء والبيئات وعمليات التقييم والدرجات وعمليات التدقيق والاستعلامات المحفوظة ولوحات المعلومات والتنبيهات والمشاكل ومفاتيح API والأعضاء، بالإضافة إلى تواريخ نافذة القياس. لا تحتوي على معرفات أو أسماء أو نص استعلام، وتصل سواء كان هناك شخص مسجل دخول أم لا.

## ما لا يتم جمعه أبداً

- **لا توجد رسائل فورية أو استجابات نموذجية أو محتوى حدث**، لا كنص أو بادئة أو تجزئة
- **لا توجد معرفات جلسة أو وكيل أو تتبع**
- **لا توجد أسماء درجات المقيّم**
- **لا توجد رسائل خطأ أو نص استثناء أو أجسام استجابة**، فقط رمز الحالة وفئة من قائمة ثابتة
- **لا توجد حجج أدوات أو SQL أو نص استعلام**
- **لا توجد تفاصيل التطبيق المتصل.** يرسل الاتصال أو إلغاء الاتصال بعميل MCP عدد الأذونات على الأكثر، وليس أبداً اسم التطبيق أو أي رمز
- **لا توجد عناوين بريد إلكتروني**
- **لا توجد عناوين URL للمحيل أو سلاسل استعلام**
- **لا توجد تسجيلات شاشة أو التقاط DOM أو تتبع النقر والمؤشر**

## تعطيله على تثبيت ذاتي الاستضافة

اضبط `DO_NOT_TRACK=1` على لوحة المعلومات والخادم معاً. يقررانها بشكل منفصل، لذلك ضبطها على واحد فقط يترك الآخر يبلغ. أعد تشغيل الخادم لتطبيق التغيير.

يصف ملف README الإصدار الخاص بك إعدادات عدم الاشتراك الأخرى وكيفية تأكيد تعطيل التلمترى.

## ping واحد عند عدم الاشتراك

إذا قمت بإلغاء الاشتراك باستخدام إعداد المنتج بدلاً من `DO_NOT_TRACK`، قد ترسل لوحة المعلومات **ping مجهول الهوية واحد فقط** يسجل ذلك، باحتمال 1 في 1000 لكل بدء عملية. يخبرنا بعدد المشغلين الذين يعطلون التلمترى. لا يحتوي على معرفات: لا منظمة أو مستخدم أو اسم مضيف أو عنوان URL أو IP، فقط المنتج والمكون والإصدار ونوع النشر والسبب. لا يرسل خادم لم يتم الاشتراك فيه أي شيء.

لا يتم إرساله أبداً عند استخدام `DO_NOT_TRACK`، وهذا هو السبب في أن هذا هو الإعداد الذي يجب استخدامه إذا كانت سياستك تحظر أي بيانات تلمترى صادرة.

## حيث يذهب

إلى PostHog (`us.i.posthog.com`) عبر TLS على المنفذ 443. إنه اسم مضيف واحد، بحيث يمكنك أيضاً حجبه باستخدام قاعدة خروج واحدة.

لمعرفة كيفية التعامل مع المعلومات الشخصية بشكل أوسع، راجع [سياسة الخصوصية](https://befailproof.ai/privacy/).
