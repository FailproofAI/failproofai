ترسل Failproof AI Cloud بيانات قياس الاستخدام **عن البرنامج نفسه** إلى مطوريها. لا تتضمن أبداً بيانات وكلائك. في التثبيت المستضاف ذاتياً، يكون مفعلاً بشكل افتراضي، ويمكنك إيقاف تشغيله.

## ما يتم جمعه

كل حدث يحمل خمسة أبعاد ولا شيء يحدد شخصاً ما:

| البعد | مثال | ما هو |
| --- | --- | --- |
| `product` | `agenteye` | أي منتج أرسله |
| `component` | `dashboard`, `server`, `cli` | أي جزء من المنتج أرسله |
| `app_version` | `0.0.1-beta.81` | الإصدار الذي تقوم بتشغيله |
| `deployment_kind` | `self_hosted` | ما إذا كان هذا تثبيتاً للعميل أو عرضنا التوضيحي أو QA أو جهاز تطوير |
| `org_id` | UUID | الهيئة التنظيمية التي حدث فيها الإجراء، كمعرف معتم |

بالإضافة إلى ذلك، تسجل الأحداث **ما تم استخدامه، لا ما يحتويه أبداً**: أي صفحة تم عرضها (كنمط مسار مثل `/:org/sessions/:id`، وليس عنوان URL الفعلي)، وعدد المرشحات من أي نوع تم تطبيقها، وما إذا نجح الإجراء، ومدة استغرقه.

يسجل تطبيق Slack الاتصالات والقطع الكهربائية في مساحة العمل والروابط الحسابية والأسئلة المطروحة والمخططات المنشورة وقرارات الموافقة والفشل حسب فئة ثابتة. لا يتضمن أبداً معرفات مساحة عمل Slack أو المستخدم أو القناة أو البريد الإلكتروني أو الأسئلة أو الإجابات أو SQL أو الرموز.

### اسم منظمتك

إلى جانب المعرف المعتم `org_id`، نسجل اسم منظمتك وشريط URL وعنوان لوحة المعلومات مرة واحدة، على سجل منظمة وليس على كل حدث. يتيح لنا معرفة الحساب الذي ينتمي إليه النمط عند النظر في الاعتماد أو التحقيق في المشكلة التي أبلغت عنها. هذه هي المعلومة التعريفية الوحيدة التي يرسلها المنتج عنك.

### إجماليات الاستخدام الخاصة بك

يقدم الخادم إجماليات الاستخدام المقيسة لكل منظمة، وهي نفس الأرقام التي تراها على صفحة الاستخدام. هذه أرقام فقط: الأحداث والجلسات والوكلاء والبيئات وتشغيل التقييم والنقاط وتشغيل التدقيق والاستعلامات المحفوظة ولوحات المعلومات والتنبيهات والمشكلات ومفاتيح API والأعضاء، بالإضافة إلى تواريخ نافذة القياس. لا تحتوي على معرفات أو أسماء أو نص استعلام، وتصل سواء كان أي شخص مسجلاً دخولاً أم لا.

## ما لا يتم جمعه أبداً

- **لا يوجد موجهات أو استجابات نموذجية أو محتوى أحداث**، وليس كنص أو بادئة أو تجزئة
- **لا توجد معرفات الجلسة أو الوكيل أو التتبع**
- **لا توجد أسماء نقاط المقيم**
- **لا توجد رسائل خطأ أو نص استثناء أو أجسام الاستجابة**، فقط رمز الحالة وفئة من قائمة ثابتة
- **لا توجد وسيطات أدوات أو SQL أو نص استعلام**
- **لا توجد تفاصيل التطبيقات المتصلة.** يؤدي توصيل عميل MCP أو إلغاء تفويضه إلى إرسال عدد الأذونات على الأكثر، وليس اسم التطبيق أو أي رمز
- **لا توجد عناوين بريد إلكترونية**
- **لا توجد عناوين URL أو سلاسل استعلامات المحيل**
- **لا توجد تسجيلات شاشة أو التقاط DOM أو تتبع النقر والمؤشر**

## إيقاف التشغيل على التثبيت المستضاف ذاتياً

عيّن `DO_NOT_TRACK=1` على كل من لوحة المعلومات والخادم. يقررون بشكل منفصل، لذا فإن تعيينها على جانب واحد فقط يترك الآخر يقدم تقارير. أعد تشغيل الخادم لتطبيق التغيير.

يصف ملف README للإصدار الخاص بك إعدادات الانسحاب الأخرى وكيفية تأكيد إيقاف قياس الاستخدام.

## Ping واحد عند الانسحاب

إذا اخترت عدم المشاركة باستخدام إعداد المنتج بدلاً من `DO_NOT_TRACK`، فقد ترسل لوحة المعلومات **ping مجهول واحد** يسجل ذلك، باحتمالية 1 في 1000 لكل بدء عملية. يخبرنا عن عدد المشغلين الذين يقومون بإيقاف قياس الاستخدام. لا يحتوي على معرفات: لا منظمة أو مستخدم أو اسم مضيف أو URL أو IP، فقط المنتج والمكون والإصدار ونوع النشر والسبب. لا يرسل الخادم الذي اخترت عدم المشاركة فيه أي شيء.

لا يتم إرساله أبداً عند استخدام `DO_NOT_TRACK`، وهذا هو السبب في أن هذا هو الإعداد المراد استخدامه إذا كانت السياسة الخاصة بك تحظر أي قياس استخدام خارج.

إلى PostHog (`us.i.posthog.com`) عبر TLS على المنفذ 443. إنه اسم مضيف واحد، لذا يمكنك أيضاً حجبه بقاعدة خروج واحدة.
