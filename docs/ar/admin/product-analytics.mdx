يرسل Failproof AI Cloud بيانات استخدام **عن البرنامج نفسه** إلى مطوريه. لا تتضمن هذه البيانات أي معلومات عن وكلائك (agents). في التثبيت الذاتي، تكون مفعّلة بشكل افتراضي، ويمكنك إيقافها.

## ما يتم جمعه

كل حدث يحمل خمسة أبعاد فقط ولا شيء يعرّف شخصًا:

| البعد | مثال | ما هو |
| --- | --- | --- |
| `product` | `agenteye` | أي منتج أرسله |
| `component` | `dashboard`, `server`, `cli` | أي جزء من المنتج أرسله |
| `app_version` | `0.0.1-beta.81` | الإصدار الذي تقوم بتشغيله |
| `deployment_kind` | `self_hosted` | ما إذا كان هذا تثبيت عميل، أو تجريبة لدينا، أو اختبار QA، أو جهاز تطوير |
| `org_id` | معرّف فريد (UUID) | المؤسسة التي حدث فيها الإجراء، كمعرّف معتم |

بالإضافة إلى ذلك، تسجل الأحداث **ما تم استخدامه، وليس أبدًا محتواه**: الصفحة التي تم عرضها (كنمط مسار مثل `/:org/sessions/:id`، وليس العنوان الفعلي)، عدد المرشحات من كل نوع التي تم تطبيقها، ما إذا نجح الإجراء، والمدة التي استغرقها.

يسجل تطبيق Slack اتصالات وقطع الاتصالات بمساحات العمل، وربط الحسابات، والأسئلة المطروحة، والمخططات المنشورة، وقرارات الموافقة، والأخطاء حسب فئة محددة. لا يتضمن معرّفات مساحات العمل أو المستخدمين أو القنوات في Slack، أو البريد الإلكتروني، أو الأسئلة، أو الإجابات، أو SQL، أو الرموز (tokens).

### اسم مؤسستك

بجانب المعرّف المعتم `org_id`، نسجل اسم مؤسستك، رابط URL الخاص بك، وعنوان لوحة التحكم مرة واحدة فقط، في سجل المؤسسة وليس في كل حدث. يتيح لنا هذا تحديد الحساب الذي تنتمي إليه النمط عند النظر في معدل التبني أو التحقيق في مشكلة أبلغت عنها. هذه هي المعلومة الوحيدة التي تعرّفك والتي يرسلها المنتج عنك.

### إجمالي استخدامك

يبلغ الخادم عن إجمالي استخدام كل مؤسسة المقاس، وهي نفس الأرقام التي تراها في صفحة الاستخدام. هذه أرقام فقط: الأحداث والجلسات والوكلاء والبيئات ودورات التقييم والدرجات وعمليات التدقيق والاستعلامات المحفوظة ولوحات التحكم والتنبيهات والمشاكل ومفاتيح API والأعضاء، بالإضافة إلى تواريخ نافذة القياس. لا تحتوي على معرّفات أو أسماء أو نصوص استعلام، وتصل سواء كان هناك شخص مسجل الدخول أم لا.

## ما لا يتم جمعه أبدًا

- **لا توجد تعليمات (prompts) أو استجابات نموذج أو محتوى حدث**، لا كنص أو بادئة أو تجزئة (hash)
- **لا توجد معرّفات جلسة أو وكيل أو تتبع**
- **لا توجد أسماء درجات المقيّم**
- **لا توجد رسائل خطأ أو نص استثناء أو أجسام استجابة**، فقط رمز الحالة وفئة من قائمة محددة
- **لا توجد وسيطات أدوات (tool arguments) أو SQL أو نصوص استعلام**
- **لا توجد تفاصيل التطبيقات المتصلة.** الاتصال أو إلغاء اتصال عميل MCP يرسل عدد الأذونات على الأكثر، وليس أبدًا اسم التطبيق أو أي رمز (token)
- **لا توجد عناوين بريد إلكتروني**
- **لا توجد عناوين referrer أو سلاسل استعلام**
- **لا توجد تسجيلات شاشة أو التقاط DOM أو تتبع النقرات والمؤشر**

## إيقافه على التثبيت الذاتي

اضبط `DO_NOT_TRACK=1` على لوحة التحكم والخادم معًا. يقرران بشكل منفصل، لذا إذا قمت بضبطه على واحد فقط، سيستمر الآخر في الإبلاغ. أعد تشغيل الخادم لتطبيق التغيير.

يصف ملف README للإصدار الخاص بك إعدادات الاستبعاد الأخرى وكيفية التأكد من إيقاف بيانات الاستخدام.

## ping واحد عند الاستبعاد

إذا قمت بالاستبعاد باستخدام إعداد منتج بدلاً من `DO_NOT_TRACK`، قد ترسل لوحة التحكم **ping مجهول واحد فقط** مسجلة ذلك، باحتمالية 1 من 1000 لكل بدء عملية. يخبرنا عن عدد المشغلين الذين يقومون بإيقاف بيانات الاستخدام. لا يحتوي على معرّفات: لا توجد مؤسسة أو مستخدم أو اسم مضيف أو عنوان URL أو عنوان IP، فقط المنتج والمكون والإصدار ونوع النشر والسبب. الخادم المستبعد لا يرسل شيئًا.

لا يتم إرسالها أبدًا عند استخدام `DO_NOT_TRACK`، وهذا هو السبب في أن هذا هو الإعداد الذي يجب استخدامه إذا كانت سياستك تحظر أي بيانات اتصال خارجي.

## حيث تذهب

إلى PostHog (`us.i.posthog.com`) عبر TLS على المنفذ 443. إنه اسم مضيف واحد، لذا يمكنك أيضًا حظره باستخدام قاعدة استخراج واحدة فقط.
