ترسل Failproof AI Cloud بيانات الاستخدام **عن البرنامج نفسه** إلى فريق الصيانة الخاص به. لا تتضمن أبداً بيانات وكلائك. في التثبيت ذاتي الاستضافة، يكون مفعلاً بشكل افتراضي، ويمكنك إيقافه.

## ما يتم جمعه

يحمل كل حدث خمسة أبعاد ولا شيء يعرّف شخصاً:

| البعد | مثال | التعريف |
| --- | --- | --- |
| `product` | `agenteye` | المنتج الذي أرسله |
| `component` | `dashboard`, `server`, `cli` | الجزء من المنتج الذي أرسله |
| `app_version` | `0.0.1-beta.81` | الإصدار الذي تقوم بتشغيله |
| `deployment_kind` | `self_hosted` | ما إذا كان هذا تثبيتاً للعميل أو عرضنا التوضيحي أو اختباراتنا أو جهاز تطوير |
| `org_id` | معرّف UUID | المنظمة التي حدثت فيها الإجراءات، كمعرّف معتم |

بالإضافة إلى ذلك، تسجل الأحداث **ما تم استخدامه، وليس أبداً ما بداخله**: الصفحة التي تم عرضها (كنمط مسار مثل `/:org/sessions/:id`، وليس الرابط الفعلي)، وعدد المرشحات من كل نوع التي تم تطبيقها، وما إذا كان الإجراء ناجحاً، والوقت الذي استغرقه.

يسجل تطبيق Slack توصيلات واقطاعات مساحات العمل، وربط الحسابات، والأسئلة المطروحة، والمخططات المنشورة، وقرارات الموافقة، والأخطاء حسب فئة ثابتة. لا يتضمن أبداً معرّفات مساحة عمل Slack أو المستخدم أو القنوات أو البريد الإلكتروني أو الأسئلة أو الإجابات أو SQL أو الرموز.

### اسم منظمتك

بجانب معرّف `org_id` المعتم، نسجل اسم منظمتك وعنوان URL الخاص بك وعنوان لوحة التحكم مرة واحدة، على سجل المنظمة وليس على كل حدث. يتيح لنا معرفة أي حساب ينتمي إليه النمط عند النظر في الاعتماد أو التحقيق في مشكلة أبلغت عنها. هذه هي المعلومة المعرّفة الوحيدة التي يرسلها المنتج عنك.

### إجمالي الاستخدام الخاص بك

يبلغ الخادم عن إجمالي استخدام كل منظمة مقيسة، وهو نفس الأرقام التي تراها على صفحة الاستخدام. هذه أرقام فقط: الأحداث والجلسات والوكلاء والبيئات وعمليات التقييم والنقاط وعمليات التدقيق والاستعلامات المحفوظة لوحات التحكم والتنبيهات والمشاكل ومفاتيح API والأعضاء، بالإضافة إلى تواريخ نافذة القياس. لا تحتوي على معرّفات أو أسماء أو نص استعلام، وتصل سواء تم تسجيل الدخول أم لا.

## ما لا يتم جمعه أبداً

- **لا توجد موجهات أو استجابات نموذج أو محتوى حدث**، لا كنص أو بادئة أو تجزئة
- **لا توجد معرّفات جلسة أو وكيل أو تتبع**
- **لا توجد أسماء نقاط المقيّم**
- **لا توجد رسائل خطأ أو نص استثناء أو أجسام الاستجابة**، فقط رمز الحالة وفئة من قائمة ثابتة
- **لا توجد حجج أداة أو SQL أو نص استعلام**
- **لا توجد تفاصيل تطبيقات متصلة.** الاتصال أو إلغاء تفويض عميل MCP يرسل عدد الأذونات على الأكثر، وليس أبداً اسم التطبيق أو أي رمز
- **لا توجد عناوين بريد إلكترونية**
- **لا توجد عناوين URL للإحالة أو سلاسل الاستعلام**
- **لا توجد تسجيلات شاشة أو التقاط DOM أو تتبع النقرات والمؤشر**

## إيقافه في التثبيت ذاتي الاستضافة

عيّن `DO_NOT_TRACK=1` على لوحة التحكم والخادم معاً. يقررانها بشكل منفصل، لذلك قد يترك تعيينها على واحد فقط الآخر يبلغ. أعد تشغيل الخادم لتطبيق التغيير.

يصف ملف README الخاص بإصدارك الإعدادات الأخرى لإلغاء الاشتراك وكيفية تأكيد إيقاف التلميتري.

## أرسلة واحدة عند إلغاء الاشتراك

إذا قمت بإلغاء الاشتراك باستخدام إعداد المنتج بدلاً من `DO_NOT_TRACK`، قد ترسل لوحة التحكم **رسالة مجهولة واحدة** تسجل ذلك، باحتمالية 1 من كل 1000 لكل بدء عملية. يخبرنا عن عدد المشغلين الذين يقومون بإيقاف التلميتري. لا تحتوي على معرّفات: لا منظمة أو مستخدم أو اسم مضيف أو عنوان URL أو IP، فقط المنتج والمكون والإصدار ونوع النشر والسبب. الخادم الذي تم إلغاء الاشتراك عنه لا يرسل شيئاً.

لا يتم إرسالها أبداً عند استخدام `DO_NOT_TRACK`، وهذا هو السبب في أن هذا هو الإعداد الذي يجب استخدامه إذا كانت السياسة الخاصة بك تحظر أي بيانات ترسل خارجة.
