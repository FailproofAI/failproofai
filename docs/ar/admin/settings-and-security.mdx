استخدم الإعدادات للقيم التشغيلية الخاصة بالنشر وتجاوزات نافذة سياق النموذج. تفحص مخطط الإعدادات قبل تغيير أي قيمة عبر واجهة برمجية (API) أو واجهة سطر الأوامر (CLI).

## تغيير إعداد المنظمة

<Tabs>
  <Tab title="Dashboard">
    1. انتقل إلى **الإدارة → الإعدادات**، ابحث عن مجموعة الإعدادات، واقرأ وصفها والمصدر الحالي لها.
    2. غيّر القيمة واحفظها.
    3. بالنسبة لنوافذ سياق النموذج، أضف أو حدّث تجاوز النموذج وأكّد الحد الفعلي.
    4. أعد التحقق من الجلسات والمقاييس التي تعتمد على القيمة المتغيرة.

    ![صفحة الإعدادات تعرض إعدادات المصادقة التشغيلية للمنظمة.](/images/dashboard/settings.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp settings list
    fp settings schema
    fp settings set <key> --value <scalar>
    fp settings set alerts.email_default_recipients \
      --json-value '["oncall@example.com"]'
    ```

    قم بتشغيل `fp settings set --help` لمعرفة نوع القيمة وأعلام التأكيد المستخدمة من قبل واجهة سطر الأوامر المثبتة.
  </Tab>
</Tabs>

## خيارات معالجة البيانات

يؤدي توصيل failproofai CLI إلى إرسال النصوص الكاملة بشكل افتراضي لأن التتبعات والتدقيقات تعتمد على محتواها. استخدم `--no-transcripts` عندما تحتاج المحفوظات والمحتويات والإدخالات الطرفية إلى البقاء محلياً؛ يمكن لا تزال إمكانية الإبلاغ عن نشاط الخطاف وقرارات السياسة.

يتم تخزين بيانات اعتماد الامتصاص المحلية بشكل منفصل عن إعدادات الخادم غير السرية وتكتب برمز أذونات مقيدة. يجب أن تُدار مفاتيح واجهة برمجية (API) بشكل استثنائي كأسرار الإنتاج.

## مرجع إعدادات المنظمة

جميع الإعدادات القابلة للتعديل عبر لوحة التحكم تقتصر على المنظمة. يبقى السلوك على نطاق النشر من خلال تكوين بيئة الخادم.

| المفتاح | الافتراضي | الغرض |
| --- | --- | --- |
| `allowed_sign_ins` | `[]` | تقييد الأعضاء الحاليين على رسائل بريد إلكترونية دقيقة أو `*@domain`؛ القائمة الفارغة تعني عدم وجود تقييد إضافي. |
| `session_ttl_secs` | `86400` | مدة جلسة لوحة التحكم؛ النطاق المقبول هو من 60 ثانية إلى 30 يوماً. |
| `otp_ttl_secs` | `600` | مدة كلمة المرور لمرة واحدة والرابط السحري؛ النطاق المقبول هو 60–1800 ثانية. |
| `alerts.email_default_recipients` | `[]` | المستقبلون الافتراضيون عندما لا تتجاوز قناة البريد الإلكتروني للتنبيهات عنهم. |
| `alerts.slack_default_webhook` | فارغ | عنوان URL لـ Slack incoming-webhook الافتراضي. |
| `alerts.webhook_default_url` | فارغ | عنوان URL الخطاف الويب العام JSON الافتراضي. |
| `alerts.webhook_signing_secret` | فارغ | مفتاح HMAC-SHA256 المستخدم لرأس `X-AgentEye-Signature`؛ تُخفى عمليات القراءة. |
| `alerts.enabled_channels` | البريد الإلكتروني، Slack، webhook | أنواع القنوات على مستوى المنظمة التي قد توزعها قواعد التنبيهات. |
| `default_user_permissions` | `standard` | مجموعة الأذونات المسماة المحددة مسبقاً للدعوات الجديدة. |

`allowed_sign_ins` هو مرشح وليس منحة: يجب أن تكون الشخص بالفعل عضواً في المنظمة. استخدم قائمة فارغة للسماح لكل عضو؛ يتم رفض القيمة المجردة `*`. يجب أن تستخدم عناوين URL للتنبيهات HTTPS باستثناء عناوين التطوير loopback.

## قائمة الفحص الأمني

- استخدم HTTPS للاتصالات السحابية.
- حدد نطاق المفاتيح لأصغر مجموعة أذونات.
- افصل بيئات الإنتاج وغير الإنتاج.
- راجع إعدادات النسخ الكاملة والتصحيح قبل النشر.
- دقّق في تغييرات المستخدم والمفاتيح والمنظمة.
- اختبر متطلبات النسخ الاحتياطي والاحتفاظ والاستجابة للحوادث لنشرك.

  إيقاف تشغيل التقاط النصوص الكاملة يغيّر ما يمكن للتدقيقات والتحقيقات إثباته. سجل القرار والقيود المتوقعة منه.
</Warning>
