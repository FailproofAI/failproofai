يعرض الاستخدام استهلاك المؤسسة الحالية ونوافذ الفواتير الخاصة بها. استخدمه لفهم كيفية تأثير إطلاق الإنتاج وحجم النسخ والتقييمات وتكرار التدقيق على خطتك.

## مراجعة الاستخدام

<Tabs>
  <Tab title="لوحة التحكم">
    1. انتقل إلى **الإدارة → الاستخدام**.
    2. أكد المؤسسة ونافذة القياس.
    3. راجع الاستيعاب والجلسات والتقييمات والمقاييس والتدقيق والنتائج والتنبيهات والمستخدمين والمفاتيح.
    4. قارن عمل التدقيق المبدوء والمكتمل عندما يبدو استخدام التدقيق غير متوقع.

    ![صفحة الاستخدام تعرض نافذة القياس والأحداث المسجلة وخطوط أنابيب التقييم والتدقيق وموارد مساحة العمل والأعضاء ومفاتيح API.](/images/dashboard/usage-overview.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp usage
    fp --json usage
    fp --org reliability-team --json usage
    ```
  </Tab>
</Tabs>

## التحقيق في التغيير

1. أكد المؤسسة والنافذة النشطة.
2. قارن الزيادة مع حجم الجلسات حسب البيئة.
3. تحقق مما إذا بدأت عملية دمج جديدة بإرسال نسخ.
4. راجع تغييرات تكرار المُقيّم والتدقيق.
5. قارن مع الحدود على خطة التسعير الحالية.

تُرجع واجهة سطر الأوامر نفس الملخص للبرامج النصية.
