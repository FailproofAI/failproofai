يعرض الاستخدام معلومات الاستهلاك للمنظمة الحالية ونوافذ الفواتير الخاصة بها. استخدمه لفهم كيفية تأثير طرح الإنتاج وحجم النسخ المكتوبة والتقييمات وتكرار التدقيق على خطتك.

## مراجعة الاستخدام

<Tabs>
  <Tab title="لوحة المعلومات">
    1. انتقل إلى **الإدارة → الاستخدام**.
    2. أكّد المنظمة ونافذة القياس.
    3. راجع الاستقبال والجلسات والتقييمات والمقاييس والتدقيق والنتائج والتنبيهات والمستخدمين والمفاتيح.
    4. قارن عمل التدقيق المبدوء والمكتمل عندما يبدو استخدام التدقيق غير متوقع.

    ![صفحة الاستخدام تعرض نافذة القياس والأحداث المسجلة وخطوط أنابيب التقييم والتدقيق وموارد مساحة العمل والأعضاء ومفاتيح API.](/images/dashboard/usage-overview.png)
  </Tab>
  <Tab title="سطر الأوامر">
    ```bash
    fp usage
    fp --json usage
    fp --org reliability-team --json usage
    ```
  </Tab>
</Tabs>

## التحقيق في التغيير

1. أكّد المنظمة والنافذة النشطة.
2. قارن الزيادة مع حجم الجلسات حسب البيئة.
3. تحقق مما إذا كان تكامل جديد قد بدأ إرسال النسخ المكتوبة.
4. راجع تغييرات المقيّم وتكرار التدقيق.
5. قارن مع حدود خطة التسعير الحالية.

يرجع سطر الأوامر ملخصًا مشابهًا للبرامج النصية.
