تعزل المنظمات الجلسات والتقييمات والتدقيق والمشاكل والتنبيهات والاستعلامات والتجميعات والمستخدمين والمفاتيح. تأكد من نشاط المنظمة الصحيحة قبل تغيير الموارد الإدارية.

## إدارة الأعضاء والمنظمات

<Tabs>
  <Tab title="Dashboard">
    1. استخدم محدد المنظمة في أعلى شريط Cloud الجانبي لتغيير المنظمات.
    2. انتقل إلى **الإدارة → المستخدمون** للبحث عن الأعضاء أو التصفية حسب حالة النشاط والدور.
    3. اختر **مستخدم جديد**، أدخل البريد الإلكتروني، واختر مجموعة أذونات، وعدّل الاستثناءات إذا لزم الأمر.
    4. افتح مستخدمًا لاحقًا لتحديث الأذونات أو تعطيل تسجيل الدخول أو إعادة تفعيل الحساب.

    ![صفحة المستخدمين تعرض عناوين بريد الأعضاء ومجموعات الأذونات وعناصر التحكم في التعديل والتعطيل.](/images/dashboard/users.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp orgs list
    fp orgs switch reliability-team
    fp orgs current
    fp orgs perms

    fp users create engineer@example.com --permission-set standard
    fp users show engineer@example.com
    fp users update engineer@example.com --add audits:write
    fp users disable engineer@example.com
    fp users enable engineer@example.com
    ```
  </Tab>
</Tabs>

يمكن للمسؤولين إنشاء وتحديث وتعطيل وإعادة تفعيل المستخدمين، ثم تعيين مجموعة الأذونات المناسبة لدورهم. تستخدم واجهة برمجية التطبيقات عملية حذف للتعطيل، لكنها لا تزيل الحساب أو سجل العضوية الخاص به.

<Warning>
  تعطيل مستخدم يمنع هذه الهوية من تسجيل الدخول إلى أي منظمة، وليس فقط المنظمة المحددة حاليًا. إعادة التفعيل تستعيد تسجيل الدخول العام والأذونات الخاصة بالعضو في هذه المنظمة.
</Warning>

<Tip>
  أعط حسابات الخدمة أسماءً وصفية مرتبطة بعبء العمل والمالك. تجنب مشاركة المفاتيح بين المنظمات أو بين الأشخاص والآلات.
</Tip>
