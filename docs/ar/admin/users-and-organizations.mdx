تعزل المنظمات الجلسات والتقييمات والتدقيق والمشاكل والتنبيهات والاستعلامات والوحدات اللوحية والمستخدمين والمفاتيح. تأكد من المنظمة النشطة قبل تغيير الموارد الإدارية.

## إدارة الأعضاء والمنظمات

<Tabs>
  <Tab title="Dashboard">
    1. استخدم مبدل المنظمة في أعلى شريط جانب Cloud لتغيير المنظمات.
    2. انتقل إلى **Administration → Users** للبحث عن الأعضاء أو التصفية حسب حالة النشاط والدور.
    3. حدد **new user**، أدخل البريد الإلكتروني، واختر مجموعة أذونات، واضبط التجاوزات إن لزم الأمر.
    4. افتح مستخدمًا لاحقًا لتحديث الامتيازات أو تعطيل تسجيل الدخول أو إعادة تفعيل الحساب.

    ![صفحة المستخدمين توضح عناوين البريد الإلكتروني للأعضاء ومجموعات الأذونات وعناصر التحكم في التعديل والتعطيل.](/images/dashboard/users.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp orgs list
    fp orgs switch reliability-team
    fp orgs current
    fp orgs perms

    fp users create engineer@example.com --permission-set standard
    fp users show engineer@example.com
    fp users update engineer@example.com --add audits:write
    fp users disable engineer@example.com
    fp users enable engineer@example.com
    ```
  </Tab>
</Tabs>

يمكن للمسؤولين إنشاء المستخدمين وتحديثهم وتعطيلهم وإعادة تفعيلهم، ثم تعيين مجموعة الأذونات المناسبة لدورهم. تستخدم واجهة برمجية التطبيقات عملية حذف لتعطيل المستخدم، لكنها لا تزيل الحساب أو سجل العضوية.

<Warning>
  تعطيل المستخدم يمنع هذه الهوية من تسجيل الدخول إلى كل منظمة وليس فقط المنظمة المحددة حاليًا. إعادة التفعيل تعيد تسجيل الدخول العام وأذونات العضو في هذه المنظمة.
</Warning>

<Tip>
  أعطِ حسابات الخدمة أسماءً وصفية مرتبطة بعبء العمل والمالك. تجنب مشاركة المفاتيح بين المنظمات أو بين الأشخاص والآلات.
</Tip>
