نشر Failproof AI Observability كاملاً، بأمر واحد فقط. تحقق من الإنتاج، أو أنشئ مفتاح API، أو أقرّ بحادثة دون مغادرة طرفيتك، ثم قم بنصّ أي منها في CI، أو اجعل وكيل ترميز يفعل ذلك نيابة عنك بلغة إنجليزية عادية.

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*CLI agenteye يتواصل مع لوحة التحكم الخاصة بك. إنها أداة مختلفة عن المجمّع، الذي يرسل الأحداث إلى الخادم.*

## نشرك الكامل، بأمر واحد فقط

توقف عن التنقل بين التبويبات للإجابة على سؤال سريع. CLI agenteye يقرأ بيانات إنتاجك وإدارة مؤسستك من ملف تنفيذي واحد، لذلك يصبح الفحص الذي كان يعني النقر عبر لوحة التحكم سطراً واحداً يمكنك إعادة تشغيله أو إنشاء اختصار له أو لصقه في دليل التشغيل. تحصل على أربع واجهات:

- **اقرأ بيانات إنتاجك:** `sessions` و `events` و `evals` و `errors`، مع تصفية حسب الوقت والوكيل والبيئة.
- **إدارة مؤسستك:** `keys` و `users` و `settings` و `alerts` و `incidents`.
- **تشغيل التحليلات:** استعلامات SQL محفوظة بالإضافة إلى أداة `query` مخصصة على بيانات أحداثك.
- **اطلب من المساعد:** `agent ask` يصل إلى نفس المحلل المتخصص في القراءة فقط الذي تتحدث معه في لوحة التحكم.

ثبّته مرة واحدة باستخدام `pipx`، وقم بتسجيل الدخول برمز مكون من 6 أرقام يتم إرساله عبر البريد الإلكتروني، وأنت جاهز. الجلسة تستمر حوالي يوم واحد؛ أعد تشغيل `agenteye login` عندما تنتهي. استخدمه للتحقق الفوري من الإنتاج أو توفير مفتاح أو فرز حادثة تطلق التنبيهات، كل ذلك دون فتح متصفح:

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

عادة واحدة يجب معرفتها: الخيارات العامة مثل `--json` تأتي قبل الأمر. `agenteye --json sessions` صحيح؛ `agenteye sessions --json` غير صحيح.

## نصّه، ووصّله في CI

كل أمر يقبل `--json`، وهذا يغير كل شيء. JSON نظيف يذهب إلى stdout بينما حالة إنسانية وتحذيرات تذهب إلى stderr، لذا فإن التقاط `--json` ينقل مباشرة إلى `jq` دون أي سطر غريب يجب حذفه. هذا ما يجعل CLI جيداً بالتساوي بالنسبة لك في الموجه وبالنسبة لوكيل ترميز يحلل الإخراج:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

بُني للتشغيل دون مراقبة. مطالبات التأكيد تتخطى تلقائياً عندما لا يكون هناك محطة معلقة، لذا لا شيء يتوقف في خط أنابيب، وكل أمر يعيد رمز خروج معنوي: `0` نجح، `4` لم تقم بتسجيل دخول، `5` فقد صلاحية (الرسالة تسميها، على سبيل المثال `alerts:write`)، `3` لوحة التحكم غير قابلة للوصول. يمكن للنص أن يتفرع على `4` لإعادة المصادقة أو `5` لإخبارك بالضبط ما يجب أن تطلبه من مسؤول، بدلاً من الفشل الأعمى.

## دع وكيل ترميز يقوده بلغة إنجليزية عادية

الأفضل من ذلك، يجب ألا تضطر إلى تذكر أي من هذه الأعلام على الإطلاق. **مهارة CLI** هي مجلد مهارة وكيل صغير باسم `agenteye-cli` يعلّم وكيل ترميز مثل Claude Code أو Codex قيادة CLI من طلبات باللغة الإنجليزية العادية. اسأل "هل هناك أي شيء معطوب اليوم؟" والوكيل يختار الأمر، ويشغله باسمك، ويرد بنثر.

بالنسبة لـ Claude Code، اسقط مجلد `agenteye-cli` في `~/.claude/skills/` وسيتم اكتشافه تلقائياً. Failproof AI Observability يوفر المجلد؛ لا يوجد شيء إضافي لتثبيته، لأنه يقود فقط CLI الذي ثبّته بالفعل. قم بتسجيل الدخول بنفسك أولاً: المهارة لا يمكنها إكمال تسجيل دخول الرمز المرسل بالبريد نيابة عنك.

نظراً لأن الوكيل يقود CLI باسمك، يمكنه فعل كل ما تسمح به عمليتك، القراءة والكتابة على حد سواء: إنشاء مفاتيح، تغيير الإعدادات، حل الحوادث. مطالبة "هل أنت متأكد؟" في CLI لا تطلق للوكيل، لذا فإن المهارة مكتوبة لتوضيح الأمر الدقيق والانتظار لموافقتك قبل أي تغيير. أنت خطوة التأكيد.

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

البيانات المقروءة تبقى فورية، وكل كتابة توقف لانتظارك:

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
