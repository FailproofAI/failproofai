نشر Failproof AI Observability بالكامل، على بعد أمر واحد فقط. تحقق من الإنتاج، أنشئ مفتاح API، أو أقر حادثة دون مغادرة المحطة الطرفية، ثم قم بأتمتة أي منها في CI، أو اترك وكيل ترميز يقوم به بلغة إنجليزية عادية.

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*واجهة سطر الأوامر `agenteye` تتواصل مع لوحة التحكم. إنها أداة مختلفة عن المجمع، الذي يرسل الأحداث إلى الخادم.*

## نشرك بالكامل، أمر واحد فقط

توقف عن التنقل بين علامات التبويب للإجابة على سؤال سريع. واجهة سطر أوامر `agenteye` تقرأ بيانات وتدير مؤسستك من ثنائي واحد، لذلك التحقق الذي كان يتطلب النقر عبر لوحة التحكم يصبح سطراً واحداً يمكنك إعادة تشغيله أو إنشاء اختصار له أو لصقه في كتاب التشغيل. تحصل على أربع واجهات:

- **اقرأ بيانات:** `sessions` و `events` و `evals` و `errors`، مصفاة حسب الوقت والوكيل والبيئة.
- **أدر مؤسستك:** `keys` و `users` و `settings` و `alerts` و `incidents`.
- **قم بتشغيل التحليلات:** SQL محفوظة بالإضافة إلى أداة `query` موحدة على بيانات الأحداث الخاصة بك.
- **اسأل المساعد:** `agent ask` يصل إلى نفس محلل القراءة فقط الذي تتحدث معه في لوحة التحكم.

ثبته مرة واحدة باستخدام `pipx`، وقم بتسجيل الدخول باستخدام كود سادس الأرقام المرسل عبر البريد الإلكتروني، وأنت جاهز. تستمر الجلسة حوالي يوم واحد؛ أعد تشغيل `agenteye login` عند انتهاء صلاحيتها. استخدمه للتحقق السريع من الإنتاج أو تجهيز مفتاح أو فرز حادثة نشطة، كل هذا دون فتح متصفح:

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

عادة واحدة يجب معرفتها: الخيارات العامة مثل `--json` تأتي قبل الأمر. `agenteye --json sessions` صحيح؛ `agenteye sessions --json` خطأ.

## قم بأتمتته، وربطه مع CI

كل أمر يتبنى `--json`، وهذا يغير كل شيء. JSON نظيف يذهب إلى stdout بينما حالة بشرية وتحذيرات تذهب إلى stderr، لذلك التقاط `--json` يمرر مباشرة إلى `jq` بدون سطر شارد يجب تجريده. هذا ما يجعل واجهة سطر الأوامر جيدة بنفس القدر لك في المحطة الطرفية وللوكيل ترميز يحلل الإخراج:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

إنها مبنية للتشغيل بدون إشراف. موجهات التأكيد تتخطى تلقائياً عند عدم وجود محطة طرفية مرفقة، لذلك لا شيء يتعطل في خط أنابيب، وكل أمر يرجع كود خروج ذو معنى: `0` نجاح، `4` لم يتم تسجيل الدخول، `5` إذن مفقود (الرسالة تسميه، مثلاً `alerts:write`)، `3` لوحة التحكم غير متاحة. يمكن للنص البرمجي أن يتفرع على `4` لإعادة المصادقة أو `5` لإخبارك بالضبط ما تطلبه من المسؤول، بدلاً من الفشل الأعمى.

## دع وكيل ترميز يقوده بلغة إنجليزية عادية

الأفضل من ذلك، لا يجب أن تتذكر أي من هذه الأعلام على الإطلاق. **مهارة CLI** عبارة عن مجلد مهارة وكيل صغير باسم `agenteye-cli` يعلم وكيل ترميز مثل Claude Code أو Codex كيفية قيادة واجهة سطر الأوامر من طلبات باللغة الإنجليزية العادية. اسأل "هل هناك شيء معطل اليوم؟" والوكيل يختار الأمر، ينفذه كأنت، ويجيب بالنثر.

بالنسبة لـ Claude Code، أسقط مجلد `agenteye-cli` في `~/.claude/skills/` وسيتم اكتشافه تلقائياً. توفر Failproof AI Observability المجلد؛ لا يوجد شيء إضافي للتثبيت، لأنها تقود فقط واجهة سطر الأوامس التي ثبتتها بالفعل. قم بتسجيل الدخول بنفسك أولاً: لا يمكن للمهارة إكمال تسجيل الدخول برمز مرسل بريد لك.

لأن الوكيل يشغل واجهة سطر الأوامر كأنت، يمكنه فعل كل شيء يسمح به تسجيل الدخول الخاص بك، قراءات وكتابات على حد سواء: إنشاء مفاتيح، تغيير الإعدادات، حل الحوادث. موجه "هل أنت متأكد؟" في واجهة سطر الأوامر لا يحدث للوكيل، لذلك يتم كتابة المهارة لبيان الأمر الدقيق والانتظار لموافقتك قبل أي تغيير. أنت خطوة التأكيد.

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

تبقى القراءات فورية، وكل كتابة تتوقف من أجلك:

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
