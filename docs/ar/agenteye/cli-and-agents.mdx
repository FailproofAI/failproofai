نشر Failproof AI Observability بالكامل، على بعد أمر واحد فقط. تحقق من الإنتاج، أصدر مفتاح API، أو أقرّ حادثة دون مغادرة المحطة الطرفية، ثم وسّع أي منها إلى CI، أو دع وكيل ترميز يفعلها لك باللغة الطبيعية.

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*واجهة سطر الأوامر `agenteye` تتواصل مع لوحة التحكم الخاصة بك. وهي أداة مختلفة عن جامع البيانات الذي يرسل الأحداث إلى الخادم.*

## نشرك بالكامل، أمر واحد فقط

توقف عن الانتقال بين الألسنة للإجابة على سؤال سريع. واجهة سطر الأوامر `agenteye` تقرأ بيانات الأداة وتدير مؤسستك من ملف واحد، لذا فإن الفحص الذي كان يعني النقر عبر لوحة التحكم يصبح سطر واحد يمكنك إعادة تشغيله أو تعيينه أو لصقه في دليل التشغيل. ستحصل على أربع واجهات:

- **اقرأ بيانات الأداة:** `sessions` و `events` و `evals` و `errors`، مصفاة حسب الوقت والوكيل والبيئة.
- **أدر مؤسستك:** `keys` و `users` و `settings` و `alerts` و `incidents`.
- **قم بتشغيل التحليلات:** SQL المحفوظة بالإضافة إلى أداة `query` مخصصة لبيانات الأحداث الخاصة بك.
- **اطلب من المساعد:** `agent ask` يصل إلى نفس محلل قراءة فقط الذي تتحدث معه في لوحة التحكم.

ثبّتها مرة واحدة باستخدام `pipx`، وسجّل الدخول باستخدام رمز 6 أرقام تم إرساله عبر البريد الإلكتروني، وأنت جاهز. تستمر الجلسة حوالي يوم واحد؛ أعد تشغيل `agenteye login` عند انتهاء صلاحيتها. استخدمها للتحقق من الإنتاج أو توفير مفتاح أو فحص حادثة حريق فوري، كل هذا دون فتح مستعرض:

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

عادة واحدة يجب معرفتها: الخيارات العامة مثل `--json` تذهب قبل الأمر. `agenteye --json sessions` صحيح؛ `agenteye sessions --json` ليس كذلك.

## وسّعها، قم بربطها في CI

كل أمر يأخذ `--json`، وهذا يغير كل شيء. JSON نظيف يذهب إلى stdout بينما الحالة البشرية والتحذيرات تذهب إلى stderr، لذا فإن التقاط `--json` يُنقل مباشرة إلى `jq` دون سطر غريب للتجريد. هذا ما يجعل واجهة سطر الأوامر جيدة بنفس القدر لك في المحطة الطرفية ووكيل ترميز يحلل النتاج:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

تم بناؤها للتشغيل دون إشراف. تخطي مطالبات التأكيد تلقائياً عندما لا تكون محطة طرفية مرفقة، لذا لا شيء يتعطل في خط أنابيب، وكل أمر يعيد رمز خروج ذي معنى: `0` نجاح، `4` لم يتم تسجيل الدخول، `5` حق وصول مفقود (الرسالة تسميها، على سبيل المثال `alerts:write`)، `3` لوحة التحكم غير متاحة. يمكن للبرنامج النصي أن يتفرع على `4` لإعادة المصادقة أو `5` لإخبارك بالضبط ما يجب أن تطلبه من المسؤول، بدلاً من الفشل بشكل عمياني.

## دع وكيل ترميز يقودها باللغة الطبيعية

الأفضل من ذلك، لا يجب عليك تذكر أي من هذه الأعلام على الإطلاق. **مهارة واجهة سطر الأوامر** هي مجلد مهارة Agent صغير باسم `agenteye-cli` الذي يعلّم وكيل ترميز مثل Claude Code أو Codex قيادة واجهة سطر الأوامر من الطلبات باللغة الإنجليزية العادية. اسأل "هل هناك أي شيء معطل اليوم؟" والوكيل يختار الأمر ويشغله بصفتك ويجيب بالنثر.

بالنسبة إلى Claude Code، أسقط مجلد `agenteye-cli` في `~/.claude/skills/` وسيتم اكتشافه تلقائياً. يوفر Failproof AI Observability المجلد؛ لا يوجد شيء إضافي للتثبيت، لأنه يقود واجهة سطر الأوامر التي ثبتها بالفعل. سجّل الدخول بنفسك أولاً: المهارة لا يمكنها إكمال تسجيل الدخول برمز البريد الإلكتروني لك.

نظراً لأن الوكيل يشغل واجهة سطر الأوامر بصفتك، يمكنه القيام بكل شيء يسمح به تسجيل الدخول الخاص بك، القراءة والكتابة على حد سواء: إنشاء المفاتيح وتغيير الإعدادات وحل الحوادث. مطالبة "هل أنت متأكد؟" في واجهة سطر الأوامر لا تُطلق لوكيل، لذا تمت كتابة المهارة لذكر الأمر الدقيق والانتظار للموافقة قبل أي تغيير. أنت خطوة التأكيد.

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

البيانات المقروءة تبقى فورية، وكل كتابة توقف للانتظار:

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
