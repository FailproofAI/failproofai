اسحب بيانات الجلسات والأحداث والتقييمات (وشغّل إعادة التقييمات) مباشرة من سكريبت أو عامل ترميز، مع JSON نظيف على stdout يتدفق مباشرة إلى `jq`. تحول هذه الوصفات بيانات Failproof AI Observability إلى شيء يمكن لمستخدم طرفية أو عامل ترميز ذكي (Claude Code، Cursor) أن يستعلم عنه ويقوم بأتمتته، دون الحاجة للنقر عبر لوحة التحكم.

الأنماط أدناه جاهزة للنسخ واللصق لسطر أوامر Failproof AI Observability (`agenteye`). للتثبيت والمصادقة والقائمة الكاملة للخيارات، راجع [CLI](/ar/agenteye/cli)؛ شغّل `agenteye -h` أو `agenteye <command> -h` للمساعدة المدمجة.

## القواعد الذهبية

1. **الخيارات العامة تأتي *قبل* الأمر.** `agenteye --json sessions` صحيح؛ `agenteye sessions --json` خاطئ. الخيارات العامة هي `--json`، `--base-url`، `--org`، `--token`، `--insecure`/`--secure`، `--timeout`، `--quiet`، `--no-color`.
2. **مرر `--json` كلما قمت بتحليل الإخراج.** البيانات تذهب إلى **stdout** كـ JSON؛ حالة الإنسان والأخطاء تذهب إلى **stderr**، لذا يبقى stdout نظيفًا للأنابيب إلى `jq`.
3. **افرع بناءً على رمز الخروج**، وليس نص stderr: `0` موافق · `1` خطأ غير متوقع · `2` حجج سيئة · `3` لا يمكن الوصول إلى لوحة التحكم · `4` لم تقم بتسجيل الدخول أو انتهت الجلسة · `5` صلاحية مفقودة · `6` المورد غير موجود.
4. **اكتشف باستخدام `-h`.** كل أمر يوثق مرشحاته وصيغ القيم وشكل JSON.

## إعداد لمرة واحدة

```bash
export AGENTEYE_DASHBOARD_URL=https://agenteye.example.com   # حتى لا تكرر --base-url
agenteye login --email you@example.com                       # الصق الكود المُرسل بالبريد الإلكتروني؛ صالح ~24 ساعة
```

## تأكد من المصادقة قبل القيام بالعمل

`whoami` لا يرجع أخطاء على جلسة مفقودة أو منتهية الصلاحية؛ بدلاً من ذلك يُبلغ عن `logged_in:false`، لذا يمكن للعامل أن يفحص حالة المصادقة بأمان. (يمكنه أيضًا أن يخرج برمز غير صفري إذا لم يتم تعيين عنوان URL أساسي أو كانت لوحة التحكم غير قابلة للوصول.)

```bash
if [ "$(agenteye --json whoami | jq -r .logged_in)" != "true" ]; then
  echo "Not authenticated. Run: agenteye login" >&2; exit 1
fi
```

## ابحث عن الجلسات الفاشلة أو منخفضة التصنيف

```bash
# جلسات في آخر 24 ساعة حدث خطأ في تقييمها
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'

# التقييمات التي تسجل <= 0.5 على المساعدة، لعامل واحد
agenteye --json evals --agent-id checkout-bot --score helpfulness:..0.5 \
  | jq '.evaluations[] | {session_id, scores}'
```

يعيش تصفية النقاط على **`evals`**، وليس `sessions`. `--score KEY:MIN..MAX` قابل للتكرار ومدمج بـ AND؛ أي حد اختياري (`..0.5` يعني ≤ 0.5، `0.9..` يعني ≥ 0.9). يمكنك تمرير ما يصل إلى 20 مرشح نقاط لكل طلب؛ أكثر من ذلك يرجع HTTP 400. يشارك `sessions` مرشحات `--env`، `--status`، `--agent-id`، `--session-id`، ونطاق الوقت مع `evals`، لكنه لا يحتوي على `--score`.

## اقرأ جلسة واحدة من البداية إلى النهاية

لا توجد أمر واحد `session show`. ادمج مسار الأحداث مع تقييم الجلسة:

```bash
# أحدث تقييم للجلسة (الحالة + النقاط)
agenteye --json evals --session-id run-001 | jq '.evaluations[0] | {status, scores}'

# كل حدث في المشغل (رفع --limit للمسح الكامل)
agenteye --json events --session-id run-001 --all --limit 1000 | jq '.events[] | {ts, event_type}'

# فقط استدعاءات الأدوات في جلسة (--full مطلوب للحصول على payload الخام)
agenteye --json events --full --session-id run-001 --event-type tool_use,tool_result --all \
  | jq '.events[].payload'
```

> **ملاحظة:** بشكل افتراضي، يقرأ `events` موجز سريع خالي من payload. كل حدث يحمل ملخص محسوب من الخادم بسطر واحد `summary` بالإضافة إلى أعلام مثل `is_error` وحسابات الرموز، لكن `payload` يعود كـ `{}`. لسحب payload الخام، أضف `--full` (أو `--fields payload`). موجز الكمال أبطأ في الحجم، لذا اجعله محدودًا: ادمج `--full` مع `--session-id` واحد.

## اسحب كل شيء (الترقيم)

النتائج الأحدث أولاً وقائمة على المؤشر.

```bash
# لقطة واحدة: اسحب ما يصل إلى 500 صف في صفحات 200 صف
agenteye --json events --session-id run-001 --limit 500 --all > events.json

# ترقيم يدوي: غذي next_cursor مرة أخرى
page=$(agenteye --json events --limit 100)
cursor=$(echo "$page" | jq -r '.next_cursor // empty')
[ -n "$cursor" ] && agenteye --json events --limit 100 --cursor "$cursor"
```

## نحّف الإخراج باستخدام --fields

قيّد المفاتيح (في كل من الجدول و`--json`) لتقليل ما يجب على العامل قراءته.

```bash
agenteye --json sessions --since 7d --fields session_id,status,scores | jq -c '.sessions[]'
agenteye --json events --session-id run-001 --fields ts,event_type --all
```

أسماء الحقول غير المعروفة يتم رفضها (خروج `2`) مع القائمة الصحيحة، وهي طريقة رخيصة لاكتشاف أسماء الحقول.

## اكتشف قيم المرشح الصحيحة

```bash
agenteye --json list envs | jq -r '.values[]'           # قيم --env
agenteye --json list tools | jq -r '.values[]'          # أسماء الأدوات؛ أيضًا agents و models و event_types وغيرها
agenteye --json list score_filters | jq -r '.values[]'  # KEY الصحيح لـ --score KEY:MIN..MAX
```

## اختر منظمتك (متعدد المستأجرين)

إذا كنت تنتمي إلى أكثر من منظمة واحدة، اختر المستأجر النشط عند تسجيل الدخول (يتم حفظه):

```bash
agenteye login --org acme --email you@corp.com   # اضبط المستأجر في نفس خطوة تسجيل الدخول
agenteye --json orgs list | jq -r '.orgs[].org_slug'
agenteye --org globex --json sessions --since 24h   # تجاوز لأمر واحد
```

تسجيل دخول متعدد المنظمات بدون `--org` يخرج برمز غير صفري ويطبع المنظمات للاختيار منها.

## مفتاح API للـ SDK/collector

```bash
# يتم طباعة السر مرة واحدة، مع --json إنه حقل .key
key=$(agenteye --json keys create ci-bot --add events:read.add | jq -r '.key')
agenteye keys regenerate ci-bot --yes    # دوّر؛ agenteye keys disable ci-bot --yes للإلغاء
```

## شغّل استعلامًا محفوظًا أو حسب الطلب

```bash
agenteye --json query run --sql "select count(*) from analytics.events" | jq '.rows'
agenteye --json query run errs --arg prod | jq '.rows'   # استعلام محفوظ + موضعي $1
```

## تصنيف حادثة بدون تفاعل

```bash
id=$(agenteye --json incidents list --state firing | jq -r '.incidents[0].id')
agenteye incidents ack "$id"
agenteye incidents assign "$id" --assignee you@corp.com
agenteye incidents resolve "$id" --yes
```

> **ملاحظة:** التحويرات تتخطى تلقائيًا موجز التأكيد الخاص بها تحت `--json` أو عندما لا يكون stdin TTY، لذا لن يتعلق العملاء؛ مرر `--yes`/`-y` لتخطيه بشكل صريح في مكان آخر.

## معالجة رمز الخروج في سكريبت

```bash
out=$(agenteye --json sessions --since 1h) || code=$?
case "${code:-0}" in
  0) echo "$out" | jq '.sessions | length' ;;
  4) echo "Session expired - run 'agenteye login'." >&2 ;;
  5) echo "Missing permission (ask an admin for evaluations:read)." >&2 ;;
  3) echo "Dashboard unreachable - check the URL." >&2 ;;
  *) echo "Unexpected error (exit ${code})." >&2 ;;
esac
```

## أشكال إخراج JSON

| الأمر | stdout JSON (مع `--json`) |
|---|---|
| `whoami` | `{"logged_in": true, "id", "email", "is_instance_admin", "active_org", "permissions": [...], "memberships": [...]}` أو `{"logged_in": false}` |
| `orgs list` | `{"active_org", "orgs": [{"org_slug","org_name","permission_set","permissions"}]}` |
| `events` | `{"events": [...], "next_cursor": <cursor or null>}` |
| `evals` | `{"evaluations": [...], "next_cursor": <cursor or null>}` |
| `sessions` | `{"sessions": [...], "next_cursor": <cursor or null>}` |
| `errors` | `{"errors": [...], "next_cursor": <cursor or null>}` |
| `list <kind>` | `{"kind", "values": [...]}` |
| `keys list` / `keys create` | `{"keys": [...]}` / `{id, name, permissions, created_at, key}` (`key` يظهر مرة واحدة) |
| `query run` | `{columns: [{name,type}], rows: [[...]], truncated, elapsed_ms}` |
| `users list` / `settings list` | `{"users": [...]}` / `{"settings": [...]}` |
| `alerts list` / `incidents list` | `{"alerts": [...]}` / `{"incidents": [...]}` |
| create/update/delete (أي) | كائن المورد، أو `{"deleted": true, "id"}` للحذف |
| فشل (أي، مع `--json`) | `{"error": "...", "exit_code": <n>, "status"?: <http>, "hint"?: "..."}` على stdout |

- كل عنصر **event** (`events`): `id, session_id, agent_id, event_type, ts, payload, environment, summary, is_error, error_type, output_tokens, context_window, context_fill`. لاحظ أن `payload` هو `{}` إلا إذا طلبت موجز الكمال مع `--full` (أو `--fields payload`).
- كل عنصر **evaluation** (`evals`): `id, session_id, agent_id, environment, status, scores, reasoning, summary, error, attempt_count, duration_ms, completed_at, created_at`.
- كل عنصر **session** (`sessions`): `session_id, agent_id, environment, status, scores, event_count, started_at, last_event_at, first_event_id, last_event_id, latest_evaluation`.

يقبل كل أمر `--fields` بالضبط أسماء حقول عنصره الخاص. تختلف المجموعة بين `sessions` و `evals`، لذا قد يكون الاسم الصحيح لأحدهما مرفوضًا من الآخر.
