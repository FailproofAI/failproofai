مهندسوك يستخدمون OpenAI Codex بالفعل كل يوم. التقاط جلسات Codex يجلب تلك الجلسات البرمجية إلى AgentEye كجلسات وأحداث عادية، بحيث يمكنك البحث عنها وإعادة تشغيلها وتقييمها جنباً إلى جنب مع كل شيء آخر تراقبه. إنه يكمل [Python SDK](/ar/agenteye/python-sdk): الـ SDK يُجهز الوكلاء التي تكتبها، بينما هذا يلتقط عمل Codex الذي يقوم به فريقك بالفعل — بدون أي تغيير في كيفية تشغيله.

محصِّل خلفية صغير يقرأ نصوص جلسات Codex المحلية أثناء كتابتها ويرسلها إلى AgentEye. جهاز جمع واحد لكل جهاز يلتقط كل سطح محلي من Codex في نفس الوقت — لا توجد إعدادات منفصلة لكل سطح.

نفس الجهاز يلتقط وكلاء آخرين أيضاً — انظر [OpenClaw](/ar/agenteye/openclaw-capture) و [Hermes](/ar/agenteye/hermes-capture). فعّل كل واحد تقوم بتشغيله؛ يمكن لجهاز جمع واحد التقاط عدة أجهزة في نفس الوقت.

---

## ما يتم التقاطه

كل سطح Codex يعمل **محلياً** ينتج نفس نصوص جلسات على القرص، وجهاز الجمع يلتقطها جميعاً:

- **واجهة سطر أوامر** Codex و `codex exec`
- **ملحق VS Code / IDE**
- **تطبيق سطح المكتب**، عندما يقوم بتشغيل جلسة محلياً

تصبح كل جلسة Codex [جلسة](/ar/agenteye/sessions) في AgentEye؛ رسائل المستخدم والمساعد والمنطق واستدعاءات الأدوات ونتائج الأدوات واستخدام الرموز تصبح [أحداث](/ar/agenteye/event-stream) المطابقة. يتم تسجيل السطح الذي جاءت منه كل جلسة (واجهة سطر الأوامر أو IDE أو سطح المكتب)، بحيث يمكنك التمييز بينها.

> **جلسات السحابة لا يتم التقاطها.** يقوم تطبيق سطح المكتب بشكل متزايد بتشغيل الجلسات في سحابة Codex ويحتفظ فقط ببيانات تعريفها على الجهاز — لا يوجد نص محلي للقراءة. يتم التقاط الجلسات المُنفذة محلياً فقط.

---

## تشغيله

التقاط مُطفأ حتى تقوم بتفعيله. ثبّت جهاز الجمع باستخدام مفتاح API له إذن `events:add` (انظر [API keys](/ar/agenteye/api-keys))، وفعّل التقاط Codex:

```bash
curl -fsSL https://raw.githubusercontent.com/FailproofAI/agenteye-collector/main/install.sh \
  | sh -s -- --key <YOUR_API_KEY> --codex-enabled
```

يثبت هذا جهاز الجمع، ويسجله كخدمة خلفية، ويبدأ الالتقاط. تأكد من أنه يعمل:

```bash
agenteye-collector health
```

عند التشغيل الأول، يتم إعادة ملء جلساتك الموجودة في Codex مرة واحدة ثم يتدفق النشاط الجديد في غضون ثوان. ملفات Codex الخاصة به يتم قراءتها فقط — لا يتم تعديلها أو نقلها أو حذفها — وكل جلسة يتم شحنها مرة واحدة بالضبط، حتى عند إعادة التشغيل.

---

## حيث تظهر

تظهر الجلسات الملتقطة في **Sessions**، وأحداثها في تدفق **Events**، مثل أي وكيل آخر تراقبه — لذلك [إعادة تشغيل الجلسة](/ar/agenteye/sessions) و [البحث](/ar/agenteye/queries) و [التقييمات](/ar/agenteye/evaluations) و [التنبيهات](/ar/agenteye/alerts) تعمل جميعها عليها. قم بالتصفية حسب وكيل Codex لرؤيتها بمفردها.

---

## الخصوصية

نصوص Codex تحتوي على الجلسة الكاملة — بما في ذلك إخراج الأوامر ومحتويات الملفات وأي شيء قرأه Codex أو كتبه — وقد تحتوي على أسرار. يتم شحن الجلسات الملتقطة كما هي، لذا فعّل الالتقاط فقط على الأجهزة والفرق حيث يكون من المناسب مركزية هذا المحتوى في AgentEye، وأعط جهاز الجمع مفتاح مقتصر على `events:add` فقط. انظر [Security](/ar/agenteye/security) لمعرفة كيفية عزل بيانات الخاص بك.
