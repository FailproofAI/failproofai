مهندسوك يشغلون OpenAI Codex بالفعل كل يوم. التقاط جلسات Codex يجلب تلك جلسات البرمجة إلى AgentEye كجلسات وأحداث عادية، حتى تتمكن من البحث والتشغيل المتكرر وتقييمها جنباً إلى جنب مع كل شيء آخر تلاحظه. إنه يكمل [Python SDK](/ar/agenteye/python-sdk): يقوم الـ SDK بأداة تجهيز الوكلاء التي تكتبها، بينما يلتقط هذا عمل Codex الذي يقوم به فريقك بالفعل — دون أي تغيير في طريقة تشغيله.

جامع خلفي صغير يقرأ نسخ جلسات Codex المحلية عند كتابتها وينقلها إلى AgentEye. جامع واحد لكل جهاز يلتقط كل سطح Codex محلي في وقت واحد — لا توجد عملية إعداد لكل سطح.

---

## ما يتم التقاطه

كل سطح Codex يعمل **محلياً** ينتج نفس نسخ جلسات على القرص، والجامع يلتقط كل منها:

- Codex **CLI** و `codex exec`
- **VS Code / IDE extension**
- **تطبيق سطح المكتب**، عند تشغيله لجلسة محلياً

تصبح كل جلسة Codex [جلسة](/ar/agenteye/sessions) في AgentEye؛ رسائل المستخدم والمساعد، التفكير، استدعاءات الأدوات، نتائج الأدوات، واستخدام الرموز تصبح [أحداث](/ar/agenteye/event-stream) المطابقة. يتم تسجيل السطح الذي جاءت منه كل جلسة (CLI أو IDE أو سطح المكتب)، حتى تتمكن من التمييز بينها.

> **لا يتم التقاط الجلسات السحابية.** يشغل تطبيق سطح المكتب بشكل متزايد الجلسات في سحابة Codex ويحتفظ فقط بالبيانات الوصفية الخاصة بها على الجهاز — لا توجد نسخة محلية للقراءة. يتم التقاط الجلسات المنفذة محلياً فقط.

---

## تفعيلها

التقاط معطل حتى تقوم بتفعيله. ثبّت الجامع باستخدام مفتاح API له صلاحية `events:add` (انظر [مفاتيح API](/ar/agenteye/api-keys))، وشغّل التقاط Codex:

```bash
curl -fsSL https://raw.githubusercontent.com/FailproofAI/agenteye-collector/main/install.sh \
  | sh -s -- --key <YOUR_API_KEY> --codex-enabled
```

هذا يثبت الجامع، ويسجله كخدمة خلفية، ويبدأ التقاط. تأكد من أنه يعمل:

```bash
agenteye-collector health
```

عند التشغيل الأول، يتم ملء جلسات Codex الموجودة مرة واحدة وتتدفق النشاط الجديد بعد ذلك في غضون ثوانٍ. ملفات Codex الخاصة بها يتم قراءتها فقط — لا تُعدَّل أو تُنقَل أو تُحذف — وتُرسل كل جلسة مرة واحدة بالضبط، حتى عبر إعادة التشغيل.

---

## حيث تظهر

تظهر الجلسات المُلتقطة في **Sessions**، وأحداثها في تدفق **Events**، مثل أي وكيل آخر تلاحظه — لذا فإن [جلسة التشغيل المتكرر](/ar/agenteye/sessions)، و[البحث](/ar/agenteye/queries)، و[التقييمات](/ar/agenteye/evaluations)، و[التنبيهات](/ar/agenteye/alerts) كلها تعمل عليها. قم بالتصفية حسب وكيل Codex لرؤيتها بمفردها.

---

## الخصوصية

نسخ Codex تحتوي على الجلسة الكاملة — بما في ذلك مخرجات الأوامر ومحتويات الملفات وأي شيء قرأه أو كتبه Codex — ويمكن أن تحتوي على أسرار. يتم شحن الجلسات المُلتقطة كما هي، لذا قم بتفعيل التقاط فقط على الأجهزة والفريق حيث يكون تركيز هذا المحتوى في AgentEye مناسباً، وأعطِ الجامع مفتاحاً محدد النطاق فقط لـ `events:add`. انظر [Security](/ar/agenteye/security) لمعرفة كيفية الحفاظ على عزلة بياناتك.
