مهندسوك يشغلون OpenAI Codex بالفعل كل يوم. التقاط جلسات Codex يجلب تلك الجلسات البرمجية إلى AgentEye كجلسات وأحداث عادية، بحيث يمكنك البحث فيها وإعادة تشغيلها وتقييمها جنباً إلى جنب مع كل شيء آخر تلاحظه. وهو يكمل [Python SDK](/ar/agenteye/python-sdk): يجهز SDK الوكلاء الذين تكتبهم، بينما يلتقط هذا عمل Codex الذي يقوم به فريقك بالفعل — دون أي تغيير في طريقة تشغيلهم له.

جامع خلفي صغير يقرأ نسخ جلسات Codex المحلية عند كتابتها وينقلها إلى AgentEye. جامع واحد لكل جهاز يلتقط كل سطح Codex محلي في نفس الوقت — لا توجد إعدادات منفصلة لكل سطح.

يلتقط الجامع نفسه وكلاء آخرين أيضاً — انظر [OpenClaw](/ar/agenteye/openclaw-capture) و [Hermes](/ar/agenteye/hermes-capture). فعّل كل واحد تشغله؛ يمكن لجامع واحد التقاط عدة منها في نفس الوقت.

---

## ما الذي يلتقطه

كل سطح Codex يعمل **محلياً** ينتج نفس نسخ الجلسات المخزنة على القرص، والجامع يلتقطها جميعاً:

- **CLI** من Codex و `codex exec`
- **ملحق VS Code / IDE**
- **تطبيق سطح المكتب**، عند تشغيل جلسة محلياً

تصبح كل جلسة Codex [جلسة](/ar/agenteye/sessions) في AgentEye؛ رسائل المستخدم والمساعد والاستدلال واستدعاءات الأدوات ونتائج الأدوات واستخدام الرموز تصبح [أحداث](/ar/agenteye/event-stream) مطابقة. يتم تسجيل السطح الذي أتت منه كل جلسة (CLI أو IDE أو سطح المكتب)، بحيث يمكنك التمييز بينها.

> **لا يتم التقاط الجلسات السحابية.** يعمل تطبيق سطح المكتب بشكل متزايد على تشغيل الجلسات في سحابة Codex ويحتفظ فقط بالبيانات الوصفية الخاصة بها على الجهاز — لا توجد نسخة محلية للقراءة. يتم التقاط الجلسات المنفذة محلياً فقط.

## تشغيله

الالتقاط معطّل حتى تفعّله. ثبّت الجامع باستخدام مفتاح API يمتلك صلاحية `events:add` (انظر [مفاتيح API](/ar/agenteye/api-keys))، وفعّل التقاط Codex:

```bash
curl -fsSL https://raw.githubusercontent.com/FailproofAI/agenteye-collector/main/install.sh \
  | sh -s -- --key <YOUR_API_KEY> --codex-enabled
```

يثبّت هذا الجامع، ويسجله كخدمة خلفية، ويبدأ الالتقاط. تأكد من أنه يعمل:

```bash
agenteye-collector health
```

عند التشغيل الأول، يتم ملء جلساتك الموجودة من Codex مرة واحدة والنشاط الجديد ينساب بعد ذلك خلال ثوان. ملفات Codex الخاصة تقرأ فقط — لم تُعدّل أبداً أو تُنقل أو تُحذف — وتُرسل كل جلسة بالضبط مرة واحدة، حتى عبر إعادة التشغيل.

---

## حيث تظهر

تظهر الجلسات الملتقطة في **الجلسات**، وأحداثها في دفق **الأحداث**، مثل أي وكيل آخر تراقبه — لذا [إعادة تشغيل الجلسة](/ar/agenteye/sessions) و [البحث](/ar/agenteye/queries) و [التقييمات](/ar/agenteye/evaluations) و [التنبيهات](/ar/agenteye/alerts) تعمل جميعاً عليها. صفّي حسب وكيل Codex لمشاهدتها بمفردها.

---

## الخصوصية

نسخ Codex تحتوي على الجلسة الكاملة — بما فيها مخرجات الأوامر ومحتويات الملفات وأي شيء قرأه أو كتبه Codex — وقد تحتوي على أسرار. يتم نقل الجلسات الملتقطة كما هي، لذا فعّل الالتقاط فقط على الأجهزة والفرق حيث يكون تركيز هذا المحتوى في AgentEye مناسباً، وأعطِ الجامع مفتاحاً مقتصراً على `events:add` فقط. انظر [الأمان](/ar/agenteye/security) لمعرفة كيفية عزل بياناتك.
