استخدم تدقيقًا محليًا للمراجعة الفورية والخاصة قبل توصيل جهاز بـ Failproof AI Cloud. يقوم بمسح سجلات الوكيل المخزنة بالفعل على جهازك، وإعادة تشغيل نشاط الأدوات من خلال السياسات المدمجة، وفتح لوحة تحكم نتائج محلية.

## تشغيل تدقيق تفاعلي

<Tabs>
  <Tab title="Dashboard">
    يبدأ التدقيق المحلي من واجهة سطر الأوامر لأنه يجب أن يكتشف السجلات على الجهاز الحالي. قم بتشغيل `failproofai audit`؛ بعد الفحص، يبدأ Failproof AI لوحة التحكم المضمنة ويفتح **http://localhost:8020/audit**.

    في عرض التدقيق، راجع عدد الجلسات واستدعاءات الأدوات والمشاريع وضربات السياسة. ابدأ بالنتائج المتكررة، ثم افحص المشروع المتأثر وسجل الوكيل قبل تمكين الإنفاذ.

    <Info>لوحة تحكم التدقيق المحلية منفصلة عن **Analyze → Audits** في Failproof AI Cloud. تبقى التدقيقات المحلية على الجهاز ولا تتطلب حسابًا أو اتصالاً بالشبكة.</Info>
  </Tab>
  <Tab title="CLI">
    ```bash
    npm install -g failproofai
    failproofai audit
    ```

    تؤدي الأمر إلى فحص كامل لكل سجل مدعوم يعثر عليه. الأمر الحالي لا يقبل عوامل تصفية مثل `--since` أو `--cli` أو `--project` أو `--port` أو `--no-open`.

    اترك العملية قيد التشغيل أثناء استخدام لوحة التحكم المحلية. اضغط على <kbd>Ctrl</kbd>+<kbd>C</kbd> عند الانتهاء.
  </Tab>
</Tabs>

تستطيع محولات التدقيق الحالية قراءة السجلات من Claude Code و Codex و GitHub Copilot CLI و Cursor و OpenCode و Pi و Hermes و OpenClaw و Factory و Devin و Antigravity و Goose. يتم فحص السجلات المتاحة محليًا فقط.

## جدولة التدقيقات المحلية المتكررة

<Tabs>
  <Tab title="Dashboard">
    افتح **Settings** في لوحة التحكم المحلية، وقم بتمكين التدقيقات المجدولة، واختر الفاصل الزمني، وعيّن عنوان البريد الإلكتروني الذي يجب أن يتلقى النتائج. تقوم لوحة التحكم وواجهة سطر الأوامر بتحديث نفس تكوين الجهاز.
  </Tab>
  <Tab title="CLI">
    قم بتمكين تدقيق أسبوعي وأرسل النتائج إلى العنوان المسمى:

    ```bash
    failproofai audit --schedule 7 --email reliability@example.com
    failproofai audit --status
    ```

    يقبل الفاصل الزمني 1-90 يومًا والافتراضي هو 7 عند الحذف. الإعداد الأول يوقعك عندما لزم الأمر؛ يوفر `--email` عنوان التقرير دون المطالبة.

    أوقف الجدولة دون حذف سجل التدقيق المحلي:

    ```bash
    failproofai audit --no-schedule
    ```
  </Tab>
</Tabs>

يقوم المراقب بتشغيل عمليات مسح مجدولة في الخلفية، وتحديث النتيجة المخزنة مؤقتًا المستخدمة بواسطة لوحة التحكم المحلية، وإرسال بريد إلكتروني بالتقرير المكون. استخدم `failproofai audit` عندما تريد تشغيل فحص تفاعلي على الفور.

## الانتقال من الأدلة المحلية إلى عمليات Cloud

التدقيق المحلي هو خط أساس سريع. قم بتوصيل الجهاز بـ Failproof AI Cloud عندما تحتاج إلى آثار مشتركة وتدقيقات سكانية متكررة والنتائج والمشاكل والتنبيهات ونشر السياسات على مستوى المؤسسة أو صحة الأسطول.
