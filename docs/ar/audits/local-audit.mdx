استخدم تدقيقًا محليًا للحصول على مراجعة فورية وخاصة قبل توصيل جهاز بـ Failproof AI Cloud. يقوم بمسح سجلات الوكيل المخزنة بالفعل على جهازك، وإعادة تشغيل نشاط الأدوات من خلال السياسات المدمجة، وفتح لوحة معلومات النتائج المحلية.

## تشغيل تدقيق تفاعلي

<Tabs>
  <Tab title="لوحة المعلومات">
    يبدأ التدقيق المحلي من واجهة الأوامر لأنه يجب أن يكتشف السجلات على الجهاز الحالي. شغّل `failproofai audit`؛ بعد المسح، يبدأ Failproof AI لوحة المعلومات المضمنة ويفتح **http://localhost:8020/audit**.

    في عرض التدقيق، راجع عدد الجلسات واستدعاءات الأدوات والمشاريع وضربات السياسة. ابدأ بالنتائج المتكررة، ثم افحص المشروع المتأثر وسجل وكيل قبل تفعيل الفرض.

    <Info>لوحة معلومات التدقيق المحلية منفصلة عن **تحليل → التدقيقات** في Failproof AI Cloud. التدقيقات المحلية تبقى على الجهاز ولا تتطلب حسابًا أو اتصالاً بالشبكة.</Info>
  </Tab>
  <Tab title="واجهة الأوامر">
    ```bash
    npm install -g failproofai
    failproofai audit
    ```

    تنفذ الأمر مسحًا كاملاً لكل سجل مدعوم يجده. لا يقبل الأمر الحالي مرشحات مثل `--since` أو `--cli` أو `--project` أو `--port` أو `--no-open`.

    اترك العملية قيد التشغيل أثناء استخدام لوحة المعلومات المحلية. اضغط <kbd>Ctrl</kbd>+<kbd>C</kbd> عند الانتهاء.
  </Tab>
</Tabs>

يمكن لمحولات التدقيق الحالية قراءة السجلات من Claude Code و Codex و GitHub Copilot CLI و Cursor و OpenCode و Pi و Hermes و OpenClaw و Factory و Devin و Antigravity و Goose. يتم مسح السجلات المتاحة محليًا فقط.

## جدولة التدقيقات المحلية المتكررة

<Tabs>
  <Tab title="لوحة المعلومات">
    افتح **الإعدادات** في لوحة المعلومات المحلية، فعّل التدقيقات المجدولة، واختر الفترة الزمنية، وعيّن عنوان البريد الإلكتروني الذي يجب أن يتلقى النتائج. تحدّث لوحة المعلومات وواجهة الأوامر نفس إعدادات الجهاز.
  </Tab>
  <Tab title="واجهة الأوامر">
    فعّل تدقيقًا أسبوعيًا وأرسل النتائج إلى العنوان المسمى:

    ```bash
    failproofai audit --schedule 7 --email reliability@example.com
    failproofai audit --status
    ```

    تقبل الفترة الزمنية 1-90 يومًا وتعود إلى 7 عند الحذف. تسجل الإعداد الأول دخولك عند الحاجة؛ `--email` توفر عنوان التقرير دون طلب.

    أوقف الجدول دون حذف سجل التدقيق المحلي:

    ```bash
    failproofai audit --no-schedule
    ```
  </Tab>
</Tabs>

يقوم مراقب الخدمة بتشغيل عمليات المسح المجدولة في الخلفية، وتحديث النتيجة المخزنة مؤقتًا المستخدمة بواسطة لوحة المعلومات المحلية، وإرسال البريد بالتقرير المكون. استخدم `failproofai audit` عندما تريد تشغيل مسح تفاعلي فورًا.

## الانتقال من الأدلة المحلية إلى عمليات Cloud

التدقيق المحلي هو خط أساس سريع. اتصل بالجهاز بـ Failproof AI Cloud عندما تحتاج إلى آثار مشتركة وتدقيقات سكانية متكررة وأوجد قصور والمشاكل والتنبيهات ونشر السياسة على مستوى المنظمة أو صحة الأسطول.
