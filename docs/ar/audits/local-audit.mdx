استخدم التدقيق المحلي لمراجعة فورية وخاصة قبل توصيل جهاز بـ Failproof AI Cloud. يقوم بمسح سجلات الوكيل المخزنة بالفعل على جهازك، وتشغيل نشاط الأداة من خلال السياسات المدمجة، وفتح لوحة نتائج محلية.

## تشغيل تدقيق تفاعلي

<Tabs>
  <Tab title="Dashboard">
    يبدأ التدقيق المحلي من سطر الأوامر لأنه يجب أن يكتشف السجلات على الجهاز الحالي. قم بتشغيل `failproofai audit`؛ بعد المسح، يبدأ Failproof AI لوحة المعلومات المرفقة ويفتح **http://localhost:8020/audit**.

    في عرض التدقيق، راجع عدد الجلسات واستدعاءات الأداة والمشاريع والنتائج المتعلقة بالسياسة. ابدأ بالنتائج المتكررة، ثم افحص المشروع المتأثر وسجل الوكيل قبل تفعيل الإنفاذ.

    <Info>لوحة معلومات التدقيق المحلية منفصلة عن **Analyze → Audits** في Failproof AI Cloud. التدققيقات المحلية تبقى على الجهاز ولا تتطلب حسابًا أو اتصالاً بالشبكة.</Info>
  </Tab>
  <Tab title="CLI">
    ```bash
    npm install -g failproofai
    failproofai audit
    ```

    الأمر يجري مسحًا كاملاً لكل سجل مدعوم يجده. الأمر الحالي لا يقبل عوامل تصفية مثل `--since` أو `--cli` أو `--project` أو `--port` أو `--no-open`.

    اترك العملية قيد التشغيل أثناء استخدام لوحة المعلومات المحلية. اضغط على <kbd>Ctrl</kbd>+<kbd>C</kbd> عند الانتهاء.
  </Tab>
</Tabs>

محولات التدقيق الحالية يمكنها قراءة السجلات من Claude Code و Codex و GitHub Copilot CLI و Cursor و OpenCode و Pi و Hermes و OpenClaw و Factory و Devin و Antigravity و Goose. يتم مسح السجلات المتاحة محليًا فقط.

## جدولة التدققيقات المحلية المتكررة

<Tabs>
  <Tab title="Dashboard">
    افتح **Settings** في لوحة المعلومات المحلية، وفعّل التدققيقات المجدولة، واختر الفاصل الزمني، وعيّن عنوان البريد الإلكتروني الذي يجب أن يستقبل النتائج. تحدّث لوحة المعلومات وسطر الأوامر نفس إعدادات الجهاز.
  </Tab>
  <Tab title="CLI">
    فعّل تدقيقًا أسبوعيًا وأرسل النتائج إلى العنوان المحدد:

    ```bash
    failproofai audit --schedule 7 --email reliability@example.com
    failproofai audit --status
    ```

    يقبل الفاصل الزمني 1-90 يومًا ويعود إلى 7 عند إغفاله. يوقع عليك الإعداد الأول عند الحاجة؛ يوفر `--email` عنوان التقرير دون طلب.

    أوقف الجدول دون حذف سجل التدقيق المحلي:

    ```bash
    failproofai audit --no-schedule
    ```
  </Tab>
</Tabs>

يشغّل الخادم عمليات المسح المجدولة في الخلفية، وينعش النتيجة المخزنة مؤقتًا المستخدمة من قبل لوحة المعلومات المحلية، ويرسل التقرير المُعد. استخدم `failproofai audit` عندما تريد تشغيل مسح تفاعلي فورًا.

## الانتقال من الأدلة المحلية إلى عمليات Cloud

التدقيق المحلي أساس سريع. وصّل الجهاز بـ Failproof AI Cloud عندما تحتاج إلى تتبعات مشتركة أو تدققيقات سكانية متكررة أو نتائج ومشاكل أو تنبيهات أو نشر السياسات على مستوى المنظمة أو صحة الأسطول.
