استخدم هذه كأهداف بداية، ثم أضف وكيلك وبيئتك وسير العمل المتوقع.

<Tabs>
  <Tab title="Dashboard">
    انتقل إلى **Analyze → Audits → New audit**، انسخ إحدى الوصفات في الوصف أو الملخص، ثم أضف البيئة والوكيل والفترة الزمنية ورابط المراجع ذات الصلة. أنشئ التدقيق وتفحص التشغيل الأول قبل جدولته.

    يحول نموذج التدقيق الجديد الوصفة إلى فحص فشل قابل للتنفيذ بإضافة النطاق والسياق والإيقاع والإخطارات.

    ![نموذج التدقيق الجديد المكون بهدف مركز وجدول زمني ونطاق الوكيل والبيئة والسياق وقنوات الإخطار.](/images/dashboard/audit-new.png)

    بعد الإنشاء، تأكد من ظهور التدقيق في القائمة بالحالة والجدول الزمني المتوقع قبل الاعتماد على التشغيلات المتكررة.

    ![صفحة التدقيقات حيث تظهر وصفة التدقيق الخاصة بسير العمل بعد الإنشاء.](/images/dashboard/audits.png)

    افتح التشغيل الأول وقم بتحسين الوصفة إذا كانت نتائجها أوسع أو أضيق من نمط الفشل المقصود.
  </Tab>
  <Tab title="CLI">
    احفظ الوصفة كملف نصي وأرفقها أثناء الإنشاء:

    ```bash
    fp audits create retry-loop-review \
      --scope '{"environments":["production"]}' \
      --text-file ./retry-loop-audit.txt \
      --schedule-interval-secs 86400
    ```
  </Tab>
</Tabs>

<AccordionGroup>
  <Accordion title="حلقات إعادة المحاولة المتكررة">
    ابحث عن الجلسات التي يكرر فيها الوكيل نفس استدعاء الأداة الفاشلة دون تغيير الإدخال أو اختيار أداة بديلة أو التصعيد إلى شخص ما.
  </Accordion>
  <Accordion title="استخدام الأداة غير الصحيح">
    ابحث عن الجلسات التي لا تطابق فيها الأداة المختارة المهمة المذكورة، أو حيث يخالف إدخال الأداة الشروط المسبقة المطلوبة لسير العمل.
  </Accordion>
  <Accordion title="الوصول غير الآمن للبيانات">
    ابحث عن الجلسات التي تقرأ أو تكتب أو تنقل بيانات حساسة خارج المسارات والخدمات المعتمدة لهذا الوكيل.
  </Accordion>
  <Accordion title="التخلي عن المهمة">
    ابحث عن الجلسات التي تنتهي بدون النتيجة المطلوبة أو خطأ واضح أو تسليم صريح لشخص ما.
  </Accordion>
  <Accordion title="انحدار التكلفة أو الكمون">
    ابحث عن الجلسات التي تتجاوز فيها مدة النموذج أو الأداة أو الإجمالية الميزانية المتوقعة، وحدد نمط الحدث المسؤول.
  </Accordion>
  <Accordion title="تصعيد بشري مفقود">
    ابحث عن الجلسات التي تطلبت فيها الثقة أو الفشل المتكرر أو التوجيه السياساتي قرار بشري لكن الوكيل استمر بشكل مستقل.
  </Accordion>
</AccordionGroup>
