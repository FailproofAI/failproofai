---

```bash
failproofai
```

يبدأ لوحة المعلومات على الويب على `http://localhost:8020`.

## الخيارات

| العلم | الوصف |
|------|--------|
| `--port <number>` | المنفذ للاستماع عليه (الافتراضي: `8020`) |
| `--allowed-origins <origins>` | المضيفون/عناوين IP المسموح لهم بالوصول إلى موارد التطوير، مفصولة بفواصل |

لتوجيه لوحة المعلومات إلى مجلد مشروع Claude غير افتراضي، عيّن متغير البيئة `CLAUDE_PROJECTS_PATH` عند البدء.

## أمثلة

```bash
# شغّل على منفذ مختلف
failproofai --port 9000

# استخدم مسار مشاريع Claude مخصص عبر متغير البيئة
CLAUDE_PROJECTS_PATH=~/my-claude-projects failproofai
```
