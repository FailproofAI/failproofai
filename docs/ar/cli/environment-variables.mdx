## لوحة التحكم

| المتغير | الوصف |
|----------|-------------|
| `PORT` | منفذ لوحة التحكم (الافتراضي: `8020`) |
| `CLAUDE_PROJECTS_PATH` | تجاوز موقع مجلدات مشاريع Claude Code |
| `FAILPROOFAI_DISABLE_PAGES=policies,projects` | صفحات لوحة التحكم المراد إخفاؤها مفصولة بفواصل |
| `FAILPROOFAI_ALLOWED_DEV_ORIGINS` | المضيفون/عناوين IP المسموح لهم بالوصول إلى موارد التطوير. نفس `--allowed-origins`. |

## تسجيل السجلات

| المتغير | الوصف |
|----------|-------------|
| `FAILPROOFAI_LOG_LEVEL=info\|warn\|error` | مستوى سجل الخادم (الافتراضي: `warn`) |
| `FAILPROOFAI_HOOK_LOG_FILE` | مسار ملف السجل المخصص للربط، أو `true` للافتراضي (`~/.failproofai/logs/hooks.log`) |

## قياس الاستخدام

يقوم failproofai بالإبلاغ عن قياس الاستخدام المجهول افتراضياً. هناك طريقتان لإيقافه، وسيتم اختيار الخيار الأكثر تقييداً - لا يمكن لمتغير بيئة أبداً إعادة تفعيل شيء قام ملف التكوين بإيقافه.

| المتغير | الوصف |
|----------|-------------|
| `FAILPROOFAI_TELEMETRY_DISABLED=1` | تعطيل قياس الاستخدام المجهول لهذه العملية |

لتعطيله بشكل دائم على الجهاز، أضف هذا إلى `~/.failproofai/config.toml`:

```toml
[telemetry]
enabled = false
```

<Note>
ملف التكوين هو الخيار المراد استخدامه إذا كنت تشغل خادم **failproofaid**. الخادم هو خدمة نطاق النظام، وبيئته لا تتضمن المتغيرات المُصدَّرة من الغلاف الخاص بك — لذا لا يمكن لـ `FAILPROOFAI_TELEMETRY_DISABLED` الوصول إليه. `[telemetry] enabled = false` يُقرأ بواسطة كل من واجهة سطر الأوامر والخادم.
</Note>

يقوم الخادم بالإبلاغ عن **دورة حياته** فقط: أنه بدأ (وما إذا انتهت المحاولة السابقة بشكل نظيف)، أنه توقف، عندما تم استنتاج مشغل التقييم أو إعادة تشغيله، عندما فشلت مهمة جمع البيانات، ونتيجة سحب السياسة السحابية. وتتميز هذه بقيم منخفضة الأساسية وعدادات — لم يتم أبداً استخراج مسار ملف أو أمر أو سياسة أو موجه أو أي شيء من نسخة. لا توجد حدث لكل استدعاء أداة.

## المصادقة

| المتغير | الوصف |
|----------|-------------|
| `FAILPROOF_API_URL` | تجاوز عنوان URL الأساسي لخادم API الذي تستخدمه نافذة مصادقة لوحة التحكم. الافتراضي هو `https://api.befailproof.ai`؛ اضبطه على `http://localhost:8080` (أو أي مكان آخر) عند تشغيل خادم api محلي. |
| `FAILPROOFAI_AUTH_DIR` | تجاوز حيث يتم تخزين `auth.json` (الافتراضي: `~/.failproofai`). مفيد بشكل أساسي للاختبارات المعزولة. |

## موجه التشغيل الأول

| المتغير | الوصف |
|----------|-------------|
| `FAILPROOFAI_NO_FIRST_RUN=1` | تخطي الموجه الذي يعرض تثبيت السياسات عند استدعاء `failproofai` الأولي العاري |

## LLM (لتقييم السياسة)

| المتغير | الوصف |
|----------|-------------|
| `FAILPROOFAI_LLM_BASE_URL` | نقطة نهاية LLM API (الافتراضي: `https://api.openai.com/v1`) |
| `FAILPROOFAI_LLM_API_KEY` | مفتاح API للسياسات المدعومة بـ LLM |
| `FAILPROOFAI_LLM_MODEL` | اسم النموذج (الافتراضي: `gpt-4o-mini`) |
