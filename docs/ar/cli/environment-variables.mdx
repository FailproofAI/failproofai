## لوحة المراقبة

| المتغير | الوصف |
|----------|-------------|
| `PORT` | منفذ لوحة المراقبة (الافتراضي: `8020`) |
| `CLAUDE_PROJECTS_PATH` | تجاوز موقع مجلدات مشاريع Claude Code |
| `FAILPROOFAI_DISABLE_PAGES=policies,projects` | صفحات لوحة المراقبة المفصولة بفواصل لإخفاؤها |
| `FAILPROOFAI_ALLOWED_DEV_ORIGINS` | الأجهزة/عناوين IP المسموح لها بالوصول إلى موارد التطوير. نفس `--allowed-origins`. |

## السجلات

| المتغير | الوصف |
|----------|-------------|
| `FAILPROOFAI_LOG_LEVEL=info\|warn\|error` | مستوى سجل الخادم (الافتراضي: `warn`) |
| `FAILPROOFAI_HOOK_LOG_FILE` | مسار ملف سجل hook مخصص، أو `true` للقيمة الافتراضية (`~/.failproofai/logs/hooks.log`) |

## القياس عن بعد

يقوم failproofai بإرسال بيانات تلقائية مجهولة المصدر عن الاستخدام بشكل افتراضي. هناك طريقتان لإيقاف تشغيلها، وتُحل كل منهما بما هو أكثر تقييدًا — لا يمكن لمتغير البيئة أبدًا إعادة تمكين شيء ما قام ملف الإعدادات بإيقاف تشغيله.

| المتغير | الوصف |
|----------|-------------|
| `FAILPROOFAI_TELEMETRY_DISABLED=1` | عطّل بيانات الاستخدام المجهولة المصدر لهذه العملية |

لإيقاف تشغيله بشكل دائم على الجهاز، أضف هذا إلى `~/.failproofai/config.toml`:

```toml
[telemetry]
enabled = false
```

<Note>
ملف الإعدادات هو الخيار المراد استخدامه إذا كنت تشغل **failproofaid daemon**.
الخدمة الخلفية هي خدمة على مستوى النظام، والبيئة الخاصة بها لا تتضمن متغيرات مُصدَّرة من الـ shell الخاص بك — لذا لا يمكن لـ `FAILPROOFAI_TELEMETRY_DISABLED` الوصول إليها. يتم قراءة `[telemetry] enabled = false` بواسطة كل من CLI والخدمة الخلفية.
</Note>

تُبلّغ الخدمة الخلفية عن **دورة حياتها** فقط: أنها بدأت (وما إذا كان التشغيل السابق قد انتهى بشكل نظيف)، وأنها توقفت، ومتى تم إنشاء أو إعادة تشغيل مُقيّم العامل الخاص بها، ومتى فشلت مهمة جامع، والنتيجة من سحب السياسة السحابية. تحمل هذه قيمًا وعددًا محدودة الصحة — لا تتضمن أبدًا مسار ملف أو أمرًا أو سياسة أو موجه أو أي شيء تم قراءته من نسخة. لا توجد حدث لكل استدعاء أداة.

## المصادقة

| المتغير | الوصف |
|----------|-------------|
| `FAILPROOF_API_URL` | تجاوز عنوان URL الأساسي لخادم api المستخدم بواسطة حوار مصادقة لوحة المراقبة. القيمة الافتراضية `https://api.befailproof.ai`؛ عيّن `http://localhost:8080` (أو في أي مكان آخر) عند تشغيل خادم api محلي. |
| `FAILPROOFAI_AUTH_DIR` | تجاوز موقع تخزين `auth.json` (الافتراضي: `~/.failproofai`). مفيد بشكل أساسي للاختبارات المعزولة. |

## موجه التشغيل الأول

| المتغير | الوصف |
|----------|-------------|
| `FAILPROOFAI_NO_FIRST_RUN=1` | تخطّ الموجه الذي يعرض تثبيت السياسات عند أول استدعاء عادي لـ `failproofai` |

## LLM (لتقييم السياسة)

| المتغير | الوصف |
|----------|-------------|
| `FAILPROOFAI_LLM_BASE_URL` | نقطة نهاية LLM API (الافتراضي: `https://api.openai.com/v1`) |
| `FAILPROOFAI_LLM_API_KEY` | مفتاح API للسياسات التي يدعمها LLM |
| `FAILPROOFAI_LLM_MODEL` | اسم النموذج (الافتراضي: `gpt-4o-mini`) |
