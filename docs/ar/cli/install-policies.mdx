```bash
failproofai policies --install [policy-names...] [options]
```

يكتب مدخلات hook في ملف الإعدادات الخاص بـ CLI الوكيل المثبت لديك (Claude Code أو OpenAI Codex أو GitHub Copilot CLI _(beta)_) بحيث يتم اعتراض استدعاءات الأدوات بواسطة failproofai.

الأسماء المستعارة: `failproofai p -i`

## الخيارات

| الخيار | الوصف |
|------|-------------|
| `--cli claude\|codex\|copilot` | CLI الوكيل (الوكلاء) المراد التثبيت لها؛ مفصولة بمسافات (على سبيل المثال `--cli claude codex copilot`) أو مكررة. حذفها للكشف التلقائي عن CLIs المثبتة والطلب منك الاختيار. |
| `--scope user` | تثبيت في ملف الإعدادات بنطاق المستخدم (Claude: `~/.claude/settings.json`؛ Codex: `~/.codex/hooks.json`؛ Copilot: `~/.copilot/hooks/failproofai.json`). الخيار الافتراضي. |
| `--scope project` | تثبيت في ملف الإعدادات بنطاق المشروع (Claude: `<cwd>/.claude/settings.json`؛ Codex: `<cwd>/.codex/hooks.json`؛ Copilot: `<cwd>/.github/hooks/failproofai.json`). |
| `--scope local` | Claude فقط — التثبيت في `<cwd>/.claude/settings.local.json`. لا يتوفر نطاق `local` في Codex و Copilot. |
| `--custom <path>` / `-c` | المسار إلى ملف JS يحتوي على سياسات hook مخصصة |

## السلوك

- **بدون أسماء سياسات** - فتح موجه تفاعلي لاختيار السياسات
- **أسماء محددة** - تفعيل هذه السياسات (إضافتها إلى أي سياسات مفعلة بالفعل)
- **`all`** - تفعيل كل سياسة متاحة

التثبيت تراكمي: تشغيل `--install` مرة أخرى يضيف سياسات جديدة دون إزالة السياسات الموجودة.

## أمثلة

```bash
# تثبيت جميع السياسات الافتراضية عالميًا (تفاعلي)
failproofai policies --install

# تثبيت سياسات محددة للمشروع الحالي
failproofai policies --install block-sudo sanitize-api-keys --scope project

# تفعيل جميع السياسات في المرة الواحدة
failproofai policies --install all

# التثبيت مع ملف سياسات مخصص
failproofai policies --install --custom ./my-policies.js

# التثبيت لـ OpenAI Codex (نطاق المشروع)
failproofai policies --install --cli codex --scope project

# التثبيت لـ GitHub Copilot CLI (beta) للمشروع الحالي
failproofai policies --install --cli copilot --scope project

# التثبيت للـ CLIs الثلاثة في المرة الواحدة
failproofai policies --install --cli claude codex copilot
```

عند توفير `--custom <path>`، يتم التحقق من الملف فورًا - يجب أن يستدعي `customPolicies.add()` مرة واحدة على الأقل. يتم حفظ المسار المحلول في `policies-config.json` باسم `customPoliciesPath`.
