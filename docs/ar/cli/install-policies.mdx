---

```bash
failproofai policies --install [policy-names...] [options]
```

يكتب إدخالات hook في ملف الإعدادات الخاص بـ agent CLI المثبت لديك (Claude Code أو OpenAI Codex أو GitHub Copilot CLI _(beta)_) بحيث يعترض failproofai استدعاءات الأدوات.

الاختصارات: `failproofai p -i`

## الخيارات

| العلم | الوصف |
|------|-------------|
| `--cli claude\|codex\|copilot` | CLI(s) الوكيل المراد التثبيت عليه؛ مفصول بمسافات (مثل `--cli claude codex copilot`) أو مكرر. اترك فارغاً للكشف عن CLIs المثبتة والمطالبة. |
| `--scope user` | التثبيت في ملف إعدادات النطاق الشخصي (Claude: `~/.claude/settings.json`؛ Codex: `~/.codex/hooks.json`؛ Copilot: `~/.copilot/hooks/failproofai.json`). الافتراضي. |
| `--scope project` | التثبيت في ملف إعدادات نطاق المشروع (Claude: `<cwd>/.claude/settings.json`؛ Codex: `<cwd>/.codex/hooks.json`؛ Copilot: `<cwd>/.github/hooks/failproofai.json`). |
| `--scope local` | Claude فقط — تثبيت في `<cwd>/.claude/settings.local.json`. لا يملك Codex و Copilot نطاق `local`. |
| `--custom <path>` / `-c` | المسار إلى ملف JS يحتوي على سياسات hook مخصصة |

## السلوك

- **لا توجد أسماء سياسات** - يفتح موجه تفاعلي لتحديد السياسات
- **أسماء محددة** - تفعيل تلك السياسات (مضافة إلى أي سياسات مفعلة بالفعل)
- **`all`** - تفعيل كل سياسة متاحة

التثبيت تراكمي: تشغيل `--install` مرة أخرى يضيف سياسات جديدة دون إزالة الموجودة.

## أمثلة

```bash
# تثبيت جميع السياسات الافتراضية على المستوى العام (تفاعلي)
failproofai policies --install

# تثبيت سياسات محددة للمشروع الحالي
failproofai policies --install block-sudo sanitize-api-keys --scope project

# تفعيل جميع السياسات دفعة واحدة
failproofai policies --install all

# التثبيت مع ملف سياسات مخصص
failproofai policies --install --custom ./my-policies.js

# التثبيت لـ OpenAI Codex (نطاق المشروع)
failproofai policies --install --cli codex --scope project

# التثبيت لـ GitHub Copilot CLI (beta) للمشروع الحالي
failproofai policies --install --cli copilot --scope project

# التثبيت لجميع CLIs الثلاثة في نفس الوقت
failproofai policies --install --cli claude codex copilot
```

عند توفير `--custom <path>`، يتم التحقق من الملف على الفور - يجب أن يستدعي `customPolicies.add()` مرة واحدة على الأقل. يتم حفظ المسار المحل في `policies-config.json` كـ `customPoliciesPath`.
