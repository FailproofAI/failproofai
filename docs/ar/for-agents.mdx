أضف مرجع Failproof AI الكامل إلى وكيل الترميز الخاص بك بأمر واحد. يعمل مع Claude Code و Cursor و Windsurf وأي وكيل آخر يدعم المهارات.

```bash
npx skills add https://docs.befailproof.ai
```

يكتشف `npx skills` الوكلاء المثبتين لديك ويضيف المهارة بالتنسيق الصحيح لكل منها تلقائياً.

## ما تغطيه المهارة

| المنطقة | ما هو مشمول |
|------|----------------|
| السياسات | أسماء السياسات المدمجة وأنواع الأحداث والمعاملات والتفعيل/التعطيل |
| السياسات المخصصة | `customPolicies.add()`، مرشحات المطابقة، واجهة برمجية `allow`/`deny`/`instruct` |
| كائن السياق | `ctx.eventType`، `ctx.toolName`، `ctx.toolInput`، `ctx.session` |
| الإعدادات | هيكل `policies-config.json`، دمج النطاقات، `policyParams` |
| سطر الأوامر | `failproofai policies --install`، `--uninstall`، `--custom`، النطاقات |
| لوحة البيانات | عارض الجلسات، نشاط السياسة، متغيرات البيئة |
| البنية | تدفق معالج الخطاف، رموز الخروج، عقد stdin/stdout |

## هل المهارة كاملة؟

ينشئ Mintlify `llms.txt` من جميع الصفحات في التنقل. وثائق Failproof AI تغطي واجهة برمجية كاملة - كل سياسة وخيار ومثال مدرج. إذا وجدت شيئاً ناقصاً، المصدر موجود في `https://docs.befailproof.ai/llms-full.txt`.

للحصول على سياق موجه، قم بالربط مباشرة إلى صفحة محددة:

```bash
# فقط واجهة برمجية السياسات المخصصة
npx skills add https://docs.befailproof.ai/custom-policies

# فقط السياسات المدمجة
npx skills add https://docs.befailproof.ai/built-in-policies
```
