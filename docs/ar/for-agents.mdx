أضف مرجع Failproof AI الكامل إلى وكيل الترميز الخاص بك بأمر واحد. يعمل مع Claude Code و Cursor و Windsurf وأي وكيل آخر يدعم المهارات.

```bash
npx skills add https://docs.befailproof.ai
```

يكتشف `npx skills` الوكلاء المثبتين لديك ويضيف المهارة بالصيغة الصحيحة لكل منهم تلقائياً.

## ما الذي تغطيه المهارة

| المنطقة | ما هو مضمون |
|------|----------------|
| السياسات | أسماء السياسات المدمجة، أنواع الأحداث، المعاملات، التفعيل/الإلغاء |
| السياسات المخصصة | `customPolicies.add()`، مرشحات المطابقة، واجهة برمجة التطبيقات `allow`/`deny`/`instruct` |
| كائن السياق | `ctx.eventType`، `ctx.toolName`، `ctx.toolInput`، `ctx.session` |
| التكوين | هيكل `policies-config.json`، دمج النطاق، `policyParams` |
| واجهة سطر الأوامر | `failproofai policies --install`، `--uninstall`، `--custom`، النطاقات |
| لوحة التحكم | عارض الجلسة، نشاط السياسة، متغيرات البيئة |
| العمارة | تدفق معالج الخطاف، أكواد الخروج، عقد stdin/stdout |

## هل المهارة مكتملة؟

يُنشئ Mintlify `llms.txt` من جميع الصفحات في التنقل. تغطي وثائق Failproof AI واجهة برمجة التطبيقات الكاملة - كل سياسة وخيار ومثال مضمون. إذا وجدت شيئاً مفقوداً، فالمصدر موجود في `https://docs.befailproof.ai/llms-full.txt`.

للحصول على سياق موجه، قم بالربط المباشر إلى صفحة محددة:

```bash
# واجهة برمجة التطبيقات للسياسات المخصصة فقط
npx skills add https://docs.befailproof.ai/custom-policies

# السياسات المدمجة فقط
npx skills add https://docs.befailproof.ai/built-in-policies
```
