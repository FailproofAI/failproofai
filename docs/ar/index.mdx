> **Session → Audit → Finding → Issue → Policy**<br />
> تتبع ما حدث، اعثر على الفشل، أدر الاستجابة، ثم منع نفس السلوك في التشغيل المستقبلي.

إذا كنت تنشر وكيلك المزود بآليات المراقبة للمرة الأولى، فابدأ بـ [quickstart](/ar/start/quickstart). إذا كانت البيانات تصل بالفعل، افتح [Sessions](/ar/sessions/overview) وافحص تشغيل حقيقي قبل تكوين التدقيقات أو السياسات.
