خطافات وسياسات لـ **معالجة فشل الذكاء الاصطناعي**، **استرجاع الأخطاء**، و **موثوقية نماذج اللغة الكبيرة**. حافظ على موثوقية وكلائك الذكيين وتشغيلهم بشكل مستقل عبر **Claude Code**، **OpenAI Codex**، **GitHub Copilot**، **Cursor Agent**، **OpenCode**، **Pi**، **Hermes**، **OpenClaw**، **Factory Droid**، **Devin CLI**، **Antigravity CLI**، و **Agents SDK**.

وكلاء الذكاء الاصطناعي يفشلون بطرق يمكن التنبؤ بها. يقومون بتنفيذ أوامر مدمرة، تسريب الأسرار، الانجراف عن المهمة، الوقوع في حلقات، أو الدفع مباشرة إلى الفرع الرئيسي. إذا تُركت دون مراقبة، قد تتسبب الأخطاء الصغيرة في انقطاعات كبيرة، تسريب بيانات اعتماد، وفقدان العمل.

FailproofAI يحل هذه المشكلة باستخدام **السياسات**. هذه القواعد تتصل بكل استدعاء أداة وكيل لـ **الكشف عن الأخطاء**، **تخفيفها** (حظر، إرشاد، تنظيف)، و **تنبيهك** عندما يحتاج شيء ما إلى اهتمام. لوحة معلومات محلية تتيح لك مراجعة كل استدعاء أداة، فشل وكيل، وإجراء استرجاع بعد ذلك.

النصوص المكتوبة وتقييم السياسات تبقى على جهازك. يتم إرسال البيانات فقط عندما تستخدم صراحةً ميزة عبر الإنترنت، مثل تذكيرات التدقيق المصرح بها أو الدعوات.

## البدء السريع

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # تفعيل السياسات (أو تخطي — `failproofai` سيعرض عليك إعدادها في المرة الأولى)
failproofai                      # تشغيل لوحة المعلومات
```

اطلع على دليل [البدء](/ar/getting-started) للحصول على الشرح الكامل.
