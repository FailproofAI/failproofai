خطافات وسياسات لـ **معالجة فشل الذكاء الاصطناعي**، **استرجاع الأخطاء**، و **موثوقية نماذج اللغة الكبيرة**. حافظ على موثوقية وكلاء الذكاء الاصطناعي وتشغيلهم بشكل مستقل عبر **Claude Code**، **OpenAI Codex**، **GitHub Copilot**، **Cursor Agent**، **OpenCode**، **Pi**، **Hermes**، **OpenClaw**، **Factory Droid**، **Devin CLI**، **Antigravity CLI**، و **Agents SDK**.

وكلاء الذكاء الاصطناعي يفشلون بطرق يمكن التنبؤ بها. يقومون بتنفيذ أوامر مدمرة، تسريب الأسرار، الانحراف عن المهمة، الوقوع في حلقات لانهائية، أو الدفع مباشرة إلى الفرع الرئيسي. إذا تُركت دون مراقبة، قد تتسبب الأخطاء الصغيرة في انقطاعات، تسريب بيانات اعتماد، وفقدان العمل.

يحل FailproofAI هذه المشكلة بـ **السياسات**. هذه القواعد تتدخل في كل استدعاء أداة للوكيل لـ **كشف الأخطاء**، **التخفيف من حدتها** (الحجب، التعليمات، التنقية)، و **تنبيهك** عندما يحتاج شيء ما إلى اهتمام. لوحة معلومات محلية تسمح لك بمراجعة كل استدعاء أداة، فشل وكيل، وإجراء استرجاع بعد ذلك.

النصوص وتقييم السياسات تبقى على جهازك. يتم إرسال البيانات فقط عندما تستخدم بشكل صريح ميزة عبر الإنترنت، مثل تذكيرات التدقيق المصرح بها أو الدعوات.

## البدء السريع

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # تفعيل السياسات (أو تخطي — سيقدم `failproofai` الإعداد عند التشغيل الأول)
failproofai                      # تشغيل لوحة المعلومات
```
