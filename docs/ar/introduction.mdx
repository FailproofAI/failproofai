الخطافات والسياسات لـ **معالجة فشل الذكاء الاصطناعي**، **استرجاع الأخطاء**، و **موثوقية النموذج اللغوي**. حافظ على موثوقية وكلائك الذين يعملون بشكل مستقل عبر **Claude Code**، **OpenAI Codex**، **GitHub Copilot**، **Cursor Agent**، **OpenCode**، **Pi**، **Hermes**، **OpenClaw**، **Factory Droid**، **Devin CLI**، **Antigravity CLI**، و **Agents SDK**.

وكلاء الذكاء الاصطناعي يفشلون بطرق يمكن التنبؤ بها. يقومون بتشغيل أوامر مدمرة، ويسربون الأسرار، ويحيدون عن المهمة، ويعلقون في حلقات، أو يدفعون مباشرة إلى الفرع الرئيسي. إذا تُركوا دون مراقبة، فإن الفشل البسيط يتحول إلى انقطاعات وتسرب بيانات اعتماد وفقدان العمل.

يحل FailproofAI هذه المشكلة بـ **السياسات**. هذه القواعد تتصل بكل استدعاء أداة وكيل لـ **كشف الأعطال**، **تخفيفها** (حظر، تعليمات، تطهير)، و **تنبيهك** عند الحاجة إلى الانتباه. لوحة تحكم محلية تتيح لك مراجعة كل استدعاء أداة وفشل وكيل وإجراء استرجاع بعد ذلك.

النصوص وتقييم السياسة تبقى على جهازك. يتم إرسال البيانات فقط عندما تستخدم بشكل صريح ميزة عبر الإنترنت، مثل تذكيرات التدقيق المصرح بها أو الدعوات.

## البدء السريع

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # enable policies (or skip — `failproofai` will offer to set them up on first run)
failproofai                      # launch the dashboard
```

اطّلع على دليل [البدء السريع](/ar/getting-started) للحصول على الشرح الكامل.
