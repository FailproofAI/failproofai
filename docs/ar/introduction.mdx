خطافات وسياسات لـ **معالجة فشل الذكاء الاصطناعي**، **استرجاع الأخطاء**، و**موثوقية نموذج اللغة الكبير**. حافظ على وكلاء الذكاء الاصطناعي الخاص بك موثوقين وتشغيلهم بشكل مستقل عبر **Claude Code**، **OpenAI Codex**، **GitHub Copilot**، **Cursor Agent**، **OpenCode**، **Pi**، **Hermes**، **OpenClaw**، **Factory Droid**، **Devin CLI**، **Antigravity CLI**، و**Agents SDK**.

وكلاء الذكاء الاصطناعي يفشلون بطرق يمكن التنبؤ بها. يقومون بتشغيل أوامر مدمرة، وتسريب الأسرار، والانجراف عن المهمة، والعلوق في حلقات، أو الدفع مباشرة إلى الفرع الرئيسي. في حالة تركهم بدون مراقبة، قد تتسبب الأخطاء الصغيرة في انهيارات وتسريب بيانات المصادقة وفقدان العمل.

يحل FailproofAI هذه المشكلة باستخدام **السياسات**. هذه القواعد تتعلق بكل استدعاء أداة من وكيل لـ **اكتشاف الأخطاء**، **التخفيف من آثارها** (حظر، إرشاد، تعقيم)، و**إنبيهك** عند الحاجة إلى الانتباه. لوحة تحكم محلية تسمح لك بمراجعة كل استدعاء أداة، فشل الوكيل، وإجراء الاسترجاع لاحقاً.

لا تترك أي بيانات جهازك.

## البدء السريع

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # enable policies (or skip — `failproofai` will offer to set them up on first run)
failproofai                      # launch the dashboard
```

اطلع على دليل [البدء](/ar/getting-started) للحصول على الشرح الكامل.
