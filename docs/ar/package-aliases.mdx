## الحزمة الرسمية

حزمة npm القانونية هي **`failproofai`**:

```bash
npm install -g failproofai
# أو
bun add -g failproofai
```

---

## لماذا نمتلك أسماء البدائل

الاستيلاء على أسماء الحزم هو هجوم شائع على سلسلة التوريد حيث يقوم ممثل خبيث بتسجيل اسم حزمة يختلف بضغطة مفتاح واحدة فقط عن حزمة شهيرة. المستخدمون غير المدركين الذين يخطئون في كتابة أمر التثبيت ينتهي بهم الحال إلى تشغيل كود يتحكم فيه المهاجم بوصول كامل للنظام - بالضبط نوع التهديد الذي تم تصميم Failproof AI للدفاع عنه.

لإزالة هذا السطح الضعيف، **نمتلك مسبقاً جميع الأخطاء الإملائية الشائعة والمتغيرات الصيغية** لـ `failproofai` على npm. لا يمكن لأي طرف ثالث تسجيل أي من هذه الأسماء. كل اسم هو بمثابة وكيل بسيط يثبت الحزمة الحقيقية ويفوض المسؤولية إليها.

## الأسماء البديلة المسجلة

**متغيرات الصيغة** - طرق مختلفة لكتابة "failproof ai":

| الحزمة | الحالة |
|--------|--------|
| `failproof` | ✅ منشورة |
| `failproof-ai` | ⏳ في انتظار دعم npm |
| `fail-proof-ai` | ⏳ في انتظار دعم npm |
| `failproof_ai` | ⏳ في انتظار دعم npm |
| `fail_proof_ai` | ⏳ في انتظار دعم npm |
| `fail-proofai` | ⏳ في انتظار دعم npm |

**أخطاء إملائية `failprof*`** - حرف `o` ناقص من "proof":

| الحزمة | الحالة |
|--------|--------|
| `failprof` | ✅ منشورة |
| `failprof-ai` | ✅ منشورة |
| `failprofai` | ⏳ في انتظار دعم npm |
| `fail-prof-ai` | ⏳ في انتظار دعم npm |
| `failprof_ai` | ⏳ في انتظار دعم npm |

**أخطاء إملائية `faliproof*`** - تبديل موضع `a` و `i`:

| الحزمة | الحالة |
|--------|--------|
| `faliproof` | ✅ منشورة |
| `faliproof-ai` | ✅ منشورة |
| `faliproofai` | ⏳ في انتظار دعم npm |

> **لماذا قيد الانتظار؟** سياسة منع الرسائل غير المرغوبة في npm تحظر الأسماء التي تتطبع إلى نفس السلسلة النصية مثل حزمة موجودة بعد حذف علامات الترقيم وتشغيل فحوصات التشابه. لقد تواصلنا مع دعم npm لحجز هذه الأسماء لأغراض منع الاستيلاء. سيتم تفعيلها بعد الموافقة عليها.

يمكنك التحقق من أن أي اسم بديل منشور مملوك لنا:

```bash
npm info failproof
# ابحث عن: "ExosphereHost Inc." في حقل المشرفين
```

## كيفية عمل الأسماء البديلة

كل حزمة بديلة:

1. تسرد `failproofai` كمتعلقة - بحيث يتم تثبيت الحزمة الحقيقية وتصبح ملفاتها التنفيذية متاحة
2. تعرض ملف تنفيذي يطابق اسمها الخاص (مثل `failprof-ai`) يفوض جميع المعاملات إلى ملف `failproofai` التنفيذي

الوكيل هو سكريبت Node بسطتين؛ لا توجد منطق، ولا استدعاءات شبكة، ولا جمع بيانات بخلاف ما يفعله `failproofai` بنفسه.
