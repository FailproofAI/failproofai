## الحزمة الرسمية

الحزمة npm الأساسية هي **`failproofai`**:

```bash
npm install -g failproofai
# أو
bun add -g failproofai
```

---

## لماذا نمتلك أسماء بديلة

Typosquatting هو هجوم شائع على سلسلة التوريد حيث يقوم مهاجم بتسجيل اسم حزمة يختلف بخطأ طباعي واحد عن حزمة شهيرة. المستخدمون الذين يخطئون في كتابة أمر التثبيت ينتهي بهم الحال إلى تشغيل كود يتحكم به المهاجم برصيد كامل للنظام - وهذا بالضبط نوع التهديد الذي Failproof AI مصمم للدفاع عنه.

لاستئصال هذا الخطر، **نمتلك مسبقاً جميع التهجئات الخاطئة الشائعة والمتغيرات المختلفة** من `failproofai` على npm. لا يمكن لأي طرف ثالث تسجيل أي من هذه الأسماء. كل واحد منها بمثابة وكيل خفيف يثبت ويفوض إلى حزمة `failproofai` الحقيقية.

## الأسماء البديلة المسجلة

**متغيرات التنسيق** - طرق مختلفة لكتابة "failproof ai":

| الحزمة | الحالة |
|---------|--------|
| `failproof` | ✅ منشورة |
| `failproof-ai` | ⏳ في انتظار دعم npm |
| `fail-proof-ai` | ⏳ في انتظار دعم npm |
| `failproof_ai` | ⏳ في انتظار دعم npm |
| `fail_proof_ai` | ⏳ في انتظار دعم npm |
| `fail-proofai` | ⏳ في انتظار دعم npm |

**أخطاء `failprof*` طباعية** - حرف واحد `o` ناقص من "proof":

| الحزمة | الحالة |
|---------|--------|
| `failprof` | ✅ منشورة |
| `failprof-ai` | ✅ منشورة |
| `failprofai` | ⏳ في انتظار دعم npm |
| `fail-prof-ai` | ⏳ في انتظار دعم npm |
| `failprof_ai` | ⏳ في انتظار دعم npm |

**أخطاء `faliproof*` طباعية** - `a` و`i` متبادلة:

| الحزمة | الحالة |
|---------|--------|
| `faliproof` | ✅ منشورة |
| `faliproof-ai` | ✅ منشورة |
| `faliproofai` | ⏳ في انتظار دعم npm |

> **لماذا قيد الانتظار؟** سياسة npm لمنع الرسائل غير المرغوبة تحظر الأسماء التي تتطابق مع اسم حزمة موجود بعد إزالة علامات الترقيم وإجراء فحوصات التشابه. لقد تواصلنا مع دعم npm لحجز هذه الأسماء لأغراض مكافحة الهجمات. سيتم تفعيلها بمجرد الموافقة عليها.

يمكنك التحقق من أن أي اسم بديل منشور مملوك لنا:

```bash
npm info failproof
# ابحث عن: "ExosphereHost Inc." في حقل المسؤولين
```

## كيفية عمل الأسماء البديلة

كل حزمة بديلة:

1. تدرج `failproofai` كاعتماد - لذا يتم تثبيت الحزمة الحقيقية ويصبح ملفها الثنائي متاحاً
2. تكشف عن ملف ثنائي يطابق اسمها الخاص (على سبيل المثال `failprof-ai`) الذي يوجه جميع المعاملات إلى ملف `failproofai` الثنائي

الوكيل عبارة عن نص Node من سطرين؛ لا توجد منطق، لا اتصالات شبكية، ولا جمع بيانات بما يتجاوز ما يفعله `failproofai` نفسه.
