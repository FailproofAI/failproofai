## الحزمة الرسمية

حزمة npm الأساسية هي **`failproofai`**:

```bash
npm install -g failproofai
# أو
bun add -g failproofai
```

---

## لماذا نمتلك أسماء الاستعارات

محاكاة الكتابة الخاطئة (Typosquatting) هي هجوم شائع في سلسلة التوريد حيث يقوم مهاجم خبيث بتسجيل اسم حزمة يختلف عن حزمة شهيرة بضغطة مفتاح واحدة فقط. المستخدمون الذين يخطئون في كتابة أمر التثبيت ينتهي بهم الحال إلى تشغيل كود يتحكم به المهاجم بصلاحيات النظام الكاملة - وهو بالضبط نوع التهديد الذي صُممت Failproof AI للدفاع ضده.

لإزالة هذا السطح الضعيف، **نمتلك مسبقاً جميع الأخطاء الإملائية الشائعة والمتغيرات المختلفة** لـ `failproofai` على npm. لا يمكن لأي طرف ثالث تسجيل أي من هذه الأسماء. كل واحد منها هو وسيط بسيط يثبت الحزمة الحقيقية `failproofai` ويفوض العمل إليها.

> **لماذا قيد الانتظار؟** سياسة npm لمنع البريد العشوائي تحظر الأسماء التي تُعيد تنسيقها إلى نفس السلسلة الموجودة بعد إزالة علامات الترقيم وتطبيق فحوصات التشابه. لقد تواصلنا مع فريق دعم npm لحجز هذه الأسماء لأغراض منع محاكاة الكتابة. سيتم تفعيلها بمجرد الموافقة عليها.

يمكنك التحقق من أن أي اسم مستعار منشور مملوك لنا:

```bash
npm info failproof
# ابحث عن: "ExosphereHost Inc." في حقل المُشرفين
```

## كيفية عمل الأسماء المستعارة

كل حزمة مستعارة:

1. تضع `failproofai` كتبعية - بحيث يتم تثبيت الحزمة الحقيقية وتصبح ملفاتها التنفيذية متاحة
2. توفر ملف تنفيذي يطابق اسمها الخاص (مثلاً `failprof-ai`) يفوض جميع المعاملات إلى ملف `failproofai` التنفيذي

الوسيط عبارة عن سكريبت Node بسطرين؛ لا توجد منطق، ولا استدعاءات شبكية، وعدم جمع بيانات بخلاف ما تفعله `failproofai` نفسها.
