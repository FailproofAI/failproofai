تغطي السياسات المدمجة معالجة الأسرار والملفات البيئية وأوامر shell التدميرية والفروع المحمية وأدوات السحابة والبنية التحتية ونشر الحزم والاستدعاءات المتكررة وفحوصات سير عمل نهاية المهمة.

## تفعيل والتحقق من سياسة مدمجة

<Tabs>
  <Tab title="لوحة التحكم">
    1. قم بتثبيت السياسة على جهاز متصل باستخدام واجهة سطر الأوامر المحلية.
    2. قم بتشغيل إجراء اختبار آمن في الوكيل المقيس.
    3. انتقل إلى **Observe → policy** وقم بالتصفية حسب اسم السياسة أو بيئة الجهاز أو القرار.
    4. افتح الجلسة المرتبطة لتأكيد إدخال الأداة المطابق والسبب المُرجع.

  </Tab>
  <Tab title="CLI">
    ```bash
    failproofai policies
    failproofai policy add block-rm-rf --cli claude --scope project
    failproofai config --status
    ```

    أزلها باستخدام `failproofai policy remove block-rm-rf --cli claude --scope project`.
  </Tab>
</Tabs>

اعرض قائمة بالسياسات المتاحة في النسخة المثبتة لديك:

```bash
failproofai policies
```

قم بتفعيل سياسة واحدة لمشروع:

```bash
failproofai policy add block-rm-rf --scope project
```

قم بتفعيل عدة سياسات لأجهزة اختبار معينة:

```bash
failproofai policies --install block-sudo block-force-push \
  --cli claude codex --scope project
```

بعض السياسات تقبل معاملات أو تحمل علامة beta. راجع الوصف ونطاق المطابقة والسلوك الافتراضي قبل الطرح. قد تحمي سياسة ما سير عمل واحد وتحظر العمليات الصحيحة في آخر.
