تغطي السياسات المدمجة التعامل مع الأسرار وملفات البيئة والأوامر الصدفية المدمرة والفروع المحمية وأدوات السحابة والبنية التحتية ونشر الحزم والاستدعاءات المتكررة والتحقق من سير عمل نهاية المهمة.

## تفعيل والتحقق من السياسة المدمجة

<Tabs>
  <Tab title="Dashboard">
    1. ثبّت السياسة على جهاز متصل باستخدام واجهة سطر الأوامر المحلية.
    2. قم بتشغيل إجراء اختبار آمن في العميل المراقب.
    3. انتقل إلى **Observe → policy** وقم بالتصفية حسب اسم السياسة أو بيئة الجهاز أو القرار.
    4. افتح الجلسة المرتبطة لتأكيد مدخلات الأداة المطابقة والسبب المُرجع.

  </Tab>
  <Tab title="CLI">
    ```bash
    failproofai policies
    failproofai policy add block-rm-rf --cli claude --scope project
    failproofai config --status
    ```

    أزله باستخدام `failproofai policy remove block-rm-rf --cli claude --scope project`.
  </Tab>
</Tabs>

اعرض قائمة السياسات المتاحة في إصدارك المثبت:

```bash
failproofai policies
```

فعّل سياسة واحدة لمشروع:

```bash
failproofai policy add block-rm-rf --scope project
```

فعّل عدة سياسات لأجهزة محددة:

```bash
failproofai policies --install block-sudo block-force-push \
  --cli claude codex --scope project
```

بعض السياسات تقبل معاملات أو تُحتسب كنسخة تجريبية. راجع الوصف ونطاق المطابقة والسلوك الافتراضي قبل الإطلاق. قد تحمي السياسة التي تحمي سير عمل واحد عمليات صحيحة في سير عمل آخر.

</Tip>
