تقارن تغطية الأسطول ما خصصته السحابة مع ما طبّقه كل جهاز آخر مرة.

## التحقق من جهاز

```bash
failproofai config --status
failproofai flush --wait --timeout 120
```

من السحابة:

```bash
fp fleet list
fp fleet diff
fp fleet show <machine-id>
```

يتطلب `fp fleet` جلسة تسجيل دخول، وليس مفتاح API.

| الأمر | ما يفعله |
| --- | --- |
| `fp fleet list` | اسرد الأجهزة وحالة النشر |
| `fp fleet show <machine>` | اعرض مجموعة السياسات لجهاز واحد |
| `fp fleet deploy <machine> --add <ref>` | أضف أو حدّث سياسة واحدة |
| `fp fleet deploy <machine> --remove <id>` | أزل سياسة واحدة |
| `fp fleet deploy <machine> --set <ref>...` | استبدل المجموعة بأكملها |
| `fp fleet diff [machine]` | قارن الإصدارات المقصودة والمطبّقة |
| `fp fleet history <machine>` | اسرد أجيال النشر |
| `fp fleet rollback <machine> <generation>` | استعد جيلاً |
| `fp fleet rename <machine> "<label>"` | غيّر تسمية السحابة |

<Warning>
  يستبدل `--set` مجموعة السياسات الكاملة. يفرض `--add <id>` بدون معاملات أخرى سياسة جديدة فوراً. استخدم `--add <id>:observe` لنشر ظلي.
</Warning>

## راقب، ثم طبّق

```bash
fp fleet deploy ci-runner-01 --add prod-guard:observe
fp guardrails summary --since 24h --machine ci-runner-01
fp fleet deploy ci-runner-01 --add prod-guard:enforce
```

يقيّم وضع المراقبة السياسة الفعلية ويسجل القرارات التي لا تسمح بها دون حجب الوكيل.

## هوية الجهاز

معرّف الجهاز ثابت ويحدد الجهاز. التسمية مخصصة للعرض فقط ويمكن أن تتغير:

```bash
failproofai config --machine-label checkout-runner-03
fp fleet rename <machine-id> "Checkout runner 03"
```

لا يؤدي تغيير التسمية إلى إعادة توصيل الجهاز أو إعادة تعيين مفاتيحه.
