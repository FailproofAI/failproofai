استخدم النطاق (scope) لتحديد من سيتلقى سياسة محلية:

| النطاق | ينطبق على |
| --- | --- |
| `user` | وكلاؤك المدعومون على هذا الجهاز |
| `project` | الوكلاء الذين يعملون في هذا المشروع |
| `local` | Claude فقط، في إعدادات المشروع المحلي |
| `all` | الإلغاء فقط |

```bash
failproofai policies add block-sudo --scope user
failproofai policies add block-rm-rf --scope project
```

يدعم Hermes وOpenClaw نطاق المستخدم فقط. تدعم معظم الأدوات الأخرى نطاق المستخدم والمشروع. يدعم Claude أيضًا النطاق المحلي. اطّلع على [Harnesses](/ar/reference/harnesses).

## معاملات السياسة

توجد إعدادات السياسة في `policies-config.json` عند النطاق المطابق. استخدم عرض **Policies → Configure** من لوحة المعلومات المحلية عند الإمكان.

يتعلق المعامل بسياسة واحدة فقط ويغير كيفية اتخاذ تلك السياسة قرارًا. على سبيل المثال، يمكن لقائمة السماح بجعل سياسة الحجب تقبل الأوامر أو المسارات الآمنة المعروفة.

يمكن تحميل ملفات السياسات المخصصة تلقائيًا من `.failproofai/policies/`، أو بشكل صريح:

```bash
failproofai policies -i -c ./guards.mjs --scope project
```

أزل المسارات الصريحة باستخدام:

```bash
failproofai policies -u -c
```

## الملفات

| الملف | الغرض |
| --- | --- |
| `~/.failproofai/config.json` | إعدادات الجهاز والمجمّع |
| `policies-config.json` | السياسات المفعّلة والمعاملات لنطاق معين |
| `.failproofai/policies/*policies.mjs` | السياسات المحملة بالاتفاقية |
| `~/.failproofai/policies/packs/installed.json` | الحزم المثبتة والاختيارات |

لا تحرّر معاملات الحزمة المثبتة مباشرة. أعد التثبيت أو انشر إصدارًا معدّلًا.
