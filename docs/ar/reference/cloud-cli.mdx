استخدم `fp` للاطلاع على بيانات السحابة (telemetry)، وإدارة الإنفاذ المُدار بواسطة السحابة (السياسات ونشرات الأسطول وقرارات الحماية)، وإدارة عمليات التدقيق والنتائج والمشاكل والتنبيهات والمفاتيح والمستخدمين والاستعلامات والإعدادات. استخدم [`failproofai`](/ar/reference/failproof-cli) للخطافات المحلية والسياسات والالتقاط وتسجيل الآلات.

ثبّت واجهة سطر أوامر السحابة المُصدرة كأداة مستقلة:

```bash
uv tool install fp-cloud-cli
fp version
```

## تسجيل الدخول

```bash
fp login
fp whoami
```

## بناء الجملة

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

يجب أن تأتي الخيارات العامة قبل الأمر:

```bash
fp --json sessions --since 24h
```

نفّذ `fp COMMAND --help` أو `fp COMMAND SUBCOMMAND --help` للحصول على المساعدة في الطرفية.

### الأحداث

```text
fp events [OPTIONS]
```

يسرد أحداث الوكيل الفردية. يستبعد التغذية الخفيفة الافتراضية الحمولات الأولية؛ استخدم `--full` فقط للتحقيق المحدود.

| الخيار | الوصف |
| --- | --- |
| `--limit`, `-n <n>` | أقصى إجمالي للصفوف. الافتراضي: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h`, أو `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | نطاق ISO 8601 UTC؛ يتجاوز `--since`. |
| `--env <value>` | تصفية البيئة؛ كرّر أو افصل القيم بفواصل. |
| `--event-type <value>` | تصفية نوع الحدث؛ كرّر أو افصل القيم بفواصل. |
| `--agent-id <value>` | تصفية الوكيل؛ كرّر أو افصل القيم بفواصل. |
| `--session-id <value>` | تصفية الجلسة؛ كرّر أو افصل القيم بفواصل. |
| `--search <text>` | بحث نص الحمولة؛ قابل للتكرار، مع تطابق أي مصطلح. |
| `--order asc\|desc` | ترتيب الوقت. الافتراضي: الأحدث أولاً. |
| `--all` | ترقيم تلقائي حتى `--limit`. |
| `--cursor <token>` | استأنف من مؤشر معتم. |
| `--page-size <n>` | صفوف لكل طلب مع `--all`؛ أقصى `200`. |
| `--full` | أدرج الحمولات الأولية عبر نقطة نهاية الحدث الأثقل. |
| `--fields <csv>` | أرجع الحقول المحددة فقط؛ طلب `payload` يفعّل الوضع الكامل. |

```bash
fp events --session-id <session-id> --order asc --all --limit 10000
fp --json events --full --session-id <session-id> --all --limit 10000
```

<Note>
  `--all` يرقّم حتى `--limit`، التي تبلغ افتراضياً **50** — لذا `--all` وحده يتوقف عند 50 صف. عندما يتوقف مبكراً، تحمل الاستجابة `next_cursor` للاستئناف منه؛ `"next_cursor": null` تعني أن التغذية استُنفدت فعلاً.
</Note>

#### خيارات إنشاء التدقيق

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| الخيار | الوصف |
| --- | --- |
| `--file <path>` | أسّس التعريف على JSON، أو استخدم `-` للإدخال القياسي. تتجاوز الأعلام الصريحة قيم الملف. |
| `--description <text>` | اذكر سؤال الفشل أو الغرض. |
| `--enabled` / `--disabled` | ابدأ الجدولة بتشغيل أو إيقاف. الافتراضي: مفعّل. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. الافتراضي: `86400`. |
| `--schedule-anchor <timestamp>` | مرحلة UTC ثابتة في شكل ISO 8601. الافتراضي: 09:00 UTC التالية. |
| `--window-mode since_last\|fixed` | استمرّ بعد آخر نافذة محللة بالكامل أو افحص نافذة دوارة بشكل متكرر. الافتراضي: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. الافتراضي: `604800`. |
| `--scope '<json>'` | صفّي حسب `environments`, `agent_ids`, أو حقول النطاق الأخرى المدعومة. |
| `--ignore-error-type <type>` | استبعد أنواع الأخطاء؛ كرّر أو افصل بفواصل. |
| `--llm` / `--no-llm` | فعّل أو عطّل التحليل الموجه بالوكيل. الافتراضي: مفعّل. |
| `--top-k <n>` | احتفظ بـ `1`–`500` نتيجة. الافتراضي: `50`. |
| `--sensitivity low\|medium\|high` | اضبط حساسية الإبلاغ. الافتراضي: `medium`. |
| `--channels '<json>'` | مصفوفة قنوات الإخطار. |
| `--text <brief>` | ملخص مضمّن، أقصى 8,192 حرف. |
| `--text-file <path>` | اقرأ الملخص من ملف؛ حصري متبادل مع `--text`. |
| `--url <https-url>` | أضف مرجع HTTPS عام؛ كرّر حتى خمس مرات. |

أدرج السياق أثناء الإنشاء عندما يحتاجه التشغيل الأول. يلتزم الإنشاء بالتعريف والسياق معاً قبل بدء التشغيل المصفوف.

<Note>
  `fp audits run` غير متزامن. صوّت `fp audits runs NAME` حتى يحقق آخر تشغيل النجاح أو الفشل قبل قراءة نتائجه.
</Note>

## الأعلام العامة

| العلم | الوصف |
| --- | --- |
| `--json` | أصدر JSON قابل لقراءة الآلة. |
| `--base-url <url>` | استخدم لوحة معلومات مستقلة أو تطوير. |
| `--org <slug>` | اختر مؤسسة لهذا التشغيل. |
| `--token <token>` | تجاوز رمز جلسة المستخدم المحفوظ. |
| `--api-key <key>` | صادق الأتمتة برمز API؛ لا يُحفظ أبداً. |
| `--timeout <seconds>` | مهلة HTTP؛ يجب أن تكون موجبة. الافتراضي: `30`. |
| `--quiet`, `-q` | اكتم مخرجات الحالة على stderr. |
| `--no-color` | عطّل الإخراج الملون. |
| `--insecure` / `--secure` | عطّل أو استعد التحقق من شهادة TLS. |
| `--version` | اطبع الإصدار غير المجاور وخرج. |
| `--help`, `-h` | اعرض المساعدة. |

`--api-key` مقصود للأتمتة. تسجيل الدخول وتبديل المؤسسة وأوامر المساعد تتطلب جلسة مستخدم.

## متغيرات البيئة

| المتغير | ما يعادله أو الغرض |
| --- | --- |
| `FP_DASHBOARD_URL` | `--base-url` |
| `FP_ORG` | `--org` |
| `FP_TOKEN` | `--token` |
| `FP_API_KEY` | `--api-key` |
| `FP_JSON` | `--json` |
| `FP_INSECURE` | `--insecure` |
| `FP_HOME` | أعد توضيع دليل تكوين CLI (الافتراضي `~/.failproofai/fpcli`). |
| `FP_ANALYTICS_DISABLED` أو `DO_NOT_TRACK` | عطّل تحليلات CLI المجهولة. |
| `NO_COLOR` | عطّل الإخراج الملون. |

تتجاوز الأعلام الصريحة متغيرات البيئة، التي تتجاوز التكوين المحفوظ. في وضع مفتاح API، اختر المستأجر بوضوح مع `--org` أو `FP_ORG`.

<Warning>
  تهجئات `AGENTEYE_*` من هذه **لا تُقرأ بواسطة `fp`** ولم تكن أبداً — يعلن CLI `FP_*` (`fp_cli/app.py`)، ومتغير غير معروف ليس خطأ. ضبط `AGENTEYE_DASHBOARD_URL` لا يستهدف CLI؛ يُتجاهل والأمر يعمل بصمت ضد لوحة المعلومات المحفوظة بدلاً من ذلك.

  `AGENTEYE_HOME` و `AGENTEYE_ENVIRONMENT` موجودة لا تزال، لكنها تنتمي إلى **جامع والتطبيق الكلينوميتري**، وليس إلى CLI هذا.
</Warning>

<Warning>
  الأوامر التي تحذف أو تلغي أو تكتم أو تحلّ أو تستبدل التكوين تطالب افتراضياً. استخدم `--yes` فقط بعد التحقق من المؤسسة النشطة والهدف.
</Warning>
