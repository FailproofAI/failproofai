استخدم `fp` للتحقق من تلمترية Cloud وإدارة عمليات التدقيق والنتائج والمشاكل والتنبيهات والمفاتيح والمستخدمين والاستعلامات والإعدادات. استخدم [`failproofai`](/ar/reference/failproof-cli) للتعاملات المحلية والسياسات والالتقاط وتسجيل الأجهزة.

قم بتثبيت واجهة سطر الأوامر السحابية المُصدرة كأداة معزولة:

```bash
uv tool install fp-cloud-cli
fp version
```

## تسجيل الدخول

```bash
fp login
fp whoami
```

## الصيغة

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

يجب أن تأتي الخيارات العامة قبل الأمر:

```bash
fp --json sessions --since 24h
```

قم بتشغيل `fp COMMAND --help` أو `fp COMMAND SUBCOMMAND --help` للحصول على مساعدة في الطرفية.

## أوامر واجهة سطر الأوامر

```bash
fp login --email you@example.com --org reliability-team

```

### الأحداث

```text
fp events [OPTIONS]
```

يسرد أحداث الوكيل الفردية. يستبعد الخلاصة الخفيفة الافتراضية الحمولات الخام؛ استخدم `--full` فقط للتحقيق المحدود.

| الخيار | الوصف |
| --- | --- |
| `--limit`, `-n <n>` | الحد الأقصى للصفوف الإجمالية. الافتراضي: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h`, أو `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | نطاق ISO 8601 UTC؛ يتجاوز `--since`. |
| `--env <value>` | مرشح البيئة؛ كرر أو افصل بفواصل. |
| `--event-type <value>` | مرشح نوع الحدث؛ كرر أو افصل بفواصل. |
| `--agent-id <value>` | مرشح الوكيل؛ كرر أو افصل بفواصل. |
| `--session-id <value>` | مرشح الجلسة؛ كرر أو افصل بفواصل. |
| `--search <text>` | البحث في نص الحمولة؛ قابل للتكرار، مع مطابقة أي مصطلح. |
| `--order asc\|desc` | ترتيب زمني. الافتراضي: الأحدث أولاً. |
| `--all` | ترقيم تلقائي حتى `--limit`. |
| `--cursor <token>` | استئنف من مؤشر معتم. |
| `--page-size <n>` | صفوف لكل طلب مع `--all`؛ بحد أقصى `200`. |
| `--full` | قم بتضمين الحمولات الخام من خلال نقطة الحدث الأثقل. |
| `--fields <csv>` | إرجاع الحقول المحددة فقط؛ طلب `payload` يفعل الوضع الكامل. |

```bash
fp events --session-id <session-id> --order asc --all
fp --json events --full --session-id <session-id> --all
```

#### خيارات إنشاء التدقيق

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| الخيار | الوصف |
| --- | --- |
| `--file <path>` | استند التعريف على JSON أو استخدم `-` للمدخلات المعيارية. الأعلام الصريحة تتجاوز قيم الملف. |
| `--description <text>` | اذكر سؤال الفشل أو الغرض. |
| `--enabled` / `--disabled` | ابدأ الجدولة قيد التشغيل أو الإيقاف. الافتراضي: مُفعّل. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. الافتراضي: `86400`. |
| `--schedule-anchor <timestamp>` | مرحلة UTC ثابتة في شكل ISO 8601. الافتراضي: الساعة 09:00 UTC التالية. |
| `--window-mode since_last\|fixed` | المتابعة بعد آخر نافذة تم تحليلها بالكامل أو فحص نافذة متغيرة بشكل متكرر. الافتراضي: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. الافتراضي: `604800`. |
| `--scope '<json>'` | تصفية حسب `environments` أو `agent_ids` أو حقول النطاق المدعومة الأخرى. |
| `--ignore-error-type <type>` | استبعد أنواع الأخطاء؛ كرر أو افصل بفواصل. |
| `--llm` / `--no-llm` | فعّل أو عطّل التحليل الوكلاء. الافتراضي: مُفعّل. |
| `--top-k <n>` | احتفظ بـ `1`–`500` نتيجة. الافتراضي: `50`. |
| `--sensitivity low\|medium\|high` | عيّن حساسية الإبلاغ. الافتراضي: `medium`. |
| `--channels '<json>'` | مصفوفة قناة الإشعار. |
| `--text <brief>` | موجز مضمّن، بحد أقصى 8,192 حرف. |
| `--text-file <path>` | اقرأ الموجز من ملف؛ متنافر حصراً مع `--text`. |
| `--url <https-url>` | أضف مرجع HTTPS عام؛ كرر حتى خمس مرات. |

قم بتضمين السياق أثناء الإنشاء عندما يحتاج التشغيل الأول إليه. يلتزم الإنشاء بالتعريف والسياق معاً قبل بدء التشغيل المُدرج في قائمة الانتظار.

<Note>
  `fp audits run` غير متزامن. استقصي `fp audits runs NAME` حتى ينجح التشغيل الأخير أو يفشل قبل قراءة نتائجه.
</Note>

| `--api-key <key>` | مصادقة الأتمتة برمز API؛ لا تُحفظ أبداً. |
| `--timeout <seconds>` | مهلة HTTP؛ يجب أن تكون موجبة. الافتراضي: `30`. |
| `--quiet`, `-q` | اكتم مخرجات الحالة على stderr. |
| `--no-color` | عطّل الإخراج الملون. |
| `--insecure` / `--secure` | عطّل أو استعد التحقق من شهادة TLS. |
| `--version` | اطبع الإصدار غير المعبأ وخرج. |
| `--help`, `-h` | اعرض المساعدة. |

`--api-key` مقصود للأتمتة. تتطلب عمليات تسجيل الدخول وتبديل المنظمة والأوامر المساعدة جلسة مستخدم.

## متغيرات البيئة

| المتغير | المكافئ أو الغرض |

تتجاوز الأعلام الصريحة متغيرات البيئة، التي تتجاوز الإعدادات المحفوظة. في وضع مفتاح API، اختر المستأجر بوضوح مع `--org` أو `AGENTEYE_ORG`.

</Warning>
