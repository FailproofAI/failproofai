استخدم `fp` للتحقق من التلميترية السحابية وإدارة الفرض المدار من السحابة (السياسات ونشرات الأسطول وقرارات guardrail) وإدارة التدقيقات والنتائج والمشاكل والتنبيهات والمفاتيح والمستخدمين والاستعلامات والإعدادات. استخدم [`failproofai`](/ar/reference/failproof-cli) للخطافات المحلية والسياسات والالتقاط وتسجيل الآلات.

ثبّت أداة Cloud CLI المُصدرة كأداة معزولة:

```bash
uv tool install fp-cloud-cli
fp version
```

## تسجيل الدخول

```bash
fp login
fp whoami
```

## بنية الصيغة

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

يجب أن تأتي الخيارات العامة قبل الأمر:

```bash
fp --json sessions --since 24h
```

قم بتشغيل `fp COMMAND --help` أو `fp COMMAND SUBCOMMAND --help` للحصول على مساعدة في المحطة الطرفية.

### الأحداث

```text
fp events [OPTIONS]
```

يسرد أحداث الوكيل الفردية. يستبعد الفيد الخفيف الافتراضي الحمولات الأولية؛ استخدم `--full` فقط للتحقيق المحدود.

| الخيار | الوصف |
| --- | --- |
| `--limit`, `-n <n>` | أقصى عدد صفوف إجمالي. الافتراضي: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h`, أو `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | نطاق ISO 8601 UTC؛ يتجاوز `--since`. |
| `--env <value>` | عامل تصفية البيئة؛ كرر أو افصل القيم بفواصل. |
| `--event-type <value>` | عامل تصفية نوع الحدث؛ كرر أو افصل القيم بفواصل. |
| `--agent-id <value>` | عامل تصفية الوكيل؛ كرر أو افصل القيم بفواصل. |
| `--session-id <value>` | عامل تصفية الجلسة؛ كرر أو افصل القيم بفواصل. |
| `--search <text>` | البحث عن نص الحمولة؛ قابل للتكرار، أي مصطلح متطابق. |
| `--order asc\|desc` | ترتيب الوقت. الافتراضي: الأحدث أولاً. |
| `--all` | الترقيم التلقائي حتى `--limit`. |
| `--cursor <token>` | استأنف من مؤشر معتم. |
| `--page-size <n>` | صفوف لكل طلب مع `--all`؛ الحد الأقصى `200`. |
| `--full` | قم بتضمين الحمولات الأولية من خلال نقطة نهاية الحدث الأثقل. |
| `--fields <csv>` | أرجع الحقول المحددة فقط؛ يتطلب طلب `payload` الوضع الكامل. |

```bash
fp events --session-id <session-id> --order asc --all --limit 10000
fp --json events --full --session-id <session-id> --all --limit 10000
```

<Note>
  `--all` يرقّم **حتى `--limit`**، الذي يبلغ افتراضياً **50** — لذا `--all` وحده يتوقف عند 50 صفاً. عندما يتوقف مبكراً، تحمل الاستجابة `next_cursor` للاستئناف منه؛ `"next_cursor": null` يعني أن الفيد استُنزف فعلاً.
</Note>

#### خيارات إنشاء التدقيق

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| الخيار | الوصف |
| --- | --- |
| `--file <path>` | أساس التعريف على JSON، أو استخدم `-` لـ stdin. تتجاوز الأعلام الصريحة قيم الملف. |
| `--description <text>` | اذكر سؤال الفشل أو الغرض. |
| `--enabled` / `--disabled` | ابدأ الجدولة على أو إيقاف. الافتراضي: مُفعّل. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. الافتراضي: `86400`. |
| `--schedule-anchor <timestamp>` | مرحلة UTC ثابتة في شكل ISO 8601. الافتراضي: 09:00 UTC القادمة. |
| `--window-mode since_last\|fixed` | استمر بعد النافذة التي تم تحليلها بالكامل الأخيرة أو افحص النافذة المتداول بشكل متكرر. الافتراضي: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. الافتراضي: `604800`. |
| `--scope '<json>'` | صفّي حسب `environments`, `agent_ids`, أو حقول النطاق المدعومة الأخرى. |
| `--ignore-error-type <type>` | استبعد أنواع الأخطاء؛ كرر أو افصل بفواصل. |
| `--llm` / `--no-llm` | فعّل أو عطّل التحليل الوكيلي. الافتراضي: مُفعّل. |
| `--top-k <n>` | احتفظ بـ `1`–`500` نتيجة. الافتراضي: `50`. |
| `--sensitivity low\|medium\|high` | ضع حساسية التقرير. الافتراضي: `medium`. |
| `--channels '<json>'` | مصفوفة قناة الإخطار. |
| `--text <brief>` | ملخص مضمن، بحد أقصى 8192 حرفاً. |
| `--text-file <path>` | اقرأ الملخص من ملف؛ حصري مع `--text`. |
| `--url <https-url>` | أضف مرجعاً عاماً HTTPS؛ كرر حتى خمس مرات. |

قم بتضمين السياق أثناء الإنشاء عندما يحتاج التشغيل الأول إليه. يلتزم الإنشاء بالتعريف والسياق معاً قبل أن يبدأ التشغيل المصفوف.

<Note>
  `fp audits run` غير متزامن. اسأل `fp audits runs NAME` حتى ينجح أو يفشل آخر تشغيل قبل قراءة النتائج.
</Note>

## الأعلام العامة

| العلم | الوصف |
| --- | --- |
| `--json` | أصدر JSON قابل للقراءة من قبل الآلة. |
| `--base-url <url>` | استخدم لوحة تحكم مضيافة ذاتياً أو للتطوير. |
| `--org <slug>` | اختر منظمة لهذا الاستدعاء. |
| `--token <token>` | تجاوز رمز جلسة المستخدم المحفوظ. |
| `--api-key <key>` | مصادقة الأتمتة مع مفتاح API؛ أبداً لم يتم الحفظ. |
| `--timeout <seconds>` | انتظار HTTP؛ يجب أن يكون موجباً. الافتراضي: `30`. |
| `--quiet`, `-q` | اكبت مخرجات الحالة على stderr. |
| `--no-color` | عطّل مخرجات ملونة. |
| `--insecure` / `--secure` | عطّل أو استعد التحقق من شهادة TLS. |
| `--version` | اطبع الإصدار بدون صندوق وخرج. |
| `--help`, `-h` | أظهر المساعدة. |

`--api-key` مخصص للأتمتة. تسجيل الدخول وتبديل المنظمة وأوامر المساعد تتطلب جلسة مستخدم.

## متغيرات البيئة

| المتغير | المكافئ أو الغرض |
| --- | --- |
| `FP_DASHBOARD_URL` | `--base-url` |
| `FP_ORG` | `--org` |

| `FP_JSON` | `--json` |
| `FP_INSECURE` | `--insecure` |
| `FP_HOME` | نقل دليل تكوين CLI (افتراضي `~/.failproofai/fpcli`). |
| `FP_ANALYTICS_DISABLED` أو `DO_NOT_TRACK` | عطّل تحليلات CLI المجهولة. |
| `NO_COLOR` | عطّل مخرجات ملونة. |

تتجاوز الأعلام الصريحة متغيرات البيئة، التي تتجاوز التكوين المحفوظ. في وضع مفتاح API، اختر المستأجر بشكل صريح مع `--org` أو `FP_ORG`.

<Warning>
  تهجئات `AGENTEYE_*` لهذه **لم يتم قراءتها بواسطة `fp`** وأبداً كانت — يعلن CLI `FP_*` (`fp_cli/app.py`)، ومتغير غير معروف ليس خطأ. تعيين `AGENTEYE_DASHBOARD_URL` لا يعيد توجيه CLI؛ يتم تجاهله والأمر يعمل بصمت ضد لوحة التحكم المحفوظة بدلاً من ذلك.

  `AGENTEYE_HOME` و `AGENTEYE_ENVIRONMENT` لا يزالان موجودان، لكنهما ينتميان إلى **جامع وTelemetry SDK**، وليس إلى هذا CLI.
</Warning>

<Warning>
  الأوامر التي تحذف أو تلغي أو تكبت أو تحل أو تستبدل التكوين تطالب بشكل افتراضي. استخدم `--yes` فقط بعد التحقق من المنظمة النشطة والهدف.
</Warning>
