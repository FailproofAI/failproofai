استخدم `fp` للتفتيش على بيانات telemetry السحابة، وإدارة فرض العمل المدار بواسطة السحابة (السياسات، نشرات الأسطول، قرارات guardrail)، والإشراف على عمليات التدقيق والنتائج والمشاكل والتنبيهات والمفاتيح والمستخدمين والاستعلامات والإعدادات. استخدم [`failproofai`](/ar/reference/failproof-cli) للخطافات المحلية والسياسات والالتقاط وتسجيل الماكينة.

ثبّت واجهة سطر الأوامر السحابية المُصدرة كأداة معزولة:

```bash
uv tool install fp-cloud-cli
fp version
```

## تسجيل الدخول

```bash
fp login
fp whoami
```

## بناء الجملة

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

يجب أن تأتي الخيارات العامة قبل الأمر:

```bash
fp --json sessions --since 24h
```

شغّل `fp COMMAND --help` أو `fp COMMAND SUBCOMMAND --help` للحصول على مساعدة من المحطة الطرفية.

### الأحداث

```text
fp events [OPTIONS]
```

تسرد أحداث الوكيل الفردية. يستبعد التغذية الخفيفة الافتراضية الحمولات الأولية؛ استخدم `--full` فقط للتحقيق المحدود.

| الخيار | الوصف |
| --- | --- |
| `--limit`, `-n <n>` | الحد الأقصى للصفوف الكلية. الافتراضي: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h`, أو `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | نطاق ISO 8601 UTC؛ يتجاوز `--since`. |
| `--env <value>` | تصفية البيئة؛ كرر أو افصل القيم بفواصل. |
| `--event-type <value>` | تصفية نوع الحدث؛ كرر أو افصل القيم بفواصل. |
| `--agent-id <value>` | تصفية الوكيل؛ كرر أو افصل القيم بفواصل. |
| `--session-id <value>` | تصفية الجلسة؛ كرر أو افصل القيم بفواصل. |
| `--search <text>` | بحث نصي عن الحمولة؛ قابل للتكرار، مع مطابقة أي حد. |
| `--order asc\|desc` | ترتيب زمني. الافتراضي: الأحدث أولاً. |
| `--all` | ترحيل تلقائي حتى `--limit`. |
| `--cursor <token>` | استئناف من مؤشر معتم. |
| `--page-size <n>` | صفوف لكل طلب مع `--all`؛ الحد الأقصى `200`. |
| `--full` | تضمين الحمولات الأولية من خلال نقطة نهاية الحدث الأثقل. |
| `--fields <csv>` | إرجاع الحقول المحددة فقط؛ طلب `payload` يفعّل الوضع الكامل. |

```bash
fp events --session-id <session-id> --order asc --all --limit 10000
fp --json events --full --session-id <session-id> --all --limit 10000
```

<Note>
  `--all` يرحّل **حتى `--limit`**، والذي يبلغ افتراضياً **50** — لذا `--all` بمفرده يتوقف عند 50 صف. عندما يتوقف مبكراً، تحمل الاستجابة `next_cursor` للاستئناف منه؛ `"next_cursor": null` يعني أن التغذية كانت مستنفدة فعلاً.
</Note>

#### خيارات إنشاء المراجعة

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| الخيار | الوصف |
| --- | --- |
| `--file <path>` | بناء التعريف على JSON، أو استخدم `-` للإدخال القياسي. الأعلام الصريحة تتجاوز قيم الملف. |
| `--description <text>` | حدد سؤال الفشل أو الغرض. |
| `--enabled` / `--disabled` | ابدأ الجدولة على أو بـ إيقاف. الافتراضي: مفعّل. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. الافتراضي: `86400`. |
| `--schedule-anchor <timestamp>` | المرحلة UTC الثابتة بصيغة ISO 8601. الافتراضي: 09:00 UTC التالية. |
| `--window-mode since_last\|fixed` | متابعة بعد آخر نافذة تم تحليلها بالكامل أو فحص نافذة متداخلة بشكل متكرر. الافتراضي: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. الافتراضي: `604800`. |
| `--scope '<json>'` | التصفية حسب `environments`, `agent_ids`, أو حقول نطاق أخرى مدعومة. |
| `--ignore-error-type <type>` | استبعد أنواع الأخطاء؛ كرر أو افصل بفواصل. |
| `--llm` / `--no-llm` | فعّل أو عطّل التحليل الذي يحركه الوكيل. الافتراضي: مفعّل. |
| `--top-k <n>` | احتفظ بـ `1`–`500` نتيجة. الافتراضي: `50`. |
| `--sensitivity low\|medium\|high` | اضبط حساسية الإبلاغ. الافتراضي: `medium`. |
| `--channels '<json>'` | مصفوفة قنوات الإخطار. |
| `--text <brief>` | ملخص مضمن، بحد أقصى 8192 حرف. |
| `--text-file <path>` | اقرأ الملخص من ملف؛ متعارض مع `--text`. |
| `--url <https-url>` | أضف مرجعاً عام HTTPS؛ كرر حتى خمس مرات. |

أدرج السياق أثناء الإنشاء عندما يحتاجه التشغيل الأول. الإنشاء ينفذ التعريف والسياق معاً قبل بدء التشغيل المطلوب.

<Note>
  `fp audits run` غير متزامن. استطلع `fp audits runs NAME` حتى ينجح التشغيل الأخير أو يفشل قبل قراءة نتائجه.
</Note>

إصدارات السياسة المدارة بواسطة السحابة. **جلسة فقط** — كل أمر هنا يُخرج `2` تحت مفتاح API، قبل أي طلب، لأن هذه مسارات كتابة جذرية محذوفة عن قصد من `/v1`.

| الأمر | الغرض | الخيارات |
| --- | --- | --- |
| `fp policies list` | عرض قائمة إصدارات السياسة. | `--json` |
| `fp policies show POLICY_ID` | عرض سياسة واحدة، مع مصدرها. | — |
| `fp policies publish NAME PATH` | نقيب إصدار من `.mjs` محلي. | `--description`; `--no-verify` |
| `fp policies enable POLICY_ID` | أضفها مرة أخرى إلى كل نشر تم إزالتها منه، نقيب جيل جديد على كل واحد. | `--yes`, `-y` |
| `fp policies disable POLICY_ID` | أزلها من كل نشر تحملها، نقيب جيل جديد على كل واحد. | `--yes`, `-y` |
| `fp policies delete POLICY_ID` | حذف إصدار سياسة. | `--yes`, `-y` |
| `fp policies test PATH` | شغّل سياسة محلياً مقابل سياق تركيبي. تطبق تصفية `match` لكل سياسة، لذلك التي لا تغطي الحدث/الأداة المحددة يتم الإبلاغ عنها `skipped` بدلاً من التشغيل. | `--event`; `--tool`; `--command`; `--file`; `--expect` |
| `fp policies compose PROMPT` | صيغ سياسة مع المساعد. يحتاج `policies:write`. | — |

## الأعلام العامة

| العلم | الوصف |
| --- | --- |
| `--json` | بث JSON قابل للقراءة من الآلة. |
| `--base-url <url>` | استخدم لوحة تحكم ذاتية الاستضافة أو التطوير. |
| `--org <slug>` | حدد مؤسسة لهذا الاستدعاء. |
| `--token <token>` | تجاوز رمز جلسة المستخدم المحفوظ. |
| `--api-key <key>` | المصادقة الأتمتة برمز API؛ لا تُحفظ أبداً. |
| `--timeout <seconds>` | مهلة HTTP؛ يجب أن تكون موجبة. الافتراضي: `30`. |
| `--quiet`, `-q` | قمع إخراج الحالة على stderr. |
| `--no-color` | تعطيل الإخراج الملون. |
| `--insecure` / `--secure` | تعطيل أو استعادة التحقق من شهادة TLS. |
| `--version` | طباعة الإصدار المفتوح والخروج. |
| `--help`, `-h` | عرض المساعدة. |

`--api-key` مخصصة للأتمتة. تسجيل الدخول وتبديل المؤسسة وأوامر المساعد تتطلب جلسة مستخدم.

## متغيرات البيئة

| المتغير | المكافئ أو الغرض |
| --- | --- |
| `FP_DASHBOARD_URL` | `--base-url` |
| `FP_ORG` | `--org` |
| `FP_TOKEN` | `--token` |
| `FP_API_KEY` | `--api-key` |
| `FP_JSON` | `--json` |
| `FP_INSECURE` | `--insecure` |
| `FP_HOME` | أعد وضع مجلد تكوين CLI (الافتراضي `~/.failproofai/fpcli`). |
| `FP_ANALYTICS_DISABLED` أو `DO_NOT_TRACK` | عطّل تحليلات CLI المجهولة. |
| `NO_COLOR` | عطّل الإخراج الملون. |

الأعلام الصريحة تتجاوز متغيرات البيئة، التي تتجاوز التكوين المحفوظ. في وضع مفتاح API، حدد المستأجر بشكل صريح مع `--org` أو `FP_ORG`.

<Warning>
  تهجئات `AGENTEYE_*` لهذه **لا تُقرأ بواسطة `fp`** وأبداً لم تكن — يعلن CLI عن `FP_*` (`fp_cli/app.py`)، وحتى متغير غير معروف ليس خطأ. تعيين `AGENTEYE_DASHBOARD_URL` لا يعيد تحديد هدف CLI؛ يتم تجاهله والأمر يعمل بصمت مقابل لوحة التحكم المحفوظة بدلاً منه.

  `AGENTEYE_HOME` و `AGENTEYE_ENVIRONMENT` لا تزال موجودة، لكنها تتعلق بـ **المجمع و telemetry SDK**، وليس بـ CLI هذا.
</Warning>

<Warning>
  الأوامر التي تحذف أو تلغي أو تقمع أو تحل أو تستبدل التكوين تطالب بشكل افتراضي. استخدم `--yes` فقط بعد التحقق من المؤسسة النشطة والهدف.
</Warning>
