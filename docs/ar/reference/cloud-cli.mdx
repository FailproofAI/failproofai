استخدم `fp` للتحقق من بيانات السحابة والتحكم في عمليات التدقيق والنتائج والمشاكل والتنبيهات والمفاتيح والمستخدمين والاستعلامات والإعدادات. استخدم [`failproofai`](/ar/reference/failproof-cli) للخطافات المحلية والسياسات والالتقاط وتسجيل الآلات.

ثبّت Cloud CLI المُصدرة كأداة معزولة:

```bash
uv tool install fp-cli
fp version
```

## تسجيل الدخول

```bash
fp login
fp whoami
```

## بناء الجملة

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

يجب أن تأتي الخيارات العامة قبل الأمر:

```bash
fp --json sessions --since 24h
```

شغّل `fp COMMAND --help` أو `fp COMMAND SUBCOMMAND --help` للحصول على المساعدة في الطرفية.

### الأحداث

```text
fp events [OPTIONS]
```

يسرد أحداث الوكيل الفردية. يستبعد التغذية الخفيفة الافتراضية الحمولات الخام؛ استخدم `--full` فقط للتحقيق المحدود.

| الخيار | الوصف |
| --- | --- |
| `--limit`, `-n <n>` | الحد الأقصى لإجمالي الصفوف. الافتراضي: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h`, أو `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | نطاق ISO 8601 UTC؛ يتجاوز `--since`. |
| `--env <value>` | مرشح البيئة؛ كرّر أو افصل القيم بفواصل. |
| `--event-type <value>` | مرشح نوع الحدث؛ كرّر أو افصل القيم بفواصل. |
| `--agent-id <value>` | مرشح الوكيل؛ كرّر أو افصل القيم بفواصل. |
| `--session-id <value>` | مرشح الجلسة؛ كرّر أو افصل القيم بفواصل. |
| `--search <text>` | بحث نصي بالحمولة؛ قابل للتكرار، مع مطابقة أي مصطلح. |
| `--order asc\|desc` | ترتيب زمني. الافتراضي: الأحدث أولاً. |
| `--all` | ترقيم تلقائي حتى `--limit`. |
| `--cursor <token>` | استئنف من مؤشر معتم. |
| `--page-size <n>` | صفوف لكل طلب مع `--all`؛ الحد الأقصى `200`. |
| `--full` | ضمّن الحمولات الخام عبر نقطة نهاية الحدث الأثقل وزناً. |
| `--fields <csv>` | أرجع الحقول المحددة فقط؛ طلب `payload` يفعّل الوضع الكامل. |

```bash
fp events --session-id <session-id> --order asc --all
fp --json events --full --session-id <session-id> --all
```

#### خيارات إنشاء التدقيق

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| الخيار | الوصف |
| --- | --- |
| `--file <path>` | أساس التعريف على JSON، أو استخدم `-` لـ stdin. الأعلام الصريحة تتجاوز قيم الملف. |
| `--description <text>` | اذكر سؤال الفشل أو الغرض. |
| `--enabled` / `--disabled` | ابدأ الجدولة بتشغيل أو إيقاف. الافتراضي: ممكّن. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. الافتراضي: `86400`. |
| `--schedule-anchor <timestamp>` | مرحلة UTC ثابتة بصيغة ISO 8601. الافتراضي: القادمة 09:00 UTC. |
| `--window-mode since_last\|fixed` | استمر بعد آخر نافذة محللة بالكامل أو افحص نافذة متحركة بشكل متكرر. الافتراضي: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. الافتراضي: `604800`. |
| `--scope '<json>'` | صفّ حسب `environments`, `agent_ids`, أو حقول النطاق المدعومة الأخرى. |
| `--ignore-error-type <type>` | استبعد أنواع الأخطاء؛ كرّر أو افصل بفواصل. |
| `--llm` / `--no-llm` | فعّل أو عطّل التحليل الوكيل. الافتراضي: ممكّن. |
| `--top-k <n>` | احتفظ بـ `1`–`500` نتيجة. الافتراضي: `50`. |
| `--sensitivity low\|medium\|high` | اضبط حساسية التقرير. الافتراضي: `medium`. |
| `--channels '<json>'` | مصفوفة قنوات الإشعار. |
| `--text <brief>` | موجز مضمّن، بحد أقصى 8,192 حرف. |
| `--text-file <path>` | اقرأ الموجز من ملف؛ حصري معاً مع `--text`. |
| `--url <https-url>` | أضف مرجعاً عاماً HTTPS؛ كرّر حتى خمس مرات. |

ضمّن السياق أثناء الإنشاء عندما تحتاج العملية الأولى إليه. يلتزم الإنشاء بالتعريف والسياق معاً قبل أن تبدأ العملية المصطفة.

<Note>
  `fp audits run` غير متزامن. استقصِ `fp audits runs NAME` حتى تنجح أو تفشل أحدث عملية قبل قراءة نتائجها.
</Note>

| `--no-color` | عطّل الإخراج الملون. |
| `--insecure` / `--secure` | عطّل أو استعد التحقق من شهادة TLS. |
| `--version` | اطبع الإصدار وغادر. |
| `--help`, `-h` | اعرض المساعدة. |

`--api-key` مخصص للأتمتة. تسجيل الدخول وتبديل المنظمة وأوامر المساعد تتطلب جلسة مستخدم.

## متغيرات البيئة

| المتغير | ما يعادله أو الغرض |
| --- | --- |
| `AGENTEYE_DASHBOARD_URL` | `--base-url` |
| `AGENTEYE_ORG` | `--org` |
| `AGENTEYE_CLI_TOKEN` | `--token` |
| `AGENTEYE_CLI_API_KEY` | `--api-key` |
| `AGENTEYE_CLI_JSON` | `--json` |
| `AGENTEYE_INSECURE` | `--insecure` |
| `AGENTEYE_HOME` | أعد تحديد موقع مجلد تكوين CLI الحالي. |
| `AGENTEYE_ANALYTICS_DISABLED` أو `DO_NOT_TRACK` | عطّل تحليلات CLI المجهولة. |
| `NO_COLOR` | عطّل الإخراج الملون. |

تتجاوز الأعلام الصريحة متغيرات البيئة، والتي تتجاوز الإعدادات المحفوظة. في وضع مفتاح API، حدد المستأجر بوضوح باستخدام `--org` أو `AGENTEYE_ORG`.

  تطالب الأوامر التي تحذف أو تبطل أو تقمع أو تحلّ أو تستبدل التكوين بشكل افتراضي. استخدم `--yes` فقط بعد التحقق من المنظمة النشطة والهدف.
</Warning>
