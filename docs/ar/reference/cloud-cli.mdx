استخدم `fp` لفحص بيانات Cloud الوصفية وإدارة الفرض المدار بواسطة السحابة (السياسات وعمليات نشر الأسطول وقرارات الحماية) وإدارة التدقيق والنتائج والقضايا والتنبيهات والمفاتيح والمستخدمين والاستعلامات والإعدادات. استخدم [`failproofai`](/ar/reference/failproof-cli) للخطافات المحلية والسياسات والالتقاط وتسجيل الماكينات.

ثبّت Cloud CLI المُصدرة كأداة معزولة:

```bash
uv tool install fp-cloud-cli
fp version
```

## تسجيل الدخول

```bash
fp login
fp whoami
```

## بناء الجملة

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

يجب أن تأتي الخيارات العامة قبل الأمر:

```bash
fp --json sessions --since 24h
```

شغّل `fp COMMAND --help` أو `fp COMMAND SUBCOMMAND --help` للحصول على المساعدة في المحطة الطرفية.

### الأحداث

```text
fp events [OPTIONS]
```

يسرد أحداث الوكيل الفردية. يستبعد الخلاصة الخفيفة الافتراضية الأحمال الأولية؛ استخدم `--full` فقط للتحقيق المحدود.

| الخيار | الوصف |
| --- | --- |
| `--limit`, `-n <n>` | الحد الأقصى الكلي للصفوف. الافتراضي: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h`, أو `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | نطاق ISO 8601 UTC؛ يتجاوز `--since`. |
| `--env <value>` | مرشح البيئة؛ كرّر أو افصل القيم بفواصل. |
| `--event-type <value>` | مرشح نوع الحدث؛ كرّر أو افصل القيم بفواصل. |
| `--agent-id <value>` | مرشح الوكيل؛ كرّر أو افصل القيم بفواصل. |
| `--session-id <value>` | مرشح الجلسة؛ كرّر أو افصل القيم بفواصل. |
| `--search <text>` | بحث نصي في الحمل الأولي؛ قابل للتكرار، مع مطابقة أي حد. |
| `--order asc\|desc` | ترتيب الوقت. الافتراضي: الأحدث أولاً. |
| `--all` | صفحة تلقائية تصل إلى `--limit`. |
| `--cursor <token>` | استئنف من مؤشر معتم. |
| `--page-size <n>` | الصفوف لكل طلب مع `--all`؛ الحد الأقصى `200`. |
| `--full` | ضمّن الأحمال الأولية عبر نقطة الحدث الأثقل وزناً. |
| `--fields <csv>` | أرجع الحقول المحددة فقط؛ يتطلب طلب `payload` وضع المحرّر الكامل. |

```bash
fp events --session-id <session-id> --order asc --all --limit 10000
fp --json events --full --session-id <session-id> --all --limit 10000
```

<Note>
  `--all` ينقّح **حتى `--limit`**، والذي يأتي بقيمة افتراضية تبلغ **50** — لذلك `--all` بمفردها تتوقف عند 50 صفاً. عندما تتوقف مبكراً، تحمل الاستجابة `next_cursor` للاستئناف منها؛ `"next_cursor": null` تعني أن الخلاصة استُنفدت حقاً.
</Note>

#### خيارات إنشاء التدقيق

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| الخيار | الوصف |
| --- | --- |
| `--file <path>` | اعتمد التعريف على JSON، أو استخدم `-` لـ stdin. الأعلام الصريحة تتجاوز قيم الملف. |
| `--description <text>` | اذكر سؤال الفشل أو الغرض. |
| `--enabled` / `--disabled` | ابدأ الجدولة على أو بدونها. الافتراضي: مفعل. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. الافتراضي: `86400`. |
| `--schedule-anchor <timestamp>` | مرحلة UTC ثابتة بصيغة ISO 8601. الافتراضي: الساعة 09:00 UTC القادمة. |
| `--window-mode since_last\|fixed` | ابدأ بعد آخر نافذة تم تحليلها بالكامل أو افحص نافذة متحركة بشكل متكرر. الافتراضي: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. الافتراضي: `604800`. |
| `--scope '<json>'` | صفّ حسب `environments`, `agent_ids`, أو حقول نطاق مدعومة أخرى. |
| `--ignore-error-type <type>` | استبعد أنواع الأخطاء؛ كرّر أو افصل. |
| `--llm` / `--no-llm` | فعّل أو عطّل التحليل المدعوم بالوكيل. الافتراضي: مفعل. |
| `--top-k <n>` | احتفظ بـ `1`–`500` نتيجة. الافتراضي: `50`. |
| `--sensitivity low\|medium\|high` | اضبط حساسية الإبلاغ. الافتراضي: `medium`. |
| `--channels '<json>'` | مصفوفة قناة الإخطار. |
| `--text <brief>` | موجز مضمّن، بحد أقصى 8192 حرفاً. |
| `--text-file <path>` | اقرأ الموجز من ملف؛ متنافي مع `--text`. |
| `--url <https-url>` | أضف مرجعاً عاماً HTTPS؛ كرّر حتى خمس مرات. |

ضمّن السياق أثناء الإنشاء عندما يحتاج التشغيل الأول إليه. يسجّل الإنشاء التعريف والسياق معاً قبل بدء التشغيل المجدول.

<Note>
  `fp audits run` غير متزامن. استقصِ `fp audits runs NAME` حتى ينجح التشغيل الأحدث أو يفشل قبل قراءة نتائجه.
</Note>

إصدارات السياسات المدارة بواسطة السحابة. **جلسة فقط** — كل أمر هنا ينتهي برمز `2` بموجب مفتاح API، قبل أي طلب، لأن هذه عمليات كتابة جذرية متعمدة غير موجودة في `/v1`.

| الأمر | الغرض | الخيارات |
| --- | --- | --- |
| `fp policies list` | ادرج إصدارات السياسة. | `--json` |
| `fp policies show POLICY_ID` | اعرض سياسة واحدة مع مصدرها. | — |
| `fp policies publish NAME PATH` | اصك إصدارة من `.mjs` محلي. | `--description`; `--no-verify` |
| `fp policies enable POLICY_ID` | أضفها مجدداً إلى كل نشر تمت إزالتها منه، واصك جيل جديد على كل واحد. | `--yes`, `-y` |
| `fp policies disable POLICY_ID` | أزلها من كل نشر يحملها، واصك جيل جديد على كل واحد. | `--yes`, `-y` |
| `fp policies delete POLICY_ID` | احذف إصدار سياسة. | `--yes`, `-y` |
| `fp policies test PATH` | شغّل سياسة محلياً مقابل سياق اصطناعي. تطبّق مرشح `match` لكل سياسة، لذلك يتم الإبلاغ عن واحد لا يغطي الحدث/الأداة المعطاة باسم `skipped` بدلاً من التشغيل. | `--event`; `--tool`; `--command`; `--file-path`; `--expect` |
| `fp policies compose PROMPT` | صغ سياسة مع المساعد. تحتاج `policies:write`. | — |

## الأعلام العامة

| العلم | الوصف |
| --- | --- |
| `--json` | أصدر JSON قابلاً للقراءة الآلية. |
| `--base-url <url>` | استخدم لوحة قيادة ذاتية التدقيق أو للتطوير. |
| `--org <slug>` | حدّد مؤسسة لهذا الاستدعاء. |
| `--token <token>` | تجاوز رمز جلسة المستخدم المحفوظ. |
| `--api-key <key>` | صرّح الأتمتة باستخدام مفتاح API؛ لم يتم الحفظ أبداً. |
| `--timeout <seconds>` | مهلة HTTP؛ يجب أن تكون موجبة. الافتراضي: `30`. |
| `--quiet`, `-q` | كبّت إخراج الحالة على stderr. |
| `--no-color` | عطّل الإخراج الملون. |
| `--insecure` / `--secure` | عطّل أو استعد التحقق من شهادة TLS. |
| `--version` | اطبع الإصدار الصريح والخروج. |
| `--help`, `-h` | اعرض المساعدة. |

`--api-key` مخصص للأتمتة. تسجيل الدخول وتبديل المؤسسة وأوامر المساعد تتطلب جلسة مستخدم.

## متغيرات البيئة

| المتغير | ما يعادله أو الغرض |
| --- | --- |
| `FP_DASHBOARD_URL` | `--base-url` |
| `FP_ORG` | `--org` |
| `FP_TOKEN` | `--token` |
| `FP_API_KEY` | `--api-key` |
| `FP_JSON` | `--json` |
| `FP_INSECURE` | `--insecure` |
| `FP_HOME` | أعد تحديد موقع دليل تكوين CLI (افتراضي `~/.failproofai/fpcli`). |
| `FP_ANALYTICS_DISABLED` أو `DO_NOT_TRACK` | عطّل تحليل CLI المجهول. |
| `NO_COLOR` | عطّل الإخراج الملون. |

الأعلام الصريحة تتجاوز متغيرات البيئة، التي تتجاوز التكوين المحفوظ. في وضع مفتاح API، حدّد المستأجر بشكل صريح باستخدام `--org` أو `FP_ORG`.

<Warning>
  تهجئات `AGENTEYE_*` لهذه **لا يتم قراءتها بواسطة `fp`** ولم تكن أبداً — يصرّح CLI بـ `FP_*` (`fp_cli/app.py`)، والمتغير غير المعروف ليس خطأ. تعيين `AGENTEYE_DASHBOARD_URL` لا يعيد استهداف CLI؛ يتم تجاهله والأمر يعمل بصمت ضد لوحة القيادة المحفوظة بدلاً من ذلك.

  `AGENTEYE_HOME` و `AGENTEYE_ENVIRONMENT` موجودة بعد، لكنها تنتمي إلى **جامع وSDK القياس**، وليس إلى هذا CLI.
</Warning>

<Warning>
  الأوامر التي تحذف أو تسحب أو تكبّت أو تحلّ أو تستبدل التكوين تطلب بشكل افتراضي. استخدم `--yes` فقط بعد التحقق من المؤسسة النشطة والهدف.
</Warning>
