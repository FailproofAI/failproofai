استخدم `fp` للتفتيش على telemetry السحابة وإدارة الإنفاذ المدار سحابياً (السياسات وعمليات النشر للأسطول وقرارات الحماية) وإدارة التدقيق والنتائج والمشاكل والتنبيهات والمفاتيح والمستخدمين والاستعلامات والإعدادات. استخدم [`failproofai`](/ar/reference/failproof-cli) للخطافات المحلية والسياسات والالتقاط وتسجيل الآلات.

ثبّت Cloud CLI المصدَّر كأداة معزولة:

```bash
uv tool install fp-cloud-cli
fp version
```

## تسجيل الدخول

```bash
fp login
fp whoami
```

## الصيغة

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

يجب أن تأتي الخيارات العامة قبل الأمر:

```bash
fp --json sessions --since 24h
```

شغّل `fp COMMAND --help` أو `fp COMMAND SUBCOMMAND --help` للحصول على مساعدة الطرفية.

### الأحداث

```text
fp events [OPTIONS]
```

يسرد أحداث الوكيل الفردية. تستبعد خلاصة البث الخفيفة الافتراضية البيانات الخام؛ استخدم `--full` فقط للتحقيق المحدود.

| الخيار | الوصف |
| --- | --- |
| `--limit`, `-n <n>` | الحد الأقصى للصفوف الإجمالية. الافتراضي: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h`, أو `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | نطاق ISO 8601 UTC؛ يتجاوز `--since`. |
| `--env <value>` | فلتر البيئة؛ كرر أو افصل بفواصل. |
| `--event-type <value>` | فلتر نوع الحدث؛ كرر أو افصل بفواصل. |
| `--agent-id <value>` | فلتر الوكيل؛ كرر أو افصل بفواصل. |
| `--session-id <value>` | فلتر الجلسة؛ كرر أو افصل بفواصل. |
| `--search <text>` | بحث نص البيانات؛ قابل للتكرار مع مطابقة أي مصطلح. |
| `--order asc\|desc` | ترتيب الوقت. الافتراضي: الأحدث أولاً. |
| `--all` | ترقيم تلقائي حتى `--limit`. |
| `--cursor <token>` | استئناف من مؤشر معتم. |
| `--page-size <n>` | صفوف لكل طلب مع `--all`؛ الحد الأقصى `200`. |
| `--full` | تضمين البيانات الخام عبر نقطة نهاية الحدث الأثقل. |
| `--fields <csv>` | إرجاع الحقول المحددة فقط؛ طلب `payload` يفعّل الوضع الكامل. |

```bash
fp events --session-id <session-id> --order asc --all --limit 10000
fp --json events --full --session-id <session-id> --all --limit 10000
```

<Note>
  `--all` يرقّم حتى `--limit`**، الذي يبلغ افتراضياً **50** — لذا فإن `--all` وحده يتوقف عند 50 صفاً. عند التوقف مبكراً تحتوي الاستجابة على `next_cursor` للاستئناف منه؛ `"next_cursor": null` تعني أن البث كان محسوماً فعلاً.
</Note>

#### خيارات إنشاء التدقيق

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| الخيار | الوصف |
| --- | --- |
| `--file <path>` | أساس التعريف على JSON، أو استخدم `-` لـ stdin. تتجاوز الأعلام الصريحة قيم الملف. |
| `--description <text>` | اذكر سؤال الفشل أو الغرض. |
| `--enabled` / `--disabled` | ابدأ الجدولة أم لا. الافتراضي: ممكّن. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. الافتراضي: `86400`. |
| `--schedule-anchor <timestamp>` | مرحلة UTC ثابتة بشكل ISO 8601. الافتراضي: 09:00 UTC التالي. |
| `--window-mode since_last\|fixed` | استمر بعد آخر نافذة محللة بالكامل أو فحص متكرر للنافذة المتحركة. الافتراضي: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. الافتراضي: `604800`. |
| `--scope '<json>'` | فلتر حسب `environments`, `agent_ids`، أو حقول نطاق مدعومة أخرى. |
| `--ignore-error-type <type>` | استبعد أنواع الأخطاء؛ كرر أو افصل بفواصل. |
| `--llm` / `--no-llm` | فعّل أو عطّل التحليل الوكيل. الافتراضي: ممكّن. |
| `--top-k <n>` | احتفظ بـ `1`–`500` نتائج. الافتراضي: `50`. |
| `--sensitivity low\|medium\|high` | عيّن حساسية الإبلاغ. الافتراضي: `medium`. |
| `--channels '<json>'` | مصفوفة قنوات الإشعارات. |
| `--text <brief>` | إيجاز مضمّن، الحد الأقصى 8,192 حرف. |
| `--text-file <path>` | اقرأ الإيجاز من ملف؛ حصري متبادل مع `--text`. |
| `--url <https-url>` | أضف مرجعاً عاماً HTTPS؛ كرر حتى خمس مرات. |

أدرج السياق عند الإنشاء عندما يحتاج التشغيل الأول إليه. الإنشاء ينفذ التعريف والسياق معاً قبل بدء التشغيل المصفوف.

<Note>
  `fp audits run` غير متزامن. استطلع `fp audits runs NAME` حتى يتمكّن آخر تشغيل أو يفشل قبل قراءة نتائجه.
</Note>

## الأعلام العامة

| العلم | الوصف |
| --- | --- |
| `--json` | أصدر JSON قابل للآلة. تتضمن الأخطاء `request_id` للطلب الفاشل. |
| `--base-url <url>` | استخدم لوحة معلومات موزعة ذاتياً أو تطوير. |
| `--org <slug>` | حدّد منظمة لهذا الاستدعاء. |
| `--token <token>` | تجاوز رمز جلسة المستخدم المحفوظ. |
| `--api-key <key>` | صرّح الأتمتة برمز API؛ لم يُحفظ أبداً. |
| `--timeout <seconds>` | انتهاء HTTP؛ يجب أن يكون موجباً. الافتراضي: `30`. |
| `--quiet`, `-q` | اكبت إخراج الحالة على stderr. |
| `--no-color` | عطّل الإخراج الملون. |
| `--insecure` / `--secure` | عطّل أو استعد تحقق شهادة TLS. |
| `--version` | اطبع الإصدار وخرج. |
| `--help`, `-h` | عرض المساعدة. |

`--api-key` مقصود للأتمتة. تسجيل الدخول وتبديل المنظمة وأوامر المساعد تتطلب جلسة مستخدم.

## متغيرات البيئة

| المتغير | المكافئ أو الغرض |
| --- | --- |
| `FP_DASHBOARD_URL` | `--base-url` |
| `FP_ORG` | `--org` |
| `FP_TOKEN` | `--token` |
| `FP_API_KEY` | `--api-key` |
| `FP_JSON` | `--json` |
| `FP_INSECURE` | `--insecure` |
| `FP_HOME` | انقل دليل إعدادات CLI (الافتراضي `~/.failproofai/fpcli`). |
| `FP_ANALYTICS_DISABLED` أو `DO_NOT_TRACK` | عطّل تحليلات CLI المجهولة. |
| `NO_COLOR` | عطّل الإخراج الملون. |

تتجاوز الأعلام الصريحة متغيرات البيئة التي تتجاوز الإعدادات المحفوظة. في وضع مفتاح API حدّد المستأجر بوضوح مع `--org` أو `FP_ORG`.

<Warning>
  تملّيات `AGENTEYE_*` هذه **لا تُقرأ بـ `fp`** ولم تكن أبداً — يعلن CLI عن `FP_*` (`fp_cli/app.py`)، ومتغير غير معروف ليس خطأ. تعيين `AGENTEYE_DASHBOARD_URL` لا يعيد تحديد هدف CLI؛ يُتجاهل والأمر يعمل بصمت ضد لوحة المعلومات المحفوظة.

  `AGENTEYE_HOME` و `AGENTEYE_ENVIRONMENT` لا تزال موجودة لكنها تنتمي إلى **المجمع و telemetry SDK**، ليس لـ CLI هذا.
</Warning>

<Warning>
  الأوامر التي تحذف أو تلغي أو تكبت أو تحل أو تستبدل الإعدادات تطلب افتراضياً. استخدم `--yes` فقط بعد التحقق من المنظمة النشطة والهدف.
</Warning>
