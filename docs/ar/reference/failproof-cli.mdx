قم بالتثبيت باستخدام `npm install -g failproofai`. قم بتشغيل `failproofai` بدون وسائط لفتح لوحة المعلومات المحلية.

## الأوامر الأساسية

| الأمر | الوظيفة |
| --- | --- |
| `failproofai config` | إعداد الوكلاء والخدمة الخلفية واتصال Cloud الاختياري |
| `failproofai config --token <key>` | الإعداد والاتصال بدون أسئلة |
| `failproofai config --status` | عرض الاتصال وإصدار الخدمة وحالة الإيقاف المؤقت |
| `failproofai policies` | قائمة بالسياسات وحالة تشغيلها |
| `failproofai policies add <name>` | تفعيل سياسة واحدة |
| `failproofai policies add <owner>/<repo>` | تثبيت حزمة سياسات |
| `failproofai policies remove <name-or-pack>` | تعطيل سياسة أو إزالة حزمة |
| `failproofai policies show <owner>/<repo>` | فحص حزمة قبل تثبيتها |
| `failproofai publish` | نشر سياساتك كحزمة |
| `failproofai audit` | مسح سجل الوكيل المحلي |
| `failproofai harness` | إدارة مواقع الجلسات الإضافية |
| `failproofai flush` | إرسال الأحداث المقررة الآن |
| `failproofai backfill` | إعادة قراءة سجل الوكيل الأقدم |
| `failproofai update` | إنهاء ترقية npm وتحديث الخدمة |
| `failproofai uninstall` | إزالة الخطافات والخدمة |

`policy` و `pack` و `p` مقبولة كأسماء بديلة لـ `policies`، لكن الوثائق تستخدم `policies`.

## إعداد جهاز

```bash
npm install -g failproofai
failproofai config
failproofai policies add FailproofAI/policies
failproofai config --status
```

الإعداد لا يختار أي حزمة سياسات. قبل إضافة واحدة، يعمل فقط `block-failproofai-commands`.

لإعداد Cloud بدون مراقبة:

```bash
export FAILPROOFAI_CLOUD_TOKEN="<key>"
failproofai config
```

لإرسال القرارات بدون نسخ صوتية، قم بالاتصال أولاً وعيّن `collector.sessions` إلى `false` في `~/.failproofai/config.json`. العلم `--no-transcripts` المستخدم في الإعداد الحالي تتم معالجته ولكن لا ينطبق هذا الإعداد.

استخدم `--machine-label <name>` بعد توصيل الجهاز لإعادة تسميته. `--connect <url>` هو الأمر الأضيق الخاص بالتسجيل فقط لجهاز تم إعداده بالفعل.

## السياسات والحزم

```bash
failproofai policies
failproofai policies add block-sudo
failproofai policies show owner/repo
failproofai policies add owner/repo --category git,database
failproofai policies remove owner/repo
```

أي شيء يحتوي على شرطة مائلة هو مصدر حزمة؛ أي شيء بدونها هو اسم سياسة.

أعلام اختيار الحزمة المفيدة:

| العلم | الاستخدام |
| --- | --- |
| `--policy a,b` | تحديد السياسات المسماة |
| `--category x,y` | تحديد الفئات |
| `--all` | تحديد كل شيء |
| `--cli <agents...>` | تقييد الأجهزة المحمولة المسماة |

استخدم `failproofai policies -i -c <path>` لتحميل سياسة مخصصة من أي مسار. ملفات الاتفاقيات المسماة `*policies.{js,mjs,ts}` ضمن `.failproofai/policies/` تُحمّل تلقائياً.

## إيقاف الإنفاذ مؤقتاً

```bash
failproofai config --pause 10m
failproofai config --status
failproofai config --resume
```

الإيقاف المؤقت ينطبق على جلسة محلية واحدة ويتوقف دائماً. لا يوقف سياسات Cloud المُدارة أو `block-failproofai-commands`.

## المراجعة والتسليم

```bash
failproofai audit
failproofai audit --schedule 7 --email team@example.com
failproofai audit --status
failproofai flush --wait
failproofai backfill --since 30d --dry-run
```

يقرأ `backfill` من `~/.failproofai/config.json`. أزل `--dry-run` لإرسال السجل مرة أخرى.

## مواقع الجلسات الإضافية

```bash
failproofai harness list
failproofai harness add-path claude work=/srv/team/.claude/projects
failproofai harness remove-path claude work
```

التسميات تمنع دمج الجلسات من منزلتين تم نسخهما تحت نفس معرّف الوكيل المشتق.

الأجهزة المدعومة هي `claude` و `codex` و `copilot` و `cursor` و `opencode` و `pi` و `hermes` و `openclaw` و `factory` و `devin` و `antigravity` و `goose`. دعم النطاق يختلف؛ انظر [Harnesses](/ar/reference/harnesses).

## متغيرات البيئة المفيدة

| المتغير | الاستخدام |
| --- | --- |
| `FAILPROOFAI_CLOUD_TOKEN` | مفتاح جهاز Cloud |
| `FAILPROOFAI_CLOUD_URL` | تجاوز عنوان URL لـ Cloud |
| `FAILPROOFAI_HOME` | نقل مجلد الحالة المحلية |
| `FAILPROOFAI_NO_DOWNLOAD=1` | رفض تنزيلات الحزم والخدمة |
| `FAILPROOFAI_DAEMON_BASE_URL` | استخدم مرآة ثنائية خدمة |
| `FAILPROOFAI_PACK_BASE_URL` | استخدم مرآة حزمة |
| `FAILPROOFAI_NO_FIRST_RUN=1` | تعطيل طلبات المرة الأولى |
| `FAILPROOFAI_TELEMETRY_DISABLED=1` | تعطيل البيانات الوصفية المجهولة في CLI |
| `FAILPROOFAI_<HARNESS>_EXTRA_PATHS` | استبدال المسارات الإضافية لجهاز واحد |
| `NO_COLOR` | تعطيل ألوان المحطة |

## إزالة أو ترقية

```bash
npm install -g failproofai@latest
failproofai update
```

قبل إزالة الحزمة:

```bash
failproofai uninstall --dry-run
failproofai uninstall --yes
npm rm -g failproofai
```

<Warning>
  قم بتشغيل `failproofai uninstall` قبل إزالة حزمة npm. npm لا تزيل الخطافات المثبتة أو الخدمة الخلفية.
</Warning>

قم بتشغيل `failproofai help <command>` للحصول على الخيارات الكاملة في الإصدار المثبت لديك.
