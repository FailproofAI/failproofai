يقوم `failproofai otel` بتكوين إرسال OpenTelemetry الاختياري إلى FailproofAI Cloud. قم أولاً بتوصيل جهازك باستخدام `failproofai config` واطلب من مسؤول المؤسسة تفعيل **Settings → OpenTelemetry**.

يطرح الإعداد التفاعلي أسئلة حول OpenTelemetry بعد حقل مفتاح Cloud ومنتقي الوكيل. الخطوة الاختيارية تُعيِّن الافتراضي إلى لا. اختر نعم لاختيار وكلاء OTEL؛ نفس كود التفعيل يعمل بعد كتابة الاتصال. اضغط Esc قبل الإعداد لتطبيق عدم التغيير. الإعداد بدون تفاعل، ومفتاح مُزوَّد، والوضع مفتوح المصدر، والاحتفاظ بالاتصال المحفوظ لن يختاروك.

## تفعيل وكيل

```bash
failproofai otel enable claude
failproofai otel enable codex --local
failproofai otel enable codex --no-content
failproofai otel enable copilot
failproofai otel enable all --yes
```

الوكلاء المدعومون هم `claude` و `codex` و `copilot` (VS Code). يتطلب إعداد Copilot ملف تنفيذي VS Code أو ملحق Copilot مثبتاً. دليل الإعدادات المتبقي وحده غير كافٍ؛ الإعداد يتخطى Copilot عندما لا يتم العثور على أيٍّ منهما.

`--local` يرسل إلى المرحل المحلي بدلاً من إرساله مباشرة إلى Cloud. يستخدم Copilot المرحل تلقائياً لأن إعداداته لا يمكنها تخزين رأس المصادقة.

يستمع المرحل فقط على جهازك. يلتقط خادم FailproofAI المُعرّف لديك التغيير في غضون ثوانٍ؛ لا تحتاج إلى إعادة تشغيله. إذا امتلكت تطبيق آخر منفذ المرحل، تقرير الحالة يُظهره كمُطفأ والخادم يستمر في التشغيل.

<Warning>
التقاط النص مُفعَّل بشكل افتراضي. أضف `--no-content` لحذف الطلبات وتفاصيل الأداة. يمكن لإصدارات الوكيل أن تكشف عن عناصر تحكم محتوى مختلفة؛ راجع ما يُصدِّره وكيلك قبل استخدامه مع بيانات حساسة.
</Warning>

Codex يُصدِّر سجلات المحادثة فقط، وليس آثار وقت التشغيل الداخلية أو المقاييس. تعيين صريح `log_user_prompt = false` في تكوين Codex الخاص بك يبقى مُطفأ؛ التفعيل يطبع ملاحظة عندما يحافظ على هذا الاختيار.

### اختر مسار إرسال واحد

إذا كان إرسال النص مُفعَّلاً لوكيل، يطرح الإعداد:

> failproofai بالفعل يرسل جلسات Claude Code إلى Cloud. هل تريد إرسالها مع OTEL بدلاً من ذلك؟ يتوقف تحميل النص لـ Claude Code.

الافتراضي هو لا. `--yes` يقبل التبديل بدون موجه. الوكلاء الآخرون وفرض السياسة لا يتأثران.

ينتظر إعداد Codex تأكيد الخادم لتغيير المُجمّع قبل كتابة إعدادات المُصدِّر. إذا انتهت مهلة التأكيد، يحذرك الإعداد للانتظار قبل بدء Codex.

يحتفظ Config v2 بقائمة التتبع المتذكرة في `agents.selected` (وسجل الكشف في `agents.seen`). يبقى تفضيل النص لكل وكيل في `collector.agents.<agent>.sessions`، ملكية OTEL في `otel.agents`، وإعدادات المرحل في `collector.otlp.enabled` / `collector.otlp.port`. تحافظ هذه المفاتيح المنفصلة على قراءة تكوينات OTEL القديمة: يمكن للإعداد تغيير قائمة التتبع دون فقدان تفضيل النقل أو الحالة المطلوبة لاستعادة إعدادات وكيلك.

## فتش الإعداد

```bash
failproofai otel status
```

تُظهِر الحالة كل وكيل، ما إذا كانت إعداداته يديرها FailproofAI، وجهته، مفتاح الاستقبال بالمؤسسة، حالة المرحل، ونتيجة آخر تحميل المرحل.

`unknown` لمفتاح المؤسسة يعني أن الخادم لم يوفره أو لا يمكن الوصول إليه. إنه ليس خطأ ولا يمنع التكوين على إصدار Cloud أقدم.

إذا لم يدعم Cloud OTEL بعد، يحتفظ المرحل بالصادرات المرفوضة بدلاً من التخلص منها. إذا كان الاستقبال بالمؤسسة مُطفأ، `enable` لا يكتب شيئاً ويخرج بخطأ؛ اطلب من مسؤول تشغيله أولاً.

## اطبع التكوين لتطبيق

```bash
failproofai otel env --service my-agent
failproofai otel env --service my-agent --local
```

المخرجات عبارة عن كتلة بيئة shell لمُصدِّر OTLP/HTTP. يقوم مخرجات Cloud بتعيين `OTEL_EXPORTER_OTLP_ENDPOINT` إلى قاعدة OTLP بـ Cloud، `https://<cloud>/otel`، والمُصدِّر يُضيف `/v1/<signal>`؛ متغير لكل إشارة مثل `OTEL_EXPORTER_OTLP_LOGS_ENDPOINT` يحتاج إلى `https://<cloud>/otel/v1/logs` الكامل. مخرجات المحلي تشير إلى المرحل، `http://127.0.0.1:<port>`. تتضمن مخرجات Cloud مفتاح API المُعرّف؛ تعامل معه كسر. مخرجات المحلي تحذف المفتاح. لاستخدام مخرجات محلية، فعّل وكيل محلي أولاً حتى يعمل المرحل.

## استعد الإعدادات السابقة

```bash
failproofai otel disable claude
failproofai otel disable all
```

يستعيد الإطفاء فقط الإعدادات التي كتبها FailproofAI، ويحتفظ بالتغييرات غير ذات الصلة، ويستعيد اختيار إرسال النص السابق لكل وكيل. عند تعطيل آخر وكيل محلي مُدار، يتوقف المرحل عن قبول الصادرات.

لـ Codex، يسجل الإطفاء أيضاً `collector.agents.codex.sessions_resume_after` (بايت ملي ثانية epoch). يتم التعامل مع بايتات النشر الموجودة على أنها مُسلَّمة حتى لا يتم تحميل الجلسات المُلتقطة مع OTEL مرة أخرى؛ الإضافات اللاحقة تستمر في التدفق من خلال إرسال النص.

كل أمر يدعم `--help`. انظر [OpenTelemetry في Cloud](/ar/agenteye/opentelemetry) للحصول على أمثلة التطبيق ووكيل الترميز.
