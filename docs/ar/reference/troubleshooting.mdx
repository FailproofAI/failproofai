ابدأ بـ:

```bash
failproofai config --status
failproofai policies
```

## وكيل غير متصل

أعد تشغيل الإعداد:

```bash
failproofai config
```

يدعم الإعداد Linux و macOS. يتطلب وصول مسؤول مرة واحدة لتثبيت الخدمة، لكنه لا يطلب كلمة مرور sudo.

تحقق من مسارات الأجهزة والنطاقات في [Harnesses](/ar/reference/harnesses).

## جلسة مفقودة

```bash
failproofai flush --wait
failproofai backfill --since 30d --dry-run
failproofai harness list
```

أزل `--dry-run` لإعادة إرسال السجل القديم. أضف موقع نسخة أخرى بـ:

```bash
failproofai harness add-path <harness> [label=]<path>
```

استخدم تسمية عندما يحتوي موقعان على نسخ من نفس المشروع.

## كل إجراء محمي مرفوض

على جهاز مُعد، `failproofaid` هو المقيّم الوحيد. إذا لم يتمكن من الإجابة، تفشل الإجراءات المحمية بأمان.

```bash
failproofai config --status
systemctl status failproofaid@$USER        # Linux
sudo launchctl print system/ai.failproof.failproofaid.$USER  # macOS
```

شغّل `failproofai config` لإصلاح أو إعادة تثبيت الخدمة.

## حزمة واحدة ترفض

`failproofai policies` تسمي الحزم التي لا يمكن تحميلها. تفشل حزمة محددة بأمان بدلاً من الاختفاء.

الأسباب الشائعة:

- تغير الملف بعد التثبيت.
- البيان والسياسات المرفقة غير متطابقة.
- الملف مفقود أو لا يمكن استيراده.
- تستخدم الحزمة حدثاً أو أداة أو شكل سياسة غير مدعوم.

أزل الحزمة أو ثبّت إصدار معدّل:

```bash
failproofai policies remove owner/repo
failproofai policies add owner/repo@<release>
```

## السحابة غير متصلة

فضّل متغير البيئة للمفتاح:

```bash
export FAILPROOFAI_CLOUD_TOKEN="<key>"
failproofai config
failproofai config --status
```

يمكن لجهاز سحب السياسات وإرسال النشاط بشكل مستقل. تقرير الحالة يعرض كليهما.

## سياسة لم تحجب

تحقق من ثلاثة أشياء:

1. السياسة قيد التشغيل: `failproofai policies`.
2. حدثها وأداتها تطابق الإجراء.
3. يمكن لذلك الجهاز تطبيق الحدث.

يتم التحقق من رفض استدعاء الأداة على جميع الأجهزة الـ 12 المدعومة. تتنوع الأحداث الأخرى. انظر [قدرة التطبيق](/ar/reference/harnesses#enforcement-capability).

## التنزيلات محظورة

- `FAILPROOFAI_NO_DOWNLOAD=1` يرفض التنزيلات الشبكية.
- `FAILPROOFAI_DAEMON_BASE_URL` يوجه تنزيلات الخدمة إلى مرآة.
- `FAILPROOFAI_PACK_BASE_URL` يوجه تنزيلات الحزم إلى مرآة.

تحتفظ الحزم المثبتة بفرض السياسات عند تعطيل التنزيلات.
