اطلب من مساعد Failproof القيام بأي شيء في Failproof AI باللغة الطبيعية. يمكنه تحليل الجلسات والأخطاء، وتشغيل الاستعلامات، وبناء لوحات المعلومات، والتحقق من التقييمات والتنبيهات، والمساعدة في إنشاء وتشغيل التدقيقات دون الحاجة إلى ترجمة المهمة إلى شاشات المنتج أو أوامر سطر الأوامر.

```text
Why did production checkout agents regress this week?
Build a dashboard for tool failures, latency, and evaluation scores.
Create an audit that finds agents retrying the same failed action without changing approach.
Show me the sessions behind the most common audit finding.
```

يعمل المساعد مع البيانات والأذونات المتاحة في المنظمة النشطة. راجع أدلته والتغييرات المقترحة قبل تطبيق الإجراءات التي تؤثر على المستخدمين أو الوكلاء الآخرين.

## اسأل المساعد

<Tabs>
  <Tab title="لوحة المعلومات">
    1. حدد **فتح دردشة الوكيل** واصف ما تريد فهمه أو إنشاءه أو تشغيله.
    2. راجع استدعاءات الأداة والجداول ونتائج الاستعلام للمساعد أثناء عمله.
    3. افتح الجلسة أو التنبيه أو الاستعلام المشار إليه للتحقق من النتيجة مقابل البيانات الأصلية.
    4. ابدأ دردشة جديدة لتحقيق مختلف، أو استخدم سجل الدردشة لمتابعة نفس خط التحليل.

    ![مساعد السحابة يجيب على سؤال الملاحظة مع التحليل والاستعلامات الداعمة.](/images/dashboard/assistant.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp agent health
    fp agent models
    fp agent ask "Which production checkout agents had the most tool errors in the last 24 hours?"
    fp agent chats
    fp agent show <chat-id>
    fp agent ask "Open representative sessions" --chat <chat-id>
    ```

    استخدم `fp agent rename <chat-id> --title <title>` لإبقاء التحقيق معروفًا و`fp agent delete <chat-id>` لإزالته.
  </Tab>
</Tabs>

## العمل بفعالية مع المساعد

- أعطِه هدفًا أولاً؛ أضف بيئة أو سير عمل أو نطاق زمني عندما تكون هذه الحدود مهمة.
- تعامل مع SQL والملخصات المُنشأة كمساعدة في التحقيق، وليس كدليل نهائي.
- افتح جلسات تمثيلية قبل إنشاء تدقيق أو مشكلة أو تنبيه أو سياسة.
- احتفظ بمرشحات المنظمة والبيئة والوقت صريحة.
- احفظ SQL المفيد كاستعلام حتى يتمكن مشغل آخر من إعادة إنتاج النتيجة.

<Warning>
  يمكن للمساعد قراءة ما يمكن لمستخدمك الحالي الوصول إليه فقط. لا توسّع الأذونات لجعل السؤال يعمل؛ اطلب من مشغل مخول تشغيل التحقيق بدلاً من ذلك.
</Warning>
