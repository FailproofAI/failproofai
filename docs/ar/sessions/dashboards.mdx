تجمع لوحات التحكم الاستعلامات المحفوظة في عرض تشغيلي. قم ببناء واحدة حول قرار تتوقع أن يتخذه شخص ما—وليس حول كل مقياس متاح.

## بناء لوحة تحكم

<Tabs>
  <Tab title="لوحة التحكم">
    1. انتقل إلى **Analyze → Queries**، وأنشئ أو افتح استعلاماً محفوظاً، والتحقق من نتيجته.
    2. اختر **add to dashboard**، ثم اختر لوحة تحكم موجودة أو أنشئ واحدة تحت **Analyze → Dashboards**.
    3. افتح لوحة التحكم، ادخل وضع التحرير، رتب المربعات، واحفظ التخطيط.
    4. عد إلى الاستعلام عندما تحتاج إلى تغيير البيانات أو المرشحات خلف المربع.

    ![لوحة تحكم مكونة من استعلامات محفوظة لحجم الأحداث والأخطاء والكمون واستخدام رموز النموذج.](/images/dashboard/dashboard-fleet.png)
  </Tab>
  <Tab title="CLI">
    عمليات CRUD للوحة التحكم غير معروضة بواسطة سطر الأوامر السحابي الحالي. استخدم سطر الأوامر لبناء والتحقق من الاستعلام المحفوظ، ثم أضفه إلى لوحة تحكم في واجهة المستخدم.

    ```bash
    fp query schema
    fp query create "production error rate" --sql "SELECT ..."
    fp query run <query-id>
    ```
  </Tab>
</Tabs>

تشمل مجموعات لوحات التحكم المفيدة:

- **النماذج:** الحجم والكمون واستخدام الرموز ومعدل الأخطاء ودرجات التقييم.
- **التقييمات:** معدل النجاح واتجاهات الدرجات حسب الوكيل أو البيئة.
- **الأدوات:** حجم الاستدعاءات ومعدل الفشل والمدة والاستدعاءات المتكررة.
- **الخطافات والسياسات:** القرارات والرفض ومعدل مطابقة السياسة.
- **مقاييس سير العمل المخصصة:** النتائج من حقول الأحداث والـ SQL الخاص بك.

ابدأ باستعلام محفوظ، تحقق من نتيجته، ثم أضفه كمربع. حافظ على مرشحات الإنتاج والتطوير صريحة بحيث لا يخفي حركة المرور الاختبارية انحدار.

<Tip>
  أعط كل لوحة تحكم مالكاً وسؤال استجابة، مثل "هل موثوقية checkout-agent أسوأ من الأسبوع الماضي؟"
</Tip>
