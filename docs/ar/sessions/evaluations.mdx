تطبق التقييمات المباشرة أحكامًا متسقة على جلسات الوكيل. استخدمها للإشارات التي يجب قياسها بشكل مستمر بدلاً من التحقيق فيها فقط أثناء التدقيق.

## استعراض جودة التقييم

<Tabs>
  <Tab title="لوحة التحكم">
    1. انتقل إلى **Observe → Evaluations**.
    2. أضف سلسلة واختر الوكيل والبيئة ودرجة التقييم والإحصائية والمنحنى.
    3. أضف سلاسل لمقارنة البيئات أو الوكلاء أو مفاتيح الدرجات.
    4. حدد نتيجة لفتح الجلسات المطابقة أو مشاركة العرض المصفى. استخدم **Observe → Metrics** للكمون والرموز والتكلفة والقيم الأخرى.

    ![لوحة تحكم جودة تعرض درجات التقييم المتوسطة والاتجاهات بمرور الوقت.](/images/dashboard/dashboard-quality.png)

    افتح جلسة من التحليل التفصيلي لفحص التفكير لكل درجة:

    ![عرض تفاصيل الجلسة يعرض درجات التقييم والتفكير بجانب الأثر الكامل.](/images/dashboard/session-detail.png)
  </Tab>
  <Tab title="واجهة سطر الأوامر">
    ```bash
    fp evals --agent-id checkout-agent --aggregate
    fp evals --aggregate --env production --status error
    fp evals --score helpfulness:0.8.. --since 7d
    ```

    أضف `--json` العام قبل `evals` للأتمتة، على سبيل المثال `fp --json evals --aggregate --env production`.
  </Tab>
</Tabs>

يتلقى المقيّم هوية الجلسة والبيئة والطوابع الزمنية والأحداث المرتبة. يمكنه إرجاع مفاتيح درجات رقمية مع تفكير اختياري وملخص. يمكن للمقيّمين طويلي المدى إرجاع وظيفة معلقة والاستعلام عنها لاحقًا.

## أهداف التقييم الجيدة

- إكمال المهمة أو صحتها
- التأسيس على الأرضية وخطر الهلوسة
- اختيار الأداة وكفاءة الأداة
- الامتثال للسياسة أو العملية
- ميزانيات التكلفة والكمون
- التصعيد البشري المطلوب

## من الدرجة إلى الاستجابة

اعرض الدرجات في لوحات التحكم لتتبع الاتجاهات. أنشئ تنبيهات للحدود أو الشروط المركبة. عندما تنخفض درجة ما عبر مجموعة سكانية، قم بإجراء تدقيق للتحقيق في السبب؛ عندما يكون السبب إجراءً قابلاً للتكرار، قم بنشر سياسة.
