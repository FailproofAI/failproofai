تعرض الخطافات وقت تشغيل خطافات دورة حياة الوكيل ومدة استغراقها. قرارات السياسات لها طريقة عرض منفصلة.

<Tabs>
  <Tab title="لوحة التحكم">
    1. انتقل إلى **Observe → Hooks**.
    2. قم بالتصفية حسب البيئة أو اسم الخطاف أو حدث المحفز أو الوكيل أو معرف الجلسة.
    3. استعرض زمن الانتظار والتوزيع الخاص بالخطاف.
    4. حدد نقطة على الرسم البياني أو قطاع خطاف لفتح الأحداث الأساسية.

    ![صفحة الخطافات تعرض زمن الانتظار مجمعاً حسب اسم الخطاف وحدث المحفز.](/images/dashboard/hooks.png)
  </Tab>
  <Tab title="واجهة سطر الأوامر">
    ```bash
    fp list hooks
    fp events --event-type hook_triggered,hook_completed --env production --since 24h
    fp events --search "PreToolUse" --since 24h
    ```
  </Tab>
</Tabs>
