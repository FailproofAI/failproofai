تعرض الخطافات متى يتم تشغيل خطافات دورة حياة الوكيل ومدة استغراقها. قرارات السياسات هي عرض منفصل.

<Tabs>
  <Tab title="لوحة المعلومات">
    1. انتقل إلى **Observe → Hooks**.
    2. قم بالتصفية حسب البيئة واسم الخطاف وحدث المشغّل والوكيل أو معرّف الجلسة.
    3. راجع كمون الخطاف والتوزيع.
    4. حدد نقطة على الرسم البياني أو قطعة خطاف لفتح الأحداث الأساسية.

    ![صفحة الخطافات تظهر الكمون مجمّع حسب اسم الخطاف وحدث المشغّل.](/images/dashboard/hooks.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list hooks
    fp events --event-type hook_triggered,hook_completed --env production --since 24h
    fp events --search "PreToolUse" --since 24h
    ```
  </Tab>
</Tabs>
