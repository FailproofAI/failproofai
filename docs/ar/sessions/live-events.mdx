تساعدك الأحداث المباشرة على تأكيد الأدوات المستخدمة ومراقبة عملية محفوفة بالمخاطر دون انتظار انتهاء الجلسة.

## مراقبة النشاط

<Tabs>
  <Tab title="Dashboard">
    1. انتقل إلى **Observe → Events**.
    2. ابدأ بنافذة زمنية حالية وبدون عوامل تصفية لتأكيد وصول البيانات.
    3. صفّ حسب البيئة أو نوع الحدث أو الوكيل أو الجلسة. استخدم البحث لنص الحمولة الأساسية.
    4. حدد حدثاً لفحص ملخصه والتفاصيل. اتبع رابط جلسته للحصول على التتبع الكامل.

    ![تدفق الأحداث المباشر يعرض حركة المرور من بوابة دردشة Hermes إلى جانب عمليات تشغيل برنامج coding-CLI، مصفاة حسب الوقت والبيئة ونوع الحدث والوكيل والنموذج والسياق والجلسة.](/images/dashboard/events-stream-current.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp events --env production --event-type tool_use,error --limit 100
    fp events --session-id <session-id> --order asc --all
    fp --json events --full --session-id <session-id> --all
    ```

    يستبعد التغذية الافتراضية الحمولات الخام. استخدم `--full` فقط للتحقيق في جلسة محدودة.
  </Tab>
</Tabs>

استخدم تدفق الأحداث للإجابة على ثلاثة أسئلة فورية:

- هل الوكيل المتوقع يُبلغ عن البيئة الصحيحة؟
- هل وصلت استدعاءات النموذج واستدعاءات الأدوات وقرارات السياسة بالترتيب الصحيح؟
- هل توقفت الجلسة عن إحراز تقدم أم بدأت بتكرار إجراء ما؟

تتضمن أنواع الأحداث أحداث دورة حياة الوكيل وطلبات النموذج والاستجابات واستخدام الأدوات والنتائج وتنفيذ الخطاف والانتظار البشري والمقاطعات والأخطاء الصريحة. معرّفات الارتباط توصل الأحداث المقترنة مثل استدعاء الأداة ونتيجتها.

<Tip>
  احتفظ بالعرض المباشر واسعاً أثناء التحقق من تكامل جديد. أضف عوامل تصفية فقط بعد أن ترى الحدث الأول؛ يمكن لعامل تصفية غير صحيح أن يبدو كفشل في البيانات الواردة.
</Tip>

إذا لم تظهر أي أحداث، قم بتشغيل `failproofai config --status`، ثم [استكشف أخطاء البيانات الواردة](/ar/reference/troubleshooting).

الوكلاء الذين لا يعملون في أحد [الأطر](/ar/reference/harnesses) الـ 12 المدعومة يُبلغون عن نفس أنواع الأحداث عبر [Python SDK](/ar/reference/custom-agents)، بما في ذلك أحداث التفاعل البشري (`human_wait`، `human_input`، `human_interrupt`) التي تعتمد عليها وكلاء البوابة والإنتاج.
