المقاييس مخصصة للقيم التي لها وحدات. التقييمات مخصصة للنتائج والأحكام.

<Tabs>
  <Tab title="لوحة المعلومات">
    1. انتقل إلى **Observe → Metrics**.
    2. اختر **add series** واختر وكيلاً وبيئة ومقياساً وإحصائية ومنحنى.
    3. أضف سلاسل لمقارنة الوكلاء أو البيئات؛ الوحدات المختلفة تحصل على محاور منفصلة.
    4. اختر نقطة لفتح التقييمات والجلسات المطابقة، أو اختر **share** لنسخ العرض الدقيق.

    ![صفحة المقاييس التي تقارن سلسلتي تكلفة لكل وحدة إخراج مع عناصر التحكم في الوقت ومحددات التجميع والمنحنيات وإجراء المشاركة.](/images/dashboard/metrics-series.png)
  </Tab>
  <Tab title="CLI">
    لا توجد أوامر مقاييس حجم مخصصة حتى الآن. اكتشف المفاتيح المتاحة وافحص الجلسات أو التقييمات:

    ```bash
    fp list score_filters
    fp --json evals --since 24h
    fp --json sessions --since 24h
    ```

    استخدم `fp query` لتجميع المقاييس المخصصة.
  </Tab>
</Tabs>
