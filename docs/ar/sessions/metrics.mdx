المقاييس مخصصة للقيم التي لها وحدات. التقييمات مخصصة للدرجات والأحكام.

<Tabs>
  <Tab title="لوحة المعلومات">
    1. انتقل إلى **Observe → Metrics**.
    2. حدد **add series** واختر وكيل وبيئة ومقياس وإحصائية ومنحنى.
    3. أضف سلاسل للمقارنة بين الوكلاء أو البيئات؛ تتلقى الوحدات المختلفة محاور منفصلة.
    4. حدد نقطة لفتح التقييمات والجلسات المطابقة، أو حدد **share** لنسخ العرض الدقيق.

    ![صفحة المقاييس التي تقارن سلسلتي تكلفة لكل وحدة إخراج مع عناصر التحكم الزمنية ومحددات التجميع والمنحنيات وإجراء المشاركة.](/images/dashboard/metrics-series.png)
  </Tab>
  <Tab title="واجهة سطر الأوامر">
    لا توجد أوامر مخصصة لمقاييس الحجم حتى الآن. اكتشف المفاتيح المتاحة والفحص الجلسات أو التقييمات:

    ```bash
    fp list score_filters
    fp --json evals --since 24h
    fp --json sessions --since 24h
    ```

    استخدم `fp query` للتجميع المخصص للمقاييس.
  </Tab>
</Tabs>
