استخدم النماذج لمعرفة ما إذا تغيرت الموثوقية أو التكلفة مع نموذج أو وكيل أو بيئة أو نطاق زمني.

<Tabs>
  <Tab title="لوحة المعلومات">
    1. انتقل إلى **Observe → Models**.
    2. عيّن نطاق الوقت، ثم قم بالتصفية حسب البيئة أو النموذج أو الوكيل أو معرّف الجلسة.
    3. راجع زمن الاستجابة واستهلاك الرموز واستخدام نافذة السياق وتوزيع النموذج.
    4. حدد نقطة رسم بياني أو مقطع توزيع لفتح الأحداث المطابقة.

    ![صفحة النماذج تعرض عروض زمن الاستجابة والنسبة المئوية والرمز والتكلفة ونافذة السياق وتوزيع النموذج.](/images/dashboard/models.png)
  </Tab>
  <Tab title="واجهة سطر الأوامر">
    ```bash
    fp list models
    fp events --event-type model_request,model_response --env production --since 24h
    fp --json events --fields ts,agent_id,session_id,event_type,output_tokens,context_fill
    ```

    استخدم استعلام محفوظ للحصول على تجميعات على مستوى النموذج غير المعروضة كأمر واجهة سطر أوامر مخصص.
  </Tab>
</Tabs>
