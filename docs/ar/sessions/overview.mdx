الجلسة هي أفضل نقطة انطلاق عندما يتصرف الوكيل بشكل غير متوقع. فهي تجمع طلبات النموذج والاستجابات واستدعاءات الأدوات والتفاعلات البشرية والأخطاء والتقييمات وقرارات السياسة التي تتعلق بتشغيل واحد.

تابع تشغيل وكيل واحد من هدفه عبر استدعاءات النموذج والأدوات والاستجابة النهائية.

## البحث عن جلسة

<Tabs>
  <Tab title="لوحة المعلومات">
    1. في شريط Cloud الجانبي، انتقل إلى **Observe → Sessions**.
    2. عيّن نافذة زمنية، ثم صفّ حسب البيئة أو الحالة أو الوكيل أو معرّف الجلسة.
    3. أضف نطاقات النقاط أو المقاييس عندما تحتاج إلى قطاع الجودة أو التكلفة أو الرمز المميز أو الكمون.
    4. حدد صفًا لفتح تتبعه. استخدم عنصر النسخ بجانب معرّف الجلسة عند مشاركتها.

    ![قائمة الجلسات تعرض صفًا واحدًا لكل تشغيل مع فلاتر البيئة والوكيل والحالة ونقاط التقييم.](/images/dashboard/sessions-list.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp sessions --env production --since 24h
    fp sessions --status error,timeout --agent-id checkout-agent
    fp --json sessions --session-id <session-id>
    ```

    أضف `--agents` لتوسيع التشغيلات متعددة الوكيلات، أو `--all` للترقيم، أو `--fields` لاختيار أعمدة الإخراج.
  </Tab>
</Tabs>

## ما يمكنك فعله

- ابحث عن تشغيل حسب الوكيل أو البيئة أو الوقت أو النموذج أو نوع الحدث أو حالة الخطأ.
- اتبع التسلسل الدقيق الذي أنتج النتيجة.
- قارن بين التشغيلات الناجحة والفاشلة.
- افتح الأدلة المستخدمة من قبل نتيجة تدقيق أو حادث تنبيه.
- صدّر جلسة عندما تحتاج إلى سجل غير متصل.

## ترتيب تحقيق موثوق به

1. أكّد هدف الجلسة والبيئة.
2. ابحث عن الخطأ الأول أو القرار غير المتوقع—وليس فقط الفشل النهائي.
3. افحص سياق النموذج ومدخلات الأداة مباشرة قبله.
4. تحقق من إعادة المحاولات والكمون والمقاطعات البشرية.
5. راجع نقاط التقييم وقرارات السياسة.
