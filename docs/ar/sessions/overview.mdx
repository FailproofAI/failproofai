الجلسة هي أفضل نقطة انطلاق عندما يتصرف الوكيل بشكل غير متوقع. فهي تجمع طلبات النموذج والاستجابات واستدعاءات الأدوات والتفاعلات البشرية والأخطاء والتقييمات وقرارات السياسة التي تتعلق بتشغيل واحد.

تبدو الجلسات متطابقة بغض النظر عن الأداة التي أنتجتها. تشغيل Claude Code يعيد كتابة مستودع، وكيل Hermes يجيب على عميل في Slack، وخدمة Python مزودة بـ Agents SDK - كل ذلك ينتهي به الحال بنفس تنسيق التتبع، لذا عرض واحد يغطي الأسطول.

تابع تشغيل وكيل واحد من هدفه عبر استدعاءات النموذج والأدوات والاستجابة النهائية.

## البحث عن جلسة

إذا تم الاحتفاظ بالجلسة في التخزين البارد بعد وصولك إلى حد التشغيل، فإن زيادة الحد ضمن نفس نافذة الفواتير تحرر الجلسات المؤهلة الأقدم أولاً. لا تجعل محاولات تسليم الإعادة الجلسة تستهلك الحد مرتين.

<Tabs>
  <Tab title="لوحة التحكم">
    1. في شريط Cloud الجانبي، انتقل إلى **Observe → Sessions**.
    2. عيّن نافذة الوقت، ثم صفّ حسب البيئة أو الحالة أو الوكيل أو معرّف الجلسة.
    3. أضف نطاقات الدرجة أو المقياس عندما تحتاج إلى جزء من الجودة أو التكلفة أو الرموز أو الكمون.
    4. حدد صفاً لفتح تتبعه. استخدم عنصر النسخ بجانب معرّف الجلسة عند مشاركته.

    ![قائمة الجلسات تُظهر صفاً واحداً لكل تشغيل مع مرشحات البيئة والوكيل والحالة ودرجة التقييم.](/images/dashboard/sessions-list.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp sessions --env production --since 24h
    fp sessions --status error,timeout --agent-id checkout-agent
    fp --json sessions --session-id <session-id>
    ```

    أضف `--agents` لتوسيع تشغيلات متعددة الوكلاء، أو `--all` للترقيم، أو `--fields` لاختيار أعمدة الإخراج.
  </Tab>
</Tabs>

## ما يمكنك فعله

- البحث عن التشغيل حسب الوكيل أو البيئة أو الوقت أو النموذج أو نوع الحدث أو حالة الخطأ.
- تتبع التسلسل الدقيق الذي أنتج النتيجة.
- مقارنة التشغيلات الناجحة والفاشلة.
- فتح الأدلة المستخدمة من قبل اكتشاف التدقيق أو حادثة التنبيه.
- تصدير جلسة عندما تحتاج إلى سجل دون اتصال.

## ترتيب تحقيق موثوق

1. تأكد من هدف الجلسة والبيئة.
2. ابحث عن أول خطأ أو قرار غير متوقع - ليس فقط الفشل النهائي.
3. افحص سياق النموذج ومدخلات الأداة مباشرة قبله.
4. تحقق من المحاولات الجديدة والكمون والمقاطعات البشرية.
5. راجع درجات التقييم وقرارات السياسة.
