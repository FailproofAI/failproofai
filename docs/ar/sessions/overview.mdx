الجلسة هي أفضل نقطة انطلاق عندما يتصرف الوكيل بطريقة غير متوقعة. تجمع طلبات النموذج والاستجابات واستدعاءات الأدوات والتفاعلات البشرية والأخطاء والتقييمات وقرارات السياسة التي تنتمي إلى تشغيل واحد.

تبدو الجلسات متطابقة بغض النظر عن الأداة التي أنتجتها. تشغيل Claude Code الذي يعيد كتابة مستودع، ووكيل Hermes الذي يجيب على عميل في Slack، وخدمة Python المزودة بـ Agents SDK، كلها تصل إلى نفس تنسيق التتبع، بحيث يغطي عرض واحد الأسطول بأكمله.

تابع تشغيل وكيل واحد من هدفه عبر استدعاءات النموذج والأدوات والاستجابة النهائية.

## البحث عن جلسة

<Tabs>
  <Tab title="لوحة المعلومات">
    1. في شريط الجانب السحابي، انتقل إلى **Observe → Sessions**.
    2. عيّن نطاق الوقت، ثم صفّي حسب البيئة أو الحالة أو الوكيل أو معرّف الجلسة.
    3. أضف نطاقات الدرجة أو المقياس عندما تحتاج إلى شريحة من الجودة أو التكلفة أو الرمز أو الكمون.
    4. حدد صفًا لفتح تتبعه. استخدم عنصر النسخ بجانب معرّف الجلسة عند مشاركتها.

    ![قائمة الجلسات تعرض صفًا واحدًا لكل تشغيل مع مرشحات البيئة والوكيل والحالة ودرجة التقييم.](/images/dashboard/sessions-list.png)
  </Tab>
  <Tab title="واجهة سطر الأوامر">
    ```bash
    fp sessions --env production --since 24h
    fp sessions --status error,timeout --agent-id checkout-agent
    fp --json sessions --session-id <session-id>
    ```

    أضف `--agents` لتوسيع تشغيلات الوكلاء المتعددين، أو `--all` للتصفح، أو `--fields` لاختيار أعمدة الإخراج.
  </Tab>
</Tabs>

## ما يمكنك القيام به

- ابحث عن تشغيل حسب الوكيل أو البيئة أو الوقت أو النموذج أو نوع الحدث أو حالة الخطأ.
- تتبع التسلسل الدقيق الذي أنتج نتيجة.
- قارن التشغيلات الناجحة والفاشلة.
- افتح الأدلة المستخدمة في البحث عن تدقيق أو حادثة تنبيه.
- صدّر جلسة عندما تحتاج إلى سجل دون اتصال.

## ترتيب تحقيق موثوق به

1. أكّد هدف الجلسة والبيئة.
2. ابحث عن أول خطأ أو قرار غير متوقع—لا فقط الفشل النهائي.
3. افحص سياق النموذج ومدخل الأداة مباشرة قبله.
4. تحقق من إعادة المحاولات والكمون والمقاطعات البشرية.
5. راجع درجات التقييم وقرارات السياسة.
