شرح قرارات السياسة ما فعله الإنفاذ. استخدمها للتحقق من الطرح، وقياس معدل الحظر، والعثور على الأنشطة غير المحمية.

<Tabs>
  <Tab title="لوحة التحكم">
    1. انتقل إلى **Observe → policy** واختر نطاق الوقت وإذا رغبت في ذلك جهازًا واحدًا.
    2. راجع الإجراءات المقيّمة والحظر ومعدل الحظر وقرارات السحابة والإجراءات غير المحمية والنشاط أثناء الإيقاف المؤقت.
    3. صفّ جدول تعيين السياسة وفحص الواجبات المنشورة.
    4. حدّد نقطة في المخطط لفتح القرارات والجلسات الخاصة بها.

    ![صفحة السياسة تعرض مجاميع القرارات وتصفية الآلات ونشاط الإنفاذ بمرور الوقت وجدول تعيين السياسة.](/images/dashboard/policy-observe.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp events --event-type hook_completed --env production --since 24h
    fp events --search "deny" --since 24h
    failproofai config --status
    ```

    استخدم `failproofai` لحالة الإنفاذ المحلية للجهاز و`fp` لتحقيق أحداث السحابة.
  </Tab>
</Tabs>
