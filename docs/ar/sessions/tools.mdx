تعرض صفحة الأدوات ما يستدعيه الوكلاء، وعدد مرات فشل الاستدعاءات، والجلسات التي تتأثر بها.

تأتي أسماء الأدوات من كل جهاز وكيل، لذلك قد تظهر نفس الإمكانية بأسماء مختلفة. على سبيل المثال، قد يظهر استدعاء shell كـ `Bash` أو `exec` أو `Shell` أو `terminal` أو `run_command`. شغّل `fp list tools` قبل بناء مرشح.

<Tabs>
  <Tab title="لوحة المعلومات">
    اذهب إلى **Observe → Tools**. قم بالتصفية حسب البيئة أو الأداة أو الوكيل أو الجلسة.

    ![صفحة الأدوات تعرض زمن الاستجابة وتفاصيل النجاح والفشل وتوزيع استدعاءات الأدوات.](/images/dashboard/tools.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list tools
    fp events --event-type tool_use,tool_result --since 24h
    fp errors --event-type tool_result --since 24h
    fp --json events --full --event-type tool_use,tool_result --session-id <session-id> --all --limit 2000
    ```

    استخدم `--full` عندما تحتاج إلى حقول الحمولة مثل مدة كل استدعاء.
  </Tab>
</Tabs>

استخدم هذه الصفحة للعثور على الأخطاء المتكررة، أو مقارنة التشغيلات الناجحة والفاشلة، أو التأكد من أن الأداة المستهدفة بسياسة ما تُستخدم فعلاً.
