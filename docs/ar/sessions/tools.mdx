تجميع الأدوات استدعاءات الأدوات عبر الجلسات حتى تتمكن من مقارنة زمن الكمون وتوزيع الاستدعاءات.

<Tabs>
  <Tab title="لوحة التحكم">
    1. انتقل إلى **Observe → Tools**.
    2. قم بالتصفية حسب البيئة أو اسم الأداة أو الوكيل أو معرّف الجلسة.
    3. راجع زمن الكمون وتوزيع الأدوات.
    4. حدد نقطة على الرسم البياني أو جزء أداة لفتح الأحداث والجلسات المطابقة.

    ![صفحة الأدوات تعرض زمن الكمون وأعطال النجاح والفشل وتوزيع استدعاءات الأدوات.](/images/dashboard/tools.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list tools
    fp events --event-type tool_use,tool_result --env production --since 24h
    fp --json events --full --session-id <session-id> --all
    ```
  </Tab>
</Tabs>
