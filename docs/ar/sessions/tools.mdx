تجمع الأدوات استدعاءات الأدوات عبر الجلسات حتى تتمكن من مقارنة زمن الاستجابة توزيع الاستدعاءات.

<Tabs>
  <Tab title="لوحة التحكم">
    1. انتقل إلى **Observe → Tools**.
    2. قم بالتصفية حسب البيئة أو اسم الأداة أو الوكيل أو معرّف الجلسة.
    3. راجع زمن الاستجابة وتوزيع الأدوات.
    4. حدد نقطة على الرسم البياني أو قطاع أداة لفتح الأحداث والجلسات المطابقة.

    ![صفحة الأدوات تعرض زمن الاستجابة وتفاصيل النجاح والفشل وتوزيع استدعاءات الأدوات.](/images/dashboard/tools.png)
  </Tab>
  <Tab title="واجهة سطر الأوامر">
    ```bash
    fp list tools
    fp events --event-type tool_use,tool_result --env production --since 24h
    fp --json events --full --session-id <session-id> --all
    ```
  </Tab>
</Tabs>
