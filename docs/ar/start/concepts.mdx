---

| المفهوم | معناه | ما يمكنك تحقيقه |
| --- | --- | --- |
| Session | مهمة أو تشغيل وكيل واحد | إعادة بناء نتيجة فردية |
| Event | إجراء مسجل واحد في جلسة | فحص استدعاء نموذج أو استخدام أداة أو خطأ أو إجراء بشري أو قرار سياسة |
| Trace | عرض الجلسة المرتب والمتداخل | فهم العلاقة السببية بدلاً من قراءة السجلات غير المترابطة |
| Evaluation | درجة أو حكم على جلسة | تتبع الجودة أو الامتثال أو التكلفة أو الكمون بشكل مستمر |
| Audit | مراجعة مجموعة محددة من الجلسات | البحث عن أنماط الفشل بهدف محدد وتكرار منتظم |
| Finding | فشل مدعوم بالأدلة اكتشفه تدقيق | رؤية نمط الفشل والخطورة والجلسات المتأثرة |
| Issue | سجل استجابة دائم | تعيين ومناقشة وحل نتيجة أو حادث تنبيه |
| Alert | قاعدة تكتشف التكرار | إخطار المستجيبين عند عودة حالة معروفة |
| Policy | قاعدة يتم تقييمها أثناء نشاط الوكيل | مراقبة السلوك المحفوف بالمخاطر أو حظره أو إعادة توجيهه |
| Deployment | نشر السياسة الإصدار إلى الأجهزة | التحكم في مكان تشغيل السياسة وإرجاعها بأمان |

## حلقة الموثوقية

ابدأ من الأدلة. تُظهر جلسة ما حدث. يحدد التدقيق ما إذا كان خطأ معزول أم نمط متكرر. تحدد النتيجة نمط الفشل؛ وتتحمل المشكلة مسؤولية الاستجابة. تمنع السياسة نفس السلوك، بينما تخبرك التنبيهات إذا عادت الحالة.

<Warning>
  عملية `failproofai audit` محلية تفحص سجل الوكيل المحلي. تقوم عملية تدقيق Cloud متكررة بمراجعة الجلسات المخزنة في Failproof AI Cloud. وهما عمليات منفصلة بنطاقات وجدولة مختلفة.
</Warning>
