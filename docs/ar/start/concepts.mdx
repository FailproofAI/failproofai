| المفهوم | معناه | ما يمكنك تحقيقه |
| --- | --- | --- |
| Session | مهمة وكيل واحدة أو تشغيل واحد | إعادة بناء نتيجة فردية |
| Event | إجراء مسجل واحد في جلسة | فحص استدعاء نموذج أو استخدام أداة أو خطأ أو إجراء بشري أو قرار سياسة |
| Trace | عرض الجلسة المرتب والمتداخل | فهم السببية بدلاً من قراءة السجلات غير المتصلة |
| Evaluation | درجة أو حكم على جلسة | تتبع الجودة أو الامتثال أو التكلفة أو زمن الاستجابة بشكل مستمر |
| Audit | مراجعة مجموعة جلسات محددة | البحث عن أنماط الفشل بهدف معين وجدول زمني |
| Finding | فشل مدعوم بالأدلة يتم اكتشافه بواسطة تدقيق | اطّلع على نمط الفشل والشدة والجلسات المتأثرة |
| Issue | سجل استجابة دائم | تعيين ومناقشة وحل نتيجة أو حادثة تنبيه |
| Alert | قاعدة تكتشف التكرار | إخطار المستجيبين عند عودة حالة معروفة |
| Policy | قاعدة يتم تقييمها أثناء نشاط الوكيل | مراقبة أو حظر أو إعادة توجيه السلوك المحفوف بالمخاطر |
| Deployment | نشر السياسة المُصدر إلى الأجهزة | التحكم في مكان تشغيل السياسة وإرجاعها بأمان |

## حلقة الموثوقية

ابدأ من الأدلة. تُظهر جلسة ما حدث. يحدد التدقيق ما إذا كان خطأ معزول أم نمط متكرر. تحدد النتيجة نمط الفشل؛ والمشكلة تملك الاستجابة. تمنع السياسة السلوك ذاته، بينما تخبرك التنبيهات إذا عادت الحالة.

<Warning>
  يقوم `failproofai audit` محلي بمسح سجل الوكيل المحلي. يراجع التدقيق المتكرر في السحابة الجلسات المخزنة في Failproof AI Cloud. وهي تمثل سير عمل منفصل بنطاق وجدولة مختلفة.
</Warning>
