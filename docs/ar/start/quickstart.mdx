يوفر هذا البدء السريع إعداد جهاز واحد للإبلاغ عن الجلسات، وتشغيل تدقيق، ونشر سياسة. استخدم المهارة لإعداد Failproof AI، أو اتبع الخطوات اليدوية. تحتاج إلى Node.js 20.9 أو إصدار أحدث.

<Tabs>
  <Tab title="استخدم المهارة">
    <Steps>
      <Step title="تثبيت مهارات Failproof AI">
        ```bash
        npx skills add FailproofAI/skills
        ```
      </Step>
      <Step title="اطلب من وكيلك إعداد كل شيء">
        ```text
        Set up Failproof AI for this project, connect this machine, install the right hooks and policies, and verify that a session arrives.
        ```

        يفحص الوكيل المشروع، ويختار التكامل ذا الصلة، ويقوم بالإعداد، ويتحقق منه. راجع [مستودع مهارات FailproofAI](https://github.com/FailproofAI/skills) للحصول على المهارات الفردية وخيارات التثبيت المتقدمة.
      </Step>
    </Steps>
  </Tab>
  <Tab title="الإعداد اليدوي">
    ## قبل أن تبدأ

1. افتح [لوحة معلومات Failproof AI](https://app.befailproof.ai) وأنشئ حسابًا أو سجّل الدخول باستخدام بريدك الإلكتروني للعمل.
2. انتقل إلى **Administration → Keys** وأنشئ مفتاحًا باستخدام `events:add` و `policies:pull`.
3. انسخ السر لمرة واحدة وخزّنه على الجهاز الهدف:

```bash
export FAILPROOFAI_KEY="<one-time-secret>"
```

    ## التثبيت

<Steps>
  <Step title="تثبيت وربط Failproof AI">
    ```bash
    npm install -g failproofai
    failproofai config --connect https://app.befailproof.ai --token "$FAILPROOFAI_KEY"
    ```

    يتم إرسال نصوص الجلسات بشكل افتراضي. أضف `--no-transcripts` للإبلاغ عن نشاط الخطاف وقرارات السياسة دون محتوى النص.

    إذا كان هذا الجهاز يحتوي بالفعل على سجل وكيل، فاعرض واستيراد آخر سبعة أيام، ثم انتظر انتهاء التسليم. تخطَّ هذه الخطوة على جهاز جديد.

    ```bash
    failproofai backfill --since 7d --dry-run
    failproofai backfill --since 7d
    failproofai flush --wait
    ```

    افتح **Sessions** في Failproof AI وحدد جلسة مستوردة.
  </Step>
  <Step title="تثبيت خطافات وكيل والسياسات">
    يؤدي هذا إلى إرفاق Failproof AI بواجهة سطر أوامر الوكيل الخاص بك وتثبيت السياسات المدمجة. استخدمها لرؤية قرارات السياسة المحلية وجرب الإنفاذ قبل أن يقوم Failproof AI بتدقيق جلساتك وكتابة السياسات للوكلاء الخاصين بك.

    دع المثبِّت يكتشف واجهة سطر أوامر الوكيل الخاص بك، أو سمِّ واحدة بشكل صريح.

    ```bash
    failproofai policies --install --cli claude --scope user
    ```
  </Step>
  <Step title="تدقيق السلوك">
    اتبع [تشغيل فحص الفشل الأول](/ar/start/first-audit). استخدم هدفًا ملموسًا مثل "ابحث عن الجلسات التي أعاد فيها الوكيل محاولة أداة فاشلة دون تغيير نهجه."
  </Step>
  <Step title="منع الفشل">
    اتبع [منع الفشل الأول باستخدام سياسة](/ar/start/first-policy). ابدأ في وضع المراقبة، افحص التطابقات، ثم طبّق النسخة المراجعة.
  </Step>
</Steps>

<Check>
  شغّل `failproofai config --status`. يبلغ الإعداد السليم عن اتصال السحابة وحالة daemon والعملية الموقوفة.
</Check>
  </Tab>
