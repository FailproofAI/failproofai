يوضح هذا البدء السريع كيفية جعل جهاز واحد يبلغ عن الجلسات، وتشغيل عملية تدقيق، ونشر سياسة. استخدم المهارة لإعداد Failproof، أو اتبع الخطوات اليدوية. تحتاج إلى Node.js 20.9 أو إصدار أحدث.

<Tabs>
  <Tab title="استخدام المهارة">
    <Steps>
      <Step title="تثبيت مهارات Failproof AI">
        ```bash
        npx skills add FailproofAI/skills
        ```
      </Step>
      <Step title="اطلب من وكيلك إعداد كل شيء">
        ```text
        Set up Failproof AI for this project, connect this machine, install the right hooks and policies, and verify that a session arrives.
        ```

        يفحص وكيلك المشروع، ويختار التكامل ذي الصلة، ويؤدي الإعداد، ويتحقق منه. اطلع على [مستودع مهارات FailproofAI](https://github.com/FailproofAI/skills) للاطلاع على المهارات الفردية وخيارات التثبيت المتقدمة.
      </Step>
    </Steps>
  </Tab>
  <Tab title="الإعداد اليدوي">
    ## قبل البدء

1. افتح [لوحة تحكم Failproof AI](https://app.befailproof.ai) وأنشئ حسابًا أو سجل الدخول ببريدك الإلكتروني للعمل.
2. انتقل إلى **Administration → Keys** وأنشئ مفتاحًا باستخدام `events:add` و `policies:pull`.
3. انسخ السر لمرة واحدة وخزنه على الجهاز الهدف:

```bash
export FAILPROOFAI_KEY="<one-time-secret>"
```

    ## التثبيت

<Steps>
  <Step title="تثبيت وربط Failproof AI">
    ```bash
    npm install -g failproofai
    failproofai config --connect https://app.befailproof.ai --token "$FAILPROOFAI_KEY"
    ```

    يتم إرسال نسخ الجلسات بشكل افتراضي. أضف `--no-transcripts` للإبلاغ عن نشاط الخطاف وقرارات السياسة دون محتوى النسخة.

    إذا كان لدى هذا الجهاز بالفعل سجل وكيل، فقم بمعاينة واستيراد آخر سبعة أيام، ثم انتظر انتهاء التسليم. تخطَّ هذه الخطوة على جهاز جديد.

    ```bash
    failproofai backfill --since 7d --dry-run
    failproofai backfill --since 7d
    failproofai flush --wait
    ```

    افتح **Sessions** في Failproof AI واختر جلسة مستوردة.
  </Step>
  <Step title="تثبيت خطافات الوكيل والسياسات">
    يربط هذا Failproof AI بـ CLI للوكيل ويثبت السياسات المدمجة. استخدمها لرؤية قرارات السياسة المحلية وتجربة الفرض قبل أن تدقق Failproof AI جلساتك وتكتب سياسات لوكلائك.

    دع المثبت يكتشف CLI للوكيل، أو أسمِ واحدًا بشكل صريح.

    ```bash
    failproofai policies --install --cli claude --scope user
    ```
  </Step>
  <Step title="تدقيق السلوك">
    اتبع [تشغيل أول فحص فشل لديك](/ar/start/first-audit). استخدم هدفًا محددًا مثل "البحث عن الجلسات حيث حاول الوكيل مجددًا أداة فاشلة دون تغيير نهجه."
  </Step>
  <Step title="منع الفشل">
    اتبع [منع الفشل الأول باستخدام سياسة](/ar/start/first-policy). ابدأ في وضع الملاحظة، وفحص المطابقات، ثم فرض النسخة المراجعة.
  </Step>
</Steps>

<Check>
  قم بتشغيل `failproofai config --status`. الإعداد السليم يبلغ عن اتصال السحابة وحالة مراقب العمليات وما إذا كان الفرض موقوفًا.
</Check>
