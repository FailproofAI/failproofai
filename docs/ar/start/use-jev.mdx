يساعد Jev في نقطتين أثناء تشغيل الوكيل: تقييم جلسة مكتملة مقابل إجابات معروفة، أو مراجعة استدعاء أداة في سياق ما طلبته من الوكيل.

<Tabs>
  <Tab title="تقييمات Jev">
    استخدم تقييم Jev عندما يمكن تقييم جلسة مكتملة مقابل سؤال بعدة إجابات معروفة، مثل "هل طلب العميل استرجاع أموال؟ أجب بنعم أو لا." يساعدك في العثور على أنماط عبر الجلسات.

    ## إنشاء تقييم

    في لوحة تحكم Cloud، افتح **analyse → checks → new check** (أو **new evaluation**). صِف سؤال ثابت الإجابة واحد، راجع القاعدة التي تُنشئها، وتحقق من أن **كيفية الفحص** هي **نموذج القرار** — وهذا هو Jev. [اختبره](/ar/evaluations/test) على جلسات حقيقية، ثم فعّله.

    ![نموذج تأليف التقييم المشترك حيث تصِف سؤالاً وتراجع المسودة وتنشرها. تُظهر لقطة الشاشة هذه مسودة رمز؛ استخدم سؤال ثابت الإجابة لـ Jev.](/images/dashboard/eval-authoring-draft.png)

    ## قراءة الدرجات

    بعد انتهاء جلسة جديدة، افتح **analyse → checks → evals** وحدد التقييم، أو استخدم واجهة سطر أوامر Cloud:

    ```bash
    fp evals --since 7d
    fp evals --aggregate --since 7d
    ```

    تقرأ واجهة سطر الأوامر الدرجات؛ ينطوي إنشاء تقييم Jev حالياً على استخدام لوحة التحكم. انظر [تقييمات Jev](/ar/evaluations/jev) لأنواع الأسئلة والأمثلة.
  </Tab>
  <Tab title="سياسات Jev">
    استخدم مراجعة سياسة Jev عندما تحتاج سياسة مطابقة السلاسل النصية إلى سياق طلبك لتحديد ما إذا كان استدعاء أداة آمناً. ابدأ في وضع **observe** حتى تتمكن من فحص إجابات Jev بينما تظل السياسات المثبتة لديك تقرر كل استدعاء.

    تأتي فحوصات Jev من حزمة؛ Failproof AI لا تشحن أياً منها. حتى تقوم بتثبيتها، لا يسأل Jev عن شيء، حتى عند تكوينه:

    ```bash
    failproofai policies add FailproofAI/jev-policies
    ```

    ## إعداد Cloud Jev

    في لوحة تحكم Cloud، افتح **settings → api keys** وتحت **new key**، اختر **a machine running failproofai**. استخدمه مع `failproofai config` كما هو موضح في [البداية السريعة](/ar/start/quickstart). على جهاز بدون تكوين Jev موجود، يفعّل هذا Cloud Jev في وضع observe. تحقق من الاتصال مع:

    ```bash
    failproofai jev status
    failproofai jev test
    ```

    ## استخدم نقطة نهايتك الخاصة

    في لوحة التحكم المحلية، افتح **Settings → Jev**. اختر المزود، الصق رمزه، حدد **observe**، وفعّل Jev.

    ![لوحة إعدادات Jev المحلية مع مزود وحقل رمز ووضع observe محدد.](/images/dashboard/jev-settings.png)

    أو قم بتكوين واختبار نقطة النهاية الخاصة بك من محطة طرفية:

    ```bash
    failproofai jev --url https://api.typesafe.ai/v1 --mode observe --key-stdin < ~/typesafe.key
    failproofai jev test
    ```

    اطلب من وكيل موصول باستخدام أداة قراءة الملفات على `README.md`. أكد أن استدعاء الأداة هذا يظهر في الجلسة، ثم افحصه تحت **Policies → Activity** في لوحة التحكم المحلية. بمجرد أن تبدو نتائج observe صحيحة، تشرح [سياسات Jev](/ar/policies/jev) متى يتم فرضها. للتفاصيل والتكوين الخاص بالمزود، انظر [مرجع التكامل](/ar/reference/jev).
  </Tab>
