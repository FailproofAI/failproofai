يساعد Jev في نقطتين أثناء تشغيل الوكيل: تقييم جلسة منتهية مقابل إجابات معروفة، أو مراجعة استدعاء أداة في سياق ما طلبته من الوكيل.

<Tabs>
  <Tab title="تقييمات Jev">
    استخدم تقييم Jev عندما يمكن تقييم جلسة منتهية مقابل سؤال له عدة إجابات معروفة، مثل "هل طلب العميل استرجاع أمواله؟ أجب بنعم أو لا." يساعدك في العثور على أنماط عبر الجلسات.

    ## إنشاء تقييم

    في لوحة التحكم السحابية، افتح **Analyze → eval authoring → new eval**. أدخل سؤالاً واحداً بإجابة ثابتة، اختر **draft**، وتحقق من أنه اختار درجة مصنف. [اختبره](/ar/evaluations/test) على جلسات حقيقية، ثم انشره.

    ![نموذج تأليف التقييم المشترك حيث تصف سؤالاً، وتراجع المسودة، وتنشرها. تُظهر هذه لقطة الشاشة مسودة كود؛ استخدم سؤالاً بإجابة ثابتة لـ Jev.](/images/dashboard/eval-authoring-draft.png)

    ## قراءة الدرجات

    بعد انتهاء جلسة جديدة، افتح **Observe → Evaluations** أو استخدم واجهة سطر الأوامر السحابية:

    ```bash
    fp evals --since 7d
    fp evals --aggregate --since 7d
    ```

    تقرأ واجهة سطر الأوامر الدرجات؛ إنشاء تقييم Jev حالياً يستخدم لوحة التحكم. انظر [تقييمات Jev](/ar/evaluations/jev) لأنواع الأسئلة والأمثلة.
  </Tab>
  <Tab title="سياسات Jev">
    استخدم مراجعة سياسة Jev عندما تحتاج سياسة المطابقة النصية إلى سياق طلبك لتقرر ما إذا كان استدعاء الأداة آمناً. ابدأ في وضع **observe** حتى تتمكن من فحص إجابات Jev بينما لا تزال سياساتك المثبتة تحدد كل استدعاء.

    تأتي فحوصات Jev من حزمة؛ Failproof AI لا تشحن أياً منها. حتى تقوم بتثبيتها، لا يطرح Jev أسئلة، حتى عند تكوينه:

    ```bash
    failproofai policies add FailproofAI/jev-policies
    ```

    ## إعداد Cloud Jev

    في لوحة التحكم السحابية، افتح **Administration → Keys** وأنشئ مفتاحاً باستخدام إعداد **machine**. استخدمه مع `failproofai config` كما هو موضح في [البدء السريع](/ar/start/quickstart). على جهاز بدون تكوين Jev موجود، هذا يفعّل Cloud Jev في وضع المراقبة. تحقق من الاتصال بـ:

    ```bash
    failproofai jev status
    failproofai jev test
    ```

    ## استخدام نقطة النهاية الخاصة بك

    في لوحة التحكم المحلية، افتح **Settings → Jev**. اختر موفر الخدمة، والصق رمزه المميز، اختر **observe**، وقم بتشغيل Jev.

    ![لوحة إعدادات Jev المحلية مع موفر خدمة، حقل رمز مميز، ووضع المراقبة محدد.](/images/dashboard/jev-settings.png)

    أو قم بتكوين واختبار نقطة النهاية الخاصة بك من محطة طرفية:

    ```bash
    failproofai jev --url https://api.typesafe.ai/v1 --mode observe --key-stdin < ~/typesafe.key
    failproofai jev test
    ```

    اطلب من وكيل معني استخدام أداة قراءة الملفات الخاصة به على `README.md`. تأكد من ظهور استدعاء الأداة هذا في الجلسة، ثم فحصه تحت **Policies → Activity** في لوحة التحكم المحلية. بمجرد أن تبدو نتائج المراقبة صحيحة، [سياسات Jev](/ar/policies/jev) توضح متى يتم الإنفاذ. لتفاصيل موفر الخدمة والتكوين، انظر [مرجع التكامل](/ar/reference/jev).
  </Tab>
</Tabs>
