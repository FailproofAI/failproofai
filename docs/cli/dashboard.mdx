---
title: "failproofai (dashboard)"
description: "Launch the dashboard to browse agent sessions and manage policies"
---

```bash
failproofai
```

Starts the web dashboard at `http://localhost:8020`.

## Options

The dashboard takes no flags — `failproofai` rejects any it does not recognize. The port is
fixed at `8020`.

To point the dashboard at a non-default Claude project folder, set the `CLAUDE_PROJECTS_PATH` environment variable when launching.

## Examples

```bash
# Launch the dashboard on http://localhost:8020
failproofai

# Use a custom Claude projects path via environment variable
CLAUDE_PROJECTS_PATH=~/my-claude-projects failproofai
```
