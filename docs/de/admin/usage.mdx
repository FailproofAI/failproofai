Die Nutzungsübersicht zeigt den Verbrauch der aktuellen Organisation und ihrer Abrechnungsfenster. Verwenden Sie sie, um zu verstehen, wie Produktionsrollout, Transkriptvolumen, Evaluierungen und Audit-Kadenz Ihren Plan beeinflussen.

## Nutzung prüfen

<Tabs>
  <Tab title="Dashboard">
    1. Gehen Sie zu **Administration → Nutzung**.
    2. Bestätigen Sie die Organisation und das Messfenster.
    3. Prüfen Sie Ingest, Sitzungen, Evaluierungen, Metriken, Audits, Befunde, Warnmeldungen, Benutzer und Schlüssel.
    4. Vergleichen Sie gestartete und abgeschlossene Audit-Vorgänge, wenn die Audit-Nutzung unerwartet aussieht.

    ![Die Nutzungsseite zeigt das Messfenster, erfasste Ereignisse, Evaluierungs- und Audit-Pipelines, Workspace-Ressourcen, Mitglieder und API-Schlüssel.](/images/dashboard/usage-overview.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp usage
    fp --json usage
    fp --org reliability-team --json usage
    ```
  </Tab>
</Tabs>

## Eine Änderung untersuchen

1. Bestätigen Sie die aktive Organisation und das aktive Fenster.
2. Vergleichen Sie den Anstieg mit dem Sitzungsvolumen nach Umgebung.
3. Prüfen Sie, ob eine neue Integration begonnen hat, Transkripte zu senden.
4. Überprüfen Sie Änderungen an der Evaluator- und Audit-Kadenz.
5. Vergleichen Sie die Werte mit den Limits des aktuellen Preisplans.

Die CLI gibt dieselbe Zusammenfassung für Skripte zurück.
