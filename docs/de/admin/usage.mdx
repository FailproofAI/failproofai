Nutzung zeigt den Verbrauch für die aktuelle Organisation und ihre Abrechnungsfenster an. Verwenden Sie diese Ansicht, um zu verstehen, wie Produktions-Rollout, Transkriptvolumen, Evaluierungen und Audit-Kadenz Ihren Plan beeinflussen.

## Nutzung prüfen

<Tabs>
  <Tab title="Dashboard">
    1. Gehen Sie zu **Administration → Nutzung**.
    2. Bestätigen Sie die Organisation und das Messfenster.
    3. Überprüfen Sie Ingest, Sitzungen, Evaluierungen, Metriken, Audits, Befunde, Warnmeldungen, Benutzer und Schlüssel.
    4. Vergleichen Sie gestartete und abgeschlossene Audit-Aufgaben, wenn die Audit-Nutzung unerwartet erscheint.

    ![Die Nutzungsseite mit Messfenster, erfassten Ereignissen, Evaluierungs- und Audit-Pipelines, Workspace-Ressourcen, Mitgliedern und API-Schlüsseln.](/images/dashboard/usage-overview.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp usage
    fp --json usage
    fp --org reliability-team --json usage
    ```
  </Tab>
</Tabs>

## Eine Änderung untersuchen

1. Bestätigen Sie die aktive Organisation und das Fenster.
2. Vergleichen Sie den Anstieg mit dem Sitzungsvolumen nach Umgebung.
3. Prüfen Sie, ob eine neue Integration begonnen hat, Transkripte zu senden.
4. Überprüfen Sie Änderungen bei der Evaluator- und Audit-Kadenz.
5. Vergleichen Sie mit den Limits des aktuellen Preisplans.

Das CLI gibt für Skripte dieselbe Zusammenfassung zurück.
