Stellen Sie Ihren Agentendaten eine Frage in einfacher Sprache und erhalten Sie eine Antwort, die direkt auf die Belege verweist. Kein SQL zu schreiben, keine Dashboards zu durchsuchen – der **Failproof AI Observability**-Assistent ist der schnellste Weg für alle in Ihrem Team, um Antworten über Ihre Agenten zu erhalten.

![Der Failproof AI Observability-Assistent beantwortet eine Frage in einfacher Sprache im Dashboard und zeigt eine Live-Agenten-Aktivitätstabelle, eine Aufschlüsselung der Modellnutzung pro Agent sowie schriftliche Erkenntnisse – mit den ausgeführten Abfragen inline angezeigt](/agenteye/images/assistant.png)
*Fragen Sie in einfacher Sprache und erhalten Sie eine Antwort, die aus Ihren eigenen Daten aufgebaut ist. Hier wird aufgeschlüsselt, welche Agenten am beschäftigtsten sind und welche Modelle sie verwenden – und die ausgeführten Abfragen werden angezeigt, damit Sie jede Zahl nachprüfen können.*

Es gibt nichts zu lernen. Öffnen Sie den Chat, tippen Sie ein, was Sie wissen möchten, und folgen Sie den zurückgegebenen Links:

```
You:  which sessions errored today?
AI:   5 sessions errored today, newest first. Each one is linked:
      • checkout-agent   14:02   tool timeout
      • billing-agent    11:47   unhandled error
      • ...and 3 more

You:  summarize this session          (asked while viewing a run)
AI:   This run took 12 steps across 3 tools and failed near the end when a
      payment tool returned an error. It scored low on your "resolved" eval.
      Links: the session, the failing event, and that evaluation.
```

## Einfach fragen und direkt zum Beweis springen

Sie hören auf zu raten und hören auf, Abfragen zu schreiben. Fragen Sie „Wie entwickelt sich die Qualität in der Produktion diese Woche?", „Welche Sitzungen hatten heute Fehler?" oder „Fasse diese Sitzung zusammen" – und Sie erhalten in Sekunden eine direkte Antwort, anstatt selbst eine Abfrage zu erstellen und zu lesen.

Jede Antwort kommt mit ihren Belegen. Der Assistent verlinkt die genauen Sitzungen, gespeicherten Abfragen und Dashboards, die er zur Ableitung der Antwort verwendet hat, sodass Sie durchklicken und bestätigen können, anstatt ihm blind zu vertrauen. Er ist außerdem **seitenabhängig**: Fragen Sie nach „dieser Sitzung", während Sie eine anzeigen, weiß er bereits, welchen Durchlauf Sie meinen. Öffnen Sie jedes frühere Gespräch später über den Verlaufs-Umschalter erneut und machen Sie dort weiter, wo Sie aufgehört haben.

## Eine gute Antwort in eine gespeicherte Abfrage oder ein Dashboard umwandeln

Wenn eine Antwort es wert ist, aufbewahrt zu werden, bitten Sie den Assistenten, sie zu speichern. Er entwirft das SQL für eine gespeicherte Abfrage oder stellt ein Dashboard aus diesen Abfragen zusammen und zeigt Ihnen dann eine **Genehmigen / Ablehnen**-Karte. Nichts wird gespeichert, bis Sie auf „Genehmigen" klicken – so erhalten Sie die Geschwindigkeit des „Einfach fragen" und behalten dabei immer das letzte Wort.

Auf der **Abfragen**-Seite geht er einen Schritt weiter und wird zum SQL-Autor: Beschreiben Sie die gewünschte Abfrage („Zeige Fehlerrate nach Agent für die letzten 7 Tage") und er streamt SQL direkt in den Editor, öffnet eine Diff-Ansicht, damit Sie die Änderung **Akzeptieren** oder **Ablehnen** können, bevor sie übernommen wird.

![Die Observability-Abfrageseite und ihr SQL-Editor](/agenteye/images/query-lab.png)
*Die Abfrageseite: Dieser Editor ist der Ort, wo der Assistent einen schreibgeschützten Entwurf streamt, den Sie akzeptieren oder ablehnen können.*

Das Erstellen von SQL durch Fragen hier verwendet die `queries:run`-Berechtigung, dieselbe, die hinter dem **Ausführen**-Button des Editors steckt. Der Chat überall sonst benötigt `agent:use`.

## Sicher für das gesamte Team

Sie können den Assistenten für alle öffnen, ohne sich Sorgen zu machen, was er möglicherweise berühren könnte:

- **Er liest nur, was Sie bereits sehen können.** Antworten sind auf Ihre eigenen Leseberechtigungen beschränkt, sodass er Ihre Datenfläche nie erweitert.
- **Jeder Schreibvorgang wartet auf Sie.** Gespeicherte Abfragen und Dashboards werden nur nach Ihrem expliziten Klick auf „Genehmigen" erstellt, und es gibt keine Einstellung, die dieses Gate deaktiviert.
- **Er kann niemals etwas löschen.** Es ist kein Lösch-Werkzeug verfügbar und der Assistent hat keine Löschberechtigung. Löschungen bleiben in Ihren Händen, im Dashboard.
- **Er bleibt in Ihrer Organisation.** Der Assistent sieht immer nur die Organisation, die Sie gerade anzeigen.
- **Ihre Fragen bleiben Ihre.** Eingaben und Antworten leben in Ihrer eigenen Observability-Datenbank; die Produktanalyse erfasst nur Nutzungsmetadaten, niemals Ihren Fragentext.

## Wo Sie ihn finden

Der Assistent befindet sich am rechten Rand jeder Seite unter Ihrer Organisation (`/<org-slug>/...`). Klicken Sie auf die Leiste oder drücken Sie `⌘J` / `Ctrl+J`, um sie zum vollständigen Chat-Panel zu erweitern, und ziehen Sie deren Rand zum Anpassen der Größe; Ihre Breite wird über Neuladen hinaus gespeichert. Sie benötigen die **`agent:use`**-Berechtigung, um ihn zu verwenden, andernfalls ist die Leiste ausgegraut. Wenn er für Ihre Bereitstellung noch nicht aktiviert wurde (er benötigt eine LLM-Verbindung), sehen Sie eine gedimmte Leiste anstelle eines funktionierenden Chats.
