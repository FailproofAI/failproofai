Ihr gesamtes Failproof AI Observability-Deployment, einen Befehl entfernt. Überprüfen Sie die Produktion, erstellen Sie einen API-Schlüssel oder bestätigen Sie einen Incident, ohne Ihr Terminal zu verlassen – und automatisieren Sie all das in CI oder lassen Sie einen Coding-Agenten es für Sie in einfachem Englisch erledigen.

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*Die `agenteye`-CLI kommuniziert mit Ihrem Dashboard. Sie ist ein anderes Werkzeug als der Collector, der Events an den Server sendet.*

## Ihr gesamtes Deployment, einen Befehl entfernt

Hören Sie auf, zwischen Tabs zu wechseln, um eine schnelle Frage zu beantworten. Die `agenteye`-CLI liest Ihre Daten und verwaltet Ihre Organisation über eine einzige ausführbare Datei – eine Überprüfung, die früher mehrere Klicks im Dashboard erforderte, wird zur einzeiligen Anweisung, die Sie wiederholen, als Alias anlegen oder in ein Runbook einfügen können. Sie erhalten vier Bereiche:

- **Daten lesen:** `sessions`, `events`, `evals` und `errors`, gefiltert nach Zeit, Agent und Umgebung.
- **Organisation verwalten:** `keys`, `users`, `settings`, `alerts` und `incidents`.
- **Analysen ausführen:** gespeichertes SQL sowie ein Ad-hoc-`query`-Runner über Ihre Event-Daten.
- **Den Assistenten befragen:** `agent ask` erreicht denselben schreibgeschützten Analysten, mit dem Sie im Dashboard chatten.

Installieren Sie es einmalig mit `pipx`, melden Sie sich mit einem per E-Mail zugesandten 6-stelligen Code an, und Sie sind startklar. Die Sitzung dauert etwa einen Tag; führen Sie `agenteye login` erneut aus, wenn sie abläuft. Nutzen Sie die CLI für Stichproben in der Produktion, zum Bereitstellen eines Schlüssels oder zur Triage eines aktiven Incidents – alles ohne einen Browser zu öffnen:

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

Eine wichtige Gewohnheit: Globale Optionen wie `--json` stehen vor dem Befehl. `agenteye --json sessions` ist korrekt; `agenteye sessions --json` ist es nicht.

## Automatisieren und in CI einbinden

Jeder Befehl unterstützt `--json`, und das ändert alles. Sauberes JSON geht an stdout, während menschenlesbare Statusmeldungen und Warnungen an stderr gehen – eine `--json`-Ausgabe lässt sich daher direkt in `jq` pipen, ohne störende Zeilen entfernen zu müssen. Das macht die CLI gleichermaßen geeignet für Sie am Terminal und für einen Coding-Agenten, der die Ausgabe verarbeitet:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

Sie ist für den unbeaufsichtigten Betrieb ausgelegt. Bestätigungsabfragen werden automatisch übersprungen, wenn kein Terminal angeschlossen ist, sodass nichts in einer Pipeline hängenbleibt. Jeder Befehl gibt einen aussagekräftigen Exit-Code zurück: `0` Erfolg, `4` nicht angemeldet, `5` fehlende Berechtigung (die Meldung nennt sie, z. B. `alerts:write`), `3` Dashboard nicht erreichbar. Ein Skript kann bei `4` zur erneuten Authentifizierung verzweigen oder bei `5` genau anzeigen, was Sie beim Administrator anfragen müssen, anstatt blind zu scheitern.

## Einen Coding-Agenten im Klartext steuern lassen

Noch besser: Sie müssen sich diese Flags gar nicht merken. Der **CLI-Skill** ist ein kleiner Agent-Skill-Ordner namens `agenteye-cli`, der einen Coding-Agenten wie Claude Code oder Codex beibringt, die CLI auf Basis von Anfragen in einfachem Englisch zu bedienen. Fragen Sie „Ist heute irgendetwas kaputt?" – der Agent wählt den passenden Befehl, führt ihn in Ihrem Namen aus und antwortet in Prosa.

Für Claude Code legen Sie den `agenteye-cli`-Ordner in `~/.claude/skills/` ab, und er wird automatisch erkannt. Failproof AI Observability stellt den Ordner bereit; es gibt nichts Zusätzliches zu installieren, da der Skill nur die bereits installierte CLI verwendet. Melden Sie sich zuerst selbst an: Der Skill kann den per E-Mail zugesandten Code-Login nicht für Sie abschließen.

Da der Agent die CLI als Sie ausführt, kann er alles tun, was Ihre Anmeldung erlaubt – sowohl Lese- als auch Schreibvorgänge: Schlüssel erstellen, Einstellungen ändern, Incidents auflösen. Die „Sind Sie sicher?"-Abfrage der CLI wird für einen Agenten nicht ausgelöst, daher ist der Skill so konzipiert, dass er den genauen Befehl angibt und vor jeder Änderung auf Ihre Zustimmung wartet. Sie sind der Bestätigungsschritt.

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

Lesevorgänge sind sofort, und jeder Schreibvorgang wartet auf Sie:

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
