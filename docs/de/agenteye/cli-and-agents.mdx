Ihr gesamtes Failproof AI Observability-Deployment, einen Befehl entfernt. Prüfen Sie die Produktion, erstellen Sie einen API-Schlüssel oder bestätigen Sie einen Incident, ohne Ihr Terminal zu verlassen – und skripten Sie das alles in CI oder lassen Sie einen Coding-Agenten es in einfachem Englisch für Sie erledigen.

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*Die `agenteye` CLI kommuniziert mit Ihrem Dashboard. Sie ist ein anderes Werkzeug als der Collector, der Events an den Server sendet.*

## Ihr gesamtes Deployment, einen Befehl entfernt

Hören Sie auf, zwischen Tabs zu wechseln, nur um eine schnelle Frage zu beantworten. Die `agenteye` CLI liest Ihre Daten und verwaltet Ihre Organisation über eine einzige Binary, sodass eine Prüfung, die früher ein Durchklicken des Dashboards bedeutete, zu einer einzigen Zeile wird – wiederverwendbar, als Alias speicherbar oder in ein Runbook einfügbar. Sie haben vier Bereiche:

- **Daten lesen:** `sessions`, `events`, `evals` und `errors`, gefiltert nach Zeit, Agent und Umgebung.
- **Organisation verwalten:** `keys`, `users`, `settings`, `alerts` und `incidents`.
- **Analysen ausführen:** gespeichertes SQL sowie ein Ad-hoc-`query`-Runner über Ihre Event-Daten.
- **Den Assistenten befragen:** `agent ask` greift auf denselben schreibgeschützten Analysten zu, mit dem Sie im Dashboard chatten.

Installieren Sie es einmal mit `pipx`, melden Sie sich mit einem per E-Mail zugesandten 6-stelligen Code an, und Sie sind startklar. Die Sitzung dauert etwa einen Tag; führen Sie `agenteye login` erneut aus, wenn sie abläuft. Nutzen Sie es für schnelle Produktionsprüfungen, die Bereitstellung eines Schlüssels oder die Triage eines aktiven Incidents – alles ohne Browser:

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

Eine wichtige Konvention: Globale Optionen wie `--json` kommen vor dem Befehl. `agenteye --json sessions` ist korrekt; `agenteye sessions --json` ist es nicht.

## Als Skript oder in CI einbinden

Jeder Befehl unterstützt `--json`, und das verändert alles. Sauberes JSON geht nach stdout, während Status- und Warnmeldungen für Menschen nach stderr gehen – eine `--json`-Ausgabe lässt sich also direkt in `jq` pipen, ohne störende Zeilen entfernen zu müssen. Das macht die CLI gleichermaßen nützlich für Sie an der Eingabeaufforderung und für einen Coding-Agenten, der die Ausgabe parst:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

Sie ist für den unbeaufsichtigten Betrieb konzipiert. Bestätigungsaufforderungen werden automatisch übersprungen, wenn kein Terminal angebunden ist, sodass nichts in einer Pipeline hängen bleibt. Jeder Befehl gibt einen aussagekräftigen Exit-Code zurück: `0` Erfolg, `4` nicht eingeloggt, `5` fehlende Berechtigung (die Meldung nennt sie, z. B. `alerts:write`), `3` Dashboard nicht erreichbar. Ein Skript kann bei `4` zur erneuten Authentifizierung verzweigen oder bei `5` genau anzeigen, was bei einem Admin angefragt werden muss – statt blind zu scheitern.

## Einen Coding-Agenten in einfachem Englisch steuern lassen

Noch besser: Sie müssen sich diese Flags gar nicht merken. Der **CLI-Skill** ist ein kleiner Agent-Skill-Ordner namens `agenteye-cli`, der einen Coding-Agenten wie Claude Code oder Codex beibringt, die CLI auf Basis von Anfragen in natürlicher Sprache zu bedienen. Fragen Sie „ist heute irgendetwas kaputt?" und der Agent wählt den passenden Befehl, führt ihn als Sie aus und antwortet in Prosaform.

Für Claude Code legen Sie den Ordner `agenteye-cli` in `~/.claude/skills/` ab – er wird automatisch erkannt. Failproof AI Observability stellt den Ordner bereit; es muss nichts zusätzlich installiert werden, da er nur die bereits installierte CLI steuert. Melden Sie sich zuerst selbst an: Der Skill kann den per E-Mail übermittelten Code-Login nicht für Sie abschließen.

Da der Agent die CLI als Sie ausführt, kann er alles tun, was Ihr Login erlaubt – lesend und schreibend: Schlüssel erstellen, Einstellungen ändern, Incidents auflösen. Die „Sind Sie sicher?"-Abfrage der CLI greift für einen Agenten nicht, daher ist der Skill so gestaltet, dass er den genauen Befehl nennt und Ihre Bestätigung abwartet, bevor er eine Änderung vornimmt. Sie sind der Bestätigungsschritt.

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

Leseoperationen bleiben sofort, und jeder Schreibvorgang wartet auf Sie:

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
