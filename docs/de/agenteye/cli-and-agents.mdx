Ihr gesamtes Failproof AI Observability-Deployment, einen Befehl entfernt. Produktionsstatus prüfen, einen API-Schlüssel erstellen oder einen Incident bestätigen – alles ohne das Terminal zu verlassen. Dann skripten Sie es in CI, oder lassen Sie einen Coding-Agenten es für Sie auf Deutsch erledigen.

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*Das `agenteye`-CLI kommuniziert mit Ihrem Dashboard. Es ist ein anderes Tool als der Collector, der Events an den Server sendet.*

## Ihr gesamtes Deployment, einen Befehl entfernt

Hören Sie auf, zwischen Tabs zu wechseln, um eine schnelle Frage zu beantworten. Das `agenteye`-CLI liest Ihre Daten und verwaltet Ihre Organisation über eine einzige Binary – was früher bedeutete, durch das Dashboard zu klicken, wird zu einer Zeile, die Sie wiederverwenden, als Alias anlegen oder in ein Runbook einfügen können. Sie erhalten vier Bereiche:

- **Daten lesen:** `sessions`, `events`, `evals` und `errors`, gefiltert nach Zeit, Agent und Umgebung.
- **Organisation verwalten:** `keys`, `users`, `settings`, `alerts` und `incidents`.
- **Analysen ausführen:** gespeichertes SQL sowie ein ad-hoc `query`-Runner für Ihre Event-Daten.
- **Den Assistenten befragen:** `agent ask` erreicht denselben schreibgeschützten Analysten, mit dem Sie im Dashboard chatten.

Installieren Sie es einmalig mit `pipx`, melden Sie sich mit einem per E-Mail zugesandten 6-stelligen Code an, und Sie sind bereit. Die Sitzung hält etwa einen Tag; führen Sie `agenteye login` erneut aus, wenn sie abläuft. Nutzen Sie es, um Produktionszustände zu prüfen, Schlüssel bereitzustellen oder einen aktiven Incident zu triagieren – alles ohne einen Browser zu öffnen:

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

Eine wichtige Gewohnheit: Globale Optionen wie `--json` kommen vor dem Befehl. `agenteye --json sessions` ist korrekt; `agenteye sessions --json` ist es nicht.

## Skripten Sie es, integrieren Sie es in CI

Jeder Befehl unterstützt `--json`, und das verändert alles. Sauberes JSON geht an stdout, während menschenlesbare Statusmeldungen und Warnungen an stderr gehen – ein `--json`-Capture lässt sich also direkt in `jq` pipen, ohne dass eine störende Zeile entfernt werden müsste. Genau das macht das CLI gleichermaßen geeignet für Sie an der Eingabeaufforderung und für einen Coding-Agenten, der die Ausgabe parst:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

Es ist für den unbeaufsichtigten Betrieb ausgelegt. Bestätigungsaufforderungen werden automatisch übersprungen, wenn kein Terminal angeschlossen ist, sodass nichts in einer Pipeline hängt. Jeder Befehl gibt einen aussagekräftigen Exit-Code zurück: `0` Erfolg, `4` nicht eingeloggt, `5` fehlende Berechtigung (die Meldung nennt sie, z. B. `alerts:write`), `3` Dashboard nicht erreichbar. Ein Skript kann bei `4` eine erneute Authentifizierung anstoßen oder bei `5` genau angeben, was Sie einen Administrator anfragen müssen, anstatt blind zu scheitern.

## Lassen Sie einen Coding-Agenten es auf Deutsch steuern

Noch besser: Sie sollten sich überhaupt keine dieser Flags merken müssen. Der **CLI-Skill** ist ein kleiner Agent-Skill-Ordner namens `agenteye-cli`, der einem Coding-Agenten wie Claude Code oder Codex beibringt, das CLI über Anfragen in natürlicher Sprache zu steuern. Fragen Sie „Ist heute irgendetwas kaputt?" und der Agent wählt den Befehl, führt ihn als Sie aus und antwortet in Prosaform.

Für Claude Code legen Sie den Ordner `agenteye-cli` in `~/.claude/skills/` ab – er wird automatisch erkannt. Failproof AI Observability stellt den Ordner bereit; es gibt nichts Zusätzliches zu installieren, da er nur das CLI antreibt, das Sie bereits installiert haben. Loggen Sie sich zuerst selbst ein: Der Skill kann den per E-Mail versandten Code-Login nicht für Sie abschließen.

Da der Agent das CLI als Sie ausführt, kann er alles tun, was Ihr Login erlaubt – Lesen und Schreiben gleichermaßen: Schlüssel erstellen, Einstellungen ändern, Incidents auflösen. Die „Sind Sie sicher?"-Aufforderung des CLI wird für einen Agenten nicht ausgelöst, daher ist der Skill so geschrieben, dass er den genauen Befehl angibt und auf Ihre Zustimmung wartet, bevor eine Änderung vorgenommen wird. Sie sind der Bestätigungsschritt.

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

Lesevorgänge bleiben sofort, und jeder Schreibvorgang wartet auf Sie:

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
