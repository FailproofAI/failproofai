---

Ihre Entwickler führen OpenAI Codex bereits täglich aus. Die Codex-Sitzungsaufzeichnung überträgt diese Codiersitzungen als gewöhnliche Sitzungen und Ereignisse in AgentEye, sodass Sie sie gemeinsam mit allem anderen, was Sie beobachten, durchsuchen, wiedergeben und auswerten können. Sie ergänzt das [Python SDK](/de/agenteye/python-sdk): Das SDK instrumentiert Agents, die Sie selbst schreiben, während diese Funktion die Codex-Arbeit Ihres Teams erfasst – ohne jede Änderung an deren Arbeitsweise.

Ein kleiner Hintergrundsammler liest Codex' lokale Sitzungstranskripte, während sie geschrieben werden, und überträgt sie an AgentEye. Ein Sammler pro Maschine erfasst gleichzeitig alle lokalen Codex-Oberflächen – es ist keine separate Einrichtung pro Oberfläche erforderlich.

---

## Was aufgezeichnet wird

Jede Codex-Oberfläche, die **lokal** ausgeführt wird, erzeugt dieselben Sitzungstranskripte auf der Festplatte, und der Sammler verarbeitet sie alle:

- die Codex-**CLI** und `codex exec`
- die **VS Code / IDE-Erweiterung**
- die **Desktop-App**, wenn sie eine Sitzung lokal ausführt

Jede Codex-Sitzung wird zu einer AgentEye-[Sitzung](/de/agenteye/sessions); ihre Benutzer- und Assistentennachrichten, Überlegungen, Tool-Aufrufe, Tool-Ergebnisse und Token-Nutzung werden zu den entsprechenden [Ereignissen](/de/agenteye/event-stream). Die Oberfläche, von der jede Sitzung stammt (CLI, IDE oder Desktop), wird aufgezeichnet, damit Sie sie unterscheiden können.

> **Cloud-Sitzungen werden nicht aufgezeichnet.** Die Desktop-App führt Sitzungen zunehmend in der Codex-Cloud aus und speichert auf dem Gerät nur deren Metadaten – es gibt kein lokales Transkript zum Lesen. Nur lokal ausgeführte Sitzungen werden aufgezeichnet.

---

## Aktivierung

Die Aufzeichnung ist deaktiviert, bis Sie sie einschalten. Installieren Sie den Sammler mit einem API-Schlüssel, der die Berechtigung `events:add` besitzt (siehe [API-Schlüssel](/de/agenteye/api-keys)), und aktivieren Sie die Codex-Aufzeichnung:

```bash
curl -fsSL https://raw.githubusercontent.com/FailproofAI/agenteye-collector/main/install.sh \
  | sh -s -- --key <YOUR_API_KEY> --codex-enabled
```

Dadurch wird der Sammler installiert, als Hintergrunddienst registriert und die Aufzeichnung gestartet. Überprüfen Sie, ob er läuft:

```bash
agenteye-collector health
```

Beim ersten Start werden Ihre vorhandenen Codex-Sitzungen einmalig nachgefüllt, danach wird neue Aktivität innerhalb von Sekunden gestreamt. Codex' eigene Dateien werden ausschließlich gelesen – niemals verändert, verschoben oder gelöscht – und jede Sitzung wird genau einmal übertragen, auch über Neustarts hinweg.

---

## Wo die Daten erscheinen

Aufgezeichnete Sitzungen erscheinen unter **Sitzungen** und ihre Ereignisse im **Ereignis**-Stream, genauso wie jeder andere beobachtete Agent – daher funktionieren [Sitzungswiedergabe](/de/agenteye/sessions), [Suche](/de/agenteye/queries), [Auswertungen](/de/agenteye/evaluations) und [Benachrichtigungen](/de/agenteye/alerts) für sie genauso. Filtern Sie nach dem Codex-Agent, um sie einzeln anzuzeigen.

---

## Datenschutz

Codex-Transkripte enthalten die vollständige Sitzung – einschließlich Befehlsausgaben, Dateiinhalten und allem, was Codex gelesen oder geschrieben hat – und können Geheimnisse enthalten. Aufgezeichnete Sitzungen werden unverändert übertragen. Aktivieren Sie die Aufzeichnung daher nur auf Maschinen und für Teams, bei denen die Zentralisierung dieser Inhalte in AgentEye angemessen ist, und versehen Sie den Sammler mit einem Schlüssel, der ausschließlich auf `events:add` beschränkt ist. Unter [Sicherheit](/de/agenteye/security) erfahren Sie, wie Ihre Daten isoliert aufbewahrt werden.
