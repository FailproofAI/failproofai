Ihre Entwickler arbeiten bereits täglich mit OpenAI Codex. Die Codex-Sitzungserfassung überträgt diese Coding-Sitzungen als gewöhnliche Sitzungen und Ereignisse in AgentEye, sodass Sie sie durchsuchen, wiedergeben und neben allem anderen, was Sie beobachten, auswerten können. Sie ergänzt das [Python SDK](/de/agenteye/python-sdk): Das SDK instrumentiert Agents, die Sie selbst schreiben, während diese Funktion die Codex-Arbeit Ihres Teams erfasst — ohne Änderungen an deren Arbeitsweise.

Ein kleiner Hintergrund-Collector liest Codex' lokale Sitzungsprotokolle, während sie geschrieben werden, und überträgt sie an AgentEye. Ein Collector pro Maschine erfasst gleichzeitig jede lokale Codex-Oberfläche — es ist keine Einrichtung pro Oberfläche erforderlich.

Derselbe Collector erfasst auch andere Agents — siehe [OpenClaw](/de/agenteye/openclaw-capture) und [Hermes](/de/agenteye/hermes-capture). Aktivieren Sie jeden, den Sie verwenden; ein einzelner Collector kann mehrere gleichzeitig erfassen.

---

## Was erfasst wird

Jede Codex-Oberfläche, die **lokal** ausgeführt wird, erzeugt dieselben lokalen Sitzungsprotokolle auf der Festplatte, und der Collector liest sie alle:

- die Codex **CLI** und `codex exec`
- die **VS Code / IDE-Erweiterung**
- die **Desktop-App**, wenn sie eine Sitzung lokal ausführt

Jede Codex-Sitzung wird zu einer AgentEye-[Sitzung](/de/agenteye/sessions); ihre Benutzer- und Assistentennachrichten, Überlegungen, Tool-Aufrufe, Tool-Ergebnisse und Token-Nutzung werden zu den entsprechenden [Ereignissen](/de/agenteye/event-stream). Die Oberfläche, von der jede Sitzung stammt (CLI, IDE oder Desktop), wird aufgezeichnet, damit Sie sie unterscheiden können.

> **Cloud-Sitzungen werden nicht erfasst.** Die Desktop-App führt Sitzungen zunehmend in der Codex-Cloud aus und speichert nur deren Metadaten lokal — es gibt kein lokales Protokoll zum Lesen. Nur lokal ausgeführte Sitzungen werden erfasst.

## Aktivierung

Die Erfassung ist deaktiviert, bis Sie sie einschalten. Installieren Sie den Collector mit einem API-Schlüssel, der die Berechtigung `events:add` besitzt (siehe [API-Schlüssel](/de/agenteye/api-keys)), und aktivieren Sie die Codex-Erfassung:

```bash
curl -fsSL https://raw.githubusercontent.com/FailproofAI/agenteye-collector/main/install.sh \
  | sh -s -- --key <YOUR_API_KEY> --codex-enabled
```

Dadurch wird der Collector installiert, als Hintergrunddienst registriert und die Erfassung gestartet. Überprüfen Sie, ob er läuft:

```bash
agenteye-collector health
```

Beim ersten Start werden Ihre vorhandenen Codex-Sitzungen einmalig nachgefüllt, und neue Aktivitäten werden anschließend innerhalb von Sekunden übertragen. Codex' eigene Dateien werden ausschließlich gelesen — niemals verändert, verschoben oder gelöscht — und jede Sitzung wird genau einmal übertragen, auch nach Neustarts.

---

## Wo sie erscheinen

Erfasste Sitzungen erscheinen unter **Sitzungen** und ihre Ereignisse im **Ereignisse**-Stream, genau wie jeder andere Agent, den Sie beobachten — sodass [Sitzungswiedergabe](/de/agenteye/sessions), [Suche](/de/agenteye/queries), [Auswertungen](/de/agenteye/evaluations) und [Benachrichtigungen](/de/agenteye/alerts) alle darauf angewendet werden können. Filtern Sie nach dem Codex-Agent, um nur diese anzuzeigen.

---

## Datenschutz

Codex-Protokolle enthalten die vollständige Sitzung — einschließlich Befehlsausgaben, Dateiinhalten und allem, was Codex gelesen oder geschrieben hat — und können Geheimnisse enthalten. Erfasste Sitzungen werden unverändert übertragen. Aktivieren Sie die Erfassung daher nur auf Maschinen und für Teams, bei denen die Zentralisierung dieser Inhalte in AgentEye angemessen ist, und geben Sie dem Collector einen Schlüssel, der ausschließlich auf `events:add` beschränkt ist. Weitere Informationen zur Isolation Ihrer Daten finden Sie unter [Sicherheit](/de/agenteye/security).
