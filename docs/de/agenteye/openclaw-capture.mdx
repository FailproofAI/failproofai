Wenn Ihr Team [OpenClaw](https://docs.openclaw.ai) nutzt, bringt die OpenClaw-Sitzungserfassung diese Sitzungen als gewöhnliche Sitzungen und Ereignisse in AgentEye ein — so können Sie sie durchsuchen, wiedergeben und neben allem anderen auswerten, was Sie beobachten. Sie ergänzt das [Python SDK](/de/agenteye/python-sdk): Das SDK instrumentiert Agenten, die Sie selbst schreiben, während diese Funktion die OpenClaw-Arbeit erfasst, die Ihr Team bereits erledigt — ohne Änderungen an der Art, wie es ausgeführt wird.

Ein kleiner Hintergrundkollektor liest die lokalen Sitzungsprotokolle von OpenClaw, während sie geschrieben werden, und sendet sie an AgentEye. Er funktioniert genauso wie die [Codex-Erfassung](/de/agenteye/codex-capture), und ein einziger Kollektor kann beide gleichzeitig erfassen.

---

## Was erfasst wird

Jeder Agent, der in der OpenClaw-Konfiguration eines Rechners eingerichtet ist, wird vom Kollektor dieses Rechners erfasst — es ist keine agentenspezifische Einrichtung erforderlich.

Jede OpenClaw-Sitzung wird zu einer AgentEye-[Sitzung](/de/agenteye/sessions); ihre Benutzer- und Assistenznachrichten, Tool-Aufrufe und Tool-Ergebnisse werden zu den entsprechenden [Ereignissen](/de/agenteye/event-stream).

---

## Aktivierung

Die Erfassung ist deaktiviert, bis Sie sie einschalten. Installieren Sie den Kollektor mit einem API-Schlüssel, der die Berechtigung `events:add` besitzt (siehe [API-Schlüssel](/de/agenteye/api-keys)), und aktivieren Sie die OpenClaw-Erfassung:

```bash
curl -fsSL https://raw.githubusercontent.com/FailproofAI/agenteye-collector/main/install.sh \
  | sh -s -- --key <YOUR_API_KEY> --openclaw-enabled
```

Damit wird der Kollektor installiert, als Hintergrunddienst registriert und die Erfassung gestartet. Überprüfen Sie, ob er läuft:

```bash
agenteye-collector health
```

Sollen mehrere Agenten auf demselben Rechner erfasst werden? Fügen Sie die jeweiligen Flags demselben Befehl hinzu — zum Beispiel `--openclaw-enabled --codex-enabled`.

Beim ersten Start werden Ihre vorhandenen OpenClaw-Sitzungen einmalig rückwirkend importiert, danach wird neue Aktivität innerhalb von Sekunden übertragen. Die eigenen Dateien von OpenClaw werden ausschließlich gelesen — niemals geändert, verschoben oder gelöscht — und jede Sitzung wird genau einmal gesendet, auch nach Neustarts.

---

## Wo die Daten erscheinen

Erfasste Sitzungen erscheinen unter **Sessions** und ihre Ereignisse im **Events**-Stream — genauso wie bei jedem anderen beobachteten Agenten. Damit stehen [Sitzungswiedergabe](/de/agenteye/sessions), [Suche](/de/agenteye/queries), [Auswertungen](/de/agenteye/evaluations) und [Benachrichtigungen](/de/agenteye/alerts) vollständig zur Verfügung. Filtern Sie nach dem OpenClaw-Agenten, um nur dessen Sitzungen anzuzeigen.

---

## Datenschutz

OpenClaw-Protokolle enthalten die vollständige Sitzung — einschließlich Befehlsausgaben, Dateiinhalten und allem, was der Agent gelesen oder geschrieben hat — und können vertrauliche Daten enthalten. Erfasste Sitzungen werden unverändert übertragen. Aktivieren Sie die Erfassung daher nur auf Rechnern und für Teams, bei denen die Zentralisierung dieser Inhalte in AgentEye angemessen ist, und erteilen Sie dem Kollektor ausschließlich einen auf `events:add` beschränkten Schlüssel. Unter [Security](/de/agenteye/security) erfahren Sie, wie Ihre Daten isoliert aufbewahrt werden.
