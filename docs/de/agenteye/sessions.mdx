## Alle Runs auf einen Blick

Der rohe Ereignisverlauf ist die Wahrheit hinter jedem Schritt – doch wenn Sie Tausende von Schritten über Dutzende von Runs hinweg haben, benötigen Sie den Run als Ganzes und nicht den einzelnen Schritt. Die Sessions-Seite fasst alle Ereignisse eines Runs in einer einzigen Zeile zusammen, sodass aus einem Tag voller Aktivität eine übersichtliche Liste statt eines unkontrollierbaren Datenstroms wird.

Jede Zeile trägt ein Status-Pill, sodass ein fehlgeschlagener Run bereits vor dem ersten Klick von einem erfolgreichen zu unterscheiden ist. Filtern Sie nach Datumsbereich, Umgebung, Agent oder Session, um mit wenigen Klicks von „alles" zu „genau der Run, der mich interessiert" zu gelangen.

Sobald Sie einen Evaluator verbinden, wird jeder abgeschlossene Run automatisch bewertet und sein aktuellster Score erscheint als Badge in der Zeile. Sie können nach beliebigen Score-Bereichen filtern – „zeig mir alle schlecht bewerteten Prod-Runs dieser Woche" ist ein Filter, keine manuelle Durchsicht. Bis Sie einen Evaluator einrichten, werden Sessions weiterhin vollständig erfasst; sie erhalten lediglich noch keinen Score.

## Den gesamten Run als Bild erfassen

![Der Git-artige Ausführungsgraph einer Session neben ihrer Ereigniszeitachse, mit dem Aufschlüsselungs-Panel für Tools, Modelle und Hooks](/agenteye/images/session-detail.png)

*Der Ausführungsgraph (links) liegt neben der Ereigniszeitachse; die rechte Spalte schlüsselt die Tools, Modelle, Hooks und den Token-Verbrauch des Runs auf.*

Klicken Sie auf eine beliebige Session, um ihren Ausführungsgraphen zu öffnen: eine Git-artige Ansicht, die zeigt, wie Agents, Tools, Hooks und Modellaufrufe sich über die Zeit entfaltet haben. Parallele Sub-Agents verzweigen sich jeweils in ihre eigene Spur, sodass Sie sehen können, welche Arbeiten parallel liefen, welcher Sub-Agent ins Stocken geraten ist und wo der Run vom Kurs abgekommen ist – ohne ihn gedanklich aus einem Wall of Logs rekonstruieren zu müssen.

Die rechte Spalte liefert die Aufschlüsselung pro Run: welche Tools und Modelle ausgeführt wurden, welche Hooks gefeuert haben und wie viele Tokens der Run verbraucht hat. Das ist die Antwort auf „Warum hat dieser Run so viel gekostet?" oder „Welches Tool ist das langsame?" – direkt neben dem Graph, der dafür verantwortlich ist.

## Wo Sie es finden

Jede Dashboard-Seite ist auf Ihre Organisation beschränkt (`/<org-slug>/…`). Sessions befindet sich unter **Observe** in der linken Seitenleiste, neben Events, mit den Filtern für Datumsbereich, Umgebung, Agent und Session oberhalb der Liste. Jede Zeile ist einen Klick vom vollständigen Ausführungsgraphen entfernt.

Um die Score-Badges und die Score-Bereichsfilterung zu aktivieren, verbinden Sie einen Evaluator: siehe [Evaluations](/de/agenteye/evaluations).
