Verwende ein lokales Audit für eine sofortige, private Überprüfung, bevor du einen Rechner mit Failproof AI Cloud verbindest. Es scannt die bereits auf deinem Rechner gespeicherten Agentverläufe, verarbeitet die Tool-Aktivitäten durch die integrierten Richtlinien und öffnet ein lokales Ergebnis-Dashboard.

## Interaktives Audit ausführen

<Tabs>
  <Tab title="Dashboard">
    Das lokale Audit startet über die CLI, da es die Verläufe auf dem aktuellen Rechner erkennen muss. Führe `failproofai audit` aus; nach dem Scan startet Failproof AI das integrierte Dashboard und öffnet **http://localhost:8020/audit**.

    Überprüfe in der Audit-Ansicht die Anzahl der Sitzungen, Tool-Aufrufe, Projekte und Richtlinientreffer. Beginne mit häufigen Befunden, und untersuche anschließend das betroffene Projekt und den Agentverlauf, bevor du die Durchsetzung aktivierst.

    <Info>Das lokale Audit-Dashboard ist von **Analyze → Audits** in Failproof AI Cloud getrennt. Lokale Audits verbleiben auf dem Rechner und erfordern kein Konto oder keine Netzwerkverbindung.</Info>
  </Tab>
  <Tab title="CLI">
    ```bash
    npm install -g failproofai
    failproofai audit
    ```

    Der Befehl führt einen vollständigen Scan aller unterstützten Verläufe durch, die er findet. Der aktuelle Befehl akzeptiert keine Filter wie `--since`, `--cli`, `--project`, `--port` oder `--no-open`.

    Lasse den Prozess laufen, während du das lokale Dashboard verwendest. Drücke <kbd>Ctrl</kbd>+<kbd>C</kbd>, wenn du fertig bist.
  </Tab>
</Tabs>

Die aktuellen Audit-Adapter können Verläufe von Claude Code, Codex, GitHub Copilot CLI, Cursor, OpenCode, Pi, Hermes, OpenClaw, Factory, Devin, Antigravity und Goose lesen. Es werden nur lokal verfügbare Verläufe gescannt.

## Wiederkehrende lokale Audits planen

<Tabs>
  <Tab title="Dashboard">
    Öffne **Einstellungen** im lokalen Dashboard, aktiviere geplante Audits, wähle das Intervall und gib die E-Mail-Adresse an, die die Befunde erhalten soll. Dashboard und CLI aktualisieren dieselbe Rechnerkonfiguration.
  </Tab>
  <Tab title="CLI">
    Aktiviere ein wöchentliches Audit und sende die Befunde an die angegebene Adresse:

    ```bash
    failproofai audit --schedule 7 --email reliability@example.com
    failproofai audit --status
    ```

    Das Intervall akzeptiert 1–90 Tage und ist standardmäßig auf 7 gesetzt, wenn kein Wert angegeben wird. Bei der ersten Einrichtung wirst du bei Bedarf angemeldet; `--email` gibt die Berichtsadresse an, ohne eine Eingabeaufforderung zu zeigen.

    Den Zeitplan beenden, ohne den lokalen Audit-Verlauf zu löschen:

    ```bash
    failproofai audit --no-schedule
    ```
  </Tab>
</Tabs>

Der Daemon führt geplante Scans im Hintergrund aus, aktualisiert das gecachte Ergebnis für das lokale Dashboard und sendet den konfigurierten Bericht per E-Mail. Verwende `failproofai audit`, wenn du sofort einen interaktiven Scan ausführen möchtest.

## Von lokalen Erkenntnissen zu Cloud-Operationen wechseln

Ein lokales Audit ist eine schnelle Ausgangsbasis. Verbinde den Rechner mit Failproof AI Cloud, wenn du gemeinsame Traces, wiederkehrende Populations-Audits, Befunde und Issues, Benachrichtigungen, organisationsweite Richtlinienbereitstellung oder Fleet-Health benötigst.
