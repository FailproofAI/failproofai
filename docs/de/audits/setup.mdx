Die Qualität eines Audits beginnt mit seinem Umfang. Eine breite Anfrage wie „Probleme finden" liefert weniger nützliche Ergebnisse als eine konkrete Fehlerfrage.

## Das Audit konfigurieren

<Tabs>
  <Tab title="Dashboard">
    1. Gehen Sie zu **Analyze → Audits → New audit** und geben Sie Name und Beschreibung ein.
    2. Legen Sie den Rhythmus, das Zeitfenster, den Agent-/Umgebungsbereich, ignorierte Fehler, die Empfindlichkeit und die maximale Anzahl von Findings fest.
    3. Fügen Sie unter **agents** den Agentenkontext hinzu oder überprüfen Sie ihn, dann fügen Sie das Operator-Brief und beliebige öffentliche HTTPS-Referenz-URLs hinzu.
    4. Wählen Sie Benachrichtigungskanäle aus und klicken Sie auf **create audit**. Der erste Durchlauf wird sofort in die Warteschlange gestellt.

    ![Das neue Audit-Formular mit Name, Beschreibung, Rhythmus, Zeitfenster, Umgebungs- und Agentenbereich, ignorierten Fehlern, Analyseeinstellungen, Brief, Referenzseiten und Benachrichtigungskanälen.](/images/dashboard/audit-new.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp audits create checkout-reliability \
      --description "Find checkout failures that agents do not recover from" \
      --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
      --schedule-interval-secs 86400 \
      --window-mode since_last \
      --sensitivity medium \
      --text-file ./checkout-audit-brief.txt \
      --url https://runbooks.example.com/checkout
    ```

    Der erste Durchlauf wird sofort in die Warteschlange gestellt. Fügen Sie Brief und Referenz-URLs bereits bei der Erstellung hinzu, damit der erste Durchlauf diese erhält.

    Siehe die vollständige [`fp audits create`-Referenz](/de/reference/cloud-cli#audits).
  </Tab>
</Tabs>

<Tip>
  Beginnen Sie mit einer bekannten fehlgeschlagenen Sitzung und mehreren normalen Sitzungen. So erhält das Audit sowohl ein positives Beispiel als auch einen Vergleichssatz.
</Tip>

<Info>
  Der Audit-Kontext wird als eigene Ressource gespeichert, sodass das Bearbeiten eines Audits das Referenzmaterial nicht versehentlich entfernt.
</Info>
