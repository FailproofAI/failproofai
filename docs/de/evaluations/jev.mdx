Eine Jev-Evaluierung liest eine **abgeschlossene Sitzung** und vergibt eine Punktzahl von 0 bis 1. Verwende sie, wenn die Antwort im Voraus bekannt ist, zum Beispiel: „Hat der Kunde Dringlichkeit ausgedrückt?" oder „Wie frustriert war der Kunde?" Sie hilft dir, Muster über mehrere Durchläufe hinweg zu erkennen – sie stoppt jedoch keinen Tool-Aufruf. Für Entscheidungen, die **vor** der Ausführung eines Tools getroffen werden, verwende [Jev-Richtlinien](/de/policies/jev).

## Eine Evaluierung im Dashboard erstellen

1. Öffne **Analyze → eval authoring** und wähle **new eval**.
2. Beschreibe eine Frage und ihre möglichen Antworten. Zum Beispiel: „Hat der Agent eine Rückerstattung versprochen, bevor er die Rückerstattungsrichtlinie geprüft hat? Antworte mit Ja oder Nein." Wähle **draft** und überprüfe, dass das Ergebnis ein Klassifizierungswert ist.
3. [Teste sie](/de/evaluations/test) anhand aktueller Sitzungen und [stelle sie dann bereit](/de/evaluations/deploy). Neu abgeschlossene Sitzungen werden bewertet; nutze [Backfill](/de/evaluations/deploy#score-sessions-you-already-have), wenn du auch historische Daten benötigst.

Das gezeigte Beispiel ist eine Code-Evaluierung; eine Jev-Frage verwendet denselben Erstellungsablauf.](/images/dashboard/eval-authoring-draft.png)

Der Assistent kann zwischen Code, Jev-Klassifizierung und einem [Judge](/de/evaluations/judge) wählen. Überprüfe seine Wahl vor der Bereitstellung. Jev liefert eine Punktzahl ohne ausführliche Begründung; wähle einen Judge, wenn du eine Erklärung benötigst. Siehe die [Jev-Evaluierungsreferenz](/de/reference/jev-evaluations) für Fragetypen und Punktgrenzen.

## Die Ergebnisse lesen

Öffne **Observe → Evaluations**, um das Ergebnis nach Agent und Zeit darzustellen. Über ein Terminal kann das Cloud-CLI dieselben Ergebnisse abrufen:

```bash
fp evals --since 7d
fp evals --aggregate --since 7d
```

Das Cloud-CLI liest Ergebnisse; Erstellung und Bereitstellung erfolgen im Dashboard. Siehe die [Cloud-CLI-Referenz](/de/reference/cloud-cli#evaluations) für Filter.
