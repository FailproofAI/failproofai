Eine Jev-Auswertung liest eine **abgeschlossene Sitzung** und gibt einen Wert zwischen 0 und 1 zurück. Verwende sie, wenn die Antwort im Voraus bekannt ist – zum Beispiel: „Hat der Kunde Dringlichkeit signalisiert?" oder „Wie frustriert war der Kunde?" Sie hilft dabei, Muster über mehrere Durchläufe hinweg zu erkennen; sie unterbricht keinen Tool-Aufruf. Für Entscheidungen, die **vor** einem Tool-Aufruf getroffen werden, verwende [Jev-Richtlinien](/de/policies/jev).

## Eine Auswertung im Dashboard erstellen

1. Öffne **Analyse → Checks → Neue Auswertung** und wähle unter **Wie soll bewertet werden?** die Option **Entscheidungsmodell** aus.
2. Beschreibe eine Frage und ihre möglichen Antworten. Beispiel: „Hat der Agent eine Rückerstattung versprochen, bevor er die Rückerstattungsrichtlinie geprüft hat? Antworte mit Ja oder Nein." Prüfe in der **Vorschau** die **Frage** sowie die Bedeutung von **Ja** und **Nein**; ein Entscheidungsmodell gibt immer einen Wert zurück.
3. [Teste die Auswertung](/de/evaluations/test) anhand aktueller Sitzungen und [stelle sie dann bereit](/de/evaluations/deploy). Neu abgeschlossene Sitzungen werden automatisch bewertet; für ältere Daten kannst du einen [Rückwärtslauf](/de/evaluations/deploy#score-sessions-you-already-have) durchführen.

Beim Erstellen eines Entwurfs kann failproofai zwischen **Code**, einem **Entscheidungsmodell** (Jev) und einem [**LLM als Richter**](/de/evaluations/judge) wählen. Überprüfe die Wahl, bevor du die Auswertung bereitstellst. Jev liefert einen Wert ohne ausführliche Begründung; wähle einen Richter, wenn du eine Erklärung benötigst. Unter der [Jev-Auswertungsreferenz](/de/reference/jev-evaluations) findest du Fragetypen und Wertegrenzen.

## Ergebnisse lesen

Öffne **Analyse → Checks → Auswertungen** und wähle eine Auswertung aus, um die Ergebnisse nach Agent und Zeitraum aufzuschlüsseln. Über ein Terminal kann die Cloud-CLI dieselben Ergebnisse abrufen:

```bash
fp evals --since 7d
fp evals --aggregate --since 7d
```

Im Terminal dient `fp evaluators` zum Erstellen und Bereitstellen von Jev-Auswertungen, während `fp evals` deren Ergebnisse ausliest. Beide Befehle sind in der [Cloud-CLI-Referenz](/de/reference/cloud-cli#evaluations) dokumentiert.
