Failproof AI hilft jedem, der Agenten betreibt, zu verstehen, was passiert ist, Fehler zu finden und zu verhindern, dass sie sich wiederholen.

Es funktioniert mit 12 gängigen Agentenumgebungen, darunter Claude Code, Codex, Hermes, OpenClaw und Goose. Agenten, die mit LangChain, CrewAI, LlamaIndex, Pydantic AI oder deiner eigenen Laufzeitumgebung erstellt wurden, können über das [Python SDK](/de/reference/custom-agents) berichten.

## Lokal starten oder Cloud verbinden

<Columns cols={2}>
  <Card title="Lokal, ohne Konto" icon="laptop" href="/de/audits/local-audit">
    Öffne das Dashboard unter `localhost:8020` und führe `failproofai audit` aus. Dein Agentenverlauf bleibt auf diesem Rechner.
  </Card>
  <Card title="Failproof AI Cloud" icon="cloud" href="/de/start/setup">
    Sieh Sessions über mehrere Maschinen hinweg und verwalte Richtlinien für dein Team.
  </Card>
</Columns>

Das Setup wählt absichtlich kein Richtlinienpaket aus. Füge unseres nach der Einrichtung hinzu:

```bash
failproofai policies add FailproofAI/policies
```

Bis dahin läuft nur `block-failproofai-commands`. Es verhindert, dass ein Agent Failproof AI deaktiviert.

> **Session → Audit → Finding → Issue → Policy**
> Sieh, was passiert ist, finde den Fehler, übernimm die Verantwortung für die Reaktion, und verhindere ihn dann.

<Note>
  Das Setup unterstützt Linux und macOS. Siehe [unterstützte Harnesses](/de/reference/harnesses) für das, was jede Agentenumgebung beobachten oder blockieren kann.
</Note>
