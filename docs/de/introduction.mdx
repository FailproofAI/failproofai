[![npm weekly downloads](https://img.shields.io/npm/dw/failproofai?style=flat-square&color=2ea44f)](https://www.npmjs.com/package/failproofai)

Hooks und Policies für **KI-Fehlerbehandlung**, **Fehlerwiederherstellung** und **LLM-Zuverlässigkeit**. Halten Sie Ihre KI-Agenten zuverlässig und autonom laufend in **Claude Code**, **OpenAI Codex**, **GitHub Copilot**, **Cursor Agent**, **OpenCode**, **Pi**, **Hermes**, **OpenClaw**, **Factory Droid**, **Devin CLI**, **Antigravity CLI** und dem **Agents SDK**.

KI-Agenten versagen auf vorhersehbare Weise. Sie führen destruktive Befehle aus, geben Geheimnisse preis, weichen von ihrer Aufgabe ab, geraten in Endlosschleifen oder pushen direkt in den main-Branch. Unbeaufsichtigt eskalieren kleine Fehler zu Ausfällen, geleakten Zugangsdaten und verlorener Arbeit.

FailproofAI löst dieses Problem mit **Policies**. Diese Regeln greifen in jeden Agenten-Tool-Aufruf ein, um **Fehler zu erkennen**, **sie zu beheben** (blockieren, anweisen, bereinigen) und **Sie zu benachrichtigen**, wenn etwas Aufmerksamkeit erfordert. Ein lokales Dashboard ermöglicht es Ihnen, im Nachgang jeden Tool-Aufruf, jeden Agentenfehler und jede Wiederherstellungsmaßnahme zu überprüfen.

Transkripte und Policy-Auswertungen verbleiben auf Ihrem Rechner. Daten werden nur übertragen, wenn Sie explizit eine Online-Funktion nutzen, etwa authentifizierte Audit-Erinnerungen oder Einladungen.

## Schnellstart

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # enable policies (or skip — `failproofai` will offer to set them up on first run)
failproofai                      # launch the dashboard
```

Den vollständigen Einrichtungsablauf finden Sie im [Erste Schritte](/de/getting-started)-Leitfaden.
