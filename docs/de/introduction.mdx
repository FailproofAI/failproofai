[![npm weekly downloads](https://img.shields.io/npm/dw/failproofai?style=flat-square&color=2ea44f)](https://www.npmjs.com/package/failproofai)

Hooks und Richtlinien für **KI-Fehlerbehandlung**, **Fehlerwiederherstellung** und **LLM-Zuverlässigkeit**. Halte deine KI-Agenten zuverlässig und autonom am Laufen – mit **Claude Code**, **OpenAI Codex**, **GitHub Copilot**, **Cursor Agent**, **OpenCode**, **Pi**, **Hermes**, **OpenClaw**, **Factory Droid**, **Devin CLI**, **Antigravity CLI** und dem **Agents SDK**.

KI-Agenten scheitern auf vorhersehbare Arten. Sie führen destruktive Befehle aus, leaken Secrets, weichen von ihrer Aufgabe ab, stecken in Schleifen fest oder pushen direkt in den main-Branch. Unbeaufsichtigt können kleine Fehler zu Ausfällen, geleakten Zugangsdaten und verlorener Arbeit führen.

FailproofAI löst das mit **Richtlinien**. Diese Regeln haken sich in jeden Tool-Aufruf des Agenten ein, um **Fehler zu erkennen**, **sie zu beheben** (blockieren, anweisen, bereinigen) und **dich zu benachrichtigen**, wenn etwas Aufmerksamkeit erfordert. Ein lokales Dashboard ermöglicht es dir, im Nachhinein jeden Tool-Aufruf, jeden Agentenfehler und jede Wiederherstellungsmaßnahme zu überprüfen.

Transkripte und Richtlinienauswertungen verbleiben auf deinem Rechner. Daten werden nur übertragen, wenn du explizit eine Online-Funktion verwendest, z. B. authentifizierte Audit-Erinnerungen oder Einladungen.

## Schnellstart

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # enable policies (or skip — `failproofai` will offer to set them up on first run)
failproofai                      # launch the dashboard
```

Den vollständigen Leitfaden findest du unter [Erste Schritte](/de/getting-started).
