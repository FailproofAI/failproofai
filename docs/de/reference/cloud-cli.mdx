Verwende `fp` zum Einsehen von Cloud-Telemetrie und zur Verwaltung von Audits, Befunden, Issues, Alerts, Schlüsseln, Benutzern, Abfragen und Einstellungen. Verwende [`failproofai`](/de/reference/failproof-cli) für lokale Hooks, Richtlinien, Aufzeichnung und Maschinenregistrierung.

Installiere das veröffentlichte Cloud CLI als isoliertes Tool:

```bash
uv tool install fp-cli
fp version
```

## Anmelden

```bash
fp login
fp whoami
```

## Syntax

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

Globale Optionen müssen vor dem Befehl angegeben werden:

```bash
fp --json sessions --since 24h
```

Führe `fp COMMAND --help` oder `fp COMMAND SUBCOMMAND --help` aus, um die Terminalhilfe anzuzeigen.

### Ereignisse

```text
fp events [OPTIONS]
```

Listet einzelne Agentenereignisse auf. Der standardmäßige Light-Feed schließt rohe Payloads aus; verwende `--full` nur für eine begrenzte Untersuchung.

| Option | Beschreibung |
| --- | --- |
| `--limit`, `-n <n>` | Maximale Gesamtanzahl von Zeilen. Standard: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h` oder `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | ISO 8601 UTC-Bereich; überschreibt `--since`. |
| `--env <value>` | Umgebungsfilter; Werte wiederholen oder kommagetrennt angeben. |
| `--event-type <value>` | Ereignistypfilter; Werte wiederholen oder kommagetrennt angeben. |
| `--agent-id <value>` | Agentenfilter; Werte wiederholen oder kommagetrennt angeben. |
| `--session-id <value>` | Sitzungsfilter; Werte wiederholen oder kommagetrennt angeben. |
| `--search <text>` | Payload-Textsuche; wiederholbar, wobei ein beliebiger Begriff übereinstimmen muss. |
| `--order asc\|desc` | Zeitreihenfolge. Standard: neueste zuerst. |
| `--all` | Automatische Paginierung bis `--limit`. |
| `--cursor <token>` | Fortfahren ab einem undurchsichtigen Cursor. |
| `--page-size <n>` | Zeilen pro Anfrage mit `--all`; maximal `200`. |
| `--full` | Rohe Payloads über den umfangreicheren Ereignis-Endpunkt einschließen. |
| `--fields <csv>` | Nur ausgewählte Felder zurückgeben; Anforderung von `payload` aktiviert den Vollmodus. |

```bash
fp events --session-id <session-id> --order asc --all
fp --json events --full --session-id <session-id> --all
```

### API-Schlüssel

| Befehl | Zweck | Optionen |
| --- | --- | --- |
| `fp keys list` | Organisationsschlüssel auflisten. | `--show-id`; `--fields <csv>` |
| `fp keys show NAME` | Einen Schlüssel und seine Berechtigungen anzeigen. | — |

| `fp keys update NAME` | Den Berechtigungssatz ersetzen oder Berechtigungen anpassen. | `--permission-set`; `--add`; `--remove`; `--yes`, `-y` |

#### Audit create options

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| Option | Beschreibung |
| --- | --- |
| `--file <path>` | Die Definition auf JSON basieren oder `-` für stdin verwenden. Explizite Flags überschreiben Dateiwerte. |
| `--description <text>` | Die Fehlerfrage oder den Zweck beschreiben. |
| `--enabled` / `--disabled` | Planung ein- oder ausschalten. Standard: aktiviert. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. Standard: `86400`. |
| `--schedule-anchor <timestamp>` | Feste UTC-Phase im ISO 8601-Format. Standard: nächstes 09:00 UTC. |
| `--window-mode since_last\|fixed` | Nach dem letzten vollständig analysierten Fenster fortfahren oder ein rollierendes Fenster wiederholt untersuchen. Standard: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. Standard: `604800`. |
| `--scope '<json>'` | Nach `environments`, `agent_ids` oder anderen unterstützten Scope-Feldern filtern. |
| `--ignore-error-type <type>` | Fehlertypen ausschließen; wiederholen oder kommagetrennt angeben. |
| `--llm` / `--no-llm` | Agentische Analyse aktivieren oder deaktivieren. Standard: aktiviert. |
| `--top-k <n>` | `1`–`500` Befunde beibehalten. Standard: `50`. |
| `--sensitivity low\|medium\|high` | Meldeempfindlichkeit festlegen. Standard: `medium`. |
| `--channels '<json>'` | Array der Benachrichtigungskanäle. |
| `--text <brief>` | Inline-Kurztext, maximal 8.192 Zeichen. |
| `--text-file <path>` | Den Kurztext aus einer Datei lesen; schließt sich mit `--text` gegenseitig aus. |
| `--url <https-url>` | Eine öffentliche HTTPS-Referenz hinzufügen; bis zu fünfmal wiederholen. |

Kontext während der Erstellung einschließen, wenn der erste Durchlauf ihn benötigt. Die Erstellung schreibt Definition und Kontext gemeinsam fest, bevor der eingereihte Durchlauf beginnt.

<Note>
  `fp audits run` ist asynchron. `fp audits runs NAME` pollen, bis der neueste Durchlauf erfolgreich abgeschlossen oder fehlgeschlagen ist, bevor die Befunde gelesen werden.
</Note>

## Globale Flags

| Flag | Beschreibung |
| --- | --- |
| `--json` | Maschinenlesbares JSON ausgeben. |
| `--base-url <url>` | Ein selbst gehostetes oder Entwicklungs-Dashboard verwenden. |
| `--org <slug>` | Eine Organisation für diesen Aufruf auswählen. |
| `--token <token>` | Das gespeicherte Benutzersitzungs-Token überschreiben. |
| `--api-key <key>` | Automatisierung mit einem API-Schlüssel authentifizieren; wird nie gespeichert. |
| `--timeout <seconds>` | HTTP-Timeout; muss positiv sein. Standard: `30`. |
| `--quiet`, `-q` | Statusausgabe auf stderr unterdrücken. |
| `--no-color` | Farbige Ausgabe deaktivieren. |
| `--insecure` / `--secure` | TLS-Zertifikatsverifizierung deaktivieren oder wiederherstellen. |
| `--version` | Die Version ausgeben und beenden. |
| `--help`, `-h` | Hilfe anzeigen. |

`--api-key` ist für die Automatisierung gedacht. Anmeldung, Organisationswechsel und Assistentenbefehle erfordern eine Benutzersitzung.

| Variable | Äquivalent oder Zweck |

| `AGENTEYE_DASHBOARD_URL` | `--base-url` |

Explizite Flags überschreiben Umgebungsvariablen, die die gespeicherte Konfiguration überschreiben. Im API-Schlüssel-Modus den Mandanten explizit mit `--org` oder `AGENTEYE_ORG` auswählen.

<Warning>
  Befehle, die Konfigurationen löschen, widerrufen, unterdrücken, auflösen oder ersetzen, fragen standardmäßig nach einer Bestätigung. `--yes` nur nach Überprüfung der aktiven Organisation und des Ziels verwenden.
</Warning>
