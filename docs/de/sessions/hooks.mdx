Ein Hook ist ein Punkt, an dem ein Agent Failproof AI um eine Entscheidung bittet. Hook-Aktivitätsdatensätze erfassen das Event, die Richtlinie, das Ergebnis und die Auswertungszeit.

## Hook-Aktivität untersuchen

<Tabs>
  <Tab title="Dashboard">
    Gehe zu **Observe → Hooks**. Filtere nach Umgebung, Event, Agent oder Session.

    ![Die Hooks-Seite mit nach Hook-Name und Trigger-Event gruppierter Latenz.](/images/dashboard/hooks.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp guardrails summary --since 24h
    fp --json events --full --event-type hook_completed --session-id <session-id> --all --limit 500
    fp list hooks
    ```
  </Tab>
</Tabs>

Standardmäßig wird jede `deny`- und `instruct`-Entscheidung vollständig übermittelt. Wiederholte allows werden gebündelt, um das Rauschen zu reduzieren. Setze `collector.hooks_verbosity` in `~/.failproofai/config.json` auf `all`, `decisions` oder `off`.

<Warning>
  Hook-Aktivität belegt, dass eine Auswertung stattgefunden hat – nicht, dass das Harness das entsprechende Event hätte blockieren können. Siehe [Enforcement-Fähigkeit](/de/reference/harnesses#enforcement-capability). Ein nicht aufgeführtes Harness-Event-Paar gilt als nicht verifiziert.
</Warning>
