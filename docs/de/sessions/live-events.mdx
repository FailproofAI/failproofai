Live-Ereignisse zeigen die Aktivität von Agenten in Echtzeit: Modellaufrufe, Tools, Fehler, menschliche Eingaben, Hooks und Richtlinienentscheidungen.

## Aktivität beobachten

Gehen Sie zu **Observe → Live events** oder führen Sie folgendes aus:

```bash
fp events --since 1h
fp events --event-type tool_use,tool_result --since 1h
fp --json events --full --session-id <session-id> --all --limit 2000
```

Verwenden Sie `--full`, wenn Sie die Inhalte der Nutzdaten benötigen. Der kompakte Feed ist schneller und für die meisten Filterzwecke ausreichend.

Häufige Ereignistypen sind:

- `session_start` und `session_end`
- `model_request` und `model_response`
- `tool_use` und `tool_result`
- `hook_triggered` und `hook_completed`
- `error`
- `human_wait` und `human_input`
- `agent_pause` und `agent_resume`

## Falls keine Ereignisse angezeigt werden

```bash
failproofai flush --wait
failproofai config --status
failproofai backfill --since 30d --dry-run
```

Die Standardumgebung ist `local`. Ein Filter für `production` liefert keine Ergebnisse, bis Sie die Umgebungsbezeichnung entsprechend ändern.

Für einen Agenten außerhalb eines unterstützten Frameworks verwenden Sie das [Python SDK](/de/reference/custom-agents).
