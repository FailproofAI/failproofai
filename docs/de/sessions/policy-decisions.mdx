title: "Policy-Entscheidungen"
description: "Sehen Sie, welche Policies ausgewertet, blockiert, angewiesen oder erlaubt haben."
icon: "shield-check"
---

Policy-Entscheidungen erklären, was die Durchsetzung bewirkt hat. Nutzen Sie diese Ansicht, um einen Rollout zu verifizieren, die Blockierungsrate zu messen und ungeschützte Aktivitäten zu finden.

<Tabs>
  <Tab title="Dashboard">
    1. Gehen Sie zu **Observe → policy** und wählen Sie den Zeitraum sowie optional eine einzelne Maschine aus.
    2. Überprüfen Sie ausgewertete Aktionen, Blockierungen, Blockierungsrate, Cloud-Entscheidungen, ungeschützte Aktionen und Aktivitäten während einer Pause.
    3. Filtern Sie die Policy-Zuordnungstabelle und prüfen Sie bereitgestellte Zuweisungen.
    4. Wählen Sie einen Diagrammpunkt aus, um die Entscheidungen und die zugehörigen Sitzungen zu öffnen.

    ![Die Policy-Seite mit Entscheidungsgesamtzahlen, einem Maschinenfilter, Durchsetzungsaktivität im Zeitverlauf und der Policy-Zuordnungstabelle.](/images/dashboard/policy-observe.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp events --event-type hook_completed --env production --since 24h
    fp events --search "deny" --since 24h
    failproofai config --status
    ```

    Verwenden Sie `failproofai` für den lokalen Durchsetzungsstatus der Maschine und `fp` für die Cloud-Ereignisuntersuchung.
  </Tab>
</Tabs>
