Administración contiene los controles necesarios para ejecutar Failproof AI en todo un equipo. La mayoría de los usuarios pueden quedarse en Sesiones, Auditorías y Políticas; los administradores utilizan esta sección para gestionar el acceso y los límites operativos.

<Tabs>
  <Tab title="Panel de control">
    Usa la sección **Admin** de la barra lateral en la nube para acceder al **editor de políticas**, **aplicación**, **uso**, **claves**, **usuarios** y **configuración**. Un elemento bloqueado indica que a tu cuenta le falta el permiso de lectura correspondiente.

    ![La sección Admin de la barra lateral en la nube con editor de políticas, aplicación, uso, claves, usuarios y configuración.](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    Coloca las opciones globales antes del comando, por ejemplo `fp --org reliability-team --json usage`.
  </Tab>
</Tabs>
