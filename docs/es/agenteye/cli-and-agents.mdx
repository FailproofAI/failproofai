Todo tu despliegue de observabilidad de Failproof AI, a un solo comando. Revisa producción, genera una clave API o reconoce un incidente sin salir de tu terminal; luego automatiza cualquier tarea en CI o deja que un agente de codificación lo haga por ti en lenguaje natural.

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*El CLI `agenteye` se comunica con tu dashboard. Es una herramienta distinta del recolector, que envía eventos al servidor.*

## Todo tu despliegue, a un solo comando

Deja de cambiar de pestaña para responder una pregunta rápida. El CLI `agenteye` lee tus datos y administra tu organización desde un único binario, de modo que una comprobación que antes requería navegar por el dashboard se convierte en una línea que puedes volver a ejecutar, crear como alias o pegar en un runbook. Dispones de cuatro áreas:

- **Lee tus datos:** `sessions`, `events`, `evals` y `errors`, filtrados por tiempo, agente y entorno.
- **Administra tu organización:** `keys`, `users`, `settings`, `alerts` e `incidents`.
- **Ejecuta analíticas:** SQL guardado más un ejecutor `query` ad hoc sobre tus datos de eventos.
- **Consulta el asistente:** `agent ask` accede al mismo analista de solo lectura con el que chateas en el dashboard.

Instálalo una vez con `pipx`, inicia sesión con un código de 6 dígitos enviado por correo y listo. La sesión dura aproximadamente un día; vuelve a ejecutar `agenteye login` cuando expire. Úsalo para revisar producción, aprovisionar una clave o hacer triage de un incidente activo, todo sin abrir el navegador:

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

Un detalle importante: las opciones globales como `--json` van antes del comando. `agenteye --json sessions` es correcto; `agenteye sessions --json` no lo es.

## Automatízalo e intégralo en CI

Cada comando acepta `--json`, y eso lo cambia todo. El JSON limpio va a stdout mientras los mensajes de estado y advertencias van a stderr, así que una captura con `--json` se puede pasar directamente a `jq` sin necesidad de filtrar líneas extrañas. Eso es lo que hace que el CLI sea igual de útil para ti en el terminal y para un agente de codificación que analice la salida:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

Está diseñado para ejecutarse de forma desatendida. Los prompts de confirmación se omiten automáticamente cuando no hay terminal conectada, así que nada queda bloqueado en un pipeline, y cada comando devuelve un código de salida significativo: `0` éxito, `4` sesión no iniciada, `5` permiso insuficiente (el mensaje lo indica, por ejemplo `alerts:write`), `3` dashboard inaccesible. Un script puede ramificarse ante un `4` para reautenticarse o ante un `5` para saber exactamente qué permiso solicitar a un administrador, en lugar de fallar sin información.

## Deja que un agente de codificación lo gestione en lenguaje natural

Mejor aún: no deberías tener que recordar ninguno de estos flags. El **CLI skill** es una pequeña carpeta de Agent Skill llamada `agenteye-cli` que enseña a un agente de codificación como Claude Code o Codex a manejar el CLI a partir de instrucciones en lenguaje natural. Pregunta "¿hay algo roto hoy?" y el agente elige el comando, lo ejecuta con tu sesión y responde en prosa.

Para Claude Code, coloca la carpeta `agenteye-cli` en `~/.claude/skills/` y se detectará automáticamente. Failproof AI Observability proporciona la carpeta; no hay nada adicional que instalar, ya que solo maneja el CLI que ya instalaste. Inicia sesión tú primero: el skill no puede completar el inicio de sesión con código por correo en tu lugar.

Como el agente ejecuta el CLI con tu sesión, puede hacer todo lo que tu login permite, tanto lecturas como escrituras: crear claves, cambiar configuraciones, resolver incidentes. El prompt de confirmación del CLI no se activa para un agente, por eso el skill está diseñado para indicar el comando exacto y esperar tu aprobación antes de cualquier cambio. Tú eres el paso de confirmación.

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

Las lecturas son instantáneas, y cada escritura espera tu confirmación:

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
