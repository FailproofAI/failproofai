Todo tu despliegue de Failproof AI Observability, a un comando de distancia. Consulta producción, genera una clave API o confirma un incidente sin salir de tu terminal, luego automatiza cualquier cosa en CI, o deja que un agente de codificación lo haga por ti en lenguaje natural.

```bash
pipx install agenteye
agenteye login --email tu@ejemplo.com        # recibirás un código de 6 dígitos en tu correo
agenteye --json sessions --since 24h         # todas las ejecuciones de agentes del último día, las más recientes primero
```

*El CLI `agenteye` se comunica con tu panel de control. Es una herramienta distinta al colector, que envía eventos al servidor.*

## Todo tu despliegue, a un comando de distancia

Deja de saltar entre pestañas para responder una pregunta rápida. El CLI `agenteye` lee tus datos y administra tu organización desde un único binario, así que una consulta que antes requería navegar por el panel de control se convierte en una línea que puedes volver a ejecutar, crear como alias o pegar en un runbook. Tienes cuatro áreas de acción:

- **Lee tus datos:** `sessions`, `events`, `evals` y `errors`, filtrados por tiempo, agente y entorno.
- **Gestiona tu organización:** `keys`, `users`, `settings`, `alerts` e `incidents`.
- **Ejecuta análisis:** SQL guardado más un ejecutor `query` ad-hoc sobre tus datos de eventos.
- **Consulta al asistente:** `agent ask` conecta con el mismo analista de solo lectura con el que chateas en el panel de control.

Instálalo una vez con `pipx`, inicia sesión con un código de 6 dígitos enviado por correo, y ya estás listo. La sesión dura aproximadamente un día; vuelve a ejecutar `agenteye login` cuando expire. Úsalo para revisar producción de forma puntual, aprovisionar una clave o clasificar un incidente activo, todo sin abrir un navegador:

```bash
agenteye errors --since 24h --aggregate      # qué está fallando, agrupado por tipo de error
agenteye incidents list --state firing       # qué está en llamas ahora mismo
agenteye keys create ci --add events:add     # una clave que solo puede enviar eventos, secreto visible una sola vez
```

Un hábito a recordar: las opciones globales como `--json` van antes del comando. `agenteye --json sessions` es correcto; `agenteye sessions --json` no lo es.

## Automatízalo, intégralo en CI

Cada comando acepta `--json`, y eso lo cambia todo. El JSON limpio va a stdout mientras que los mensajes de estado y advertencias para humanos van a stderr, por lo que una captura con `--json` se puede pasar directamente a `jq` sin necesidad de filtrar ninguna línea extra. Eso es lo que hace que el CLI sea igual de útil para ti en un prompt que para un agente de codificación que analiza la salida:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

Está diseñado para ejecutarse de forma desatendida. Los prompts de confirmación se omiten automáticamente cuando no hay terminal conectada, así que nada se bloquea en un pipeline, y cada comando devuelve un código de salida significativo: `0` éxito, `4` sesión no iniciada, `5` permiso insuficiente (el mensaje lo especifica, por ejemplo `alerts:write`), `3` panel de control inaccesible. Un script puede ramificarse con un `4` para reautenticarse o con un `5` para indicarte exactamente qué permisos solicitar a un administrador, en lugar de fallar sin información.

## Deja que un agente de codificación lo maneje en lenguaje natural

Mejor aún, no deberías tener que recordar ninguno de estos flags. El **CLI skill** es una pequeña carpeta de Agent Skill llamada `agenteye-cli` que enseña a un agente de codificación como Claude Code o Codex a usar el CLI a partir de solicitudes en lenguaje natural. Pregunta "¿hay algo roto hoy?" y el agente elige el comando, lo ejecuta como tú y responde en prosa.

Para Claude Code, coloca la carpeta `agenteye-cli` en `~/.claude/skills/` y se descubre automáticamente. Failproof AI Observability proporciona la carpeta; no hay nada extra que instalar, porque solo usa el CLI que ya instalaste. Inicia sesión tú mismo primero: el skill no puede completar el inicio de sesión con código enviado por correo en tu lugar.

Como el agente ejecuta el CLI como tú, puede hacer todo lo que tu sesión permite, tanto lecturas como escrituras: crear claves, cambiar configuraciones, resolver incidentes. El prompt de confirmación del CLI no se activa para un agente, por lo que el skill está diseñado para indicar el comando exacto y esperar tu aprobación antes de cualquier cambio. Tú eres el paso de confirmación.

```text
tú      ¿Por qué falló la sesión run-001?

agente  Ejecutando: agenteye --json events --session-id run-001 --all
        El checkout-agent encontró un TimeoutError en su tercera llamada a herramienta.
```

Las lecturas son inmediatas, y cada escritura hace una pausa para que confirmes:

```text
tú      Dale a CI una clave que solo pueda enviar eventos.

agente  Esto crea una clave API. Ejecutaré:
          agenteye keys create ci --add events:add
        ¿Procedo?

tú      sí

agente  Listo. Clave "ci" creada solo con events:add. El secreto se muestra una sola vez, guárdalo ahora.
```
