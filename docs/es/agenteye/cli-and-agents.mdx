Todo tu despliegue de Failproof AI Observability, a un comando de distancia. Revisa producción, genera una clave API o reconoce un incidente sin salir de tu terminal, y luego automatiza cualquier cosa en CI, o deja que un agente de código lo haga por ti en lenguaje natural.

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*El CLI `agenteye` se comunica con tu panel de control. Es una herramienta distinta del colector, que envía eventos al servidor.*

## Todo tu despliegue, a un comando de distancia

Deja de cambiar de pestaña para responder una pregunta rápida. El CLI `agenteye` lee tus datos y administra tu organización desde un único binario, de modo que una revisión que antes implicaba navegar por el panel de control se convierte en una sola línea que puedes volver a ejecutar, poner como alias o pegar en un runbook. Tienes cuatro superficies:

- **Lee tus datos:** `sessions`, `events`, `evals` y `errors`, filtrados por tiempo, agente y entorno.
- **Administra tu organización:** `keys`, `users`, `settings`, `alerts` e `incidents`.
- **Ejecuta análisis:** SQL guardado más un ejecutor `query` ad-hoc sobre tus datos de eventos.
- **Consulta al asistente:** `agent ask` accede al mismo analista de solo lectura con el que chateas en el panel de control.

Instálalo una vez con `pipx`, inicia sesión con un código de 6 dígitos enviado por correo y estás listo. La sesión dura aproximadamente un día; vuelve a ejecutar `agenteye login` cuando expire. Úsalo para verificar producción, aprovisionar una clave o hacer triage de un incidente activo, todo sin abrir un navegador:

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

Un hábito que vale la pena recordar: las opciones globales como `--json` van antes del comando. `agenteye --json sessions` es correcto; `agenteye sessions --json` no lo es.

## Automatízalo, intégralo en CI

Cada comando acepta `--json`, y eso lo cambia todo. El JSON limpio va a stdout mientras que los mensajes de estado y advertencias van a stderr, de modo que una captura con `--json` puede canalizarse directamente a `jq` sin líneas extrañas que limpiar. Eso es lo que hace que el CLI sea igual de útil para ti en un prompt y para un agente de código que analiza la salida:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

Está diseñado para ejecutarse de forma desatendida. Las confirmaciones interactivas se omiten automáticamente cuando no hay una terminal conectada, así que nada queda bloqueado en un pipeline, y cada comando devuelve un código de salida con significado: `0` éxito, `4` sesión no iniciada, `5` falta un permiso (el mensaje lo indica, por ejemplo `alerts:write`), `3` panel de control inaccesible. Un script puede ramificarse ante un `4` para reautenticarse o ante un `5` para indicarte exactamente qué pedirle a un administrador, en lugar de fallar sin información.

## Deja que un agente de código lo maneje en lenguaje natural

Mejor aún, no deberías tener que recordar ninguna de estas opciones. El **CLI skill** es una pequeña carpeta de Agent Skill llamada `agenteye-cli` que enseña a un agente de código como Claude Code o Codex a manejar el CLI a partir de solicitudes en lenguaje natural. Pregunta «¿hay algo roto hoy?» y el agente elige el comando, lo ejecuta como tú y responde en prosa.

Para Claude Code, coloca la carpeta `agenteye-cli` en `~/.claude/skills/` y se descubrirá automáticamente. Failproof AI Observability proporciona la carpeta; no hay nada extra que instalar, porque solo maneja el CLI que ya instalaste. Inicia sesión tú mismo primero: el skill no puede completar el inicio de sesión con código enviado por correo en tu lugar.

Dado que el agente ejecuta el CLI como tú, puede hacer todo lo que tu sesión permite, tanto lecturas como escrituras: crear claves, cambiar configuraciones, resolver incidentes. El prompt de confirmación del CLI no se activa para un agente, por lo que el skill está diseñado para indicar el comando exacto y esperar tu aprobación antes de cualquier cambio. Tú eres el paso de confirmación.

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

Las lecturas son instantáneas, y cada escritura espera tu confirmación:

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
