Usa auditorías recurrentes para patrones de fallo que pueden reaparecer a medida que cambian los agentes, prompts, herramientas y modelos.

## Cambiar la programación

<Tabs>
  <Tab title="Dashboard">
    1. Ve a **Analyze → Audits** y abre la auditoría.
    2. Abre su configuración y cambia el estado habilitado, el intervalo, el ancla UTC, el modo de ventana o el período de revisión.
    3. Guarda la auditoría y confirma la hora de la próxima ejecución en la tarjeta de auditoría.
    4. Usa **run now** una vez tras un cambio importante en el alcance o el contexto.

    ![El editor de auditorías mostrando cadencia, ventana de barrido, alcance, configuración de análisis, contexto y canales de notificación.](/images/dashboard/audit-edit.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp audits edit checkout-reliability \
      --schedule-interval-secs 86400 \
      --schedule-anchor 2026-08-15T09:00:00Z \
      --lookback-window-secs 86400 \
      --yes

    fp audits edit checkout-reliability --disabled --yes
    fp audits edit checkout-reliability --enabled --yes
    ```

    Consulta la [referencia de `fp audits`](/es/reference/cloud-cli#audits) para conocer los límites de programación, el comportamiento de la ventana y todos los comandos de auditoría.
  </Tab>
</Tabs>

Elige la cadencia en función de la velocidad y el coste del riesgo:

| Patrón de riesgo | Cadencia inicial |
| --- | --- |
| Acción de producción de alto impacto | Diaria |
| Regresión de flujo de trabajo o modelo | Semanal |
| Revisión de gobernanza o acceso | Mensual |
| Investigación puntual de una versión | Ejecución única |

Alinea la ventana de revisión con la cadencia para que las ejecuciones no dejen huecos ni examinen repetidamente una población innecesariamente grande. Después de cambiar el objetivo o el contexto de una auditoría, ejecútala manualmente una vez antes de confiar en el próximo resultado programado.

<Note>
  Las auditorías programadas locales se configuran en la máquina y escanean el historial de agentes local. Las programaciones de auditorías en la nube operan sobre sesiones de la nube. Trata sus resultados y su propiedad de forma independiente.
</Note>
