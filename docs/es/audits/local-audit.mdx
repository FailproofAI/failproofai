Utiliza una auditoría local para una revisión inmediata y privada antes de conectar un equipo a Failproof AI Cloud. Escanea los historiales de agentes ya almacenados en tu máquina, reproduce la actividad de herramientas a través de políticas integradas y abre un panel de resultados local.

## Ejecutar una auditoría interactiva

<Tabs>
  <Tab title="Panel de control">
    La auditoría local se inicia desde la CLI porque debe descubrir los historiales en la máquina actual. Ejecuta `failproofai audit`; tras el escaneo, Failproof AI inicia el panel incluido y abre **http://localhost:8020/audit**.

    En la vista de auditoría, revisa el número de sesiones, llamadas a herramientas, proyectos y coincidencias de políticas. Comienza con los hallazgos más frecuentes, luego inspecciona el proyecto afectado y el historial del agente antes de habilitar la aplicación de políticas.

    <Info>El panel de auditoría local es independiente de **Analyze → Audits** en Failproof AI Cloud. Las auditorías locales permanecen en el equipo y no requieren cuenta ni conexión a la red.</Info>
  </Tab>
  <Tab title="CLI">
    ```bash
    npm install -g failproofai
    failproofai audit
    ```

    El comando realiza un escaneo completo de todos los historiales compatibles que encuentre. El comando actual no acepta filtros como `--since`, `--cli`, `--project`, `--port` ni `--no-open`.

    Mantén el proceso en ejecución mientras usas el panel local. Pulsa <kbd>Ctrl</kbd>+<kbd>C</kbd> cuando hayas terminado.
  </Tab>
</Tabs>

Los adaptadores de auditoría actuales pueden leer historiales de Claude Code, Codex, GitHub Copilot CLI, Cursor, OpenCode, Pi, Hermes, OpenClaw, Factory, Devin, Antigravity y Goose. Solo se escanean los historiales disponibles localmente.

## Programar auditorías locales periódicas

<Tabs>
  <Tab title="Panel de control">
    Abre **Settings** en el panel local, habilita las auditorías programadas, elige el intervalo y establece la dirección de correo electrónico que debe recibir los hallazgos. El panel y la CLI actualizan la misma configuración del equipo.
  </Tab>
  <Tab title="CLI">
    Habilita una auditoría semanal y envía los hallazgos a la dirección indicada:

    ```bash
    failproofai audit --schedule 7 --email reliability@example.com
    failproofai audit --status
    ```

    El intervalo acepta entre 1 y 90 días y tiene un valor predeterminado de 7 si se omite. La primera configuración inicia sesión cuando es necesario; `--email` proporciona la dirección del informe sin solicitar confirmación.

    Detén la programación sin eliminar el historial de auditorías local:

    ```bash
    failproofai audit --no-schedule
    ```
  </Tab>
</Tabs>

El demonio ejecuta escaneos programados en segundo plano, actualiza el resultado en caché utilizado por el panel local y envía el informe configurado por correo electrónico. Usa `failproofai audit` cuando quieras ejecutar un escaneo interactivo de forma inmediata.

## Pasar de la evidencia local a las operaciones en Cloud

Una auditoría local es una base de referencia rápida. Conecta el equipo a Failproof AI Cloud cuando necesites trazas compartidas, auditorías periódicas de población, hallazgos e incidencias, alertas, despliegue de políticas a nivel de organización o el estado de la flota.
