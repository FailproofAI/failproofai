---
title: Ver sesiones
description: "Inicia el panel de control para explorar sesiones de agentes y gestionar políticas"
---

```bash
failproofai
```

Inicia el panel de control web en `http://localhost:8020`.

## Opciones

The dashboard takes no flags — `failproofai` rejects any it does not recognize. The port is fixed at `8020`.

Para apuntar el panel de control a una carpeta de proyecto de Claude distinta a la predeterminada, establece la variable de entorno `CLAUDE_PROJECTS_PATH` al iniciarlo.

## Ejemplos

```bash
failproofai

# Usar una ruta de proyectos de Claude personalizada mediante variable de entorno
CLAUDE_PROJECTS_PATH=~/my-claude-projects failproofai
```
