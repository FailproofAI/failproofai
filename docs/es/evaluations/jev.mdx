Una evaluación Jev lee una **sesión finalizada** y asigna una puntuación de 0 a 1. Úsala cuando la respuesta se conoce de antemano, por ejemplo: "¿El cliente expresó urgencia?" o "¿Qué tan frustrado estaba el cliente?" Te ayuda a identificar patrones entre ejecuciones; no detiene una llamada a herramienta. Para decisiones tomadas **antes** de que se ejecute una herramienta, usa las [políticas Jev](/es/policies/jev).

## Crear una desde el panel

1. Abre **Analyze → eval authoring** y selecciona **new eval**.
2. Describe una pregunta y sus posibles respuestas. Por ejemplo: "¿El agente prometió un reembolso antes de revisar la política de reembolsos? Responde sí o no." Selecciona **draft** y verifica que el resultado sea una puntuación de clasificación.
3. [Pruébala](/es/evaluations/test) con sesiones recientes y luego [despliégala](/es/evaluations/deploy). Las nuevas sesiones completadas serán puntuadas; realiza un [relleno retroactivo](/es/evaluations/deploy#score-sessions-you-already-have) si también necesitas el historial.

El ejemplo mostrado es una evaluación de código; una pregunta Jev utiliza el mismo flujo de creación.](/images/dashboard/eval-authoring-draft.png)

El asistente puede elegir entre código, clasificación Jev y un [juez](/es/evaluations/judge). Verifica su elección antes de desplegar. Jev otorga una puntuación sin razonamiento en prosa; elige un juez cuando necesites una explicación. Consulta la [referencia de evaluaciones Jev](/es/reference/jev-evaluations) para ver los tipos de preguntas y los límites de puntuación.

## Leer las puntuaciones

Abre **Observe → Evaluations** para visualizar el resultado por agente y por tiempo. Desde una terminal, el Cloud CLI puede leer los mismos resultados:

```bash
fp evals --since 7d
fp evals --aggregate --since 7d
```

El Cloud CLI lee resultados; la creación y el despliegue ocurren en el panel. Consulta la [referencia del Cloud CLI](/es/reference/cloud-cli#evaluations) para ver los filtros disponibles.
