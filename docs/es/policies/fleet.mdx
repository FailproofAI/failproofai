La cobertura de flota compara lo que Cloud asignó con lo que cada máquina aplicó por última vez.

## Verificar una máquina

```bash
failproofai config --status
failproofai flush --wait --timeout 120
```

Desde Cloud:

```bash
fp fleet list
fp fleet diff
fp fleet show <machine-id>
```

`fp fleet` requiere una sesión con sesión iniciada, no una clave de API.

| Comando | Qué hace |
| --- | --- |
| `fp fleet list` | Lista las máquinas y el estado de despliegue |
| `fp fleet show <machine>` | Muestra el conjunto de políticas de una máquina |
| `fp fleet deploy <machine> --add <ref>` | Añade o actualiza una política |
| `fp fleet deploy <machine> --remove <id>` | Elimina una política |
| `fp fleet deploy <machine> --set <ref>...` | Reemplaza el conjunto completo |
| `fp fleet diff [machine]` | Compara las versiones previstas y aplicadas |
| `fp fleet history <machine>` | Lista las generaciones de despliegue |
| `fp fleet rollback <machine> <generation>` | Restaura una generación |
| `fp fleet rename <machine> "<label>"` | Cambia la etiqueta en Cloud |

<Warning>
  `--set` reemplaza el conjunto completo de políticas. Un `--add <id>` simple aplica la nueva política de inmediato. Usa `--add <id>:observe` para un despliegue en modo sombra.
</Warning>

## Observar y luego aplicar

```bash
fp fleet deploy ci-runner-01 --add prod-guard:observe
fp guardrails summary --since 24h --machine ci-runner-01
fp fleet deploy ci-runner-01 --add prod-guard:enforce
```

El modo observación evalúa la política real y registra las decisiones que no son allow sin bloquear al agente.

## Identidad de la máquina

El ID de máquina es estable e identifica la máquina. La etiqueta es solo para visualización y puede cambiar:

```bash
failproofai config --machine-label checkout-runner-03
fp fleet rename <machine-id> "Checkout runner 03"
```

Cambiar la etiqueta no reconecta ni renueva las claves de la máquina.
