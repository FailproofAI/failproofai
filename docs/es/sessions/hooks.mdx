Un hook es un punto donde un agente solicita a Failproof AI una decisión. El registro de actividad de hooks captura el evento, la política, el resultado y el tiempo de evaluación.

## Investigar la actividad de hooks

<Tabs>
  <Tab title="Panel de control">
    Ve a **Observe → Hooks**. Filtra por entorno, evento, agente o sesión.

    ![La página de Hooks mostrando la latencia agrupada por nombre de hook y evento desencadenante.](/images/dashboard/hooks.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp guardrails summary --since 24h
    fp --json events --full --event-type hook_completed --session-id <session-id> --all --limit 500
    fp list hooks
    ```
  </Tab>
</Tabs>

De forma predeterminada, cada decisión deny e instruct se envía completa. Los allow repetidos se agrupan para reducir el ruido. Establece `collector.hooks_verbosity` en `~/.failproofai/config.json` con el valor `all`, `decisions` o `off`.

<Warning>
  La actividad de hooks demuestra que la evaluación se ejecutó, no que el arnés pudiera bloquear ese evento. Consulta [capacidad de aplicación](/es/reference/harnesses#enforcement-capability). Un par arnés-evento no listado no está verificado.
</Warning>
