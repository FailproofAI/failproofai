Las decisiones de políticas muestran lo que Failproof AI hizo durante la ejecución de un agente.

<Tabs>
  <Tab title="Panel de control">
    Ve a **Observe → policy** para revisar las decisiones, la tasa de bloqueos, las máquinas y las asignaciones desplegadas.

    ![La página de políticas que muestra los totales de decisiones, un filtro de máquina, la actividad de aplicación a lo largo del tiempo y la tabla de asignación de políticas.](/images/dashboard/policy-observe.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp guardrails summary --since 24h
    fp guardrails timeline --since 24h
    failproofai policies
    failproofai config --status
    ```

    `--since` acepta `1h`, `6h`, `24h` o `7d`. Añade `--machine <id>` para centrarte en una máquina específica.
  </Tab>
</Tabs>

## Interpretar un despliegue en modo observación

El modo observación ejecuta la política real y registra cualquier decisión de tipo `deny` o `instruct`. El agente puede continuar de todos modos.

```bash
fp fleet deploy <machine> --add <policy>:observe
fp guardrails summary --since 24h --machine <machine>
fp fleet deploy <machine> --add <policy>:enforce
```

<Warning>
  Un `--add <policy>` sin sufijo aplica la política de forma inmediata cuando no existe un despliegue previo. Añade `:observe` para un despliegue en modo sombra.
</Warning>

Solo se registran las decisiones observadas que no son allow. Un tiempo de espera agotado se registra como allow, ya que eso es también lo que ocurre en el modo de aplicación.

Un deny registrado no es prueba de que el sistema haya detenido la acción. Las denegaciones de llamadas a herramientas están verificadas en los 12 adaptadores compatibles; otros eventos pueden variar. Consulta [capacidad de aplicación](/es/reference/harnesses#enforcement-capability).

## Investigar un resultado inesperado

| Lo que ves | Qué revisar |
| --- | --- |
| Sin decisiones | `failproofai config --status` y si la sesión está pausada |
| Muchas denegaciones sin nombre de política | [Comportamiento ante fallos de política](/es/policies/failure-behavior) |
| Cada acción protegida es denegada | Si el servicio `failproofaid` está en buen estado |
| Un deny que no puedes deshabilitar | `block-failproofai-commands` siempre está activo |
| Sin datos para `--env production` | Las máquinas nuevas usan el entorno `local` |
