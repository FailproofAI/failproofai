title: "Herramientas"
description: "Encuentra herramientas lentas, fallidas o sobreutilizadas en las ejecuciones de agentes."

---

Herramientas muestra qué llaman los agentes, con qué frecuencia fallan las llamadas y qué sesiones se ven afectadas.

Los nombres de las herramientas provienen de cada agente, por lo que la misma capacidad puede tener nombres distintos. Por ejemplo, una llamada de shell puede aparecer como `Bash`, `exec`, `Shell`, `terminal` o `run_command`. Ejecuta `fp list tools` antes de crear un filtro.

<Tabs>
  <Tab title="Dashboard">
    Ve a **Observe → Tools**. Filtra por entorno, herramienta, agente o sesión.

    ![La página de Herramientas mostrando latencia, desglose de éxitos y fallos, y distribución de llamadas a herramientas.](/images/dashboard/tools.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list tools
    fp events --event-type tool_use,tool_result --since 24h
    fp errors --event-type tool_result --since 24h
    fp --json events --full --event-type tool_use,tool_result --session-id <session-id> --all --limit 2000
    ```

    Usa `--full` cuando necesites campos del payload como la duración por llamada.
  </Tab>
</Tabs>

Usa esta página para encontrar fallos repetidos, comparar ejecuciones exitosas y fallidas, o confirmar que una herramienta objetivo de una política realmente se está utilizando.
