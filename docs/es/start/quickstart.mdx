Configura Failproof AI en una máquina y luego trabaja en local o conéctate a Cloud.

Si tu agente se ejecuta en un [entorno compatible](/es/reference/harnesses), sigue estos pasos. Para agentes construidos con LangChain, CrewAI, LlamaIndex, Pydantic AI o tu propio runtime, empieza por [instrumentar tu agente](/es/start/integrations).

## Deja que tu agente guíe la configuración

Instala la habilidad umbrella de Failproof AI en un agente compatible:

```bash
npx skills add FailproofAI/skills
```

Esto instala la habilidad umbrella y sus habilidades especializadas. Usa `--skill
failproofai` si solo quieres la umbrella. Entiende la configuración local y de Cloud,
el estado del daemon, sesiones, auditorías, políticas y resolución de problemas. Guía el trabajo
y enruta las tareas especializadas a la habilidad correcta de Failproof AI; no reemplaza
la instalación mediante CLI que se describe a continuación.

## Configura la máquina

<Steps>
  <Step title="Instala y configura Failproof AI">
    ```bash
    npm install -g failproofai
    failproofai config
    ```

    La configuración instala el servicio en segundo plano y conecta todos los agentes compatibles que encuentra. Es posible que solicite acceso de administrador una vez. Compatible con Linux y macOS.
  </Step>

  <Step title="Elige políticas">
    La configuración no selecciona ningún paquete de políticas por defecto. Agrega el paquete de Failproof AI:

    ```bash
    failproofai policies add FailproofAI/policies
    failproofai policies
    ```

    El segundo comando muestra todas las políticas de esta máquina y su estado de activación. Hasta que añadas un paquete, solo se ejecuta `block-failproofai-commands`.
  </Step>

  <Step title="Verifica el estado de la máquina">
    ```bash
    failproofai config --status
    ```

    Muestra información sobre el servicio, la conexión a Cloud y el estado de pausa.
  </Step>
</Steps>

## Elige entre local o Cloud

<Tabs>
  <Tab title="Trabajar en local">
    No se requiere ninguna cuenta.

    ```bash
    failproofai
    failproofai audit
    ```

    El primer comando abre el panel local en `http://localhost:8020`. El segundo analiza el historial de agentes que ya existe en esta máquina.
  </Tab>

  <Tab title="Conectar a Cloud">
    Crea una clave de máquina en Failproof AI Cloud y luego ejecuta:

    ```bash
    failproofai config --token <machine-key>
    failproofai config --status
    ```

    Cloud recibe las decisiones de políticas y las transcripciones de sesiones. Para enviar solo las decisiones, conéctate primero y luego establece `collector.sessions` en `false` en `~/.failproofai/config.json`; el flag de configuración `--no-transcripts` no aplica ese ajuste. Para shells compartidas y entornos CI, usa `FAILPROOFAI_CLOUD_TOKEN` en lugar de introducir la clave en el historial de comandos.
  </Tab>
</Tabs>

## Verifícalo

Ejecuta uno de tus agentes y pídele que realice una tarea habitual. Luego:

El bloqueo de llamadas a herramientas se ha verificado en los 12 entornos compatibles. La aplicación al finalizar el turno se ha verificado en 8; otros pares entorno-evento pueden ser solo de observación o no estar verificados.

- Abre **Policies → Activity** en el panel local para ver las decisiones de políticas.
- Abre **Observe → Sessions** en Cloud para ver la ejecución completa.
- Ejecuta `failproofai audit` para detectar patrones de riesgo o ineficiencias.

<Warning>
  Tras la configuración, el servicio `failproofaid` actúa como evaluador. Si no puede responder, las acciones protegidas serán denegadas. Ejecuta `failproofai config --status` cuando un agente se detenga de forma inesperada.
</Warning>
