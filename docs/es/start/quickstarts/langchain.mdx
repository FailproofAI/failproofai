Tres pasos para tu primera traza con LangChain o LangGraph. Para streaming, human-in-the-loop, nomenclatura de spans y otras opciones, consulta [la guía completa](/es/start/integrations/langchain).

## Instalar

```bash
pip install 'failproofai-sdk[langgraph]'
```

Para LangChain sin LangGraph, usa `failproofai-sdk[langchain]`.

## Instrumentar

```python
import failproofai_sdk

failproofai_sdk.configure(environment="production")
failproofai_sdk.instrument()

with failproofai_sdk.session():
    graph.invoke({"messages": [HumanMessage("...")]})
```

Sin cambios en los puntos de llamada. `instrument()` registra un tracer que LangChain inyecta en cada gestor de callbacks que construye, de modo que grafos, herramientas y modelos quedan capturados — incluidos los que se encuentran dentro de bibliotecas que no escribiste tú.

## Verificar que llegó

Ejecútalo una vez, luego abre **Observe → Sessions** y selecciona tu entorno. Tu ejecución aparecerá como una traza reconstruida.

Si no llega nada, confirma que la máquina está conectada con `failproofai config --status`.
