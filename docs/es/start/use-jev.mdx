title: "Usar Jev"
description: "Configura evaluaciones Jev para sesiones finalizadas o políticas Jev para la revisión de llamadas a herramientas en tiempo real."

---

Jev ayuda en dos momentos durante la ejecución de un agente: puntuar una sesión finalizada comparándola con respuestas conocidas, o revisar una llamada a herramienta en el contexto de lo que le pediste al agente que hiciera.

<Tabs>
  <Tab title="Evaluaciones Jev">
    Usa una evaluación Jev cuando una sesión finalizada pueda puntuarse comparándola con una pregunta de pocas respuestas conocidas, como «¿El cliente solicitó un reembolso? Responde sí o no.» Te ayuda a encontrar patrones entre sesiones.

    ## Crear una evaluación

    En el panel de control de Cloud, abre **Analyze → eval authoring → new eval**. Introduce una pregunta de respuesta fija, selecciona **draft** y comprueba que se haya elegido una puntuación clasificadora. [Pruébala](/es/evaluations/test) en sesiones reales y luego publícala.

    ![El formulario compartido de creación de evaluaciones donde describes una pregunta, revisas el borrador y lo publicas. Esta captura muestra un borrador de código; usa una pregunta de respuesta fija para Jev.](/images/dashboard/eval-authoring-draft.png)

    ## Leer las puntuaciones

    Tras completarse una nueva sesión, abre **Observe → Evaluations** o usa la CLI de Cloud:

    ```bash
    fp evals --since 7d
    fp evals --aggregate --since 7d
    ```

    La CLI lee las puntuaciones; crear una evaluación Jev actualmente requiere usar el panel de control. Consulta [evaluaciones Jev](/es/evaluations/jev) para ver los tipos de preguntas y ejemplos.
  </Tab>
  <Tab title="Políticas Jev">
    Usa la revisión de políticas Jev cuando una política de coincidencia de cadenas necesite el contexto de tu solicitud para decidir si una llamada a herramienta es segura. Comienza en modo **observe** para que puedas inspeccionar las respuestas de Jev mientras tus políticas instaladas siguen decidiendo cada llamada.

    Las comprobaciones de Jev provienen de un paquete; Failproof AI no incluye ninguno por defecto. Hasta que los instales, Jev no realizará ninguna pregunta, incluso si está configurado:

    ```bash
    failproofai policies add FailproofAI/jev-policies
    ```

    ## Configurar Cloud Jev

    En el panel de control de Cloud, abre **Administration → Keys** y crea una clave con el perfil **machine**. Úsala con `failproofai config` tal como se muestra en la [guía de inicio rápido](/es/start/quickstart). En una máquina sin configuración Jev existente, esto habilita Cloud Jev en modo observe. Verifica la conexión con:

    ```bash
    failproofai jev status
    failproofai jev test
    ```

    ## Usar tu propio endpoint

    En el panel de control local, abre **Settings → Jev**. Elige el proveedor, pega su token, selecciona **observe** y activa Jev.

    ![El panel de configuración Jev local con un proveedor, campo de token y modo observe seleccionado.](/images/dashboard/jev-settings.png)

    O configura y prueba tu endpoint desde una terminal:

    ```bash
    failproofai jev --url https://api.typesafe.ai/v1 --mode observe --key-stdin < ~/typesafe.key
    failproofai jev test
    ```

    Pídele a un agente con hook que use su herramienta de lectura de archivos sobre `README.md`. Confirma que esa llamada a herramienta aparece en la sesión y luego inspecciónala en **Policies → Activity** en el panel de control local. Una vez que los resultados en modo observe se vean correctos, consulta [políticas Jev](/es/policies/jev) para saber cuándo aplicarlas. Para detalles del proveedor y la configuración, consulta la [referencia de integración](/es/reference/jev).
  </Tab>
</Tabs>
