---

Jev ayuda en dos momentos de la ejecución de un agente: puntuar una sesión finalizada comparándola con respuestas conocidas, o revisar una llamada a herramienta en el contexto de lo que le pediste al agente que hiciera.

<Tabs>
  <Tab title="Evaluaciones de Jev">
    Usa una evaluación de Jev cuando una sesión finalizada pueda puntuarse contra una pregunta con algunas respuestas conocidas, como «¿El cliente solicitó un reembolso? Responde sí o no.» Te ayuda a encontrar patrones entre sesiones.

    ## Crear una evaluación

    En el panel de control de Cloud, abre **Analyze → eval authoring → new eval**. Introduce una pregunta de respuesta fija, selecciona **draft** y comprueba que eligió una puntuación de clasificador. [Pruébala](/es/evaluations/test) en sesiones reales y luego despliégala.

    ![El formulario compartido de creación de evaluaciones donde describes una pregunta, revisas el borrador y lo despliegas. Esta captura muestra un borrador de código; usa una pregunta de respuesta fija para Jev.](/images/dashboard/eval-authoring-draft.png)

    ## Leer las puntuaciones

    Después de que una nueva sesión finalice, abre **Observe → Evaluations** o usa la CLI de Cloud:

    ```bash
    fp evals --since 7d
    fp evals --aggregate --since 7d
    ```

    La CLI lee las puntuaciones; crear una evaluación de Jev actualmente requiere el panel de control. Consulta [Evaluaciones de Jev](/es/evaluations/jev) para ver los tipos de preguntas y ejemplos.
  </Tab>
  <Tab title="Políticas de Jev">
    Usa la revisión de políticas de Jev cuando una política de coincidencia de cadenas necesite el contexto de tu solicitud para determinar si una llamada a herramienta es segura. Comienza en modo **observe** para poder inspeccionar las respuestas de Jev mientras tus políticas instaladas siguen decidiendo cada llamada.

    Las comprobaciones de Jev provienen de un paquete; Failproof AI no incluye ninguno. Hasta que los instales, Jev no pregunta nada, incluso cuando está configurado:

    ```bash
    failproofai policies add FailproofAI/jev-policies
    ```

    ## Configurar Cloud Jev

    En el panel de control de Cloud, abre **Administration → Keys** y crea una clave con el ajuste predefinido **machine**. Úsala con `failproofai config` tal como se muestra en la [guía de inicio rápido](/es/start/quickstart). En una máquina sin una configuración de Jev existente, esto habilita Cloud Jev en modo observe. Comprueba la conexión con:

    ```bash
    failproofai jev status
    failproofai jev test
    ```

    ## Usar tu propio endpoint

    En el panel de control local, abre **Settings → Jev**. Elige el proveedor, pega su token, selecciona **observe** y activa Jev.

    ![El panel de configuración de Jev local con un proveedor, campo de token y modo observe seleccionado.](/images/dashboard/jev-settings.png)

    O configura y prueba tu endpoint desde un terminal:

    ```bash
    failproofai jev --url https://api.typesafe.ai/v1 --mode observe --key-stdin < ~/typesafe.key
    failproofai jev test
    ```

    Pídele a un agente conectado que use su herramienta de lectura de archivos en `README.md`. Confirma que esa llamada a herramienta aparece en la sesión, luego inspecciónala en **Policies → Activity** en el panel de control local. Una vez que los resultados de observe se vean correctos, [Políticas de Jev](/es/policies/jev) explica cuándo aplicar el modo enforce. Para más detalles sobre el proveedor y la configuración, consulta la [referencia de integración](/es/reference/jev).
  </Tab>
</Tabs>
