L'administration regroupe les contrôles nécessaires pour faire fonctionner Failproof AI au sein d'une équipe. La plupart des utilisateurs peuvent rester dans Sessions, Audits et Politiques ; les administrateurs utilisent cette section pour gérer les accès et les périmètres opérationnels.

<Tabs>
  <Tab title="Dashboard">
    Utilisez la section **Admin** de la barre latérale Cloud pour accéder à l'**éditeur de politiques**, à l'**application des règles**, à l'**utilisation**, aux **clés**, aux **utilisateurs** et aux **paramètres**. Un élément verrouillé indique que votre compte ne dispose pas de l'autorisation de lecture correspondante.

    ![La section Admin de la barre latérale Cloud avec l'éditeur de politiques, l'application des règles, l'utilisation, les clés, les utilisateurs et les paramètres.](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    Placez les options globales avant la commande, par exemple `fp --org reliability-team --json usage`.
  </Tab>
</Tabs>
