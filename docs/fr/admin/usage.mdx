La section Utilisation affiche la consommation de l'organisation actuelle et ses fenêtres de facturation. Utilisez-la pour comprendre comment le déploiement en production, le volume de transcripts, les évaluations et la cadence des audits influent sur votre plan.

## Consulter l'utilisation

<Tabs>
  <Tab title="Tableau de bord">
    1. Accédez à **Administration → Utilisation**.
    2. Confirmez l'organisation et la fenêtre de mesure.
    3. Examinez l'ingestion, les sessions, les évaluations, les métriques, les audits, les résultats, les alertes, les utilisateurs et les clés.
    4. Comparez les audits démarrés et terminés si la consommation d'audit semble inattendue.

    ![La page Utilisation affichant la fenêtre de mesure, les événements capturés, les pipelines d'évaluation et d'audit, les ressources de l'espace de travail, les membres et les clés API.](/images/dashboard/usage-overview.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp usage
    fp --json usage
    fp --org reliability-team --json usage
    ```
  </Tab>
</Tabs>

## Analyser une variation

1. Confirmez l'organisation active et la fenêtre en cours.
2. Comparez la hausse avec le volume de sessions par environnement.
3. Vérifiez si une nouvelle intégration a commencé à envoyer des transcripts.
4. Examinez les modifications de cadence des évaluateurs et des audits.
5. Comparez avec les limites du plan tarifaire actuel.

Le CLI retourne le même résumé pour les scripts.
