Tout votre déploiement Failproof AI Observability, accessible en une seule commande. Vérifiez la production, créez une clé API ou acquittez un incident sans quitter votre terminal, puis scriptez le tout dans une CI, ou laissez un agent de code le faire pour vous en langage naturel.

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*Le CLI `agenteye` communique avec votre tableau de bord. C'est un outil distinct du collecteur, qui achemine les événements vers le serveur.*

## Tout votre déploiement, en une seule commande

Fini les changements d'onglets pour répondre à une simple question. Le CLI `agenteye` lit vos données et administre votre organisation depuis un seul binaire, de sorte qu'une vérification qui nécessitait autrefois de naviguer dans le tableau de bord ne prend plus qu'une ligne que vous pouvez relancer, aliaser ou coller dans un runbook. Vous disposez de quatre surfaces :

- **Lecture de vos données :** `sessions`, `events`, `evals` et `errors`, filtrés par période, agent et environnement.
- **Gestion de votre organisation :** `keys`, `users`, `settings`, `alerts` et `incidents`.
- **Analyses :** requêtes SQL sauvegardées et un runner `query` ad hoc sur vos données d'événements.
- **Interrogation de l'assistant :** `agent ask` accède au même analyste en lecture seule que celui avec lequel vous discutez dans le tableau de bord.

Installez-le une fois avec `pipx`, connectez-vous à l'aide d'un code à 6 chiffres reçu par e-mail, et vous êtes prêt. La session dure environ une journée ; relancez `agenteye login` à son expiration. Utilisez-le pour inspecter la production, provisionner une clé ou trier un incident en cours, tout cela sans ouvrir un navigateur :

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

Une habitude à retenir : les options globales comme `--json` se placent avant la commande. `agenteye --json sessions` est correct ; `agenteye sessions --json` ne l'est pas.

## Scriptez-le, intégrez-le à votre CI

Chaque commande accepte `--json`, ce qui change tout. Le JSON propre est envoyé sur stdout tandis que les messages d'état et avertissements lisibles par l'humain vont sur stderr, de sorte qu'une capture `--json` se pipe directement dans `jq` sans aucune ligne parasite à éliminer. C'est ce qui rend le CLI aussi efficace pour vous à un terminal que pour un agent de code qui analyse des sorties :

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

Il est conçu pour fonctionner de manière non supervisée. Les invites de confirmation sont automatiquement ignorées lorsqu'aucun terminal n'est connecté, ce qui évite tout blocage dans un pipeline. Chaque commande retourne également un code de sortie explicite : `0` pour le succès, `4` si vous n'êtes pas connecté, `5` s'il manque une permission (le message la nomme, par exemple `alerts:write`), `3` si le tableau de bord est injoignable. Un script peut bifurquer sur un `4` pour se réauthentifier, ou sur un `5` pour indiquer exactement ce qu'il faut demander à un administrateur, au lieu d'échouer silencieusement.

## Laissez un agent de code le piloter en langage naturel

Mieux encore, vous ne devriez pas avoir à mémoriser ces options. La **compétence CLI** est un petit dossier Agent Skill nommé `agenteye-cli` qui apprend à un agent de code comme Claude Code ou Codex à piloter le CLI à partir de demandes en langage naturel. Demandez « est-ce que quelque chose est cassé aujourd'hui ? » et l'agent choisit la commande, l'exécute en votre nom et répond en prose.

Pour Claude Code, déposez le dossier `agenteye-cli` dans `~/.claude/skills/` et il est automatiquement découvert. Failproof AI Observability fournit le dossier ; il n'y a rien de plus à installer, car il pilote simplement le CLI que vous avez déjà installé. Connectez-vous vous-même au préalable : la compétence ne peut pas effectuer la connexion par code e-mail à votre place.

Puisque l'agent exécute le CLI en votre nom, il peut tout faire que votre connexion permet, en lecture comme en écriture : créer des clés, modifier des paramètres, résoudre des incidents. L'invite de confirmation du CLI ne se déclenche pas pour un agent, c'est pourquoi la compétence est conçue pour indiquer la commande exacte et attendre votre accord avant tout changement. Vous êtes l'étape de confirmation.

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

Les lectures restent instantanées, et chaque écriture s'interrompt pour vous :

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
