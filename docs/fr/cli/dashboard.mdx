title: Voir les sessions
description: "Lancer le tableau de bord pour parcourir les sessions d'agents et gérer les politiques"
---

```bash
failproofai
```

Lance le tableau de bord web sur `http://localhost:8020`.

## Options

The dashboard takes no flags — `failproofai` rejects any it does not recognize. The port is fixed at `8020`.

Pour pointer le tableau de bord vers un dossier de projet Claude non par défaut, définissez la variable d'environnement `CLAUDE_PROJECTS_PATH` au lancement.

## Exemples

```bash
failproofai

# Utiliser un chemin de projets Claude personnalisé via une variable d'environnement
CLAUDE_PROJECTS_PATH=~/my-claude-projects failproofai
```
