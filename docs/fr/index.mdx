Failproof AI aide toute personne exécutant des agents à comprendre ce qui s'est passé, à identifier les défaillances et à les empêcher de se reproduire.

Il fonctionne avec 12 environnements d'agents courants, notamment Claude Code, Codex, Hermes, OpenClaw et Goose. Les agents construits avec LangChain, CrewAI, LlamaIndex, Pydantic AI ou votre propre runtime peuvent envoyer des rapports via le [SDK Python](/fr/reference/custom-agents).

## Démarrer en local ou se connecter au Cloud

<Columns cols={2}>
  <Card title="En local, sans compte" icon="laptop" href="/fr/audits/local-audit">
    Ouvrez le tableau de bord sur `localhost:8020` et exécutez `failproofai audit`. L'historique de vos agents reste sur cette machine.
  </Card>
  <Card title="Failproof AI Cloud" icon="cloud" href="/fr/start/setup">
    Consultez les sessions sur plusieurs machines et gérez les politiques pour votre équipe.
  </Card>
</Columns>

La configuration ne sélectionne délibérément aucun pack de politiques. Ajoutez le nôtre après la configuration :

```bash
failproofai policies add FailproofAI/policies
```

En attendant, seul `block-failproofai-commands` est actif. Il empêche un agent de désactiver Failproof AI.

> **Session → Audit → Constat → Incident → Politique**
> Voyez ce qui s'est passé, identifiez la défaillance, prenez en charge la réponse, puis prévenez sa répétition.

<Note>
  La configuration est compatible avec Linux et macOS. Consultez les [environnements pris en charge](/fr/reference/harnesses) pour savoir ce que chaque environnement d'agent peut observer ou bloquer.
</Note>
