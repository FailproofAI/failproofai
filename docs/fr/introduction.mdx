[![npm weekly downloads](https://img.shields.io/npm/dw/failproofai?style=flat-square&color=2ea44f)](https://www.npmjs.com/package/failproofai)

Hooks et politiques pour la **gestion des défaillances IA**, la **récupération d'erreurs** et la **fiabilité des LLM**. Gardez vos agents IA fiables et en fonctionnement autonome avec **Claude Code**, **OpenAI Codex**, **GitHub Copilot**, **Cursor Agent**, **OpenCode**, **Pi**, **Hermes**, **OpenClaw**, **Factory Droid**, **Devin CLI**, **Antigravity CLI** et l'**Agents SDK**.

Les agents IA échouent de manière prévisible. Ils exécutent des commandes destructrices, divulguent des secrets, dérivent hors de leur tâche, se retrouvent coincés dans des boucles ou poussent directement vers la branche principale. Sans surveillance, de petites défaillances se transforment en pannes en cascade, en credentials compromis et en travail perdu.

FailproofAI résout ce problème grâce aux **politiques**. Ces règles s'accrochent à chaque appel d'outil de l'agent pour **détecter les défaillances**, **les atténuer** (bloquer, instruire, assainir) et **vous alerter** lorsqu'une situation nécessite votre attention. Un tableau de bord local vous permet de consulter chaque appel d'outil, chaque défaillance d'agent et chaque action de récupération après coup.

Les transcriptions et l'évaluation des politiques restent sur votre machine. Les données ne sont transmises que lorsque vous utilisez explicitement une fonctionnalité en ligne, telle que les rappels d'audit authentifiés ou les invitations.

## Démarrage rapide

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # enable policies (or skip — `failproofai` will offer to set them up on first run)
failproofai                      # launch the dashboard
```

Consultez le guide [Démarrage](/fr/getting-started) pour un parcours complet.
