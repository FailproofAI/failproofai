Un pack de politiques est un ensemble versionné de politiques publié sous forme de release publique GitHub. Le package ne fournit aucun pack par défaut ; installez le nôtre comme n'importe quel autre :

```bash
failproofai policies show FailproofAI/policies
failproofai policies add FailproofAI/policies
```

`show` lit le manifeste sans exécuter le code du pack.

## Choisir ce qu'il faut installer

```bash
failproofai policies add owner/repo --policy block-refunds
failproofai policies add owner/repo --category billing,git
failproofai policies add owner/repo --all
```

Sans sélection explicite, le pack applique les valeurs par défaut définies par son éditeur. Ajouter à nouveau une release plus récente conserve votre sélection existante.

Tout ce qui contient une barre oblique est une source de pack. Tout ce qui n'en contient pas est un nom de politique.

## Épingler une release

| Source | Résultat |
| --- | --- |
| `owner/repo` | Release la plus récente, épinglée après résolution |
| `owner/repo@a1b2c3d4e5f6` | Release exacte basée sur le commit |
| `owner/repo@v2.1.0` | Release exacte nommée |
| URL de release GitHub | La release correspondant à cette URL |

Un pack utilise normalement le SHA de commit à 12 caractères à partir duquel il a été construit. Utilisez `failproofai policies show owner/repo --releases` pour voir l'ordre des releases.

## Gérer les packs installés

```bash
failproofai policies
failproofai policies remove block-refunds
failproofai policies add block-refunds
failproofai policies remove owner/repo
```

Si deux packs installés contiennent le même nom de politique, la CLI refuse le nom ambigu seul. Sélectionnez la politique via l'un des packs ou désinstallez l'autre pack.

## Sécurité et disponibilité

Chaque release contient un manifeste, du code de politique intégré et des sommes de contrôle. Failproof AI vérifie le condensé enregistré avant de le charger. Les sommes de contrôle garantissent que les octets correspondent à la release ; elles ne prouvent pas l'identité de l'éditeur.

Un pack sélectionné qui ne peut pas se charger échoue de manière fermée pour les événements qu'il a déclarés. Voir [comportement en cas d'échec de politique](/fr/policies/failure-behavior).

| Variable | Effet |
| --- | --- |
| `FAILPROOFAI_NO_DOWNLOAD=1` | Refuse les nouveaux téléchargements ; les packs installés continuent de fonctionner |
| `FAILPROOFAI_PACK_BASE_URL` | Utilise un miroir |
| `FAILPROOFAI_PACK_DIR` | Déplace le répertoire de stockage des packs |

Parcourez les packs dans le [Policy Hub](https://befailproof.ai/policy-hub/) ou [publiez le vôtre](/fr/policies/publish-a-pack).
