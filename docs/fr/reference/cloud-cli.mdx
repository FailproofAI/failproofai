Utilisez `fp` pour inspecter la télémétrie Cloud et gérer les audits, les résultats, les incidents, les alertes, les clés, les utilisateurs, les requêtes et les paramètres. Utilisez [`failproofai`](/fr/reference/failproof-cli) pour les hooks locaux, les politiques, la capture et l'enrôlement des machines.

Installez la version publiée du Cloud CLI en tant qu'outil isolé :

```bash
uv tool install fp-cli
fp version
```

## Connexion

```bash
fp login
fp whoami
```

## Syntaxe

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

Les options globales doivent être placées avant la commande :

```bash
fp --json sessions --since 24h
```

Exécutez `fp COMMAND --help` ou `fp COMMAND SUBCOMMAND --help` pour obtenir l'aide dans le terminal.

## Commandes CLI

### Événements

```text
fp events [OPTIONS]
```

Liste les événements individuels des agents. Le flux léger par défaut exclut les charges utiles brutes ; n'utilisez `--full` que pour une investigation délimitée.

| Option | Description |
| --- | --- |
| `--limit`, `-n <n>` | Nombre total maximum de lignes. Par défaut : `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h` ou `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | Plage ISO 8601 UTC ; remplace `--since`. |
| `--env <value>` | Filtre d'environnement ; répétable ou séparé par des virgules. |
| `--event-type <value>` | Filtre de type d'événement ; répétable ou séparé par des virgules. |
| `--agent-id <value>` | Filtre d'agent ; répétable ou séparé par des virgules. |
| `--session-id <value>` | Filtre de session ; répétable ou séparé par des virgules. |
| `--search <text>` | Recherche dans le texte des charges utiles ; répétable, avec correspondance sur n'importe quel terme. |
| `--order asc\|desc` | Ordre chronologique. Par défaut : plus récent en premier. |
| `--all` | Pagination automatique jusqu'à `--limit`. |
| `--cursor <token>` | Reprendre depuis un curseur opaque. |
| `--page-size <n>` | Lignes par requête avec `--all` ; maximum `200`. |
| `--full` | Inclure les charges utiles brutes via le point de terminaison d'événements plus lourd. |
| `--fields <csv>` | Retourner uniquement les champs sélectionnés ; demander `payload` active le mode complet. |

```bash
fp events --session-id <session-id> --order asc --all
fp --json events --full --session-id <session-id> --all
```

### Clés API

| Commande | Objectif | Options |
| --- | --- | --- |
| `fp keys list` | Lister les clés de l'organisation. | `--show-id` ; `--fields <csv>` |
| `fp keys show NAME` | Afficher une clé et ses autorisations. | — |
| `fp keys create NAME` | Créer une clé et révéler son secret une seule fois. | `--permission-set` ; `--add` ; `--remove` |
| `fp keys update NAME` | Remplacer l'ensemble de permissions ou ajuster les autorisations. | `--permission-set` ; `--add` ; `--remove` ; `--yes`, `-y` |
| `fp keys regenerate NAME` | Faire tourner le secret et révéler le remplacement une seule fois. | `--yes`, `-y` |

Les jetons de permission utilisent le format `resource:action`, par exemple `events:add`. Répétez `--add`, séparez les jetons par des virgules, ou utilisez des actions pointées telles que `events:read.add`.

#### Options de création d'audit

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| Option | Description |
| --- | --- |
| `--file <path>` | Baser la définition sur du JSON, ou utiliser `-` pour stdin. Les options explicites remplacent les valeurs du fichier. |
| `--description <text>` | Énoncer la question d'échec ou l'objectif. |
| `--enabled` / `--disabled` | Démarrer la planification activée ou désactivée. Par défaut : activée. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. Par défaut : `86400`. |
| `--schedule-anchor <timestamp>` | Phase UTC fixe au format ISO 8601. Par défaut : prochain 09:00 UTC. |
| `--window-mode since_last\|fixed` | Continuer après la dernière fenêtre entièrement analysée ou inspecter répétitivement une fenêtre glissante. Par défaut : `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. Par défaut : `604800`. |
| `--scope '<json>'` | Filtrer par `environments`, `agent_ids` ou autres champs de portée pris en charge. |
| `--ignore-error-type <type>` | Exclure des types d'erreurs ; répétable ou séparé par des virgules. |
| `--llm` / `--no-llm` | Activer ou désactiver l'analyse agentique. Par défaut : activée. |
| `--top-k <n>` | Conserver `1`–`500` résultats. Par défaut : `50`. |
| `--sensitivity low\|medium\|high` | Définir la sensibilité du rapport. Par défaut : `medium`. |
| `--channels '<json>'` | Tableau de canaux de notification. |
| `--text <brief>` | Résumé en ligne, maximum 8 192 caractères. |
| `--text-file <path>` | Lire le résumé depuis un fichier ; mutuellement exclusif avec `--text`. |
| `--url <https-url>` | Ajouter une référence HTTPS publique ; répétable jusqu'à cinq fois. |

Incluez le contexte lors de la création si la première exécution en a besoin. La création valide la définition et le contexte ensemble avant le début de l'exécution mise en file d'attente.

<Note>
  `fp audits run` est asynchrone. Interrogez `fp audits runs NAME` jusqu'à ce que la dernière exécution réussisse ou échoue avant de lire ses résultats.
</Note>

## Options globales

| Option | Description |
| --- | --- |
| `--json` | Émettre du JSON lisible par machine. |
| `--base-url <url>` | Utiliser un tableau de bord auto-hébergé ou de développement. |
| `--org <slug>` | Sélectionner une organisation pour cette invocation. |
| `--token <token>` | Remplacer le jeton de session utilisateur enregistré. |
| `--api-key <key>` | Authentifier l'automatisation avec une clé API ; jamais enregistrée. |
| `--timeout <seconds>` | Délai d'expiration HTTP ; doit être positif. Par défaut : `30`. |
| `--quiet`, `-q` | Supprimer la sortie d'état sur stderr. |
| `--no-color` | Désactiver la sortie colorée. |
| `--insecure` / `--secure` | Désactiver ou restaurer la vérification du certificat TLS. |
| `--version` | Afficher la version et quitter. |
| `--help`, `-h` | Afficher l'aide. |

`--api-key` est destiné à l'automatisation. Les commandes de connexion, de changement d'organisation et d'assistant nécessitent une session utilisateur.

## Variables d'environnement

| Variable | Équivalent ou objectif |
| --- | --- |
| `AGENTEYE_DASHBOARD_URL` | `--base-url` |

| `AGENTEYE_INSECURE` | `--insecure` |

Les options explicites remplacent les variables d'environnement, qui remplacent la configuration enregistrée. En mode clé API, sélectionnez le tenant explicitement avec `--org` ou `AGENTEYE_ORG`.

<Warning>
  Les commandes qui suppriment, révoquent, masquent, résolvent ou remplacent une configuration demandent une confirmation par défaut. N'utilisez `--yes` qu'après avoir vérifié l'organisation active et la cible.
</Warning>
