Demandez au Failproof Assistant d'effectuer n'importe quelle opération dans Failproof AI en langage naturel. Il peut analyser les sessions et les échecs, exécuter des requêtes, créer des tableaux de bord, examiner les évaluations et les alertes, et vous aider à concevoir et lancer des audits sans avoir à traduire la tâche en écrans produit ou en commandes CLI.

```text
Why did production checkout agents regress this week?
Build a dashboard for tool failures, latency, and evaluation scores.
Create an audit that finds agents retrying the same failed action without changing approach.
Show me the sessions behind the most common audit finding.
```

L'assistant travaille avec les données et les permissions disponibles dans l'organisation active. Examinez ses preuves et les modifications proposées avant d'appliquer des actions qui affectent d'autres utilisateurs ou agents.

## Interroger l'assistant

<Tabs>
  <Tab title="Tableau de bord">
    1. Sélectionnez **Ouvrir le chat agent** et décrivez ce que vous souhaitez comprendre, créer ou exploiter.
    2. Examinez les appels d'outils, les tableaux et les résultats de requêtes de l'assistant pendant son travail.
    3. Ouvrez la session, l'alerte ou la requête citée pour vérifier le résultat par rapport aux données sources.
    4. Démarrez un nouveau chat pour une investigation différente, ou utilisez l'historique des chats pour poursuivre la même ligne d'analyse.

    ![L'assistant Cloud répondant à une question d'observabilité avec une analyse et des requêtes à l'appui.](/images/dashboard/assistant.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp agent health
    fp agent models
    fp agent ask "Which production checkout agents had the most tool errors in the last 24 hours?"
    fp agent chats
    fp agent show <chat-id>
    fp agent ask "Open representative sessions" --chat <chat-id>
    ```

    Utilisez `fp agent rename <chat-id> --title <title>` pour garder une investigation facilement identifiable et `fp agent delete <chat-id>` pour la supprimer.
  </Tab>
</Tabs>

## Travailler efficacement avec l'assistant

- Commencez par lui donner un objectif ; précisez un environnement, un flux de travail ou une plage temporelle lorsque ces limites sont importantes.
- Considérez le SQL généré et les résumés comme des outils d'investigation, et non comme des preuves définitives.
- Ouvrez des sessions représentatives avant de créer un audit, un problème, une alerte ou une politique.
- Rendez explicites les filtres d'organisation, d'environnement et de temps.
- Sauvegardez le SQL utile en tant que requête afin qu'un autre opérateur puisse reproduire le résultat.

<Warning>
  L'assistant ne peut lire que ce à quoi votre utilisateur actuel a accès. N'élargissez pas les permissions pour faire fonctionner une requête ; demandez plutôt à un opérateur autorisé de mener l'investigation.
</Warning>
