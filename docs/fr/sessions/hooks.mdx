---
title: "Hooks"
description: "Mesurez l'activité des hooks, les déclencheurs et la latence indépendamment des résultats de politique."
icon: "webhook"
---

Hooks affiche le moment où les hooks du cycle de vie des agents s'exécutent et le temps qu'ils prennent. Les décisions de politique sont une vue distincte.

<Tabs>
  <Tab title="Tableau de bord">
    1. Accédez à **Observer → Hooks**.
    2. Filtrez par environnement, nom de hook, événement déclencheur, agent ou ID de session.
    3. Examinez la latence des hooks et leur distribution.
    4. Sélectionnez un point du graphique ou un segment de hook pour ouvrir les événements sous-jacents.

    ![La page Hooks affichant la latence regroupée par nom de hook et événement déclencheur.](/images/dashboard/hooks.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list hooks
    fp events --event-type hook_triggered,hook_completed --env production --since 24h
    fp events --search "PreToolUse" --since 24h
    ```
  </Tab>
</Tabs>
