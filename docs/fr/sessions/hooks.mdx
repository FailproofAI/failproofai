Un hook est un point où un agent interroge Failproof AI pour obtenir une décision. L'activité des hooks enregistre l'événement, la politique, le résultat et le temps d'évaluation.

## Analyser l'activité des hooks

<Tabs>
  <Tab title="Tableau de bord">
    Accédez à **Observe → Hooks**. Filtrez par environnement, événement, agent ou session.

    ![La page Hooks affichant la latence regroupée par nom de hook et événement déclencheur.](/images/dashboard/hooks.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp guardrails summary --since 24h
    fp --json events --full --event-type hook_completed --session-id <session-id> --all --limit 500
    fp list hooks
    ```
  </Tab>
</Tabs>

Par défaut, chaque décision `deny` et `instruct` est transmise intégralement. Les autorisations répétées sont regroupées pour réduire le bruit. Définissez `collector.hooks_verbosity` dans `~/.failproofai/config.json` sur `all`, `decisions` ou `off`.

<Warning>
  L'activité des hooks prouve que l'évaluation a été exécutée, et non que le harnais était en mesure de bloquer cet événement. Consultez [la capacité d'application](/fr/reference/harnesses#enforcement-capability). Toute paire harnais-événement non répertoriée est non vérifiée.
</Warning>
