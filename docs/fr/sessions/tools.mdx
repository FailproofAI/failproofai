La page Outils affiche ce que les agents appellent, la fréquence des échecs et les sessions concernées.

Les noms des outils proviennent de chaque harnais d'agent, de sorte qu'une même fonctionnalité peut porter des noms différents. Par exemple, un appel shell peut apparaître sous la forme `Bash`, `exec`, `Shell`, `terminal` ou `run_command`. Exécutez `fp list tools` avant de construire un filtre.

<Tabs>
  <Tab title="Tableau de bord">
    Accédez à **Observer → Outils**. Filtrez par environnement, outil, agent ou session.

    ![La page Outils affichant la latence, les répartitions des succès et des échecs, ainsi que la distribution des appels d'outils.](/images/dashboard/tools.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list tools
    fp events --event-type tool_use,tool_result --since 24h
    fp errors --event-type tool_result --since 24h
    fp --json events --full --event-type tool_use,tool_result --session-id <session-id> --all --limit 2000
    ```

    Utilisez `--full` lorsque vous avez besoin de champs de charge utile tels que la durée par appel.
  </Tab>
</Tabs>

Utilisez cette page pour identifier les échecs répétés, comparer les exécutions réussies et défaillantes, ou confirmer qu'un outil ciblé par une politique est effectivement utilisé.
