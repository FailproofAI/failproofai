## Trois lignes, quel que soit le framework

<CodeGroup>
```bash LangGraph
pip install 'failproofai-sdk[langgraph]'
```

```bash CrewAI
pip install 'failproofai-sdk[crewai]'
```

```bash LlamaIndex
pip install 'failproofai-sdk[llamaindex]'
```

```bash Pydantic AI
pip install 'failproofai-sdk[pydantic-ai]'
```

```bash Custom agents
pip install failproofai-sdk
```
</CodeGroup>

```python
import failproofai_sdk

failproofai_sdk.configure(environment="production")
failproofai_sdk.instrument()          # détecte les frameworks que vous avez importés

with failproofai_sdk.session():
    ...                               # votre appel d'agent existant, inchangé
```

Pas de décorateurs sur vos fonctions, pas de callback passé à vos appels, pas d'identifiants propagés dans votre code. Seul l'appel à l'intérieur de la session diffère :

<Tabs>
  <Tab title="LangGraph">
    ```python
    graph.invoke({"messages": [HumanMessage("...")]})
    ```
  </Tab>
  <Tab title="CrewAI">
    ```python
    Crew(agents=[analyst, writer], tasks=[gather, summarise]).kickoff()
    ```
  </Tab>
  <Tab title="LlamaIndex">
    ```python
    await agent.run("...")        # sous `async with failproofai_sdk.session():`
    ```
  </Tab>
  <Tab title="Pydantic AI">
    ```python
    agent.run_sync("...")
    ```
  </Tab>
  <Tab title="Custom agents">
    ```python
    with failproofai_sdk.agent("planner"):
        with failproofai_sdk.tool_call("search", input={"q": q}) as t:
            t.output = search(q)
    ```
  </Tab>
</Tabs>

L'installation supplémentaire ajoute le **framework**. Chaque adaptateur est inclus dans le wheel de base, donc un projet qui dispose déjà de son framework n'a besoin d'aucune installation supplémentaire.

## Vérifier que les données sont bien reçues

Exécutez une session instrumentée, puis ouvrez **Observe → Sessions** et sélectionnez votre environnement. L'exécution apparaît sous forme de trace reconstruite.

Si rien n'arrive, vérifiez que la machine est connectée avec `failproofai config --status`. Consultez [Configurer la capture](/fr/start/setup).

<Warning>
  Ne vérifiez pas le répertoire spool pour confirmer la livraison. Le daemon Failproof collecte et supprime chaque lot en quelques millisecondes, donc lire ce répertoire entre en compétition avec le collecteur et affiche bien moins d'événements que ce qui a été émis.
</Warning>
