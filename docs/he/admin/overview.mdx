ניהול מכיל את הפקדים הדרושים להפעיל את Failproof AI בכל הצוות. רוב הקוראים יכולים להישאר ב-Sessions, Audits ו-Policies; מנהלי מערכת משתמשים בסעיף זה לניהול גישה וגבולות הפעלה.

<Tabs>
  <Tab title="Dashboard">
    השתמש בסעיף **Admin** בסרגל הצד של Cloud עבור **policy editor**, **enforcement**, **usage**, **keys**, **users** ו-**settings**. פריט נעול מציין שלחשבון שלך חסרה הרשאת קריאה.

    ![סעיף Admin בסרגל הצד של Cloud עם policy editor, enforcement, usage, keys, users ו-settings.](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    הצב אפשרויות גלובליות לפני הפקודה, לדוגמה `fp --org reliability-team --json usage`.
  </Tab>
</Tabs>
