ניהול מכיל את הפקדים הדרושים להפעיל את Failproof AI בצוות. רוב הקוראים יכולים להישאר ב-Sessions, Audits ו-Policies; מנהלים משתמשים בקטע זה כדי לנהל גישה וגבולות הפעלה.

<Tabs>
  <Tab title="Dashboard">
    השתמש בסעיף **Admin** בסרגל הצד של Cloud עבור **עורך מדיניויות**, **אכיפה**, **שימוש**, **מפתחות**, **משתמשים** ו**הגדרות**. פריט נעול מציין שלחשבון שלך חסרה הרשאת קריאה שלו.

    ![סעיף Admin בסרגל הצד של Cloud עם עורך מדיניויות, אכיפה, שימוש, מפתחות, משתמשים והגדרות.](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    הצב אפשרויות גלובליות לפני הפקודה, לדוגמה `fp --org reliability-team --json usage`.
  </Tab>
</Tabs>
