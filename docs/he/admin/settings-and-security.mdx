הגדרות הארגון משפיעות על כולם בארגון Cloud זה. שנה אותן מ-**Admin → settings** או עם `fp settings`.

```bash
fp settings list
fp settings set <key> <value>
```

## טיפול בנתונים

מכונה מחוברת שולחת החלטות מדיניות ותמלילי הפעלה מלאים כברירת מחדל. כדי לשלוח החלטות בלבד, הגדר את `collector.sessions` ל-`false` ב-`~/.failproofai/config.json` של המכונה לאחר החיבור. דגל ההגדרה `--no-transcripts` הנוכחי אינו חל על הגדרה זו.

בעיות נמחקות במכונה לפני ההעלאה, אך ביטול הגילוי הוא רצפת בטיחות, לא תחליף לבקרת גישה.

השימוש המקומי בלבד אינו דורש חשבון. היסטוריית ההפעלה וביקורות נשמרות במכונה, למעט ביקורות מקומיות מתוזמנות המשלחות זהות מכונה וסיכום מוגבל לאחר הסכמתך. ניתן להשבית טלמטריה CLI אנונימית עם `FAILPROOFAI_TELEMETRY_DISABLED=1`.

## עיונות

אסימוני מכונה מאוחסנים תחת `~/.failproofai/` עם הרשאות של בעלים בלבד. הם לא נכתבים בהגדרת השירות.

השתמש במפתחות נפרדים לאנשים, אוטומציה ומכונות. תן לכל אחד רק את ההרשאות שהוא זקוק להן, סובב אותו כאשר הבעלות משתנה, והשבת אותו כאשר המכונה או זרימת העבודה פורשות.

## רשימת בדיקה

- דרוש את ההרשאות השימושיות הצרות ביותר.
- הגדר את `collector.sessions` ל-`false` כאשר תוכן מלא אינו נחוץ.
- בדוק מי יכול להפריש מדיניות אכיפה.
- בדוק מדיניות במצב התבוננות לפני אכיפה.
- שמור על תוויות מכונה ברורות ומזהים מכונה יציבים.
- הרץ `failproofai config --status` לאחר שינוי הגדרות החיבור.

ראה [מפתחות והרשאות](/he/admin/keys-and-permissions) בקטלוג ההרשאות.
