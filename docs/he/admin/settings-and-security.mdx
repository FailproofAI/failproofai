השתמש בהגדרות עבור ערכים תפעוליים ספציפיים לפריסה וחסימות הקשר של מודלים. בדוק את סכמת ההגדרות לפני שינוי ערך דרך ה-API או ה-CLI.

## שינוי הגדרה ארגונית

<Tabs>
  <Tab title="Dashboard">
    1. עבור אל **Administration → Settings**, מצא את קבוצת ההגדרות, וקרא את התיאור והמקור הנוכחי שלה.
    2. שנה את הערך והשמור.
    3. עבור חסימות קשר של מודלים, הוסף או עדכן את החסימה של המודל ואשר את המגבלה האפקטיבית.
    4. בדוק שוב הפעלות מטריקות התלויות בערך ששונה.

    ![דף ההגדרות המציג אימות ארגוני והגדרות תפעוליות.](/images/dashboard/settings.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp settings list
    fp settings schema
    fp settings set <key> --value <scalar>
    fp settings set alerts.email_default_recipients \
      --json-value '["oncall@example.com"]'
    ```

    הרץ `fp settings set --help` לקבלת סוג הערך וסימני אישור המשמשים את ה-CLI המותקן.
  </Tab>
</Tabs>

## בחירות טיפול בנתונים

חיבור ה-CLI של Failproof AI שולח תמלילים כברירת מחדל מכיוון שהעקבות והביקורות תלויים בתוכנם. השתמש ב-`--no-transcripts` כאשר הנושאים, תכני קבצים או קלט מטרמינל חייבים להישאר מקומיים; פעילות ווק והחלטות מדיניות עדיין יכולות להיות מדווחות.

כללי הנכנסים מקומיים מאוחסנים בנפרד מהגדרות daemon שאינן סודיות ונכתבים עם הרשאות מגבילות. API keys עדיין צריכים להיות מנוהלים כסודות ייצור.

## ייחוס הגדרה ארגונית

כל ההגדרות הניתנות לעריכה דרך הדשבורד הן בתחום הארגוני. התנהגות בכל הפריסה נשארת תצורה של סביבת השרת.

| מפתח | ברירת מחדל | מטרה |
| --- | --- | --- |
| `allowed_sign_ins` | `[]` | הגבל חברים קיימים לדוא״ל מדויק או `*@domain`; רשימה ריקה פירושה ללא הגבלה נוספת. |
| `session_ttl_secs` | `86400` | משך חיי הפעלת הדשבורד; הטווח המקובל הוא 60 שניות עד 30 ימים. |
| `otp_ttl_secs` | `600` | משך חיי OTP וקישור קסום; הטווח המקובל הוא 60–1800 שניות. |
| `alerts.email_default_recipients` | `[]` | נמענים ברירת מחדל כאשר ערוץ דוא״ל של התראה לא עוקף אותם. |
| `alerts.slack_default_webhook` | ריק | URL של Slack incoming-webhook ברירת מחדל. |
| `alerts.webhook_default_url` | ריק | URL של webhook JSON גנרי ברירת מחדל. |
| `alerts.webhook_signing_secret` | ריק | מפתח HMAC-SHA256 המשמש לכותרת `X-AgentEye-Signature`; הקריאות מוסתרות. |
| `alerts.enabled_channels` | דוא״ל, Slack, webhook | סוגי ערוצים בכל הארגון שחוקי התראה עשויים לשדר. |
| `default_user_permissions` | `standard` | קבוצת הרשאות בשם שנבחרה מראש להזמנות חדשות. |

`allowed_sign_ins` הוא מסנן, לא הענקה: אדם חייב להיות כבר חבר בארגון. השתמש ברשימה ריקה כדי לאפשר לכל חבר; הערך ה`*` בעצמו נדחה. URL התראות חייבים להשתמש ב-HTTPS למעט כתובות פיתוח loopback.

## רשימת ביקורת ביטחון

- השתמש ב-HTTPS לחיבורים בענן.
- הגבל מפתחות לקבוצת ההרשאות הקטנה ביותר.
- הפוך בין סביבות ייצור ללא ייצור.
- בדוק הגדרות תמלול וריתוך לפני הרמה.
- בדוק שינויים במשתמש, מפתח וארגון.
- בדוק דרישות גיבוי, שמירה והגבלה עבור הפריסה שלך.
