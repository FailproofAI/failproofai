השתמש ב-Settings עבור ערכים הפעלה ספציפיים לפריסה וקביעת גודל חלון הקשר של המודל. בדוק את סכמת ההגדרות לפני שינוי ערך דרך ה-API או ה-CLI.

## שינוי הגדרה ארגונית

<Tabs>
  <Tab title="Dashboard">
    1. עבור אל **Administration → Settings**, חפש את קבוצת ההגדרות, וקרא את התיאור שלה ואת המקור הנוכחי.
    2. שנה את הערך ושמור אותו.
    3. עבור חלונות קשר של מודל, הוסף או עדכן את קביעת ההחלפה של המודל וודא את הגבול האפקטיבי.
    4. בדוק שוב הפעלות ומדדים התלויים בערך ששונה.

    ![דף ההגדרות המציג הגדרות הזדהות ופעלה ארגוניות.](/images/dashboard/settings.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp settings list
    fp settings schema
    fp settings set <key> --value <scalar>
    fp settings set alerts.email_default_recipients \
      --json-value '["oncall@example.com"]'
    ```

    הרץ את `fp settings set --help` לצורך סוג הערך וההדגלים של אישור המשמשים את ה-CLI המותקן.
  </Tab>
</Tabs>

## בחירות טיפול בנתונים

חיבור ה-CLI של Failproof AI שולח תמלול כברירת מחדל מכיוון שעקבות ביקורות תלויות בתוכנם. השתמש ב-`--no-transcripts` כאשר הנושאים, תכנים של קבצים, או קלט מטרמינל חייבים להישאר מקומיים; פעילות האתחול וההחלטות על מדיניות עדיין יכולות להיות דווחות.

אישורי הגדרה מקומיים מאוחסנים בנפרד מהגדרות daemon שאינן חסויות ונכתבות עם הרשאות מגבילות. מפתחות API עדיין צריכים להיות מנוהלים כסודות ייצור.

## הפניה הגדרות ארגוניות

כל ההגדרות הניתנות לעריכה בדashboard הן בהיקף ארגוני. התנהגות בהיקף הפריסה נותרה קביעה של סביבת השרת.

| מפתח | ברירת מחדל | מטרה |
| --- | --- | --- |
| `allowed_sign_ins` | `[]` | הגבל חברים קיימים לדואר אלקטרוני מדויק או `*@domain`; רשימה ריקה פירושה אין הגבלה נוספת. |
| `session_ttl_secs` | `86400` | משך זמן הפעלת ה-Dashboard; הטווח המקובל הוא 60 שניות עד 30 ימים. |
| `otp_ttl_secs` | `600` | משך זמן OTP וקישור קסום; הטווח המקובל הוא 60–1800 שניות. |
| `alerts.email_default_recipients` | `[]` | נמעניםברירת מחדל כאשר ערוץ דוא"ל של התראה לא משנה אותם. |
| `alerts.slack_default_webhook` | ריק | כתובת ה-URL של Slack incoming-webhook ברירת מחדל. |
| `alerts.webhook_default_url` | ריק | כתובת ה-URL של webhook JSON גנרית ברירת מחדל. |
| `alerts.webhook_signing_secret` | ריק | מפתח HMAC-SHA256 המשמש לכותרת `X-AgentEye-Signature`; הקריאות מוסווה. |
| `alerts.enabled_channels` | דוא"ל, Slack, webhook | סוגי ערוצים בהיקף ארגוני שכללי התראות עשויים להפיץ. |
| `default_user_permissions` | `standard` | מערך הרשאות בשם שנבחר מראש עבור הזמנות חדשות. |

`allowed_sign_ins` הוא מסנן, לא הענקה: אדם חייב להיות כבר חבר בארגון. השתמש ברשימה ריקה כדי לאפשר לכל חבר; הערך הגולמי `*` נדחה. כתובות URL של התראה חייבות להשתמש ב-HTTPS למעט כתובות פיתוח loopback.

## רשימת בדיקה אבטחה

- השתמש ב-HTTPS לחיבורי Cloud.
- קבע מפתחות לקבוצת הרשאות הקטנה ביותר.
- הפרד סביבות ייצור ולא ייצור.
- בדוק הגדרות תמלול וחיזוי לפני הטלגרף.
- בדוק משתמשים, מפתחות, וביטחון שינויים בארגון.
- בדוק גיבוי, שמור, וידם תגובה דרישות עבור הפריסה שלך.
