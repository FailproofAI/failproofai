שימוש מציג את הצריכה של הארגון הנוכחי וחלונות החיובי שלו. השתמש בו כדי להבין כיצד השקת הייצור, נפח תמליל, הערכות וקצב ביקורת משפיעים על התוכנית שלך.

## בדוק שימוש

<Tabs>
  <Tab title="Dashboard">
    1. עבור אל **Administration → Usage**.
    2. אשר את הארגון וחלון המדידה.
    3. בדוק הזנה, הפעלות, הערכות, מטריקות, ביקורות, ממצאים, התראות, משתמשים ומפתחות.
    4. השווה עבודת ביקורת שהתחילה והשלימה כאשר שימוש ביקורת נראה בלתי צפוי.

    ![דף השימוש המציג את חלון המדידה, אירועים שנתפסו, צינורות הערכה וביקורת, משאבי סביבת עבודה, חברים ומפתחות API.](/images/dashboard/usage-overview.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp usage
    fp --json usage
    fp --org reliability-team --json usage
    ```
  </Tab>
</Tabs>

## חקור שינוי

1. אשר את הארגון וחלון פעיל.
2. השווה את הגדילה עם נפח הפעלות לפי סביבה.
3. בדוק אם שילוב חדש התחיל לשלוח תמלילים.
4. בדוק שינויים בקצב מעריך וביקורת.
5. השווה עם ההגבלות בתוכנית התמחור הנוכחית.

ה-CLI מחזיר את אותה סיכום עבור סקריפטים.
