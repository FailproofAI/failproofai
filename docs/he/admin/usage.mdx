שימוש מציג צריכת עבור הארגון הנוכחי ותיקיות החיוביות שלו. השתמש בו כדי להבין כיצד הטיפול בייצור, נפח תמלילים, הערכות וקדנציה ביקורת משפיעים על התוכנית שלך.

## בדוק שימוש

<Tabs>
  <Tab title="Dashboard">
    1. עבור אל **Administration → Usage**.
    2. אשר את הארגון וחלון המדידה.
    3. בדוק ingest, sessions, evaluations, metrics, audits, findings, alerts, users, וkeys.
    4. השווה בעבודת ביקורת שהתחילה והשלימה כאשר שימוש בביקורת נראה בלתי צפוי.

    ![דף Usage המציג את חלון המדידה, אירועים שנתפסו, צינורות הערכה וביקורת, משאבי מרחב עבודה, חברים וקליחות API.](/images/dashboard/usage-overview.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp usage
    fp --json usage
    fp --org reliability-team --json usage
    ```
  </Tab>
</Tabs>

## חקור שינוי

1. אשר את הארגון החלון הפעיל.
2. השווה את העלייה עם נפח הסשן לפי סביבה.
3. בדוק אם שילוב חדש התחיל לשלוח תמלילים.
4. בדוק שינויים בקדנציה של מעריכים וביקורת.
5. השווה מול המגבלות בתוכנית התמחור הנוכחית.

ה-CLI מחזיר את אותו סיכום עבור סקריפטים.
