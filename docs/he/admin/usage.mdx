שימוש מציג צריכה עבור הארגון הנוכחי וחלוני החיוב שלו. השתמש בו כדי להבין כיצד הנתונים של rollout לייצור, נפח תמלילים, הערכות ותדירות ביקורת משפיעים על התוכנית שלך.

## בדוק שימוש

<Tabs>
  <Tab title="Dashboard">
    1. עבור אל **Administration → Usage**.
    2. אשר את הארגון וחלון המדידה.
    3. בדוק ingest, sessions, evaluations, metrics, audits, findings, alerts, users, and keys.
    4. השווה עבודת ביקורת שהתחילה והושלמה כאשר השימוש בביקורת נראה בלתי צפוי.

    ![עמוד השימוש המציג את חלון המדידה, אירועים שנתפסו, צינורות הערכה וביקורת, משאבי סביבת עבודה, חברים ומפתחות API.](/images/dashboard/usage-overview.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp usage
    fp --json usage
    fp --org reliability-team --json usage
    ```
  </Tab>
</Tabs>

## חקור שינוי

1. אשר את הארגון וחלון פעיל.
2. השווה את הגדילה עם נפח session לפי סביבה.
3. בדוק האם אינטגרציה חדשה התחילה לשלוח תמלילים.
4. בדוק שינויים בתדירות מעריכים וביקורת.
5. השווה מול הגבולות בתוכנית התמחור הנוכחית.

CLI מחזיר את אותו סיכום עבור סקריפטים.
