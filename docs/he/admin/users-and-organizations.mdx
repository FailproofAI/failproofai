ארגונים מבודדים הפעלות, הערכות, ביקורות, בעיות, התראות, שאילתות, לוחות מחוונים, משתמשים ומפתחות. אמת את הארגון הפעיל לפני שינוי משאבים ניהוליים.

## ניהול חברים וארגונים

<Tabs>
  <Tab title="Dashboard">
    1. השתמש במחליף הארגונים בחלק העליון של סרגל הצד של Cloud כדי להחליף ארגונים.
    2. עבור אל **Administration → Users** כדי לחפש חברים או לסנן לפי מצב פעיל ותפקיד.
    3. בחר **new user**, הכנס את הדוא"ל, בחר קבוצת הרשאות והתאם חזרות אם נדרש.
    4. פתח משתמש מאוחר יותר כדי לעדכן הענקות, להשבית כניסה או להפעיל את החשבון שוב.

    ![דף Users המציג כתובות דוא"ל של חברים, קבוצות הרשאות וריכוזי עריכה והשבתה.](/images/dashboard/users.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp orgs list
    fp orgs switch reliability-team
    fp orgs current
    fp orgs perms

    fp users create engineer@example.com --permission-set standard
    fp users show engineer@example.com
    fp users update engineer@example.com --add audits:write
    fp users disable engineer@example.com
    fp users enable engineer@example.com
    ```
  </Tab>
</Tabs>

מנהלים יכולים ליצור, לעדכן, להשבית ולהפעיל מחדש משתמשים, ואז להקצות את קבוצת ההרשאות המתאימה לתפקידם. ה-API משתמש בפעולת מחיקה להשבתה, אך זה לא מסיר את החשבון או את רשומת החברות שלו.

<Warning>
  השבתת משתמש חוסמת זהות זו מהכניסה לכל ארגון, ולא רק לארגון שנבחר כרגע. הפעלה מחדש משחזרת כניסה גלובלית והרשאות החבר בארגון זה.
</Warning>

<Tip>
  תן לחשבונות שירות שמות תיאוריים הקשורים לעומס עבודה ובעלים. הימנע משיתוף מפתחות בין ארגונים או בין אנשים וקבוצים.
</Tip>
