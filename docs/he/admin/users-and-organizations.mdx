ארגונים מבודדים סשנים, הערכות, ביקורות, בעיות, התראות, שאילתות, לוחות בקרה, משתמשים ומפתחות. אשר את הארגון הפעיל לפני שינוי משאבים ממשלתיים.

## ניהול חברים וארגונים

<Tabs>
  <Tab title="Dashboard">
    1. השתמש במחליף הארגונים בראש סרגל הצד של Cloud כדי להחליף ארגונים.
    2. עבור ל-**Administration → Users** כדי לחפש חברים או לסנן לפי מצב פעיל וקן.
    3. בחר **new user**, הזן את הדוא"ל, בחר קבוצת הרשאות והתאם חריגים במידת הצורך.
    4. פתח משתמש מאוחר יותר כדי לעדכן הענקות, להשבית כניסה או להפעיל את החשבון שוב.

    ![דף Users המציג כתובות דוא"ל של חברים, קבוצות הרשאות וכללי עריכה והשבתה.](/images/dashboard/users.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp orgs list
    fp orgs switch reliability-team
    fp orgs current
    fp orgs perms

    fp users create engineer@example.com --permission-set standard
    fp users show engineer@example.com
    fp users update engineer@example.com --add audits:write
    fp users disable engineer@example.com
    fp users enable engineer@example.com
    ```
  </Tab>
</Tabs>

מנהלים יכולים ליצור, לעדכן, להשבית ולהפעיל שוב משתמשים, ואז להקצות את קבוצת ההרשאות המתאימה לתפקידם. ה-API משתמש בפעולת מחיקה להשבתה, אך היא אינה מסירה את החשבון או את רשם החברות שלו.

<Warning>
  השבתת משתמש חוסמת את הזהות מכניסה לכל ארגון, לא רק לארגון שנבחר כרגע. הפעלה מחדש משחזרת כניסה גלובלית והרשאות החברה בארגון זה.
</Warning>

<Tip>
  תן לחשבונות שירות שמות תיאוריים הקשורים לעומס עבודה ובעלים. הימנע משיתוף מפתחות בין ארגונים או בין אנשים למכונות.
</Tip>
