ארגונים מבודדים הפעלות, הערכות, ביקורות, בעיות, התראות, שאילתות, לוחות בקרה, משתמשים ומפתחות. אשר את הארגון הפעיל לפני שינוי משאבים אדמיניסטרטיביים.

## ניהול חברים וארגונים

<Tabs>
  <Tab title="Dashboard">
    1. השתמש במחליף הארגונים בחלק העליון של סרגל הצד Cloud כדי להחליף ארגונים.
    2. עבור אל **Administration → Users** כדי לחפש חברים או להסנן לפי מצב פעיל וסוג.
    3. בחר **new user**, הזן את הדוא"ל, בחר קבוצת הרשאות, והתאם עקיפות אם נדרש.
    4. פתח משתמש מאוחר יותר כדי לעדכן הרשאות, להשבית כניסה, או להפעיל את החשבון שוב.

    ![דף Users המציג כתובות דוא"ל של חברים, קבוצות הרשאות, ובקרות עריכה והשבתה.](/images/dashboard/users.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp orgs list
    fp orgs switch reliability-team
    fp orgs current
    fp orgs perms

    fp users create engineer@example.com --permission-set standard
    fp users show engineer@example.com
    fp users update engineer@example.com --add audits:write
    fp users disable engineer@example.com
    fp users enable engineer@example.com
    ```
  </Tab>
</Tabs>

מנהלים יכולים ליצור, לעדכן, להשבית ולהפעיל משתמשים מחדש, ולאחר מכן להקצות את קבוצת ההרשאות המתאימה לתפקידם. ה-API משתמש בפעולת מחיקה להשבתה, אך הוא אינו מסיר את החשבון או את רשומת החברות שלו.

<Warning>
  השבתת משתמש חוסמת את הזהות מכניסה לכל ארגון, לא רק לארגון שנבחר כעת. הפעלה מחדש משחזרת כניסה גלובלית והרשאות החבר בארגון זה.
</Warning>

<Tip>
  תן לחשבונות שירות שמות תיאוריים הקשורים לעומס עבודה ובעלים. הימנע משיתוף מפתחות בין ארגונים או בין אנשים למכונות.
</Tip>
