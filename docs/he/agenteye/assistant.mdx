שאל את נתוני הエージェント שלך שאלה בעברית פשוטה וקבל תשובה המקושרת ישירות לראיות. אין צורך לכתוב SQL, אין צורך לחפור דרך לוחות מחוונים — העוזר **Failproof AI Observability** הוא הדרך המהירה ביותר לכל אחד בצוות שלך לקבל תשובות לגבי הエージェנט שלך.

![העוזר Failproof AI Observability משיב לשאלה בעברית פשוטה בתוך לוח המחוונים, המציג טבלת Agent Activity חיה, פירוט שימוש בדגמים לכל אژנט, וממצאים בכתב, כשהשאילתות שהוא הרגיש מוצגות בשורה](/agenteye/images/assistant.png)
*שאל בעברית פשוטה וקבל תשובה הבנויה מהנתונים שלך. כאן זה מפרק אילו אژנטים עסוקים ביותר ואילו דגמים הם משתמשים בהם, ומציג את השאילתות שהוא הרגיש כדי שתוכל לאמת כל מספר.*

אין כלום ללמוד. פתח את הצ'אט, הקלד מה שאתה רוצה לדעת, ועקוב אחרי הקישורים שהוא משיב:

```
You:  which sessions errored today?
AI:   5 sessions errored today, newest first. Each one is linked:
      • checkout-agent   14:02   tool timeout
      • billing-agent    11:47   unhandled error
      • ...and 3 more

You:  summarize this session          (asked while viewing a run)
AI:   This run took 12 steps across 3 tools and failed near the end when a
      payment tool returned an error. It scored low on your "resolved" eval.
      Links: the session, the failing event, and that evaluation.
```

## פשוט שאל, וקפוץ ישירות להוכחה

אתה מפסיק לנחש ואתה מפסיק לכתוב שאילתות. שאל "איך האיכות משתפרת בפרוד השבוע הזה?", "אילו פעילויות שגו היום?", או "סכם את הפעילות הזו," וקבל תשובה ישירה תוך שניות במקום לבנות שאילתה ולקרוא אותה בעצמך.

כל תשובה מגיעה עם התעודות שלה. העוזר מקשר את הפעילויות המדויקות, השאילתות השמורות, ולוחות המחוונים שהשתמש בהם כדי להגיע לתשובה, כדי שתוכל ללחוץ עליהם ולאשר במקום לקחת את זה כמובן. זה גם **עמוד-מודע**: שאל על "הפעילות הזו" בזמן שאתה רואה אחת והוא כבר יודע איזו הרצה אתה מתכוון. פתח מחדש כל שיחה קודמת מאוחר יותר מבורר ההיסטוריה והמשך מכאן.

## הפוך תשובה טובה לשאילתה שמורה או לוח מחוונים

כאשר תשובה שווה את זה, בקש מהעוזר לשמור אותה. הוא משרטט את SQL לשאילתה שמורה, או מרכיב לוח מחוונים מהשאילתות הללו, ואז מציג לך כרטיס **Approve / Reject**. שום דבר לא נכתב עד שתלחץ על Approve, כך שאתה מקבל את מהירות "פשוט שאל" עם לתמיד המילה האחרונה היא שלך.

בעמוד **Queries** זה הולך עוד צעד קדימה והופך למחבר SQL: תאר את השאילתה שאתה רוצה ("הצג שיעור שגיאה לפי אژנט בשבע הימים האחרונים") והעוזר זורם SQL ישירות לעורך, ופוקח תצוגת diff כדי שתוכל **Accept** או **Reject** את השינוי לפני שהוא נחות.

![עמוד Observability Queries ועורך ה-SQL שלו](/agenteye/images/query-lab.png)
*עמוד Queries: עורך זה הוא המקום שבו העוזר זורם שאילתה טיוטה, קריאה בלבד עבורך לקבל או לדחות.*

הפקת SQL על ידי שאילה כאן משתמשת בהרשאה `queries:run`, אותה אחת מאחורי כפתור ה**Run** של העורך. צ'אט בכל מקום אחר דורש `agent:use`.

## בטוח להעביר לכל הצוות

אתה יכול לפתוח את העוזר לכולם בלי לדאוג מה הוא אולי יגע בו:

- **זה קורא רק מה שאתה כבר יכול לראות.** התשובות מוגבלות להרשאות הקריאה שלך, אז זה לעולם לא מרחיב את משטח הנתונים שלך.
- **כל כתיבה מחכה לך.** שאילתות שמורות ולוחות מחוונים נוצרים רק לאחר לחיצת Approve מפורשת שלך, ואין הגדרה שמפנה את הדלת הזו.
- **זה לעולם לא יכול למחוק כלום.** אין כלי מחיקה חשוף ולעוזר אין הרשאת מחיקה. מחיקות נשארות בידיך, בלוח המחוונים.
- **זה נשאר בתוך הארגון שלך.** העוזר רואה רק את הארגון שאתה צופה כרגע.
- **השאלות שלך נשארות שלך.** הנושאים והתשובות חיים בבסיס הנתונים Observability שלך; ניתוח מוצר רושם רק מטא-נתונים של שימוש, לעולם לא את טקסט הנושא שלך.

## היכן למצוא אותו

העוזר רוכב לאורך הקצה הימני של כל עמוד תחת הארגון שלך (`/<org-slug>/...`). לחץ על הקו, או לחץ על `⌘J` / `Ctrl+J`, כדי להרחיב אותו לפנל צ'אט מלא, וגרור את הקצה שלו לשינוי גודל; הרוחב שלך זכור על פני טעינות מחדש. אתה צריך את הרשאת **`agent:use`** כדי להשתמש בו, אחרת הקו אפור. אם הוא עדיין לא הופעל עבור הפריסה שלך (הוא צריך חיבור LLM), תראה קו שקט במקום צ'אט עובד.
