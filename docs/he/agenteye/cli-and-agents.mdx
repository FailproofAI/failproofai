כל הפריסה של Failproof AI Observability שלך, במרחק פקודה אחת. בדוק את הייצור, צור מפתח API, או אשר תקריר ללא צורך לעזוב את הטרמינל שלך, ואז עטוף כל דבר בסקריפט לתוך CI, או תן לסוכן קוד לעשות זאת עבורך בשפה אנגלית רגילה.

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*ה-CLI של `agenteye` משוחח עם לוח הבקרה שלך. זה כלי שונה מה-collector, שמשדר אירועים לשרת.*

## כל הפריסה שלך, פקודה אחת

הפסק לדלג בין כרטיסיות כדי לענות על שאלה מהירה. ה-CLI של `agenteye` קורא את הנתונים שלך ומנהל את הארגון שלך מבינארי יחיד, כך שבדיקה שהייתה דורשת לחיצה דרך לוח הבקרה הופכת לשורה אחת שתוכל להריץ שוב, להגדיר כתחליף, או להדביק לתוך runbook. אתה מקבל ארבע ממשקים:

- **קרא את הנתונים שלך:** `sessions`, `events`, `evals`, ו-`errors`, מסוננים לפי זמן, סוכן וסביבה.
- **נהל את הארגון שלך:** `keys`, `users`, `settings`, `alerts`, ו-`incidents`.
- **הרץ אנליטיקה:** SQL שמור בתוספת `query` ad-hoc על נתוני האירועים שלך.
- **שאל את העוזר:** `agent ask` מגיע לאותו אנליסט לקריאה בלבד שאתה משוחח איתו בלוח הבקרה.

התקן אותו פעם אחת עם `pipx`, היכנס עם קוד 6 ספרות שנשלח בדוא"ל, ואתה מוכן. ההפעלה נמשכת בערך יום; הרץ `agenteye login` שוב כשזה תוקף. השתמש בו כדי לבדוק את הייצור, להפעיל מפתח, או לטפל בתקריר שנוער, הכל ללא פתיחת דפדפן:

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

הרגל אחד שחשוב לדעת: אפשרויות גלובליות כמו `--json` הולכות לפני הפקודה. `agenteye --json sessions` נכון; `agenteye sessions --json` לא.

## עטוף בסקריפט, חבר לתוך CI

כל פקודה לוקחת `--json`, וזה משנה הכל. JSON נקי הולך ל-stdout בעוד סטטוס אנושי והתראות הולכות ל-stderr, כך שתופס `--json` משדרר ישירות ל-`jq` ללא שורה תועה להסרה. זה מה שגורם ל-CLI להיות שווה בשביל אתה בהודעה וגם לסוכן קוד שמנתח פלט:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

זה בנוי להיות בלתי מעוקב. הודעות אישור דלג אוטומטית כשאין טרמינל מחובר, כך שלא משהו תלוי בצינור, וכל פקודה מחזירה קוד יציאה משמעותי: `0` הצלחה, `4` לא מחובר, `5` חסר הרשאה (ההודעה שמה לשם, לדוגמה `alerts:write`), `3` לוח בקרה בלתי נגיש. סקריפט יכול להתפצל על `4` כדי לאמת מחדש או על `5` כדי לומר לך בדיוק מה לבקש ממנהל, במקום להיכשל עיוור.

## תן לסוכן קוד להנהיג אותו בשפה אנגלית רגילה

עדיף עוד יותר, אתה לא צריך לזכור את כל הדגלים האלה בכלל. **CLI skill** הוא תיקייה Skill סוכן קטנה בשם `agenteye-cli` שמלמדת סוכן קוד כגון Claude Code או Codex להנהיג את ה-CLI מבקשות בשפה אנגלית רגילה. שאל "האם משהו שבור היום?" והסוכן בוחר את הפקודה, מריץ אותה כשאתה, ועונה בפתגם.

עבור Claude Code, זרוק את תיקיית `agenteye-cli` ל-`~/.claude/skills/` והוא נגלה באופן אוטומטי. Failproof AI Observability מספק את התיקייה; אין שום דבר נוסף להתקין, כי זה רק מנהיג את ה-CLI שכבר התקנת. היכנס לעצמך תחילה: הכישור לא יכול להשלים את ההתחברות לקוד שנשלח בדוא"ל עבורך.

כי הסוכן מריץ את ה-CLI כשאתה, הוא יכול לעשות הכל שהקבלה שלך מאפשרת, קריאה וכתיבה כאחד: יצירת מפתחות, שינוי הגדרות, פתרון תקריר. הודעת "אתה בטוח?" של ה-CLI לא נורה לסוכן, כך שהכישור נכתב כדי לציין את הפקודה המדוקדקת ולהמתין לאישורך לפני כל שינוי. אתה שלב האישור.

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

קריאות נשארות מיידיות, וכל כתיבה עוצרת עבורך:

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
