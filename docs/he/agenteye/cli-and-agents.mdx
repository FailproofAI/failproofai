כל התפוצה של Failproof AI Observability שלך, פקודה אחת בלבד. בדוק את הייצור, צור מפתח API, או אשר תקרית ללא צורך להשאיר את הטרמינל שלך, ואז הריץ כל דבר שלו בתוך CI, או תן לסוכן קוד לעשות זאת עבורך בעברית רגילה.

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*ה-`agenteye` CLI מדבר ללוח הבקרה שלך. זהו כלי שונה מהאספן, המספק אירועים לשרת.*

## כל התפוצה שלך, פקודה אחת בלבד

הפסק להקפיץ בין כרטיסיות כדי לענות על שאלה מהירה. ה-`agenteye` CLI קורא את הנתונים שלך ומנהל את הארגון שלך מבינארי יחיד, כך שבדיקה שהייתה בעבר פירושה קליק דרך לוח הבקרה הופכת לשורה אחת שאתה יכול להריץ שוב, לחלק, או להדביק לרנבוק. אתה מקבל ארבע ממשקים:

- **קרא את הנתונים שלך:** `sessions`, `events`, `evals`, ו-`errors`, מסוננים לפי זמן, סוכן וסביבה.
- **נהל את הארגון שלך:** `keys`, `users`, `settings`, `alerts`, ו-`incidents`.
- **הרץ ניתוח:** SQL שמור בתוספת מריץ `query` אד-הוק על נתוני האירועים שלך.
- **שאל את העוזר:** `agent ask` מגיע לאותו אנליסט קריא-בלבד שאתה משוחח איתו בלוח הבקרה.

התקן פעם אחת עם `pipx`, היכנס עם קוד 6 ספרות שהופץ בדוא"ל, ואתה מוכן. הסשן נמשך בערך יום; הרץ `agenteye login` שוב כשתוקף פג. הגש את זה כדי לבדוק את הייצור, לספק מפתח, או לפתור תקרית שפעמון, הכל ללא פתיחת דפדפן:

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

הרגל אחד שחשוב לדעת: אפשרויות גלובליות כמו `--json` הולכות לפני הפקודה. `agenteye --json sessions` נכון; `agenteye sessions --json` אינו נכון.

## שנה לסקריפט, חבר אותו ל-CI

כל פקודה לוקחת `--json`, וזה משנה הכל. JSON נקי הולך ל-stdout בעוד סטטוס אנושי וכן אזהרות הולכים ל-stderr, אז קיפוץ `--json` זורם ישר ל-`jq` ללא שורה תועה להסיר. זו הסיבה שהCLI טוב באותה מידה עבורך בשדכן ועבור סוכן קוד המנתח פלט:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

זה בנוי להריץ ללא השגחה. הנחיות אישור דלג-אוטומטי כשלא יש טרמינל מצורף, אז כלום לא תלוי בצינור, וכל פקודה מחזירה קוד יציאה משמעותי: `0` הצלחה, `4` לא בתוך מערכת, `5` חסרה הרשאה (ההודעה שמה שם, למשל `alerts:write`), `3` לוח בקרה בלתי מסיס. סקריפט יכול להסתעף בתיאור `4` כדי להתאמת אמת או `5` כדי להגיד לך בדיוק מה לבקש ממנהל, במקום להיכשל עיוור.

## תן לסוכן קוד לנהוג בו בעברית רגילה

עדיף עוד יותר, לא צריך לזכור אף אחת מהדגלים האלה. ה-**CLI skill** היא תיקייה Skill סוכן קטנה בשם `agenteye-cli` המלמדת סוכן קוד כמו Claude Code או Codex לנהוג בCLI מבקשות בעברית רגילה. שאל "האם משהו שבור היום?" והסוכן בוחר את הפקודה, מריץ אותה כמוך, ועונה בפרוזה.

עבור Claude Code, שחרר את התיקייה `agenteye-cli` לתוך `~/.claude/skills/` וזה מגולה-אוטומטי. Failproof AI Observability מספק את התיקייה; אין כלום נוסף להתקנה, משום שהוא רק מנהל את הCLI שכבר התקנת. היכנס בעצמך תחילה: הskill לא יכול להשלים את הכניסה בקוד מעונג עבורך.

מכיוון שהסוכן מריץ את הCLI כמוך, הוא יכול לעשות הכל שההכנסה שלך מתיר, קראו וכתבו כגון: ליצור מפתחות, לשנות הגדרות, לפתור תקריות. הpromppt "האם אתה בטוח?" של הCLI לא נורים עבור סוכן, אז הskill כתוב כדי להגיד את הפקודה המדויקת וחכה להסכמתך לפני כל שינוי. אתה שלב האישור.

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

הקריאות נשארות מיידיות, וכל כתיבה עוצרת עבורך:

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
