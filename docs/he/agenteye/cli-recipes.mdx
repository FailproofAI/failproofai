משוך נתוני סשן, אירוע והערכה (והפעל הערכות חוזרות) ישירות מסקריפט או סוכן קידוד, עם JSON נקי על stdout שמתחבר ישירות ל-`jq`. המתכונים הללו הופכים את הנתונים של Failproof AI Observability למשהו שמשתמש בטרמינל או סוכן קידוד AI (Claude Code, Cursor) יכול לשאול וליישם אוטומציה, ללא לחיצה דרך הלוח המחווני.

הדפוסים למטה מוכנים להעתקה עבור CLI של Failproof AI Observability (`agenteye`). להתקנה, אימות ורשימת האפשרויות המלאה ראה [CLI](/he/agenteye/cli); הרץ `agenteye -h` או `agenteye <command> -h` לעזרה מובנית.

## כללי זהב

1. **אפשרויות גלובליות מתבצעות *לפני* הפקודה.** `agenteye --json sessions` נכון; `agenteye sessions --json` אינו נכון. הגלובליים הם `--json`, `--base-url`, `--org`, `--token`, `--insecure`/`--secure`, `--timeout`, `--quiet`, `--no-color`.
2. **העבר `--json` בכל פעם שאתה מנתח פלט.** נתונים עוברים ל-**stdout** כ-JSON; סטטוס אנושי ושגיאות עוברים ל-**stderr**, כך ש-stdout נשאר נקי לחיבור ל-`jq`.
3. **ענף על קוד היציאה**, לא על טקסט stderr: `0` בסדר · `1` שגיאה בלתי צפויה · `2` ארגומנטים גרועים · `3` לא יכול להגיע ללוח המחווני · `4` לא מחובר או פג תוקף · `5` הרשאה חסרה · `6` משאב לא נמצא.
4. **גלה עם `-h`.** כל פקודה מתעדת את המסננים שלה, פורמטי הערכים וצורת JSON.

## הגדרה חד-פעמית

```bash
export AGENTEYE_DASHBOARD_URL=https://agenteye.example.com   # כך שלא תחזור על --base-url
agenteye login --email you@example.com                       # הדבק את הקוד בדוא"ל; תקף ~24h
```

## אשר אימות לפני ביצוע עבודה

`whoami` לעולם לא טועה בסשן חסר או פג תוקף; במקום זאת היא מדווחת `logged_in:false`, כך שסוכן יכול לחקור את מצב האימות בבטחה. (זה עדיין יכול לצאת עם קוד שונה מאפס אם לא מוגדר כתובת URL בסיס או לא ניתן להגיע ללוח המחווני.)

```bash
if [ "$(agenteye --json whoami | jq -r .logged_in)" != "true" ]; then
  echo "Not authenticated. Run: agenteye login" >&2; exit 1
fi
```

## מצא סשנים נכשלים או בעלי ניקוד נמוך

```bash
# סשנים ב-24 שעות האחרונות שהערכתם שגויה
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'

# הערכות בעלות ניקוד <= 0.5 בעזרתיות, לסוכן אחד
agenteye --json evals --agent-id checkout-bot --score helpfulness:..0.5 \
  | jq '.evaluations[] | {session_id, scores}'
```

סינון ניקוד חי על **`evals`**, לא `sessions`. `--score KEY:MIN..MAX` ניתן לחזור עליו והוא משולב עם AND; כל תחום הוא אופציונלי (`..0.5` אומר ≤ 0.5, `0.9..` אומר ≥ 0.9). אתה יכול להעביר עד 20 מסנני ניקוד לכל בקשה; יותר מזה מחזיר HTTP 400. `sessions` חולק את `--env`, `--status`, `--agent-id`, `--session-id` ומסננים טווח זמן עם `evals`, אך אין `--score`.

## קרא סשן אחד מקצה לקצה

אין פקודה `session show` יחידה. שלב את רצף האירועים עם ההערכה של הסשן:

```bash
# ההערכה העדכנית ביותר של הסשן (סטטוס + ניקודות)
agenteye --json evals --session-id run-001 | jq '.evaluations[0] | {status, scores}'

# כל אירוע בהרצה (הגדל את --limit לסחיטה מלאה)
agenteye --json events --session-id run-001 --all --limit 1000 | jq '.events[] | {ts, event_type}'

# רק קריאות הכלים בסשן (--full נדרש כדי לקבל את הטעינה הגולמית)
agenteye --json events --full --session-id run-001 --event-type tool_use,tool_result --all \
  | jq '.events[].payload'
```

> **הערה:** כברירת מחדל, `events` קורא הזנה מהירה ללא טעינה. כל אירוע נושא שורת `summary` מחושבת בשרת בנוסף לדגלים כמו `is_error` וספירות אסימונים, אך `payload` חוזר כ-`{}`. כדי למשוך את הטעינה הגולמית, הוסף `--full` (או `--fields payload`). ההזנה המלאה איטית בהיקף, כך ששמור על זה מוגבל: שלב `--full` עם `--session-id` יחיד.

## אחוז הכל (דפדוף)

התוצאות הן הראשונות החדשות ביותר ודפדוף עם cursor.

```bash
# דגם אחד: אחוז עד 500 שורות בעמודים של 200 שורות
agenteye --json events --session-id run-001 --limit 500 --all > events.json

# דפדוף ידני: הזן את next_cursor בחזרה
page=$(agenteye --json events --limit 100)
cursor=$(echo "$page" | jq -r '.next_cursor // empty')
[ -n "$cursor" ] && agenteye --json events --limit 100 --cursor "$cursor"
```

## הצר את הפלט עם --fields

הגבל את המפתחות (הן בטבלה והן ב-`--json`) כדי להפחית מה שסוכן חייב לקרוא.

```bash
agenteye --json sessions --since 7d --fields session_id,status,scores | jq -c '.sessions[]'
agenteye --json events --session-id run-001 --fields ts,event_type --all
```

שמות שדות לא ידועים נדחים (יציאה `2`) עם הרשימה התקפה, דרך זולה לגילוי שמות שדות.

## גלה ערכי מסננים תקפים

```bash
agenteye --json list envs | jq -r '.values[]'           # ערכים עבור --env
agenteye --json list tools | jq -r '.values[]'          # שמות כלים; גם סוכנים, דגמים, event_types וכו'
agenteye --json list score_filters | jq -r '.values[]'  # KEY תקף עבור --score KEY:MIN..MAX
```

## בחר את הארגון שלך (ריבוי-דיירים)

אם אתה שייך ליותר מארגון אחד, בחר את הדיירים הפעילים בעת הכניסה (זה נשמר):

```bash
agenteye login --org acme --email you@corp.com   # קבע את הדיירים באותו שלב כמו הכניסה
agenteye --json orgs list | jq -r '.orgs[].org_slug'
agenteye --org globex --json sessions --since 24h   # עקוף לפקודה אחת
```

כניסה ריבוי-ארגון ללא `--org` יוצאת עם קוד שונה מאפס והדפסת הארגונים לבחירה.

## הנושא מפתח API עבור SDK/collector

```bash
# הסוד מודפס פעם אחת, עם --json זה שדה .key
key=$(agenteye --json keys create ci-bot --add events:read.add | jq -r '.key')
agenteye keys regenerate ci-bot --yes    # סיבוב; agenteye keys disable ci-bot --yes לביטול
```

## הרץ שאילתה שנשמרה או זמנית

```bash
agenteye --json query run --sql "select count(*) from analytics.events" | jq '.rows'
agenteye --json query run errs --arg prod | jq '.rows'   # שאילתה שנשמרה + $1 פוזיציונלי
```

## טריאז' של תקרית ללא אינטראקציה

```bash
id=$(agenteye --json incidents list --state firing | jq -r '.incidents[0].id')
agenteye incidents ack "$id"
agenteye incidents assign "$id" --assignee you@corp.com
agenteye incidents resolve "$id" --yes
```

> **הערה:** מוטציות דלג אוטומטית בהודעת האישור שלהן תחת `--json` או כאשר stdin אינו TTY, כך שסוכנים לעולם לא תלויים; העבר `--yes`/`-y` כדי לדלג עליה במפורש במקום אחר.

## טיפול בקוד היציאה בסקריפט

```bash
out=$(agenteye --json sessions --since 1h) || code=$?
case "${code:-0}" in
  0) echo "$out" | jq '.sessions | length' ;;
  4) echo "Session expired - run 'agenteye login'." >&2 ;;
  5) echo "Missing permission (ask an admin for evaluations:read)." >&2 ;;
  3) echo "Dashboard unreachable - check the URL." >&2 ;;
  *) echo "Unexpected error (exit ${code})." >&2 ;;
esac
```

## צורות פלט JSON

| פקודה | stdout JSON (עם `--json`) |
|---|---|
| `whoami` | `{"logged_in": true, "id", "email", "is_instance_admin", "active_org", "permissions": [...], "memberships": [...]}` או `{"logged_in": false}` |
| `orgs list` | `{"active_org", "orgs": [{"org_slug","org_name","permission_set","permissions"}]}` |
| `events` | `{"events": [...], "next_cursor": <cursor or null>}` |
| `evals` | `{"evaluations": [...], "next_cursor": <cursor or null>}` |
| `sessions` | `{"sessions": [...], "next_cursor": <cursor or null>}` |
| `errors` | `{"errors": [...], "next_cursor": <cursor or null>}` |
| `list <kind>` | `{"kind", "values": [...]}` |
| `keys list` / `keys create` | `{"keys": [...]}` / `{id, name, permissions, created_at, key}` (`key` מוצג פעם אחת) |
| `query run` | `{columns: [{name,type}], rows: [[...]], truncated, elapsed_ms}` |
| `users list` / `settings list` | `{"users": [...]}` / `{"settings": [...]}` |
| `alerts list` / `incidents list` | `{"alerts": [...]}` / `{"incidents": [...]}` |
| create/update/delete (כל אחד) | אובייקט המשאב, או `{"deleted": true, "id"}` למחיקות |
| כישלון (כל אחד, עם `--json`) | `{"error": "...", "exit_code": <n>, "status"?: <http>, "hint"?: "..."}` ב-stdout |

- כל פריט **אירוע** (`events`): `id, session_id, agent_id, event_type, ts, payload, environment, summary, is_error, error_type, output_tokens, context_window, context_fill`. שים לב ש-`payload` הוא `{}` אלא אם אתה מבקש את ההזנה המלאה עם `--full` (או `--fields payload`).
- כל פריט **הערכה** (`evals`): `id, session_id, agent_id, environment, status, scores, reasoning, summary, error, attempt_count, duration_ms, completed_at, created_at`.
- כל פריט **סשן** (`sessions`): `session_id, agent_id, environment, status, scores, event_count, started_at, last_event_at, first_event_id, last_event_id, latest_evaluation`.

ה-`--fields` של כל פקודה מקבל בדיוק שמות שדות של הפריט שלה. הסט שונה בין `sessions` ו-`evals`, כך ששם תקף לאחד יכול להיות נדחה על ידי השני.
