משוך סשן, אירוע, וערכת הערכה (והפעיל הערכות מחדש) ישירות מסקריפט או סוכן קידוד, עם JSON נקי על stdout שמעביר ישירות ל-`jq`. המתכונים הללו הופכים נתונים של Failproof AI Observability לתוך משהו שמשתמש טרמינל או סוכן קידוד AI (Claude Code, Cursor) יכול לשאול ולהפוך לאוטומציה, בלי ללחוץ דרך לוח הבקרה.

הדפוסים למטה מוכנים להעתק-הדבקה עבור Failproof AI Observability CLI (`agenteye`). להתקנה, אימות, וההשמה המלאה ראה [CLI](/he/agenteye/cli); הרץ `agenteye -h` או `agenteye <command> -h` להוראות מובנות.

## כללים זהב

1. **אפשרויות גלובליות הולכות *לפני* הפקודה.** `agenteye --json sessions` זה נכון; `agenteye sessions --json` לא. הגלובליים הם `--json`, `--base-url`, `--org`, `--token`, `--insecure`/`--secure`, `--timeout`, `--quiet`, `--no-color`.
2. **העבר `--json` בכל פעם שאתה מנתח פלט.** נתונים הולכים ל-**stdout** כ-JSON; סטטוס אנושי ושגיאות הולכות ל-**stderr**, אז stdout נשאר נקי להעברה ל-`jq`.
3. **הסתעף בקוד היציאה, לא בטקסט stderr**: `0` בסדר · `1` שגיאה בלתי צפויה · `2` ארגומנטים רעים · `3` לא יכול להגיע לוח בקרה · `4` לא התחברו או שפג תוקף · `5` הרשאה חסרה · `6` משאב לא נמצא.
4. **גלה עם `-h`.** כל פקודה תיעד את המסננים, פורמטי ערך, וצורת JSON.

## הגדרה חד-פעמית

```bash
export AGENTEYE_DASHBOARD_URL=https://agenteye.example.com   # כך שלא תחזור --base-url
agenteye login --email you@example.com                       # הדבק את הקוד שנשלח בדוא"ל; תוקף ~24h
```

## אשר אימות לפני ביצוע עבודה

`whoami` לעולם לא שגיאות בסשן חסר או שפג תוקף; זה מדווח `logged_in:false` במקום, אז סוכן יכול לחקור מצב אימות בבטחה. (זה עדיין יכול לצאת non-zero אם אין base URL מוגדר או לוח הבקרה בלתי ניתן להשגה.)

```bash
if [ "$(agenteye --json whoami | jq -r .logged_in)" != "true" ]; then
  echo "Not authenticated. Run: agenteye login" >&2; exit 1
fi
```

## מצא סשנים כושלים או בעלי ניקוד נמוך

```bash
# סשנים בעת 24h האחרונות שהערכה שלהם נשגגה
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'

# הערכות ניקוד <= 0.5 בעברה, עבור סוכן אחד
agenteye --json evals --agent-id checkout-bot --score helpfulness:..0.5 \
  | jq '.evaluations[] | {session_id, scores}'
```

סינון ניקוד חי על **`evals`**, לא `sessions`. `--score KEY:MIN..MAX` חוזר ו-AND-משולב; גבול כלשהו הוא אופציונלי (`..0.5` פירוש ≤ 0.5, `0.9..` פירוש ≥ 0.9). אתה יכול להעביר עד 20 מסננים ניקוד לכל בקשה; יותר מחזיר HTTP 400. `sessions` משתף `--env`, `--status`, `--agent-id`, `--session-id`, ומסננים טווח זמן עם `evals`, אבל אין `--score`.

## קרא סשן אחד מקצה לקצה

אין פקודה יחידה של `session show`. שלב את שביל האירוע עם הערכת הסשן:

```bash
# הערכה האחרונה של הסשן (סטטוס + ניקודים)
agenteye --json evals --session-id run-001 | jq '.evaluations[0] | {status, scores}'

# כל אירוע בהרצה (הגבה --limit לטאטא מלא)
agenteye --json events --session-id run-001 --all --limit 1000 | jq '.events[] | {ts, event_type}'

# רק קריאות הכלים בסשן (--full נדרש כדי לקבל את ה-payload הגולמי)
agenteye --json events --full --session-id run-001 --event-type tool_use,tool_result --all \
  | jq '.events[].payload'
```

> **הערה:** כברירת מחדל, `events` קורא ספציפיקה מהיר, ללא payload. כל אירוע נושא בעבודת שרת מחושבת `summary` של שורה אחת בתוספת דגלים כמו `is_error` וספירות אסימון, אבל `payload` חוזר כ-`{}`. כדי למשוך את ה-payload הגולמי, הוסף `--full` (או `--fields payload`). ספציפיקה מלאה איטית בקנה מידה, כך שהשאר אתה כבול: זוג `--full` עם `--session-id` יחיד.

## אחזר הכל (דירוג עמודים)

התוצאות הן newest-first ו-cursor-paginated.

```bash
# זריקה אחת: אחזור עד 500 שורות בעמודים של 200 שורות
agenteye --json events --session-id run-001 --limit 500 --all > events.json

# דירוג ידני: הזן את next_cursor חזרה
page=$(agenteye --json events --limit 100)
cursor=$(echo "$page" | jq -r '.next_cursor // empty')
[ -n "$cursor" ] && agenteye --json events --limit 100 --cursor "$cursor"
```

## הדק את הפלט עם --fields

הגבל את המפתחות (גם בטבלה וגם `--json`) כדי להפחית מה סוכן חייב לקרוא.

```bash
agenteye --json sessions --since 7d --fields session_id,status,scores | jq -c '.sessions[]'
agenteye --json events --session-id run-001 --fields ts,event_type --all
```

שמות שדות לא ידועים נדחים (יציאה `2`) עם הרשימה התקפה, דרך זולה לגלות שמות שדות.

## גלה ערכי מסנן תקפים

```bash
agenteye --json list envs | jq -r '.values[]'           # ערכים ל--env
agenteye --json list tools | jq -r '.values[]'          # שמות כלים; גם סוכנים, מודלים, event_types, …
agenteye --json list score_filters | jq -r '.values[]'  # KEY תקף ל--score KEY:MIN..MAX
```

## בחר את ה-org שלך (ריבוי דיירים)

אם אתה שייך ליותר מ-org אחד, בחר את הדייר הפעיל בהתחברות (זה חוסך):

```bash
agenteye login --org acme --email you@corp.com   # קבע את הדייר בשלב זהה להתחברות
agenteye --json orgs list | jq -r '.orgs[].org_slug'
agenteye --org globex --json sessions --since 24h   # לפקודה אחת בלבד
```

התחברות עם ריבוי ארגונים ללא `--org` יוצאת non-zero ופיצחה את הארגונים לבחירה.

## אפשר מפתח API ל-SDK/collector

```bash
# הסוד מודפס פעם אחת, עם --json זה .key שדה
key=$(agenteye --json keys create ci-bot --add events:read.add | jq -r '.key')
agenteye keys regenerate ci-bot --yes    # סובב; agenteye keys disable ci-bot --yes כדי לשלול
```

## הרץ שאילתה שמורה או ad-hoc

```bash
agenteye --json query run --sql "select count(*) from analytics.events" | jq '.rows'
agenteye --json query run errs --arg prod | jq '.rows'   # שאילתה שמורה + $1 פוזיציונלי
```

## ריאה דירוגים לא-אינטראקטיבית

```bash
id=$(agenteye --json incidents list --state firing | jq -r '.incidents[0].id')
agenteye incidents ack "$id"
agenteye incidents assign "$id" --assignee you@corp.com
agenteye incidents resolve "$id" --yes
```

> **הערה:** מוטציות דילוג אוטומטי את הודעת אישור תחת `--json` או כאשר stdin לא TTY, כך סוכנים לעולם תלויים; העבר `--yes`/`-y` לדלוג זה במפורש במקום אחר.

## עיבוד קוד יציאה בסקריפט

```bash
out=$(agenteye --json sessions --since 1h) || code=$?
case "${code:-0}" in
  0) echo "$out" | jq '.sessions | length' ;;
  4) echo "Session expired - run 'agenteye login'." >&2 ;;
  5) echo "Missing permission (ask an admin for evaluations:read)." >&2 ;;
  3) echo "Dashboard unreachable - check the URL." >&2 ;;
  *) echo "Unexpected error (exit ${code})." >&2 ;;
esac
```

## צורות פלט JSON

| פקודה | stdout JSON (עם `--json`) |
|---|---|
| `whoami` | `{"logged_in": true, "id", "email", "is_instance_admin", "active_org", "permissions": [...], "memberships": [...]}` או `{"logged_in": false}` |
| `orgs list` | `{"active_org", "orgs": [{"org_slug","org_name","permission_set","permissions"}]}` |
| `events` | `{"events": [...], "next_cursor": <cursor or null>}` |
| `evals` | `{"evaluations": [...], "next_cursor": <cursor or null>}` |
| `sessions` | `{"sessions": [...], "next_cursor": <cursor or null>}` |
| `errors` | `{"errors": [...], "next_cursor": <cursor or null>}` |
| `list <kind>` | `{"kind", "values": [...]}` |
| `keys list` / `keys create` | `{"keys": [...]}` / `{id, name, permissions, created_at, key}` (`key` הוצג פעם אחת) |
| `query run` | `{columns: [{name,type}], rows: [[...]], truncated, elapsed_ms}` |
| `users list` / `settings list` | `{"users": [...]}` / `{"settings": [...]}` |
| `alerts list` / `incidents list` | `{"alerts": [...]}` / `{"incidents": [...]}` |
| create/update/delete (כל) | אובייקט המשאב, או `{"deleted": true, "id"}` למחיקות |
| כישלון (כל, עם `--json`) | `{"error": "...", "exit_code": <n>, "status"?: <http>, "hint"?: "..."}` על stdout |

- כל פריט **אירוע** (`events`): `id, session_id, agent_id, event_type, ts, payload, environment, summary, is_error, error_type, output_tokens, context_window, context_fill`. שימו לב כי `payload` הוא `{}` אלא אם כן אתה מבקש את ספציפיקה המלא עם `--full` (או `--fields payload`).
- כל פריט **הערכה** (`evals`): `id, session_id, agent_id, environment, status, scores, reasoning, summary, error, attempt_count, duration_ms, completed_at, created_at`.
- כל פריט **סשן** (`sessions`): `session_id, agent_id, environment, status, scores, event_count, started_at, last_event_at, first_event_id, last_event_id, latest_evaluation`.

`--fields` של כל פקודה מקבלת בדיוק שמות שדות של הפריט שלה. הסט שונה בין `sessions` ל-`evals`, כך ששם תקף עבור אחד עלול להידחות על ידי השני.
