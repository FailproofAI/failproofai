משוך נתוני session, event והערכה (וטריגר re-evaluations) ישירות מscript או coding agent, עם JSON נקי ב-stdout שמובא ישירות אל `jq`. המתכונים האלה הופכים את הנתונים של Failproof AI Observability למשהו שמשתמש בטרמינל או AI coding agent (Claude Code, Cursor) יכול לשאול ולטמטם, בלי ללחוץ דרך ה-dashboard.

הדפוסים מטה הם מוכנים copy-paste עבור Failproof AI Observability CLI (`agenteye`). להתקנה, הזדהות, ורשימת אפשרויות מלאה ראה [CLI](/he/agenteye/cli); הרץ `agenteye -h` או `agenteye <command> -h` לעזרה מובנית.

## כללים זהובים

1. **אפשרויות גלובליות הולכות *לפני* הפקודה.** `agenteye --json sessions` זה נכון; `agenteye sessions --json` זה לא. הגלובליות הן `--json`, `--base-url`, `--org`, `--token`, `--insecure`/`--secure`, `--timeout`, `--quiet`, `--no-color`.
2. **עבור `--json` בכל פעם שאתה מנתח output.** נתונים הולכים ל-**stdout** כ-JSON; סטטוס אנושי ושגיאות הולכים ל-**stderr**, כך ש-stdout נשאר נקי לheavy אל `jq`.
3. **סתומה על exit code, לא על טקסט stderr**: `0` בסדר · `1` שגיאה בלתי צפויה · `2` ארגומנטים רעים · `3` לא יכול להגיע ל-dashboard · `4` לא logged in או פג תוקף · `5` הרשאה חסרה · `6` משאב לא נמצא.
4. **גלה עם `-h`.** כל פקודה מתעדת את המסננים שלה, פורמטי ערך, וצורת JSON.

## setup חד-פעמי

```bash
export AGENTEYE_DASHBOARD_URL=https://agenteye.example.com   # כדי שלא תחזור על --base-url
agenteye login --email you@example.com                       # תעתיק את הקוד בדוא"ל; תוקף ~24h
```

## אשר הזדהות לפני עבודה

`whoami` לעולם לא טועה בsession חסר או פג תוקף; זה מדווח `logged_in:false` במקום, כך שagent יכול לבדוק מצב hauth בבטחה. (זה עדיין יכול להיפול non-zero אם לא מוגדר base URL או ה-dashboard לא נגיע.)

```bash
if [ "$(agenteye --json whoami | jq -r .logged_in)" != "true" ]; then
  echo "Not authenticated. Run: agenteye login" >&2; exit 1
fi
```

## מצא sessions עם כשלון או ניקוד נמוך

```bash
# sessions בשעות 24 האחרונות שההערכה שלהם טעתה
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'

# evaluations שמדווח <= 0.5 על עזרתיות, עבור agent אחד
agenteye --json evals --agent-id checkout-bot --score helpfulness:..0.5 \
  | jq '.evaluations[] | {session_id, scores}'
```

ניקוד filtering חי על **`evals`**, לא `sessions`. `--score KEY:MIN..MAX` ניתן לחזור וAND-combined; כל bound הוא optional (`..0.5` פירושו ≤ 0.5, `0.9..` פירושו ≥ 0.9). אתה יכול להעביר עד 20 score filters לכל בקשה; יותר מחזיר HTTP 400. `sessions` משתף את `--env`, `--status`, `--agent-id`, `--session-id`, ו-time-range filters עם `evals`, אך אין `--score`.

## קרא session אחד end-to-end

אין פקודת `session show` יחידה. שלב את ה-event trail עם ה-evaluation של ה-session:

```bash
# ה-evaluation האחרון של ה-session (status + scores)
agenteye --json evals --session-id run-001 | jq '.evaluations[0] | {status, scores}'

# כל event בריצה (הגדל --limit לסרוק מלא)
agenteye --json events --session-id run-001 --all --limit 1000 | jq '.events[] | {ts, event_type}'

# רק ה-tool calls בsession (--full נדרש כדי לקבל את raw payload)
agenteye --json events --full --session-id run-001 --event-type tool_use,tool_result --all \
  | jq '.events[].payload'
```

> **Note:** בברירת מחדל, `events` קורא מהיר, payload-free feed. כל event נושא server-computed one-line `summary` בתוספת flags כמו `is_error` וקצב tokenים, אך `payload` חוזר כ-`{}`. כדי לשלוף את raw payload, הוסף `--full` (או `--fields payload`). ה-full feed איטי יותר בקנה מידה, אז שמרוהו מוגבל: צפו את `--full` עם `--session-id` יחיד.

## שלוף הכל (pagination)

התוצאות הן newest-first ו-cursor-paginated.

```bash
# shot אחד: שלוף עד 500 שורות בעמודים של 200 שורות
agenteye --json events --session-id run-001 --limit 500 --all > events.json

# manual paging: חזור next_cursor בחזרה
page=$(agenteye --json events --limit 100)
cursor=$(echo "$page" | jq -r '.next_cursor // empty')
[ -n "$cursor" ] && agenteye --json events --limit 100 --cursor "$cursor"
```

## הרזה את output עם --fields

הגבל את הmeys (בטבלה וב-`--json`) כדי להפחית מה שagent צריך לקרוא.

```bash
agenteye --json sessions --since 7d --fields session_id,status,scores | jq -c '.sessions[]'
agenteye --json events --session-id run-001 --fields ts,event_type --all
```

שמות field לא ידוע נדחו (exit `2`) עם הרשימה התקפה, דרך זולה גלוי שמות field.

## גלה ערכי filter תקפים

```bash
agenteye --json list envs | jq -r '.values[]'           # ערכים עבור --env
agenteye --json list tools | jq -r '.values[]'          # שמות tool; גם agents, models, event_types, …
agenteye --json list score_filters | jq -r '.values[]'  # KEY תקף עבור --score KEY:MIN..MAX
```

## בחר את ה-org שלך (multi-tenant)

אם אתה שייך ליותר מ-org אחד, בחר את ה-tenant הפעיל בlogin (זה שמור):

```bash
agenteye login --org acme --email you@corp.com   # set the tenant in the same step as login
agenteye --json orgs list | jq -r '.orgs[].org_slug'
agenteye --org globex --json sessions --since 24h   # override for one command
```

multi-org login ללא `--org` יציאות non-zero וטיפול את ה-orgs בחירה מ.

## Provision API key עבור SDK/collector

```bash
# הsecret מודפס ONCE, עם --json זה .key field
key=$(agenteye --json keys create ci-bot --add events:read.add | jq -r '.key')
agenteye keys regenerate ci-bot --yes    # rotate; agenteye keys disable ci-bot --yes to revoke
```

## הרץ שמורה או ad-hoc שאילתה

```bash
agenteye --json query run --sql "select count(*) from analytics.events" | jq '.rows'
agenteye --json query run errs --arg prod | jq '.rows'   # a saved query + a positional $1
```

## Triage incident non-interactively

```bash
id=$(agenteye --json incidents list --state firing | jq -r '.incidents[0].id')
agenteye incidents ack "$id"
agenteye incidents assign "$id" --assignee you@corp.com
agenteye incidents resolve "$id" --yes
```

> **Note:** Mutations auto-skip confirmation prompt תחת `--json` או כש-stdin לא TTY, כך agents לעולם לא תלויים; עבור `--yes`/`-y` לבטל אותו בפירוש במקום אחר.

## exit-code handling בscript

```bash
out=$(agenteye --json sessions --since 1h) || code=$?
case "${code:-0}" in
  0) echo "$out" | jq '.sessions | length' ;;
  4) echo "Session expired - run 'agenteye login'." >&2 ;;
  5) echo "Missing permission (ask an admin for evaluations:read)." >&2 ;;
  3) echo "Dashboard unreachable - check the URL." >&2 ;;
  *) echo "Unexpected error (exit ${code})." >&2 ;;
esac
```

## JSON output shapes

| Command | stdout JSON (with `--json`) |
|---|---|
| `whoami` | `{"logged_in": true, "id", "email", "is_instance_admin", "active_org", "permissions": [...], "memberships": [...]}` or `{"logged_in": false}` |
| `orgs list` | `{"active_org", "orgs": [{"org_slug","org_name","permission_set","permissions"}]}` |
| `events` | `{"events": [...], "next_cursor": <cursor or null>}` |
| `evals` | `{"evaluations": [...], "next_cursor": <cursor or null>}` |
| `sessions` | `{"sessions": [...], "next_cursor": <cursor or null>}` |
| `errors` | `{"errors": [...], "next_cursor": <cursor or null>}` |
| `list <kind>` | `{"kind", "values": [...]}` |
| `keys list` / `keys create` | `{"keys": [...]}` / `{id, name, permissions, created_at, key}` (`key` shown once) |
| `query run` | `{columns: [{name,type}], rows: [[...]], truncated, elapsed_ms}` |
| `users list` / `settings list` | `{"users": [...]}` / `{"settings": [...]}` |
| `alerts list` / `incidents list` | `{"alerts": [...]}` / `{"incidents": [...]}` |
| create/update/delete (any) | the resource object, or `{"deleted": true, "id"}` for deletes |
| failure (any, with `--json`) | `{"error": "...", "exit_code": <n>, "status"?: <http>, "hint"?: "..."}` on stdout |

- כל **event** פריט (`events`): `id, session_id, agent_id, event_type, ts, payload, environment, summary, is_error, error_type, output_tokens, context_window, context_fill`. שימו לב כי `payload` הוא `{}` אלא אם אתה מבקש את full feed עם `--full` (או `--fields payload`).
- כל **evaluation** פריט (`evals`): `id, session_id, agent_id, environment, status, scores, reasoning, summary, error, attempt_count, duration_ms, completed_at, created_at`.
- כל **session** פריט (`sessions`): `session_id, agent_id, environment, status, scores, event_count, started_at, last_event_at, first_event_id, last_event_id, latest_evaluation`.

כל `--fields` של פקודה מקבל בדיוק את שמות field של הפריט שלו. הסט שונה בין `sessions` ו-`evals`, אז שם תקף לאחד אולי נדחה על ידי השני.
