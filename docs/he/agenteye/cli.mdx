הנהג את כל Failproof AI Observability מהטרמינל או מסקריפט: ללא סיבובים בדשבורד. ה-CLI `agenteye` שוקל את הנתונים שלך (sessions, event logs, evaluations) ומנהל את הארגון שלך (API keys, users, settings, alerts, incidents, saved queries), לכן פנה אליו כאשר אתה רוצה להפעיל בדיקה אוטומטית, להטמיע Observability ב-CI, או לתת לסוכן קוד לבדוק את ההפקה. כל פקודה תומכת בדגל `--json`, ולכן היא עובדת באותו אופן טוב בעבורך בהנחיה או לסוכן קוד (Claude Code, Cursor) שמבצע שימוש חיצוני ומחלץ את התוצאה.

עם בינארי אחד אתה יכול:

- **קרא את הנתונים שלך**: `sessions`, `events`, `evals`, `errors` (סנן לפי זמן, סוכן, env, ניקוד).
- **נהל את הארגון שלך**: `keys`, `users`, `settings`, `alerts`, `incidents`.
- **הפעל ניתוח**: SQL שמור וממשק שאילתה אד-הוק (`query`).
- **שאל את עוזר ה-AI**: אותו אנליסט בעל גישה-קריאה שאתה משוחח איתו בדשבורד (`agent`).

> **הערה:** זה ה-CLI `agenteye`, כלי שונה מה-collector daemon (`agenteye-collector`). ה-CLI מדבר עם הדשבורד שלך; ה-collector משלח אירועים לשרת.

## התחלה מהירה

מכלום לתוצאה הראשונה שלך בארבע שורות. הצבע את ה-CLI לדשבורד שלך, התחבר, אשר מי אתה, ואחר כך משוך את יום הריצות האחרון:

```bash
pipx install agenteye
agenteye --base-url https://agenteye.example.com login --email you@example.com   # emailed 6-digit code
agenteye whoami                                                                  # confirm user + active org
agenteye --json sessions --since 24h                                             # one row per agent run, last 24h
```

הפקודה האחרונה הזו מדפיסה אובייקט JSON של ה-sessions האחרונים ביותר (החדשים ביותר תחילה, מוגבלים ל-50 כברירת מחדל). צינור אותו ל-`jq` כדי לחתוך אותו, או הסר `--json` לטבלה מסודרת וצבעונית. כל שורה נושאת את סטטוס הריצה ואם מעריך קיבל ניקוד עליה, ניקודי המטריקה שלה (מקוצר כאן):

```json
{
  "sessions": [
    {
      "session_id": "run-8f2a",
      "agent_id": "checkout-bot",
      "environment": "prod",
      "status": "error",
      "scores": { "helpfulness": 0.42, "tool_efficiency": 0.55 },
      "event_count": 37,
      "started_at": "2026-07-16T09:14:02Z",
      "last_event_at": "2026-07-16T09:14:48Z"
    }
  ],
  "next_cursor": null
}
```

השאר של העמוד הזה מסביר כל חלק: [התקנה](#installation) בבידוד, [התחברות](#authentication), [תצורה](#configuration), [הכנוונים הגלובליים](#global-options--conventions) שכל פקודה חולקת, ו[הייחוס הפקודה המלא](#command-reference).

## התקנה

ה-CLI הוא חבילת PyPI ציבורית בשם **`agenteye`**. התקן אותה בסביבה מבודדת כדי שלה תמיד יהיו התלויות שלה:

```bash
pipx install agenteye
# or
uv tool install agenteye
```

זה דורש Python 3.10+. הפקודה המותקנת היא **`agenteye`**:

```bash
agenteye --version
agenteye --help
```

> **הערה:** Python SDK של Failproof AI Observability גם משתמש בשם ההפצה `agenteye`. התקנת ה-CLI עם `pipx` או `uv tool` (במקום `pip install` לתוך virtualenv משותף) שומר על שניהם מלהתנגש. `pip install agenteye` רגיל בסדר רק אם SDK לא מותקן באותה סביבה.

## אימות

ה-CLI מאמת את **הדשבורד** עם קוד חד-פעמי שנשלח בדוא"ל:

```bash
agenteye login --email you@example.com
# A 6-digit code is emailed to you; paste it at the prompt.
```

אסימון ההפעלה מאוחסן ב-`~/.agenteye/cli.json` (קריא רק עבורך, מצב `0600`) ותקף ל-24 שעות כברירת מחדל. כאשר הוא פג, הפעל `agenteye login` שוב.

```bash
agenteye whoami     # show the current user, active org, and permissions
agenteye logout     # revoke the session and clear the stored token
```

`whoami` לעולם לא שגיאות בהפעלה חסרה או שפגה; זה מדווח `logged_in: false` במקום זאת, כך שסקריפט או סוכן יכול לבדוק בבטחה את מצב האימות (הוא עדיין יכול להצא מאפס אם לא מוגדרת URL בסיס או הדשבורד אינו זמין).

**דרישות:** הדוא"ל שלך חייב להיות מורשה להיכנס לדשבורד (שאל את מנהל Failproof AI Observability שלך), והדשבורד חייב להיות זמין בכתובת ה-URL הבסיסית שלו (ראה [תצורה](#configuration)). אם אתה מבקש קוד ואף אחד לא מגיע, הדוא"ל שלך כנראה עדיין לא מופעל לגישה לדשבורד.

## בחירת הארגון שלך (ריבוי שוכן)

אם החשבון שלך שייך ליותר מארגון אחד, בחר את הפעיל **בעת ההתחברות**; זה נשמר וביושם לכל פקודה מאוחרת יותר:

```bash
agenteye login --org acme           # authenticate and set the active tenant in one step
agenteye orgs list                  # the orgs you can access (the active one is marked)
agenteye orgs switch globex         # change the saved default
agenteye --org globex sessions      # override for a single command
```

אם אתה שייך בדיוק לארגון אחד, זה נבחר באופן אוטומטי ואתה יכול להתעלם מ-`--org` לחלוטין. אם אתה שייך לכמה ולא בחרת אחד, ה-CLI רשום אותם ושואל אותך להפעיל מחדש עם `--org <slug>`. הארגון הפעיל נשלח לדשבורד בכל בקשה, וההרשאות שלך נפתרות **לכל ארגון**; `agenteye whoami` מציג את הארגון הפעיל, ההרשאות שלך בו וכל החברויות שלך.

## תצורה

| הגדרה | דגל | משתנה סביבה | ברירת מחדל |
|---|---|---|---|
| Dashboard base URL | `--base-url` | `AGENTEYE_DASHBOARD_URL` | **נדרש** (אין ברירת מחדל) |
| Active org/tenant | `--org` | `AGENTEYE_ORG` | נבחר בעת ההתחברות; נשמר ב-`~/.agenteye/cli.json` |
| Session token | `--token` | `AGENTEYE_CLI_TOKEN` | מ-`~/.agenteye/cli.json` |
| JSON output | `--json` | `AGENTEYE_CLI_JSON` | כבוי |
| Skip TLS verification | `--insecure` / `--secure` | `AGENTEYE_INSECURE` | כבוי (נשמר בעת ההתחברות) |
| Request timeout (seconds) | `--timeout` | _(none)_ | 30 |
| Disable usage telemetry | _(none)_ | `AGENTEYE_ANALYTICS_DISABLED` (or `DO_NOT_TRACK`) | telemetry is currently disabled; nothing is sent |

סדר ההחלטה הוא **דגל → משתנה סביבה → קובץ תצורה**. אין ברירת מחדל; אתה חייב להצביע את ה-CLI שלך לדשבורד שלך, או לכל פקודה (`--base-url https://agenteye.example.com`) או פעם אחת דרך הסביבה (זה גם נשמר לאחר `login` הראשון שלך):

```bash
export AGENTEYE_DASHBOARD_URL=https://agenteye.example.com
```

ספריית התצורה מכבדת `AGENTEYE_HOME` (אותה כנוונית המשמשת את SDK וה-collector); אם מוגדרת, `cli.json` גרים ב-`$AGENTEYE_HOME/cli.json`.

### TLS חתום לעצמו או פנימי

אם הדשבורד שלך מוגש דרך HTTPS עם תעודה חתומה לעצמה או פנימית (לדוגמה, שם hostname של מאזן עומס גולמי), אימות TLS דוחה זאת עם שגיאה `CERTIFICATE_VERIFY_FAILED`. העבר `--insecure` כדי לדלג על אימות תעודה:

```bash
agenteye --base-url https://agenteye.internal --insecure login
```

`--insecure` **נשמר ל-`cli.json` כאשר אתה מתחבר**, כך שפקודות מאוחרות יותר דולגות על אימות באופן אוטומטי; אתה לא צריך לחזור על הדגל. העבר `--secure` לשיחה מאומתת חד-פעמית, או כדי לשמור על אימות חזרה בעת ההתחברות הבאה שלך. ה-CLI מדפיס אזהרה ל-stderr לפני כל פקודה שיוצרת קשר עם הדשבורד בזמן שאימות מבוטל. דילוג על אימות מסיר הגנה מפני התקפות man-in-the-middle; ודא שאתה סומך על נתיב הרשת לדשבורד שלך (VPN, תת-רשת פרטית וכו') לפני שנשענת עליו.

## טלמטריה וחיסיון

> **הערה:** ה-CLI המשוגר שולח **ללא טלמטריה שימוש היום.** דו"כ הרג אב הוא על, כך שום דבר לא משודר ללא קשר לסביבה שלך. הסעיף להלן מתאר את יכולת ההסרה אם כשהטלמטריה אי פעם מופעלת.

גם כאשר מופעל, טלמטריה תהיה **ניתוח שימוש אנונימי בלבד**, לעולם לא הסוכן, ההפעלה או נתוני האירוע שלך:

- **אין נתוני סוכן, פעלות או אירוע המותירים אי פעם את התשתית שלך.** רק שימוש ב-CLI יוגד: שם הפקודה והתת-פקודה (למשל `keys create`), **שמות** הדגלים שהשתמשת בהם (לעולם לא הערכים שלהם), סטטוס הצלחה/יציאה ומשך זמן, בתוספת אירוע לכל פעולה עבור מוטציות (למשל `api_key_created`, `query_run`) הנושא שמות/enums סטטיים בלבד וספירות גסות. URL הדשבורד, אסימון ההפעלה, דוא"ל, slug ארגון, מזהי משאבים, SQL, סודות מפתח וסינוני שאילתה **לעולם** לא יישלחו. מפעילים יזוהו רק לפי מזהה פנימי אטום, לעולם לא לפי דוא"ל.
- **בחר להימנע מראש** על ידי הגדרת `AGENTEYE_ANALYTICS_DISABLED=1` בסביבת ה-CLI (ה-CLI גם מכבד את הכנוונית בחצי הכלים `DO_NOT_TRACK=1`). זה חל ברגע שטלמטריה אי פעם מופעלת, כך שסביבה מודעת לחיסיון יכולה להישמר ממצי בהיתר לצמיתות.
- אם טלמטריה הייתה מופעלת, ה-CLI היה שולח ישירות ל-PostHog (`https://us.i.posthog.com`); מכונה עם אותו מארח חסום הייתה שולחת בשקט כלום וה-CLI לא היה מושפע.

## אפשרויות גלובליות וכנוונויות

קרא זאת פעם אחת; זה חל לכל פקודה.

- **אפשרויות גלובליות הולכות לפני הפקודה.** `agenteye --json sessions` נכון; `agenteye sessions --json` היא שגיאת שימוש. הגלובליים הם `--json`, `--base-url`, `--org`, `--token`, `--insecure`/`--secure`, `--timeout`, `--quiet` ו-`--no-color`.
- **`--json` מדפיס JSON טהור ל-stdout, וכלום אחר.** שורות מצב אנושיות, אזהרות ושגיאות עוברות ל-**stderr**, כך שתיפוס `--json` stdout נשאר נקי כדי להצינור ל-`jq` גם כאשר שורת מצב מוצגת. ללא `--json` אתה מקבל תצוגה מסודרת וצבעונית לעיניים אנושיות.
- **גלה עם `--help`.** לכל פקודה וב-sub-command יש `--help` (ו-`-h` כינוי): `agenteye -h`, `agenteye sessions -h`, `agenteye keys create -h`. ה-help רמה עליונה גם מרשימה את קודי היציאה ואת האפשרויות הגלובליות. אין דמפ משטח קריא מכונה גלובלית; השתמש ב-`--help` לכל פקודה, בתוספת `agenteye query schema` ו-`agenteye settings schema` לשתי הרשומות תחומיות.
- **אישורים דילג אוטומטי לסקריפטים וסוכנים.** פקודות יצירה/עדכון/מחיקה מעוררות הנחיה אם זה טרמינל אינטראקטיבי, אך **דילוג אוטומטי על הנחיה זאת תחת `--json` או כאשר stdin אינו TTY** (TTY הוא הפעלה טרמינלית אינטראקטיבית; צינור או רץ CI אינו), כך שסקריפטים וסוכנים לעולם לא תלויים. העבר `--yes`/`-y` כדי לדלג עליה באופן מפורש. מכיוון שההנחיה לא תעבור לסוכן, סוכן צריך לאשר פעולות הרסניות עם האדם תחילה.
- **עמוד חיפוש:** התוצאות הן המחודשות ביותר תחילה ו-cursor-paginated (כל עמוד מחזיר אסימון שבו משתמש כדי להביא את הבא). `--limit N` (כינוי `-n`) כובעים בשורות ו**ברירת מחדל ל-50**; `--all` פיגוקציה אוטומטית (בחתיכות של 200 שורות) **עד `--limit`**, כך שחוקי `--all` עדיין עוצר ב-50. להטאות מלאה העבר כובע מפורש גבוה: `--all --limit 1000`. `--page-size N` שולט בחתיכה לכל בקשה (מקס 200); `--cursor <id>` חוזר ממספר קודם של `next_cursor`.
- **סינוני זמן:** `--since` לוקח חלון יחסי: `15m`, `1h`, `6h`, `24h`, `7d`, או `all` (הטרם-הגדרות בדשבורד). לטווח ארוך יותר או מותאם (נגיד 30 הימים האחרונים), השתמש ב-`--from`/`--to`: ברורה ISO-8601 UTC timestamps **עם `T` וטיפול זמן** (למשל `2026-06-01T00:00:00Z`) שדורכים `--since`. ערך מופרד או חסר טיפול זמן הוא שגיאת שימוש.
- **`--fields a,b,c`** (על `events`, `sessions`, `evals`, `errors`) מגביל את הפלט לאותם מקשים, עבור הטבלה ו-`--json`. שמות לא ידועים דחויים עם הרשימה התקפה, דרך זולה לגלות שמות שדה.
- **`--file payload.json`** (או `--file -` לקריאת stdin) מסופק גוף בקשת JSON מלא כאשר משאב יש צורה מורכבת (על `alerts create/update`, `settings set` ו-`users create/update`). SQL חוקי שמור משתמש ב-`--sql @file.sql` במקום זאת.
- **סינוני ערך רב** הם מופרדים בפסיקים → התאימו כסט (איחוד בתוך סינון אחד, AND דרך סינונים): `--event-type tool_use,tool_result`. אפשרויות לחיצה אינן variadic, כך ש-`--add a b` שברים. השתמש ב-`--add a,b`, חזור על דגל (`--add a --add b`) או ציטוט (`--add "a b"`).

## ייחוס פקודה

### אתה תשתמש בפקודות 5 אלה הכי הרבה

רוב העבודה יום-יום עוברת דרך קומץ של פקודות קריאה. התחל כאן, ואחר כך פנה למשטח המלא להלן כאשר אתה צריך זאת:

| פקודה | מה היא עושה | נסה זאת |
|---|---|---|
| `sessions` | שורה אחת לכל ריצת סוכן: זמן, env, סוכן, סטטוס, ניקוד אחרון. | `agenteye --json sessions --since 24h --status error` |
| `events` | שביל ירייה גולמי בתוך ריצה (הוסף `--full` עבור muginss). | `agenteye --json events --session-id run-001 --all` |
| `evals` | תוצאות הערכה וניקודים; `--aggregate` מגביל אותם. | `agenteye --json evals --aggregate --since 7d --env prod` |
| `errors` | רק אירועים מוטעים; `--aggregate` לספירות לפי סוג. | `agenteye --json errors --since 24h --aggregate` |
| `list` | גלה את ערכי הסינון התקפים (סוכנים, envs, models, …). | `agenteye list agents` |

### הכל ה-CLI יכול לעשות

המשטח המלא צפוי. ל-CLI יש **18 פקודות ברמה עליונה**. כל פקודות קריאה מקבלות `--json` ואת האפשרויות הגלובליות לעיל; הפעל `agenteye <command> -h` (או `<command> <subcommand> -h`) עבור רשימה הדגל ממצה וצורת JSON של כל אחד.

### זהות: `login` · `logout` · `whoami` · `orgs` · `version` · `help`

```bash
agenteye login --email you@example.com [--org acme]   # emailed one-time code; saves the session
agenteye logout                                       # clear the saved session on this machine
agenteye whoami                                       # current user, active org, permissions
agenteye version                                      # print the CLI version (same as --version)
agenteye help                                         # top-level help (same as --help)
```

`orgs` בודקות וממיר את השוכן הפעיל:

```bash
agenteye orgs list        # your orgs + your role in each (active one marked)
agenteye orgs switch acme # change the saved active org (omit the slug to pick from a list on a TTY)
agenteye orgs current     # identity card for the active org
agenteye orgs perms       # your permissions in the active org, grouped by resource
```

### צפייה (קריאה בלבד): `events` · `sessions` · `evals` · `errors` · `list`

אף אחד מאלה לא צריך אישור. סינונים משותפים: `--session-id`, `--agent-id`, `--env` (**לא** `--environment`), וטווח הזמן (`--since` / `--from` / `--to`).

```bash
# events (alias: the raw per-step trail), newest first
agenteye --json events --session-id run-001 --event-type tool_use,tool_result --all --limit 1000
agenteye --json events --since 1h --search timeout --all | jq '.events[].payload'

# sessions: one row per agent run (time/env/agent/session/status; no score filtering)
agenteye --json sessions --since 24h --status error
agenteye --json sessions --agent-id checkout-bot --env prod --all --limit 1000

# evals: evaluation results + scores; --score filters by metric, --aggregate rolls up
agenteye --json evals --score helpfulness:0.5..0.8 --score tool_efficiency:..0.3
agenteye --json evals --aggregate --since 7d --env prod        # status mix + per-key score stats

# errors: errored events; --aggregate for counts/sessions/agents/last-seen
agenteye --json errors --since 24h --aggregate
agenteye --json errors --since 24h --error-type timeout --all --limit 1000

# list: discover valid filter values before you filter
agenteye list envs        # also: agents event_types score_filters models hooks tools error_types
```

`--score KEY:MIN..MAX` (על **`evals`**, לא `sessions`) הוא חזרה ו-AND-combined; כל בן קשור הוא אופציונלי (`..0.5` פירושו ≤ 0.5, `0.9..` פירושו ≥ 0.9). עד 20 סינוני ניקוד לכל בקשה. `evals --scores-full` היא דגל תצוגה עבור **הטבלה האנושית בלבד**; זה מציג כל זוג ניקוד במקום הראשון כמה בתוספת ספירת `+N`. אין השפעה תחת `--json`, הגם תמיד מחזיר את אובייקט הניקוד המלא. כדי לקרוא **הפעלה אחת מההתחלה לסוף**, שלב את שביל האירוע עם הערכתו:

```bash
agenteye --json events --session-id run-001 --all --limit 1000 | jq '.events[] | {ts, event_type}'
agenteye --json evals  --session-id run-001                       # its scores + status
```

### ניהול (שוער בהרשאה): `keys` · `users` · `settings` · `alerts` · `incidents`

**`keys`**: API keys. הסוד נוצר באופן מקומי, נשלח לשרת (אשר מאחסן רק חיבור) ו**הוצג פעם אחת** ביצירה/יצירה; תיפוס זאת אז. עם `--json` זה מופיע רק בשדה `key`. ההתייחסות לפי **שם**.

```bash
agenteye keys list                                   # active keys first, then revoked
agenteye keys show ci-bot
agenteye keys create ci-bot --add events:read.add    # scope to what you need; prints the secret ONCE
agenteye keys create ops --permission-set standard --remove queries:run   # seed a preset, then trim
agenteye keys update ci-bot --add evaluations:read --yes
agenteye keys regenerate ci-bot --yes                # rotate the secret (the old one stops working)
agenteye keys disable ci-bot --yes                   # revoke
```

ההרשאות עבודה כמו `(permission-set ∪ --add) − --remove`. אסימונים הם `slug:action` (למשל `events:read`) או `slug:action.action` להרחיב כמה במשאב אחד (`events:read.add` → `events:read`, `events:add`). מוגדרים מראש: `read-only`, `standard`, `admin`. הרשאות בעלות אנושיות בלבד (`keys:update`) אינן יכולות להעניק למפתח.

**`users`**: חברי ארגון, ההתייחסות לפי **דוא"ל** (מזהה UUID מקובל גם).

```bash
agenteye users list [--active-only]
agenteye users show dev@corp.com
agenteye users create dev@corp.com --permission-set standard
agenteye users update dev@corp.com --add alerts:write --remove queries:delete   # predicts + confirms
agenteye users disable dev@corp.com --yes            # has protected/self guards
agenteye users enable dev@corp.com
```

**`settings`**: רשימה קבועה (אתה קורא ומשנה מפתחות קיימים; אתה לא יכול ליצור חדשים).

```bash
agenteye settings list                               # key · value · type · updated (secrets masked)
agenteye settings schema                             # what each key accepts (type · range · description)
agenteye settings set session_ttl_secs --value 86400 --yes
```

**`alerts`**: הגדרות התראה, ההתייחסות לפי **שם**. `create` לוקח NAME עמדתי בתוספת דגלים או גוף JSON מלא דרך `--file`.

```bash
agenteye alerts list
agenteye alerts show high-errors
agenteye alerts create high-errors --file alert.json          # NAME is required (positional)
agenteye alerts update high-errors --severity critical --yes
agenteye alerts test high-errors --yes                        # fire a test notification
agenteye alerts delete high-errors --yes
```

**`incidents`**: התראה התקרויות, ההתייחסות לפי id (short ids מקובלים). `show` מדפיס את יומן הפעילות המלא; קרא אותו לפני פעולה.

```bash
agenteye incidents list --state firing                # also: acknowledged, resolved
agenteye incidents count
agenteye incidents show <id>
agenteye incidents ack <id>
agenteye incidents assign <id> you@corp.com           # assignee must be an operator
agenteye incidents resolve <id> --yes
agenteye incidents open --alert-id <id> --severity critical    # open one manually against an alert
agenteye incidents comment-add <id> "root cause: upstream 5xx"
agenteye incidents comment-list <id> ; agenteye incidents comment-delete <id> <comment-id>
agenteye incidents subscribe <id> ; agenteye incidents unsubscribe <id> ; agenteye incidents subscribers <id>
```

### ניתוח וסוכן: `query` · `agent`

**`query`**: SQL שמור כנגד חנות הניתוח שלך בתוספת רץ אד-הוק. שאילתות שמורות הן ההתייחסות לפי **שם**; SQL מעודכן בשרת (SELECT/WITH בלבד, timeout הצהרה, כובע שורה).

```bash
agenteye query schema [TABLE]                         # column layout of the analytics views
agenteye query run --sql "select count(*) from analytics.events"
agenteye query run errs --arg prod --limit 100        # run a saved query + a positional $1
agenteye query list ; agenteye query show errs
agenteye query create errs --sql @errs.sql --description "errored events (24h)"
agenteye query update errs --sql @errs.sql --yes ; agenteye query delete errs --yes
```

**`agent`**: מדברות אל **עוזר ה-AI** המובנה (אותו אנליסט בעל גישה קריאה שאתה יכול לשוחח איתו בדשבורד). השיחות הן ההתייחסות לפי short chat-id (prefix-resolved).

```bash
agenteye agent health                                 # is the AI assistant configured/reachable
agenteye agent models                                 # models you can pass to --model (default marked)
agenteye agent ask "which agents errored most in the last day?"    # starts a chat; prints its short id
agenteye agent ask --chat <short-id> "and which tools did they call?"   # continue that chat
agenteye agent chats ; agenteye agent show <short-id>
agenteye agent rename <short-id> --title "error triage" ; agenteye agent delete <short-id>
```

## קודי יציאה

| קוד | משמעות |
|---|---|
| 0 | הצלחה |
| 1 | שגיאה בלתי צפויה (למשל הדשבורד החזיר 5xx) |
| 2 | שגיאת שימוש (ארגומנטים לא תקפים, פקודה/דגל לא ידוע, התנגשות שם) |
| 3 | לא יכול להגיע לדשבורד |
| 4 | לא מחובר או הפעלה פג; הפעל `agenteye login` |
| 5 | מאומת, אך לחשבון שלך חסרה ההרשאה הנדרשת (ההודעה קורא אותה) |
| 6 | המשאב המבוקש לא נמצא (למשל session או incident id לא ידוע) |

אלה עושים את ה-CLI בטוח לסקריפט: סוכן קוד יכול ענף על `4` כדי להנחות אותך לאימות מחדש, או `5` לפני ההרשאה החסרה. ראה [CLI recipes for agents](/he/agenteye/cli-recipes) לתמונות תעלול קוד יציאה וצורות פלט JSON.
