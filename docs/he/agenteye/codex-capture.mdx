המהندסים שלך כבר משתמשים ב-OpenAI Codex כל יום. Codex session capture מביא את הסשנים הקודינג האלה ל-AgentEye כסשנים וevents רגילים, כדי שתוכל לחפש, להשמיע שוב, והערכה עליהם לצד הכל האחר שאתה צופה. זה משלים את [Python SDK](/he/agenteye/python-sdk): ה-SDK משדר agents שאתה כותב, בעוד שזה תופס את עבודת ה-Codex שהצוות שלך כבר עושה — ללא שינוי בדרך שהם משתמשים בה.

collector קטן בחזקה בקרקע קורא את שיריות הסשן המקומיות של Codex כשהן נכתבות ושולח אותן ל-AgentEye. collector אחד למכונה תופס כל משטח Codex מקומי בו-זמנית — אין הגדרה לכל משטח.

אותו collector תופס agents אחרים גם — ראה [OpenClaw](/he/agenteye/openclaw-capture) ו-[Hermes](/he/agenteye/hermes-capture). הפעל את כל אחד שאתה משתמש בו; collector יחיד יכול לתפוס כמה בו-זמנית.

---

## מה זה תופס

כל משטח Codex שפעל **באופן מקומי** מייצר את אותן שיריות סשן על-דיסק, וה-collector אוסף את כולן:

- ה-Codex **CLI** וכן `codex exec`
- הרחבת **VS Code / IDE**
- את **desktop app**, כשהוא מחיל סשן באופן מקומי

כל סשן Codex הופך ל-AgentEye [session](/he/agenteye/sessions); הודעות המשתמש וה-assistant שלו, חשיבה, קריאות כלים, תוצאות כלים, וצריכת tokens הופכות ל-[events](/he/agenteye/event-stream) תואמים. המשטח שממנו הגיע כל סשן (CLI, IDE, או desktop) מתועד, כדי שתוכל להבדיל בינם.

> **לא תופסים סשנים בענן.** The desktop app יותר ויותר מחיל סשנים בענן Codex ושומר רק את metadata שלהם על המכונה — אין שיר סשן מקומי לקרוא. רק סשנים שביצעו באופן מקומי תופסים.

---

## הפעל אותו

Capture כבוי עד שתפעיל אותו. התקן את ה-collector עם API key שיש לו ההרשאה `events:add` (ראה [API keys](/he/agenteye/api-keys)), והפעל את Codex capture:

```bash
curl -fsSL https://raw.githubusercontent.com/FailproofAI/agenteye-collector/main/install.sh \
  | sh -s -- --key <YOUR_API_KEY> --codex-enabled
```

זה מתקין את ה-collector, רושם אותו כשירות רקע, והתחיל לתפוס. אשר שהוא פועל:

```bash
agenteye-collector health
```

בהרצה הראשונה, הסשנים הקיימים שלך ב-Codex מלא טעון פעם אחת וpractice חדש זורם תוך שניות. קבצים של Codex עצמו קראו בלבד — אף פעם לא שונו, הועברו, או מחקו — וכל סשן נשלח בדיוק פעם אחת, אפילו על פני restarts.

---

## איפה זה מופיע

סשנים תופסים מופיעים ב-**Sessions**, וה-events שלהם בזרם **Events**, כמו כל agent אחר שאתה צופה — אז [session replay](/he/agenteye/sessions), [search](/he/agenteye/queries), [evaluations](/he/agenteye/evaluations), ו-[alerts](/he/agenteye/alerts) כולם עובדים עליהם. סנן לפי ה-agent של Codex כדי לראות אותם בעצמם.

---

## פרטיות

שיריות Codex מכילות את הסשן המלא — כולל פלט פקודה, תכנים קבצים, וכל דבר שCodex קרא או כתב — ויכול להכיל סודות. סשנים תופסים נשלחים כפי שהם, אז הפעל capture רק על מכונות ועבור צוותים שם מרכזית על תוכן ב-AgentEye מתאימה, ותן ל-collector key scoped ל-`events:add` בלבד. ראה [Security](/he/agenteye/security) לאיך הנתונים שלך נשמרים מבודדים.
