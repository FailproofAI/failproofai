המהנדסים שלכם כבר מריצים OpenAI Codex כל יום. תיעוד ישיבות Codex מביא את ישיבות הקידוד הללו ל-AgentEye כישיבות ואירועים רגילים, כך שתוכלו לחפש, להשמיע שוב ולהעריך אותם לצד כל שאר מה שאתם צופים. זה משלים את [Python SDK](/he/agenteye/python-sdk): ה-SDK מכשיר agents שאתם כותבים, בעוד שזה תופס את עבודת ה-Codex שהצוות שלכם כבר עושה — ללא כל שינוי בדרך הפעולה שלהם.

אוסף רקע קטן קורא את תמלילי ישיבות Codex המקומיים כשהם נכתבים ושולח אותם ל-AgentEye. אוסף אחד לכל מכונה תופס כל משטח Codex מקומי בבת אחת — אין כל הגדרה לכל משטח.

אותו אוסף תופס גם agents אחרים — ראה [OpenClaw](/he/agenteye/openclaw-capture) ו-[Hermes](/he/agenteye/hermes-capture). הפעל את כל אלה שאתה מריץ; אוסף יחיד יכול לתפוס כמה בו זמנית.

---

## מה הוא תופס

כל משטח Codex שמתבצע **ברמה מקומית** מייצר אותם תמלילי ישיבות בכונן קשיח, והאוסף בוחר אותם:

- ה-**CLI** של Codex ו-`codex exec`
- ה-**extension של VS Code / IDE**
- את ה-**desktop app**, כשהוא מריץ ישיבה ברמה מקומית

כל ישיבת Codex הופכת ל-AgentEye [session](/he/agenteye/sessions); ההודעות של המשתמש והעוזר שלה, הנמקה, קריאות כלים, תוצאות כלים, ושימוש בטוקנים הופכים ל-[events](/he/agenteye/event-stream) המתאימים. המשטח שמהו הגיעה כל ישיבה (CLI, IDE, או desktop) מתועד, כך שתוכל להבדיל ביניהם.

> **ישיבות ענן אינן תפוסות.** ה-desktop app יותר ויותר מריץ ישיבות בענן Codex ושומר רק על המטא-דאטה שלהם במכונה — אין תמליל מקומי לקרוא. רק ישיבות המתבצעות ברמה מקומית תפוסות.

## הפעל זאת

התיעוד כבוי עד שתפעיל אותו. התקן את האוסף עם מפתח API שיש לו הרשאת `events:add` (ראה [API keys](/he/agenteye/api-keys)), והפעל את תיעוד Codex:

```bash
curl -fsSL https://raw.githubusercontent.com/FailproofAI/agenteye-collector/main/install.sh \
  | sh -s -- --key <YOUR_API_KEY> --codex-enabled
```

זה מתקין את האוסף, רושם אותו כשירות רקע, ומתחיל בתיעוד. אשר שהוא פועל:

```bash
agenteye-collector health
```

בהרצה הראשונה, הישיבות הקיימות שלך ב-Codex מתמלאות חזרה פעם אחת פעולה חדשה ואז זורמת תוך שניות. הקבצים של Codex עצמו נקראים רק — לעולם לא משונים, מועברים, או מחוקים — וכל ישיבה נשלחה בדיוק פעם אחת, אפילו על פני הפעלה מחדש.

## איפה זה מופיע

ישיבות תפוסות מופיעות ב-**Sessions**, והאירועים שלהן ב-**Events** stream, בדיוק כמו כל agent אחר שאתה צופה — אז [session replay](/he/agenteye/sessions), [search](/he/agenteye/queries), [evaluations](/he/agenteye/evaluations), ו-[alerts](/he/agenteye/alerts) כל זה עובד עליהם. סנן לפי agent Codex כדי לראות אותם לבד.

---

## פרטיות

תמלילי Codex מכילים את כל הישיבה — כולל פלט פקודה, תוכן קבצים, וכל דבר ש-Codex קרא או כתב — ויכולים להכיל סודות. ישיבות תפוסות נשלחות כמו שהן, אז הפעל תיעוד רק על מכונות ועבור צוותים שבהם ריכוז התוכן הזה ב-AgentEye מתאים, ותן לאוסף מפתח מוגבל לרק `events:add`. ראה [Security](/he/agenteye/security) כדי להבין כיצד הנתונים שלך מוחזקים בבידוד.
