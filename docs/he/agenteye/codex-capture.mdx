המהנדסים שלך כבר מריצים OpenAI Codex כל יום. Codex session capture מביא את הסשנים הקודיים הללו ל-AgentEye כסשנים ואירועים רגילים, כך שתוכל לחפש, להשמיע פעם נוספת, ולהעריך אותם לצד הכל האחר שאתה צופה בו. זה משלים את [Python SDK](/he/agenteye/python-sdk): ה-SDK מכשיר אגנטים שאתה כותב, בעוד שזה תופס את עבודת ה-Codex שהצוות שלך כבר עושה — בלי שום שינוי באופן שהם מריצים אותה.

אספן רקע קטן קורא תמלילי סשנים מקומיים של Codex כשהם נכתבים ומשלח אותם ל-AgentEye. אספן אחד לכל מכונה תופס כל משטח Codex מקומי בבת אחת — אין הגדרה לכל משטח.

אותו אספן תופס גם אגנטים אחרים — ראה [OpenClaw](/he/agenteye/openclaw-capture) ו-[Hermes](/he/agenteye/hermes-capture). הפעל כל אחד שאתה מריץ; אספן יחיד יכול תפס כמה בו זמנית.

---

## מה זה תופס

כל משטח Codex שרץ **באופן מקומי** מייצר את אותם תמלילי סשנים על הדיסק, והאספן תופס את כולם:

- ה-Codex **CLI** ו-`codex exec`
- ה-**VS Code / IDE extension**
- ה-**desktop app**, כשהוא מריץ סשן באופן מקומי

כל סשן Codex הופך ל-[session](/he/agenteye/sessions) ב-AgentEye; ההודעות שלו של משתמש ועוזר, חשיבה, קריאות כלים, תוצאות כלים, וצריכת טוקנים הופכות ל-[events](/he/agenteye/event-stream) התואמות. המשטח שממנו הגיע כל סשן (CLI, IDE, או desktop) נרשם, כך שתוכל להבדיל ביניהם.

> **סשנים בענן לא נתפסים.** ה-desktop app מריץ כל יותר סשנים בענן ה-Codex ושומר רק על המטא-דטה שלהם על המכונה — אין תמליל מקומי לקרוא. רק סשנים שמבוצעים באופן מקומי נתפסים.

## הפעל זאת

Capture כבוי עד שאתה מפעיל אותו. התקן את האספן עם מפתח API שיש לו הרשאת `events:add` (ראה [API keys](/he/agenteye/api-keys)), והפעל את Codex capture:

```bash
curl -fsSL https://raw.githubusercontent.com/FailproofAI/agenteye-collector/main/install.sh \
  | sh -s -- --key <YOUR_API_KEY> --codex-enabled
```

זה מתקין את האספן, רושם אותו כשירות רקע, ומתחיל לתפוס. אשר שהוא פועל:

```bash
agenteye-collector health
```

בהפעלה ראשונה, הסשנים ה-Codex הקיימים שלך מולאו אחורה פעם אחת ופעילות חדשה זורמת אחרי כן תוך שניות. קבצים שלו של Codex נקראים בלבד — לעולם לא משונים, מועברים, או מחוקים — וכל סשן משלח בדיוק פעם אחת, גם על פני הפעלות מחדש.

---

## היכן זה מופיע

סשנים שנתפסו מופיעים ב-**Sessions**, והאירועים שלהם בזרם **Events**, בדיוק כמו כל סוכן אחר שאתה צופה בו — ולכן [session replay](/he/agenteye/sessions), [search](/he/agenteye/queries), [evaluations](/he/agenteye/evaluations), ו-[alerts](/he/agenteye/alerts) כולם עובדים עליהם. סנן לפי סוכן ה-Codex כדי לראות אותם בעצמם.

---

## פרטיות

תמלילי Codex מכילים את הסשן המלא — כולל פלט פקודה, תוכן קבצים, וכל דבר ש-Codex קרא או כתב — וגם יכולים להכיל סודות. סשנים שנתפסו משלחים כפי שהם, ולכן הפעל capture רק על מכונות וצוותים שבהם ריכוז תוכן זה ב-AgentEye הוא מתאים, ותן לאספן מפתח מתחום עם `events:add` בלבד. ראה [Security](/he/agenteye/security) כדי לדעת איך הנתונים שלך מוחזקים מבודדים.
