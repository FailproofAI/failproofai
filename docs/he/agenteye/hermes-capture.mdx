[Hermes](https://hermes-agent.nousresearch.com) עונה לצוות שלכם מכל מקום בו הם כבר עובדים — Slack, Telegram, ממשק ה-CLI והרצות מתוזמנות. לכידת הפעלות Hermes מביאה את הכל ל-AgentEye כהפעלות ואירועים רגילים, כך שהעוזר אתו צוות שלכם מדבר כל יום הוא בדיוק כמו שניתן להתבונן בסוכנים שאתם כותבים בעצמכם.

אוסף קטן וברקע קורא את אחסון ההפעלות המקומי של Hermes כשהוא נכתב וששולח הפעלות ל-AgentEye. זה פועל באותו אופן כמו לכידת [Codex](/he/agenteye/codex-capture) ו-[OpenClaw](/he/agenteye/openclaw-capture), ואוסף אחד יכול ללכוד מספר בו-זמנית.

---

## מה הוא לוכד

כל הפעלת Hermes במכונה נלכדת, מהערוץ שלה בעדיפות. כל אחת מהן הופכת ל-[הפעלה](/he/agenteye/sessions) ב-AgentEye; הודעות המשתמש והעוזר שלה, קריאות לכלים ותוצאות כלים הופכות ל-[אירועים](/he/agenteye/event-stream) תואמים.

הערוץ שממנו התחילה הפעלה — Slack, Telegram, CLI או הרצה מתוזמנת — מוקלט בהפעלה, כך שתוכלו להבדיל ביניהם ולסנן לאחד בכל פעם. לצדו מופיע המודל שעליו הרצתה ההפעלה, הצ'אט והאדם ממנו היא הופעלה, וכאשר הפעלה יצרה הפעלה אחרת, הקישור חזרה להורה שלה.

הפעלות מופיעות ברגע שבו Hermes מתחיל אותן, בין אם משהו נאמר או לא, ותשובת התור וקריאות הכלים שלה נשארות בסדר בו הן בעצם קרו. כאשר הפעלה מסתיימת, אתם גם מקבלים מדוע היא הסתיימה, כמה היא עלתה וכמה טוקנים היא השתמשה.

## הפעילו את זה

הלכידה כבויה עד שתאפשרו אותה. התקינו את האוסף עם מפתח API שיש לו הרשאת `events:add` (ראה [מפתחות API](/he/agenteye/api-keys)), והפעילו לכידת Hermes:

```bash
curl -fsSL https://raw.githubusercontent.com/FailproofAI/agenteye-collector/main/install.sh \
  | sh -s -- --key <YOUR_API_KEY> --hermes-enabled
```

זה מתקין את האוסף, רושם אותו כשירות ברקע, ומתחיל ללכוד. אימתו שהוא פועל:

```bash
agenteye-collector health
```

ללכוד יותר מסוכן אחד באותה מכונה? הוסיפו את הדגל של כל אחד לאותו פקודה — לדוגמה `--hermes-enabled --codex-enabled`.

בהרצה הראשונה, הפעלות Hermes הקיימות שלכם מולאות בחזרה פעם אחת וגם פעילות חדשה זורמת תוך שניות. הנתונים של Hermes עצמו נקראים בלבד — לעולם לא משונים או מחוקים — וכל הודעה נשלחת פעם אחת, אפילו על פני אתחולים מחדש.

`health` גם אומר לכם האם הכל שהאוסף לכד בעצם הגיע ל-AgentEye. אם אצווה לא יכלה להיות מסופקת היא נשמרת ובוצעת חדשה במקום להיות מושלכת, והבדיקה מדווחת כבריאה לא בריאה בזמן שיש עדיין משהו ממתין — כך ש"בריא" פירושו שהנתונים שלכם הגיעו, לא רק שהתהליך חי.

## איפה זה מופיע

הפעלות שנלכדו מופיעות ב-**Sessions**, והאירועים שלהן בזרם **Events**, בדיוק כמו כל סוכן אחר שאתם משגחים — כך [replay הפעלה](/he/agenteye/sessions), [חיפוש](/he/agenteye/queries), [הערכות](/he/agenteye/evaluations) ו-[התראות](/he/agenteye/alerts) כלם עובדים עליהן. סננו לפי סוכן ה-Hermes כדי לראות אותן בעצמן.

## פרטיות

הפעלות Hermes מכילות את התמלול המלא — כולל פלט פקודה, תוכני קבצים וכל דבר שהסוכן קרא או כתב — ויכולות להכיל סודות. הפעלות שנלכדו נשלחות כפי שהן, כך שהפעילו לכידה רק כאשר ריכוז תוכן זה ב-AgentEye הוא הולם, ותנו לאוסף מפתח המוגבל ל-`events:add` בלבד. ראה [Security](/he/agenteye/security) כדי לדעת כיצד הנתונים שלכם נשמרים מבודדים.
