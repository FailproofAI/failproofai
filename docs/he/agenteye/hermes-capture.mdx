[Hermes](https://hermes-agent.nousresearch.com) עונה לצוות שלך מכל מקום בו הם כבר עובדים — Slack, Telegram, ה-CLI, ריצות מתוזמנות. Hermes session capture מביא את הכל ל-AgentEye כ-session ים ו-event ים רגילים, כך שהעוזר שהצוות שלך מדבר איתו כל יום נצפה בדיוק כמו ה-agent ים שאתה כותב בעצמך.

מאספן רקע קטן קורא את חנות ה-session המקומית של Hermes כשהיא נכתבת ושולח session ים ל-AgentEye. זה עובד באותה דרך כמו [Codex](/he/agenteye/codex-capture) ו-[OpenClaw](/he/agenteye/openclaw-capture) capture, ומאספן אחד יכול ללכוד כמה בו-זמנית.

---

## מה זה לוכד

כל session של Hermes במכונה נלכד, מכל ערוץ שהוא בא ממנו. כל אחד הופך ל-[session](/he/agenteye/sessions) של AgentEye; ההודעות של המשתמש וה-assistant שלו, קריאות tool, ותוצאות tool הופכות ל-[event ים](/he/agenteye/event-stream) התואמים.

הערוץ שממנו התחיל session — Slack, Telegram, CLI, או ריצה מתוזמנת — מתועד ב-session, כך שאתה יכול להבדיל ביניהם ולסנן לאחד בכל פעם. לצידו מגיעים המודל שעליו רץ ה-session, ה-chat והאדם שממנו הוא הוחל, וכאשר session יצר אחר, הקישור חזרה להורה שלו.

Session ים מופיעים ברגע שHermes מתחיל אותם, בין אם נאמר משהו או לא, ותשובה של turn וקריאות ה-tool שלה נשארות בסדר שבו הן בעצם התרחשו. כאשר session מסתיים, אתה גם מקבל למה הוא הסתיים, כמה זה עלה, וכמה token ים הוא השתמש.

## הדלק את זה

Capture כבוי עד שאתה מפעיל אותו. התקן את המאספן עם API key שיש בו את ההרשאה `events:add` (ראה [API keys](/he/agenteye/api-keys)), והדלק את Hermes capture:

```bash
curl -fsSL https://raw.githubusercontent.com/FailproofAI/agenteye-collector/main/install.sh \
  | sh -s -- --key <YOUR_API_KEY> --hermes-enabled
```

זה מתקין את המאספן, רושם אותו כשירות רקע, ומתחיל ללכוד. אשר שהוא פועל:

```bash
agenteye-collector health
```

לוכד יותר מ-agent אחד באותה מכונה? הוסף את הדגל של כל אחד לאותה הפקודה — לדוגמה `--hermes-enabled --codex-enabled`.

בריצה הראשונה, ה-session ים של Hermes הקיימים שלך מתמלאים לאחור פעם אחת ופעילות חדשה אז זורמת תוך שניות. נתוני Hermes של שלו קוראים בלבד — אף פעם לא משונים או נמחקים — וכל הודעה נשלחת פעם אחת, אפילו על פני restarts.

`health` גם אומר לך האם כל מה שהמאספן לכד בעצם הגיע ל-AgentEye. אם batch לא יכול היה להיות מועבר הוא שמור ומנוסה שוב במקום להיות מושלך, והבדיקה דיווח לא בריא בזמן שיש עדיין משהו תלוי — כך "בריא" אומר שהנתונים שלך הגיעו, לא רק שהתהליך חי.

## איפה זה מופיע

Session ים שנתפסו מופיעים ב-**Sessions**, והאירועים שלהם בזרם **Events**, בדיוק כמו agent אחר שאתה צופה בו — כך [session replay](/he/agenteye/sessions), [search](/he/agenteye/queries), [evaluations](/he/agenteye/evaluations), ו-[alerts](/he/agenteye/alerts) כולם עובדים על אלה. סנן לפי ה-Hermes agent כדי לראות אותם בפני עצמם.

---

## פרטיות

Session ים של Hermes מכילים את התמלול המלא — כולל פלט פקודה, תוכן קבצים, וכל מה ש-agent קרא או כתב — ויכול להכיל סודות. Session ים שנתפסו נשלחים כמו שהם, כך שאפשר ללכוד רק כאשר ריכוז תוכן ב-AgentEye הוא מתאים, ותן למאספן מפתח שמוגבל ל-`events:add` בלבד. ראה [Security](/he/agenteye/security) לכיצד הנתונים שלך מובדלים.
