אם הצוות שלך מפעיל את [OpenClaw](https://docs.openclaw.ai), OpenClaw session capture מביא את הסשנים האלה ל-AgentEye כסשנים ואירועים רגילים, כך שתוכל לחפש, להשמיע שוב, ולהעריך אותם בצד הכל השני שאתה צופה בו. זה משלים את [Python SDK](/he/agenteye/python-sdk): ה-SDK מחליל agents שאתה כותב, בעוד שזה תופס את עבודת OpenClaw שהצוות שלך כבר עושה — ללא כל שינוי בדרך הפעלתו.

מאסף רקע קטן קורא את תמלילי הסשן המקומיים של OpenClaw תוך כדי כתיבתם ושולח אותם ל-AgentEye. זה עובד באותו אופן כמו [Codex capture](/he/agenteye/codex-capture), ומאסף אחד יכול לתפוס את שניהם בו זמנית.

---

## מה זה תופס

כל agent שהוגדר בהגדרת OpenClaw של מכונה מסוימת נתפס על ידי מאסף המכונה הזו — אין הגדרה לכל agent.

כל סשן OpenClaw הופך לסשן AgentEye של [session](/he/agenteye/sessions); הודעות המשתמש והעוזר שלו, קריאות הכלים, ותוצאות הכלים הופכות ל[אירועים](/he/agenteye/event-stream) המתאימים.

---

## הפעל את זה

Capture כבוי עד שתפעיל אותו. התקן את המאסף עם מפתח API שיש לו את ההרשאה `events:add` (ראה [API keys](/he/agenteye/api-keys)), והפעל את OpenClaw capture:

```bash
curl -fsSL https://raw.githubusercontent.com/FailproofAI/agenteye-collector/main/install.sh \
  | sh -s -- --key <YOUR_API_KEY> --openclaw-enabled
```

זה מתקין את המאסף, רושם אותו כשירות רקע, ומתחיל תופיסה. אישר שהוא פועל:

```bash
agenteye-collector health
```

תופס יותר מ-agent אחד באותה מכונה? הוסף את הדגל של כל אחד לאותה פקודה — למשל `--openclaw-enabled --codex-enabled`.

בהרצה הראשונה, הסשנים הקיימים שלך של OpenClaw מתמלאים בחזרה פעם אחת ופעילות חדשה אז מזרמת תוך שניות. הקבצים של OpenClaw עצמו נקראים בלבד — לעולם לא שינוי, הורדה, או מחיקה — וכל סשן נשלח בדיוק פעם אחת, אפילו בהתחלות מחדש.

---

## איפה זה מופיע

סשנים תפוסים מופיעים ב-**Sessions**, והאירועים שלהם בזרם **Events**, בדיוק כמו כל agent אחר שאתה צופה בו — כך ש[session replay](/he/agenteye/sessions), [search](/he/agenteye/queries), [evaluations](/he/agenteye/evaluations), ו[alerts](/he/agenteye/alerts) כולם עובדים עליהם. סנן לפי ה-OpenClaw agent כדי לראות אותם בעצמאות.

---

## פרטיות

תמלילי OpenClaw מכילים את הסשן המלא — כולל פלט פקודה, תוכן קבצים, וכל דבר שה-agent קרא או כתב — ויכולים להכיל סודות. סשנים תפוסים משלחים כמו שהם, כך שהפעל capture רק על מכונות וצוותים שבהם מרכוז תוכן זה ב-AgentEye מתאים, ותן למאסף מפתח המוגבל ל-`events:add` בלבד. ראה [Security](/he/agenteye/security) להבנת איך הנתונים שלך מוחזקים מבודדים.
