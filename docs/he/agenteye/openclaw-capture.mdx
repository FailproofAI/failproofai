אם הצוות שלך משתמש ב-[OpenClaw](https://docs.openclaw.ai), תיעוד הפעילויות של OpenClaw מביא את הפעילויות הללו ל-AgentEye כפעילויות ואירועים רגילים, כך שאתה יכול לחפש, להשמיע מחדש ולהעריך אותם לצד כל מה שאתה צופה. זה משלים את [Python SDK](/he/agenteye/python-sdk): ה-SDK מצייד agents שאתה כותב, בעוד שזה תופס את עבודת OpenClaw שהצוות שלך כבר עושה — ללא כל שינוי לאופן הפעולה שלה.

קולט רקע קטן קורא את תמלילי ההפעילויות המקומיות של OpenClaw כשהם נכתבים ושולח אותם ל-AgentEye. זה עובד באותו אופן כמו [Codex capture](/he/agenteye/codex-capture), וקולט אחד יכול ללכוד את שניהם בו-זמנית.

---

## מה זה תופס

כל agent שמוגדר בהגדרת OpenClaw של מכונה מיוצר על ידי הקולט של אותה מכונה — אין הגדרה לכל agent.

כל פעילות של OpenClaw הופכת ל-[פעילות](/he/agenteye/sessions) של AgentEye; הודעות המשתמש והעוזר שלה, קריאות הכלים ותוצאות הכלים הופכות ל-[אירועים](/he/agenteye/event-stream) המתאימים.

---

## הפעל את זה

התיעוד כבוי עד שאתה מפעיל אותו. התקן את הקולט עם מפתח API שיש לו הרשאת `events:add` (ראה [מפתחות API](/he/agenteye/api-keys)), והפעל את תיעוד OpenClaw:

```bash
curl -fsSL https://raw.githubusercontent.com/FailproofAI/agenteye-collector/main/install.sh \
  | sh -s -- --key <YOUR_API_KEY> --openclaw-enabled
```

זה מתקין את הקולט, מרשם אותו כשירות רקע, ומתחיל ללכוד. אשר שהוא פועל:

```bash
agenteye-collector health
```

תופס יותר מ-agent אחד על אותה מכונה? הוסף את הדגל של כל אחד לאותו פקודה — לדוגמה `--openclaw-enabled --codex-enabled`.

בהפעלה הראשונה, הפעילויות הקיימות של OpenClaw שלך מסופקות בחזרה פעם אחת והפעילות החדשה ואז זורמת תוך שניות. הקבצים של OpenClaw עצמו נקראים בלבד — לעולם לא שונו, הועברו או נמחקו — וכל פעילות משפעת בדיוק פעם אחת, אפילו על פני התחלות מחדש.

---

## איפה זה מופיע

פעילויות שיוצרו מופיעות ב-**Sessions**, והאירועים שלהם בזרם **Events**, כמו כל agent אחר שאתה צופה בו — כך ש-[session replay](/he/agenteye/sessions), [חיפוש](/he/agenteye/queries), [הערכות](/he/agenteye/evaluations), ו-[התראות](/he/agenteye/alerts) כולם עובדים עליהם. סנן לפי ה-agent של OpenClaw כדי לראות אותם בעצמם.

---

## פרטיות

תמלילי OpenClaw מכילים את הפעילות המלאה — כולל פלט פקודה, תוכן קבצים וכל דבר שה-agent קרא או כתב — וישנם סודות אפשריים. פעילויות שיוצרו משפעות כמו שהן, ולכן הפעל תיעוד רק על מכונות וצוותים שבהם ריכוז תוכן זה ב-AgentEye הוא מתאים, ותן לקולט מפתח מוגבל ל-`events:add` בלבד. ראה [Security](/he/agenteye/security) לקבלת מידע כיצד הנתונים שלך מוגנים מבודדים.
