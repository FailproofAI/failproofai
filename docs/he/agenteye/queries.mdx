שאל כל שאלה על נתוני הסוכן שלך וקבל תשובה בשניות. Failproof AI Observability נותן לך ספריית שאילתות שמורות וגמורות להפעלה על האירועים וההערכות שלך, כך שאתה מתחיל מדוגמה עובדת במקום מעורך SQL ריק.

![ספריית השאילתות השמורות: רשת של שאילתות לשימוש חוזר, גם הפריסטים המובנים וגם אלה המותאמים](/agenteye/images/queries.png)

*ספריית השאילתות השמורות שלך ב`/<org-slug>/queries`: הפריסטים המובנים יושבים לצד השאילתות שהצוות שלך שמר.*

## התחל מפריסט, לא מעמוד ריק

אתה לא צריך לזכור שמות טבלאות או לכתוב SQL מאפס. הספריה נפתחת עם פריסטים מובנים לשאלות שהצוותים שואלים הכי הרבה, יושבים בדיוק לצד השאילתות שהצוות שלך שמר וקרא להן. בחר אחת שקרובה למה שאתה רוצה וחצי הדרך לתשובה בידיים שלך.

כל שאילתה שמורה היא בהיקף הארגון ושותפה, כך ששאילתות שימושיות שהעמיתים שלך כותבים הופכות גם להן שלך. תן שם לשאילתה, תן לה תיאור פעם אחת, וכל אחד בארגון שלך יכול למצוא אותה, להריץ אותה, או לצמד את התוצאות שלה לדשבורד מאוחר יותר.

מצא אותה ב`/<org-slug>/queries`.

## התאם אותה והרץ אותה בקומפוזר SQL

פתח כל שאילתה והיא תנחת בקומפוזר SQL, שם אתה יכול להתאים אותה ולראות את התשובה תוך זמן קצר: אין ייצוא, אין תור חזרה, אין המתנה למישהו אחר.

![קומפוזר שאילתות SQL המריץ שאילתה שמורה, עם סרגל צד של סכימה ורשת תוצאות חי](/agenteye/images/query-lab.png)

*קומפוזר SQL: השאילתה שלך משמאל, סרגל צד של סכימה כך שאתה לא משער שם עמודה, ורשת תוצאות חי למטה.*

- **סרגל צד של סכימה** פורש את טבלאות האנליטיקה והעמודות שלהן, כך שאתה יכול ליצור שאילתה בלי לציד שמות שדות.
- **רשת תוצאות חי** מחזירה שורות ברגע שאתה מריץ, כך שאתה חוזר עליה בשניות במקום לנחש ולנחש שוב.
- **קריאה בלבד בעיצוב.** שאילתות מריצות כנגד חנות האירועים שלך והן תקפות בשרת: רק הצהרות `SELECT` ו`WITH` מותרות, עם timeout של הצהרה וקאפ שורה. שאילתה חקרונית לעולם לא יכולה לשנות את הנתונים שלך, ואחת שברחה מתוקפת בשבילך.

שמח עם התוצאה? שמור אותה חזרה לספריה כדי שכל הצוות יוכל להשיג אותה, או צמד את הפלט שלה לדשבורד כאריח קו, עמוד, אזור או עוגה.

## הרץ אותן מהטרמינל, או תן לעוזר לכתוב אותן

אותן שאילתות שמורות עוקבות אחריך לכל מקום בו אתה עובד:

- **מהטרמינל.** ה`agenteye` CLI מפרט, מריץ וחוסך את אותן שאילתות בדיוק, כך שאתה יכול להוריד תוצאה לתוך סקריפט, לחוט אותה ל CI, או להעביר אותה לסוכן קידוד.

```bash
agenteye query list                 # the same saved queries, from your terminal
agenteye query run errs --arg prod  # run one and print the rows (add --json to pipe it)
```

  ראה [CLI and agents](/he/agenteye/cli-and-agents) לקבוצת הפקודה המלאה.

- **מהעוזר AI.** לא בטוח איך לנסח את ה SQL? שאל את [עוזר AI](/he/agenteye/assistant) בדשבורד באנגלית פשוטה והוא יעצור את השאילתה וישמור אותה לספריה שלך בשבילך.

הריצה של שאילתה שמורה מוגדרת בגבול על ידי הרשאת `queries:run`, המוחזקת בנפרד מההרשאות ליצירה או מחיקת שאילתות, כך שאתה יכול לתן גישת קריאה בלי לתת לכולם לשכתב את הספריה.
