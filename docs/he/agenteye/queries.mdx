שאל כל שאלה על נתוני הסוכן שלך וקבל תשובה בשניות. Failproof AI Observability נותן לך ספריה של שאילתות שמורות וגמורות לריצה על האירועים והערכות שלך, כך שאתה מתחיל מדוגמה עובדת במקום עורך SQL ריק.

![ספריית השאילתות השמורות: רשת של שאילתות בר-שימוש חוזר, הן תצוגות מובנות והן אלה מותאמות אישית](/agenteye/images/queries.png)

*ספריית השאילתות השמורות שלך בכתובת `/<org-slug>/queries`: תצוגות מובנות יושבות לצד השאילתות שהצוות שלך שמר.*

## התחל מתצוגה מוגדרת, לא מעמוד ריק

אתה לא צריך לזכור שמות טבלאות או לכתוב SQL מאפס. הספריה נפתחת עם תצוגות מובנות לשאלות שהצוותים שואלים כי הכי הרבה, יושבות ממש לצד השאילתות שהצוות שלך שמר וקרא לו. בחר באחד שקרוב למה שאתה רוצה ואתה בדרך הטובה ביותר לתשובה.

כל שאילתה שמורה היא בתחום הארגון ומשותפת, ולכן גם ההיענויות שהשותפים שלך כותבים הופכות להיות שלך. קרא לשאילתה תן לה תיאור פעם אחת, וכל אחד בארגון שלך יכול למצוא אותה, להריץ אותה, או להצמיד את התוצאות שלה לדשבורד מאוחר יותר.

מצא את זה בכתובת `/<org-slug>/queries`.

## התאם אותה והריץ אותה ב-composer ה-SQL

פתח כל שאילתה וזה נוחת ב-SQL composer, כאשר אתה יכול להתאים אותה ולראות את התשובה מיד: אין ייצוא, אין הלוך וחזור, אין המתנה למישהו אחר.

![ה-SQL query composer שמריץ שאילתה שמורה, עם sidebar סכימה ורשת תוצאות חיה](/agenteye/images/query-lab.png)

*ה-SQL composer: השאילתה שלך בצד שמאל, sidebar סכימה כדי שלעולם לא תנחש שם עמודה, ורשת תוצאות חיה למטה.*

- **Sidebar סכימה** מפרק את טבלאות האנליטיקה והעמודות שלהם, כך שאתה יכול לעצב שאילתה בלי לחפש שמות שדות.
- **רשת תוצאות חיה** מחזירה שורות ברגע שאתה מריץ, כך שאתה חוזר על עצמך בשניות במקום לנחש ולחזור על עצמו.
- **קריאה בלבד בעיצוב.** שאילתות רצות נגד חנות האירועים שלך ומוודאות בשרת: רק הצהרות `SELECT` ו-`WITH` מורשות, עם timeout הצהרה ותקרת שורה. שאילתה חקר לא יכולה אף פעם לשנות את הנתונים שלך, והיא שנגרמה לך מופסקת בשבילך.

שמחה עם התוצאה? שמור אותה חזרה לספריה כדי שהצוות כולו יירש אותה, או הצמד את הפלט שלה לדשבורד כ-line, bar, area או pie tile.

## הריץ אותם מהטרמינל, או תן לעוזר לכתוב אותם

אותן שאילתות שמורות עוקבות אחריך בכל מקום שבו אתה עובד:

- **מהטרמינל.** ה-CLI של `agenteye` מפרט, מריץ, ושומר את בדיוק אותן שאילתות, כך שאתה יכול להוריד תוצאה לתוך סקריפט, חוט אותה ל-CI, או להעביר אותה לסוכן קידוד.

```bash
agenteye query list                 # the same saved queries, from your terminal
agenteye query run errs --arg prod  # run one and print the rows (add --json to pipe it)
```

  ראה [CLI and agents](/he/agenteye/cli-and-agents) עבור מערך הפקודה המלא.

- **מעוזר ה-AI.** לא בטוח איך לנסח את ה-SQL? שאל את [עוזר ה-AI](/he/agenteye/assistant) בתוך הדשבורד באנגלית פשוטה וזה יעצב את השאילתה ויחסוך אותה לספריה שלך בשבילך.

הריצת שאילתה שמורה מוגנת על ידי הרשאת `queries:run`, שמורה בנפרד מההרשאות ליצור או למחוק שאילתות, כך שתוכל להעניק גישה קריאה בלי לתת לכולם לשכתב את הספריה.
