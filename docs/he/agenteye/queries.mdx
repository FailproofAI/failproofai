שאל כל שאלה על נתוני הסוכן שלך וקבל תשובה תוך שניות. Failproof AI Observability נותן לך ספריית שאילתות שמורות וגמורות להפעלה על האירועים וההערכות שלך, כך שאתה מתחיל מדוגמה עובדת במקום מעורך SQL ריק.

![ספריית השאילתות השמורות: רשת של שאילתות שניתן להשתמש בהן מחדש, גם קביעות מובנות וגם מותאמות אישית](/agenteye/images/queries.png)

*ספריית השאילתות השמורות שלך ב־`/<org-slug>/queries`: קביעות מובנות ליד השאילתות שהצוות שלך שמר.*

## התחל מקביעה מסומנת, לא מעמוד ריק

אתה לא צריך לזכור שמות של טבלאות או לכתוב SQL מאפס. הספרייה נפתחת עם קביעות מובנות לשאלות שהצוותים שואלים בתדירות הגבוהה ביותר, ממש ליד השאילתות שהצוות שלך שמר ותייג. בחר אחת שקרובה למה שאתה רוצה ואתה כבר חצי הדרך לתשובה.

כל שאילתה שמורה היא בהיקף ארגון וזמינה לשיתוף, כך שהשאילתות השימושיות שעמיתיך כותבים הופכות לשלך גם כן. תן שם לשאילתה וכתוב לה תיאור פעם אחת, וכל אחד בארגון שלך יכול למצוא אותה, להריץ אותה, או להדביק את התוצאות שלה לתצוגת מידע מאוחר יותר.

תמצא אותה ב־`/<org-slug>/queries`.

## התאם אותה והרץ אותה במחבר SQL

פתח כל שאילתה והיא תנחת במחבר SQL, שם אתה יכול להתאים אותה ולראות את התשובה מיד: ללא ייצוא, ללא הקפצה הלוך וחזור, ללא המתנה למישהו אחר.

![מחבר שאילתות SQL המריץ שאילתה שמורה, עם סרגל צד של סכמה ורשת תוצאות חיה](/agenteye/images/query-lab.png)

*מחבר SQL: השאילתה שלך בצד שמאל, סרגל צד של סכמה כדי שלא תצטרך לנחש שם עמודה, ורשת תוצאות חיה למטה.*

- **סרגל צד של סכמה** מפרט את טבלאות הניתוח והעמודות שלהן, כדי שתוכל ליצור שאילתה ללא חפוש אחר שמות שדות.
- **רשת תוצאות חיה** מחזירה שורות ברגע שאתה מריץ, כדי שתוכל לעשות איטרציה תוך שניות ולא לנחש ולנחש שוב.
- **קריאה בלבד בעיצוב.** שאילתות מתבצעות כנגד חנות האירועים שלך ומאומתות בשרת: רק הצהרות `SELECT` ו־`WITH` מותרות, עם זמן קצובה של הצהרה וגבול שורות. שאילתה חקרנית לעולם לא יכולה לשנות את הנתונים שלך, ואחת שהתפרוזה מעצרת עבורך.

מרוצה מהתוצאה? שמור אותה חזרה לספרייה כדי שהצוות כולו יוכל להרוויח ממנה, או הדבק את הפלט שלה לתצוגת מידע כאריח קו, עמודה, אזור או עוגה.

## הרץ אותן מהטרמינל, או תן לסוכן AI לכתוב אותן

אותן שאילתות שמורות עוקבות אחריך למקום שבו אתה עובד:

- **מהטרמינל.** CLI ה־`agenteye` מפרט, מריץ ושומר את אותן שאילתות בדיוק, כדי שתוכל להשמיט תוצאה לתוך סקריפט, לחווט אותה ל־CI, או להסגיר אותה לסוכן קידוד.

```bash
agenteye query list                 # the same saved queries, from your terminal
agenteye query run errs --arg prod  # run one and print the rows (add --json to pipe it)
```

  ראה [CLI וסוכנים](/he/agenteye/cli-and-agents) לקבוצת הפקודות המלאה.

- **מעוזר ה־AI.** לא בטוח איך לנסח את ה־SQL? שאל את עוזר ה־AI בתצוגת המידע ב[אנגלית פשוטה](/he/agenteye/assistant) והוא יעצור את השאילתה ויחזיר אותה לספרייה עבורך.

הפעלת שאילתה שמורה נשמרת על ידי הרשאת `queries:run`, המופרדת מההרשאות ליצור או למחוק שאילתות, כדי שתוכל להעניק גישת קריאה ללא כניסה לכולם.
