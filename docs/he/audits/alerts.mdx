התראות עוקבות אחרי תנאי הניתן למדידה ויוצרות אירוע כאשר הוא מופעל. השתמש בהן כאשר כשל צריך לייצור תגובה בזמן, בין אם מדיניות יכולה לחסום אותו או לא.

## יצירה ובדיקה של התראה

<Tabs>
  <Tab title="Dashboard">
    1. עבור ל-**Analyze → Alerts** ובחר **new alert**. אתה יכול גם להתחיל מהפעמון על שגיאה מייצגת.
    2. הזן את השם, החומרה, סוג ההפעלה, התנאי, מרווח ההערכה, ספירת ההפרה, החלון וערוצים.
    3. שמור את ההתראה, פתח את דף הפירוטים שלה והפעל **test**.
    4. עבור ל-**Analyze → Issues** כדי להודות, להקצות, לדון, להירשם וליישב אירועים שנוצרו על ידי ההתראה.

    החלק הראשון של הטופס מזהה את ההתראה והאות שאמורה להפעיל אותה.

    ![החלק הראשון של טופס new-alert עם שם, תיאור, מצב מופעל וסוג הפעלה.](/images/dashboard/alert-new-trigger.png)

    החלק השני שולט כמה זמן התנאי חייב להיות קיים, בכמה קצב הוא מוערך ולאן נשלחות הודעות.

    ![החלק השני של טופס new-alert עם לוגיקת הפרה, לוח זמנים, חומרה, ערוצי משלוח ופעולת יצירה.](/images/dashboard/alert-new-routing.png)

    לאחר השמירה, השתמש בחائמת ההתראות כדי לאשר שהכלל פעיל וש-trigger, window, severity וערוצים שלו תואמים את מה שהתכוונת.

    ![דף ההתראות המציג כללי התראה עם ה-triggers, חלונות הערכה, ערוצים וחומרה שלהם.](/images/dashboard/alerts.png)

    בדוק את ההתראה לפני שתסתמך עליה לתגובה בייצור.
  </Tab>
  <Tab title="CLI">
    ```bash
    fp alerts create high-errors \
      --trigger-kind metric_threshold \
      --severity warning \
      --trigger-spec '{"metric":"error_count","op":">","value":50,"window_secs":900}'

    fp alerts show high-errors
    fp alerts test high-errors
    fp alerts update high-errors --severity critical --yes
    ```

    השתמש ב-`fp alerts list` כדי לסקור כללים וב-`fp alerts delete <name>` כדי להסיר אחד.

    ראה את ההפניה של [`fp alerts`](/he/reference/cloud-cli#alerts) לקבוצת הפקודות השלמה של ההתראות.
  </Tab>
</Tabs>

תנאי התראה יכולים להיות מבוססים על שגיאות, ציוני הערכה, שילובי הערכה או SQL מותאם. הוסף מקבלים, בדוק את הכלל ופתח את האירוע המתקבל כדי להודות, להקצות, להגיב, להירשם וליישב אותו.

## עיצוב התראה טוב

- שם את התנאי וזרימת העבודה המושפעת.
- הגדר את הסביבה בבירור.
- הגדר חלון וסף המונעים תגובה לאירוע חסר ערך יחיד.
- כלול קישור או שאילתה המובילים לתגובות לשיחות.
- הקצה בעלים לפני הפעלת הכלל.

<Tip>
  לאחר פתרון ממצא ביקורת, הוסף התראה כאשר אותו כשל יכול להחזור מחוץ לכיסוי המדיניות.
</Tip>
