התראות צופות בתנאי מדיד ויוצרות תקרית כאשר הוא מופעל. השתמש בהן כאשר כשל צריך לייצר תגובה בזמן, בין אם מדיניות יכולה לחסום אותו או לא.

## יצירה וקבלת החלטה על התראה

<Tabs>
  <Tab title="Dashboard">
    1. עבור אל **Analyze → Alerts** ובחר **new alert**. אתה יכול גם להתחיל מהפעמון בשגיאה מייצגת.
    2. הזן את השם, הגדירות, סוג הטריגר, התנאי, מרווח ההערכה, ספירת ההפרה, החלון, והערוצים.
    3. שמור את ההתראה, פתח את דף הפרטים שלה, והפעל **test**.
    4. עבור אל **Analyze → Issues** כדי לאשר, להקצות, לדון, להירשם ולפתור תקריות שנוצרו על ידי ההתראה.

    החלק הראשון של הטופס מזהה את ההתראה והאות שאמורה להפעיל אותה.

    ![החלק הראשון של טופס new-alert עם השם, התיאור, מצב מופעל, וסוג טריגר.](/images/dashboard/alert-new-trigger.png)

    החלק השני שולט כמה זמן התנאי חייב להימשך, באיזו תדירות הוא מוערך, וההודעות נשלחות.

    ![החלק השני של טופס new-alert עם לוגיקת הפרה, לוח זמנים, גדירות, ערוצי משלוח, ופעולת יצירה.](/images/dashboard/alert-new-routing.png)

    לאחר השמירה, השתמש ברשימת ההתראות כדי לאשר שהכלל מופעל וש-trigger, window, severity, וערוצים שלו תואמים את הכיוונים שלך.

    ![עמוד ההתראות המציג כללי התראה עם triggers, חלונות הערכה, ערוצים, וגדירות.](/images/dashboard/alerts.png)

    קבל החלטה על ההתראה לפני שאתה מסתמך עליה לתגובה בייצור.
  </Tab>
  <Tab title="CLI">
    ```bash
    fp alerts create high-errors \
      --trigger-kind metric_threshold \
      --severity warning \
      --trigger-spec '{"metric":"error_count","op":">","value":50,"window_secs":900}'

    fp alerts show high-errors
    fp alerts test high-errors
    fp alerts update high-errors --severity critical --yes
    ```

    השתמש ב-`fp alerts list` כדי לבחון כללים וב-`fp alerts delete <name>` כדי להסיר כלל.

    ראה את ההפניה [`fp alerts`](/he/reference/cloud-cli#alerts) לקבוצת הפקודות הושלמה של התראה.
  </Tab>
</Tabs>

תנאי התראה יכולים להיות מבוססים על שגיאות, ניקוד הערכה, שילובי הערכה, או SQL מותאם. הוסף נמענים, קבל החלטה על הכלל, ופתח את התקרית שנוצרה כדי לאשר, להקצות, להגיב, להירשם ולפתור אותה.

## תכנון התראה טוב

- תן שם לתנאי וזרימת העבודה המושפעת.
- הגדר את הסביבה בצורה מפורשת.
- קבע חלון וסף שמונעים תגובה לאירוע אחד חסר נזק.
- כלול קישור או שאילתה שמובילים נושאים לתוך הפעלות.
- הקצה בעלים לפני הפעלת הכלל.

<Tip>
  לאחר פתרון ממצא ביקורת, הוסף התראה כאשר אותו כשל יכול להחזור מחוץ לכיסוי המדיניות.
</Tip>
