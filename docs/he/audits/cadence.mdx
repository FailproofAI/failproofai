השתמש בביקורות חוזרות עבור אופני כשל שיכולים להחזור כאשר סוכנים, הנחיות, כלים ודגמים משתנים.

## שינוי לוח הזמנים

<Tabs>
  <Tab title="Dashboard">
    1. עבור אל **Analyze → Audits** ופתח את הביקורת.
    2. פתח את ההגדרות שלה ושנה את מצב ההפעלה, המרווח, עוגן ה-UTC, מצב החלון או ה-lookback.
    3. שמור את הביקורת ובדוק את זמן ההרצה הבא בכרטיס הביקורת.
    4. השתמש ב-**run now** פעם אחת לאחר שינוי היקף או הקשר משמעותי.

    ![עורך הביקורת המציג קדנס, חלון סוויפ, היקף, הגדרות ניתוח, הקשר וערוצי התראה.](/images/dashboard/audit-edit.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp audits edit checkout-reliability \
      --schedule-interval-secs 86400 \
      --schedule-anchor 2026-08-15T09:00:00Z \
      --lookback-window-secs 86400 \
      --yes

    fp audits edit checkout-reliability --disabled --yes
    fp audits edit checkout-reliability --enabled --yes
    ```

    ראה את הסימוכין של [`fp audits`](/he/reference/cloud-cli#audits) עבור גבולות לוח זמנים, התנהגות החלון וכל פקודות הביקורת.
  </Tab>
</Tabs>

בחר קדנס מהירות והעלות של הסיכון:

| דפוס סיכון | קדנס התחלתי |
| --- | --- |
| פעולת ייצור בעלת השפעה גבוהה | יומי |
| רגרסיה בזרימת עבודה או דגם | שבועי |
| ביקורת ממשל או גישה | חודשי |
| חקירת שחרור חד-פעמית | הרץ פעם אחת |

יישר את חלון ה-lookback עם הקדנס כך שהרצות לא תעזוב פערים וגם לא יבדקו מחדש אוכלוסיה גדולה לא הכרחית. לאחר שינוי המטרה או ההקשר של ביקורת, הרץ אותה ידנית פעם אחת לפני התיעדוד על התוצאה המתוזמנת הבאה.

<Note>
  ביקורות מתוזמנות מקומיות מוגדרות במכונה וסורקות היסטוריית סוכן מקומית. לוח הזמנים של ביקורות ענן פועל בהפעלות ענן. התייחס לתוצאות הבעלות שלהם בנפרד.
</Note>
