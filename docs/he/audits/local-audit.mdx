השתמש בביקורת מקומית לבדיקה מיידית וחסויה לפני חיבור מכונה ל-Failproof AI Cloud. זה סורק את היסטוריות הסוכנים המאוחסנות כבר במכונה שלך, משגר פעילות כלים דרך מדיניות מובנית, ופותח לוח בקרה מקומי לתוצאות.

## הפעלת ביקורת אינטראקטיבית

<Tabs>
  <Tab title="Dashboard">
    הביקורת המקומית מתחילה מה-CLI מכיוון שעליה לגלות היסטוריות במכונה הנוכחית. הפעל `failproofai audit`; לאחר הסריקה, Failproof AI מפעיל את לוח הבקרה המצורף ופותח את **http://localhost:8020/audit**.

    בתצוגת הביקורת, בדוק את מספר ההפעלות, קריאות הכלים, הפרויקטים וקריאות המדיניות. התחל עם ממצאים תכופים, ואז בדוק את הפרויקט המושפע וההיסטוריה של הסוכן לפני הפעלת אכיפה.

    <Info>לוח הבקרה של הביקורת המקומית נפרד מ-**Analyze → Audits** ב-Failproof AI Cloud. ביקורות מקומיות נשארות במכונה ואינן דורשות חשבון או חיבור רשת.</Info>
  </Tab>
  <Tab title="CLI">
    ```bash
    npm install -g failproofai
    failproofai audit
    ```

    הפקודה מבצעת סריקה מלאה של כל היסטוריה בתמיכה שהיא מוצאת. הפקודה הנוכחית לא מקבלת מסננים כמו `--since`, `--cli`, `--project`, `--port`, או `--no-open`.

    שמור את התהליך פועל בזמן שאתה משתמש בלוח הבקרה המקומי. לחץ על <kbd>Ctrl</kbd>+<kbd>C</kbd> כאשר סיימת.
  </Tab>
</Tabs>

מתאמי הביקורת הנוכחיים יכולים לקרוא היסטוריות מ-Claude Code, Codex, GitHub Copilot CLI, Cursor, OpenCode, Pi, Hermes, OpenClaw, Factory, Devin, Antigravity, ו-Goose. רק היסטוריות זמינות מקומית נסרקות.

## תזמון ביקורות מקומיות חוזרות

<Tabs>
  <Tab title="Dashboard">
    פתח **Settings** בלוח הבקרה המקומי, הפעל ביקורות מתוכננות, בחר את המרווח, והגדר את כתובת הדוא"ל שצריכה לקבל ממצאים. לוח הבקרה ו-CLI מעדכנים את אותה תצורת מכונה.
  </Tab>
  <Tab title="CLI">
    הפעל ביקורת שבועית ושלח ממצאים לכתובת בשם:

    ```bash
    failproofai audit --schedule 7 --email reliability@example.com
    failproofai audit --status
    ```

    המרווח מקבל 1-90 ימים וברירת המחדל היא 7 כאשר מושמט. התקנה ראשונה מחתמת אותך כאשר נדרש; `--email` מספק את כתובת הדוח מבלי להנחות.

    עצור את ההזמנה מבלי למחוק היסטוריית ביקורת מקומית:

    ```bash
    failproofai audit --no-schedule
    ```
  </Tab>
</Tabs>

ה-daemon מפעיל סריקות מתוכננות ברקע, מרענן את התוצאה בטמון בשימוש בלוח הבקרה המקומי, ושולח דוא"ל לדוח המוגדר. השתמש ב-`failproofai audit` כאשר אתה רוצה להפעיל סריקה אינטראקטיבית מיידית.

## מעבר מהראיות המקומיות לפעולות Cloud

ביקורת מקומית היא קו בסיס מהיר. חבר את המכונה ל-Failproof AI Cloud כאשר אתה זקוק לעקבות משותפים, ביקורות אוכלוסייה חוזרות, ממצאים ובעיות, התראות, פריסת מדיניות בכל הארגון, או בריאות צי.
