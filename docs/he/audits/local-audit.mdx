Failproof AI クラウドにマシンを接続する前に、ローカル監査を使用して即座にプライベートなレビューを実行します。マシンに既に保存されているエージェント履歴をスキャンし、組み込みポリシーを通じてツールアクティビティを再生し、ローカル結果ダッシュボードを開きます。

## インタラクティブ監査を実行する

<Tabs>
  <Tab title="ダッシュボード">
    ローカル監査は、現在のマシン上の履歴を発見する必要があるため、CLI から開始します。`failproofai audit` を実行します。スキャン後、Failproof AI がバンドルされたダッシュボードを起動し、**http://localhost:8020/audit** を開きます。

    監査ビューでは、セッション数、ツール呼び出し、プロジェクト、およびポリシーヒット数を確認します。頻繁な検出から開始し、その後、適用を有効にする前に影響を受けたプロジェクトとエージェント履歴を検査します。

    <Info>ローカル監査ダッシュボードは、Failproof AI クラウドの **Analyze → Audits** とは別です。ローカル監査はマシンに残り、アカウントやネットワーク接続は必要ありません。</Info>
  </Tab>
  <Tab title="CLI">
    ```bash
    npm install -g failproofai
    failproofai audit
    ```

    コマンドは、見つかるすべてのサポートされている履歴の完全スキャンを実行します。現在のコマンドは、`--since`、`--cli`、`--project`、`--port`、または `--no-open` などのフィルターを受け入れません。

    ローカルダッシュボードを使用する間、プロセスを実行したままにしておきます。完了したら <kbd>Ctrl</kbd>+<kbd>C</kbd> を押します。
  </Tab>
</Tabs>

現在の監査アダプターは、Claude Code、Codex、GitHub Copilot CLI、Cursor、OpenCode、Pi、Hermes、OpenClaw、Factory、Devin、Antigravity、および Goose から履歴を読み取ることができます。ローカルで利用可能な履歴のみがスキャンされます。

## 定期的なローカル監査をスケジュール設定する

<Tabs>
  <Tab title="ダッシュボード">
    ローカルダッシュボードで **Settings** を開き、スケジュール設定された監査を有効にし、間隔を選択し、検出結果を受け取るメールアドレスを設定します。ダッシュボードと CLI は同じマシン設定を更新します。
  </Tab>
  <Tab title="CLI">
    週間監査を有効にし、指定されたアドレスに検出結果を送信します。

    ```bash
    failproofai audit --schedule 7 --email reliability@example.com
    failproofai audit --status
    ```

    間隔は 1～90 日を受け入れ、省略された場合はデフォルトで 7 になります。最初のセットアップは必要に応じてサインインします。`--email` はプロンプトなしでレポートアドレスを指定します。

    ローカル監査履歴を削除せずにスケジュールを停止します。

    ```bash
    failproofai audit --no-schedule
    ```
  </Tab>
</Tabs>

デーモンはバックグラウンドでスケジュール設定されたスキャンを実行し、ローカルダッシュボードで使用されるキャッシュ結果を更新し、設定されたレポートをメール送信します。インタラクティブスキャンをすぐに実行したい場合は、`failproofai audit` を使用します。

## ローカルエビデンスからクラウド操作へ移動する

ローカル監査は高速なベースラインです。共有トレース、定期的な母集団監査、検出結果と問題、アラート、組織全体のポリシー展開、またはフリートヘルスが必要な場合は、マシンを Failproof AI クラウドに接続します。

<CardGroup cols={2}>
  <Card title="クラウド監査を作成する" icon="scan-search" href="/he/audits/setup">
    定期的な目標、母集団、エビデンスウィンドウ、およびレスポンスチャネルを定義します。
  </Card>
  <Card title="ポリシーを有効にする" icon="shield-check" href="/he/start/first-policy">
    ローカルで検証し、慎重に公開し、まず狭いマシングループに展開します。
  </Card>
</CardGroup>

<Warning>
  監査出力は、フラグが付いたすべてのアクションが安全でないことの証拠であり、証明ではありません。検出を適用の強制に変える前に、コンテキストを確認してください。
</Warning>
