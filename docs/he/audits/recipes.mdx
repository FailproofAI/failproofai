השתמש באלה כיעדים ראשוניים, ואז הוסף את הסוכן, הסביבה וזרימת העבודה הצפויה שלך.

<Tabs>
  <Tab title="Dashboard">
    עבור אל **Analyze → Audits → New audit**, העתק מתכון אחד לתיאור או תקציר, ואז הוסף את הסביבה, הסוכן, lookback וכתובות הURL של הייחוס הרלוונטיות. צור את הביקורת וציין את ההרצה הראשונה לפני שאתה קובע אותה.

    טופס הביקורת החדש הופך מתכון לבדיקת כשל ניתנת להפעלה על ידי הוספת היקף, הקשר, קדנציה וערוצי התראה.

    ![טופס הביקורת החדש שהוגדר עם יעד ממוקד, לוח זמנים, היקף סוכן וסביבה, הקשר וערוצי התראה.](/images/dashboard/audit-new.png)

    לאחר היצירה, אשר שהביקורת מופיעה ברשימה עם הסטטוס והלוח הזמנים הצפויים לפני התנחמות על הרצות חוזרות.

    ![עמוד הביקורות שבו מתכון ביקורת ספציפי לזרימת עבודה מופיע לאחר יצירה.](/images/dashboard/audits.png)

    פתח את ההרצה הראשונה וחדד את המתכון אם הממצאים שלו רחבים יותר או צרים יותר מממוד הכשל המיועד.
  </Tab>
  <Tab title="CLI">
    שמור מתכון כקובץ טקסט ושיתף אותו במהלך היצירה:

    ```bash
    fp audits create retry-loop-review \
      --scope '{"environments":["production"]}' \
      --text-file ./retry-loop-audit.txt \
      --schedule-interval-secs 86400
    ```
  </Tab>
</Tabs>

<AccordionGroup>
  <Accordion title="לולאות ניסיון חוזרות">
    מצא הפעלות שבהן הסוכן חוזר על אותה קריאת כלי נכשלה ללא שינוי קלט, בחירת כלי חלופי או הסלמה לאדם.
  </Accordion>
  <Accordion title="שימוש כלי שגוי">
    מצא הפעלות שבהן הכלי שנבחר אינו תואם את המשימה המוצהרת, או שקלט הכלי מפר את התנאים המקדימים הנדרשים של זרימת העבודה.
  </Accordion>
  <Accordion title="גישה לנתונים לא בטוחה">
    מצא הפעלות שקוראות, כותבות או משדרות נתונים רגישים מחוץ לנתיבים והשירותים המאושרים של סוכן זה.
  </Accordion>
  <Accordion title="עזיבת משימה">
    מצא הפעלות שמסתיימות ללא התוצאה המבוקשת, שגיאה ברורה או מסירה מפורשת לאדם.
  </Accordion>
  <Accordion title="ירידה בעלות או בעיכוב">
    מצא הפעלות שדגם, כלי או משך הזמן הכולל עולה על התקציב הצפוי, וזהה את דפוס האירוע האחראי.
  </Accordion>
  <Accordion title="הסלמה אנושית שהוחמצה">
    מצא הפעלות שבהן ביטחון, כשל חוזר או הדרכה מדיניות דרשו החלטה אנושית אך הסוכן המשיך באופן עצמאי.
  </Accordion>
</AccordionGroup>
