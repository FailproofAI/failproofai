השתמש באלה כיעדים התחלתיים, ואז הוסף את הסוכן, הסביבה והזרימת העבודה הצפויה שלך.

<Tabs>
  <Tab title="Dashboard">
    עבור אל **Analyze → Audits → New audit**, העתק מתכון אחד לתוך התיאור או הסיכום, ואז הוסף את הסביבה, הסוכן, lookback והתייחסות לכתובות URL הרלוונטיות. צור את הביקורת ובדוק את ההרצה הראשונה לפני תזמונה.

    טופס הביקורת החדש הופך מתכון למבחן כשל הניתן להפעלה על ידי הוספת היקף, הקשר, קדנציה והודעות.

    ![טופס הביקורת החדש מוגדר עם יעד ממוקד, לוח זמנים, סוכן והיקף סביבה, הקשר וערוצי הודעה.](/images/dashboard/audit-new.png)

    לאחר היצירה, אשר שהביקורת מופיעה ברשימה עם הסטטוס והלוח הזמנים הצפויים לפני שמסתמכים על הרצות חוזרות.

    ![דף הביקורות כאשר מתכון ביקורת ספציפי לזרימת עבודה מופיע לאחר היצירה.](/images/dashboard/audits.png)

    פתח את ההרצה הראשונה וחדד את המתכון אם הממצאים שלו רחבים או צרים יותר ממצב הכשל המיועד.
  </Tab>
  <Tab title="CLI">
    שמור מתכון כקובץ טקסט וצרף אותו במהלך היצירה:

    ```bash
    fp audits create retry-loop-review \
      --scope '{"environments":["production"]}' \
      --text-file ./retry-loop-audit.txt \
      --schedule-interval-secs 86400
    ```
  </Tab>
</Tabs>

<AccordionGroup>
  <Accordion title="לולאות חזרה חוזרות">
    מצא הפעלות שבהן הסוכן חוזר על אותה קריאת כלי נכשלת ללא שינוי קלט, בחירה בכלי חלופי או הסלמה לאדם.
  </Accordion>
  <Accordion title="שימוש בכלי לא נכון">
    מצא הפעלות שבהן הכלי הנבחר אינו תואם לגם משימה, או שבהן קלט כלי מפר תנאי מוקדמים נדרשים של זרימת העבודה.
  </Accordion>
  <Accordion title="גישה לא בטוחה לנתונים">
    מצא הפעלות הקוראות, כותבות או משדרות נתונים רגישים מחוץ לנתיבים והשירותים המאושרים לסוכן זה.
  </Accordion>
  <Accordion title="עזיבת משימה">
    מצא הפעלות שמסתיימות ללא התוצאה המבוקשת, שגיאה ברורה או הסלמה מפורשת לאדם.
  </Accordion>
  <Accordion title="רגרסיה בעלות או בזמן אחזור">
    מצא הפעלות שבהן משך הזמן של הדגם, הכלי או הכללי חורג מהתקציב הצפוי, וזהה את דפוס האירועים האחראי.
  </Accordion>
  <Accordion title="הסלמה אנושית שנעלמה">
    מצא הפעלות שבהן ביטחון, כשל חוזר או הנחיות מדיניות דרשו החלטה אנושית אך הסוכן המשיך באופן אוטונומי.
  </Accordion>
</AccordionGroup>
