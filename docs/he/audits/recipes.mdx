השתמש באלה כיעדים התחלתיים, ואז הוסף את הסוכן שלך, הסביבה, וזרימת העבודה הצפויה.

<Tabs>
  <Tab title="לוח בקרה">
    עבור אל **Analyze → Audits → New audit**, העתק מתכן אחד לתיאור או לתקציר, ואז הוסף את הסביבה הרלוונטית, סוכן, lookback, וכתובות URL להתייחסות. צור את הביקורת ובדוק את ההרצה הראשונה לפני תזמון שלה.

    טופס הביקורת החדש הופך מתכן למבחן כשל הניתן להוצאה לפועל על ידי הוספת טווח, הקשר, קדנציה, והודעות.

    ![טופס הביקורת החדש מוגדר עם יעד ממוקד, לוח זמנים, טווח סוכן וסביבה, הקשר, וערוצי הודעות.](/images/dashboard/audit-new.png)

    לאחר היצירה, אשר שהביקורת מופיעה בהרשימה עם הסטטוס והלוח הזמנים הצפויים לפני סמך על הרצות חוזרות.

    ![דף הביקורות שבו מתכן ביקורת ספציפי לזרימת עבודה מופיע לאחר היצירה.](/images/dashboard/audits.png)

    פתח את ההרצה הראשונה וחדד את המתכן אם הממצאים שלו רחבים או צרים יותר מעומת מצב הכשל המיועד.
  </Tab>
  <Tab title="CLI">
    שמור מתכן כקובץ טקסט והצמד אותו במהלך היצירה:

    ```bash
    fp audits create retry-loop-review \
      --scope '{"environments":["production"]}' \
      --text-file ./retry-loop-audit.txt \
      --schedule-interval-secs 86400
    ```
  </Tab>
</Tabs>

<AccordionGroup>
  <Accordion title="לולאות ניסיון חוזר">
    מצא הפעלות שבהן הסוכן חוזר על אותה קריאת כלי כושלת ללא שינוי קלט, בחירת כלי חלופי, או הסלמה לאדם.
  </Accordion>
  <Accordion title="שימוש כלי שגוי">
    מצא הפעלות שבהן הכלי שנבחר אינו תואם למשימה המצוינת, או שבהן קלט הכלי מפר תנאי קדם נדרשים של זרימת העבודה.
  </Accordion>
  <Accordion title="גישה לנתונים לא בטוחה">
    מצא הפעלות הקוראות, כותבות, או משדרות נתונים רגישים מחוץ לנתיבים והשירותים המאושרים לסוכן זה.
  </Accordion>
  <Accordion title="הנטשת משימה">
    מצא הפעלות המסתיימות ללא התוצאה המבוקשת, שגיאה ברורה, או הסלמה מפורשת לאדם.
  </Accordion>
  <Accordion title="נסיגה בעלות או בעיכוב">
    מצא הפעלות שעיכול המודל, הכלי, או הזמן הכולל שלהן חוצה את התקציב הצפוי, וזהה את דפוס האירוע האחראי.
  </Accordion>
  <Accordion title="הסלמה לאדם שהוחמצה">
    מצא הפעלות שבהן ביטחון, כשל חוזר, או הנחיה של מדיניות דרשו החלטת אדם אך הסוכן המשיך בעצמאות.
  </Accordion>
</AccordionGroup>
