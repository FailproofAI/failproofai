title: צפייה בהפעלות
description: "הפעל את לוח הבקרה לעיון בהפעלות סוכן וניהול מדיניות"
---

```bash
failproofai
```

מפעיל את לוח הבקרה באינטרנט בכתובת `http://localhost:8020`.

## אפשרויות

| דגל | תיאור |
|------|-------------|
| `--port <number>` | היציאה להאזנה (ברירת מחדל: `8020`) |
| `--allowed-origins <origins>` | מארחים/כתובות IP מופרדות בפסיקים המורשות לגשת למשאבי פיתוח |

כדי להצביע על לוח הבקרה בתיקיית פרויקט Claude לא ברירת המחדל, הגדר את משתנה הסביבה `CLAUDE_PROJECTS_PATH` בעת ההפעלה.

## דוגמאות

```bash
# הפעל ביציאה אחרת
failproofai --port 9000

# השתמש בנתיב פרויקטים Claude מותאם אישית דרך משתנה סביבה
CLAUDE_PROJECTS_PATH=~/my-claude-projects failproofai
```
