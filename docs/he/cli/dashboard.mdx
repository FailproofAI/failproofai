title: צפייה בהפעלות
description: "הפעל את לוח הבקרה לעיון בהפעלות של סוכנים וניהול מדיניות"
---

```bash
failproofai
```

מפעיל את לוח הבקרה בכתובת `http://localhost:8020`.

## אפשרויות

| דגל | תיאור |
|------|-------------|
| `--port <number>` | הפורט להאזנה (ברירת מחדל: `8020`) |
| `--allowed-origins <origins>` | כתובות/כתובות IP מופרדות בפסיקים שמורשות לגשת למשאבי פיתוח |

כדי להצביע את לוח הבקרה לתיקייה פרויקט Claude שאינה ברירת המחדל, הגדר את משתנה הסביבה `CLAUDE_PROJECTS_PATH` בעת ההפעלה.

## דוגמאות

```bash
# הפעל בפורט שונה
failproofai --port 9000

# השתמש בנתיב פרויקטים Claude מותאם אישית דרך משתנה סביבה
CLAUDE_PROJECTS_PATH=~/my-claude-projects failproofai
```
