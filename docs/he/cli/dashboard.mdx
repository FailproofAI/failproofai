description: "הפעל את לוח הבקרה לעיון בהפעלות סוכן וניהול מדיניויות"
---

```bash
failproofai
```

מפעיל את לוח הבקרה בכתובת `http://localhost:8020`.

## אפשרויות

The dashboard takes no flags — `failproofai` rejects any it does not recognize. The port is fixed at `8020`.

כדי להצביע על לוח הבקרה לתיקיית פרויקט Claude שאינה ברירת המחדל, הגדר את משתנה הסביבה `CLAUDE_PROJECTS_PATH` בעת ההפעלה.

## דוגמאות

```bash
failproofai

# השתמש בנתיב פרויקטים Claude מותאם אישית דרך משתנה סביבה
CLAUDE_PROJECTS_PATH=~/my-claude-projects failproofai
```
