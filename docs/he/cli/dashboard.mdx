title: צפיה בהפעלות
description: "הפעלת לוח הבקרה לעיון בהפעלות של סוכנים וניהול מדיניויות"
---

```bash
failproofai
```

מפעילה את לוח הבקרה בכתובת `http://localhost:8020`.

## אפשרויות

| דגל | תיאור |
|------|-------------|
| `--port <number>` | יציאה להקשבה (ברירת מחדל: `8020`) |
| `--allowed-origins <origins>` | רשימה מופרדת בפסיקים של שמות מארחים/כתובות IP המורשות לגישה למשאבי פיתוח |

כדי להצביע על תיקיית פרויקט Claude שאינה ברירת המחדל, הגדר את משתנה הסביבה `CLAUDE_PROJECTS_PATH` בעת ההפעלה.

## דוגמאות

```bash
# הפעלה ביציאה שונה
failproofai --port 9000

# שימוש בנתיב פרויקטים Claude מותאם דרך משתנה סביבה
CLAUDE_PROJECTS_PATH=~/my-claude-projects failproofai
```
