---
title: צפייה בהפעלות
description: "הפעל את לוח הבקרה לדיוג בהפעלות של סוכנים וניהול מדיניות"
---

```bash
failproofai
```

מפעיל את לוח הבקרה בכתובת `http://localhost:8020`.

## אפשרויות

| דגל | תיאור |
|------|-------------|
| `--port <number>` | יציאה להאזנה (ברירת מחדל: `8020`) |
| `--allowed-origins <origins>` | רשימה מופרדת בפסיקים של מארחים/כתובות IP מורשות לגישה למשאבי פיתוח |

כדי להצביע על לוח הבקרה לתיקייה של Claude שאינה ברירת המחדל, הגדר את משתנה הסביבה `CLAUDE_PROJECTS_PATH` בעת הפעלה.

## דוגמאות

```bash
# הפעל ביציאה שונה
failproofai --port 9000

# השתמש בנתיב פרויקטי Claude מותאם אישית דרך משתנה סביבה
CLAUDE_PROJECTS_PATH=~/my-claude-projects failproofai
```
