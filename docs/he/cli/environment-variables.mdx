## Dashboard

| משתנה | תיאור |
|----------|-------------|
| `PORT` | יציאת Dashboard (ברירת מחדל: `8020`) |
| `CLAUDE_PROJECTS_PATH` | עקוף את מיקום תיקיות פרויקט Claude Code |
| `FAILPROOFAI_DISABLE_PAGES=policies,projects` | דפי Dashboard להסתרה, מופרדים בפסיקים |
| `FAILPROOFAI_ALLOWED_DEV_ORIGINS` | מארחים/IPs מורשים לגישה למשאבי dev. זהה ל-`--allowed-origins`. |

## Logging

| משתנה | תיאור |
|----------|-------------|
| `FAILPROOFAI_LOG_LEVEL=info\|warn\|error` | רמת רישום שרת (ברירת מחדל: `warn`) |
| `FAILPROOFAI_HOOK_LOG_FILE` | נתיב קובץ log מותאם אישית, או `true` לברירת מחדל (`~/.failproofai/logs/hooks.log`) |

## Telemetry

failproofai מדווח על טלמטריית שימוש אנונימית בברירת מחדל. יש שתי דרכים להשבית זאת, והן מפתרות לכל מה שמגביל יותר — משתנה סביבה לעולם לא יכול להשבית מחדש משהו שקובץ ההגדרות השבית.

| משתנה | תיאור |
|----------|-------------|
| `FAILPROOFAI_TELEMETRY_DISABLED=1` | השבת טלמטריית שימוש אנונימית לתהליך זה |

כדי להשבית זאת באופן קבוע עבור המכונה, הוסף זאת ל-`~/.failproofai/config.json`:

```json
{
  "telemetry": {
    "enabled": false
  }
}
```

<Note>
קובץ ההגדרות הוא האפשרות לשימוש אם אתה מריץ את **failproofaid daemon**.
ה-daemon הוא שירות בהיקף מערכת, והסביבה שלו אינה כוללת משתנים המיוצאים מהקונסול שלך — כך ש-`FAILPROOFAI_TELEMETRY_DISABLED` לא יכול להגיע אליו. `[telemetry] enabled = false` נקרא גם על ידי CLI וגם על ידי ה-daemon.
</Note>

ה-daemon מדווח על **lifecycle** שלו בלבד: שהוא התחיל (והאם ההרץ הקודם יצא בצורה נקייה), שהוא עצר, מתי עובד ההערכה שלו הופעל או הופעל מחדש, מתי משימת collector נכשלה, ותוצאה של cloud-policy pull. אלה נושאים ערכים בעלי קרדינליות נמוכה וספירות — לעולם לא נתיב קובץ, פקודה, מדיניות, prompt, או כל דבר שנקרא מתוך תמלול. אין אירוע per-tool-call.

## Authentication

| משתנה | תיאור |
|----------|-------------|
| `FAILPROOF_API_URL` | עקוף את URL בסיס ה-api-server המשמש את דיאלוג ה-auth של Dashboard. ברירת המחדל היא `https://api.befailproof.ai`; הגדר ל-`http://localhost:8080` (או היכן שלא) בעת הרצת api-server מקומי. |
| `FAILPROOFAI_AUTH_DIR` | עקוף את מיקום שמירת `auth.json` (ברירת מחדל: `~/.failproofai`). שימושי בעיקר לבדיקות מבודדות. |

## First-run prompt

| משתנה | תיאור |
|----------|-------------|
| `FAILPROOFAI_NO_FIRST_RUN=1` | דלג על ה-prompt המציע התקנת מדיניות ב-failproofai ראשון ים |

## LLM (להערכת מדיניות)

| משתנה | תיאור |
|----------|-------------|
| `FAILPROOFAI_LLM_BASE_URL` | נקודת קצה של LLM API (ברירת מחדל: `https://api.openai.com/v1`) |
| `FAILPROOFAI_LLM_API_KEY` | מפתח API עבור מדיניות המופעלות על ידי LLM |
| `FAILPROOFAI_LLM_MODEL` | שם מודל (ברירת מחדל: `gpt-4o-mini`) |
