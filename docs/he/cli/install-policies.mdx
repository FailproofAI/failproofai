---
title: התקנת מדיניות
description: "הפעל מדיניות כך שהן יפעלו בכל קריאת כלי של סוכן"
---

```bash
failproofai policies --install [policy-names...] [options]
```

כותב ערכי hook לקובץ הגדרות של ה-CLI של הסוכן המותקן שלך (Claude Code, OpenAI Codex, או GitHub Copilot CLI _(beta)_) כדי שה-failproofai יוכל להתערב בקריאות כלים.

כינויים: `failproofai p -i`

## אפשרויות

| דגל | תיאור |
|------|-------------|
| `--cli claude\|codex\|copilot` | CLI של סוכן להתקנה; מופרדים בחללים (לדוגמה `--cli claude codex copilot`) או חוזרים. השמט כדי לגלות CLI מותקנים וקבל הנחיות. |
| `--scope user` | התקן לקובץ הגדרות בטווח משתמש (Claude: `~/.claude/settings.json`; Codex: `~/.codex/hooks.json`; Copilot: `~/.copilot/hooks/failproofai.json`). ברירת מחדל. |
| `--scope project` | התקן לקובץ הגדרות בטווח פרויקט (Claude: `<cwd>/.claude/settings.json`; Codex: `<cwd>/.codex/hooks.json`; Copilot: `<cwd>/.github/hooks/failproofai.json`). |
| `--scope local` | Claude בלבד — התקנה ל-`<cwd>/.claude/settings.local.json`. Codex ו-Copilot אינם תומכים בטווח `local`. |
| `--custom <path>` / `-c` | נתיב לקובץ JS המכיל מדיניות hook מותאמות אישית |

## התנהגות

- **ללא שמות מדיניות** - פותח הנחיה אינטראקטיבית לבחירת מדיניות
- **שמות ספציפיים** - הפעל מדיניות אלה (מתווסף לכל אחד שכבר מופעל)
- **`all`** - הפעל כל מדיניות זמינה

התקנה היא תוספת: הפעלת `--install` שוב מוסיפה מדיניות חדשה ללא הסרה של קיימות.

## דוגמאות

```bash
# התקן את כל המדיניות הברירת מחדל באופן גלובלי (אינטראקטיבי)
failproofai policies --install

# התקן מדיניות ספציפיות עבור הפרויקט הנוכחי
failproofai policies --install block-sudo sanitize-api-keys --scope project

# הפעל את כל המדיניות בבת אחת
failproofai policies --install all

# התקן עם קובץ מדיניות מותאם אישית
failproofai policies --install --custom ./my-policies.js

# התקן עבור OpenAI Codex (טווח פרויקט)
failproofai policies --install --cli codex --scope project

# התקן עבור GitHub Copilot CLI (beta) עבור הפרויקט הנוכחי
failproofai policies --install --cli copilot --scope project

# התקן עבור שלוש ה-CLI בו-זמנית
failproofai policies --install --cli claude codex copilot
```

כאשר `--custom <path>` מסופק, הקובץ מאומת מיד - הוא חייב לקרוא ל-`customPolicies.add()` לפחות פעם אחת. הנתיב המתורגם נשמר ל-`policies-config.json` בתור `customPoliciesPath`.
