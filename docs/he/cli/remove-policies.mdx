title: הסרת מדיניות
description: "הסרת ערכי hook מהגדרות Claude Code"
---

```bash
failproofai policies --uninstall [policy-names...] [options]
```

מסירה ערכי hook של failproofai מתוך `settings.json` של Claude Code.

כינויים: `failproofai p -u`

## אפשרויות

| דגל | תיאור |
|------|-------------|
| `--scope user` | הסרה מהגדרות גלובליות (ברירת מחדל) |
| `--scope project` | הסרה מהגדרות הפרויקט |
| `--scope local` | הסרה מהגדרות מקומיות |
| `--scope all` | הסרה מכל הטווחים בו-זמנית |
| `--custom` / `-c` | ניקוי ה-`customPoliciesPath` מתוך התצורה |

## התנהגות

- **ללא שמות מדיניות** - מסירה את כל ערכי ה-hook של failproofai מקובץ ההגדרות
- **שמות ספציפיים** - משבית את המדיניויות הללו אך שומרת על hooks מותקנים

## דוגמאות

```bash
# הסרת כל ה-hooks בגלובלי
failproofai policies --uninstall

# השבתת מדיניות ספציפית (שומרת על hooks מותקנים)
failproofai policies --uninstall block-sudo

# הסרת hooks מכל טווח
failproofai policies --uninstall --scope all

# ניקוי נתיב המדיניות המותאמות אישית
failproofai policies --uninstall --custom
```
