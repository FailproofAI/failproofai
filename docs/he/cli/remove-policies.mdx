title: הסרת מדיניות
description: "הסרת רשומות hook מהגדרות Claude Code"
---

```bash
failproofai policies --uninstall [policy-names...] [options]
```

מסיר רשומות hook של failproofai מ-`settings.json` של Claude Code.

כינויים: `failproofai p -u`

## אפשרויות

| דגל | תיאור |
|------|-------------|
| `--scope user` | הסרה מהגדרות גלובליות (ברירת מחדל) |
| `--scope project` | הסרה מהגדרות הפרויקט |
| `--scope local` | הסרה מהגדרות מקומיות |
| `--scope all` | הסרה מכל ההיקפים בו-זמנית |
| `--custom` / `-c` | ניקוי של `customPoliciesPath` מתצורה |

## התנהגות

- **ללא שמות מדיניות** - מסיר את כל רשומות hook של failproofai מקובץ ההגדרות
- **שמות ספציפיים** - משבית את המדיניות הנ"ל אך שומר על ה-hooks המותקנים

## דוגמאות

```bash
# הסרת כל hooks באופן גלובלי
failproofai policies --uninstall

# השבתת מדיניות ספציפית (שמור על hooks מותקנים)
failproofai policies --uninstall block-sudo

# הסרת hooks מכל היקף
failproofai policies --uninstall --scope all

# ניקוי נתיב של מדיניות מותאמת אישית
failproofai policies --uninstall --custom
```
