הערכת Jev קוראת **סשן שהסתיים** ונותנת ציון מ-0 עד 1. השתמש בה כאשר התשובה ידועה מראש, כמו "האם הלקוח בטא דחיפות?" או "כמה התוסכל הלקוח?" זה עוזר לך למצוא דפוסים על פני הרצות; זה לא עוצר קריאת כלי. לקבלת החלטות שנעשו **לפני** שכלי רץ, השתמש ב-[מדיניות Jev](/he/policies/jev).

## יצירה בלוח הבקרה

1. פתח את **Analyze → eval authoring** ובחר **new eval**.
2. תאר שאלה אחת והתשובות האפשריות שלה. לדוגמה: "האם הסוכן הבטיח החזר כספי לפני בדיקת מדיניות ההחזרים? ענה כן או לא." בחר **draft** ובדוק שהתוצאה היא ציון מסווג.
3. [בחן אותה](/he/evaluations/test) בסשנים אחרונים, ואז [פרוס אותה](/he/evaluations/deploy). סשנים חדשים שהושלמו מקבלים ציון; [מלא אחורה](/he/evaluations/deploy#score-sessions-you-already-have) אם אתה גם צריך היסטוריה.

![טופס יצירת הערכות משותף, שבו אתה מתאר שאלה בעלת תשובה קבועה, בודק את הטיוטה ופורס לאחר בדיקה. הדוגמה המוצגת היא הערכת קוד; שאלת Jev משתמשת בזרימת יצירה זהה.](/images/dashboard/eval-authoring-draft.png)

העוזר יכול לבחור בין קוד, סיווג Jev, וב-[שופט](/he/evaluations/judge). בדוק את הבחירה שלו לפני פריסה. Jev נותן ציון ללא טיעון בפרוזה; בחר בשופט כאשר אתה צריך הסבר. ראה את [הפניה לפי הערכת Jev](/he/reference/jev-evaluations) לסוגי שאלות והגבלות ציון.

## קריאת הציונים

פתח את **Observe → Evaluations** כדי לתרשום את התוצאה לפי סוכן וזמן. מטרמינל, Cloud CLI יכול לקרוא את אותן תוצאות:

```bash
fp evals --since 7d
fp evals --aggregate --since 7d
```

Cloud CLI קורא תוצאות; יצירה וגריסה מתרחשות בלוח הבקרה. ראה את [הפניה Cloud CLI](/he/reference/cloud-cli#evaluations) לסינונים.
