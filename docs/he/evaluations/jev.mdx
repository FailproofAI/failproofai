הערכת Jev קוראת **שיחה שהסתיימה** ונותנת ציון מ-0 עד 1. השתמש בה כאשר התשובה ידועה מראש, כמו "האם הלקוח הביע דחיפות?" או "כמה מתוסכל היה הלקוח?" זה עוזר לך למצוא דפוסים בין הרצות; זה לא עוצר קריאת כלי. לקבלת החלטות שהתקבלו **לפני** הרצת כלי, השתמש ב-[מדיניות Jev](/he/policies/jev).

## יצירת הערכה בלוח הבקרה

1. פתח **Analyze → eval authoring** ובחר **new eval**.
2. תאר שאלה אחת והתשובות האפשריות שלה. לדוגמה: "האם הסוכן הבטיח החזר כסף לפני בדיקת מדיניות ההחזרים? ענה כן או לא." בחר **draft** וסקור שהתוצאה היא ציון מסווג.
3. [בדוק אותה](/he/evaluations/test) בשיחות אחרונות, ואחר כך [העלה אותה](/he/evaluations/deploy). שיחות שהסתיימו חדשות מקבלות ציון; [בצע מילוי אחורי](/he/evaluations/deploy#score-sessions-you-already-have) אם אתה גם צריך היסטוריה.

![טופס authoring הערכה משותף, שבו אתה מתאר שאלה בעלת תשובה קבועה, בוחן את הטיוטה, והעלה לאחר בדיקה. הדוגמה המוצגת היא הערכה של קוד; שאלה Jev משתמשת בזרימת authoring זהה.](/images/dashboard/eval-authoring-draft.png)

העוזר יכול לבחור בין קוד, סיווג Jev, ו-[judge](/he/evaluations/judge). בדוק את הבחירה שלו לפני הפריסה. Jev נותן ציון ללא נימוק בפרוזה; בחר judge כאשר אתה זקוק להסבר. ראה את [ממויקד ההערכה של Jev](/he/reference/jev-evaluations) עבור סוגי שאלות וגבולות ציון.

## קריאת הציונים

פתח **Observe → Evaluations** כדי לתרשים את התוצאה לפי סוכן וזמן. מטרמינל, ה-Cloud CLI יכול לקרוא את אותן התוצאות:

```bash
fp evals --since 7d
fp evals --aggregate --since 7d
```

ה-Cloud CLI קורא תוצאות; authoring והעלאה מתרחשים בלוח הבקרה. ראה את [ממויקד Cloud CLI](/he/reference/cloud-cli#evaluations) עבור מסננים.
