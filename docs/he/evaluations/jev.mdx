הערכת Jev קוראת **סשן מסיים** ונותנת ציון מ-0 עד 1. השתמש בה כאשר התשובה ידועה מראש, כגון "האם הלקוח הביע דחיפות?" או "כמה התוסכן הלקוח?" היא עוזרת למצוא דפוסים על פני הרצות; היא לא עוצרת קריאת כלי. לقررות שנעשו **לפני** שכלי רץ, השתמש ב-[מדיניות Jev](/he/policies/jev).

## צור אחת בלוח המחוונים

1. פתח **Analyze → eval authoring** ובחר **new eval**.
2. תאר שאלה אחת והתשובות האפשריות שלה. לדוגמה: "האם הסוכן הבטיח החזר כסף לפני בדיקת מדיניות ההחזר? ענה בן או לא." בחר **draft** וסקור שהתוצאה היא ציון מסווג.
3. [בדוק אותה](/he/evaluations/test) בסשנים אחרונים, ואז [הפרסם אותה](/he/evaluations/deploy). סשנים שהושלמו חדשים מקבלים ציון; [מלא לאחור](/he/evaluations/deploy#score-sessions-you-already-have) אם אתה צריך גם הסטוריה.

![טופס הערכת משותף, שבו אתה מתאר שאלה בעלת תשובה קבועה, בוחן את הטיוטה ומפרסם לאחר בדיקה. הדוגמה המוצגת היא הערכת קוד; שאלת Jev משתמשת באותה זרימת הערכה.](/images/dashboard/eval-authoring-draft.png)

העוזר יכול לבחור בין קוד, סיווג Jev, ו-[judge](/he/evaluations/judge). בדוק את בחירתו לפני הפרסום. Jev נותן ציון ללא נימוק בעל פרוזה; בחר judge כאשר אתה צריך הסבר. ראה את [הספר ההתייחסות להערכות Jev](/he/reference/jev-evaluations) לסוגי שאלות והגבלות ציונים.

## קרא את הציונים

פתח **Observe → Evaluations** לתיאור התוצאה לפי סוכן וזמן. מטרמינל, Cloud CLI יכול לקרוא את אותן התוצאות:

```bash
fp evals --since 7d
fp evals --aggregate --since 7d
```

Cloud CLI קורא תוצאות; הערכה והפרסום מתרחשים בלוח המחוונים. ראה את [הספר ההתייחסות של Cloud CLI](/he/reference/cloud-cli#evaluations) לסננים.
