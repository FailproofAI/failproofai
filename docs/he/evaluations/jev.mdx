הערכת Jev קוראת **סשן שהסתיים** ונותנת ניקוד מ-0 ל-1. השתמש בה כאשר התשובה ידועה מראש, כמו "האם הלקוח הביע דחיפות?" או "כמה מתוסכל היה הלקוח?" היא עוזרת למצוא דפוסים על פני הרצות; היא לא עוצרת קריאת כלי. להחלטות שנעשות **לפני** הרצת כלי, השתמש ב-[Jev policies](/he/policies/jev).

## צור אחת בדשבורד

1. פתח **Analyze → eval authoring** ובחר **new eval**.
2. תאר שאלה אחת והתשובות האפשריות שלה. לדוגמה: "האם הסוכן הבטיח החזר כספי לפני בדיקת מדיניות ההחזר? ענה כן או לא." בחר **draft** והשקיף כי התוצאה היא ניקוד מסווג.
3. [בדוק אותה](/he/evaluations/test) על סשנים אחרונים, ואז [פרוס אותה](/he/evaluations/deploy). סשנים שהסתיימו חדשים מקבלים ניקוד; [backfill](/he/evaluations/deploy#score-sessions-you-already-have) אם אתה צריך גם היסטוריה.

![טופס הערכה משותף, שבו אתה מתאר שאלה בעלת תשובה קבועה, בודק את הטיוטה, ופורס לאחר בדיקה. הדוגמה המוצגת היא הערכת קוד; שאלת Jev משתמשת בזרימת הערכה זהה.](/images/dashboard/eval-authoring-draft.png)

העוזר יכול לבחור בין קוד, סיווג Jev, ו-[judge](/he/evaluations/judge). בדוק את בחירתו לפני פרסום. Jev נותן ניקוד ללא נימוקים בעלי פרוזה; בחר judge כאשר אתה צריך הסבר. ראה את [הפניית הערכת Jev](/he/reference/jev-evaluations) לסוגי שאלות ומגבלות ניקוד.

## קרא את הניקוד

פתח **Observe → Evaluations** כדי לתרשים את התוצאה לפי סוכן וזמן. מטרמינל, Cloud CLI יכול לקרוא את אותן תוצאות:

```bash
fp evals --since 7d
fp evals --aggregate --since 7d
```

Cloud CLI קורא תוצאות; הערכה ופרסום מתרחשים בדשבורד. ראה את [הפניית Cloud CLI](/he/reference/cloud-cli#evaluations) למסננים.
