הוסף את התיעוד המלא של Failproof AI לסוכן הקידוד שלך בפקודה אחת. עובד עם Claude Code, Cursor, Windsurf וכל סוכן אחר התומך בכישרונות.

```bash
npx skills add https://docs.befailproof.ai
```

`npx skills` מזהה אילו סוכנים מותקנים לך ומוסיף את הכישרון בפורמט הנכון לכל אחד באופן אוטומטי.

## מה הכישרון מכסה

| תחום | מה כלול |
|------|---------|
| Policies | שמות policy מובנים, סוגי אירועים, פרמטרים, הפעלה/השבתה |
| Custom policies | `customPolicies.add()`, מסנני התאמה, `allow`/`deny`/`instruct` API |
| Context object | `ctx.eventType`, `ctx.toolName`, `ctx.toolInput`, `ctx.session` |
| Configuration | מבנה `policies-config.json`, מיזוג scope, `policyParams` |
| CLI | `failproofai policies --install`, `--uninstall`, `--custom`, scopes |
| Dashboard | תצוגת session, פעילות policy, משתנים סביבה |
| Architecture | זרימת hook handler, קודי יציאה, חוזה stdin/stdout |

## האם הכישרון שלם?

Mintlify יוצר `llms.txt` מכל הדפים בניווט. התיעוד של Failproof AI מכסה את ה-API המלא - כל policy, אפשרות ודוגמה כלולה. אם אתה מוצא משהו חסר, המקור נמצא ב-`https://docs.befailproof.ai/llms-full.txt`.

לקונטקסט ממוקד, קישור ישירות לדף ספציפי:

```bash
# רק Custom Policies API
npx skills add https://docs.befailproof.ai/custom-policies

# רק Built-in Policies
npx skills add https://docs.befailproof.ai/built-in-policies
```
