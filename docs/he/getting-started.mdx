## דרישות

- **Node.js** >= 20.9.0
- **Bun** >= 1.3.0 (אופציונלי - נדרש רק בעת בנייה מקוד מקור)

## התקנה

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

## התחלה מהירה

<Steps>
  <Step title="הפעלת מדיניות">
    מדיניות הן כללים שרצים לפני ואחרי כל קריאת כלי אג'נט. הם תופסים פקודות הרסניות, דליפות סודות ומצבי כשל אחרים לפני שהם גורמים נזק.

    ```bash
    failproofai policies --install
    ```

    פעולה זו כותבת ערכי hook לתוך CLI האג'נטים המותקנים שלך (Claude Code's `~/.claude/settings.json`, OpenAI Codex's `~/.codex/hooks.json`, GitHub Copilot CLI's `~/.copilot/hooks/failproofai.json`, Cursor Agent's `~/.cursor/hooks.json`, OpenCode's generated plugin shim at `~/.config/opencode/plugins/failproofai.mjs` plus a registration entry in `~/.config/opencode/opencode.json`'s `plugin` array, Pi's `~/.pi/agent/settings.json`, Hermes's `~/.hermes/config.yaml`, OpenClaw's `~/.openclaw/openclaw.json`, Factory Droid's `~/.factory/hooks.json`, Devin CLI's `~/.config/devin/config.json`, Antigravity CLI's `~/.gemini/config/hooks.json`, או Goose's auto-discovered plugin dir at `~/.agents/plugins/failproofai/hooks/hooks.json`). כאשר קיים יותר מאחד, תיוודע לך; העבר `--cli claude codex copilot cursor opencode pi hermes openclaw factory devin antigravity goose` (כל תת-קבוצה) כדי לדלג על ההנמקה.

    GitHub Copilot CLI, Cursor Agent, OpenCode, ו-Pi support הם **beta** — התקן עם `--cli copilot`, `--cli cursor`, `--cli opencode`, או `--cli pi`. Hermes (hermes-agent, שער Slack/Telegram) מתקין בהיקף משתמש עם `--cli hermes` והוא **גם** מקור ביקורת לא מקוון. OpenClaw (שער openclaw, עוזר מרובה ערוצים בעצמאות) מתקין בהיקף משתמש עם `--cli openclaw` — האכיפה פועלת דרך hooks התוסף שלה בתוך התהליך (`before_agent_finalize` הוא שער סיום תור אמיתי, כך שה-`require-*-before-stop` builtins אוכפים) — והוא **גם** מקור ביקורת לא מקוון. Factory Droid (`droid`) מתקין עם `--cli factory` (היקף משתמש + פרויקט) והוא **גם** מקור ביקורת לא מקוון. Devin CLI (`devin`, Cognition) מתקין עם `--cli devin` (היקף משתמש + פרויקט) והוא **גם** מקור ביקורת לא מקוון. Antigravity CLI (`agy`) מתקין עם `--cli antigravity` (היקף משתמש + פרויקט) והוא **גם** מקור ביקורת לא מקוון. Goose (codename goose, Block) מתקין עם `--cli goose` (היקף משתמש + פרויקט) — המתקין פשוט מפיל ספריית תוסף ב-`~/.agents/plugins/failproofai/` שGoose משנה אותה בגילוי אוטומטי, והוא **גם** מקור ביקורת לא מקוון.

    ```bash
    failproofai policies --install --scope project
    failproofai policies --install --cli codex --scope project
    failproofai policies --install --cli copilot --scope project
    failproofai policies --install --cli cursor --scope project
    failproofai policies --install --cli opencode --scope project
    failproofai policies --install --cli pi --scope project
    failproofai policies --install --cli hermes --scope user
    failproofai policies --install --cli openclaw --scope user
    failproofai policies --install --cli factory --scope project
    failproofai policies --install --cli devin --scope project
    failproofai policies --install --cli antigravity --scope project
    failproofai policies --install --cli goose --scope project
    failproofai policies --install block-sudo block-rm-rf sanitize-api-keys
    ```
  </Step>
  <Step title="אימות">
    ```bash
    failproofai policies
    ```

    מציג כל מדיניות, האם היא מופעלת, וכל פרמטרים מוגדרים.
  </Step>
  <Step title="הפעלת לוח הבקרה">
    ```bash
    failproofai
    ```

    פותח לוח בקרה מקומי ב-`http://localhost:8020` שבו אתה יכול לדפדף בהפעלות, לבחון קריאות כלים ולנהל מדיניות.
  </Step>
  <Step title="הפעלת האג'נט שלך">
    התחל את Claude Code כרגיל. אם האג'נט מנסה משהו מסוכן, failproofai יתקול אותו בעצמאות. השאר זה פועל ללא השגחה ובדוק מה קרה בלוח הבקרה.
  </Step>
</Steps>

## כיצד עובדות מדיניות

בכל פעם שאג'נט מריץ כלי, Claude Code קורא ל-failproofai כתהליך משנה:

```text
Claude Code  →  failproofai --hook PreToolUse  →  קרא JSON מ-stdin
                                                 הערוך מדיניות
                                                 כתוב החלטה ל-stdout
```

כל מדיניות מחזירה אחת משלוש החלטות:

- **allow** - האג'נט ממשיך בדרך רגילה
- **deny** - הפעולה חסומה, האג'נט מקבל הסבר למה
- **instruct** - הקשר נוסף מתווסף להנמקה של האג'נט

<Note>
מדיניות רצים בתהליך המקומי שלך. שום דבר לא נשלח לשירות מרחוק.
</Note>

## הגדרת מדיניויות קבוצתיות עם מדיניויות מבוססות על קונוונציה

הדרך המהירה ביותר לכון תקנים איכות בצוות שלך היא הקונוונציה `.failproofai/policies/`. זרוק קבצי מדיניות לתוך ספריה זו והם יטענו בעצמאות — אין דגלים, אין שינויי תצורה, אין פקודות התקנה.

<Steps>
  <Step title="יצירת ספריית המדיניות">
    ```bash
    mkdir -p .failproofai/policies
    ```
  </Step>
  <Step title="הוספת קבצי מדיניות">
    העתק דוגמאות התחלה או כתוב שלך:

    ```bash
    cp node_modules/failproofai/examples/convention-policies/*.mjs .failproofai/policies/
    ```

    או צור אחת חדשה:

    ```js
    // .failproofai/policies/team-policies.mjs
    import { customPolicies, allow, deny, instruct } from "failproofai";

    customPolicies.add({
      name: "test-before-commit",
      match: { events: ["PreToolUse"] },
      fn: async (ctx) => {
        if (ctx.toolName !== "Bash") return allow();
        if (/git\s+commit/.test(ctx.toolInput?.command ?? "")) {
          return instruct("הפעל בדיקות לפני commit.");
        }
        return allow();
      },
    });
    ```
  </Step>
  <Step title="commit ל-git">
    ```bash
    git add .failproofai/policies/
    git commit -m "Add team quality policies"
    ```

    כל חברי צוות שיש להם failproofai מותקן, יביאו את המדיניות הללו בעצמאות. אין צורך בהגדרה לכל מפתח.
  </Step>
</Steps>

<Tip>
Commit את `.failproofai/policies/` ללא וודקד שלך כך שכל הצוות חולק את אותם תקנים. כשהצוות שלך גוגל אופן כשל חדש, הוסף מדיניות והדחוף — כולם מקבלים את ההעדכון ב-`git pull` הבא שלהם. בעבור הזמן המדיניויות הללו הופכות לתקן איכות חי שמשתפר ברציפות.
</Tip>

## אחסון נתונים

כל התצורה וההתחקויות נשארים במכונה שלך:

| נתיב | מה זה שומר |
|------|----------------|
| `~/.failproofai/policies-config.json` | תצורת מדיניות גלובלית |
| `~/.failproofai/policies/` | המדיניות שלך - זרוק `*-policies.mjs`, אין צורך בתצורה |
| `~/.failproofai/policies/cloud-policies/` | מדיניויות שהוצגו למכונה זו על ידי הארגון שלך |
| `~/.failproofai/hook-activity/` | היסטוריית ביצוע hook (JSONL מדורוג) |
| `~/.failproofai/logs/` | התחקויות ניפוי עבור שגיאות hook מותאמות |
| `.failproofai/policies-config.json` | תצורת לכל פרויקט (committed) |
| `.failproofai/policies-config.local.json` | דריסות אישיות (gitignored) |

## הסרה

```bash
failproofai policies --uninstall
```

מסיר ערכי hook מ-`~/.claude/settings.json`. קבצי תצורה ב-`~/.failproofai/` נשמרים.
