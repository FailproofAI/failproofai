## דרישות

- **Node.js** >= 20.9.0
- **Bun** >= 1.3.0 (אופציונלי - נדרש רק לבנייה מקוד מקור)

## התקנה

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

## התחלה מהירה

<Steps>
  <Step title="הפעל מדיניויות">
    מדיניויות הן כללים שפועלים לפני ואחרי כל קריאת כלי של סוכן. הן תופסות פקודות הרסניות, דיווח סודות וקווי כשל נוספים לפני שהם גורמים נזק.

    ```bash
    failproofai policies --install
    ```

    זה כותב ערכי hook לתוך ה-CLI של הסוכנים המותקנים שלך (Claude Code's `~/.claude/settings.json`, OpenAI Codex's `~/.codex/hooks.json`, GitHub Copilot CLI's `~/.copilot/hooks/failproofai.json`, Cursor Agent's `~/.cursor/hooks.json`, OpenCode's generated plugin shim at `~/.config/opencode/plugins/failproofai.mjs` plus a registration entry in `~/.config/opencode/opencode.json`'s `plugin` array, Pi's `~/.pi/agent/settings.json`, Hermes's `~/.hermes/config.yaml`, OpenClaw's `~/.openclaw/openclaw.json`, Factory Droid's `~/.factory/hooks.json`, Devin CLI's `~/.config/devin/config.json`, Antigravity CLI's `~/.gemini/config/hooks.json`, או Goose's auto-discovered plugin dir at `~/.agents/plugins/failproofai/hooks/hooks.json`). כאשר קיים יותר מאחד, תיקבל הנחיה; העבר `--cli claude codex copilot cursor opencode pi hermes openclaw factory devin antigravity goose` (כל תת-קבוצה) כדי לדלג על ההנחיה.

    GitHub Copilot CLI, Cursor Agent, OpenCode, ותמיכה ב-Pi הם **beta** — התקן עם `--cli copilot`, `--cli cursor`, `--cli opencode`, או `--cli pi`. Hermes (hermes-agent, שער Slack/Telegram) מתקין בהיקף משתמש עם `--cli hermes` והוא **גם** מקור אודיט לא מקוון. OpenClaw (openclaw gateway, עוזר מרובה ערוצים באירוח עצמי) מתקין בהיקף משתמש עם `--cli openclaw` — אכיפה פועלת דרך ה-hooks של plugin בתוך התהליך שלו (`before_agent_finalize` הוא שער סוף תור אמיתי, כך שה-`require-*-before-stop` builtins אוכפים) — והוא **גם** מקור אודיט לא מקוון. Factory Droid (`droid`) מתקין עם `--cli factory` (היקף משתמש + פרויקט) והוא **גם** מקור אודיט לא מקוון. Devin CLI (`devin`, Cognition) מתקין עם `--cli devin` (היקף משתמש + פרויקט) והוא **גם** מקור אודיט לא מקוון. Antigravity CLI (`agy`) מתקין עם `--cli antigravity` (היקף משתמש + פרויקט) והוא **גם** מקור אודיט לא מקוון. Goose (codename goose, Block) מתקין עם `--cli goose` (היקף משתמש + פרויקט) — המתקין פשוט זורק ספריית plugin ב-`~/.agents/plugins/failproofai/` שGoose גוגל באופן אוטומטי, והוא **גם** מקור אודיט לא מקוון.

    ```bash
    failproofai policies --install --scope project
    failproofai policies --install --cli codex --scope project
    failproofai policies --install --cli copilot --scope project
    failproofai policies --install --cli cursor --scope project
    failproofai policies --install --cli opencode --scope project
    failproofai policies --install --cli pi --scope project
    failproofai policies --install --cli hermes --scope user
    failproofai policies --install --cli openclaw --scope user
    failproofai policies --install --cli factory --scope project
    failproofai policies --install --cli devin --scope project
    failproofai policies --install --cli antigravity --scope project
    failproofai policies --install --cli goose --scope project
    failproofai policies --install block-sudo block-rm-rf sanitize-api-keys
    ```
  </Step>
  <Step title="אמת">
    ```bash
    failproofai policies
    ```

    מציג כל מדיניות, אם היא מופעלת, וכל פרמטרים מוגדרים.
  </Step>
  <Step title="הפעל את לוח המחוונים">
    ```bash
    failproofai
    ```

    פותח לוח מחוונים מקומי ב-`http://localhost:8020` כאשר אתה יכול לעיין בהפעלות, לבדוק קריאות כלים ולנהל מדיניויות.
  </Step>
  <Step title="הרץ את הסוכן שלך">
    התחל את Claude Code כרגיל. אם הסוכן מנסה משהו מסוכן, failproofai יתפוס זאת באופן אוטומטי. תן לו לרוץ ללא השגחה ובדוק מה קרה בלוח המחוונים.
  </Step>
</Steps>

## איך מדיניויות עובדות

בכל פעם שסוכן מריץ כלי, Claude Code קורא ל-failproofai כתהליך משנה:

```text
Claude Code  →  failproofai --hook PreToolUse  →  קורא JSON מ-stdin
                                                 מעריך מדיניויות
                                                 כותב החלטה ל-stdout
```

כל מדיניות מחזירה אחת משלוש החלטות:

- **allow** - הסוכן ממשיך כרגיל
- **deny** - הפעולה נחסמת, הסוכן נמודע למה
- **instruct** - הקשר נוסף מתווסף להנחיית הסוכן

<Note>
מדיניויות פועלות בתהליך המקומי שלך. שום דבר לא נשלח לשירות מרחוק.
</Note>

## הגדר מדיניויות קבוצה עם מדיניויות המבוססות על קונבנציה

הדרך המהירה ביותר לקבוע תקנים איכות בצוות שלך היא הקונבנציה `.failproofai/policies/`. שחרר קבצי מדיניות לתוך ספרייה זו והם נטענים באופן אוטומטי — ללא דגלים, ללא שינויי תצורה, ללא פקודות התקנה.

<Steps>
  <Step title="צור את ספריית המדיניויות">
    ```bash
    mkdir -p .failproofai/policies
    ```
  </Step>
  <Step title="הוסף קבצי מדיניות">
    העתק דוגמאות ההתחלה או כתוב שלך:

    ```bash
    cp node_modules/failproofai/examples/convention-policies/*.mjs .failproofai/policies/
    ```

    או צור אחד חדש:

    ```js
    // .failproofai/policies/team-policies.mjs
    import { customPolicies, allow, deny, instruct } from "failproofai";

    customPolicies.add({
      name: "test-before-commit",
      match: { events: ["PreToolUse"] },
      fn: async (ctx) => {
        if (ctx.toolName !== "Bash") return allow();
        if (/git\s+commit/.test(ctx.toolInput?.command ?? "")) {
          return instruct("הרץ בדיקות לפני ביצוע.");
        }
        return allow();
      },
    });
    ```
  </Step>
  <Step title="בצע commit ל-git">
    ```bash
    git add .failproofai/policies/
    git commit -m "הוסף מדיניויות איכות קבוצה"
    ```

    כל חברי צוות שיש להם failproofai מותקן קוטפים את המדיניויות הללו באופן אוטומטי. אין צורך בהגדרה לכל מפתח.
  </Step>
</Steps>

<Tip>
בצע commit ל-`.failproofai/policies/` אל המאגר שלך כך שכל הצוות חולקים את אותם תקנים. כשהצוות שלך מגלה קווי כשל חדשים, הוסף מדיניויות ודחוף — כולם מקבלים את העדכון ב-`git pull` הבא שלהם. עם הזמן מדיניויות אלה הופכות לתקן איכות חי המשתפר בעצמו.
</Tip>

## אחסון נתונים

כל התצורה והיומנים נשארים במכונה שלך:

| נתיב | מה הוא שומר |
|------|----------------|
| `~/.failproofai/policies/local-policies/policies-config.json` | תצורת מדיניות גלובלית |
| `~/.failproofai/hook-activity/` | היסטוריית ביצוע hook (JSONL עמוד) |
| `~/.failproofai/logs/` | יומנים לניפוי שגיאות עבור שגיאות hook מותאם אישית |
| `.failproofai/policies-config.json` | תצורה לכל פרויקט (committed) |
| `.failproofai/policies-config.local.json` | עדכונים אישיים (gitignored) |

---

## הסרה

```bash
failproofai policies --uninstall
```

מסיר ערכי hook מ-`~/.claude/settings.json`. קבצי תצורה ב-`~/.failproofai/` נשמרים.
