Failproof AI עוזר לכל מי שמריץ סוכנים להבין מה קרה, למצוא כשלים, ולמנוע מהם להתרחש שוב.

זה עובד עם 12 סביבות סוכנים נפוצות, כולל Claude Code, Codex, Hermes, OpenClaw, וGoose. סוכנים שבנויים עם LangChain, CrewAI, LlamaIndex, Pydantic AI, או הריטיים שלך יכולים לדווח דרך [Python SDK](/he/reference/custom-agents).

## התחל ברמה מקומית או התחבר ל-Cloud

<Columns cols={2}>
  <Card title="מקומי, ללא חשבון" icon="laptop" href="/he/audits/local-audit">
    פתח את הדאשבורד ב-`localhost:8020` והפעל `failproofai audit`. היסטוריית הסוכן שלך נשארת על המכונה הזו.
  </Card>
  <Card title="Failproof AI Cloud" icon="cloud" href="/he/start/setup">
    ראה הפעלות על פני מכונות והנהל מדיניויות לצוות שלך.
  </Card>
</Columns>

ההגדרה בוחרת בכוונה ללא חבילת מדיניות. הוסף את שלנו אחרי ההגדרה:

```bash
failproofai policies add FailproofAI/policies
```

עד אז, רק `block-failproofai-commands` פועל. זה עוצר סוכן מביטול Failproof AI.

  <Card title="מנע חזרה" icon="shield-check" href="/he/policies/overview">

> **הפעלה → ביקורת → ממצא → בעיה → מדיניות**
> ראה מה קרה, מצא את הכשל, קבל אחריות על התגובה, ואז מנע אותו.

<Note>
  ההגדרה תומכת ב-Linux וב-macOS. ראה [harnesses נתמכים](/he/reference/harnesses) כדי לראות מה כל סביבת סוכן יכולה להתבונן או לחסום.
</Note>
