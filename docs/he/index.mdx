אם אתה מטמיע את ה-agent בעל instrumentation הראשון שלך, התחל עם ה-[quickstart](/he/start/quickstart). אם נתונים כבר הגיעו, פתח את [Sessions](/he/sessions/overview) וביקור בריצה אמיתית לפני שתגדיר ביקורות או policies.
