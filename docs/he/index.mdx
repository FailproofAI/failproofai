> **Session → Audit → Finding → Issue → Policy**<br />
> עקוב אחרי מה שקרה, מצא את הכשל, נהל את התגובה, ואז מנע אותה התנהגות בהפעלות עתידיות.

## התחל כאן

אם אתה פורס את הסוכן המואבחן הראשון שלך, התחל עם [המדריך המהיר](/he/start/quickstart). אם נתונים כבר מגיעים, פתח את [Sessions](/he/sessions/overview) בדוק הפעלה ממשית לפני הגדרת ביקורות או מדיניות.
