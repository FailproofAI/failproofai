hooks ומדיניויות ל**טיפול בכשלי AI**, **התאוששות מטעויות**, ו**אמינות LLM**. שמור על סוכני AI שלך אמינים ופועלים בצורה אוטונומית ב**Claude Code**, **OpenAI Codex**, **GitHub Copilot**, **Cursor Agent**, **OpenCode**, **Pi**, **Hermes**, **OpenClaw**, **Factory Droid**, **Devin CLI**, **Antigravity CLI**, וה**Agents SDK**.

סוכני AI נכשלים בדרכים צפויות. הם מריצים פקודות הרסניות, משחררים סודות, חורגים מהמשימה, תקועים בלולאות, או דוחפים ישירות ל-main. כאשר הם לא מפוקחים, כשלים קטנים מתפתחים לבעיות חמורות, דיווחי אישורים, ועבודה אבודה.

FailproofAI פותר זאת באמצעות **מדיניויות**. כללים אלה מתחברים לכל קריאת כלי סוכן כדי **לגלות כשלים**, **להקטין אותם** (חסום, הנחה, נקיון), ו**התריע** כאשר משהו דורש תשומת לב. לוח מחוונים מקומי מאפשר לך לבדוק כל קריאת כלי, כשל סוכן, וביצוע התאוששות לאחר מכן.

תמלילים והערכת מדיניויות נשארים במכונה שלך. נתונים נשלחים רק כאשר אתה משתמש במפורש בתכונה מקוונת, כגון תזכורות ביקורת מאומתות או הזמנות.

## התחלה מהירה

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # enable policies (or skip — `failproofai` will offer to set them up on first run)
failproofai                      # launch the dashboard
```

ראה את המדריך [תחילת העבודה](/he/getting-started) להדרכה מלאה.
