ווֹקטּוֹרִים וּמְדִינִיּוֹת עבור **טִפּוּל בַּכִּשְׁלוֹנוֹת AI**, **הִחלָמוּת מֵטְעוּיוֹת**, וְ**אַמִּינוּת LLM**. שמור על סוכנים בינה מלאכותית אמינים ופעילים בעצמאות ברחבי **Claude Code**, **OpenAI Codex**, **GitHub Copilot**, **Cursor Agent**, **OpenCode**, **Pi**, **Hermes**, **OpenClaw**, **Factory Droid**, **Devin CLI**, **Antigravity CLI**, וה-**Agents SDK**.

סוכנים בינה מלאכותית כושלים בדרכים צפויות. הם מריצים פקודות הרסניות, דוסים סודות, סוטים מהמשימה, נתקעים בלולאות, או דוחפים ישירות ל-main. אם משאירים אותם ללא השגחה, כישלונות קטנים מתגבירים להפסקות פעילות, פרישת פרטים זדוניים, ועבודה הולכת לאיבוד.

FailproofAI פותר זאת עם **מדיניות**. כללים אלו מתחברים לכל קריאת כלי סוכן כדי **לגלות כישלונות**, **להפחית אותם** (חסימה, הוראה, חיטוי), וְ**להעביר התרעה** כאשר משהו זקוק לתשומת לב. לוח בקרה מקומי מאפשר לך לבדוק כל קריאת כלי, כשל סוכן ופעולת שחזור בשלב מאוחר יותר.

תמלילים והערכת מדיניות נשמרים במחשבך. נתונים נשלחים רק כאשר אתה משתמש במפורש בתכונה מקוונת, כגון התרעות ביקורת מאומתות או הזמנות.

## התחלה מהירה

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # enable policies (or skip — `failproofai` will offer to set them up on first run)
failproofai                      # launch the dashboard
```

ראה את הגיד [התחלה](/he/getting-started) להדרכה המלאה.
