[![npm weekly downloads](https://img.shields.io/npm/dw/failproofai?style=flat-square&color=2ea44f)](https://www.npmjs.com/package/failproofai)

Hooks ומדיניות עבור **טיפול בכישלונות AI**, **התאוששות משגיאות**, ו**אמינות LLM**. שמור על סוכנים AI אמינים ורצים באופן אוטונומי על פני **Claude Code**, **OpenAI Codex**, **GitHub Copilot**, **Cursor Agent**, **OpenCode**, **Pi**, **Hermes**, **OpenClaw**, **Factory Droid**, **Devin CLI**, **Antigravity CLI**, וה-**Agents SDK**.

סוכנים AI נכשלים בדרכים צפויות. הם מריצים פקודות הרסניות, דולפים סודות, סוטים מהמטלה, תקועים בלולאות, או דוחפים ישירות ל-main. אם משאירים אותם ללא פיקוח, כישלונות קטנים מתגברים להפסקות שירות, דלפות אישורים, ועבודה אבודה.

FailproofAI פותר זאת עם **מדיניות**. כללים אלה מוכנסים לכל קריאת כלי סוכן כדי **לגלות כישלונות**, **להקל עליהם** (חסימה, הנחיה, sanitize), ו**להתריע אליך** כאשר משהו דורש תשומת לב. לוח מחוונים מקומי מאפשר לך לסקור כל קריאת כלי, כישלון סוכן וביצוע התאוששות לאחר מכן.

עמלות והערכת מדיניות נשארות במכונה שלך. נתונים נשלחים רק כאשר אתה משתמש במפורש בתכונה מקוונת, כגון תזכורות ביקורת מאומתות או הזמנות.

## התחלה מהירה

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # הפוך מדיניות לזמינות (או דלג — `failproofai` יציע להגדיר אותן בהרצה הראשונה)
failproofai                      # הפעל את לוח המחוונים
```
