[![npm weekly downloads](https://img.shields.io/npm/dw/failproofai?style=flat-square&color=2ea44f)](https://www.npmjs.com/package/failproofai)

ווקס ומדיניויות לטיפול **בכישלונות AI**, **התאוששות משגיאות**, ו**אמינות LLM**. שמור על סוכני ה-AI שלך אמינים וריצה עצמאית ב-**Claude Code**, **OpenAI Codex**, **GitHub Copilot**, **Cursor Agent**, **OpenCode**, **Pi**, **Hermes**, **OpenClaw**, **Factory Droid**, **Devin CLI**, **Antigravity CLI**, וה-**Agents SDK**.

סוכני AI כושלים בדרכים צפויות. הם מריצים פקודות הרסניות, מדליפים סודות, סוחפים מהמטרה, תקועים בלולאות, או דוחפים ישירות ל-main. אם לא יעד לבדוק, כישלונות קטנים עלולים להצטרף להפסקות, דלף של אישורים, והפסד של עבודה.

FailproofAI פותר זאת עם **מדיניויות**. חוקים אלה מתחברים לכל קריאת כלי סוכן כדי **לזהות כישלונות**, **להפחית אותם** (חסום, הנחה, ניקוי), ו**להתריע אותך** כאשר משהו צריך תשומת לב. לוח מחוונים מקומי מאפשר לך לבדוק כל קריאת כלי, כישלון סוכן, ופעולת התאוששות לאחר מכן.

תעתיקים והערכת מדיניות נשארים במכונה שלך. נתונים נשלחים רק כאשר אתה משתמש במפורש בתכונה מקוונת, כגון תזכורות ביקורת מאומתות או הזמנות.

## התחלה מהירה

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # enable policies (or skip — `failproofai` will offer to set them up on first run)
failproofai                      # launch the dashboard
```

ראה את מדריך [התחלה](/he/getting-started) להדרכה המלאה.
