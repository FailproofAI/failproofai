וו וענקים ל**טיפול בכשלים של AI**, **התאוששות משגיאות**, ו**אמינות LLM**. שמור על סוכני ה-AI שלך אמינים וממשיכים לפעול באופן אוטונומי על פני **Claude Code**, **OpenAI Codex**, **GitHub Copilot**, **Cursor Agent**, **OpenCode**, **Pi**, **Hermes**, **OpenClaw**, **Factory Droid**, **Devin CLI**, **Antigravity CLI**, ו**Agents SDK**.

סוכני AI כושלים בדרכים צפויות. הם מריצים פקודות הרסניות, מדליפים סודות, סוטים מהמשימה, נתקעים בלולאות, או דוחפים ישירות לענף הראשי. אם משאירים אותם ללא השגחה, כשלים קטנים מסתלבלים להפסקות, דלף של אישורים, ועבודה שאבדה.

FailproofAI פותר זאת עם **מדיניות**. כללים אלה מתחברים לכל קריאת כלים של סוכן כדי **לזהות כשלים**, **להפחית אותם** (חסימה, הוראה, ניקיון), ו**להתריע עליך** כשמשהו זקוק לתשומת לב. לוח מחוונים מקומי מאפשר לך לבדוק כל קריאת כלים, כשל סוכן, ופעולת התאוששות לאחר מכן.

שום נתון אינו עוזב את המכשיר שלך.

## התחלה מהירה

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # הפוך מדיניות (או דלג — `failproofai` יציע להגדיר אותם בהפעלה הראשונה)
failproofai                      # הפעל את לוח המחוונים
```
