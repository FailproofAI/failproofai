[![npm weekly downloads](https://img.shields.io/npm/dw/failproofai?style=flat-square&color=2ea44f)](https://www.npmjs.com/package/failproofai)

ווקים ומדיניויות ל**טיפול בכישלונות AI**, **התאוששות מ-שגיאות**, ו**אמינות LLM**. שמור על סוכני AI שלך אמינים וריצה אוטונומית ב**Claude Code**, **OpenAI Codex**, **GitHub Copilot**, **Cursor Agent**, **OpenCode**, **Pi**, **Hermes**, **OpenClaw**, **Factory Droid**, **Devin CLI**, **Antigravity CLI**, ו**Agents SDK**.

סוכני AI כושלים בדרכים צפויות. הם מריצים פקודות הרסניות, מדליפים סודות, סוטים מהמשימה, נתקעים בלולאות, או דוחפים ישירות ל-main. אם משאירים זאת ללא פיקוח, כישלונות קטנים עלולים להיות לתאונות קטסטרופליות, דליפות אישורים עבודה, ואובדן עבודה.

FailproofAI פותרת זאת באמצעות **מדיניויות**. כללים אלו משתלבים בכל קריאת כלי סוכן כדי **לגלות כישלונות**, **להפחית אותם** (לחסום, להנחות, לנקות), ו**להתריע עליך** כאשר משהו זקוק לתשומת לב. לוח מחוונים מקומי מאפשר לך לעיין בכל קריאת כלי, כישלון סוכן ופעולת התאוששות לאחר מכן.

תמליל וה-evaluation של מדיניות נשארים במחשב שלך. נתונים נשלחים רק כאשר אתה משתמש באופן מפורש בתכונה מקוונת, כגון תזכורות ביקורת מאומתות או הזמנות.

## התחלה מהירה

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # enable policies (or skip — `failproofai` will offer to set them up on first run)
failproofai                      # launch the dashboard
```
