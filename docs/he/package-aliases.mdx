## החבילה הרשמית

החבילה npm הקנונית היא **`failproofai`**:

```bash
npm install -g failproofai
# or
bun add -g failproofai
```

---

## למה אנחנו בעלים של שמות הכינויים

Typosquatting הוא התקפת שרשרת אספקה נפוצה שבה שחקן זדוני רושם שם חבילה שהוא מכות אחת משם חבילה פופולרית. משתמשים חסרי ספק שטעו בהקלדת פקודת ההתקנה בסופו של דבר מריצים קוד שנשלט על ידי התוקף עם גישה מלאה למערכת - בדיוק את סוג האיום שFailproof AI מעוצב להגנה עליו.

כדי להסיר את פני השטח הזה, **אנחנו בעלים מראש של כל ההטעויות והגרסאות הפורמט הנפוצות** של `failproofai` ב-npm. אף אחד מהשמות האלה לא יכול להיות רשום על ידי צד שלישי. כל אחד הוא פרוקסי דק שמתקין ומעביר לחבילת `failproofai` האמיתית.

## כיצד הכינויים עובדים

כל חבילת כינוי:

1. מרשימה `failproofai` כתלות - כך שהחבילה האמיתית מותקנת והבינארי שלה זמין
2. חושפת בינארי המתאים לשם שלה (לדוגמה `failproof-ai`) שמעביר את כל הטיעונים לבינארי `failproofai`

הפרוקסי הוא סקריפט Node דו-קווי; אין לוגיקה, אין קריאות רשת, ואין איסוף נתונים מעבר לאלו שfaiproofai עצמו עושה.
