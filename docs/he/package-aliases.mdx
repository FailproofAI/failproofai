## החבילה הרשמית

החבילת npm הקנונית היא **`failproofai`**:

```bash
npm install -g failproofai
# or
bun add -g failproofai
```

---

## למה אנחנו בעלי שמות הכינויים

Typosquatting הוא התקפת שרשרת אספקה נפוצה שבה שחקן זדוני רושם שם חבילה שהוא דקה אחת של הקשה משם חבילה פופולרי. משתמשים שלא משים לב שעשו טעות בהקשת פקודת ההתקנה בסופו של דבר מריצים קוד בשלוט התוקף עם גישה מלאה למערכת - בדיוק סוג האיום שـ Failproof AI מעוצב כדי להגן מולו.

כדי לביטל את פני ההתקפה הזה, **אנחנו בעלים מראש של כל ההקלדות השגויות וגרסאות העיצוב הנפוצות** של `failproofai` ב-npm. אף אחד מהשמות האלה לא יכול להיות רשום על ידי צד שלישי. כל אחד מהם הוא פרוקסי דק שמתקין ומעביר אל החבילה האמיתית של `failproofai`.

## כינויים רשומים

**גרסאות עיצוב** - דרכים שונות לכתוב "failproof ai":

| חבילה | סטטוס |
|---------|--------|
| `failproof` | ✅ פורסם |
| `failproof-ai` | ⏳ מחכה לתמיכת npm |
| `fail-proof-ai` | ⏳ מחכה לתמיכת npm |
| `failproof_ai` | ⏳ מחכה לתמיכת npm |
| `fail_proof_ai` | ⏳ מחכה לתמיכת npm |
| `fail-proofai` | ⏳ מחכה לתמיכת npm |

**הקלדות שגויות `failprof*`** - חסר `o` אחד מ-"proof":

| חבילה | סטטוס |
|---------|--------|
| `failprof` | ✅ פורסם |
| `failprof-ai` | ✅ פורסם |
| `failprofai` | ⏳ מחכה לתמיכת npm |
| `fail-prof-ai` | ⏳ מחכה לתמיכת npm |
| `failprof_ai` | ⏳ מחכה לתמיכת npm |

**הקלדות שגויות `faliproof*`** - `a` ו-`i` הוחלפו:

| חבילה | סטטוס |
|---------|--------|
| `faliproof` | ✅ פורסם |
| `faliproof-ai` | ✅ פורסם |
| `faliproofai` | ⏳ מחכה לתמיכת npm |

> **למה מחכה?** מדיניות ההגנה נגד ספאם של npm חוסמת שמות שמתנרמלים לאותו מחרוזת כמו חבילה קיימת לאחר הסרת פיסוק וביצוע בדיקות דומיון. יצרנו קשר עם תמיכת npm כדי להזמין את השמות האלה למטרות anti-squatting. הם יופעלו ברגע שיאושרו.

אתה יכול לאמת שכל כינוי שפורסם בעלות שלנו:

```bash
npm info failproof
# חפש: "ExosphereHost Inc." בשדה המתחזקים
```

## כיצד הכינויים עובדים

כל חבילת כינוי:

1. רושמת את `failproofai` כתלות - כך החבילה האמיתית מותקנת וההיקסה שלה נהיית זמינה
2. חושפת בינארי התואם לשמה שלה (למשל `failproof-ai`) שמעביר את כל הארגומנטים לבינארי `failproofai`

הפרוקסי הוא קוד Node בן שתי שורות; אין הגיון, אין קריאות רשת, ואין אוסף נתונים מעבר למה ש-`failproofai` עצמו עושה.
