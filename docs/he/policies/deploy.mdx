פרוס מדיניות שעברה בדיקה למכונה אחת בכל פעם. התחל במצב צפייה.

## הפצה מה-CLI

```bash
fp policies test ./rule.mjs --tool Bash --command "git push --force" --expect deny
fp policies publish no-force-push ./rule.mjs
fp fleet deploy <machine> --add no-force-push:observe
fp guardrails summary --since 24h --machine <machine>
fp fleet deploy <machine> --add no-force-push:enforce
```

מצב צפייה מעריך את המדיניות בפועל ורושם החלטות שאינן allow, אך לא חוסם את ה-agent.

<Warning>
  `--add no-force-push` בלבד אוכף מיד. הוסף `:observe` לפריסה צללית.
</Warning>

אם אכיפה גורמת לבעיות:

```bash
fp fleet history <machine>
fp fleet rollback <machine> <generation>
```

## פריסה מהלוח המחווט

1. עבור אל **Admin → enforcement**.
2. פתח את המכונה המטרה.
3. הוסף את גרסת המדיניות עם אפקט **observe**.
4. החל את הפריסה.
5. בחן תוצאות תחת **Observe → policy**.
6. קדם את אותה גרסה ל-**enforce** כאשר ההתאמות נכונות.

## החלפה או הכנה מקדמית של קבוצה

- `--remove <id>` מסיר מדיניות אחת.
- `--set <ref>...` מחליף את קבוצת המדיניות השלמה.
- `--create` מכין פריסה לפני שמכונה בודקת בפעם הראשונה.
- `fp fleet diff <machine>` משווה מצב מיועד וממומש.

<Note>
  ללא Cloud, פרסם חבילה עם `failproofai publish --effect observe` וחקור החלטות בלוח המחווט המקומי.
</Note>

מכונות זקוקות ל-`policies:pull` כדי לקבל פריסות ול-`events:add` כדי לדווח על החלטות.
