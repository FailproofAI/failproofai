כיסוי פלוטה משווה בין מה שCloud הקצה לבין מה שכל מכונה החילה לאחרונה.

## בדיקת מכונה

```bash
failproofai config --status
failproofai flush --wait --timeout 120
```

מ-Cloud:

```bash
fp fleet list
fp fleet diff
fp fleet show <machine-id>
```

`fp fleet` דורש הפעלה עם חשבון משתמש, לא מפתח API.

| פקודה | מה היא עושה |
| --- | --- |
| `fp fleet list` | רשום מכונות וסטטוס פריסה |
| `fp fleet show <machine>` | הצג את קבוצת המדיניויות של מכונה אחת |
| `fp fleet deploy <machine> --add <ref>` | הוסף או עדכן מדיניות אחת |
| `fp fleet deploy <machine> --remove <id>` | הסר מדיניות אחת |
| `fp fleet deploy <machine> --set <ref>...` | החלף את הקבוצה כולה |
| `fp fleet diff [machine]` | השווה גרסאות מיועדות ומיושמות |
| `fp fleet history <machine>` | רשום דורות פריסה |
| `fp fleet rollback <machine> <generation>` | שחזר דור |
| `fp fleet rename <machine> "<label>"` | שנה את התווית ב-Cloud |

<Warning>
  `--set` מחליף את קבוצת המדיניויות השלמה. `--add <id>` בלבד אוכף מדיניות חדשה מיד. השתמש ב-`--add <id>:observe` לפריסה צללית.
</Warning>

## צפייה, ואז הטלה

```bash
fp fleet deploy ci-runner-01 --add prod-guard:observe
fp guardrails summary --since 24h --machine ci-runner-01
fp fleet deploy ci-runner-01 --add prod-guard:enforce
```

מצב צפייה מעריך את המדיניות האמיתית ורושם החלטות שאינן allow ללא חסימת הסוכן.

## זהות מכונה

מזהה המכונה יציב ומזהה את המכונה. התווית היא למטרות תצוגה בלבד ויכולה להשתנות:

```bash
failproofai config --machine-label checkout-runner-03
fp fleet rename <machine-id> "Checkout runner 03"
```

שינוי התווית אינו מתחבר מחדש או מחליק מחדש את המכונה.
