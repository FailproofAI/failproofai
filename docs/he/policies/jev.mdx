Jev קורא קריאת כלים מול מה שהאדם ביקש מהסוכן לעשות. השתמש בה כאשר מדיניות התאמת מחרוזות חוסמת עבודה תקפה או מפספסת פעולה מסוכנת שדורשת הקשר. היא משיבה לצד המדיניות שלך בשער `PreToolUse` או `PermissionRequest`. לניקוד **לאחר** שהפגישה מסתיימת, השתמש ב-[הערכות Jev](/he/evaluations/jev).

## התחל במצב צפייה

התקן את Failproof AI וחבר hooks ל-[harness נתמך](/he/reference/harnesses). השתמש ב-failproofai 1.0.8-beta.0 או מאוחר יותר.

Failproof AI אינו מגיע עם בדיקות Jev. התקן אותן כחבילה, או ל-Jev אין מה לשאול והיא לעולם לא תיקרא:

```bash
failproofai policies add FailproofAI/jev-policies
```

לאחר מכן בחר כיצד בקשות מגיעות ל-Jev:

| נתיב | שלב ראשון |
| --- | --- |
| FailproofAI Cloud | התחבר עם מפתח **machine** הנושא `jev:evaluate`. במכונה ללא תצורת Jev, `failproofai config` הופך את Jev ללא במצב צפייה. |
| ספק משלך | בלוח הבקרה המקומי, פתח **Settings → Jev**, בחר את הספק, הדבק את ה-token שלו, ובחר **observe**. או הרץ `failproofai jev --url https://api.typesafe.ai/v1 --mode observe --key-stdin < ~/typesafe.key`. |

![הגדרות Jev בלוח הבקרה המקומי: ספק, endpoint, token, ומצב צפייה לפני הפעלת Jev.](/images/dashboard/jev-settings.png)

```bash
failproofai jev status
failproofai jev test
```

`test` בודק את ה-endpoint. כדי לבדוק את נתיב ה-hook, בקש מסוכן מחובר להשתמש בכלי קריאת הקבצים שלו ב-`README.md`. אשר שקריאת כלים זו מופיעה בפגישה, ואז בדוק **Policies → Activity** בלוח [הבקרה המקומי](/he/reference/local-dashboard#review-policy-activity). ספירת Jev ב-`status` צריכה להגדיל. מצב צפייה מתעד מה Jev הייתה מחליטה בעוד שתוצאת המדיניות הקיימת שלך עדיין חלה.

## החלט מתי לאכוף

מדיניות **קשה** תמיד יש את המילה האחרונה. Jev עשוי לפנות שלילה רק ממדיניות המסומנת במפורש כ-**reviewable** ורק כאשר היא בדקה את הדאגה הנקובה של המדיניות. ראה [סמכות מדיניות](/he/policies/authority) לפני התאמת על הסילוק. Jev יכול גם להזהיר או לשלול בעצמו. אם היא לא יכולה לענות, תוצאת המדיניות מחליטה על קריאה זו.

כאשר תוצאות הצפייה נראות נכונות, עבור למצב אכיפה ב-**Settings → Jev** או הרץ:

```bash
failproofai jev setup --mode enforce
```

עבור כתובות URL של ספקים, מפתחות Cloud, תצורה, fallbacks, ונתונים שנשלחו עם כל בקשה, ראה את [הפניית האינטגרציה של Jev](/he/reference/jev).
