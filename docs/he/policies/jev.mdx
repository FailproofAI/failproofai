Jev בודקת קריאת כלי מול מה שהאדם ביקש מהסוכן לעשות. השתמש בה כאשר מדיניות התאמת מחרוזות חוסמת עבודה תקפה או מחמיקה פעולה מסוכנת שזקוקה להקשר. היא משיבה לצד המדיניויות שלך בשער `PreToolUse` או `PermissionRequest`. לקבלת ניקוד **לאחר** סיום הפגישה, השתמש ב[הערכות Jev](/he/evaluations/jev).

## התחל במצב צפייה

התקן את Failproof AI וחבר hooks ל[harness נתמך](/he/reference/harnesses). השתמש בגרסה 1.0.8-beta.0 של failproofai או גרסה חדשה יותר.

Failproof AI לא משתלחת עם בדיקות Jev. התקן אותן כחבילה, אחרת ל-Jev אין מה לשאול ולא היא לעולם תיקרא:

```bash
failproofai policies add FailproofAI/jev-policies
```

לאחר מכן בחר כיצד בקשות מגיעות ל-Jev:

| נתיב | הצעד הראשון |
| --- | --- |
| FailproofAI Cloud | התחבר עם מפתח **machine** הנושא `jev:evaluate`. במכונה ללא הגדרת Jev, `failproofai config` הופכת את Jev למצב צפייה. |
| הספק שלך | בלוח הבקרה המקומי, פתח **Settings → Jev**, בחר את הספק, הדבק את הטוקן שלו, ובחר **observe**. או הרץ `failproofai jev --url https://api.typesafe.ai/v1 --mode observe --key-stdin < ~/typesafe.key`. |

![הגדרות Jev של לוח הבקרה המקומי: ספק, endpoint, טוקן ומצב צפייה לפני הפעלת Jev.](/images/dashboard/jev-settings.png)

```bash
failproofai jev status
failproofai jev test
```

`test` בודק את ה-endpoint. כדי לבדוק את נתיב ה-hook, בקש מסוכן מחובר להשתמש בכלי קריאת הקבצים שלו ב-`README.md`. אשר שקריאת הכלי הזו מופיעה בפגישה, ואז בדוק **Policies → Activity** ב[לוח הבקרה המקומי](/he/reference/local-dashboard#review-policy-activity). ספירת Jev ב-`status` צריכה להעלות. מצב צפייה רושם מה Jev היתה החליטה בעוד שתוצאת המדיניות הקיימת שלך עדיין חלה.

## החלט מתי להטיל

מדיניות **hard** תמיד יש את הדברים האחרונים. Jev אולי תנקה deny רק ממדיניות המסומנת במפורש **reviewable** ורק כאשר היא בדקה את הדאגה בשם של המדיניות הזו. ראה [policy authority](/he/policies/authority) לפני הסתמכות על ניקוי. Jev יכולה גם להזהיר או לדחות בעצמה. אם היא לא יכולה לענות, תוצאת המדיניות קובעת את הקריאה הזו.

לאחר שתוצאות הצפייה נראות נכונות, עבור למצב enforce ב-**Settings → Jev** או הרץ:

```bash
failproofai jev setup --mode enforce
```

לקבלת כתובות ספקים, Cloud keys, הגדרות, fallbacks, ונתונים שנשלחים עם כל בקשה, ראה את [עזר שילוב Jev](/he/reference/jev).
