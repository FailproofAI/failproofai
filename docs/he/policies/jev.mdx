Jev קורא קריאת כלים מול מה שהאדם ביקש מהסוכן לעשות. השתמש בו כאשר מדיניות התאמת מחרוזות חוסמת עבודה תקפה או מפספסת פעולה מסוכנת שדורשת הקשר. הוא עונה לצד המדיניות שלך בשער `PreToolUse` או `PermissionRequest`. לציון **לאחר** שסשן מסתיים, השתמש ב-[Jev evaluations](/he/evaluations/jev).

## התחל במצב תצפית

התקן את Failproof AI והצמד hook ל-[harness נתמך](/he/reference/harnesses). השתמש ב-failproofai 1.0.8-beta.0 או בגרסה מאוחרת יותר.

Failproof AI אינו משלח בדיקות Jev. התקנם כחבילה, או ל-Jev אין מה לשאול ולעולם לא תקראה:

```bash
failproofai policies add FailproofAI/jev-policies
```

לאחר מכן בחר כיצד בקשות מגיעות אל Jev:

| נתיב | שלב ראשון |
| --- | --- |
| FailproofAI Cloud | התחבר עם מפתח **machine** הנושא `jev:evaluate`. במכונה ללא תצורת Jev, `failproofai config` הופך את Jev למצב תצפית. |
| ספק משלך | בלוח הבקרה המקומי, פתח את **Settings → Jev**, בחר בספק, הדבק את האסימון שלו, ובחר **observe**. או הריץ `failproofai jev --url https://api.typesafe.ai/v1 --mode observe --key-stdin < ~/typesafe.key`. |

![הגדרות Jev של לוח הבקרה המקומי: ספק, נקודת קצה, אסימון, ומצב תצפית לפני הפעלת Jev.](/images/dashboard/jev-settings.png)

```bash
failproofai jev status
failproofai jev test
```

`test` בודק את נקודת הקצה. כדי לבדוק את נתיב ה-hook, בקש מסוכן מחובר להשתמש בכלי קריאת הקבצים שלו על `README.md`. אשר שקריאת הכלים הזאת מופיעה בסשן, ואז בדוק את **Policies → Activity** ב-[לוח הבקרה המקומי](/he/reference/local-dashboard#review-policy-activity). ספירת Jev ב-`status` צריכה לעלות. מצב התצפית מתעד מה Jev היה החליט בעודו תוצאת המדיניות הקיימת שלך עדיין חלה.

## החלט מתי לאכוף

מדיניות **hard** תמיד יש את הדברים האחרונים. Jev עשוי להוציא רק 否הימ ממדיניות מסומנת במפורש כ-**reviewable** ורק כאשר היא בדקה את הדאגה הנקובה של המדיניות. ראה [policy authority](/he/policies/authority) לפני הסתמכות על קבלה. Jev יכול גם להזהיר או להכחיש בכוחות עצמו. אם הוא לא יכול לענות, תוצאת המדיניות מחליטה על קריאה זו.

כשתוצאות התצפית נראות נכונות, עבור למצב אכיפה ב-**Settings → Jev** או הריץ:

```bash
failproofai jev setup --mode enforce
```

לכתובות URL של ספקים, מפתחות Cloud, תצורה, חזרות לאחור, ונתונים שנשלחים עם כל בקשה, ראה את [Jev integration reference](/he/reference/jev).
