Jev קורא קריאת כלי מול מה שביקשו אדם מהסוכן לעשות. השתמש בה כאשר מדיניות התאמת מחרוזות חוסמת עבודה תקפה או מחמיצה פעולה מסוכנת הזקוקה להקשר. היא משיבה לצד המדיניויות שלך בשער `PreToolUse` או `PermissionRequest`. לניקוד **לאחר** סיום הפעילות, השתמש ב-[Jev evaluations](/he/evaluations/jev).

## התחל במצב צפייה

התקן את Failproof AI וצרף hooks ל-[harness נתמך](/he/reference/harnesses). השתמש בגרסה failproofai 1.0.8-beta.0 או חדשה יותר.

Failproof AI אינו משלח בדיקות Jev. התקן אותן כחבילה, או ל-Jev אין מה לשאול ולעולם לא יוקרא:

```bash
failproofai policies add FailproofAI/jev-policies
```

לאחר מכן בחר כיצד בקשות מגיעות ל-Jev:

| נתיב | שלב ראשון |
| --- | --- |
| FailproofAI Cloud | התחבר עם מפתח **machine** הנושא `jev:evaluate`. במכונה ללא הגדרת Jev, `failproofai config` הופך את Jev למצב צפייה. |
| הספק שלך | בלוח הבקרה המקומי, פתח **Settings → Jev**, בחר בספק, הדבק את האסימון שלו, ובחר **observe**. או הריץ `failproofai jev --url https://api.typesafe.ai/v1 --mode observe --key-stdin < ~/typesafe.key`. |

![הגדרות Jev של לוח הבקרה המקומי: ספק, endpoint, אסימון, ומצב צפייה לפני הפעלת Jev.](/images/dashboard/jev-settings.png)

```bash
failproofai jev status
failproofai jev test
```

`test` בודק את ה-endpoint. כדי לבדוק את נתיב ה-hook, בקש מסוכן בעל hooks להשתמש בכלי קריאת הקבצים שלו על `README.md`. אשר שקריאת הכלי הזו מופיעה בפעילות, ואחר כך בדוק **Policies → Activity** בלוח [הבקרה המקומי](/he/reference/local-dashboard#review-policy-activity). ספירת Jev ב`status` צריכה להיות גבוהה יותר. מצב צפייה מתעד את מה שJev הוא הוא היה מחליט בזמן שתוצאת המדיניות הקיימת שלך עדיין חלה.

## החלט מתי לאכוף

מדיניות **hard** תמיד יש את המילה האחרונה. Jev עשוי לחסל deny רק ממדיניות מסומנת בעליל **reviewable** ורק כאשר היא בדקה את ההשגחה המנויה של המדיניות הזו. ראה [policy authority](/he/policies/authority) לפני הסתמכות על קבלה. Jev יכול גם להזהיר או לחסום בעצמו. אם היא לא יכולה לענות, תוצאת המדיניות קובעת את הקריאה הזו.

ברגע שתוצאות הצפייה נראות נכונות, עבור למצב אכיפה ב-**Settings → Jev** או הריץ:

```bash
failproofai jev setup --mode enforce
```

עבור כתובות ספקי, מפתחות Cloud, הגדרה, fallbacks ונתונים שנשלחים עם כל בקשה, ראה את [Jev integration reference](/he/reference/jev).
