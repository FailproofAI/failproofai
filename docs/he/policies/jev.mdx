Jev קורא קריאת כלי מול מה שהאדם ביקש מהסוכן לעשות. השתמש בו כאשר מדיניות התאמת מחרוזות חוסמת עבודה תקפה או מחמיצה פעולה מסוכנת הדורשת הקשר. זה עונה לצד המדיניות שלך בשער `PreToolUse` או `PermissionRequest`. לתוצאה **אחרי** סיום סשן, השתמש ב[הערכות Jev](/he/evaluations/jev).

## התחל במצב צפייה

התקן את Failproof AI והדבק הוקים ל[מנגנון נתמך](/he/reference/harnesses). השתמש בגרסה failproofai 1.0.8-beta.0 ואילך.

Failproof AI לא משלחת בדיקות Jev. התקן אותן כחבילה, או ל-Jev אין מה לשאול ולעולם לא תיקראנו:

```bash
failproofai policies add FailproofAI/jev-policies
```

לאחר מכן בחר כיצד בקשות מגיעות אל Jev:

| נתיב | הצעד הראשון |
| --- | --- |
| FailproofAI Cloud | התחבר עם מפתח **machine** הנושא `jev:evaluate`. על מכונה ללא תצורת Jev, `failproofai config` מפעיל את Jev במצב צפייה. |
| הספק שלך | בלוח הבקרה המקומי, פתח **Settings → Jev**, בחר את הספק, הדבק את הטוקן שלו, ובחר **observe**. או הרץ `failproofai jev --url https://api.typesafe.ai/v1 --mode observe --key-stdin < ~/typesafe.key`. |

![הגדרות Jev של לוח הבקרה המקומי: ספק, endpoint, טוקן, ומצב צפייה לפני הפעלת Jev.](/images/dashboard/jev-settings.png)

```bash
failproofai jev status
failproofai jev test
```

`test` בודק את ה-endpoint. כדי לבדוק את נתיב ה-hook, בקש מסוכן מחובר להשתמש בכלי קריאת הקובץ שלו ב-`README.md`. אשר שקריאת הכלי הזו מופיעה בסשן, ואז בדוק את **Policies → Activity** ב[לוח הבקרה המקומי](/he/reference/local-dashboard#review-policy-activity). ספירת ה-Jev ב-`status` צריכה להגדיל. מצב צפייה רושם מה Jev היה מחליט בעוד התוצאה של המדיניות הקיימת שלך עדיין תחול.

## החליט מתי לאכוף

מדיניות **hard** תמיד יש לה את הדבר האחרון. Jev עשוי לנקות כניסה רק ממדיניות שתויגה במפורש כ-**reviewable** וברק כאשר הוא בדק את הדאגה הנקובה של המדיניות הזו. ראה [סמכות מדיניות](/he/policies/authority) לפני הסתמכות על קרחה. Jev יכול גם להזהיר או לשלול בעצמו. אם לא יכול לענות, תוצאת המדיניות מחליטה על הקריאה הזו.

ברגע שתוצאות הצפייה נראות נכונות, עבור למצב אכיפה ב-**Settings → Jev** או הרץ:

```bash
failproofai jev setup --mode enforce
```

עבור כתובות ספקים, מפתחות Cloud, תצורה, חזרות כלליות, ונתונים שנשלחו עם כל בקשה, ראה את [ההתייחسות לשילוב Jev](/he/reference/jev).
