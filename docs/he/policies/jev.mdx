Jev קורא קריאת כלי מול מה שהאדם ביקש מהסוכן לעשות. השתמש בו כאשר מדיניות התאמת מחרוזות חוסמת עבודה תקפה או מחמיצה פעולה מסוכנת הדורשת הקשר. זה עונה לצד המדיניויות שלך בשער `PreToolUse` או `PermissionRequest`. לניקוד **לאחר** שסשן מסתיים, השתמש ב-[Jev evaluations](/he/evaluations/jev).

## התחל במצב צפייה

התקן את Failproof AI והצמד hook לסדר [נתמך](/he/reference/harnesses). השתמש ב-failproofai 1.0.8-beta.0 או גרסה מאוחרת יותר.

Failproof AI לא מגיע עם בדיקות Jev. התקן אותם כחבילה, או שלJev אין מה לשאול ולא יהיה קריא אליו:

```bash
failproofai policies add FailproofAI/jev-policies
```

לאחר מכן בחר כיצד בקשות מגיעות אל Jev:

| נתיב | שלב ראשון |
| --- | --- |
| FailproofAI Cloud | התחבר בעזרת מפתח **machine** הנושא `jev:evaluate`. על מכונה ללא תצורת Jev, `failproofai config` מפעיל את Jev במצב צפייה. |
| ספק משלך | בלוח הבקרה המקומי, פתח **Settings → Jev**, בחר את הספק, הדבק את הטוקן שלו, ובחר **observe**. או הרץ `failproofai jev --url https://api.typesafe.ai/v1 --mode observe --key-stdin < ~/typesafe.key`. |

![הגדרות Jev של לוח הבקרה המקומי: ספק, endpoint, טוקן, ומצב צפייה לפני הפעלת Jev.](/images/dashboard/jev-settings.png)

```bash
failproofai jev status
failproofai jev test
```

`test` בודק את ה-endpoint. כדי לבדוק את נתיב ה-hook, בקש מסוכן מחובר להשתמש בכלי קריאת הקובץ שלו ב-`README.md`. אשר שקריאת הכלי הזאת מופיעה בסשן, ואז בדוק **Policies → Activity** בלוח [הבקרה המקומי](/he/reference/local-dashboard#review-policy-activity). ספירת Jev ב-`status` צריכה לעלות. מצב צפייה רושם מה היה עלוJev להחליט בעוד שתוצאת המדיניות הקיימת שלך עדיין חלה.

## החלט מתי לאכוף

מדיניות **hard** תמיד יש לה את המילה האחרונה. Jev עשוי לנקות deny רק ממדיניות המסומנת במפורש כ-**reviewable** וזה רק כאשר הוא בדק את הדאגה הנקובה של המדיניות הזו. ראה [policy authority](/he/policies/authority) לפני שאתה מסתמך על ניקוי. Jev יכול גם להזהיר או להכחיש בעצמו. אם הוא לא יכול לענות, תוצאת המדיניות מחליטה על הקריאה הזו.

ברגע שתוצאות הצפייה נראות נכונות, עבור למצב אכיפה ב-**Settings → Jev** או הרץ:

```bash
failproofai jev setup --mode enforce
```

עבור כתובות ספק, מפתחות Cloud, הגדרות, fallbacks, ונתונים שנשלחים עם כל בקשה, ראה את [Jev integration reference](/he/reference/jev).
