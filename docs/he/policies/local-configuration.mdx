השתמש בـ scope כדי להחליט מי מקבל מדיניות מקומית:

| Scope | חל על |
| --- | --- |
| `user` | הסוכנים הנתמכים שלך במכונה זו |
| `project` | סוכנים הפועלים בפרויקט זה |
| `local` | Claude בלבד, בהגדרות הפרויקט המקומי |
| `all` | הסרה בלבד |

```bash
failproofai policies add block-sudo --scope user
failproofai policies add block-rm-rf --scope project
```

Hermes ו-OpenClaw תומכים בـ user scope בלבד. רוב ההרנסים האחרים תומכים ב-user וב-project. Claude תומך גם ב-local scope. ראה [Harnesses](/he/reference/harnesses).

## פרמטרי מדיניות

הגדרות המדיניות נמצאות בـ `policies-config.json` בـ scope התואם. השתמש בתצוגת **Policies → Configure** של לוח הבקרה המקומי כאשר זה אפשרי.

פרמטר שייך למדיניות אחת ומשנה כיצד מדיניות זו מחליטה. לדוגמה, רשימת מתן הרשאה יכולה להפוך מדיניות חוסמת לקבל פקודות או נתיבים בטוחים ידועים.

קבצי מדיניות מותאמים אישית יכולים להיטען באופן אוטומטי מ-`.failproofai/policies/`, או בעקיפין:

```bash
failproofai policies -i -c ./guards.mjs --scope project
```

הסר נתיבים מפורשים עם:

```bash
failproofai policies -u -c
```

## קבצים

| קובץ | מטרה |
| --- | --- |
| `~/.failproofai/config.json` | הגדרות מכונה ואספן |
| `policies-config.json` | מדיניויות מאופשרות ופרמטרים עבור scope |
| `.failproofai/policies/*policies.mjs` | מדיניויות שנטענו לפי קונבנציה |
| `~/.failproofai/policies/packs/installed.json` | חבילות מותקנות וברירות |

אל תערוך חפצי חבילה מותקנות באופן ישיר. התקן מחדש או פרסם גרסה מתוקנת.
