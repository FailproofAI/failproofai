השתמש ב־`fp` כדי לבדוק טלמטריה של Cloud, לנהל אכיפה מנוהלת בענן (מדיניות, פריסות fleet, החלטות guardrail), ולנהל ביקורות, ממצאים, בעיות, התראות, מפתחות, משתמשים, שאילתות והגדרות. השתמש ב־[`failproofai`](/he/reference/failproof-cli) עבור hooks מקומיים, מדיניות, capture והרשמת מכונה.

התקן את ה־Cloud CLI שוחרר ככלי מבודד:

```bash
uv tool install fp-cloud-cli
fp version
```

## התחברות

```bash
fp login
fp whoami
```

## תחביר

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

אפשרויות גלובליות חייבות להופיע לפני הפקודה:

```bash
fp --json sessions --since 24h
```

הרץ `fp COMMAND --help` או `fp COMMAND SUBCOMMAND --help` לעזרה בטרמינל.

### אירועים

```text
fp events [OPTIONS]
```

רשום אירועי סוכן בודדים. הרד הקל המוגדר כברירת מחדל אינו כולל עומסים גולמיים; השתמש ב־`--full` רק לחקירה מוגבלת.

| אפשרות | תיאור |
| --- | --- |
| `--limit`, `-n <n>` | מספר שורות כולל מרבי. ברירת מחדל: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h`, או `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | טווח ISO 8601 UTC; דורס את `--since`. |
| `--env <value>` | מסנן סביבה; חזור או הפרד בפסיקים. |
| `--event-type <value>` | מסנן סוג אירוע; חזור או הפרד בפסיקים. |
| `--agent-id <value>` | מסנן סוכן; חזור או הפרד בפסיקים. |
| `--session-id <value>` | מסנן הפעלה; חזור או הפרד בפסיקים. |
| `--search <text>` | חיפוש טקסט בעומס; ניתן לחזור, כל מונח תואם. |
| `--order asc\|desc` | סדר זמן. ברירת מחדל: חדש ביותר ראשון. |
| `--all` | עמוד אוטומטי עד `--limit`. |
| `--cursor <token>` | חזור מקורסור אטום. |
| `--page-size <n>` | שורות לכל בקשה עם `--all`; מרבי `200`. |
| `--full` | כלול עומסים גולמיים דרך נקודת הקצה של אירוע כבדה יותר. |
| `--fields <csv>` | החזר רק שדות נבחרים; בקשה ל־`payload` מאפשרת מצב מלא. |

```bash
fp events --session-id <session-id> --order asc --all --limit 10000
fp --json events --full --session-id <session-id> --all --limit 10000
```

<Note>
  `--all` עמודים **עד `--limit`**, שברירת מחדל לו **50** — כך ש־`--all` בפני עצמו עוצר ב־50 שורות. כשהוא עוצר מוקדם, התגובה נושאת `next_cursor` כדי להמשיך ממנו; `"next_cursor": null` אומר שהרד אכן מותש.
</Note>

#### אפשרויות יצירת ביקורת

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| אפשרות | תיאור |
| --- | --- |
| `--file <path>` | בסיס ההגדרה על JSON, או השתמש ב־`-` עבור stdin. דגלים מפורשים דורסים ערכי קובץ. |
| `--description <text>` | ציין את שאלת ההכשל או המטרה. |
| `--enabled` / `--disabled` | התחל תזמון פעיל או כבוי. ברירת מחדל: מאופשר. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. ברירת מחדל: `86400`. |
| `--schedule-anchor <timestamp>` | שלב UTC קבוע בצורת ISO 8601. ברירת מחדל: ה־09:00 UTC הבא. |
| `--window-mode since_last\|fixed` | המשך לאחר חלון האחרון שנותחה לחלוטין או בדוק שוב חלון מתגלגל. ברירת מחדל: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. ברירת מחדל: `604800`. |
| `--scope '<json>'` | סנן לפי `environments`, `agent_ids`, או שדות scope אחרים תומכים. |
| `--ignore-error-type <type>` | לא לכלול סוגי שגיאות; חזור או הפרד בפסיקים. |
| `--llm` / `--no-llm` | הפוך או בטל אנליזה סוכנית. ברירת מחדל: מאופשר. |
| `--top-k <n>` | שמור ממצאים `1`–`500`. ברירת מחדל: `50`. |
| `--sensitivity low\|medium\|high` | הגדר רגישות דיווח. ברירת מחדל: `medium`. |
| `--channels '<json>'` | מערך ערוצי התראה. |
| `--text <brief>` | קצר מובנה, מרבי 8,192 תווים. |
| `--text-file <path>` | קרא את הקצר מקובץ; בלעדי הדדי עם `--text`. |
| `--url <https-url>` | הוסף הפניה ציבורית HTTPS; חזור עד חמש פעמים. |

כלול הקשר במהלך יצירה כאשר ההרצה הראשונה זקוקה לו. יצירה מחייבת את ההגדרה וההקשר יחד לפני תחילת ההרצה בתור.

<Note>
  `fp audits run` הוא אסינכרוני. סקור `fp audits runs NAME` עד שההרצה האחרונה תהיה מוצלחת או כושלת לפני קריאת הממצאים שלה.
</Note>

מצבי בעיה חוקיים הם `firing`, `acknowledged`, ו־`resolved`. חומרות בעיה עצמאיות הן `info`, `warning`, ו־`critical`.

### מדיניות

גרסאות מדיניות מנוהלות ענן. **הפעלה בלבד** — כל פקודה כאן יוצאת `2` תחת מפתח API, לפני כל בקשה, כי אלה נתיבי כתיבה בעל שורש בכוונה היעדרים מ־`/v1`.

| פקודה | מטרה | אפשרויות |
| --- | --- | --- |
| `fp policies list` | רשום גרסאות מדיניות. | `--json` |
| `fp policies show POLICY_ID` | הצג מדיניות אחת, עם המקור שלה. | — |
| `fp policies publish NAME PATH` | טבע גרסה מ־`.mjs` מקומי. | `--description`; `--no-verify` |
| `fp policies enable POLICY_ID` | הוסף אותו חזרה לכל פריסה שהוא הוסר ממנה, טבע דור חדש בכל אחת. | `--yes`, `-y` |
| `fp policies disable POLICY_ID` | הסר אותו מכל פריסה הנושאת אותו, טבע דור חדש בכל אחת. | `--yes`, `-y` |
| `fp policies delete POLICY_ID` | מחק גרסת מדיניות. | `--yes`, `-y` |
| `fp policies test PATH` | הרץ מדיניות באופן מקומי כנגד הקשר סינתטי. מחיל את מסנן `match` של כל מדיניות, כך שאחת שלא מכסה את האירוע/הכלי הנתון מדווחת `skipped` במקום להירות. | `--event`; `--tool`; `--command`; `--file-path`; `--expect` |
| `fp policies compose PROMPT` | טיוטה מדיניות עם העוזר. צריך `policies:write`. | — |

## דגלים גלובליים

| דגל | תיאור |
| --- | --- |
| `--json` | פלוט JSON קריא למכונה. |
| `--base-url <url>` | השתמש בדDashboard משודר או פיתוח. |
| `--org <slug>` | בחר ארגון להפעלה זו. |
| `--token <token>` | דרס את אסימון ההפעלה של המשתמש השמור. |
| `--api-key <key>` | אימות אוטומציה עם מפתח API; לעולם לא שמור. |
| `--timeout <seconds>` | HTTP timeout; חייב להיות חיובי. ברירת מחדל: `30`. |
| `--quiet`, `-q` | דכא פלט מצב ב־stderr. |
| `--no-color` | בטל פלט צבוע. |
| `--insecure` / `--secure` | בטל או שחזר אימות תעודה TLS. |
| `--version` | הדפס את הגרסה ללא תיבה וצא. |
| `--help`, `-h` | הצג עזרה. |

`--api-key` מיועד לאוטומציה. התחברות, החלפת ארגון, ופקודות עוזר דורשות הפעלת משתמש.

דגלים מפורשים דורסים משתנים סביבה, המדרסים קונפיגורציה שמורה. במצב מפתח API, בחר את הדייר במפורש עם `--org` או `FP_ORG`.

<Warning>
  ההוקעות של `AGENTEYE_*` אלה **אינן קריאות על ידי `fp`** ולעולם לא היו — ה־CLI מצהיר `FP_*` (`fp_cli/app.py`), ומשתנה לא ידוע אינו שגיאה. הגדרת `AGENTEYE_DASHBOARD_URL` לא משנה את יעד ה־CLI; היא מתעלמת והפקודה פועלת בשקט כנגד לוח הבקרה השמור במקום.

  `AGENTEYE_HOME` ו־`AGENTEYE_ENVIRONMENT` עדיין קיימים, אך הם שייכים ל־**Collector וה־SDK של טלמטריה**, לא ל־CLI זה.
</Warning>

<Warning>
  פקודות שמחקות, מבטלות, דוכים, פותרות, או מחליפות קונפיגורציה שאלה כברירת מחדל. השתמש ב־`--yes` רק לאחר אימות הארגון הפעיל והיעד.
</Warning>
