השתמש ב-`fp` לבחינת טלמטריה בענן וניהול ביקורות, ממצאים, בעיות, התראות, מפתחות, משתמשים, שאילתות והגדרות. השתמש ב-[`failproofai`](/he/reference/failproof-cli) לוו-קישורים מקומיים, מדיניות, לכידה ורישום מכונות.

התקן את Cloud CLI המשוחרר ככלי מבודד:

```bash
uv tool install fp-cli
fp version
```

## התחברות

```bash
fp login
fp whoami
```

## תחביר

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

אפשרויות גלובליות חייבות לבוא לפני הפקודה:

```bash
fp --json sessions --since 24h
```

הרץ `fp COMMAND --help` או `fp COMMAND SUBCOMMAND --help` לעזרה בטרמינל.

### אירועים

```text
fp events [OPTIONS]
```

מפרט אירועי סוכן בודדים. ההזנה הקלה המוגדרת כברירת מחדל אינה כוללת עומסי עבודה גולמיים; השתמש ב-`--full` רק לחקירה מוגבלת.

| אפשרות | תיאור |
| --- | --- |
| `--limit`, `-n <n>` | סך הכל שורות מקסימום. ברירת מחדל: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h`, או `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | טווח ISO 8601 UTC; משבית `--since`. |
| `--env <value>` | סנן סביבה; חזור או הפרד בפסיק. |
| `--event-type <value>` | סנן סוג אירוע; חזור או הפרד בפסיק. |
| `--agent-id <value>` | סנן סוכן; חזור או הפרד בפסיק. |
| `--session-id <value>` | סנן הפעלה; חזור או הפרד בפסיק. |
| `--search <text>` | חיפוש טקסט עומס; חוזר, כל מונח תואם. |
| `--order asc\|desc` | סדר זמן. ברירת מחדל: החדש ביותר ראשון. |
| `--all` | עימוד אוטומטי עד `--limit`. |
| `--cursor <token>` | המשך מסמן אטום. |
| `--page-size <n>` | שורות לבקשה עם `--all`; מקסימום `200`. |
| `--full` | כלול עומסי עבודה גולמיים דרך נקודת הקצה של אירוע כבדה יותר. |
| `--fields <csv>` | החזר רק שדות נבחרים; בקשה `payload` מאפשרת מצב מלא. |

```bash
fp events --session-id <session-id> --order asc --all
fp --json events --full --session-id <session-id> --all
```

#### אפשרויות יצירת ביקורת

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| אפשרות | תיאור |
| --- | --- |
| `--file <path>` | בסיס ההגדרה על JSON, או השתמש ב-`-` עבור stdin. דגלים מפורשים מעקפים ערכי קובץ. |
| `--description <text>` | ציין את שאלת ההכשל או המטרה. |
| `--enabled` / `--disabled` | התחל תזמון או מחוזק. ברירת מחדל: מופעל. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. ברירת מחדל: `86400`. |
| `--schedule-anchor <timestamp>` | שלב UTC קבוע בצורת ISO 8601. ברירת מחדל: 09:00 UTC הבא. |
| `--window-mode since_last\|fixed` | המשך לאחר החלון המנותח לאחרונה או בדוק שוב ושוב חלון מתגלגל. ברירת מחדל: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. ברירת מחדל: `604800`. |
| `--scope '<json>'` | סנן לפי `environments`, `agent_ids`, או שדות טווח נתמכים אחרים. |
| `--ignore-error-type <type>` | אל תכלול סוגי שגיאות; חזור או הפרד בפסיק. |
| `--llm` / `--no-llm` | הפוך או השבת ניתוח סוכן. ברירת מחדל: מופעל. |
| `--top-k <n>` | שמור `1`–`500` ממצאים. ברירת מחדל: `50`. |
| `--sensitivity low\|medium\|high` | קבע רגישות דיווח. ברירת מחדל: `medium`. |
| `--channels '<json>'` | מערך ערוץ הודעה. |
| `--text <brief>` | קצר מובנה, מקסימום 8,192 תווים. |
| `--text-file <path>` | קרא את הקצר מקובץ; בלעדי הדדי עם `--text`. |
| `--url <https-url>` | הוסף ייחוס ציבורי HTTPS; חזור עד חמש פעמים. |

כלול הקשר במהלך יצירה כאשר הריצה הראשונה זקוקה לה. יצירה מחייבת את ההגדרה וההקשר יחדיו לפני תחילת הריצה בתור.

<Note>
  `fp audits run` הוא אסינכרוני. סקור `fp audits runs NAME` עד שהריצה האחרונה תצליח או תיכשל לפני קריאת הממצאים שלה.
</Note>

| דגל | תיאור |
| --- | --- |
| `--json` | פלוט JSON הניתן לקריאת מכונה. |
| `--base-url <url>` | השתמש במעצב המארח או בפיתוח. |
| `--org <slug>` | בחר ארגון לזימון זה. |
| `--token <token>` | עקוף את אסימון ההפעלה המשומר של המשתמש. |
| `--api-key <key>` | אימות אוטומציה עם מפתח API; אף פעם לא שמור. |
| `--timeout <seconds>` | פגיעה ב-HTTP; חייב להיות חיובי. ברירת מחדל: `30`. |
| `--quiet`, `-q` | דכא פלט סטטוס ב-stderr. |
| `--no-color` | השבת פלט צבעוני. |
| `--insecure` / `--secure` | השבת או שחזר אימות תעודת TLS. |
| `--version` | הדפס את הגרסה הלא מעוטפת וצא. |
| `--help`, `-h` | הצג עזרה. |

`--api-key` מיועד לאוטומציה. התחברות, עברת ארגון, ופקודות עוזר דורשות הפעלת משתמש.

## משתנים סביבה

| משתנה | שקול או מטרה |
| --- | --- |
| `AGENTEYE_DASHBOARD_URL` | `--base-url` |
| `AGENTEYE_ORG` | `--org` |
| `AGENTEYE_CLI_TOKEN` | `--token` |
| `AGENTEYE_CLI_API_KEY` | `--api-key` |
| `AGENTEYE_CLI_JSON` | `--json` |
| `AGENTEYE_INSECURE` | `--insecure` |

דגלים מפורשים משבים משתנים סביבה, המשבים תצורה משומרת. במצב מפתח API, בחר את השוכר מפורשות עם `--org` או `AGENTEYE_ORG`.

</Warning>
