השתמש ב-`fp` לבדיקת טלמטריית Cloud, ניהול כפיית Cloud (מדיניות, פריסות צי, החלטות guardrail), וניהול ביקורות, ממצאים, בעיות, התראות, מפתחות, משתמשים, שאילתות והגדרות. השתמש ב-[`failproofai`](/he/reference/failproof-cli) עבור hooks מקומיים, מדיניות, capture וההרשמה של מכונות.

התקן את Cloud CLI המשוחרר ככלי מבודד:

```bash
uv tool install fp-cloud-cli
fp version
```

## כניסה

```bash
fp login
fp whoami
```

## תחביר

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

אפשרויות גלובליות חייבות להיות לפני הפקודה:

```bash
fp --json sessions --since 24h
```

הרץ `fp COMMAND --help` או `fp COMMAND SUBCOMMAND --help` לעזרה בטרמינל.

### Events

```text
fp events [OPTIONS]
```

רשימת אירועי agent בודדים. ההזנה הקלה ברירת המחדל אינה כוללת payload גולם; השתמש ב-`--full` רק לחקירה מוגבלת.

| Option | Description |
| --- | --- |
| `--limit`, `-n <n>` | מרבי שורות כוללות. ברירת מחדל: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h`, או `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | טווח ISO 8601 UTC; דורס את `--since`. |
| `--env <value>` | מסנן סביבה; חזור או הפרד בפסיקים. |
| `--event-type <value>` | מסנן סוג אירוע; חזור או הפרד בפסיקים. |
| `--agent-id <value>` | מסנן agent; חזור או הפרד בפסיקים. |
| `--session-id <value>` | מסנן session; חזור או הפרד בפסיקים. |
| `--search <text>` | חיפוש טקסט payload; חוזר, כל מונח תואם. |
| `--order asc\|desc` | סדר זמן. ברירת מחדל: החדש ביותר תחילה. |
| `--all` | עימוד אוטומטי עד `--limit`. |
| `--cursor <token>` | חידוש מ-cursor אטום. |
| `--page-size <n>` | שורות לבקשה עם `--all`; מרבי `200`. |
| `--full` | כלול payload גולם דרך נקודת הקצה של אירוע כבדה יותר. |
| `--fields <csv>` | החזר רק שדות נבחרים; בקשת `payload` מאפשרת מצב מלא. |

```bash
fp events --session-id <session-id> --order asc --all --limit 10000
fp --json events --full --session-id <session-id> --all --limit 10000
```

<Note>
  `--all` פוגן **עד `--limit`**, שברירת המחדל היא **50** — אז `--all` לבדו מעצור ב-50 שורות. כאשר הוא מעצור מוקדם התגובה נושאת `next_cursor` לחידוש מעמדה; `"next_cursor": null` פירושו שההזנה באמת הייתה מחוקה.
</Note>

#### Audit create options

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| Option | Description |
| --- | --- |
| `--file <path>` | בסיס ההגדרה על JSON, או השתמש ב-`-` עבור stdin. דגלים מפורשים דורסים ערכי קובץ. |
| `--description <text>` | מדינת שאלת כישלון או מטרה. |
| `--enabled` / `--disabled` | תחילת תזמון מופעל או כבוי. ברירת מחדל: מופעל. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. ברירת מחדל: `86400`. |
| `--schedule-anchor <timestamp>` | שלב UTC קבוע בצורה ISO 8601. ברירת מחדל: 09:00 UTC הבא. |
| `--window-mode since_last\|fixed` | המשך לאחר החלון שנותח לאחרונה או בדיקה חוזרת של חלון מתגלגל. ברירת מחדל: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. ברירת מחדל: `604800`. |
| `--scope '<json>'` | סנן לפי `environments`, `agent_ids`, או שדות scope נתמכים אחרים. |
| `--ignore-error-type <type>` | הסרת סוגי שגיאה; חזור או הפרד בפסיקים. |
| `--llm` / `--no-llm` | הפעלה או השבתה של ניתוח agentic. ברירת מחדל: מופעל. |
| `--top-k <n>` | שמור `1`–`500` ממצאים. ברירת מחדל: `50`. |
| `--sensitivity low\|medium\|high` | הגדרת רגישות דיווח. ברירת מחדל: `medium`. |
| `--channels '<json>'` | מערך ערוץ התראה. |
| `--text <brief>` | תיאור מובנה, מרבי 8,192 תווים. |
| `--text-file <path>` | קרא את התיאור מקובץ; הדדיות בלעדית עם `--text`. |
| `--url <https-url>` | הוספת reference ציבורי HTTPS; חזור עד חמש פעמים. |

כלול הקשר במהלך יצירה כאשר הריצה הראשונה זקוקה לה. יצירה מחייבת את ההגדרה וההקשר ביחד לפני תחילת הריצה בתור.

<Note>
  `fp audits run` אסינכרוני. סקור `fp audits runs NAME` עד שהריצה האחרונה מצליחה או נכשלת לפני קריאת הממצאים שלה.
</Note>

### Policies

| Command | Purpose | Options |

## דגלים גלובליים

| Flag | Description |
| --- | --- |
| `--json` | פלט JSON קריא למכונה. |
| `--base-url <url>` | השתמש בדashboard שמעוכב או פיתוח. |
| `--org <slug>` | בחר ארגון להפעלה זו. |
| `--token <token>` | דרוס את token session המשתמש השמור. |
| `--api-key <key>` | הוסכם אוטומציה עם מפתח API; לעולם לא נשמר. |
| `--timeout <seconds>` | timeout HTTP; חייב להיות חיובי. ברירת מחדל: `30`. |
| `--quiet`, `-q` | דיכוי פלט סטטוס על stderr. |
| `--no-color` | השבתה של פלט צבעוני. |
| `--insecure` / `--secure` | השבתה או שחזור של אימות תעודה TLS. |

דגלים מפורשים דורסים משתנים סביבה, שדורסים תצורה שמורה. במצב מפתח API, בחר את הדייר בצורה מפורשת עם `--org` או `FP_ORG`.

<Warning>
  הכתיבים `AGENTEYE_*` של משתנים אלה **אינם נקראים על ידי `fp`** ומעולם לא נקראו — ה-CLI מצהיר על `FP_*` (`fp_cli/app.py`), ומשתנה לא מוכר אינו נחשב שגיאה. הגדרת `AGENTEYE_DASHBOARD_URL` אינה מפנה את ה-CLI ליעד אחר; מתעלמים ממנה, והפקודה רצה בשקט מול ה-dashboard השמור.

  `AGENTEYE_HOME` ו-`AGENTEYE_ENVIRONMENT` עדיין קיימים, אך הם משתייכים ל-**collector וה-telemetry SDK**, לא ל-CLI זה.
</Warning>

<Warning>
  פקודות המחיקות, רוקות, מדכאות, פותרות, או מחליפות תצורה מהות כברירת מחדל. השתמש ב-`--yes` רק לאחר אימות הארגון הפעיל והיעד.
</Warning>
