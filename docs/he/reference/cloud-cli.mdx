השתמש ב-`fp` כדי לבדוק טלמטריית Cloud, לנהל אכיפה המנוהלת בענן (מדיניות, פריסות צי, החלטות guardrail), ולנהל ביקורות, ממצאים, בעיות, התראות, מפתחות, משתמשים, שאילתות והגדרות. השתמש ב-[`failproofai`](/he/reference/failproof-cli) עבור hooks מקומיים, מדיניות, capture, וביטוח מכונה.

התקן את Cloud CLI המשוחרר כ-tool מבודד:

```bash
uv tool install fp-cloud-cli
fp version
```

## התחברות

```bash
fp login
fp whoami
```

## תחביר

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

אפשרויות globales חייבות להיות לפני הפקודה:

```bash
fp --json sessions --since 24h
```

הרץ `fp COMMAND --help` או `fp COMMAND SUBCOMMAND --help` עבור עזרה בטרמינל.

### Events

```text
fp events [OPTIONS]
```

מפרט אירועי agent בודדים. ה-feed הקל כברירת מחדל אינו כולל payloads גולמיים; השתמש ב-`--full` רק עבור חקירה מוגבלת.

| אפשרות | תיאור |
| --- | --- |
| `--limit`, `-n <n>` | מקסימום שורות כוללות. ברירת מחדל: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h`, או `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | טווח ISO 8601 UTC; מחליף את `--since`. |
| `--env <value>` | מסנן סביבה; חזור או הפרד בפסיקים. |
| `--event-type <value>` | מסנן event-type; חזור או הפרד בפסיקים. |
| `--agent-id <value>` | מסנן agent; חזור או הפרד בפסיקים. |
| `--session-id <value>` | מסנן session; חזור או הפרד בפסיקים. |
| `--search <text>` | חיפוש טקסט payload; חוזר, כאשר כל מונח תואם. |
| `--order asc\|desc` | סדר זמן. ברירת מחדל: החדש ביותר תחילה. |
| `--all` | עמוד אוטומטי עד `--limit`. |
| `--cursor <token>` | חזור מ-cursor בעלום. |
| `--page-size <n>` | שורות לכל בקשה עם `--all`; מקסימום `200`. |
| `--full` | כלול payloads גולמיים דרך נקודת end of events כבדה יותר. |
| `--fields <csv>` | החזר רק שדות נבחרים; בקשת `payload` מפעילה מצב מלא. |

```bash
fp events --session-id <session-id> --order asc --all --limit 10000
fp --json events --full --session-id <session-id> --all --limit 10000
```

<Note>
  `--all` עומד בעמוד **עד `--limit`**, שברירת מחדל היא **50** — כך ש-`--all` בעצמו עוצר ב-50 שורות. כאשר הוא עוצר מוקדם, התגובה נושאת `next_cursor` כדי לחזור ממנו; `"next_cursor": null` פירושו ש-feed באמת הסתיים.
</Note>

#### אפשרויות create של Audit

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| אפשרות | תיאור |
| --- | --- |
| `--file <path>` | בסס את ההגדרה על JSON, או השתמש ב-`-` עבור stdin. דגלים מפורשים דורסים ערכי קובץ. |
| `--description <text>` | ציין את שאלת הכישלון או המטרה. |
| `--enabled` / `--disabled` | התחל תזמון על או כבוי. ברירת מחדל: מאופשר. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. ברירת מחדל: `86400`. |
| `--schedule-anchor <timestamp>` | שלב UTC קבוע בצורת ISO 8601. ברירת מחדל: הבא 09:00 UTC. |
| `--window-mode since_last\|fixed` | המשך אחרי החלון האחרון שנותחה לחלוטין או בדוק שוב חלון גלגול. ברירת מחדל: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. ברירת מחדל: `604800`. |
| `--scope '<json>'` | סנן לפי `environments`, `agent_ids`, או שדות scope אחרים. |
| `--ignore-error-type <type>` | אל תכלול error types; חזור או הפרד בפסיקים. |
| `--llm` / `--no-llm` | הפעל או בטל ניתוח agentic. ברירת מחדל: מאופשר. |
| `--top-k <n>` | שמור `1`–`500` ממצאים. ברירת מחדל: `50`. |
| `--sensitivity low\|medium\|high` | קבע רגישות דיווח. ברירת מחדל: `medium`. |
| `--channels '<json>'` | מערך ערוץ הודעה. |
| `--text <brief>` | brief מוטבע, מקסימום 8,192 תווים. |
| `--text-file <path>` | קרא את ה-brief מקובץ; בלעדי הדדי עם `--text`. |
| `--url <https-url>` | הוסף התייחסות ציבורית HTTPS; חזור עד חמש פעמים. |

כלול context במהלך יצירה כאשר ההפעלה הראשונה זקוקה לו. יצירה מחייבת את ההגדרה ו-context ביחד לפני שההפעלה הקבועה מתחילה.

<Note>
  `fp audits run` אינו סינכרוני. עמוד על `fp audits runs NAME` עד שההפעלה הסופית מצליחה או נכשלת לפני קריאת ממצאים שלה.
</Note>

| פקודה | תכלית | אפשרויות |

## דגלים globales

| דגל | תיאור |

דגלים מפורשים דורסים משתנים סביבה, אשר דורסים את הקונפיגורציה השמורה. במצב API-key, בחר את ה-tenant בצורה מפורשת עם `--org` או `FP_ORG`.

<Warning>
  האיות `AGENTEYE_*` של אלה הם **לא נקרא על ידי `fp`** ואף פעם לא היו — ה-CLI מצהיר `FP_*` (`fp_cli/app.py`), ומשתנה לא ידוע אינו שגיאה. הגדרת `AGENTEYE_DASHBOARD_URL` לא משנה את היעד של ה-CLI; היא מתעלמת והפקודה שקט רצה כנגד הדוח השמור במקום זאת.

  `AGENTEYE_HOME` ו-`AGENTEYE_ENVIRONMENT` עדיין קיימים, אך הם שייכים ל-**collector וטלמטריית SDK**, לא ל-CLI זה.
</Warning>

<Warning>
  פקודות שמוחקות, מבטלות, דוכאות, פותרות, או מחליפות קונפיגורציה מנומנות כברירת מחדל. השתמש ב-`--yes` רק לאחר אימות ארגון פעיל ויעד.
</Warning>
