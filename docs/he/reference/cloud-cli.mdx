השתמש ב-`fp` כדי לבדוק טלמטריה בענן וניהול ביקורות, ממצאים, בעיות, התראות, מפתחות, משתמשים, שאילתות והגדרות. השתמש ב-[`failproofai`](/he/reference/failproof-cli) עבור קישורים מקומיים, מדיניות, הקלטה, והרשמת מכונה.

התקן את Cloud CLI המשוחרר ככלי מבודד:

```bash
uv tool install fp-cli
fp version
```

## התחברות

```bash
fp login
fp whoami
```

## תחביר

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

אפשרויות גלובליות חייבות להופיע לפני הפקודה:

```bash
fp --json sessions --since 24h
```

הרץ `fp COMMAND --help` או `fp COMMAND SUBCOMMAND --help` לעזרה בטרמינל.

### Events

```text
fp events [OPTIONS]
```

מפרטת אירועי סוכן בודדים. הזנת ברירת המחדל הקלה לא כוללת עומסי עבודה גולמיים; השתמש ב-`--full` רק לחקירה מוגבלת.

| אפשרות | תיאור |
| --- | --- |
| `--limit`, `-n <n>` | מקסימום שורות כוללות. ברירת מחדל: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h`, או `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | טווח ISO 8601 UTC; דורס `--since`. |
| `--env <value>` | סינון סביבה; חזור או הפרד בפסיק. |
| `--event-type <value>` | סינון סוג אירוע; חזור או הפרד בפסיק. |
| `--agent-id <value>` | סינון סוכן; חזור או הפרד בפסיק. |
| `--session-id <value>` | סינון סשן; חזור או הפרד בפסיק. |
| `--search <text>` | חיפוש טקסט בעומסי עבודה; יכול להחזור, כל מונח מתאים. |
| `--order asc\|desc` | סדר זמן. ברירת מחדל: החדש ביותר תחילה. |
| `--all` | עמוד אוטומטי עד `--limit`. |
| `--cursor <token>` | המשך מקרסור אטום. |
| `--page-size <n>` | שורות לכל בקשה עם `--all`; מקסימום `200`. |
| `--full` | כלול עומסי עבודה גולמיים דרך נקודת הקצה של האירוע הכבדה יותר. |
| `--fields <csv>` | החזר רק שדות נבחרים; בקשת `payload` מפעילה מצב מלא. |

```bash
fp events --session-id <session-id> --order asc --all
fp --json events --full --session-id <session-id> --all
```

#### Audit create options

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| אפשרות | תיאור |
| --- | --- |
| `--file <path>` | בסיס את ההגדרה ב-JSON, או השתמש ב-`-` עבור stdin. דגלים מפורשים דורסים ערכי קבצים. |
| `--description <text>` | ציין את שאלת הכישלון או המטרה. |
| `--enabled` / `--disabled` | התחל תזמון פעיל או כבוי. ברירת מחדל: מופעל. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. ברירת מחדל: `86400`. |
| `--schedule-anchor <timestamp>` | שלב UTC קבוע בצורה ISO 8601. ברירת מחדל: הבא 09:00 UTC. |
| `--window-mode since_last\|fixed` | המשך אחרי החלון שנותח לחלוטין אחרון או בדוק מחדש חלון גלגול. ברירת מחדל: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. ברירת מחדל: `604800`. |
| `--scope '<json>'` | סנן לפי `environments`, `agent_ids`, או שדות היקף נתמכים אחרים. |
| `--ignore-error-type <type>` | אל תכלול סוגי שגיאות; חזור או הפרד בפסיק. |
| `--llm` / `--no-llm` | הפעל או השבת ניתוח סוכן. ברירת מחדל: מופעל. |
| `--top-k <n>` | שמור `1`–`500` ממצאים. ברירת מחדל: `50`. |
| `--sensitivity low\|medium\|high` | הגדר רגישות דיווח. ברירת מחדל: `medium`. |
| `--channels '<json>'` | מערך ערוץ התראה. |
| `--text <brief>` | עד מקום, מקסימום 8,192 תווים. |
| `--text-file <path>` | קרא את ההעד מקובץ; ממלא מקום זה עם `--text`. |
| `--url <https-url>` | הוסף הפניית HTTPS ציבורית; חזור עד חמש פעמים. |

כלול הקשר במהלך יצירה כאשר הריצה הראשונה זקוקה להם. יצירה תחייבת את ההגדרה וההקשר ביחד לפני תחילת הריצה במוקדם.

<Note>
  `fp audits run` הוא אסינכרוני. סקור `fp audits runs NAME` עד שהריצה העדכנית תצליח או תכשל לפני קריאת ממצאיה.
</Note>

| `--base-url <url>` | השתמש בלוח שליטה עצמי-מתארח או שכן. |
| `--org <slug>` | בחר ארגון להוקדשה זו. |
| `--token <token>` | עקוף את אסימון הסשן המשתמש השמור. |
| `--api-key <key>` | הזדהה אוטומציה עם מפתח API; אף פעם לא נשמר. |
| `--timeout <seconds>` | פסק זמן HTTP; חייב להיות חיובי. ברירת מחדל: `30`. |
| `--quiet`, `-q` | דכא פלט מצב על stderr. |
| `--no-color` | השבת פלט צבעוני. |
| `--insecure` / `--secure` | השבת או שחזר אימות תעודת TLS. |
| `--version` | הדפס את הגרסה הלא מתולתלת ויצא. |
| `--help`, `-h` | הצג עזרה. |

`--api-key` מיועד לאוטומציה. התחברות, עקוף ארגון ופקודות עוזר דורשים סשן משתמש.

## Environment variables

| משתנה | שווה ערך או מטרה |
| --- | --- |
| `AGENTEYE_DASHBOARD_URL` | `--base-url` |
| `AGENTEYE_ORG` | `--org` |
| `AGENTEYE_CLI_TOKEN` | `--token` |
| `AGENTEYE_CLI_API_KEY` | `--api-key` |
| `AGENTEYE_CLI_JSON` | `--json` |
| `AGENTEYE_INSECURE` | `--insecure` |
| `AGENTEYE_HOME` | העתק את ספרית תצורת CLI הנוכחית. |
| `AGENTEYE_ANALYTICS_DISABLED` או `DO_NOT_TRACK` | השבת אנליטיקה CLI אנונימית. |
| `NO_COLOR` | השבת פלט צבעוני. |

דגלים מפורשים דורסים משתני סביבה, אשר דורסים תצורה שמורה. במצב מפתח API, בחר את הדייר בבירור עם `--org` או `AGENTEYE_ORG`.

<Warning>
  פקודות המוחקות, שולטות, דוכאות, פותרות או מחליפות תצורה מעודדות בברירת מחדל. השתמש ב-`--yes` רק לאחר אימות הארגון הפעיל והמטרה.
</Warning>
