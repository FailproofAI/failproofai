## משפחות אירועים

- התחלה, סיום, השהייה וחידוש של Agent
- בקשה ותגובה של מודל
- שימוש בכלי וביצוע
- Hook הופעל והסתיים
- המתנה אנושית, קלט, השהייה והפסקה
- שגיאות ברורות

כל אירוע נושא חותמת זמן, מזהה סשן, מזהה agent, סוג אירוע וסביבה. שדות ספציפיים לאירוע מכילים נתוני מודל, כלי, קורלציה, תוצאה, תוכן, משך זמן או שגיאה.

## בדוק חוזה אירוע

<Tabs>
  <Tab title="Dashboard">
    1. פתח את **Observe → Events**.
    2. הגדר חלון זמן קצר וסנן לפי סביבה, agent וסוג אירוע.
    3. בחר אירוע כדי לבדוק את השדות המנורמלים שלו ותשלום גולמי, ואז פתח את הסשן שלו כדי לראות את הקשר ההוצאה לפועל.
    4. אם משך זמן מזוגג חסר, בדוק שאירועי ההתחלה והסיום משתמשים באותו מזהה קורלציה.

    השתמש בזרם Events כדי לצמצם את הנתונים לריצת agent אחת ובדוק את שדות האירוע המנורמלים.

    ![זרם Events חי עם מסננים לסביבה, agent, סשן וסוג אירוע.](/images/dashboard/events-stream.png)

    לאחר מכן עקוב אחר האירוע לתוך הסשן שלו. העקבות מציגים מה קרה מיד לפני ואחרי זה, וזה הכרחי כאשר התשלום לבדו דו משמעי.

    ![שקע הסשן המקושר המשמש לבדוק את האירוע בהקשר הוצאה לפועל.](/images/dashboard/session-detail.png)

    השווה מזהי קורלציה וחותמות זמן בשתי התצוגות כאשר אירוע מזוגג או משך זמן חסר.
  </Tab>
  <Tab title="CLI">
    גלה ערכי מסנן תקפים, ואז אחזר עומסי אירוע מלאים לסשן אחד:

    ```bash
    fp list event_types
    fp list envs
    fp events --since 1h \
      --env production \
      --event-type tool_use,tool_result \
      --session-id <session-id> \
      --full
    ```

    השתמש ב-`fp --json events ... --fields ts,event_type,session_id,payload` לבדיקה קריאה-מכונה.
  </Tab>
</Tabs>

## שדות SDK שמורים

אל תשתמש ב-`timestamp`, `session_id`, `agent_id`, `type` או `environment` כשדות Python SDK מותאמים אישית. משכי אירוע מזוגגים כמו משך זמן של תוצאת כלי מחושבים על ידי ה-SDK ואינם יכולים להיות מסופקים ידנית.

## גבולות מקומיים

- מצב Failproof AI חי תחת `~/.failproofai` אלא אם צוין אחרת במפורש.
- `failproofai-sdk` משתמש ב-`AGENTEYE_HOME` להחלפת ספריית הבסיס המורשת שלו.
- ניתן להגדיר תוויות סביבה דרך קונפיגורציה SDK או `AGENTEYE_ENVIRONMENT`.
- אישורי Daemon מאוחסנים בנפרד מהגדרות שאינן סודיות.

השתמש בשמות סביבה יציבים ונמוכים בקרדינליות. פסיקים אינם נתמכים בתוויות סביבת daemon.

## שנה תווית סביבה

<Tabs>
  <Tab title="Dashboard">
    תוויות סביבה מוקצות על ידי ה-SDK או ה-Failproof daemon הפולט. לאחר שינוי אחד, פתח את **Observe → Sessions** והשתמש במסנן הסביבה כדי לאשר שסשנים חדשים נושאים את הערך החדש. סשנים קיימים שומרים על הסביבה המקורית שלהם.

  </Tab>
  <Tab title="CLI">
    עבור `failproofai-sdk`, קונפיגור את הסביבה בקוד או עם משתנה הסביבה המורשה שלו. הפעל מחדש קונפיגורציה daemon בעת שינוי הגדרות ברמת המכונה.

    ```bash
    export AGENTEYE_ENVIRONMENT=production-us-east
    failproofai config
    failproofai config --status
    fp sessions --since 1h --env production-us-east
    ```
  </Tab>
</Tabs>
