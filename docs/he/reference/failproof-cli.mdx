התקן עם `npm install -g failproofai`. הרץ `failproofai` ללא ארגומנטים כדי לפתוח את לוח הבקרה המקומי.

## פקודות ליבה

| פקודה | מה היא עושה |
| --- | --- |
| `failproofai config` | הגדרת agents, השירות בכל עת, והתחברות Cloud אופציונלית |
| `failproofai config --token <key>` | התקנה והתחברות ללא שאלות |
| `failproofai config --status` | הצג סטטוס התחברות, גרסת השירות, וסטטוס השהיה |
| `failproofai policies` | רשום מדיניות והאם הן פעילות |
| `failproofai policies add <name>` | הפוך מדיניות אחת לפעילה |
| `failproofai policies add <owner>/<repo>` | התקן חבילת מדיניות |
| `failproofai policies remove <name-or-pack>` | כבה מדיניות או הסר חבילה |
| `failproofai policies show <owner>/<repo>` | בדוק חבילה לפני התקנתה |
| `failproofai publish` | פרסם את המדיניות שלך כחבילה |
| `failproofai audit` | סרוק היסטוריית agent מקומית |
| `failproofai harness` | נהל מיקומי sessions נוספים |
| `failproofai flush` | שלח אירועים בתור כעת |
| `failproofai backfill` | קרא מחדש היסטוריית agent ישנה יותר |
| `failproofai update` | סיים שדרוג npm ועדכן את השירות |
| `failproofai uninstall` | הסר hooks והשירות |

`policy`, `pack`, ו-`p` מתקבלים כ-aliases עבור `policies`, אך התיעוד משתמש ב-`policies`.

## הגדרת מכונה

```bash
npm install -g failproofai
failproofai config
failproofai policies add FailproofAI/policies
failproofai config --status
```

ההתקנה בוחרת בחבילת מדיניות ללא. לפני שתוסיף חבילה, רק `block-failproofai-commands` פועל.

לעבור Cloud ללא השגחה אנושית:

```bash
export FAILPROOFAI_CLOUD_TOKEN="<key>"
failproofai config
```

כדי לשלוח החלטות ללא תמלילים, התחבר תחילה והגדר `collector.sessions` ל-`false` ב-`~/.failproofai/config.json`. דגל ההתקנה `--no-transcripts` הנוכחי מופרש אך לא מחיל את הגדרה זו.

השתמש ב-`--machine-label <name>` לאחר התחברות המכונה כדי לשנות את שמה. `--connect <url>` היא הפקודה צרה יותר ל-enrol-only עבור מכונה שכבר הוגדרה.

## מדיניות וחבילות

```bash
failproofai policies
failproofai policies add block-sudo
failproofai policies show owner/repo
failproofai policies add owner/repo --category git,database
failproofai policies remove owner/repo
```

כל דבר עם קו נטוי הוא מקור חבילה; כל דבר ללא אחד הוא שם מדיניות.

דגלי בחירת חבילות שימושיים:

| דגל | שימוש |
| --- | --- |
| `--policy a,b` | בחר מדיניות בשם |
| `--category x,y` | בחר קטגוריות |
| `--all` | בחר הכל |
| `--cli <agents...>` | הגבל ל-harnesses בשם |

השתמש ב-`failproofai policies -i -c <path>` כדי לטעון מדיניות מותאמת מנתיב כלשהו. קובצי כינוס בשם `*policies.{js,mjs,ts}` תחת `.failproofai/policies/` נטענים באופן אוטומטי.

## השהיית אכיפה

```bash
failproofai config --pause 10m
failproofai config --status
failproofai config --resume
```

השהיה חלה על session מקומי אחד תמיד תפוג. היא לא משהה מדיניות מנוהלת בענן או `block-failproofai-commands`.

## ביקורת והעברה

```bash
failproofai audit
failproofai audit --schedule 7 --email team@example.com
failproofai audit --status
failproofai flush --wait
failproofai backfill --since 30d --dry-run
```

`backfill` קורא `~/.failproofai/config.json`. הסר `--dry-run` לשליחת ההיסטוריה שוב.

## מיקומי sessions נוספים

```bash
failproofai harness list
failproofai harness add-path claude work=/srv/team/.claude/projects
failproofai harness remove-path claude work
```

תוויות מונעות sessions משתי בתים מועתקים מתמזגות תחת אותו agent ID נגזר.

Harnesses נתמכים הם `claude`, `codex`, `copilot`, `cursor`, `opencode`, `pi`, `hermes`, `openclaw`, `factory`, `devin`, `antigravity`, ו-`goose`. תמיכת scope שונה; ראה [Harnesses](/he/reference/harnesses).

## משתני סביבה שימושיים

| משתנה | שימוש |
| --- | --- |
| `FAILPROOFAI_CLOUD_TOKEN` | מפתח מכונת Cloud |
| `FAILPROOFAI_CLOUD_URL` | עקוף את כתובת ה-Cloud |
| `FAILPROOFAI_HOME` | הזז את ספריית המצב המקומי |
| `FAILPROOFAI_NO_DOWNLOAD=1` | סרב להורדות חבילה ושירות |
| `FAILPROOFAI_DAEMON_BASE_URL` | השתמש במראה בינארי של שירות |
| `FAILPROOFAI_PACK_BASE_URL` | השתמש במראה חבילה |
| `FAILPROOFAI_NO_FIRST_RUN=1` | השבת הודעות הרצה ראשונה |
| `FAILPROOFAI_TELEMETRY_DISABLED=1` | השבת טלמטריה CLI אנונימית |
| `FAILPROOFAI_<HARNESS>_EXTRA_PATHS` | החלף נתיבים נוספים ל-harness אחד |
| `NO_COLOR` | השבת צבע טרמינל |

## הסרה או שדרוג

```bash
npm install -g failproofai@latest
failproofai update
```

לפני הסרת החבילה:

```bash
failproofai uninstall --dry-run
failproofai uninstall --yes
npm rm -g failproofai
```

<Warning>
  הרץ `failproofai uninstall` לפני הסרת חבילת npm. npm לא מסיר hooks מותקנים או השירות בכל עת.
</Warning>

הרץ `failproofai help <command>` עבור האפשרויות המלאות בגרסה המותקנת שלך.
