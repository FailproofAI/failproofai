נתון הוא כל מה שהסוכן שלך בעצם פועל בתוכו. Failproof AI תומך בשנים עשר מהם, בשתי קטגוריות:

- **CLI-ים לקידוד** (10) — Claude Code, Codex, GitHub Copilot CLI, Cursor, OpenCode, Pi, Factory Droid, Devin CLI, Antigravity CLI, Goose
- **שערים לצ'אט ועוזרים** (2) — Hermes (Slack, Telegram, cron), OpenClaw (עוזר מאורח עצמי)

אותה מדיניות וגם אותו היסטוריית הפעלה זהים באיזה נתון שהסוכן פועל בתוכו. שכבת מתאם אחת ממפה את שמות האירועים המקוריים של כל נתון, שמות הכלים וממצעי הקלט של כלים למעל 29 אירועים קנוניים לפני שמדיניות כלשהי פועלת.

סוכן שפועל ב**אף אחד** מהשנים עשר מותקן ישירות עם [Python SDK](/he/reference/python-sdk). זו חוזה אחרת, וראוי לציין זאת בבהירות: ה-SDK מספק עקיבה, הפעלות, הערכות וביקורות — **הוא אינו אוכף מדיניות בעצמו.** חסימת פעולה לא בטוחה לפני שהיא מתבצעת דורשת hook אכיפה בגבול הכלים של הזמן ריצה שלך; [צור איתנו קשר](mailto:support@befailproof.ai) ואנו נממפה אותו.

| נתון | ההיקף של hook שנתמך |
| --- | --- |
| Claude Code | משתמש, פרויקט, מקומי |
| Codex, GitHub Copilot CLI, Cursor, OpenCode, Pi | משתמש, פרויקט |
| Factory Droid, Devin CLI, Antigravity CLI, Goose | משתמש, פרויקט |
| Hermes, OpenClaw | משתמש |

כל אינטגרציה מנרמלת את שמות אירועי ה-hook המקוריים שלה, שמות כלים וממצעי קלט של כלים לפני שמדיניות פועלת. מדיניות יכולה להשפיע רק על אירועים שהנתון חשוף; בדוק התנהגות סוף-תור והוראה בנתון וגרסה המדויקים שאתה משתמש בהם.

## יכולת אכיפה

"חסום" פירושו שהגזר של המתאם הנוכחי נצרך על ידי הנתון המנוקד. חסימה לאחר כלי עשויה להחליף את התוצאה המוצגת למודל אך לא יכולה לבטל תופעת צד של כלי שכבר התרחשה.

| נתון | אירועי חסימה מאומתים | קביעות של תצפית בלבד או ללא חסימה |
| --- | --- | --- |
| Claude Code | `PreToolUse`, `UserPromptSubmit`, `PermissionRequest`, `Stop`, `SubagentStop`, `PreCompact` ואירועי משימה/תצורה רבים | `PostToolUse`, מחזור חיים של הפעלה, הודעות ואירועי לאחר כישלון הן תצפייתיות. |
| Codex | `PreToolUse`, `PermissionRequest`, `UserPromptSubmit`, `Stop`, `SubagentStop`, `PostToolUse` | חסימה לאחר כלי מחליפה את התוצאה אחרי ביצוע; אירועי התחלת הפעלה וקומפקטיות הם תצפייתיות במתאם הנוכחי. |
| GitHub Copilot CLI | `PreToolUse`, `UserPromptSubmit`, `PermissionRequest`, `Stop`, `SubagentStop`, `PostToolUse` | חסימה לאחר כלי מחליפה את התוצאה אחרי ביצוע; אירועי הפעלה והודעה הם תצפייתיות. |
| Cursor | `PreToolUse`, `UserPromptSubmit`, `Stop` | `PostToolUse` ואירועי הפעלה הם תצפייתיות. |
| OpenCode | `PreToolUse` | אירועי לאחר כלי ומחזור חיים הם תצפייתיות; טיפול עצירה נוכחי הוא הדרכה לתור מאוחר יותר ולא שער מאומת. |
| Pi | `PreToolUse`, `UserPromptSubmit` | אירועי לאחר כלי ומחזור חיים הם תצפייתיות; הדרכת עצירה חלה על תור מאוחר יותר. |
| Hermes | `PreToolUse` | אחרי כלי, הפעלה וגזרי עצירה תת-סוכן אינם שערים. |
| OpenClaw | `PreToolUse`, `UserPromptSubmit`, `Stop` | אחרי כלי, הפעלה, עצירה תת-סוכן ואירועי דחיסה הם תצפייתיים. |
| Factory Droid | `PreToolUse`, `UserPromptSubmit`, `Stop`, `PreCompact` | גזרי לאחר כלי ועצירה תת-סוכן הם תצפייתיים. |
| Devin CLI | `PreToolUse`, `UserPromptSubmit`, `Stop`, `PermissionRequest` מותנה | hook הרשאה אינו פועל בכל מצב הרשאה; אירועי לאחר כלי והפעלה הם תצפייתיים. |
| Antigravity CLI | `PreToolUse`, `Stop` | גזרי הנחת משתמש ולאחר כלי הם תצפייתיים; הוראות הנחה עדיין יכולות להיות מוזרקות. |
| Goose | `PreToolUse` | אירועי הנחת משתמש, לאחר כלי והפעלה הם תצפייתיים. hook עצירה חסימה מקומי קיים במעלה הזרם אך לא מותקן על ידי המתאם הנוכחי. |

יכולות תלויות בגרסה. בדוק מחדש אחרי שדרוג סוכן CLI, במיוחד כשמדיניות מסתמכת על התנהגות של הנחה, עצירה, הרשאה או לאחר כלי ולא על שער לפני כלי נפוץ.

## התקן capture ו-policy hooks

<Tabs>
  <Tab title=" Dashboard">
    1. פתח **Administration → Keys** וצור מפתח עם `events:add` ו-`policies:pull`, נקרא למכונה או לסביבה.
    2. במכונת היעד, חבר את ה-CLI המקומי עם המפתח המוצג והתקן את hook-ים של הנתון.
    3. התחל הפעלה חדשה של סוכן, ואז אשר את hook שלה ואירועי הפעלה תחת **Observe → Events**.
    4. פתח **Observe → policy** עבור אותה חלון זמן ואשר שהחלטת מדיניות מיוחסת למכונה.

    החיבור מתחיל עם מפתח של מכונה. אשר שהוא כולל הן הרשאות הזנה והן הרשאות הספקת מדיניות לפני שתעתיק את הסוד שלו.

    ![מגירת המפתח החדשה של API המשמשת להעניית הרשאות הזנה ואספקת מדיניות.](/images/dashboard/key-create.png)

    לאחר התקנת hook-ים, זרם Events צריך להציג אירועים חדשים מהמכונה והסביבה שחיברת.

    ![זרם Events חי המשמש לאישור שנתון שהתקנת זה מדווח.](/images/dashboard/events-stream.png)

    לבסוף, אמת שהחלטות מדיניות מיוחסות לאותה מכונה. זה מאשר שהנתון מדווח פעילות מדיניות כמו גם אירועי עקיבה.

    ![דף Policy המשמש לאימות החלטות מדיניות מנתון שחובר לאחרונה.](/images/dashboard/policy-observe.png)
  </Tab>
  <Tab title="CLI">
    התקן hook-ים עבור כל נתון שגילה:

    ```bash
    failproofai config \
      --connect https://app.befailproof.ai \
      --token <machine-key>
    failproofai policies --install
    ```

    או היעד נתוני בשם וההיקף של תצורה:

    ```bash
    failproofai policies --install \
      --cli claude codex cursor \
      --scope user
    ```

    היקף פרויקט שומר על תצורת hook עם מחסן. היקף משתמש מכסה עבודה על פני מחסנים. Claude Code גם תומך בהיקף מקומי; התמיכה משתנה לפי נתון וה-CLI דוחה שילובים לא נתמכים.

    אמת את המכונה ואירועיה:

    ```bash
    failproofai config --status
    failproofai flush --wait
    fp events --since 1h --event-type hook_triggered,hook_completed
    ```
  </Tab>
</Tabs>

## הוסף נתיב הפעלה שאינו ברירת מחדל

<Tabs>
  <Tab title="Dashboard">
    נתיבים נוספים רשומים על המכונה, לא בענן. לאחר הוספת אחד, פתח **Observe → Sessions**, סנן לסביבת המכונה ואשר שהפעלות מהנתיב החדש מופיעות. פתח הפעלה ובדוק את הסוכן, הנתון וחותמות הזמן של אירועים לפני שתסתמך על כך בביקורת.

    ![רשימת Sessions מסוננת לסביבה המקבלת נתונים מנתיב הלכידה הנוסף.](/images/dashboard/sessions-list.png)
  </Tab>
  <Tab title="CLI">
    הוסף נתיב עם תווית אופציונלית, ואז בדוק את הנתיבים המוגדרים:

    ```bash
    failproofai harness add-path claude checkout=/srv/checkout/.claude
    failproofai harness list claude
    failproofai backfill --since 7d --dry-run
    failproofai backfill --since 7d
    ```

    הסר נתיב עם `failproofai harness remove-path claude checkout`.
  </Tab>
</Tabs>

<Tip>
  הרץ הפעלה חדשה אחת לאחר ההתקנה. אמת גם את זרם האירוע החי וגם החלטת מדיניות בפועל לפני הרחבת ההצגה.
</Tip>
