עמוד זה מתאר את צורות השאלות וכללי הדירוג מאחורי [Jev evaluations](/he/evaluations/jev). חלק מהשאלות דורשות מודל שיוכל *לקרוא* את השיחה, אך לא בהכרח *לכתוב* עליה. "האם הלקוח הביע דחיפות?" יש שתי תשובות. "כמה התסכלו?" יש קומץ, בסדר מסוים. אתה מכיר כל תשובה אפילו לפני ששואל.

**classifier evaluation** קיים בדיוק לכך. אתה כותב את השאלה והתשובות שהיא עלולה לתת, ומודל קטן שבנוי לסיווג מחזיר מספר מכוּיל — אף פעם לא טקסט חופשי.

<Note>
כמו שופט, classifier evaluation עולה קריאת מודל אחת לכל סשן. בשונה משופט, זה מודל קטן וחד-תכליתי ולא כללי, כך שהוא מהיר וזול יותר — אך הוא לעולם לא יסביר את עצמו. אם אתה צריך את ההנמקה, השתמש ב-[judge](/he/evaluations/judge).
</Note>

## איזה אחד אני רוצה?

| שאלה | השתמש ב |
| --- | --- |
| כמה קריאות כלים היו? | code |
| האם הסשן היה פחות מ-30 שניות? | code |
| האם הלקוח הביע דחיפות? | **classifier** |
| איזה צוות צריך להתמודד עם זה: billing, technical, או sales? | **classifier** |
| כמה התסכל הלקוח? | **classifier** |
| האם התשובה באמת הייתה נכונה? | **judge** |
| האם זה פעל לפי מדיניות ההסלמה שלנו, ולמה אתה חושב כך? | **judge** |

כלל האצבע: **ניתן לספירה → code, תשובות שאתה יכול לרשום → classifier, דורש הסבר → judge.**

אתה לא צריך להחליט מראש. תאר מה אתה רוצה למדוד והעוזר בוחר, אומר לך איזה בחר ולמה, ואתה יכול להחליף.

## שני סוגי השאלות

### `noul` — האם זה נכון?

שתי תשובות, ואתה מתאר את שתיהן. התוצאה היא ההסתברות שתיאור "נכון" מתאים:

```json
{
  "instructions": "Did the assistant promise a refund without first checking the refund policy?",
  "criteria": {
    "true":  "A refund was promised or issued with no prior policy check or approval",
    "false": "No refund was promised, or every refund followed a policy check"
  }
}
```

תאר את שני הצדדים. "לא הביעו דחיפות" היא תשובה אמיתית וההצהרה עושה את השנייה חדה יותר.

### `score` — כמה מזה?

רובריקה מסודרת, **הגרוע ביותר ראשון**. התוצאה היא היכן הסשן נוחת בה, משוּנה לקנה מידה 0–1:

```json
{
  "instructions": "How frustrated is the customer?",
  "criteria": ["Calm", "Frustrated", "Very angry"]
}
```

**רובריקה דורשת שלוש עד חמש רמות, וכולן חייבות להיות שונות.** שני הגבולות נמדדים, לא סגנוניים:

- **שתי רמות** קורסות למה `noul` כבר עושה יותר טוב, ו**יותר מחמש** גורמות למודל להתנדנד לעבר האמצע במקום להתחייב. אותה שאלה על אותו סשן קיבלה 0.00 עם שתי רמות, 0.01 עם שלוש, ו-0.55 עם עשר.
- **רמות חוזרות** מפצלות את התשובה באופן שרירותי ביניהן. סשן שהיה ללא ספק כועס קיבל 1.00 מול `["Calm", "Frustrated", "Very angry"]` ו-0.66 מול `["Angry", "Angry", "Angry"]` — מספר טוב-צורתי שאין לו משמעות.

קטגוריות ללא סדר — "billing, technical, or sales" — אינן רובריקה. שאל אותן כ-`noul` לכל קטגוריה, או השתמש בשופט.

## קריאת התוצאות

classifier מייצר **score** מ-0 עד 1, בדיוק כמו שופט, כך שהוא תרשימים, מסנן, והפעלות התריעות באותו אופן. שתי הבדלים כדאי לדעת:

- **אין הנמקה.** השדה ריק, בכוונה. המודל הזה לא מסביר את עצמו, והמצאת הסבר תהיה זיוף ולא תכונה.
- **אי-ודאות מתויגת.** שאלת `score` מדווחת על הביטחון שלה, ותוצאה שהמודל היה לא בטוח בה מתוייגת `low_confidence` — אז "איזה מהם צריך אדם לבדוק" הוא מסנן ולא ניחוש. שאלת `noul` לא דווחת על ביטחון, כך שהיא לעולם לא מתויגת.

סשנים ארוכים מאוד נקראים בקטעים ומשולבים. כאשר סשן ארוך מדי לקריאה במלואו, התוצאה אומרת כמה סיבובים הושמטו — אתה לעולם לא תראה שיפוט שנעשה על חלק מסשן המוצג כאחד שנעשה על כולו.

## מגבלות

- **שלוש עד חמש רמות רובריקה, כולן ברורות.** ראה לעיל; שני הגבולות משתולבים בעת הכתיבה.
- **שאלה אחת לכל evaluation.** שאל שני דברים ותקבל שתי evaluations, שזה גם מה שאתה רוצה בתרשים.
- **עריכת השאלה מפרסמת גרסה חדשה.** ניקוד ישן וחדש אינו ניתן להשוואה, כך שהם מופרדים ולא מעורבבים לשורה אחת.
- **classifier תמיד מייצר score**, לעולם לא מדד או טענה.
- **אין הנמקה**, כמו לעיל. אם מספר יגרום למישהו לשאול "למה?", כתוב שופט במקום זה.

## בדיקה והמלאה חזרה

בשונה משופט, classifier evaluation **יכול** להיבדק לפני שאתה משם אותו בפועל — [בדוק אותו](/he/evaluations/test) מול סשנים אמיתיים באותו אופן שהיית בוחן code evaluation, וקרא את הניקוד לפני שדבר מה הולך לחי.

ניתן גם [להמלא בחזרה](/he/evaluations/deploy#score-sessions-you-already-have) על סשנים שכבר יש לך. זה עולה קריאת מודל לכל סשן, אז הגדר את החלון בכוונה במקום להשמיט הכל.
