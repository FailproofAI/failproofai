`failproofai otel` מגדיר דיווחי OpenTelemetry אופציונליים ל-FailproofAI Cloud. תחילה חבר את המחשב שלך עם `failproofai config` והבקש ממנהל ארגון להפעיל את **Settings → OpenTelemetry**.

ההגדרה האינטראקטיבית שואלת על OpenTelemetry לאחר שדה מפתח ה-Cloud ובחירת הסוכן. השלב האופציונלי מוגדר כברירת מחדל ל-No. בחר Yes כדי לבחור סוכני OTEL; אותו קוד הפעלה פועל לאחר שההתחברות נכתבת. Esc לפני שההגדרה לא תחיל שום שינויים. הגדרה ללא השגחה, מפתח סופק, מצב קוד פתוח, והשמרת חיבור שמור לא יבחרו בך.

## הפעלת סוכן

```bash
failproofai otel enable claude
failproofai otel enable codex --local
failproofai otel enable codex --no-content
failproofai otel enable copilot
failproofai otel enable all --yes
```

הסוכנים הנתמכים הם `claude`, `codex`, ו-`copilot` (VS Code). הגדרת Copilot דורשת קובץ בר-הפעלה של VS Code או הרחבת Copilot מותקנת. ספרייה של הגדרות שנותרה לבדה אינה מספיקה; ההגדרה דולגת על Copilot כאשר אף אחד מהם לא נמצא.

`--local` שולח למשחזר המקומי במקום ישירות ל-Cloud. Copilot משתמש במשחזר באופן אוטומטי מכיוון שההגדרות שלו לא יכולות לאחסן את כותרת ההזדהות.

המשחזר מאזין רק על המחשב שלך. ה-daemon של FailproofAI שהוגדר לך יודע על השינוי תוך שניות; אתה לא צריך להפעיל אותו מחדש. אם יישום אחר בבעלות על יציאת המשחזר, דוח הסטטוס אומר שהוא כבוי וה-daemon ממשיך לפעול.

<Warning>
לכידת טקסט פעילה כברירת מחדל. הוסף `--no-content` כדי להשמיט הנמקות ופרטי כלי. גרסאות סוכן יכולות לחשוף בקרות תוכן שונות; בדוק מה הסוכן שלך מייצא לפני שתשתמש בו עם נתונים רגישים.
</Warning>

Codex מייצא רק יומנים של שיחות, לא עקבות או מדדי זמן ריצה פנימיים. `log_user_prompt = false` מפורש בתצורת Codex שלך נשאר כבוי; הפעלה מדפיסה הערה כאשר היא משמרת את הבחירה הזו.

### בחר בנתיב דיווח אחד

אם דיווח תמלול פעיל עבור סוכן, ההגדרה שואלת:

> failproofai כבר שולח את פגישות Claude Code ל-Cloud. לשלוח אותן עם OTEL במקום? העלאת תמלול עבור Claude Code מפסיקה.

ברירת המחדל היא No. `--yes` מקבל את ההחלפה ללא הנמקה. סוכנים אחרים והטלת מדיניות אינם מושפעים.

הגדרת Codex מחכה ל-daemon כדי לאשר את שינוי האספן לפני כתיבת הגדרות היצואים שלו. אם האישור עולה על הזמן, ההגדרה מזהירה אותך להמתין לפני הפעלת Codex.

Config v2 שומר על רשימת ההתחקות שנזכרה ב-`agents.selected` (והיסטוריית גילוי ב-`agents.seen`). ההעדפה לתמלול לכל סוכן נשארת ב-`collector.agents.<agent>.sessions`, בעלות OTEL ב-`otel.agents`, והגדרות משחזר ב-`collector.otlp.enabled` / `collector.otlp.port`. מפתחות נפרדים אלה שומרים על תצורות OTEL ישנות כקריאות: ההגדרה יכולה לשנות את רשימת ההתחקות ללא אובדן העדפת ההובלה או המצב הדרוש לשחזור הגדרות הסוכן שלך.

## בדוק הגדרה

```bash
failproofai otel status
```

הסטטוס מציג כל סוכן, האם הגדרותיו מנוהלות על ידי FailproofAI, היעד שלו, קלט הספיגה של הארגון, מצב המשחזר, ותוצאת העלאת המשחזר האחרונה.

`unknown` עבור מתג הארגון אומר שהשרת לא סיפק אותו או לא יכול הגיע. זה לא שגיאה ולא מונע תצורה בגרסה ישנה יותר של Cloud.

אם Cloud עדיין לא תומך ב-OTEL, המשחזר שומר על ייצוא שנדחה במקום להשליך אותם. אם הספיגה של הארגון כבויה, `enable` לא כותב שום דבר ויוצא עם שגיאה; בקש מנהל להפעיל אותה ראשון.

## הדפס תצורה עבור יישום

```bash
failproofai otel env --service my-agent
failproofai otel env --service my-agent --local
```

הפלט הוא בלוק סביבה של shell עבור יצואן OTLP/HTTP. פלט Cloud מגדיר את `OTEL_EXPORTER_OTLP_ENDPOINT` לבסיס OTLP של Cloud, `https://<cloud>/otel`, ויצואן מהסרט `/v1/<signal>`; משתנה לכל אות כגון `OTEL_EXPORTER_OTLP_LOGS_ENDPOINT` זקוק ל-`https://<cloud>/otel/v1/logs` המלא. פלט מקומי מצביע על המשחזר, `http://127.0.0.1:<port>`. פלט Cloud כולל את מפתח ה-API שהוגדר; התייחס אליו כסוד. פלט מקומי משמיט את המפתח. כדי להשתמש בפלט מקומי, תחילה הפעל סוכן מקומי כדי שהמשחזר יפעל.

## החזר הגדרות קודמות

```bash
failproofai otel disable claude
failproofai otel disable all
```

השיבוי משחזר מחזיר רק את ההגדרות ש-FailproofAI כתב, שומר על שינויים לא קשורים, ומחזיר את בחירת דיווח התמלול הקודמת של כל סוכן. כאשר סוכן המקום המנוהל האחרון הוא משיביות, המשחזר מפסיק לקבל ייצוא.

עבור Codex, השיבוי גם רושם `collector.agents.codex.sessions_resume_after` (אפוך אלפיות השנייה). בתים פרודול קיימים מטופלים כמועברים כך שפגישות שנלכדו עם OTEL לא יעלו שוב; הנספחות מאוחרות עדיין זורמות דרך דיווח תמלול.

כל פקודה תומכת ב-`--help`. ראה [OpenTelemetry ב-Cloud](/he/agenteye/opentelemetry) לדוגמאות יישום וסוכן קידוד.
