`failproofai otel` מגדיר דיווח OpenTelemetry אופציונלי ל-FailproofAI Cloud. תחילה חבר את המכונה שלך עם `failproofai config` ובקש מ-admin של הארגון להפעיל **Settings → OpenTelemetry**.

ההגדרה האינטראקטיבית שואלת על OpenTelemetry לאחר שדה המפתח של Cloud ובוחר הסוכן. השלב האופציונלי מתחדש כברירת מחדל ל-No. בחר Yes לבחירת סוכני OTEL; אותו קוד הפעלה פועל לאחר שהחיבור נכתב. Esc לפני ההגדרה לא מחיל שום שינויים. הגדרה ללא השגחה, מפתח מסופק, מצב קוד פתוח, והשמירה על חיבור שמור לא בוחרים אותך.

## הפעלת סוכן

```bash
failproofai otel enable claude
failproofai otel enable codex --local
failproofai otel enable codex --no-content
failproofai otel enable copilot
failproofai otel enable all --yes
```

הסוכנים הנתמכים הם `claude`, `codex`, ו-`copilot` (VS Code). הגדרת Copilot דורשת קובץ הפעלה של VS Code או הרחבת Copilot מותקנת. ספריית הגדרות שנשארה לבדה אינה מספיקה; ההגדרה דילגה על Copilot כאשר אף אחד מהם לא נמצא.

`--local` שולח ליחידת ההעברה המקומית במקום ישירות ל-Cloud. Copilot משתמש ביחידת ההעברה באופן אוטומטי מכיוון שההגדרות שלו לא יכולות לאחסן את כותרת ההזדהות.

יחידת ההעברה מאזינה רק במכונה שלך. ה-daemon FailproofAI המוגדר שלך יוצא את השינוי תוך שניות; אינך צריך להפעיל אותו מחדש. אם יישום אחר הוא בעלים של יציאת יחידת ההעברה, דיווחי הסטטוס זה כ-off וה-daemon ממשיך לפעול.

<Warning>
לכידת הטקסט פועלת כברירת מחדל. הוסף `--no-content` כדי להשמיט הנחות ופרטי כלים. גרסאות סוכנים יכולות לחשוף בקרות תוכן שונות; בדוק מה הסוכן שלך ייצא לפני השימוש בו עם נתונים רגישים.
</Warning>

Codex ייצא רישומי שיחה בלבד, לא זיכרונות זמן ריצה פנימיים או מדדים. `log_user_prompt = false` מפורש בתצורת Codex שלך נשאר כבוי; הפעלה מדפיסה הערה כאשר היא משמרת בחירה זו.

### בחר נתיב דיווח אחד

אם דיווח תמלול פועל עבור סוכן, ההגדרה שואלת:

> failproofai כבר שולח Claude Code ישיבות ל-Cloud. שלח אותן עם OTEL במקום? העלאת תמלול ל-Claude Code עוצרת.

ברירת המחדל היא No. `--yes` קובל את המתג ללא הנחיה. סוכנים אחרים והטלת מדיניות אינם מושפעים.

הגדרת Codex מחכה ל-daemon לאשר את שינוי המאסף לפני כתיבת הגדרות הייצואר שלו. אם אימות הזמן פג, ההגדרה מזהירה אותך לחכות לפני התחלת Codex.

Config v2 שומר את רשימת ההעקבה הנזכרה ב-`agents.selected` (ורשומת זיהוי בְ-`agents.seen`). ההעדפה לתמלול לפי סוכן נשארת ב-`collector.agents.<agent>.sessions`, בעלות OTEL בְ-`otel.agents`, והגדרות יחידת ההעברה בְ-`collector.otlp.enabled` / `collector.otlp.port`. המפתחות המופרדים הללו מונעים תצורות OTEL ישנות קריאות: ההגדרה יכולה לשנות את רשימת ההעקבה ללא אובדן העדפת התחבורה או המצב הנדרש לשחזור הגדרות הסוכן שלך.

## בדוק הגדרה

```bash
failproofai otel status
```

הסטטוס מראה כל סוכן, האם ההגדרות שלו מנוהלות על ידי FailproofAI, היעד שלו, מתג הספיגה של הארגון, מצב יחידת ההעברה, ותוצאת ההעלאה האחרונה של יחידת ההעברה.

`unknown` עבור מתג הארגון פירושו שהשרת לא סיפק אותו או לא יכול להגיע אליו. זה לא שגיאה ואינו מונע הגדרה בגרסת Cloud ישנה יותר.

אם Cloud עדיין לא תומך ב-OTEL, יחידת ההעברה שומרת ייצואים דחויים במקום להשליכם. אם ספיגת הארגון כבויה, `enable` לא כותב כלום ויוצא עם שגיאה; בקש מ-admin להפעיל אותה תחילה.

## הדפס תצורה עבור יישום

```bash
failproofai otel env --service my-agent
failproofai otel env --service my-agent --local
```

הפלט הוא בלוק סביבה של shell עבור מייצואר OTLP/HTTP. פלט Cloud מגדיר `OTEL_EXPORTER_OTLP_ENDPOINT` לבסיס OTLP של Cloud, `https://<cloud>/otel`, והמייצואר מוסיף `/v1/<signal>`; משתנה לפי אות כגון `OTEL_EXPORTER_OTLP_LOGS_ENDPOINT` צריך את ה-`https://<cloud>/otel/v1/logs` המלא. פלט מקומי מצביע על יחידת ההעברה, `http://127.0.0.1:<port>`. פלט Cloud כולל את מפתח ה-API המוגדר; התייחס אליו כלסוד. פלט מקומי משמיט את המפתח. כדי להשתמש בפלט מקומי, תחילה הפעל סוכן מקומי כדי שיחידת ההעברה תפעל.

## החזר הגדרות קודמות

```bash
failproofai otel disable claude
failproofai otel disable all
```

Disable משחזר רק את ההגדרות ש-FailproofAI כתב, שומר שינויים לא קשורים, והחזר כל בחירה קודמת של דיווח תמלול של סוכן. כאשר האחרון מ-local agents המנוהל מבוטל, יחידת ההעברה מפסיקה להקבל ייצואים.

עבור Codex, disable גם רושם `collector.agents.codex.sessions_resume_after` (אפוך אלפיות שניות). בתים קיימים של rollout מטופלים כמוסרים כך שישיבות שתויה עם OTEL לא יעלו שוב; תוספות מאוחרות עדיין זורמות דרך דיווח תמלול.

כל פקודה תומכת ב-`--help`. ראה [OpenTelemetry ב-Cloud](/he/agenteye/opentelemetry) לדוגמאות יישום וסוכן קידוד.
