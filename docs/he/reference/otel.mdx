`failproofai otel` מגדיר דיווח OpenTelemetry אופציונלי ל-FailproofAI Cloud. ראשית, חבר את המכונה שלך עם `failproofai config`. תשליך OpenTelemetry תמיד פועל בענן, כך שאין מתג ארגוני להפעלה.

ההגדרה האינטראקטיבית שואלת לגבי OpenTelemetry לאחר שדה מפתח הענן ובורר הסוכן. השלב האופציונלי מתאים כברירת מחדל ל-No. בחר Yes כדי לבחור סוכני OTEL; אותו קוד הפעלה פועל לאחר שהחיבור נכתב. Esc לפני ההגדרה לא מחיל שינויים. הגדרה ללא התערבות, מפתח מסופק, מצב קוד פתוח, ושמירת חיבור שנשמר אינם מצמידים אותך.

## הפעלת סוכן

```bash
failproofai otel enable claude
failproofai otel enable codex --local
failproofai otel enable codex --no-content
failproofai otel enable copilot
failproofai otel enable all --yes
```

הסוכנים הנתמכים הם `claude`, `codex`, ו-`copilot` (VS Code). הגדרת Copilot דורשת הפעלה של VS Code או הרחבת Copilot מותקנת. ספרייה הגדרות שנותרה בלבד אינה מספיקה; ההגדרה דולגת על Copilot כאשר לא נמצא אף אחד מהם.

`--local` שולח להעברה מקומית במקום ישירות לענן. Copilot משתמש בהעברה באופן אוטומטי מכיוון שההגדרות שלו אינן יכולות לאחסן את כותרת ההזדהות.

ההעברה מאזינה רק על המכונה שלך. ה-daemon של FailproofAI המוגדר שלך אוגד את השינוי תוך שניות; אתה לא צריך להפעיל אותו מחדש. אם יישום אחר בעל היציאה של ההעברה, דיווחי הסטטוס עליו כמכובה וה-daemon ממשיך לפעול.

<Warning>
לכידת טקסט מופעלת כברירת מחדל. הוסף `--no-content` כדי להשמיט הנחיות ופרטי כלים. גרסאות סוכן יכולות לחשוף בקרות תוכן שונות; בדוק מה הסוכן שלך מייצא לפני השימוש בו עם נתונים רגישים.
</Warning>

Codex מייצא רישומי שיחות בלבד, לא זיכרונות זמן ריצה פנימיים או מדדים. `log_user_prompt = false` מפורש בתצורת Codex שלך נשאר כבוי; הפעלה מדפיסה הערה כאשר היא שומרת על אפשרות זו.

### בחר נתיב דיווח אחד

אם דיווח תמלול פועל לסוכן, ההגדרה שואלת:

> failproofai כבר שולח Claude Code סשנים לענן. לשלוח אותם עם OTEL במקום? העלאת תמלול עבור Claude Code נעצרת.

ברירת המחדל היא No. `--yes` מקבל את המתג ללא הנחיה. סוכנים אחרים והטלת מדיניות אינם מושפעים.

הגדרת Codex חוכה לדמון כדי לאשר את השינוי של האוסף לפני כתיבת הגדרות המייצא שלו. אם האישור יפה תשובה, ההגדרה מזהירה אותך להמתין לפני תחילת Codex.

Config v2 שומר על רשימת העקיבוי הנזכרת ב-`agents.selected` (והיסטוריית גילוי ב-`agents.seen`). ההעדפה של תמלול לכל סוכן נשארת ב-`collector.agents.<agent>.sessions`, בעלות OTEL ב-`otel.agents`, והגדרות העברה ב-`collector.otlp.enabled` / `collector.otlp.port`. מפתחות נפרדים אלה משמרים קונפיגורציות OTEL ישנות קריאות: ההגדרה יכולה לשנות את רשימת העקיבוי מבלי לאבד את העדפת התחבורה או את המצב הנחוץ כדי להחזיר את הגדרות הסוכן שלך.

## בדיקת הגדרה

```bash
failproofai otel status
```

הסטטוס מציג כל סוכן, האם הגדרותיו מנוהלות על ידי FailproofAI, היעד שלו, מתג הספיגה של הארגון, מצב ההעברה, ותוצאת ההעלאה האחרונה של ההעברה.

`unknown` עבור מתג הארגון פירושו שהשרת לא סיפק אותו או לא היה ניתן להגיע אליו. זה לא שגיאה ואינו מונע תצורה בגרסת ענן ישנה יותר.

אם ענן עדיין לא תומך ב-OTEL, ההעברה שומרת על ייצוא מדורג במקום להיפטר מהם. אם גרסה ישנה יותר של Cloud מדווחת על ספיגה ארגונית כמכובה, `enable` לא כותב שום דבר ויוצא עם שגיאה.

## הדפס קונפיגורציה עבור יישום

```bash
failproofai otel env --service my-agent
failproofai otel env --service my-agent --local
```

הפלט הוא בלוק סביבה של shell עבור מייצא OTLP/HTTP. פלט ענן מגדיר את `OTEL_EXPORTER_OTLP_ENDPOINT` ל-OTLP base של Cloud, `https://<cloud>/otel`, והמייצא מוסיף `/v1/<signal>`; משתנה לכל סוגנל כגון `OTEL_EXPORTER_OTLP_LOGS_ENDPOINT` זקוק ל-`https://<cloud>/otel/v1/logs` המלא. הפלט המקומי מצביע על ההעברה, `http://127.0.0.1:<port>`. פלט ענן כולל את מפתח ה-API המוגדר; התייחס אליו כסוד. הפלט המקומי משמיט את המפתח. כדי להשתמש בפלט מקומי, תחילה הפעל סוכן מקומי כך שההעברה פועלת.

## החזרת הגדרות קודמות

```bash
failproofai otel disable claude
failproofai otel disable all
```

Disable משחזר רק את ההגדרות שכתب FailproofAI, שומר על שינויים שאינם קשורים, והחזרות בחירת דיווח תמלול קודמת של כל סוכן. כאשר האחרון מסוכן מקומי המנוהל מכובה, ההעברה מפסיקה לקבל ייצוא.

עבור Codex, disable גם תיעוד `collector.agents.codex.sessions_resume_after` (epoch milliseconds). בתים קיימים של השחרור מטופלים כמועברים כך שסשנים שתפסו עם OTEL אינם מועלים שוב; הוספות מאוחרות עדיין זורמות דרך דיווח תמלול.

כל הפקודה תומכת `--help`. ראה [OpenTelemetry בענן](/he/agenteye/opentelemetry) לדוגמאות יישום וסוכן קידוד.
