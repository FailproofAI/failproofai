`failproofai otel` מגדיר דיווח OpenTelemetry אופציונלי ל-FailproofAI Cloud. תחילה חבר את המכונה שלך עם `failproofai config` והנח ממנהל ארגון להפעיל את **Settings → OpenTelemetry**.

ההגדרה האינטראקטיבית שואלת על OpenTelemetry לאחר שדה מפתח Cloud ובוררי הסוכן. השלב האופציונלי מוגדר כברירת מחדל ל-No. בחר Yes כדי לבחור סוכני OTEL; אותו קוד הפעלה יפעל לאחר שהחיבור כתוב. Esc לפני ההגדרה לא משנה כלום. הגדרה ללא השגחה, מפתח שסופק, מצב קוד פתוח ושמירת חיבור שנשמר לא מפעילים אותך.

## הפעל סוכן

```bash
failproofai otel enable claude
failproofai otel enable codex --local
failproofai otel enable codex --no-content
failproofai otel enable copilot
failproofai otel enable all --yes
```

הסוכנים הנתמכים הם `claude`, `codex` ו-`copilot` (VS Code). הגדרת Copilot דורשת קובץ בר הפעלה של VS Code או הרחבת Copilot מותקנת. ספריית הגדרות שנותרה לבדה אינה מספיקה; ההגדרה מדלגת על Copilot כאשר אף אחד מהם לא נמצא.

`--local` שולח ליחידת ממסר מקומית בדל מלשלוח ישירות ל-Cloud. Copilot משתמש בממסר באופן אוטומטי מכיוון שההגדרות שלו לא יכולות לאחסן את כותרת האימות.

הממסר מאזין רק על המכונה שלך. דמון FailproofAI שלך בתצורה יוצא מן הכלל לשינוי תוך שניות; אתה לא צריך להפעיל אותו מחדש. אם אפליקציה אחרת בעלת יציאת הממסר, דוחות המצב אותה כשקם והדמון ממשיך לרוץ.

<Warning>
לכידת טקסט פועלת כברירת מחדל. הוסף `--no-content` כדי להשמיט הנמקות פרטים בעלי כלים. גרסאות סוכן יכולות לחשוף בקרות תוכן שונות; בדוק מה הסוכן שלך מייצא לפני שימוש בו עם נתונים רגישים.
</Warning>

Codex מייצא רישומי שיחה בלבד, לא עקבות או מדדים פנימיים בזמן ריצה. `log_user_prompt = false` מפורש בתצורה ה-Codex שלך נשאר כבוי; הפעלה מדפיסה הערה כאשר היא משמרת את הבחירה הזו.

### בחר נתיב דיווח אחד

אם דיווח תמליל מופעל לסוכן, ההגדרה שואלת:

> failproofai כבר שולח Claude Code הישיבות ל-Cloud. שלח אותם עם OTEL במקום? העלאת תמליל עבור Claude Code מפסיקה.

ברירת המחדל היא No. `--yes` מקבל את ההחלפה ללא הנמקה. סוכנים אחרים ואכיפת מדיניות לא מושפעים.

הגדרת Codex מחכה לדמון לאשר את שינוי הסוכן לפני כתיבת הגדרות המייצא שלו. אם אישור פוקת זמן, ההגדרה מזהירה אותך להמתין לפני הפעלת Codex.

Config v2 שומר את רשימת ההתחקות הנזכרת ב-`agents.selected` (והיסטוריית זיהוי ב-`agents.seen`). ההעדפה של תמליל לסוכן נשארת ב-`collector.agents.<agent>.sessions`, בעלות OTEL ב-`otel.agents` והגדרות ממסר ב-`collector.otlp.enabled` / `collector.otlp.port`. המפתחות הנפרדים האלה שומרים על תצורות OTEL ישנות קריאות: ההגדרה יכולה לשנות את רשימת ההתחקות ללא איבוד ההעדפת התחבורה או המצב הדרוש לחזור להגדרות הסוכן שלך.

## בדוק הגדרה

```bash
failproofai otel status
```

Status מציג כל סוכן, בין אם הגדרותיו מנוהלות על ידי FailproofAI, היעד שלו, מתג ההנהלה של הארגון, מצב הממסר ותוצאת ההעלאה האחרונה של הממסר.

`unknown` למתג הארגון פירושו שהשרת לא סיפק אותו או לא הצליח להגיע אליו. זה לא שגיאה ואינו מונע תצורה בגרסת Cloud קדומה.

אם Cloud עדיין לא תומך ב-OTEL, הממסר שומר על ייצוא שנדחה בדל מהשלכתם. אם ההנהלה של הארגון כבויה, `enable` לא כותב כלום ויוצא עם שגיאה; בקש מממנהל להפעיל אותו תחילה.

## הדפס תצורה עבור אפליקציה

```bash
failproofai otel env --service my-agent
failproofai otel env --service my-agent --local
```

הפלט הוא בלוק סביבת מעטפת עבור יצואן OTLP/HTTP. פלט Cloud מגדיר את `OTEL_EXPORTER_OTLP_ENDPOINT` לבסיס OTLP של Cloud, `https://<cloud>/otel`, והיצואן מצרף `/v1/<signal>`; משתנה לסימן כגון `OTEL_EXPORTER_OTLP_LOGS_ENDPOINT` זקוק ל-`https://<cloud>/otel/v1/logs` המלא. פלט מקומי מצביע על הממסר, `http://127.0.0.1:<port>`. פלט Cloud כולל את מפתח ה-API המוגדר; התייחס אליו כסוד. פלט מקומי משמיט את המפתח. כדי להשתמש בפלט מקומי, תחילה הפעל סוכן מקומי כדי שהממסר יפעל.

## חזור להגדרות הקודמות

```bash
failproofai otel disable claude
failproofai otel disable all
```

Disable משחזר רק את ההגדרות ש-FailproofAI כתב, שומר על שינויים לא קשורים ומשחזר את בחירת דיווח התמליל הקודמת של כל סוכן. כאשר הסוכן המקומי המנוהל האחרון מבוטל, הממסר מפסיק לקבל ייצוא.

עבור Codex, disable גם מתעד את `collector.agents.codex.sessions_resume_after` (epoch milliseconds). בתים עדכנים קיימים מטופלים כמסופקים כך שהפעלות שנתפסו עם OTEL לא הועלו שוב; תוספות שמאוחר יותר עדיין זורמות דרך דיווח תמליל.

כל פקודה תומכת ב-`--help`. ראה [OpenTelemetry in Cloud](/he/agenteye/opentelemetry) לדוגמאות יישום וסוכני קידוד.
