`failproofai otel` מגדיר דיווח OpenTelemetry אופציונלי ל-FailproofAI Cloud. תחילה חבר את המכונה שלך עם `failproofai config` והבקש מממנהל הארגון להפעיל את **Settings → OpenTelemetry**.

ההגדרה האינטראקטיבית שואלת על OpenTelemetry לאחר שדה Cloud key ובוחר הסוכן. השלב האופציונלי ברירת המחדל שלו היא No. בחר Yes כדי לבחור סוכני OTEL; אותו קוד הפעלה פועל לאחר שכתבת את החיבור. Esc לפני שההגדרה משלימה לא תשנה דבר. הגדרה ללא השגחה, מפתח שסופק, מצב קוד פתוח, שמירת חיבור שמור לא משויכים אותך.

## הפעל סוכן

```bash
failproofai otel enable claude
failproofai otel enable codex --local
failproofai otel enable codex --no-content
failproofai otel enable copilot
failproofai otel enable all --yes
```

הסוכנים הנתמכים הם `claude`, `codex` ו-`copilot` (VS Code). הגדרת Copilot דורשת קובץ הפעלה של VS Code או הרחבת Copilot מותקנת. ספריית הגדרות שנותרה בלבד אינה מספיקה; ההגדרה דילגה על Copilot כאשר אף אחד מהם לא נמצא.

`--local` שולח ליחידת הממסר המקומית במקום ישירות לענן. Copilot משתמש בממסר באופן אוטומטי מכיוון שההגדרות שלו לא יכולות לאחסן את כותרת התימוכין.

הממסר מקשיב רק על המכונה שלך. ה-daemon של FailproofAI המחובר שלך חוטף את השינוי תוך שניות; אתה לא צריך להפעיל אותו מחדש. אם יישום אחר בעלות על יציאת הממסר, דוח המצב משנה אותה כ-off והדאימון ממשיך להפעיל.

<Warning>
לכידת טקסט היא ברירת מחדל. הוסף `--no-content` כדי להשמיט הנחיות פרטי כלים. גרסאות סוכן יכולות להחשוף בקרות תוכן שונות; בדוק מה הסוכן שלך מיצא לפני שבו משתמש עם נתונים רגישים.
</Warning>

Codex מיצא יומני שיחה בלבד, לא עקבות זמן ריצה פנימי או מדדים. `log_user_prompt = false` מפורש בתצורת Codex שלך נשאר כבוי; הפעלה מודפסת הערה כאשר היא שומרת על בחירה זו.

### בחר נתיב דיווח אחד

אם דיווח תמלול הוא פעיל עבור סוכן, ההגדרה שואלת:

> failproofai כבר שולח Claude Code הפגישות לענן. לשלוח אותם עם OTEL במקום? העלאת תמלול עבור Claude Code עוצרת.

ברירת המחדל היא No. `--yes` מקבל את הגיבוש ללא הנחיה. סוכנים אחרים אכיפת מדיניות לא מושפעים.

הגדרת Codex מחכה לדאימון לאשר את שינוי אספן לפני שכתיבת הגדרות מייצאה שלה. אם אישור פוקס, הגדרה מעניקה לך הערה להמתין לפני שתפעל את Codex.

Config v2 שומר על רשימת ההתחקות הנזכרת ב-`agents.selected` (וההיסטוריה של גילוי ב-`agents.seen`). ההעדפה תמלול לכל סוכן נשארת ב-`collector.agents.<agent>.sessions`, בעלות OTEL ב-`otel.agents` והגדרות הממסר ב-`collector.otlp.enabled` / `collector.otlp.port`. מפתחות נפרדים אלה שומרים על תצורות OTEL ישנות קריאות: ההגדרה יכולה לשנות את רשימת ההתחקות ללא אובדן העדפת התחבורה או המדינה הדרושה להשבת הגדרות הסוכן שלך.

## בדוק הגדרה

```bash
failproofai otel status
```

הסטטוס מציג כל סוכן, אם ההגדרות שלו מנוהלות על ידי FailproofAI, יעדו, קבלת הארגון, מצב הממסר ותוצאת ההעלאה האחרונה של הממסר.

`unknown` עבור קבלת הארגון פירושו השרת לא סיפק אותו או לא היה ניתן להגיע אליו. זה לא טעות ולא מונע תצורה בגרסה ענן ישנה יותר.

אם Cloud עדיין לא תומך ב-OTEL, הממסר שומר על יצוא דחוי במקום להשליך אותו. אם קבלת ארגון כבויה, `enable` לא כותבת דבר ויוצא עם שגיאה; בקש מממנהל להדליק אותו תחילה.

## הדפס תצורה עבור יישום

```bash
failproofai otel env --service my-agent
failproofai otel env --service my-agent --local
```

הפלט הוא בלוק סביבה של מעטפת עבור OTLP/HTTP מיצואר. פלט ענן קובע את `OTEL_EXPORTER_OTLP_ENDPOINT` לבסיס OTLP של ענן, `https://<cloud>/otel`, והמיצואר מוסיף `/v1/<signal>`; משתנה לכל-אות כמו `OTEL_EXPORTER_OTLP_LOGS_ENDPOINT` זקוק את הפלט `https://<cloud>/otel/v1/logs`. הפלט המקומי מציע את הממסר, `http://127.0.0.1:<port>`. פלט ענן כולל את מפתח API המחובר; התייחס אליו כסוד. פלט מקומי משמיט את המפתח. כדי להשתמש בפלט מקומי, תחילה הפעל סוכן מקומי כך שהממסר פועל.

## השב את ההגדרות הקודמות

```bash
failproofai otel disable claude
failproofai otel disable all
```

Disable משחזר רק את ההגדרות ש-FailproofAI כתב, שומר על שינויים לא קשורים, והשיב את בחירת דיווח התמלול הקודמת של כל סוכן. כאשר סוכן מקומי מנוהל אחרון מכובה, הממסר מפסיק לקבל יצוא.

עבור Codex, disable גם רשומות `collector.agents.codex.sessions_resume_after` (epoch אלפיות שניות). בתים של rollout קיימים מטופלים כמו מסירה כך שהפגישות שנתפסו עם OTEL לא יועלו שוב; appendices מאוחרות עדיין זורמות דרך דיווח תמלול.

כל פקודה תומכת ב-`--help`. ראה [OpenTelemetry בענן](/he/agenteye/opentelemetry) לדוגמאות יישום וסוכן קידוד.
