`failproofai otel` מגדיר דיווח OpenTelemetry אופציונלי ל-FailproofAI Cloud. תחילה חבר את המכונה שלך עם `failproofai config` והבקש מאדמין ארגוני להפעיל **Settings → OpenTelemetry**.

ההתקנה האינטראקטיבית שואלת על OpenTelemetry לאחר שדה מפתח Cloud ובחירת הסוכן. השלב האופציונלי גם כברירת מחדל ל-No. בחר Yes כדי לבחור סוכני OTEL; אותו קוד הפעלה מופעל לאחר כתיבת החיבור. Esc לפני ההתקנה לא משנה דבר. התקנה ללא השגחה, מפתח מסופק, מצב קוד פתוח, והשמירה על חיבור שמור לא משנים אותך.

## הפעלת סוכן

```bash
failproofai otel enable claude
failproofai otel enable codex --local
failproofai otel enable codex --no-content
failproofai otel enable copilot
failproofai otel enable all --yes
```

הסוכנים הנתמכים הם `claude`, `codex`, ו-`copilot` (VS Code). התקנת Copilot דורשת קובץ הפעלה של VS Code או הרחבת Copilot מותקנת. ספרייה הגדרות שנותרה בלבד אינה מספיקה; ההתקנה דילוגת על Copilot כאשר לא נמצא אחד מהם.

`--local` שולח לרלה מקומי במקום ישירות ל-Cloud. Copilot משתמש בריליי באופן אוטומטי מכיוון שההגדרות שלו לא יכולות לאחסן את כותרת ההזדהות.

הרלה מאזינה רק במכונה שלך. ה-daemon של FailproofAI שלך יקלט את השינוי תוך שניות; אינך צריך להפעיל אותו מחדש. אם יישום אחר הוא בעלך של יציאת הרלה, דוחות המצב מדווחים עליה כ-off וה-daemon ממשיך לפעול.

<Warning>
לכידת טקסט פועלת כברירת מחדל. הוסף `--no-content` כדי להשמיט הנחיות ופרטי כלים. גרסאות סוכן יכולות לחשוף בקרות תוכן שונות; בדוק מה הסוכן שלך מייצא לפני שימוש בנתונים רגישים.
</Warning>

Codex מייצא יומני שיחה בלבד, לא עקבות או מדדים פנימיים בזמן ריצה. `log_user_prompt = false` מפורש בתצורת Codex שלך נשאר כבוי; הפעלה מדפיסה הערה כאשר היא שומרת על בחירה זו.

### בחר נתיב דיווח אחד

אם דיווח על תמלול פועל עבור סוכן, ההתקנה שואלת:

> failproofai כבר שולח ישיבות Claude Code ל-Cloud. לשלוח אותן עם OTEL במקום? עלייה של הוצאת תמלול עבור Claude Code מפסיקה.

הברירה המחדלת היא No. `--yes` מקבל את ההחלפה ללא הנחיה. סוכנים אחרים אבטחת מדיניות אינם מושפעים.

התקנת Codex מחכה לדיימון לאשר את שינוי המאסף לפני כתיבת הגדרות הממוצא שלו. אם אישור פגה בתוקף, ההתקנה מזהירה אותך להמתין לפני הפעלת Codex.

Config v2 שומר את רשימת ההתקפות הנזכרת ב-`agents.selected` (וההיסטוריה של גילוי ב-`agents.seen`). העדפת התמלול לסוכן נשארת ב-`collector.agents.<agent>.sessions`, בעלות OTEL ב-`otel.agents`, והגדרות ריליי ב-`collector.otlp.enabled` / `collector.otlp.port`. מקשים נפרדים אלה שומרים תצורות OTEL ישנות קריאות: ההתקנה יכולה לשנות את רשימת ההתקפות ללא הפסד של העדפת התחבורה או המצב הדרוש להשבת הגדרות הסוכן שלך.

## בדוק התקנה

```bash
failproofai otel status
```

המצב מציג כל סוכן, האם ההגדרות שלו מנוהלות על ידי FailproofAI, היעד שלו, מתג ההנקה של הארגון, מצב ריליי, ותוצאת ההעלאה האחרונה של ריליי.

`unknown` עבור מתג הארגון פירושו השרת לא סיפק אותו או לא היה ניתן להגיע אליו. זה לא שגיאה ואינו מונע תצורה בגרסת Cloud ישנה יותר.

אם Cloud עדיין אינו תומך ב-OTEL, הרלה משמרת ייצוא דחוי במקום לזרוק אותם. אם צריכה ארגונית כבויה, `enable` לא כותב דבר ויוצא עם שגיאה; בקש מ-admin להדליק את זה קודם.

## הדפס תצורה עבור יישום

```bash
failproofai otel env --service my-agent
failproofai otel env --service my-agent --local
```

הפלט הוא בלוק סביבה של shell עבור יצואן OTLP/HTTP. פלט Cloud מגדיר `OTEL_EXPORTER_OTLP_ENDPOINT` לבסיס OTLP של Cloud, `https://<cloud>/otel`, והיצואן משתנה `/v1/<signal>`; משתנה לכל אות כמו `OTEL_EXPORTER_OTLP_LOGS_ENDPOINT` צריך את ה-`https://<cloud>/otel/v1/logs` המלא. פלט מקומי מצביע על הרלה, `http://127.0.0.1:<port>`. פלט Cloud כולל את מפתח ה-API המוגדר; התייחס אליו כסוד. פלט מקומי משמיט את המפתח. כדי להשתמש בפלט מקומי, תחילה הפעל סוכן מקומי כדי שהרלה תפעל.

## השבת הגדרות קודמות

```bash
failproofai otel disable claude
failproofai otel disable all
```

Disable משחזר רק את ההגדרות ש-FailproofAI כתב, שומר על שינויים שאינם קשורים, ומשחזר את בחירת הדיווח על התמלול הקודמת של כל סוכן. כאשר הסוכן המקומי המנוהל האחרון מושבת, הרלה מפסיקה לקבל ייצוא.

עבור Codex, disable גם מתעד `collector.agents.codex.sessions_resume_after` (epoch milliseconds). בתים קיימים של הטלה מתרחשים כמועברים כך שישיבות שתפסו עם OTEL לא יועלו שוב; תוספות מאוחרות יותר עדיין זורמות דרך דיווח תמלול.

כל פקודה תומכת ב-`--help`. ראה [OpenTelemetry in Cloud](/he/agenteye/opentelemetry) לדוגמאות יישום וסוכן קוד.
