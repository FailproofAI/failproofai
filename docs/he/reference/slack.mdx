שאל את [העוזר Failproof](/he/sessions/assistant) מ-Slack. הזכר את האפליקציה בערוץ, שלח לה הודעה ישירה, או השתמש ב-`/failproof <question>`. התשובות משתמשות **בהרשאות שלך שלך** ב-Failproof AI, התרשימים מופיעים בתוך ההודעה, וכל דבר שיגרום לשינוי מבקש ממך אישור קודם לכן.

יש אפליקציה רשמית אחת. היא פועלת באותו האופן בין אם ה-Failproof AI Cloud שלך מתורחן או self-hosted.

<Note>
  תשובות מופקות על ידי מודלי AI ויכולות להיות לא מדויקות. בדוק כל דבר חשוב מול נתוני המקור המקושרים.
</Note>

## חבר מרחב עבודה

אתה זקוק להרשאת `settings:write` ב-Failproof AI ובSlack, להיות מנהל או בעלים של מרחב עבודה, או האדם שמוסיף את האפליקציה.

<Tabs>
  <Tab title="מ-Failproof AI">
    1. עבור ל-**Settings → Integrations** ובחר **Add to Slack**.
    2. אשר את האפליקציה ב-Slack.
    3. חזרה ב-Failproof AI, אשר את חיבור מרחב העבודה לארגון שלך.
  </Tab>
  <Tab title="מ-Slack">
    1. הוסף את האפליקציה, ואז פתח את הכרטיסייה **Home** שלה.
    2. בחר **Continue with FailproofAI Cloud**, או **Use my own URL** והזן את הכתובת שאתה נכנס אליה.
    3. בחר את כפתור ההמשך, התחבר, בחר את הארגון, ואשר. הקישור פעיל פעם אחת ותוקפו פוקע לאחר 10 דקות.
  </Tab>
</Tabs>

מרחב עבודה אחד מתחבר לארגון אחד, וארגון אחד למרחב עבודה אחד.

אין לך חשבון? [צור אחד](https://app.befailproof.ai/login) קודם, ואז התחבר.

## מי אתה ב-Slack

בפעם הראשונה שאתה שואל, האפליקציה מוצאת איזה חבר אתה:

- **באופן אוטומטי, לפי דוא״ל**, כאשר אתה חבר מלא של מרחב העבודה המחובר, הדוא״ל של Slack שלך מאושר, וחבר אחד בדיוק בארגון משתמש בדוא״ל זה.
- **אחרת**, אתה מקבל כפתור **Link your account** פרטי שפותח את Failproof AI ומקשר את משתמש Slack שלך לחשבון שלך.

## שאל שאלה

| היכן | איך |
| --- | --- |
| ערוץ | הזכר את האפליקציה. השב בתוך ההודעה שלה כדי להמשיך, ללא צורך בהזכרה |
| הודעה ישירה | שלח הודעה לאפליקציה |
| הודעה ישירה קבוצתית שהאפליקציה בה | הזכר אותה, ואז השב בתוך ההודעה שלה כדי להמשיך |
| ערוץ Slack Connect | הזכר את האפליקציה |
| כל שיחה שהאפליקציה בה | `/failproof <question>` מתחיל שרשור עם התשובה |
| `/failproof help` | ראה מה האפליקציה יכולה לעשות |
| `/failproof status` | ראה איזה ארגון מחובר ולמי אתה מקושר |
| `/failproof link` | ראה לאיזה חשבון Failproof AI אתה מקושר |

שרשור אחד היא שיחה אחת. עמיתים יכולים להזכיר את האפליקציה באותו השרשור, והיא עונה לכל אחד מהם בהרשאות שלהם. רק האדם שהתחיל את השרשור ממשיך אותו ללא הזכרה.

כאשר התשובה היא נתונים, האפליקציה מפרסמת תרשים או טבלה עם קישור לפתיחתה ב-Failproof AI.

## אישור שינויים

כל שינוי שהעוזר עושה מראה כפתורי **Approve** ו-**Cancel** קודם לכן, ו-Slack שואל פעם נוספת לפני **Approve**. רק האדם שביקש יכול לענות עליהם, הכפתורים פוקעים לאחר 5 דקות, והשינוי מתבצע בהרשאות של אותו אדם.

מ-Slack, העוזר יכול לשנות שאילתות וDashboard שנשמרו, הערכות, התראות, ביקורות, בעיות, ומדיניות, והציע תיקוני קוד, כל אחד אם אתה מחזיק בהרשאה. הוא לא יכול לשנות מפתחות API, משתמשים, או הגדרות.

## קישורי תצוגה מקדימה

קישורי ה-issue, session, והערכה של Failproof AI שהודבקו ב-Slack מתפתחים לכרטיסים ב-Failproof AI Cloud מתורחן. כרטיס מראה רק את מה שהאדם שגרם לו יכול לראות. קישורים לכתובת self-hosted לא מתפתחים, למרות שכרטיסים בתשובות שלעוזר עצמו עדיין מופיעים.

## ערוצי Slack Connect

אנשים ממרחב עבודה אחר יכולים להשתמש באפליקציה אם הם חברים בארגון, לאחר קישור החשבון שלהם. התשובות גלויות לכולם בשיחה, כולל אנשים שאינם חברים בארגון שלך, לכן שאל היכן כולם עלולים לראות את התשובה.

האפליקציה עונה רק כאשר למישהו אחד בכל מרחב עבודה אחר בערוץ יש קישור לארגון. עד אז, היא אומרת לאדם השואל למה.

## הרשאות שהאפליקציה מבקשת

| הרשאת Slack | למה |
| --- | --- |
| `app_mentions:read` | דע מתי מישהו מזכיר את האפליקציה |
| `channels:history`, `groups:history`, `im:history`, `mpim:history` | קבל הודעות ישירות והשבות בשרשורי האפליקציה. האפליקציה מתעלמת מהודעות אחרות, ולעולם לא קוראת הודעות קודמות של שיחה |
| `channels:read`, `groups:read`, `im:read`, `mpim:read` | בדוק איזה סוג שיחה היא, כדי שהיא תדע מי יכול לראות תשובה |
| `chat:write` | פרסם תשובות וכפתורי אישור |
| `commands` | ספק `/failproof` |
| `files:write` | פרסם תרשימים |
| `links:read`, `links:write` | הצג קישורי Failproof AI שהודבקו |
| `users:read`, `users:read.email` | התאם אותך לחשבון Failproof AI שלך, והצג שמות |

## התנתק

עבור ל-**Settings → Integrations** ובחר **Disconnect**, השתמש ב-**Disconnect** בכרטיסייה **Home** של האפליקציה, או הסר את האפליקציה מ-Slack.

כל אחד מאלה מוחק את החיבור של מרחב העבודה, token הבוט, חשבונות מקושרים, וקובצי שרשור. שיחות Slack קודמות נשארות קריאות בDashboard. הארגון יכול אז לחבר כל מרחב עבודה מיד.

## נתונים וגופניות

שאלות ותשובות נשמרות כשיחות בDashboard של הארגון שלך, תחת האדם שהתחיל את השרשור. נתוני Slack לא מעולם משמשים לאימון מודלי AI. ראה את [מדיניות הפרטיות](https://befailproof.ai/privacy/) למה האפליקציה מקבלת וכמה זמן היא נשמרת.
