שאל את [סוכן failproof](/he/sessions/assistant) מ-Slack. הזכר את האפליקציה בערוץ, שלח לה הודעה ישירה, או השתמש ב-`/failproof <שאלה>`. התשובות משתמשות **בהרשאות שלך שלך** של Failproof AI, תרשימים מגיעים לתוך השרשור, וכל דבר שיעשה שינוי מבקש ממך את אישורך קודם לכן.

יש אפליקציה רשמית אחת. היא עובדת בדיוק באותה צורה בין אם ה-Failproof AI Cloud שלך מתורחן או מתורחן בעצמך.

<Note>
  תשובות נוצרות על ידי דגמי AI ויכולות להיות אינדוקטיביות. בדוק כל דבר חשוב מול נתוני המקור המקושרים.
</Note>

## חיבור workspace

אתה צריך את הרשאת `settings:write` ב-Failproof AI ובנוסף, ב-Slack, להיות מנהל workspace או בעלים, או האדם שמוסיף את האפליקציה.

<Tabs>
  <Tab title="מ-Failproof AI">
    1. עבור אל **settings → integrations** ובחר ב-**Add to Slack**.
    2. אשר את האפליקציה ב-Slack.
    3. חזרה ב-Failproof AI, אשר את חיבור ה-workspace לארגון שלך.
  </Tab>
  <Tab title="מ-Slack">
    1. הוסף את האפליקציה, ואז פתח את הכרטיסייה **Home** שלה.
    2. בחר ב-**Continue with FailproofAI Cloud**, או **Use my own URL** והזן את הכתובת שבה אתה נכנס.
    3. בחר את כפתור ההמשך, היכנס, בחר את הארגון, ואשר. הקישור עובד פעם אחת ופוקע לאחר 10 דקות.
  </Tab>
</Tabs>

workspace אחד מתחבר לארגון אחד, וארגון אחד ל-workspace אחד.

אין לך חשבון? [צור אחד](https://app.befailproof.ai/login) קודם כל, ואז התחבר.

## מי אתה ב-Slack

בפעם הראשונה שאתה שואל, האפליקציה מבררת איזה חבר אתה:

- **באופן אוטומטי, לפי דוא״ל**, כאשר אתה חבר מלא של ה-workspace המחובר, הדוא״ל שלך ב-Slack מאומת, וכלי חבר אחד בדיוק של הארגון משתמש בדוא״ל הזה.
- **אחרת**, אתה מקבל כפתור **Link your account** פרטי שפותח את Failproof AI ומקשר את משתמש ה-Slack שלך לחשבון שלך.

## שאל שאלה

| איפה | כיצד |
| --- | --- |
| ערוץ | הזכר את האפליקציה. הגב בשרשור שלה כדי להמשיך, ללא צורך בהזכרה |
| הודעה ישירה | שלח הודעה לאפליקציה |
| הודעה ישירה קבוצתית שהאפליקציה נמצאת בה | הזכר אותה, ואז הגב בשרשור שלה כדי להמשיך |
| ערוץ Slack Connect | הזכר את האפליקציה |
| כל שיחה שהאפליקציה נמצאת בה | `/failproof <שאלה>` מתחיל שרשור עם התשובה |
| `/failproof help` | ראה מה האפליקציה יכולה לעשות |
| `/failproof status` | ראה איזה ארגון מחובר וכמי אתה מקושר |
| `/failproof link` | ראה איזה חשבון Failproof AI אתה מקושר אליו |

שרשור אחד היא שיחה אחת. קולגות יכולים להזכיר את האפליקציה באותו שרשור, והיא עונה לכל אחד מהם עם ההרשאות שלהם. רק האדם שהתחיל את השרשור משך אותו ללא הזכרה.

כאשר התשובה היא נתונים, האפליקציה מפרסמת תרשים או טבלה עם קישור לפתיחתה ב-Failproof AI.

## אישור שינויים

כל שינוי שסוכן failproof ביצע מציג כפתורי **Approve** ו-**Cancel** קודם לכן, ו-Slack שואל שוב לפני **Approve**. רק האדם שהשאל יכול לענות להם, הכפתורים פוקעים לאחר 5 דקות, והשינוי בוצע עם הרשאות אדם זה.

מ-Slack, סוכן failproof יכול לשנות שאילתות שמורות ודשבורדים, הערכות, התראות, ביקורות, insights, ומדיניויות, והצע תיקונים קוד, כל אחד אם יש לך את ההרשאה. זה לא יכול לשנות מפתחות API, משתמשים, או הגדרות.

## Link previews

Failproof AI insight, session, ו-evaluation קישורים שהודבקו ב-Slack פורשים לכרטיסים ב-Failproof AI Cloud מתורחן. כרטיס מציג רק את מה שהאדם שהוביל אותו יכול לראות. קישורים לכתובת מתורחנת בעצמי לא פורשים, אם כי כרטיסים בתשובות שלו של סוכן failproof עדיין מופיעים.

## ערוצי Slack Connect

אנשים מ-workspace אחר יכולים להשתמש באפליקציה אם הם חברים בארגון, לאחר קישור החשבון שלהם. תשובות גלויות לכל אדם בשיחה, כולל אנשים שאינם חברים בארגון שלך, אז שאל איפה כולם עשויים לראות את התשובה.

האפליקציה עונה רק כאשר כל workspace אחר בערוץ יש למישהו מקושר לארגון. עד אז, זה אומר לאדם השואל למה.

## הרשאות שהאפליקציה מבקשת

| הרשאת Slack | למה |
| --- | --- |
| `app_mentions:read` | ידע כאשר מישהו הזכר את האפליקציה |
| `channels:history`, `groups:history`, `im:history`, `mpim:history` | קבל הודעות ישירות וגבים בשרשורי האפליקציה. האפליקציה מתעלמת מהודעות אחרות, והיא לעולם לא קוראת הודעות העבר של שיחה |
| `channels:read`, `groups:read`, `im:read`, `mpim:read` | בדוק איזה סוג של שיחה היא נמצאת, כך שהיא יודעת מי יכול לראות תשובה |
| `chat:write` | פרסם תשובות וכפתורי אישור |
| `commands` | ספק `/failproof` |
| `files:write` | פרסם תרשימים |
| `links:read`, `links:write` | הצג תצוגות מקדימות של קישורים Failproof AI שהודבקו |
| `users:read`, `users:read.email` | התאם אותך לחשבון Failproof AI שלך, והצג שמות |

## התנתקות

עבור אל **settings → integrations** ובחר ב-**Disconnect**, השתמש ב-**Disconnect** בכרטיסייה **Home** של האפליקציה, או הסר את האפליקציה מ-Slack.

כל אחד מאלה מוחק את חיבור ה-workspace, bot token, חשבונות מקושרים, וריכוזי שרשור. שיחות Slack שעברו נשארות ניתנות לקריאה בלוח המחוונים. הארגון יכול אז להתחבר כל workspace מיד.

## נתונים וגופנות

שאלות ותשובות שמורות כשיחות בלוח המחוונים של הארגון שלך, תחת האדם שהתחיל את השרשור. נתוני Slack לעולם לא משמשים לאימון דגמי AI. ראה את [מדיניות הגופנות](https://befailproof.ai/privacy/) לפרטים מה האפליקציה מקבלת ומשך זמן הוא נשמר.
