שאל את [Failproof Assistant](/he/sessions/assistant) מSlack. אזכר את האפליקציה בערוץ, שלח לה הודעה ישירה, או השתמש ב`/failproof <question>`. התשובות משתמשות **בהרשאות שלך שלך** של Failproof AI, תרשימים מגיעים בתוך הthread, וכל דבר שיגרום לשינוי מבקש ממך לאשר תחילה.

יש אפליקציה רשמית אחת. היא עובדת באותו אופן בין אם ה-Failproof AI Cloud שלך מתופעל בענן או בעצמך.

<Note>
  תשובות נוצרות על ידי מודלים AI ויכולות להיות אינם מדויקות. בדוק כל דבר חשוב מול נתוני המקור המקושרים.
</Note>

## חיבור workspace

אתה צריך את ההרשאה `settings:write` ב-Failproof AI וב-Slack, להיות מנהל workspace או בעלים, או האדם שמוסיף את האפליקציה.

<Tabs>
  <Tab title="מFailuproofAI">
    1. עבור ל**Settings → Integrations** ובחר ב**Add to Slack**.
    2. אשר את האפליקציה ב-Slack.
    3. חזור ל-Failproof AI והאשר חיבור ה-workspace לארגון שלך.
  </Tab>
  <Tab title="מSlack">
    1. הוסף את האפליקציה, ואז פתח את הכרטיסית **Home** שלה.
    2. בחר ב**Continue with FailproofAI Cloud**, או **Use my own URL** והזן את הכתובת שבה אתה מתחבר.
    3. בחר את כפתור ההמשך, התחבר, בחר את הארגון, והאשר. הקישור עובד פעם אחת ותוקפו פוקע לאחר 10 דקות.
  </Tab>
</Tabs>

workspace אחד מתחבר לארגון אחד, וארגון אחד ל-workspace אחד.

אין לך חשבון? [צור אחד](https://app.befailproof.ai/login) תחילה, ואז התחבר.

## מי אתה ב-Slack

בפעם הראשונה שאתה שואל, האפליקציה יוצאת למצא איזה חבר אתה:

- **באופן אוטומטי, לפי דוא"ל**, כשאתה חבר מלא של ה-workspace המחובר, הדוא"ל של Slack שלך מאומת, וחבר אחד בדיוק של הארגון משתמש בדוא"ל זה.
- **אחרת**, אתה מקבל כפתור **Link your account** פרטי שפותח את Failproof AI ומקשר את משתמש Slack שלך לחשבון שלך.

## הצע שאלה

| איפה | איך |
| --- | --- |
| ערוץ | אזכר את האפליקציה. הגב בתוך ה-thread שלה להמשך, ללא צורך בהזכרה |
| הודעה ישירה | שלח הודעה לאפליקציה |
| קבוצה הודעה ישירה שהאפליקציה נמצאת בה | אזכר אותה, ואז הגב בתוך ה-thread שלה להמשך |
| ערוץ Slack Connect | אזכר את האפליקציה |
| כל שיחה שהאפליקציה נמצאת בה | `/failproof <question>` מתחיל thread עם התשובה |
| `/failproof help` | ראה מה האפליקציה יכולה לעשות |
| `/failproof status` | ראה איזה ארגון מחובר ומי אתה מקושר בתור |
| `/failproof link` | ראה איזה חשבון Failproof AI אתה מקושר אליו |

thread אחד היא שיחה אחת. עמיתים יכולים להזכיר את האפליקציה באותו thread, והיא משיבה לכל אחד מהם עם הרשאות משלהם. רק האדם שהתחיל את ה-thread ממשיך אותו ללא הזכרה.

כשהתשובה היא נתונים, האפליקציה מפרסמת תרשים או טבלה עם קישור לפתיחה ב-Failproof AI.

## אישור שינויים

כל שינוי שהעוזר עושה מראה כפתורים **Approve** ו**Cancel** תחילה, וSlack שואל שוב לפני **Approve**. רק האדם ששאל יכול לענות עליהם, הכפתורים פוקעים לאחר 5 דקות, והשינוי מתבצע עם הרשאות האדם הזה.

מSlack, העוזר יכול לשנות שאילתות שמורות ודashboards, הערכות, התרעות, ביקורות, בעיות ומדיניות, והציע תיקוני קוד, כל אחד אם יש לך את ההרשאה. היא לא יכולה לשנות API keys, משתמשים, או הגדרות.

## תצוגה מקדימה של קישורים

Failproof AI issue, session, ו-evaluation קישורים דביקים ב-Slack נפרסות לכרטיסיות ב-Failproof AI Cloud מתופעל. כרטיסייה מראה רק מה האדם שהפעיל אותה יכול לראות. קישורים לכתובת בעצמך מתופעלת לא נפרסות, אם כי כרטיסיות בתשובות של העוזר עצמו עדיין מופיעות.

## ערוצי Slack Connect

אנשים מworkspace אחר יכולים להשתמש באפליקציה אם הם חברים בארגון, לאחר קישור חשבונם. תשובות גלויות לכולם בשיחה, כולל אנשים שאינם חברים בארגון שלך, אז שאל איפה כולם עלולים לראות את התשובה.

האפליקציה משיבה רק פעם אחת כל workspace אחר בערוץ יש למישהו המקושר לארגון. עד אז, היא מספרת לאדם ששאל למה.

## הרשאות שהאפליקציה מבקשת

| הרשאת Slack | למה |
| --- | --- |
| `app_mentions:read` | דע מתי מישהו מזכיר את האפליקציה |
| `channels:history`, `groups:history`, `im:history`, `mpim:history` | קבל הודעות ישירות והגבות בתוך threads של האפליקציה. האפליקציה מתעלמת מהודעות אחרות, והיא אף פעם לא קוראת הודעות עבר של שיחה |
| `channels:read`, `groups:read`, `im:read`, `mpim:read` | בדוק איזה סוג שיחה זה, כדי שהיא תדע מי יכול לראות תשובה |
| `chat:write` | פרסם תשובות וכפתורי אישור |
| `commands` | ספק `/failproof` |
| `files:write` | פרסם תרשימים |
| `links:read`, `links:write` | הצג תצוגה מקדימה של קישורים Failproof AI דביקים |
| `users:read`, `users:read.email` | תאימו אתכם לחשבון Failproof AI שלכם, והצג שמות |

## התנתק

עבור ל**Settings → Integrations** ובחר ב**Disconnect**, השתמש ב**Disconnect** בכרטיסית **Home** של האפליקציה, או הסר את האפליקציה מSlack.

כל אחד מאלה מחק את חיבור ה-workspace, bot token, חשבונות מקושרים, ורשומות thread. שיחות Slack בעבר נשארות קריאות בדashboard. הארגון יכול אז לחבר כל workspace מיד.

## נתונים וגופנות

שאלות ותשובות שמורות כשיחות בדashboard של הארגון שלך, תחת האדם שהתחיל את ה-thread. נתוני Slack לא משמשים לעולם להכשרת מודלי AI. ראה את [מדיניות הגופנות](https://befailproof.ai/privacy/) עבור מה האפליקציה מקבלת וכמה זמן היא שמורה.

## Troubleshooting

| מה אתה רואה | מה לעשות |
| --- | --- |
| "This workspace isn't connected to a FailproofAI Cloud yet." | מנהל workspace פותח את כרטיסית **Home** של האפליקציה ובוחר באחד |
| "This link expired or was already used." | בחר את Cloud שלך שוב בכרטיסית **Home** עבור קישור חדש |
| "This org is already connected to a Slack workspace." | התנתק ממנו בהגדרות תחילה |
| "That Slack workspace is connected to another org." | התנתק ממנו מארגון זה תחילה |
| "Link your account to use the assistant." | בחר את הכפתור והאשר ב-Failproof AI |
| האפליקציה לא משיבה בהודעה ישירה לקבוצה | הוסף את האפליקציה ל-Slack שוב כדי להעניק הרשאות הקבוצה שלה. החיבור שלך נשמר |
| "I won't post answers from your organization here" | מישהו בworkspace זה שהוא חבר בארגון מזכיר את האפליקציה וקושר את חשבונם |
