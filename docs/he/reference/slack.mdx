שאל את [עוזר Failproof](/he/sessions/assistant) מ-Slack. הזכר את האפליקציה בערוץ, שלח לה הודעה ישירה, או השתמש ב-`/failproof <question>`. התשובות משתמשות **בהרשאות שלך שלך** של Failproof AI, תרשימים מגיעים בשרשור, וכל דבר שיעשה שינוי מבקש את אישורך תחילה.

יש אפליקציה רשמית אחת. היא פועלת באותו אופן בין אם ה-Failproof AI Cloud שלך מתארח או self-hosted.

<Note>
  תשובות נוצרות על ידי מודלים של AI ויכולות להיות לא מדויקות. בדוק כל דבר חשוב מול נתוני המקור המקושרים.
</Note>

## חיבור workspace

אתה צריך הרשאת `settings:write` ב-Failproof AI ובSlack, להיות admin או בעלים של workspace, או האדם המוסיף את האפליקציה.

<Tabs>
  <Tab title="מ-Failproof AI">
    1. עבור ל-**Settings → Integrations** ובחר **Add to Slack**.
    2. אשר את האפליקציה ב-Slack.
    3. בחזרה ב-Failproof AI, אשר חיבור של ה-workspace לארגון שלך.
  </Tab>
  <Tab title="מ-Slack">
    1. הוסף את האפליקציה, ואז פתח את הכרטיסייה **Home** שלה.
    2. בחר **Continue with FailproofAI Cloud**, או **Use my own URL** והכנס את הכתובת בה אתה מתחבר.
    3. בחר את כפתור ההמשך, התחבר, בחר את הארגון וחזק. הקישור עובד פעם אחת ותוקף עד 10 דקות.
  </Tab>
</Tabs>

workspace אחד מתחבר לארגון אחד, וארגון אחד ל-workspace אחד.

אין לך חשבון? [צור אחד](https://app.befailproof.ai/login) תחילה, ואז התחבר.

## מי אתה ב-Slack

בפעם הראשונה שאתה שואל, האפליקציה מבינה איזה חברה אתה:

- **באופן אוטומטי, לפי אימייל**, כאשר אתה חברה מלאה של ה-workspace המחובר, האימייל שלך ב-Slack אושר, וחברה אחת בדיוק בארגון משתמשת באימייל זה.
- **אחרת**, אתה מקבל כפתור **Link your account** פרטי שפותח את Failproof AI ומקשר את משתמש ה-Slack שלך לחשבון שלך.

## שאל שאלה

| איפה | איך |
| --- | --- |
| ערוץ | הזכר את האפליקציה. הגב בשרשור שלה כדי להמשיך, ללא הזכרה נדרשת |
| הודעה ישירה | שלח הודעה לאפליקציה |
| הודעה ישירה קבוצתית שהאפליקציה נמצאת בה | הזכר אותה, ואז הגב בשרשור שלה כדי להמשיך |
| ערוץ Slack Connect | הזכר את האפליקציה |
| כל שיחה שהאפליקציה נמצאת בה | `/failproof <question>` מתחיל שרשור עם התשובה |
| `/failproof help` | ראה מה האפליקציה יכולה לעשות |
| `/failproof status` | ראה איזה ארגון מחובר ולמי אתה קשור |
| `/failproof link` | ראה לאיזה חשבון Failproof AI אתה קשור |

שרשור אחד היא שיחה אחת. עמיתים יכולים להזכר את האפליקציה באותו שרשור, והיא משיבה לכל אחד מהם בהרשאות שלהם. רק האדם שהתחיל את השרשור ממשיך בו ללא הזכרה.

כאשר התשובה היא נתונים, האפליקציה מרסלת תרשים או טבלה עם קישור לפתיחה ב-Failproof AI.

## אישור שינויים

כל שינוי שהעוזר עושה מציג תחילה כפתורי **Approve** ו-**Cancel**, ו-Slack שואל שוב לפני **Approve**. רק האדם ששאל יכול לענות עליהם, הכפתורים תוקפים ל-5 דקות, והשינוי נעשה בהרשאות של אדם זה.

מ-Slack, העוזר יכול לשנות queries שמורים ודוחים, הערכות, התראות, ביקורות, issues, ומדיניות, ולהציע תיקוני קוד, כל אחד אם יש לך את ההרשאה. הוא לא יכול לשנות API keys, משתמשים, או הגדרות.

## חזויות קישור

Failproof AI issue, session, והערכת קישורים מודבקים ב-Slack מתרחיבים לכרטיסים ב-Failproof AI Cloud המתארח. כרטיס מציג רק מה שהאדם שהפעיל אותו יכול לראות. קישורים לכתובת self-hosted לא מתרחיבים, אם כי כרטיסים בתשובות שלעוזר עצמו עדיין מופיעים.

## ערוצי Slack Connect

אנשים מworkspace אחר יכולים להשתמש באפליקציה אם הם חברים בארגון, לאחר קישור החשבון שלהם. תשובות נראות לכל אחד בשיחה, כולל אנשים שאינם חברים בארגון שלך, אז שאל איפה כולם עשויים לראות את התשובה.

האפליקציה משיבה רק כאשר לכל workspace אחר בערוץ יש מישהו קשור לארגון. עד אז, היא אומרת לאדם ששאל למה.

## הרשאות שהאפליקציה מבקשת

| הרשאת Slack | למה |
| --- | --- |
| `app_mentions:read` | דעו מתי מישהו מזכיר את האפליקציה |
| `channels:history`, `groups:history`, `im:history`, `mpim:history` | קבל הודעות ישירות והגבות בשרשורי האפליקציה. האפליקציה מתעלמת מהודעות אחרות, והיא לעולם לא קוראת הודעות בעבר של שיחה |
| `channels:read`, `groups:read`, `im:read`, `mpim:read` | בדוק איזה סוג שיחה זה בו, כך שהיא יודעת מי יכול לראות תשובה |
| `chat:write` | רסל תשובות וכפתורי אישור |
| `commands` | ספק `/failproof` |
| `files:write` | רסל תרשימים |
| `links:read`, `links:write` | הצג חזויות של קישורי Failproof AI מודבקים |
| `users:read`, `users:read.email` | תאום אותך לחשבון Failproof AI שלך, והצג שמות |

## התנתקות

עבור ל-**Settings → Integrations** וחר **Disconnect**, השתמש ב-**Disconnect** בכרטיסייה **Home** של האפליקציה, או הסר את האפליקציה מSlack.

כל אחד מאלה מוחק את חיבור ה-workspace, bot token, חשבונות קשורים, ורשומות שרשור. שיחות Slack בעבר נותרו קריאות בדוח הבקרה. הארגון יכול אז להתחבר כל workspace מיד.

## נתונים וסודיות

שאלות ותשובות נשמרות כשיחות בדוח הבקרה של הארגון שלך, תחת האדם שהתחיל את השרשור. נתוני Slack לעולם לא משמשים לאימון מודלי AI. ראה את [מדיניות הפרטיות](https://befailproof.ai/privacy/) לגבי מה שהאפליקציה מקבלת ותוך כמה זמן היא נשמרת.
