התחל עם:

```bash
failproofai config --status
failproofai policies
```

## סוכן אינו מחובר

הרץ את ההגדרה שוב:

```bash
failproofai config
```

ההגדרה תומכת ב-Linux ו-macOS. היא זקוקה לגישת מנהל פעם אחת כדי להתקין את השירות, אך לעולם לא מבקשת סיסמת sudo.

בדוק נתיבי harness וטווחים ב-[Harnesses](/he/reference/harnesses).

## סשן חסר

```bash
failproofai flush --wait
failproofai backfill --since 30d --dry-run
failproofai harness list
```

הסר את `--dry-run` כדי לשלוח מחדש היסטוריה ישנה. הוסף מיקום תמלול נוסף עם:

```bash
failproofai harness add-path <harness> [label=]<path>
```

השתמש בתווית כאשר שתי מיקומים מכילים עותקים של אותו פרויקט.

## כל פעולה מוגנת נדחית

במכונה מוגדרת, `failproofaid` הוא ההערכן היחיד. אם הוא לא יכול לענות, פעולות מוגנות נכשלות בצורה סגורה.

```bash
failproofai config --status
systemctl status failproofaid@$USER        # Linux
sudo launchctl print system/ai.failproof.failproofaid.$USER  # macOS
```

הרץ את `failproofai config` כדי לתקן או להתקין מחדש את השירות.

## חבילה אחת דוחה

`failproofai policies` מונה חבילות שלא ניתן לטעון. חבילה שנבחרה נכשלת בצורה סגורה במקום להיעלם.

סיבות נפוצות:

- ההיצע השתנה לאחר ההתקנה.
- המניפסט והמדיניויות המצורפות לא מסכימות.
- הקובץ חסר או לא ניתן לייבא אותו.
- החבילה משתמשת באירוע, כלי או צורת מדיניות שלא נתמכה.

הסר את החבילה או התקן גרסה מתוקנת:

```bash
failproofai policies remove owner/repo
failproofai policies add owner/repo@<release>
```

## ענן מנותק

יש להעדיף משתנה סביבה עבור המפתח:

```bash
export FAILPROOFAI_CLOUD_TOKEN="<key>"
failproofai config
failproofai config --status
```

מכונה יכולה למשוך מדיניויות ולשלוח פעילות באופן עצמאי. דוח סטטוס מציג את שניהם.

## מדיניות לא חסמה

בדוק שלוש דברים:

1. המדיניות פועלת: `failproofai policies`.
2. האירוע והכלי שלה תואמים את הפעולה.
3. ה-harness הזה יכול אכוף את האירוע.

דחיית קריאת כלים מאומתת על כל 12 ה-harnesses הנתמכים. אירועים אחרים משתנים. ראה [יכולת אכיפה](/he/reference/harnesses#enforcement-capability).

## הורדות חסומות

- `FAILPROOFAI_NO_DOWNLOAD=1` דוחה הורדות ברשת.
- `FAILPROOFAI_DAEMON_BASE_URL` מפנה הורדות שירות למראה.
- `FAILPROOFAI_PACK_BASE_URL` מפנה הורדות חבילה למראה.

חבילות מותקנות ממשיכות להאכוף כאשר הורדות מוגבלות.
