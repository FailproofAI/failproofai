בקש מה-Failproof Assistant לבצע כל משימה ב-Failproof AI בשפה טבעית. הוא יכול לנתח הפעלות וכשלים, להריץ שאילתות, לבנות לוחות מידע, לחקור הערכות והתראות, וסייע ביצירה והרצת ביקורות ללא צורך בתרגום המשימה לחסנים במוצר או פקודות CLI.

```text
Why did production checkout agents regress this week?
Build a dashboard for tool failures, latency, and evaluation scores.
Create an audit that finds agents retrying the same failed action without changing approach.
Show me the sessions behind the most common audit finding.
```

העוזר עובד עם הנתונים וההרשאות הזמינים בארגון הפעיל. בדוק את ההוכחות והשינויים המוצעים שלו לפני שחלת פעולות המשפיעות על משתמשים או agents אחרים.

## שאל את העוזר

<Tabs>
  <Tab title="Dashboard">
    1. בחר ב-**Open agent chat** ותאר מה אתה רוצה להבין, ליצור או להפעיל.
    2. בדוק את קריאות הכלי, הטבלאות ותוצאות השאילתה של העוזר בזמן שהוא עובד.
    3. פתח את ההפעלה, ההתראה או השאילתה שצוטטו כדי לאמת את התוצאה מול נתוני המקור.
    4. התחל שיחה חדשה לחקירה שונה, או השתמש בהיסטוריית הצ'ט כדי להמשיך את אותו קו ניתוח.

    ![העוזר בענן משיב לשאלת observability עם ניתוח ותוצאות שאילתה תומכות.](/images/dashboard/assistant.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp agent health
    fp agent models
    fp agent ask "Which production checkout agents had the most tool errors in the last 24 hours?"
    fp agent chats
    fp agent show <chat-id>
    fp agent ask "Open representative sessions" --chat <chat-id>
    ```

    השתמש ב-`fp agent rename <chat-id> --title <title>` כדי לשמור על חקירה מזוהה ו-`fp agent delete <chat-id>` להסרתה.
  </Tab>
</Tabs>

## עבודה יעילה עם העוזר

- תן לו מטרה תחילה; הוסף סביבה, זרימת עבודה או טווח זמן כאשר גבולות אלה חשובים.
- התייחס ל-SQL שנוצר וסיכומים כעזר בחקירה, לא כהוכחה סופית.
- פתח הפעלות נציגות לפני יצירת ביקורת, בעיה, התראה או מדיניות.
- שמור על מסננים ארגוניים, סביבה וזמן מפורשים.
- שמור SQL שימושי כשאילתה כדי שמפעיל אחר יוכל להעתיק את התוצאה.

<Warning>
  העוזר יכול לקרוא רק את מה שהמשתמש הנוכחי שלך יכול לגשת אליו. אל תרחיב הרשאות כדי שאלה תעבוד; בקש מאופרטור מורשה להריץ את החקירה במקום זאת.
</Warning>
