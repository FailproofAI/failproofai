Errors מעניק לך תצוגה מכוונת לכשלים על פני סשנים. קבץ לפי סוג שגיאה, agent, סביבה, מודל, כלי או חלון זמן כדי למצוא בעיות תפעול חוזרות.

## חקור שגיאות

<Tabs>
  <Tab title="Dashboard">
    1. עבור אל **Observe → Errors**.
    2. סנן לפי סביבה, סוג אירוע, סוג שגיאה, agent, session ID, או טקסט חיפוש.
    3. הרחב שגיאה מקובצת כדי לראות התרחשויות. בחר בשורה כדי לפתוח את האירוע המדויק בסשן שלו.
    4. בחר בפקד הפעמון בשגיאה מייצגת כדי להתחיל התראה לשגיאות דומות.

    ![עמוד Errors המציג היסטוגרמה כשל, שגיאות מקובצות, והפקד ליצירת התראה.](/images/dashboard/errors.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp errors --env production --since 24h
    fp errors --error-type TimeoutError --agent-id checkout-agent
    fp errors --aggregate --env production --since 7d
    ```

    השתמש ב-`fp events --full --session-id <id>` כאשר אתה זקוק ל-raw payload מאחורי סיכום שגיאה.
  </Tab>
</Tabs>

## השתמש ב-Errors כאשר אתה צריך ל

- מצא את מחלקת השגיאה השכיחה ביותר בייצור.
- קבע אם כלי או מודל אחד גורם לעלייה.
- קפוץ מספירת מצטברת אל סשנים מייצגים.
- צור התראה לחזרה על התרחשות.
- כלול את האוכלוסייה המושפעת בביקורת.

שגיאה היא אירוע שנצפה. הערכה כושלת היא שיפוט איכות, והממצא ביקורת הוא דפוס כשל שנחקר. שמור על הבחנות אלה כאשר אתה מחליט איזה זרימת עבודה תגובה להשתמש.
