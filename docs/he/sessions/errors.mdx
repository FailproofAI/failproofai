Errors מעניק לך תצוגה ממוקדת על כשלים על פני הפעלות. קבץ לפי סוג שגיאה, סוכן, סביבה, מודל, כלי או חלון זמן כדי למצוא בעיות תפעוליות חוזרות.

## חקור שגיאות

<Tabs>
  <Tab title="Dashboard">
    1. עבור אל **Observe → Errors**.
    2. סנן לפי סביבה, סוג אירוע, סוג שגיאה, סוכן, מזהה הפעלה או טקסט חיפוש.
    3. הרחב שגיאה מקובצת כדי לראות מופעים. בחר שורה כדי לפתוח את האירוע המדויק בהפעלה שלו.
    4. בחר את בקרת הפעמון בשגיאה מייצגת כדי להתחיל התראה לשגיאות דומות.

    ![עמוד Errors המציג היסטוגרמת כשל, שגיאות מקובצות, ובקרה ליצירת התראה.](/images/dashboard/errors.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp errors --env production --since 24h
    fp errors --error-type TimeoutError --agent-id checkout-agent
    fp errors --aggregate --env production --since 7d
    ```

    השתמש ב-`fp events --full --session-id <id>` כשאתה צריך את התשלום הגולמי מאחורי סיכום שגיאה.
  </Tab>
</Tabs>

## השתמש ב-Errors כאשר אתה צריך

- מצא את מחלקת השגיאה השכיחה ביותר בייצור.
- קבע אם כלי או מודל אחד גורם לעלייה.
- קפוץ מספירה מצטברת להפעלות מייצגות.
- צור התראה לחזרה על הופעות.
- כלול את האוכלוסייה המושפעת בביקורת.

שגיאה היא אירוע שנצפה. הערכה כושלת היא שיקול איכות, וממצא ביקורת הוא דפוס כשל שחקור. שמור על הבחנות אלו כאשר מחליטים איזה זרימת תגובה להשתמש.
