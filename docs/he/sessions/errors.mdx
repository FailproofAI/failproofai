Errors מעניק לך תצוגה ממוקדת על כשלים על פני הפעילויות. קבץ לפי סוג שגיאה, Agent, סביבה, מודל, כלי או חלון זמן כדי למצוא בעיות תפעוליות חוזרות.

## חקור שגיאות

<Tabs>
  <Tab title="Dashboard">
    1. עבור ל-**Observe → Errors**.
    2. סנן לפי סביבה, סוג אירוע, סוג שגיאה, Agent, מזהה הפעילות או טקסט חיפוש.
    3. הרחב שגיאה מקובצת כדי לראות התרחשויות. בחר שורה כדי לפתוח את האירוע המדויק בהפעילות שלו.
    4. בחר בבקרת הפעמון על שגיאה מייצגת כדי להתחיל התראה לשגיאות דומות.

    ![עמוד ה-Errors המציג היסטוגרמת כשלים, שגיאות מקובצות ובקרה ליצירת התראה.](/images/dashboard/errors.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp errors --env production --since 24h
    fp errors --error-type TimeoutError --agent-id checkout-agent
    fp errors --aggregate --env production --since 7d
    ```

    השתמש ב-`fp events --full --session-id <id>` כאשר אתה צריך את המטען הגולמי מאחורי סיכום שגיאה.
  </Tab>
</Tabs>

## השתמש ב-Errors כאשר אתה צריך ל

- מצא את מחלקת השגיאות השכיחה ביותר בייצור.
- קבע אם כלי או מודל אחד גורם לקפיצה.
- קפוץ מספירת מצטברת להפעילויות מייצגות.
- צור התראה על חזרה.
- כלול את האוכלוסייה המושפעת בביקורת.

שגיאה היא אירוע שנצפה. הערכה כושלת היא שיפוט איכות, ותוצאת ביקורת היא דפוס כשל שחקור. שמור על הבחנות אלו כאשר אתה מחליט איזו זרימת עבודה להגיב להשתמש בה.
