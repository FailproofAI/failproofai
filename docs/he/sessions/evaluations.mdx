הערכות מקוונות מיישמות שיקול דעת עקבי לשיחות של סוכנים. השתמש בהן לאותות שצריך למדוד ברציפות ולא רק בזמן ביקורת.

## סקור איכות הערכה

<Tabs>
  <Tab title="Dashboard">
    1. עבור אל **Observe → Evaluations**.
    2. הוסף סדרה ובחר את הסוכן, הסביבה, ציון ההערכה, הנתון וההעקומה.
    3. הוסף סדרות להשוואת סביבות, סוכנים או מפתחות ציון.
    4. בחר תוצאה כדי לפתוח הפעלות תואמות או שתף את התצוגה המסוננת. השתמש ב-**Observe → Metrics** לערכי השהיה, אסימונים, עלות וערכי גודל אחרים.

    ![לוח מחוונים איכות המציג ציוני הערכה ממוצעים והטרנדים לאורך זמן.](/images/dashboard/dashboard-quality.png)

    פתח הפעלה מהדקירה כדי לבדוק את הנימוקים לכל ציון:

    ![תצוגת פרטי הפעלה המציגה ציוני הערכה ונימוקים ליד העקבות המלאים.](/images/dashboard/session-detail.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp evals --agent-id checkout-agent --aggregate
    fp evals --aggregate --env production --status error
    fp evals --score helpfulness:0.8.. --since 7d
    ```

    הוסף `--json` גלובלי לפני `evals` לאוטומציה, לדוגמה `fp --json evals --aggregate --env production`.
  </Tab>
</Tabs>

מעריך מקבל את זהות ההפעלה, הסביבה, חותמות זמן ואירועים מסודרים. הוא יכול להחזיר מפתחות ציון מספריים עם נימוקים אופציונליים וסיכום. מעריכים בעלי ריצה ארוכה יכולים להחזיר עבודה תלויה ולהיבדק מאוחר יותר.

## יעדי הערכה טובים

- השלמת משימה או נכונות
- עוגנות וסיכון הזיה
- בחירת כלים ויעילות כלים
- ציות למדיניות או תהליך
- תקציבי עלות והשהיה
- הסלמה אנושית נדרשת

## מציון לתגובה

הצג ציונים בלוחות מחוונים כדי לעקוב אחר טרנדים. צור התראות לסף או תנאים מורכבים. כאשר ציון פוחת על פני אוכלוסייה, הפעל ביקורת כדי לחקור את הסיבה; כאשר הסיבה היא פעולה הניתנת לחזרה, פרוס מדיניות.
