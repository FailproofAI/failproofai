הערכות מקוונות מחילות שיקול דעת עקבי על סשנים של סוכנים. השתמש בהן לאותות שצריך למדוד בהמשכיות ולא רק במהלך ביקורת.

## בדוק את איכות ההערכה

<Tabs>
  <Tab title="Dashboard">
    1. עבור אל **Observe → Evaluations**.
    2. הוסף סדרה ובחר את הסוכן, הסביבה, ציון ההערכה, הסטטיסטיקה והעקומה.
    3. הוסף סדרות כדי להשוות בין סביבות, סוכנים או מפתחות ציון.
    4. בחר בתוצאה כדי לפתוח סשנים תואמים או לשתף את התצוגה המסוננת. השתמש ב-**Observe → Metrics** לערכי זמן תגובה, אסימונים, עלות וערכי גודל אחרים.

    ![לוח בקרה איכות המציג ציוני הערכה ממוצעים ומגמות לאורך זמן.](/images/dashboard/dashboard-quality.png)

    פתח סשן מ-drill-down כדי לבדוק את הנמקתו לכל ציון:

    ![תצוגת פרטי סשן המציגה ציוני הערכה והנמקה לצד העקיבוד המלא.](/images/dashboard/session-detail.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp evals --agent-id checkout-agent --aggregate
    fp evals --aggregate --env production --status error
    fp evals --score helpfulness:0.8.. --since 7d
    ```

    הוסף `--json` גלובלי לפני `evals` לאוטומציה, לדוגמה `fp --json evals --aggregate --env production`.
  </Tab>
</Tabs>

מעריך מקבל את זהות הסשן, הסביבה, הטימסטמפים והאירועים המסודרים. הוא יכול להחזיר מפתחות ציון מספריים עם הנמקה וסיכום אופציוניים. מעריכים שרצים זמן רב יכולים להחזיר עבודה בהמתנה ולהיות מתועדים מאוחר יותר.

## יעדי הערכה טובים

- השלמת משימה או נכונות
- הנסקה מקורות והסיכון להלוציה
- בחירת כלים ויעילות כלים
- עמידה בתקנות או בתהליכים
- תקציבי עלות וזמן תגובה
- הסקלמציה אנושית נדרשת

## מציון לתגובה

הצג ציונים בלוחות בקרה לתעקוב אחר מגמות. צור התראות לסף או תנאים מורכבים. כאשר ציון מידרדר בקבוצה אוכלוסייה, הפעל ביקורת כדי לחקור למה; כאשר הגורם הוא פעולה שניתן לחזור עליה, פרוס מדיניות.
