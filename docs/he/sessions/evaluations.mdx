הערכות מקוונות מחילות שיקול דעת עקבי על הפעלות של סוכנים. השתמש בהן לאותות שצריכים להימדד באופן רציף ולא להיחקר רק במהלך ביקורת.

## בדיקת איכות הערכה

<Tabs>
  <Tab title="Dashboard">
    1. עבור ל-**Observe → Evaluations**.
    2. הוסף סדרה ובחר את הסוכן, הסביבה, ציון ההערכה, הסטטיסטיקה והעקומה.
    3. הוסף סדרות כדי להשוות בין סביבות, סוכנים או מפתחות ציונים.
    4. בחר בתוצאה כדי לפתוח הפעלות תואמות או לשתף את התצוגה המסוננת. השתמש ב-**Observe → Metrics** עבור ערכים של זמן תגובה, tokenים, עלות וערכי גודל אחרים.

    ![לוח בקרה איכות המציג ממוצע ניקוד הערכות ומגמות לאורך זמן.](/images/dashboard/dashboard-quality.png)

    פתח הפעלה מהקידוד כלפי מטה כדי לבדוק את ההנמקה לכל ציון:

    ![תצוגת פרטי הפעלה המציגה ציוני הערכה והנמקה ליד העקבות המלאות.](/images/dashboard/session-detail.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp evals --agent-id checkout-agent --aggregate
    fp evals --aggregate --env production --status error
    fp evals --score helpfulness:0.8.. --since 7d
    ```

    הוסף `--json` גלובלי לפני `evals` להתאמה אוטומטית, לדוגמה `fp --json evals --aggregate --env production`.
  </Tab>
</Tabs>

מעריך מקבל את זהות ההפעלה, הסביבה, חותמות זמן והאירועים המסודרים. הוא יכול להחזיר מפתחות ציונים מספריים עם הנמקה אופציונלית וסיכום. מעריכים שרצים זמן רב יכולים להחזיר משימה בהמתנה ולהיחקר מאוחר יותר.

## יעדי הערכה טובים

- השלמת משימה או נכונות
- הנמקה וסיכון הזיה
- בחירת כלים ויעילות כלים
- עמידה בדיניות או תהליכים
- תקציבי עלות וזמן תגובה
- הנתמכה הנדרשת לאדם

## מציון לתגובה

הצג ציונים בלוחות בקרה כדי לעקוב אחר מגמות. צור התראות לסף או תנאים מורכבים. כאשר ציון יורד על פני אוכלוסייה, הפעל ביקורת כדי לחקור מדוע; כאשר הגורם הוא פעולה הניתנת לחזרה, פרוס מדיניות.
