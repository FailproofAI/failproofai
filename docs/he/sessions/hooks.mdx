hook הוא נקודה שבה agent מבקש מ-Failproof AI החלטה. רישום פעילות hook מתעד את האירוע, את ה-policy, את התוצאה ואת זמן ההערכה.

## חקרו פעילות hook

<Tabs>
  <Tab title="Dashboard">
    עברו אל **Observe → Hooks**. סננו לפי environment, event, agent או session.

    ![דף Hooks המציג latency מקובצת לפי שם hook ואירוע trigger.](/images/dashboard/hooks.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp guardrails summary --since 24h
    fp --json events --full --event-type hook_completed --session-id <session-id> --all --limit 500
    fp list hooks
    ```
  </Tab>
</Tabs>

כברירת מחדל, כל החלטה `deny` ו-`instruct` נשלחת במלואה. אפשרויות חוזרות מקובצות כדי להפחית רעש. הגדירו `collector.hooks_verbosity` ב-`~/.failproofai/config.json` ל-`all`, `decisions` או `off`.

<Warning>
  פעילות hook מוכיחה שהערכה רצה, לא שה-harness יכול היה לחסום את האירוע הזה. ראו [יכולת כפייה](/he/reference/harnesses#enforcement-capability). זוג harness-event שאינו מופיע אינו מאומת.
</Warning>
