אירועים בזמן אמת עוזרים לך לאשר כי הגדרת הקצה עובדת וצפה בהרצה בסיכון גבוה ללא צורך להמתין לסיום המושב.

## צפיה בפעילות

<Tabs>
  <Tab title="Dashboard">
    1. עבור אל **Observe → Events**.
    2. התחל עם חלון הזמן הנוכחי וללא מסננים כדי לאשר שנתונים מגיעים.
    3. סנן לפי סביבה, סוג אירוע, סוכן או מושב. השתמש בחיפוש לטקסט בעומס השליטה.
    4. בחר באירוע כדי לבדוק את הסיכום והפרטים שלו. עקוב אחר קישור המושב שלו כדי לראות את העקיבה המלאה.

    ![זרם אירועים חי המציג תעבורה משער שיחה Hermes לצד הרצות coding-CLI, מסונן לפי זמן, סביבה, סוג אירוע, סוכן, מודל, הקשר ומושב.](/images/dashboard/events-stream-current.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp events --env production --event-type tool_use,error --limit 100
    fp events --session-id <session-id> --order asc --all
    fp --json events --full --session-id <session-id> --all
    ```

    הזרם הדברתי מוגדר כברירת מחדל להשמיט עומסים גולמיים. השתמש ב-`--full` רק לחקירת מושב מוגבל.
  </Tab>
</Tabs>

השתמש בזרם האירועים כדי לענות על שלוש שאלות מיידיות:

- האם הסוכן הצפוי מדווח לסביבה הנכונה?
- האם קריאות מודל, קריאות כלים והחלטות מדיניות מגיעות בסדר?
- האם המושב הפסיק להתקדם או התחיל לחזור על אותה פעולה?

סוגי אירועים כוללים אירועי מחזור חיים של סוכנים, בקשות ותגובות של מודל, שימוש בכלים והתוצאות שלהם, ביצוע hook, המתנה אנושית והפסקות, וטעויות מפורשות. מזהי מתאם מחברים אירועים מזווגים כמו קריאת כלי והתוצאה שלה.

<Tip>
  שמור על התצוגה החיה כללית בעת אימות שילוב חדש. הוסף מסננים רק לאחר שאתה רואה את האירוע הראשון; מסנן שגוי יכול להיראות כאל כישלון בערגון.
</Tip>

אם לא מופיעים אירועים, הרץ `failproofai config --status`, ואז [פתור בעיות בערגון](/he/reference/troubleshooting).

סוכנים שלא פועלים באחד מ-12 [harnesses](/he/reference/harnesses) הנתמכים מדווחים על אותם סוגי אירועים דרך [Python SDK](/he/reference/custom-agents), כולל אירועי הלולאה האנושית (`human_wait`, `human_input`, `human_interrupt`) שסערי שער וסוכנים ייצור תלויים בהם.
