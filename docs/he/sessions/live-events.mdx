Live events מציג פעילות תוך כדי הרצת סוכנים: קריאות מודל, כלים, שגיאות, קלט אנושי, hooks והחלטות מדיניות.

## צפייה בפעילות

עברו אל **Observe → Live events**, או הריצו:

```bash
fp events --since 1h
fp events --event-type tool_use,tool_result --since 1h
fp --json events --full --session-id <session-id> --all --limit 2000
```

השתמשו ב-`--full` כאשר אתם צריכים את תוכן ה-payload. ה-feed הקל מהיר יותר ומספיק לרוב המסננים.

סוגי אירועים נפוצים כוללים:

- `session_start` ו-`session_end`
- `model_request` ו-`model_response`
- `tool_use` ו-`tool_result`
- `hook_triggered` ו-`hook_completed`
- `error`
- `human_wait` ו-`human_input`
- `agent_pause` ו-`agent_resume`

## אם אירועים לא מופיעים

```bash
failproofai flush --wait
failproofai config --status
failproofai backfill --since 30d --dry-run
```

הסביבה ברירת המחדל היא `local`. סינון עבור `production` מחזיר שום דבר עד שתשנו את תווית הסביבה.

לסוכן מחוץ לתמיכה harness, השתמשו ב-[Python SDK](/he/reference/custom-agents).
