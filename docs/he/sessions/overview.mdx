סשן הוא נקודת התחלה מעולה כאשר סוכן מתנהג בצורה בלתי צפויה. הוא משלב את בקשות המודל, התגובות, קריאות הכלים, האינטראקציות האנושיות, השגיאות, ההערכות והחלטות המדיניות השייכות להרצה אחת.

עקוב אחר הרצה אחת של סוכן מהמטרה שלו דרך קריאות מודל, כלים, והתגובה הסופית.

## מצא סשן

<Tabs>
  <Tab title="Dashboard">
    1. בסרגל הצד של Cloud, עבור אל **Observe → Sessions**.
    2. הגדר את חלון הזמן, ואז סנן לפי סביבה, סטטוס, סוכן, או מזהה סשן.
    3. הוסף טווחי ניקוד או מטריקה כאשר אתה זקוק לפרוסה של איכות, עלות, אסימון או זמן השהייה.
    4. בחר שורה כדי לפתוח את ה־trace שלה. השתמש בפקד ההעתקה ליד מזהה הסשן כאשר אתה משתף אותו.

    ![רשימת הסשנים המציגה שורה אחת לכל הרצה עם סינוני סביבה, סוכן, סטטוס וניקוד הערכה.](/images/dashboard/sessions-list.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp sessions --env production --since 24h
    fp sessions --status error,timeout --agent-id checkout-agent
    fp --json sessions --session-id <session-id>
    ```

    הוסף `--agents` להרחיב הרצות של מספר סוכנים, `--all` לעימוד, או `--fields` לבחירת עמודות פלט.
  </Tab>
</Tabs>

## מה אתה יכול לעשות

- מצא הרצה לפי סוכן, סביבה, זמן, מודל, סוג אירוע, או מצב שגיאה.
- עקוב אחר הרצף המדויק שייצר תוצאה.
- השווה הרצות שהצליחו והחזיקו בכישלון.
- פתח את הראיות המשמשות במציאת ביקורת או אירוע התראה.
- ייצא סשן כאשר אתה זקוק לרשומה לא מקוונת.

## סדר חקירה אמין

1. אשר את המטרה של הסשן וההסביבה.
2. מצא את השגיאה או ההחלטה הלא צפויה הראשונה—לא רק הכישלון הסופי.
3. בדוק את הקשר של המודל וקלט הכלי מיד לפניו.
4. בדוק ניסיונות חוזרים, זמן השהייה והפסקות אנושיות.
5. בחן ניקודי הערכה והחלטות מדיניות.
