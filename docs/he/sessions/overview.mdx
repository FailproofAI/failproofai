סשן הוא נקודת ההתחלה הטובה ביותר כאשר סוכן מתנהג באופן בלתי צפוי. הוא משלב את בקשות המודל, התגובות, קריאות הכלים, האינטראקציות האנושיות, השגיאות, ההערכות והחלטות המדיניות ששייכות להרצה אחת.

סשנים נראים זהים ללא קשר לאיזה מנגנון ייצר אותם. הרצת Claude Code שכותבת מחדש מאגר קוד, סוכן Hermes שעונה ללקוח ב-Slack, וסירות Python עם SDK מכווונות כולן לאותו פורמט עקיבה, כך שתצוגה אחת מכסה את כל הצי.

עקוב אחר הרצת סוכן אחת מהמטרה שלה דרך קריאות מודל, כלים, ותגובה סופית.

## מצא סשן

<Tabs>
  <Tab title="Dashboard">
    1. בסרגל הצד של Cloud, עבור אל **Observe → Sessions**.
    2. הגדר את חלון הזמן, ואז סנן לפי סביבה, סטטוס, סוכן, או מזהה סשן.
    3. הוסף טווחי ניקוד או מטרה כאשר אתה צריך חתך איכות, עלות, טוקן, או חביון.
    4. בחר שורה כדי לפתוח את העקיבה שלה. השתמש בבקרת ההעתקה ליד מזהה הסשן כאשר אתה שוקל אותו.

    ![רשימת הסשנים המציגה שורה אחת לכל הרצה עם מסננים של סביבה, סוכן, סטטוס, וניקוד הערכה.](/images/dashboard/sessions-list.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp sessions --env production --since 24h
    fp sessions --status error,timeout --agent-id checkout-agent
    fp --json sessions --session-id <session-id>
    ```

    הוסף `--agents` כדי להרחיב הרצות מרובות-סוכנים, `--all` כדי לדפדף, או `--fields` כדי לבחור עמודות פלט.
  </Tab>
</Tabs>

## מה אתה יכול לעשות

- מצא הרצה לפי סוכן, סביבה, זמן, מודל, סוג אירוע, או מצב שגיאה.
- עקוב אחר הרצף המדויק שהביא לתוצאה.
- השווה הרצות מוצלחות ושנכשלו.
- פתח את הראיות שהשתמשו בממצא ביקורת או תקרית התראה.
- ייצא סשן כאשר אתה צריך רשומה לא מקוונת.

## סדר חקירה אמין

1. אשר את מטרת הסשן והסביבה.
2. מצא את השגיאה הראשונה או ההחלטה בלתי צפויה - לא רק את הכישלון הסופי.
3. בדוק את הקשר של המודל וקלט הכלי מיד לפניו.
4. בדוק ניסיונות חוזרים, חביון, והפסקות אנושיות.
5. בדוק ניקוד הערכה והחלטות מדיניות.
