מפגש הוא נקודת ההתחלה הטובה ביותר כאשר סוכן מתנהג בצורה בלתי צפויה. הוא משלב את בקשות המודל, התגובות, קריאות הכלים, האינטראקציות האנושיות, השגיאות, הערכות והחלטות המדיניות השייכות לריצה אחת.

עקוב אחר ריצת סוכן אחת מהיעדה שלה דרך קריאות מודל, כלים, ותגובה סופית.

## חיפוש מפגש

<Tabs>
  <Tab title="לוח בקרה">
    1. בסרגל הצד של Cloud, עבור אל **Observe → Sessions**.
    2. הגדר את חלון הזמן, ואז סנן לפי סביבה, סטטוס, סוכן, או מזהה מפגש.
    3. הוסף טווחי ניקוד או מדדים כאשר אתה זקוק לחתך איכות, עלות, טוקן או עיכוב.
    4. בחר בשורה כדי לפתוח את העקבות שלה. השתמש בבקרת ההעתקה ליד מזהה המפגש כאשר אתה משתף אותו.

    ![רשימת המפגשים המציגה שורה אחת לכל ריצה עם סנני סביבה, סוכן, סטטוס וניקוד הערכה.](/images/dashboard/sessions-list.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp sessions --env production --since 24h
    fp sessions --status error,timeout --agent-id checkout-agent
    fp --json sessions --session-id <session-id>
    ```

    הוסף `--agents` כדי להרחיב ריצות ריבוי סוכנים, `--all` כדי לדפדף, או `--fields` כדי לבחור עמודות פלט.
  </Tab>
</Tabs>

## מה אתה יכול לעשות

- מצא ריצה לפי סוכן, סביבה, זמן, מודל, סוג אירוע, או מצב שגיאה.
- עקוב אחר הסדר המדויק שייצר תוצאה.
- השווה ריצות מוצלחות וכושלות.
- פתח את הראיות המשמשות ממצא ביקורת או אירוע התראה.
- ייצא מפגש כאשר אתה זקוק לרשומה לא מקוונת.

## סדר חקירה אמין

1. אשר את היעד והסביבה של המפגש.
2. מצא את השגיאה הראשונה או ההחלטה הבלתי צפויה - לא רק את הכישלון הסופי.
3. בדוק את הקשר של המודל ותשומת הכלים מיד לפניו.
4. בדוק ניסיונות חוזרים, עיכוב, והפסקות אנושיות.
5. סקור ניקודי הערכה והחלטות מדיניות.
