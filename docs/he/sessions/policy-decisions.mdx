## קריאת הצבה של observe

מצב Observe מריץ את המדיניות האמיתית וחותם כל החלטה `deny` או `instruct`. הסוכן עדיין מורשה להמשיך.

```bash
fp fleet deploy <machine> --add <policy>:observe
fp guardrails summary --since 24h --machine <machine>
fp fleet deploy <machine> --add <policy>:enforce
```

<Warning>
  `--add <policy>` בודד אוכף מיד כאשר למדיניות אין הצבה קיימת. הוסף `:observe` לצבירת צל.
</Warning>

רק החלטות שנצפו שאינן allow חותמות. קצר זמן חותם כ-allow, מכיוון שזה גם מה שקורה במצב enforce.

deny שנחתם אינו הוכחה שהערכה עצרה את הפעולה. denies של Tool-call מאומתים בכל 12 הערכות התומכות; אירועים אחרים משתנים. ראה [יכולת אכיפה](/he/reference/harnesses#enforcement-capability).

## חקור תוצאה לא צפויה

| מה שאתה רואה | בדוק |
| --- | --- |
| אין החלטות | `failproofai config --status` ואם ההפעלה מושהית |
| הרבה שלילות ללא שם מדיניות | [התנהגות כשל של מדיניות](/he/policies/failure-behavior) |
| כל פעולה מוגנת נדחית | האם שירות `failproofaid` בריא |
| deny שאתה לא יכול להשבית | `block-failproofai-commands` תמיד פעיל |
| אין נתונים עבור `--env production` | מכונות חדשות משתמשות בסביבה `local` |
