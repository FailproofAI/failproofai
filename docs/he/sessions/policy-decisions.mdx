החלטות מדיניות מסבירה מה עשה האכיפה. השתמש בה כדי לאמת הטלת שינויים, למדוד שיעור חסימה, ולמצוא פעילות ללא הגנה.

<Tabs>
  <Tab title="Dashboard">
    1. עבור אל **Observe → policy** ובחר את טווח הזמן ובאופן אופציונלי מכונה אחת.
    2. בדוק פעולות שהוערכו, חסימות, שיעור חסימה, החלטות Cloud, פעולות ללא הגנה ופעילות בעת השהייה.
    3. סנן את טבלת מיפוי המדיניות וודא הקצאות שפורסמו.
    4. בחר נקודה בגרף כדי לפתוח את ההחלטות ואת הסשנים שלהן.

    ![דף המדיניות המציג סה"כ החלטות, סינון מכונה, פעילות אכיפה לאורך זמן וטבלת מיפוי המדיניות.](/images/dashboard/policy-observe.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp events --event-type hook_completed --env production --since 24h
    fp events --search "deny" --since 24h
    failproofai config --status
    ```

    השתמש ב-`failproofai` למצב האכיפה המקומי של המכונה וב-`fp` לחקירת אירועים ב-Cloud.
  </Tab>
</Tabs>
