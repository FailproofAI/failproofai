החלטות מדיניות מסביר מה עשתה האכיפה. השתמשו בזה כדי לוודא השקה, למדוד שיעור חסימה, ולמצוא פעילות לא מוגנת.

<Tabs>
  <Tab title="Dashboard">
    1. עברו אל **Observe → policy** בחרו את טווח הזמן ובאופן אופציונלי מכונה אחת.
    2. בדקו פעולות שהוערכו, חסימות, שיעור חסימה, החלטות Cloud, פעולות לא מוגנות ופעילות בזמן השהייה.
    3. סננו את טבלת המיפוי של המדיניות ובדקו הקצאות שהוטמעו.
    4. בחרו בנקודת תרשים כדי לפתוח את ההחלטות והפעילויות שלהן.

    ![עמוד המדיניות המציג סה"כ החלטות, סנן מכונה, פעילות אכיפה לאורך זמן וטבלת מיפוי המדיניות.](/images/dashboard/policy-observe.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp events --event-type hook_completed --env production --since 24h
    fp events --search "deny" --since 24h
    failproofai config --status
    ```

    השתמשו ב-`failproofai` לסטטוס האכיפה המקומי של המכונה ו-`fp` לחקירת אירועי Cloud.
  </Tab>
</Tabs>
