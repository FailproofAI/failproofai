---

כלים מציג מה סוכנים קוראים, כמה פעמים קריאות נכשלות, ואילו הפעלות הם משפיעים.

שמות הכלים מגיעים מכל יחידת סוכן, כך שאותה יכולת עשויה להיות בעלת שמות שונים. לדוגמה, קריאת shell יכולה להופיע כ-`Bash`, `exec`, `Shell`, `terminal`, או `run_command`. הרץ `fp list tools` לפני בניית פילטר.

<Tabs>
  <Tab title="Dashboard">
    עבור אל **Observe → Tools**. סנן לפי סביבה, כלי, סוכן, או הפעלה.

    ![דף הכלים מציג פירוקים של זמן השהיה, הצלחה וכישלון, וחלוקת קריאות כלים.](/images/dashboard/tools.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list tools
    fp events --event-type tool_use,tool_result --since 24h
    fp errors --event-type tool_result --since 24h
    fp --json events --full --event-type tool_use,tool_result --session-id <session-id> --all --limit 2000
    ```

    השתמש ב-`--full` כשאתה צריך שדות payload כמו משך זמן לכל קריאה.
  </Tab>
</Tabs>

השתמש בדף זה כדי למצוא כשלים חוזרים, השוואה בין הרצות עובדות וכושלות, או אישור שכלי ממוקד במדיניות משמש בפועל.
