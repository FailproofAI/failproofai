---
title: "הפעל את בדיקת הכשל הראשונה שלך"
description: "צור ביקורת מלוח הבקרה של הענן או מה-fp CLI וסקור את הממצאים הראשונים שלה."
icon: "scan-search"
---

ביקורת הופכת קבוצה של הפעלות לממצאי כשל מדורגים המסוגלים בראיות. התחל בשאלת כשל צרה אחת.

<Tabs>
  <Tab title="Dashboard">
    <Steps>
      <Step title="פתח Audits">
        בסרגל הצד של הענן, עבור ל-**Analyze → Audits**. בחר **new audit**.
      </Step>
      <Step title="הגדר את הביקורת">
        הזן שם ויעד כשל ישיר, כגון "מצא הפעלות בייצור שחוזרות על אותה קריאת תשלום שנכשלה ללא שינוי קלט או הסלמה." בחר את הסוכן, הסביבה, חלון הזמן והלוח הזמנים. הוסף תיאור קצר והפנה ל-URL כאשר המבקר זקוק לחוקי זרימת העבודה שלך.
      </Step>
      <Step title="צור והמתן להפעלה">
        בחר **create audit**. ההפעלה הראשונה מתורבתת מיד. פתח את כרטיס הביקורת כדי לצפות בהעברה שלה מתורבת להפעלה להשלמה.
      </Step>
    </Steps>

    לאחר שההפעלה הושלמה, פתח ממצא וסקור את ראיות ההפעלה שלו. לאחר מכן תוכל להודות, להקצות, לדחות, להשתיק או לפתור אותו.

    ![ממצא ביקורת שהושלם המציג את תיאור הכשל שלו, הפעולה המומלצת, הראיות התומכות וההפעלות המושפעות.](/images/dashboard/audit-finding.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp audits create payment-retry-failures \
      --description "Find production sessions that retry a failed payment call without changing input or escalating" \
      --scope '{"environments":["production"]}' \
      --text "Escalate after two unchanged payment failures"

    fp audits list
    fp audits runs payment-retry-failures
    fp audits findings --audit payment-retry-failures
    fp audits finding <finding-id>
    ```

    הוסף הקשר התייחסות, ולאחר מכן רענן אותו כאשר המקור משתנה:

    ```bash
    fp audits context-set payment-retry-failures --url https://example.com/payment-runbook
    fp audits context-refresh payment-retry-failures
    fp audits run payment-retry-failures
    ```

    השתמש ב-`fp audits ack <finding-id>`, `fp audits assign <finding-id> --to <email>`, `fp audits dismiss <finding-id>`, `fp audits mute <finding-id>`, `fp audits resolve <finding-id>`, או `fp audits reopen <finding-id>` כדי להעביר ממצא דרך הקופה.
  </Tab>
</Tabs>

בשלב הבא, [מנע את הכשל הראשון שלך באמצעות מדיניות](/he/start/first-policy) עבור פעולה חזרה מרושמת.
