## שלוש שורות, כל framework

<CodeGroup>
```bash LangGraph
pip install 'failproofai-sdk[langgraph]'
```

```bash CrewAI
pip install 'failproofai-sdk[crewai]'
```

```bash LlamaIndex
pip install 'failproofai-sdk[llamaindex]'
```

```bash Pydantic AI
pip install 'failproofai-sdk[pydantic-ai]'
```

```bash Custom agents
pip install failproofai-sdk
```
</CodeGroup>

```python
import failproofai_sdk

failproofai_sdk.configure(environment="production")
failproofai_sdk.instrument()          # מזהה את ה-frameworks שיבאת

with failproofai_sdk.session():
    ...                               # קריאת הסוכן הקיימת שלך, ללא שינוי
```

אין דקורטורים על הפונקציות שלך, אין callback מועבר לקריאות שלך, אין ids מועבים דרך הקוד שלך. רק הקריאה בתוך ה-session שונה:

<Tabs>
  <Tab title="LangGraph">
    ```python
    graph.invoke({"messages": [HumanMessage("...")]})
    ```
  </Tab>
  <Tab title="CrewAI">
    ```python
    Crew(agents=[analyst, writer], tasks=[gather, summarise]).kickoff()
    ```
  </Tab>
  <Tab title="LlamaIndex">
    ```python
    await agent.run("...")        # תחת `async with failproofai_sdk.session():`
    ```
  </Tab>
  <Tab title="Pydantic AI">
    ```python
    agent.run_sync("...")
    ```
  </Tab>
  <Tab title="Custom agents">
    ```python
    with failproofai_sdk.agent("planner"):
        with failproofai_sdk.tool_call("search", input={"q": q}) as t:
            t.output = search(q)
    ```
  </Tab>
</Tabs>

ההתקנה הנוספת משדרגת את ה-**framework**. כל אדפטר נספק בחבילה הבסיסית, כך שפרויקט שכבר יש לו את ה-framework שלו לא צריך שום דבר נוסף בכלל.

## בדוק שהגיע

הפעל סשן אחד עם כלים, ואז פתח **Observe → Sessions** בחר את הסביבה שלך. ההפעלה תופיע כעקבות שנבנו מחדש.

אם כלום לא הגיע, אשר שהמכונה מחוברת עם `failproofai config --status`. ראה [Set up capture](/he/start/setup).

<Warning>
  אל תבדוק את ספירת הספרייה כדי לאשר משלוח. ה-daemon של Failproof אוספת ומוחקות כל אצווה תוך מילישניות, כך שקריאה שלה מתחרות בעם האספן ומראה הרבה פחות אירועים מאלה שפעלו.
</Warning>

## הבא

כל quickstart למעלה מקשר להנחיה המלאה שלו — מה מקליטים, אפשרויות, זרימה, שמות span, והבעיות שאנשים באמת פוגעים בהן. הם חיים תחת **Trace Agents → Plug in your agent**.
