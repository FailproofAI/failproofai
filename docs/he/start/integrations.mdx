## לפני שתתחיל

שני דברים שהנתיב הזה מניח, ואף אחד מהם לא מכוסה בקוד להלן:

| דרישה | סיבה |
| --- | --- |
| Python 3.10 או חדש יותר | הרצפה שה-SDK מכריז עליה. |
| מכונה שנקבעה עם `failproofai config` | הפקודה הזו מתקינה את daemon failproofaid, והדeamon הוא הדבר היחיד שמשלח את מה ש-SDK כותב. בלעדיו הביצים מצטברות בתיקיית spool ולעולם לא עוזבות. |

<Note>
  **הנתיב הזה מקליט; הוא לא כופה.** ה-SDK תופס את מה שה-agent שלך עשה. פוליטיקות נורות מ-hook בתוך CLI של agent, אז כפיית אכיפה על agent framework פירושה הכנסת hook לתוך ה-runtime שלך — ראה [Policies](/he/policies/overview).
</Note>

## שלוש שורות, כל framework

<CodeGroup>
```bash LangGraph
pip install 'failproofai-sdk[langgraph]'
```

```bash CrewAI
pip install 'failproofai-sdk[crewai]'
```

```bash LlamaIndex
pip install 'failproofai-sdk[llamaindex]'
```

```bash Pydantic AI
pip install 'failproofai-sdk[pydantic-ai]'
```

```bash Custom agents
pip install failproofai-sdk
```
</CodeGroup>

```python
import failproofai_sdk

failproofai_sdk.configure(environment="production")
failproofai_sdk.instrument()          # detects the frameworks you imported

with failproofai_sdk.session():
    ...                               # your existing agent call, unchanged
```

ללא decorators בפונקציות שלך, לא callback שמועבר לקריאות שלך, לא ids מתורגלים דרך הקוד שלך. רק הקריאה בתוך ה-session שונה:

<Tabs>
  <Tab title="LangGraph">
    ```python
    graph.invoke({"messages": [HumanMessage("...")]})
    ```
  </Tab>
  <Tab title="CrewAI">
    ```python
    Crew(agents=[analyst, writer], tasks=[gather, summarise]).kickoff()
    ```
  </Tab>
  <Tab title="LlamaIndex">
    ```python
    await agent.run("...")        # under `async with failproofai_sdk.session():`
    ```
  </Tab>
  <Tab title="Pydantic AI">
    ```python
    agent.run_sync("...")
    ```
  </Tab>
  <Tab title="Custom agents">
    ```python
    with failproofai_sdk.agent("planner"):
        with failproofai_sdk.tool_call("search", input={"q": q}) as t:
            t.output = search(q)
    ```
  </Tab>
</Tabs>

ההתקנה הנוספת מתקינה את ה-**framework**. כל adapter נושא בגלגל הבסיס, אז פרויקט שכבר יש לו את ה-framework שלו לא צריך כלום.

## בדוק שהגיע

הרץ session אחד מכויל, ואז פתח **Observe → Sessions** ובחר את ה-environment שלך. ההרצה מופיעה כ-trace משוחזר.

אם כלום לא הגיע, אשר שהמכונה מוגדרת ומחוברת עם `failproofai config --status`. אם היא לא, הרץ `failproofai config`. ראה [Choose your setup](/he/start/setup).

<Warning>
  אל תבדוק את תיקיית spool לאישור משלוח. ה-Failproof daemon אוסף ומוחק כל batch בתוך אלפיות שנייה, אז קריאה שלה מתחרה בקולט ומציגה הרבה פחות events מאשר נשלחו.
</Warning>

כדי להוכיח שה-SDK כותב בכלל, עצור תחילה את ה-daemon, ואז הרץ את ה-session שלך והסתכל ב-`~/.failproofai/custom-agents/events/`. כאשר ה-daemon רץ, תיקייה ריקה היא המצב הבריא.

<CodeGroup>
```bash Linux
sudo systemctl stop failproofaid@$USER
```

```bash macOS
sudo launchctl bootout system/ai.failproof.failproofaid.$USER
```
</CodeGroup>

הרץ `failproofai config` אחר כך להחזיר אותו. בזמן שה-daemon עצור, hook events במכונה הזו לא יש evaluator ודחויים, אז עצור אותו רק כמה זמן שהבדיקה לוקחת.
