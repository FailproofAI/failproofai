התחלה מהירה זו מגדירה מכונה אחת לדיווח הפעלות, מריצה ביקורת ויוצרת פריסה של מדיניות. השתמשו בכישוריות כדי להגדיר את Failproof AI, או עקבו אחר השלבים הידניים.

**איזה מסלול שלך?** אם הסוכן שלך פועל באחד מ-12 [harnesses](/he/reference/harnesses) הנתמכים — CLI קידוד, או gateway כמו Hermes או OpenClaw — עקבו אחר השלבים להלן; אתם זקוקים ל-Node.js 20.9 או חדש יותר. אם לסוכן שלך אין harness, אנו מציעים לכם להשתמש ב-[Python SDK](/he/reference/custom-agents) לכדי מעקב וביקורות, ואז חזרו אל [הריצה של בדיקת הכשל הראשונה שלכם](/he/start/first-audit); אכיפה בנתיב זה דורשת hook בזמן הריצה שלכם.

  <Tab title="הגדרה ידנית">
    ## לפני שאתם מתחילים

1. פתחו את [לוח הבקרה של Failproof AI](https://app.befailproof.ai) וצרו חשבון או התחברו עם דוא"ל שלך לעבודה.
2. עברו אל **Administration → Keys** וצרו מפתח עם `events:add` ו-`policies:pull`.
3. העתיקו את הסוד החד-פעמי ואחסנו בו על המכונה היעד:

```bash
export FAILPROOFAI_KEY="<one-time-secret>"
```

    ## התקנה

<Steps>
  <Step title="התקינו וחברו את Failproof AI">
    ```bash
    npm install -g failproofai
    failproofai config --connect https://app.befailproof.ai --token "$FAILPROOFAI_KEY"
    ```

    תמלילי הפעלות נשלחים כברירת מחדל. הוסיפו `--no-transcripts` כדי לדווח על פעילות hook והחלטות מדיניות ללא תוכן תמלילים.

    אם למכונה זו כבר יש היסטוריה של סוכן, הצג בחזקה ויבוא את שבעת הימים האחרונים, ואז חכו להשלמת המסירה. דלגו על שלב זה במכונה חדשה.

    ```bash
    failproofai backfill --since 7d --dry-run
    failproofai backfill --since 7d
    failproofai flush --wait
    ```

    פתחו את **Sessions** ב-Failproof AI ובחרו בהפעלה מיובאת.
  </Step>
  <Step title="התקינו hook ומדיניות סוכן">
    זה מחבר את Failproof AI ל-harness שלכם ומתקין את 40 המדיניות המובנות. השתמשו בהן כדי לראות החלטות מדיניות מקומיות ולנסות אכיפה לפני שFailproof AI מבקרת בהפעלות שלכם ורושמת מדיניות לסוכנים שלכם.

    תנו להתקנה לזהות את ה-harness שלכם, או שמו אחד בבירור. כל אחד מ-12 הוא ערך חוקי של `--cli` — `claude`, `codex`, `copilot`, `cursor`, `opencode`, `pi`, `hermes`, `openclaw`, `factory`, `devin`, `antigravity`, `goose`.

    ```bash
    failproofai policies --install --cli claude --scope user     # a coding CLI
    failproofai policies --install --cli hermes --scope user     # a Slack/Telegram gateway
    ```

    חסימת קריאת כלי לפני שהוא פועל מאומתת על כל 12. שערי סוף פנייה מאומתים ב-8 — ראו [יכולת אכיפה](/he/reference/harnesses#enforcement-capability) למטריקס לפי harness.
  </Step>
  <Step title="בדקו את ההתנהגות">
    עקבו אחר [הריצה של בדיקת הכשל הראשונה שלכם](/he/start/first-audit). השתמשו במטרה קונקרטית כמו "מצאו הפעלות שבהן הסוכן ניסה מחדש כלי שנכשל ללא שינוי בגישתו."
  </Step>
  <Step title="מנעו את הכשל">
    עקבו אחר [מנעו את הכשל הראשון שלכם עם מדיניות](/he/start/first-policy). התחילו במצב צפייה, בדקו התאמות, ואז אכוף את הגרסה שבדקתם.
  </Step>
</Steps>

<Check>

</Check>
