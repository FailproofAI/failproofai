ההתחלה המהירה הזו תקבל מכונה אחת המדווחת על הפעלות, תריץ ביקורת, ותפרוס מדיניות. השתמש בכישור כדי להגדיר את Failproof AI, או בצע את השלבים ידנית. אתה זקוק ל-Node.js 20.9 או גרסה מעדכנת יותר.

<Tabs>
  <Tab title="השתמש בכישור">
    <Steps>
      <Step title="התקן את כישורי Failproof AI">
        ```bash
        npx skills add FailproofAI/skills
        ```
      </Step>
      <Step title="בקש מה-agent שלך להגדיר הכל">
        ```text
        Set up Failproof AI for this project, connect this machine, install the right hooks and policies, and verify that a session arrives.
        ```

        ה-agent שלך בוחן את הפרויקט, בוחר את האינטגרציה הרלוונטית, מבצע את ההגדרה ומאמת אותה. ראה את [מאגר כישורי FailproofAI](https://github.com/FailproofAI/skills) כדי לקבל כישורים בודדים ואפשרויות התקנה מתקדמות.
      </Step>
    </Steps>
  </Tab>
  <Tab title="הגדרה ידנית">
    ## לפני שתתחיל

1. פתח את [לוח בקרת Failproof AI](https://app.befailproof.ai) וצור חשבון או התחבר עם דוא״ל עבודה.
2. עבור אל **Administration → Keys** וצור מפתח עם `events:add` ו-`policies:pull`.
3. העתק את הסוד החד-פעמי ושמור אותו במכונת היעד:

```bash
export FAILPROOFAI_KEY="<one-time-secret>"
```

    ## התקן

<Steps>
  <Step title="התקן וחבר את Failproof AI">
    ```bash
    npm install -g failproofai
    failproofai config --connect https://app.befailproof.ai --token "$FAILPROOFAI_KEY"
    ```

    תמלילי הפעלות נשלחים כברירת מחדל. הוסף `--no-transcripts` כדי לדווח על פעילות hook והחלטות מדיניות ללא תוכן תמלילים.

    אם למכונה זו יש כבר היסטוריית agent, סקור וייבא את שבעת הימים האחרונים, ואז חכה עד שהמסירה תסתיים. דלג על שלב זה במכונה חדשה.

    ```bash
    failproofai backfill --since 7d --dry-run
    failproofai backfill --since 7d
    failproofai flush --wait
    ```

    פתח את **Sessions** ב-Failproof AI בחר הפעלה שייובאה.
  </Step>
  <Step title="התקן agent hooks ומדיניויות">
    זה מצמיד את Failproof AI ל-CLI של ה-agent שלך ומתקין את המדיניויות המובנות. השתמש בהן כדי לראות החלטות מדיניות מקומיות וננסה אכיפה לפני שFailuproof AI מבצע ביקורת בהפעלות שלך וכותב מדיניויות עבור ה-agents שלך.

    תן להתקן לזהות את CLI של ה-agent שלך, או שם אחד במפורש.

    ```bash
    failproofai policies --install --cli claude --scope user
    ```
  </Step>
  <Step title="ערוך ביקורת בהתנהגות">
    עקוב אחר [הריצה של בדיקת הכשל הראשונה שלך](/he/start/first-audit). השתמש במטרה קונקרטית כגון "מצא הפעלות שבהן ה-agent ניסה שוב כלי כושל ללא שינוי בגישה שלו."
  </Step>
  <Step title="מנע את הכשל">
    עקוב אחר [מנע את הכשל הראשון שלך עם מדיניות](/he/start/first-policy). התחל במצב התבונה, בדוק התאמות, ואז אכוף את הגרסה שנבדקה.
  </Step>
</Steps>

<Check>
  הריצ `failproofai config --status`. הגדרה תקינה מדווחת על חיבור הענן, מצב ה-daemon, והאם האכיפה מושהית.
</Check>
