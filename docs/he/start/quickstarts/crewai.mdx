שלוש שלבים לעקבות CrewAI הראשונים שלך. לקבלת פרטים על כל אירוע, זרימות וטיפול בבעיות, ראה [את המדריך המלא](/he/start/integrations/crewai).

## התקנה

```bash
pip install 'failproofai-sdk[crewai]'
```

## כיול

```python
import failproofai_sdk

failproofai_sdk.configure(environment="production")
failproofai_sdk.instrument()

with failproofai_sdk.session():
    Crew(agents=[analyst, writer], tasks=[gather, summarise]).kickoff()
```

שום דבר בקבוצה, סוכנים, משימות או כלים שלך לא משתנה. `instrument()` מירתם לאוטובוס האירועים ברמת המודול של CrewAI.

## בדוק שהגיע

הרץ פעם אחת, ואז פתח **Observe → Sessions** ובחר את הסביבה שלך. ההרצה שלך מופיעה כעקבות משוחזר.

אם כלום לא הגיע, אשר שהמכונה מחוברת עם `failproofai config --status`.
