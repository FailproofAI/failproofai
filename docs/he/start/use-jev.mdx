Jev עוזר בשתי נקודות בהפעלת agent: לדרג session שהסתיים מול תשובות ידועות, או לבדוק קריאת כלי בהקשר של מה שביקשת מה-agent לעשות.

<Tabs>
  <Tab title="הערכות Jev">
    השתמש בהערכת Jev כשניתן לדרג session שהסתיים מול שאלה עם כמה תשובות ידועות, כמו "האם הלקוח ביקש החזר? ענה כן או לא." זה עוזר לך למצוא דפוסים ב-sessions.

    ## יצירת הערכה

    בדashboard בענן, פתח **Analyze → eval authoring → new eval**. הזן שאלה אחת בתשובה קבועה, בחר **draft**, וודא שבחרת ניקוד classifier. [בדוק אותה](/he/evaluations/test) על sessions אמיתיות, ואז הפעל אותה.

    ![טופס יצירת הערכה משותף שבו אתה מתאר שאלה, בודק את ה-draft, והופעל אותו. צילום זה מראה draft של קוד; השתמש בשאלה בתשובה קבועה עבור Jev.](/images/dashboard/eval-authoring-draft.png)

    ## קרא את הניקודים

    לאחר השלמת session חדש, פתח **Observe → Evaluations** או השתמש ב-Cloud CLI:

    ```bash
    fp evals --since 7d
    fp evals --aggregate --since 7d
    ```

    ה-CLI קורא ניקודים; יצירת הערכת Jev משתמשת כרגע בdashboard. ראה [הערכות Jev](/he/evaluations/jev) לסוגי שאלות ודוגמאות.
  </Tab>
  <Tab title="מדיניויות Jev">
    השתמש בבדיקת מדיניות Jev כשמדיניות התאמת strings צריכה את ההקשר של בקשתך כדי להחליט אם קריאת כלי בטוחה. התחל ב-mode **observe** כדי שתוכל לבדוק את התשובות של Jev בזמן שהמדיניויות המותקנות שלך עדיין מחליטות על כל קריאה.

    הבדיקות של Jev מגיעות מחבילה; Failproof AI לא משוגר עם אחת. עד שתתקין אותן, Jev לא שואל כלום, גם כשהוא מוגדר:

    ```bash
    failproofai policies add FailproofAI/jev-policies
    ```

    ## הגדר את Cloud Jev

    בdashboard בענן, פתח **Administration → Keys** ויצור מפתח עם ה-preset **machine**. השתמש בו עם `failproofai config` כפי שמוצג ב-[quickstart](/he/start/quickstart). במכונה ללא תצורת Jev קיימת, זה מפעיל את Cloud Jev ב-observe mode. בדוק את החיבור עם:

    ```bash
    failproofai jev status
    failproofai jev test
    ```

    ## השתמש בנקודת הקצה שלך

    בdashboard המקומי, פתח **Settings → Jev**. בחר את ה-provider, הדבק את ה-token שלו, בחר **observe**, והפעל את Jev.

    ![לוח הגדרות Jev המקומי עם provider, שדה token, וobserve mode נבחר.](/images/dashboard/jev-settings.png)

    או הגדר ובדוק את נקודת הקצה שלך מטרמינל:

    ```bash
    failproofai jev --url https://api.typesafe.ai/v1 --mode observe --key-stdin < ~/typesafe.key
    failproofai jev test
    ```

    בקש מ-agent בו נתקלת לשתמש בכלי קריאת הקבצים שלו ב-`README.md`. אשר שקריאת הכלי מופיעה ב-session, ואז בדוק אותה תחת **Policies → Activity** בdashboard המקומי. ברגע שתוצאות ה-observe נראות נכונות, [מדיניויות Jev](/he/policies/jev) מסבירה מתי להפעיל. לפרטי provider והגדרות, ראה את [reference ההשתלבות](/he/reference/jev).
  </Tab>
</Tabs>
