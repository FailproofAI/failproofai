Jev עוזר בשתי נקודות בהרצת סוכן: הערכת סשן שהסתיים מול תשובות ידועות, או סקירת קריאת כלים בהקשר של מה שביקשת מהסוכן לעשות.

<Tabs>
  <Tab title="הערכות Jev">
    השתמש בהערכת Jev כאשר ניתן להעריך סשן שהסתיים מול שאלה עם כמה תשובות ידועות, כמו "האם הלקוח ביקש החזר כספי? ענה כן או לא." זה עוזר לך למצוא דפוסים על פני סשנים.

    ## יצירת הערכה

    בלוח בקרה של Cloud, פתח **analyse → checks → new check** (או **new evaluation**). תאר שאלה אחת בעלת תשובה קבועה, בדוק את הכלל שהוא משרטט, ובדוק ש**איך הוא בודק** הוא **מודל ההחלטה** — זה Jev. [בדוק זאת](/he/evaluations/test) בסשנים אמיתיים, ואז הפעל אותה.

    ![טופס יצירת הערכה משותפת שבו אתה מתאר שאלה, בוחן את הטיוטה ופורסם אותה. צילום מסך זה מציג טיוטת קוד; השתמש בשאלה בעלת תשובה קבועה עבור Jev.](/images/dashboard/eval-authoring-draft.png)

    ## קריאת הציונים

    לאחר הסתיום של סשן חדש, פתח **analyse → checks → evals** ובחר בהערכה, או השתמש ב-Cloud CLI:

    ```bash
    fp evals --since 7d
    fp evals --aggregate --since 7d
    ```

    ה-CLI קורא ציונים; יצירת הערכת Jev משתמשת כרגע בלוח בקרה. ראה [הערכות Jev](/he/evaluations/jev) לסוגי שאלות ודוגמאות.
  </Tab>
  <Tab title="מדיניויות Jev">
    השתמש בסקירת מדיניות Jev כאשר מדיניות התאמת מחרוזות צריכה את הקשר של בקשתך כדי להחליט האם קריאת כלים בטוחה. התחל במצב **observe** כדי שתוכל לבדוק תשובות של Jev בזמן שהמדיניויות המותקנות שלך עדיין מחליטות על כל קריאה.

    בדיקות Jev מגיעות מחבילה; Failproof AI לא משלח אף אחת. עד שתתקין אותן, Jev לא שואל כלום, גם כשהוא מוגדר:

    ```bash
    failproofai policies add FailproofAI/jev-policies
    ```

    ## הגדרת Cloud Jev

    בלוח בקרה של Cloud, פתח **settings → api keys** וב**new key**, בחר **a machine running failproofai**. השתמש בו עם `failproofai config` כפי שמוצג ב[quickstart](/he/start/quickstart). במכונה ללא תצורת Jev קיימת, זה מאפשר Cloud Jev במצב observe. בדוק את החיבור עם:

    ```bash
    failproofai jev status
    failproofai jev test
    ```

    ## השתמש בנקודת הקצה שלך

    בלוח בקרה המקומי, פתח **Settings → Jev**. בחר את ספק השירות, הדבק את הטוקן שלו, בחר **observe**, והפעל את Jev.

    ![פאנל הגדרות Jev המקומי עם ספק שירות, שדה טוקן ומצב observe שנבחר.](/images/dashboard/jev-settings.png)

    או הגדר ובדוק את נקודת הקצה שלך מטרמינל:

    ```bash
    failproofai jev --url https://api.typesafe.ai/v1 --mode observe --key-stdin < ~/typesafe.key
    failproofai jev test
    ```

    בקש מסוכן מחובר להשתמש בכלי קריאת הקבצים שלו ב`README.md`. אשר שקריאת כלים זו מופיעה בסשן, ואז בדוק אותה תחת **Policies → Activity** בלוח בקרה המקומי. ברגע שתוצאות observe נראות נכון, [מדיניויות Jev](/he/policies/jev) מסבירות מתי לאכוף. לפרטי ספק ותצורה, ראה [התייחסות אינטגרציה](/he/reference/jev).
  </Tab>
