Jev עוזר בשתי נקודות בהפעלת סוכן: הערכת הפעלה סיימה מול תשובות ידועות, או סקירת קריאת כלי בהקשר של מה שביקשת מהסוכן לעשות.

<Tabs>
  <Tab title="הערכות Jev">
    השתמש בהערכת Jev כאשר הפעלה סיימה יכולה להיות מוערכת מול שאלה עם כמה תשובות ידועות, כגון "האם הלקוח ביקש החזר? ענה כן או לא." זה עוזר לך למצוא דפוסים על פני הפעלות.

    ## יצירת הערכה

    בדוח הענן, פתח **Analyze → eval authoring → new eval**. הזן שאלה אחת בעלת תשובה קבועה, בחר **draft**, ובדוק שהוא בחר ניקוד מסווג. [בדוק אותה](/he/evaluations/test) על הפעלות אמיתיות, ואז הפעל אותה.

    ![טופס הערכה משותף שבו אתה מתאר שאלה, בודק את הטיוטה והופך אותה. צילום מסך זה מציג טיוטת קוד; השתמש בשאלה בעלת תשובה קבועה עבור Jev.](/images/dashboard/eval-authoring-draft.png)

    ## קריאת הניקודים

    לאחר שהפעלה חדשה תסתיים, פתח **Observe → Evaluations** או השתמש ב-Cloud CLI:

    ```bash
    fp evals --since 7d
    fp evals --aggregate --since 7d
    ```

    ה-CLI קורא ניקודים; יצירת הערכת Jev משתמשת כרגע בדוח. ראה [הערכות Jev](/he/evaluations/jev) לסוגי שאלות ודוגמאות.
  </Tab>
  <Tab title="מדיניות Jev">
    השתמש בסקירת מדיניות Jev כאשר למדיניות המתאימה מחרוזת יש צורך בהקשר של הבקשה שלך כדי להחליט אם קריאת כלי היא בטוחה. התחל במצב **observe** כדי שתוכל לבדוק תשובות של Jev בזמן שהמדיניות המותקנות שלך עדיין מחליטות על כל קריאה.

    הבדיקות של Jev מגיעות מחבילה; Failproof AI לא משלחת אחת. עד שתתקין אותן, Jev לא שואל דבר, גם כאשר הוא מוגדר:

    ```bash
    failproofai policies add FailproofAI/jev-policies
    ```

    ## הגדר Cloud Jev

    בדוח הענן, פתח **Administration → Keys** ויצור מפתח עם הקבע **machine**. השתמש בו עם `failproofai config` כמוצג ב-[quickstart](/he/start/quickstart). במכונה ללא תצורת Jev קיימת, זה מאפשר Cloud Jev במצב observe. בדוק את החיבור עם:

    ```bash
    failproofai jev status
    failproofai jev test
    ```

    ## השתמש בנקודת הקצה שלך

    בדוח המקומי, פתח **Settings → Jev**. בחר את ספק השירות, הדבק את הטוקן שלו, בחר **observe**, והפעל את Jev.

    ![לוח הגדרות Jev המקומי עם ספק שירות, שדה טוקן ומצב observe שנבחר.](/images/dashboard/jev-settings.png)

    או הגדר ובדוק את נקודת הקצה שלך מטרמינל:

    ```bash
    failproofai jev --url https://api.typesafe.ai/v1 --mode observe --key-stdin < ~/typesafe.key
    failproofai jev test
    ```

    בקש מסוכן שנתפס לשימוש בכלי קריאת הקבצים שלו ב-`README.md`. אשר שקריאת כלי זו מופיעה בהפעלה, ואז בדוק אותה תחת **Policies → Activity** בדוח המקומי. לאחר שתוצאות ה-observe נראות נכון, [מדיניות Jev](/he/policies/jev) מסבירה מתי לאכוף. לפרטי ספק וקונפיגורציה, ראה את [התייחסות האינטגרציה](/he/reference/jev).
  </Tab>
