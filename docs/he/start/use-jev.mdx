Jev עוזר בשתי נקודות בהפעלת סוכן: הוא משמש לדירוג הפעלה שנסתיימה כנגד תשובות ידועות, או לבדיקת קריאת כלי בהקשר של מה שביקשת מהסוכן לעשות.

<Tabs>
  <Tab title="הערכות Jev">
    השתמש בהערכת Jev כאשר ניתן לדרג הפעלה שנסתיימה כנגד שאלה עם כמה תשובות ידועות, כגון "האם הלקוח ביקש החזר? ענה כן או לא." זה עוזר לך למצוא דפוסים על פני הפעלות.

    ## יצירת הערכה

    בלוח הבקרה של Cloud, פתח את **Analyze → eval authoring → new eval**. הזן שאלה בתשובה קבועה אחת, בחר **draft**, ובדוק שהוא בחר דירוג מסווג. [בדוק אותה](/he/evaluations/test) על הפעלות אמיתיות, ולאחר מכן פרוס אותה.

    ![טופס יצירת הערכה משותף שבו אתה מתאר שאלה, בודק את הטיוטה ופורס אותה. צילום מסך זה מציג טיוטת קוד; השתמש בשאלה בתשובה קבועה עבור Jev.](/images/dashboard/eval-authoring-draft.png)

    ## קריאת הדירוגים

    לאחר השלמת הפעלה חדשה, פתח את **Observe → Evaluations** או השתמש ב-Cloud CLI:

    ```bash
    fp evals --since 7d
    fp evals --aggregate --since 7d
    ```

    ה-CLI קורא דירוגים; יצירת הערכת Jev כרגע משתמשת בלוח הבקרה. ראה [הערכות Jev](/he/evaluations/jev) לסוגי שאלות ודוגמאות.
  </Tab>
  <Tab title="מדיניות Jev">
    השתמש בבדיקת מדיניות Jev כאשר מדיניות התאמה מחרוזת זקוקה להקשר של בקשתך כדי להחליט האם קריאת כלי היא בטוחה. התחל ב-**observe** mode כדי שתוכל לבדוק את התשובות של Jev בזמן שהמדיניות המותקנת שלך עדיין מחליטה על כל קריאה.

    הבדיקות של Jev מגיעות מחבילה; Failproof AI לא משלח אף אחת. עד שתעביד אותן, Jev לא שואל כלום, גם כשהוא מוגדר:

    ```bash
    failproofai policies add FailproofAI/jev-policies
    ```

    ## הגדר Cloud Jev

    בלוח הבקרה של Cloud, פתח את **Administration → Keys** וצור מפתח עם ההגדר המוגדר מראש של **machine**. השתמש בו עם `failproofai config` כמוצג ב-[quickstart](/he/start/quickstart). במכונה ללא תצורת Jev קיימת, זה מפעיל את Cloud Jev ב-observe mode. בדוק את החיבור עם:

    ```bash
    failproofai jev status
    failproofai jev test
    ```

    ## השתמש בנקודת הקצה שלך

    בלוח הבקרה המקומי, פתח את **Settings → Jev**. בחר את ספק השירות, הדבק את האסימון שלו, בחר **observe**, והדלק את Jev.

    ![לוח הבקרה של הגדרות Jev המקומיות עם ספק שירות, שדה אסימון, ו-observe mode שנבחר.](/images/dashboard/jev-settings.png)

    או הגדר ובדוק את נקודת הקצה שלך מטרמינל:

    ```bash
    failproofai jev --url https://api.typesafe.ai/v1 --mode observe --key-stdin < ~/typesafe.key
    failproofai jev test
    ```

    בקש מסוכן מחובר להשתמש בכלי קריאת הקבצים שלו על `README.md`. אשר שקריאת הכלי הזו מופיעה בהפעלה, ואז בדוק אותה תחת **Policies → Activity** בלוח הבקרה המקומי. ברגע שתוצאות ה-observe נראות נכונות, [מדיניות Jev](/he/policies/jev) מסבירה מתי להטיל. לפרטי ספק וקונפיגורציה, ראה את [ההפניה לשילוב](/he/reference/jev).
  </Tab>
