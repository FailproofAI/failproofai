Jev עוזר בשתי נקודות במהלך ריצת agent: הערכת שיעור שהסתיים מול תשובות ידועות, או בדיקת קריאת כלי בהקשר של מה שביקשת מה-agent לעשות.

<Tabs>
  <Tab title="הערכות Jev">
    השתמש בהערכת Jev כאשר שיעור שהסתיים יכול להיות מדורג מול שאלה עם כמה תשובות ידועות, כגון "האם הלקוח ביקש זיכוי? ענה כן או לא." זה עוזר לך למצוא דפוסים על פני שיעורים.

    ## יצירת הערכה

    בלוח המחוונים של Cloud, פתח את **Analyze → eval authoring → new eval**. הזן שאלה עם תשובה אחת קבועה, בחר **draft**, ובדוק שהוא בחר ניקוד מסווג. [בדוק אותה](/he/evaluations/test) על שיעורים אמיתיים, ואז פרוס אותה.

    ![טופס יצירת הערכות משותף שבו אתה מתאר שאלה, בוחן את ההטיוטה ופורס אותה. צילום המסך הזה מראה טיוטת קוד; השתמש בשאלה עם תשובה קבועה עבור Jev.](/images/dashboard/eval-authoring-draft.png)

    ## קריאת הניקודות

    לאחר השלמת שיעור חדש, פתח את **Observe → Evaluations** או השתמש ב-Cloud CLI:

    ```bash
    fp evals --since 7d
    fp evals --aggregate --since 7d
    ```

    ה-CLI קורא ניקודות; יצירת הערכת Jev כרגע משתמשת בלוח המחוונים. ראה [הערכות Jev](/he/evaluations/jev) לסוגי שאלות ודוגמאות.
  </Tab>
  <Tab title="מדיניויות Jev">
    השתמש בבדיקת מדיניות Jev כאשר מדיניות התאמה מחרוזות צריכה את ההקשר של בקשתך כדי להחליט אם קריאת כלי בטוחה. התחל במצב **observe** כך שתוכל לבדוק את התשובות של Jev בזמן שהמדיניויות המותקנות שלך עדיין קובעות כל קריאה.

    הבדיקות של Jev מגיעות מחבילה; Failproof AI לא משלחת אף אחת. עד שתתקין אותן, Jev לא שואל כלום, אפילו כאשר הוא מוגדר:

    ```bash
    failproofai policies add FailproofAI/jev-policies
    ```

    ## הגדרת Cloud Jev

    בלוח המחוונים של Cloud, פתח את **Administration → Keys** וצור מפתח עם ההגדרה המוקדמת **machine**. השתמש בו עם `failproofai config` כפי שמוצג ב[quickstart](/he/start/quickstart). במכונה ללא תצורת Jev קיימת, זה מאפשר Cloud Jev במצב observe. בדוק את החיבור עם:

    ```bash
    failproofai jev status
    failproofai jev test
    ```

    ## שימוש בנקודת הקצה שלך

    בלוח המחוונים המקומי, פתח את **Settings → Jev**. בחר את ספק השירותים, הדבק את האסימון שלו, בחר **observe**, והפעל את Jev.

    ![לוח ההגדרות המקומי של Jev עם ספק, שדה אסימון, ומצב observe שנבחר.](/images/dashboard/jev-settings.png)

    או קצה ובדוק את נקודת הקצה שלך מטרמינל:

    ```bash
    failproofai jev --url https://api.typesafe.ai/v1 --mode observe --key-stdin < ~/typesafe.key
    failproofai jev test
    ```

    בקש מ-agent מחובר להשתמש בכלי קריאת הקבצים שלו ב-`README.md`. אשר שקריאה זו מופיעה בשיעור, ואז בדוק אותה תחת **Policies → Activity** בלוח המחוונים המקומי. ברגע שתוצאות ה-observe נראות נכונות, [מדיניויות Jev](/he/policies/jev) מסבירות מתי להטיל. לפרטי ספק וקונפיגורציה, ראה את [הפניה לאינטגרציה](/he/reference/jev).
  </Tab>
