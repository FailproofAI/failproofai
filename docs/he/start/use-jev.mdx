Jev עוזר בשתי נקודות בהפעלת אגנט: תן ניקוד להפעלה שהסתיימה מול תשובות ידועות, או בדוק קריאת כלי בהקשר של מה שביקשת מהאגנט לעשות.

<Tabs>
  <Tab title="הערכות Jev">
    השתמש בהערכת Jev כאשר הפעלה שהסתיימה יכולה להיות מדורגת מול שאלה עם כמה תשובות ידועות, כגון "האם הלקוח ביקש החזר כסף? ענה כן או לא." זה עוזר לך למצוא דפוסים על פני הפעלות.

    ## יצירת הערכה

    בלוח הבקרה בענן, פתח **Analyze → eval authoring → new eval**. הזן שאלה בעלת תשובה קבועה אחת, בחר **draft**, ובדוק שבחר ניקוד מסווג. [בחן אותה](/he/evaluations/test) על הפעלות אמיתיות, ואז הפעל אותה.

    ![טופס יצירת הערכות משותפת שבו אתה מתאר שאלה, בודק את הטיוטה והופך אותה. צילום מסך זה מציג טיוטת קוד; השתמש בשאלה בעלת תשובה קבועה ל-Jev.](/images/dashboard/eval-authoring-draft.png)

    ## קריאת הניקודים

    לאחר שהפעלה חדשה הסתיימה, פתח **Observe → Evaluations** או השתמש ב-Cloud CLI:

    ```bash
    fp evals --since 7d
    fp evals --aggregate --since 7d
    ```

    ה-CLI קורא ניקודים; יצירת הערכת Jev משתמשת כרגע בלוח הבקרה. ראה [הערכות Jev](/he/evaluations/jev) לסוגי שאלות ודוגמאות.
  </Tab>
  <Tab title="מדיניות Jev">
    השתמש בסקירת מדיניות Jev כאשר מדיניות התאמה מחרוזות צריכה את ההקשר של הבקשה שלך כדי להחליט אם קריאת כלי בטוחה. התחל במצב **observe** כדי שתוכל לבדוק את התשובות של Jev בזמן שהמדיניות המותקנת שלך עדיין מחליטה על כל קריאה.

    הבדיקות של Jev מגיעות מחבילה; FailproofAI לא משלחת אף אחת. עד שתתקין אותן, Jev לא שואל כלום, אפילו כשהוא מוגדר:

    ```bash
    failproofai policies add FailproofAI/jev-policies
    ```

    ## הגדרת Cloud Jev

    בלוח הבקרה בענן, פתח **Administration → Keys** וצור מפתח עם ערכת ברירת המחדל **machine**. השתמש בו עם `failproofai config` כמוצג ב-[quickstart](/he/start/quickstart). במכונה ללא תצורת Jev קיימת, זה מאפשר Cloud Jev במצב observe. בדוק את החיבור עם:

    ```bash
    failproofai jev status
    failproofai jev test
    ```

    ## שימוש בנקודת הקצה שלך

    בלוח הבקרה המקומי, פתח **Settings → Jev**. בחר את הספק, הדבק את האסימון שלו, בחר **observe**, והפעל את Jev.

    ![לוח הגדרות Jev המקומי עם ספק, שדה אסימון ומצב observe שנבחר.](/images/dashboard/jev-settings.png)

    או הגדר ובחן את נקודת הקצה שלך מטרמינל:

    ```bash
    failproofai jev --url https://api.typesafe.ai/v1 --mode observe --key-stdin < ~/typesafe.key
    failproofai jev test
    ```

    בקש מאגנט מחובר להשתמש בכלי קריאת הקבצים שלו על `README.md`. אשר שקריאת כלי זו מופיעה בהפעלה, ואז בחן אותה תחת **Policies → Activity** בלוח הבקרה המקומי. ברגע שתוצאות observe נראות נכונות, [מדיניות Jev](/he/policies/jev) מסביר מתי להחיל. לפרטי ספק וקונפיגורציה, ראה את [התייחסות האינטגרציה](/he/reference/jev).
  </Tab>
