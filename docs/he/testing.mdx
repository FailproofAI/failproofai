## הרצת בדיקות

```bash
# הרץ את כל בדיקות היחידה פעם אחת
bun run test:run

# הרץ בדיקות יחידה במצב watch
bun run test

# הרץ בדיקות E2E (דורש התקנה - ראה בהמשך)
bun run test:e2e

# בדוק טיפוסים ללא בנייה
bunx tsc --noEmit

# Lint
bun run lint
```

### כתיבת בדיקת מדיניות יחידה

```typescript
import { describe, it, expect, beforeEach } from "vitest";
import { getBuiltinPolicies } from "../../src/hooks/builtin-policies";
import { allow, deny } from "../../src/hooks/policy-types";

describe("block-sudo", () => {
  const policy = getBuiltinPolicies().find((p) => p.name === "block-sudo")!;

  it("denies sudo commands", () => {
    const ctx = {
      eventType: "PreToolUse" as const,
      payload: {},
      toolName: "Bash",
      toolInput: { command: "sudo apt install nodejs" },
      params: { allowPatterns: [] },
    };
    expect(policy.fn(ctx)).toEqual(deny("sudo command blocked by failproofai"));
  });

  it("allows non-sudo commands", () => {
    const ctx = {
      eventType: "PreToolUse" as const,
      payload: {},
      toolName: "Bash",
      toolInput: { command: "ls -la" },
      params: { allowPatterns: [] },
    };
    expect(policy.fn(ctx)).toEqual(allow());
  });

  it("allows patterns in allowPatterns", () => {
    const ctx = {
      eventType: "PreToolUse" as const,
      payload: {},
      toolName: "Bash",
      toolInput: { command: "sudo systemctl status nginx" },
      params: { allowPatterns: ["sudo systemctl status"] },
    };
    expect(policy.fn(ctx)).toEqual(allow());
  });
});
```

## בדיקות end-to-end

בדיקות E2E מזמנות את הקובץ הבינארי `failproofai` האמיתי כתהליך משנה, משדרות מטען JSON אל stdin, וטוענות על פלט stdout וקוד יציאה. זה בוחן את נתיב האינטגרציה המלא שבו Claude Code משתמש.

### התקנה

בדיקות E2E מריצות את הקובץ הבינארי ישירות מקוד המאגר. לפני ההרצה הראשונה, בנו את ערימה CJS שקובצי hook מותאמים אישית משתמשים בה בעת ייבוא מ`'failproofai'`:

```bash
bun build src/index.ts --outdir dist --target node --format cjs
```

ואז הריצו את הבדיקות:

```bash
bun run test:e2e
```

בנו מחדש את `dist/` בכל פעם שתשנו את ה-API של ה-hook הציבורי (`src/hooks/custom-hooks-registry.ts`, `src/hooks/policy-helpers.ts`, או `src/hooks/policy-types.ts`).

### מבנה בדיקת E2E

```text
__tests__/e2e/
  helpers/
    hook-runner.ts      # הזמן את הקובץ הבינארי, משדר מטען JSON, תופס קוד יציאה + stdout + stderr
    fixture-env.ts      # תיקיות זמניות מבודדות לכל בדיקה עם קובצי קונפיגורציה
    payloads.ts         # מפעלות מטענים מדויקות ל-Claude לכל סוג אירוע
  hooks/
    builtin-policies.e2e.test.ts   # כל מדיניות builtin עם תהליך משנה אמיתי
    custom-hooks.e2e.test.ts       # טעינה והערכה של hook מותאם אישית
    config-scopes.e2e.test.ts      # מיזוג קונפיגורציה על פני project/local/global
    policy-params.e2e.test.ts      # הזרקת פרמטרים לכל מדיניות בעלת פרמטרים
```

### שימוש בעוזרי E2E

**`FixtureEnv`** - סביבה מבודדת לכל בדיקה:

```typescript
import { createFixtureEnv } from "../helpers/fixture-env";

const env = createFixtureEnv();
// env.cwd    - תיקיה זמנית; העביר כ-payload.cwd כדי לאסוף את .failproofai/policies-config.json
// env.home   - תיקיית home מבודדת; אין דליפה של ~/.failproofai אמיתי

env.writeConfig({
  enabledPolicies: ["block-sudo"],
  policyParams: {
    "block-sudo": { allowPatterns: ["sudo systemctl status"] },
  },
});
```

`createFixtureEnv()` רושם ניקוי `afterEach` באופן אוטומטי.

**`runHook`** - הזמן את הקובץ הבינארי:

```typescript
import { runHook } from "../helpers/hook-runner";
import { Payloads } from "../helpers/payloads";

const result = await runHook(
  "PreToolUse",
  Payloads.preToolUse.bash("sudo apt install nodejs", env.cwd),
  { homeDir: env.home }
);

expect(result.exitCode).toBe(0);
expect(result.parsed?.hookSpecificOutput?.permissionDecision).toBe("deny");
```

**`Payloads`** - מפעלות מטענים מוכנות:

```typescript
Payloads.preToolUse.bash(command, cwd)
Payloads.preToolUse.write(filePath, content, cwd)
Payloads.preToolUse.read(filePath, cwd)
Payloads.postToolUse.bash(command, output, cwd)
Payloads.postToolUse.read(filePath, content, cwd)
Payloads.notification(message, cwd)
Payloads.stop(cwd)
```

### כתיבת בדיקת E2E

```typescript
import { describe, it, expect } from "vitest";
import { createFixtureEnv } from "../helpers/fixture-env";
import { runHook } from "../helpers/hook-runner";
import { Payloads } from "../helpers/payloads";

describe("block-rm-rf (E2E)", () => {
  it("denies rm -rf", async () => {
    const env = createFixtureEnv();
    env.writeConfig({ enabledPolicies: ["block-rm-rf"] });

    const result = await runHook(
      "PreToolUse",
      Payloads.preToolUse.bash("rm -rf /", env.cwd),
      { homeDir: env.home }
    );

    expect(result.exitCode).toBe(0);
    expect(result.parsed?.hookSpecificOutput?.permissionDecision).toBe("deny");
  });

  it("allows non-recursive rm", async () => {
    const env = createFixtureEnv();
    env.writeConfig({ enabledPolicies: ["block-rm-rf"] });

    const result = await runHook(
      "PreToolUse",
      Payloads.preToolUse.bash("rm /tmp/file.txt", env.cwd),
      { homeDir: env.home }
    );

    expect(result.exitCode).toBe(0);
    expect(result.stdout).toBe("");  // allow → empty stdout
  });
});
```

### צורות תגובה של E2E

| החלטה | קוד יציאה | stdout |
|----------|-----------|--------|
| `PreToolUse` deny | `0` | `{"hookSpecificOutput":{"permissionDecision":"deny","permissionDecisionReason":"..."}}` |
| `PostToolUse` deny | `0` | `{"hookSpecificOutput":{"additionalContext":"Blocked ... because: ..."}}` |
| Instruct (non-Stop) | `0` | `{"hookSpecificOutput":{"additionalContext":"Instruction from failproofai: ..."}}` |
| Stop instruct | `2` | stdout ריק; סיבה ב-stderr |
| Allow | `0` | string ריק |

### קונפיגורציית Vitest

בדיקות E2E משתמשות ב`vitest.config.e2e.mts` עם:

- `environment: "node"` - אין צורך ב-browser globals
- `pool: "forks"` - בידוד תהליך אמיתי (בדיקות מזמנות תהליכי משנה)
- `testTimeout: 20_000` - 20 שניות לכל בדיקה (התחלת קובץ בינארי + הערכת hook)

ערימת `forks` חשובה: עובדים מבוססי חוט חולקים `globalThis`, מה שיכול להפריע לבדיקות שמזמנות תהליכי משנה. forks מבוססי תהליכים נמנעים מכך.
