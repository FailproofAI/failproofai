प्रशासन में एक टीम के पार Failproof AI को चलाने के लिए आवश्यक नियंत्रण शामिल हैं। अधिकांश पाठक Sessions, Audits, और Policies में रह सकते हैं; प्रशासक इस अनुभाग का उपयोग एक्सेस और ऑपरेटिंग सीमाओं को प्रबंधित करने के लिए करते हैं।

<Tabs>
  <Tab title="Dashboard">
    Cloud साइडबार के **Admin** अनुभाग का उपयोग करें **policy editor**, **enforcement**, **usage**, **keys**, **users**, और **settings** के लिए। एक लॉक किया गया आइटम दिखाता है कि आपके खाते को इसकी read permission नहीं है।

    ![Cloud साइडबार के Admin अनुभाग में policy editor, enforcement, usage, keys, users, और settings।](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    कमांड से पहले वैश्विक विकल्प रखें, उदाहरण के लिए `fp --org reliability-team --json usage`।
  </Tab>
</Tabs>
