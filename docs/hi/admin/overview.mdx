प्रशासन में एक टीम के भीतर Failproof AI को चलाने के लिए आवश्यक नियंत्रण होते हैं। अधिकांश पाठक Sessions, Audits, और Policies में रह सकते हैं; प्रशासक इस खंड का उपयोग पहुंच और परिचालन सीमाओं को प्रबंधित करने के लिए करते हैं।

<Tabs>
  <Tab title="Dashboard">
    Cloud साइडबार के **Admin** खंड का उपयोग करें **policy editor**, **enforcement**, **usage**, **keys**, **users**, और **settings** के लिए। एक लॉक किया गया आइटम दिखाता है कि आपके खाते में इसकी read permission नहीं है।

    ![Cloud साइडबार का Admin खंड policy editor, enforcement, usage, keys, users, और settings के साथ।](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    वैश्विक विकल्प को कमांड से पहले रखें, उदाहरण के लिए `fp --org reliability-team --json usage`।
  </Tab>
</Tabs>
