प्रशासन में Failproof AI को एक टीम में चलाने के लिए आवश्यक नियंत्रण होते हैं। अधिकांश पाठक Sessions, Audits और Policies में रह सकते हैं; प्रशासक इस अनुभाग का उपयोग पहुंच और परिचालन सीमाओं को प्रबंधित करने के लिए करते हैं।

<Tabs>
  <Tab title="Dashboard">
    Cloud साइडबार के **Admin** अनुभाग का उपयोग **policy editor**, **enforcement**, **usage**, **keys**, **users** और **settings** के लिए करें। एक लॉक किया गया आइटम दिखाता है कि आपके खाते में इसकी रीड अनुमति नहीं है।

    ![Cloud साइडबार के Admin अनुभाग में policy editor, enforcement, usage, keys, users और settings।](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    कमांड से पहले वैश्विक विकल्प रखें, उदाहरण के लिए `fp --org reliability-team --json usage`।
  </Tab>
</Tabs>
