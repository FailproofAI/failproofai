Failproof AI Cloud **सॉफ़्टवेयर के बारे में** उपयोग टेलीमेट्री अपने रखरखाव कर्ताओं को भेजता है। इसमें कभी आपके agents का डेटा शामिल नहीं होता है। Self-hosted install पर यह डिफ़ॉल्ट रूप से चालू होता है, और आप इसे बंद कर सकते हैं।

## क्या एकत्र किया जाता है

प्रत्येक event में पाँच dimensions होते हैं और कुछ भी ऐसा नहीं जो किसी व्यक्ति की पहचान करे:

| Dimension | उदाहरण | यह क्या है |
| --- | --- | --- |
| `product` | `agenteye` | कौन सा उत्पाद इसे भेजा |
| `component` | `dashboard`, `server`, `cli` | उत्पाद का कौन सा हिस्सा इसे भेजा |
| `app_version` | `0.0.1-beta.81` | आप जो build चला रहे हैं |
| `deployment_kind` | `self_hosted` | क्या यह customer install है, हमारा demo है, हमारा QA है, या dev machine है |
| `org_id` | एक UUID | कौन सी organization में action हुआ, एक opaque identifier के रूप में |

उन पर, events **क्या use किया गया था, कभी क्या इसमें था नहीं**: कौन सा पृष्ठ देखा गया (एक route pattern जैसे `/:org/sessions/:id`, कभी असली URL नहीं), कितने filters किस प्रकार के लागू किए गए, क्या एक action सफल रहा, और इसमें कितना समय लगा।

Slack app workspace connections और disconnections, account links, पूछे गए सवाल, posted charts, approval decisions, और एक fixed category से failures को record करता है। इसमें कभी Slack workspace, user, या channel IDs, email, सवाल, जवाब, SQL, या tokens शामिल नहीं होते।

### आपकी organization का नाम

Opaque `org_id` के साथ-साथ, हम आपकी organization का नाम, URL slug, और dashboard address एक बार record करते हैं, हर event पर नहीं बल्कि एक organization record पर। यह हमें बताता है कि जब हम adoption को देखते हैं या आपके द्वारा रिपोर्ट की गई समस्या की जांच करते हैं तो कौन सा pattern किस account का है। यह एक ही पहचान करने योग्य जानकारी है जो उत्पाद आपके बारे में भेजता है।

### आपके उपयोग की कुल संख्या

Server प्रत्येक organization के metered usage totals को report करता है, वही संख्याएं जो आप Usage page पर देखते हैं। ये केवल counts हैं: events, sessions, agents, environments, evaluation runs, scores, audit runs, saved queries, dashboards, alerts, issues, API keys, और members, साथ ही metering window की तारीखें। इनमें कोई identifiers, names, या query text नहीं हैं, और वे तब भी आते हैं जब कोई signed in न हो।

## क्या कभी एकत्र नहीं किया जाता है

- **कोई prompts, model responses, या event content नहीं**, न text के रूप में, न prefix, न ही hash
- **कोई session, agent, या trace identifiers नहीं**
- **कोई evaluator score names नहीं**
- **कोई error messages, exception text, या response bodies नहीं**, केवल एक status code और एक fixed list से एक category
- **कोई tool arguments, SQL, या query text नहीं**
- **कोई connected-app details नहीं।** एक MCP client को connect या revoke करना अधिकतम एक permission count भेजता है, कभी app का नाम या कोई token नहीं
- **कोई email addresses नहीं**
- **कोई referrer URLs या query strings नहीं**
- **कोई screen recording, DOM capture, या click और cursor tracking नहीं**

## Self-hosted install पर इसे बंद करें

Dashboard और server दोनों पर `DO_NOT_TRACK=1` set करें। वे अलग से decide करते हैं, इसलिए केवल एक पर सेट करने से दूसरा reporting छोड़ देता है। Change को apply करने के लिए server को restart करें।

आपकी release README अन्य opt-out settings और telemetry बंद होने की पुष्टि कैसे करें इसका वर्णन करती है।

## Opt out करने पर एक ping

यदि आप `DO_NOT_TRACK` के बजाय एक product setting के साथ opt out करते हैं, तो dashboard **एक anonymous ping** भेज सकता है जो record करता है, प्रति process start पर 1 में 1000 की probability के साथ। यह हमें बताता है कि कितने operators telemetry को बंद कर देते हैं। इसमें कोई identifiers नहीं हैं: कोई organization, user, hostname, URL, या IP नहीं, केवल product, component, version, deployment kind, और reason। Opted-out server कुछ नहीं भेजता है।

यह कभी नहीं भेजा जाता है जब आप `DO_NOT_TRACK` use करते हैं, यही कारण है कि वह setting use करने के लिए है यदि आपकी policy किसी भी outbound telemetry को forbid करती है।

## यह कहाँ जाता है

PostHog (`us.i.posthog.com`) को TLS पर port 443 पर। यह एक hostname है, इसलिए आप इसे एक single egress rule से भी block कर सकते हैं।

हम व्यक्तिगत जानकारी को अधिक व्यापक रूप से कैसे handle करते हैं, के लिए [privacy policy](https://befailproof.ai/privacy/) देखें।
