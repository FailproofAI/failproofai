उपयोग वर्तमान संगठन और उसकी बिलिंग विंडो के लिए खपत दिखाता है। इसका उपयोग यह समझने के लिए करें कि उत्पादन रोलआउट, ट्रांसक्रिप्ट वॉल्यूम, मूल्यांकन और ऑडिट आवृत्ति आपकी योजना को कैसे प्रभावित करते हैं।

## उपयोग की समीक्षा करें

<Tabs>
  <Tab title="Dashboard">
    1. **Administration → Usage** पर जाएं।
    2. संगठन और मीटरिंग विंडो की पुष्टि करें।
    3. इनजेस्ट, सेशन, मूल्यांकन, मेट्रिक्स, ऑडिट, निष्कर्ष, अलर्ट, उपयोगकर्ता और कुंजियों की समीक्षा करें।
    4. जब ऑडिट उपयोग अप्रत्याशित दिखे तो शुरू किए गए और पूर्ण किए गए ऑडिट कार्य की तुलना करें।

    ![उपयोग पृष्ठ जो मीटरिंग विंडो, कैप्चर की गई घटनाओं, मूल्यांकन और ऑडिट पाइपलाइन, वर्कस्पेस संसाधनों, सदस्यों और API कुंजियों को दिखा रहा है।](/images/dashboard/usage-overview.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp usage
    fp --json usage
    fp --org reliability-team --json usage
    ```
  </Tab>
</Tabs>

## परिवर्तन की जांच करें

1. सक्रिय संगठन और विंडो की पुष्टि करें।
2. पर्यावरण द्वारा सेशन वॉल्यूम के साथ वृद्धि की तुलना करें।
3. जांचें कि क्या कोई नया एकीकरण ट्रांसक्रिप्ट भेजना शुरू करता है।
4. मूल्यांकनकर्ता और ऑडिट आवृत्ति परिवर्तनों की समीक्षा करें।
5. वर्तमान मूल्य निर्धारण योजना की सीमाओं के विरुद्ध तुलना करें।

CLI स्क्रिप्ट के लिए समान सारांश देता है।
