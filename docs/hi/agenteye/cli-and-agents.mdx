आपकी संपूर्ण Failproof AI Observability deployment, एक कमांड की दूरी पर। Production को देखें, API key काटें, या incident को स्वीकार करें, सब कुछ अपने terminal से बाहर निकले बिना, फिर इसे CI में script करें, या एक coding agent को plain English में इसे करने दें।

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*`agenteye` CLI आपके dashboard से बात करता है। यह collector से एक अलग tool है, जो server को events भेजता है।*

## आपकी पूरी deployment, एक कमांड की दूरी पर

एक त्वरित सवाल का जवाब देने के लिए tab-hopping बंद करें। `agenteye` CLI आपके data को पढ़ता है और एक single binary से अपने org को manage करता है, इसलिए एक check जो पहले dashboard के through clicking का मतलब था, अब एक line बन जाता है जिसे आप rerun कर सकते हैं, alias कर सकते हैं, या runbook में paste कर सकते हैं। आपको चार surfaces मिलते हैं:

- **अपना data पढ़ें:** `sessions`, `events`, `evals`, और `errors`, time, agent, और environment के आधार पर filtered।
- **अपने org को manage करें:** `keys`, `users`, `settings`, `alerts`, और `incidents`।
- **Analytics चलाएं:** saved SQL plus एक ad-hoc `query` runner आपके event data पर।
- **Assistant से पूछें:** `agent ask` उसी read-only analyst तक पहुंचता है जिससे आप dashboard में chat करते हैं।

इसे एक बार `pipx` के साथ install करें, emailed 6-digit code के साथ sign in करें, और आप तैयार हैं। Session लगभग एक दिन तक रहता है; जब यह expire हो, तो `agenteye login` को rerun करें। Production को spot-check करने, key provision करने, या firing incident को triage करने के लिए इसे reach करें, सब कुछ browser खोले बिना:

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

जानने वाली एक आदत: global options जैसे `--json` command से पहले जाते हैं। `agenteye --json sessions` सही है; `agenteye sessions --json` नहीं है।

## इसे Script करें, CI में wire करें

हर command `--json` लेता है, और यह सब कुछ बदल देता है। Clean JSON stdout को जाता है जबकि human status और warnings stderr को जाते हैं, इसलिए एक `--json` capture सीधे `jq` में pipe हो जाता है बिना किसी stray line को strip किए। यह वह है जो CLI को आपके लिए prompt पर और एक coding agent के लिए output को parse करने के लिए equally अच्छा बनाता है:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

यह unattended चलाने के लिए बनाया गया है। Confirmation prompts auto-skip हो जाते हैं जब कोई terminal attached नहीं होता, इसलिए कुछ भी pipeline में hang नहीं होता, और हर command एक meaningful exit code return करता है: `0` success, `4` not logged in, `5` missing a permission (message इसे names करता है, उदाहरण के लिए `alerts:write`), `3` dashboard unreachable। एक script एक `4` पर reauthenticate करने के लिए या एक `5` पर branch कर सकता है ताकि आप बिल्कुल बता सकें कि admin से क्या मांगना है, blind fail करने के बजाय।

## एक coding agent को plain English में इसे drive करने दें

बेहतर है कि आपको इन flags में से किसी को भी याद रखना नहीं चाहिए। **CLI skill** एक small Agent Skill folder है जिसे `agenteye-cli` नाम दिया गया है जो एक coding agent जैसे Claude Code या Codex को plain-English requests से CLI को drive करना सिखाता है। "क्या आज कुछ broken है?" पूछें और agent command pick करता है, इसे आप के रूप में run करता है, और prose में जवाब देता है।

Claude Code के लिए, `agenteye-cli` folder को `~/.claude/skills/` में drop करें और यह auto-discovered होता है। Failproof AI Observability folder प्रदान करता है; install करने के लिए कोई extra नहीं है, क्योंकि यह केवल CLI को drive करता है जो आप पहले से install कर चुके हैं। पहले अपने आप को log in करें: skill emailed-code login को complete नहीं कर सकता है आपके लिए।

क्योंकि agent CLI को आप के रूप में run करता है, यह सब कुछ कर सकता है जो आपकी login permit करती है, reads और writes दोनों: keys create करें, settings बदलें, incidents resolve करें। CLI का "क्या आप सुनिश्चित हैं?" prompt agent के लिए fire नहीं होता है, इसलिए skill को exact command state करने और किसी भी change से पहले आपके OK की प्रतीक्षा करने के लिए लिखा जाता है। आप confirmation step हैं।

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

Reads instant रहते हैं, और हर write आपके लिए pause करता है:

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
