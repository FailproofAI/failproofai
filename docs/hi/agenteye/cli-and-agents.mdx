आपकी संपूर्ण Failproof AI Observability तैनाती, एक कमांड दूर। प्रोडक्शन की जांच करें, API कुंजी काटें, या अपने टर्मिनल से बाहर न निकले एक घटना को स्वीकार करें, फिर इसमें से कुछ भी CI में स्क्रिप्ट करें, या एक कोडिंग एजेंट को सादी अंग्रेजी में ऐसा करने दें।

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*`agenteye` CLI आपके डैशबोर्ड से बात करता है। यह कलेक्टर से एक अलग टूल है, जो सर्वर को इवेंट भेजता है।*

## आपकी संपूर्ण तैनाती, एक कमांड दूर

एक त्वरित सवाल का जवाब देने के लिए टैब-हॉपिंग बंद करें। `agenteye` CLI आपके डेटा को पढ़ता है और एक एकल बाइनरी से आपके संगठन का प्रशासन करता है, इसलिए एक जांच जो डैशबोर्ड के माध्यम से क्लिक करने का मतलब हुआ करता था वह एक पंक्ति बन जाती है जिसे आप पुनः चला सकते हैं, उपनाम दे सकते हैं, या एक रनबुक में पेस्ट कर सकते हैं। आपको चार सतहें मिलती हैं:

- **अपने डेटा को पढ़ें:** `sessions`, `events`, `evals`, और `errors`, समय, एजेंट और वातावरण द्वारा फ़िल्टर किए गए।
- **अपने संगठन का प्रबंधन करें:** `keys`, `users`, `settings`, `alerts`, और `incidents`।
- **विश्लेषण चलाएं:** सहेजी गई SQL और आपके इवेंट डेटा पर एक तदर्थ `query` रनर।
- **सहायक से पूछें:** `agent ask` उसी पढ़ने-केवल विश्लेषक तक पहुंचता है जिससे आप डैशबोर्ड में बात करते हैं।

इसे `pipx` के साथ एक बार स्थापित करें, एक ईमेल किए गए 6-अंकीय कोड के साथ साइन इन करें, और आप तैयार हैं। सत्र लगभग एक दिन तक रहता है; जब यह समाप्त हो जाए तो `agenteye login` को फिर से चलाएं। प्रोडक्शन को स्पॉट-जांचने, एक कुंजी प्रदान करने, या एक फायरिंग घटना को ट्रिएज करने के लिए इसे ब्राउज़र खोले बिना उपयोग करें:

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

जानने के लिए एक आदत: `--json` जैसे वैश्विक विकल्प कमांड से पहले जाते हैं। `agenteye --json sessions` सही है; `agenteye sessions --json` नहीं है।

## इसे स्क्रिप्ट करें, इसे CI में जोड़ें

प्रत्येक कमांड `--json` लेता है, और यह सब कुछ बदल देता है। स्वच्छ JSON stdout पर जाता है जबकि मानव स्थिति और चेतावनियां stderr पर जाती हैं, इसलिए एक `--json` कैप्चर सीधे `jq` में पाइप करता है कोई आवारा लाइन छिपाने के लिए। यह CLI को एक प्रॉम्प्ट पर आपके लिए और कोडिंग एजेंट के लिए आउटपुट पार्सिंग के लिए समान रूप से अच्छा बनाता है:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

यह बिना मानवीय हस्तक्षेप के चलाने के लिए बनाया गया है। पुष्टिकरण प्रॉम्प्ट स्वचालित रूप से छोड़ दिए जाते हैं जब कोई टर्मिनल जुड़ा नहीं होता, इसलिए कोई पाइपलाइन में हैंग नहीं करता, और प्रत्येक कमांड एक सार्थक निकास कोड लौटाता है: `0` सफलता, `4` लॉगिन नहीं, `5` अनुमति गायब (संदेश इसे नाम देता है, उदाहरण के लिए `alerts:write`), `3` डैशबोर्ड अनुपलब्ध। एक स्क्रिप्ट पुनः प्रमाणीकरण के लिए `4` पर शाखा कर सकता है या आपको बताने के लिए `5` पर कि एक व्यवस्थापक से क्या पूछना है, अंधे विफल होने के बजाय।

## एक कोडिंग एजेंट को इसे सादी अंग्रेजी में चलाने दें

और भी बेहतर, आपको इन झंडों में से कोई भी याद रखने की आवश्यकता नहीं होनी चाहिए। **CLI कौशल** `agenteye-cli` नामक एक छोटा Agent Skill फ़ोल्डर है जो Claude Code या Codex जैसे एक कोडिंग एजेंट को सादी-अंग्रेजी अनुरोधों से CLI को चलाना सिखाता है। "क्या आज कुछ टूटा है?" पूछें और एजेंट कमांड चुनता है, इसे आपके रूप में चलाता है, और गद्य में जवाब देता है।

Claude Code के लिए, `agenteye-cli` फ़ोल्डर को `~/.claude/skills/` में ड्रॉप करें और यह स्वचालित रूप से खोजा जाता है। Failproof AI Observability फ़ोल्डर प्रदान करता है; स्थापित करने के लिए कुछ अतिरिक्त नहीं है, क्योंकि यह केवल उस CLI को चलाता है जिसे आप पहले ही स्थापित कर चुके हैं। पहले स्वयं लॉगिन करें: कौशल ईमेल किए गए-कोड लॉगिन को आपके लिए पूरा नहीं कर सकता।

क्योंकि एजेंट CLI को आपके रूप में चलाता है, यह आपके लॉगिन की अनुमति देने वाली सब कुछ कर सकता है, पढ़ता और लिखता है: कुंजियां बनाएं, सेटिंग्स बदलें, घटनाओं को हल करें। CLI का "क्या आप सुनिश्चित हैं?" प्रॉम्प्ट एक एजेंट के लिए फायर नहीं करता, इसलिए कौशल सटीक कमांड बताने और किसी भी परिवर्तन से पहले आपके ठीक होने की प्रतीक्षा के लिए लिखा गया है। आप पुष्टिकरण कदम हैं।

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

पढ़ता तुरंत रहता है, और हर लिखना आपके लिए रुकता है:

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
