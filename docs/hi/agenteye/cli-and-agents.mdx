आपकी पूरी Failproof AI Observability डिप्लॉयमेंट, बस एक कमांड दूर। प्रोडक्शन चेक करें, API की जारी करें, या इंसिडेंट को स्वीकार करें — सब कुछ टर्मिनल छोड़े बिना करें, फिर इसे CI में स्क्रिप्ट करें या किसी कोडिंग एजेंट को सादी अंग्रेजी में यह काम करने दें।

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*`agenteye` CLI आपके डैशबोर्ड से बात करता है। यह कलेक्टर से एक अलग टूल है, जो सर्वर को इवेंट भेजता है।*

## आपकी पूरी डिप्लॉयमेंट, एक कमांड दूर

टैब-होपिंग बंद करें और एक क्विक सवाल का जवाब दें। `agenteye` CLI आपका डेटा पढ़ता है और एक ही बाइनरी से आपके ऑर्गनाइजेशन को प्रबंधित करता है, इसलिए एक चेक जो पहले डैशबोर्ड क्लिक करके करना पड़ता था, अब सिर्फ एक लाइन है जिसे आप फिर से चला सकते हैं, एलियास कर सकते हैं, या रनबुक में पेस्ट कर सकते हैं। आपको चार सर्फेस मिलते हैं:

- **अपना डेटा पढ़ें:** `sessions`, `events`, `evals`, और `errors`, समय, एजेंट और एनवायरनमेंट से फ़िल्टर किए गए।
- **अपने ऑर्गनाइजेशन को प्रबंधित करें:** `keys`, `users`, `settings`, `alerts`, और `incidents`।
- **एनालिटिक्स चलाएं:** सेव किए गए SQL और आपके इवेंट डेटा पर एक ad-hoc `query` रनर।
- **असिस्टेंट से पूछें:** `agent ask` उसी रीड-ओनली एनालिस्ट तक पहुंचता है जिसके साथ आप डैशबोर्ड में चैट करते हैं।

`pipx` से एक बार इंस्टॉल करें, एक ईमेल किए गए 6-डिजिट कोड से साइन इन करें, और आप तैयार हैं। सेशन लगभग एक दिन तक चलता है; जब यह एक्सपायर हो जाए तो `agenteye login` फिर से चलाएं। प्रोडक्शन को स्पॉट-चेक करने, एक की प्रोविजन करने, या फायरिंग इंसिडेंट को ट्रिएज करने के लिए इसका उपयोग करें — सब कुछ ब्राउजर खोले बिना:

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

एक आदत जानने योग्य है: ग्लोबल ऑप्शन जैसे `--json` कमांड से पहले जाते हैं। `agenteye --json sessions` सही है; `agenteye sessions --json` नहीं है।

## इसे स्क्रिप्ट करें, CI में वायर करें

हर कमांड `--json` लेता है, और वह सब कुछ बदल देता है। क्लीन JSON stdout पर जाता है जबकि मानव स्टेटस और चेतावनियां stderr पर जाती हैं, इसलिए एक `--json` कैप्चर सीधे `jq` में पाइप करता है और कोई खोया हुआ लाइन नहीं होता। यही है जो CLI को आपके लिए प्रॉम्प्ट पर और कोडिंग एजेंट के लिए आउटपुट पार्स करते समय समान रूप से अच्छा बनाता है:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

यह अनअटेंडेड चलने के लिए बनाया गया है। कन्फर्मेशन प्रॉम्प्ट ऑटो-स्किप करते हैं जब कोई टर्मिनल संलग्न नहीं होता, इसलिए कुछ भी पाइपलाइन में हैंग नहीं होता, और हर कमांड एक अर्थपूर्ण एक्जिट कोड रिटर्न करता है: `0` सफल, `4` लॉगिन नहीं, `5` अनुमति नहीं है (संदेश इसका नाम बताता है, उदाहरण के लिए `alerts:write`), `3` डैशबोर्ड अप्राप्य। एक स्क्रिप्ट `4` पर रीऑथेंटिकेट करने या `5` पर आपको बिल्कुल बताने के लिए शाखा कर सकता है कि एक एडमिन से क्या पूछना है, अंधेरे में विफल होने के बजाय।

## किसी कोडिंग एजेंट को सादी अंग्रेजी में इसे चलाने दें

और भी बेहतर, आपको इन फ्लैग्स को याद रखने की जरूरत नहीं होनी चाहिए। **CLI स्किल** एक छोटा Agent Skill फोल्डर है जिसका नाम `agenteye-cli` है जो एक कोडिंग एजेंट जैसे Claude Code या Codex को सादी-अंग्रेजी अनुरोधों से CLI चलाना सिखाता है। पूछें "क्या आज कुछ टूटा हुआ है?" और एजेंट कमांड को चुनता है, इसे आप के रूप में चलाता है, और गद्य में उत्तर देता है।

Claude Code के लिए, `agenteye-cli` फोल्डर को `~/.claude/skills/` में ड्रॉप करें और यह ऑटो-डिस्कवर होता है। Failproof AI Observability फोल्डर प्रदान करता है; इंस्टॉल करने के लिए कुछ अतिरिक्त नहीं है, क्योंकि यह केवल CLI को ड्राइव करता है जो आप पहले से इंस्टॉल कर चुके हैं। पहले स्वयं लॉगिन करें: स्किल आपके लिए ईमेल किए गए कोड लॉगिन को पूरा नहीं कर सकता।

क्योंकि एजेंट CLI को आप के रूप में चलाता है, यह सब कुछ कर सकता है जो आपका लॉगिन अनुमति देता है, पढ़ता और लिखता है: कुंजियां बनाएं, सेटिंग्स बदलें, इंसिडेंट हल करें। CLI का "क्या आप सुनिश्चित हैं?" प्रॉम्प्ट एजेंट के लिए फायर नहीं होता, इसलिए स्किल को सटीक कमांड स्टेट करना और किसी भी परिवर्तन से पहले आपकी OK की प्रतीक्षा करनी होती है। आप कन्फर्मेशन स्टेप हैं।

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

पढ़ना तुरंत रहता है, और हर लिखावट आपके लिए रुकता है:

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
