आपके engineers पहले से ही हर दिन OpenAI Codex चलाते हैं। Codex session capture उन कोडिंग सेशन को AgentEye में सामान्य सेशन और इवेंट के रूप में लाता है, ताकि आप उन्हें खोज सकें, replay कर सकें, और आप जो कुछ और देखते हैं उसके साथ मूल्यांकन कर सकें। यह [Python SDK](/hi/agenteye/python-sdk) को पूरक करता है: SDK उन agents को instrument करता है जो आप लिखते हैं, जबकि यह Codex कार्य को कैप्चर करता है जो आपकी टीम पहले से करती है — इसे चलाने के तरीके में कोई बदलाव नहीं।

एक छोटा background collector Codex के स्थानीय session transcripts को पढ़ता है जैसे वे लिखे जाते हैं और उन्हें AgentEye को भेजता है। एक मशीन प्रति collector एक साथ हर स्थानीय Codex surface को कैप्चर करता है — कोई per-surface setup नहीं है।

---

## यह क्या कैप्चर करता है

हर Codex surface जो **स्थानीय रूप से** चलता है, समान on-disk session transcripts बनाता है, और collector सभी को उठाता है:

- Codex **CLI** और `codex exec`
- **VS Code / IDE extension**
- **desktop app**, जब यह स्थानीय रूप से सेशन चलाता है

प्रत्येक Codex session एक AgentEye [session](/hi/agenteye/sessions) बन जाता है; इसके user और assistant messages, reasoning, tool calls, tool results, और token usage matching [events](/hi/agenteye/event-stream) बन जाते हैं। वह surface जहां से प्रत्येक session आया है (CLI, IDE, या desktop) दर्ज किया जाता है, ताकि आप उन्हें अलग बता सकें।

> **Cloud sessions कैप्चर नहीं किए जाते।** Desktop app तेजी से Codex cloud में sessions चलाता है और मशीन पर केवल उनके metadata रखता है — कोई local transcript नहीं है। केवल स्थानीय रूप से निष्पादित sessions कैप्चर किए जाते हैं।

---

## इसे चालू करें

Capture तब तक बंद है जब तक आप इसे सक्षम न करें। Collector को एक API key के साथ install करें जिसके पास `events:add` permission है ([API keys](/hi/agenteye/api-keys) देखें), और Codex capture चालू करें:

```bash
curl -fsSL https://raw.githubusercontent.com/FailproofAI/agenteye-collector/main/install.sh \
  | sh -s -- --key <YOUR_API_KEY> --codex-enabled
```

यह collector को install करता है, इसे background service के रूप में register करता है, और capture शुरू करता है। पुष्टि करें कि यह चल रहा है:

```bash
agenteye-collector health
```

पहली run पर, आपके मौजूदा Codex sessions एक बार backfill किए जाते हैं और नई activity फिर कुछ सेकंड में stream होती है। Codex की अपनी files को केवल read किया जाता है — कभी modified, moved, या deleted नहीं — और प्रत्येक session को बिल्कुल एक बार shipped किया जाता है, restarts के भी बाद।

---

## यह कहां दिखाई देता है

कैप्चर किए गए sessions **Sessions** में दिखाई देते हैं, और उनके events **Events** stream में, जैसे कि कोई अन्य agent जिसे आप देखते हैं — इसलिए [session replay](/hi/agenteye/sessions), [search](/hi/agenteye/queries), [evaluations](/hi/agenteye/evaluations), और [alerts](/hi/agenteye/alerts) सभी इन पर काम करते हैं। उन्हें अपने आप पर देखने के लिए Codex agent के अनुसार filter करें।

---

## गोपनीयता

Codex transcripts में पूरा session होता है — command output, file contents सहित, और कुछ भी जो Codex ने read या write किया — और में secrets हो सकते हैं। कैप्चर किए गए sessions को जैसे हैं वैसे ही shipped किया जाता है, इसलिए capture को केवल उन मशीनों पर और उन टीमों के लिए enable करें जहां उस content को AgentEye में centralize करना appropriate है, और collector को केवल `events:add` के लिए scoped key दें। देखें [Security](/hi/agenteye/security) कि आपके डेटा को कैसे isolated रखा जाता है।
