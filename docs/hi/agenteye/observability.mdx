observe सर्फेस वह जगह हैं जहाँ आप देख सकते हैं कि आपके agents अभी क्या कर रहे हैं और किसी भी एकल run में विस्तार से जानकारी प्राप्त कर सकते हैं। यहाँ सब कुछ लाइव है, आपके संगठन के दायरे में है, और तारीख की सीमा, वातावरण, agent और सेशन द्वारा फ़िल्टर किया जा सकता है, इसलिए आप "कुछ गलत लग रहा है" से लेकर सटीक run तक कुछ ही सेकंड में पहुँच सकते हैं।

![लाइव Event Stream, प्रकार के अनुसार रंग-कोडित और वातावरण, agent और सेशन द्वारा फ़िल्टर किया जा सकता है](/agenteye/images/events-stream.png)

चार सर्फेस, प्रत्येक का अपना पृष्ठ है:

- **[Event stream](/hi/agenteye/event-stream)**: हर agent के across हर run का लाइव, प्रति-स्टेप ट्रेल, सबसे नया पहले। आपका संगठन होम और triage के लिए पहला पड़ाव।
- **[Sessions और execution graph](/hi/agenteye/sessions)**: उन events को एक row में rolled up किया गया है प्रति run, साथ ही एक git-शैली की तस्वीर कि कैसे प्रत्येक run विकसित हुआ।
- **[Performance metrics](/hi/agenteye/telemetry)**: latency heat-maps और आपके models, tools और hooks के लिए p50/p95/p99 vitals, ताकि एक tail spike माध्यिका से अलग दिखे।
- **[Error tracking](/hi/agenteye/error-tracking)**: सब कुछ के लिए एक triage सर्फेस जो गलत हुआ, एक firing alert से broken run तक एक क्लिक की दूरी पर।

## संबंधित

- [Audits](/hi/agenteye/audits): Failproof AI Observability को आपके लिए sessions के across विफलता के पैटर्न खोजने दें।
- [CLI और agents](/hi/agenteye/cli-and-agents): आपके terminal से समान observability।
