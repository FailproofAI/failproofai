Observe सतहें वह स्थान हैं जहां आप देख सकते हैं कि आपके agents अभी क्या कर रहे हैं और किसी भी एक run में गहराई से जा सकते हैं। यहां सब कुछ लाइव है, आपके organization के दायरे में है, और date range, environment, agent और session द्वारा filterable है, ताकि आप "कुछ गलत लग रहा है" से लेकर सही run तक कुछ ही सेकंड में पहुंच सकें।

![लाइव Event Stream, type के अनुसार color-coded और environment, agent और session द्वारा filterable](/agenteye/images/events-stream.png)

चार सतहें, प्रत्येक का अपना page है:

- **[Event stream](/hi/agenteye/event-stream)**: हर agent के पार हर run का लाइव, प्रति-step trail, सबसे नया पहले। आपका org home और triage के लिए पहली stop।
- **[Sessions और execution graph](/hi/agenteye/sessions)**: ये events एक row में प्रति run के लिए rolled up हैं, साथ ही एक git-style चित्र है कि प्रत्येक run कैसे unfold हुआ।
- **[Performance metrics](/hi/agenteye/telemetry)**: latency heat-maps और आपके models, tools और hooks के लिए p50/p95/p99 vitals, ताकि एक tail spike median से अलग दिखे।
- **[Error tracking](/hi/agenteye/error-tracking)**: सब कुछ के लिए एक triage surface जो गलत हुआ, एक firing alert से लेकर run जो टूटा, सब एक क्लिक दूर है।
