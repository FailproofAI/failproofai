Observe सतहें वह हैं जहां आप अपने agents को अभी क्या कर रहे हैं यह देख सकते हैं और किसी भी एकल run में drill कर सकते हैं। यहां सब कुछ live है, आपके organization के लिए scoped है, और date range, environment, agent, और session के अनुसार filterable है, इसलिए आप "कुछ गलत लग रहा है" से exact run तक सेकंडों में पहुंच जाते हैं।

![The live Event Stream, colour-coded by type और environment, agent, और session के द्वारा filterable](/agenteye/images/events-stream.png)

चार सतहें, प्रत्येक के अपने page के साथ:

- **[Event stream](/hi/agenteye/event-stream)**: हर agent के साथ हर run का live, per-step trail, newest first। आपके org का home और triage के लिए पहला स्टॉप।
- **[Sessions and execution graph](/hi/agenteye/sessions)**: वे events एक row में rolled up, प्रति run, साथ ही एक git-style picture कि कैसे हर run unfold हुआ।
- **[Performance metrics](/hi/agenteye/telemetry)**: latency heat-maps और आपके models, tools, और hooks के लिए p50/p95/p99 vitals, तो एक tail spike median से अलग दिखता है।
- **[Error tracking](/hi/agenteye/error-tracking)**: सब कुछ जो गलत हुआ उसके लिए एक triage surface, एक click से एक firing alert से उस run तक जो टूट गया।

## संबंधित

- [Evaluations](/hi/agenteye/evaluations): हर run को quality के लिए score करें।
- [Alerts](/hi/agenteye/alerts): किसी भी threshold को एक paging rule में बदलें।
- [Audits](/hi/agenteye/audits): Failproof AI Observability को sessions में failure patterns खोजने दें।
- [CLI and agents](/hi/agenteye/cli-and-agents): आपके terminal से एक ही observability।
