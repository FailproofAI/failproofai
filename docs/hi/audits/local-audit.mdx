Failproof AI Cloud से मशीन को कनेक्ट करने से पहले तत्काल, निजी समीक्षा के लिए स्थानीय ऑडिट का उपयोग करें। यह आपकी मशीन पर पहले से संग्रहीत एजेंट इतिहास को स्कैन करता है, निर्मित नीतियों के माध्यम से टूल गतिविधि को फिर से चलाता है, और एक स्थानीय परिणाम डैशबोर्ड खोलता है।

## एक इंटरैक्टिव ऑडिट चलाएं

<Tabs>
  <Tab title="Dashboard">
    स्थानीय ऑडिट CLI से शुरू होता है क्योंकि इसे वर्तमान मशीन पर इतिहास खोजना होगा। `failproofai audit` चलाएं; स्कैन के बाद, Failproof AI बंडल किया गया डैशबोर्ड शुरू करता है और **http://localhost:8020/audit** खोलता है।

    ऑडिट दृश्य में, सत्रों, टूल कॉल, प्रोजेक्ट और नीति हिट की संख्या की समीक्षा करें। लगातार निष्कर्षों से शुरू करें, फिर प्रवर्तन सक्षम करने से पहले प्रभावित प्रोजेक्ट और एजेंट इतिहास का निरीक्षण करें।

    <Info>स्थानीय ऑडिट डैशबोर्ड Failproof AI Cloud में **विश्लेषण → ऑडिट** से अलग है। स्थानीय ऑडिट मशीन पर रहते हैं और किसी खाते या नेटवर्क कनेक्शन की आवश्यकता नहीं है।</Info>
  </Tab>
  <Tab title="CLI">
    ```bash
    npm install -g failproofai
    failproofai audit
    ```

    यह कमांड हर समर्थित इतिहास का एक पूर्ण स्कैन करता है जो इसे मिलता है। वर्तमान कमांड `--since`, `--cli`, `--project`, `--port`, या `--no-open` जैसे फ़िल्टर स्वीकार नहीं करता है।

    स्थानीय डैशबोर्ड का उपयोग करते समय प्रक्रिया को चलते रहने दें। समाप्त होने पर <kbd>Ctrl</kbd>+<kbd>C</kbd> दबाएं।
  </Tab>
</Tabs>

वर्तमान ऑडिट एडेप्टर Claude Code, Codex, GitHub Copilot CLI, Cursor, OpenCode, Pi, Hermes, OpenClaw, Factory, Devin, Antigravity और Goose से इतिहास पढ़ सकते हैं। केवल स्थानीय रूप से उपलब्ध इतिहास को स्कैन किया जाता है।

## आवर्ती स्थानीय ऑडिट शेड्यूल करें

<Tabs>
  <Tab title="Dashboard">
    स्थानीय डैशबोर्ड में **सेटिंग्स** खोलें, शेड्यूल किए गए ऑडिट सक्षम करें, अंतराल चुनें, और वह ईमेल पता सेट करें जिसे निष्कर्ष प्राप्त होने चाहिए। डैशबोर्ड और CLI एक ही मशीन कॉन्फ़िगरेशन को अपडेट करते हैं।
  </Tab>
  <Tab title="CLI">
    साप्ताहिक ऑडिट सक्षम करें और नाम के पते पर निष्कर्ष भेजें:

    ```bash
    failproofai audit --schedule 7 --email reliability@example.com
    failproofai audit --status
    ```

    अंतराल 1–90 दिनों को स्वीकार करता है और छोड़े जाने पर डिफ़ॉल्ट रूप से 7 होता है। पहला सेटअप आवश्यकतानुसार आपको साइन इन करता है; `--email` बिना संकेत दिए रिपोर्ट पता प्रदान करता है।

    स्थानीय ऑडिट इतिहास को हटाए बिना शेड्यूल को बंद करें:

    ```bash
    failproofai audit --no-schedule
    ```
  </Tab>
</Tabs>

डेमन पृष्ठभूमि में शेड्यूल किए गए स्कैन चलाता है, स्थानीय डैशबोर्ड द्वारा उपयोग किए जाने वाले कैश्ड परिणाम को रीफ्रेश करता है, और कॉन्फ़िगर की गई रिपोर्ट को ईमेल करता है। जब आप तुरंत एक इंटरैक्टिव स्कैन चलाना चाहते हैं तो `failproofai audit` का उपयोग करें।

## स्थानीय साक्ष्य से क्लाउड संचालन में जाएं

स्थानीय ऑडिट एक तेज़ आधार रेखा है। जब आपको साझा ट्रेस, आवर्ती जनसंख्या ऑडिट, निष्कर्ष और समस्याएं, सतर्कताएं, संगठन-व्यापी नीति तैनाती या बेड़े स्वास्थ्य की आवश्यकता हो तो मशीन को Failproof AI Cloud से कनेक्ट करें।
