Failproof AI Cloud से कनेक्ट करने से पहले तत्काल, निजी समीक्षा के लिए स्थानीय ऑडिट का उपयोग करें। यह आपकी मशीन पर पहले से संग्रहीत एजेंट इतिहास को स्कैन करता है, निर्मित नीतियों के माध्यम से टूल गतिविधि को दोहराता है, और एक स्थानीय परिणाम डैशबोर्ड खोलता है।

## एक इंटरैक्टिव ऑडिट चलाएं

<Tabs>
  <Tab title="Dashboard">
    स्थानीय ऑडिट CLI से शुरू होता है क्योंकि इसे वर्तमान मशीन पर इतिहास की खोज करनी चाहिए। `failproofai audit` चलाएं; स्कैन के बाद, Failproof AI बंडल किए गए डैशबोर्ड को शुरू करता है और **http://localhost:8020/audit** को खोलता है।

    ऑडिट दृश्य में, सत्रों की संख्या, टूल कॉल, प्रोजेक्ट और नीति हिट की समीक्षा करें। बार-बार होने वाले निष्कर्षों से शुरू करें, फिर प्रवर्तन सक्षम करने से पहले प्रभावित प्रोजेक्ट और एजेंट इतिहास का निरीक्षण करें।

    <Info>स्थानीय ऑडिट डैशबोर्ड Failproof AI Cloud में **Analyze → Audits** से अलग है। स्थानीय ऑडिट मशीन पर रहते हैं और खाते या नेटवर्क कनेक्शन की आवश्यकता नहीं है।</Info>
  </Tab>
  <Tab title="CLI">
    ```bash
    npm install -g failproofai
    failproofai audit
    ```

    कमांड हर समर्थित इतिहास का पूर्ण स्कैन करता है जो इसे मिलता है। वर्तमान कमांड `--since`, `--cli`, `--project`, `--port` या `--no-open` जैसे फ़िल्टर स्वीकार नहीं करता है।

    स्थानीय डैशबोर्ड का उपयोग करते समय प्रक्रिया को चलाते रहें। जब आप पूरा कर लें तो <kbd>Ctrl</kbd>+<kbd>C</kbd> दबाएं।
  </Tab>
</Tabs>

वर्तमान ऑडिट अनुकूलक Claude Code, Codex, GitHub Copilot CLI, Cursor, OpenCode, Pi, Hermes, OpenClaw, Factory, Devin, Antigravity और Goose से इतिहास पढ़ सकते हैं। केवल स्थानीय रूप से उपलब्ध इतिहास स्कैन किए जाते हैं।

## आवर्ती स्थानीय ऑडिट शेड्यूल करें

<Tabs>
  <Tab title="Dashboard">
    स्थानीय डैशबोर्ड में **Settings** खोलें, अनुसूचित ऑडिट सक्षम करें, अंतराल चुनें, और ईमेल पता सेट करें जिसे निष्कर्ष प्राप्त करने चाहिए। डैशबोर्ड और CLI समान मशीन कॉन्फ़िगरेशन को अपडेट करते हैं।
  </Tab>
  <Tab title="CLI">
    साप्ताहिक ऑडिट सक्षम करें और निष्कर्ष नामित पते पर भेजें:

    ```bash
    failproofai audit --schedule 7 --email reliability@example.com
    failproofai audit --status
    ```

    अंतराल 1–90 दिन स्वीकार करता है और जब छोड़ा जाए तो डिफ़ॉल्ट 7 है। पहली सेटअप आवश्यकतानुसार आपको साइन इन करता है; `--email` बिना संकेत दिए रिपोर्ट पता प्रदान करता है।

    स्थानीय ऑडिट इतिहास को हटाए बिना शेड्यूल को रोकें:

    ```bash
    failproofai audit --no-schedule
    ```
  </Tab>
</Tabs>

डेमॉन पृष्ठभूमि में अनुसूचित स्कैन चलाता है, स्थानीय डैशबोर्ड द्वारा उपयोग किए गए कैश किए गए परिणाम को ताज़ा करता है, और कॉन्फ़िगर की गई रिपोर्ट को ईमेल करता है। जब आप तुरंत एक इंटरैक्टिव स्कैन चलाना चाहते हैं तो `failproofai audit` का उपयोग करें।

## स्थानीय साक्ष्य से क्लाउड संचालन तक जाएं

स्थानीय ऑडिट एक तेज़ आधार है। जब आपको साझा ट्रेस, आवर्ती जनसंख्या ऑडिट, निष्कर्ष और समस्याएं, सतर्कताएं, संगठन-व्यापी नीति तैनाती, या बेड़े स्वास्थ्य की आवश्यकता हो तो मशीन को Failproof AI Cloud से कनेक्ट करें।

</Warning>
