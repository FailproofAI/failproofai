Failproof AI Cloud से मशीन को कनेक्ट करने से पहले तत्काल, निजी समीक्षा के लिए स्थानीय ऑडिट का उपयोग करें। यह आपकी मशीन पर पहले से संग्रहीत एजेंट इतिहास को स्कैन करता है, निर्मित नीतियों के माध्यम से टूल गतिविधि को दोहराता है, और एक स्थानीय परिणाम डैशबोर्ड खोलता है।

## इंटरैक्टिव ऑडिट चलाएँ

<Tabs>
  <Tab title="Dashboard">
    स्थानीय ऑडिट CLI से शुरू होता है क्योंकि इसे वर्तमान मशीन पर इतिहास की खोज करनी चाहिए। `failproofai audit` चलाएँ; स्कैन के बाद, Failproof AI बंडल डैशबोर्ड शुरू करता है और **http://localhost:8020/audit** खोलता है।

    ऑडिट दृश्य में, सत्रों, टूल कॉल, प्रोजेक्ट और नीति हिट की संख्या की समीक्षा करें। बार-बार होने वाले निष्कर्षों के साथ शुरू करें, फिर प्रवर्तन सक्षम करने से पहले प्रभावित प्रोजेक्ट और एजेंट इतिहास का निरीक्षण करें।

    <Info>स्थानीय ऑडिट डैशबोर्ड Failproof AI Cloud में **Analyze → Audits** से अलग है। स्थानीय ऑडिट मशीन पर रहते हैं और किसी खाते या नेटवर्क कनेक्शन की आवश्यकता नहीं है।</Info>
  </Tab>
  <Tab title="CLI">
    ```bash
    npm install -g failproofai
    failproofai audit
    ```

    कमांड उसे खोजे गए प्रत्येक समर्थित इतिहास की पूर्ण स्कैन करता है। वर्तमान कमांड `--since`, `--cli`, `--project`, `--port`, या `--no-open` जैसे फ़िल्टर स्वीकार नहीं करता है।

    स्थानीय डैशबोर्ड का उपयोग करते समय प्रक्रिया को चलाते रहें। समाप्त होने पर <kbd>Ctrl</kbd>+<kbd>C</kbd> दबाएँ।
  </Tab>
</Tabs>

वर्तमान ऑडिट एडेप्टर Claude Code, Codex, GitHub Copilot CLI, Cursor, OpenCode, Pi, Hermes, OpenClaw, Factory, Devin, Antigravity और Goose से इतिहास पढ़ सकते हैं। केवल स्थानीय रूप से उपलब्ध इतिहास स्कैन किए जाते हैं।

## आवर्ती स्थानीय ऑडिट शेड्यूल करें

<Tabs>
  <Tab title="Dashboard">
    स्थानीय डैशबोर्ड में **Settings** खोलें, शेड्यूल किए गए ऑडिट को सक्षम करें, अंतराल चुनें, और ईमेल पता सेट करें जो निष्कर्ष प्राप्त करना चाहिए। डैशबोर्ड और CLI एक ही मशीन कॉन्फ़िगरेशन को अपडेट करते हैं।
  </Tab>
  <Tab title="CLI">
    साप्ताहिक ऑडिट सक्षम करें और निष्कर्ष नामित पते पर भेजें:

    ```bash
    failproofai audit --schedule 7 --email reliability@example.com
    failproofai audit --status
    ```

    अंतराल 1–90 दिन स्वीकार करता है और छोड़े जाने पर डिफ़ॉल्ट रूप से 7 होता है। पहली सेटअप आवश्यकता होने पर आपको साइन इन करती है; `--email` संकेत दिए बिना रिपोर्ट पता प्रदान करता है।

    स्थानीय ऑडिट इतिहास को हटाए बिना शेड्यूल बंद करें:

    ```bash
    failproofai audit --no-schedule
    ```
  </Tab>
</Tabs>

डेमॉन पृष्ठभूमि में शेड्यूल किए गए स्कैन चलाता है, स्थानीय डैशबोर्ड द्वारा उपयोग किए गए कैश किए गए परिणाम को ताज़ा करता है, और कॉन्फ़िगर की गई रिपोर्ट को ईमेल करता है। जब आप तुरंत एक इंटरैक्टिव स्कैन चलाना चाहते हैं तो `failproofai audit` का उपयोग करें।

## स्थानीय साक्ष्य से क्लाउड संचालन में जाएँ

एक स्थानीय ऑडिट एक तेज़ आधारभूत है। जब आपको साझा ट्रेस, आवर्ती जनसंख्या ऑडिट, निष्कर्ष और समस्याएं, सचेतनाएँ, संगठन-व्यापी नीति परिनियोजन, या फ़्लीट स्वास्थ्य की आवश्यकता होती है तो मशीन को Failproof AI Cloud से कनेक्ट करें।
