```bash
failproofai
```

`http://localhost:8020` पर वेब डैशबोर्ड शुरू करता है।

## विकल्प

The dashboard takes no flags — `failproofai` rejects any it does not recognize. The port is fixed at `8020`.

डैशबोर्ड को एक गैर-डिफ़ॉल्ट Claude प्रोजेक्ट फ़ोल्डर की ओर इंगित करने के लिए, लॉन्च करते समय `CLAUDE_PROJECTS_PATH` पर्यावरण चर सेट करें।

## उदाहरण

```bash
failproofai

# पर्यावरण चर के माध्यम से कस्टम Claude प्रोजेक्ट पथ का उपयोग करें
CLAUDE_PROJECTS_PATH=~/my-claude-projects failproofai
```
