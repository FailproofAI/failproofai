## डैशबोर्ड

| चर | विवरण |
|----------|-------------|
| `PORT` | डैशबोर्ड पोर्ट (डिफ़ॉल्ट: `8020`) |
| `CLAUDE_PROJECTS_PATH` | Claude Code प्रोजेक्ट फ़ोल्डर्स को खोजने के लिए स्थान को ओवरराइड करें |
| `FAILPROOFAI_DISABLE_PAGES=policies,projects` | छिपाने के लिए अल्पविराम-अलग किए गए डैशबोर्ड पृष्ठ |
| `FAILPROOFAI_ALLOWED_DEV_ORIGINS` | डेव संसाधनों तक पहुंचने के लिए अनुमत होस्ट/IP। `--allowed-origins` के समान। |

## लॉगिंग

| चर | विवरण |
|----------|-------------|
| `FAILPROOFAI_LOG_LEVEL=info\|warn\|error` | सर्वर लॉग स्तर (डिफ़ॉल्ट: `warn`) |
| `FAILPROOFAI_HOOK_LOG_FILE` | कस्टम हुक लॉग फ़ाइल पथ, या डिफ़ॉल्ट के लिए `true` (`~/.failproofai/logs/hooks.log`) |

## टेलीमेट्री

failproofai डिफ़ॉल्ट रूप से अनाम उपयोग टेलीमेट्री की रिपोर्ट करता है। इसे बंद करने के दो तरीके हैं, और वे अधिक प्रतिबंधक को हल करते हैं — एक पर्यावरण चर कभी भी कुछ फिर से सक्षम नहीं कर सकता जिसे कॉन्फ़िगरेशन फ़ाइल ने बंद कर दिया है।

| चर | विवरण |
|----------|-------------|
| `FAILPROOFAI_TELEMETRY_DISABLED=1` | इस प्रक्रिया के लिए अनाम उपयोग टेलीमेट्री को अक्षम करें |

इसे मशीन के लिए स्थायी रूप से अक्षम करने के लिए, इसे `~/.failproofai/config.toml` में जोड़ें:

```toml
[telemetry]
enabled = false
```

<Note>
कॉन्फ़िगरेशन फ़ाइल यह विकल्प है यदि आप **failproofaid daemon** चलाते हैं।
डेमॉन एक सिस्टम-स्कोप सेवा है, और इसके पर्यावरण में आपके शेल से निर्यात किए गए चर शामिल नहीं हैं — इसलिए `FAILPROOFAI_TELEMETRY_DISABLED` इस तक नहीं पहुंच सकता। `[telemetry] enabled = false` को CLI और डेमॉन दोनों द्वारा पढ़ा जाता है।
</Note>

डेमॉन केवल अपने **जीवनचक्र** की रिपोर्ट करता है: कि यह शुरू हुआ (और क्या पिछली रन ने स्वच्छ तरीके से बंद की), कि यह रुक गया, जब इसका मूल्यांकन कार्यकर्ता को स्पॉन या पुनः शुरू किया गया था, जब एक कलेक्टर कार्य विफल हुआ, और एक क्लाउड-नीति पुल का परिणाम। ये कम-कार्डिनैलिटी मान और गणना करते हैं — कभी कोई फ़ाइल पथ, कमांड, नीति, प्रॉम्प्ट, या ट्रांसक्रिप्ट से कुछ भी पढ़ा नहीं। कोई प्रति-टूल-कॉल इवेंट नहीं है।

## प्रमाणीकरण

| चर | विवरण |
|----------|-------------|
| `FAILPROOF_API_URL` | डैशबोर्ड auth डायलॉग द्वारा उपयोग किए गए api-server आधार URL को ओवरराइड करें। डिफ़ॉल्ट `https://api.befailproof.ai` है; एक स्थानीय api-server चलाते समय `http://localhost:8080` (या कहीं और) पर सेट करें। |
| `FAILPROOFAI_AUTH_DIR` | `auth.json` को स्टोर किए जाने के स्थान को ओवरराइड करें (डिफ़ॉल्ट: `~/.failproofai`)। अधिकतर पृथक परीक्षणों के लिए उपयोगी। |

## पहली बार चलाने वाली प्रॉम्प्ट

| चर | विवरण |
|----------|-------------|
| `FAILPROOFAI_NO_FIRST_RUN=1` | प्रॉम्प्ट को छोड़ें जो पहली बार failproofai आह्वान पर नीतियों को स्थापित करने की पेशकश करता है |

## LLM (नीति मूल्यांकन के लिए)

| चर | विवरण |
|----------|-------------|
| `FAILPROOFAI_LLM_BASE_URL` | LLM API एंडपॉइंट (डिफ़ॉल्ट: `https://api.openai.com/v1`) |
| `FAILPROOFAI_LLM_API_KEY` | LLM-संचालित नीतियों के लिए API कुंजी |
| `FAILPROOFAI_LLM_MODEL` | मॉडल नाम (डिफ़ॉल्ट: `gpt-4o-mini`) |
