एक कमांड में अपने कोडिंग एजेंट को संपूर्ण Failproof AI संदर्भ जोड़ें। Claude Code, Cursor, Windsurf और किसी भी अन्य एजेंट के साथ काम करता है जो कौशल का समर्थन करते हैं।

```bash
npx skills add https://docs.befailproof.ai
```

`npx skills` यह पहचानता है कि आपके पास कौन से एजेंट स्थापित हैं और प्रत्येक के लिए सही प्रारूप में कौशल को स्वचालित रूप से जोड़ता है।

## स्किल क्या कवर करता है

| क्षेत्र | क्या शामिल है |
|------|----------------|
| पॉलिसीज़ | अंतर्निर्मित पॉलिसी नाम, इवेंट प्रकार, पैरामीटर, सक्षम/अक्षम करना |
| कस्टम पॉलिसीज़ | `customPolicies.add()`, मैच फिल्टर, `allow`/`deny`/`instruct` API |
| Context ऑब्जेक्ट | `ctx.eventType`, `ctx.toolName`, `ctx.toolInput`, `ctx.session` |
| कॉन्फ़िगरेशन | `policies-config.json` संरचना, स्कोप मर्जिंग, `policyParams` |
| CLI | `failproofai policies --install`, `--uninstall`, `--custom`, स्कोप |
| डैशबोर्ड | सेशन व्यूअर, पॉलिसी गतिविधि, एनवायरनमेंट वेरिएबल्स |
| आर्किटेक्चर | हुक हैंडलर प्रवाह, एक्जिट कोड, stdin/stdout अनुबंध |

## क्या स्किल पूर्ण है?

Mintlify नेविगेशन में सभी पृष्ठों से `llms.txt` जेनरेट करता है। Failproof AI दस्तावेज़ संपूर्ण API को कवर करते हैं - हर पॉलिसी, विकल्प और उदाहरण शामिल है। यदि आपको कुछ लापता लगे, तो स्रोत `https://docs.befailproof.ai/llms-full.txt` पर है।

लक्षित संदर्भ के लिए, किसी विशिष्ट पृष्ठ से सीधे लिंक करें:

```bash
# केवल कस्टम पॉलिसीज़ API
npx skills add https://docs.befailproof.ai/custom-policies

# केवल अंतर्निर्मित पॉलिसीज़
npx skills add https://docs.befailproof.ai/built-in-policies
```
