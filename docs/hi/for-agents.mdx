एक कमांड में अपने कोडिंग एजेंट को पूरा Failproof AI संदर्भ जोड़ें। Claude Code, Cursor, Windsurf और किसी भी अन्य एजेंट के साथ काम करता है जो स्किल्स को सपोर्ट करता है।

```bash
npx skills add https://docs.befailproof.ai
```

`npx skills` पहचानता है कि आपके पास कौन से एजेंट इंस्टॉल हैं और प्रत्येक के लिए सही फॉर्मेट में स्किल को स्वचालित रूप से जोड़ता है।

## स्किल में क्या शामिल है

| क्षेत्र | क्या शामिल है |
|------|----------------|
| Policies | बिल्ट-इन पॉलिसी नाम, ईवेंट टाइप, पैरामीटर, सक्षम/अक्षम करें |
| Custom policies | `customPolicies.add()`, मैच फिल्टर, `allow`/`deny`/`instruct` API |
| Context object | `ctx.eventType`, `ctx.toolName`, `ctx.toolInput`, `ctx.session` |
| Configuration | `policies-config.json` संरचना, स्कोप मर्जिंग, `policyParams` |
| CLI | `failproofai policies --install`, `--uninstall`, `--custom`, स्कोप |
| Dashboard | सेशन व्यूअर, पॉलिसी एक्टिविटी, एनवायरनमेंट वेरिएबल्स |
| Architecture | हुक हैंडलर फ्लो, एक्जिट कोड, stdin/stdout कॉन्ट्रैक्ट |

## क्या स्किल संपूर्ण है?

Mintlify नेविगेशन के सभी पेजों से `llms.txt` जेनरेट करता है। Failproof AI डॉक्स पूरे API को कवर करते हैं - हर पॉलिसी, विकल्प और उदाहरण शामिल है। यदि आपको कुछ गायब दिखता है, तो स्रोत `https://docs.befailproof.ai/llms-full.txt` पर है।

लक्षित संदर्भ के लिए, किसी विशिष्ट पेज से सीधे लिंक करें:

```bash
# केवल custom policies API
npx skills add https://docs.befailproof.ai/custom-policies

# केवल built-in policies
npx skills add https://docs.befailproof.ai/built-in-policies
```
