Failproof AI टीमों को यह समझने में मदद करता है कि agents ने क्या किया, वे कहाँ विफल हुए, और समान behavior दोबारा होने से पहले safeguards को deploy करें।

> **Session → Audit → Finding → Issue → Policy**<br />
> क्या हुआ यह trace करें, failure को खोजें, response को manage करें, फिर भविष्य के runs में समान behavior को रोकें।

## यहाँ से शुरू करें

यदि आप अपना पहला instrumented agent deploy कर रहे हैं, तो [quickstart](/hi/start/quickstart) से शुरू करें। यदि data पहले से आ रहा है, तो [Sessions](/hi/sessions/overview) खोलें और audits या policies को configure करने से पहले एक real run को inspect करें।
