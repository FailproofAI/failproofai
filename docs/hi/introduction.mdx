**AI फेलियर हैंडलिंग**, **एरर रिकवरी**, और **LLM रिलायबिलिटी** के लिए हुक्स और पॉलिसीज। अपने AI एजेंट्स को **Claude Code**, **OpenAI Codex**, **GitHub Copilot**, **Cursor Agent**, **OpenCode**, **Pi**, **Hermes**, **OpenClaw**, **Factory Droid**, **Devin CLI**, **Antigravity CLI**, और **Agents SDK** के साथ रिलायबल और ऑटोनमसली रनिंग रखें।

AI एजेंट्स अनुमानित तरीकों से फेल करते हैं। वे डिस्ट्रक्टिव कमांड्स चलाते हैं, सीक्रेट्स लीक करते हैं, टास्क से भटकते हैं, लूप्स में फंसते हैं, या सीधे मेन में पुश करते हैं। अनअटेंडेड छोड़ दिए जाने पर, छोटी फेलियर्स आउटेजेस, लीक की गई क्रेडेंशियल्स, और खोए हुए काम में बदल जाती हैं।

FailproofAI इसे **पॉलिसीज** से हल करता है। ये नियम हर एजेंट टूल कॉल में हुक करते हैं ताकि **फेलियर्स डिटेक्ट** हों, **उन्हें मिटिगेट** किया जाए (ब्लॉक, निर्देश दें, सैनिटाइज करें), और **आपको अलर्ट** किया जाए जब कुछ ध्यान देने की जरूरत हो। एक लोकल डैशबोर्ड आपको बाद में हर टूल कॉल, एजेंट फेलियर, और रिकवरी एक्शन की समीक्षा करने देता है।

ट्रांसक्रिप्ट्स और पॉलिसी इवैल्यूएशन आपकी मशीन पर रहते हैं। डेटा केवल तब भेजा जाता है जब आप स्पष्ट रूप से किसी ऑनलाइन फीचर का उपयोग करते हैं, जैसे ऑथेंटिकेटेड ऑडिट रिमाइंडर्स या इनविटेशन्स।

## क्विक स्टार्ट

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # पॉलिसीज एनेबल करें (या स्किप करें — `failproofai` पहली रन पर उन्हें सेट अप करने की ऑफर देगा)
failproofai                      # डैशबोर्ड लॉन्च करें
```
