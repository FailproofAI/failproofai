**AI failure handling**, **error recovery**, और **LLM reliability** के लिए Hooks और policies। अपने AI agents को **Claude Code**, **OpenAI Codex**, **GitHub Copilot**, **Cursor Agent**, **OpenCode**, **Pi**, **Hermes**, **OpenClaw**, **Factory Droid**, **Devin CLI**, **Antigravity CLI**, और **Agents SDK** में विश्वसनीय और स्वायत्त रूप से चलता रहें।

AI agents predictable तरीकों से fail होते हैं। वे destructive commands चलाते हैं, secrets leak करते हैं, task से भटकते हैं, loops में फंसते हैं, या सीधे main में push करते हैं। बिना निगरानी के, छोटी failures cascading outages, leaked credentials, और lost work में बदल जाती हैं।

FailproofAI इसे **policies** के साथ solve करता है। ये rules हर agent tool call में hook करते हैं ताकि **failures को detect किया जा सके**, **उन्हें mitigate किया जा सके** (block, instruct, sanitize), और **आपको alert किया जा सके** जब कुछ attention की जरूरत हो। एक local dashboard आपको बाद में हर tool call, agent failure, और recovery action को review करने देता है।

Transcripts और policy evaluation आपकी machine पर ही रहते हैं। Data केवल तभी भेजा जाता है जब आप explicitly एक online feature का use करते हैं, जैसे authenticated audit reminders या invitations।

## Quick start

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # enable policies (या skip करें — `failproofai` पहली run पर setup का offer करेगा)
failproofai                      # launch the dashboard
```
