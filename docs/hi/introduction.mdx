[![npm weekly downloads](https://img.shields.io/npm/dw/failproofai?style=flat-square&color=2ea44f)](https://www.npmjs.com/package/failproofai)

**एआई फेलियर हैंडलिंग**, **एरर रिकवरी**, और **एलएलएम रिलायबिलिटी** के लिए हुक्स और पॉलिसीज़। अपने एआई एजेंट्स को **Claude Code**, **OpenAI Codex**, **GitHub Copilot**, **Cursor Agent**, **OpenCode**, **Pi**, **Hermes**, **OpenClaw**, **Factory Droid**, **Devin CLI**, **Antigravity CLI**, और **Agents SDK** में विश्वसनीय और स्वायत्त रूप से चलते रहने दें।

एआई एजेंट्स पूर्वानुमानित तरीकों से विफल होते हैं। वे डिस्ट्रक्टिव कमांड्स चलाते हैं, सीक्रेट्स लीक करते हैं, टास्क से भटक जाते हैं, लूप्स में फंस जाते हैं, या सीधे मेन में पुश कर देते हैं। बिना निगरानी के, छोटी विफलताएं आउटेज, लीक क्रेडेंशियल्स और खोए हुए काम में परिणत हो सकती हैं।

FailproofAI इसे **पॉलिसीज़** के साथ हल करता है। ये नियम हर एजेंट टूल कॉल में हुक करते हैं ताकि **फेलियर्स का पता लगाया** जा सके, उन्हें **कम किया** जा सके (ब्लॉक, इंस्ट्रक्ट, सैनिटाइज़), और जब कुछ ध्यान की जरूरत हो तो आपको **अलर्ट किया** जा सके। एक लोकल डैशबोर्ड आपको हर टूल कॉल, एजेंट फेलियर और रिकवरी एक्शन की समीक्षा करने देता है।

ट्रांसक्रिप्ट्स और पॉलिसी मूल्यांकन आपकी मशीन पर रहते हैं। डेटा केवल तभी भेजा जाता है जब आप स्पष्ट रूप से कोई ऑनलाइन फीचर्स का उपयोग करते हैं, जैसे कि प्रमाणित ऑडिट रिमाइंडर्स या आमंत्रण।

## त्वरित शुरुआत

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # पॉलिसीज़ को सक्षम करें (या स्किप करें — `failproofai` पहली रन पर उन्हें सेट अप करने की पेशकश करेगा)
failproofai                      # डैशबोर्ड लॉन्च करें
```
