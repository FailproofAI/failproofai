## आधिकारिक पैकेज

कैनोनिकल npm पैकेज है **`failproofai`**:

```bash
npm install -g failproofai
# या
bun add -g failproofai
```

---

## हम उपनाम नामों के मालिक क्यों हैं

टाइपोस्क्वाटिंग एक आम आपूर्ति-श्रृंखला हमला है जहां एक दुर्भावनापूर्ण अभिनेता एक पैकेज नाम पंजीकृत करता है जो एक लोकप्रिय पैकेज से एक कीस्ट्रोक दूर है। जो उपयोगकर्ता अनजाने में इंस्टॉल कमांड को गलत तरीके से टाइप करते हैं, वे पूर्ण सिस्टम पहुंच के साथ हमलावर द्वारा नियंत्रित कोड चलाते हैं - बिल्कुल वही खतरा जिससे Failproof AI की रक्षा के लिए डिज़ाइन किया गया है।

इस सतह को समाप्त करने के लिए, **हम npm पर `failproofai` के सभी सामान्य गलत वर्तनी और स्वरूपण वेरिएंट को पहले से ही स्वामित्व करते हैं**। इनमें से कोई भी नाम किसी तीसरे पक्ष द्वारा पंजीकृत नहीं किया जा सकता। प्रत्येक वास्तविक `failproofai` पैकेज के लिए एक पतली प्रॉक्सी है जो इंस्टॉल करता है और प्रतिनिधित्व करता है।

## पंजीकृत उपनाम

**स्वरूपण वेरिएंट** - "failproof ai" लिखने के विभिन्न तरीके:

| पैकेज | स्थिति |
|---------|--------|
| `failproof` | ✅ प्रकाशित |
| `failproof-ai` | ⏳ npm सहायता की प्रतीक्षा |
| `fail-proof-ai` | ⏳ npm सहायता की प्रतीक्षा |
| `failproof_ai` | ⏳ npm सहायता की प्रतीक्षा |
| `fail_proof_ai` | ⏳ npm सहायता की प्रतीक्षा |
| `fail-proofai` | ⏳ npm सहायता की प्रतीक्षा |

**`failprof*` टाइपो** - "proof" से एक `o` गायब:

| पैकेज | स्थिति |
|---------|--------|
| `failprof` | ✅ प्रकाशित |
| `failprof-ai` | ✅ प्रकाशित |
| `failprofai` | ⏳ npm सहायता की प्रतीक्षा |
| `fail-prof-ai` | ⏳ npm सहायता की प्रतीक्षा |
| `failprof_ai` | ⏳ npm सहायता की प्रतीक्षा |

**`faliproof*` टाइपो** - `a` और `i` को स्थानांतरित किया गया:

| पैकेज | स्थिति |
|---------|--------|
| `faliproof` | ✅ प्रकाशित |
| `faliproof-ai` | ✅ प्रकाशित |
| `faliproofai` | ⏳ npm सहायता की प्रतीक्षा |

> **प्रतीक्षा में क्यों?** npm की स्पैम-रोकथाम नीति उन नामों को ब्लॉक करती है जो विद्यमान पैकेज के समान स्ट्रिंग को सामान्य करते हैं विराम चिन्हों को हटाने और समानता जांच चलाने के बाद। हमने anti-squatting उद्देश्यों के लिए इन नामों को आरक्षित करने के लिए npm सहायता से संपर्क किया है। अनुमोदन के बाद वे सक्रिय किए जाएंगे।

आप सत्यापित कर सकते हैं कि कोई भी प्रकाशित उपनाम हमारे द्वारा स्वामित्व में है:

```bash
npm info failproof
# देखें: maintainers फील्ड में "ExosphereHost Inc."
```

## उपनाम कैसे काम करते हैं

प्रत्येक उपनाम पैकेज:

1. `failproofai` को एक निर्भरता के रूप में सूचीबद्ध करता है - इसलिए वास्तविक पैकेज स्थापित होता है और इसका बाइनरी उपलब्ध हो जाता है
2. अपने स्वयं के नाम से मेल खाने वाला एक बाइनरी उजागर करता है (उदाहरण के लिए `failprof-ai`) जो सभी तर्कों को `failproofai` बाइनरी के लिए प्रॉक्सी करता है

प्रॉक्सी एक दो-पंक्ति वाली Node स्क्रिप्ट है; कोई तर्क नहीं है, कोई नेटवर्क कॉल नहीं है, और `failproofai` स्वयं क्या करता है, इससे परे कोई डेटा संग्रह नहीं है।
