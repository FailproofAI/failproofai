## आधिकारिक पैकेज

canonical npm पैकेज **`failproofai`** है:

```bash
npm install -g failproofai
# या
bun add -g failproofai
```

---

## हम उपनाम नाम क्यों रखते हैं

टाइपोस्क्वॉटिंग एक सामान्य आपूर्ति-श्रृंखला हमला है जहां एक दुर्भावनापूर्ण अभिनेता एक लोकप्रिय पैकेज से एक कीस्ट्रोक दूर एक पैकेज नाम पंजीकृत करता है। जो उपयोगकर्ता इंस्टॉल कमांड में गलती करते हैं, वे पूर्ण सिस्टम एक्सेस के साथ हमलावर-नियंत्रित कोड चलाते हैं - ठीक वही प्रकार का खतरा जिसे Failproof AI रक्षा करने के लिए डिज़ाइन किया गया है।

इस सतह को समाप्त करने के लिए, **हम npm पर `failproofai` के सभी सामान्य गलतियों और फॉर्मेटिंग वेरिएंट को सक्रिय रूप से रखते हैं**। इनमें से कोई भी नाम किसी तीसरे पक्ष द्वारा पंजीकृत नहीं किया जा सकता। प्रत्येक एक पतला प्रॉक्सी है जो असली `failproofai` पैकेज को स्थापित करता है और प्रतिनिधि करता है।

---

## पंजीकृत उपनाम

**फॉर्मेटिंग वेरिएंट** - "failproof ai" लिखने के विभिन्न तरीके:

| पैकेज | स्थिति |
|---------|--------|
| `failproof` | ✅ प्रकाशित |
| `failproof-ai` | ⏳ npm समर्थन की प्रतीक्षा में |
| `fail-proof-ai` | ⏳ npm समर्थन की प्रतीक्षा में |
| `failproof_ai` | ⏳ npm समर्थन की प्रतीक्षा में |
| `fail_proof_ai` | ⏳ npm समर्थन की प्रतीक्षा में |
| `fail-proofai` | ⏳ npm समर्थन की प्रतीक्षा में |

**`failprof*` टाइपो** - "proof" से एक `o` छूटा:

| पैकेज | स्थिति |
|---------|--------|
| `failprof` | ✅ प्रकाशित |
| `failprof-ai` | ✅ प्रकाशित |
| `failprofai` | ⏳ npm समर्थन की प्रतीक्षा में |
| `fail-prof-ai` | ⏳ npm समर्थन की प्रतीक्षा में |
| `failprof_ai` | ⏳ npm समर्थन की प्रतीक्षा में |

**`faliproof*` टाइपो** - `a` और `i` को स्थानांतरित किया:

| पैकेज | स्थिति |
|---------|--------|
| `faliproof` | ✅ प्रकाशित |
| `faliproof-ai` | ✅ प्रकाशित |
| `faliproofai` | ⏳ npm समर्थन की प्रतीक्षा में |

> **प्रतीक्षा में क्यों?** npm की स्पैम-निवारण नीति उन नामों को ब्लॉक करती है जो विद्यमान पैकेज के समान स्ट्रिंग में सामान्य होते हैं विराम चिह्न को हटाने और समानता जांच चलाने के बाद। हमने इन नामों को एंटी-स्क्वॉटिंग उद्देश्यों के लिए आरक्षित करने के लिए npm समर्थन से संपर्क किया है। वे मंजूरी मिलने के बाद सक्रिय किए जाएंगे।

आप यह सत्यापित कर सकते हैं कि कोई भी प्रकाशित उपनाम हमारे द्वारा स्वामित्व में है:

```bash
npm info failproof
# रखरखाव कर्ताओं क्षेत्र में "ExosphereHost Inc." देखें
```

## उपनाम कैसे काम करते हैं

प्रत्येक उपनाम पैकेज:

1. `failproofai` को एक निर्भरता के रूप में सूचीबद्ध करता है - इसलिए असली पैकेज स्थापित किया जाता है और इसका बाइनरी उपलब्ध हो जाता है
2. अपने स्वयं के नाम से मेल खाने वाला एक बाइनरी प्रदर्शित करता है (जैसे `failprof-ai`) जो सभी तर्कों को `failproofai` बाइनरी को प्रॉक्सी करता है

प्रॉक्सी एक दो-लाइन Node स्क्रिप्ट है; कोई तर्क नहीं है, कोई नेटवर्क कॉल नहीं है, और `failproofai` स्वयं जो करता है उसके बाहर कोई डेटा संग्रहण नहीं है।
