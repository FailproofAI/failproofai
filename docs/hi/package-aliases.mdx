## आधिकारिक पैकेज

canonical npm पैकेज **`failproofai`** है:

```bash
npm install -g failproofai
# or
bun add -g failproofai
```

---

## हम एलियास नामों के मालिक क्यों हैं

टाइपोस्क्वाटिंग एक सामान्य सप्लाई-चेन अटैक है जहां एक दुर्भावनापूर्ण अभिनेता एक पैकेज नाम को पंजीकृत करता है जो एक लोकप्रिय पैकेज से केवल एक कीस्ट्रोक दूर है। जो उपयोगकर्ता अनजाने में इंस्टॉल कमांड को गलत तरीके से टाइप करते हैं, वे संपूर्ण सिस्टम एक्सेस के साथ हमलावर-नियंत्रित कोड चलाते हैं - बिल्कुल वह तरह का खतरा जिससे Failproof AI की रक्षा के लिए डिज़ाइन किया गया है।

इस सतह को खत्म करने के लिए, **हम `failproofai` के सभी सामान्य गलतियों और फॉर्मेटिंग वेरिएंट्स को npm पर पहले से ही अपने कब्जे में कर लेते हैं**। इनमें से कोई भी नाम किसी तीसरे पक्ष द्वारा पंजीकृत नहीं किया जा सकता। प्रत्येक एक पतला प्रॉक्सी है जो वास्तविक `failproofai` पैकेज को इंस्टॉल करता है और उसे सौंपता है।

## पंजीकृत एलियासेस

**फॉर्मेटिंग वेरिएंट्स** - "failproof ai" लिखने के विभिन्न तरीके:

| पैकेज | स्थिति |
|---------|--------|
| `failproof` | ✅ प्रकाशित |
| `failproof-ai` | ⏳ npm समर्थन की प्रतीक्षा |
| `fail-proof-ai` | ⏳ npm समर्थन की प्रतीक्षा |
| `failproof_ai` | ⏳ npm समर्थन की प्रतीक्षा |
| `fail_proof_ai` | ⏳ npm समर्थन की प्रतीक्षा |
| `fail-proofai` | ⏳ npm समर्थन की प्रतीक्षा |

**`failprof*` टाइपो** - "proof" से एक `o` गायब है:

| पैकेज | स्थिति |
|---------|--------|
| `failprof` | ✅ प्रकाशित |
| `failprof-ai` | ✅ प्रकाशित |
| `failprofai` | ⏳ npm समर्थन की प्रतीक्षा |
| `fail-prof-ai` | ⏳ npm समर्थन की प्रतीक्षा |
| `failprof_ai` | ⏳ npm समर्थन की प्रतीक्षा |

**`faliproof*` टाइपो** - `a` और `i` स्थानांतरित:

| पैकेज | स्थिति |
|---------|--------|
| `faliproof` | ✅ प्रकाशित |
| `faliproof-ai` | ✅ प्रकाशित |
| `faliproofai` | ⏳ npm समर्थन की प्रतीक्षा |

> **प्रतीक्षा क्यों?** npm की स्पैम-प्रिवेंशन नीति उन नामों को ब्लॉक करती है जो विद्यमान पैकेज के समान स्ट्रिंग में सामान्यीकृत होते हैं विराम चिह्नों को हटाने और समानता जांच चलाने के बाद। हमने एंटी-स्क्वाटिंग उद्देश्यों के लिए इन नामों को सुरक्षित करने के लिए npm समर्थन से संपर्क किया है। अनुमोदन मिलने के बाद वे सक्रिय किए जाएंगे।

आप किसी भी प्रकाशित एलियास को सत्यापित कर सकते हैं कि वह हमारे द्वारा स्वामित्व में है:

```bash
npm info failproof
# Look for: "ExosphereHost Inc." in the maintainers field
```

## एलियासेस कैसे काम करते हैं

प्रत्येक एलियास पैकेज:

1. `failproofai` को एक निर्भरता के रूप में सूचीबद्ध करता है - इसलिए वास्तविक पैकेज इंस्टॉल किया जाता है और इसका बाइनरी उपलब्ध हो जाता है
2. अपने स्वयं के नाम के साथ मेल खाता एक बाइनरी उजागर करता है (उदा. `failprof-ai`) जो सभी तर्कों को `failproofai` बाइनरी को प्रॉक्सी करता है

प्रॉक्सी एक दो-लाइन Node स्क्रिप्ट है; कोई तर्क नहीं है, कोई नेटवर्क कॉल नहीं है, और `failproofai` स्वयं जो कुछ करता है उससे परे कोई डेटा संग्रह नहीं है।
