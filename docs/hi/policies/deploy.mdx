एक समीक्षा की गई नीति को एक बार में एक मशीन पर तैनात करें। अवलोकन मोड से शुरुआत करें।

## CLI से रोलआउट करें

```bash
fp policies test ./rule.mjs --tool Bash --command "git push --force" --expect deny
fp policies publish no-force-push ./rule.mjs
fp fleet deploy <machine> --add no-force-push:observe
fp guardrails summary --since 24h --machine <machine>
fp fleet deploy <machine> --add no-force-push:enforce
```

अवलोकन मोड वास्तविक नीति का मूल्यांकन करता है और गैर-allow निर्णयों को रिकॉर्ड करता है, लेकिन एजेंट को ब्लॉक नहीं करता है।

<Warning>
  एक साधारण `--add no-force-push` तुरंत लागू करता है। छाया रोलआउट के लिए `:observe` जोड़ें।
</Warning>

यदि प्रवर्तन समस्याएं पैदा करता है:

```bash
fp fleet history <machine>
fp fleet rollback <machine> <generation>
```

## डैशबोर्ड से तैनात करें

1. **Admin → enforcement** पर जाएं।
2. लक्ष्य मशीन खोलें।
3. प्रभाव **observe** के साथ नीति संस्करण जोड़ें।
4. तैनाती लागू करें।
5. **Observe → policy** के अंतर्गत परिणामों की समीक्षा करें।
6. जब मिलान सही हों तो समान संस्करण को **enforce** में बढ़ाएं।

## एक सेट को बदलें या पूर्व-चरण करें

- `--remove <id>` एक नीति को हटाता है।
- `--set <ref>...` संपूर्ण नीति सेट को बदलता है।
- `--create` एक मशीन के पहली बार चेक इन करने से पहले एक तैनाती तैयार करता है।
- `fp fleet diff <machine>` इच्छित और लागू स्थिति की तुलना करता है।

<Note>
  Cloud के बिना, `failproofai publish --effect observe` के साथ एक पैक प्रकाशित करें और स्थानीय डैशबोर्ड में निर्णयों का निरीक्षण करें।
</Note>

मशीनों को तैनातियां प्राप्त करने के लिए `policies:pull` की आवश्यकता है और निर्णयों की रिपोर्ट करने के लिए `events:add` की आवश्यकता है।
