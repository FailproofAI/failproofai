एक policy pack policies का एक संस्करणित set है जो एक सार्वजनिक GitHub release के रूप में प्रकाशित होता है। पैकेज अपना कोई pack नहीं भेजता; किसी अन्य की तरह हमारे को इंस्टॉल करें:

```bash
failproofai policies show FailproofAI/policies
failproofai policies add FailproofAI/policies
```

`show` pack के कोड को चलाए बिना manifest को पढ़ता है।

## चुनें कि क्या इंस्टॉल करना है

```bash
failproofai policies add owner/repo --policy block-refunds
failproofai policies add owner/repo --category billing,git
failproofai policies add owner/repo --all
```

बिना किसी चयन के, pack प्रकाशक के डिफ़ॉल्ट का उपयोग करता है। एक नए release को फिर से जोड़ने से आपका मौजूदा चयन बना रहता है।

स्लैश वाला कुछ भी एक pack source है। बिना स्लैश वाला कुछ भी एक policy name है।

## एक release को pin करें

| Source | परिणाम |
| --- | --- |
| `owner/repo` | नवीनतम release, resolution के बाद pinned |
| `owner/repo@a1b2c3d4e5f6` | सटीक commit-आधारित release |
| `owner/repo@v2.1.0` | सटीक नाम वाला release |
| GitHub release URL | उस URL में release |

एक pack आमतौर पर 12-character commit SHA का उपयोग करता है जिससे यह बनाया गया था। Release order देखने के लिए `failproofai policies show owner/repo --releases` का उपयोग करें।

## इंस्टॉल किए गए packs को प्रबंधित करें

```bash
failproofai policies
failproofai policies remove block-refunds
failproofai policies add block-refunds
failproofai policies remove owner/repo
```

यदि दो इंस्टॉल किए गए packs में समान policy name है, तो CLI ambiguous bare name को अस्वीकार करता है। एक pack के माध्यम से policy को चुनें या दूसरे pack को अनइंस्टॉल करें।

## सुरक्षा और उपलब्धता

प्रत्येक release में एक manifest, bundled policy code, और checksums होते हैं। Failproof AI इसे लोड करने से पहले रिकॉर्ड किए गए digest को सत्यापित करता है। Checksums साबित करते हैं कि bytes release से मेल खाते हैं; वे यह साबित नहीं करते कि इसे किसने प्रकाशित किया।

एक चयनित pack जो लोड नहीं हो सकता, उन events के लिए बंद fail करता है जिन्हें वह घोषित करता है। [policy failure behavior](/hi/policies/failure-behavior) देखें।

| Variable | प्रभाव |
| --- | --- |
| `FAILPROOFAI_NO_DOWNLOAD=1` | नए downloads को अस्वीकार करें; इंस्टॉल किए गए packs चलते रहते हैं |
| `FAILPROOFAI_PACK_BASE_URL` | एक mirror का उपयोग करें |
| `FAILPROOFAI_PACK_DIR` | Pack store को move करें |

[Policy Hub](https://befailproof.ai/policy-hub/) में packs को browse करें या [अपना खुद का प्रकाशित करें](/hi/policies/publish-a-pack)।
