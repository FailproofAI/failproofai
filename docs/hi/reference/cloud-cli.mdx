Cloud telemetry का निरीक्षण करने और audits, findings, issues, alerts, keys, users, queries, और settings को प्रबंधित करने के लिए `fp` का उपयोग करें। स्थानीय hooks, policies, capture, और machine enrollment के लिए [`failproofai`](/hi/reference/failproof-cli) का उपयोग करें।

Released Cloud CLI को एक isolated tool के रूप में install करें:

```bash
uv tool install fp-cli
fp version
```

## Sign in करें

```bash
fp login
fp whoami
```

## Syntax

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

Global options को command से पहले आना चाहिए:

```bash
fp --json sessions --since 24h
```

Terminal help के लिए `fp COMMAND --help` या `fp COMMAND SUBCOMMAND --help` चलाएं।

### Events

```text
fp events [OPTIONS]
```

Individual agent events को list करता है। Default light feed raw payloads को exclude करता है; bounded investigation के लिए केवल `--full` का उपयोग करें।

| Option | Description |
| --- | --- |
| `--limit`, `-n <n>` | Maximum total rows। Default: `50`। |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h`, या `7d`। |
| `--from <timestamp>` / `--to <timestamp>` | ISO 8601 UTC range; `--since` को override करता है। |
| `--env <value>` | Environment filter; values को repeat या comma-separate करें। |
| `--event-type <value>` | Event-type filter; values को repeat या comma-separate करें। |
| `--agent-id <value>` | Agent filter; values को repeat या comma-separate करें। |
| `--session-id <value>` | Session filter; values को repeat या comma-separate करें। |
| `--search <text>` | Payload text search; repeatable, किसी भी term के साथ matching। |
| `--order asc\|desc` | Time order। Default: newest first। |
| `--all` | `--limit` तक auto-paginate करें। |
| `--cursor <token>` | एक opaque cursor से resume करें। |
| `--page-size <n>` | `--all` के साथ rows per request; maximum `200`। |
| `--full` | Heavier event endpoint के माध्यम से raw payloads को शामिल करें। |
| `--fields <csv>` | केवल selected fields को return करें; `payload` को requesting करने से full mode enable होता है। |

```bash
fp events --session-id <session-id> --order asc --all
fp --json events --full --session-id <session-id> --all
```

### API keys

| Command | Purpose | Options |
| --- | --- | --- |
| `fp keys list` | Organization keys को list करें। | `--show-id`; `--fields <csv>` |
| `fp keys show NAME` | एक key और इसके grants को दिखाएं। | — |
| `fp keys create NAME` | एक key बनाएं और इसके secret को एक बार reveal करें। | `--permission-set`; `--add`; `--remove` |
| `fp keys update NAME` | Permission set को replace करें या grants को adjust करें। | `--permission-set`; `--add`; `--remove`; `--yes`, `-y` |
| `fp keys regenerate NAME` | Secret को rotate करें और replacement को एक बार reveal करें। | `--yes`, `-y` |
| `fp keys disable NAME` | एक key को permanently revoke करें। | `--yes`, `-y` |

Permission tokens `resource:action` का उपयोग करते हैं, जैसे `events:add`। `--add` को repeat करें, tokens को comma-separate करें, या `events:read.add` जैसी dotted actions का उपयोग करें।

#### Audit create options

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| Option | Description |
| --- | --- |
| `--file <path>` | Definition को JSON पर base करें, या stdin के लिए `-` का उपयोग करें। Explicit flags file values को override करते हैं। |
| `--description <text>` | Failure question या purpose को state करें। |
| `--enabled` / `--disabled` | Scheduling को on या off पर start करें। Default: enabled। |
| `--schedule-interval-secs <n>` | `3600`–`604800`। Default: `86400`। |
| `--schedule-anchor <timestamp>` | ISO 8601 form में fixed UTC phase। Default: next 09:00 UTC। |
| `--window-mode since_last\|fixed` | Last fully analyzed window के बाद continue करें या repeatedly एक rolling window को inspect करें। Default: `since_last`। |
| `--lookback-window-secs <n>` | `3600`–`7776000`। Default: `604800`। |
| `--scope '<json>'` | `environments`, `agent_ids`, या अन्य supported scope fields द्वारा filter करें। |
| `--ignore-error-type <type>` | Error types को exclude करें; repeat या comma-separate करें। |
| `--llm` / `--no-llm` | Agentic analysis को enable या disable करें। Default: enabled। |
| `--top-k <n>` | `1`–`500` findings को retain करें। Default: `50`। |
| `--sensitivity low\|medium\|high` | Reporting sensitivity को set करें। Default: `medium`। |
| `--channels '<json>'` | Notification channel array। |
| `--text <brief>` | Inline brief, maximum 8,192 characters। |
| `--text-file <path>` | एक file से brief को read करें; `--text` के साथ mutually exclusive। |
| `--url <https-url>` | एक public HTTPS reference को add करें; पांच बार तक repeat करें। |

Creation के दौरान context को शामिल करें जब first run को इसकी आवश्यकता हो। Creation definition और context को एक साथ commit करता है queued run शुरू होने से पहले।

<Note>
  `fp audits run` asynchronous है। `fp audits runs NAME` को poll करें जब तक latest run succeed या fail न हो जाए इससे पहले कि आप इसके findings को read करें।
</Note>

## Global flags

| Flag | Description |
| --- | --- |
| `--json` | Machine-readable JSON को emit करें। |
| `--base-url <url>` | एक self-hosted या development dashboard का उपयोग करें। |
| `--org <slug>` | इस invocation के लिए एक organization को select करें। |
| `--token <token>` | Saved user-session token को override करें। |
| `--api-key <key>` | Automation को एक API key से authenticate करें; कभी save नहीं होता। |
| `--timeout <seconds>` | HTTP timeout; positive होना चाहिए। Default: `30`। |
| `--quiet`, `-q` | stderr पर status output को suppress करें। |
| `--no-color` | Colored output को disable करें। |
| `--insecure` / `--secure` | TLS certificate verification को disable या restore करें। |
| `--version` | Unboxed version को print करें और exit करें। |
| `--help`, `-h` | Help दिखाएं। |

`--api-key` automation के लिए intended है। Login, organization switching, और assistant commands को एक user session की आवश्यकता होती है।

| Variable | Equivalent या purpose |
| --- | --- |
| `AGENTEYE_DASHBOARD_URL` | `--base-url` |

<Warning>
  Commands जो delete, revoke, suppress, resolve, या replace configuration को default रूप से prompt करते हैं। `--yes` का उपयोग केवल active organization और target को verify करने के बाद करें।
</Warning>
