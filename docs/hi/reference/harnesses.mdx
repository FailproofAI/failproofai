Failproof AI Claude Code, Codex, GitHub Copilot CLI, Cursor, OpenCode, Pi, Hermes, OpenClaw, Factory Droid, Devin CLI, Antigravity CLI, और Goose को समर्थन करता है।

| हार्नेस | समर्थित हुक स्कोप |
| --- | --- |
| Claude Code | User, project, local |
| Codex, GitHub Copilot CLI, Cursor, OpenCode, Pi | User, project |
| Factory Droid, Devin CLI, Antigravity CLI, Goose | User, project |
| Hermes, OpenClaw | User |

प्रत्येक एकीकरण अपने नेटिव हुक इवेंट नाम, टूल नाम, और टूल-इनपुट फ़ील्ड को सामान्यीकृत करता है इससे पहले कि नीतियां चलें। एक नीति केवल उन इवेंट पर कार्य कर सकती है जो हार्नेस उजागर करता है; टर्न के अंत और निर्देश व्यवहार को उसी हार्नेस और संस्करण पर परीक्षण करें जिसे आप परिनियोजित करते हैं।

## प्रवर्तन क्षमता

"ब्लॉक" का अर्थ है कि वर्तमान एडेप्टर की रिटर्न की गई राय का उपभोग नामित हार्नेस द्वारा किया जाता है। पोस्ट-टूल ब्लॉकिंग मॉडल को दिखाया गया परिणाम बदल सकता है लेकिन एक टूल साइड इफ़ेक्ट को पूर्ववत नहीं कर सकता जो पहले से हुआ है।

| हार्नेस | सत्यापित ब्लॉकिंग इवेंट | केवल अवलोकन या गैर-ब्लॉकिंग सावधानियां |
| --- | --- | --- |
| Claude Code | `PreToolUse`, `UserPromptSubmit`, `PermissionRequest`, `Stop`, `SubagentStop`, `PreCompact`, और कई कार्य/कॉन्फ़िग इवेंट | `PostToolUse`, सत्र जीवनचक्र, सूचनाएं, और पोस्ट-विफलता इवेंट अवलोकनात्मक हैं। |
| Codex | `PreToolUse`, `PermissionRequest`, `UserPromptSubmit`, `Stop`, `SubagentStop`, `PostToolUse` | पोस्ट-टूल ब्लॉकिंग निष्पादन के बाद परिणाम को प्रतिस्थापित करता है; सत्र-प्रारंभ और कॉम्पैक्ट इवेंट वर्तमान एडेप्टर में अवलोकनात्मक हैं। |
| GitHub Copilot CLI | `PreToolUse`, `UserPromptSubmit`, `PermissionRequest`, `Stop`, `SubagentStop`, `PostToolUse` | पोस्ट-टूल ब्लॉकिंग निष्पादन के बाद परिणाम को प्रतिस्थापित करता है; सत्र और सूचना इवेंट अवलोकनात्मक हैं। |
| Cursor | `PreToolUse`, `UserPromptSubmit`, `Stop` | `PostToolUse` और सत्र इवेंट अवलोकनात्मक हैं। |

| Pi | `PreToolUse`, `UserPromptSubmit` | पोस्ट-टूल और जीवनचक्र इवेंट अवलोकनात्मक हैं; स्टॉप मार्गदर्शन एक बाद के टर्न पर लागू होता है। |
| Hermes | `PreToolUse` | पोस्ट-टूल, सत्र, और सबएजेंट-स्टॉप राय गेट नहीं हैं। |
| OpenClaw | `PreToolUse`, `UserPromptSubmit`, `Stop` | पोस्ट-टूल, सत्र, सबएजेंट-स्टॉप, और कॉम्पैक्शन इवेंट अवलोकनात्मक हैं। |
| Factory Droid | `PreToolUse`, `UserPromptSubmit`, `Stop`, `PreCompact` | पोस्ट-टूल और सबएजेंट-स्टॉप राय अवलोकनात्मक हैं। |
| Devin CLI | `PreToolUse`, `UserPromptSubmit`, `Stop`, सशर्त `PermissionRequest` | अनुमति हुक हर अनुमति मोड में नहीं चलते; पोस्ट-टूल और सत्र इवेंट अवलोकनात्मक हैं। |
| Antigravity CLI | `PreToolUse`, `Stop` | यूजर-प्रॉम्प्ट और पोस्ट-टूल राय अवलोकनात्मक हैं; प्रॉम्प्ट निर्देश अभी भी इंजेक्ट किए जा सकते हैं। |
| Goose | `PreToolUse` | यूजर-प्रॉम्प्ट, पोस्ट-टूल, और सत्र इवेंट अवलोकनात्मक हैं। एक नेटिव ब्लॉकिंग स्टॉप हुक अपस्ट्रीम में मौजूद है लेकिन वर्तमान एडेप्टर द्वारा स्थापित नहीं है। |

क्षमताएं संस्करण-संवेदनशील हैं। एजेंट CLI को अपग्रेड करने के बाद पुनः परीक्षण करें, विशेष रूप से जब कोई नीति प्रॉम्प्ट, स्टॉप, अनुमति, या पोस्ट-टूल व्यवहार पर निर्भर करती है न कि सामान्य प्री-टूल गेट पर।

## कैप्चर और नीति हुक स्थापित करें

<Tabs>
  <Tab title="डैशबोर्ड">
    1. **Administration → Keys** खोलें और `events:add` और `policies:pull` के साथ एक कुंजी बनाएं, मशीन या वातावरण के लिए नामित करें।
    2. लक्ष्य मशीन पर, स्थानीय CLI को प्रदर्शित कुंजी के साथ जोड़ें और हार्नेस हुक स्थापित करें।
    3. एक नया एजेंट सत्र शुरू करें, फिर **Observe → Events** के तहत इसके हुक और सत्र इवेंट की पुष्टि करें।
    4. **Observe → policy** खोलें एक ही समय खिड़की के लिए और पुष्टि करें कि एक नीति निर्णय मशीन को जिम्मेदार ठहराया गया है।

    कनेक्शन एक मशीन कुंजी के साथ शुरू होता है। पुष्टि करें कि इसमें अंतर्ग्रहण और नीति-डिलीवरी दोनों अनुमतियां शामिल हैं इससे पहले कि इसके रहस्य को कॉपी करें।

    ![नई API कुंजी ड्रॉअर जिसका उपयोग इवेंट अंतर्ग्रहण और नीति डिलीवरी अनुमतियां देने के लिए किया जाता है।](/images/dashboard/key-create.png)

    हुक स्थापित करने के बाद, इवेंट स्ट्रीम को मशीन और वातावरण से नए इवेंट दिखाने चाहिए जिसे आपने जोड़ा है।

    ![लाइव इवेंट स्ट्रीम जिसका उपयोग नए स्थापित हार्नेस की रिपोर्टिंग की पुष्टि करने के लिए किया जाता है।](/images/dashboard/events-stream.png)

    अंत में, सत्यापित करें कि नीति निर्णय एक ही मशीन को जिम्मेदार ठहराए गए हैं। यह पुष्टि करता है कि हार्नेस ट्रेस इवेंट के साथ-साथ नीति गतिविधि की रिपोर्टिंग कर रहा है।

    ![नीति पृष्ठ जिसका उपयोग नए जुड़े हार्नेस से नीति निर्णय सत्यापित करने के लिए किया जाता है।](/images/dashboard/policy-observe.png)
  </Tab>
  <Tab title="CLI">
    प्रत्येक पाए गए हार्नेस के लिए हुक स्थापित करें:

    ```bash
    failproofai config \
      --connect https://app.befailproof.ai \
      --token <machine-key>
    failproofai policies --install
    ```

    या नामित हार्नेस और कॉन्फ़िगरेशन स्कोप को लक्ष्य करें:

    ```bash
    failproofai policies --install \
      --cli claude codex cursor \
      --scope user
    ```

    प्रोजेक्ट स्कोप हुक कॉन्फ़िगरेशन को एक रिपॉजिटरी के साथ रखता है। यूजर स्कोप रिपॉजिटरी के पार काम को कवर करता है। Claude Code स्थानीय स्कोप का भी समर्थन करता है; समर्थन हार्नेस के आधार पर अलग-अलग होता है और CLI अनुपयोगी संयोजनों को अस्वीकार करता है।

    मशीन और इसके इवेंट को सत्यापित करें:

    ```bash
    failproofai config --status
    failproofai flush --wait
    fp events --since 1h --event-type hook_triggered,hook_completed
    ```
  </Tab>
</Tabs>

## एक गैर-डिफ़ॉल्ट सत्र पथ जोड़ें

<Tabs>
  <Tab title="डैशबोर्ड">
    अतिरिक्त पथ मशीन पर पंजीकृत होते हैं, क्लाउड में नहीं। एक जोड़ने के बाद, **Observe → Sessions** खोलें, मशीन के वातावरण के लिए फ़िल्टर करें, और नए पथ से सत्रों की उपस्थिति की पुष्टि करें। एक सत्र खोलें और एजेंट, हार्नेस, और इवेंट टाइमस्टैम्प की जांच करें इससे पहले कि आप इसे ऑडिट में भरोसा करें।

    ![सत्र सूची अतिरिक्त कैप्चर पथ से डेटा प्राप्त करने वाले वातावरण के लिए फ़िल्टर की गई।](/images/dashboard/sessions-list.png)
  </Tab>
  <Tab title="CLI">
    एक पथ एक वैकल्पिक लेबल के साथ जोड़ें, फिर कॉन्फ़िगर किए गए पथों का निरीक्षण करें:

    ```bash
    failproofai harness add-path claude checkout=/srv/checkout/.claude
    failproofai harness list claude
    failproofai backfill --since 7d --dry-run
    failproofai backfill --since 7d
    ```

    `failproofai harness remove-path claude checkout` के साथ एक पथ हटाएं।
  </Tab>
</Tabs>

<Tip>
  स्थापना के बाद एक नया सत्र चलाएं। विस्तार को व्यापक करने से पहले लाइव इवेंट स्ट्रीम और एक वास्तविक नीति निर्णय दोनों सत्यापित करें।
</Tip>
