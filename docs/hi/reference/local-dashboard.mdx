failproofai को बिना किसी तर्क के चलाएं ताकि `http://localhost:8020` पर बंडल किया गया डैशबोर्ड शुरू हो सके। यह स्थानीय एजेंट इतिहास, पॉलिसी कॉन्फ़िगरेशन, ऑडिट परिणाम और हुक गतिविधि को सीधे मशीन से पढ़ता है।

स्थानीय डैशबोर्ड Failproof AI Cloud से अलग है। यह क्लाउड खाते के बिना काम करता है और यह साबित नहीं करता कि घटनाएं आपके संगठन को प्रदान की गई थीं।

## डैशबोर्ड क्षेत्र

| क्षेत्र | आप क्या कर सकते हैं |
| --- | --- |
| Policies → Activity | स्थानीय allow, instruct और deny निर्णयों की जांच करें; निर्णय, घटना, CLI, टूल, स्रोत, पॉलिसी और सेशन के आधार पर फ़िल्टर करें। |
| Policies → Configure | built-ins सक्षम करें, समर्थित पैरामीटर संपादित करें, खोजी गई कस्टम पॉलिसी को टॉगल करें और लक्ष्य हार्नेस चुनें। |
| Projects | समर्थित एजेंट इतिहास में खोजे गए प्रोजेक्ट्स को ब्राउज़ करें और उनके सबसे हाल के सेशन की तुलना करें। |
| Project sessions | एक स्थानीय ट्रांसक्रिप्ट खोलें, कच्ची क्रमबद्ध प्रविष्टियों और उप-एजेंटों की समीक्षा करें, इसे डाउनलोड करें और पॉलिसी गतिविधि को सहसंबंधित करें। |
| Audit | अंतिम ऑफ़लाइन स्कैन, जोखिमपूर्ण पैटर्न, शक्तियां, प्रभावित प्रोजेक्ट्स और सुझाई गई built-in पॉलिसी की समीक्षा करें। |
| Settings | शेड्यूल किए गए स्थानीय स्कैन और ईमेल किए गए ऑडिट रिपोर्ट कॉन्फ़िगर करें जब डेमॉन/प्लेटफ़ॉर्म उन्हें समर्थन करता है। |

## पॉलिसी गतिविधि की समीक्षा करें

<Tabs>
  <Tab title="Dashboard">
    1. **Policies → Activity** खोलें और निर्णय और स्रोत फ़िल्टर सेट करें।
    2. घटना, हार्नेस, टूल या पॉलिसी नाम के आधार पर संकीर्ण करें।
    3. इसके कारण, मिली पॉलिसी, स्रोत, निष्पादन मोड और अवधि की जांच करने के लिए एक पंक्ति को विस्तृत करें।
    4. निर्णय को ट्रांसक्रिप्ट संदर्भ में रखने के लिए सेशन लिंक का अनुसरण करें।

    एक अस्वीकृत दिखने वाली पंक्ति एक हार्नेस/घटना जोड़ी पर अभी भी प्रेक्षणीय हो सकती है जो ब्लॉकिंग फैसले का उपभोग नहीं करता है। विस्तार दृश्य सत्यापित प्रवर्तन क्षमता को कॉल करता है।
  </Tab>
  <Tab title="CLI">
    ```bash
    failproofai config --status
    failproofai policies
    failproofai
    ```

    स्थानीय गतिविधि `~/.failproofai/hook-activity` के तहत संग्रहीत है। इन फ़ाइलों को संपादित करने के बजाय डैशबोर्ड का उपयोग करें।
  </Tab>
</Tabs>

## स्थानीय रूप से पॉलिसी कॉन्फ़िगर करें

<Tabs>
  <Tab title="Dashboard">
    1. **Policies → Configure** खोलें और हार्नेस और कॉन्फ़िगरेशन स्कोप चुनें।
    2. एक built-in या खोजी गई कस्टम पॉलिसी सक्षम करें।
    3. एक पैरामीटरयुक्त built-in के लिए, इसके कॉन्फ़िगरेशन नियंत्रण को खोलें और समर्थित मान सहेजें।
    4. Activity पर लौटें और मिलने वाली और न मिलने वाली कार्रवाई चलाएं।

    सम्मेलन पॉलिसी अपने प्रोजेक्ट या उपयोगकर्ता स्रोत दिखाते हैं। स्पष्ट कस्टम-पथ परिवर्तनों को CLI कॉन्फ़िगरेशन को फिर से चलाने की आवश्यकता हो सकती है ताकि चुना गया पथ रिकॉर्ड किया जाए।
  </Tab>
  <Tab title="CLI">
    ```bash
    failproofai policy add block-sudo --scope project
    failproofai policies --install --custom ./security.policies.ts --scope project
    failproofai policies
    ```
  </Tab>
</Tabs>

## प्रोजेक्ट्स और सेशन ब्राउज़ करें

प्रोजेक्ट्स पृष्ठ समर्थित स्थानीय इतिहास स्टोर को जोड़ता है। अपने सेशन को सूचीबद्ध करने के लिए एक प्रोजेक्ट चुनें, फिर कच्चे लॉग दर्शक, उप-एजेंट सेगमेंट, डाउनलोड कार्रवाई और सेशन-स्कोप्ड पॉलिसी गतिविधि के लिए एक सेशन खोलें।

यदि कोई प्रोजेक्ट या सेशन गायब है, तो पुष्टि करें कि हार्नेस अपने डिफ़ॉल्ट इतिहास स्थान का उपयोग करता है या `failproofai harness add-path` के साथ एक अतिरिक्त रूट पंजीकृत करें।

## ऑफ़लाइन ऑडिट शेड्यूल करें

<Tabs>
  <Tab title="Dashboard">
    **Settings** खोलें, शेड्यूल किए गए स्कैनिंग को सक्षम करें, इसके समर्थित अंतराल को चुनें और उपलब्ध होने पर रिपोर्ट डिलीवरी कॉन्फ़िगर करें। पृष्ठ अगला चलन, अंतिम चलन, बाहर निकलने का कोड और क्या पृष्ठभूमि डेमॉन प्लेटफ़ॉर्म पर समर्थित है, की रिपोर्ट करता है।
  </Tab>
  <Tab title="CLI">
    ```bash
    failproofai audit --schedule 7 --email reliability@example.com
    failproofai audit --status
    ```

    एक अलग 1–90 दिन का अंतराल सेट करने के लिए दिनों की संख्या बदलें। `failproofai audit --no-schedule` के साथ आवर्ती स्कैन अक्षम करें; तुरंत इंटरैक्टिव स्कैन के लिए `failproofai audit` चलाएं।
  </Tab>
</Tabs>

<Warning>
  स्थानीय डैशबोर्ड स्थानीय एजेंट इतिहास से प्रॉम्प्ट, टूल इनपुट, फ़ाइल सामग्री और टर्मिनल आउटपुट प्रदर्शित कर सकता है। इसे केवल विश्वस्त इंटरफ़ेस पर बाइंड करें और समीक्षा पूर्ण होने पर प्रक्रिया को बंद करें।
</Warning>
