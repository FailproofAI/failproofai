एक AI टूल को Failproof AI Cloud से कनेक्ट करें और इससे अपने एजेंट्स के डेटा के साथ काम करें। आपका टूल सत्रों और घटनाओं को क्वेरी कर सकता है, रीड-ओनली SQL चला सकता है, डैशबोर्ड, अलर्ट, समस्याएं, ऑडिट और नीतियां पढ़ सकता है, और यदि आपके पास अनुमति है, तो अलर्ट बनाना या नीति तैनात करना जैसे परिवर्तन कर सकता है।

हर कॉल **आपकी स्वयं की** अनुमतियों के साथ चलती है, **एक** संगठन में जो आप कनेक्ट करते समय चुनते हैं।

सभी के लिए एक पता है, होस्ट किया गया या स्व-होस्ट किया गया:

```text
https://gateway.befailproof.ai/mcp
```

## क्लाइंट को कनेक्ट करें

पता अपने क्लाइंट में जोड़ें। पहली बार जब कोई टूल उपयोग किया जाता है, तो आपका ब्राउज़र खुलता है। चुनें कि आपका Failproof AI Cloud कहाँ है, साइन इन करें, एक संगठन चुनें, और **Allow** चुनें। **Cancel** कुछ भी कनेक्ट नहीं करता है।

पृष्ठ ऐप का नाम और जहाँ यह वापस जाता है उसका नाम बताता है। एक ऐप जो अपने स्वयं के वेब पता द्वारा पहचाना नहीं जाता है उसे **unverified app** के रूप में चिह्नित किया जाता है, इसलिए केवल तभी आगे बढ़ें यदि आपने इसे अभी अपने क्लाइंट से शुरू किया है।

<Tabs>
  <Tab title="Claude">
    claude.ai या Claude Desktop में, **Settings → Connectors → Add custom connector** पर जाएं। इसे `Failproof AI` नाम दें, पता दर्ज करें, **Add** चुनें, फिर **Connect** चुनें।

    Team और Enterprise प्लान पर, एक मालिक पहले संगठन के लिए कनेक्टर जोड़ता है। फिर प्रत्येक व्यक्ति अपने स्वयं के खाते को कनेक्ट करता है।
  </Tab>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http failproofai https://gateway.befailproof.ai/mcp
    ```

    फिर Claude Code के अंदर `/mcp` चलाएं, `failproofai` चुनें, और **Authenticate** चुनें।
  </Tab>
  <Tab title="Cursor">
    इसे `~/.cursor/mcp.json` में, या अपनी परियोजना के `.cursor/mcp.json` में जोड़ें:

    ```json
    {
      "mcpServers": {
        "failproofai": { "url": "https://gateway.befailproof.ai/mcp" }
      }
    }
    ```

    Cursor सर्वर के पास **Needs login** दिखाता है। साइन इन करने के लिए इसे चुनें।
  </Tab>
  <Tab title="Codex">
    इसे `~/.codex/config.toml` में जोड़ें:

    ```toml
    [mcp_servers.failproofai]
    url = "https://gateway.befailproof.ai/mcp"
    ```

    फिर `codex mcp login failproofai` चलाएं।
  </Tab>
  <Tab title="अन्य क्लाइंट">
    कोई भी क्लाइंट जो Streamable HTTP के साथ दूरस्थ MCP सर्वर को OAuth समर्थन करता है काम करता है। इसे ऊपर दिया गया पता दें। कोई क्लाइंट ID या गोपनीय कॉन्फ़िगर करने के लिए नहीं है।
  </Tab>
</Tabs>

## प्रति कनेक्शन एक संगठन

एक कनेक्शन केवल उस संगठन में कार्य करता है जो आपने चुना था। दो संगठनों का उपयोग करने के लिए, सर्वर को अलग-अलग नामों के तहत दो बार जोड़ें, जैसे `failproofai-acme` और `failproofai-sandbox`, और प्रत्येक को अपने संगठन से कनेक्ट करें।

डेमो संगठन कनेक्शन स्वीकार नहीं करते। इसके बजाय अपना स्वयं का संगठन चुनें।

## अनुमतियां

एक कनेक्शन नीचे दिए गए सेट के भीतर, संगठन में आप जो कर सकते हैं वह कर सकता है। यह आपकी वर्तमान अनुमतियों का पालन करता है: यदि कोई व्यवस्थापक आपको अधिक देता है, तो टूल को यह मिलता है, और यदि वे कुछ ले जाते हैं, तो टूल इसे अपनी अगली कॉल पर खो देता है।

| अनुमति | टूल को अनुमति देता है |
| --- | --- |
| `events:read` | घटनाओं को सूचीबद्ध करें, एक सत्र का अवलोकन पढ़ें, एजेंट्स और वातावरणों को सूचीबद्ध करें |
| `evaluations:read` | सत्रों को सूचीबद्ध करें, और मूल्यांकन परिणाम और नौकरियों को पढ़ें और सारांशित करें |
| `evaluations:trigger` | मूल्यांकन बनाएं, नए संस्करण प्रकाशित करें, उन्हें चालू या बंद करें, बैकफिल करें, और एक सत्र का पुनर्मूल्यांकन करें |
| `dashboards:read`, `dashboards:write` | डैशबोर्ड पढ़ें, या उन्हें बनाएं, नाम बदलें, और क्वेरी जोड़ें |
| `queries:read`, `queries:write` | सहेजी गई क्वेरीज़ को पढ़ें, या उन्हें सहेजें और संपादित करें |
| `queries:run` | एक रीड-ओनली SQL क्वेरी चलाएं और क्वेरी स्कीमा पढ़ें |
| `alerts:read`, `alerts:write` | अलर्ट पढ़ें, या उन्हें बनाएं, संपादित करें, रोकें, हटाएं, और परीक्षण करें |
| `issues:read` | समस्याओं को पढ़ें, उन्हें स्वीकार करें, और उन पर टिप्पणी करें |
| `issues:create` | एक अलर्ट पर समस्या खोलें |
| `issues:close` | समस्याओं को हल करें और बंद करें |
| `audits:read`, `audits:write` | ऑडिट, रन, और निष्कर्षों को पढ़ें, या ऑडिट बनाएं, संपादित करें और रन शुरू करें |
| `code_fixes:read` | देखें कि एक समस्या को कैसे ठीक करें, और अपने स्वयं के एजेंट को ठीक करने के लिए इसका संदर्भ प्राप्त करें |
| `code_fixes:write` | Failproof AI Cloud में एक फिक्स शुरू करें, जो आपके GitHub पर एक पुल अनुरोध खोलता है |
| `policies:read`, `policies:write` | नीतियां, मशीनें, और तैनाती पढ़ें, या नीतियां प्रकाशित करें, तैनात करें, और रोलबैक करें |

कुछ टूलों को कोई अनुमति की आवश्यकता नहीं है क्योंकि वे कोई संगठन डेटा नहीं पढ़ते: सत्र और घटना लिंक बनाना, और इस दस्तावेज़ को खोजना।

एक AI टूल कभी भी API कुंजी, उपयोगकर्ताओं, सेटिंग्स, या संगठन प्रशासन को नहीं छू सकता है, और यह घटनाएं नहीं भेज सकता है।

## परिवर्तनों को मंजूरी देना

यदि आपका क्लाइंट प्रॉम्प्ट दिखा सकता है तो लिखने के लिए पहले आपसे पूछा जाता है। आप देखते हैं कि क्या बदलेगा और आगे बढ़ने के लिए **Approve this change** चुनते हैं। यदि आप अस्वीकार करते हैं या लगभग 4 मिनट के भीतर उत्तर नहीं देते हैं, तो कुछ नहीं बदलता है। कुछ क्लाइंट एक मिनट के बाद प्रतीक्षा करना बंद कर देते हैं, इसलिए तुरंत उत्तर दें।

<Warning>
  एक क्लाइंट जो प्रॉम्प्ट को समर्थन नहीं करता है उससे पूछा नहीं जाता है, और एक लिखना क्लाइंट द्वारा कॉल करते ही चलता है। वहां, आपके क्लाइंट की अपनी पुष्टि ही एकमात्र है, इसलिए लिखने वाले टूल के लिए इसे चालू रखें।
</Warning>

## कनेक्ट किए गए ऐप्स और प्रतिबंधित करना

**Settings → Integrations → MCP** वर्तमान संगठन में आपके कनेक्ट किए गए ऐप्स को सूचीबद्ध करता है, उनकी अनुमतियों और अंतिम उपयोग के साथ। **Revoke** एक ऐप को तुरंत काट देता है। अपने क्लाइंट में सर्वर को हटाना कनेक्शन को भी प्रतिबंधित करता है।

आप प्रति संगठन में 5 कनेक्ट किए गए ऐप्स तक रख सकते हैं। एक ही ऐप को फिर से कनेक्ट करना इसके पहले के कनेक्शन को बदल देता है।

## स्व-होस्ट किए गए तैनातियां

कनेक्ट करते समय **Self-hosted Failproof AI Cloud** चुनें, और वह पता दर्ज करें जहाँ आप साइन इन करते हैं। आपकी तैनाती सार्वजनिक HTTPS पर पहुंचने योग्य होनी चाहिए।

टूल कॉल और उनके परिणाम आपके AI टूल और आपकी तैनाती के बीच होस्ट किए गए Failproof AI गेटवे के माध्यम से जाते हैं। गेटवे उन्हें स्टोर नहीं करता है।

## आपके डेटा के साथ क्या होता है

परिणाम उस AI टूल में जाते हैं जिसे आपने कनेक्ट किया है, और उस टूल का प्रदाता उन्हें अपनी शर्तों के तहत संभालता है। प्रत्येक टूल कॉल के लिए, Failproof AI टूल का नाम, इसका परिणाम, इसमें कितना समय लगा, और संगठन को लॉग करता है, कभी भी तर्क या परिणाम नहीं। [गोपनीयता नीति](https://befailproof.ai/privacy/) देखें।

| "You have 5 connected apps" | **Settings → Integrations → MCP** के तहत एक को प्रतिबंधित करें, फिर फिर से कनेक्ट करें |
