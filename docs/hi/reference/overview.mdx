## एजेंट को कनेक्ट करें और डेटा को सत्यापित करें

<Tabs>
  <Tab title="Dashboard">
    1. **Administration → Keys** खोलें, `events:add` और `policies:pull` के साथ एक key बनाएं, और secret को कॉपी करें।
    2. ऊपर दिए गए मिलते-जुलते पृष्ठ का उपयोग करके एकीकरण को कॉन्फ़िगर करें।
    3. **Observe → Events** खोलें ताकि confirm करें कि events आ रहे हैं, फिर **Observe → Sessions** खोलें ताकि confirm करें कि वे complete runs बनाते हैं।
    4. एकीकरण के environment को फ़िल्टर करें और model, tool, error, और policy fields के लिए one session का निरीक्षण करें जो audits द्वारा आवश्यक हैं।

    key drawer से शुरू करें। चयनित grants यह निर्धारित करते हैं कि क्या मशीन events भेज सकती है और Cloud-managed policies प्राप्त कर सकती है।

    ![नया API key drawer जो event ingestion और policy delivery permissions प्रदान करने के लिए उपयोग किया जाता है।](/images/dashboard/key-create.png)

    एकीकरण को कनेक्ट करने के बाद, Sessions list का उपयोग करके confirm करें कि इसके events को expected environment में complete runs में group किया जा रहा है।

    ![Sessions list जो verify करने के लिए उपयोग किया जाता है कि एक नया-कनेक्ट किया गया एकीकरण complete agent runs की रिपोर्ट कर रहा है।](/images/dashboard/sessions-list.png)

    एकीकरण को complete मानने से पहले इनमें से एक session को खोलें; trace में model, tool, error, और policy evidence होना चाहिए जो आपके audits को चाहिए।
  </Tab>
  <Tab title="CLI">
    एक machine key बनाएं, Failproof daemon को कनेक्ट करें, और पहले session को verify करें।

    ```bash
    fp keys create agent-production \
      --add events:add \
      --add policies:pull

    failproofai config \
      --connect https://app.befailproof.ai \
      --token <machine-key>

    failproofai flush --wait
    fp sessions --since 1h --env production
    fp events --since 1h --env production --limit 20
    ```

    जब कोई अन्य tool परिणाम का उपभोग करेगा तो `fp --json sessions ...` का उपयोग करें। Global flags जैसे `--json`, `--org`, और `--base-url` को command से पहले आना चाहिए।

    स्थानीय commands के लिए [Failproof AI CLI संदर्भ](/hi/reference/failproof-cli) और `fp` commands के लिए [Failproof Cloud CLI संदर्भ](/hi/reference/cloud-cli#cli-commands) देखें।
  </Tab>
</Tabs>
