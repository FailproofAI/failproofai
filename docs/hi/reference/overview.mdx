## एक agent को कनेक्ट करें और डेटा सत्यापित करें

<Tabs>
  <Tab title="Dashboard">
    1. **Administration → Keys** खोलें, `events:add` और `policies:pull` के साथ एक key बनाएं, और secret को कॉपी करें।
    2. ऊपर दिए गए मिलान पृष्ठ का उपयोग करके integration को कॉन्फ़िगर करें।
    3. **Observe → Events** खोलें यह पुष्टि करने के लिए कि events आ रहे हैं, फिर **Observe → Sessions** खोलें यह पुष्टि करने के लिए कि वे पूर्ण runs बनाते हैं।
    4. integration के environment के लिए फ़िल्टर करें और audits के लिए आवश्यक model, tool, error, और policy fields के लिए एक session की जांच करें।

    key drawer से शुरुआत करें। चयनित grants निर्धारित करते हैं कि machine क्या events भेज सकता है और Cloud-managed policies प्राप्त कर सकता है।

    ![नया API key drawer जिसका उपयोग event ingestion और policy delivery permissions देने के लिए किया जाता है।](/images/dashboard/key-create.png)

    integration को कनेक्ट करने के बाद, Sessions list का उपयोग करके पुष्टि करें कि इसके events अपेक्षित environment में पूर्ण runs में grouped हो रहे हैं।

    ![Sessions list जिसका उपयोग यह सत्यापित करने के लिए किया जाता है कि एक नया कनेक्ट किया गया integration पूर्ण agent runs की रिपोर्ट कर रहा है।](/images/dashboard/sessions-list.png)

    integration को पूर्ण मानने से पहले इनमें से एक session खोलें; trace में वह model, tool, error, और policy evidence होना चाहिए जो आपके audits को चाहिए।
  </Tab>
  <Tab title="CLI">
    एक machine key बनाएं, Failproof daemon को कनेक्ट करें, और पहले session को सत्यापित करें।

    ```bash
    fp keys create agent-production \
      --add events:add \
      --add policies:pull

    failproofai config \
      --connect https://app.befailproof.ai \
      --token <machine-key>

    failproofai flush --wait
    fp sessions --since 1h --env production
    fp events --since 1h --env production --limit 20
    ```

    जब कोई अन्य tool परिणाम का उपभोग करेगा तो `fp --json sessions ...` का उपयोग करें। Global flags जैसे `--json`, `--org`, और `--base-url` को command से पहले आना चाहिए।

    स्थानीय commands के लिए [Failproof AI CLI reference](/hi/reference/failproof-cli) और `fp` commands के लिए [Failproof Cloud CLI reference](/hi/reference/cloud-cli#cli-commands) देखें।
  </Tab>
</Tabs>
