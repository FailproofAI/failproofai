## एजेंट को कनेक्ट करें और डेटा सत्यापित करें

<Tabs>
  <Tab title="Dashboard">
    1. **Administration → Keys** खोलें, `events:add` और `policies:pull` के साथ एक कुंजी बनाएं, और गोपनीय को कॉपी करें।
    2. ऊपर दिए गए मिलान पृष्ठ का उपयोग करके एकीकरण को कॉन्फ़िगर करें।
    3. **Observe → Events** खोलें यह पुष्टि करने के लिए कि घटनाएं आती हैं, फिर **Observe → Sessions** खोलें यह पुष्टि करने के लिए कि वे पूर्ण रन बनाती हैं।
    4. एकीकरण के पर्यावरण में फ़िल्टर करें और ऑडिट के लिए आवश्यक मॉडल, टूल, त्रुटि और नीति फ़ील्ड के लिए एक सेशन की जांच करें।

    कुंजी ड्रॉअर से शुरू करें। चयनित अनुदान यह निर्धारित करते हैं कि क्या मशीन घटनाएं भेज सकती है और Cloud-प्रबंधित नीति प्राप्त कर सकती है।

    ![नई API कुंजी ड्रॉअर जिसका उपयोग घटना सेवन और नीति वितरण अनुमति प्रदान करने के लिए किया जाता है।](/images/dashboard/key-create.png)

    एकीकरण को कनेक्ट करने के बाद, यह पुष्टि करने के लिए सेशन सूची का उपयोग करें कि इसकी घटनाएं अपेक्षित पर्यावरण में पूर्ण रन में समूहीकृत की जा रही हैं।

    ![सेशन सूची जिसका उपयोग यह सत्यापित करने के लिए किया जाता है कि नव जुड़ा हुआ एकीकरण पूर्ण एजेंट रन की रिपोर्ट कर रहा है।](/images/dashboard/sessions-list.png)

    एकीकरण को पूर्ण मानने से पहले इनमें से एक सेशन खोलें; ट्रेस में मॉडल, टूल, त्रुटि और नीति साक्ष्य होना चाहिए जो आपके ऑडिट को चाहिए।
  </Tab>
  <Tab title="CLI">
    एक मशीन कुंजी बनाएं, Failproof डेमन को कनेक्ट करें, और पहला सेशन सत्यापित करें।

    ```bash
    fp keys create agent-production \
      --add events:add \
      --add policies:pull

    failproofai config \
      --connect https://app.befailproof.ai \
      --token <machine-key>

    failproofai flush --wait
    fp sessions --since 1h --env production
    fp events --since 1h --env production --limit 20
    ```

    जब कोई अन्य टूल परिणाम का उपभोग करेगा तो `fp --json sessions ...` का उपयोग करें। `--json`, `--org`, और `--base-url` जैसे वैश्विक फ़्लैग कमांड से पहले आने चाहिए।

    स्थानीय कमांड के लिए [Failproof AI CLI संदर्भ](/hi/reference/failproof-cli) और `fp` कमांड के लिए [Failproof Cloud CLI संदर्भ](/hi/reference/cloud-cli#cli-commands) देखें।
  </Tab>
</Tabs>
