Failproof Assistant से Failproof AI में कुछ भी करने के लिए प्राकृतिक भाषा में पूछें। यह सेशन और विफलताओं का विश्लेषण कर सकता है, क्वेरी चला सकता है, डैशबोर्ड बना सकता है, मूल्यांकन और सतर्कताओं की जांच कर सकता है, और ऑडिट बनाने और चलाने में मदद कर सकता है - बिना आपको कार्य को प्रोडक्ट स्क्रीन या CLI कमांड में बदलने की आवश्यकता के।

```text
Why did production checkout agents regress this week?
Build a dashboard for tool failures, latency, and evaluation scores.
Create an audit that finds agents retrying the same failed action without changing approach.
Show me the sessions behind the most common audit finding.
```

सहायक सक्रिय संगठन में उपलब्ध डेटा और अनुमतियों के साथ काम करता है। किसी भी कार्रवाई को लागू करने से पहले जो अन्य उपयोगकर्ताओं या एजेंटों को प्रभावित करे, इसके साक्ष्य और प्रस्तावित परिवर्तनों की समीक्षा करें।

## सहायक से पूछें

<Tabs>
  <Tab title="Dashboard">
    1. **Open agent chat** चुनें और वर्णन करें कि आप क्या समझना, बनाना या संचालित करना चाहते हैं।
    2. सहायक के टूल कॉल, तालिकाओं और क्वेरी परिणामों की समीक्षा करें जब यह काम कर रहा हो।
    3. उद्धृत सेशन, सतर्कता या क्वेरी को खोलें और परिणाम को स्रोत डेटा के विरुद्ध सत्यापित करें।
    4. एक अलग जांच के लिए नया चैट शुरू करें, या समान विश्लेषण की पंक्ति को जारी रखने के लिए चैट इतिहास का उपयोग करें।

## सहायक के साथ प्रभावी ढंग से काम करें

- पहले इसे एक लक्ष्य दें; जब ये सीमाएं महत्वपूर्ण हों तो पर्यावरण, वर्कफ़्लो या समय सीमा जोड़ें।
- जनित SQL और सारांश को अंतिम साक्ष्य नहीं, जांच सहायता के रूप में मानें।
- ऑडिट, समस्या, सतर्कता या नीति बनाने से पहले प्रतिनिधि सेशन खोलें।
- संगठन, पर्यावरण और समय फ़िल्टर को स्पष्ट रखें।
- उपयोगी SQL को क्वेरी के रूप में सहेजें ताकि अन्य ऑपरेटर परिणाम को पुन: उत्पन्न कर सकें।

<Warning>
  सहायक केवल वह देख सकता है जो आपका वर्तमान उपयोगकर्ता एक्सेस कर सकता है। किसी प्रश्न को काम करने के लिए अनुमतियों को व्यापक न करें; इसके बजाय एक अधिकृत ऑपरेटर से जांच चलाने के लिए कहें।
</Warning>
