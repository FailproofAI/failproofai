Failproof Assistant से Failproof AI में कुछ भी प्राकृतिक भाषा में करने के लिए कहें। यह सत्रों और विफलताओं का विश्लेषण कर सकता है, क्वेरीज़ चला सकता है, डैशबोर्ड बना सकता है, मूल्यांकन और अलर्ट की जांच कर सकता है, और ऑडिट बनाने और चलाने में मदद कर सकता है - बिना आपको कार्य को उत्पाद स्क्रीन या CLI कमांड में अनुवादित करने की आवश्यकता के।

```text
Why did production checkout agents regress this week?
Build a dashboard for tool failures, latency, and evaluation scores.
Create an audit that finds agents retrying the same failed action without changing approach.
Show me the sessions behind the most common audit finding.
```

यह सहायक सक्रिय संगठन में उपलब्ध डेटा और अनुमतियों के साथ काम करता है। अपनी कार्रवाइयों को लागू करने से पहले जो अन्य उपयोगकर्ताओं या एजेंटों को प्रभावित करते हैं, इसके साक्ष्य और प्रस्तावित परिवर्तनों की समीक्षा करें।

## सहायक से पूछें

<Tabs>
  <Tab title="Dashboard">
    1. **Open agent chat** चुनें और वर्णन करें कि आप क्या समझना, बनाना या संचालित करना चाहते हैं।
    2. सहायक के उपकरण कॉल, तालिकाओं और क्वेरी परिणामों की समीक्षा करें जबकि वह काम करता है।
    3. उद्धृत सत्र, अलर्ट या क्वेरी को खोलें परिणाम को स्रोत डेटा के विरुद्ध सत्यापित करने के लिए।
    4. एक अलग जांच के लिए एक नई चैट शुरू करें, या विश्लेषण की एक ही पंक्ति जारी रखने के लिए चैट इतिहास का उपयोग करें।

## सहायक के साथ प्रभावी ढंग से काम करें

- पहले इसे एक लक्ष्य दें; जब वे सीमाएं महत्वपूर्ण हों तो एक वातावरण, वर्कफ़्लो या समय सीमा जोड़ें।
- उत्पन्न SQL और सारांशों को अंतिम साक्ष्य के रूप में नहीं, बल्कि एक जांच सहायता के रूप में मानें।
- एक ऑडिट, समस्या, अलर्ट या नीति बनाने से पहले प्रतिनिधि सत्र खोलें।
- संगठन, वातावरण और समय फ़िल्टर को स्पष्ट रखें।
- उपयोगी SQL को एक क्वेरी के रूप में सहेजें ताकि एक अन्य ऑपरेटर परिणाम को दोहरा सके।

<Warning>
  सहायक केवल वही पढ़ सकता है जो आपका वर्तमान उपयोगकर्ता एक्सेस कर सकता है। किसी प्रश्न को काम करने के लिए अनुमतियां विस्तृत न करें; इसके बजाय किसी अधिकृत ऑपरेटर से जांच चलाने के लिए कहें।
</Warning>
