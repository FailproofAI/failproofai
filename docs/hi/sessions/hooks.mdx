---

Hooks दिखाता है कि agent lifecycle hooks कब चलते हैं और उन्हें कितना समय लगता है। Policy निर्णय एक अलग view हैं।

<Tabs>
  <Tab title="Dashboard">
    1. **Observe → Hooks** पर जाएं।
    2. Environment, hook name, trigger event, agent, या session ID द्वारा फ़िल्टर करें।
    3. Hook latency और distribution की समीक्षा करें।
    4. अंतर्निहित events को खोलने के लिए किसी chart point या hook segment को चुनें।

    ![Hooks page जो hook name और trigger event द्वारा grouped latency दिखा रहा है।](/images/dashboard/hooks.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list hooks
    fp events --event-type hook_triggered,hook_completed --env production --since 24h
    fp events --search "PreToolUse" --since 24h
    ```
  </Tab>
</Tabs>
