एक hook एक बिंदु है जहाँ एक agent Failproof AI से निर्णय के लिए अनुरोध करता है। Hook activity इस event, policy, outcome और evaluation time को record करती है।

## Hook activity की जांच करें

<Tabs>
  <Tab title="Dashboard">
    **Observe → Hooks** पर जाएं। Environment, event, agent या session के आधार पर filter करें।

    ![The Hooks page showing latency grouped by hook name and trigger event.](/images/dashboard/hooks.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp guardrails summary --since 24h
    fp --json events --full --event-type hook_completed --session-id <session-id> --all --limit 500
    fp list hooks
    ```
  </Tab>
</Tabs>

डिफ़ॉल्ट रूप से, हर `deny` और `instruct` निर्णय पूरी तरह भेजा जाता है। Repeated allows को noise कम करने के लिए grouped किया जाता है। `~/.failproofai/config.json` में `collector.hooks_verbosity` को `all`, `decisions` या `off` पर सेट करें।

<Warning>
  Hook activity यह साबित करती है कि evaluation चली, यह नहीं कि harness उस event को block कर सकता था। [enforcement capability](/hi/reference/harnesses#enforcement-capability) देखें। एक unlisted harness-event pair unverified है।
</Warning>
