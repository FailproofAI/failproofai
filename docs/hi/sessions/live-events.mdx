लाइव ईवेंट्स एजेंट्स के चलने के समय गतिविधि दिखाता है: मॉडल कॉल, टूल्स, त्रुटियां, मानव इनपुट, हुक्स, और पॉलिसी निर्णय।

## गतिविधि देखें

**Observe → Live events** पर जाएं, या यह चलाएं:

```bash
fp events --since 1h
fp events --event-type tool_use,tool_result --since 1h
fp --json events --full --session-id <session-id> --all --limit 2000
```

जब आपको पेलोड कंटेंट्स की आवश्यकता हो तो `--full` का उपयोग करें। लाइट फीड तेजी से है और अधिकांश फ़िल्टरिंग के लिए पर्याप्त है।

सामान्य ईवेंट प्रकारों में शामिल हैं:

- `session_start` और `session_end`
- `model_request` और `model_response`
- `tool_use` और `tool_result`
- `hook_triggered` और `hook_completed`
- `error`
- `human_wait` और `human_input`
- `agent_pause` और `agent_resume`

## यदि ईवेंट्स दिखाई नहीं देते

```bash
failproofai flush --wait
failproofai config --status
failproofai backfill --since 30d --dry-run
```

डिफ़ॉल्ट पर्यावरण `local` है। `production` के लिए एक फ़िल्टर तब तक कुछ नहीं लौटाता जब तक आप पर्यावरण लेबल को बदलते नहीं हैं।

एक समर्थित हार्नेस के बाहर एजेंट के लिए, [Python SDK](/hi/reference/custom-agents) का उपयोग करें।
