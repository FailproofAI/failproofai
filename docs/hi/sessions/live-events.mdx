लाइव events आपको instrumentation की पुष्टि करने और जोखिम भरे run को देखने में मदद करते हैं, बिना सत्र के समाप्त होने का इंतजार किए।

## Activity देखें

<Tabs>
  <Tab title="Dashboard">
    1. **Observe → Events** पर जाएं।
    2. वर्तमान समय विंडो के साथ शुरू करें और डेटा आने की पुष्टि करने के लिए कोई फ़िल्टर न रखें।
    3. Environment, event type, agent, या session के आधार पर फ़िल्टर करें। Payload text के लिए search का उपयोग करें।
    4. एक event चुनें इसके सारांश और विवरण को देखने के लिए। पूरी trace के लिए इसके session link को फॉलो करें।

    ![लाइव Events stream जो Hermes chat gateway से traffic दिखा रहा है साथ ही coding-CLI runs, समय, environment, event type, agent, model, context, और session के आधार पर फ़िल्टर किए गए।](/images/dashboard/events-stream-current.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp events --env production --event-type tool_use,error --limit 100
    fp events --session-id <session-id> --order asc --all
    fp --json events --full --session-id <session-id> --all
    ```

    डिफ़ॉल्ट feed raw payloads को छोड़ देता है। `--full` का उपयोग केवल bounded session investigation के लिए करें।
  </Tab>
</Tabs>

तीन तुरंत सवालों के जवाब देने के लिए event stream का उपयोग करें:

- क्या अपेक्षित agent सही environment को रिपोर्ट कर रहा है?
- क्या model calls, tool calls, और policy decisions क्रम में आ रहे हैं?
- क्या सत्र प्रगति करना बंद कर गया है या किसी action को दोहराना शुरू कर दिया है?

Event types में agent lifecycle events, model requests और responses, tool use और results, hook execution, human waits और interrupts, और explicit errors शामिल हैं। Correlation IDs जोड़ी गई events को जोड़ते हैं जैसे कि एक tool call और इसका result।

<Tip>
  किसी नए integration को सत्यापित करते समय लाइव view को व्यापक रखें। पहले event को देखने के बाद ही फ़िल्टर जोड़ें; एक गलत फ़िल्टर विफल ingestion जैसा दिख सकता है।
</Tip>

यदि कोई events दिखाई न दें, तो `failproofai config --status` चलाएं, फिर [troubleshoot ingestion](/hi/reference/troubleshooting)।

Agents जो 12 समर्थित [harnesses](/hi/reference/harnesses) में से किसी एक में नहीं चलते हैं, [Python SDK](/hi/reference/custom-agents) के माध्यम से एक ही event types रिपोर्ट करते हैं, जिनमें human-in-the-loop events (`human_wait`, `human_input`, `human_interrupt`) शामिल हैं जो gateway और production agents पर निर्भर हैं।
