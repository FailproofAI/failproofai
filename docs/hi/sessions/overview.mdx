एक सेशन सबसे अच्छा शुरुआती बिंदु है जब कोई एजेंट अप्रत्याशित रूप से व्यवहार करता है। यह एक रन से संबंधित मॉडल अनुरोधों, प्रतिक्रियाओं, टूल कॉलों, मानव इंटरैक्शन, त्रुटियों, मूल्यांकनों और नीति निर्णयों को जोड़ता है।

सेशन वही दिखते हैं चाहे किसी भी हार्नेस ने उन्हें बनाया हो। एक Claude Code रन जो किसी रिपॉजिटरी को फिर से लिखता है, एक Hermes एजेंट जो Slack में ग्राहक को जवाब देता है, और एक Python सेवा जो SDK से जुड़ी है, सभी एक ही ट्रेस फॉर्मेट में आते हैं, इसलिए एक दृश्य पूरे बेड़े को कवर करता है।

एक एजेंट रन को इसके लक्ष्य से शुरू करके मॉडल कॉलों, टूलों और अंतिम प्रतिक्रिया तक फॉलो करें।

## एक सेशन खोजें

<Tabs>
  <Tab title="डैशबोर्ड">
    1. क्लाउड साइडबार में, **Observe → Sessions** पर जाएं।
    2. समय विंडो सेट करें, फिर पर्यावरण, स्थिति, एजेंट या सेशन ID द्वारा फ़िल्टर करें।
    3. जब आपको गुणवत्ता, लागत, टोकन या लेटेंसी स्लाइस चाहिए तो स्कोर या मेट्रिक रेंज जोड़ें।
    4. इसका ट्रेस खोलने के लिए एक पंक्ति चुनें। सेशन ID के बगल में कॉपी नियंत्रण का उपयोग करें जब इसे साझा कर रहे हों।

    ![सेशन सूची जो पर्यावरण, एजेंट, स्थिति और मूल्यांकन स्कोर फ़िल्टर के साथ प्रति रन एक पंक्ति दिखाती है।](/images/dashboard/sessions-list.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp sessions --env production --since 24h
    fp sessions --status error,timeout --agent-id checkout-agent
    fp --json sessions --session-id <session-id>
    ```

    मल्टी-एजेंट रन विस्तारित करने के लिए `--agents` जोड़ें, पेजिनेट करने के लिए `--all` जोड़ें, या आउटपुट कॉलम चुनने के लिए `--fields` जोड़ें।
  </Tab>
</Tabs>

## आप क्या कर सकते हैं

- एजेंट, पर्यावरण, समय, मॉडल, इवेंट प्रकार या त्रुटि स्थिति द्वारा एक रन खोजें।
- सटीक अनुक्रम का पालन करें जिसने परिणाम का उत्पादन किया।
- सफल और विफल रन की तुलना करें।
- एक ऑडिट खोज या अलर्ट घटना द्वारा उपयोग किए गए साक्ष्य को खोलें।
- जब आपको ऑफलाइन रिकॉर्ड चाहिए तो एक सेशन एक्सपोर्ट करें।

## एक विश्वसनीय जांच क्रम

1. सेशन लक्ष्य और पर्यावरण की पुष्टि करें।
2. पहली त्रुटि या अप्रत्याशित निर्णय खोजें—केवल अंतिम विफलता नहीं।
3. इससे तुरंत पहले मॉडल संदर्भ और टूल इनपुट का निरीक्षण करें।
4. पुनः प्रयास, लेटेंसी और मानव हस्तक्षेपों की जांच करें।
5. मूल्यांकन स्कोर और नीति निर्णयों की समीक्षा करें।
