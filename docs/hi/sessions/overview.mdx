सेशन सबसे अच्छा शुरुआती बिंदु है जब कोई एजेंट अप्रत्याशित रूप से व्यवहार करता है। यह मॉडल अनुरोधों, प्रतिक्रियाओं, टूल कॉल, मानव इंटरैक्शन, त्रुटियों, मूल्यांकन और नीति निर्णयों को जोड़ता है जो एक रन से संबंधित हैं।

सेशन उसी तरह दिखते हैं भले ही कौन सा हार्नेस उन्हें बनाता है। Claude Code एक रिपॉजिटरी को फिर से लिखता है, Hermes एजेंट Slack में किसी ग्राहक को उत्तर देता है, और SDK के साथ उपकरणीकृत Python सेवा सभी एक ही ट्रेस प्रारूप में आते हैं, इसलिए एक दृश्य पूरे फ्लीट को कवर करता है।

एक एजेंट रन को इसके लक्ष्य से मॉडल कॉल, टूल और अंतिम प्रतिक्रिया तक फॉलो करें।

## सेशन खोजें

<Tabs>
  <Tab title="डैशबोर्ड">
    1. क्लाउड साइडबार में, **Observe → Sessions** पर जाएं।
    2. समय विंडो सेट करें, फिर पर्यावरण, स्थिति, एजेंट या सेशन ID द्वारा फ़िल्टर करें।
    3. जब आपको गुणवत्ता, लागत, टोकन या विलंबता स्लाइस की आवश्यकता हो तो स्कोर या मेट्रिक रेंज जोड़ें।
    4. इसके ट्रेस को खोलने के लिए एक पंक्ति चुनें। इसे साझा करते समय सेशन ID के बगल में कॉपी नियंत्रण का उपयोग करें।

    ![सेशन सूची जो पर्यावरण, एजेंट, स्थिति और मूल्यांकन स्कोर फ़िल्टर के साथ प्रति रन एक पंक्ति दिखाती है।](/images/dashboard/sessions-list.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp sessions --env production --since 24h
    fp sessions --status error,timeout --agent-id checkout-agent
    fp --json sessions --session-id <session-id>
    ```

    मल्टी-एजेंट रन का विस्तार करने के लिए `--agents` जोड़ें, पेजिनेट करने के लिए `--all` जोड़ें, या आउटपुट कॉलम चुनने के लिए `--fields` जोड़ें।
  </Tab>
</Tabs>

## आप क्या कर सकते हैं

- एजेंट, पर्यावरण, समय, मॉडल, इवेंट प्रकार या त्रुटि स्थिति द्वारा एक रन खोजें।
- उस सटीक क्रम का पालन करें जिसने एक परिणाम दिया।
- सफल और विफल रन की तुलना करें।
- ऑडिट खोज या सतर्कता घटना द्वारा उपयोग किए गए साक्ष्य खोलें।
- जब आपको ऑफलाइन रिकॉर्ड की आवश्यकता हो तो एक सेशन निर्यात करें।

## एक विश्वसनीय जांच क्रम

1. सेशन लक्ष्य और पर्यावरण की पुष्टि करें।
2. पहली त्रुटि या अप्रत्याशित निर्णय खोजें—केवल अंतिम विफलता नहीं।
3. इसके तुरंत पहले मॉडल संदर्भ और टूल इनपुट की जांच करें।
4. पुनः प्रयास, विलंबता और मानव हस्तक्षेप की जांच करें।
5. मूल्यांकन स्कोर और नीति निर्णयों की समीक्षा करें।
