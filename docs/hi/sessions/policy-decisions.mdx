## observe रोलआउट को पढ़ें

Observe मोड वास्तविक नीति चलाता है और किसी भी `deny` या `instruct` निर्णय को रिकॉर्ड करता है। एजेंट को अभी भी जारी रखने की अनुमति है।

```bash
fp fleet deploy <machine> --add <policy>:observe
fp guardrails summary --since 24h --machine <machine>
fp fleet deploy <machine> --add <policy>:enforce
```

<Warning>
  एक सामान्य `--add <policy>` तुरंत प्रवर्तित करता है जब नीति का कोई मौजूदा तैनाती नहीं है। एक छाया रोलआउट के लिए `:observe` जोड़ें।
</Warning>

केवल गैर-allow देखे गए निर्णय रिकॉर्ड किए जाते हैं। एक टाइमआउट एक allow के रूप में रिकॉर्ड होता है, क्योंकि यह enforce मोड में भी होता है।

एक रिकॉर्ड किया गया deny यह साक्ष्य नहीं है कि harness ने कार्रवाई को रोका है। Tool-call denies सभी 12 समर्थित harnesses में सत्यापित किए जाते हैं; अन्य घटनाएं भिन्न होती हैं। [प्रवर्तन क्षमता](/hi/reference/harnesses#enforcement-capability) देखें।

## अप्रत्याशित परिणाम की जांच करें

| आप क्या देखते हैं | जांचें |
| --- | --- |
| कोई निर्णय नहीं | `failproofai config --status` और क्या सत्र को रोका गया है |
| कोई नीति का नाम नहीं के साथ कई इनकार | [नीति विफलता व्यवहार](/hi/policies/failure-behavior) |
| हर संरक्षित कार्रवाई इनकार की गई | क्या `failproofaid` सेवा स्वस्थ है |
| एक deny जिसे आप अक्षम नहीं कर सकते | `block-failproofai-commands` हमेशा चालू है |
| `--env production` के लिए कोई डेटा नहीं | नई मशीनें environment `local` का उपयोग करती हैं |
