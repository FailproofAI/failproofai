Policy निर्णय enforcement द्वारा किए गए कार्यों की व्याख्या करता है। इसका उपयोग rollout को सत्यापित करने, block rate को मापने और असुरक्षित गतिविधि खोजने के लिए करें।

<Tabs>
  <Tab title="Dashboard">
    1. **Observe → policy** पर जाएं और समय सीमा और वैकल्पिक रूप से एक मशीन चुनें।
    2. मूल्यांकन की गई कार्रवाइयों, blocks, block rate, Cloud निर्णयों, असुरक्षित कार्रवाइयों और pause के दौरान की गतिविधि की समीक्षा करें।
    3. policy mapping table को filter करें और deployed assignments का निरीक्षण करें।
    4. निर्णयों और उनके sessions को खोलने के लिए एक chart point चुनें।

    ![Policy पृष्ठ जो निर्णय totals, एक मशीन filter, समय के साथ enforcement activity, और policy mapping table दिखाता है।](/images/dashboard/policy-observe.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp events --event-type hook_completed --env production --since 24h
    fp events --search "deny" --since 24h
    failproofai config --status
    ```

    मशीन की local enforcement state के लिए `failproofai` का उपयोग करें और Cloud event investigation के लिए `fp` का उपयोग करें।
  </Tab>
</Tabs>
