Policy decisions बताता है कि enforcement ने क्या किया। इसका उपयोग rollout को verify करने, block rate को मापने और unguarded activity को खोजने के लिए करें।

<Tabs>
  <Tab title="Dashboard">
    1. **Observe → policy** पर जाएं और समय सीमा और वैकल्पिक रूप से एक मशीन चुनें।
    2. मूल्यांकन की गई actions, blocks, block rate, Cloud decisions, unguarded actions, और paused होने के दौरान activity की समीक्षा करें।
    3. policy mapping table को फ़िल्टर करें और deployed assignments का निरीक्षण करें।
    4. decisions और उनके sessions को खोलने के लिए एक chart point चुनें।

    ![Policy page जो decision totals, एक machine filter, enforcement activity over time, और policy mapping table दिखा रहा है।](/images/dashboard/policy-observe.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp events --event-type hook_completed --env production --since 24h
    fp events --search "deny" --since 24h
    failproofai config --status
    ```

    मशीन की local enforcement state के लिए `failproofai` का उपयोग करें और Cloud event investigation के लिए `fp` का उपयोग करें।
  </Tab>
</Tabs>
