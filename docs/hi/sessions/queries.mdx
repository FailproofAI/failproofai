क्वेरीज़ डैशबोर्ड, ऑडिट और जांच के नीचे का लचीला परत है। एक विचार को परीक्षण करने के लिए ad-hoc SQL का उपयोग करें, फिर जब यह एक आवर्ती वर्कफ़्लो का हिस्सा बन जाए तो क्वेरी को सहेजें।

## क्वेरी बनाएं और चलाएं

<Tabs>
  <Tab title="Dashboard">
    1. **Analyze → Queries** पर जाएं और **new query** चुनें।
    2. स्कीमा ब्राउज़र खोलें और इवेंट, सेशन या मूल्यांकन डेटा से फ़ील्ड चुनें।
    3. SQL लिखें, जरूरत पड़ने पर पैरामीटर जोड़ें और क्वेरी चलाएं।
    4. इसे एक स्पष्ट नाम और विवरण के साथ सहेजें, फिर जब परिणाम की निगरानी करनी हो तो **add to dashboard** का उपयोग करें।

    क्वेरी एडिटर इवेंट स्कीमा, SQL, पैरामीटर और एक परिणाम पूर्वावलोकन को जोड़ता है ताकि आप इसे सहेजने से पहले सवाल को सत्यापित कर सकें।

    ![SQL क्वेरी एडिटर स्कीमा ब्राउज़र और लाइव परिणाम ग्रिड के साथ।](/images/dashboard/query-lab.png)

    सहेजी गई क्वेरीज़ तब साझा लाइब्रेरी में दिखाई देती हैं, जहां टीम के सदस्य उन्हें फिर से चला सकते हैं या अपने परिणामों को डैशबोर्ड में जोड़ सकते हैं।

    ![पुनः उपयोग योग्य निर्मित और कस्टम क्वेरीज़ युक्त सहेजी गई Queries लाइब्रेरी।](/images/dashboard/queries.png)

    एक स्पष्ट नाम और विवरण का उपयोग करें ताकि परिणाम इसके SQL को फिर से खोले बिना समझने योग्य रहे।
  </Tab>
  <Tab title="CLI">
    ```bash
    fp query schema
    fp query create "retry loops" --sql "SELECT ..."
    fp query run <query-id>
    fp query show <query-id>
    fp query update <query-id> --sql "SELECT ..."
    ```

    IDs खोजने के लिए `fp query list` का उपयोग करें और सहेजी गई क्वेरी को हटाने के लिए `fp query delete <query-id>` का उपयोग करें।
  </Tab>
</Tabs>

## सामान्य उपयोग

- एक ही टूल के लिए बार-बार कॉल वाले सेशन खोजें।
- मॉडल या वातावरण में मूल्यांकन स्कोर की तुलना करें।
- किसी मानव प्रतीक्षा और पुनः शुरुआत के बीच का समय मापें।
- नीति इनकार के बाद एक सफल विकल्प की पहचान करें।
- ऑडिट के लिए एक समूह बनाएं।

अपरिचित फ़ील्ड के विरुद्ध लिखने से पहले **Queries → Schema** खोलें। स्पष्ट समय और पर्यावरण फ़िल्टर को प्राथमिकता दें, और अन्वेषण के दौरान परिणाम सीमा रखें।

<Warning>
  एक क्वेरी एक संदिग्ध पैटर्न की पहचान कर सकती है, लेकिन यह अपने आप से विफलता मोड स्थापित नहीं करती है। प्रतिनिधि ट्रेस खोलें या परिणाम को नीति में बदलने से पहले ऑडिट चलाएं।
</Warning>
