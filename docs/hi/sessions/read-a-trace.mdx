ट्रेस एक फ्लैट ईवेंट स्ट्रीम को रन की कारणात्मक कथा में बदल देता है। इसे पहले विचलन से पढ़ें, न कि अंतिम त्रुटि से पीछे की ओर।

## ट्रेस खोलें

<Tabs>
  <Tab title="Dashboard">
    1. **Observe → Sessions** पर जाएं और एक सेशन खोलें।
    2. परिणाम, समय, त्रुटियां और मूल्यांकन स्कोर जांचने के लिए प्रोफाइल सारांश का उपयोग करें।
    3. टाइमलाइन और मिनिमैप स्कैन करें। जब सेशन बड़ा हो तो ईवेंट प्रकार या समय को फ़िल्टर करें।
    4. एक ईवेंट चुनें इसका निरीक्षण करने के लिए। मूल्यांकनकर्ता JSON के लिए **export** का उपयोग करें, या चयनित साक्ष्य के लिए गहरी लिंक साझा करने के लिए पृष्ठ URL की प्रतिलिपि बनाएं।

    ![एक सेशन विस्तृत दृश्य जिसमें इसका निष्पादन ग्राफ, ईवेंट टाइमलाइन, मूल्यांकन पैनल, और टूल, मॉडल और हुक ब्रेकडाउन है।](/images/dashboard/session-detail.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp --json sessions --session-id <session-id>
    fp events --session-id <session-id> --order asc --all
    fp --json events --full --session-id <session-id> --all
    ```

    पहले हल्के ईवेंट फीड का उपयोग करें। पूर्ण पेलोड केवल तभी मांगें जब ईवेंट सारांश में पर्याप्त साक्ष्य न हो।
  </Tab>
</Tabs>

<Steps>
  <Step title="अपने आप को ओरिएंट करें">
    एजेंट, पर्यावरण, समय, परिणाम और अवधि की पुष्टि करें, फिर त्रुटियां, लंबे स्पैन, दोहराए गए टूल, मानव प्रतीक्षा और अस्वीकृत नीति निर्णयों को स्कैन करें।
  </Step>
  <Step title="पहले संदिग्ध ईवेंट को विस्तृत करें">
    इसके अनुरोध, प्रतिक्रिया, टूल इनपुट, आउटपुट और सहसंबंध ID का निरीक्षण करें। संवेदनशील सामग्री केवल तब दिखाई देती है जब ट्रांसक्रिप्ट कैप्चर सक्षम हो और आपकी अनुमतियां इसकी अनुमति देती हों।
  </Step>
  <Step title="पूर्ववर्ती संदर्भ का निरीक्षण करें">
    कारण अक्सर एक ईवेंट पहले होता है: एक गलत मॉडल प्रतिक्रिया, लापता टूल परिणाम, या पुरानी धारणा।
  </Step>
  <Step title="साक्ष्य को कार्रवाई में बदलें">
    सेशन को ऑडिट स्कोप में जोड़ें, इसे किसी समस्या से लिंक करें, या विफलता मोड का उपयोग करके एक नीति लिखें।
  </Step>
</Steps>

<Warning>
  लंबी अवधि हमेशा मॉडल विलंबता का मतलब नहीं है। यह तय करने से पहले कि क्या ठीक करना है, मॉडल, टूल, हुक और मानव-प्रतीक्षा समय को अलग करें।
</Warning>
