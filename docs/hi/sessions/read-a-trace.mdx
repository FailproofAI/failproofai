एक ट्रेस सपाट ईवेंट स्ट्रीम को रन की कारणात्मक कहानी में बदल देता है। इसे पहले अपसरण से पढ़ें, अंतिम त्रुटि से पीछे की ओर नहीं।

## ट्रेस खोलें

<Tabs>
  <Tab title="Dashboard">
    1. **Observe → Sessions** पर जाएं और एक सेशन खोलें।
    2. परिणाम, समय, त्रुटियों और मूल्यांकन स्कोर की जांच करने के लिए प्रोफाइल सारांश का उपयोग करें।
    3. टाइमलाइन और मिनिमैप को स्कैन करें। सेशन बड़ा होने पर ईवेंट प्रकार या समय फ़िल्टर करें।
    4. इसका निरीक्षण करने के लिए एक ईवेंट चुनें। मूल्यांकनकर्ता JSON के लिए **export** का उपयोग करें, या चयनित साक्ष्य के लिए गहरे लिंक को साझा करने के लिए पृष्ठ URL की प्रतिलिपि बनाएं।

    ![एक सेशन विस्तार दृश्य जिसमें इसके निष्पादन ग्राफ, ईवेंट टाइमलाइन, मूल्यांकन पैनल और टूल, मॉडल और हुक विभाजन हैं।](/images/dashboard/session-detail.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp --json sessions --session-id <session-id>
    fp events --session-id <session-id> --order asc --all
    fp --json events --full --session-id <session-id> --all
    ```

    पहले हल्के ईवेंट फीड का उपयोग करें। केवल तभी पूर्ण पेलोड का अनुरोध करें जब ईवेंट सारांश पर्याप्त साक्ष्य न रखते हों।
  </Tab>
</Tabs>

<Steps>
  <Step title="अपने आप को ओरिएंट करें">
    एजेंट, पर्यावरण, समय, परिणाम और अवधि की पुष्टि करें, फिर त्रुटियों, लंबी अवधि, दोहराए गए टूल, मानव प्रतीक्षा और अस्वीकृत नीति निर्णयों के लिए स्कैन करें।
  </Step>
  <Step title="पहली संदिग्ध ईवेंट को विस्तारित करें">
    इसके अनुरोध, प्रतिक्रिया, टूल इनपुट, आउटपुट और सहसंबंध ID का निरीक्षण करें। संवेदनशील सामग्री केवल तभी दृश्य है जब ट्रांसक्रिप्ट कैप्चर सक्षम हो और आपकी अनुमतियों की अनुमति हो।
  </Step>
  <Step title="पूर्ववर्ती संदर्भ का निरीक्षण करें">
    कारण अक्सर एक ईवेंट पहले बैठता है: एक गलत मॉडल प्रतिक्रिया, लापता टूल परिणाम, या पुरानी धारणा।
  </Step>
  <Step title="साक्ष्य को कार्रवाई में बदलें">
    सेशन को ऑडिट स्कोप में जोड़ें, इसे किसी समस्या से जोड़ें, या विफलता मोड का उपयोग करके एक नीति बनाएं।
  </Step>
</Steps>

<Warning>
  लंबी अवधि हमेशा मॉडल विलंबता का मतलब नहीं है। क्या ठीक करना है यह तय करने से पहले मॉडल, टूल, हुक और मानव-प्रतीक्षा समय को अलग करें।
</Warning>
