Tools दिखाता है कि agents क्या कॉल करते हैं, कितनी बार कॉल विफल होती हैं, और कौन से sessions इससे प्रभावित होते हैं।

Tool के नाम प्रत्येक agent harness से आते हैं, इसलिए एक ही capability के अलग-अलग नाम हो सकते हैं। उदाहरण के लिए, shell कॉल `Bash`, `exec`, `Shell`, `terminal`, या `run_command` के रूप में दिखाई दे सकती है। फ़िल्टर बनाने से पहले `fp list tools` चलाएं।

<Tabs>
  <Tab title="Dashboard">
    **Observe → Tools** पर जाएं। Environment, tool, agent, या session के अनुसार फ़िल्टर करें।

    ![Tools पृष्ठ जो latency, success और failure breakdowns, और tool-call distribution को दर्शाता है।](/images/dashboard/tools.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list tools
    fp events --event-type tool_use,tool_result --since 24h
    fp errors --event-type tool_result --since 24h
    fp --json events --full --event-type tool_use,tool_result --session-id <session-id> --all --limit 2000
    ```

    जब आपको per-call duration जैसे payload fields की आवश्यकता हो तो `--full` का उपयोग करें।
  </Tab>
</Tabs>

इस पृष्ठ का उपयोग दोहराए गए विफलताओं को खोजने, काम करने और विफल runs की तुलना करने, या यह पुष्टि करने के लिए करें कि policy-targeted tool वास्तव में उपयोग किया जा रहा है।
