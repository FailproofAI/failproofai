| अवधारणा | इसका अर्थ | आप क्या हासिल कर सकते हैं |
| --- | --- | --- |
| Session | एक एजेंट कार्य या रन | एक व्यक्तिगत परिणाम का पुनर्निर्माण करें |
| Event | एक सत्र में एक दर्ज किया गया कार्य | एक मॉडल कॉल, टूल उपयोग, त्रुटि, मानव कार्रवाई, या नीति निर्णय का निरीक्षण करें |
| Trace | क्रमबद्ध और नेस्टेड सत्र दृश्य | असंबंधित लॉग पढ़ने के बजाय कारणात्मकता को समझें |
| Evaluation | एक सत्र पर स्कोर या판断 | गुणवत्ता, अनुपालन, लागत, या विलंबता को लगातार ट्रैक करें |
| Audit | चयनित सत्र जनसंख्या की समीक्षा | एक बताए गए लक्ष्य और गति के साथ विफलता पैटर्न खोजें |
| Finding | एक ऑडिट द्वारा खोजी गई साक्ष्य-समर्थित विफलता | विफलता मोड, गंभीरता, और प्रभावित सत्र देखें |
| Issue | एक टिकाऊ प्रतिक्रिया रिकॉर्ड | एक निष्कर्ष या सतर्कता घटना को असाइन, चर्चा, और हल करें |
| Alert | एक नियम जो पुनरावृत्ति का पता लगाता है | जब कोई ज्ञात स्थिति फिर से होती है तो उत्तरदाताओं को सूचित करें |
| Policy | एजेंट गतिविधि के दौरान मूल्यांकन किया गया एक नियम | जोखिम भरे व्यवहार को देखें, अवरुद्ध करें, या पुनः निर्देशित करें |
| Deployment | मशीनों में एक संस्करणीकृत नीति रोलआउट | नियंत्रित करें कि कोई नीति कहाँ चलती है और इसे सुरक्षित रूप से वापस रोल करें |

## विश्वसनीयता लूप

साक्ष्य से शुरुआत करें। एक सत्र दिखाता है कि क्या हुआ। एक ऑडिट निर्धारित करती है कि क्या यह एक अलग-थलग गलती है या एक पैटर्न। एक निष्कर्ष विफलता मोड की पहचान करता है; एक समस्या प्रतिक्रिया का स्वामित्व लेती है। एक नीति एक ही व्यवहार को रोकती है, जबकि सतर्कताएं आपको बताती हैं कि क्या स्थिति फिर से लौटती है।

<Warning>
  एक स्थानीय `failproofai audit` स्थानीय एजेंट इतिहास को स्कैन करता है। एक आवर्ती Cloud ऑडिट Failproof AI Cloud में संग्रहीत सत्रों की समीक्षा करता है। ये अलग-अलग वर्कफ़्लो हैं जिनके अलग-अलग दायरे और शेड्यूलिंग हैं।
</Warning>
