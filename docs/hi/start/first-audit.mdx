icon: "scan-search"

एक ऑडिट सत्रों के एक समूह को रैंक किए गए, साक्ष्य-समर्थित विफलता निष्कर्षों में बदल देता है। एक संकीर्ण विफलता प्रश्न से शुरू करें।

<Tabs>
  <Tab title="Dashboard">
    <Steps>
      <Step title="ऑडिट खोलें">
        क्लाउड साइडबार में, **विश्लेषण → ऑडिट** पर जाएं। **नया ऑडिट** चुनें।
      </Step>
      <Step title="ऑडिट सेट अप करें">
        एक नाम और सीधा विफलता लक्ष्य दर्ज करें, जैसे "उत्पादन सत्र खोजें जो इनपुट बदले बिना या बढ़ाए बिना एक ही विफल भुगतान कॉल को फिर से प्रयास करते हैं।" एजेंट, वातावरण, समय विंडो और शेड्यूल चुनें। एक संक्षिप्त विवरण और संदर्भ URLs जोड़ें जब ऑडिटर को आपके वर्कफ़्लो नियमों की आवश्यकता हो।
      </Step>
      <Step title="ऑडिट बनाएं और प्रतीक्षा करें">
        **ऑडिट बनाएं** चुनें। पहला रन तुरंत कतार में डाल दिया जाता है। इसे कतारबद्ध से चल रहे से पूर्ण तक जाते हुए देखने के लिए ऑडिट कार्ड खोलें।
      </Step>
    </Steps>

    चलने के बाद, एक खोज खोलें और इसके सत्र साक्ष्य की समीक्षा करें। आप इसे स्वीकार, असाइन, खारिज, म्यूट या हल कर सकते हैं।

    ![एक पूर्ण ऑडिट खोज जो इसके विफलता विवरण, अनुशंसित कार्रवाई, समर्थन साक्ष्य और प्रभावित सत्र दिखाता है।](/images/dashboard/audit-finding.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp audits create payment-retry-failures \
      --description "Find production sessions that retry a failed payment call without changing input or escalating" \
      --scope '{"environments":["production"]}' \
      --text "Escalate after two unchanged payment failures"

    fp audits list
    fp audits runs payment-retry-failures
    fp audits findings --audit payment-retry-failures
    fp audits finding <finding-id>
    ```

    संदर्भ संदर्भ जोड़ें, फिर इसे तब ताज़ा करें जब स्रोत बदले:

    ```bash
    fp audits context-set payment-retry-failures --url https://example.com/payment-runbook
    fp audits context-refresh payment-retry-failures
    fp audits run payment-retry-failures
    ```

    एक खोज को त्रिया के माध्यम से ले जाने के लिए `fp audits ack <finding-id>`, `fp audits assign <finding-id> --to <email>`, `fp audits dismiss <finding-id>`, `fp audits mute <finding-id>`, `fp audits resolve <finding-id>`, या `fp audits reopen <finding-id>` का उपयोग करें।
  </Tab>
</Tabs>
