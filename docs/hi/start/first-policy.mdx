icon: "shield-check"
---

किसी नीति का उपयोग केवल तभी करें जब आप असुरक्षित कार्रवाई और उन वैध कार्रवाइयों का वर्णन कर सकें जिन्हें अनुमति दी जानी चाहिए।

<Tabs>
  <Tab title="Dashboard">
    <Steps>
      <Step title="नीति तैयार करें">
        **Admin → policy editor** पर जाएं। डेमो नीति से शुरुआत करें, इसके स्रोत की समीक्षा करें या संपादित करें, फिर **publish version** का चयन करें। प्रकाशन एक अपरिवर्तनीय संस्करण बनाता है जिसे आप मशीनों पर तैनात कर सकते हैं।

        ![नीति संपादक compose दृश्य एक अपरिवर्तनीय संस्करण के रूप में प्रकाशित करने के लिए तैयार डेमो नीति के साथ।](/images/dashboard/policy-editor.png)
      </Step>
      <Step title="इसे एक मशीन पर तैनात करें">
        **Admin → enforcement** पर जाएं, लक्ष्य मशीन को विस्तारित करें, और **edit this machine** का चयन करें। प्रकाशित डेमो नीति जोड़ें, इसके संस्करण को pin करें, **observe** चुनें, और तैनाती लागू करें।

        ![मशीन तैनाती संपादक जिसमें observe मोड में तैनाती लागू करने से पहले एक प्रकाशित नीति संस्करण चयनित है।](/images/dashboard/enforcement-editor.png)
      </Step>
      <Step title="नीति को सत्यापित करें">
        उस मशीन पर एक नया agent सेशन चलाएं, फिर **Observe → policy** खोलें। मशीन का चयन करें और पुष्टि करें कि डेमो नीति नीति मैपिंग और निर्णय टाइमलाइन में दिखाई देती है। Observe मोड रिकॉर्ड करता है कि नीति क्या करेगी, लेकिन कार्रवाई को ब्लॉक नहीं करती।

        ![नीति पृष्ठ जो निर्णय कुल, समय के साथ प्रवर्तन गतिविधि, और स्थानीय और Cloud-प्रबंधित नीति मैपिंग दिखाता है।](/images/dashboard/policy-observe.png)
      </Step>
    </Steps>
  </Tab>
  <Tab title="CLI">
    Cloud नीति लेखन और fleet तैनाती प्रशासनिक कार्यप्रवाह हैं। इसे प्रकाशित करने से पहले स्थानीय CLI का उपयोग करके समान नीति को सत्यापित करें:

    ```bash
    failproofai policies --install --custom ./payment-retry.policies.ts \
      --cli claude --scope project
    failproofai config --status
    ```

    Cloud-दृश्यमान नीति निर्णयों का निरीक्षण करने के लिए `fp` का उपयोग करें:

    ```bash
    fp events --event-type hook_completed --env production --since 24h
    fp sessions --env production --since 24h
    ```

    Cloud CLI रूट-केवल प्रवर्तन तैनाती मार्ग को उजागर नहीं करता है। **Admin → policy editor** से संस्करण प्रकाशित करें और **Admin → enforcement** से उन्हें तैनात करें।
  </Tab>
</Tabs>
