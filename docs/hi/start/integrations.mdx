## तीन लाइनें, कोई भी फ्रेमवर्क हो

<CodeGroup>
```bash LangGraph
pip install 'failproofai-sdk[langgraph]'
```

```bash CrewAI
pip install 'failproofai-sdk[crewai]'
```

```bash LlamaIndex
pip install 'failproofai-sdk[llamaindex]'
```

```bash Pydantic AI
pip install 'failproofai-sdk[pydantic-ai]'
```

```bash Custom agents
pip install failproofai-sdk
```
</CodeGroup>

```python
import failproofai_sdk

failproofai_sdk.configure(environment="production")
failproofai_sdk.instrument()          # आपके द्वारा इंपोर्ट किए गए फ्रेमवर्क का पता लगाता है

with failproofai_sdk.session():
    ...                               # आपकी मौजूदा एजेंट कॉल, अपरिवर्तित
```

आपके फ़ंक्शन पर कोई डेकोरेटर नहीं, आपकी कॉल पर कोई कॉलबैक नहीं, आपके कोड के माध्यम से कोई आईडी नहीं। केवल सेशन के अंदर की कॉल अलग है:

<Tabs>
  <Tab title="LangGraph">
    ```python
    graph.invoke({"messages": [HumanMessage("...")]})
    ```
  </Tab>
  <Tab title="CrewAI">
    ```python
    Crew(agents=[analyst, writer], tasks=[gather, summarise]).kickoff()
    ```
  </Tab>
  <Tab title="LlamaIndex">

    await agent.run("...")        # `async with failproofai_sdk.session():` के तहत
    ```
  </Tab>
  <Tab title="Pydantic AI">

    agent.run_sync("...")
    ```
  </Tab>
  <Tab title="Custom agents">
    ```python
    with failproofai_sdk.agent("planner"):
        with failproofai_sdk.tool_call("search", input={"q": q}) as t:
            t.output = search(q)
    ```
  </Tab>
</Tabs>

अतिरिक्त इंस्टॉल **फ्रेमवर्क** को स्थापित करता है। हर एडेप्टर बेस व्हील में शामिल होता है, इसलिए एक परियोजना जिसके पास पहले से ही अपना फ्रेमवर्क है, को कुछ भी अतिरिक्त की आवश्यकता नहीं है।

## यह जांचें कि यह पहुंचा है या नहीं

एक इंस्ट्रूमेंटेड सेशन चलाएं, फिर **Observe → Sessions** खोलें और अपना पर्यावरण चुनें। रन एक पुनर्निर्मित ट्रेस के रूप में दिखाई देता है।

यदि कुछ भी नहीं आता है, तो `failproofai config --status` के साथ पुष्टि करें कि मशीन जुड़ी हुई है। [कैप्चर सेट अप करें](/hi/start/setup) देखें।

<Warning>
  डिलीवरी की पुष्टि करने के लिए स्पूल डायरेक्टरी को न देखें। Failproof डेमन प्रत्येक बैच को मिलीसेकंड के भीतर एकत्र करता है और हटाता है, इसलिए इसे पढ़ना कलेक्टर के साथ दौड़ता है और उत्सर्जित इवेंट्स की तुलना में बहुत कम इवेंट दिखाता है।
</Warning>

## अगला

ऊपर प्रत्येक क्विकस्टार्ट अपनी पूरी गाइड से लिंक करता है — क्या रिकॉर्ड किया जाता है, विकल्प, स्ट्रीमिंग, स्पैन नामकरण, और असली समस्याएं जो लोगों को होती हैं। वे **Trace Agents → Plug in your agent** के तहत रहते हैं।
