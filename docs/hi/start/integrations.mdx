## शुरू करने से पहले

इस पथ के दो अनुमान, जिनमें से कोई भी नीचे दिया गया कोड आपके लिए नहीं करता:

| आवश्यकता | कारण |
| --- | --- |
| Python 3.10 या नया | वह सीमा जो SDK घोषित करता है। |
| `failproofai config` के साथ सेटअप किया गया मशीन | वह कमांड failproofaid डेमॉन इंस्टॉल करता है, और डेमॉन ही एकमात्र चीज़ है जो SDK लिखता है उसे शिप करता है। इसके बिना बैचेस स्पूल डायरेक्टरी में जमा हो जाते हैं और कभी नहीं जाते। |

<Note>
  **यह पथ रिकॉर्ड करता है; लागू नहीं करता।** SDK आपके एजेंट ने जो किया उसे कैप्चर करता है। पॉलिसीज़ एजेंट CLI के अंदर एक हुक से फायर करती हैं, इसलिए फ्रेमवर्क एजेंट पर लागू करने का मतलब है अपने स्वयं के रनटाइम में एक हुक डालना — [Policies](/hi/policies/overview) देखें।
</Note>

## तीन लाइनें, कोई भी फ्रेमवर्क

<CodeGroup>
```bash LangGraph
pip install 'failproofai-sdk[langgraph]'
```

```bash CrewAI
pip install 'failproofai-sdk[crewai]'
```

```bash LlamaIndex
pip install 'failproofai-sdk[llamaindex]'
```

```bash Pydantic AI
pip install 'failproofai-sdk[pydantic-ai]'
```

```bash Custom agents
pip install failproofai-sdk
```
</CodeGroup>

```python
import failproofai_sdk

failproofai_sdk.configure(environment="production")
failproofai_sdk.instrument()          # आपके द्वारा इंपोर्ट किए गए फ्रेमवर्क्स को डिटेक्ट करता है

with failproofai_sdk.session():
    ...                               # आपकी मौजूदा एजेंट कॉल, अपरिवर्तित
```

आपके फंक्शन्स पर कोई डेकोरेटर नहीं, आपकी कॉल्स में कोई कॉलबैक पास नहीं किया गया, आपके कोड के माध्यम से कोई आईडीज़ थ्रेड नहीं की गई। केवल सेशन के अंदर कॉल अलग है:

<Tabs>
  <Tab title="LangGraph">
    ```python
    graph.invoke({"messages": [HumanMessage("...")]})
    ```
  </Tab>
  <Tab title="CrewAI">
    ```python
    Crew(agents=[analyst, writer], tasks=[gather, summarise]).kickoff()
    ```
  </Tab>
  <Tab title="LlamaIndex">
    ```python
    await agent.run("...")        # `async with failproofai_sdk.session():` के अंदर
    ```
  </Tab>
  <Tab title="Pydantic AI">
    ```python
    agent.run_sync("...")
    ```
  </Tab>
  <Tab title="Custom agents">
    ```python
    with failproofai_sdk.agent("planner"):
        with failproofai_sdk.tool_call("search", input={"q": q}) as t:
            t.output = search(q)
    ```
  </Tab>
</Tabs>

अतिरिक्त इंस्टॉल **फ्रेमवर्क** करता है। हर एडेप्टर बेस व्हील में शिप होता है, इसलिए एक प्रोजेक्ट जिसके पास पहले से ही इसका फ्रेमवर्क है को कोई अतिरिक्त की ज़रूरत नहीं है।

## जांचें कि यह आया

एक इंस्ट्रूमेंटेड सेशन चलाएं, फिर **Observe → Sessions** खोलें और अपना परिवेश चुनें। रन एक पुनर्निर्मित ट्रेस के रूप में दिखाई देता है।

यदि कुछ नहीं आता है, तो `failproofai config --status` के साथ मशीन सेटअप और कनेक्टेड है यह पुष्टि करें। यदि नहीं है, तो `failproofai config` चलाएं। [Choose your setup](/hi/start/setup) देखें।

<Warning>
  डिलीवरी की पुष्टि करने के लिए स्पूल डायरेक्टरी को न देखें। Failproof डेमॉन प्रत्येक बैच को मिलीसेकंड के भीतर एकत्र करता है और हटाता है, इसलिए इसे पढ़ना कलेक्टर के साथ दौड़ता है और उत्सर्जित घटनाओं की तुलना में बहुत कम दिखाता है।
</Warning>

साबित करने के लिए कि SDK बिल्कुल लिख रहा है, पहले डेमॉन को रोकें, फिर अपना सेशन चलाएं और `~/.failproofai/custom-agents/events/` में देखें। डेमॉन चलने के साथ, एक खाली डायरेक्टरी स्वस्थ स्थिति है।

<CodeGroup>
```bash Linux
sudo systemctl stop failproofaid@$USER
```

```bash macOS
sudo launchctl bootout system/ai.failproof.failproofaid.$USER
```
</CodeGroup>

इसे वापस डालने के लिए बाद में `failproofai config` चलाएं। जबकि डेमॉन बंद है, इस मशीन पर हुक इवेंट्स के पास कोई मूल्यांकनकर्ता नहीं है और इनकार किए जाते हैं, इसलिए इसे केवल जाँच जितने समय के लिए रोकें।

## अगला
