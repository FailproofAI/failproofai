एक मशीन पर Failproof AI सेट अप करें, फिर स्थानीय रहें या Cloud से कनेक्ट करें।

यदि आपका एजेंट [समर्थित हार्नेस](/hi/reference/harnesses) में चलता है, तो ये चरण अनुसरण करें। LangChain, CrewAI, LlamaIndex, Pydantic AI, या अपने स्वयं के रनटाइम के साथ बनाए गए एजेंट के लिए, [अपने एजेंट को इंस्ट्रूमेंट करें](/hi/start/integrations) से शुरू करें।

## अपने एजेंट को सेटअप गाइड करने दें

एक संगत एजेंट में Failproof AI छत्र कौशल स्थापित करें:

```bash
npx skills add FailproofAI/skills
```

यह छत्र कौशल और इसके विशेषज्ञ भाई-बहनों को स्थापित करता है। यदि आप केवल छत्र चाहते हैं तो `--skill failproofai` का उपयोग करें। यह स्थानीय और Cloud सेटअप, डेमन स्वास्थ्य, सत्र, ऑडिट, नीतियां, और समस्या निवारण को समझता है। यह काम को निर्देशित करता है और विशेष कार्यों को सही Failproof AI कौशल तक पहुंचाता है; यह नीचे CLI स्थापना को प्रतिस्थापित नहीं करता है।

## मशीन सेट अप करें

<Steps>
  <Step title="Failproof AI स्थापित और कॉन्फ़िगर करें">
    ```bash
    npm install -g failproofai
    failproofai config
    ```

    सेटअप पृष्ठभूमि सेवा स्थापित करता है और इसे खोजने वाले प्रत्येक समर्थित एजेंट को कनेक्ट करता है। यह एक बार व्यवस्थापक पहुंच मांग सकता है। यह Linux और macOS का समर्थन करता है।
  </Step>

  <Step title="नीतियां चुनें">
    सेटअप कोई नीति पैक नहीं चुनता है। Failproof AI पैक जोड़ें:

    ```bash
    failproofai policies add FailproofAI/policies
    failproofai policies
    ```

    दूसरी कमांड इस मशीन पर हर नीति दिखाती है और चाहे वह चालू हो। जब तक आप एक पैक जोड़ते हैं, केवल `block-failproofai-commands` चलता है।
  </Step>

  <Step title="मशीन की जांच करें">
    ```bash
    failproofai config --status
    ```

    यह सेवा, Cloud कनेक्शन, और विराम स्थिति की रिपोर्ट करता है।
  </Step>
</Steps>

## स्थानीय या Cloud चुनें

<Tabs>
  <Tab title="स्थानीय रहें">
    कोई खाता आवश्यक नहीं है।

    ```bash
    failproofai
    failproofai audit
    ```

    पहली कमांड `http://localhost:8020` पर स्थानीय डैशबोर्ड खोलती है। दूसरी कमांड इस मशीन पर पहले से मौजूद एजेंट इतिहास को स्कैन करती है।
  </Tab>

  <Tab title="Cloud से कनेक्ट करें">
    Failproof AI Cloud में एक मशीन कुंजी बनाएं, फिर चलाएं:

    ```bash
    failproofai config --token <machine-key>
    failproofai config --status
    ```

    Cloud नीति निर्णय और सत्र प्रतिलेख प्राप्त करता है। केवल निर्णय भेजने के लिए, पहले कनेक्ट करें, फिर `~/.failproofai/config.json` में `collector.sessions` को `false` सेट करें; वर्तमान `--no-transcripts` सेटअप फ्लैग वह सेटिंग लागू नहीं करता है। साझा शेल और CI के लिए, कमांड इतिहास में कुंजी डालने के बजाय `FAILPROOFAI_CLOUD_TOKEN` का उपयोग करें।
  </Tab>
</Tabs>

## इसे सत्यापित करें

अपने एजेंट में से एक को चलाएं और इसे एक सामान्य कार्य करने के लिए कहें। फिर:

एक टूल-कॉल अस्वीकार सभी 12 समर्थित हार्नेस पर सत्यापित है। टर्न-एंड प्रवर्तन 8 पर सत्यापित है; अन्य हार्नेस-इवेंट जोड़े अवलोकन-केवल या असत्यापित हो सकते हैं।

- स्थानीय डैशबोर्ड में **Policies → Activity** खोलें नीति निर्णय देखने के लिए।
- Cloud में **Observe → Sessions** खोलें पूर्ण रन देखने के लिए।
- जोखिम भरे या बेकार पैटर्न के लिए `failproofai audit` चलाएं।

<Warning>
  सेटअप के बाद, `failproofaid` सेवा मूल्यांकनकर्ता है। यदि वह उत्तर नहीं दे सकता, तो सुरक्षित कार्य अस्वीकार किए जाते हैं। जब कोई एजेंट अप्रत्याशित रूप से रुके तो `failproofai config --status` चलाएं।
</Warning>
