यह quickstart एक मशीन को सेशन रिपोर्ट करने, ऑडिट चलाने और नीति तैनात करने के लिए सेट अप करता है। Failproof को सेट करने के लिए स्किल का उपयोग करें, या मैनुअल स्टेप्स का पालन करें। आपको Node.js 20.9 या बाद का संस्करण चाहिए।

<Tabs>
  <Tab title="स्किल का उपयोग करें">
    <Steps>
      <Step title="Failproof AI स्किल्स इंस्टॉल करें">
        ```bash
        npx skills add FailproofAI/skills
        ```
      </Step>
      <Step title="अपने एजेंट से सबकुछ सेट अप करने के लिए कहें">
        ```text
        Set up Failproof AI for this project, connect this machine, install the right hooks and policies, and verify that a session arrives.
        ```

        आपका एजेंट प्रोजेक्ट का निरीक्षण करता है, प्रासंगिक इंटीग्रेशन चुनता है, सेटअप करता है, और इसे सत्यापित करता है। व्यक्तिगत स्किल्स और उन्नत इंस्टॉलेशन विकल्पों के लिए [FailproofAI स्किल्स रिपॉजिटरी](https://github.com/FailproofAI/skills) देखें।
      </Step>
    </Steps>
  </Tab>
  <Tab title="मैनुअल सेटअप">
    ## शुरू करने से पहले

1. [Failproof AI डैशबोर्ड](https://app.befailproof.ai) खोलें और अपने वर्क ईमेल के साथ खाता बनाएं या साइन इन करें।
2. **Administration → Keys** पर जाएं और `events:add` और `policies:pull` के साथ एक कुंजी बनाएं।
3. एकबारी सीक्रेट कॉपी करें और इसे टार्गेट मशीन पर स्टोर करें:

```bash
export FAILPROOFAI_KEY="<one-time-secret>"
```

    ## इंस्टॉल करें

<Steps>
  <Step title="Failproof AI इंस्टॉल करें और कनेक्ट करें">
    ```bash
    npm install -g failproofai
    failproofai config --connect https://app.befailproof.ai --token "$FAILPROOFAI_KEY"
    ```

    सेशन ट्रांसक्रिप्ट्स डिफॉल्ट रूप से भेजे जाते हैं। ट्रांसक्रिप्ट कंटेंट के बिना हुक एक्टिविटी और नीति निर्णय रिपोर्ट करने के लिए `--no-transcripts` जोड़ें।

    अगर इस मशीन पर पहले से एजेंट हिस्ट्री है, तो पिछले सात दिनों का प्रीव्यू देखें और इंपोर्ट करें, फिर डिलीवरी समाप्त होने का इंतजार करें। नई मशीन पर इस स्टेप को छोड़ें।

    ```bash
    failproofai backfill --since 7d --dry-run
    failproofai backfill --since 7d
    failproofai flush --wait
    ```

    Failproof AI में **Sessions** खोलें और एक इंपोर्ट किए गए सेशन को चुनें।
  </Step>
  <Step title="एजेंट हुक्स और नीतियां इंस्टॉल करें">
    यह Failproof AI को आपके एजेंट CLI से जोड़ता है और बिल्ट-इन नीतियां इंस्टॉल करता है। Failproof AI आपके सेशन्स को ऑडिट करने और आपके एजेंट्स के लिए नीतियां लिखने से पहले उन्हें स्थानीय नीति निर्णय देखने और लागू करने का प्रयास करने के लिए उपयोग करें।

    इंस्टॉलर को अपने एजेंट CLI को स्वचालित रूप से डिटेक्ट करने दें, या एक को स्पष्ट रूप से नाम दें।

    ```bash
    failproofai policies --install --cli claude --scope user
    ```
  </Step>
  <Step title="व्यवहार का ऑडिट करें">
    [अपनी पहली विफलता जांच चलाएं](/hi/start/first-audit) का पालन करें। एक ठोस लक्ष्य का उपयोग करें जैसे "सेशन खोजें जहां एजेंट ने अपने दृष्टिकोण को बदले बिना विफल उपकरण को फिर से प्रयास किया।"
  </Step>
  <Step title="विफलता को रोकें">
    [नीति के साथ अपनी पहली विफलता को रोकें](/hi/start/first-policy) का पालन करें। observe मोड में शुरू करें, मिलानों का निरीक्षण करें, फिर समीक्षित संस्करण को लागू करें।
  </Step>
</Steps>

<Check>
  `failproofai config --status` चलाएं। एक स्वस्थ सेटअप क्लाउड कनेक्शन, daemon स्थिति, और क्या लागू करना रोक दिया गया है, यह रिपोर्ट करता है।
</Check>
