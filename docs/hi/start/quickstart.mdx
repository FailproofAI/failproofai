यह त्वरित शुरुआत एक मशीन को सेशन रिपोर्ट करने, एक ऑडिट चलाने और एक नीति तैनात करने के लिए प्राप्त करती है। Failproof को सेट अप करने के लिए कौशल का उपयोग करें, या मैनुअल चरणों का पालन करें।

**आपका पथ कौन सा है?** यदि आपका एजेंट 12 समर्थित [harnesses](/hi/reference/harnesses) में से एक में चलता है — एक कोडिंग CLI, या Hermes या OpenClaw जैसा गेटवे — नीचे दिए गए चरणों का पालन करें; आपको Node.js 20.9 या बाद का संस्करण चाहिए। यदि आपके एजेंट के पास कोई harness नहीं है, तो इसे ट्रेसिंग और ऑडिट के लिए [Python SDK](/hi/reference/python-sdk) के साथ instrument करें, फिर [अपनी पहली विफलता जांच चलाएं](/hi/start/first-audit) पर फिर से जुड़ें; उस पथ पर प्रवर्तन के लिए आपके रनटाइम में एक हुक की आवश्यकता है।

        आपका एजेंट प्रोजेक्ट का निरीक्षण करता है, प्रासंगिक integration चुनता है, सेटअप निष्पादित करता है और इसे सत्यापित करता है। व्यक्तिगत कौशल और उन्नत स्थापना विकल्पों के लिए [FailproofAI कौशल रिपॉजिटरी](https://github.com/FailproofAI/skills) देखें।
      </Step>
    </Steps>

  <Tab title="मैनुअल सेटअप">
    ## शुरू करने से पहले

1. [Failproof AI डैशबोर्ड](https://app.befailproof.ai) खोलें और एक खाता बनाएं या अपने काम के ईमेल से साइन इन करें।
2. **Administration → Keys** पर जाएं और `events:add` और `policies:pull` के साथ एक कुंजी बनाएं।
3. एकबारी secret की प्रतिलिपि बनाएं और इसे लक्ष्य मशीन पर संग्रहीत करें:

```bash
export FAILPROOFAI_KEY="<one-time-secret>"
```

    ## स्थापित करें

<Steps>
  <Step title="Failproof AI स्थापित और कनेक्ट करें">
    ```bash
    npm install -g failproofai
    failproofai config --connect https://app.befailproof.ai --token "$FAILPROOFAI_KEY"
    ```

    सेशन transcripts डिफ़ॉल्ट रूप से भेजे जाते हैं। transcript सामग्री के बिना हुक गतिविधि और नीति निर्णयों की रिपोर्ट करने के लिए `--no-transcripts` जोड़ें।

    यदि इस मशीन के पास पहले से एजेंट history है, तो पिछले सात दिनों का पूर्वावलोकन और आयात करें, फिर डिलीवरी समाप्त होने का प्रतीक्षा करें। एक नई मशीन पर इस चरण को छोड़ें।

    ```bash
    failproofai backfill --since 7d --dry-run
    failproofai backfill --since 7d
    failproofai flush --wait
    ```

    Failproof AI में **Sessions** खोलें और एक आयातित सेशन चुनें।
  </Step>
  <Step title="एजेंट हुक और नीतियां स्थापित करें">
    यह Failproof AI को आपके harness से जोड़ता है और 40 built-in नीतियां स्थापित करता है। उन्हें स्थानीय नीति निर्णय देखने और Failproof AI आपके सेशन का ऑडिट करने और आपके एजेंट के लिए नीतियां लिखने से पहले प्रवर्तन आजमाने के लिए उपयोग करें।

    installer को अपने harness का पता लगाने दें, या एक को स्पष्ट रूप से नाम दें। 12 में से प्रत्येक एक वैध `--cli` मान है — `claude`, `codex`, `copilot`, `cursor`, `opencode`, `pi`, `hermes`, `openclaw`, `factory`, `devin`, `antigravity`, `goose`।

    ```bash
    failproofai policies --install --cli claude --scope user     # a coding CLI
    failproofai policies --install --cli hermes --scope user     # a Slack/Telegram gateway
    ```

    यह चलाने से पहले एक tool call को ब्लॉक करना सभी 12 पर सत्यापित किया जाता है। Turn-end gates 8 पर सत्यापित हैं — प्रति-harness मैट्रिक्स के लिए [प्रवर्तन क्षमता](/hi/reference/harnesses#enforcement-capability) देखें।
  </Step>
  <Step title="व्यवहार का ऑडिट करें">
    [अपनी पहली विफलता जांच चलाएं](/hi/start/first-audit) का पालन करें। एक ठोस लक्ष्य का उपयोग करें जैसे यह खोजना कि सेशन कहां एजेंट ने अपने दृष्टिकोण को बदले बिना एक विफल tool को पुन: प्रयास किया।
  </Step>
  <Step title="विफलता को रोकें">
    [एक नीति के साथ अपनी पहली विफलता को रोकें](/hi/start/first-policy) का पालन करें। observe मोड में शुरू करें, मिलान का निरीक्षण करें, फिर समीक्षा किए गए संस्करण को लागू करें।
  </Step>
</Steps>
