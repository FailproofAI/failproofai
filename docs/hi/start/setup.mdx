Failproof AI एक मशीन पर पूरी तरह चल सकता है या साझा सत्र और नीति प्रबंधन के लिए Cloud से कनेक्ट हो सकता है।

## स्थानीय, कोई खाता नहीं

```bash
npm install -g failproofai
failproofai config
failproofai policies add FailproofAI/policies
failproofai
```

यह सेवा को इंस्टॉल करता है, समर्थित एजेंटों को कनेक्ट करता है, एक नीति पैक जोड़ता है, और `http://localhost:8020` पर डैशबोर्ड खोलता है।

मशीन पर पहले से मौजूद एजेंट इतिहास को स्कैन करने के लिए `failproofai audit` चलाएं।

## Failproof AI Cloud से कनेक्ट करें

Cloud में एक मशीन कुंजी बनाएं, फिर चलाएं:

```bash
failproofai config --token <machine-key>
failproofai config --machine-label checkout-runner-01
failproofai policies add FailproofAI/policies
failproofai config --status
```

या `FAILPROOFAI_CLOUD_TOKEN=<machine-key>` को एक्सपोर्ट करें और साधारण `failproofai config` चलाएं। साझा मशीनों और CI में वातावरण चर को प्राथमिकता दें ताकि कुंजी शेल इतिहास या प्रक्रिया सूचियों में न पड़े।

Cloud दो अलग-अलग कार्यों के लिए एक कनेक्शन का उपयोग करता है:

- इस मशीन को असाइन की गई नीतियों को खींचें।
- नीति निर्णय और सत्र ट्रांसक्रिप्ट भेजें।

केवल निर्णय भेजने के लिए, पहले कनेक्ट करें, फिर `~/.failproofai/config.json` में `collector.sessions` को `false` पर सेट करें। `--no-transcripts` पर निर्भर न रहें: वर्तमान सेटअप पथ फ्लैग को पार्स करता है लेकिन इसे लागू नहीं करता है। [इवेंट्स और कॉन्फ़िगरेशन](/hi/reference/events-and-configuration#machine-configuration) देखें।

<Note>
  `--machine-label` एक मशीन का नाम बदलता है जो पहले से कनेक्ट है। इसे सेटअप कमांड के बाद चलाएं, पहले कनेक्शन के भाग के रूप में नहीं।
</Note>

## अनमानी सेटअप

`failproofai config` को विशेष गैर-इंटरैक्टिव फ्लैग की आवश्यकता नहीं है। CI या कंटेनर में यह बिना पूछे अनुरोधित सेटअप को लागू करता है।

```bash
export FAILPROOFAI_CLOUD_TOKEN="<key>"
failproofai config
```

पृष्ठभूमि सेवा को इंस्टॉल करने के लिए एक बार प्रशासक पहुंच की आवश्यकता है। सेटअप कभी भी एक इंटरैक्टिव `sudo` पासवर्ड प्रॉम्प्ट नहीं खोलता है: यह या तो बिना एक के सफल होता है या ऐसे कमांड प्रिंट करता है जो एक प्रशासक को चलाना चाहिए।

## प्लेटफॉर्म समर्थन

सेटअप Linux और macOS को समर्थन करता है। किसी अन्य प्लेटफॉर्म पर यह हुक या आंशिक सेटअप स्थिति लिखे बिना बाहर निकल जाता है।
