Failproof AI helps anyone running agents understand what happened, find failures, and prevent them from repeating.

It works with 16 common agent environments, including Claude Code, Codex, Cline, Hermes, OpenClaw, Goose, grok and Ori. Agents built with LangChain, CrewAI, LlamaIndex, Pydantic AI, or your own runtime can report through the [Python SDK](/reference/custom-agents).

## Start locally or connect Cloud

<Columns cols={2}>
  <Card title="Local, no account" icon="laptop" href="/audits/local-audit">
    Open the dashboard at `localhost:8020` and run `failproofai audit`. Your agent history stays on this machine.
  </Card>
  <Card title="Failproof AI Cloud" icon="cloud" href="/start/setup">
    See sessions across machines and manage policies for your team.
  </Card>
</Columns>

Setup deliberately chooses no policy pack. Add ours after setup:

```bash
failproofai policies add FailproofAI/policies
```

Until then, only `block-failproofai-commands` runs. It stops an agent disabling Failproof AI.
