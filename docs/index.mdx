> Trace what happened, find the failure, turn it into a policy, then enforce it so the same behavior does not happen in future runs.

## Start here

If you are deploying your first instrumented agent, start with the [quickstart](/start/quickstart). If data is already arriving, open **trace → sessions** ([Sessions](/sessions/overview)) and inspect a real run before configuring audits or policies.
