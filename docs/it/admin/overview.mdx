Administration contiene i controlli necessari per eseguire Failproof AI in un team. La maggior parte dei lettori può rimanere nelle sezioni Sessions, Audits e Policies; gli amministratori utilizzano questa sezione per gestire l'accesso e i confini operativi.

<Tabs>
  <Tab title="Dashboard">
    Usa la sezione **Admin** della barra laterale Cloud per **policy editor**, **enforcement**, **usage**, **keys**, **users** e **settings**. Un elemento bloccato indica che il tuo account non dispone dell'autorizzazione di lettura.

    ![La sezione Admin della barra laterale Cloud con policy editor, enforcement, usage, keys, users e settings.](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    Posiziona le opzioni globali prima del comando, ad esempio `fp --org reliability-team --json usage`.
  </Tab>
</Tabs>
