Utilizzo mostra il consumo per l'organizzazione corrente e le relative finestre di fatturazione. Usalo per comprendere come il rollout di produzione, il volume di trascritti, le valutazioni e la cadenza di audit influiscono sul tuo piano.

## Rivedi l'utilizzo

<Tabs>
  <Tab title="Dashboard">
    1. Vai a **Administration → Usage**.
    2. Conferma l'organizzazione e la finestra di misurazione.
    3. Rivedi l'inserimento, le sessioni, le valutazioni, le metriche, gli audit, i risultati, gli avvisi, gli utenti e le chiavi.
    4. Confronta il lavoro di audit avviato e completato quando l'utilizzo dell'audit sembra inaspettato.

    ![La pagina Usage che mostra la finestra di misurazione, gli eventi acquisiti, le pipeline di valutazione e audit, le risorse dello spazio di lavoro, i membri e le chiavi API.](/images/dashboard/usage-overview.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp usage
    fp --json usage
    fp --org reliability-team --json usage
    ```
  </Tab>
</Tabs>

## Indaga un cambiamento

1. Conferma l'organizzazione e la finestra attive.
2. Confronta l'aumento con il volume di sessioni per ambiente.
3. Verifica se una nuova integrazione ha iniziato a inviare trascritti.
4. Rivedi i cambiamenti nella cadenza di valutatore e audit.
5. Confronta con i limiti sul piano tariffario corrente.

La CLI restituisce lo stesso riepilogo per gli script.
