Utilizzo mostra il consumo per l'organizzazione corrente e le relative finestre di fatturazione. Usalo per comprendere come l'implementazione in produzione, il volume di trascrizioni, le valutazioni e la cadenza di audit influiscono sul tuo piano.

## Rivedi utilizzo

<Tabs>
  <Tab title="Dashboard">
    1. Vai a **Administration → Usage**.
    2. Conferma l'organizzazione e la finestra di misurazione.
    3. Rivedi acquisizione, sessioni, valutazioni, metriche, audit, risultati, avvisi, utenti e chiavi.
    4. Confronta il lavoro di audit iniziato e completato quando l'utilizzo di audit sembra inaspettato.

    ![La pagina Usage che mostra la finestra di misurazione, gli eventi acquisiti, le pipeline di valutazione e audit, le risorse dell'area di lavoro, i membri e le chiavi API.](/images/dashboard/usage-overview.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp usage
    fp --json usage
    fp --org reliability-team --json usage
    ```
  </Tab>
</Tabs>

## Indaga una modifica

1. Conferma l'organizzazione e la finestra attive.
2. Confronta l'aumento con il volume di sessioni per ambiente.
3. Verifica se una nuova integrazione ha iniziato a inviare trascrizioni.
4. Rivedi le modifiche alla cadenza di valutatore e audit.
5. Confronta rispetto ai limiti del piano tariffario corrente.

La CLI restituisce lo stesso riepilogo per gli script.
