L'intera distribuzione di Failproof AI Observability, a un comando di distanza. Controlla la produzione, crea una chiave API o riconosci un incidente senza lasciare il terminale, quindi automatizza tutto in CI oppure lascia che un agente di codifica lo faccia per te in linguaggio naturale.

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*La CLI `agenteye` comunica con il tuo dashboard. È uno strumento diverso dal collector, che invia gli eventi al server.*

## L'intera distribuzione, a un comando di distanza

Smetti di saltare da una scheda all'altra per rispondere a una domanda veloce. La CLI `agenteye` legge i tuoi dati e amministra la tua organizzazione da un singolo binario, quindi un controllo che prima significava navigare nel dashboard diventa una sola riga che puoi rieseguire, aliasare o incollare in un runbook. Hai quattro superfici:

- **Leggi i tuoi dati:** `sessions`, `events`, `evals` e `errors`, filtrati per ora, agente e ambiente.
- **Gestisci la tua org:** `keys`, `users`, `settings`, `alerts` e `incidents`.
- **Esegui analitiche:** SQL salvato più un runner `query` ad hoc sui tuoi dati di evento.
- **Chiedi all'assistente:** `agent ask` raggiunge lo stesso analista di sola lettura con cui chatti nel dashboard.

Installalo una volta con `pipx`, accedi con un codice a 6 cifre inviato via email e sei pronto. La sessione dura circa un giorno; riesegui `agenteye login` quando scade. Usalo per controllare la produzione, provisioning di una chiave o triage di un incidente attivo, tutto senza aprire un browser:

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

Un'abitudine da conoscere: le opzioni globali come `--json` vanno prima del comando. `agenteye --json sessions` è corretto; `agenteye sessions --json` non lo è.

## Automatizzalo, integralo in CI

Ogni comando accetta `--json` e questo cambia tutto. Un JSON pulito va a stdout mentre messaggi di stato e avvisi umani vanno a stderr, quindi una cattura `--json` si pipe direttamente in `jq` senza righe estranee da rimuovere. Questo rende la CLI ugualmente buona per te al prompt e per un agente di codifica che analizza l'output:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

È costruita per funzionare in modo autonomo. I prompt di conferma si saltano automaticamente quando nessun terminale è allegato, quindi nulla si blocca in una pipeline, e ogni comando restituisce un exit code significativo: `0` successo, `4` non connesso, `5` permesso mancante (il messaggio lo nomina, ad esempio `alerts:write`), `3` dashboard non raggiungibile. Uno script può ramificarsi su un `4` per riauthenticarsi o su un `5` per dirti esattamente cosa chiedere a un admin, invece di fallire alla cieca.

## Lascia che un agente di codifica lo usi in linguaggio naturale

Meglio ancora, non dovresti dover ricordare nessuno di questi flag. La **CLI skill** è una piccola cartella Agent Skill denominata `agenteye-cli` che insegna a un agente di codifica come Claude Code o Codex di usare la CLI da richieste in linguaggio naturale. Chiedi "c'è qualcosa di rotto oggi?" e l'agente sceglie il comando, lo esegue come te e risponde in prosa.

Per Claude Code, rilascia la cartella `agenteye-cli` in `~/.claude/skills/` e viene auto-scoperta. Failproof AI Observability fornisce la cartella; non c'è nulla di extra da installare, perché usa solo la CLI che hai già installato. Accedi tu stesso prima: la skill non può completare per te l'accesso tramite codice via email.

Poiché l'agente esegue la CLI come te, può fare tutto ciò che il tuo accesso consente, letture e scritture: creare chiavi, modificare impostazioni, risolvere incidenti. Il prompt "sei sicuro?" della CLI non si attiva per un agente, quindi la skill è scritta per dichiarare il comando esatto e attendere il tuo OK prima di qualsiasi modifica. Tu sei il passo di conferma.

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

Le letture rimangono istantanee e ogni scrittura si ferma per te:

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
