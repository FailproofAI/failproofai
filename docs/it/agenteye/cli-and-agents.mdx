L'intera distribuzione di Failproof AI Observability, a un solo comando di distanza. Controlla la produzione, genera una chiave API o riconosci un incidente senza lasciare il terminale, quindi automatizza tutto in CI oppure lascia che un agente di codifica lo faccia per te in linguaggio naturale.

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*La CLI `agenteye` comunica con la tua dashboard. È uno strumento diverso dal collector, che invia gli eventi al server.*

## L'intera distribuzione, a un solo comando di distanza

Smetti di passare da una scheda all'altra per rispondere a una domanda veloce. La CLI `agenteye` legge i tuoi dati e amministra la tua organizzazione da un singolo binario, quindi un controllo che normalmente richiedeva di navigare la dashboard diventa una riga che puoi rieseguire, creare alias o incollare in un runbook. Hai quattro superfici a disposizione:

- **Leggi i tuoi dati:** `sessions`, `events`, `evals` e `errors`, filtrati per tempo, agente e ambiente.
- **Gestisci la tua organizzazione:** `keys`, `users`, `settings`, `alerts` e `incidents`.
- **Esegui analitiche:** SQL salvati più un runner `query` ad hoc sui tuoi dati di eventi.
- **Chiedi all'assistente:** `agent ask` raggiunge lo stesso analista di sola lettura con cui chatti nella dashboard.

Installalo una volta con `pipx`, accedi con un codice a 6 cifre inviato per email e sei pronto. La sessione dura circa un giorno; riesegui `agenteye login` quando scade. Utilizzalo per controllare rapidamente la produzione, provisioning di una chiave o per analizzare un incidente attivo, il tutto senza aprire un browser:

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

Un'abitudine da conoscere: le opzioni globali come `--json` vanno prima del comando. `agenteye --json sessions` è corretto; `agenteye sessions --json` non lo è.

## Automatizzala, integrala in CI

Ogni comando accetta `--json` e questo cambia tutto. JSON pulito va a stdout mentre stato e avvisi per l'utente vanno a stderr, quindi un output catturato con `--json` si collega direttamente a `jq` senza linee spurie da eliminare. Questo è quello che rende la CLI altrettanto buona per te al prompt e per un agente di codifica che analizza l'output:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

È costruita per funzionare senza supervisione. I prompt di conferma vengono saltati automaticamente quando non è collegato alcun terminale, quindi niente si blocca in una pipeline, e ogni comando restituisce un codice di uscita significativo: `0` successo, `4` non connesso, `5` permesso mancante (il messaggio lo specifica, ad esempio `alerts:write`), `3` dashboard non raggiungibile. Uno script può diramazioni su un `4` per riautenticarsi o su un `5` per dirti esattamente cosa chiedere a un amministratore, invece di fallire al buio.

## Lascia che un agente di codifica lo guidi in linguaggio naturale

Ancora meglio, non dovresti dover ricordare nessuno di questi flag. La **CLI skill** è una piccola cartella Agent Skill denominata `agenteye-cli` che insegna a un agente di codifica come Claude Code o Codex a gestire la CLI da richieste in linguaggio naturale. Chiedi "c'è qualcosa di rotto oggi?" e l'agente sceglie il comando, lo esegue come te e risponde in prosa.

Per Claude Code, rilascia la cartella `agenteye-cli` in `~/.claude/skills/` e viene scoperta automaticamente. Failproof AI Observability fornisce la cartella; non c'è nulla di extra da installare, perché guida solo la CLI che hai già installato. Accedi tu stesso per primo: la skill non può completare l'accesso con codice inviato per email per te.

Poiché l'agente esegue la CLI come te, può fare tutto ciò che il tuo login consente, letture e scritture: creare chiavi, modificare impostazioni, risolvere incidenti. Il prompt "sei sicuro?" della CLI non si attiva per un agente, quindi la skill è scritta per indicare il comando esatto e attendere il tuo OK prima di qualsiasi modifica. Tu sei il passaggio di conferma.

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

Le letture rimangono istantanee e ogni scrittura pausa per te:

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
