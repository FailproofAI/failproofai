Fai qualsiasi domanda sui dati del tuo agente e ottieni una risposta in pochi secondi. Failproof AI Observability ti fornisce una libreria di query salvate e pronte all'uso sui tuoi eventi e valutazioni, così inizi da un esempio funzionante invece che da un editor SQL vuoto.

![La libreria delle query salvate: una griglia di query riutilizzabili, sia preset incorporati che personalizzati](/agenteye/images/queries.png)

*La tua libreria di query salvate su `/<org-slug>/queries`: i preset incorporati insieme alle query che il tuo team ha salvato.*

## Inizia da un preset, non da una pagina vuota

Non devi ricordare i nomi delle tabelle o scrivere SQL da zero. La libreria si apre con preset incorporati per le domande che i team pongono più frequentemente, direttamente accanto alle query che il tuo team ha salvato e denominato. Scegline una simile a quello che cerchi e avrai già per la maggior parte la tua risposta.

Ogni query salvata è limitata all'organizzazione e condivisa, quindi le query utili che i tuoi colleghi scrivono diventano tue. Dai un nome a una query e scrivi una descrizione una sola volta, e chiunque nella tua organizzazione potrà trovarla, eseguirla o fissare i suoi risultati su un dashboard in seguito.

Trovalo su `/<org-slug>/queries`.

## Modificala ed eseguila nel composer SQL

Apri qualsiasi query e si carica nel composer SQL, dove puoi modificarla e vedere la risposta immediatamente: nessuna esportazione, nessun andirivieni, nessuna attesa.

![Il composer di query SQL che esegue una query salvata, con una barra laterale dello schema e una griglia di risultati live](/agenteye/images/query-lab.png)

*Il composer SQL: la tua query a sinistra, una barra laterale dello schema per non indovinare mai un nome di colonna, e una griglia di risultati live sotto.*

- **Una barra laterale dello schema** mostra le tabelle di analisi e le loro colonne, così puoi strutturare una query senza cercare i nomi dei campi.
- **Una griglia di risultati live** restituisce le righe non appena esegui, così iteri in pochi secondi invece di indovinare e riscoprire.
- **Progettato solo in lettura.** Le query vengono eseguite sul tuo archivio eventi e convalidate dal server: sono consentite solo istruzioni `SELECT` e `WITH`, con un timeout di istruzione e un limite di righe. Una query esplorativa non può mai modificare i tuoi dati, e una fuori controllo viene fermata per te.

Soddisfatto del risultato? Salvalo nuovamente nella libreria in modo che l'intero team lo erediti, o fissa il suo output su un dashboard come tile di linea, barre, area o torta.

## Eseguile dal terminale, oppure lascia che l'assistente le scriva

Le stesse query salvate ti seguono ovunque lavori:

- **Dal terminale.** La CLI `agenteye` elenca, esegue e salva le stesse query, così puoi inserire un risultato in uno script, collegarlo a CI, o passarlo a un agente di codifica.

```bash
agenteye query list                 # le stesse query salvate, dal tuo terminale
agenteye query run errs --arg prod  # esegui una e stampa le righe (aggiungi --json per piparla)
```

  Vedi [CLI e agenti](/it/agenteye/cli-and-agents) per l'elenco completo dei comandi.

- **Dall'assistente AI.** Non sei sicuro di come formulare l'SQL? Chiedi all'[assistente AI](/it/agenteye/assistant) nel dashboard in inglese naturale e ti preparerà la query e la salverà nella tua libreria.

L'esecuzione di una query salvata è controllata dal permesso `queries:run`, mantenuto separato dai permessi per creare o eliminare query, così puoi concedere l'accesso in lettura senza lasciare che tutti riscrivano la libreria.
