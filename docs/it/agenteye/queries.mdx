Fai qualsiasi domanda sui dati del tuo agent e ottieni una risposta in secondi. Failproof AI Observability ti mette a disposizione una libreria di query salvate e pronte all'uso sui tuoi eventi e valutazioni, così puoi partire da un esempio funzionante invece da un editor SQL vuoto.

![La libreria delle query salvate: una griglia di query riutilizzabili, sia preset built-in che personalizzate](/agenteye/images/queries.png)

*La tua libreria di query salvate su `/<org-slug>/queries`: i preset built-in affiancati alle query salvate dal tuo team.*

## Inizia da un preset, non da una pagina bianca

Non devi ricordare i nomi delle tabelle o scrivere SQL da zero. La libreria si apre con preset built-in per le domande che i team fanno più frequentemente, insieme alle query salvate e nominate dal tuo team. Scegline una simile a quello che stai cercando e sei già a metà strada della risposta.

Ogni query salvata è scoped all'organizzazione e condivisa, quindi le query utili scritte dai tuoi colleghi diventano anche tue. Assegna un nome a una query, aggiungi una descrizione una volta sola, e chiunque nella tua organizzazione potrà trovarla, eseguirla o fissarne i risultati su una dashboard più tardi.

Puoi trovarla su `/<org-slug>/queries`.

## Modificala ed eseguila nel composer SQL

Apri qualsiasi query e apparirà nel composer SQL, dove puoi adattarla e vedere la risposta istantaneamente: senza esportazioni, senza round-trip, senza aspettare qualcun altro.

![Il composer SQL che esegue una query salvata, con una barra laterale dello schema e una griglia di risultati in tempo reale](/agenteye/images/query-lab.png)

*Il composer SQL: la tua query sulla sinistra, una barra laterale dello schema così non devi indovinare il nome delle colonne, e una griglia di risultati in tempo reale sotto.*

- **Una barra laterale dello schema** espone le tabelle di analytics e le loro colonne, così puoi costruire una query senza cercare i nomi dei campi.
- **Una griglia di risultati in tempo reale** restituisce le righe nel momento in cui esegui la query, così iteri in secondi piuttosto che indovinare e riindovinare.
- **Read-only per design.** Le query vengono eseguite contro il tuo event store e validate sul server: sono consentite solo istruzioni `SELECT` e `WITH`, con un timeout e un limite di righe. Una query esplorativa non potrà mai modificare i tuoi dati, e una query in fuga verrà fermata automaticamente.

Soddisfatto del risultato? Salvalo di nuovo nella libreria così tutto il team lo eredita, oppure fissa l'output su una dashboard come una linea, barra, area o tile a torta.

## Eseguile dal terminale, oppure lascia che l'assistente le scriva

Le stesse query salvate ti seguono ovunque lavori:

- **Dal terminale.** La CLI `agenteye` elenca, esegue e salva le stesse identiche query, così puoi inserire un risultato in uno script, collegarlo a CI, oppure passarlo a un coding agent.

```bash
agenteye query list                 # le stesse query salvate, dal tuo terminale
agenteye query run errs --arg prod  # esegui una e stampa le righe (aggiungi --json per usarla in pipe)
```

  Vedi [CLI e agents](/it/agenteye/cli-and-agents) per l'elenco completo dei comandi.

- **Dall'assistente AI.** Non sei sicuro di come formulare l'SQL? Chiedi all'[assistente AI](/it/agenteye/assistant) in-dashboard in inglese semplice e ti bozzerà la query, salvandola nella tua libreria per te.

L'esecuzione di una query salvata è protetta dal permesso `queries:run`, mantenuto separato dai permessi per creare o eliminare query, così puoi concedere accesso in lettura senza lasciare a tutti la possibilità di riscrivere la libreria.
