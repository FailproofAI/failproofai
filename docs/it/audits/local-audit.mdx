Utilizza un audit locale per una revisione immediata e privata prima di connettere una macchina a Failproof AI Cloud. Esegue la scansione delle cronologie dell'agente già archiviate sulla tua macchina, riproduce l'attività dei tool attraverso le politiche integrate e apre un dashboard dei risultati locale.

## Esegui un audit interattivo

<Tabs>
  <Tab title="Dashboard">
    L'audit locale inizia dalla CLI perché deve scoprire le cronologie sulla macchina corrente. Esegui `failproofai audit`; dopo la scansione, Failproof AI avvia il dashboard incluso e apre **http://localhost:8020/audit**.

    Nella vista di audit, rivedi il numero di sessioni, chiamate ai tool, progetti e riscontri di politiche. Inizia con i risultati più frequenti, quindi ispeziona il progetto interessato e la cronologia dell'agente prima di abilitare l'applicazione.

    <Info>Il dashboard di audit locale è separato da **Analyze → Audits** in Failproof AI Cloud. Gli audit locali rimangono sulla macchina e non richiedono account o connessione di rete.</Info>
  </Tab>
  <Tab title="CLI">
    ```bash
    npm install -g failproofai
    failproofai audit
    ```

    Il comando esegue una scansione completa di ogni cronologia supportata che trova. Il comando attuale non accetta filtri come `--since`, `--cli`, `--project`, `--port` o `--no-open`.

    Mantieni il processo in esecuzione mentre utilizzi il dashboard locale. Premi <kbd>Ctrl</kbd>+<kbd>C</kbd> quando hai finito.
  </Tab>
</Tabs>

Gli attuali adattatori di audit possono leggere le cronologie da Claude Code, Codex, GitHub Copilot CLI, Cursor, OpenCode, Pi, Hermes, OpenClaw, Factory, Devin, Antigravity e Goose. Solo le cronologie disponibili localmente vengono scansionate.

## Pianifica audit locali ricorrenti

<Tabs>
  <Tab title="Dashboard">
    Apri **Settings** nel dashboard locale, abilita gli audit pianificati, scegli l'intervallo e imposta l'indirizzo email che dovrebbe ricevere i risultati. Il dashboard e la CLI aggiornano la stessa configurazione della macchina.
  </Tab>
  <Tab title="CLI">
    Abilita un audit settimanale e invia i risultati all'indirizzo specificato:

    ```bash
    failproofai audit --schedule 7 --email reliability@example.com
    failproofai audit --status
    ```

    L'intervallo accetta 1–90 giorni e il valore predefinito è 7 quando omesso. La prima configurazione ti accede quando necessario; `--email` fornisce l'indirizzo del report senza richiedere input.

    Interrompi la pianificazione senza eliminare la cronologia di audit locale:

    ```bash
    failproofai audit --no-schedule
    ```
  </Tab>
</Tabs>

Il daemon esegue scansioni pianificate in background, aggiorna il risultato memorizzato nella cache utilizzato dal dashboard locale e invia il report configurato. Utilizza `failproofai audit` quando desideri eseguire una scansione interattiva immediatamente.

## Passa da prove locali a operazioni Cloud

Un audit locale è una base veloce. Connetti la macchina a Failproof AI Cloud quando hai bisogno di tracce condivise, audit periodici della popolazione, risultati e problemi, avvisi, distribuzione di politiche a livello organizzativo o salute della flotta.

<Warning>
  L'output dell'audit è una prova per la revisione, non la prova che ogni azione segnalata sia unsafe. Conferma il contesto prima di trasformare un risultato in un'applicazione bloccante.
</Warning>
