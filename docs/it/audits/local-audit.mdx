Utilizza un audit locale per una revisione immediata e privata prima di connettere una macchina a Failproof AI Cloud. Esegue la scansione delle cronologie dell'agent già archiviate sulla tua macchina, riproduce l'attività degli strumenti attraverso le policy integrate e apre una dashboard dei risultati locale.

## Eseguire un audit interattivo

<Tabs>
  <Tab title="Dashboard">
    L'audit locale inizia dalla CLI perché deve scoprire le cronologie sulla macchina corrente. Esegui `failproofai audit`; dopo la scansione, Failproof AI avvia la dashboard integrata e apre **http://localhost:8020/audit**.

    Nella vista dell'audit, rivedi il numero di sessioni, chiamate a strumenti, progetti e policy hit. Inizia con i risultati più frequenti, quindi ispeziona il progetto interessato e la cronologia dell'agent prima di abilitare l'enforcement.

    <Info>La dashboard dell'audit locale è separata da **Analyze → Audits** in Failproof AI Cloud. Gli audit locali rimangono sulla macchina e non richiedono un account o una connessione di rete.</Info>
  </Tab>
  <Tab title="CLI">
    ```bash
    npm install -g failproofai
    failproofai audit
    ```

    Il comando esegue una scansione completa di ogni cronologia supportata che trova. Il comando attuale non accetta filtri come `--since`, `--cli`, `--project`, `--port` o `--no-open`.

    Mantieni il processo in esecuzione mentre utilizzi la dashboard locale. Premi <kbd>Ctrl</kbd>+<kbd>C</kbd> quando hai finito.
  </Tab>
</Tabs>

Gli attuali adapter di audit possono leggere cronologie da Claude Code, Codex, GitHub Copilot CLI, Cursor, OpenCode, Pi, Hermes, OpenClaw, Factory, Devin, Antigravity e Goose. Vengono scansionate solo le cronologie disponibili localmente.

## Pianificare audit locali ricorrenti

<Tabs>
  <Tab title="Dashboard">
    Apri **Settings** nella dashboard locale, abilita gli audit pianificati, scegli l'intervallo e imposta l'indirizzo email che deve ricevere i risultati. La dashboard e la CLI aggiornano la stessa configurazione della macchina.
  </Tab>
  <Tab title="CLI">
    Abilita un audit settimanale e invia i risultati all'indirizzo specificato:

    ```bash
    failproofai audit --schedule 7 --email reliability@example.com
    failproofai audit --status
    ```

    L'intervallo accetta 1–90 giorni e predefinito a 7 quando omesso. La prima configurazione ti accede quando necessario; `--email` fornisce l'indirizzo del report senza chiedere conferma.

    Interrompi la pianificazione senza eliminare la cronologia dell'audit locale:

    ```bash
    failproofai audit --no-schedule
    ```
  </Tab>
</Tabs>

Il daemon esegue le scansioni pianificate in background, aggiorna il risultato memorizzato nella cache utilizzato dalla dashboard locale e invia un email del report configurato. Utilizza `failproofai audit` quando desideri eseguire una scansione interattiva immediatamente.

## Passare da evidenze locali a operazioni Cloud

Un audit locale è una baseline veloce. Connetti la macchina a Failproof AI Cloud quando hai bisogno di tracce condivise, audit ricorrenti della popolazione, risultati e problemi, avvisi, distribuzione di policy a livello organizzativo o salute della flotta.

  L'output dell'audit è evidenza per la revisione, non prova che ogni azione segnalata sia non sicura. Conferma il contesto prima di trasformare un risultato in enforcement bloccante.
</Warning>
