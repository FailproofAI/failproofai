---
title: Visualizzare le sessioni
description: "Avvia il dashboard per consultare le sessioni degli agent e gestire le policy"
---

```bash
failproofai
```

Avvia il dashboard web all'indirizzo `http://localhost:8020`.

## Opzioni

| Flag | Descrizione |
|------|-------------|
| `--port <number>` | Porta su cui ascoltare (predefinita: `8020`) |
| `--allowed-origins <origins>` | Host/IP separati da virgola autorizzati ad accedere alle risorse di sviluppo |

Per indirizzare il dashboard a una cartella di progetto Claude non predefinita, imposta la variabile di ambiente `CLAUDE_PROJECTS_PATH` al momento dell'avvio.

## Esempi

```bash
# Avvia su una porta diversa
failproofai --port 9000

# Usa un percorso personalizzato dei progetti Claude tramite variabile di ambiente
CLAUDE_PROJECTS_PATH=~/my-claude-projects failproofai
```
