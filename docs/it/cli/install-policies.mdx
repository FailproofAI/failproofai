---
title: Installare le politiche
description: "Abilita le politiche in modo che vengano eseguite su ogni chiamata di tool dell'agente"
---

```bash
failproofai policies --install [policy-names...] [options]
```

Scrive voci di hook nel file delle impostazioni della CLI dell'agente installata (Claude Code, OpenAI Codex o GitHub Copilot CLI _(beta)_) in modo che failproofai intercetti le chiamate di tool.

Alias: `failproofai p -i`

## Opzioni

| Flag | Descrizione |
|------|-------------|
| `--cli claude\|codex\|copilot` | CLI dell'agente per cui installare; separate da spazi (es. `--cli claude codex copilot`) o ripetute. Ometti per rilevare automaticamente le CLI installate e ricevere un prompt. |
| `--scope user` | Installa nel file delle impostazioni con ambito utente (Claude: `~/.claude/settings.json`; Codex: `~/.codex/hooks.json`; Copilot: `~/.copilot/hooks/failproofai.json`). Impostazione predefinita. |
| `--scope project` | Installa nel file delle impostazioni con ambito progetto (Claude: `<cwd>/.claude/settings.json`; Codex: `<cwd>/.codex/hooks.json`; Copilot: `<cwd>/.github/hooks/failproofai.json`). |
| `--scope local` | Solo Claude — installa in `<cwd>/.claude/settings.local.json`. Codex e Copilot non hanno un ambito `local`. |
| `--custom <path>` / `-c` | Percorso di un file JS contenente politiche di hook personalizzate |

## Comportamento

- **Nessun nome di politica** - apre un prompt interattivo per selezionare le politiche
- **Nomi specifici** - abilita tali politiche (aggiunte a quelle già abilitate)
- **`all`** - abilita ogni politica disponibile

L'installazione è additiva: eseguire `--install` di nuovo aggiunge nuove politiche senza rimuovere quelle esistenti.

## Esempi

```bash
# Installa tutte le politiche predefinite globalmente (interattivo)
failproofai policies --install

# Installa politiche specifiche per il progetto corrente
failproofai policies --install block-sudo sanitize-api-keys --scope project

# Abilita tutte le politiche contemporaneamente
failproofai policies --install all

# Installa con un file di politiche personalizzate
failproofai policies --install --custom ./my-policies.js

# Installa per OpenAI Codex (ambito progetto)
failproofai policies --install --cli codex --scope project

# Installa per GitHub Copilot CLI (beta) per il progetto corrente
failproofai policies --install --cli copilot --scope project

# Installa per tutte e tre le CLI contemporaneamente
failproofai policies --install --cli claude codex copilot
```

Quando viene fornito `--custom <path>`, il file viene convalidato immediatamente - deve chiamare `customPolicies.add()` almeno una volta. Il percorso risolto viene salvato in `policies-config.json` come `customPoliciesPath`.
