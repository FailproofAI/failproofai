---
title: Installa i criteri
description: "Abilita i criteri in modo che vengano eseguiti su ogni chiamata di strumento dell'agente"
---

```bash
failproofai policies --install [policy-names...] [options]
```

Scrive voci hook nel file di impostazioni della CLI dell'agente installata (Claude Code, OpenAI Codex o GitHub Copilot CLI _(beta)_) in modo che failproofai intercetti le chiamate di strumenti.

Alias: `failproofai p -i`

## Opzioni

| Flag | Descrizione |
|------|-------------|
| `--cli claude\|codex\|copilot` | CLI dell'agente su cui eseguire l'installazione; separati da spazio (ad es. `--cli claude codex copilot`) o ripetuti. Ometti per rilevare automaticamente le CLI installate e ricevere una richiesta. |
| `--scope user` | Installa nel file di impostazioni con ambito utente (Claude: `~/.claude/settings.json`; Codex: `~/.codex/hooks.json`; Copilot: `~/.copilot/hooks/failproofai.json`). Impostazione predefinita. |
| `--scope project` | Installa nel file di impostazioni con ambito progetto (Claude: `<cwd>/.claude/settings.json`; Codex: `<cwd>/.codex/hooks.json`; Copilot: `<cwd>/.github/hooks/failproofai.json`). |
| `--scope local` | Solo Claude — installa in `<cwd>/.claude/settings.local.json`. Codex e Copilot non hanno un ambito `local`. |
| `--custom <path>` / `-c` | Percorso di un file JS contenente criteri hook personalizzati |

## Comportamento

- **Nessun nome di criterio** - apre un prompt interattivo per selezionare i criteri
- **Nomi specifici** - abilita quei criteri (aggiunti a quelli già abilitati)
- **`all`** - abilita tutti i criteri disponibili

L'installazione è additiva: eseguire `--install` di nuovo aggiunge nuovi criteri senza rimuovere quelli esistenti.

## Esempi

```bash
# Installa tutti i criteri predefiniti globalmente (interattivo)
failproofai policies --install

# Installa criteri specifici per il progetto corrente
failproofai policies --install block-sudo sanitize-api-keys --scope project

# Abilita tutti i criteri in una volta
failproofai policies --install all

# Installa con un file di criteri personalizzati
failproofai policies --install --custom ./my-policies.js

# Installa per OpenAI Codex (ambito progetto)
failproofai policies --install --cli codex --scope project

# Installa per GitHub Copilot CLI (beta) per il progetto corrente
failproofai policies --install --cli copilot --scope project

# Installa per tutti e tre i CLI contemporaneamente
failproofai policies --install --cli claude codex copilot
```

Quando viene fornito `--custom <path>`, il file viene convalidato immediatamente - deve chiamare `customPolicies.add()` almeno una volta. Il percorso risolto viene salvato in `policies-config.json` come `customPoliciesPath`.
