Aggiungi il riferimento completo di Failproof AI al tuo agent di coding in un comando. Funziona con Claude Code, Cursor, Windsurf e qualsiasi altro agent che supporti le skill.

```bash
npx skills add https://docs.befailproof.ai
```

`npx skills` rileva quali agent hai installato e aggiunge la skill nel formato corretto per ognuno automaticamente.

## Cosa copre la skill

| Area | Cosa è incluso |
|------|----------------|
| Policies | Nomi delle policy built-in, tipi di evento, parametri, enable/disable |
| Custom policies | `customPolicies.add()`, filtri di match, API `allow`/`deny`/`instruct` |
| Context object | `ctx.eventType`, `ctx.toolName`, `ctx.toolInput`, `ctx.session` |
| Configuration | Struttura di `policies-config.json`, scope merging, `policyParams` |
| CLI | `failproofai policies --install`, `--uninstall`, `--custom`, scope |
| Dashboard | Session viewer, policy activity, variabili d'ambiente |
| Architecture | Hook handler flow, codici di uscita, contratto stdin/stdout |

## La skill è completa?

Mintlify genera `llms.txt` da tutte le pagine nella navigazione. La documentazione di Failproof AI copre l'intera API - ogni policy, opzione e esempio è incluso. Se trovi qualcosa di mancante, la fonte si trova in `https://docs.befailproof.ai/llms-full.txt`.

Per un contesto mirato, collega direttamente a una pagina specifica:

```bash
# Solo l'API delle custom policies
npx skills add https://docs.befailproof.ai/custom-policies

# Solo le built-in policies
npx skills add https://docs.befailproof.ai/built-in-policies
```
