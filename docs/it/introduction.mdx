Hook e politiche per **la gestione dei fallimenti dell'AI**, **il recupero dagli errori** e **l'affidabilità dell'LLM**. Mantieni i tuoi agenti AI affidabili e in esecuzione autonoma su **Claude Code**, **OpenAI Codex**, **GitHub Copilot**, **Cursor Agent**, **OpenCode**, **Pi**, **Hermes**, **OpenClaw**, **Factory Droid**, **Devin CLI**, **Antigravity CLI** e l'**Agents SDK**.

Gli agenti AI falliscono in modi prevedibili. Eseguono comandi distruttivi, perdono segreti, si allontanano dall'attività, rimangono intrappolati in loop o eseguono push direttamente al ramo principale. Se lasciati incustoditi, i piccoli fallimenti si cascano in disservizi, credenziali perse e lavoro perduto.

FailproofAI risolve questo con le **politiche**. Queste regole si agganciano a ogni chiamata di strumento dell'agente per **rilevare i fallimenti**, **mitigarli** (bloccare, istruire, bonificare) e **avvertirti** quando qualcosa necessita attenzione. Una dashboard locale ti permette di rivedere ogni chiamata di strumento, fallimento dell'agente e azione di recupero successivamente.

Le trascrizioni e la valutazione delle politiche rimangono sul tuo computer. I dati vengono inviati solo quando utilizzi esplicitamente una funzione online, come i promemoria di audit autenticati o gli inviti.

## Avvio rapido

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # abilita le politiche (o salta — `failproofai` offrirà di configurarle al primo avvio)
failproofai                      # avvia la dashboard
```

Consulta la guida [Introduzione](/it/getting-started) per la procedura completa.
