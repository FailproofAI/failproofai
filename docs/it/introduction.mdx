Hook e politiche per la **gestione dei fallimenti AI**, il **recupero dagli errori** e l'**affidabilità dei modelli linguistici**. Mantieni i tuoi agenti AI affidabili e in esecuzione autonoma su **Claude Code**, **OpenAI Codex**, **GitHub Copilot**, **Cursor Agent**, **OpenCode**, **Pi**, **Hermes**, **OpenClaw**, **Factory Droid**, **Devin CLI**, **Antigravity CLI** e l'**Agents SDK**.

Gli agenti AI falliscono in modo prevedibile. Eseguono comandi distruttivi, perdono segreti, si allontanano dal compito, rimangono bloccati in loop oppure eseguono push direttamente al branch principale. Se lasciati incustoditi, i piccoli fallimenti si trasformano in disservizi, credenziali compromesse e lavoro perso.

FailproofAI risolve questo problema con le **politiche**. Queste regole si collegano a ogni chiamata di tool dell'agente per **rilevare i fallimenti**, **mitigarli** (bloccare, istruire, bonificare) e **avvisarti** quando è necessaria l'attenzione. Una dashboard locale ti permette di rivedere ogni chiamata di tool, fallimento dell'agente e azione di recupero in seguito.

I trascritti e la valutazione delle politiche rimangono sul tuo computer. I dati vengono inviati solo quando utilizzi esplicitamente una funzione online, come promemoria di audit autenticati o inviti.

## Avvio rapido

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # abilita le politiche (oppure salta — `failproofai` offrirà di configurarle al primo avvio)
failproofai                      # avvia la dashboard
```

Consulta la guida [Getting started](/it/getting-started) per la procedura dettagliata completa.
