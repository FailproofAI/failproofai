La copertura della flotta confronta ciò che Cloud ha assegnato con ciò che ogni macchina ha applicato più di recente.

## Controllare una macchina

```bash
failproofai config --status
failproofai flush --wait --timeout 120
```

Da Cloud:

```bash
fp fleet list
fp fleet diff
fp fleet show <machine-id>
```

`fp fleet` richiede una sessione autenticata, non una chiave API.

| Comando | Cosa fa |
| --- | --- |
| `fp fleet list` | Elenca le macchine e lo stato di distribuzione |
| `fp fleet show <machine>` | Mostra l'insieme di politiche di una macchina |
| `fp fleet deploy <machine> --add <ref>` | Aggiungi o aggiorna una politica |
| `fp fleet deploy <machine> --remove <id>` | Rimuovi una politica |
| `fp fleet deploy <machine> --set <ref>...` | Sostituisci l'intero insieme |
| `fp fleet diff [machine]` | Confronta le versioni previste e applicate |
| `fp fleet history <machine>` | Elenca le generazioni di distribuzione |
| `fp fleet rollback <machine> <generation>` | Ripristina una generazione |
| `fp fleet rename <machine> "<label>"` | Cambia l'etichetta Cloud |

<Warning>
  `--set` sostituisce l'intero insieme di politiche. Un semplice `--add <id>` applica una nuova politica immediatamente. Usa `--add <id>:observe` per un rollout in modalità shadow.
</Warning>

## Osserva, poi applica

```bash
fp fleet deploy ci-runner-01 --add prod-guard:observe
fp guardrails summary --since 24h --machine ci-runner-01
fp fleet deploy ci-runner-01 --add prod-guard:enforce
```

La modalità osservazione valuta la politica reale e registra le decisioni che non consentono il passaggio senza bloccare l'agente.

## Identità della macchina

L'ID della macchina è stabile e identifica la macchina. L'etichetta è solo per la visualizzazione e può cambiare:

```bash
failproofai config --machine-label checkout-runner-03
fp fleet rename <machine-id> "Checkout runner 03"
```

Cambiare l'etichetta non ricollega o rigenera le chiavi della macchina.
