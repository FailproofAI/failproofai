Un policy pack è un set di policy versionato pubblicato come release pubblica su GitHub. Il pacchetto non include un pack proprio; installa il nostro come qualsiasi altro:

```bash
failproofai policies show FailproofAI/policies
failproofai policies add FailproofAI/policies
```

`show` legge il manifest senza eseguire il codice del pack.

## Scegli cosa installare

```bash
failproofai policies add owner/repo --policy block-refunds
failproofai policies add owner/repo --category billing,git
failproofai policies add owner/repo --all
```

Senza selezione, il pack utilizza i valori predefiniti dell'editore. Aggiungere nuovamente una release più recente mantiene la selezione esistente.

Qualsiasi cosa con una barra è una sorgente di pack. Qualsiasi cosa senza una barra è un nome di policy.

## Blocca una release

| Sorgente | Risultato |
| --- | --- |
| `owner/repo` | Release più recente, bloccata dopo la risoluzione |
| `owner/repo@a1b2c3d4e5f6` | Release basata su commit esatto |
| `owner/repo@v2.1.0` | Release nominata esatta |
| URL di release GitHub | La release in quell'URL |

Un pack normalmente utilizza lo SHA del commit a 12 caratteri da cui è stato costruito. Usa `failproofai policies show owner/repo --releases` per vedere l'ordine delle release.

## Gestisci i pack installati

```bash
failproofai policies
failproofai policies remove block-refunds
failproofai policies add block-refunds
failproofai policies remove owner/repo
```

Se due pack installati contengono lo stesso nome di policy, la CLI rifiuta il nome ambiguo. Seleziona la policy tramite un pack o disinstalla l'altro.

## Sicurezza e disponibilità

Ogni release contiene un manifest, il codice delle policy raggruppate e i checksum. Failproof AI verifica il digest registrato prima di caricarlo. I checksum provano che i byte corrispondono alla release; non provano chi l'ha pubblicata.

Un pack selezionato che non può caricarsi fallisce in modo sicuro per gli eventi che ha dichiarato. Vedi [comportamento in caso di errore della policy](/it/policies/failure-behavior).

| Variabile | Effetto |
| --- | --- |
| `FAILPROOFAI_NO_DOWNLOAD=1` | Rifiuta i nuovi download; i pack installati continuano a essere eseguiti |
| `FAILPROOFAI_PACK_BASE_URL` | Usa uno specchio |
| `FAILPROOFAI_PACK_DIR` | Sposta il repository dei pack |

Sfoglia i pack nell'[Hub delle Policy](https://befailproof.ai/policy-hub/) o [pubblica il tuo](/it/policies/publish-a-pack).
