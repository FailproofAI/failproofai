Usa `fp` per ispezionare la telemetria Cloud e gestire audit, risultati, problemi, avvisi, chiavi, utenti, query e impostazioni. Usa [`failproofai`](/it/reference/failproof-cli) per hook locali, politiche, capture e iscrizione di macchine.

Installa la Cloud CLI rilasciata come strumento isolato:

```bash
uv tool install fp-cli
fp version
```

## Accedi

```bash
fp login
fp whoami
```

## Sintassi

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

Le opzioni globali devono precedere il comando:

```bash
fp --json sessions --since 24h
```

Esegui `fp COMMAND --help` o `fp COMMAND SUBCOMMAND --help` per l'aiuto del terminale.

### Eventi

```text
fp events [OPTIONS]
```

Elenca i singoli eventi dell'agente. Il feed leggero predefinito esclude i payload grezzi; usa `--full` solo per un'indagine limitata.

| Opzione | Descrizione |
| --- | --- |
| `--limit`, `-n <n>` | Numero massimo totale di righe. Predefinito: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h`, o `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | Intervallo UTC ISO 8601; sostituisce `--since`. |
| `--env <value>` | Filtro ambiente; ripeti o separa con virgole i valori. |
| `--event-type <value>` | Filtro tipo evento; ripeti o separa con virgole i valori. |
| `--agent-id <value>` | Filtro agente; ripeti o separa con virgole i valori. |
| `--session-id <value>` | Filtro sessione; ripeti o separa con virgole i valori. |
| `--search <text>` | Ricerca testo del payload; ripetibile, con qualsiasi termine corrispondente. |
| `--order asc\|desc` | Ordine temporale. Predefinito: più recente per primo. |
| `--all` | Pagina automatica fino a `--limit`. |
| `--cursor <token>` | Riprendi da un cursore opaco. |
| `--page-size <n>` | Righe per richiesta con `--all`; massimo `200`. |
| `--full` | Includi i payload grezzi tramite l'endpoint evento più pesante. |
| `--fields <csv>` | Restituisci solo i campi selezionati; richiedere `payload` abilita la modalità completa. |

```bash
fp events --session-id <session-id> --order asc --all
fp --json events --full --session-id <session-id> --all
```

### Chiavi API

| Comando | Scopo | Opzioni |
| --- | --- | --- |
| `fp keys list` | Elenca le chiavi dell'organizzazione. | `--show-id`; `--fields <csv>` |
| `fp keys show NAME` | Mostra una chiave e i suoi grant. | — |
| `fp keys create NAME` | Crea una chiave e rivelane il segreto una sola volta. | `--permission-set`; `--add`; `--remove` |
| `fp keys update NAME` | Sostituisci il set di permessi o adatta i grant. | `--permission-set`; `--add`; `--remove`; `--yes`, `-y` |

#### Opzioni di creazione dell'audit

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| Opzione | Descrizione |
| --- | --- |
| `--file <path>` | Basa la definizione su JSON, o usa `-` per stdin. I flag espliciti sostituiscono i valori del file. |
| `--description <text>` | Indica la domanda di fallimento o lo scopo. |
| `--enabled` / `--disabled` | Inizia la pianificazione attivata o disattivata. Predefinito: abilitato. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. Predefinito: `86400`. |
| `--schedule-anchor <timestamp>` | Fase UTC fissa in formato ISO 8601. Predefinito: prossime 09:00 UTC. |
| `--window-mode since_last\|fixed` | Continua dopo l'ultima finestra completamente analizzata o ispeziona ripetutamente una finestra mobile. Predefinito: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. Predefinito: `604800`. |
| `--scope '<json>'` | Filtra per `environments`, `agent_ids`, o altri campi di scope supportati. |
| `--ignore-error-type <type>` | Esclude i tipi di errore; ripeti o separa con virgole. |
| `--llm` / `--no-llm` | Abilita o disabilita l'analisi agentica. Predefinito: abilitato. |
| `--top-k <n>` | Mantieni `1`–`500` risultati. Predefinito: `50`. |
| `--sensitivity low\|medium\|high` | Imposta la sensibilità di segnalazione. Predefinito: `medium`. |
| `--channels '<json>'` | Array di canale di notifica. |
| `--text <brief>` | Brief in linea, massimo 8.192 caratteri. |
| `--text-file <path>` | Leggi il brief da un file; reciprocamente esclusivo con `--text`. |
| `--url <https-url>` | Aggiungi un riferimento HTTPS pubblico; ripeti fino a cinque volte. |

Includi il contesto durante la creazione quando la prima esecuzione ne ha bisogno. La creazione esegue il commit della definizione e del contesto insieme prima che l'esecuzione accodata inizi.

<Note>
  `fp audits run` è asincrono. Esegui il polling di `fp audits runs NAME` fino a quando l'esecuzione più recente non avrà successo o avrà esito negativo prima di leggere i suoi risultati.
</Note>

### Problemi

| Comando | Scopo | Opzioni |
| --- | --- | --- |
| `fp issues list` | Elenca i problemi. | `--state`; `--alert-id`; `--limit`, `-n`; `--show-id` |
| `fp issues count` | Conta i problemi aperti o selezionati. | `--state` |
| `fp issues show INCIDENT_ID` | Mostra i dettagli del problema, i commenti, gli abbonati e l'attività. | — |
| `fp issues open` | Apri un problema manuale o collegato a un avviso. | richiesto `--summary`; opzionale `--title`, `--alert-id`, `--severity` |
| `fp issues ack INCIDENT_ID` | Riconosci un problema. | — |
| `fp issues assign INCIDENT_ID` | Sostituisci gli assegnatari; ometti l'opzione per cancellarli. | ripetibile `--assignee` |
| `fp issues resolve INCIDENT_ID` | Risolvi un problema. | `--yes`, `-y` |
| `fp issues comment-list INCIDENT_ID` | Elenca i commenti. | — |
| `fp issues comment-add INCIDENT_ID` | Aggiungi un commento. | esattamente uno di `--body`, `--file` |
| `fp issues comment-delete INCIDENT_ID COMMENT_ID` | Elimina un commento. | `--yes`, `-y` |
| `fp issues subscribers INCIDENT_ID` | Elenca gli abbonati. | — |
| `fp issues subscribe INCIDENT_ID` | Iscriviti tu stesso o un altro operatore. | `--email` |
| `fp issues unsubscribe INCIDENT_ID` | Rimuovi un abbonamento. | `--email` |

Gli stati di problema validi sono `firing`, `acknowledged` e `resolved`. Le severità dei problemi autonomi sono `info`, `warning` e `critical`.

## Flag globali

| Flag | Descrizione |
| --- | --- |
| `--json` | Emetti JSON leggibile da macchina. |
| `--base-url <url>` | Usa un dashboard self-hosted o di sviluppo. |
| `--org <slug>` | Seleziona un'organizzazione per questa invocazione. |
| `--token <token>` | Sostituisci il token di sessione utente salvato. |
| `--api-key <key>` | Autentica l'automazione con una chiave API; mai salvata. |
| `--timeout <seconds>` | Timeout HTTP; deve essere positivo. Predefinito: `30`. |
| `--quiet`, `-q` | Sopprimere l'output di stato su stderr. |
| `--no-color` | Disabilita l'output colorato. |
| `--insecure` / `--secure` | Disabilita o ripristina la verifica del certificato TLS. |
| `--version` | Stampa la versione e esci. |
| `--help`, `-h` | Mostra l'aiuto. |

`--api-key` è destinato all'automazione. Login, cambio di organizzazione e comandi dell'assistente richiedono una sessione utente.

## Variabili d'ambiente

| Variabile | Equivalente o scopo |
| --- | --- |
| `AGENTEYE_DASHBOARD_URL` | `--base-url` |
| `AGENTEYE_ORG` | `--org` |
| `AGENTEYE_CLI_TOKEN` | `--token` |
| `AGENTEYE_CLI_API_KEY` | `--api-key` |
| `AGENTEYE_CLI_JSON` | `--json` |
| `AGENTEYE_INSECURE` | `--insecure` |
| `AGENTEYE_HOME` | Sposta la directory di configurazione CLI attuale. |
| `AGENTEYE_ANALYTICS_DISABLED` o `DO_NOT_TRACK` | Disabilita l'analitiche CLI anonime. |
| `NO_COLOR` | Disabilita l'output colorato. |

I flag espliciti sostituiscono le variabili d'ambiente, che a loro volta sostituiscono la configurazione salvata. In modalità chiave API, seleziona il tenant esplicitamente con `--org` o `AGENTEYE_ORG`.

<Warning>
  I comandi che eliminano, revocano, sopprimono, risolvono o sostituiscono la configurazione chiedono conferma per impostazione predefinita. Usa `--yes` solo dopo aver verificato l'organizzazione attiva e il target.
</Warning>
