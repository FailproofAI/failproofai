Usa `fp` per ispezionare la telemetria Cloud e gestire audit, findings, issues, alert, chiavi, utenti, query e impostazioni. Usa [`failproofai`](/it/reference/failproof-cli) per hook locali, policies, capture e enrollment delle macchine.

Installa la CLI Cloud rilasciata come strumento isolato:

```bash
uv tool install fp-cloud-cli
fp version
```

## Accedi

```bash
fp login
fp whoami
```

## Sintassi

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

Le opzioni globali devono precedere il comando:

```bash
fp --json sessions --since 24h
```

Esegui `fp COMMAND --help` o `fp COMMAND SUBCOMMAND --help` per l'aiuto nel terminale.

## Comandi CLI

### Eventi

```text
fp events [OPTIONS]
```

Elenca i singoli eventi degli agent. Il feed leggero predefinito esclude i payload grezzi; usa `--full` solo per un'indagine delimitata.

| Opzione | Descrizione |
| --- | --- |
| `--limit`, `-n <n>` | Numero massimo totale di righe. Predefinito: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h`, o `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | Intervallo ISO 8601 UTC; sostituisce `--since`. |
| `--env <value>` | Filtro per ambiente; ripeti o separa con virgola i valori. |
| `--event-type <value>` | Filtro per tipo di evento; ripeti o separa con virgola i valori. |
| `--agent-id <value>` | Filtro per agent; ripeti o separa con virgola i valori. |
| `--session-id <value>` | Filtro per sessione; ripeti o separa con virgola i valori. |
| `--search <text>` | Ricerca testo nel payload; ripetibile, qualsiasi termine corrisponde. |
| `--order asc\|desc` | Ordine temporale. Predefinito: più recente per primo. |
| `--all` | Auto-paginazione fino a `--limit`. |
| `--cursor <token>` | Riprendi da un cursore opaco. |
| `--page-size <n>` | Righe per richiesta con `--all`; massimo `200`. |
| `--full` | Includi payload grezzi tramite l'endpoint evento più pesante. |
| `--fields <csv>` | Restituisci solo i campi selezionati; richiedere `payload` abilita la modalità completa. |

```bash
fp events --session-id <session-id> --order asc --all
fp --json events --full --session-id <session-id> --all
```

### Chiavi API

| Comando | Scopo | Opzioni |
| --- | --- | --- |
| `fp keys list` | Elenca le chiavi dell'organizzazione. | `--show-id`; `--fields <csv>` |
| `fp keys show NAME` | Mostra una chiave e le sue concessioni. | — |
| `fp keys create NAME` | Crea una chiave e rivela il suo segreto una volta. | `--permission-set`; `--add`; `--remove` |
| `fp keys update NAME` | Sostituisci il set di permessi o regola le concessioni. | `--permission-set`; `--add`; `--remove`; `--yes`, `-y` |
| `fp keys regenerate NAME` | Ruota il segreto e rivela la sostituzione una volta. | `--yes`, `-y` |
| `fp keys disable NAME` | Revoca permanentemente una chiave. | `--yes`, `-y` |

I token di permesso usano il formato `resource:action`, come `events:add`. Ripeti `--add`, separa con virgola i token, o usa azioni puntate come `events:read.add`.

#### Opzioni di creazione dell'audit

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| Opzione | Descrizione |
| --- | --- |
| `--file <path>` | Basa la definizione su JSON, o usa `-` per stdin. I flag espliciti sostituiscono i valori del file. |
| `--description <text>` | Dichiara la domanda di fallimento o lo scopo. |
| `--enabled` / `--disabled` | Avvia la pianificazione attiva o disattivata. Predefinito: abilitato. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. Predefinito: `86400`. |
| `--schedule-anchor <timestamp>` | Fase UTC fissa in formato ISO 8601. Predefinito: prossimo 09:00 UTC. |
| `--window-mode since_last\|fixed` | Continua dopo l'ultima finestra completamente analizzata o ispeziona ripetutamente una finestra mobile. Predefinito: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. Predefinito: `604800`. |
| `--scope '<json>'` | Filtra per `environments`, `agent_ids`, o altri campi di scope supportati. |
| `--ignore-error-type <type>` | Escludi i tipi di errore; ripeti o separa con virgola. |
| `--llm` / `--no-llm` | Abilita o disabilita l'analisi agentica. Predefinito: abilitato. |
| `--top-k <n>` | Mantieni `1`–`500` findings. Predefinito: `50`. |
| `--sensitivity low\|medium\|high` | Imposta la sensibilità di segnalazione. Predefinito: `medium`. |
| `--channels '<json>'` | Array di canali di notifica. |
| `--text <brief>` | Brief inline, massimo 8.192 caratteri. |
| `--text-file <path>` | Leggi il brief da un file; mutuamente esclusivo con `--text`. |
| `--url <https-url>` | Aggiungi un riferimento HTTPS pubblico; ripeti fino a cinque volte. |

Includi il contesto durante la creazione quando la prima esecuzione ne ha bisogno. La creazione confirma la definizione e il contesto insieme prima che l'esecuzione in coda inizi.

<Note>
  `fp audits run` è asincrono. Esegui il polling di `fp audits runs NAME` finché l'esecuzione più recente non riesce o fallisce prima di leggere i suoi findings.
</Note>

## Flag globali

| Flag | Descrizione |
| --- | --- |
| `--json` | Emetti JSON leggibile da macchina. |
| `--base-url <url>` | Usa un dashboard self-hosted o di sviluppo. |
| `--org <slug>` | Seleziona un'organizzazione per questa invocazione. |
| `--token <token>` | Sostituisci il token di sessione utente salvato. |
| `--api-key <key>` | Autentica l'automazione con una chiave API; mai salvata. |
| `--timeout <seconds>` | Timeout HTTP; deve essere positivo. Predefinito: `30`. |
| `--quiet`, `-q` | Sopprimere l'output di stato su stderr. |
| `--no-color` | Disabilita l'output colorato. |
| `--insecure` / `--secure` | Disabilita o ripristina la verifica del certificato TLS. |
| `--version` | Stampa la versione non racchiusa ed esci. |
| `--help`, `-h` | Mostra l'aiuto. |

`--api-key` è destinato all'automazione. L'accesso, il passaggio di organizzazione e i comandi dell'assistente richiedono una sessione utente.

## Variabili di ambiente

| Variabile | Equivalente o scopo |
| --- | --- |
| `AGENTEYE_DASHBOARD_URL` | `--base-url` |
| `AGENTEYE_ORG` | `--org` |
| `AGENTEYE_CLI_TOKEN` | `--token` |
| `AGENTEYE_CLI_API_KEY` | `--api-key` |
| `AGENTEYE_CLI_JSON` | `--json` |
| `AGENTEYE_INSECURE` | `--insecure` |
| `AGENTEYE_HOME` | Rilocalizza la directory di configurazione CLI corrente. |
| `AGENTEYE_ANALYTICS_DISABLED` o `DO_NOT_TRACK` | Disabilita l'analytics CLI anonima. |

I flag espliciti sostituiscono le variabili di ambiente, che sostituiscono la configurazione salvata. In modalità chiave API, seleziona il tenant esplicitamente con `--org` o `AGENTEYE_ORG`.

<Warning>
  I comandi che eliminano, revocano, sopprimono, risolvono o sostituiscono la configurazione chiedono per impostazione predefinita. Usa `--yes` solo dopo aver verificato l'organizzazione attiva e il target.
</Warning>
