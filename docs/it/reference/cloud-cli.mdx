Usa `fp` per ispezionare la telemetria del Cloud, gestire l'enforcement gestito dal cloud (policy, distribuzioni di flotte, decisioni di guardrail) e gestire audit, findings, issues, alert, chiavi, utenti, query e impostazioni. Usa [`failproofai`](/it/reference/failproof-cli) per hook locali, policy, capture e enrollment di macchine.

Installa la Cloud CLI rilasciata come strumento isolato:

```bash
uv tool install fp-cloud-cli
fp version
```

## Accedi

```bash
fp login
fp whoami
```

## Sintassi

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

Le opzioni globali devono venire prima del comando:

```bash
fp --json sessions --since 24h
```

Esegui `fp COMMAND --help` o `fp COMMAND SUBCOMMAND --help` per l'aiuto nel terminale.

### Eventi

```text
fp events [OPTIONS]
```

Elenca i singoli eventi dell'agent. Il feed leggero predefinito esclude i payload grezzi; usa `--full` solo per un'indagine limitata.

| Opzione | Descrizione |
| --- | --- |
| `--limit`, `-n <n>` | Massimo totale di righe. Predefinito: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h` o `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | Intervallo ISO 8601 UTC; sostituisce `--since`. |
| `--env <value>` | Filtro per ambiente; ripeti o separa con virgola i valori. |
| `--event-type <value>` | Filtro per tipo di evento; ripeti o separa con virgola i valori. |
| `--agent-id <value>` | Filtro per agent; ripeti o separa con virgola i valori. |
| `--session-id <value>` | Filtro per sessione; ripeti o separa con virgola i valori. |
| `--search <text>` | Ricerca testo nel payload; ripetibile, corrisponde a qualsiasi termine. |
| `--order asc\|desc` | Ordine temporale. Predefinito: più recenti per primi. |
| `--all` | Paginazione automatica fino a `--limit`. |
| `--cursor <token>` | Riprendi da un cursore opaco. |
| `--page-size <n>` | Righe per richiesta con `--all`; massimo `200`. |
| `--full` | Includi payload grezzi attraverso l'endpoint evento più pesante. |
| `--fields <csv>` | Restituisci solo i campi selezionati; richiedere `payload` abilita la modalità completa. |

```bash
fp events --session-id <session-id> --order asc --all --limit 10000
fp --json events --full --session-id <session-id> --all --limit 10000
```

<Note>
  `--all` pagina **fino a `--limit`**, che ha predefinito **50** — quindi `--all` da solo si ferma a 50 righe. Quando si ferma anticipatamente la risposta contiene un `next_cursor` per riprendere da lì; `"next_cursor": null` significa che il feed era veramente esaurito.
</Note>

#### Opzioni di creazione audit

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| Opzione | Descrizione |
| --- | --- |
| `--file <path>` | Basa la definizione su JSON o usa `-` per stdin. Flag espliciti sostituiscono i valori del file. |
| `--description <text>` | Dichiara la domanda di errore o lo scopo. |
| `--enabled` / `--disabled` | Avvia la pianificazione attiva o no. Predefinito: abilitato. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. Predefinito: `86400`. |
| `--schedule-anchor <timestamp>` | Fase UTC fissa in formato ISO 8601. Predefinito: prossimo 09:00 UTC. |
| `--window-mode since_last\|fixed` | Continua dopo l'ultima finestra completamente analizzata o ispeziona ripetutamente una finestra mobile. Predefinito: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. Predefinito: `604800`. |
| `--scope '<json>'` | Filtra per `environments`, `agent_ids` o altri campi di scope supportati. |
| `--ignore-error-type <type>` | Escludi tipi di errore; ripeti o separa con virgola. |
| `--llm` / `--no-llm` | Abilita o disabilita l'analisi agentiva. Predefinito: abilitato. |
| `--top-k <n>` | Conserva `1`–`500` findings. Predefinito: `50`. |
| `--sensitivity low\|medium\|high` | Imposta la sensibilità di reporting. Predefinito: `medium`. |
| `--channels '<json>'` | Array di canali di notifica. |
| `--text <brief>` | Briefing inline, massimo 8.192 caratteri. |
| `--text-file <path>` | Leggi il briefing da un file; mutualmente esclusivo con `--text`. |
| `--url <https-url>` | Aggiungi un riferimento HTTPS pubblico; ripeti fino a cinque volte. |

Includi il contesto durante la creazione quando la prima esecuzione ne ha bisogno. La creazione impegna la definizione e il contesto insieme prima che l'esecuzione in coda inizi.

<Note>
  `fp audits run` è asincrona. Esegui il polling di `fp audits runs NAME` fino a quando l'esecuzione più recente riesce o non fallisce prima di leggere i suoi findings.
</Note>

### Policy

Versioni di policy gestite dal cloud. **Solo sessione** — ogni comando qui esce con `2` con una chiave API, prima di qualsiasi richiesta, perché questi sono percorsi di scrittura root-only deliberatamente assenti da `/v1`.

| Comando | Scopo | Opzioni |
| --- | --- | --- |
| `fp policies list` | Elenca le versioni di policy. | `--json` |
| `fp policies show POLICY_ID` | Mostra una policy con il suo sorgente. | — |
| `fp policies publish NAME PATH` | Crea una versione da un `.mjs` locale. | `--description`; `--no-verify` |
| `fp policies enable POLICY_ID` | Aggiungila a ogni deployment da cui è stata rimossa, creando una nuova generazione su ognuna. | `--yes`, `-y` |
| `fp policies disable POLICY_ID` | Rimuovila da ogni deployment che la contiene, creando una nuova generazione su ognuna. | `--yes`, `-y` |
| `fp policies delete POLICY_ID` | Elimina una versione di policy. | `--yes`, `-y` |
| `fp policies test PATH` | Esegui una policy localmente su un contesto sintetico. Applica il filtro `match` di ogni policy, quindi una che non copre l'evento/strumento specificato è riportata come `skipped` piuttosto che eseguita. | `--event`; `--tool`; `--command`; `--file-path`; `--expect` |
| `fp policies compose PROMPT` | Elabora una policy con l'assistente. Necessita `policies:write`. | — |

## Flag globali

| Flag | Descrizione |
| --- | --- |
| `--json` | Emetti JSON leggibile da macchina. |
| `--base-url <url>` | Usa un dashboard auto-hosted o di sviluppo. |
| `--org <slug>` | Seleziona un'organizzazione per questa invocazione. |
| `--token <token>` | Sostituisci il token di sessione utente salvato. |
| `--api-key <key>` | Autentica l'automazione con una chiave API; mai salvata. |
| `--timeout <seconds>` | Timeout HTTP; deve essere positivo. Predefinito: `30`. |
| `--quiet`, `-q` | Sopprimere l'output di stato su stderr. |
| `--no-color` | Disabilita l'output colorato. |
| `--insecure` / `--secure` | Disabilita o ripristina la verifica del certificato TLS. |
| `--version` | Stampa la versione e esci. |
| `--help`, `-h` | Mostra l'aiuto. |

`--api-key` è destinato all'automazione. L'accesso, il cambio di organizzazione e i comandi dell'assistente richiedono una sessione utente.

## Variabili d'ambiente

| Variabile | Equivalente o scopo |
| --- | --- |
| `FP_DASHBOARD_URL` | `--base-url` |
| `FP_ORG` | `--org` |
| `FP_TOKEN` | `--token` |
| `FP_API_KEY` | `--api-key` |
| `FP_JSON` | `--json` |
| `FP_INSECURE` | `--insecure` |
| `FP_HOME` | Riposiziona la directory di configurazione della CLI (predefinito `~/.failproofai/fpcli`). |
| `FP_ANALYTICS_DISABLED` o `DO_NOT_TRACK` | Disabilita l'analitiche anonime della CLI. |
| `NO_COLOR` | Disabilita l'output colorato. |

I flag espliciti sostituiscono le variabili d'ambiente, che a loro volta sostituiscono la configurazione salvata. In modalità chiave API, seleziona il tenant esplicitamente con `--org` o `FP_ORG`.

<Warning>
  I nomi `AGENTEYE_*` di questi **non sono letti da `fp`** e non lo sono mai stati — la CLI dichiara `FP_*` (`fp_cli/app.py`), e una variabile sconosciuta non è un errore. Impostare `AGENTEYE_DASHBOARD_URL` non reindirizz la CLI; viene ignorato e il comando è eseguito silenziosamente contro il dashboard salvato.

  `AGENTEYE_HOME` e `AGENTEYE_ENVIRONMENT` esistono ancora, ma appartengono al **collector e all'SDK di telemetria**, non a questa CLI.
</Warning>

<Warning>
  I comandi che eliminano, revocano, sopprimono, risolvono o sostituiscono la configurazione chiedono per impostazione predefinita. Usa `--yes` solo dopo aver verificato l'organizzazione attiva e il target.
</Warning>
