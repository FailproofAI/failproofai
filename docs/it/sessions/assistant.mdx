Chiedi a Failproof Assistant di fare qualsiasi cosa in Failproof AI in linguaggio naturale. Può analizzare sessioni e errori, eseguire query, costruire dashboard, indagare valutazioni e avvisi, e aiutarti a creare ed eseguire audit senza dover tradurre l'attività in schermate del prodotto o comandi CLI.

```text
Why did production checkout agents regress this week?
Build a dashboard for tool failures, latency, and evaluation scores.
Create an audit that finds agents retrying the same failed action without changing approach.
Show me the sessions behind the most common audit finding.
```

L'assistente funziona con i dati e le autorizzazioni disponibili nell'organizzazione attiva. Rivedi le prove e le modifiche proposte prima di applicare azioni che interessano altri utenti o agenti.

## Chiedi all'assistente

<Tabs>
  <Tab title="Dashboard">
    1. Seleziona **Open agent chat** e descrivi cosa vuoi comprendere, creare o gestire.
    2. Rivedi le chiamate ai tool, le tabelle e i risultati delle query dell'assistente mentre lavora.
    3. Apri la sessione, l'avviso o la query citata per verificare il risultato rispetto ai dati di origine.
    4. Avvia una nuova chat per un'indagine diversa, o utilizza la cronologia della chat per continuare la stessa linea di analisi.

    ![The Cloud assistant answering an observability question with supporting analysis and queries.](/images/dashboard/assistant.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp agent health
    fp agent models
    fp agent ask "Which production checkout agents had the most tool errors in the last 24 hours?"
    fp agent chats
    fp agent show <chat-id>
    fp agent ask "Open representative sessions" --chat <chat-id>
    ```

    Usa `fp agent rename <chat-id> --title <title>` per mantenere un'indagine riconoscibile e `fp agent delete <chat-id>` per rimuoverla.
  </Tab>
</Tabs>

## Lavora efficacemente con l'assistente

- Dagli prima un obiettivo; aggiungi un ambiente, un workflow o un intervallo temporale quando questi confini sono importanti.
- Considera SQL generato e riepiloghi come ausilio per l'indagine, non come prova finale.
- Apri sessioni rappresentative prima di creare un audit, un problema, un avviso o una policy.
- Mantieni espliciti i filtri di organizzazione, ambiente e tempo.
- Salva SQL utile come query in modo che un altro operatore possa riprodurre il risultato.

<Warning>
  L'assistente può leggere solo ciò che l'utente corrente può accedere. Non ampliare le autorizzazioni per risolvere una domanda; chiedi invece a un operatore autorizzato di eseguire l'indagine.
</Warning>
