Un hook è un punto in cui un agent chiede a Failproof AI una decisione. L'attività degli hook registra l'evento, la policy, il risultato e il tempo di valutazione.

## Investigare l'attività degli hook

<Tabs>
  <Tab title="Dashboard">
    Vai a **Observe → Hooks**. Filtra per ambiente, evento, agent o sessione.

    ![La pagina Hooks che mostra la latenza raggruppata per nome dell'hook e evento di attivazione.](/images/dashboard/hooks.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp guardrails summary --since 24h
    fp --json events --full --event-type hook_completed --session-id <session-id> --all --limit 500
    fp list hooks
    ```
  </Tab>
</Tabs>

Per impostazione predefinita, ogni decisione `deny` e `instruct` viene inviata per intero. Gli allow ripetuti vengono raggruppati per ridurre il rumore. Imposta `collector.hooks_verbosity` in `~/.failproofai/config.json` su `all`, `decisions` o `off`.

<Warning>
  L'attività degli hook dimostra che la valutazione è stata eseguita, non che il harness potrebbe bloccare quell'evento. Vedi [capacità di enforcement](/it/reference/harnesses#enforcement-capability). Una coppia harness-evento non elencata non è verificata.
</Warning>
