Strumenti mostra cosa chiamano gli agenti, quanto spesso le chiamate falliscono e quali sessioni interessano.

I nomi degli strumenti provengono da ogni harness dell'agente, quindi la stessa funzionalità può avere nomi diversi. Ad esempio, una chiamata shell può apparire come `Bash`, `exec`, `Shell`, `terminal`, o `run_command`. Esegui `fp list tools` prima di costruire un filtro.

<Tabs>
  <Tab title="Dashboard">
    Vai a **Observe → Tools**. Filtra per ambiente, strumento, agente o sessione.

    ![La pagina Tools che mostra latenza, suddivisione successi e errori, e distribuzione delle chiamate agli strumenti.](/images/dashboard/tools.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list tools
    fp events --event-type tool_use,tool_result --since 24h
    fp errors --event-type tool_result --since 24h
    fp --json events --full --event-type tool_use,tool_result --session-id <session-id> --all --limit 2000
    ```

    Usa `--full` quando hai bisogno di campi di payload come la durata per chiamata.
  </Tab>
</Tabs>

Usa questa pagina per trovare fallimenti ripetuti, confrontare esecuzioni funzionanti e fallite, o confermare che uno strumento mirato da una policy è effettivamente utilizzato.
