---

Strumenti raggruppa le chiamate di strumenti tra sessioni in modo da poter confrontare la latenza e la distribuzione delle chiamate.

<Tabs>
  <Tab title="Dashboard">
    1. Vai a **Observe → Tools**.
    2. Filtra per ambiente, nome dello strumento, agente o ID sessione.
    3. Rivedi la latenza e la distribuzione dello strumento.
    4. Seleziona un punto del grafico o un segmento dello strumento per aprire gli eventi e le sessioni corrispondenti.

    ![La pagina Tools che mostra i grafici di latenza, successo e guasto, e la distribuzione delle chiamate di strumenti.](/images/dashboard/tools.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list tools
    fp events --event-type tool_use,tool_result --env production --since 24h
    fp --json events --full --session-id <session-id> --all
    ```
  </Tab>
</Tabs>
