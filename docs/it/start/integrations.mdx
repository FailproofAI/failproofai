## Tre righe, qualsiasi framework

<CodeGroup>
```bash LangGraph
pip install 'failproofai-sdk[langgraph]'
```

```bash CrewAI
pip install 'failproofai-sdk[crewai]'
```

```bash LlamaIndex
pip install 'failproofai-sdk[llamaindex]'
```

```bash Pydantic AI
pip install 'failproofai-sdk[pydantic-ai]'
```

```bash Agenti personalizzati
pip install failproofai-sdk
```
</CodeGroup>

```python
import failproofai_sdk

failproofai_sdk.configure(environment="production")
failproofai_sdk.instrument()          # rileva i framework che hai importato

with failproofai_sdk.session():
    ...                               # la tua chiamata di agente esistente, invariata
```

Nessun decoratore sulle tue funzioni, nessun callback passato alle tue chiamate, nessun id thread nel tuo codice. Solo la chiamata all'interno della sessione differisce:

<Tabs>
  <Tab title="LangGraph">
    ```python
    graph.invoke({"messages": [HumanMessage("...")]})
    ```
  </Tab>
  <Tab title="CrewAI">
    ```python
    Crew(agents=[analyst, writer], tasks=[gather, summarise]).kickoff()
    ```
  </Tab>
  <Tab title="LlamaIndex">
    ```python
    await agent.run("...")        # under `async with failproofai_sdk.session():`
    ```
  </Tab>
  <Tab title="Pydantic AI">
    ```python
    agent.run_sync("...")
    ```
  </Tab>
  <Tab title="Agenti personalizzati">
    ```python
    with failproofai_sdk.agent("planner"):
        with failproofai_sdk.tool_call("search", input={"q": q}) as t:
            t.output = search(q)
    ```
  </Tab>
</Tabs>

L'extra installa il **framework**. Ogni adapter è incluso nella wheel di base, quindi un progetto che ha già il suo framework non necessita di extra.

## Verifica l'arrivo

Esegui una sessione strumentata, quindi apri **Observe → Sessions** e seleziona il tuo ambiente. L'esecuzione appare come una traccia ricostruita.

Se nulla arriva, conferma che la macchina è connessa con `failproofai config --status`. Vedi [Configura la cattura](/it/start/setup).

<Warning>
  Non controllare la directory di spool per confermare la consegna. Il daemon Failproof raccoglie ed elimina ogni batch entro millisecondi, quindi leggerlo gara con il collettore e mostra molti meno eventi di quelli emessi.
</Warning>
