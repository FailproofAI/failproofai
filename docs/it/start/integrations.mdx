## Tre righe, qualsiasi framework

<CodeGroup>
```bash LangGraph
pip install 'failproofai-sdk[langgraph]'
```

```bash CrewAI
pip install 'failproofai-sdk[crewai]'
```

```bash LlamaIndex
pip install 'failproofai-sdk[llamaindex]'
```

```bash Pydantic AI
pip install 'failproofai-sdk[pydantic-ai]'
```

```bash Custom agents
pip install failproofai-sdk
```
</CodeGroup>

```python
import failproofai_sdk

failproofai_sdk.configure(environment="production")
failproofai_sdk.instrument()          # rileva i framework che hai importato

with failproofai_sdk.session():
    ...                               # la tua chiamata agente esistente, invariata
```

Nessun decoratore sulle tue funzioni, nessun callback passato alle tue chiamate, nessun id filettato nel tuo codice. Solo la chiamata all'interno della sessione è diversa:

<Tabs>
  <Tab title="LangGraph">
    ```python
    graph.invoke({"messages": [HumanMessage("...")]})
    ```
  </Tab>
  <Tab title="CrewAI">
    ```python
    Crew(agents=[analyst, writer], tasks=[gather, summarise]).kickoff()
    ```
  </Tab>
  <Tab title="LlamaIndex">
    ```python
    await agent.run("...")        # under `async with failproofai_sdk.session():`
    ```
  </Tab>
  <Tab title="Pydantic AI">
    ```python
    agent.run_sync("...")
    ```
  </Tab>
  <Tab title="Custom agents">
    ```python
    with failproofai_sdk.agent("planner"):
        with failproofai_sdk.tool_call("search", input={"q": q}) as t:
            t.output = search(q)
    ```
  </Tab>
</Tabs>

L'installazione extra fornisce il **framework**. Ogni adattatore viene fornito nella wheel di base, quindi un progetto che ha già il suo framework non ha bisogno di nulla di extra.

## Verifica che sia arrivato

Esegui una sessione strumentata, quindi apri **Observe → Sessions** e seleziona il tuo ambiente. L'esecuzione viene visualizzata come una traccia ricostruita.

Se non arriva nulla, conferma che la macchina è connessa con `failproofai config --status`. Vedi [Configurare la cattura](/it/start/setup).

<Warning>
  Non controllare la directory di spool per confermare la consegna. Il daemon di Failproof raccoglie ed elimina ogni batch in pochi millisecondi, quindi leggerlo gara con il collector e mostra molti meno eventi di quelli emessi.
</Warning>
