Questa guida rapida configura una macchina per inviare sessioni, esegue un audit e distribuisce una policy. Usa la skill per configurare Failproof AI, oppure segui i passaggi manuali. È necessario Node.js 20.9 o versioni successive.

<Tabs>
  <Tab title="Usa la skill">
    <Steps>
      <Step title="Installa le skill di Failproof AI">
        ```bash
        npx skills add FailproofAI/skills
        ```
      </Step>
      <Step title="Chiedi al tuo agente di configurare tutto">
        ```text
        Set up Failproof AI for this project, connect this machine, install the right hooks and policies, and verify that a session arrives.
        ```

        Il tuo agente ispeziona il progetto, sceglie l'integrazione pertinente, esegue la configurazione e la verifica. Consulta il [repository delle skill di FailproofAI](https://github.com/FailproofAI/skills) per le skill individuali e le opzioni di installazione avanzate.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Configurazione manuale">
    ## Prima di iniziare

1. Apri il [dashboard di Failproof AI](https://app.befailproof.ai) e crea un account o accedi con la tua email di lavoro.
2. Vai su **Administration → Keys** e crea una chiave con i permessi `events:add` e `policies:pull`.
3. Copia il segreto usa-e-getta e salvalo sulla macchina target:

```bash
export FAILPROOFAI_KEY="<one-time-secret>"
```

    ## Installa

<Steps>
  <Step title="Installa e connetti Failproof AI">
    ```bash
    npm install -g failproofai
    failproofai config --connect https://app.befailproof.ai --token "$FAILPROOFAI_KEY"
    ```

    I trascritti delle sessioni vengono inviati per impostazione predefinita. Aggiungi `--no-transcripts` per segnalare l'attività degli hook e le decisioni delle policy senza il contenuto del trascritto.

    Se questa macchina ha già una cronologia dell'agente, visualizza in anteprima e importa gli ultimi sette giorni, quindi attendi il completamento della consegna. Salta questo passaggio su una nuova macchina.

    ```bash
    failproofai backfill --since 7d --dry-run
    failproofai backfill --since 7d
    failproofai flush --wait
    ```

    Apri **Sessions** in Failproof AI e seleziona una sessione importata.
  </Step>
  <Step title="Installa gli hook dell'agente e le policy">
    Questo collega Failproof AI alla CLI del tuo agente e installa le policy integrate. Usale per vedere le decisioni delle policy locali e provare l'enforcement prima che Failproof AI auditi le tue sessioni e scriva policy per i tuoi agenti.

    Lascia che il programma di installazione rilevi la CLI del tuo agente, oppure specificane uno esplicitamente.

    ```bash
    failproofai policies --install --cli claude --scope user
    ```
  </Step>
  <Step title="Audita il comportamento">
    Segui [Esegui il tuo primo controllo di errori](/it/start/first-audit). Usa un obiettivo concreto come "trovare sessioni in cui l'agente ha ritentato uno strumento che non funzionava senza cambiare il suo approccio."
  </Step>
  <Step title="Previeni l'errore">
    Segui [Previeni il tuo primo errore con una policy](/it/start/first-policy). Inizia in modalità osservazione, ispeziona le corrispondenze, quindi applica la versione revisionata.
  </Step>
</Steps>

<Check>
  Esegui `failproofai config --status`. Una configurazione corretta segnala la connessione cloud, lo stato del daemon e se l'enforcement è in pausa.
</Check>
  </Tab>
</Tabs>
