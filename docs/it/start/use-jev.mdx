Jev aiuta in due punti durante l'esecuzione di un agente: valutare una sessione completata rispetto a risposte note, oppure revisionare una chiamata tool nel contesto di ciò che hai chiesto all'agente di fare.

<Tabs>
  <Tab title="Jev evals">
    Usa una valutazione Jev quando una sessione completata può essere valutata rispetto a una domanda con alcune risposte note, ad esempio "Il cliente ha chiesto un rimborso? Rispondi sì o no." Ti aiuta a trovare pattern tra le sessioni.

    ## Creare una valutazione

    Nel dashboard Cloud, apri **analyse → checks → new check** (oppure **new evaluation**). Descrivi una domanda con risposta fissa, rivedi la regola che genera, e verifica che **how it checks** sia il **decision model** — cioè Jev. [Testala](/it/evaluations/test) su sessioni reali, quindi attivala.

    ![Il modulo di authoring della valutazione condivisa dove descrivi una domanda, rivedi la bozza e la distribuisci. Questo screenshot mostra una bozza di codice; usa una domanda con risposta fissa per Jev.](/images/dashboard/eval-authoring-draft.png)

    ## Leggi i punteggi

    Dopo che una nuova sessione si completa, apri **analyse → checks → evals** e seleziona la valutazione, oppure usa Cloud CLI:

    ```bash
    fp evals --since 7d
    fp evals --aggregate --since 7d
    ```

    La CLI legge i punteggi; la creazione di una valutazione Jev attualmente utilizza il dashboard. Vedi [Jev evaluations](/it/evaluations/jev) per i tipi di domande e gli esempi.
  </Tab>
  <Tab title="Jev policies">
    Usa la revisione dei criteri Jev quando un criterio basato su corrispondenza di stringhe ha bisogno del contesto della tua richiesta per decidere se una chiamata tool è sicura. Inizia in modalità **observe** così puoi ispezionare le risposte di Jev mentre i tuoi criteri installati decidono ancora ogni chiamata.

    I controlli di Jev provengono da un pacchetto; Failproof AI non ne spedisce nessuno. Finché non li installi, Jev non chiede nulla, anche se è configurato:

    ```bash
    failproofai policies add FailproofAI/jev-policies
    ```

    ## Configura Cloud Jev

    Nel dashboard Cloud, apri **settings → api keys** e, sotto **new key**, scegli **a machine running failproofai**. Usalo con `failproofai config` come mostrato nella [quickstart](/it/start/quickstart). Su una macchina senza una configurazione Jev esistente, questo abilita Cloud Jev in modalità observe. Verifica la connessione con:

    ```bash
    failproofai jev status
    failproofai jev test
    ```

    ## Usa il tuo endpoint

    Nel dashboard locale, apri **Settings → Jev**. Scegli il provider, incolla il suo token, seleziona **observe**, e attiva Jev.

    ![Il pannello impostazioni Jev locale con un provider, un campo token e la modalità observe selezionata.](/images/dashboard/jev-settings.png)

    Oppure configura e testa il tuo endpoint da un terminale:

    ```bash
    failproofai jev --url https://api.typesafe.ai/v1 --mode observe --key-stdin < ~/typesafe.key
    failproofai jev test
    ```

    Chiedi a un agente con hook di utilizzare il suo tool di lettura file su `README.md`. Conferma che la chiamata tool appaia nella sessione, quindi ispezionala sotto **Policies → Activity** nel dashboard locale. Una volta che i risultati dell'observe sembrano corretti, [Jev policies](/it/policies/jev) spiega quando applicare. Per i dettagli del provider e la configurazione, vedi la [integration reference](/it/reference/jev).
  </Tab>
</Tabs>
