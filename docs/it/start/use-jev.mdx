Jev aiuta in due punti durante l'esecuzione di un agente: valutare una sessione completata rispetto a risposte note, oppure revisionare un tool call nel contesto di ciò che hai chiesto all'agente di fare.

<Tabs>
  <Tab title="Jev evals">
    Usa una Jev eval quando una sessione completata può essere valutata rispetto a una domanda con alcune risposte note, ad esempio "Il cliente ha chiesto un rimborso? Rispondi sì o no." Ti aiuta a trovare pattern tra le sessioni.

    ## Creare una eval

    Nel dashboard Cloud, apri **analyse → checks → new check** (oppure **new evaluation**). Descrivi una domanda con risposta fissa, rivedi la regola che viene proposta e verifica che **how it checks** sia il **decision model** — cioè Jev. [Testala](/it/evaluations/test) su sessioni reali, quindi attivala.

    ![Il modulo di creazione della eval condivisa dove descrivi una domanda, rivedi la bozza e la distribuisci. Questo screenshot mostra una bozza di codice; usa una domanda a risposta fissa per Jev.](/images/dashboard/eval-authoring-draft.png)

    ## Leggi i punteggi

    Dopo che una nuova sessione si completa, apri **analyse → checks → evals** e seleziona la valutazione, oppure usa Cloud CLI:

    ```bash
    fp evals --since 7d
    fp evals --aggregate --since 7d
    ```

    La CLI legge i punteggi; la creazione di una Jev eval attualmente utilizza il dashboard. Vedi [Jev evaluations](/it/evaluations/jev) per i tipi di domande e gli esempi.
  </Tab>
  <Tab title="Jev policies">
    Usa la revisione della policy Jev quando una policy basata su corrispondenza di stringhe ha bisogno del contesto della tua richiesta per decidere se un tool call è sicuro. Inizia in modalità **observe** così potrai ispezionare le risposte di Jev mentre le tue policy installate decidono ancora ogni call.

    I controlli di Jev provengono da un pack; Failproof AI non ne spedisce nessuno. Finché non li installi, Jev non chiede nulla, anche quando è configurato:

    ```bash
    failproofai policies add FailproofAI/jev-policies
    ```

    ## Configura Cloud Jev

    Nel dashboard Cloud, apri **settings → api keys** e, sotto **new key**, scegli **a machine running failproofai**. Usalo con `failproofai config` come mostrato nella [quickstart](/it/start/quickstart). Su una macchina senza una configurazione Jev esistente, questo abilita Cloud Jev in modalità observe. Controlla la connessione con:

    ```bash
    failproofai jev status
    failproofai jev test
    ```

    ## Usa il tuo endpoint

    Nel dashboard locale, apri **Settings → Jev**. Scegli il provider, incolla il suo token, seleziona **observe** e attiva Jev.

    ![Il pannello delle impostazioni Jev locale con un provider, un campo token e la modalità observe selezionata.](/images/dashboard/jev-settings.png)

    Oppure configura e testa il tuo endpoint da un terminale:

    ```bash
    failproofai jev --url https://api.typesafe.ai/v1 --mode observe --key-stdin < ~/typesafe.key
    failproofai jev test
    ```

    Chiedi a un agente hooked di usare il suo tool di lettura file su `README.md`. Conferma che il tool call appaia nella sessione, quindi ispezionalo sotto **Policies → Activity** nel dashboard locale. Una volta che i risultati di observe sembrano corretti, [Jev policies](/it/policies/jev) spiega quando applicare. Per i dettagli del provider e la configurazione, vedi il [reference di integrazione](/it/reference/jev).
  </Tab>
</Tabs>
