管理セクションには、チーム全体でFailproof AIを運用するために必要なコントロールが含まれています。ほとんどのユーザーはセッション、監査、ポリシーの画面を利用すればよく、管理者はこのセクションでアクセスと運用範囲を管理します。

<Tabs>
  <Tab title="ダッシュボード">
    クラウドサイドバーの **Admin** セクションから **policy editor**、**enforcement**、**usage**、**keys**、**users**、**settings** にアクセスできます。ロックされた項目は、そのアカウントに読み取り権限がないことを示しています。

    ![The Admin section of the Cloud sidebar with policy editor, enforcement, usage, keys, users, and settings.](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    グローバルオプションはコマンドの前に指定します。例：`fp --org reliability-team --json usage`
  </Tab>
</Tabs>
