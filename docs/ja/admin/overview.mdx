管理セクションには、チーム全体で Failproof AI を運用するために必要なコントロールが含まれています。ほとんどのユーザーはセッション、監査、ポリシーの各画面を使用しますが、管理者はこのセクションでアクセス管理と運用上の境界を設定します。

<Tabs>
  <Tab title="ダッシュボード">
    クラウドサイドバーの **Admin** セクションから、**ポリシーエディター**、**適用**、**使用状況**、**キー**、**ユーザー**、**設定**にアクセスできます。ロックアイコンが表示されているアイテムは、アカウントに読み取り権限がないことを示しています。

    ![ポリシーエディター、適用、使用状況、キー、ユーザー、設定を含むクラウドサイドバーの Admin セクション。](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    グローバルオプションはコマンドの前に指定します。例: `fp --org reliability-team --json usage`
  </Tab>
</Tabs>
