Failproof AI Cloud は、ソフトウェア自体に関する利用状況テレメトリをメンテナーに送信します。エージェントのデータが含まれることは一切ありません。セルフホスト環境ではデフォルトで有効になっており、オフにすることができます。

## 収集される情報

すべてのイベントには5つのディメンションが含まれており、個人を特定する情報は含まれません。

| ディメンション | 例 | 内容 |
| --- | --- | --- |
| `product` | `agenteye` | どのプロダクトが送信したか |
| `component` | `dashboard`, `server`, `cli` | プロダクトのどの部分が送信したか |
| `app_version` | `0.0.1-beta.81` | 実行中のビルドバージョン |
| `deployment_kind` | `self_hosted` | カスタマーインストール、デモ環境、QA環境、開発マシンのいずれか |
| `org_id` | UUID | アクションが発生した組織を示す不透明な識別子 |

これらに加えて、イベントには**何が使用されたか（内容ではない）**が記録されます。たとえば、閲覧されたページ（`/:org/sessions/:id` のようなルートパターンとして記録され、実際のURLは含まれません）、適用されたフィルターの種類と数、アクションの成否、所要時間などです。

Slackアプリは、ワークスペースの接続・切断、アカウントリンク、質問の送信、チャートの投稿、承認の決定、および固定カテゴリによる失敗を記録します。Slackのワークスペース、ユーザー、チャンネルID、メールアドレス、質問・回答の内容、SQL、トークンは一切含まれません。

### 組織名について

不透明な `org_id` とあわせて、組織名・URLスラッグ・ダッシュボードアドレスを1回だけ記録します。これはすべてのイベントではなく、組織レコードに対して記録されます。これにより、採用状況の分析や報告された問題の調査の際に、どのアカウントにパターンが属するかを把握できます。これがプロダクトが送信する唯一の識別情報です。

### 利用状況の集計

サーバーは各組織の計測済み利用状況の合計（使用量ページに表示される数値と同じ）を報告します。これらはカウントのみです。イベント、セッション、エージェント、環境、評価実行、スコア、監査実行、保存済みクエリ、ダッシュボード、アラート、イシュー、APIキー、メンバー数、および計測期間の日付が含まれます。識別子、名前、クエリテキストは含まれず、誰かがサインインしているかどうかに関わらず送信されます。

## 収集されない情報

- **プロンプト、モデルの応答、イベントの内容** ——テキスト、プレフィックス、ハッシュのいずれの形式でも収集しません
- **セッション、エージェント、トレースの識別子**
- **評価スコアの名前**
- **エラーメッセージ、例外テキスト、レスポンスボディ** ——ステータスコードと固定リストのカテゴリのみ記録します
- **ツールの引数、SQL、クエリテキスト**
- **接続済みアプリの詳細** ——MCPクライアントの接続・失効時に送信されるのは最大でも権限の数のみであり、アプリ名やトークンは含まれません
- **メールアドレス**
- **リファラーURLやクエリ文字列**
- **画面録画、DOMキャプチャ、クリックやカーソルのトラッキング**

## セルフホスト環境でオフにする方法

ダッシュボードとサーバーの両方に `DO_NOT_TRACK=1` を設定してください。それぞれが独立して判断するため、どちらか一方にのみ設定した場合、もう一方は引き続き報告を行います。変更を反映するにはサーバーを再起動してください。

その他のオプトアウト設定とテレメトリが無効になっていることを確認する方法については、リリースREADMEをご参照ください。

## オプトアウト時の1回限りのpingについて

プロダクト設定で `DO_NOT_TRACK` を使わずにオプトアウトした場合、ダッシュボードはプロセス起動ごとに1/1000の確率で**匿名のpingを1回**送信することがあります。これは何人のオペレーターがテレメトリをオフにしているかを把握するためのものです。識別子は一切含まれません。組織、ユーザー、ホスト名、URL、IPアドレスは含まれず、プロダクト、コンポーネント、バージョン、デプロイ種別、および理由のみが含まれます。オプトアウト済みのサーバーは何も送信しません。

`DO_NOT_TRACK` を使用した場合はこのpingも送信されません。ポリシー上、外部へのテレメトリ送信を一切禁止している場合は `DO_NOT_TRACK` を使用してください。

## 送信先

TLS経由でポート443番を使用して PostHog（`us.i.posthog.com`）に送信されます。ホスト名は1つだけなので、単一のエグレスルールでブロックすることも可能です。

個人情報の取り扱いについての詳細は、[プライバシーポリシー](https://befailproof.ai/privacy/)をご覧ください。
