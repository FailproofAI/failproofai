Failproof AI Cloud は**ソフトウェア自体に関する**利用状況テレメトリーをメンテナーに送信します。エージェントのデータが含まれることは一切ありません。セルフホスト型インストールではデフォルトでオンになっており、オフにすることができます。

## 収集される情報

すべてのイベントには5つのディメンションが含まれており、個人を特定する情報は一切含まれません。

| ディメンション | 例 | 内容 |
| --- | --- | --- |
| `product` | `agenteye` | 送信元のプロダクト |
| `component` | `dashboard`, `server`, `cli` | 送信元のプロダクト構成要素 |
| `app_version` | `0.0.1-beta.81` | 実行中のビルドバージョン |
| `deployment_kind` | `self_hosted` | カスタマーインストール、デモ環境、QA環境、開発マシンのいずれか |
| `org_id` | UUID | アクションが発生した組織を示す不透明な識別子 |

これらに加えて、イベントには**何が使われたか**が記録され、**その内容は記録されません**。具体的には、閲覧されたページ（`/:org/sessions/:id` のようなルートパターンとして記録され、実際のURLは記録されません）、どの種類のフィルターが何件適用されたか、アクションが成功したかどうか、および処理にかかった時間が含まれます。

Slackアプリでは、ワークスペースの接続・切断、アカウントリンク、質問、チャート投稿、承認決定、および固定カテゴリ別の失敗が記録されます。Slackのワークスペース、ユーザー、チャンネルID、メールアドレス、質問・回答の内容、SQL、トークンは一切記録されません。

### 組織名について

不透明な `org_id` とあわせて、組織名、URLスラッグ、およびダッシュボードのアドレスを、各イベントにではなく組織レコードとして1回だけ記録します。これにより、導入状況の確認や報告された問題の調査の際に、特定のパターンがどのアカウントに属するかを把握できます。これは、プロダクトが送信する唯一の識別情報です。

### 利用状況の合計

サーバーは各組織の計量済み利用状況の合計を報告します。これはUsageページに表示される数値と同じものです。内容はカウントのみです：イベント、セッション、エージェント、環境、評価実行、スコア、監査実行、保存済みクエリ、ダッシュボード、アラート、問題、APIキー、メンバーの数、および計量ウィンドウの日付が含まれます。識別子、名前、クエリテキストは含まれず、誰かがサインインしているかどうかに関わらず送信されます。

## 収集されない情報

- **プロンプト、モデルの応答、イベントの内容**（テキスト、プレフィックス、ハッシュのいずれの形式も含まない）
- **セッション、エージェント、トレースの識別子**
- **エバリュエータースコア名**
- **エラーメッセージ、例外テキスト、レスポンス本文**（ステータスコードと固定リストのカテゴリのみ）
- **ツール引数、SQL、クエリテキスト**
- **接続済みアプリの詳細**（MCPクライアントの接続・失効時に権限の数を送信するのみで、アプリ名やトークンは送信されない）
- **メールアドレス**
- **リファラーURLやクエリ文字列**
- **スクリーン録画、DOMキャプチャ、クリックやカーソルのトラッキング**

## セルフホスト型インストールでオフにする方法

ダッシュボードとサーバーの両方に `DO_NOT_TRACK=1` を設定してください。それぞれが独立して判断するため、一方にのみ設定すると、もう一方は引き続き報告を行います。変更を適用するにはサーバーを再起動してください。

リリースのREADMEには、その他のオプトアウト設定とテレメトリーがオフになっていることを確認する方法が記載されています。

## オプトアウト時の1回限りのpingについて

プロダクト設定で `DO_NOT_TRACK` を使わずにオプトアウトした場合、ダッシュボードはプロセス起動ごとに1/1000の確率で**1回の匿名ping**を送信することがあります。これは、何人のオペレーターがテレメトリーをオフにしているかを把握するためのものです。内容には識別子は含まれません：組織、ユーザー、ホスト名、URL、IPアドレスは含まれず、プロダクト、コンポーネント、バージョン、デプロイメント種別、および理由のみが含まれます。オプトアウトしたサーバーは何も送信しません。

`DO_NOT_TRACK` を使用した場合は一切送信されません。ポリシーで外部へのテレメトリー送信が禁止されている場合は、この設定を使用することをお勧めします。

## 送信先

ポート443のTLS経由でPostHog（`us.i.posthog.com`）に送信されます。ホスト名は1つのみであるため、単一のegressルールでブロックすることも可能です。

個人情報の取り扱いについての詳細は、[プライバシーポリシー](https://befailproof.ai/privacy/)をご覧ください。
