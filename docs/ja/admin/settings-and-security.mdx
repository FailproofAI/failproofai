デプロイ固有の運用値やモデルのコンテキストウィンドウのオーバーライドには Settings を使用してください。APIまたはCLIで値を変更する前に、設定スキーマを確認しておきましょう。

## 組織設定の変更

<Tabs>
  <Tab title="ダッシュボード">
    1. **Administration → Settings** に移動し、設定グループを見つけて説明と現在のソースを確認します。
    2. 値を変更して保存します。
    3. モデルのコンテキストウィンドウについては、モデルオーバーライドを追加または更新し、有効な上限を確認します。
    4. 変更した値に依存するセッションやメトリクスを再確認します。

    ![組織の認証設定と運用設定を表示する Settings ページ。](/images/dashboard/settings.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp settings list
    fp settings schema
    fp settings set <key> --value <scalar>
    fp settings set alerts.email_default_recipients \
      --json-value '["oncall@example.com"]'
    ```

    インストール済みCLIが使用する値の型と確認フラグについては、`fp settings set --help` を実行してください。
  </Tab>
</Tabs>

## データ取り扱いの選択

Failproof AI CLIを接続すると、トレースや監査がトランスクリプトの内容に依存するため、デフォルトでトランスクリプトが送信されます。プロンプト、ファイルの内容、またはターミナル入力をローカルに留める必要がある場合は `--no-transcripts` を使用してください。フックアクティビティとポリシーの判断は引き続き報告できます。

ローカルの取り込み資格情報は、非シークレットのデーモン設定とは別に保存され、制限的なパーミッションで書き込まれます。APIキーは引き続き本番環境のシークレットとして管理してください。

## 組織設定リファレンス

ダッシュボードで編集可能なすべての設定は組織スコープです。デプロイ全体の動作はサーバー環境の設定として維持されます。

| キー | デフォルト | 目的 |
| --- | --- | --- |
| `allowed_sign_ins` | `[]` | 既存メンバーを特定のメールアドレスまたは `*@domain` に制限します。空のリストは追加の制限なしを意味します。 |
| `session_ttl_secs` | `86400` | ダッシュボードセッションの有効期間。60秒〜30日の範囲で設定可能です。 |
| `otp_ttl_secs` | `600` | OTPおよびマジックリンクの有効期間。60〜1800秒の範囲で設定可能です。 |
| `alerts.email_default_recipients` | `[]` | アラートのメールチャンネルでオーバーライドされない場合のデフォルト受信者。 |
| `alerts.slack_default_webhook` | 空 | デフォルトのSlack Incoming Webhook URL。 |
| `alerts.webhook_default_url` | 空 | デフォルトの汎用JSON Webhook URL。 |
| `alerts.webhook_signing_secret` | 空 | `X-AgentEye-Signature` ヘッダーに使用されるHMAC-SHA256キー。読み取り時はマスクされます。 |
| `alerts.enabled_channels` | email、Slack、webhook | アラートルールがディスパッチできる組織全体のチャンネル種別。 |
| `default_user_permissions` | `standard` | 新しい招待に対してあらかじめ選択される権限セットの名前。 |

`allowed_sign_ins` はフィルターであり、アクセス権の付与ではありません。対象者はすでに組織メンバーである必要があります。すべてのメンバーを許可するには空のリストを使用してください。単独の値 `*` は拒否されます。アラートURLは、ループバック開発アドレスを除き、HTTPSを使用する必要があります。

## セキュリティチェックリスト

- Cloudへの接続にはHTTPSを使用します。
- キーは最小限の権限セットにスコープを限定します。
- 本番環境と非本番環境を分離します。
- ロールアウト前にトランスクリプトとリダクションの設定を確認します。
- ユーザー、キー、組織の変更を監査します。
- デプロイにおけるバックアップ、保持、インシデント対応の要件をテストします。

<Warning>
  トランスクリプトのキャプチャをオフにすると、監査や調査で証明できる内容が変わります。その決定と想定される制限事項を記録しておいてください。
</Warning>
