デプロイメント固有の運用値やモデルのコンテキストウィンドウのオーバーライドには「設定」を使用してください。API または CLI を通じて値を変更する前に、設定スキーマを確認してください。

## 組織設定の変更

<Tabs>
  <Tab title="ダッシュボード">
    1. **管理 → 設定** に移動し、設定グループを見つけて、その説明と現在のソースを確認します。
    2. 値を変更して保存します。
    3. モデルのコンテキストウィンドウについては、モデルオーバーライドを追加または更新し、有効な上限を確認します。
    4. 変更した値に依存するセッションとメトリクスを再確認します。

    ![組織の認証および運用設定を表示する設定ページ。](/images/dashboard/settings.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp settings list
    fp settings schema
    fp settings set <key> --value <scalar>
    fp settings set alerts.email_default_recipients \
      --json-value '["oncall@example.com"]'
    ```

    インストールされている CLI で使用される値の型と確認フラグについては、`fp settings set --help` を実行してください。
  </Tab>
</Tabs>

## データ取り扱いの選択

Failproof AI CLI を接続すると、トレースや監査がその内容に依存するため、デフォルトでトランスクリプトが送信されます。プロンプト、ファイルの内容、またはターミナル入力をローカルに保持する必要がある場合は `--no-transcripts` を使用してください。フックのアクティビティとポリシーの決定は引き続き報告できます。

ローカルの取り込みクレデンシャルは、シークレット以外のデーモン設定とは別に保存され、制限されたパーミッションで書き込まれます。API キーは引き続き本番環境のシークレットとして管理してください。

## 組織設定リファレンス

ダッシュボードで編集可能なすべての設定は、組織スコープです。デプロイメント全体の動作はサーバー環境の構成として残ります。

| キー | デフォルト | 目的 |
| --- | --- | --- |
| `allowed_sign_ins` | `[]` | 既存メンバーを特定のメールアドレスまたは `*@domain` 形式に制限します。空のリストは追加制限なしを意味します。 |
| `session_ttl_secs` | `86400` | ダッシュボードのセッション有効期間。60秒〜30日の範囲で指定できます。 |
| `otp_ttl_secs` | `600` | OTPおよびマジックリンクの有効期間。60〜1800秒の範囲で指定できます。 |
| `alerts.email_default_recipients` | `[]` | アラートのメールチャンネルでオーバーライドされない場合のデフォルト受信者。 |
| `alerts.slack_default_webhook` | 空 | デフォルトの Slack インカミングWebhook URL。 |
| `alerts.webhook_default_url` | 空 | デフォルトの汎用 JSON Webhook URL。 |
| `alerts.webhook_signing_secret` | 空 | `X-AgentEye-Signature` ヘッダーに使用される HMAC-SHA256 キー。読み取り時はマスクされます。 |
| `alerts.enabled_channels` | email、Slack、webhook | アラートルールがディスパッチできる組織全体のチャンネル種別。 |
| `default_user_permissions` | `standard` | 新しい招待のためにあらかじめ選択される権限セットの名前。 |

`allowed_sign_ins` はフィルターであり、権限の付与ではありません。対象者はすでに組織メンバーである必要があります。すべてのメンバーを許可するには空のリストを使用してください。単独の値 `*` は拒否されます。アラート URL は、ループバック開発アドレスを除き HTTPS を使用する必要があります。

## セキュリティチェックリスト

- クラウド接続には HTTPS を使用する。
- キーは最小限の権限セットにスコープを絞る。
- 本番環境と非本番環境を分離する。
- ロールアウト前にトランスクリプトとリダクション設定を確認する。
- ユーザー、キー、および組織の変更を監査する。
- デプロイメントのバックアップ、保持ポリシー、およびインシデント対応要件をテストする。

<Warning>
  トランスクリプトのキャプチャをオフにすると、監査や調査で証明できる内容が変わります。その決定と予想される制限事項を記録してください。
</Warning>
