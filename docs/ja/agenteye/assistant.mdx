エージェントのデータに平易な言葉で質問し、根拠に直接リンクした回答を得られます。SQLを書く必要も、ダッシュボードを掘り下げる必要もありません — **Failproof AI Observability** アシスタントは、チームの誰もがエージェントに関する答えを最速で得るための手段です。

![Failproof AI Observability アシスタントがダッシュボード内で平易な言葉による質問に回答している画面。ライブのエージェントアクティビティテーブル、エージェントごとのモデル使用状況の内訳、文章による要点が表示され、実行されたクエリがインラインで示されている](/agenteye/images/assistant.png)
*平易な言葉で質問すると、実際のデータから構築された回答が返されます。ここでは、どのエージェントが最も忙しいか、どのモデルを使用しているかが分析され、すべての数値を検証できるよう実行されたクエリも表示されています。*

学ぶべきことは何もありません。チャットを開いて知りたいことを入力し、返ってきたリンクをたどるだけです。

```
You:  which sessions errored today?
AI:   5 sessions errored today, newest first. Each one is linked:
      • checkout-agent   14:02   tool timeout
      • billing-agent    11:47   unhandled error
      • ...and 3 more

You:  summarize this session          (asked while viewing a run)
AI:   This run took 12 steps across 3 tools and failed near the end when a
      payment tool returned an error. It scored low on your "resolved" eval.
      Links: the session, the failing event, and that evaluation.
```

## 質問するだけで、すぐに根拠へジャンプ

推測も不要、クエリの記述も不要です。「今週のプロダクション環境での品質トレンドは？」「今日エラーになったセッションはどれ？」「このセッションを要約して」と尋ねれば、クエリを組み立てて自分で読む代わりに、数秒で明確な答えが返ってきます。

すべての回答には根拠が伴います。アシスタントは答えを導き出すために使用した正確なセッション、保存済みクエリ、ダッシュボードへのリンクを提示するので、信じるだけでなくクリックして確認できます。また**ページを認識**しているため、あるセッションを表示中に「このセッション」と尋ねれば、どの実行を指しているかすでに把握しています。履歴スイッチャーから過去の会話をいつでも再開し、続きから再開できます。

## 良い回答を保存済みクエリやダッシュボードに変換

保存する価値のある回答は、アシスタントに保存を依頼できます。アシスタントが保存済みクエリ用のSQLを下書きするか、それらのクエリからダッシュボードを組み立てて、**承認 / 拒否**カードを表示します。「承認」をクリックするまで何も書き込まれないので、「質問するだけ」のスピード感を保ちながら、最終決定は常に自分の手に残ります。

**クエリ**ページではさらに一歩進んで、SQLの作成者として機能します。「過去7日間のエージェント別エラーレートを表示して」のように欲しいクエリを説明すると、SQLがエディタに直接ストリーミングされ、変更が確定する前に**承認**または**拒否**できるdiffビューが表示されます。

![ObservabilityのクエリページとSQLエディタ](/agenteye/images/query-lab.png)
*クエリページ：アシスタントが下書きの読み取り専用クエリをストリーミングし、承認または拒否するためのエディタ。*

ここで質問しながらSQLを作成する際は、エディタの**実行**ボタンと同じ`queries:run`権限を使用します。それ以外の場所でのチャットには`agent:use`が必要です。

## チーム全体に安心して公開できる

アシスタントが何に触れるか心配せずに、全員に開放できます。

- **すでに閲覧できる情報のみ読み取ります。** 回答はあなた自身の読み取り権限に限定されるため、データへのアクセス範囲が広がることはありません。
- **すべての書き込みはあなたの承認を待ちます。** 保存済みクエリとダッシュボードは、明示的に「承認」をクリックした後にのみ作成され、このゲートをオフにする設定はありません。
- **削除は一切できません。** 削除ツールは公開されておらず、アシスタントは削除権限を持ちません。削除操作はダッシュボード上であなたの手に委ねられています。
- **組織内に留まります。** アシスタントは現在表示している組織のみを参照します。
- **あなたの質問はあなただけのものです。** プロンプトと回答はあなた自身のObservabilityデータベースに保存されます。プロダクトアナリティクスは使用メタデータのみを記録し、プロンプトのテキストは記録しません。

## 見つけ方

アシスタントは組織配下のすべてのページ（`/<org-slug>/...`）の右端に常駐しています。レールをクリックするか、`⌘J` / `Ctrl+J`を押してフルチャットパネルに展開し、端をドラッグしてリサイズできます。幅はページリロード後も保持されます。使用するには**`agent:use`**権限が必要で、権限がない場合はレールがグレーアウトされます。デプロイ環境でまだ有効化されていない場合（LLM接続が必要です）、動作するチャットの代わりにミュートされたレールが表示されます。
