平易な言葉でエージェントデータに質問するだけで、根拠へ直接リンクした回答が返ってきます。SQLを書く必要も、ダッシュボードを掘り下げる必要もありません。**Failproof AI Observability** アシスタントは、チームの誰もがエージェントについての答えをすばやく得られる最速の手段です。

![ダッシュボード内でFailproof AI Observabilityアシスタントが平易な質問に回答している画面。ライブのエージェントアクティビティテーブル、エージェントごとのモデル使用量の内訳、まとめテキストが表示され、実行したクエリがインラインで示されている](/agenteye/images/assistant.png)
*平易な言葉で質問すると、あなた自身のデータから構築された回答が返ってきます。ここでは最も使われているエージェントとそれが使用するモデルを分析し、すべての数値を検証できるよう実行したクエリも表示しています。*

学ぶことは何もありません。チャットを開いて知りたいことを入力し、返ってきたリンクをたどるだけです。

```
You:  which sessions errored today?
AI:   5 sessions errored today, newest first. Each one is linked:
      • checkout-agent   14:02   tool timeout
      • billing-agent    11:47   unhandled error
      • ...and 3 more

You:  summarize this session          (asked while viewing a run)
AI:   This run took 12 steps across 3 tools and failed near the end when a
      payment tool returned an error. It scored low on your "resolved" eval.
      Links: the session, the failing event, and that evaluation.
```

## 質問するだけで、証拠に直接ジャンプ

推測も、クエリを書く手間もなくなります。「今週のプロダクション環境での品質トレンドは？」「今日エラーになったセッションはどれ？」「このセッションを要約して」と聞けば、自分でクエリを組み立てて読む代わりに、数秒で明確な答えが返ってきます。

すべての回答には裏付けが付いています。アシスタントは答えを導き出すために使用した、正確なセッション・保存済みクエリ・ダッシュボードへのリンクを提示するので、言葉を鵜呑みにせずクリックして確認できます。また**ページ認識機能**も備えています。セッションを表示中に「このセッション」と聞けば、どの実行を指しているか既に把握しています。履歴スイッチャーから過去の会話をいつでも再開して、続きから進められます。

## 良い回答を保存済みクエリやダッシュボードに変換

保存しておく価値のある回答が得られたら、アシスタントに保存を依頼してください。アシスタントは保存済みクエリ用のSQLを下書きし、またはそれらのクエリからダッシュボードを組み立て、**承認 / 却下** カードを表示します。「承認」をクリックするまで何も書き込まれないので、「聞くだけ」のスピードを享受しながら、最終決定は常に自分の手元に残ります。

**クエリ**ページではさらに一歩進んで、SQLの作成者として機能します。欲しいクエリを「過去7日間のエージェント別エラー率を表示して」と説明すると、エディターに直接SQLがストリーム入力され、変更を**承認**または**却下**できるdiffビューが開きます。

![ObservabilityのクエリページとSQLエディター](/agenteye/images/query-lab.png)
*クエリページ：このエディターにアシスタントが下書きの読み取り専用クエリをストリームで出力します。承認または却下を選択できます。*

ここでSQLの作成を依頼すると `queries:run` 権限が使用されます。これはエディターの**実行**ボタンと同じ権限です。それ以外の場所でのチャットには `agent:use` が必要です。

## チーム全員に安心して開放できる

アシスタントが何に触れるかを心配せずに、全員に開放できます。

- **読み取れるのは、あなたがすでに見られるデータのみ。** 回答はあなた自身の読み取り権限にスコープされており、データの範囲が勝手に広がることはありません。
- **すべての書き込みはあなたの承認を待ちます。** 保存済みクエリとダッシュボードは、明示的に「承認」をクリックした後にのみ作成されます。このゲートをオフにする設定は存在しません。
- **削除は一切できません。** 削除ツールは公開されておらず、アシスタントは削除権限を持ちません。削除操作はダッシュボード上のあなたの手元に残ります。
- **組織の外には出ません。** アシスタントが参照できるのは、現在表示している組織のみです。
- **質問内容はあなたのものです。** プロンプトと回答はあなた自身のObservabilityデータベースに保存されます。プロダクトアナリティクスが記録するのは使用メタデータのみで、プロンプトの内容は記録されません。

## 場所

アシスタントはあなたの組織配下のすべてのページ（`/<org-slug>/...`）の右端に常駐しています。レールをクリックするか、`⌘J` / `Ctrl+J` を押すと全画面チャットパネルに展開でき、端をドラッグしてサイズを調整できます。幅の設定はリロードをまたいで保持されます。使用するには **`agent:use`** 権限が必要で、権限がない場合はレールがグレーアウトされます。デプロイ環境でまだ有効化されていない場合（LLM接続が必要）、動作するチャットの代わりにミュート状態のレールが表示されます。
