エージェントのデータについて日常的な言葉で質問し、根拠に直接リンクした回答を得られます。SQLを書く必要も、ダッシュボードを掘り下げる必要もありません。**Failproof AI Observability** アシスタントは、チームの誰もがエージェントについての答えを最速で得られる方法です。

![Failproof AI Observabilityアシスタントがダッシュボード内で日常的な言葉による質問に回答している様子。ライブのエージェントアクティビティテーブル、エージェントごとのモデル使用状況の内訳、文章によるまとめが表示され、実行されたクエリがインラインで示されている](/agenteye/images/assistant.png)
*日常的な言葉で質問し、自分のデータから構築された回答を得られます。ここではどのエージェントが最も忙しく、どのモデルを使用しているかを分析し、すべての数値を検証できるよう実行したクエリも表示しています。*

覚えることは何もありません。チャットを開き、知りたいことを入力して、返ってきたリンクをたどるだけです:

```
You:  which sessions errored today?
AI:   5 sessions errored today, newest first. Each one is linked:
      • checkout-agent   14:02   tool timeout
      • billing-agent    11:47   unhandled error
      • ...and 3 more

You:  summarize this session          (asked while viewing a run)
AI:   This run took 12 steps across 3 tools and failed near the end when a
      payment tool returned an error. It scored low on your "resolved" eval.
      Links: the session, the failing event, and that evaluation.
```

## 質問するだけで、証拠へ直接ジャンプ

推測も、クエリ作成も必要ありません。「今週の本番環境での品質トレンドは？」「今日エラーになったセッションは？」「このセッションを要約して」と聞けば、自分でクエリを組み立てて読む代わりに、数秒で明確な答えが返ってきます。

すべての回答には根拠が付いています。アシスタントは答えを導き出すために使用した正確なセッション、保存済みクエリ、ダッシュボードへのリンクを提示するので、鵜呑みにするのではなくクリックして確認できます。また**ページ認識機能**も備えており、セッションを表示中に「このセッション」について質問すると、どの実行を指しているかをすでに把握しています。履歴スイッチャーから過去の会話を後で開き直して、中断したところから再開することもできます。

## 良い回答を保存済みクエリやダッシュボードに変換する

保存しておく価値のある回答が得られたら、アシスタントに保存を依頼してください。保存済みクエリのSQLを作成したり、それらのクエリからダッシュボードを組み立てたりして、**承認 / 拒否**カードを表示します。「承認」をクリックするまで何も書き込まれないため、「質問するだけ」のスピード感を保ちながら、最終決定は常にあなたの手元に残ります。

**クエリ**ページではさらに一歩進み、SQLの作成者として機能します。欲しいクエリを説明する（「過去7日間のエージェントごとのエラー率を表示して」など）と、SQLがエディタに直接ストリーミングされ、差分ビューが開いて変更を**承認**または**拒否**してから反映できます。

![ObservabilityクエリページとそのSQLエディタ](/agenteye/images/query-lab.png)
*クエリページ：このエディタはアシスタントが承認または拒否のための読み取り専用のドラフトクエリをストリーミングする場所です。*

ここで質問してSQLを作成する機能は `queries:run` 権限を使用します。これはエディタの**実行**ボタンと同じ権限です。それ以外の場所でのチャットには `agent:use` が必要です。

## チーム全体に安心して開放できる

アシスタントが何に触れるか心配せずに、誰でも使えるよう開放できます:

- **表示できるデータのみ読み取ります。** 回答はあなた自身の読み取り権限のスコープに限定されるため、データの参照範囲が広がることはありません。
- **すべての書き込みはあなたの承認を待ちます。** 保存済みクエリとダッシュボードは、明示的に「承認」をクリックした後にのみ作成されます。このゲートをオフにする設定はありません。
- **削除は一切できません。** 削除ツールは公開されておらず、アシスタントは削除権限を持っていません。削除操作はダッシュボード上であなたの手元に残ります。
- **組織内に留まります。** アシスタントは現在表示中の組織のみを参照します。
- **質問はあなただけのものです。** プロンプトと回答はあなた自身のObservabilityデータベースに保存されます。プロダクトアナリティクスは使用メタデータのみを記録し、プロンプトのテキストは一切記録しません。

## 使い方

アシスタントはあなたの組織（`/<org-slug>/...`）配下のすべてのページの右端に表示されています。レールをクリックするか、`⌘J` / `Ctrl+J` を押すとフルチャットパネルに展開でき、端をドラッグしてリサイズできます。幅の設定はリロードをまたいで記憶されます。使用するには **`agent:use`** 権限が必要です。権限がない場合、レールはグレーアウトされます。デプロイメントでまだ有効化されていない場合（LLM接続が必要です）、動作するチャットの代わりにミュートされたレールが表示されます。
