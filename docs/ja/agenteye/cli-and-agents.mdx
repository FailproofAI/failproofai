Failproof AI Observability のデプロイ全体を、コマンド一つで操作できます。ターミナルを離れずに本番環境を確認し、APIキーを発行し、インシデントに対応できます。さらに CI にスクリプトとして組み込んだり、コーディングエージェントに自然な英語で任せることもできます。

```bash
pipx install agenteye
agenteye login --email you@example.com      # 6桁のコードがメールで届きます
agenteye --json sessions --since 24h         # 過去1日のエージェント実行記録を新しい順に取得
```

*`agenteye` CLI はダッシュボードと通信します。イベントをサーバーに送信するコレクターとは別のツールです。*

## デプロイ全体をコマンド一つで

ちょっとした確認のためにタブを行き来するのはもうやめましょう。`agenteye` CLI は単一のバイナリからデータの参照と組織の管理を行えるため、ダッシュボードをクリックしていた確認作業が一行のコマンドになります。そのままエイリアスに登録したり、ランブックに貼り付けたりすることも可能です。以下の4つの機能を提供しています。

- **データの参照:** `sessions`、`events`、`evals`、`errors` を時間・エージェント・環境でフィルタリング。
- **組織の管理:** `keys`、`users`、`settings`、`alerts`、`incidents`。
- **分析の実行:** 保存済みSQL と、イベントデータに対してアドホックに実行できる `query` ランナー。
- **アシスタントへの問い合わせ:** `agent ask` でダッシュボード上のチャットと同じ読み取り専用アナリストに接続。

`pipx` で一度インストールし、メールで届く6桁のコードでサインインすれば準備完了です。セッションは約1日間持続し、期限が切れたら `agenteye login` を再実行してください。ブラウザを開かずに本番環境のスポットチェック、キーのプロビジョニング、発火中のインシデントのトリアージが行えます。

```bash
agenteye errors --since 24h --aggregate      # エラータイプ別にグループ化された障害状況
agenteye incidents list --state firing       # 現在発火中のインシデント一覧
agenteye keys create ci --add events:add     # イベント送信のみ可能なキーを作成（シークレットは一度だけ表示）
```

一つ覚えておきたい習慣があります。`--json` などのグローバルオプションはコマンドの前に置きます。`agenteye --json sessions` が正しく、`agenteye sessions --json` は正しくありません。

## スクリプト化してCIに組み込む

すべてのコマンドは `--json` に対応しており、これが大きな違いをもたらします。クリーンなJSONが stdout に出力され、人間向けのステータスや警告は stderr に出力されます。そのため `--json` で取得した出力は余計な行を取り除くことなく、そのまま `jq` にパイプできます。これにより、CLI はプロンプトで使う場合にも、出力をパースするコーディングエージェントが使う場合にも、同様に使いやすくなっています。

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

無人実行にも対応しています。ターミナルが接続されていない場合、確認プロンプトは自動的にスキップされるため、パイプライン内でハングすることはありません。また、すべてのコマンドは意味のある終了コードを返します。`0` は成功、`4` は未ログイン、`5` は権限不足（メッセージに `alerts:write` のように不足している権限名が表示されます）、`3` はダッシュボードへの接続不可です。スクリプトは `4` で再認証処理に分岐したり、`5` で管理者に何を依頼すべきかを正確に伝えるなど、エラー内容を把握した上で適切に対処できます。

## コーディングエージェントに自然言語で任せる

さらに良い方法として、これらのフラグをすべて覚える必要はそもそもありません。**CLIスキル**は `agenteye-cli` という小さなAgent Skillフォルダーで、Claude Code や Codex などのコーディングエージェントが自然言語のリクエストからCLIを操作できるように教えます。「今日何か壊れているものはある？」と聞くだけで、エージェントが適切なコマンドを選んで実行し、結果を文章で答えてくれます。

Claude Code の場合は、`agenteye-cli` フォルダーを `~/.claude/skills/` に置くだけで自動的に認識されます。Failproof AI Observability がフォルダーを提供するため、追加インストールは不要です。すでにインストール済みのCLIを操作するだけだからです。ただし、事前に自分でログインしておいてください。スキルはメールコードによるログインを代行することができません。

エージェントはあなたのログインでCLIを実行するため、読み取りも書き込みも、あなたのログインが許可するすべての操作が可能です。キーの作成、設定の変更、インシデントの解決も行えます。エージェントに対してCLIの「本当によろしいですか？」プロンプトは表示されないため、スキルは変更を行う前に実行するコマンドを明示してあなたの確認を待つように設計されています。確認ステップはあなた自身が担います。

```text
you    セッション run-001 はなぜ失敗したの？

agent  実行中: agenteye --json events --session-id run-001 --all
       checkout-agent は3回目のツール呼び出し時に TimeoutError が発生しました。
```

読み取りはすぐに完了し、書き込みはすべてあなたの確認を待ちます。

```text
you    CI用にイベントの送信だけできるキーを作って。

agent  APIキーを作成します。以下を実行します:
         agenteye keys create ci --add events:add
       進めてよろしいですか？

you    yes

agent  完了しました。"ci" キーが events:add のみで作成されました。シークレットは一度しか表示されないため、今すぐ保存してください。
```
