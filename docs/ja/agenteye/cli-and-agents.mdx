Failproof AI Observability のデプロイ全体を、コマンド一つで操作できます。ターミナルを離れることなく、本番環境の確認、API キーの発行、インシデントの承認が可能です。さらに、CI にスクリプトとして組み込んだり、コーディングエージェントに平易な英語で指示したりすることもできます。

```bash
pipx install agenteye
agenteye login --email you@example.com      # 6桁のコードがメールで届きます
agenteye --json sessions --since 24h         # 過去24時間のエージェント実行一覧（新しい順）
```

*`agenteye` CLI はダッシュボードと通信します。イベントをサーバーに送信するコレクターとは別のツールです。*

## デプロイ全体をコマンド一つで

簡単な確認のためにタブを切り替えるのはもう終わりにしましょう。`agenteye` CLI は単一のバイナリでデータの参照と組織の管理を行えるため、ダッシュボードをクリックして回っていた作業が一行のコマンドで完結します。そのコマンドは再実行、エイリアス化、ランブックへの貼り付けも自在です。4つの機能を提供します：

- **データの参照：** `sessions`、`events`、`evals`、`errors` を時間・エージェント・環境でフィルタリング。
- **組織の管理：** `keys`、`users`、`settings`、`alerts`、`incidents` の操作。
- **アナリティクスの実行：** 保存済み SQL およびイベントデータに対するアドホックな `query` 実行。
- **アシスタントへの問い合わせ：** `agent ask` でダッシュボードの読み取り専用アナリストと同じ機能を利用可能。

`pipx` で一度インストールし、メールで届く6桁のコードでサインインすれば準備完了です。セッションは約1日持続します。期限が切れたら `agenteye login` を再実行してください。ブラウザを開かずに、本番環境のスポットチェック、キーのプロビジョニング、発火中のインシデントのトリアージが行えます：

```bash
agenteye errors --since 24h --aggregate      # エラーの種類別にグルーピングして何が壊れているか確認
agenteye incidents list --state firing       # 現在発火中のものを確認
agenteye keys create ci --add events:add     # イベントのプッシュのみ可能なキーを作成（シークレットは一度だけ表示）
```

一つ覚えておきたい習慣があります：`--json` のようなグローバルオプションはコマンドの前に置きます。`agenteye --json sessions` が正しく、`agenteye sessions --json` は誤りです。

## スクリプト化・CI への組み込み

すべてのコマンドは `--json` オプションに対応しており、それによって使い方が大きく変わります。クリーンな JSON は stdout に出力され、人間向けのステータスや警告は stderr に出力されます。そのため `--json` でキャプチャした出力は余分な行を除去することなくそのまま `jq` にパイプできます。これにより CLI は、ターミナルで作業する人間にとっても、出力をパースするコーディングエージェントにとっても同様に扱いやすいツールになっています：

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

無人実行向けに設計されています。ターミナルが接続されていない場合は確認プロンプトが自動的にスキップされるため、パイプラインが止まることはありません。また、すべてのコマンドは意味のある終了コードを返します：`0` は成功、`4` は未ログイン、`5` は権限不足（例えば `alerts:write` のように不足している権限がメッセージに表示されます）、`3` はダッシュボード到達不可。スクリプトは `4` で再認証の分岐を行ったり、`5` で何をアドミンに依頼すべきかを正確に把握したりできるため、原因不明のエラーで失敗することがありません。

## コーディングエージェントに平易な英語で操作させる

さらに言えば、これらのフラグを一切覚える必要はありません。**CLI スキル**は `agenteye-cli` という小さな Agent Skill フォルダーで、Claude Code や Codex などのコーディングエージェントが平易な英語の指示で CLI を操作できるようにするものです。「今日何か壊れているものはある？」と聞けば、エージェントが適切なコマンドを選択し、あなたの権限で実行して、結果を文章で答えてくれます。

Claude Code の場合、`agenteye-cli` フォルダーを `~/.claude/skills/` に置くだけで自動的に検出されます。Failproof AI Observability がそのフォルダーを提供します。すでにインストール済みの CLI を操作するだけなので、追加のインストールは不要です。ただし、最初にご自身でログインしておく必要があります：メールコードによるログインはスキルが代わりに完了することはできません。

エージェントはあなたの権限で CLI を実行するため、あなたのログインが許可するすべての操作（読み取りも書き込みも）が可能です：キーの作成、設定の変更、インシデントの解決など。エージェントに対して CLI の「本当によろしいですか？」プロンプトは表示されないため、スキルは変更を行う前に実行するコマンドを明示してあなたの承認を待つように設計されています。あなた自身が確認ステップです。

```text
you    session run-001 はなぜ失敗したのですか？

agent  実行中: agenteye --json events --session-id run-001 --all
       checkout-agent は3回目のツール呼び出しで TimeoutError が発生しました。
```

読み取りは即座に行われ、すべての書き込みはあなたの承認を待ちます：

```text
you    CI にイベントのプッシュのみできるキーを発行してください。

agent  API キーを作成します。次のコマンドを実行します：
         agenteye keys create ci --add events:add
       続行してよろしいですか？

you    yes

agent  完了しました。"ci" キーが events:add のみの権限で作成されました。シークレットは一度しか表示されないので、今すぐ保存してください。
```
