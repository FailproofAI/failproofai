Failproof AI のオブザーバビリティデプロイ全体を、コマンド一つで操作できます。ターミナルを離れることなく、本番環境の確認、APIキーの発行、インシデントの承認が可能です。さらに、任意の操作をCIにスクリプト化したり、コーディングエージェントに自然な言葉で任せることもできます。

```bash
pipx install agenteye
agenteye login --email you@example.com      # 6桁のコードがメールで届きます
agenteye --json sessions --since 24h         # 過去1日のエージェント実行一覧（新しい順）
```

*`agenteye` CLIはダッシュボードと通信します。サーバーにイベントを送信するコレクターとは別ツールです。*

## デプロイ全体をコマンド一つで

ちょっとした確認のためにタブを切り替える必要はもうありません。`agenteye` CLIはシングルバイナリでデータの参照と組織管理を行えるため、これまでダッシュボードをクリックして確認していた作業が一行のコマンドになります。再実行、エイリアス登録、ランブックへの貼り付けも自由自在です。主な機能は4つです。

- **データの参照：** `sessions`、`events`、`evals`、`errors` を時間・エージェント・環境でフィルタリング。
- **組織の管理：** `keys`、`users`、`settings`、`alerts`、`incidents` を操作。
- **分析の実行：** 保存済みSQLとイベントデータへのアドホック `query` 実行。
- **アシスタントへの質問：** `agent ask` でダッシュボード上と同じ読み取り専用アナリストと対話。

`pipx` でインストールし、メールで届く6桁のコードでサインインすれば準備完了です。セッションは約1日持続し、期限が切れたら `agenteye login` を再実行してください。ブラウザを開かずに、本番環境の確認、キーのプロビジョニング、発火中インシデントのトリアージが行えます。

```bash
agenteye errors --since 24h --aggregate      # エラーの種類別に集計して何が壊れているか確認
agenteye incidents list --state firing       # 現在発火中のインシデント一覧
agenteye keys create ci --add events:add     # イベントのプッシュのみ可能なキーを作成（シークレットは一度だけ表示）
```

一つ覚えておきたい習慣：`--json` などのグローバルオプションはコマンドの前に置きます。`agenteye --json sessions` が正しく、`agenteye sessions --json` は誤りです。

## スクリプト化してCIに組み込む

すべてのコマンドは `--json` オプションに対応しており、これが大きな違いをもたらします。クリーンなJSONはstdoutに出力され、ステータスメッセージや警告はstderrに流れるため、`--json` で取得した出力は余計な行を除去する必要なく `jq` にそのままパイプできます。これにより、CLIはインタラクティブな操作にも、出力をパースするコーディングエージェントにも同様に活用できます。

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

無人実行向けに設計されています。ターミナルが接続されていない場合は確認プロンプトが自動スキップされるため、パイプラインが止まりません。また、すべてのコマンドは意味のある終了コードを返します：`0` は成功、`4` は未ログイン、`5` は権限不足（例：`alerts:write` のように対象がメッセージに明示されます）、`3` はダッシュボード到達不能。スクリプトは `4` で再認証処理に分岐したり、`5` で何の権限を管理者に依頼すべきかを正確に表示したりと、盲目的な失敗を防げます。

## コーディングエージェントに自然な言葉で任せる

実は、これらのフラグを覚える必要すらありません。**CLIスキル**は `agenteye-cli` という小さなAgent Skillフォルダで、Claude Code や Codex などのコーディングエージェントが自然な言葉でCLIを操作できるようにします。「今日、何か壊れているものはある？」と聞くだけで、エージェントが適切なコマンドを選んで実行し、結果を文章で答えてくれます。

Claude Code の場合は、`agenteye-cli` フォルダを `~/.claude/skills/` に置くだけで自動検出されます。Failproof AI Observability がフォルダを提供するため、追加インストールは不要です（すでにインストール済みのCLIを操作するだけです）。ただし、メールコードによるログインはエージェントが代行できないため、事前にご自身でログインしておいてください。

エージェントはあなたのログインでCLIを実行するため、読み取り・書き込みを問わず、あなたの権限で許可されたすべての操作が可能です（キーの作成、設定変更、インシデントの解決など）。CLIの確認プロンプトはエージェントに対して発動しないため、スキルは変更実行前に正確なコマンドを提示してあなたの許可を求めるよう設計されています。確認ステップはあなた自身です。

```text
you    なぜセッション run-001 は失敗したの？

agent  実行中: agenteye --json events --session-id run-001 --all
       checkout-agent が3回目のツール呼び出しで TimeoutError を起こしました。
```

読み取りはすぐに完了し、書き込みはすべてあなたの確認を待ちます。

```text
you    CIにイベントのプッシュだけできるキーを発行して。

agent  APIキーを作成します。次のコマンドを実行します：
         agenteye keys create ci --add events:add
       実行してよいですか？

you    yes

agent  完了しました。「ci」キーを events:add のみで作成しました。シークレットは一度しか表示されないため、今すぐ保存してください。
```
