ライブエージェントデータをチーム全員が共有できる一枚の画面に集約します。重要なクエリをチャートとして固定しておけば、誰もがクエリを再実行することなく同じ数字を一目で確認できます。

![保存済みクエリから構築されたダッシュボード：時間あたりイベント数の折れ線グラフ、エラー種別の棒グラフ、レイテンシのエリアチャート、モデル別トークン数](/agenteye/images/dashboard-fleet.png)

*1つのボードに4つの保存済みクエリ：時間あたりイベント数、エラー種別、レイテンシ、モデル別トークン数。*

## チーム全員が同じ情報を見る

スクリーンショットをチャットに貼り付けたり、同じクエリを1日に何度も再実行したりするのは終わりにしましょう。ダッシュボードはチーム全員が共有できる組織全体のボードで、誰でもまったく同じビューを開くことができます。元データが変わればチャートも自動的に更新されるため、ボードは常に最新状態を保ち、古い数字をめぐる議論も生まれません。

上のフリートダッシュボードは日常業務に最適な構成です：

- **時間あたりイベント数**の折れ線グラフ — スループットを監視して急激な落ち込みを検知
- **エラー種別**の棒グラフ — 最も多い障害カテゴリをひと目で把握
- **レイテンシ**のエリアチャート — ユーザーからクレームが来る前に遅延を発見
- **モデル別トークン数**の内訳 — コストを常に把握

ボードは `/<org-slug>/dashboards` から確認できます。

## 保存済みクエリをピン留めする

各タイルは保存済みクエリを起点にしています。[クエリ](/ja/agenteye/queries)ライブラリ（組み込みプリセットと独自クエリをイベントや評価に対して実行）で必要なクエリを作成・保存したら、データに合ったチャートタイプでダッシュボードにピン留めしましょう。時系列トレンドには**折れ線グラフ**、カテゴリ比較には**棒グラフ**、ボリューム表示には**エリアチャート**、構成比には**円グラフ**が適しています。

タイルは保存済みクエリをチャートとして表示したものに過ぎないため、手動で同期を保つ必要は一切ありません。クエリを一度更新すれば、そのクエリを使用しているすべてのダッシュボードが自動的に更新されます。

## ボリュームだけでなく品質も監視する

ボリュームはエージェントが稼働中であることを示します。品質は、エージェントが実際に期待どおりに機能しているかを示します。ダッシュボードで[評価スコア](/ja/agenteye/evaluations)を参照すれば、実行の品質を時系列で追跡できるようになり、品質の低下はチャートの落ち込みとして現れるため、顧客からのクレームになる前に気づくことができます。

![保存済み評価クエリから構築された品質重視のダッシュボード](/agenteye/images/dashboard-quality.png)

*品質ボードは評価スコアをオペレーションの数値と並べて常に前面に表示します。*

オペレーションボードと品質ボードを並べておくことで、「正常に動いているか？」「品質は十分か？」という2つの問いに1か所で答えられ、誰もクエリを再実行する必要がありません。
