Failproof AI Observability は、本番環境における AI エージェントの観測・評価・改善を行うセルフホスト型プラットフォームです。エージェントが行うあらゆる操作（ツール呼び出し、モデルリクエスト、フック、エラー）を記録し、各実行の品質をスコアリングし、気づかなかった障害を浮き彫りにします。これらすべてを、自分のインフラ内で動かすダッシュボードで確認できます。

AI エージェントをリリースしていて、実行が失敗した原因の推測に疲れているなら、まずこのページから始めてください。インストール前に、Failproof AI Observability が提供するものと、各コンポーネントがどのように連携するかを説明します。

> **Failproof AI Observability は Failproof AI のエンタープライズ製品です。** 実際の動作を確認したいですか？デモをリクエストするには、[nikita@befailproof.ai](mailto:nikita@befailproof.ai) までメールをお送りください。

## チームが使う理由

- **エージェントが実際に何をしたかを把握できる。** すべての実行が読みやすい git スタイルの実行グラフになります。どのツールが並列実行されたか、どのサブエージェントが分岐したか、どこで停滞したか、何を消費したかが一目でわかります。
- **品質の低下を自動で検出できる。** 小さなスコアリングサービスを接続すると、Failproof AI Observability がすべての完了済み実行をスコアリングするため、有用性の低下や幻覚の急増が自動的に表面化します。
- **ルールを書いていない障害も発見できる。** 定期的な監査がセッションをまたいでログを解析し、エラーのクラスター、レイテンシの外れ値、低スコア、停止した実行を検出して、根拠に基づいたランク付き結果を提供します。
- **重要なときに通知が届く。** エラー率、レイテンシ、コスト、または評価スコアに対するしきい値ルールが発火し、確認・割り当て・解決できるインシデントが生成されます。
- **日本語で質問できる。** ダッシュボード内の AI アシスタントが、自分のデータに基づいて「今週の本番環境での品質トレンドは？」といった質問に答えます。アシスタントが行う変更はすべて承認が必要です。
- **データを自分で保持できる。** Failproof AI Observability はセルフホスト型です。イベント、プロンプト、分析データはすべて自分が管理するインフラに保存されます。

## 提供機能

Failproof AI Observability は3つのコンセプト（**observe（観測）**、**analyze（分析）**、**admin（管理）**）を軸に構成されており、ダッシュボードの左サイドバーに反映されています。

**Observe**（何が起きたかのありのままの記録）：

- **[イベントストリーム](/ja/agenteye/event-stream)**：すべての実行のライブなステップごとのトレイル（ツール呼び出し、モデル呼び出し、フック、エラー）。
- **[セッション](/ja/agenteye/sessions)**：それらのイベントを実行ごとに1行にまとめたもの。各実行はスコアリング可能で、git スタイルの実行グラフが表示されます。
- **[パフォーマンスメトリクス](/ja/agenteye/telemetry)**：モデル・ツール・フックのサーフェスごとのレイテンシヒートマップと p50/p95/p99 の指標。テールスパイクが中央値から際立って見えます。
- **[エラートラッキング](/ja/agenteye/error-tracking)**：発生したすべての問題を1つのトリアージ画面で確認でき、発火中のアラートからワンクリックで到達できます。

![Tools の観測ページ：24個の時間ビンにわたるレイテンシヒートマップ、パーセンタイルバンド、ツール分布バー](/agenteye/images/tools.png)

*各観測サーフェスはスパークラインと p50/p95/p99 の指標をレイテンシヒートマップおよびパーセンタイルバンドと組み合わせています。画面はツールの例です。*

**Analyze**（活動を答えに変える）：

- **[クエリ](/ja/agenteye/queries)** と **[ダッシュボード](/ja/agenteye/dashboards)**：イベントと評価に対して保存された SQL をチャート化し、組織スコープの共有ダッシュボードに表示します。
- **[評価](/ja/agenteye/evaluations)**：自分の評価サービスが生成した品質スコアと、スコアごとの理由付け。
- **[監査](/ja/agenteye/audits)**：セッションをまたいで障害パターンを検出する定期的な調査。
- **[アラート](/ja/agenteye/alerts)** と **[インシデント](/ja/agenteye/incidents)**：通知するしきい値ルールと、トリアージのためのインシデントワークフロー。

**Interfaces**（好きな方法でデータにアクセス）：

- **[CLI](/ja/agenteye/cli-and-agents)**：ターミナルやスクリプトからデプロイ全体を操作したり、コーディングエージェントに自然言語で任せたりできます。
- **[AI アシスタント](/ja/agenteye/assistant)**：ダッシュボード内で直接、エージェントについて自然言語で質問できます。
- **REST API**：ダッシュボードと CLI が行うすべての操作は、スコープ付き [API キー](/ja/agenteye/api-keys)で直接呼び出せる REST API に裏付けられています。イベントの取り込み、セッションと評価のクエリ、ダッシュボード・アラート・監査・ユーザー・キーの管理が可能で、Failproof AI Observability を自分のツールに組み込めます。

**Admin**（チームのための運用）：

- **[API キー](/ja/agenteye/api-keys)**：コレクター、ダッシュボード、アシスタント用のスコープ付きトークン。
- **ユーザー**：許可リストによるパスワードレスのメールベースサインイン。
- **設定**：モデルのコンテキストウィンドウのオーバーライドを含む、組織ごとの設定。

## コンポーネントの連携

データはエージェントコードからダッシュボードへ一方向に流れます。エージェント（Python SDK 経由）がイベントを agenteye-collector に送信し、collector がサーバーに転送し、サーバーがダッシュボードを提供します。オプションのサービスとして、スコアリングサービス（評価）と AI アシスタントサービス（ダッシュボード内チャット）の2つが加わります。

- **Python SDK**：エージェントに `agenteye.event.*` の呼び出しをいくつか追加します。イベントはローカルにバッファリングされます。
- **agenteye-collector**：各エージェントマシン上で動作する軽量デーモン。イベントをバッチ処理してサーバーに送信します。
- **サーバー**：イベントを取り込み、自分のデータベースで運用状態を管理し、ダッシュボード・CLI・独自インテグレーションが使用する REST API を提供します。
- **ダッシュボード**：すべてを探索する場所。
- **オプションサービス**：スコアリングサービス（評価）と AI アシスタントサービス（ダッシュボード内チャット）。

ドキュメント全体で使われる用語（*event、session、evaluation、audit、finding、incident*）については、[コンセプト](/ja/agenteye/concepts)を参照してください。
