エージェントデータに関するあらゆる質問をして、数秒で回答を得ましょう。Failproof AI Observability では、イベントや評価に対してすぐに実行できる保存済みクエリのライブラリを提供しています。空白の SQL エディタから始めるのではなく、動作するサンプルをベースに作業を進められます。

![保存済みクエリのライブラリ：組み込みプリセットとカスタムクエリが並んだグリッド表示](/agenteye/images/queries.png)

*`/<org-slug>/queries` にある保存済みクエリライブラリ：組み込みプリセットとチームが保存したクエリが並んで表示されます。*

## 白紙ではなくプリセットから始める

テーブル名を覚えたり、SQL をゼロから書いたりする必要はありません。ライブラリを開くと、チームがよく尋ねる質問に対応した組み込みプリセットが、チームが保存・命名したクエリと並んで表示されます。目的に近いものを選べば、すぐに答えへたどり着けます。

保存済みクエリはすべて組織スコープで共有されるため、チームメンバーが作成した便利なクエリはあなたのものにもなります。クエリに名前と説明を一度付けておけば、組織内の誰でも見つけて実行でき、後でダッシュボードに結果をピン留めすることもできます。

`/<org-slug>/queries` からアクセスできます。

## SQL コンポーザーで編集して実行する

クエリを開くと SQL コンポーザーが起動し、すぐに調整して答えを確認できます。エクスポートも、往復通信も、他の誰かを待つ必要もありません。

![保存済みクエリを実行中の SQL クエリコンポーザー。スキーマサイドバーとライブ結果グリッドが表示されている](/agenteye/images/query-lab.png)

*SQL コンポーザー：左側にクエリ、カラム名を確認できるスキーマサイドバー、そして下部にライブ結果グリッドが表示されます。*

- **スキーマサイドバー**では、分析テーブルとそのカラムを一覧で確認できます。フィールド名を探し回ることなくクエリを組み立てられます。
- **ライブ結果グリッド**は実行と同時に行を返すため、試行錯誤を繰り返すのではなく、数秒で反復作業が行えます。
- **読み取り専用設計。** クエリはイベントストアに対して実行され、サーバー側で検証されます。許可されるのは `SELECT` および `WITH` 文のみで、ステートメントタイムアウトと行数上限が設定されています。探索的なクエリがデータを変更することはなく、暴走したクエリは自動的に停止されます。

結果に満足したら、ライブラリに保存してチーム全体で共有したり、出力をダッシュボードのライン・バー・エリア・円グラフのタイルとしてピン留めしたりできます。

## ターミナルから実行する、またはアシスタントに書かせる

保存済みクエリは、作業場所を問わず利用できます。

- **ターミナルから。** `agenteye` CLI を使って同じクエリの一覧表示・実行・保存が行えるため、結果をスクリプトに組み込んだり、CI に接続したり、コーディングエージェントに渡したりできます。

```bash
agenteye query list                 # the same saved queries, from your terminal
agenteye query run errs --arg prod  # run one and print the rows (add --json to pipe it)
```

  完全なコマンド一覧は [CLI とエージェント](/ja/agenteye/cli-and-agents) を参照してください。

- **AI アシスタントから。** SQL の書き方がわからない場合は、ダッシュボード内の [AI アシスタント](/ja/agenteye/assistant) に自然な日本語で質問するだけで、クエリを作成してライブラリに保存してくれます。

保存済みクエリの実行は `queries:run` 権限によって制御されており、クエリの作成・削除に必要な権限とは分離されています。そのため、ライブラリの書き換えを許可することなく、読み取りアクセスのみを付与することができます。
