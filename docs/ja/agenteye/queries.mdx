エージェントデータに関するあらゆる質問を投げかけ、数秒で回答を得ましょう。Failproof AI Observability には、イベントと評価に対して実行できる、保存済みのクエリライブラリが用意されています。空白の SQL エディタから始める必要はなく、動作するサンプルからすぐにスタートできます。

![保存済みクエリのライブラリ：再利用可能なクエリのグリッド。組み込みプリセットとカスタムクエリの両方が並んでいる](/agenteye/images/queries.png)

*`/<org-slug>/queries` にある保存済みクエリライブラリ：組み込みプリセットとチームが保存したクエリが並んで表示されます。*

## 空白ページではなく、プリセットから始める

テーブル名を覚えたり、SQL をゼロから書いたりする必要はありません。ライブラリにはチームがよく尋ねる質問に対応した組み込みプリセットが最初から用意されており、自分のチームが保存・命名したクエリの隣に並んでいます。目的に近いものを選べば、答えまでの道のりはほぼ完成です。

保存済みクエリはすべて組織スコープで共有されるため、チームメンバーが作成した便利なクエリはあなたのものにもなります。クエリに名前と説明を一度つければ、組織内の誰でも検索・実行でき、後からダッシュボードに結果をピン留めすることもできます。

`/<org-slug>/queries` からアクセスできます。

## SQL コンポーザーで調整して実行する

クエリを開くと SQL コンポーザーに読み込まれ、すぐに調整して結果を確認できます。エクスポートも往復作業も、他の誰かを待つことも不要です。

![保存済みクエリを実行中の SQL クエリコンポーザー。スキーマサイドバーとライブ結果グリッドが表示されている](/agenteye/images/query-lab.png)

*SQL コンポーザー：左側にクエリ、スキーマサイドバーでカラム名を確認、下部にリアルタイムの結果グリッドが表示されます。*

- **スキーマサイドバー** には分析テーブルとそのカラムが一覧表示されるため、フィールド名を探し回ることなくクエリを組み立てられます。
- **ライブ結果グリッド** は実行直後に行を返すため、何度も推測を繰り返すことなく数秒でイテレーションできます。
- **読み取り専用の設計。** クエリはイベントストアに対して実行され、サーバー側で検証されます。`SELECT` と `WITH` ステートメントのみ許可されており、ステートメントのタイムアウトと行数の上限が設けられています。探索的なクエリがデータを変更することは一切なく、暴走したクエリは自動的に停止されます。

結果に満足したら、チーム全体が活用できるようライブラリに保存し直すか、折れ線・棒・面・円グラフのタイルとしてダッシュボードに出力をピン留めしましょう。

## ターミナルから実行、またはアシスタントに作成してもらう

保存済みクエリはどこで作業していても同じように使えます。

- **ターミナルから。** `agenteye` CLI を使えば、全く同じクエリを一覧表示・実行・保存できます。スクリプトに結果を埋め込んだり、CI に組み込んだり、コーディングエージェントに渡したりすることが可能です。

```bash
agenteye query list                 # ターミナルから同じ保存済みクエリを表示
agenteye query run errs --arg prod  # クエリを実行して行を出力（パイプする場合は --json を追加）
```

  完全なコマンド一覧は [CLI とエージェント](/ja/agenteye/cli-and-agents) を参照してください。

- **AI アシスタントから。** SQL の書き方がわからない場合は、ダッシュボード内の [AI アシスタント](/ja/agenteye/assistant) に普通の言葉で質問するだけで、クエリを作成してライブラリに保存してくれます。

保存済みクエリの実行は `queries:run` 権限で制御されており、クエリの作成・削除の権限とは分離されています。そのため、ライブラリの書き換えを許可せずに読み取りアクセスだけを付与することが可能です。
