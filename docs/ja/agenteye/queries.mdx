エージェントデータに関するあらゆる質問を投げかけ、数秒で回答を得られます。Failproof AI Observability では、イベントや評価に対してすぐに実行できる保存済みクエリのライブラリを提供しているため、空白の SQL エディタからではなく、動作するサンプルから作業を始められます。

![保存済みクエリライブラリ：再利用可能なクエリのグリッド表示。組み込みプリセットとカスタムクエリの両方が含まれる](/agenteye/images/queries.png)

*`/<org-slug>/queries` にある保存済みクエリライブラリ：組み込みプリセットとチームが保存・命名したクエリが並んで表示されます。*

## 白紙のページではなく、プリセットから始める

テーブル名を覚えたり、SQL をゼロから書いたりする必要はありません。ライブラリを開くと、チームがよく尋ねる質問に対応した組み込みプリセットが、自分のチームが保存・命名したクエリのすぐ隣に表示されます。求めているものに近いものを選べば、回答までの大半の工程はすでに完了しています。

保存済みクエリはすべてオーガニゼーション単位で共有されるため、チームメンバーが作成した便利なクエリはあなたのものにもなります。クエリに名前と説明を一度付けるだけで、オーガニゼーション内の誰でもそれを見つけ、実行し、後でダッシュボードに結果をピン留めできます。

`/<org-slug>/queries` からアクセスできます。

## SQL コンポーザーで調整して実行する

クエリを開くと SQL コンポーザーに読み込まれ、そこで内容を調整して即座に結果を確認できます。エクスポートも往復作業も、他の誰かを待つ必要もありません。

![保存済みクエリを実行している SQL クエリコンポーザー。スキーマサイドバーとライブ結果グリッドが表示されている](/agenteye/images/query-lab.png)

*SQL コンポーザー：左側にクエリ、カラム名を迷わずに済むスキーマサイドバー、そして下部にライブ結果グリッドが表示されます。*

- **スキーマサイドバー**で分析テーブルとそのカラムを一覧表示できるため、フィールド名を探し回ることなくクエリを組み立てられます。
- **ライブ結果グリッド**は実行直後に行を返すため、推測と修正を繰り返すことなく数秒で試行錯誤できます。
- **設計上、読み取り専用です。** クエリはイベントストアに対して実行され、サーバー側で検証されます。`SELECT` と `WITH` ステートメントのみが許可されており、ステートメントタイムアウトと行数上限が設定されています。探索的なクエリがデータを変更することは一切なく、暴走したクエリは自動的に停止されます。

結果に満足したら、チーム全体が使えるようにライブラリへ保存するか、折れ線・棒グラフ・面グラフ・円グラフのタイルとしてダッシュボードに出力をピン留めしてください。

## ターミナルから実行する、またはアシスタントに作成させる

保存済みクエリはどこで作業していても利用できます。

- **ターミナルから。** `agenteye` CLI を使うと、まったく同じクエリの一覧表示・実行・保存が可能なため、結果をスクリプトに組み込んだり、CI に連携させたり、コーディングエージェントに渡したりできます。

```bash
agenteye query list                 # the same saved queries, from your terminal
agenteye query run errs --arg prod  # run one and print the rows (add --json to pipe it)
```

  完全なコマンド一覧は [CLI とエージェント](/ja/agenteye/cli-and-agents) を参照してください。

- **AI アシスタントから。** SQL の書き方がわからない場合は、ダッシュボード内の [AI アシスタント](/ja/agenteye/assistant) に平易な言葉で質問すれば、クエリを作成してライブラリに保存してくれます。

保存済みクエリの実行には `queries:run` 権限が必要です。この権限はクエリの作成や削除の権限とは分離されているため、ライブラリの書き換えを許可せずに読み取りアクセスのみを付与できます。
