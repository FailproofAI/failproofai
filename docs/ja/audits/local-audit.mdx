Failproof AI Cloud にマシンを接続する前に、ローカル監査を使ってすぐにプライベートなレビューを行えます。マシン上にすでに保存されているエージェント履歴をスキャンし、組み込みポリシーを通じてツールのアクティビティを再現して、ローカルの結果ダッシュボードを開きます。

## インタラクティブ監査の実行

<Tabs>
  <Tab title="ダッシュボード">
    ローカル監査は、現在のマシン上の履歴を検出する必要があるため、CLI から開始します。`failproofai audit` を実行すると、スキャン後に Failproof AI がバンドル済みのダッシュボードを起動し、**http://localhost:8020/audit** を開きます。

    監査ビューでは、セッション数、ツール呼び出し、プロジェクト、ポリシーのヒット数を確認できます。頻度の高い検出結果から確認し、影響を受けるプロジェクトとエージェント履歴を調べてから、適用を有効にしてください。

    <Info>ローカル監査ダッシュボードは、Failproof AI Cloud の **[分析] → [監査]** とは別のものです。ローカル監査はマシン上に保存され、アカウントもネットワーク接続も必要ありません。</Info>
  </Tab>
  <Tab title="CLI">
    ```bash
    npm install -g failproofai
    failproofai audit
    ```

    このコマンドは、検出されたすべての対応履歴を完全にスキャンします。現在のコマンドは `--since`、`--cli`、`--project`、`--port`、`--no-open` などのフィルターには対応していません。

    ローカルダッシュボードを使用している間は、プロセスを実行し続けてください。終了したら <kbd>Ctrl</kbd>+<kbd>C</kbd> を押してください。
  </Tab>
</Tabs>

現在の監査アダプターは、Claude Code、Codex、GitHub Copilot CLI、Cursor、OpenCode、Pi、Hermes、OpenClaw、Factory、Devin、Antigravity、Goose の履歴を読み取ることができます。ローカルで利用可能な履歴のみがスキャンされます。

## 定期的なローカル監査のスケジュール設定

<Tabs>
  <Tab title="ダッシュボード">
    ローカルダッシュボードの **[設定]** を開き、スケジュール監査を有効にして間隔を選択し、検出結果を受け取るメールアドレスを設定します。ダッシュボードと CLI は同じマシン設定を更新します。
  </Tab>
  <Tab title="CLI">
    週次監査を有効にして、指定したアドレスに検出結果を送信する場合:

    ```bash
    failproofai audit --schedule 7 --email reliability@example.com
    failproofai audit --status
    ```

    間隔には 1〜90 日を指定でき、省略した場合は 7 がデフォルト値になります。初回セットアップ時は必要に応じてサインインが求められます。`--email` はプロンプトなしでレポート先アドレスを指定します。

    ローカル監査履歴を削除せずにスケジュールを停止する場合:

    ```bash
    failproofai audit --no-schedule
    ```
  </Tab>
</Tabs>

デーモンはバックグラウンドでスケジュールされたスキャンを実行し、ローカルダッシュボードが使用するキャッシュ済みの結果を更新して、設定されたレポートをメールで送信します。すぐにインタラクティブスキャンを実行したい場合は `failproofai audit` を使用してください。

## ローカルの証拠からクラウド運用への移行

ローカル監査は手軽なベースラインです。共有トレース、定期的なポリシー監査、検出結果と課題の管理、アラート、組織全体のポリシー展開、またはフリートのヘルス監視が必要な場合は、マシンを Failproof AI Cloud に接続してください。

<CardGroup cols={2}>
  <Card title="クラウド監査の作成" icon="scan-search" href="/ja/audits/setup">
    定期的な目標、対象範囲、証拠ウィンドウ、および応答チャネルを定義します。
  </Card>
  <Card title="ポリシーの有効化" icon="shield-check" href="/ja/start/first-policy">
    ローカルで検証し、意図を持って公開し、まず限られたマシングループに展開します。
  </Card>
</CardGroup>

<Warning>
  監査の出力はレビューのための証拠であり、フラグが立てられたすべてのアクションが安全でないことの証明ではありません。検出結果をブロック適用に変える前に、必ずコンテキストを確認してください。
</Warning>
