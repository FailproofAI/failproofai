Failproof AI Cloudにマシンを接続する前に、ローカル監査を使用してすぐにプライベートなレビューを行いましょう。ローカル監査は、マシン上にすでに保存されているエージェント履歴をスキャンし、組み込みポリシーを通じてツールのアクティビティを再現し、ローカルの結果ダッシュボードを開きます。

## インタラクティブな監査を実行する

<Tabs>
  <Tab title="ダッシュボード">
    ローカル監査は、現在のマシン上の履歴を検出する必要があるため、CLIから開始します。`failproofai audit` を実行すると、スキャン後にFailproof AIがバンドルされたダッシュボードを起動し、**http://localhost:8020/audit** を開きます。

    監査ビューでは、セッション数、ツール呼び出し数、プロジェクト数、ポリシーのヒット数を確認します。頻度の高い検出結果から始め、影響を受けるプロジェクトとエージェント履歴を調査してから、エンフォースメントを有効にしてください。

    <Info>ローカル監査ダッシュボードは、Failproof AI Cloudの **Analyze → Audits** とは別物です。ローカル監査はマシン上に残り、アカウントもネットワーク接続も必要ありません。</Info>
  </Tab>
  <Tab title="CLI">
    ```bash
    npm install -g failproofai
    failproofai audit
    ```

    このコマンドは、検出されたすべての対応履歴を完全にスキャンします。現在のコマンドは `--since`、`--cli`、`--project`、`--port`、`--no-open` などのフィルターには対応していません。

    ローカルダッシュボードを使用している間はプロセスを実行したままにしてください。終了したら <kbd>Ctrl</kbd>+<kbd>C</kbd> を押します。
  </Tab>
</Tabs>

現在の監査アダプターは、Claude Code、Codex、GitHub Copilot CLI、Cursor、OpenCode、Pi、Hermes、OpenClaw、Factory、Devin、Antigravity、Gooseの履歴を読み取ることができます。スキャンされるのはローカルで利用可能な履歴のみです。

## 定期的なローカル監査をスケジュールする

<Tabs>
  <Tab title="ダッシュボード">
    ローカルダッシュボードの **Settings** を開き、スケジュール監査を有効にし、間隔を選択して、検出結果を受け取るメールアドレスを設定します。ダッシュボードとCLIは同じマシン設定を更新します。
  </Tab>
  <Tab title="CLI">
    週次監査を有効にして、指定したアドレスに検出結果を送信する:

    ```bash
    failproofai audit --schedule 7 --email reliability@example.com
    failproofai audit --status
    ```

    間隔は1〜90日で指定でき、省略した場合のデフォルトは7日です。初回設定時には必要に応じてサインインが求められます。`--email` はプロンプトを表示せずにレポートの送信先アドレスを指定します。

    ローカル監査履歴を削除せずにスケジュールを停止する:

    ```bash
    failproofai audit --no-schedule
    ```
  </Tab>
</Tabs>

デーモンはスケジュールされたスキャンをバックグラウンドで実行し、ローカルダッシュボードで使用されるキャッシュ済み結果を更新して、設定されたレポートをメールで送信します。インタラクティブなスキャンをすぐに実行したい場合は `failproofai audit` を使用してください。

## ローカルの証拠からクラウド運用へ移行する

ローカル監査は迅速なベースラインです。共有トレース、定期的なポピュレーション監査、検出結果とIssue管理、アラート、組織全体のポリシー展開、またはフリートのヘルス管理が必要な場合は、マシンをFailproof AI Cloudに接続してください。

<CardGroup cols={2}>
  <Card title="クラウド監査を作成する" icon="scan-search" href="/ja/audits/setup">
    定期的な目標、対象範囲、証拠ウィンドウ、および通知チャンネルを定義します。
  </Card>
  <Card title="ポリシーを有効にする" icon="shield-check" href="/ja/start/first-policy">
    ローカルで検証し、意図的に公開して、まず限定されたマシングループに展開します。
  </Card>
</CardGroup>

<Warning>
  監査の出力はレビューのための証拠であり、フラグが立てられたすべてのアクションが安全でないことを証明するものではありません。検出結果をブロックするエンフォースメントに変える前に、必ずコンテキストを確認してください。
</Warning>
