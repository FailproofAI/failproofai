## ダッシュボード

| 変数 | 説明 |
|----------|-------------|
| `PORT` | ダッシュボードのポート番号（デフォルト: `8020`） |
| `CLAUDE_PROJECTS_PATH` | Claude Code のプロジェクトフォルダの検索場所を上書きする |
| `FAILPROOFAI_DISABLE_PAGES=policies,projects` | 非表示にするダッシュボードページをカンマ区切りで指定する |
| `FAILPROOFAI_ALLOWED_DEV_ORIGINS` | 開発リソースへのアクセスを許可するホスト／IP。`--allowed-origins` と同等。 |

## ログ

| 変数 | 説明 |
|----------|-------------|
| `FAILPROOFAI_LOG_LEVEL=info\|warn\|error` | サーバーのログレベル（デフォルト: `warn`） |
| `FAILPROOFAI_HOOK_LOG_FILE` | フックログファイルのパスを指定する。`true` を指定するとデフォルトパス（`~/.failproofai/logs/hooks.log`）が使用される |

## テレメトリー

failproofai はデフォルトで匿名の利用状況テレメトリーを送信します。無効にする方法は2つあり、より制限の厳しい設定が優先されます。環境変数は、設定ファイルで無効にされたものを再有効化することはできません。

| 変数 | 説明 |
|----------|-------------|
| `FAILPROOFAI_TELEMETRY_DISABLED=1` | このプロセスの匿名利用状況テレメトリーを無効にする |

マシン全体で恒久的に無効にするには、`~/.failproofai/config.toml` に以下を追加してください:

```toml
[telemetry]
enabled = false
```

<Note>
**failproofaid デーモン**を使用している場合は、設定ファイルによる無効化を推奨します。
デーモンはシステムスコープのサービスであり、シェルからエクスポートされた環境変数は引き継がれません。そのため、`FAILPROOFAI_TELEMETRY_DISABLED` はデーモンに届きません。`[telemetry] enabled = false` は CLI とデーモンの両方で読み込まれます。
</Note>

デーモンが報告するのは、それ自身の**ライフサイクル**イベントのみです: 起動したこと（および前回の実行が正常終了したかどうか）、停止したこと、評価ワーカーが起動または再起動されたこと、コレクタータスクが失敗したこと、クラウドポリシーの取得結果。これらのイベントが持つのは低カーディナリティの値とカウントのみであり、ファイルパス・コマンド・ポリシー・プロンプト・トランスクリプトから読み取った内容は一切含まれません。ツール呼び出しごとのイベントもありません。

## 認証

| 変数 | 説明 |
|----------|-------------|
| `FAILPROOF_API_URL` | ダッシュボードの認証ダイアログが使用する API サーバーのベース URL を上書きする。デフォルトは `https://api.befailproof.ai`。ローカルの API サーバーを使用する場合は `http://localhost:8080`（または該当するアドレス）を指定する。 |
| `FAILPROOFAI_AUTH_DIR` | `auth.json` の保存先を上書きする（デフォルト: `~/.failproofai`）。主に独立したテスト環境で使用する。 |

## 初回起動時のプロンプト

| 変数 | 説明 |
|----------|-------------|
| `FAILPROOFAI_NO_FIRST_RUN=1` | `failproofai` を初めて実行したときに表示される、ポリシーのインストールを促すプロンプトをスキップする |

## LLM（ポリシー評価用）

| 変数 | 説明 |
|----------|-------------|
| `FAILPROOFAI_LLM_BASE_URL` | LLM API のエンドポイント（デフォルト: `https://api.openai.com/v1`） |
| `FAILPROOFAI_LLM_API_KEY` | LLM を使用するポリシー向けの API キー |
| `FAILPROOFAI_LLM_MODEL` | モデル名（デフォルト: `gpt-4o-mini`） |
