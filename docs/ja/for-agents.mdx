1つのコマンドで、Failproof AIのリファレンス全体をコーディングエージェントに追加できます。Claude Code、Cursor、Windsurf、そしてスキルをサポートするその他のエージェントに対応しています。

```bash
npx skills add https://docs.befailproof.ai
```

`npx skills` はインストール済みのエージェントを自動的に検出し、それぞれに適したフォーマットでスキルを追加します。

## スキルがカバーする内容

| エリア | 含まれる内容 |
|--------|------------|
| ポリシー | 組み込みポリシー名、イベントタイプ、パラメーター、有効化/無効化 |
| カスタムポリシー | `customPolicies.add()`、マッチフィルター、`allow`/`deny`/`instruct` API |
| コンテキストオブジェクト | `ctx.eventType`、`ctx.toolName`、`ctx.toolInput`、`ctx.session` |
| 設定 | `policies-config.json` の構造、スコープのマージ、`policyParams` |
| CLI | `failproofai policies --install`、`--uninstall`、`--custom`、スコープ |
| ダッシュボード | セッションビューアー、ポリシーアクティビティ、環境変数 |
| アーキテクチャ | フックハンドラーのフロー、終了コード、stdin/stdout コントラクト |

## スキルの内容は完全ですか？

Mintlify はナビゲーション内のすべてのページから `llms.txt` を生成します。Failproof AI のドキュメントはすべてのポリシー、オプション、サンプルを含む完全な API をカバーしています。不足している内容があれば、ソースは `https://docs.befailproof.ai/llms-full.txt` にあります。

特定のコンテキストのみを参照したい場合は、特定のページに直接リンクできます。

```bash
# カスタムポリシー API のみ
npx skills add https://docs.befailproof.ai/custom-policies

# 組み込みポリシーのみ
npx skills add https://docs.befailproof.ai/built-in-policies
```
