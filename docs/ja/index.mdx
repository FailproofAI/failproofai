Failproof AI は、エージェントが何をしたかを把握し、どこで失敗したかを特定し、同じ問題が再発する前に安全策を展開するためのツールです。

**ハーネス**とは、エージェントが実際に動作する実行環境のことです。Failproof AI は Claude Code や Codex などのコーディングCLI、Hermes などのチャットゲートウェイ、OpenClaw などのセルフホスト型アシスタントを含む12種類のハーネスに対応しており、すべてに同じイベント・ポリシー・セッション履歴が適用されます。ハーネスを使用しないエージェントは [Python SDK](/ja/reference/python-sdk) 経由でトレースと監査を行いますが、そこでポリシーを強制するには独自のランタイムにフックを実装する必要があります。

> **セッション → 監査 → 知見 → 課題 → ポリシー**<br />
> 何が起きたかをトレースし、障害を特定し、対応を管理して、将来の実行で同じ問題が起きないようにします。

## はじめに

初めてインストルメント済みエージェントをデプロイする場合は、[クイックスタート](/ja/start/quickstart)から始めてください。データがすでに届いている場合は、[セッション](/ja/sessions/overview)を開いて、監査やポリシーを設定する前に実際の実行結果を確認してください。
