Failproof AI は、エージェントが何を行ったかを把握し、失敗箇所を特定し、同じ動作が再発する前にセーフガードを展開するためのツールです。

<Columns cols={2}>
  <Card title="Failproof のセットアップ" icon="wand-sparkles" href="/ja/start/quickstart">
    スキルを使ってプロジェクトをインストルメント化し、接続して、エージェントログが届いていることを確認します。
  </Card>
  <Card title="Failproof アシスタントに質問する" icon="message-square-text" href="/ja/sessions/assistant">
    エージェントログに対して自然言語で分析、クエリ、ダッシュボード作成、監査を実行します。
  </Card>
</Columns>

<Columns cols={3}>
  <Card title="エージェントの動作を確認する" icon="route" href="/ja/sessions/overview">
    モデル呼び出し、ツール、エラー、人間の入力、レイテンシ、ポリシーの判断を1つのセッションで追跡します。
  </Card>
  <Card title="障害を体系的に発見する" icon="scan-search" href="/ja/audits/overview">
    定義されたセッションセットを監査し、根拠に基づく所見をレビューし、問題として修正状況を追跡します。
  </Card>
  <Card title="再発を防止する" icon="shield-check" href="/ja/policies/overview">
    既知の障害パターンをポリシーに変換し、その影響を観察して、フリート全体に展開します。
  </Card>
</Columns>

> **セッション → 監査 → 所見 → 問題 → ポリシー**<br />
> 何が起きたかをトレースし、障害を特定し、対応を管理してから、将来の実行で同じ動作が起きないよう防止します。

## はじめに

初めてインストルメント化されたエージェントを展開する場合は、[クイックスタート](/ja/start/quickstart)から始めてください。すでにデータが届いている場合は、[セッション](/ja/sessions/overview)を開いて実際の実行を確認してから、監査やポリシーを設定してください。

  キャプチャから安全に展開されたポリシーまで、エンドツーエンドのワークフローを完了します。
</Card>
