Failproof AI は、エージェントが何をしたかを把握し、失敗箇所を特定し、同じ挙動が再発する前にセーフガードを展開するためのツールです。

**ハーネス**とは、エージェントが実際に動作する環境のことです。Failproof AI は 12 種類のハーネスに対応しています。Claude Code や Codex などのコーディング CLI、Hermes などのチャットゲートウェイ、OpenClaw などのセルフホスト型アシスタントが含まれており、すべてに同じイベント・ポリシー・セッション履歴が適用されます。ハーネスを持たないエージェントは [Python SDK](/ja/reference/custom-agents) 経由でレポートを送信し、トレースと監査が行われます。その場合のポリシー適用には、独自ランタイム内でのフックが必要です。

> **セッション → 監査 → 知見 → 問題 → ポリシー**<br />
> 何が起きたかをトレースし、失敗を発見し、対応を管理して、同じ挙動を将来の実行で防止します。

## まずここから

初めてインストルメント化されたエージェントをデプロイする場合は、[クイックスタート](/ja/start/quickstart) から始めてください。すでにデータが届いている場合は、[セッション](/ja/sessions/overview) を開き、監査やポリシーを設定する前に実際の実行内容を確認してください。
