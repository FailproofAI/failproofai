Failproof AI は、エージェントの行動を把握し、失敗箇所を特定し、同じ問題が再発する前に安全策を展開するためのツールです。

<Columns cols={2}>
  <Card title="Failproof をセットアップする" icon="wand-sparkles" href="/ja/start/quickstart">
    スキルを使ってプロジェクトをインストルメントし、接続して、エージェントログが届くことを確認します。
  </Card>
  <Card title="Failproof アシスタントに質問する" icon="message-square-text" href="/ja/sessions/assistant">
    自然言語でエージェントログの分析、クエリ、ダッシュボード構築、監査を実行できます。
  </Card>
</Columns>

<Columns cols={3}>
  <Card title="エージェントの動作を確認する" icon="route" href="/ja/sessions/overview">
    モデルの呼び出し、ツール、エラー、人間の入力、レイテンシ、ポリシーの判定を1つのセッションで追跡できます。
  </Card>
  <Card title="失敗を体系的に発見する" icon="scan-search" href="/ja/audits/overview">
    定義されたセッションセットを監査し、根拠に基づいた知見をレビューし、課題として修正状況を追跡します。
  </Card>
  <Card title="再発を防ぐ" icon="shield-check" href="/ja/policies/overview">
    既知の障害パターンをポリシーに変換し、その影響を観察して、フリート全体に展開します。
  </Card>
</Columns>

> **セッション → 監査 → 知見 → 課題 → ポリシー**<br />
> 何が起きたかを追跡し、失敗を発見し、対応を管理し、将来の実行で同じ問題が起きないようにします。

## はじめに

初めてインストルメント済みエージェントをデプロイする場合は、[クイックスタート](/ja/start/quickstart)から始めてください。すでにデータが届いている場合は、[セッション](/ja/sessions/overview)を開いて、監査やポリシーを設定する前に実際の実行内容を確認してください。

<Card title="1つの失敗を発見して防ぐ" icon="arrow-right" href="/ja/start/quickstart">
  キャプチャから安全にデプロイされたポリシーまで、エンドツーエンドのワークフローを完了します。
</Card>
