Failproof AI は、エージェントを運用するすべての人が「何が起きたか」を把握し、障害を発見して繰り返しを防ぐためのツールです。

Claude Code、Codex、Hermes、OpenClaw、Goose を含む 12 の主要なエージェント環境に対応しています。LangChain、CrewAI、LlamaIndex、Pydantic AI、または独自のランタイムで構築されたエージェントは、[Python SDK](/ja/reference/custom-agents) 経由でレポートを送信できます。

## ローカルで始めるか、クラウドに接続するか

<Columns cols={2}>
  <Card title="ローカル（アカウント不要）" icon="laptop" href="/ja/audits/local-audit">
    `localhost:8020` でダッシュボードを開き、`failproofai audit` を実行します。エージェントの履歴はこのマシン上にのみ保存されます。
  </Card>
  <Card title="Failproof AI Cloud" icon="cloud" href="/ja/start/setup">
    複数マシン間のセッションを確認し、チームのポリシーを一元管理します。
  </Card>
</Columns>

セットアップでは意図的にポリシーパックを選択しない設計になっています。セットアップ後に以下のコマンドで追加できます:

```bash
failproofai policies add FailproofAI/policies
```

それまでの間は、`block-failproofai-commands` のみが実行されます。これはエージェントが Failproof AI を無効化するのを防ぎます。

> **セッション → 監査 → 発見 → 課題 → ポリシー**
> 何が起きたかを把握し、障害を発見し、対応を決め、そして再発を防ぎます。

<Note>
  セットアップは Linux と macOS に対応しています。各エージェント環境で観察またはブロックできる内容については、[サポートされているハーネス](/ja/reference/harnesses)を参照してください。
</Note>
