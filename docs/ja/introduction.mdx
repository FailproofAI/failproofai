**AI 障害ハンドリング**・**エラーリカバリー**・**LLM 信頼性**のためのフックとポリシー。**Claude Code**、**OpenAI Codex**、**GitHub Copilot**、**Cursor Agent**、**OpenCode**、**Pi**、**Hermes**、**OpenClaw**、**Factory Droid**、**Devin CLI**、**Antigravity CLI**、そして **Agents SDK** 上で AI エージェントを安定稼働・自律稼働させ続けましょう。

AI エージェントは予測可能なパターンで失敗します。破壊的なコマンドを実行し、シークレットを漏洩させ、タスクから逸脱し、ループにはまり込み、main ブランチに直接プッシュする——こうした小さな失敗が放置されると、障害・認証情報の漏洩・作業の消失へと連鎖していきます。

FailproofAI はこれを **ポリシー** で解決します。各ルールはすべてのエージェントツール呼び出しにフックし、**障害を検出**し、**軽減**（ブロック・インストラクト・サニタイズ）し、注意が必要なときに**アラートを通知**します。ローカルダッシュボードでは、すべてのツール呼び出し・エージェント障害・リカバリーアクションを事後確認できます。

トランスクリプトとポリシー評価はお使いのマシン上に保持されます。データが送信されるのは、認証済み監査リマインダーや招待などのオンライン機能を明示的に使用した場合のみです。

## クイックスタート

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # enable policies (or skip — `failproofai` will offer to set them up on first run)
failproofai                      # launch the dashboard
```

詳細な手順については、[はじめかた](/ja/getting-started) ガイドをご覧ください。
