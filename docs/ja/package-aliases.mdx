## 公式パッケージ

npmの正式パッケージは **`failproofai`** です:

```bash
npm install -g failproofai
# または
bun add -g failproofai
```

---

## エイリアス名を所有している理由

タイポスクワッティングは、攻撃者が人気パッケージ名から1文字違いのパッケージ名を登録するサプライチェーン攻撃の一般的な手口です。インストールコマンドを入力ミスしたユーザーが、攻撃者の管理するコードをシステム全権限で実行してしまいます — これはまさに Failproof AI が防御を目的としている脅威の一つです。

この攻撃対象を排除するため、**npm 上の `failproofai` に関するよくあるスペルミスや表記バリエーションをすべて先取りして所有しています**。これらの名前はサードパーティが登録できません。それぞれは実際の `failproofai` パッケージにインストールと処理を委譲する薄いプロキシです。

## 登録済みエイリアス

**表記バリエーション** — 「failproof ai」の様々な表記方法:

| パッケージ | ステータス |
|---------|--------|
| `failproof` | ✅ 公開済み |
| `failproof-ai` | ⏳ npm サポート対応待ち |
| `fail-proof-ai` | ⏳ npm サポート対応待ち |
| `failproof_ai` | ⏳ npm サポート対応待ち |
| `fail_proof_ai` | ⏳ npm サポート対応待ち |
| `fail-proofai` | ⏳ npm サポート対応待ち |

**`failprof*` タイポ** — 「proof」の `o` が1つ欠けているもの:

| パッケージ | ステータス |
|---------|--------|
| `failprof` | ✅ 公開済み |
| `failprof-ai` | ✅ 公開済み |
| `failprofai` | ⏳ npm サポート対応待ち |
| `fail-prof-ai` | ⏳ npm サポート対応待ち |
| `failprof_ai` | ⏳ npm サポート対応待ち |

**`faliproof*` タイポ** — `a` と `i` が入れ替わっているもの:

| パッケージ | ステータス |
|---------|--------|
| `faliproof` | ✅ 公開済み |
| `faliproof-ai` | ✅ 公開済み |
| `faliproofai` | ⏳ npm サポート対応待ち |

> **対応待ちの理由:** npm のスパム防止ポリシーにより、句読点を除去して類似性チェックを行った際に既存パッケージと同一の文字列に正規化される名前はブロックされます。これらの名前をアンチスクワッティング目的で予約するよう npm サポートに連絡済みです。承認され次第、有効化されます。

公開済みのエイリアスが私たちの所有であることは以下のコマンドで確認できます:

```bash
npm info failproof
# maintainers フィールドに "ExosphereHost Inc." が表示されることを確認してください
```

## エイリアスの仕組み

各エイリアスパッケージは以下の構成になっています:

1. `failproofai` を依存関係として列挙することで、実際のパッケージがインストールされ、そのバイナリが利用可能になります
2. 自身の名前に対応するバイナリ（例: `failprof-ai`）を公開し、すべての引数を `failproofai` バイナリにプロキシします

プロキシは2行の Node スクリプトで、ロジックもネットワーク通信も、`failproofai` 自体が行う以上のデータ収集も一切ありません。
