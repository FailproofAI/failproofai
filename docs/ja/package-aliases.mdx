## 公式パッケージ

npm の正規パッケージは **`failproofai`** です：

```bash
npm install -g failproofai
# または
bun add -g failproofai
```

---

## エイリアス名を所有している理由

タイポスクワッティングは、攻撃者が人気パッケージの名前から1文字違いのパッケージ名を登録するサプライチェーン攻撃の手口です。インストールコマンドを打ち間違えたユーザーが、システムへのフルアクセス権を持つ攻撃者制御のコードを実行してしまうことになります。これはまさに Failproof AI が防御対象としている脅威です。

この攻撃経路を排除するために、**npm 上の `failproofai` のよくある誤字・表記バリアントをすべて先行取得しています**。これらの名前はいずれもサードパーティに登録される心配がありません。それぞれが `failproofai` の本体パッケージをインストールして処理を委譲する薄いプロキシとなっています。

## 登録済みエイリアス

**表記バリアント** - "failproof ai" の様々な書き方：

| パッケージ | ステータス |
|---------|--------|
| `failproof` | ✅ 公開済み |
| `failproof-ai` | ⏳ npm サポート対応待ち |
| `fail-proof-ai` | ⏳ npm サポート対応待ち |
| `failproof_ai` | ⏳ npm サポート対応待ち |
| `fail_proof_ai` | ⏳ npm サポート対応待ち |
| `fail-proofai` | ⏳ npm サポート対応待ち |

**`failprof*` 系タイポ** - "proof" の `o` が1つ抜けたもの：

| パッケージ | ステータス |
|---------|--------|
| `failprof` | ✅ 公開済み |
| `failprof-ai` | ✅ 公開済み |
| `failprofai` | ⏳ npm サポート対応待ち |
| `fail-prof-ai` | ⏳ npm サポート対応待ち |
| `failprof_ai` | ⏳ npm サポート対応待ち |

**`faliproof*` 系タイポ** - `a` と `i` が入れ替わったもの：

| パッケージ | ステータス |
|---------|--------|
| `faliproof` | ✅ 公開済み |
| `faliproof-ai` | ✅ 公開済み |
| `faliproofai` | ⏳ npm サポート対応待ち |

> **対応待ちの理由について：** npm のスパム防止ポリシーにより、句読点を除去して類似チェックを行った際に既存パッケージと同一文字列になる名前は登録がブロックされます。アンチスクワッティングを目的としたこれらの名前の予約について npm サポートに連絡済みであり、承認され次第有効化される予定です。

公開済みエイリアスが当社所有であることは以下のコマンドで確認できます：

```bash
npm info failproof
# maintainers フィールドに "ExosphereHost Inc." が表示されることを確認してください
```

## エイリアスの仕組み

各エイリアスパッケージは以下の動作をします：

1. `failproofai` を依存関係として記載しており、本体パッケージがインストールされてそのバイナリが利用可能になります
2. 自身の名前（例：`failprof-ai`）に対応するバイナリを公開し、すべての引数を `failproofai` バイナリにプロキシします

プロキシは2行の Node スクリプトで構成されており、ロジックやネットワーク呼び出しはなく、`failproofai` 自体が行う以外のデータ収集も一切行いません。
