フリートカバレッジは、Cloudが割り当てた内容と各マシンが最後に適用した内容を比較します。

## マシンを確認する

```bash
failproofai config --status
failproofai flush --wait --timeout 120
```

Cloudから実行する場合:

```bash
fp fleet list
fp fleet diff
fp fleet show <machine-id>
```

`fp fleet` は APIキーではなく、サインイン済みのセッションが必要です。

| コマンド | 説明 |
| --- | --- |
| `fp fleet list` | マシンとデプロイ状態の一覧を表示 |
| `fp fleet show <machine>` | 特定のマシンのポリシーセットを表示 |
| `fp fleet deploy <machine> --add <ref>` | ポリシーを追加または更新 |
| `fp fleet deploy <machine> --remove <id>` | ポリシーを削除 |
| `fp fleet deploy <machine> --set <ref>...` | ポリシーセット全体を置き換え |
| `fp fleet diff [machine]` | 意図したバージョンと適用済みバージョンを比較 |
| `fp fleet history <machine>` | デプロイ世代の履歴を表示 |
| `fp fleet rollback <machine> <generation>` | 特定の世代に戻す |
| `fp fleet rename <machine> "<label>"` | Cloudのラベルを変更 |

<Warning>
  `--set` はポリシーセット全体を置き換えます。単独の `--add <id>` は新しいポリシーを即座に適用します。シャドウロールアウトには `--add <id>:observe` を使用してください。
</Warning>

## オブザーブから適用へ

```bash
fp fleet deploy ci-runner-01 --add prod-guard:observe
fp guardrails summary --since 24h --machine ci-runner-01
fp fleet deploy ci-runner-01 --add prod-guard:enforce
```

オブザーブモードはポリシーを実際に評価し、エージェントをブロックすることなく allow 以外の判断を記録します。

## マシンID

マシンIDは不変であり、マシンを一意に識別します。ラベルは表示用であり、変更可能です:

```bash
failproofai config --machine-label checkout-runner-03
fp fleet rename <machine-id> "Checkout runner 03"
```

ラベルを変更しても、マシンの再接続や鍵の再生成は行われません。
