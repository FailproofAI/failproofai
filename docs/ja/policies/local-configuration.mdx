スコープを使用して、ローカルポリシーの適用対象を決定します。

| スコープ | 適用対象 |
| --- | --- |
| `user` | このマシン上のサポートされているエージェント |
| `project` | このプロジェクトで実行中のエージェント |
| `local` | ローカルプロジェクト設定内の Claude のみ |
| `all` | アンインストール専用 |

```bash
failproofai policies add block-sudo --scope user
failproofai policies add block-rm-rf --scope project
```

Hermes と OpenClaw は user スコープのみをサポートします。その他のほとんどのハーネスは user および project をサポートします。Claude は local スコープもサポートします。詳細は [ハーネス](/ja/reference/harnesses) を参照してください。

## ポリシーパラメータ

ポリシー設定は、対応するスコープの `policies-config.json` に保存されます。可能な場合はローカルダッシュボードの **Policies → Configure** ビューを使用してください。

パラメータは特定のポリシーに属し、そのポリシーの判定方法を変更します。たとえば、許可リストを使用することで、ブロッキングポリシーが既知の安全なコマンドやパスを受け入れるようにできます。

カスタムポリシーファイルは `.failproofai/policies/` から自動的に読み込まれるか、明示的に指定できます。

```bash
failproofai policies -i -c ./guards.mjs --scope project
```

明示的なパスを削除するには、次のコマンドを実行します。

```bash
failproofai policies -u -c
```

## ファイル

| ファイル | 用途 |
| --- | --- |
| `~/.failproofai/config.json` | マシンおよびコレクターの設定 |
| `policies-config.json` | スコープ別の有効なポリシーとパラメータ |
| `.failproofai/policies/*policies.mjs` | 規約によって読み込まれるポリシー |
| `~/.failproofai/policies/packs/installed.json` | インストール済みパックと選択内容 |

インストール済みパックのアーティファクトを直接編集しないでください。修正済みリリースを再インストールまたは公開してください。
