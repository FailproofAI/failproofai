Failproof AI は、ポリシーの選択とマシン・デーモンの設定を分離しています。これにより、リポジトリのポリシー選択をレビュー可能な状態に保ちつつ、認証情報やデーモンの状態はリポジトリの外部に置くことができます。

## ポリシースコープの選択

<Tabs>
  <Tab title="ダッシュボード">
    引数なしで `failproofai` を実行するとローカルポリシーダッシュボードが開きます。ポリシーを有効にする前に、user・project・local のいずれかのスコープを選択してください。変更は対応する設定ファイルに書き込まれます。

    - **User** — このマシン上のすべてのプロジェクトに適用されます。
    - **Project** — リポジトリに属し、コミットできます。
    - **Local** — 特定のプロジェクトを特定のユーザー向けにオーバーライドします。gitignore に追加しておくことを推奨します。

  </Tab>
  <Tab title="CLI">
    ```bash
    failproofai policy add block-rm-rf --scope user
    failproofai policy add block-force-push --scope project
    failproofai policy add warn-large-file-write --scope local
    failproofai policies
    ```

    すべてのハーネスが local スコープに対応しているわけではありません。選択したハーネスが表現できないスコープを指定した場合、CLI はエラーを返します。
  </Tab>
</Tabs>

| スコープ | ポリシー設定ファイル |
| --- | --- |
| Project | `<project>/.failproofai/policies-config.json` |
| Local | `<project>/.failproofai/policies-config.local.json` |
| User | `~/.failproofai/policies-config.json` |

有効なポリシーは和集合としてマージされます。ポリシーパラメーターは、project → local → user の順で最初にパラメーターが定義されたスコープが使用されます。明示的なカスタムポリシーパスも、最初に定義されたスコープが使用されます。

## ポリシーパラメーターの設定

<Tabs>
  <Tab title="ダッシュボード">
    ローカルダッシュボードでポリシーを開き、サポートされているパラメーターを編集して、選択したスコープで保存します。マッチするエージェントアクションとマッチしないエージェントアクションをそれぞれ実行し、**Observe → policy** で判定結果を確認してください。

  </Tab>
  <Tab title="CLI">
    選択したスコープの `policies-config.json` を編集し、`failproofai policies` を実行して未知のポリシー名やパラメーターキーを確認します。

    ```json
    {
      "enabledPolicies": ["block-rm-rf", "block-force-push"],
      "policyParams": {
        "block-rm-rf": {
          "allowPaths": ["/tmp/build-output"]
        }
      }
    }
    ```

    ```bash
    failproofai policies
    ```
  </Tab>
</Tabs>

## マシンファイルの構成

`~/.failproofai` には、信頼境界ごとに分離されたファイルが格納されています。

| パス | 用途 |
| --- | --- |
| `config.json` | 非機密のデーモン、監査、テレメトリー設定 |
| `credentials.json` | クラウド認証情報。オーナーのみ読み取り可能なパーミッションで保存されます |
| `policies-config.json` | ユーザースコープの組み込みポリシー選択、パラメーター、および明示的なカスタムパス |
| `policies/` | ユーザー定義のコンベンションポリシーおよびクラウド管理のポリシーアーティファクト |
| `hook-activity/` | ローカルポリシー判定ログ |
| `state/` | デーモンのスプール、ヘルス、一時停止、ランタイム状態 |

コンテナや隔離されたテスト環境でマシンレイアウト全体を移動するには `FAILPROOFAI_HOME` を使用してください。個々の状態ディレクトリを独立して移動させないでください。

<Warning>
  `credentials.json` は絶対にコミットしないでください。プロジェクトのポリシー設定とプロジェクトのコンベンションポリシーは、エンフォースメントコードとしてレビューしたうえでコミットしてください。
</Warning>
