ポリシーパックは、公開 GitHub リリースとして配布されたバージョン管理済みのポリシーセットです。このパッケージ自体には独自のパックは含まれていません。他のパックと同じようにインストールしてください。

```bash
failproofai policies show FailproofAI/policies
failproofai policies add FailproofAI/policies
```

`show` はパックのコードを実行せずにマニフェストを読み込みます。

## インストール内容の選択

```bash
failproofai policies add owner/repo --policy block-refunds
failproofai policies add owner/repo --category billing,git
failproofai policies add owner/repo --all
```

何も選択しない場合、パックはパブリッシャーのデフォルト設定を使用します。新しいリリースを再追加しても、既存の選択は維持されます。

スラッシュを含む文字列はパックソースとして扱われます。スラッシュを含まない文字列はポリシー名として扱われます。

## リリースのピン留め

| ソース | 結果 |
| --- | --- |
| `owner/repo` | 最新リリース（解決後にピン留め） |
| `owner/repo@a1b2c3d4e5f6` | コミットベースの特定リリース |
| `owner/repo@v2.1.0` | 名前付きの特定リリース |
| GitHub リリース URL | 該当 URL のリリース |

パックは通常、ビルド元の 12 文字のコミット SHA を使用します。リリースの順序を確認するには `failproofai policies show owner/repo --releases` を使用してください。

## インストール済みパックの管理

```bash
failproofai policies
failproofai policies remove block-refunds
failproofai policies add block-refunds
failproofai policies remove owner/repo
```

インストール済みの 2 つのパックに同じポリシー名が含まれている場合、CLI は曖昧な短縮名を拒否します。いずれかのパックを通じてポリシーを指定するか、もう一方のパックをアンインストールしてください。

## 安全性と可用性

各リリースにはマニフェスト、バンドルされたポリシーコード、およびチェックサムが含まれています。Failproof AI はロード前に記録済みのダイジェストを検証します。チェックサムはバイト列がリリースと一致することを証明しますが、公開者が誰かを証明するものではありません。

選択済みのパックがロードできない場合、そのパックが宣言したイベントはフェイルクローズ（安全側に倒して拒否）されます。詳細は[ポリシーの失敗時の動作](/ja/policies/failure-behavior)を参照してください。

| 変数 | 効果 |
| --- | --- |
| `FAILPROOFAI_NO_DOWNLOAD=1` | 新規ダウンロードを拒否。インストール済みパックは引き続き動作する |
| `FAILPROOFAI_PACK_BASE_URL` | ミラーを使用する |
| `FAILPROOFAI_PACK_DIR` | パックストアの場所を変更する |

パックは [Policy Hub](https://befailproof.ai/policy-hub/) で閲覧するか、[独自のパックを公開](/ja/policies/publish-a-pack)することもできます。
