`fp` を使用して Cloud のテレメトリを確認し、監査・検出事項・課題・アラート・キー・ユーザー・クエリ・設定を管理します。ローカルフック、ポリシー、キャプチャ、マシン登録には [`failproofai`](/ja/reference/failproof-cli) を使用してください。

リリース済みの Cloud CLI をスタンドアロンツールとしてインストールします。

```bash
uv tool install fp-cli
fp version
```

## サインイン

```bash
fp login
fp whoami
```

## 構文

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

グローバルオプションはコマンドの前に指定します。

```bash
fp --json sessions --since 24h
```

ターミナルヘルプを表示するには `fp COMMAND --help` または `fp COMMAND SUBCOMMAND --help` を実行してください。


### イベント

```text
fp events [OPTIONS]
```

個々のエージェントイベントを一覧表示します。デフォルトの軽量フィードは生ペイロードを除外します。`--full` は対象を絞った調査のみに使用してください。

| オプション | 説明 |
| --- | --- |
| `--limit`, `-n <n>` | 最大取得行数。デフォルト: `50`。 |
| `--since <window>` | `all`、`15m`、`1h`、`6h`、`24h`、または `7d`。 |
| `--from <timestamp>` / `--to <timestamp>` | ISO 8601 UTC 範囲。`--since` より優先されます。 |
| `--env <value>` | 環境フィルター。繰り返しまたはカンマ区切りで複数指定可能。 |
| `--event-type <value>` | イベントタイプフィルター。繰り返しまたはカンマ区切りで複数指定可能。 |
| `--agent-id <value>` | エージェントフィルター。繰り返しまたはカンマ区切りで複数指定可能。 |
| `--session-id <value>` | セッションフィルター。繰り返しまたはカンマ区切りで複数指定可能。 |
| `--search <text>` | ペイロードのテキスト検索。繰り返し可能で、いずれかの語句が一致した場合に該当。 |
| `--order asc\|desc` | 時間順。デフォルト: 新しい順。 |
| `--all` | `--limit` まで自動ページネーション。 |
| `--cursor <token>` | 不透明なカーソルから再開。 |
| `--page-size <n>` | `--all` 使用時のリクエストあたりの行数。最大 `200`。 |
| `--full` | より重いイベントエンドポイントから生ペイロードを含めて取得。 |
| `--fields <csv>` | 指定したフィールドのみを返す。`payload` を指定するとフルモードが有効になります。 |

```bash
fp events --session-id <session-id> --order asc --all
fp --json events --full --session-id <session-id> --all
```

### API キー

| コマンド | 目的 | オプション |
| --- | --- | --- |
| `fp keys list` | 組織のキーを一覧表示。 | `--show-id`; `--fields <csv>` |
| `fp keys show NAME` | 1つのキーとそのグラントを表示。 | — |
| `fp keys create NAME` | キーを作成し、シークレットを1回だけ表示。 | `--permission-set`; `--add`; `--remove` |
| `fp keys update NAME` | 権限セットを置き換えるかグラントを調整。 | `--permission-set`; `--add`; `--remove`; `--yes`, `-y` |

#### 監査作成オプション

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| オプション | 説明 |
| --- | --- |
| `--file <path>` | JSON をもとに定義するか、stdin には `-` を使用。明示的なフラグがファイルの値を上書きします。 |
| `--description <text>` | 障害の質問または目的を記述。 |
| `--enabled` / `--disabled` | スケジューリングをオン/オフで開始。デフォルト: 有効。 |
| `--schedule-interval-secs <n>` | `3600`〜`604800`。デフォルト: `86400`。 |
| `--schedule-anchor <timestamp>` | ISO 8601 形式の固定 UTC フェーズ。デフォルト: 次の 09:00 UTC。 |
| `--window-mode since_last\|fixed` | 最後に完全に分析されたウィンドウ以降を継続するか、ローリングウィンドウを繰り返し検査。デフォルト: `since_last`。 |
| `--lookback-window-secs <n>` | `3600`〜`7776000`。デフォルト: `604800`。 |
| `--scope '<json>'` | `environments`、`agent_ids`、またはその他のサポートされているスコープフィールドでフィルター。 |
| `--ignore-error-type <type>` | エラータイプを除外。繰り返しまたはカンマ区切りで複数指定可能。 |
| `--llm` / `--no-llm` | エージェント分析を有効/無効化。デフォルト: 有効。 |
| `--top-k <n>` | `1`〜`500` 件の検出事項を保持。デフォルト: `50`。 |
| `--sensitivity low\|medium\|high` | レポートの感度を設定。デフォルト: `medium`。 |
| `--channels '<json>'` | 通知チャンネルの配列。 |
| `--text <brief>` | インラインブリーフ。最大 8,192 文字。 |
| `--text-file <path>` | ファイルからブリーフを読み込む。`--text` とは相互排他。 |
| `--url <https-url>` | 公開 HTTPS 参照を追加。最大5回繰り返し可能。 |

最初の実行にコンテキストが必要な場合は、作成時に含めてください。作成はキューに追加された実行が開始される前に、定義とコンテキストをまとめてコミットします。

<Note>
  `fp audits run` は非同期です。検出事項を読み取る前に、`fp audits runs NAME` をポーリングして最新の実行が成功または失敗するまで待機してください。
</Note>

## グローバルフラグ

| フラグ | 説明 |
| --- | --- |
| `--json` | 機械可読な JSON を出力。 |
| `--base-url <url>` | セルフホストまたは開発用ダッシュボードを使用。 |
| `--org <slug>` | この呼び出しで使用する組織を選択。 |
| `--token <token>` | 保存されたユーザーセッショントークンを上書き。 |
| `--api-key <key>` | API キーで自動化を認証。保存されません。 |
| `--timeout <seconds>` | HTTP タイムアウト。正の値でなければなりません。デフォルト: `30`。 |
| `--quiet`, `-q` | stderr のステータス出力を抑制。 |
| `--no-color` | カラー出力を無効化。 |
| `--insecure` / `--secure` | TLS 証明書の検証を無効化または復元。 |
| `--version` | バージョンを出力して終了。 |
| `--help`, `-h` | ヘルプを表示。 |

`--api-key` は自動化用途を想定しています。ログイン・組織切り替え・アシスタントコマンドにはユーザーセッションが必要です。
