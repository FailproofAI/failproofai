`fp` を使用して Cloud のテレメトリを確認し、監査・所見・Issue・アラート・キー・ユーザー・クエリ・設定を管理します。ローカルフック、ポリシー、キャプチャ、マシン登録には [`failproofai`](/ja/reference/failproof-cli) を使用してください。

リリース済みの Cloud CLI を独立したツールとしてインストールします。

```bash
uv tool install fp-cli
fp version
```

## サインイン

```bash
fp login
fp whoami
```

## 構文

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

グローバルオプションはコマンドの前に指定する必要があります。

```bash
fp --json sessions --since 24h
```

ターミナルのヘルプを確認するには `fp COMMAND --help` または `fp COMMAND SUBCOMMAND --help` を実行してください。

### イベント

```text
fp events [OPTIONS]
```

個別のエージェントイベントを一覧表示します。デフォルトのライトフィードは生ペイロードを除外します。`--full` は範囲を限定した調査のみに使用してください。

| オプション | 説明 |
| --- | --- |
| `--limit`, `-n <n>` | 最大合計行数。デフォルト: `50`。 |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h`, または `7d`。 |
| `--from <timestamp>` / `--to <timestamp>` | ISO 8601 UTC の範囲指定; `--since` を上書きします。 |
| `--env <value>` | 環境フィルター; 複数指定またはカンマ区切りで指定します。 |
| `--event-type <value>` | イベントタイプフィルター; 複数指定またはカンマ区切りで指定します。 |
| `--agent-id <value>` | エージェントフィルター; 複数指定またはカンマ区切りで指定します。 |
| `--session-id <value>` | セッションフィルター; 複数指定またはカンマ区切りで指定します。 |
| `--search <text>` | ペイロードのテキスト検索; 繰り返し指定可能で、いずれかのキーワードにマッチします。 |
| `--order asc\|desc` | 時間順。デフォルト: 新しい順。 |
| `--all` | `--limit` まで自動ページネーションします。 |
| `--cursor <token>` | 不透明なカーソルから再開します。 |
| `--page-size <n>` | `--all` 使用時のリクエストあたりの行数; 最大 `200`。 |
| `--full` | より重いイベントエンドポイントを通じて生ペイロードを含めます。 |
| `--fields <csv>` | 選択したフィールドのみ返します; `payload` を指定するとフルモードになります。 |

```bash
fp events --session-id <session-id> --order asc --all
fp --json events --full --session-id <session-id> --all
```

### API キー

| コマンド | 目的 | オプション |
| --- | --- | --- |
| `fp keys list` | 組織のキーを一覧表示します。 | `--show-id`; `--fields <csv>` |
| `fp keys show NAME` | 1つのキーとそのグラントを表示します。 | — |

| `fp keys update NAME` | 権限セットを置き換えるかグラントを調整します。 | `--permission-set`; `--add`; `--remove`; `--yes`, `-y` |

#### 監査の作成オプション

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| オプション | 説明 |
| --- | --- |
| `--file <path>` | JSON に基づいて定義を作成します。`-` を指定すると stdin から読み込みます。明示的なフラグはファイルの値を上書きします。 |
| `--description <text>` | 障害の質問または目的を記述します。 |
| `--enabled` / `--disabled` | スケジューリングを有効または無効な状態で開始します。デフォルト: 有効。 |
| `--schedule-interval-secs <n>` | `3600`–`604800`。デフォルト: `86400`。 |
| `--schedule-anchor <timestamp>` | ISO 8601 形式の固定 UTC フェーズ。デフォルト: 次の 09:00 UTC。 |
| `--window-mode since_last\|fixed` | 最後に完全分析したウィンドウの後から継続するか、ローリングウィンドウを繰り返し検査します。デフォルト: `since_last`。 |
| `--lookback-window-secs <n>` | `3600`–`7776000`。デフォルト: `604800`。 |
| `--scope '<json>'` | `environments`、`agent_ids`、またはその他のサポートされたスコープフィールドでフィルタリングします。 |
| `--ignore-error-type <type>` | エラータイプを除外します; 繰り返しまたはカンマ区切りで指定します。 |
| `--llm` / `--no-llm` | エージェント分析を有効または無効にします。デフォルト: 有効。 |
| `--top-k <n>` | `1`–`500` 件の所見を保持します。デフォルト: `50`。 |
| `--sensitivity low\|medium\|high` | レポートの感度を設定します。デフォルト: `medium`。 |
| `--channels '<json>'` | 通知チャンネルの配列。 |
| `--text <brief>` | インラインブリーフ、最大 8,192 文字。 |
| `--text-file <path>` | ファイルからブリーフを読み込みます; `--text` とは相互排他です。 |
| `--url <https-url>` | 公開 HTTPS 参照を追加します; 最大5回繰り返せます。 |

最初の実行にコンテキストが必要な場合は、作成時に含めてください。作成によって、キューに入れた実行が開始される前に定義とコンテキストが一緒にコミットされます。

<Note>
  `fp audits run` は非同期です。所見を読む前に `fp audits runs NAME` をポーリングし、最新の実行が成功または失敗するまで待ってください。
</Note>

### Issue

| コマンド | 目的 | オプション |
| --- | --- | --- |
| `fp issues list` | Issue を一覧表示します。 | `--state`; `--alert-id`; `--limit`, `-n`; `--show-id` |
| `fp issues count` | オープンまたは選択した Issue の状態をカウントします。 | `--state` |
| `fp issues show INCIDENT_ID` | Issue の詳細、コメント、サブスクライバー、アクティビティを表示します。 | — |
| `fp issues open` | 手動またはアラートにリンクした Issue を開きます。 | 必須 `--summary`; オプション `--title`, `--alert-id`, `--severity` |
| `fp issues ack INCIDENT_ID` | Issue を確認します。 | — |
| `fp issues assign INCIDENT_ID` | アサインする担当者を置き換えます; オプションを省略するとクリアされます。 | 繰り返し指定可能 `--assignee` |
| `fp issues resolve INCIDENT_ID` | Issue を解決します。 | `--yes`, `-y` |
| `fp issues comment-list INCIDENT_ID` | コメントを一覧表示します。 | — |
| `fp issues comment-add INCIDENT_ID` | コメントを追加します。 | `--body`, `--file` のいずれか1つ |
| `fp issues comment-delete INCIDENT_ID COMMENT_ID` | コメントを削除します。 | `--yes`, `-y` |
| `fp issues subscribers INCIDENT_ID` | サブスクライバーを一覧表示します。 | — |
| `fp issues subscribe INCIDENT_ID` | 自分または別のオペレーターをサブスクライブします。 | `--email` |
| `fp issues unsubscribe INCIDENT_ID` | サブスクリプションを削除します。 | `--email` |

有効な Issue の状態は `firing`、`acknowledged`、`resolved` です。スタンドアロン Issue の重大度は `info`、`warning`、`critical` です。

## グローバルフラグ

| フラグ | 説明 |
| --- | --- |
| `--json` | 機械可読な JSON を出力します。 |
| `--base-url <url>` | セルフホストまたは開発環境のダッシュボードを使用します。 |
| `--org <slug>` | この実行の組織を選択します。 |
| `--token <token>` | 保存されているユーザーセッショントークンを上書きします。 |
| `--api-key <key>` | API キーで自動化処理を認証します; 保存されません。 |
| `--timeout <seconds>` | HTTP タイムアウト; 正の値である必要があります。デフォルト: `30`。 |
| `--quiet`, `-q` | stderr へのステータス出力を抑制します。 |
| `--no-color` | カラー出力を無効にします。 |
| `--insecure` / `--secure` | TLS 証明書検証を無効または復元します。 |
| `--version` | バージョンを表示して終了します。 |
| `--help`, `-h` | ヘルプを表示します。 |

`--api-key` は自動化処理向けです。ログイン、組織の切り替え、アシスタントコマンドにはユーザーセッションが必要です。

| `AGENTEYE_ANALYTICS_DISABLED` または `DO_NOT_TRACK` | 匿名 CLI アナリティクスを無効にします。 |
| `NO_COLOR` | カラー出力を無効にします。 |

明示的なフラグは環境変数を上書きし、環境変数は保存済みの設定を上書きします。API キーモードでは、`--org` または `AGENTEYE_ORG` でテナントを明示的に指定してください。
