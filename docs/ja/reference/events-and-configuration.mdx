## イベントファミリー

- エージェントの開始、終了、一時停止、再開
- モデルのリクエストとレスポンス
- ツールの使用と結果
- フックのトリガーと完了
- 人間の待機、入力、一時停止、割り込み
- 明示的なエラー

すべてのイベントには、タイムスタンプ、セッションID、エージェントID、イベントタイプ、環境が含まれます。イベント固有のフィールドには、モデル、ツール、相関、結果、コンテンツ、継続時間、またはエラーデータが含まれます。

## イベントコントラクトの検査

<Tabs>
  <Tab title="ダッシュボード">
    1. **Observe → Events** を開きます。
    2. 短い時間ウィンドウを設定し、環境、エージェント、イベントタイプでフィルタリングします。
    3. イベントを選択して正規化されたフィールドと生のペイロードを確認し、セッションを開いて実行コンテキストを確認します。
    4. ペアとなる継続時間が欠落している場合は、開始イベントと完了イベントが同じ相関IDを使用していることを確認してください。

    Eventsストリームを使用してデータを1つのエージェント実行に絞り込み、正規化されたイベントフィールドを検査します。

    ![環境、エージェント、セッション、イベントタイプのフィルターを備えたライブEventsストリーム。](/images/dashboard/events-stream.png)

    次に、イベントからセッションへと追跡します。トレースにはイベントの直前と直後に何が起きたかが表示されます。これはペイロード単体では意味が曖昧な場合に必要です。

    ![実行コンテキストでイベントを検査するために使用されるリンクされたセッショントレース。](/images/dashboard/session-detail.png)

    ペアとなるイベントや継続時間が欠落している場合は、両方のビューで相関IDとタイムスタンプを比較してください。
  </Tab>
  <Tab title="CLI">
    有効なフィルター値を確認してから、1つのセッションの完全なイベントペイロードを取得します：

    ```bash
    fp list event_types
    fp list envs
    fp events --since 1h \
      --env production \
      --event-type tool_use,tool_result \
      --session-id <session-id> \
      --full
    ```

    機械可読な検査には `fp --json events ... --fields ts,event_type,session_id,payload` を使用します。
  </Tab>
</Tabs>

## 予約済みSDKフィールド

`timestamp`、`session_id`、`agent_id`、`type`、`environment` をカスタムPython SDKフィールドとして使用しないでください。ツール結果の継続時間などのペアイベントの継続時間はSDKによって計算されるため、手動で指定することはできません。

## ローカルの境界

- Failproof AI の状態は、明示的に設定されていない限り `~/.failproofai` に保存されます。
- `failproofai-sdk` はレガシーベースディレクトリの上書きに `AGENTEYE_HOME` を使用します。
- 環境ラベルはSDK設定または `AGENTEYE_ENVIRONMENT` を通じて設定できます。
- デーモンの認証情報は非シークレット設定とは別に保存されます。

安定した低カーディナリティの環境名を使用してください。デーモンの環境ラベルではカンマはサポートされていません。

## 環境ラベルの変更

<Tabs>
  <Tab title="ダッシュボード">
    環境ラベルは、発行するSDKまたは Failproof デーモンによって割り当てられます。変更後は **Observe → Sessions** を開き、環境フィルターを使用して新しいセッションに新しい値が反映されていることを確認してください。既存のセッションには元の環境が保持されます。

  </Tab>
  <Tab title="CLI">
    `failproofai-sdk` の場合は、コード内または従来の環境変数で環境を設定します。マシンレベルの設定を変更する際はデーモン設定を再実行してください。

    ```bash
    export AGENTEYE_ENVIRONMENT=production-us-east
    failproofai config
    failproofai config --status
    fp sessions --since 1h --env production-us-east
    ```
  </Tab>
</Tabs>
