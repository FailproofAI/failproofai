AIツールをFailproof AI Cloudに接続し、エージェントのデータを活用できます。ツールはセッションやイベントの照会、読み取り専用SQLの実行、ダッシュボード・アラート・イシュー・監査・ポリシーの参照が可能です。また、パーミッションがあれば、アラートの作成やポリシーのデプロイといった変更操作も行えます。

すべての呼び出しは**あなた自身**のパーミッションで、接続時に選択した**1つ**の組織内で実行されます。

ホスト型・セルフホスト型を問わず、共通のアドレスを使用します：

```text
https://gateway.befailproof.ai/mcp
```

## クライアントの接続

クライアントにアドレスを追加してください。ツールを初めて使用する際にブラウザが開きます。Failproof AI Cloudの場所を選択してサインインし、組織を1つ選んで**Allow**をクリックしてください。**Cancel**を選ぶと接続されません。

ページにはアプリ名とリダイレクト先が表示されます。独自のウェブアドレスで識別されていないアプリは**未確認アプリ**と表示されるため、自分のクライアントから操作を開始した場合にのみ続行してください。

<Tabs>
  <Tab title="Claude">
    claude.aiまたはClaude Desktopで、**設定 → コネクター → カスタムコネクターを追加**に進みます。名前を`Failproof AI`と入力し、アドレスを入力して**追加**、次に**接続**をクリックします。

    チームプランおよびエンタープライズプランでは、まずオーナーが組織全体のコネクターを追加します。その後、各ユーザーが自分のアカウントを接続します。
  </Tab>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http failproofai https://gateway.befailproof.ai/mcp
    ```

    次に、Claude Code内で`/mcp`を実行し、`failproofai`を選択して**Authenticate**をクリックします。
  </Tab>
  <Tab title="Cursor">
    `~/.cursor/mcp.json`またはプロジェクトの`.cursor/mcp.json`に以下を追加します：

    ```json
    {
      "mcpServers": {
        "failproofai": { "url": "https://gateway.befailproof.ai/mcp" }
      }
    }
    ```

    Cursorのサーバー一覧に**Needs login**と表示されます。選択してサインインしてください。
  </Tab>
  <Tab title="Codex">
    `~/.codex/config.toml`に以下を追加します：

    ```toml
    [mcp_servers.failproofai]
    url = "https://gateway.befailproof.ai/mcp"
    ```

    次に`codex mcp login failproofai`を実行します。
  </Tab>
  <Tab title="その他のクライアント">
    OAuth対応のStreamable HTTPを使用したリモートMCPサーバーをサポートする任意のクライアントで動作します。上記のアドレスを設定するだけです。クライアントIDやシークレットの設定は不要です。
  </Tab>
</Tabs>

## 接続ごとに1組織

接続は選択した組織内でのみ機能します。2つの組織を使用するには、`failproofai-acme`や`failproofai-sandbox`のように異なる名前でサーバーを2回追加し、それぞれ別の組織に接続してください。

デモ組織は接続を受け付けません。自分の組織を選択してください。

## パーミッション

接続は、組織内であなたが持つパーミッションの範囲内で操作できます。パーミッションはリアルタイムに反映されます。管理者が権限を追加すると、次の呼び出し時にツールにも反映され、権限が削除された場合も同様に失われます。

| パーミッション | ツールでできること |
| --- | --- |
| `events:read` | イベントの一覧表示、セッションの概要確認、エージェントと環境の一覧表示 |
| `evaluations:read` | セッションの一覧表示、評価結果とジョブの確認・要約 |
| `evaluations:trigger` | 評価の作成、新バージョンの公開、有効/無効の切り替え、バックフィル、セッションの再評価 |
| `dashboards:read`、`dashboards:write` | ダッシュボードの参照、または作成・名前変更・クエリの追加 |
| `queries:read`、`queries:write` | 保存済みクエリの参照、または保存・編集 |
| `queries:run` | 読み取り専用SQLクエリの実行とクエリスキーマの確認 |
| `alerts:read`、`alerts:write` | アラートの参照、または作成・編集・一時停止・削除・テスト |
| `issues:read` | イシューの参照、確認、コメント |
| `issues:create` | アラートに対するイシューの作成 |
| `issues:close` | イシューの解決とクローズ |
| `audits:read`、`audits:write` | 監査・実行・検出事項の参照、または監査の作成・編集・実行の開始 |
| `code_fixes:read` | イシューの修正方法の確認、および自分のエージェントが修正に使用するコンテキストの取得 |
| `code_fixes:write` | Failproof AI CloudでフィックスをタートさせGitHubにプルリクエストを作成 |
| `policies:read`、`policies:write` | ポリシー・マシン・デプロイメントの参照、またはポリシーの公開・デプロイ・ロールバック |

組織データを参照しないため、パーミッション不要のツールも一部あります。セッション・イベントリンクの生成とこのドキュメントの検索がこれに該当します。

AIツールは、APIキー・ユーザー・設定・組織管理には一切アクセスできず、イベントの送信も行えません。

## 変更の承認

クライアントがプロンプトを表示できる場合、書き込み操作の前に確認が求められます。変更内容が表示されるので、**Approve this change**を選択して続行してください。拒否するか約4分以内に応答しない場合、変更は行われません。クライアントによっては1分で待機を終了するため、速やかに応答してください。

<Warning>
  プロンプトをサポートしないクライアントは確認を求めずに書き込みを実行します。その場合、クライアント自身の確認が唯一の安全策となるため、書き込みツールでは確認機能を有効にしておいてください。
</Warning>

## 接続済みアプリと接続の取り消し

**設定 → インテグレーション → MCP**には、現在の組織における接続済みアプリの一覧がパーミッションと最終利用日時とともに表示されます。**Revoke**を選択するとアプリを即座に切断できます。クライアント側でサーバーを削除しても接続が取り消されます。

1組織あたり最大5つのアプリを接続できます。同じアプリを再接続すると、以前の接続が上書きされます。

## セルフホストデプロイメント

接続時に**Self-hosted Failproof AI Cloud**を選択し、サインインに使用するアドレスを入力します。デプロイメントは公開HTTPSで到達可能である必要があります。

ツール呼び出しとその結果は、AIツールとデプロイメント間でホスト型Failproof AIゲートウェイを経由します。ゲートウェイはこれらのデータを保存しません。

## データの取り扱い

結果は接続したAIツールに送信され、そのツールのプロバイダーが独自の規約に基づいて処理します。各ツール呼び出しについて、Failproof AIはツール名・結果・所要時間・組織のみを記録します。引数や結果の内容は記録されません。詳細は[プライバシーポリシー](https://befailproof.ai/privacy/)をご覧ください。

## トラブルシューティング

| 表示されるメッセージ | 対処方法 |
| --- | --- |
| 「別のブラウザで開始されました」 | クライアントが開いたブラウザ（Cookieを有効にした状態）でサインインを完了し、クライアントから再度開始してください |
| **Allow**後にエラーが発生する | リンクは1回のみ有効で10分で期限切れになります。クライアントから再度開始してください |
| 期待していたツールが表示されない | この組織でそのパーミッションを持っていません。管理者に確認してください。パーミッションを取得後に再接続は不要です |
| クライアントが繰り返しサインインを求める | 接続が取り消されたか、組織を退出したか、90日間未使用だった可能性があります。再接続してください |
| 「接続済みアプリが5つあります」 | **設定 → インテグレーション → MCP**で1つを取り消してから再接続してください |

解決しない場合は、[support@befailproof.ai](mailto:support@befailproof.ai)までメールでお問い合わせください。
