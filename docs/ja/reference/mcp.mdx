AIツールをFailproof AI Cloudに接続し、エージェントのデータを活用しましょう。ツールからセッションやイベントの照会、読み取り専用SQLの実行、ダッシュボード・アラート・イシュー・監査・ポリシーの参照が可能です。また、権限を持っている場合はアラートの作成やポリシーのデプロイといった変更操作も行えます。

すべての呼び出しは**あなた自身**の権限で実行され、接続時に選択した**1つ**の組織内でのみ動作します。

ホスト型・セルフホスト型を問わず、共通のアドレスは次のとおりです。

```text
https://gateway.befailproof.ai/mcp
```

## クライアントの接続

クライアントにアドレスを追加してください。初めてツールを使用する際、ブラウザが開きます。Failproof AI Cloudの場所を選択してサインインし、組織を1つ選んで**Allow**をクリックしてください。**Cancel**を選択した場合は何も接続されません。

ページにはアプリ名とリダイレクト先が表示されます。独自のウェブアドレスで識別されていないアプリは**未確認のアプリ**と表示されるため、自分のクライアントから操作を開始した場合にのみ続行してください。

<Tabs>
  <Tab title="Claude">
    claude.aiまたはClaude Desktopで、**Settings → Connectors → Add custom connector**を開きます。名前に`Failproof AI`と入力し、アドレスを入力して**Add**、続いて**Connect**を選択します。

    TeamプランおよびEnterpriseプランでは、オーナーが組織全体のコネクターを先に追加します。その後、各メンバーが自分自身のアカウントで接続します。
  </Tab>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http failproofai https://gateway.befailproof.ai/mcp
    ```

    次に、Claude Code内で`/mcp`を実行し、`failproofai`を選択して**Authenticate**を選択します。
  </Tab>
  <Tab title="Cursor">
    `~/.cursor/mcp.json`またはプロジェクトの`.cursor/mcp.json`に以下を追加します。

    ```json
    {
      "mcpServers": {
        "failproofai": { "url": "https://gateway.befailproof.ai/mcp" }
      }
    }
    ```

    Cursorのサーバー一覧に**Needs login**と表示されます。それを選択してサインインしてください。
  </Tab>
  <Tab title="Codex">
    `~/.codex/config.toml`に以下を追加します。

    ```toml
    [mcp_servers.failproofai]
    url = "https://gateway.befailproof.ai/mcp"
    ```

    次に`codex mcp login failproofai`を実行します。
  </Tab>
  <Tab title="その他のクライアント">
    OAuthを使用したStreamable HTTP経由でリモートMCPサーバーに対応している任意のクライアントで動作します。上記のアドレスを設定してください。クライアントIDやシークレットの設定は不要です。
  </Tab>
</Tabs>

## 接続ごとに1組織

1つの接続は、選択した組織内でのみ機能します。2つの組織を利用する場合は、`failproofai-acme`や`failproofai-sandbox`のように異なる名前でサーバーを2回追加し、それぞれ別の組織に接続してください。

デモ組織への接続はできません。自分の組織を選択してください。

## 権限

接続では、以下の権限セットの範囲内で、あなたが組織内で持つ権限と同等の操作を実行できます。権限はリアルタイムで反映されます。管理者が権限を付与すれば次回の呼び出しからツールも利用可能になり、権限が剥奪されればツールも同様に利用できなくなります。

| 権限 | ツールでできること |
| --- | --- |
| `events:read` | イベントの一覧表示、セッション概要の参照、エージェントおよび環境の一覧表示 |
| `evaluations:read` | セッションの一覧表示、評価結果とジョブの参照・要約 |
| `evaluations:trigger` | 評価の作成、新バージョンの公開、有効/無効の切り替え、バックフィル、セッションの再評価 |
| `dashboards:read`、`dashboards:write` | ダッシュボードの参照、または作成・名前変更・クエリの追加 |
| `queries:read`、`queries:write` | 保存済みクエリの参照、または保存・編集 |
| `queries:run` | 読み取り専用SQLクエリの実行、クエリスキーマの参照 |
| `alerts:read`、`alerts:write` | アラートの参照、または作成・編集・一時停止・削除・テスト |
| `issues:read` | イシューの参照、確認、コメント |
| `issues:create` | アラートに対するイシューの作成 |
| `issues:close` | イシューの解決とクローズ |
| `audits:read`、`audits:write` | 監査・実行・検出結果の参照、または監査の作成・編集・実行の開始 |
| `code_fixes:read` | イシューの修正方法の確認、自分のエージェントが修正に使用するコンテキストの取得 |
| `code_fixes:write` | Failproof AI Cloudでの修正を開始（GitHubにプルリクエストが作成されます） |
| `policies:read`、`policies:write` | ポリシー・マシン・デプロイメントの参照、またはポリシーの公開・デプロイ・ロールバック |

セッションやイベントのリンク作成、このドキュメントの検索など、一部のツールは組織データを参照しないため、権限は不要です。

AIツールはAPIキー、ユーザー、設定、組織管理に一切アクセスできず、イベントの送信も行えません。

## 変更の承認

クライアントがプロンプトを表示できる場合、書き込み操作の前に確認が求められます。変更内容が表示されるので、**Approve this change**を選択して続行してください。拒否するか約4分以内に応答しない場合、何も変更されません。クライアントによっては1分で待機を終了するため、速やかに応答してください。

<Warning>
  プロンプト表示に対応していないクライアントでは確認が行われず、クライアントが呼び出しを実行した時点で書き込みが即座に実行されます。この場合、クライアント自身の確認機能が唯一の安全策となるため、書き込みツールでは確認機能を有効にしておいてください。
</Warning>

## 接続済みアプリと接続の取り消し

**Settings → Integrations → MCP**では、現在の組織に接続されているアプリの一覧が権限と最終使用日時とともに表示されます。**Revoke**を選択するとアプリへのアクセスを即座に遮断できます。クライアントからサーバーを削除しても接続が取り消されます。

1つの組織につき最大5つのアプリを接続できます。同じアプリを再接続すると、以前の接続が置き換えられます。

## セルフホスト環境

接続時に**Self-hosted Failproof AI Cloud**を選択し、サインイン時に使用するアドレスを入力してください。デプロイ環境にはパブリックHTTPS経由でアクセスできる必要があります。

ツールの呼び出しとその結果は、AIツールとデプロイ環境の間をホスト型のFailproof AIゲートウェイを経由して転送されます。ゲートウェイはこれらを保存しません。

## データの取り扱い

結果は接続したAIツールに送信され、そのツールのプロバイダーが独自の規約に基づいて処理します。ツール呼び出しごとに、Failproof AIはツール名・結果・実行時間・組織をログに記録しますが、引数や結果の内容は記録しません。詳細は[プライバシーポリシー](https://befailproof.ai/privacy/)をご確認ください。

## トラブルシューティング

| 表示されるメッセージ | 対処方法 |
| --- | --- |
| "Started in another browser" | クライアントが開いたブラウザ（Cookieを有効にした状態）でサインインを完了し、クライアントから再試行してください |
| **Allow**後にエラーが発生する | リンクは1回のみ有効で10分で期限切れになります。クライアントから再試行してください |
| 期待していたツールが表示されない | その組織での該当権限を持っていません。管理者にお問い合わせください。権限を取得後、再接続は不要です |
| クライアントが繰り返しサインインを要求する | 接続が取り消された、組織から退出した、または90日間未使用のいずれかです。再接続してください |
| "You have 5 connected apps" | **Settings → Integrations → MCP**で1つ取り消してから再接続してください |

解決しない場合は、[support@befailproof.ai](mailto:support@befailproof.ai)までメールでお問い合わせください。
