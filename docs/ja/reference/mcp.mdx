AIツールをFailproof AI Cloudに接続し、エージェントのデータを活用しましょう。ツールはセッションやイベントのクエリ実行、読み取り専用SQL、ダッシュボード・アラート・イシュー・監査・ポリシーの閲覧が可能です。また、必要な権限を持っていれば、アラートの作成やポリシーのデプロイといった変更操作も行えます。

すべての呼び出しは**あなた自身の**権限で、接続時に選択した**1つの**組織内で実行されます。

ホスト型・セルフホスト型を問わず、アドレスは共通です：

```text
https://gateway.befailproof.ai/mcp
```

## クライアントの接続

クライアントにアドレスを追加します。初めてツールを使用する際にブラウザが開くので、Failproof AI Cloudの場所を選択し、サインインして組織を1つ選び、**許可**をクリックします。**キャンセル**を選択すると接続されません。

ページにはアプリ名とリダイレクト先が表示されます。独自のWebアドレスで識別されていないアプリには**未確認のアプリ**と表示されますので、自分のクライアントから起動した場合のみ続行してください。

<Tabs>
  <Tab title="Claude">
    claude.aiまたはClaude Desktopで、**設定 → コネクター → カスタムコネクターを追加**に進みます。名前に`Failproof AI`を入力し、アドレスを入力して**追加**、次に**接続**を選択します。

    チームプランおよびエンタープライズプランでは、オーナーが先に組織用のコネクターを追加します。その後、各メンバーが自分のアカウントを接続します。
  </Tab>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http failproofai https://gateway.befailproof.ai/mcp
    ```

    次に、Claude Code内で`/mcp`を実行し、`failproofai`を選択して**認証**をクリックします。
  </Tab>
  <Tab title="Cursor">
    `~/.cursor/mcp.json`、またはプロジェクトの`.cursor/mcp.json`に以下を追加します：

    ```json
    {
      "mcpServers": {
        "failproofai": { "url": "https://gateway.befailproof.ai/mcp" }
      }
    }
    ```

    Cursorでサーバーの横に**ログインが必要**と表示されます。クリックしてサインインしてください。
  </Tab>
  <Tab title="Codex">
    `~/.codex/config.toml`に以下を追加します：

    ```toml
    [mcp_servers.failproofai]
    url = "https://gateway.befailproof.ai/mcp"
    ```

    次に`codex mcp login failproofai`を実行します。
  </Tab>
  <Tab title="その他のクライアント">
    OAuthを使用したStreamable HTTP経由のリモートMCPサーバーをサポートするクライアントであれば利用できます。上記のアドレスを設定してください。クライアントIDやシークレットの設定は不要です。
  </Tab>
</Tabs>

## 1接続につき1組織

1つの接続は、選択した組織内でのみ動作します。2つの組織を使用する場合は、`failproofai-acme`や`failproofai-sandbox`など異なる名前でサーバーを2回追加し、それぞれ別の組織に接続してください。

デモ組織は接続を受け付けません。代わりに自分の組織を選択してください。

## 権限

接続は、組織内でのあなた自身の権限の範囲内（下記のセット内）で操作できます。現在の権限に連動して動作するため、管理者が権限を追加するとツールも権限を取得し、権限を削除されると次回の呼び出し時にツールも失います。

| 権限 | ツールでできること |
| --- | --- |
| `events:read` | イベントの一覧表示、セッション概要の閲覧、エージェントと環境の一覧表示 |
| `evaluations:read` | セッションの一覧表示、評価結果とジョブの閲覧・要約 |
| `evaluations:trigger` | 評価の作成、新バージョンの公開、有効化・無効化、バックフィル、セッションの再評価 |
| `dashboards:read`、`dashboards:write` | ダッシュボードの閲覧、または作成・名前変更・クエリの追加 |
| `queries:read`、`queries:write` | 保存済みクエリの閲覧、または保存・編集 |
| `queries:run` | 読み取り専用SQLクエリの実行とクエリスキーマの閲覧 |
| `alerts:read`、`alerts:write` | アラートの閲覧、または作成・編集・一時停止・削除・テスト |
| `issues:read` | イシューの閲覧、確認、コメントの追加 |
| `issues:create` | アラートに対するイシューの作成 |
| `issues:close` | イシューの解決とクローズ |
| `audits:read`、`audits:write` | 監査・実行・検出事項の閲覧、または監査の作成・編集・実行の開始 |
| `code_fixes:read` | イシューの修正方法の確認、および自分のエージェントで修正するためのコンテキストの取得 |
| `code_fixes:write` | Failproof AI Cloudでの修正の開始（GitHubにプルリクエストが作成されます） |
| `policies:read`、`policies:write` | ポリシー・マシン・デプロイメントの閲覧、またはポリシーの公開・デプロイ・ロールバック |

セッションとイベントのリンク作成、およびドキュメントの検索など、組織データを読み取らないツールは権限不要です。

AIツールはAPIキー、ユーザー、設定、組織管理に触れることはできず、イベントの送信も行えません。

## 変更の承認

クライアントがプロンプトを表示できる場合、書き込み操作の前に確認を求めます。変更内容が表示されるので、**この変更を承認する**を選択して続行します。拒否するか約4分以内に回答しない場合、何も変更されません。クライアントによっては1分後に待機を停止するため、速やかに回答してください。

<Warning>
  プロンプトをサポートしないクライアントでは確認が求められず、クライアントが呼び出した時点で書き込みが実行されます。その場合、クライアント自身の確認が唯一の安全策となるため、書き込みツールを使用する際は確認機能を有効のままにしておいてください。
</Warning>

## 接続済みアプリの確認と失効

**設定 → インテグレーション → MCP**に、現在の組織での接続済みアプリが権限と最終使用日時とともに一覧表示されます。**失効**を選択すると即座にアクセスが遮断されます。クライアントでサーバーを削除しても接続が失効します。

1組織につき最大5つのアプリを接続できます。同じアプリを再度接続すると、以前の接続が置き換えられます。

## セルフホスト型デプロイメント

接続時に**セルフホスト型Failproof AI Cloud**を選択し、サインインに使用するアドレスを入力します。デプロイメントは公開HTTPSでアクセス可能である必要があります。

ツールの呼び出しとその結果は、AIツールとデプロイメントの間でホスト型Failproof AIゲートウェイを経由します。ゲートウェイはこれらのデータを保存しません。

## データの取り扱い

結果は接続したAIツールに送信され、そのツールのプロバイダーが自社の規約に基づいて処理します。各ツール呼び出しについて、Failproof AIはツール名、結果、処理時間、組織のみをログに記録します（引数や結果の内容は記録しません）。詳細は[プライバシーポリシー](https://befailproof.ai/privacy/)をご覧ください。

## トラブルシューティング

| 表示されるメッセージ | 対処方法 |
| --- | --- |
| 「別のブラウザで開始されました」 | クライアントが開いたブラウザでCookieを許可した状態でサインインを完了し、クライアントから再度開始してください |
| **許可**後にエラーが発生する | リンクは1回限り有効で10分後に期限切れになります。クライアントから再度開始してください |
| 期待していたツールが表示されない | その組織でのアクセス権限がありません。管理者にお問い合わせください。権限を取得後に再接続は不要です |
| クライアントが繰り返しサインインを要求する | 接続が失効したか、組織から離脱したか、90日間未使用の状態が続いています。再度接続してください |
| 「接続済みアプリが5つあります」 | **設定 → インテグレーション → MCP**で1つを失効させてから、再度接続してください |

それでも解決しない場合は、[support@befailproof.ai](mailto:support@befailproof.ai)までメールでお問い合わせください。
