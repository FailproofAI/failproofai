AIツールをFailproof AI Cloudに接続し、エージェントのデータを操作できます。セッションやイベントの照会、読み取り専用SQLの実行、ダッシュボード・アラート・イシュー・監査・ポリシーの参照が可能です。また、権限があれば、アラートの作成やポリシーのデプロイといった変更操作も行えます。

すべての呼び出しは**あなた自身**の権限で、接続時に選択した**1つ**の組織内で実行されます。

ホスト型・セルフホスト型を問わず、アドレスは共通です：

```text
https://gateway.befailproof.ai/mcp
```

## クライアントの接続

クライアントにアドレスを追加してください。ツールを初めて使用するとブラウザが開きます。Failproof AI Cloudの場所を選択し、サインインして組織を1つ選び、**Allow** をクリックします。**Cancel** を選択した場合は何も接続されません。

ページにはアプリ名とリダイレクト先が表示されます。独自のウェブアドレスで識別されていないアプリは **unverified app** と表示されるため、自分のクライアントから操作を開始した場合にのみ続行してください。

<Tabs>
  <Tab title="Claude">
    claude.aiまたはClaude Desktopで、**Settings → Connectors → Add custom connector** に進みます。名前を `Failproof AI` と入力し、アドレスを入力して **Add**、次に **Connect** を選択します。

    TeamプランおよびEnterpriseプランでは、まずオーナーが組織用のコネクターを追加します。その後、各メンバーが自分のアカウントを接続します。
  </Tab>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http failproofai https://gateway.befailproof.ai/mcp
    ```

    次に、Claude Code内で `/mcp` を実行し、`failproofai` を選択して **Authenticate** をクリックします。
  </Tab>
  <Tab title="Cursor">
    `~/.cursor/mcp.json` またはプロジェクトの `.cursor/mcp.json` に以下を追加します：

    ```json
    {
      "mcpServers": {
        "failproofai": { "url": "https://gateway.befailproof.ai/mcp" }
      }
    }
    ```

    Cursorのサーバー一覧に **Needs login** と表示されます。それを選択してサインインしてください。
  </Tab>
  <Tab title="Codex">
    `~/.codex/config.toml` に以下を追加します：

    ```toml
    [mcp_servers.failproofai]
    url = "https://gateway.befailproof.ai/mcp"
    ```

    次に、`codex mcp login failproofai` を実行します。
  </Tab>
  <Tab title="その他のクライアント">
    OAuthを使用したStreamable HTTP経由のリモートMCPサーバーをサポートするクライアントであれば使用できます。上記のアドレスを設定してください。クライアントIDやシークレットの設定は不要です。
  </Tab>
</Tabs>

## 接続ごとに1つの組織

接続は選択した組織内でのみ機能します。2つの組織を使用するには、`failproofai-acme` や `failproofai-sandbox` のように異なる名前でサーバーを2回追加し、それぞれを別の組織に接続してください。

デモ組織への接続は受け付けていません。代わりに自分の組織を選択してください。

## 権限

接続では、組織内であなたが持つ権限の範囲内で操作できます。権限はリアルタイムで反映されます。管理者が権限を追加すればツールもそれを取得し、権限を削除すれば次の呼び出し時にツールからも失われます。

| 権限 | ツールでできること |
| --- | --- |
| `events:read` | イベントの一覧表示、セッションの概要確認、エージェントと環境の一覧表示 |
| `evaluations:read` | セッションの一覧表示、評価結果とジョブの確認・要約 |
| `evaluations:trigger` | 評価の作成、新バージョンの公開、オン/オフの切り替え、バックフィル、セッションの再評価 |
| `dashboards:read`、`dashboards:write` | ダッシュボードの参照、または作成・名前変更・クエリの追加 |
| `queries:read`、`queries:write` | 保存済みクエリの参照、または保存・編集 |
| `queries:run` | 読み取り専用SQLクエリの1件実行とクエリスキーマの確認 |
| `alerts:read`、`alerts:write` | アラートの参照、または作成・編集・一時停止・削除・テスト |
| `issues:read` | イシューの参照、確認、コメント |
| `issues:create` | アラートに対するイシューの作成 |
| `issues:close` | イシューの解決とクローズ |
| `audits:read`、`audits:write` | 監査・実行・検出結果の参照、または監査の作成・編集と実行の開始 |
| `code_fixes:read` | イシューの修正方法の確認、および自分のエージェントが修正するためのコンテキスト取得 |
| `code_fixes:write` | Failproof AI Cloudでの修正を開始し、GitHubにプルリクエストを作成 |
| `policies:read`、`policies:write` | ポリシー・マシン・デプロイメントの参照、またはポリシーの公開・デプロイ・ロールバック |

一部のツールは組織データを読み取らないため権限が不要です：セッションやイベントのリンク作成、このドキュメントの検索などがこれにあたります。

AIツールは、APIキー・ユーザー・設定・組織管理には一切アクセスできず、イベントの送信も行えません。

## 変更の承認

クライアントがプロンプトを表示できる場合、書き込み操作の前に確認が求められます。変更内容を確認し、**Approve this change** を選択して続行してください。拒否するか約4分以内に回答しない場合、変更は行われません。クライアントによっては1分で待機を終了するため、速やかに回答してください。

<Warning>
  プロンプトをサポートしないクライアントでは確認が行われず、クライアントが呼び出しを行った時点で書き込みが実行されます。その場合、クライアント自身の確認が唯一の安全策となるため、書き込みツールでは必ず有効にしておいてください。
</Warning>

## 接続済みアプリの確認と削除

**Settings → Integrations → MCP** に、現在の組織の接続済みアプリが権限と最終使用日とともに一覧表示されます。**Revoke** を選択すると即座にアクセスが遮断されます。クライアントからサーバーを削除しても接続が取り消されます。

1つの組織につき最大5つのアプリを接続できます。同じアプリを再接続すると、以前の接続が置き換えられます。

## セルフホスト型デプロイメント

接続時に **Self-hosted Failproof AI Cloud** を選択し、サインイン時に使用するアドレスを入力してください。デプロイメントは公開HTTPSでアクセス可能である必要があります。

ツール呼び出しとその結果は、AIツールとデプロイメントの間でホスト型Failproofゲートウェイを経由します。ゲートウェイはそれらを保存しません。

## データの取り扱い

結果は接続したAIツールに送信され、そのツールのプロバイダーが独自の規約に基づいて処理します。各ツール呼び出しについて、Failproof AIはツール名・結果・所要時間・組織のみを記録します。引数や結果の内容は記録されません。詳しくは[プライバシーポリシー](https://befailproof.ai/privacy/)をご覧ください。

## トラブルシューティング

| 表示内容 | 対処方法 |
| --- | --- |
| "Started in another browser" | クライアントが開いたブラウザ（Cookieを許可した状態）でサインインを完了し、クライアントから再度開始してください |
| **Allow** 後にエラーが発生する | リンクは1回限り有効で10分で期限切れになります。クライアントから再度開始してください |
| 期待していたツールが表示されない | その組織での権限がありません。管理者に確認してください。権限取得後に再接続は不要です |
| クライアントがサインインを繰り返し要求する | 接続が取り消されたか、組織を退出したか、90日間未使用の状態になっています。再接続してください |
| "You have 5 connected apps" と表示される | **Settings → Integrations → MCP** でいずれかを削除してから再接続してください |

解決しない場合は [support@befailproof.ai](mailto:support@befailproof.ai) までメールでお問い合わせください。
