AIツールをFailproof AI Cloudに接続し、エージェントのデータを操作できます。ツールはセッションやイベントの照会、読み取り専用SQL、ダッシュボード・アラート・Issues・監査・ポリシーの参照が可能です。また、権限を持っている場合は、アラートの作成やポリシーのデプロイなどの変更操作も行えます。

すべての操作は**あなた自身**の権限で、接続時に選択した**1つ**の組織内で実行されます。

ホスト型・セルフホスト型を問わず、全員共通のアドレスは以下のとおりです：

```text
https://gateway.befailproof.ai/mcp
```

## クライアントを接続する

クライアントにアドレスを追加してください。ツールを初めて使用すると、ブラウザが開きます。Failproof AI Cloudの場所を選択し、サインインして組織を1つ選び、**Allow** をクリックします。**Cancel** を選択すると接続されません。

ページにはアプリ名と返送先が表示されます。自身のウェブアドレスで識別されていないアプリには **unverified app** と表示されます。自分のクライアントから開始した場合のみ続行してください。

<Tabs>
  <Tab title="Claude">
    claude.aiまたはClaude Desktopで、**Settings → Connectors → Add custom connector** に進みます。名前を `Failproof AI` とし、アドレスを入力して **Add**、次に **Connect** を選択します。

    TeamおよびEnterpriseプランでは、オーナーが先に組織向けコネクターを追加します。その後、各メンバーが自分のアカウントで接続します。
  </Tab>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http failproofai https://gateway.befailproof.ai/mcp
    ```

    その後、Claude Code内で `/mcp` を実行し、`failproofai` を選択して **Authenticate** を選びます。
  </Tab>
  <Tab title="Cursor">
    `~/.cursor/mcp.json`、またはプロジェクトの `.cursor/mcp.json` に以下を追加してください：

    ```json
    {
      "mcpServers": {
        "failproofai": { "url": "https://gateway.befailproof.ai/mcp" }
      }
    }
    ```

    サーバーの横に **Needs login** と表示されます。選択してサインインしてください。
  </Tab>
  <Tab title="Codex">
    `~/.codex/config.toml` に以下を追加してください：

    ```toml
    [mcp_servers.failproofai]
    url = "https://gateway.befailproof.ai/mcp"
    ```

    その後、`codex mcp login failproofai` を実行します。
  </Tab>
  <Tab title="その他のクライアント">
    OAuthを使用したStreamable HTTP経由のリモートMCPサーバーに対応しているクライアントであれば利用できます。上記のアドレスを設定してください。クライアントIDやシークレットの設定は不要です。
  </Tab>
</Tabs>

## 接続ごとに1組織

1つの接続は、選択した組織内でのみ動作します。2つの組織を使用する場合は、`failproofai-acme` や `failproofai-sandbox` のように異なる名前でサーバーを2回追加し、それぞれの組織に接続してください。

デモ組織への接続は受け付けられません。自分の組織を選択してください。

## 権限

接続は、以下のセット内で、組織内でのあなたの操作権限と同等のことができます。現在の権限に連動して動作します。管理者が権限を追加すると、ツールも次の呼び出し時にその権限を取得し、削除されると失います。

| 権限 | ツールで可能な操作 |
| --- | --- |
| `events:read` | イベントの一覧表示、セッションの概要確認、エージェントと環境の一覧表示 |
| `evaluations:read` | セッションの一覧表示、評価結果とジョブの参照・要約 |
| `evaluations:trigger` | 評価の作成、新バージョンの公開、有効化・無効化、バックフィル、セッションの再評価 |
| `dashboards:read`、`dashboards:write` | ダッシュボードの参照、または作成・名前変更・クエリの追加 |
| `queries:read`、`queries:write` | 保存済みクエリの参照、または保存・編集 |
| `queries:run` | 読み取り専用SQLクエリの実行とクエリスキーマの参照 |
| `alerts:read`、`alerts:write` | アラートの参照、または作成・編集・一時停止・削除・テスト |
| `issues:read` | Issueの参照・確認・コメント |
| `issues:create` | アラートに対するIssueの作成 |
| `issues:close` | Issueの解決とクローズ |
| `audits:read`、`audits:write` | 監査・実行・検出結果の参照、または監査の作成・編集・実行の開始 |
| `code_fixes:read` | Issueの修正方法の確認、および自前のエージェントが修正するためのコンテキスト取得 |
| `code_fixes:write` | Failproof AI Cloudで修正を開始し、GitHubにプルリクエストを作成 |
| `policies:read`、`policies:write` | ポリシー・マシン・デプロイメントの参照、またはポリシーの公開・デプロイ・ロールバック |

セッションやイベントのリンク作成、ドキュメント検索など、組織データを参照しないツールは権限不要です。

AIツールはAPIキー、ユーザー、設定、組織管理に触れることはできず、イベントの送信も行えません。

## 変更の承認

クライアントがプロンプトを表示できる場合、書き込み操作の前に確認が求められます。変更内容が表示されるので、**Approve this change** を選択して続行します。拒否するか約4分以内に回答しなかった場合、何も変更されません。クライアントによっては1分で待機を停止する場合があるため、速やかに回答してください。

<Warning>
  プロンプトに対応していないクライアントでは確認が行われず、クライアントが呼び出しを行った時点で書き込みが実行されます。その場合、クライアント自身の確認が唯一の承認手段となりますので、書き込みツールでは必ず有効にしておいてください。
</Warning>

## 接続済みアプリと失効

**Settings → Integrations → MCP** には、現在の組織内の接続済みアプリが権限と最終使用日時とともに一覧表示されます。**Revoke** を選択すると即座にアクセスを遮断します。クライアント側でサーバーを削除しても接続が失効します。

組織ごとに最大5つのアプリを接続できます。同じアプリを再度接続すると、以前の接続が置き換えられます。

## セルフホスト型デプロイメント

接続時に **Self-hosted Failproof AI Cloud** を選択し、サインインに使用するアドレスを入力してください。デプロイメントは公開HTTPSでアクセスできる必要があります。

ツールの呼び出しと結果は、AIツールとデプロイメントの間でホスト型のFailproof AIゲートウェイを経由します。ゲートウェイはそれらを保存しません。

## データの取り扱い

結果は接続したAIツールに送られ、そのツールのプロバイダーが自社の規約に基づいて処理します。各ツール呼び出しについて、Failproof AIはツール名・結果・処理時間・組織のみをログに記録し、引数や結果の内容は記録しません。詳しくは[プライバシーポリシー](https://befailproof.ai/privacy/)をご確認ください。

## トラブルシューティング

| 表示される内容 | 対処方法 |
| --- | --- |
| "Started in another browser" | クライアントが開いたブラウザでCookieを許可した状態でサインインを完了し、クライアントから再度開始してください |
| **Allow** 後にエラーが表示される | リンクは1回限りで有効で、10分後に失効します。クライアントから再度開始してください |
| 期待していたツールが表示されない | この組織でその権限を持っていません。管理者に確認してください。権限を取得したら再接続は不要です |
| クライアントが繰り返しサインインを求める | 接続が失効しているか、組織から外れているか、90日間未使用の状態です。再度接続してください |
| "You have 5 connected apps" と表示される | **Settings → Integrations → MCP** でいずれかを失効させてから再接続してください |

解決しない場合は [support@befailproof.ai](mailto:support@befailproof.ai) までメールでお問い合わせください。
