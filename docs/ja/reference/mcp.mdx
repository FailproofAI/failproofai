AIツールをFailproof AI Cloudに接続し、エージェントのデータを操作できます。セッションやイベントの照会、読み取り専用SQLの実行、ダッシュボード・アラート・インサイト・監査・ポリシーの参照が可能です。また、必要な権限を持っている場合は、アラートの作成やポリシーのデプロイといった変更操作も行えます。

すべての呼び出しは**あなた自身の**権限で実行され、接続時に選択した**1つの**組織内に限定されます。

ホスト型・セルフホスト型を問わず、アドレスは共通です：

```text
https://gateway.befailproof.ai/mcp
```

## クライアントの接続

クライアントにアドレスを追加します。初めてツールを使用すると、ブラウザが開きます。Failproof AI Cloudの場所を選択してサインインし、組織を1つ選んで**許可**をクリックしてください。**キャンセル**を選ぶと接続されません。

ページにはアプリ名とリダイレクト先が表示されます。独自のウェブアドレスで識別されていないアプリは**未確認アプリ**と表示されるため、自分のクライアントから操作を開始した場合のみ続行してください。

<Tabs>
  <Tab title="Claude">
    claude.aiまたはClaude Desktopで、**設定 → コネクター → カスタムコネクターを追加**に移動します。名前に `Failproof AI` と入力し、アドレスを入力して**追加**、次に**接続**を選択します。

    TeamプランおよびEnterpriseプランでは、オーナーが先に組織用のコネクターを追加します。その後、各メンバーが自分のアカウントを接続します。
  </Tab>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http failproofai https://gateway.befailproof.ai/mcp
    ```

    次に、Claude Code内で `/mcp` を実行し、`failproofai` を選択して**認証**をクリックします。
  </Tab>
  <Tab title="Cursor">
    `~/.cursor/mcp.json`、またはプロジェクトの `.cursor/mcp.json` に以下を追加します：

    ```json
    {
      "mcpServers": {
        "failproofai": { "url": "https://gateway.befailproof.ai/mcp" }
      }
    }
    ```

    サーバーの横にCursorが**ログインが必要**と表示します。それを選択してサインインします。
  </Tab>
  <Tab title="Codex">
    `~/.codex/config.toml` に以下を追加します：

    ```toml
    [mcp_servers.failproofai]
    url = "https://gateway.befailproof.ai/mcp"
    ```

    次に `codex mcp login failproofai` を実行します。
  </Tab>
  <Tab title="その他のクライアント">
    OAuthを使ったStreamable HTTP経由のリモートMCPサーバーをサポートするクライアントであれば使用できます。上記のアドレスを設定してください。クライアントIDやシークレットの設定は不要です。
  </Tab>
</Tabs>

## 接続ごとに1つの組織

1つの接続は、選択した組織内でのみ機能します。2つの組織を使用するには、`failproofai-acme` や `failproofai-sandbox` のように異なる名前でサーバーを2回追加し、それぞれ別の組織に接続してください。

デモ組織は接続を受け付けません。代わりに自分の組織を選択してください。

## 権限

接続できる操作は、組織内であなたが持つ権限の範囲内に限られます。権限はあなたの現在の権限設定に従います。管理者が権限を追加するとツールもそれを取得し、権限を削除するとツールは次回の呼び出し時にその権限を失います。

| 権限 | ツールでできること |
| --- | --- |
| `events:read` | イベントの一覧表示、セッションの概要確認、エージェントと環境の一覧表示 |
| `evaluations:read` | セッションの一覧表示、評価結果とジョブの確認・要約 |
| `evaluations:trigger` | 評価の作成、新バージョンの公開・有効化・無効化、バックフィル、セッションの再評価 |
| `dashboards:read`、`dashboards:write` | ダッシュボードの参照、または作成・名前変更・クエリの追加 |
| `queries:read`、`queries:write` | 保存済みクエリの参照、または保存・編集 |
| `queries:run` | 読み取り専用SQLクエリの実行とクエリスキーマの確認 |
| `alerts:read`、`alerts:write` | アラートの参照、または作成・編集・一時停止・削除・テスト |
| `issues:read` | インサイトの参照、確認、コメント |
| `issues:create` | アラートに対するインサイトの作成 |
| `issues:close` | インサイトの解決とクローズ |
| `audits:read`、`audits:write` | 監査・実行・検出結果の参照、または監査の作成・編集・実行開始 |
| `code_fixes:read` | インサイトの修正方法の確認、および自分のエージェントで修正するためのコンテキストの取得 |
| `code_fixes:write` | Failproof AI Cloudで修正を開始し、GitHubにプルリクエストを作成 |
| `policies:read`、`policies:write` | ポリシー・マシン・デプロイメントの参照、またはポリシーの公開・デプロイ・ロールバック |

セッションやイベントのリンク作成、ドキュメント検索など、組織データを読み取らないツールは権限不要です。

AIツールはAPIキー、ユーザー、設定、組織管理に一切アクセスできず、イベントの送信も行えません。

## 変更の承認

クライアントがプロンプトを表示できる場合、書き込み操作は事前に確認を求めます。変更内容が表示されるので、**この変更を承認する**を選択して続行してください。拒否するか約4分以内に応答しない場合、変更は行われません。クライアントによっては1分で待機を停止する場合があるため、速やかに応答してください。

<Warning>
  プロンプトをサポートしていないクライアントは確認を求めず、クライアントが呼び出しを行った時点で書き込みが実行されます。その場合、クライアント自体の確認が唯一の防護手段となるため、書き込みツールを使用する際は必ず確認機能を有効にしてください。
</Warning>

## 接続済みアプリと接続の取り消し

**設定 → インテグレーション → MCP** に、現在の組織内の接続済みアプリが権限と最終使用日時とともに一覧表示されます。**取り消し**を選択するとアプリへのアクセスを即座に遮断できます。クライアントからサーバーを削除しても接続が取り消されます。

1つの組織につき最大5つのアプリを接続できます。同じアプリを再接続すると、以前の接続が置き換えられます。

## セルフホスト型デプロイメント

接続時に**セルフホスト型Failproof AI Cloud**を選択し、サインイン時に使用するアドレスを入力します。デプロイメントは公開HTTPSでアクセス可能である必要があります。

ツール呼び出しとその結果は、AIツールとデプロイメントの間でホスト型Failproof AIゲートウェイを経由します。ゲートウェイはデータを保存しません。

## データの取り扱い

結果は接続したAIツールに送信され、そのツールのプロバイダーが独自の規約のもとで処理します。各ツール呼び出しについて、Failproof AIはツール名、実行結果、処理時間、組織名のみを記録します。引数や結果は記録されません。詳しくは[プライバシーポリシー](https://befailproof.ai/privacy/)をご覧ください。

## トラブルシューティング

| 表示されるメッセージ | 対処方法 |
| --- | --- |
| 「別のブラウザで開始されました」 | クライアントが開いたブラウザ（Cookieを許可した状態）でサインインを完了し、クライアントから再度開始してください |
| **許可**後にエラーが発生する | リンクは1回のみ有効で10分で期限切れになります。クライアントから再度開始してください |
| 期待していたツールが表示されない | この組織でその権限を持っていません。管理者に確認してください。権限を取得後、再接続は不要です |
| クライアントが繰り返しサインインを要求する | 接続が取り消されたか、組織を退出したか、90日間未使用の状態です。再度接続してください |
| 「接続済みアプリが5つあります」 | **設定 → インテグレーション → MCP** で1つ取り消してから、再度接続してください |

それでも解決しない場合は、[support@befailproof.ai](mailto:support@befailproof.ai) までメールでお問い合わせください。
