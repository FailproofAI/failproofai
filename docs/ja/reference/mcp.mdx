AIツールをFailproof AI Cloudに接続し、エージェントのデータを活用しましょう。ツールからセッションやイベントのクエリ、読み取り専用SQL、ダッシュボード、アラート、イシュー、監査、ポリシーの参照が可能です。また、権限を持っている場合は、アラートの作成やポリシーのデプロイといった変更操作も行えます。

すべての呼び出しは**あなた自身**のパーミッションで、接続時に選択した**1つ**の組織に対して実行されます。

ホスト型・セルフホスト型を問わず、共通のアドレスを使用します：

```text
https://gateway.befailproof.ai/mcp
```

## クライアントの接続

クライアントにアドレスを追加してください。ツールを初めて使用する際にブラウザが開きます。Failproof AI Cloudの場所を選択してサインインし、組織を1つ選んで**Allow**をクリックしてください。**Cancel**を選択すると何も接続されません。

ページにはアプリ名とリダイレクト先が表示されます。独自のウェブアドレスで識別されていないアプリは**unverified app**と表示されるため、自分のクライアントから操作を開始した場合のみ続行してください。

<Tabs>
  <Tab title="Claude">
    claude.aiまたはClaude Desktopで、**Settings → Connectors → Add custom connector**に移動します。名前を`Failproof AI`に設定し、アドレスを入力して**Add**、次に**Connect**を選択します。

    TeamプランおよびEnterpriseプランでは、オーナーがまず組織全体のコネクターを追加します。その後、各メンバーが自分のアカウントを接続します。
  </Tab>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http failproofai https://gateway.befailproof.ai/mcp
    ```

    次に、Claude Code内で`/mcp`を実行し、`failproofai`を選択して**Authenticate**を選びます。
  </Tab>
  <Tab title="Cursor">
    `~/.cursor/mcp.json`またはプロジェクトの`.cursor/mcp.json`に以下を追加してください：

    ```json
    {
      "mcpServers": {
        "failproofai": { "url": "https://gateway.befailproof.ai/mcp" }
      }
    }
    ```

    Cursorのサーバー一覧に**Needs login**と表示されます。それを選択してサインインしてください。
  </Tab>
  <Tab title="Codex">
    `~/.codex/config.toml`に以下を追加してください：

    ```toml
    [mcp_servers.failproofai]
    url = "https://gateway.befailproof.ai/mcp"
    ```

    次に、`codex mcp login failproofai`を実行します。
  </Tab>
  <Tab title="その他のクライアント">
    OAuthを使用したStreamable HTTP経由のリモートMCPサーバーをサポートするクライアントであれば使用できます。上記のアドレスを設定してください。クライアントIDやシークレットの設定は不要です。
  </Tab>
</Tabs>

## 接続ごとに1組織

1つの接続は、選択した組織内でのみ動作します。2つの組織を使用する場合は、`failproofai-acme`や`failproofai-sandbox`のように異なる名前でサーバーを2回追加し、それぞれ別の組織に接続してください。

デモ組織は接続を受け付けません。自分の組織を選択してください。

## パーミッション

接続は、組織内であなたが持つ権限の範囲内で、以下に定めた操作を実行できます。現在のパーミッションに従って動作するため、管理者が権限を追加すればツールもそれを取得し、権限を剥奪されれば次の呼び出し時にツールも失います。

| パーミッション | ツールでできること |
| --- | --- |
| `events:read` | イベントの一覧表示、セッションの概要確認、エージェントと環境の一覧表示 |
| `evaluations:read` | セッションの一覧表示、評価結果とジョブの確認・要約 |
| `evaluations:trigger` | 評価の作成、新バージョンの公開、有効/無効の切り替え、バックフィル、セッションの再評価 |
| `dashboards:read`、`dashboards:write` | ダッシュボードの閲覧、または作成・名前変更・クエリの追加 |
| `queries:read`、`queries:write` | 保存済みクエリの閲覧、または保存・編集 |
| `queries:run` | 読み取り専用SQLクエリの実行、クエリスキーマの確認 |
| `alerts:read`、`alerts:write` | アラートの閲覧、または作成・編集・一時停止・削除・テスト |
| `issues:read` | イシューの閲覧、承認、コメント |
| `issues:create` | アラートに対するイシューの作成 |
| `issues:close` | イシューの解決とクローズ |
| `audits:read`、`audits:write` | 監査・実行・検出結果の閲覧、または監査の作成・編集・実行開始 |
| `code_fixes:read` | イシューの修正方法の確認、自分のエージェントで修正するためのコンテキストの取得 |
| `code_fixes:write` | Failproof AI Cloudで修正を開始（GitHubにプルリクエストが作成されます） |
| `policies:read`、`policies:write` | ポリシー・マシン・デプロイメントの閲覧、またはポリシーの公開・デプロイ・ロールバック |

組織データを参照しないツールはパーミッションが不要です（セッション・イベントリンクの生成、このドキュメントの検索など）。

AIツールは、APIキー、ユーザー、設定、組織管理に対して操作できず、イベントの送信も行えません。

## 変更の承認

クライアントがプロンプトを表示できる場合、書き込み操作は事前に確認を求めます。変更内容が表示されるので、**Approve this change**を選択して続行してください。拒否するか約4分以内に回答しない場合、何も変更されません。クライアントによっては1分で待機を終了するため、すみやかに回答してください。

<Warning>
  プロンプトをサポートしないクライアントでは確認が行われず、クライアントが呼び出した時点で書き込みが実行されます。その場合、クライアント自身の確認が唯一の安全策となるため、書き込みツールでは必ず有効にしておいてください。
</Warning>

## 接続済みアプリの確認と取り消し

**Settings → Integrations → MCP**では、現在の組織に接続されているアプリの一覧が、パーミッションと最終使用日時とともに表示されます。**Revoke**をクリックするとアプリへのアクセスが即座に無効になります。クライアントからサーバーを削除しても接続が取り消されます。

1つの組織につき最大5つのアプリを接続できます。同じアプリを再接続すると、以前の接続が上書きされます。

## セルフホスト型デプロイメント

接続時に**Self-hosted Failproof AI Cloud**を選択し、サインインに使用するアドレスを入力してください。デプロイメントはパブリックHTTPS経由でアクセス可能である必要があります。

ツール呼び出しとその結果は、AIツールとデプロイメントの間でホスト型Failproofゲートウェイを経由しますが、ゲートウェイはこれらを保存しません。

## データの取り扱いについて

結果は接続したAIツールに送信され、そのツールのプロバイダーが独自の規約に従って処理します。各ツール呼び出しについて、Failproof AIはツール名、実行結果、処理時間、組織名のみをログに記録します。引数や結果の内容は記録されません。詳しくは[プライバシーポリシー](https://befailproof.ai/privacy/)をご覧ください。

## トラブルシューティング

| 表示内容 | 対処方法 |
| --- | --- |
| "Started in another browser" | クライアントが開いたブラウザ（Cookieを有効にした状態）でサインインを完了し、クライアントから再度開始してください |
| **Allow**後にエラーが発生する | リンクは1回のみ有効で10分で期限切れになります。クライアントから再度開始してください |
| 期待していたツールが表示されない | この組織でそのパーミッションを持っていません。管理者に依頼してください。権限取得後に再接続は不要です |
| クライアントが何度もサインインを求める | 接続が取り消されたか、組織を退出したか、90日間未使用の状態です。再接続してください |
| "You have 5 connected apps" | **Settings → Integrations → MCP**でいずれかのアプリを取り消してから、再接続してください |

解決しない場合は、[support@befailproof.ai](mailto:support@befailproof.ai)までメールでお問い合わせください。
