AIツールをFailproof AI Cloudに接続し、エージェントのデータを操作できます。セッションやイベントの照会、読み取り専用SQLの実行、ダッシュボード・アラート・インサイト・監査・ポリシーの閲覧が可能です。また、必要な権限を持っている場合は、アラートの作成やポリシーのデプロイといった変更操作も行えます。

すべての呼び出しは**あなた自身の**権限で、接続時に選択した**1つ**の組織内で実行されます。

ホスト型・セルフホスト型を問わず、共通のアドレスは以下の通りです：

```text
https://gateway.befailproof.ai/mcp
```

## クライアントの接続

クライアントにアドレスを追加します。ツールを初めて使用する際にブラウザが開きます。Failproof AI Cloudの場所を選択してサインインし、組織を1つ選択して **Allow** をクリックします。**Cancel** をクリックすると何も接続されません。

ページには、アプリ名とリダイレクト先が表示されます。独自のWebアドレスで識別されていないアプリは**未確認のアプリ**と表示されるため、自分のクライアントから操作を開始した場合のみ続行してください。

<Tabs>
  <Tab title="Claude">
    claude.aiまたはClaude Desktopで、**Settings → Connectors → Add custom connector** に移動します。名前に `Failproof AI` と入力し、アドレスを入力して **Add**、次に **Connect** を選択します。

    TeamプランおよびEnterpriseプランでは、オーナーがまず組織全体のコネクターを追加します。その後、各メンバーが自分自身のアカウントを接続します。
  </Tab>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http failproofai https://gateway.befailproof.ai/mcp
    ```

    次に、Claude Code内で `/mcp` を実行し、`failproofai` を選択して **Authenticate** をクリックします。
  </Tab>
  <Tab title="Cursor">
    `~/.cursor/mcp.json`、またはプロジェクトの `.cursor/mcp.json` に以下を追加します：

    ```json
    {
      "mcpServers": {
        "failproofai": { "url": "https://gateway.befailproof.ai/mcp" }
      }
    }
    ```

    Cursorのサーバー一覧に **Needs login** と表示されます。それを選択してサインインします。
  </Tab>
  <Tab title="Codex">
    `~/.codex/config.toml` に以下を追加します：

    ```toml
    [mcp_servers.failproofai]
    url = "https://gateway.befailproof.ai/mcp"
    ```

    次に `codex mcp login failproofai` を実行します。
  </Tab>
  <Tab title="その他のクライアント">
    OAuthを使用したStreamable HTTP経由のリモートMCPサーバーをサポートするクライアントであれば使用できます。上記のアドレスを設定してください。クライアントIDやシークレットの設定は不要です。
  </Tab>
</Tabs>

## 接続ごとに1つの組織

1つの接続は、選択した組織内でのみ動作します。2つの組織を使用するには、`failproofai-acme` や `failproofai-sandbox` のように異なる名前でサーバーを2回追加し、それぞれを別の組織に接続してください。

デモ組織は接続を受け付けません。代わりに自分の組織を選択してください。

## 権限

接続では、あなたがその組織内で実行できる操作を、以下の範囲内で行えます。現在の権限に従って動作するため、管理者が権限を追加するとツールにも反映され、権限が削除されると次の呼び出し時にツールからも失われます。

| 権限 | ツールでできること |
| --- | --- |
| `events:read` | イベントの一覧表示、セッションの概要閲覧、エージェントと環境の一覧表示 |
| `evaluations:read` | セッションの一覧表示、評価結果とジョブの閲覧・要約 |
| `evaluations:trigger` | 評価の作成、新バージョンの公開、オン/オフの切り替え、バックフィル、セッションの再評価 |
| `dashboards:read`、`dashboards:write` | ダッシュボードの閲覧、または作成・名前変更・クエリの追加 |
| `queries:read`、`queries:write` | 保存済みクエリの閲覧、または保存・編集 |
| `queries:run` | 読み取り専用SQLクエリの実行とクエリスキーマの閲覧 |
| `alerts:read`、`alerts:write` | アラートの閲覧、または作成・編集・一時停止・削除・テスト |
| `issues:read` | インサイトの閲覧、確認、コメント |
| `issues:create` | アラートに対するインサイトの作成 |
| `issues:close` | インサイトの解決とクローズ |
| `audits:read`、`audits:write` | 監査・実行・検出結果の閲覧、または監査の作成・編集・実行の開始 |
| `code_fixes:read` | インサイトの修正方法の確認、および自分のエージェントで修正するためのコンテキストの取得 |
| `code_fixes:write` | Failproof AI Cloudでの修正の開始（GitHubにプルリクエストが作成されます） |
| `policies:read`、`policies:write` | ポリシー・マシン・デプロイメントの閲覧、またはポリシーの公開・デプロイ・ロールバック |

組織のデータを読み取らないツールは権限が不要です。セッションやイベントのリンク作成、このドキュメントの検索などが該当します。

AIツールは、APIキー、ユーザー、設定、組織の管理に触れることは一切できず、イベントを送信することもできません。

## 変更の承認

クライアントがプロンプトを表示できる場合、書き込み操作の前に確認を求められます。変更内容が表示されるので、**Approve this change** を選択して続行します。拒否するか約4分以内に回答しない場合、何も変更されません。クライアントによっては1分で待機を停止することがあるため、速やかに回答してください。

<Warning>
  プロンプトをサポートしないクライアントでは確認が行われず、クライアントが呼び出しを行うとすぐに書き込みが実行されます。その場合、クライアント自身の確認が唯一の安全策となるため、書き込みツールでは必ず有効にしておいてください。
</Warning>

## 接続済みアプリと接続の取り消し

**settings → integrations → MCP** には、現在の組織における接続済みアプリの一覧が、権限と最終使用日時とともに表示されます。**Revoke** をクリックするとアプリへのアクセスが即座に切断されます。クライアントからサーバーを削除しても接続が取り消されます。

1つの組織につき最大5つのアプリを接続できます。同じアプリを再接続すると、以前の接続が置き換えられます。

## セルフホスト型デプロイメント

接続時に **Self-hosted Failproof AI Cloud** を選択し、サインインに使用するアドレスを入力します。デプロイメントは公開HTTPSでアクセス可能である必要があります。

ツールの呼び出しとその結果は、AIツールとデプロイメント間の通信においてホスト型のFailproof AIゲートウェイを経由します。ゲートウェイはそれらを保存しません。

## データの取り扱い

結果は接続したAIツールに送信され、そのツールのプロバイダーが独自の規約のもとで処理します。各ツール呼び出しについて、Failproof AIはツール名・結果・所要時間・組織をログに記録します。引数や結果は記録されません。詳しくは[プライバシーポリシー](https://befailproof.ai/privacy/)をご覧ください。

## トラブルシューティング

| 表示内容 | 対処方法 |
| --- | --- |
| 「Started in another browser」 | クライアントが開いたブラウザ（Cookieを許可した状態）でサインインを完了し、クライアントから再度開始してください |
| **Allow** 後にエラーが発生する | リンクは1回のみ有効で10分で期限切れになります。クライアントから再度開始してください |
| 期待していたツールが表示されない | この組織でその権限を持っていません。管理者に依頼してください。権限を取得後、再接続は不要です |
| クライアントが繰り返しサインインを要求する | 接続が取り消されたか、組織を退出したか、90日間未使用だった可能性があります。再接続してください |
| 「You have 5 connected apps」と表示される | **settings → integrations → MCP** で1つ取り消してから再接続してください |

解決しない場合は、[support@befailproof.ai](mailto:support@befailproof.ai) までメールでお問い合わせください。
