SlackからFailproof Assistantに質問できます。チャンネルでアプリにメンションするか、ダイレクトメッセージを送るか、`/failproof <質問>` を使ってください。回答には**あなた自身の** Failproof AI 権限が使用され、チャートはスレッドに届き、何かを変更する操作は事前に承認を求めます。

公式アプリは1つです。Failproof AI Cloudがホステッドでもセルフホステッドでも、動作は同じです。

<Note>
  回答はAIモデルによって生成されるため、不正確な場合があります。重要な情報はリンクされたソースデータで必ず確認してください。
</Note>

## ワークスペースを接続する

Failproof AIで `settings:write` 権限が必要です。Slack側では、ワークスペースの管理者またはオーナーであるか、アプリを追加する担当者である必要があります。

<Tabs>
  <Tab title="Failproof AIから">
    1. **設定 → インテグレーション** に移動し、**Slackに追加** を選択します。
    2. SlackでアプリをApproveします。
    3. Failproof AIに戻り、ワークスペースを組織に接続することを確認します。
  </Tab>
  <Tab title="Slackから">
    1. アプリを追加し、**ホーム** タブを開きます。
    2. **FailproofAI Cloudで続ける** を選択するか、**自分のURLを使用** を選択してサインインするアドレスを入力します。
    3. 続けるボタンを選択し、サインインして組織を選び、確認します。リンクは1回限り有効で、10分後に失効します。
  </Tab>
</Tabs>

1つのワークスペースは1つの組織に、1つの組織は1つのワークスペースに接続されます。

アカウントをお持ちでない場合は、まず[こちらで作成](https://app.befailproof.ai/login)してから接続してください。

## Slack上でのあなたのアイデンティティ

初めて質問すると、アプリがどのメンバーであるかを特定します。

- **メールアドレスによる自動識別**：接続済みワークスペースの正規メンバーであり、SlackのメールアドレスがVerify済みで、そのメールアドレスを使用する組織メンバーがちょうど1人の場合。
- **上記以外の場合**：プライベートの **アカウントをリンク** ボタンが表示され、Failproof AIを開いてSlackユーザーをアカウントに紐付けます。

## 質問する

| 場所 | 方法 |
| --- | --- |
| チャンネル | アプリにメンションする。続けてやり取りする場合はスレッド内で返信（メンション不要） |
| ダイレクトメッセージ | アプリにメッセージを送る |
| アプリが参加しているグループダイレクトメッセージ | メンションし、スレッドで返信して続ける |
| Slack Connectチャンネル | アプリにメンションする |
| アプリが参加しているすべての会話 | `/failproof <質問>` で回答付きスレッドを開始する |
| `/failproof help` | アプリの機能を確認する |
| `/failproof status` | 接続している組織とリンクしているユーザーを確認する |
| `/failproof link` | リンクされているFailproof AIアカウントを確認する |

1つのスレッドが1つの会話となります。同僚が同じスレッドでアプリにメンションすると、それぞれの権限に基づいて回答が返されます。スレッドを開始した本人だけが、メンションなしでスレッドを続けられます。

回答がデータの場合、アプリはチャートまたはテーブルを投稿し、Failproof AIで開くリンクを添えます。

## 変更を承認する

アシスタントが行うすべての変更には、まず **承認** と **キャンセル** ボタンが表示され、**承認** 前にSlackがもう一度確認を求めます。ボタンに回答できるのは質問した本人のみで、5分後に有効期限が切れ、変更はその人の権限で実行されます。

Slackから、アシスタントは権限を持っている場合に限り、保存済みクエリとダッシュボード、評価、アラート、監査、Issues、ポリシーを変更したり、コード修正を提案したりできます。APIキー、ユーザー、設定は変更できません。

## リンクプレビュー

Slackに貼り付けたFailproof AIのIssue、セッション、評価のリンクは、ホステッドFailproof AI Cloudでカードとして展開されます。カードには、それを表示させた人が閲覧できる情報のみが表示されます。セルフホステッドアドレスへのリンクは展開されませんが、アシスタント自身の回答内のカードは引き続き表示されます。

## Slack Connectチャンネル

別のワークスペースのメンバーも、組織のメンバーであればアカウントをリンクした後にアプリを使用できます。回答は会話内の全員に表示されます（組織のメンバーでない人も含む）。回答を求める際は、全員が見られる場所であることを意識してください。

アプリが回答するのは、チャンネル内の他のすべてのワークスペースに組織にリンクされているメンバーが少なくとも1人いる場合に限ります。それまでは、質問した人に理由を伝えます。

## アプリが要求するSlack権限

| Slack権限 | 理由 |
| --- | --- |
| `app_mentions:read` | アプリへのメンションを検知する |
| `channels:history`、`groups:history`、`im:history`、`mpim:history` | ダイレクトメッセージおよびアプリのスレッドへの返信を受信する。アプリはそれ以外のメッセージを無視し、過去のメッセージを読み取ることはない |
| `channels:read`、`groups:read`、`im:read`、`mpim:read` | 会話の種類を確認し、回答の閲覧範囲を把握する |
| `chat:write` | 回答と承認ボタンを投稿する |
| `commands` | `/failproof` を提供する |
| `files:write` | チャートを投稿する |
| `links:read`、`links:write` | 貼り付けられたFailproof AIリンクのプレビューを表示する |
| `users:read`、`users:read.email` | Failproof AIアカウントと照合し、名前を表示する |

## 接続を解除する

**設定 → インテグレーション** に移動して **切断** を選択するか、アプリの **ホーム** タブで **切断** を使用するか、Slackからアプリを削除してください。

いずれの操作でも、ワークスペースの接続、ボットトークン、リンクされたアカウント、スレッド記録が削除されます。過去のSlack会話はダッシュボードで引き続き閲覧できます。その後、組織は任意のワークスペースをすぐに接続できます。

## データとプライバシー

質問と回答は、スレッドを開始した人に紐付けられた会話として、組織のダッシュボードに保存されます。SlackのデータがAIモデルの学習に使用されることはありません。アプリが受け取るデータと保存期間については、[プライバシーポリシー](https://befailproof.ai/privacy/)をご確認ください。

## トラブルシューティング

| 表示されるメッセージ | 対処方法 |
| --- | --- |
| "This workspace isn't connected to a FailproofAI Cloud yet." | ワークスペース管理者がアプリの **ホーム** タブを開いて選択する |
| "This link expired or was already used." | **ホーム** タブでCloudを再選択して新しいリンクを取得する |
| "This org is already connected to a Slack workspace." | 先に設定から切断する |
| "That Slack workspace is connected to another org." | 先にその組織から切断する |
| "Link your account to use the assistant." | ボタンを選択してFailproof AIで確認する |
| グループダイレクトメッセージでアプリが応答しない | Slackでアプリを再追加してグループ権限を付与する。既存の接続は維持される |
| "I won't post answers from your organization here" | そのワークスペースで組織のメンバーになっている人がアプリにメンションし、アカウントをリンクする |

それでも解決しない場合は、[support@befailproof.ai](mailto:support@befailproof.ai) までメールでお問い合わせください。
