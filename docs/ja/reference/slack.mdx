Slackから[Failproof Assistant](/ja/sessions/assistant)に質問できます。チャンネルでアプリをメンションするか、ダイレクトメッセージを送るか、`/failproof <質問>` を使ってください。回答には**ご自身の** Failproof AI の権限が使われ、グラフはスレッドに届き、何かを変更する操作は事前に承認を求めます。

公式アプリは1つのみです。Failproof AI Cloudがホスティングされているかセルフホストされているかにかかわらず、同じように動作します。

<Note>
  回答はAIモデルによって生成されるため、不正確な場合があります。重要な内容はリンク先のソースデータで必ず確認してください。
</Note>

## ワークスペースを接続する

Failproof AI で `settings:write` 権限が必要です。Slack 側では、ワークスペースの管理者またはオーナーであるか、アプリを追加する担当者である必要があります。

<Tabs>
  <Tab title="Failproof AI から">
    1. **設定 → インテグレーション** に移動し、**Slackに追加** を選択します。
    2. Slackでアプリを承認します。
    3. Failproof AI に戻り、ワークスペースを組織に接続することを確認します。
  </Tab>
  <Tab title="Slack から">
    1. アプリを追加したら、**ホーム** タブを開きます。
    2. **FailproofAI Cloudで続ける** を選択するか、**独自のURLを使用** を選択してサインインするアドレスを入力します。
    3. 続けるボタンを選択し、サインインして組織を選び、確認します。リンクは1回のみ有効で、10分後に期限切れになります。
  </Tab>
</Tabs>

1つのワークスペースは1つの組織に、1つの組織は1つのワークスペースにのみ接続できます。

アカウントをお持ちでない場合は、まず[アカウントを作成](https://app.befailproof.ai/login)してから接続してください。

## Slackでのあなたの識別

初めて質問する際、アプリは次の方法であなたのメンバーを特定します。

- **メールアドレスによる自動識別**: 接続されたワークスペースの正規メンバーであり、SlackのメールアドレスがそのSlackアカウントで確認済みで、かつその組織内で同じメールアドレスを使用するメンバーがちょうど1人の場合。
- **それ以外の場合**: Failproof AI を開いてSlackユーザーとアカウントを紐付けるための、プライベートな **アカウントを紐付ける** ボタンが表示されます。

## 質問する

| 場所 | 方法 |
| --- | --- |
| チャンネル | アプリをメンションする。続けて質問する場合はそのスレッドに返信（メンション不要） |
| ダイレクトメッセージ | アプリにメッセージを送る |
| アプリが参加しているグループダイレクトメッセージ | メンションし、続けてスレッドに返信する |
| Slack Connectチャンネル | アプリをメンションする |
| アプリが参加している会話 | `/failproof <質問>` で回答付きのスレッドを開始する |
| `/failproof help` | アプリの機能を確認する |
| `/failproof status` | 接続中の組織と自分のリンク状況を確認する |
| `/failproof link` | 紐付けられているFailproof AIアカウントを確認する |

1つのスレッドが1つの会話です。同僚が同じスレッドでアプリをメンションすると、それぞれの権限に基づいた回答が返されます。スレッドを始めた人のみ、メンションなしで会話を続けられます。

回答がデータの場合、アプリはグラフまたは表を投稿し、Failproof AI で開くリンクを添えます。

## 変更を承認する

アシスタントが行うすべての変更には、まず **承認** と **キャンセル** ボタンが表示され、**承認** の前にSlackがもう一度確認を求めます。ボタンに回答できるのは質問した本人のみで、ボタンは5分後に期限切れになります。変更はその人の権限で実行されます。

Slackからアシスタントが変更できるのは、保存済みクエリとダッシュボード、評価、アラート、監査、課題、ポリシーへの変更、およびコード修正の提案です（それぞれ必要な権限を持っている場合）。APIキー、ユーザー、設定は変更できません。

## リンクプレビュー

ホスティングされているFailproof AI CloudのSlackに貼り付けたFailproof AIの課題、セッション、評価のリンクは、カードとして展開されます。カードには、展開をトリガーした人が閲覧できる情報のみが表示されます。セルフホストのアドレスへのリンクは展開されませんが、アシスタント自身の回答に含まれるカードは引き続き表示されます。

## Slack Connectチャンネル

別のワークスペースのユーザーも、組織のメンバーであり、アカウントを紐付けていれば、アプリを使用できます。回答は会話内の全員（組織のメンバーでない人も含む）に表示されるため、全員が見られる場所での質問に注意してください。

チャンネル内の他のすべてのワークスペースに組織と紐付けているメンバーがいる場合のみ、アプリは回答します。それまでの間は、質問した人に理由を伝えます。

## アプリが要求するSlack権限

| Slack権限 | 理由 |
| --- | --- |
| `app_mentions:read` | アプリがメンションされたことを検知するため |
| `channels:history`, `groups:history`, `im:history`, `mpim:history` | ダイレクトメッセージとアプリのスレッドへの返信を受け取るため。アプリはその他のメッセージを無視し、過去の会話履歴を読み取ることはありません |
| `channels:read`, `groups:read`, `im:read`, `mpim:read` | どの種類の会話にいるかを確認し、回答が誰に見えるかを把握するため |
| `chat:write` | 回答と承認ボタンを投稿するため |
| `commands` | `/failproof` を提供するため |
| `files:write` | グラフを投稿するため |
| `links:read`, `links:write` | 貼り付けたFailproof AIリンクのプレビューを表示するため |
| `users:read`, `users:read.email` | あなたをFailproof AIアカウントに紐付け、名前を表示するため |

## 切断する

**設定 → インテグレーション** に移動して **切断** を選択するか、アプリの **ホーム** タブで **切断** を選択するか、Slackからアプリを削除してください。

これらのいずれかを行うと、ワークスペースの接続、ボットトークン、紐付けられたアカウント、スレッドの記録が削除されます。過去のSlack会話はダッシュボードで引き続き閲覧できます。その後、組織は任意のワークスペースをすぐに接続できます。

## データとプライバシー

質問と回答は、スレッドを開始した人のアカウントの下で、組織のダッシュボードに会話として保存されます。SlackのデータはAIモデルのトレーニングに使用されることはありません。アプリが受け取る情報と保持期間については、[プライバシーポリシー](https://befailproof.ai/privacy/)をご覧ください。

## トラブルシューティング

| 表示されるメッセージ | 対処方法 |
| --- | --- |
| 「このワークスペースはまだFailproofAI Cloudに接続されていません。」 | ワークスペース管理者がアプリの **ホーム** タブを開いて接続先を選択する |
| 「このリンクは期限切れか、すでに使用済みです。」 | **ホーム** タブで再度Cloudを選択して新しいリンクを取得する |
| 「この組織はすでにSlackワークスペースに接続されています。」 | 設定で先に切断する |
| 「そのSlackワークスペースは別の組織に接続されています。」 | その組織から先に切断する |
| 「アシスタントを使用するにはアカウントを紐付けてください。」 | ボタンを選択し、Failproof AI で確認する |
| グループダイレクトメッセージでアプリが回答しない | Slackでアプリを再度追加してグループ権限を付与する。接続は維持される |
| 「あなたの組織からの回答をここに投稿しません」 | そのワークスペースで組織のメンバーでもある人がアプリをメンションし、アカウントを紐付ける |

解決しない場合は、[support@befailproof.ai](mailto:support@befailproof.ai) までメールでお問い合わせください。
