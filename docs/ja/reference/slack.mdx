Slackから[Failproof Assistant](/ja/sessions/assistant)に質問できます。チャンネルでアプリをメンションするか、ダイレクトメッセージを送るか、`/failproof <質問>` を使用してください。回答には**あなた自身の** Failproof AI 権限が使用され、グラフはスレッドに届き、何かを変更するような操作はすべて事前に承認を求めます。

公式アプリは1つです。Failproof AI Cloud がホスト型でも自己ホスト型でも同様に動作します。

<Note>
  回答はAIモデルによって生成されるため、不正確な場合があります。重要な内容はリンク先のソースデータで必ず確認してください。
</Note>

## ワークスペースを接続する

Failproof AI で `settings:write` 権限が必要です。Slack 側では、ワークスペースの管理者またはオーナーであるか、アプリを追加する担当者である必要があります。

<Tabs>
  <Tab title="Failproof AI から接続する">
    1. **Settings → Integrations** に移動し、**Add to Slack** を選択します。
    2. Slack でアプリを承認します。
    3. Failproof AI に戻り、ワークスペースを組織に接続することを確認します。
  </Tab>
  <Tab title="Slack から接続する">
    1. アプリを追加し、**Home** タブを開きます。
    2. **Continue with FailproofAI Cloud** を選択するか、**Use my own URL** を選択してサインインに使用するアドレスを入力します。
    3. 続行ボタンを選択し、サインインして組織を選び、確認します。リンクは1回のみ有効で、10分後に期限切れになります。
  </Tab>
</Tabs>

1つのワークスペースは1つの組織に、1つの組織は1つのワークスペースに接続されます。

アカウントをお持ちでない場合は、まず[アカウントを作成](https://app.befailproof.ai/login)してから接続してください。

## Slack 上でのあなたの識別

初めて質問する際、アプリは次のようにしてあなたを特定します。

- **メールアドレスによる自動識別**：あなたが接続されたワークスペースの正規メンバーで、Slack のメールアドレスが確認済みであり、組織内でそのメールアドレスを使用しているメンバーが1人だけの場合。
- **それ以外の場合**：Failproof AI を開いて Slack ユーザーをアカウントに紐付ける、プライベートな **Link your account** ボタンが表示されます。

## 質問する

| 場所 | 方法 |
| --- | --- |
| チャンネル | アプリをメンションします。続けるにはそのスレッドに返信するだけで、再度のメンションは不要です |
| ダイレクトメッセージ | アプリにメッセージを送ります |
| アプリが参加しているグループダイレクトメッセージ | アプリをメンションし、そのスレッドに返信して会話を続けます |
| Slack Connect チャンネル | アプリをメンションします |
| アプリが参加している任意の会話 | `/failproof <質問>` で回答付きのスレッドが始まります |
| `/failproof help` | アプリでできることを確認します |
| `/failproof status` | 接続されている組織と、あなたが誰として紐付けられているかを確認します |
| `/failproof link` | 紐付けられている Failproof AI アカウントを確認します |

1つのスレッドは1つの会話です。同僚が同じスレッドでアプリをメンションすると、それぞれ自分の権限で回答が得られます。スレッドを開始した本人のみ、メンションなしで会話を続けることができます。

回答がデータである場合、アプリはグラフまたはテーブルを投稿し、Failproof AI で開くためのリンクを表示します。

## 変更を承認する

アシスタントが行うすべての変更は、まず **Approve**（承認）と **Cancel**（キャンセル）ボタンが表示され、**Approve** の前に Slack がもう一度確認を求めます。これらのボタンに回答できるのは質問した本人のみで、ボタンは5分後に期限切れになり、変更はその人の権限で実行されます。

Slack からアシスタントが変更できるのは、権限を持っている場合に限り、保存済みクエリやダッシュボード、評価、アラート、監査、イシュー、ポリシー、およびコード修正の提案です。APIキー、ユーザー、設定は変更できません。

## リンクプレビュー

ホスト型 Failproof AI Cloud では、Slack に貼り付けた Failproof AI のイシュー、セッション、評価のリンクがカードとして展開されます。カードには、展開をトリガーした人が閲覧できる内容のみが表示されます。自己ホスト型アドレスへのリンクは展開されませんが、アシスタント自身の回答内のカードは引き続き表示されます。

## Slack Connect チャンネル

別のワークスペースのメンバーも、組織のメンバーであれば、アカウントを紐付けた後にアプリを使用できます。回答は会話内の全員に表示されます（組織のメンバーでない人も含む）。そのため、全員が見られる場所での質問は内容に注意してください。

アプリは、チャンネル内の他のすべてのワークスペースに組織と紐付けられたメンバーがいる場合にのみ回答します。それまでは、質問者にその理由を伝えます。

## アプリが要求する権限

| Slack の権限 | 理由 |
| --- | --- |
| `app_mentions:read` | アプリへのメンションを検知するため |
| `channels:history`、`groups:history`、`im:history`、`mpim:history` | ダイレクトメッセージやアプリのスレッドへの返信を受け取るため。アプリはその他のメッセージは無視し、過去のメッセージを読むことはありません |
| `channels:read`、`groups:read`、`im:read`、`mpim:read` | 会話の種類を確認し、誰が回答を見られるかを把握するため |
| `chat:write` | 回答と承認ボタンを投稿するため |
| `commands` | `/failproof` を提供するため |
| `files:write` | グラフを投稿するため |
| `links:read`、`links:write` | 貼り付けられた Failproof AI リンクのプレビューを表示するため |
| `users:read`、`users:read.email` | あなたを Failproof AI アカウントと照合し、名前を表示するため |

## 切断する

**Settings → Integrations** に移動して **Disconnect** を選択するか、アプリの **Home** タブで **Disconnect** を使用するか、Slack からアプリを削除します。

いずれの方法でも、ワークスペースの接続、ボットトークン、紐付けられたアカウント、スレッドの記録が削除されます。過去の Slack 会話はダッシュボードで引き続き閲覧できます。組織はその後すぐに任意のワークスペースを接続できます。

## データとプライバシー

質問と回答は、スレッドを開始した人の名前のもとで、組織のダッシュボードに会話として保存されます。Slack のデータが AI モデルのトレーニングに使用されることはありません。アプリが受け取るデータと保持期間については[プライバシーポリシー](https://befailproof.ai/privacy/)をご覧ください。

## トラブルシューティング

| 表示される内容 | 対処方法 |
| --- | --- |
| "This workspace isn't connected to a FailproofAI Cloud yet." | ワークスペースの管理者がアプリの **Home** タブを開いて接続先を選択します |
| "This link expired or was already used." | **Home** タブでクラウドを再度選択して新しいリンクを取得します |
| "This org is already connected to a Slack workspace." | 設定でまず切断します |
| "That Slack workspace is connected to another org." | その組織からまず切断します |
| "Link your account to use the assistant." | ボタンを選択して Failproof AI で確認します |
| グループダイレクトメッセージでアプリが回答しない | Slack でアプリを再度追加してグループ権限を付与します。接続は維持されます |
| "I won't post answers from your organization here" | そのワークスペース内で組織のメンバーである人がアプリをメンションし、アカウントを紐付けます |

それでも解決しない場合は、[support@befailproof.ai](mailto:support@befailproof.ai) までメールでお問い合わせください。
