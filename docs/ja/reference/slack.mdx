Slackから[Failproof Assistant](/ja/sessions/assistant)に質問できます。チャンネルでアプリをメンション、ダイレクトメッセージを送信、または `/failproof <質問>` を使用してください。回答には**ご自身の** Failproof AI の権限が使用され、グラフはスレッドに届き、何かを変更する操作は事前に承認を求められます。

公式アプリは1つです。Failproof AI Cloud がホスト型か自己ホスト型かに関わらず、同様に動作します。

<Note>
  回答はAIモデルによって生成されるため、不正確な場合があります。重要な内容はリンクされたソースデータで必ず確認してください。
</Note>

## ワークスペースを接続する

Failproof AI の `settings:write` 権限が必要です。Slack 側では、ワークスペースの管理者またはオーナーであるか、アプリを追加する担当者である必要があります。

<Tabs>
  <Tab title="Failproof AIから">
    1. **設定 → インテグレーション** に移動し、**Slackに追加** を選択します。
    2. Slack でアプリを承認します。
    3. Failproof AI に戻り、ワークスペースを組織に接続することを確認します。
  </Tab>
  <Tab title="Slackから">
    1. アプリを追加し、**ホーム** タブを開きます。
    2. **FailproofAI Cloud で続行** を選択するか、**独自のURLを使用** を選択してサインインするアドレスを入力します。
    3. 続行ボタンを選択し、サインインして組織を選び、確認します。リンクは1回のみ有効で、10分後に期限切れになります。
  </Tab>
</Tabs>

1つのワークスペースは1つの組織に接続され、1つの組織は1つのワークスペースに接続されます。

アカウントをお持ちでない場合は、まず[こちら](https://app.befailproof.ai/login)で作成してから接続してください。

## Slack上でのあなたのID

初めて質問すると、アプリはあなたがどのメンバーかを特定します。

- **メールアドレスによる自動認識**：接続されたワークスペースの正規メンバーであり、Slack のメールアドレスが確認済みで、その組織内でそのメールアドレスを使用しているメンバーが1人だけの場合。
- **それ以外の場合**：プライベートな **アカウントをリンク** ボタンが表示され、Failproof AI を開いてSlackユーザーとアカウントを紐づけることができます。

## 質問する

| 場所 | 方法 |
| --- | --- |
| チャンネル | アプリをメンションします。そのスレッド内に返信すれば、以降はメンション不要で会話を続けられます |
| ダイレクトメッセージ | アプリにメッセージを送ります |
| アプリが参加しているグループDM | メンションし、以降はスレッド内で返信して会話を続けます |
| Slack Connect チャンネル | アプリをメンションします |
| アプリが参加している会話 | `/failproof <質問>` で回答付きのスレッドが開始されます |
| `/failproof help` | アプリの機能を確認します |
| `/failproof status` | 接続されている組織とリンクされているユーザーを確認します |
| `/failproof link` | リンクされている Failproof AI アカウントを確認します |

1つのスレッドは1つの会話です。同僚が同じスレッドでアプリをメンションすると、それぞれの権限に基づいた回答が得られます。スレッドを開始した本人のみ、メンションなしで会話を続けられます。

回答がデータの場合、アプリはグラフまたはテーブルを投稿し、Failproof AI で開くためのリンクを添付します。

## 変更を承認する

アシスタントが行うすべての変更には、まず **承認** と **キャンセル** ボタンが表示され、**承認** の前にSlackがもう一度確認を求めます。ボタンに回答できるのは質問した本人のみで、ボタンは5分後に期限切れになり、変更はその人の権限で実行されます。

Slack から、アシスタントは保存済みクエリとダッシュボード、評価、アラート、監査、課題、ポリシーを変更したり、コード修正を提案したりできます（それぞれ対応する権限を持っている場合）。APIキー、ユーザー、設定は変更できません。

## リンクプレビュー

ホスト型 Failproof AI Cloud では、Slack に貼り付けた Failproof AI の課題・セッション・評価のリンクがカードとして展開されます。カードには、リンクを貼り付けた本人が閲覧できる情報のみ表示されます。自己ホスト型アドレスへのリンクは展開されませんが、アシスタントの回答内のカードは引き続き表示されます。

## Slack Connect チャンネル

別のワークスペースのメンバーも、組織のメンバーであればアカウントをリンクすることでアプリを使用できます。回答は会話内の全員に表示されます（組織のメンバーでない人も含む）ので、全員が閲覧できる場所で質問する際はご注意ください。

チャンネル内の他のすべてのワークスペースに組織にリンクされたメンバーがいる場合のみ、アプリは回答します。それまでは、質問した人に理由を通知します。

## アプリが要求する権限

| Slack の権限 | 理由 |
| --- | --- |
| `app_mentions:read` | アプリがメンションされたときに検知するため |
| `channels:history`、`groups:history`、`im:history`、`mpim:history` | ダイレクトメッセージやアプリのスレッドへの返信を受信するため。アプリはその他のメッセージは無視し、過去のメッセージを読むことはありません |
| `channels:read`、`groups:read`、`im:read`、`mpim:read` | 会話の種類を確認し、回答を閲覧できる人を把握するため |
| `chat:write` | 回答と承認ボタンを投稿するため |
| `commands` | `/failproof` を提供するため |
| `files:write` | グラフを投稿するため |
| `links:read`、`links:write` | 貼り付けられた Failproof AI リンクのプレビューを表示するため |
| `users:read`、`users:read.email` | あなたを Failproof AI アカウントと照合し、名前を表示するため |

## 切断する

**設定 → インテグレーション** から **切断** を選択するか、アプリの **ホーム** タブで **切断** を使用するか、Slack からアプリを削除してください。

いずれの操作でも、ワークスペースの接続、ボットトークン、リンクされたアカウント、スレッド記録が削除されます。過去の Slack の会話はダッシュボードで引き続き閲覧できます。その後、組織は即座にいずれかのワークスペースと接続できます。

## データとプライバシー

質問と回答は、スレッドを開始した人の名前のもと、組織のダッシュボードに会話として保存されます。Slack のデータがAIモデルのトレーニングに使用されることはありません。アプリが受け取るデータと保持期間については、[プライバシーポリシー](https://befailproof.ai/privacy/)をご覧ください。

## トラブルシューティング

| 表示されるメッセージ | 対処方法 |
| --- | --- |
| "This workspace isn't connected to a FailproofAI Cloud yet." | ワークスペースの管理者がアプリの **ホーム** タブを開いて選択します |
| "This link expired or was already used." | **ホーム** タブでCloudを再選択して新しいリンクを取得します |
| "This org is already connected to a Slack workspace." | まず設定から切断してください |
| "That Slack workspace is connected to another org." | まずその組織から切断してください |
| "Link your account to use the assistant." | ボタンを選択して Failproof AI で確認します |
| グループDM でアプリが応答しない | Slackでアプリを再追加してグループ権限を付与します。接続は維持されます |
| "I won't post answers from your organization here" | そのワークスペース内で組織のメンバーである誰かがアプリをメンションし、アカウントをリンクします |

それでも解決しない場合は、[support@befailproof.ai](mailto:support@befailproof.ai) までメールでお問い合わせください。
