Slackから[Failproofエージェント](/ja/sessions/assistant)に質問できます。チャンネルでアプリをメンション、ダイレクトメッセージを送信、または `/failproof <質問>` を使用してください。回答には**ご自身の** Failproof AI 権限が使用され、チャートはスレッドに届き、変更を伴う操作はすべて最初に承認を求めます。

公式アプリは1つのみです。Failproof AI Cloudがホスト型か自己ホスト型かに関わらず、同じように動作します。

<Note>
  回答はAIモデルによって生成されるため、不正確な場合があります。重要な内容はリンクされたソースデータで必ず確認してください。
</Note>

## ワークスペースを接続する

Failproof AI の `settings:write` 権限と、Slack ではワークスペースの管理者またはオーナー、あるいはアプリを追加するユーザーである必要があります。

<Tabs>
  <Tab title="Failproof AI から接続">
    1. **設定 → インテグレーション** に移動し、**Add to Slack** を選択します。
    2. Slack でアプリを承認します。
    3. Failproof AI に戻り、ワークスペースをorganizationに接続することを確認します。
  </Tab>
  <Tab title="Slack から接続">
    1. アプリを追加し、**Home** タブを開きます。
    2. **Continue with FailproofAI Cloud** を選択するか、**Use my own URL** を選択してサインインに使用するアドレスを入力します。
    3. 続行ボタンを選択し、サインインしてorganizationを選び、確認します。リンクは1回のみ有効で、10分後に期限切れになります。
  </Tab>
</Tabs>

1つのワークスペースは1つのorganizationに、1つのorganizationは1つのワークスペースに接続されます。

アカウントをお持ちでない場合は、まず[こちらで作成](https://app.befailproof.ai/login)してから接続してください。

## Slackでのあなたの識別

初めて質問したとき、アプリはあなたのメンバー情報を次の方法で特定します。

- **メールアドレスで自動的に**：接続されたワークスペースの正規メンバーであり、SlackのメールアドレスがConfirmed済みで、organizationのメンバーの中でそのメールアドレスを使用しているのが1人だけの場合。
- **それ以外の場合**：Failproof AI を開いてSlackユーザーとアカウントをリンクするための、非公開の **Link your account** ボタンが表示されます。

## 質問する

| 場所 | 方法 |
| --- | --- |
| チャンネル | アプリをメンションする。続けて質問する場合はそのスレッドに返信（メンション不要） |
| ダイレクトメッセージ | アプリにメッセージを送る |
| アプリが参加しているグループダイレクトメッセージ | メンションし、その後はスレッドに返信して続行 |
| Slack Connectチャンネル | アプリをメンションする |
| アプリが参加している任意の会話 | `/failproof <質問>` でスレッドを開始し、回答を受け取る |
| `/failproof help` | アプリの機能を確認する |
| `/failproof status` | 接続中のorganizationと自分のリンク状況を確認する |
| `/failproof link` | リンクされているFailproof AIアカウントを確認する |

1つのスレッドは1つの会話です。同僚が同じスレッドでアプリをメンションすると、それぞれ自分の権限で回答を受け取れます。スレッドを開始した人だけは、メンションなしで会話を続けられます。

回答がデータの場合、アプリはチャートまたはテーブルを投稿し、Failproof AI で開くリンクも表示されます。

## 変更を承認する

Failproofエージェントが行うすべての変更には、最初に **Approve** と **Cancel** ボタンが表示され、**Approve** の前にSlackがもう一度確認を求めます。ボタンに回答できるのは質問した本人のみで、ボタンは5分後に期限切れになり、変更はその人の権限で実行されます。

Slackから、Failproofエージェントは保存済みクエリとダッシュボード、評価、アラート、監査、インサイト、ポリシーの変更、およびコード修正の提案を行うことができます（それぞれ対応する権限を持っている場合）。APIキー、ユーザー、設定は変更できません。

## リンクプレビュー

Slackに貼り付けられた Failproof AI のインサイト、セッション、評価のリンクは、ホスト型 Failproof AI Cloudではカードとして展開されます。カードには、展開をトリガーした人が閲覧可能なコンテンツのみが表示されます。自己ホスト型アドレスへのリンクは展開されませんが、Failproofエージェント自身の回答内のカードは引き続き表示されます。

## Slack Connectチャンネル

別のワークスペースのユーザーも、organizationのメンバーであり、アカウントをリンクしていれば、アプリを使用できます。回答は会話内の全員に表示されます（organizationのメンバーでない人も含む）。そのため、全員が見られる場所で質問する際は注意してください。

アプリは、チャンネル内の他のすべてのワークスペースにorganizationにリンクされたメンバーがいるまで、回答しません。それまでの間、アプリは質問した人に理由を説明します。

## アプリが要求する権限

| Slack権限 | 用途 |
| --- | --- |
| `app_mentions:read` | アプリへのメンションを検知する |
| `channels:history`、`groups:history`、`im:history`、`mpim:history` | ダイレクトメッセージとアプリのスレッドへの返信を受信する。アプリはその他のメッセージを無視し、過去の会話履歴は読み取りません |
| `channels:read`、`groups:read`、`im:read`、`mpim:read` | 会話の種類を確認し、回答を閲覧できる範囲を把握する |
| `chat:write` | 回答と承認ボタンを投稿する |
| `commands` | `/failproof` を提供する |
| `files:write` | チャートを投稿する |
| `links:read`、`links:write` | 貼り付けられた Failproof AI リンクのプレビューを表示する |
| `users:read`、`users:read.email` | あなたを Failproof AI アカウントと照合し、名前を表示する |

## 切断する

**設定 → インテグレーション** に移動して **Disconnect** を選択するか、アプリの **Home** タブで **Disconnect** を使用するか、Slack からアプリを削除してください。

いずれかの操作により、ワークスペースの接続、Botトークン、リンクされたアカウント、スレッドの記録が削除されます。過去のSlack会話はダッシュボードで引き続き閲覧可能です。organizationはその後すぐに任意のワークスペースと接続できます。

## データとプライバシー

質問と回答は、スレッドを開始した人の名義で、organizationのダッシュボードに会話として保存されます。SlackのデータはAIモデルのトレーニングには使用されません。アプリが受け取る情報とその保持期間については、[プライバシーポリシー](https://befailproof.ai/privacy/)をご覧ください。

## トラブルシューティング

| 表示されるメッセージ | 対処方法 |
| --- | --- |
| 「This workspace isn't connected to a FailproofAI Cloud yet.」 | ワークスペースの管理者がアプリの **Home** タブを開き、接続先を選択します |
| 「This link expired or was already used.」 | **Home** タブで再度Cloudを選択して新しいリンクを取得します |
| 「This org is already connected to a Slack workspace.」 | 先に設定で切断します |
| 「That Slack workspace is connected to another org.」 | 先にそのorganizationから切断します |
| 「Link your account to use the assistant.」 | ボタンを選択し、Failproof AI で確認します |
| グループダイレクトメッセージでアプリが回答しない | Slackでアプリを再追加してグループ権限を付与します。接続は維持されます |
| 「I won't post answers from your organization here」 | そのワークスペースでorganizationのメンバーである人がアプリをメンションし、アカウントをリンクします |

それでも解決しない場合は、[support@befailproof.ai](mailto:support@befailproof.ai) までメールでお問い合わせください。
