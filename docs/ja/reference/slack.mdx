Slack から [failproof エージェント](/ja/sessions/assistant)に質問できます。チャンネルでアプリをメンション、ダイレクトメッセージを送信、または `/failproof <質問>` を使用してください。回答には**ご自身の** Failproof AI 権限が使用され、チャートはスレッドに届き、何かを変更する操作は事前に承認を求められます。

公式アプリは 1 つです。Failproof AI Cloud がホスト型かセルフホスト型かにかかわらず、同じように動作します。

<Note>
  回答は AI モデルによって生成されるため、不正確な場合があります。重要な内容はリンク先のソースデータで必ず確認してください。
</Note>

## ワークスペースを接続する

Failproof AI の `settings:write` 権限と、Slack 側でワークスペースの管理者またはオーナーであるか、アプリを追加する担当者である必要があります。

<Tabs>
  <Tab title="Failproof AI から接続する">
    1. **設定 → インテグレーション** に移動し、**Add to Slack** を選択します。
    2. Slack でアプリを承認します。
    3. Failproof AI に戻り、ワークスペースを組織に接続することを確認します。
  </Tab>
  <Tab title="Slack から接続する">
    1. アプリを追加し、**ホーム** タブを開きます。
    2. **Continue with FailproofAI Cloud** を選択するか、**Use my own URL** を選択してサインインに使用するアドレスを入力します。
    3. 続行ボタンを選択し、サインインして組織を選び、確認します。リンクは 1 回のみ有効で、10 分後に期限切れになります。
  </Tab>
</Tabs>

1 つのワークスペースは 1 つの組織に、1 つの組織は 1 つのワークスペースに接続されます。

アカウントをお持ちでない場合は、まず[こちらから作成](https://app.befailproof.ai/login)してから接続してください。

## Slack でのあなたのアカウント

最初に質問したとき、アプリはあなたがどのメンバーかを次の方法で特定します。

- **メールアドレスによる自動照合**: 接続済みワークスペースの正規メンバーであり、Slack のメールアドレスが確認済みで、そのメールアドレスを使用する組織メンバーがちょうど 1 人の場合。
- **それ以外の場合**: Failproof AI を開いて Slack ユーザーをアカウントにリンクするための、非公開の **アカウントをリンクする** ボタンが表示されます。

## 質問する

| 場所 | 方法 |
| --- | --- |
| チャンネル | アプリをメンションします。続けて質問する場合はスレッドに返信するだけで、メンション不要です |
| ダイレクトメッセージ | アプリにメッセージを送ります |
| アプリが参加しているグループダイレクトメッセージ | メンションし、スレッドに返信して会話を続けます |
| Slack Connect チャンネル | アプリをメンションします |
| アプリが参加している会話 | `/failproof <質問>` で回答付きのスレッドが開始されます |
| `/failproof help` | アプリでできることを確認します |
| `/failproof status` | 接続中の組織とリンクされているアカウントを確認します |
| `/failproof link` | リンクされている Failproof AI アカウントを確認します |

1 つのスレッドが 1 つの会話です。同僚が同じスレッドでアプリをメンションすると、それぞれの権限に基づいた回答が返されます。スレッドを開始した人だけが、メンションなしで会話を続けることができます。

回答がデータの場合、アプリはチャートまたはテーブルを投稿し、Failproof AI で開くためのリンクも表示されます。

## 変更を承認する

failproof エージェントが行うすべての変更には、事前に **承認** と **キャンセル** ボタンが表示されます。さらに **承認** の前にもう一度 Slack から確認が求められます。これらのボタンは質問した本人のみが操作でき、5 分後に期限切れになります。変更はその人の権限で実行されます。

Slack から failproof エージェントが変更できるのは、権限を持っている場合に限り、保存済みクエリとダッシュボード、評価、アラート、監査、インサイト、ポリシー、およびコード修正の提案です。API キー、ユーザー、設定は変更できません。

## リンクプレビュー

ホスト型 Failproof AI Cloud では、Slack に貼り付けた Failproof AI のインサイト、セッション、評価のリンクがカードとして展開されます。カードには、展開をトリガーした人が閲覧できる内容のみが表示されます。セルフホスト型アドレスへのリンクは展開されませんが、failproof エージェント自身の回答内のカードは引き続き表示されます。

## Slack Connect チャンネル

別のワークスペースのメンバーも、組織のメンバーでありアカウントをリンクしていれば、アプリを使用できます。回答は会話内の全員に表示されます（組織のメンバーでない人も含む）。そのため、全員が見られる場所で質問するよう注意してください。

アプリが回答するのは、チャンネル内の他のすべてのワークスペースに組織にリンクされたメンバーがいる場合のみです。それまでは、質問した人に理由が伝えられます。

## アプリが要求する権限

| Slack 権限 | 理由 |
| --- | --- |
| `app_mentions:read` | アプリへのメンションを検知するため |
| `channels:history`, `groups:history`, `im:history`, `mpim:history` | ダイレクトメッセージやアプリのスレッドへの返信を受け取るため。アプリは他のメッセージを無視し、過去の会話を読むことはありません |
| `channels:read`, `groups:read`, `im:read`, `mpim:read` | 会話の種類を確認し、回答を見られる人を把握するため |
| `chat:write` | 回答と承認ボタンを投稿するため |
| `commands` | `/failproof` を提供するため |
| `files:write` | チャートを投稿するため |
| `links:read`, `links:write` | 貼り付けた Failproof AI リンクのプレビューを表示するため |
| `users:read`, `users:read.email` | あなたを Failproof AI アカウントに照合し、名前を表示するため |

## 接続を解除する

**設定 → インテグレーション** に移動して **切断** を選択するか、アプリの **ホーム** タブで **切断** を使用するか、Slack からアプリを削除してください。

いずれの操作でも、ワークスペースの接続、ボットトークン、リンクされたアカウント、スレッドの記録が削除されます。過去の Slack 会話はダッシュボードで引き続き閲覧できます。組織はその後すぐに任意のワークスペースを接続できます。

## データとプライバシー

質問と回答は、スレッドを開始した人の名義で、組織のダッシュボードに会話として保存されます。Slack のデータが AI モデルのトレーニングに使用されることはありません。アプリが受け取るデータと保持期間については、[プライバシーポリシー](https://befailproof.ai/privacy/)をご覧ください。

## トラブルシューティング

| 表示されるメッセージ | 対処方法 |
| --- | --- |
| "This workspace isn't connected to a FailproofAI Cloud yet." | ワークスペースの管理者がアプリの **ホーム** タブを開き、接続先を選択します |
| "This link expired or was already used." | **ホーム** タブで Cloud を再度選択し、新しいリンクを取得します |
| "This org is already connected to a Slack workspace." | 設定から先に接続を解除してください |
| "That Slack workspace is connected to another org." | 先にその組織から接続を解除してください |
| "Link your account to use the assistant." | ボタンを選択し、Failproof AI で確認してください |
| グループダイレクトメッセージでアプリが回答しない | Slack でアプリを再度追加してグループ権限を付与してください。接続は維持されます |
| "I won't post answers from your organization here" | そのワークスペースで組織のメンバーである人がアプリをメンションし、アカウントをリンクします |

それでも解決しない場合は、[support@befailproof.ai](mailto:support@befailproof.ai) までメールでお問い合わせください。
