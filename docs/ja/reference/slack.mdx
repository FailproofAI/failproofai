Slack から [Failproof Assistant](/ja/sessions/assistant) に質問できます。チャンネルでアプリをメンション、ダイレクトメッセージを送信、または `/failproof <質問>` を使用してください。回答には**ご自身の** Failproof AI 権限が使用され、チャートはスレッドに届き、何かを変更する操作は事前に承認を求めます。

公式アプリは 1 つだけです。Failproof AI Cloud がホスト型でもセルフホスト型でも同様に動作します。

<Note>
  回答は AI モデルによって生成されるため、不正確な場合があります。重要な内容はリンクされたソースデータで必ず確認してください。
</Note>

## ワークスペースを接続する

Failproof AI の `settings:write` 権限と、Slack ではワークスペースの管理者またはオーナー、あるいはアプリを追加するユーザーである必要があります。

<Tabs>
  <Tab title="Failproof AI から">
    1. **設定 → インテグレーション** に移動し、**Slack に追加** を選択します。
    2. Slack でアプリを承認します。
    3. Failproof AI に戻り、ワークスペースを組織に接続することを確認します。
  </Tab>
  <Tab title="Slack から">
    1. アプリを追加して、**ホーム** タブを開きます。
    2. **FailproofAI Cloud で続ける** を選択するか、**独自の URL を使用する** を選択してサインイン先のアドレスを入力します。
    3. 続行ボタンを選択し、サインインして組織を選び、確認します。リンクは 1 回のみ有効で、10 分後に期限切れになります。
  </Tab>
</Tabs>

1 つのワークスペースは 1 つの組織に、1 つの組織は 1 つのワークスペースに接続されます。

アカウントをお持ちでない場合は、まず[アカウントを作成](https://app.befailproof.ai/login)してから接続してください。

## Slack でのあなたの識別

初回の質問時に、アプリはどのメンバーであるかを以下のように判断します。

- **メールアドレスによる自動識別**：接続済みワークスペースの正規メンバーであり、Slack のメールアドレスが確認済みで、そのメールアドレスを使用する組織メンバーがちょうど 1 人の場合。
- **それ以外の場合**：Failproof AI を開いて Slack ユーザーをアカウントにリンクするためのプライベートな **アカウントをリンク** ボタンが表示されます。

## 質問する

| 場所 | 方法 |
| --- | --- |
| チャンネル | アプリをメンションする。続けるにはそのスレッドに返信（メンション不要） |
| ダイレクトメッセージ | アプリにメッセージを送る |
| アプリが参加しているグループダイレクトメッセージ | メンションし、その後スレッドに返信して続ける |
| Slack Connect チャンネル | アプリをメンションする |
| アプリが参加しているすべての会話 | `/failproof <質問>` で回答付きのスレッドを開始 |
| `/failproof help` | アプリでできることを確認する |
| `/failproof status` | 接続中の組織とリンクされているユーザーを確認する |
| `/failproof link` | リンクされている Failproof AI アカウントを確認する |

1 つのスレッドが 1 つの会話です。同僚が同じスレッドでアプリをメンションすると、それぞれの権限に基づいた回答が得られます。スレッドを開始した本人のみ、メンションなしで会話を続けられます。

回答がデータの場合、アプリはチャートまたは表を投稿し、Failproof AI で開くリンクを表示します。

## 変更を承認する

アシスタントが行うすべての変更は、最初に **承認** と **キャンセル** ボタンが表示され、**承認** の前に Slack がもう一度確認を求めます。ボタンに回答できるのは質問した本人のみで、ボタンは 5 分後に期限切れになり、変更はその人の権限で実行されます。

Slack からアシスタントが変更できるのは、権限を持っている場合に限り、保存済みクエリとダッシュボード、評価、アラート、監査、課題、ポリシー、およびコード修正の提案です。API キー、ユーザー、設定は変更できません。

## リンクプレビュー

Slack に貼り付けた Failproof AI の課題、セッション、評価のリンクは、ホスト型 Failproof AI Cloud ではカードに展開されます。カードには、リンクを展開したユーザーが閲覧できる内容のみが表示されます。セルフホストのアドレスへのリンクは展開されませんが、アシスタント自身の回答内のカードは引き続き表示されます。

## Slack Connect チャンネル

別のワークスペースのユーザーも、組織のメンバーであれば、アカウントをリンクした後にアプリを使用できます。回答は会話内の全員（組織のメンバーでない方を含む）に表示されるため、全員が見られる場所で質問することをご認識ください。

チャンネル内の他のすべてのワークスペースに組織にリンクされたメンバーが存在するまで、アプリは回答しません。それまでの間は、質問した人に理由を伝えます。

## アプリが要求する権限

| Slack 権限 | 理由 |
| --- | --- |
| `app_mentions:read` | アプリへのメンションを検知するため |
| `channels:history`, `groups:history`, `im:history`, `mpim:history` | ダイレクトメッセージとアプリのスレッドへの返信を受信するため。アプリはその他のメッセージを無視し、過去のメッセージを読み返すことはありません |
| `channels:read`, `groups:read`, `im:read`, `mpim:read` | 会話の種類を確認し、回答を誰が見られるかを把握するため |
| `chat:write` | 回答と承認ボタンを投稿するため |
| `commands` | `/failproof` を提供するため |
| `files:write` | チャートを投稿するため |
| `links:read`, `links:write` | 貼り付けられた Failproof AI リンクのプレビューを表示するため |
| `users:read`, `users:read.email` | Failproof AI アカウントとの照合、および名前の表示のため |

## 切断する

**設定 → インテグレーション** に移動して **切断** を選択するか、アプリの **ホーム** タブで **切断** を使用するか、Slack からアプリを削除してください。

いずれかの操作により、ワークスペースの接続、ボットトークン、リンク済みアカウント、スレッドの記録が削除されます。過去の Slack 会話はダッシュボードで引き続き閲覧できます。その後、組織は任意のワークスペースをすぐに接続できます。

## データとプライバシー

質問と回答は、スレッドを開始した人の下で、組織のダッシュボードに会話として保存されます。Slack のデータが AI モデルのトレーニングに使用されることはありません。アプリが受信するデータと保持期間については、[プライバシーポリシー](https://befailproof.ai/privacy/)をご覧ください。

## トラブルシューティング

| 表示されるメッセージ | 対処方法 |
| --- | --- |
| "This workspace isn't connected to a FailproofAI Cloud yet." | ワークスペースの管理者がアプリの **ホーム** タブを開いて選択する |
| "This link expired or was already used." | **ホーム** タブで Cloud を再度選択して新しいリンクを取得する |
| "This org is already connected to a Slack workspace." | 先に設定で切断する |
| "That Slack workspace is connected to another org." | 先にその組織から切断する |
| "Link your account to use the assistant." | ボタンを選択して Failproof AI で確認する |
| グループダイレクトメッセージでアプリが回答しない | Slack でアプリを再度追加してグループ権限を付与する。接続は維持されます |
| "I won't post answers from your organization here" | そのワークスペースの組織メンバーがアプリをメンションしてアカウントをリンクする |

それでも解決しない場合は、[support@befailproof.ai](mailto:support@befailproof.ai) までメールでお問い合わせください。
