---
title: "フック"
description: "フックのアクティビティ、トリガー、レイテンシをポリシーの結果とは別に計測します。"
icon: "webhook"
---

フックでは、エージェントのライフサイクルフックがいつ実行されたか、またその所要時間を確認できます。ポリシーの判定結果は別のビューで確認します。

<Tabs>
  <Tab title="ダッシュボード">
    1. **Observe → Hooks** に移動します。
    2. 環境、フック名、トリガーイベント、エージェント、またはセッション ID でフィルタリングします。
    3. フックのレイテンシと分布を確認します。
    4. グラフ上の点またはフックのセグメントを選択して、対応するイベントを開きます。

    ![フック名とトリガーイベント別にレイテンシがグループ化されたフックページ。](/images/dashboard/hooks.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list hooks
    fp events --event-type hook_triggered,hook_completed --env production --since 24h
    fp events --search "PreToolUse" --since 24h
    ```
  </Tab>
</Tabs>
