フックとは、エージェントが Failproof AI に判断を求めるポイントです。フックアクティビティには、イベント、ポリシー、結果、および評価時間が記録されます。

## フックアクティビティを調査する

<Tabs>
  <Tab title="ダッシュボード">
    **Observe → Hooks** に移動します。環境、イベント、エージェント、またはセッションでフィルタリングできます。

    ![フック名とトリガーイベントでグループ化されたレイテンシを表示するHooksページ。](/images/dashboard/hooks.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp guardrails summary --since 24h
    fp --json events --full --event-type hook_completed --session-id <session-id> --all --limit 500
    fp list hooks
    ```
  </Tab>
</Tabs>

デフォルトでは、すべての `deny` および `instruct` の判断は完全な形で送信されます。繰り返される allow はノイズを減らすためにグループ化されます。`~/.failproofai/config.json` の `collector.hooks_verbosity` を `all`、`decisions`、または `off` に設定してください。

<Warning>
  フックアクティビティは評価が実行されたことを証明するものであり、ハーネスがそのイベントをブロックできることを保証するものではありません。[エンフォースメント機能](/ja/reference/harnesses#enforcement-capability) を参照してください。リストにないハーネスとイベントのペアは未検証です。
</Warning>

</Card>
