ライブイベントでは、エージェントの実行中にモデル呼び出し、ツール、エラー、ヒューマンインプット、フック、ポリシー決定などのアクティビティをリアルタイムで表示します。

## アクティビティを監視する

**Observe → Live events** に移動するか、以下のコマンドを実行してください：

```bash
fp events --since 1h
fp events --event-type tool_use,tool_result --since 1h
fp --json events --full --session-id <session-id> --all --limit 2000
```

ペイロードの内容が必要な場合は `--full` を使用してください。軽量フィードの方が高速で、ほとんどのフィルタリング用途には十分です。

主なイベントタイプは以下のとおりです：

- `session_start` と `session_end`
- `model_request` と `model_response`
- `tool_use` と `tool_result`
- `hook_triggered` と `hook_completed`
- `error`
- `human_wait` と `human_input`
- `agent_pause` と `agent_resume`

## イベントが表示されない場合

```bash
failproofai flush --wait
failproofai config --status
failproofai backfill --since 30d --dry-run
```

デフォルトの環境は `local` です。`production` 向けのフィルターは、環境ラベルを変更するまで何も返しません。

サポートされているハーネス外のエージェントを使用している場合は、[Python SDK](/ja/reference/custom-agents) をご利用ください。
