---
title: "メトリクス"
description: "レイテンシー、コスト、トークン使用量などの数値メトリクスをプロットします。"
icon: "ruler"
---

メトリクスは単位を持つ値を対象とします。評価はスコアや判断を対象とします。

<Tabs>
  <Tab title="ダッシュボード">
    1. **Observe → Metrics** に移動します。
    2. **add series** を選択し、エージェント、環境、メトリクス、統計量、カーブを選びます。
    3. エージェントや環境を比較するためにシリーズを追加します。異なる単位のシリーズはそれぞれ別の軸に表示されます。
    4. ポイントを選択すると対応する評価とセッションが開き、**share** を選択すると現在の表示をそのままコピーできます。

    ![2つのコスト/出力ユニットシリーズを比較するメトリクスページ。時間コントロール、集計セレクター、カーブ、共有アクションが表示されています。](/images/dashboard/metrics-series.png)
  </Tab>
  <Tab title="CLI">
    数値メトリクス専用のコマンドはまだ用意されていません。利用可能なキーを確認したり、セッションや評価を参照するには以下を使用してください：

    ```bash
    fp list score_filters
    fp --json evals --since 24h
    fp --json sessions --since 24h
    ```

    カスタムメトリクスの集計には `fp query` を使用してください。
  </Tab>
</Tabs>
