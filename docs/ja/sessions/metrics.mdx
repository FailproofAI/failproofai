---
title: "メトリクス"
description: "レイテンシ、コスト、トークン使用量などの定量的メトリクスをプロットします。"
icon: "ruler"
---

メトリクスは単位を持つ値を扱います。評価はスコアや判定を扱います。

<Tabs>
  <Tab title="ダッシュボード">
    1. **Observe → Metrics** に移動します。
    2. **add series** を選択し、エージェント、環境、メトリクス、統計量、カーブを選択します。
    3. エージェントや環境を比較するためにシリーズを追加します。単位が異なる場合は別々の軸が割り当てられます。
    4. ポイントを選択すると対応する評価とセッションが表示され、**share** を選択すると現在のビューのURLをコピーできます。

    ![時間コントロール、集計セレクター、カーブ、共有アクションを備えた、2つのコスト・パー・アウトプットユニットシリーズを比較するメトリクスページ。](/images/dashboard/metrics-series.png)
  </Tab>
  <Tab title="CLI">
    定量的メトリクス専用のコマンドはまだありません。利用可能なキーの確認やセッション・評価の検査には以下を使用してください:

    ```bash
    fp list score_filters
    fp --json evals --since 24h
    fp --json sessions --since 24h
    ```

    カスタムメトリクスの集計には `fp query` を使用してください。
  </Tab>
</Tabs>
