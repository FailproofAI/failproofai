モデルページを使用して、モデル、エージェント、環境、または時間範囲の変更に伴う信頼性やコストの変化を確認します。

<Tabs>
  <Tab title="ダッシュボード">
    1. **Observe → Models** に移動します。
    2. 時間範囲を設定し、環境、モデル、エージェント、またはセッション ID でフィルタリングします。
    3. レイテンシー、トークン消費量、コンテキストウィンドウ使用量、モデル分布を確認します。
    4. グラフ上の点または分布のセグメントを選択して、対応するイベントを開きます。

    ![レイテンシー、パーセンタイル、トークン、コスト、コンテキストウィンドウ、モデル分布のビューを表示するモデルページ。](/images/dashboard/models.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list models
    fp events --event-type model_request,model_response --env production --since 24h
    fp --json events --fields ts,agent_id,session_id,event_type,output_tokens,context_fill
    ```

    専用の CLI コマンドとして公開されていないモデルレベルの集計には、保存済みクエリを使用してください。
  </Tab>
</Tabs>
