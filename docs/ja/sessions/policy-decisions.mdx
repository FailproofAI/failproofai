---
title: "ポリシーの判断"
description: "評価、ブロック、指示、または許可されたポリシーを確認する。"
icon: "shield-check"
---

ポリシーの判断は、適用された内容を説明します。ロールアウトの検証、ブロック率の測定、保護されていないアクティビティの検出に活用してください。

<Tabs>
  <Tab title="ダッシュボード">
    1. **Observe → policy** に移動し、時間範囲と任意で特定のマシンを選択します。
    2. 評価されたアクション、ブロック数、ブロック率、Cloud の判断、保護されていないアクション、および一時停止中のアクティビティを確認します。
    3. ポリシーマッピングテーブルをフィルタリングし、デプロイされた割り当てを確認します。
    4. グラフ上のポイントを選択すると、判断の詳細とそのセッションが表示されます。

    ![判断の合計、マシンフィルター、時系列の適用アクティビティ、およびポリシーマッピングテーブルを表示するポリシーページ。](/images/dashboard/policy-observe.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp events --event-type hook_completed --env production --since 24h
    fp events --search "deny" --since 24h
    failproofai config --status
    ```

    マシンのローカル適用状態の確認には `failproofai` を、Cloud イベントの調査には `fp` を使用してください。
  </Tab>
</Tabs>
