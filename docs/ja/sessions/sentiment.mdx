Jevは、エージェントに送られたメッセージを**怒り（angry）**・**苛立ち（frustrated）**・**満足（happy）**・**混乱（confused）**の4つの感情と、エージェントのパフォーマンスに関する3つのシグナルについて、それぞれ0〜100でスコアリングします。

- **Correcting**（修正）: ユーザーがエージェントの回答の誤りを指摘している。
- **Resolved**（解決）: ユーザーがエージェントによって問題が解決されたことを確認している。
- **Doubtful**（疑念）: ユーザーがエージェントの回答の正確さや、実際に作業が行われたかどうかを疑問視している。

感情分析を活用することで、ユーザーが忍耐を失っている会話、繰り返し修正が必要なエージェント、好意的に受け取られた返答を発見できます。これはJevに組み込まれたスコアリング機能であり、評価を自分で作成する必要はありません。独自の固定回答型の質問については、[Jev evalを作成する](/ja/evaluations/jev)をご参照ください。

<Note>
  感情分析は、管理者が組織単位で有効にするまでオフになっています。Jevはメッセージ1件につき1回スコアリングリクエストを行い、そのメッセージとその直前のエージェント返答を受け取ります。スコアリングには組織のモデル予算が使用されます。
</Note>

## 有効にする

1. **Administration → Settings** に移動します。
2. **Human input sentiment** の項目で、スイッチを**オン**にして保存します。

直近1日分のメッセージが最初にスコアリングされます。それ以降は、新着メッセージが到着してから1〜2分以内にスコアリングされます。

## レビューする会話を見つける

**Observe → Sentiment** を開きます。時間・環境・エージェント・セッションIDでフィルタリングできます。ヘッダーにはメッセージ数とセッション数が表示され、**フラグが立てられた**メッセージの数と主要シグナルが確認できます。怒り・苛立ち・修正・混乱・疑念のいずれかのスコアが100点満点中35点に達すると、そのメッセージにフラグが立てられます。

![メッセージ数・セッション数・フラグ付きメッセージ・時系列のJevスコアを表示する感情分析ダッシュボード。](/images/dashboard/sentiment-overview.png)

**Score over time** を使って各シグナルを比較できます。表示するスコアを選択し、グラフ上のポイントをクリックすると、その時間帯のメッセージが表示されます。**By agent** テーブルでは、特定のシグナルがどのエージェントに集中しているかを確認できます。**Messages** では、最も強いネガティブスコア順に並べ替えたり、スコアを絞り込んだりできます。メッセージをクリックしてセッション内で開くと、前後の会話の流れを読んで何が問題だったかを判断できます。

![最も強いネガティブスコア順に並べられた感情分析メッセージ一覧。各メッセージには元のセッションへのリンクが表示される。](/images/dashboard/sentiment-messages.png)

## スコアリング対象のメッセージ

スコアリングされるのは、ユーザーが書いたメッセージのみです。

- SDKを通じてヒューマン入力として記録されたカスタムエージェントへのメッセージ。
- セッショントランスクリプトが送信される設定（デフォルト）において、Claude Code・Codex・OpenCode・pi・Hermes・OpenClawに入力されたプロンプト。スケジュールジョブ、注入された指示、サブエージェントへの引き継ぎ、その他エージェントのランタイムが書き込んだテキストはスコアリングされません。また、`claude -p`・`codex exec`・`hermes -z` のような非インタラクティブな実行もスコアリング対象外です。これらのプロンプトはスクリプトが生成したものであり、人間が入力したものではないためです。

スコアリングはユーザー自身の言葉を判断基準とします。「fix it」のような短くぶっきらぼうな指示は怒りとは判定されず、質問することは混乱とは判定されません。新しいリクエストは修正（correction）とはみなされず、単なる感謝の言葉だけでは解決済み（resolved）とはみなされません。
