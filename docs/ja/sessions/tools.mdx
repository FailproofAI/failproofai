---

ツールページでは、セッションをまたいでツール呼び出しをグループ化し、レイテンシや呼び出し分布を比較できます。

<Tabs>
  <Tab title="ダッシュボード">
    1. **Observe → Tools** に移動します。
    2. 環境、ツール名、エージェント、またはセッションIDでフィルタリングします。
    3. レイテンシとツールの分布を確認します。
    4. グラフ上の点またはツールセグメントを選択すると、対応するイベントやセッションが表示されます。

    ![レイテンシ、成功・失敗の内訳、ツール呼び出し分布を表示したツールページ。](/images/dashboard/tools.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list tools
    fp events --event-type tool_use,tool_result --env production --since 24h
    fp --json events --full --session-id <session-id> --all
    ```
  </Tab>
</Tabs>
