まず、止めたい動作と、引き続き許可すべき正当なアクションを明確にしましょう。

## まずレビュー済みのポリシーを試す

```bash
failproofai policies
failproofai policies add block-rm-rf
```

Failproof AI には39個のレビュー済みポリシーが含まれています。新しいポリシーを書く前に[カタログ](/ja/policies/builtin-catalog)を確認してください。

## 独自のポリシーを作成してテストする

<Steps>
  <Step title="動作するポリシーを作成する">
    ```bash
    failproofai publish --init guards.mjs
    ```

    これにより、`git push --force` をブロックするポリシーが生成されます。独自のルールに合わせて編集してください。
  </Step>
  <Step title="このマシンに適用する">
    ```bash
    failproofai policies -i -c ./guards.mjs
    ```

    エージェントにブロック対象のアクションを実行させ、ローカルダッシュボードの **Policies → Activity** で結果を確認してください。
  </Step>
  <Step title="維持するか削除するか">
    `.failproofai/policies/` 配下に `*policies.mjs` ファイルを配置すると、自動的に読み込まれます。

    明示的に指定したカスタムファイルを削除するには：

    ```bash
    failproofai policies -u -c
    ```
  </Step>
</Steps>

## 公開する

パブリックパックを公開するには：

```bash
failproofai publish
```

公開後は `failproofai policies add <owner>/<repo>` でインストールできます。[Policy Hub](https://befailproof.ai/policy-hub/) にインデックスされるよう、GitHub トピックに `failproofai-policies` を自分で追加してください。

クラウドへのロールアウトには：

```bash
fp policies publish checkout-guard ./guards.mjs
fp fleet deploy <machine> --add checkout-guard:observe
fp guardrails summary --since 24h --machine <machine>
fp fleet deploy <machine> --add checkout-guard:enforce
```

<Warning>
  `--add checkout-guard` を単体で使用すると即座に強制適用されます。エージェントをブロックせずにポリシーの動作を記録するには `:observe` を付けてください。
</Warning>

詳細なワークフローについては、[パックの公開](/ja/policies/publish-a-pack)または[ポリシーのデプロイ](/ja/policies/deploy)を参照してください。
