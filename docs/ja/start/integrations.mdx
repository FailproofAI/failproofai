## 3行で完了 — どのフレームワークでも

<CodeGroup>
```bash LangGraph
pip install 'failproofai-sdk[langgraph]'
```

```bash CrewAI
pip install 'failproofai-sdk[crewai]'
```

```bash LlamaIndex
pip install 'failproofai-sdk[llamaindex]'
```

```bash Pydantic AI
pip install 'failproofai-sdk[pydantic-ai]'
```

```bash Custom agents
pip install failproofai-sdk
```
</CodeGroup>

```python
import failproofai_sdk

failproofai_sdk.configure(environment="production")
failproofai_sdk.instrument()          # インポートされたフレームワークを自動検出

with failproofai_sdk.session():
    ...                               # 既存のエージェント呼び出し、変更なし
```

関数へのデコレーター不要、呼び出しへのコールバック渡し不要、コード全体へのID埋め込み不要。変わるのはセッション内の呼び出しだけです：

<Tabs>
  <Tab title="LangGraph">
    ```python
    graph.invoke({"messages": [HumanMessage("...")]})
    ```
  </Tab>
  <Tab title="CrewAI">
    ```python
    Crew(agents=[analyst, writer], tasks=[gather, summarise]).kickoff()
    ```
  </Tab>
  <Tab title="LlamaIndex">
    ```python
    await agent.run("...")        # `async with failproofai_sdk.session():` 内で
    ```
  </Tab>
  <Tab title="Pydantic AI">
    ```python
    agent.run_sync("...")
    ```
  </Tab>
  <Tab title="Custom agents">
    ```python
    with failproofai_sdk.agent("planner"):
        with failproofai_sdk.tool_call("search", input={"q": q}) as t:
            t.output = search(q)
    ```
  </Tab>
</Tabs>

追加インストールは**フレームワーク**そのものに向けられています。すべてのアダプターはベースホイールに含まれているため、すでにフレームワークを持つプロジェクトでは追加インストールは不要です。

## 到達確認

インストゥルメントされたセッションを1回実行し、**Observe → Sessions** を開いてお使いの環境を選択します。実行が再構築されたトレースとして表示されます。

何も届かない場合は、`failproofai config --status` でマシンが接続されていることを確認してください。[キャプチャのセットアップ](/ja/start/setup) を参照。

<Warning>
  スプールディレクトリを確認して配信を確かめようとしないでください。Failproof デーモンは各バッチをミリ秒以内に収集・削除するため、読み取りはコレクターと競合し、実際に送出されたイベントよりもはるかに少ない数しか表示されません。
</Warning>
