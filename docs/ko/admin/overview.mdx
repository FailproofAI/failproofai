관리 섹션에는 팀 전체에서 Failproof AI를 운영하는 데 필요한 제어 기능이 포함되어 있습니다. 대부분의 사용자는 세션, 감사, 정책 섹션에서 작업하면 되며, 관리자는 이 섹션을 통해 접근 권한과 운영 경계를 관리합니다.

<Tabs>
  <Tab title="대시보드">
    클라우드 사이드바의 **Admin** 섹션에서 **정책 편집기**, **적용**, **사용량**, **키**, **사용자**, **설정**을 이용하세요. 잠긴 항목은 해당 계정에 읽기 권한이 없음을 나타냅니다.

    ![정책 편집기, 적용, 사용량, 키, 사용자, 설정이 포함된 클라우드 사이드바의 Admin 섹션.](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    전역 옵션은 명령어 앞에 지정하세요. 예: `fp --org reliability-team --json usage`.
  </Tab>
</Tabs>
