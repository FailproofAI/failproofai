관리 섹션에는 팀 전체에서 Failproof AI를 운영하는 데 필요한 제어 기능이 포함되어 있습니다. 대부분의 사용자는 Sessions, Audits, Policies 섹션만 사용하면 되며, 관리자는 이 섹션을 통해 접근 권한과 운영 경계를 관리합니다.

<Tabs>
  <Tab title="Dashboard">
    Cloud 사이드바의 **Admin** 섹션에서 **policy editor**, **enforcement**, **usage**, **keys**, **users**, **settings**를 사용하세요. 잠긴 항목은 해당 계정에 읽기 권한이 없음을 나타냅니다.

    ![The Admin section of the Cloud sidebar with policy editor, enforcement, usage, keys, users, and settings.](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    전역 옵션은 명령어 앞에 지정하세요. 예: `fp --org reliability-team --json usage`.
  </Tab>
</Tabs>
