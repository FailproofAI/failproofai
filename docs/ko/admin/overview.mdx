관리 섹션에는 팀 전체에서 Failproof AI를 운영하는 데 필요한 제어 기능이 포함되어 있습니다. 대부분의 사용자는 Sessions, Audits, Policies에서 작업하면 충분하며, 관리자는 이 섹션을 통해 액세스 권한과 운영 범위를 관리합니다.

<Tabs>
  <Tab title="대시보드">
    Cloud 사이드바의 **Admin** 섹션에서 **policy editor**, **enforcement**, **usage**, **keys**, **users**, **settings**를 사용할 수 있습니다. 잠금 표시가 있는 항목은 해당 읽기 권한이 계정에 없음을 의미합니다.

    ![policy editor, enforcement, usage, keys, users, settings가 포함된 Cloud 사이드바의 Admin 섹션.](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    전역 옵션은 명령어 앞에 배치합니다. 예: `fp --org reliability-team --json usage`.
  </Tab>
</Tabs>
