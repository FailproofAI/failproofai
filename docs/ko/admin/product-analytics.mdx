Failproof AI Cloud는 유지 관리자에게 **소프트웨어 자체에 관한** 사용 텔레메트리를 전송합니다. 에이전트 데이터는 절대 포함되지 않습니다. 셀프 호스팅 설치 시 기본적으로 활성화되어 있으며, 비활성화할 수 있습니다.

## 수집 항목

모든 이벤트는 다섯 가지 차원을 포함하며, 개인을 식별할 수 있는 정보는 포함하지 않습니다.

| 차원 | 예시 | 설명 |
| --- | --- | --- |
| `product` | `agenteye` | 이벤트를 전송한 제품 |
| `component` | `dashboard`, `server`, `cli` | 이벤트를 전송한 제품의 구성 요소 |
| `app_version` | `0.0.1-beta.81` | 실행 중인 빌드 버전 |
| `deployment_kind` | `self_hosted` | 고객 설치, 데모, QA, 또는 개발 환경 여부 |
| `org_id` | UUID | 작업이 발생한 조직의 불투명 식별자 |

이 외에도 이벤트는 **콘텐츠가 아닌 사용 현황만** 기록합니다. 예를 들어 조회한 페이지(실제 URL이 아닌 `/:org/sessions/:id`와 같은 라우트 패턴), 적용된 필터의 종류 및 수, 작업 성공 여부, 소요 시간 등이 포함됩니다.

Slack 앱은 워크스페이스 연결 및 해제, 계정 연동, 질문 수, 차트 게시, 승인 결정, 고정 카테고리별 오류를 기록합니다. Slack 워크스페이스, 사용자, 채널 ID, 이메일, 질문, 답변, SQL, 토큰은 절대 포함되지 않습니다.

### 조직 이름

불투명한 `org_id`와 함께 조직 이름, URL 슬러그, 대시보드 주소를 모든 이벤트가 아닌 조직 레코드에 한 번만 기록합니다. 이를 통해 사용 패턴이 어느 계정에 속하는지 파악하거나, 보고된 문제를 조사할 때 활용합니다. 이것이 제품이 사용자에 관해 전송하는 유일한 식별 정보입니다.

### 사용량 합계

서버는 각 조직의 측정된 사용량 합계를 보고하며, 이는 사용량 페이지에서 확인할 수 있는 수치와 동일합니다. 이벤트, 세션, 에이전트, 환경, 평가 실행, 점수, 감사 실행, 저장된 쿼리, 대시보드, 알림, 이슈, API 키, 멤버 수와 측정 기간의 날짜만 포함됩니다. 식별자, 이름, 쿼리 텍스트는 포함되지 않으며, 로그인 여부와 관계없이 전송됩니다.

## 절대 수집하지 않는 항목

- **프롬프트, 모델 응답, 이벤트 내용** — 텍스트, 접두사, 해시 형태 모두 포함하지 않습니다
- **세션, 에이전트, 트레이스 식별자**
- **평가자 점수 이름**
- **오류 메시지, 예외 텍스트, 응답 본문** — 상태 코드와 고정 목록의 카테고리만 포함됩니다
- **도구 인수, SQL, 쿼리 텍스트**
- **연결된 앱 세부 정보** — MCP 클라이언트 연결 또는 해제 시 권한 수만 전송되며, 앱 이름이나 토큰은 절대 포함되지 않습니다
- **이메일 주소**
- **리퍼러 URL 또는 쿼리 문자열**
- **화면 녹화, DOM 캡처, 클릭 및 커서 추적**

## 셀프 호스팅 설치에서 비활성화하기

대시보드와 서버 모두에 `DO_NOT_TRACK=1`을 설정하세요. 각각 독립적으로 동작하므로 한쪽에만 설정하면 나머지는 계속 보고합니다. 변경 사항을 적용하려면 서버를 재시작하세요.

릴리스 README에는 다른 옵트아웃 설정 및 텔레메트리 비활성화 확인 방법이 설명되어 있습니다.

## 옵트아웃 시 한 번의 핑 전송

`DO_NOT_TRACK` 대신 제품 설정으로 옵트아웃하면, 대시보드는 프로세스 시작 시 1/1000 확률로 이를 기록하는 **익명의 핑 하나**를 전송할 수 있습니다. 이를 통해 텔레메트리를 끄는 운영자 수를 파악합니다. 조직, 사용자, 호스트명, URL, IP 등의 식별자는 포함되지 않으며, 제품, 컴포넌트, 버전, 배포 유형, 사유만 포함됩니다. 옵트아웃된 서버는 아무것도 전송하지 않습니다.

`DO_NOT_TRACK`을 사용하면 이 핑도 전송되지 않습니다. 조직 정책상 외부 텔레메트리 전송을 금지하는 경우 이 설정을 사용하세요.

## 전송 대상

포트 443에서 TLS를 통해 PostHog(`us.i.posthog.com`)로 전송됩니다. 단일 호스트명이므로, 단일 이그레스 규칙으로 차단할 수도 있습니다.

개인 정보 처리 방식에 대한 자세한 내용은 [개인정보 처리방침](https://befailproof.ai/privacy/)을 참조하세요.
