Failproof AI Cloud는 소프트웨어 자체에 대한 사용 원격 측정 데이터를 유지 관리자에게 전송합니다. 에이전트의 데이터는 절대 포함되지 않습니다. 자체 호스팅 설치 시 기본적으로 활성화되어 있으며, 비활성화할 수 있습니다.

## 수집되는 항목

모든 이벤트는 다섯 가지 차원을 포함하며, 개인을 식별할 수 있는 정보는 포함하지 않습니다:

| 차원 | 예시 | 설명 |
| --- | --- | --- |
| `product` | `agenteye` | 이벤트를 전송한 제품 |
| `component` | `dashboard`, `server`, `cli` | 이벤트를 전송한 제품의 구성 요소 |
| `app_version` | `0.0.1-beta.81` | 실행 중인 빌드 버전 |
| `deployment_kind` | `self_hosted` | 고객 설치, 데모, QA, 개발 머신 여부 |
| `org_id` | UUID | 작업이 발생한 조직을 불투명한 식별자로 표현 |

이 외에도 이벤트는 **무엇이 사용되었는지를 기록하며, 그 내용은 절대 기록하지 않습니다**: 어떤 페이지가 조회되었는지(실제 URL이 아닌 `/:org/sessions/:id`와 같은 경로 패턴으로), 어떤 종류의 필터가 몇 개 적용되었는지, 작업의 성공 여부, 소요 시간 등이 기록됩니다.

Slack 앱은 워크스페이스 연결 및 해제, 계정 연동, 질문, 차트 게시, 승인 결정, 그리고 고정된 분류 체계에 따른 실패를 기록합니다. Slack 워크스페이스, 사용자, 채널 ID, 이메일, 질문 내용, 답변, SQL, 토큰은 절대 포함하지 않습니다.

### 조직 이름

불투명한 `org_id`와 함께, 조직의 이름, URL 슬러그, 대시보드 주소를 각 이벤트가 아닌 조직 레코드에 한 번 기록합니다. 이를 통해 채택 현황을 분석하거나 보고된 문제를 조사할 때 특정 패턴이 어느 계정에 속하는지 파악할 수 있습니다. 이것이 제품이 귀하에 대해 전송하는 유일한 식별 정보입니다.

### 사용량 합계

서버는 각 조직의 측정된 사용량 합계를 보고합니다. 이는 사용량 페이지에서 확인할 수 있는 수치와 동일합니다. 이벤트, 세션, 에이전트, 환경, 평가 실행 횟수, 점수, 감사 실행 횟수, 저장된 쿼리, 대시보드, 알림, 이슈, API 키, 멤버 수와 측정 기간의 날짜만을 포함하는 집계 수치입니다. 식별자, 이름, 쿼리 텍스트는 포함되지 않으며, 로그인 여부와 관계없이 전송됩니다.

## 절대 수집하지 않는 항목

- **프롬프트, 모델 응답, 이벤트 내용** — 텍스트, 접두사, 해시 형태 모두 수집하지 않습니다
- **세션, 에이전트, 트레이스 식별자**
- **평가자 점수 이름**
- **오류 메시지, 예외 텍스트, 응답 본문** — 상태 코드와 고정된 목록의 분류만 수집합니다
- **도구 인수, SQL, 쿼리 텍스트**
- **연결된 앱 세부 정보** — MCP 클라이언트를 연결하거나 해제할 때 권한 수만 전송하며, 앱 이름이나 토큰은 절대 포함하지 않습니다
- **이메일 주소**
- **리퍼러 URL 또는 쿼리 문자열**
- **화면 녹화, DOM 캡처, 클릭 및 커서 추적**

## 자체 호스팅 설치에서 비활성화하기

대시보드와 서버 양쪽 모두에 `DO_NOT_TRACK=1`을 설정하세요. 각각 독립적으로 판단하기 때문에, 한쪽에만 설정하면 나머지 한쪽은 계속 보고합니다. 변경 사항을 적용하려면 서버를 재시작하세요.

릴리스 README에는 다른 옵트아웃 설정과 원격 측정이 비활성화되었는지 확인하는 방법이 설명되어 있습니다.

## 옵트아웃 시 1회 핑

`DO_NOT_TRACK` 대신 제품 설정으로 옵트아웃하는 경우, 대시보드는 프로세스 시작 시 1/1000의 확률로 이를 기록하는 **익명 핑을 1회** 전송할 수 있습니다. 이는 얼마나 많은 운영자가 원격 측정을 비활성화하는지 파악하기 위한 것입니다. 식별자는 전혀 포함되지 않으며, 조직, 사용자, 호스트명, URL, IP가 아닌 제품, 구성 요소, 버전, 배포 유형, 이유만 포함합니다. 옵트아웃된 서버는 아무것도 전송하지 않습니다.

`DO_NOT_TRACK`을 사용하면 이 핑은 절대 전송되지 않으므로, 정책상 모든 아웃바운드 원격 측정이 금지된 경우 이 설정을 사용하세요.

## 전송 대상

TLS를 통해 포트 443으로 PostHog(`us.i.posthog.com`)에 전송됩니다. 단일 호스트명이므로, 하나의 이그레스 규칙으로 차단할 수도 있습니다.

개인 정보 처리에 대한 더 자세한 내용은 [개인정보 처리방침](https://befailproof.ai/privacy/)을 참조하세요.
