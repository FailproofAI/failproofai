Failproof AI Cloud는 소프트웨어 자체에 관한 사용 텔레메트리를 유지 관리자에게 전송합니다. 에이전트 데이터는 절대 포함되지 않습니다. 셀프 호스팅 설치 환경에서는 기본적으로 활성화되어 있으며, 직접 비활성화할 수 있습니다.

## 수집되는 항목

모든 이벤트에는 다섯 가지 차원이 포함되며, 개인을 식별할 수 있는 정보는 전혀 포함되지 않습니다:

| 차원 | 예시 | 설명 |
| --- | --- | --- |
| `product` | `agenteye` | 이벤트를 전송한 제품 |
| `component` | `dashboard`, `server`, `cli` | 이벤트를 전송한 제품의 구성 요소 |
| `app_version` | `0.0.1-beta.81` | 실행 중인 빌드 버전 |
| `deployment_kind` | `self_hosted` | 고객 설치, 데모, QA, 또는 개발 머신 여부 |
| `org_id` | UUID | 작업이 발생한 조직을 나타내는 불투명 식별자 |

이 외에도 이벤트는 **콘텐츠가 아닌 사용 여부만** 기록합니다. 예를 들어 조회된 페이지(실제 URL이 아닌 `/:org/sessions/:id`와 같은 라우트 패턴), 적용된 필터의 종류 및 수, 작업의 성공 여부, 소요 시간 등이 포함됩니다.

Slack 앱은 워크스페이스 연결 및 해제, 계정 연동, 질문, 차트 게시, 승인 결정, 그리고 고정된 카테고리별 오류를 기록합니다. Slack 워크스페이스, 사용자, 채널 ID, 이메일, 질문 내용, 답변, SQL, 토큰은 절대 포함되지 않습니다.

### 조직 이름

불투명한 `org_id`와 함께, 조직 이름, URL 슬러그, 대시보드 주소를 매 이벤트가 아닌 조직 레코드에 한 번만 기록합니다. 이를 통해 사용 패턴이 어떤 계정에 속하는지 파악하거나, 보고된 문제를 조사할 때 활용합니다. 이 항목이 제품이 여러분에 대해 전송하는 유일한 식별 정보입니다.

### 조직별 사용량 합계

서버는 각 조직의 계량된 사용량 합계를 보고합니다. 이는 사용량 페이지에서 확인할 수 있는 수치와 동일합니다. 이벤트, 세션, 에이전트, 환경, 평가 실행, 점수, 감사 실행, 저장된 쿼리, 대시보드, 알림, 이슈, API 키, 멤버 수와 계량 기간의 날짜만 포함됩니다. 식별자, 이름, 쿼리 텍스트는 포함되지 않으며, 로그인 여부와 관계없이 전송됩니다.

## 수집되지 않는 항목

- **프롬프트, 모델 응답, 이벤트 내용** — 텍스트, 접두사, 해시 형태를 막론하고 수집하지 않습니다
- **세션, 에이전트, 트레이스 식별자**
- **평가자 점수 이름**
- **오류 메시지, 예외 텍스트, 응답 본문** — 고정 목록의 상태 코드 및 카테고리만 수집됩니다
- **도구 인수, SQL, 쿼리 텍스트**
- **연결된 앱 세부 정보** — MCP 클라이언트를 연결하거나 해제할 때 최대 권한 수만 전송되며, 앱 이름이나 토큰은 포함되지 않습니다
- **이메일 주소**
- **리퍼러 URL 또는 쿼리 문자열**
- **화면 녹화, DOM 캡처, 클릭 및 커서 추적**

## 셀프 호스팅 환경에서 비활성화하기

대시보드와 서버 양쪽 모두에 `DO_NOT_TRACK=1`을 설정하세요. 각각 독립적으로 판단하므로, 한쪽에만 설정하면 나머지는 계속 보고합니다. 변경 사항을 적용하려면 서버를 재시작하세요.

릴리스 README에서 다른 옵트아웃 설정 및 텔레메트리 비활성화 확인 방법을 확인할 수 있습니다.

## 옵트아웃 시 한 번의 핑 전송

제품 설정으로 옵트아웃하는 경우(즉, `DO_NOT_TRACK`을 사용하지 않는 경우), 대시보드가 프로세스 시작 시 1/1000의 확률로 **익명의 핑 하나**를 전송할 수 있습니다. 이를 통해 텔레메트리를 비활성화하는 운영자의 수를 파악합니다. 이 핑에는 식별 정보가 포함되지 않습니다. 조직, 사용자, 호스트명, URL, IP 주소는 포함되지 않으며, 제품, 컴포넌트, 버전, 배포 종류, 비활성화 이유만 포함됩니다. 옵트아웃된 서버는 아무것도 전송하지 않습니다.

`DO_NOT_TRACK`을 사용하면 이 핑도 전송되지 않습니다. 아웃바운드 텔레메트리를 완전히 금지하는 정책이 있다면 이 방법을 사용하세요.

## 전송 대상

포트 443에서 TLS를 통해 PostHog(`us.i.posthog.com`)로 전송됩니다. 단일 호스트명이므로 단일 이그레스 규칙으로 차단할 수도 있습니다.

개인 정보를 보다 광범위하게 처리하는 방법은 [개인정보 처리방침](https://befailproof.ai/privacy/)을 참조하세요.
