조직 설정은 해당 Cloud 조직의 모든 구성원에게 영향을 미칩니다. **Admin → settings**에서 변경하거나 `fp settings` 명령을 사용하세요.

```bash
fp settings list
fp settings set <key> <value>
```

## 데이터 처리

연결된 머신은 기본적으로 정책 결정 사항과 전체 세션 기록을 전송합니다. 결정 사항만 전송하려면, 머신을 연결한 후 `~/.failproofai/config.json`의 `collector.sessions`를 `false`로 설정하세요. 현재 `--no-transcripts` 설정 플래그는 해당 설정을 적용하지 않습니다.

자격 증명은 업로드 전 머신에서 제거되지만, 이는 최소한의 안전 장치일 뿐 접근 제어를 대체하지 않습니다.

로컬 전용으로 사용하는 경우 계정이 필요 없습니다. 세션 기록과 감사 내역은 머신에 저장되며, 예외적으로 예약된 로컬 감사의 경우 사용자가 동의한 후에만 머신 식별 정보와 제한된 요약 정보를 전송합니다. 익명 CLI 원격 측정은 `FAILPROOFAI_TELEMETRY_DISABLED=1`로 비활성화할 수 있습니다.

## 자격 증명

머신 토큰은 `~/.failproofai/` 디렉토리에 소유자 전용 권한으로 저장됩니다. 서비스 정의에는 기록되지 않습니다.

사람, 자동화, 머신에 대해 별도의 키를 사용하세요. 각각 필요한 권한만 부여하고, 소유권이 변경될 때 교체하며, 머신이나 워크플로가 폐기될 때 revoke하세요.

## 체크리스트

- 필요한 최소한의 권한만 요청하세요.
- 전체 콘텐츠가 불필요한 경우 `collector.sessions`를 `false`로 설정하세요.
- 강제 정책을 배포할 수 있는 대상을 검토하세요.
- 정책을 적용하기 전에 observe 모드에서 테스트하세요.
- 머신 레이블을 명확하게 유지하고 머신 ID를 안정적으로 관리하세요.
- 연결 설정을 변경한 후 `failproofai config --status`를 실행하세요.

권한 카탈로그는 [키 및 권한](/ko/admin/keys-and-permissions)을 참조하세요.
