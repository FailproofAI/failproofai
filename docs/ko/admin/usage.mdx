사용량 페이지에서는 현재 조직의 소비량과 청구 기간을 확인할 수 있습니다. 프로덕션 배포, 트랜스크립트 볼륨, 평가, 감사 주기가 플랜에 미치는 영향을 파악하는 데 활용하세요.

## 사용량 확인

<Tabs>
  <Tab title="대시보드">
    1. **Administration → Usage**로 이동합니다.
    2. 조직과 측정 기간을 확인합니다.
    3. 수집, 세션, 평가, 메트릭, 감사, 결과, 알림, 사용자, 키를 검토합니다.
    4. 감사 사용량이 예상과 다를 경우 시작된 감사 작업과 완료된 감사 작업을 비교합니다.

    ![측정 기간, 캡처된 이벤트, 평가 및 감사 파이프라인, 워크스페이스 리소스, 멤버, API 키를 보여주는 사용량 페이지.](/images/dashboard/usage-overview.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp usage
    fp --json usage
    fp --org reliability-team --json usage
    ```
  </Tab>
</Tabs>

## 변경 사항 조사

1. 활성 조직과 기간을 확인합니다.
2. 증가량을 환경별 세션 볼륨과 비교합니다.
3. 새로운 통합이 트랜스크립트를 전송하기 시작했는지 확인합니다.
4. 평가자 및 감사 주기 변경 사항을 검토합니다.
5. 현재 요금제의 한도와 비교합니다.

CLI는 스크립트에도 동일한 요약 정보를 반환합니다.
