에이전트 데이터에 대해 자연어로 질문하고, 근거 데이터로 바로 연결되는 답변을 받아보세요. SQL을 작성할 필요도, 대시보드를 뒤질 필요도 없습니다 — **Failproof AI Observability** 어시스턴트는 팀 누구든 에이전트에 대한 답변을 가장 빠르게 얻을 수 있는 방법입니다.

![대시보드 내에서 자연어 질문에 답변하는 Failproof AI Observability 어시스턴트 화면. 실시간 에이전트 활동 테이블, 에이전트별 모델 사용 현황, 주요 인사이트, 그리고 인라인으로 표시된 실행 쿼리가 포함되어 있습니다.](/agenteye/images/assistant.png)
*자연어로 질문하면 내 데이터를 바탕으로 구성된 답변을 받을 수 있습니다. 여기서는 가장 활발한 에이전트와 그들이 사용하는 모델을 분석하고, 모든 수치를 직접 검증할 수 있도록 실행된 쿼리도 함께 보여줍니다.*

배워야 할 것은 없습니다. 채팅을 열고, 알고 싶은 내용을 입력한 뒤, 돌아온 링크를 따라가기만 하면 됩니다:

```
You:  which sessions errored today?
AI:   5 sessions errored today, newest first. Each one is linked:
      • checkout-agent   14:02   tool timeout
      • billing-agent    11:47   unhandled error
      • ...and 3 more

You:  summarize this session          (asked while viewing a run)
AI:   This run took 12 steps across 3 tools and failed near the end when a
      payment tool returned an error. It scored low on your "resolved" eval.
      Links: the session, the failing event, and that evaluation.
```

## 그냥 물어보고, 바로 증거로 이동하세요

추측도, 쿼리 작성도 이제 그만입니다. "이번 주 프로덕션 품질 트렌드는 어때?", "오늘 오류가 발생한 세션은?", "이 세션 요약해줘" 같은 질문을 하면, 쿼리를 직접 작성하고 결과를 해석하는 대신 몇 초 만에 명확한 답변을 받을 수 있습니다.

모든 답변에는 근거가 함께 제공됩니다. 어시스턴트는 답변을 도출하는 데 사용한 정확한 세션, 저장된 쿼리, 대시보드 링크를 제공하므로, 그냥 믿는 대신 직접 클릭해서 확인할 수 있습니다. 또한 **페이지 인식** 기능도 있습니다: 특정 세션을 보는 중에 "이 세션"에 대해 질문하면 어시스턴트가 어떤 실행을 말하는지 이미 파악하고 있습니다. 히스토리 전환기를 통해 이전 대화를 나중에 다시 열고 이어서 진행할 수도 있습니다.

## 좋은 답변을 저장된 쿼리나 대시보드로 변환하세요

보관할 가치가 있는 답변이 나왔다면, 어시스턴트에게 저장해달라고 요청하세요. 어시스턴트가 저장된 쿼리용 SQL 초안을 작성하거나 해당 쿼리들로 대시보드를 구성한 뒤, **승인 / 거절** 카드를 보여줍니다. 승인을 클릭하기 전까지는 아무것도 저장되지 않으므로, "그냥 물어보는" 속도를 누리면서도 최종 결정권은 항상 여러분에게 있습니다.

**Queries** 페이지에서는 한 단계 더 나아가 SQL 작성자 역할을 합니다: 원하는 쿼리를 설명하면("지난 7일간 에이전트별 오류율 보여줘") 에디터에 SQL을 바로 스트리밍하고, 변경 사항이 적용되기 전에 **Accept** 또는 **Reject** 할 수 있는 diff 뷰를 열어줍니다.

![Observability Queries 페이지와 SQL 에디터](/agenteye/images/query-lab.png)
*Queries 페이지: 어시스턴트가 초안 읽기 전용 쿼리를 스트리밍하면 이 에디터에서 수락하거나 거절할 수 있습니다.*

여기서 질문으로 SQL을 작성하면 에디터의 **Run** 버튼과 동일한 `queries:run` 권한을 사용합니다. 다른 모든 곳에서의 채팅에는 `agent:use` 권한이 필요합니다.

## 전체 팀에게 안심하고 개방할 수 있습니다

어시스턴트가 무엇을 건드릴지 걱정하지 않고 모든 사람에게 열어줄 수 있습니다:

- **이미 볼 수 있는 것만 읽습니다.** 답변은 내 읽기 권한 범위 내로 제한되므로, 데이터 접근 범위가 넓어지는 일은 없습니다.
- **모든 쓰기 작업은 여러분의 확인을 기다립니다.** 저장된 쿼리와 대시보드는 명시적으로 승인을 클릭한 후에만 생성되며, 이 단계를 비활성화하는 설정은 없습니다.
- **어떤 것도 삭제할 수 없습니다.** 삭제 도구가 노출되지 않으며 어시스턴트는 삭제 권한을 갖지 않습니다. 삭제는 대시보드에서 여러분이 직접 수행합니다.
- **내 조직 내에서만 동작합니다.** 어시스턴트는 현재 보고 있는 조직의 데이터만 볼 수 있습니다.
- **내 질문은 내 것입니다.** 프롬프트와 답변은 내 Observability 데이터베이스에 저장되며, 제품 분석은 사용 메타데이터만 기록하고 프롬프트 텍스트는 기록하지 않습니다.

## 찾는 방법

어시스턴트는 조직 경로(`/<org-slug>/...`) 하위 모든 페이지의 오른쪽 가장자리에 상시 표시됩니다. 레일을 클릭하거나 `⌘J` / `Ctrl+J`를 눌러 전체 채팅 패널로 확장하고, 가장자리를 드래그해 크기를 조절할 수 있으며 설정한 너비는 새로고침 후에도 유지됩니다. 사용하려면 **`agent:use`** 권한이 필요하며, 없으면 레일이 회색으로 비활성화됩니다. 아직 배포에 활성화되지 않은 경우(LLM 연결이 필요합니다), 작동하는 채팅 대신 비활성화된 레일이 표시됩니다.
