Failproof AI Observability 배포 전체를 명령어 하나로 관리하세요. 터미널을 벗어나지 않고도 프로덕션을 확인하고, API 키를 생성하고, 인시던트를 확인할 수 있습니다. CI에 스크립트로 통합하거나, 코딩 에이전트가 자연어로 처리하도록 맡길 수도 있습니다.

```bash
pipx install agenteye
agenteye login --email you@example.com      # 6자리 코드가 받은 편지함으로 전송됩니다
agenteye --json sessions --since 24h         # 최근 하루 동안의 모든 에이전트 실행 내역, 최신순 정렬
```

*`agenteye` CLI는 대시보드와 통신합니다. 서버로 이벤트를 전송하는 컬렉터와는 별개의 도구입니다.*

## 배포 전체를 명령어 하나로

간단한 질문 하나에 답하기 위해 탭을 이리저리 전환할 필요가 없습니다. `agenteye` CLI는 단일 바이너리로 데이터를 읽고 조직을 관리하므로, 대시보드를 클릭해서 확인하던 작업이 한 줄 명령으로 줄어듭니다. 재실행하거나, 별칭으로 등록하거나, 런북에 붙여넣을 수 있습니다. 네 가지 기능을 제공합니다:

- **데이터 조회:** 시간, 에이전트, 환경별로 필터링된 `sessions`, `events`, `evals`, `errors`.
- **조직 관리:** `keys`, `users`, `settings`, `alerts`, `incidents`.
- **분석 실행:** 저장된 SQL과 이벤트 데이터에 대한 임시 `query` 실행기.
- **어시스턴트 호출:** `agent ask`로 대시보드에서 사용하는 읽기 전용 분석가와 동일한 기능을 이용.

`pipx`로 한 번 설치하고, 이메일로 전송된 6자리 코드로 로그인하면 바로 사용할 수 있습니다. 세션은 약 하루 동안 유지되며, 만료되면 `agenteye login`을 다시 실행하세요. 브라우저를 열지 않고도 프로덕션 상태를 점검하고, 키를 발급하고, 발생한 인시던트를 분류할 수 있습니다:

```bash
agenteye errors --since 24h --aggregate      # 오류 유형별로 그룹화된 장애 현황
agenteye incidents list --state firing       # 현재 발생 중인 인시던트 목록
agenteye keys create ci --add events:add     # 이벤트 전송만 가능한 키 생성, 시크릿은 한 번만 표시
```

알아두면 좋은 습관: `--json`과 같은 전역 옵션은 명령어 앞에 위치해야 합니다. `agenteye --json sessions`는 올바른 형식이지만, `agenteye sessions --json`은 그렇지 않습니다.

## 스크립트로 작성하고 CI에 연결하기

모든 명령어에 `--json`을 사용할 수 있으며, 이것이 모든 것을 바꿉니다. 깔끔한 JSON은 stdout으로, 사람이 읽는 상태 메시지와 경고는 stderr로 출력됩니다. 따라서 `--json`으로 캡처한 출력은 불필요한 줄 제거 없이 바로 `jq`로 파이프할 수 있습니다. 이 덕분에 CLI는 프롬프트를 직접 사용하는 개발자와 출력을 파싱하는 코딩 에이전트 모두에게 동일하게 유용합니다:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

무인 실행을 위해 설계되었습니다. 터미널이 연결되어 있지 않으면 확인 프롬프트가 자동으로 건너뛰어져 파이프라인이 멈추지 않으며, 모든 명령어는 의미 있는 종료 코드를 반환합니다: `0` 성공, `4` 미로그인, `5` 권한 부족(메시지에 `alerts:write` 등 해당 권한이 명시됨), `3` 대시보드 연결 불가. 스크립트에서 `4`를 감지하면 재인증을 수행하거나, `5`를 감지하면 어떤 권한을 관리자에게 요청해야 하는지 정확히 알 수 있습니다. 실패 원인을 모르는 채로 중단되는 일이 없습니다.

## 코딩 에이전트가 자연어로 처리하도록 하기

더 나아가, 이러한 플래그를 전혀 기억하지 않아도 됩니다. **CLI 스킬**은 `agenteye-cli`라는 작은 Agent Skill 폴더로, Claude Code나 Codex 같은 코딩 에이전트가 자연어 요청으로 CLI를 구동할 수 있도록 가르쳐줍니다. "오늘 문제가 있는 게 있나요?"라고 물으면 에이전트가 적절한 명령어를 선택해 실행하고 결과를 문장으로 답변합니다.

Claude Code의 경우, `agenteye-cli` 폴더를 `~/.claude/skills/`에 넣으면 자동으로 인식됩니다. Failproof AI Observability가 해당 폴더를 제공하며, 이미 설치된 CLI를 구동하는 방식이므로 추가로 설치할 것은 없습니다. 로그인은 직접 먼저 해야 합니다. 스킬이 이메일 코드 로그인을 대신 완료할 수 없기 때문입니다.

에이전트는 사용자의 로그인으로 CLI를 실행하므로, 로그인 권한이 허용하는 모든 작업을 수행할 수 있습니다. 읽기와 쓰기 모두 포함됩니다: 키 생성, 설정 변경, 인시던트 해결. 에이전트에 대해서는 CLI의 확인 프롬프트가 실행되지 않으므로, 스킬은 변경 사항 실행 전에 정확한 명령어를 명시하고 사용자의 승인을 기다리도록 작성되어 있습니다. 확인 단계는 사용자가 직접 수행합니다.

```text
you    session run-001이 왜 실패했나요?

agent  실행 중: agenteye --json events --session-id run-001 --all
       checkout-agent가 세 번째 도구 호출에서 TimeoutError가 발생했습니다.
```

읽기는 즉시 처리되며, 모든 쓰기 작업은 사용자 승인을 기다립니다:

```text
you    CI에 이벤트 전송만 가능한 키를 발급해 주세요.

agent  API 키를 생성합니다. 다음 명령어를 실행할 예정입니다:
         agenteye keys create ci --add events:add
       진행해도 될까요?

you    yes

agent  완료되었습니다. "ci" 키가 events:add 권한만으로 생성되었습니다. 시크릿은 한 번만 표시되므로 지금 저장해 두세요.
```
