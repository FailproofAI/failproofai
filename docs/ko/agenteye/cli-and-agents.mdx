Failproof AI Observability 전체 배포를 단 하나의 명령으로. 터미널을 벗어나지 않고도 프로덕션을 확인하고, API 키를 발급하고, 인시던트를 확인할 수 있습니다. CI에 스크립트로 삽입하거나, 코딩 에이전트가 자연어로 대신 처리하도록 할 수도 있습니다.

```bash
pipx install agenteye
agenteye login --email you@example.com      # 6자리 코드가 이메일로 전송됩니다
agenteye --json sessions --since 24h         # 최근 하루 동안의 모든 에이전트 실행 기록, 최신순
```

*`agenteye` CLI는 대시보드와 통신합니다. 이벤트를 서버로 전송하는 수집기(collector)와는 별개의 도구입니다.*

## 전체 배포를 단 하나의 명령으로

간단한 질문에 답하려고 탭을 이리저리 전환할 필요가 없습니다. `agenteye` CLI는 단일 바이너리로 데이터를 읽고 조직을 관리하므로, 예전에는 대시보드를 클릭해야 했던 확인 작업이 한 줄 명령으로 해결됩니다. 재실행하거나, 별칭으로 등록하거나, 런북에 붙여 넣을 수 있습니다. 네 가지 영역을 제공합니다:

- **데이터 조회:** 시간, 에이전트, 환경별로 필터링된 `sessions`, `events`, `evals`, `errors`.
- **조직 관리:** `keys`, `users`, `settings`, `alerts`, `incidents`.
- **분석 실행:** 저장된 SQL 및 이벤트 데이터에 대한 임시 `query` 실행기.
- **어시스턴트 활용:** `agent ask`로 대시보드에서 사용하는 읽기 전용 분석가에게 질문.

`pipx`로 한 번 설치하고, 이메일로 전송된 6자리 코드로 로그인하면 바로 사용할 수 있습니다. 세션은 약 하루 동안 유지되며, 만료되면 `agenteye login`을 다시 실행하세요. 브라우저를 열지 않고도 프로덕션 상태를 빠르게 확인하고, 키를 발급하고, 발생 중인 인시던트를 분류할 수 있습니다:

```bash
agenteye errors --since 24h --aggregate      # 오류 유형별로 그룹화된 장애 현황
agenteye incidents list --state firing       # 현재 발생 중인 인시던트
agenteye keys create ci --add events:add     # 이벤트 전송만 가능한 키, 시크릿은 한 번만 표시
```

알아두어야 할 한 가지 습관: `--json`과 같은 전역 옵션은 명령 앞에 위치해야 합니다. `agenteye --json sessions`는 올바르지만, `agenteye sessions --json`은 올바르지 않습니다.

## 스크립트로 작성하고 CI에 연동하기

모든 명령은 `--json`을 지원하며, 이것이 모든 것을 바꿉니다. 깔끔한 JSON은 stdout으로 출력되고, 사람이 읽는 상태 메시지와 경고는 stderr로 출력됩니다. 따라서 `--json`으로 캡처한 내용은 불필요한 줄을 제거할 필요 없이 바로 `jq`로 파이프할 수 있습니다. CLI가 프롬프트에서 직접 사용하거나 출력을 파싱하는 코딩 에이전트 모두에게 적합한 이유가 바로 여기에 있습니다:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

무인 실행을 위해 설계되었습니다. 터미널이 연결되어 있지 않으면 확인 프롬프트가 자동으로 생략되므로 파이프라인이 중단되지 않으며, 각 명령은 의미 있는 종료 코드를 반환합니다: `0` 성공, `4` 미로그인, `5` 권한 없음(메시지에 권한명 표시, 예: `alerts:write`), `3` 대시보드 연결 불가. 스크립트에서 `4`를 감지해 재인증하거나, `5`를 감지해 관리자에게 정확히 어떤 권한이 필요한지 알릴 수 있어 오류가 명확해집니다.

## 코딩 에이전트가 자연어로 대신 처리하도록 하기

더 나아가, 이 플래그들을 전혀 외울 필요가 없습니다. **CLI 스킬**은 `agenteye-cli`라는 이름의 작은 Agent Skill 폴더로, Claude Code나 Codex 같은 코딩 에이전트가 자연어 요청으로 CLI를 구동할 수 있도록 가르칩니다. "오늘 문제 있는 게 있어?"라고 물으면 에이전트가 적절한 명령을 선택해 실행하고 문장으로 답변합니다.

Claude Code의 경우, `agenteye-cli` 폴더를 `~/.claude/skills/`에 넣으면 자동으로 인식됩니다. Failproof AI Observability가 해당 폴더를 제공하며, 이미 설치한 CLI를 구동하는 것뿐이므로 추가로 설치할 것이 없습니다. 먼저 직접 로그인해두세요. 스킬은 이메일 코드 로그인 과정을 대신 처리할 수 없습니다.

에이전트는 사용자 로그인 권한으로 CLI를 실행하므로, 키 생성, 설정 변경, 인시던트 해결 등 허용된 모든 읽기 및 쓰기 작업을 수행할 수 있습니다. 에이전트에게는 CLI의 확인 프롬프트가 표시되지 않으므로, 스킬은 변경 작업 전에 정확한 명령을 명시하고 사용자의 승인을 기다리도록 설계되어 있습니다. 최종 확인은 사용자가 합니다.

```text
you    session run-001이 왜 실패했나요?

agent  실행 중: agenteye --json events --session-id run-001 --all
       checkout-agent가 세 번째 도구 호출에서 TimeoutError가 발생했습니다.
```

읽기 작업은 즉시 완료되며, 모든 쓰기 작업은 사용자의 확인을 기다립니다:

```text
you    CI에 이벤트 전송만 가능한 키를 발급해 주세요.

agent  API 키를 생성합니다. 다음 명령을 실행할게요:
         agenteye keys create ci --add events:add
       진행할까요?

you    yes

agent  완료. "ci" 키가 events:add 권한으로 생성되었습니다. 시크릿은 한 번만 표시되므로 지금 저장하세요.
```
