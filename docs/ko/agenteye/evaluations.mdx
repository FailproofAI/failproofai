이제 품질 문제가 먼저 찾아옵니다. 사용자 불만을 통해 뒤늦게 알게 되는 일은 없습니다. 자체 채점 서비스를 한 번만 연결해 두면, Failproof AI Observability가 완료된 모든 실행을 자동으로 채점합니다. 유용성 저하나 환각(hallucination) 급증이 고객이 체감하기 전에 스스로 드러납니다.

![점수 열이 있는 세션 그리드: 각 실행에는 평가 상태 표시와 색상으로 구분된 유용성, 사실성, 도구 효율성 배지가 표시됩니다](/agenteye/images/sessions-list.png)

*세션 그리드의 모든 실행에 점수가 표시되며, 빨강·노랑·초록 배지 덕분에 트랜스크립트를 하나도 열지 않아도 문제 있는 실행이 바로 눈에 띕니다.*

## 수동 샘플링을 그만하세요

예전에는 몇 가지 실행을 직접 점검하고 나머지는 괜찮기를 바랐을 것입니다. 이제는 완료된 모든 세션이 종료되는 즉시, 유용성·도구 효율성·사실성·안전성 등 여러분이 중요하게 생각하는 기준에 따라 채점됩니다. 점수 키는 여러분이 정의하고, Failproof AI Observability는 평가자가 반환하는 모든 값을 저장·추적·표시합니다. 채점에서 빠지는 실행은 없으며, 회귀 문제를 지원 티켓을 통해 뒤늦게 알게 되는 일도 사라집니다.

점수는 **`/<org-slug>/sessions`**(사이드바 → *observe* → *sessions*)의 세션 그리드에 행마다 배지 묶음으로 표시됩니다. 기준에 미달한 실행만 보고 싶다면, 예를 들어 유용성이 0.5 미만인 경우처럼 점수 범위로 그리드를 필터링해 꼭 확인해야 할 실행만 추출하세요. 점수 조회에는 `evaluations:read` 권한이 필요합니다.

## 낮은 점수의 원인 파악하기

숫자는 실행이 부실했다는 사실만 알려주지만, 세션 페이지는 그 이유를 알려줍니다. 실행을 열면 오른쪽 패널 상단에 요약이 표시되고, 각 평가 차원별 막대와 함께 평가자가 작성한 이유가 표시되어, "사실성 점수가 0.4"에서 정확히 어떤 주장이 틀렸는지를 몇 초 만에 파악할 수 있습니다.

![세션 오른쪽 패널: 상단의 평가 요약, 이유가 함께 표시되는 차원별 점수 막대, 그리고 전체 이벤트 타임라인](/agenteye/images/session-detail.png)

*세션 상세 뷰: 요약, 차원별 점수 막대, 각 점수의 근거가 실행 이벤트 타임라인 바로 옆에 표시됩니다.*

평가자를 개선했거나, 채점 전에 중단된 실행을 확인하고 싶다면? **re-evaluate** 버튼(`evaluations:trigger` 권한 필요)을 클릭하면 세션을 즉시 재채점하고 새 결과를 타임라인에 추가합니다. 이전 점수는 기록으로 그대로 남습니다. **`/<org-slug>/sessions/<session-id>`**에서 확인할 수 있습니다.

## 전체 플리트의 품질 추이 모니터링

한 실행의 낮은 점수는 노이즈일 수 있지만, 전체 코호트가 하락하는 것은 신호입니다. 저장된 대시보드는 점수를 한눈에 볼 수 있는 추이로 변환해 줍니다. 에이전트별, 환경별로 이번 주와 지난주의 평균 유용성을 비교해 보세요.

![품질 대시보드: 평가자 차원별 평균 점수 막대와 시간 경과에 따른 추이](/agenteye/images/dashboard-quality.png)

*저장된 품질 대시보드는 주요 점수 키의 추이를 보여주므로, 인시던트가 발생하기 훨씬 전에 완만한 하락을 감지할 수 있습니다.*

대시보드는 **`/<org-slug>/dashboards`**(사이드바 → *analyze* → *dashboards*)에 있으며 조직 전체에서 공유됩니다. 각 카드는 해당 세션을 집계하여 세션 수, 주요 점수별 평균, 추이 스파크라인을 표시합니다. "Open in sessions"를 클릭하면 특정 수치의 배경이 되는 사전 필터링된 실행으로 바로 이동합니다. 조회에는 `dashboards:read`와 `evaluations:read` 권한이 모두 필요합니다.

## 평가자를 한 번만 연결하세요

채점은 선택 사항이며, Failproof AI Observability에 채점기를 연결하기 전까지는 완전히 비활성화 상태입니다. 작은 HTTP 서비스를 하나 구성하고(Observability에서 복사 가능한 참조 구현을 제공합니다), 서버에 두 가지 값을 설정하면 이후의 모든 실행이 자동으로 채점됩니다. 전체 안내, 채점 계약, SDK는 상세 가이드에 있습니다.

어떤 차원을 채점할지 모르겠다면? [evaluator agent skill](/ko/agenteye/evaluator-skill)을 통해 코딩 에이전트가 자체 세션을 분석해 점수 차원을 결정하고 서비스를 빌드 및 배포합니다.
