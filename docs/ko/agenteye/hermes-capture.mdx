[Hermes](https://hermes-agent.nousresearch.com)는 팀이 이미 사용하는 곳이라면 어디서든 — Slack, Telegram, CLI, 예약 실행 — 응답을 제공합니다. Hermes 세션 캡처는 이 모든 활동을 AgentEye에 일반 세션과 이벤트로 가져오므로, 팀이 매일 사용하는 어시스턴트를 직접 작성한 에이전트와 동일한 수준으로 관찰할 수 있습니다.

소규모 백그라운드 수집기가 Hermes의 로컬 세션 저장소를 기록되는 즉시 읽어 AgentEye로 전송합니다. [Codex](/ko/agenteye/codex-capture) 및 [OpenClaw](/ko/agenteye/openclaw-capture) 캡처와 동일한 방식으로 작동하며, 하나의 수집기로 여러 소스를 동시에 캡처할 수 있습니다.

---

## 캡처 대상

머신에 있는 모든 Hermes 세션이 캡처되며, 출처 채널에 관계없이 적용됩니다. 각 세션은 AgentEye [세션](/ko/agenteye/sessions)으로 변환되고, 사용자 및 어시스턴트 메시지, 도구 호출, 도구 결과는 해당하는 [이벤트](/ko/agenteye/event-stream)로 기록됩니다.

세션이 시작된 채널(Slack, Telegram, CLI, 또는 예약 실행)이 세션에 기록되므로 채널별로 구분하거나 하나씩 필터링할 수 있습니다. 함께 기록되는 정보로는 세션이 실행된 모델, 시작된 채팅 및 대화 상대, 그리고 세션이 다른 세션을 생성한 경우 상위 세션으로의 연결 링크가 있습니다.

세션은 Hermes가 시작하는 즉시 나타나며, 아직 아무런 대화가 없어도 마찬가지입니다. 각 턴의 응답과 도구 호출은 실제 발생한 순서대로 유지됩니다. 세션이 종료되면 종료 이유, 비용, 사용된 토큰 수도 함께 확인할 수 있습니다.

---

## 활성화 방법

캡처는 기본적으로 비활성화되어 있으며, 직접 활성화해야 합니다. `events:add` 권한이 있는 API 키([API keys](/ko/agenteye/api-keys) 참조)로 수집기를 설치하고 Hermes 캡처를 활성화합니다.

```bash
curl -fsSL https://raw.githubusercontent.com/FailproofAI/agenteye-collector/main/install.sh \
  | sh -s -- --key <YOUR_API_KEY> --hermes-enabled
```

이 명령은 수집기를 설치하고, 백그라운드 서비스로 등록하며, 캡처를 시작합니다. 정상 실행 여부를 확인하려면 다음을 실행합니다.

```bash
agenteye-collector health
```

같은 머신에서 여러 에이전트를 캡처하려면 각 에이전트의 플래그를 동일한 명령에 추가하면 됩니다. 예를 들어 `--hermes-enabled --codex-enabled`와 같이 사용합니다.

최초 실행 시, 기존 Hermes 세션이 한 번 백필되고 이후 새로운 활동은 수 초 내에 스트리밍됩니다. Hermes의 데이터는 읽기만 하며 수정하거나 삭제하지 않고, 각 메시지는 재시작 여부와 관계없이 한 번만 전송됩니다.

`health` 명령은 수집기가 캡처한 모든 데이터가 실제로 AgentEye에 도달했는지도 알려줍니다. 배치 전송에 실패하면 데이터는 폐기되지 않고 보관되어 재시도되며, 미전송 데이터가 남아 있는 동안은 비정상(unhealthy) 상태로 표시됩니다. 따라서 "정상(healthy)"은 단순히 프로세스가 실행 중임을 의미하는 것이 아니라, 데이터가 실제로 도착했음을 의미합니다.

## 확인 위치

캡처된 세션은 **Sessions**에 표시되고, 이벤트는 **Events** 스트림에 표시됩니다. 다른 에이전트와 동일하게 처리되므로 [세션 리플레이](/ko/agenteye/sessions), [검색](/ko/agenteye/queries), [평가](/ko/agenteye/evaluations), [알림](/ko/agenteye/alerts) 기능을 모두 사용할 수 있습니다. Hermes 에이전트로 필터링하면 해당 세션만 따로 볼 수 있습니다.

---

## 개인 정보 보호

Hermes 세션에는 명령 출력, 파일 내용, 에이전트가 읽거나 쓴 모든 내용 등 전체 대화 기록이 포함되며, 시크릿(비밀 정보)이 포함될 수 있습니다. 캡처된 세션은 있는 그대로 전송되므로, AgentEye에 해당 콘텐츠를 중앙화하는 것이 적절한 환경에서만 캡처를 활성화하고, 수집기에는 `events:add` 권한만 부여된 키를 사용하세요. 데이터 격리 방식에 대한 자세한 내용은 [Security](/ko/agenteye/security)를 참조하세요.
