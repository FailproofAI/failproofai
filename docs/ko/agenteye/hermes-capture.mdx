[Hermes](https://hermes-agent.nousresearch.com)는 팀이 이미 사용하는 모든 채널(Slack, Telegram, CLI, 예약 실행)에서 질문에 답합니다. Hermes 세션 캡처를 사용하면 이 모든 것을 AgentEye에 일반 세션 및 이벤트로 가져올 수 있어, 팀이 매일 대화하는 어시스턴트를 직접 작성한 에이전트와 동일한 수준으로 관찰할 수 있습니다.

소형 백그라운드 수집기가 Hermes의 로컬 세션 저장소에 기록되는 내용을 읽어 AgentEye로 전송합니다. 동작 방식은 [Codex](/ko/agenteye/codex-capture) 및 [OpenClaw](/ko/agenteye/openclaw-capture) 캡처와 동일하며, 하나의 수집기로 여러 에이전트를 동시에 캡처할 수 있습니다.

---

## 캡처되는 내용

어떤 채널에서 시작되었든 관계없이, 해당 머신의 모든 Hermes 세션이 캡처됩니다. 각 세션은 AgentEye [세션](/ko/agenteye/sessions)이 되며, 사용자 및 어시스턴트 메시지, 도구 호출, 도구 결과는 대응하는 [이벤트](/ko/agenteye/event-stream)가 됩니다.

세션이 시작된 채널(Slack, Telegram, CLI, 예약 실행)이 세션에 기록되므로 채널별로 구분하거나 하나씩 필터링할 수 있습니다. 함께 기록되는 정보로는 세션에서 사용된 모델, 세션이 시작된 채팅과 사용자, 그리고 세션이 다른 세션을 생성한 경우 상위 세션으로의 링크가 있습니다.

세션은 Hermes가 시작하는 즉시 나타나며, 아직 아무 말도 오가지 않은 상태여도 마찬가지입니다. 한 턴의 응답과 도구 호출은 실제로 발생한 순서대로 유지됩니다. 세션이 종료되면 종료 이유, 비용, 사용된 토큰 수도 함께 확인할 수 있습니다.

---

## 활성화 방법

캡처는 직접 활성화하기 전까지 비활성 상태입니다. `events:add` 권한이 있는 API 키([API 키](/ko/agenteye/api-keys) 참조)로 수집기를 설치하고 Hermes 캡처를 켭니다.

```bash
curl -fsSL https://raw.githubusercontent.com/FailproofAI/agenteye-collector/main/install.sh \
  | sh -s -- --key <YOUR_API_KEY> --hermes-enabled
```

이 명령은 수집기를 설치하고 백그라운드 서비스로 등록한 뒤 캡처를 시작합니다. 정상 실행 여부를 확인하려면 다음을 실행하세요.

```bash
agenteye-collector health
```

같은 머신에서 여러 에이전트를 캡처하려면? 동일한 명령에 각 에이전트의 플래그를 추가하면 됩니다. 예를 들어 `--hermes-enabled --codex-enabled`와 같이 사용합니다.

최초 실행 시 기존 Hermes 세션이 한 번 백필되고, 이후의 새 활동은 몇 초 이내에 스트리밍됩니다. Hermes의 데이터는 읽기만 할 뿐, 수정하거나 삭제하지 않습니다. 또한 재시작이 반복되더라도 각 메시지는 한 번만 전송됩니다.

`health` 명령은 수집기가 캡처한 데이터가 실제로 AgentEye에 도달했는지도 알려줍니다. 배치 전송에 실패하면 폐기하지 않고 보관 후 재시도하며, 미전송 데이터가 남아 있는 동안은 비정상(unhealthy) 상태로 보고됩니다. 따라서 "정상(healthy)"은 프로세스가 살아 있다는 의미가 아니라, 데이터가 실제로 도착했다는 의미입니다.

## 확인 위치

캡처된 세션은 **Sessions**에, 이벤트는 **Events** 스트림에 표시됩니다. 다른 에이전트와 동일하게 [세션 재생](/ko/agenteye/sessions), [검색](/ko/agenteye/queries), [평가](/ko/agenteye/evaluations), [알림](/ko/agenteye/alerts)을 모두 사용할 수 있습니다. Hermes 에이전트로 필터링하면 해당 세션만 볼 수 있습니다.

---

## 개인정보 보호

Hermes 세션에는 명령 출력, 파일 내용, 에이전트가 읽거나 쓴 모든 내용을 포함한 전체 대화 기록이 담겨 있으며, 민감한 정보가 포함될 수 있습니다. 캡처된 세션은 있는 그대로 전송되므로, AgentEye에 해당 내용을 중앙화하는 것이 적절한 환경에서만 캡처를 활성화하고, 수집기에는 `events:add` 권한만 있는 키를 사용하세요. 데이터 격리 방식에 대한 자세한 내용은 [보안](/ko/agenteye/security)을 참조하세요.
