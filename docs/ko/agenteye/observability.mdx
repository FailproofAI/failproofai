관찰 화면은 에이전트가 현재 무엇을 하고 있는지 실시간으로 확인하고, 특정 실행을 자세히 살펴볼 수 있는 공간입니다. 이 화면의 모든 내용은 실시간으로 제공되며, 조직 범위 내에서 날짜 범위, 환경, 에이전트, 세션별로 필터링할 수 있어 "뭔가 이상하다"는 느낌에서 정확한 실행 지점까지 몇 초 만에 도달할 수 있습니다.

![유형별로 색상이 구분되고 환경, 에이전트, 세션별로 필터링 가능한 실시간 이벤트 스트림](/agenteye/images/events-stream.png)

각각 별도의 페이지로 구성된 네 가지 화면:

- **[이벤트 스트림](/ko/agenteye/event-stream)**: 모든 에이전트의 모든 실행에서 발생하는 단계별 실시간 이벤트 추적 기록으로, 최신 항목이 먼저 표시됩니다. 조직의 홈 화면이자 트리아지의 첫 번째 창구입니다.
- **[세션 및 실행 그래프](/ko/agenteye/sessions)**: 해당 이벤트들을 실행당 한 행으로 집약한 뷰와, 각 실행이 어떻게 전개되었는지 git 스타일의 시각적 그래프로 표현합니다.
- **[성능 지표](/ko/agenteye/telemetry)**: 모델, 도구, 훅에 대한 지연 시간 히트맵과 p50/p95/p99 주요 수치를 제공하여, 꼬리 스파이크가 중앙값과 얼마나 차이나는지 한눈에 파악할 수 있습니다.
- **[오류 추적](/ko/agenteye/error-tracking)**: 발생한 모든 문제를 하나의 트리아지 화면에서 관리하며, 발생한 알림에서 문제를 일으킨 실행까지 클릭 한 번으로 이동합니다.

## 관련 항목

- [평가](/ko/agenteye/evaluations): 모든 실행의 품질을 점수로 평가합니다.
- [알림](/ko/agenteye/alerts): 임계값을 페이징 규칙으로 전환합니다.
- [감사](/ko/agenteye/audits): Failproof AI Observability가 세션 전반에 걸쳐 실패 패턴을 자동으로 찾아줍니다.
- [CLI 및 에이전트](/ko/agenteye/cli-and-agents): 터미널에서도 동일한 관찰 기능을 사용할 수 있습니다.
