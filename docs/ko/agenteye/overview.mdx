Failproof AI Observability는 프로덕션 환경에서 AI 에이전트를 관찰, 평가, 개선하기 위한 자체 호스팅 플랫폼입니다. 에이전트의 모든 활동(툴 호출, 모델 요청, 훅, 오류)을 기록하고, 각 실행의 품질을 채점하며, 미처 발견하지 못했던 장애를 찾아내어 여러분의 인프라 내부에서 직접 운영하는 대시보드에 표시해 드립니다.

AI 에이전트를 운영하면서 실행이 잘못된 이유를 추측하는 데 지쳤다면, 이 페이지가 바로 시작점입니다. Failproof AI Observability가 제공하는 것과 각 구성 요소가 어떻게 연결되는지를 설치 전에 먼저 설명합니다.

## 팀들이 사용하는 이유

- **에이전트가 실제로 무엇을 했는지 확인하세요.** 모든 실행이 읽기 쉬운 git 스타일 실행 그래프로 변환됩니다. 어떤 툴이 병렬로 실행됐는지, 어떤 서브 에이전트가 분기됐는지, 어디서 멈췄는지, 얼마나 소비됐는지를 한눈에 파악할 수 있습니다.
- **품질 저하를 자동으로 감지하세요.** 소규모 채점 서비스를 연결하면 Failproof AI Observability가 완료된 모든 실행을 채점하여, 유용성 저하나 환각 급증을 자동으로 감지합니다.
- **규칙을 정의하지 않은 장애도 찾아내세요.** 정기 감사가 세션 전반의 로그를 분석하여 오류 클러스터, 지연 시간 이상값, 낮은 점수, 멈춘 실행을 탐지하고, 근거가 뒷받침된 우선순위 발견 사항을 제공합니다.
- **중요한 순간에 알림을 받으세요.** 오류율, 지연 시간, 비용, 또는 평가자 점수에 대한 임계값 규칙이 발동하면 인시던트가 생성되어 확인, 담당자 지정, 해결이 가능합니다.
- **일반 언어로 질문하세요.** 대시보드 내 AI 어시스턴트가 여러분의 데이터를 기반으로 "이번 주 프로덕션 품질 트렌드는 어떻게 되나요?"와 같은 질문에 답변합니다. 어시스턴트가 수행하는 모든 변경은 승인 절차를 거칩니다.
- **데이터를 직접 보관하세요.** Failproof AI Observability는 자체 호스팅 방식으로, 이벤트, 프롬프트, 분석 데이터가 모두 여러분이 관리하는 인프라에 저장됩니다.

## 제공 기능

Failproof AI Observability는 **관찰(observe)**, **분석(analyze)**, **관리(admin)**이라는 세 가지 개념을 중심으로 구성되어 있으며, 대시보드 왼쪽 사이드바에 그대로 반영되어 있습니다.

**관찰** (실제 발생한 일의 원시 기록):

- **[이벤트 스트림](/ko/agenteye/event-stream)**: 모든 실행의 실시간 단계별 추적 기록(툴 호출, 모델 호출, 훅, 오류).
- **[세션](/ko/agenteye/sessions)**: 이벤트를 실행 단위로 집계한 행 목록. 각 행은 채점 준비가 완료되어 있으며 git 스타일 실행 그래프를 제공합니다.
- **[성능 지표](/ko/agenteye/telemetry)**: 모델, 툴, 훅별 표면 단위 지연 시간 히트맵과 p50/p95/p99 핵심 지표. 꼬리 부분의 급증이 중앙값과 뚜렷이 구분됩니다.
- **[오류 추적](/ko/agenteye/error-tracking)**: 발생한 모든 오류를 한곳에서 트리아지하고, 발동 중인 알림에서 한 번의 클릭으로 접근 가능합니다.

![툴 관찰 페이지: 24개 시간 구간에 걸친 지연 시간 히트맵, 백분위 밴드, 툴 분포 막대](/agenteye/images/tools.png)

*각 관찰 화면은 스파크라인 및 p50/p95/p99 핵심 지표와 지연 시간 히트맵, 백분위 밴드를 함께 제공합니다. 여기서는 툴 화면을 보여드립니다.*

**분석** (활동을 인사이트로 전환):

- **[쿼리](/ko/agenteye/queries)** 및 **[대시보드](/ko/agenteye/dashboards)**: 이벤트와 평가 데이터에 대한 저장된 SQL 쿼리를 조직 범위의 공유 대시보드로 시각화합니다.
- **[평가](/ko/agenteye/evaluations)**: 자체 평가자 서비스가 생성한 품질 점수와 점수별 근거.
- **[감사](/ko/agenteye/audits)**: 세션 전반에서 장애 패턴을 탐지하는 정기 조사.
- **[알림](/ko/agenteye/alerts)** 및 **[인시던트](/ko/agenteye/incidents)**: 알림을 발송하는 임계값 규칙과 트리아지를 위한 인시던트 워크플로.

**인터페이스** (원하는 방식으로 데이터에 접근):

- **[CLI](/ko/agenteye/cli-and-agents)**: 터미널이나 스크립트에서 전체 배포를 관리하고, 코딩 에이전트가 일반 언어로 대신 처리하도록 할 수 있습니다.
- **[AI 어시스턴트](/ko/agenteye/assistant)**: 대시보드 내에서 일반 언어로 에이전트에 대한 질문을 할 수 있습니다.
- **REST API**: 대시보드와 CLI의 모든 기능은 범위가 지정된 [API 키](/ko/agenteye/api-keys)로 직접 호출할 수 있는 REST API로 뒷받침됩니다. 이벤트 수집, 세션 및 평가 쿼리, 대시보드·알림·감사·사용자·키 관리가 가능하므로, Failproof AI Observability를 여러분의 자체 도구에 통합할 수 있습니다.

**관리** (팀을 위한 운영):

- **[API 키](/ko/agenteye/api-keys)**: 컬렉터, 대시보드, 어시스턴트용 범위 지정 토큰.
- **사용자**: 허용 목록 기반의 이메일 패스워드리스 로그인.
- **설정**: 모델 컨텍스트 윈도우 재정의를 포함한 조직별 구성.

## 구성 요소 연결 방식

데이터는 에이전트 코드에서 대시보드까지 한 방향으로 흐릅니다. 에이전트(Python SDK를 통해)가 이벤트를 agenteye-collector로 전송하고, agenteye-collector가 서버로 전달하며, 서버가 대시보드를 제공합니다. 채점 서비스(평가)와 AI 어시스턴트 서비스(대시보드 내 채팅), 두 가지 선택적 서비스가 이를 보완합니다.

- **Python SDK**: 에이전트에 `agenteye.event.*` 호출을 몇 줄 추가하면 이벤트가 로컬에 버퍼링됩니다.
- **agenteye-collector**: 각 에이전트 머신에서 실행되는 경량 데몬으로, 이벤트를 배치 처리하여 서버로 전송합니다.
- **서버**: 이벤트를 수집하고, 자체 데이터베이스에 운영 상태를 유지하며, 대시보드·CLI·자체 통합에서 사용하는 REST API를 제공합니다.
- **대시보드**: 모든 것을 탐색하는 공간입니다.
- **선택적 서비스**: 채점 서비스(평가)와 AI 어시스턴트 서비스(대시보드 내 채팅).

문서 전반에서 사용되는 용어(*event, session, evaluation, audit, finding, incident*)에 대한 설명은 [개념](/ko/agenteye/concepts)을 참조하세요.
