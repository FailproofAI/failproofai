Failproof AI Observability는 프로덕션 환경의 AI 에이전트를 관측하고 평가하며 개선하기 위한 자체 호스팅 플랫폼입니다. 에이전트가 수행하는 모든 작업(모든 도구 호출, 모델 요청, 훅, 오류)을 기록하고, 각 실행의 품질을 채점하며, 미처 발견하지 못했던 장애를 찾아내어 여러분의 인프라 내에서 직접 운영하는 대시보드에 표시합니다.

AI 에이전트를 운영하면서 실행이 잘못된 이유를 매번 추측해야 하는 상황에 지쳤다면, 이 페이지가 시작점입니다. 설치에 앞서 Failproof AI Observability가 제공하는 것과 각 구성 요소가 어떻게 맞물리는지 설명합니다.

## 팀에서 사용하는 이유

- **에이전트가 실제로 무엇을 했는지 확인.** 모든 실행이 읽기 쉬운 git 스타일 실행 그래프로 표현됩니다. 어떤 도구가 병렬로 실행되었는지, 어느 서브 에이전트가 분기했는지, 어디서 멈췄는지, 무엇에 비용이 들었는지 한눈에 파악할 수 있습니다.
- **품질 저하 자동 감지.** 소규모 채점 서비스를 연결하면 Failproof AI Observability가 완료된 모든 실행에 점수를 매기므로, 유용성 저하나 환각 급증이 자동으로 드러납니다.
- **규칙을 작성하지 않아도 장애 발견.** 반복 감사가 세션 전반의 로그를 분석하여 오류 클러스터, 지연 시간 이상값, 낮은 점수, 중단된 실행을 찾아내고 근거가 뒷받침된 우선순위 결과를 제시합니다.
- **중요할 때 알림 수신.** 오류율, 지연 시간, 비용, 평가 점수에 임계값 규칙을 설정하면 인시던트가 생성되고, 이를 확인·할당·해결할 수 있습니다.
- **자연어로 질문.** 대시보드 내 AI 어시스턴트가 여러분의 데이터를 기반으로 "이번 주 프로덕션 품질 추이는 어떤가요?" 같은 질문에 답합니다. 어시스턴트가 변경하는 모든 사항은 승인 절차를 거칩니다.
- **데이터 직접 관리.** Failproof AI Observability는 자체 호스팅 방식으로, 이벤트·프롬프트·분석 데이터가 여러분이 통제하는 인프라에 보관됩니다.

## 제공되는 기능

Failproof AI Observability는 **관측(observe)**, **분석(analyze)**, **관리(admin)** 세 가지 개념을 중심으로 구성되며, 대시보드 왼쪽 사이드바에 그대로 반영되어 있습니다.

**관측** (실제로 무슨 일이 일어났는지 있는 그대로):

- **[이벤트 스트림](/ko/agenteye/event-stream)**: 모든 실행의 라이브 단계별 기록 (도구 호출, 모델 호출, 훅, 오류).
- **[세션](/ko/agenteye/sessions)**: 이벤트를 실행 단위로 집계한 행. 각 행에는 채점 결과와 git 스타일 실행 그래프가 포함됩니다.
- **[성능 지표](/ko/agenteye/telemetry)**: 모델·도구·훅별 지연 시간 히트맵과 p50/p95/p99 핵심 수치. 테일 스파이크가 중앙값과 어떻게 다른지 한눈에 파악할 수 있습니다.
- **[오류 추적](/ko/agenteye/error-tracking)**: 발생한 모든 오류를 한 곳에서 분류할 수 있는 화면. 경보 발생 시 클릭 한 번으로 접근합니다.

![도구 관측 페이지: 24개 시간 구간에 걸친 지연 시간 히트맵, 백분위 밴드, 도구 분포 막대 차트](/agenteye/images/tools.png)

*각 관측 화면은 스파크라인·p50/p95/p99 수치와 지연 시간 히트맵·백분위 밴드를 함께 제공합니다. 화면에 표시된 것은 도구(Tools) 페이지입니다.*

**분석** (활동을 인사이트로 변환):

- **[쿼리](/ko/agenteye/queries)** 및 **[대시보드](/ko/agenteye/dashboards)**: 이벤트와 평가 데이터에 대한 저장된 SQL 쿼리를 조직 범위의 공유 대시보드로 시각화합니다.
- **[평가](/ko/agenteye/evaluations)**: 자체 평가 서비스에서 생성된 품질 점수와 점수별 근거.
- **[감사](/ko/agenteye/audits)**: 세션 전반에서 장애 패턴을 찾아내는 반복 조사.
- **[경보](/ko/agenteye/alerts)** 및 **[인시던트](/ko/agenteye/incidents)**: 알림을 발송하는 임계값 규칙과 이를 분류하는 인시던트 워크플로우.

**인터페이스** (원하는 방식으로 데이터에 접근):

- **[CLI](/ko/agenteye/cli-and-agents)**: 터미널이나 스크립트에서 전체 배포를 제어하고, 코딩 에이전트가 자연어로 작업을 수행하게 할 수 있습니다.
- **[AI 어시스턴트](/ko/agenteye/assistant)**: 대시보드 내에서 에이전트에 대한 질문을 자연어로 바로 할 수 있습니다.
- **REST API**: 대시보드와 CLI의 모든 기능은 범위가 지정된 [API 키](/ko/agenteye/api-keys)를 통해 직접 호출할 수 있는 REST API로 제공됩니다. 이벤트 수집, 세션·평가 쿼리, 대시보드·경보·감사·사용자·키 관리가 가능하므로 Failproof AI Observability를 자체 도구와 연동할 수 있습니다.

**관리** (팀을 위한 운영):

- **[API 키](/ko/agenteye/api-keys)**: 수집기, 대시보드, 어시스턴트용 범위 지정 토큰.
- **사용자**: 허용 목록 기반의 비밀번호 없는 이메일 로그인.
- **설정**: 모델 컨텍스트 윈도우 재정의를 포함한 조직별 구성.

## 구성 요소 간 연결 방식

데이터는 에이전트 코드에서 대시보드까지 단방향으로 흐릅니다. 에이전트(Python SDK)가 이벤트를 agenteye-collector로 전송하면, collector가 서버로 전달하고, 서버가 대시보드를 제공합니다. 여기에 채점 서비스(평가)와 AI 어시스턴트 서비스(대시보드 내 채팅) 두 가지 선택적 서비스를 추가할 수 있습니다.

- **Python SDK**: 에이전트에 `agenteye.event.*` 호출 몇 줄을 추가하면 이벤트가 로컬에 버퍼링됩니다.
- **agenteye-collector**: 각 에이전트 머신에서 이벤트를 배치 처리하여 서버로 전송하는 경량 데몬.
- **서버**: 이벤트를 수집하고, 자체 데이터베이스에 운영 상태를 보관하며, 대시보드·CLI·외부 통합에서 모두 사용하는 REST API를 제공합니다.
- **대시보드**: 모든 것을 탐색하는 공간.
- **선택적 서비스**: 채점 서비스(평가)와 AI 어시스턴트 서비스(대시보드 내 채팅).

문서 전반에서 사용되는 용어(*이벤트, 세션, 평가, 감사, 결과, 인시던트*)는 [개념](/ko/agenteye/concepts)을 참조하세요.
