Failproof AI Observability는 프로덕션 환경에서 AI 에이전트를 관찰, 평가, 개선하기 위한 자체 호스팅 플랫폼입니다. 에이전트가 수행하는 모든 작업(모든 툴 호출, 모델 요청, 훅, 오류)을 기록하고, 각 실행의 품질을 채점하며, 미처 파악하지 못했던 장애를 발견할 수 있도록 여러분의 인프라 내에서 직접 운영하는 대시보드를 통해 제공합니다.

AI 에이전트를 운영하면서 실행이 잘못된 원인을 추측하는 데 지쳤다면, 바로 이 페이지에서 시작하세요. 설치 전에 Failproof AI Observability가 제공하는 기능과 각 구성 요소가 어떻게 연결되는지 설명합니다.

## 팀이 사용하는 이유

- **에이전트가 실제로 무엇을 했는지 확인.** 모든 실행이 읽기 쉬운 git 스타일의 실행 그래프로 표현됩니다. 어떤 툴이 병렬로 실행됐는지, 어떤 서브 에이전트가 분기됐는지, 어디서 멈췄는지, 무엇을 소비했는지 한눈에 파악할 수 있습니다.
- **품질 저하 자동 감지.** 소규모 채점 서비스를 연결하면 Failproof AI Observability가 완료된 모든 실행을 채점하므로, 유용성 저하나 환각 급증이 자동으로 나타납니다.
- **규칙을 작성하지 않아도 장애 탐지.** 정기적인 감사가 세션 전반의 로그에서 오류 클러스터, 지연 시간 이상값, 낮은 점수, 멈춘 실행을 찾아내고, 근거가 뒷받침된 우선순위 분석 결과를 제공합니다.
- **중요한 순간에 알림 수신.** 임계값 규칙이 오류율, 지연 시간, 비용, 또는 평가자 점수에 반응하여 인시던트를 생성하고, 확인, 할당, 해결할 수 있습니다.
- **일반 영어로 질문.** 대시보드 내 AI 어시스턴트가 "이번 주 프로덕션 품질 추이는 어떤가요?"와 같은 질문에 여러분의 데이터를 기반으로 답변합니다. 어시스턴트가 수행하는 모든 변경은 승인이 필요합니다.
- **데이터 직접 보관.** Failproof AI Observability는 자체 호스팅 방식입니다. 이벤트, 프롬프트, 분석 데이터가 여러분이 관리하는 인프라에 저장됩니다.

## 제공 기능

Failproof AI Observability는 **관찰(observe)**, **분석(analyze)**, **관리(admin)** 세 가지 개념을 중심으로 구성되며, 대시보드의 왼쪽 사이드바에 반영되어 있습니다.

**관찰** (발생한 일의 있는 그대로의 기록):

- **[이벤트 스트림](/ko/agenteye/event-stream)**: 모든 실행의 단계별 라이브 추적 기록 (툴 호출, 모델 호출, 훅, 오류).
- **[세션](/ko/agenteye/sessions)**: 실행별로 집계된 이벤트. 각 실행은 채점 준비가 된 상태로 git 스타일의 실행 그래프와 함께 표시됩니다.
- **[성능 메트릭](/ko/agenteye/telemetry)**: 모델, 툴, 훅에 대한 서피스별 지연 시간 히트맵과 p50/p95/p99 핵심 지표. 꼬리 구간 급등이 중앙값과 명확히 구분됩니다.
- **[오류 추적](/ko/agenteye/error-tracking)**: 문제가 발생한 모든 항목을 하나의 트리아지 화면에서 확인하고, 클릭 한 번으로 발생 중인 알림과 연결됩니다.

![툴 관찰 페이지: 24개 시간 구간에 걸친 지연 시간 히트맵, 백분위수 밴드, 툴 분포 막대 차트](/agenteye/images/tools.png)

*각 관찰 화면은 스파크라인과 p50/p95/p99 핵심 지표를 지연 시간 히트맵 및 백분위수 밴드와 함께 표시합니다. 사진은 툴 화면입니다.*

**분석** (활동을 인사이트로 전환):

- **[쿼리](/ko/agenteye/queries)** 및 **[대시보드](/ko/agenteye/dashboards)**: 이벤트와 평가 데이터에 대한 저장된 SQL을 차트로 표현하여 조직 전체가 공유하는 대시보드로 제공.
- **[평가](/ko/agenteye/evaluations)**: 자체 평가자 서비스가 생성한 품질 점수와 점수별 근거.
- **[감사](/ko/agenteye/audits)**: 세션 전반에서 장애 패턴을 발견하는 정기 조사.
- **[알림](/ko/agenteye/alerts)** 및 **[인시던트](/ko/agenteye/incidents)**: 알림을 전송하는 임계값 규칙과 트리아지를 위한 인시던트 워크플로.

**인터페이스** (원하는 방식으로 데이터에 접근):

- **[CLI](/ko/agenteye/cli-and-agents)**: 터미널이나 스크립트에서 전체 배포를 관리하고, 코딩 에이전트가 일반 영어로 대신 처리하도록 할 수 있습니다.
- **[AI 어시스턴트](/ko/agenteye/assistant)**: 대시보드 내에서 에이전트에 대한 질문을 일반 영어로 물어보세요.
- **REST API**: 대시보드와 CLI의 모든 기능은 범위가 지정된 [API 키](/ko/agenteye/api-keys)로 직접 호출할 수 있는 REST API로 제공됩니다. 이벤트 수집, 세션 및 평가 쿼리, 대시보드·알림·감사·사용자·키 관리가 가능하므로 Failproof AI Observability를 자체 툴링에 연동할 수 있습니다.

**관리** (팀을 위한 운영):

- **[API 키](/ko/agenteye/api-keys)**: 수집기, 대시보드, 어시스턴트에 대한 범위 지정 토큰.
- **사용자**: 허용 목록 기반의 비밀번호 없는 이메일 로그인.
- **설정**: 모델 컨텍스트 윈도우 재정의를 포함한 조직별 설정.

## 구성 요소 연결 방식

데이터는 에이전트 코드에서 대시보드로 단방향으로 흐릅니다. 에이전트(Python SDK를 통해)가 agenteye-collector로 이벤트를 전송하고, collector가 서버로 전달하며, 서버가 대시보드를 제공합니다. 두 가지 선택적 서비스로 구성을 완성할 수 있습니다. 채점 서비스(평가)와 AI 어시스턴트 서비스(대시보드 내 채팅)입니다.

- **Python SDK**: 에이전트에 `agenteye.event.*` 호출 몇 줄을 추가하면 이벤트가 로컬에 버퍼링됩니다.
- **agenteye-collector**: 각 에이전트 머신에서 실행되는 경량 데몬으로, 이벤트를 배치로 묶어 서버로 전송합니다.
- **서버**: 이벤트를 수집하고, 자체 데이터베이스에 운영 상태를 유지하며, 대시보드·CLI·자체 통합에서 사용하는 REST API를 제공합니다.
- **대시보드**: 모든 것을 탐색하는 공간.
- **선택적 서비스**: 채점 서비스(평가)와 AI 어시스턴트 서비스(대시보드 내 채팅).

문서 전반에서 사용되는 용어(*이벤트, 세션, 평가, 감사, 발견 사항, 인시던트*)는 [개념](/ko/agenteye/concepts)을 참조하세요.
