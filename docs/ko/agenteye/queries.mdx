에이전트 데이터에 대한 모든 질문을 몇 초 만에 답변받으세요. Failproof AI Observability는 이벤트와 평가 데이터를 조회할 수 있는 저장된 즉시 실행 가능한 쿼리 라이브러리를 제공합니다. 빈 SQL 편집기 앞에서 막막하게 시작하는 대신, 동작하는 예시에서 출발할 수 있습니다.

![저장된 쿼리 라이브러리: 기본 제공 프리셋과 커스텀 쿼리가 함께 표시된 그리드](/agenteye/images/queries.png)

*`/<org-slug>/queries`에 있는 저장된 쿼리 라이브러리: 기본 제공 프리셋과 팀이 저장한 쿼리가 나란히 표시됩니다.*

## 빈 페이지가 아닌 프리셋에서 시작하세요

테이블 이름을 외우거나 SQL을 처음부터 작성할 필요가 없습니다. 라이브러리는 팀이 가장 자주 묻는 질문들에 대한 기본 제공 프리셋과 함께 열리며, 팀이 저장하고 이름을 붙인 쿼리들이 바로 옆에 위치합니다. 원하는 것과 유사한 쿼리를 하나 선택하면 답변까지 거의 다 온 셈입니다.

모든 저장된 쿼리는 조직 범위로 공유되므로, 팀원이 작성한 유용한 쿼리가 곧 나의 쿼리가 됩니다. 쿼리에 이름과 설명을 한 번 붙여두면, 조직 내 누구든 이를 찾고, 실행하고, 나중에 대시보드에 결과를 고정할 수 있습니다.

`/<org-slug>/queries`에서 확인하세요.

## SQL 편집기에서 수정하고 실행하기

쿼리를 열면 SQL 편집기로 이동하여 바로 수정하고 즉시 결과를 확인할 수 있습니다. 내보낼 필요도, 왕복 작업도, 다른 사람을 기다릴 필요도 없습니다.

![저장된 쿼리를 실행 중인 SQL 편집기, 스키마 사이드바와 실시간 결과 그리드가 함께 표시됨](/agenteye/images/query-lab.png)

*SQL 편집기: 왼쪽에 쿼리, 컬럼 이름을 추측할 필요 없도록 스키마 사이드바, 아래에 실시간 결과 그리드.*

- **스키마 사이드바**는 분석 테이블과 해당 컬럼을 보여주므로, 필드 이름을 찾아 헤매지 않고도 쿼리를 작성할 수 있습니다.
- **실시간 결과 그리드**는 실행 즉시 결과 행을 반환하므로, 반복 시도 없이 몇 초 만에 수정할 수 있습니다.
- **읽기 전용으로 설계되었습니다.** 쿼리는 이벤트 저장소에 대해 실행되며 서버에서 유효성이 검사됩니다. `SELECT`와 `WITH` 구문만 허용되며, 실행 시간 제한과 행 수 제한이 적용됩니다. 탐색용 쿼리는 데이터를 절대 수정할 수 없으며, 제어되지 않는 쿼리는 자동으로 중단됩니다.

결과가 만족스러우신가요? 팀 전체가 활용할 수 있도록 라이브러리에 저장하거나, 결과를 라인, 바, 영역, 파이 타일 형태로 대시보드에 고정하세요.

## 터미널에서 실행하거나 어시스턴트가 작성하도록 하기

저장된 쿼리는 어디서 작업하든 함께합니다.

- **터미널에서.** `agenteye` CLI로 동일한 쿼리를 목록으로 보고, 실행하고, 저장할 수 있어 결과를 스크립트에 넣거나, CI에 연결하거나, 코딩 에이전트에 전달할 수 있습니다.

```bash
agenteye query list                 # the same saved queries, from your terminal
agenteye query run errs --arg prod  # run one and print the rows (add --json to pipe it)
```

  전체 명령 목록은 [CLI and agents](/ko/agenteye/cli-and-agents)를 참고하세요.

- **AI 어시스턴트에서.** SQL 표현 방법이 확실하지 않으신가요? 대시보드 내 [AI 어시스턴트](/ko/agenteye/assistant)에 자연어로 질문하면 쿼리를 작성하고 라이브러리에 저장해 드립니다.

저장된 쿼리 실행은 `queries:run` 권한으로 제어되며, 쿼리를 생성하거나 삭제하는 권한과 분리되어 있습니다. 따라서 라이브러리를 수정할 권한 없이 읽기 접근 권한만 부여할 수 있습니다.
