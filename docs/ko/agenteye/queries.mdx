에이전트 데이터에 대한 모든 질문을 몇 초 안에 답변받으세요. Failproof AI Observability는 이벤트와 평가 데이터에 대해 저장된 실행 가능한 쿼리 라이브러리를 제공하므로, 빈 SQL 편집기 대신 바로 사용할 수 있는 예제에서 시작할 수 있습니다.

![저장된 쿼리 라이브러리: 기본 제공 프리셋과 사용자 정의 쿼리가 함께 있는 그리드](/agenteye/images/queries.png)

*`/<org-slug>/queries`에 있는 저장된 쿼리 라이브러리: 기본 제공 프리셋과 팀이 저장한 쿼리가 나란히 표시됩니다.*

## 빈 페이지가 아닌 프리셋에서 시작하기

테이블 이름을 외우거나 SQL을 처음부터 작성할 필요가 없습니다. 라이브러리는 팀이 가장 자주 묻는 질문에 대한 기본 제공 프리셋과 함께 열리며, 팀이 저장하고 이름을 붙인 쿼리도 바로 옆에 표시됩니다. 원하는 것과 가까운 쿼리를 선택하면 답변에 거의 다가간 셈입니다.

모든 저장된 쿼리는 조직 범위로 공유되므로, 팀원이 작성한 유용한 쿼리가 여러분의 것이 되기도 합니다. 쿼리에 이름과 설명을 한 번만 붙여두면, 조직 내 누구든 찾아서 실행하거나 나중에 대시보드에 결과를 고정할 수 있습니다.

`/<org-slug>/queries`에서 찾을 수 있습니다.

## SQL 컴포저에서 수정하고 실행하기

쿼리를 열면 SQL 컴포저로 이동하며, 여기서 쿼리를 조정하고 즉시 결과를 확인할 수 있습니다. 내보내기, 왕복 요청, 다른 사람을 기다릴 필요가 없습니다.

![저장된 쿼리를 실행 중인 SQL 쿼리 컴포저, 스키마 사이드바와 실시간 결과 그리드 포함](/agenteye/images/query-lab.png)

*SQL 컴포저: 왼쪽의 쿼리, 컬럼 이름을 추측할 필요 없는 스키마 사이드바, 그리고 하단의 실시간 결과 그리드.*

- **스키마 사이드바**는 분석 테이블과 컬럼을 보여주어, 필드 이름을 찾아 헤매지 않고도 쿼리를 작성할 수 있습니다.
- **실시간 결과 그리드**는 실행 즉시 행을 반환하므로, 반복 수정 작업을 몇 초 만에 처리할 수 있습니다.
- **읽기 전용 설계.** 쿼리는 이벤트 스토어에 대해 실행되며 서버에서 검증됩니다. `SELECT`와 `WITH` 구문만 허용되며, 실행 시간 제한과 행 수 제한이 적용됩니다. 탐색용 쿼리는 데이터를 수정할 수 없으며, 과부하가 걸린 쿼리는 자동으로 중단됩니다.

결과가 만족스러우신가요? 라이브러리에 저장하여 팀 전체가 공유하거나, 결과를 라인, 바, 영역, 또는 파이 타일로 대시보드에 고정할 수 있습니다.

## 터미널에서 실행하거나 어시스턴트에게 작성 요청하기

저장된 쿼리는 어디서든 함께합니다.

- **터미널에서.** `agenteye` CLI를 통해 동일한 쿼리를 나열하고, 실행하고, 저장할 수 있으므로, 결과를 스크립트에 넣거나 CI에 연결하거나 코딩 에이전트에 전달할 수 있습니다.

```bash
agenteye query list                 # the same saved queries, from your terminal
agenteye query run errs --arg prod  # run one and print the rows (add --json to pipe it)
```

  전체 명령어 목록은 [CLI and agents](/ko/agenteye/cli-and-agents)를 참조하세요.

- **AI 어시스턴트에서.** SQL을 어떻게 표현해야 할지 모르겠다면? 대시보드 내 [AI 어시스턴트](/ko/agenteye/assistant)에 일반 언어로 질문하면 쿼리를 작성하고 라이브러리에 저장해줍니다.

저장된 쿼리 실행은 `queries:run` 권한으로 제한되며, 쿼리 생성 또는 삭제 권한과 분리되어 있어 라이브러리를 수정할 권한을 부여하지 않고도 읽기 접근 권한을 부여할 수 있습니다.
