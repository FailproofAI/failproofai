에이전트 데이터에 대해 어떤 질문이든 입력하고 몇 초 만에 답변을 받으세요. Failproof AI Observability는 이벤트 및 평가 데이터에 대해 저장되고 바로 실행할 수 있는 쿼리 라이브러리를 제공합니다. 빈 SQL 편집기 대신 동작하는 예시에서 시작할 수 있습니다.

![저장된 쿼리 라이브러리: 기본 제공 프리셋과 커스텀 쿼리가 함께 표시된 그리드](/agenteye/images/queries.png)

*`/<org-slug>/queries`에서 확인할 수 있는 저장된 쿼리 라이브러리: 기본 제공 프리셋과 팀이 저장한 쿼리가 나란히 표시됩니다.*

## 빈 페이지가 아닌 프리셋에서 시작하기

테이블 이름을 외우거나 SQL을 처음부터 작성할 필요가 없습니다. 라이브러리는 팀이 가장 자주 묻는 질문에 대한 기본 제공 프리셋과 함께 열리며, 팀이 저장하고 이름을 붙인 쿼리들도 바로 옆에 위치합니다. 원하는 것에 가까운 쿼리를 선택하면 답변까지 거의 다 온 셈입니다.

저장된 모든 쿼리는 조직 범위로 공유되므로, 팀원이 유용하게 작성한 쿼리를 나도 바로 활용할 수 있습니다. 쿼리에 이름과 설명을 한 번만 지정해 두면, 조직 내 누구든 해당 쿼리를 찾아 실행하거나 나중에 대시보드에 결과를 고정할 수 있습니다.

`/<org-slug>/queries`에서 확인하세요.

## SQL 편집기에서 수정하고 실행하기

쿼리를 열면 SQL 편집기로 이동하며, 쿼리를 조정하고 즉시 결과를 확인할 수 있습니다. 내보내기, 왕복 처리, 다른 사람을 기다릴 필요가 없습니다.

![저장된 쿼리를 실행 중인 SQL 편집기, 스키마 사이드바와 실시간 결과 그리드 포함](/agenteye/images/query-lab.png)

*SQL 편집기: 왼쪽에는 쿼리, 컬럼 이름을 추측할 필요 없는 스키마 사이드바, 그리고 아래에는 실시간 결과 그리드.*

- **스키마 사이드바**는 분석 테이블과 컬럼을 정리하여 보여주므로, 필드 이름을 찾아 헤맬 필요 없이 쿼리를 작성할 수 있습니다.
- **실시간 결과 그리드**는 실행 즉시 행을 반환하므로, 추측과 재시도 없이 몇 초 만에 반복 작업이 가능합니다.
- **설계상 읽기 전용입니다.** 쿼리는 이벤트 저장소에 대해 실행되며 서버에서 검증됩니다. `SELECT` 및 `WITH` 구문만 허용되며, 문 타임아웃과 행 수 제한이 적용됩니다. 탐색 쿼리는 데이터를 절대 수정할 수 없으며, 과부하 쿼리는 자동으로 중단됩니다.

결과가 만족스럽다면 팀 전체가 활용할 수 있도록 라이브러리에 다시 저장하거나, 라인, 바, 영역, 파이 타일 형태로 대시보드에 출력 결과를 고정할 수 있습니다.

## 터미널에서 실행하거나 AI 어시스턴트에게 작성 요청하기

저장된 쿼리는 어디서 작업하든 동일하게 사용할 수 있습니다.

- **터미널에서.** `agenteye` CLI를 통해 동일한 쿼리를 목록 조회, 실행, 저장할 수 있으므로, 결과를 스크립트에 삽입하거나 CI에 연동하거나 코딩 에이전트에 전달할 수 있습니다.

```bash
agenteye query list                 # 터미널에서 동일한 저장 쿼리 목록 보기
agenteye query run errs --arg prod  # 하나를 실행하고 행 출력 (파이프 연결 시 --json 추가)
```

  전체 명령어 세트는 [CLI와 에이전트](/ko/agenteye/cli-and-agents)를 참고하세요.

- **AI 어시스턴트에서.** SQL 작성이 막막하다면? 대시보드 내 [AI 어시스턴트](/ko/agenteye/assistant)에 평문 한국어로 질문하면 쿼리를 초안 작성하고 라이브러리에 저장해 줍니다.

저장된 쿼리 실행은 `queries:run` 권한으로 제어되며, 쿼리 생성 또는 삭제 권한과 별도로 관리됩니다. 따라서 라이브러리를 수정할 수 없도록 하면서도 읽기 접근 권한은 부여할 수 있습니다.
