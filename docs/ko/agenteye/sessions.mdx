## 모든 실행을 한눈에 파악하기

원시 이벤트 내역은 모든 단계의 실상을 담고 있지만, 수십 번의 실행에 걸쳐 수천 개의 단계가 쌓이면 개별 단계가 아닌 실행 전체를 파악해야 합니다. 세션 페이지는 한 실행의 모든 이벤트를 하나의 행으로 압축하여, 하루치 활동이 끝없는 로그 스트림이 아닌 한눈에 훑어볼 수 있는 목록이 됩니다.

각 행에는 상태 표시 배지가 붙어 있어, 클릭하기 전에도 실패한 실행이 정상 실행과 구별됩니다. 날짜 범위, 환경, 에이전트, 세션으로 필터링하면 몇 번의 클릭만으로 "전체 실행"에서 "내가 관심 있는 실행"으로 좁혀갈 수 있습니다.

평가기를 연결하면 완료된 실행마다 자동으로 점수가 매겨지고, 최신 점수가 배지 형태로 행에 표시됩니다. 점수 범위로도 필터링할 수 있으므로 "이번 주 점수가 낮은 프로덕션 실행 모두 보기"가 수동 검토가 아닌 필터 하나로 해결됩니다. 평가기를 설정하기 전에도 세션은 전체 실행 내역을 캡처하며, 다만 점수 배지가 아직 없을 뿐입니다.

## 전체 실행을 그림으로 읽기

![세션의 git 스타일 실행 그래프와 이벤트 타임라인, 그리고 도구·모델·훅 분석 패널](/agenteye/images/session-detail.png)

*실행 그래프(왼쪽)와 이벤트 타임라인이 나란히 표시되고, 오른쪽 패널은 도구, 모델, 훅, 토큰 사용량 내역을 보여줍니다.*

세션을 클릭하면 실행 그래프가 열립니다. 에이전트, 도구, 훅, 모델 호출이 시간 흐름에 따라 어떻게 전개되었는지를 git 스타일로 시각화한 뷰입니다. 병렬 서브 에이전트는 각각 별도의 레인으로 분기되므로, 어떤 작업이 동시에 실행되었는지, 어떤 서브 에이전트가 멈췄는지, 실행이 어디서 잘못되었는지를 로그 더미를 머릿속으로 재현하지 않고도 한눈에 파악할 수 있습니다.

오른쪽 패널은 실행별 세부 내역을 제공합니다. 어떤 도구와 모델이 실행되었는지, 어떤 훅이 발동했는지, 실행에 토큰이 얼마나 소모되었는지를 보여줍니다. "이 실행은 왜 이렇게 비쌌지?" 또는 "느린 도구가 어떤 건지?"에 대한 답이 바로 그 원인이 된 그래프 옆에 나란히 있습니다.

## 찾는 방법

모든 대시보드 페이지는 조직 단위로 범위가 지정됩니다(`/<org-slug>/…`). 세션은 왼쪽 사이드바의 **Observe** 아래, 이벤트 옆에 위치하며, 목록 상단에 날짜 범위, 환경, 에이전트, 세션 필터가 배치되어 있습니다. 모든 행을 클릭하면 해당 전체 실행 그래프로 이동합니다.

점수 배지와 점수 범위 필터링을 활성화하려면 평가기를 연결하세요: [Evaluations](/ko/agenteye/evaluations)를 참고하세요.
