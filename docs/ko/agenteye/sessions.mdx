## 모든 실행을 한눈에 파악하기

원시 이벤트 기록은 모든 단계의 진실을 담고 있지만, 수십 개의 실행에 걸쳐 수천 개의 단계가 존재할 때는 개별 단계가 아닌 실행 전체를 파악해야 합니다. 세션 페이지는 실행의 모든 이벤트를 하나의 행으로 집약하므로, 하루치 활동이 쏟아지는 로그 대신 훑어볼 수 있는 목록으로 정리됩니다.

각 행에는 상태 뱃지가 표시되어 클릭하기 전에도 실패한 실행을 정상 실행과 구분할 수 있습니다. 날짜 범위, 환경, 에이전트, 세션별로 필터링하면 몇 번의 클릭만으로 "전체"에서 "내가 관심 있는 실행"으로 범위를 좁힐 수 있습니다.

평가기를 연결하면 완료된 모든 실행이 자동으로 점수를 받고, 최신 점수가 해당 행에 뱃지로 표시됩니다. 점수 범위로도 필터링할 수 있어 "이번 주 프로덕션에서 낮은 점수를 받은 실행 전체 보기"가 수동 검토 없이 필터 하나로 해결됩니다. 평가기를 설정하기 전에도 세션은 전체 실행을 캡처하며, 다만 점수 뱃지는 아직 표시되지 않습니다.

## 전체 실행을 그림으로 읽기

![세션의 git 스타일 실행 그래프와 이벤트 타임라인, 도구·모델·훅 분석 패널](/agenteye/images/session-detail.png)

*실행 그래프(왼쪽)는 이벤트 타임라인 옆에 표시되며, 오른쪽 패널에서는 해당 실행의 도구, 모델, 훅, 토큰 사용량을 분석해 보여줍니다.*

세션을 클릭하면 실행 그래프가 열립니다. 에이전트, 도구, 훅, 모델 호출이 시간순으로 펼쳐지는 git 스타일 뷰입니다. 병렬 서브 에이전트는 각자의 레인으로 분기되므로, 어떤 작업이 동시에 실행됐는지, 어떤 서브 에이전트가 멈췄는지, 실행이 어디서 어긋났는지를 방대한 로그를 머릿속으로 되짚지 않고도 파악할 수 있습니다.

오른쪽 패널에서는 실행별 세부 정보를 제공합니다. 어떤 도구와 모델이 실행됐는지, 어떤 훅이 발동됐는지, 실행에 사용된 토큰이 얼마인지 확인할 수 있습니다. "이 실행이 왜 이렇게 비쌌지?" 또는 "느린 도구가 뭐지?"에 대한 답이 해당 원인이 된 그래프 바로 옆에 나타납니다.

## 찾는 방법

모든 대시보드 페이지는 조직(`/<org-slug>/…`) 단위로 범위가 지정됩니다. 세션은 왼쪽 사이드바의 **Observe** 메뉴 아래, Events 옆에 있으며, 목록 상단에 날짜 범위, 환경, 에이전트, 세션 필터가 가로로 배치되어 있습니다. 모든 행은 한 번의 클릭으로 전체 실행 그래프로 이동합니다.

점수 뱃지와 점수 범위 필터링을 활성화하려면 평가기를 연결하세요: [Evaluations](/ko/agenteye/evaluations)를 참고하세요.
