## 모든 실행을 한눈에 확인

원시 이벤트 기록은 모든 단계의 실제 내역이지만, 수십 번의 실행에 걸쳐 수천 개의 단계가 쌓이면 개별 단계보다 전체 실행 흐름이 필요합니다. Sessions 페이지는 실행의 모든 이벤트를 하나의 행으로 압축하므로, 하루치 활동이 쏟아지는 데이터 대신 훑어볼 수 있는 목록으로 표시됩니다.

각 행에는 상태 표시가 있어, 클릭하기 전에도 실패한 실행이 정상적인 실행과 구분됩니다. 날짜 범위, 환경, 에이전트, 세션으로 필터링하면 클릭 몇 번으로 "전체"에서 "내가 찾는 실행"으로 좁혀갈 수 있습니다.

평가기를 연결하면 완료된 모든 실행이 자동으로 점수가 매겨지고, 최신 점수가 배지로 행에 표시됩니다. 점수 범위로도 필터링할 수 있어 "이번 주 프로덕션에서 낮은 점수를 받은 실행 전부 보기"가 수동 검토 대신 필터 하나로 해결됩니다. 평가기를 설정하기 전에도 세션은 전체 실행을 캡처하며, 다만 점수 배지가 아직 표시되지 않을 뿐입니다.

## 전체 실행을 그림으로 읽기

![세션의 git 스타일 실행 그래프와 이벤트 타임라인, 그리고 도구·모델·훅 분석 패널](/agenteye/images/session-detail.png)

*실행 그래프(왼쪽)는 이벤트 타임라인 옆에 표시되며, 오른쪽 패널에서는 실행에 사용된 도구, 모델, 훅, 토큰 비용을 세부적으로 확인할 수 있습니다.*

세션을 클릭하면 실행 그래프가 열립니다. 에이전트, 도구, 훅, 모델 호출이 시간에 따라 어떻게 전개되었는지를 git 스타일로 보여줍니다. 병렬 서브 에이전트는 각각 별도의 레인에 분기되어 표시되므로, 어떤 작업이 동시에 실행되었는지, 어떤 서브 에이전트가 멈췄는지, 실행이 어디서 잘못되었는지를 로그 더미를 머릿속으로 되감지 않고도 파악할 수 있습니다.

오른쪽 패널에서는 실행별 세부 정보를 확인할 수 있습니다. 어떤 도구와 모델이 실행되었는지, 어떤 훅이 작동했는지, 실행에 토큰이 얼마나 사용되었는지를 그래프 바로 옆에서 볼 수 있습니다. "이 실행이 왜 이렇게 비쌌지?" 또는 "느린 도구가 어떤 건지?"에 대한 답이 바로 거기 있습니다.

개별 이벤트는 주소 지정이 가능하므로, "세션에서 약 3분의 2 지점"처럼 모호하게 설명하는 대신 특정 순간의 링크를 공유할 수 있습니다. 이벤트에서 링크를 복사하거나, [감사](/ko/agenteye/audits) 결과나 오류에서 링크를 따라가면 해당 이벤트가 선택된 상태로 세션이 열립니다. 매우 긴 실행에서도 마찬가지입니다. 타임라인은 브라우저 성능을 위해 일정 범위만 로드하지만, 그 범위를 벗어난 이벤트를 가리키는 링크도 시작 지점으로 떨어뜨리지 않고 해당 이벤트를 정확히 찾아줍니다. 이벤트가 보존 기간을 초과하여 만료된 경우, 아무것도 선택되지 않은 채 조용히 넘어가는 대신 페이지에서 명확히 알려줍니다.

## 찾는 방법

모든 대시보드 페이지는 조직 단위로 범위가 지정됩니다(`/<org-slug>/…`). Sessions는 왼쪽 사이드바의 **Observe** 아래 Events 옆에 있으며, 목록 상단에 날짜 범위, 환경, 에이전트, 세션 필터가 배치되어 있습니다. 모든 행은 클릭 한 번으로 전체 실행 그래프로 이동합니다.

점수 배지와 점수 범위 필터링을 활성화하려면 평가기를 연결하세요. [Evaluations](/ko/agenteye/evaluations)를 참고하세요.
