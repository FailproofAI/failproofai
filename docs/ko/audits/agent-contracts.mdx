에이전트 컨텍스트는 각 에이전트의 존재 목적, 반드시 생성해야 할 결과물, 절대 해서는 안 되는 행동을 감사에 알립니다. Failproof AI는 이 컨텍스트를 에이전트당 하나의 에이전트 계약으로 저장합니다.

에이전트 컨텍스트는 특정 감사가 아닌 조직에 귀속됩니다. 에이전트당 한 번만 작성하면, 해당 에이전트를 범위에 포함하는 모든 모델 기반 감사에서 이를 사용합니다.

## 에이전트 컨텍스트 추가

<Tabs>
  <Tab title="대시보드">
    1. **분석 → 감사**로 이동하여 **에이전트**를 선택하고, 세션에서 보고된 에이전트 ID를 선택합니다.
    2. **콘텐츠 추가** 또는 **편집**을 선택합니다.
    3. 에이전트의 목적, 반드시 생성해야 할 결과물, 완료 조건, 실행 주기, 절대 해서는 안 되는 행동을 작성합니다.
    4. 컨텍스트를 저장한 후 감사 양식으로 돌아가 선택한 에이전트가 커버됨으로 표시되는지 확인합니다.

    ![감사 에이전트 드로어 — 에이전트의 목적, 주기, 결과물, 완료 조건, 금지 행동을 추가하는 화면.](/images/dashboard/agent-context.png)

    감사를 생성하거나 편집하는 동안 **에이전트** 드로어에서도 에이전트 컨텍스트를 추가하거나 편집할 수 있습니다. 컨텍스트는 독립적으로 저장되며, 해당되는 모든 감사에 즉시 적용됩니다.
  </Tab>
  <Tab title="CLI">
    Cloud CLI는 아직 계약 명령을 지원하지 않습니다. `audits:read` 및 `audits:write` 권한이 있는 키를 사용하여 공개 API를 이용하세요.

    ```bash
    curl -X POST "https://app.befailproof.ai/v1/audits/contracts" \
      -H "Authorization: Bearer $FAILPROOFAI_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "agent_id": "nightly-reconciler",
        "enabled": true,
        "body": "# Purpose\nReconcile yesterday's payouts.\n\n## Outputs\nPublish a signed summary.\n\n## Must not\nNever modify ledger entries."
      }'
    ```

    `GET /v1/audits/contracts`로 계약 목록을 조회하고, `GET /v1/audits/contracts/{id}`로 특정 계약을 조회합니다. `PUT`으로 업데이트하는 경우 전체 교체 방식이며 `agent_id`와 `body` 모두 필수입니다.
  </Tab>
</Tabs>

## 유용한 컨텍스트 작성하기

컨텍스트는 5,000자 이내로 유지하고 테스트 가능하게 작성하세요. 유용한 컨텍스트는 일반적으로 다음 내용을 포함합니다.

- **목적:** 에이전트가 존재하는 이유
- **결과물:** 반드시 생성하거나 수행해야 하는 산출물 또는 작업
- **완료 조건:** 실행이 성공했다고 판단하는 조건
- **실행 주기:** 실행 빈도 또는 실행 시점
- **금지 사항:** 절대 허용되지 않는 행동 및 결과

```markdown
---
agent: nightly-reconciler
purpose: Reconcile yesterday's payouts and publish a signed summary.
cadence: Once daily after 02:00 UTC. Never more than once.
---

## Outputs
- A signed reconciliation summary in the finance channel.

## Done when
- Every payout is matched or explicitly flagged.

## Must not
- Modify ledger entries. Report discrepancies instead.
```

에이전트 컨텍스트는 예상 동작을 명시하는 것이며, 분석이 도달해야 할 결론을 지시하거나 검토할 증거를 제한할 수 없습니다. 컨텍스트가 없는 에이전트도 정상적으로 감사되지만, Failproof AI는 조직 고유의 의도를 기준으로 해당 에이전트의 동작을 판단할 수 없습니다.

## 에이전트 컨텍스트 일시 중지 또는 변경

- 감사에서 일시적으로 컨텍스트를 무시해야 할 경우 에이전트 컨텍스트를 일시 중지하세요. 일시 중지는 되돌릴 수 있습니다.
- 에이전트의 책임이 변경된 경우 컨텍스트를 편집하세요. 변경된 내용은 이후 실행부터 적용됩니다.
- 실행 중인 에이전트가 컨텍스트를 사용하지 않는 것처럼 보이면 **마지막 일치** 항목을 확인하세요. 이는 보통 에이전트 ID가 텔레메트리와 일치하지 않기 때문입니다.
- 텍스트를 영구적으로 삭제해야 하는 경우에만 API를 통해 삭제하세요. 대시보드는 의도적으로 삭제 대신 일시 중지를 제공합니다.

모든 감사 실행은 해당 실행 시 사용된 에이전트 컨텍스트 스냅샷을 정확히 저장합니다. 현재 계약 리소스를 편집, 일시 중지, 또는 삭제해도 이전 분석 결과의 근거는 변경되지 않습니다.

<Info>
  계약을 조회하려면 `audits:read` 권한이 필요합니다. 계약을 생성, 편집, 일시 중지, 또는 삭제하려면 `audits:write` 권한이 필요합니다.
</Info>
