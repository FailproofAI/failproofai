Failproof AI Cloud에 머신을 연결하기 전에 로컬 감사를 사용하여 즉각적이고 프라이빗한 검토를 수행하세요. 로컬 감사는 머신에 이미 저장된 에이전트 히스토리를 스캔하고, 내장 정책을 통해 도구 활동을 재현하며, 로컬 결과 대시보드를 엽니다.

## 인터랙티브 감사 실행

<Tabs>
  <Tab title="대시보드">
    로컬 감사는 현재 머신의 히스토리를 검색해야 하므로 CLI에서 시작합니다. `failproofai audit`을 실행하면 스캔 후 Failproof AI가 번들된 대시보드를 시작하고 **http://localhost:8020/audit**을 엽니다.

    감사 뷰에서 세션 수, 도구 호출, 프로젝트, 정책 적중 횟수를 검토하세요. 자주 발생하는 결과부터 시작하여 영향을 받은 프로젝트와 에이전트 히스토리를 확인한 후 적용을 활성화하세요.

    <Info>로컬 감사 대시보드는 Failproof AI Cloud의 **Analyze → Audits**와는 별개입니다. 로컬 감사는 머신에 저장되며 계정이나 네트워크 연결이 필요하지 않습니다.</Info>
  </Tab>
  <Tab title="CLI">
    ```bash
    npm install -g failproofai
    failproofai audit
    ```

    이 명령은 발견된 모든 지원 히스토리를 전체 스캔합니다. 현재 명령은 `--since`, `--cli`, `--project`, `--port`, `--no-open`과 같은 필터를 지원하지 않습니다.

    로컬 대시보드를 사용하는 동안 프로세스를 계속 실행 상태로 유지하세요. 완료되면 <kbd>Ctrl</kbd>+<kbd>C</kbd>를 누르세요.
  </Tab>
</Tabs>

현재 감사 어댑터는 Claude Code, Codex, GitHub Copilot CLI, Cursor, OpenCode, Pi, Hermes, OpenClaw, Factory, Devin, Antigravity, Goose의 히스토리를 읽을 수 있습니다. 로컬에서 사용 가능한 히스토리만 스캔됩니다.

## 반복 로컬 감사 예약

<Tabs>
  <Tab title="대시보드">
    로컬 대시보드에서 **Settings**를 열고, 예약된 감사를 활성화한 후, 주기를 선택하고, 결과를 받을 이메일 주소를 설정하세요. 대시보드와 CLI는 동일한 머신 구성을 업데이트합니다.
  </Tab>
  <Tab title="CLI">
    주간 감사를 활성화하고 지정된 주소로 결과를 전송합니다:

    ```bash
    failproofai audit --schedule 7 --email reliability@example.com
    failproofai audit --status
    ```

    주기는 1~90일을 허용하며 생략 시 기본값은 7입니다. 최초 설정 시 필요한 경우 로그인을 진행하며, `--email`은 별도 프롬프트 없이 리포트 주소를 지정합니다.

    로컬 감사 히스토리를 삭제하지 않고 예약을 중지합니다:

    ```bash
    failproofai audit --no-schedule
    ```
  </Tab>
</Tabs>

데몬은 백그라운드에서 예약된 스캔을 실행하고, 로컬 대시보드에서 사용하는 캐시된 결과를 새로 고치며, 설정된 리포트를 이메일로 전송합니다. 즉시 인터랙티브 스캔을 실행하려면 `failproofai audit`을 사용하세요.

## 로컬 증거에서 Cloud 운영으로 전환

로컬 감사는 빠른 기준선 역할을 합니다. 공유 트레이스, 반복 집단 감사, 결과 및 이슈, 알림, 조직 전체 정책 배포, 또는 플릿 상태 관리가 필요한 경우 머신을 Failproof AI Cloud에 연결하세요.

  </Card>
  <Card title="정책 활성화" icon="shield-check" href="/ko/start/first-policy">

  </Card>
</CardGroup>

<Warning>
  감사 출력은 검토를 위한 증거이며, 플래그된 모든 동작이 안전하지 않다는 증명이 아닙니다. 결과를 차단 적용으로 전환하기 전에 컨텍스트를 반드시 확인하세요.
</Warning>
