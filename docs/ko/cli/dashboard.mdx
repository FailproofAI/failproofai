```bash
failproofai
```

`http://localhost:8020`에서 웹 대시보드를 시작합니다.

## 옵션

The dashboard takes no flags — `failproofai` rejects any it does not recognize. The port is fixed at `8020`.

기본값이 아닌 Claude 프로젝트 폴더를 대시보드에 지정하려면, 실행 시 `CLAUDE_PROJECTS_PATH` 환경 변수를 설정하세요.

## 예시

```bash
# Launch the dashboard on http://localhost:8020
failproofai

# Use a custom Claude projects path via environment variable
CLAUDE_PROJECTS_PATH=~/my-claude-projects failproofai
```
