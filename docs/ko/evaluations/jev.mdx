Jev 평가는 **완료된 세션**을 읽고 0에서 1 사이의 점수를 반환합니다. "고객이 긴박감을 표현했는가?" 또는 "고객이 얼마나 불만을 느꼈는가?"와 같이 답변을 미리 알고 있는 경우에 사용하세요. 여러 실행에서 패턴을 찾는 데 도움이 되며, 도구 호출을 중단하지는 않습니다. 도구가 실행되기 **이전**에 내려지는 결정에는 [Jev 정책](/ko/policies/jev)을 사용하세요.

## 대시보드에서 평가 만들기

1. **Analyze → eval authoring**을 열고 **new eval**을 선택합니다.
2. 질문 하나와 가능한 답변을 설명합니다. 예: "에이전트가 환불 정책을 확인하기 전에 환불을 약속했는가? yes 또는 no로 답하세요." **draft**를 선택하고 결과가 분류 점수인지 검토합니다.
3. 최근 세션에서 [테스트](/ko/evaluations/test)한 후 [배포](/ko/evaluations/deploy)합니다. 새로 완료된 세션은 점수화되며, 이전 기록도 필요하다면 [백필](/ko/evaluations/deploy#score-sessions-you-already-have)을 사용하세요.

![공유 eval 작성 양식으로, 고정 답변 질문을 설명하고, 초안을 검토한 뒤, 테스트 후 배포합니다. 표시된 예는 코드 평가이며, Jev 질문도 동일한 작성 흐름을 사용합니다.](/images/dashboard/eval-authoring-draft.png)

어시스턴트는 코드, Jev 분류, [판정자(judge)](/ko/evaluations/judge) 중에서 선택할 수 있습니다. 배포 전에 선택 결과를 확인하세요. Jev는 산문 형태의 추론 없이 점수만 반환하므로, 설명이 필요한 경우에는 판정자를 선택하세요. 질문 유형 및 점수 한도에 대한 자세한 내용은 [Jev 평가 레퍼런스](/ko/reference/jev-evaluations)를 참조하세요.

## 점수 확인하기

**Observe → Evaluations**를 열면 에이전트별, 시간별로 결과를 차트로 확인할 수 있습니다. 터미널에서는 Cloud CLI로 동일한 결과를 조회할 수 있습니다:

```bash
fp evals --since 7d
fp evals --aggregate --since 7d
```

Cloud CLI는 결과 조회에 사용하며, 작성 및 배포는 대시보드에서 이루어집니다. 필터에 대한 자세한 내용은 [Cloud CLI 레퍼런스](/ko/reference/cloud-cli#evaluations)를 참조하세요.
