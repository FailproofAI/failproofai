Failproof AI는 팀이 에이전트가 무엇을 했는지 파악하고, 어디서 실패했는지 찾아내며, 동일한 동작이 재발하기 전에 안전장치를 배포할 수 있도록 돕습니다.

<Columns cols={2}>
  <Card title="Failproof 설정하기" icon="wand-sparkles" href="/ko/start/quickstart">
    스킬을 사용하여 프로젝트를 계측하고, 연결하고, 에이전트 로그가 정상적으로 수신되는지 확인하세요.
  </Card>
  <Card title="Failproof 어시스턴트에게 질문하기" icon="message-square-text" href="/ko/sessions/assistant">
    에이전트 로그를 자연어로 분석하고, 쿼리하고, 대시보드를 만들고, 감사를 실행하세요.
  </Card>
</Columns>

<Columns cols={3}>
  <Card title="에이전트가 무엇을 했는지 확인하기" icon="route" href="/ko/sessions/overview">
    하나의 세션에서 모델 호출, 도구, 오류, 사용자 입력, 지연 시간, 정책 결정을 추적하세요.
  </Card>
  <Card title="체계적으로 실패 찾기" icon="scan-search" href="/ko/audits/overview">
    정의된 세션 집합을 감사하고, 근거가 뒷받침된 발견 사항을 검토하며, 이슈로서 해결 과정을 추적하세요.
  </Card>
  <Card title="재발 방지하기" icon="shield-check" href="/ko/policies/overview">
    알려진 실패 유형을 정책으로 전환하고, 영향을 관찰한 후 전체 플릿에 배포하세요.
  </Card>
</Columns>

> **세션 → 감사 → 발견 사항 → 이슈 → 정책**<br />
> 무슨 일이 있었는지 추적하고, 실패를 찾아내고, 대응을 관리한 다음, 향후 실행에서 동일한 동작을 방지하세요.

## 시작하기

처음으로 계측된 에이전트를 배포하는 경우 [빠른 시작](/ko/start/quickstart)부터 시작하세요. 데이터가 이미 수신되고 있다면 [세션](/ko/sessions/overview)을 열어 감사나 정책을 구성하기 전에 실제 실행을 먼저 검토해 보세요.

<Card title="하나의 실패를 찾아 방지하기" icon="arrow-right" href="/ko/start/quickstart">
  캡처부터 안전하게 배포된 정책까지 전체 워크플로를 완료하세요.
</Card>
