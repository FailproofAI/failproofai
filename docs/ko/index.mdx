Failproof AI는 팀이 에이전트가 무엇을 했는지 파악하고, 어디서 실패했는지 찾아내며, 동일한 동작이 다시 발생하기 전에 안전장치를 배포할 수 있도록 도와줍니다.

**하네스**는 에이전트가 실제로 실행되는 환경을 의미합니다. Failproof AI는 Claude Code, Codex 같은 코딩 CLI, Hermes 같은 채팅 게이트웨이, OpenClaw 같은 자체 호스팅 어시스턴트 등 12가지 하네스를 지원하며, 동일한 이벤트, 동일한 정책, 동일한 세션 히스토리가 모든 하네스에 적용됩니다. 하네스가 없는 에이전트는 [Python SDK](/ko/reference/custom-agents)를 통해 보고하며, 이를 통해 추적 및 감사가 이루어집니다. 해당 환경에서 정책을 적용하려면 자체 런타임에 훅을 추가해야 합니다.

> **세션 → 감사 → 발견 사항 → 이슈 → 정책**<br />
> 무슨 일이 있었는지 추적하고, 실패를 찾아내고, 대응을 관리한 다음, 이후 실행에서 동일한 동작이 반복되지 않도록 방지하세요.

## 시작하기

처음으로 계측된 에이전트를 배포하는 경우, [퀵스타트](/ko/start/quickstart)부터 시작하세요. 데이터가 이미 들어오고 있다면 [Sessions](/ko/sessions/overview)를 열어 감사나 정책을 설정하기 전에 실제 실행 결과를 먼저 확인하세요.
