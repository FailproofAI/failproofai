Failproof AI는 팀이 에이전트의 행동을 이해하고, 실패 지점을 파악하며, 동일한 문제가 재발하기 전에 안전장치를 배포할 수 있도록 돕습니다.

**harness**는 에이전트가 실제로 실행되는 환경을 의미합니다. Failproof AI는 12가지 환경을 지원합니다 — Claude Code, Codex 같은 코딩 CLI, Hermes 같은 채팅 게이트웨이, OpenClaw 같은 자체 호스팅 어시스턴트 — 그리고 동일한 이벤트, 동일한 정책, 동일한 세션 기록이 모든 환경에 적용됩니다. harness 없이 동작하는 에이전트는 [Python SDK](/ko/reference/custom-agents)를 통해 보고하며, 추적 및 감사가 이루어집니다. 해당 환경에서 정책을 적용하려면 자체 런타임에 훅을 추가해야 합니다.

> **세션 → 감사 → 발견 → 이슈 → 정책**<br />
> 발생한 일을 추적하고, 실패를 찾고, 대응을 관리한 후, 향후 실행에서 동일한 동작을 방지하세요.

## 시작하기

처음으로 구성된 에이전트를 배포하는 경우, [퀵스타트](/ko/start/quickstart)부터 시작하세요. 데이터가 이미 수신되고 있다면, [Sessions](/ko/sessions/overview)를 열어 감사나 정책을 설정하기 전에 실제 실행 기록을 먼저 살펴보세요.
