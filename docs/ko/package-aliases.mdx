## 공식 패키지

npm의 공식 패키지명은 **`failproofai`**입니다:

```bash
npm install -g failproofai
# or
bun add -g failproofai
```

---

## 별칭 이름을 직접 소유하는 이유

타이포스쿼팅(typosquatting)은 공급망 공격의 일종으로, 악의적인 공격자가 인기 패키지와 한 글자 차이밖에 나지 않는 패키지 이름을 등록하는 방식입니다. 설치 명령어를 잘못 입력한 사용자는 시스템 전체 접근 권한을 가진 공격자 제어 코드를 실행하게 됩니다. 이는 바로 Failproof AI가 방어하도록 설계된 위협입니다.

이러한 공격 경로를 차단하기 위해, **npm에서 `failproofai`의 일반적인 오타 및 표기 변형을 선제적으로 모두 선점**해 두었습니다. 이 이름들은 제3자가 등록할 수 없으며, 각각은 실제 `failproofai` 패키지를 설치하고 위임하는 얇은 프록시 역할을 합니다.

## 등록된 별칭

**표기 변형** - "failproof ai"를 작성하는 다양한 방식:

| 패키지 | 상태 |
|--------|------|
| `failproof` | ✅ 게시됨 |
| `failproof-ai` | ⏳ npm 검토 대기 중 |
| `fail-proof-ai` | ⏳ npm 검토 대기 중 |
| `failproof_ai` | ⏳ npm 검토 대기 중 |
| `fail_proof_ai` | ⏳ npm 검토 대기 중 |
| `fail-proofai` | ⏳ npm 검토 대기 중 |

**`failprof*` 오타** - "proof"에서 `o` 하나가 빠진 경우:

| 패키지 | 상태 |
|--------|------|
| `failprof` | ✅ 게시됨 |
| `failprof-ai` | ✅ 게시됨 |
| `failprofai` | ⏳ npm 검토 대기 중 |
| `fail-prof-ai` | ⏳ npm 검토 대기 중 |
| `failprof_ai` | ⏳ npm 검토 대기 중 |

**`faliproof*` 오타** - `a`와 `i`가 전치된 경우:

| 패키지 | 상태 |
|--------|------|
| `faliproof` | ✅ 게시됨 |
| `faliproof-ai` | ✅ 게시됨 |
| `faliproofai` | ⏳ npm 검토 대기 중 |

> **대기 중인 이유는?** npm의 스팸 방지 정책상, 구두점을 제거하고 유사도 검사를 거쳤을 때 기존 패키지와 동일한 문자열로 정규화되는 이름은 등록이 차단됩니다. 저희는 이름 선점 방지를 목적으로 npm 지원팀에 해당 이름 예약을 요청한 상태입니다. 승인되는 즉시 활성화될 예정입니다.

게시된 별칭이 저희 소유인지 확인하려면 다음 명령어를 사용하세요:

```bash
npm info failproof
# Look for: "ExosphereHost Inc." in the maintainers field
```

## 별칭 작동 방식

각 별칭 패키지는:

1. `failproofai`를 의존성으로 등록합니다 — 실제 패키지가 설치되고 해당 바이너리를 사용할 수 있게 됩니다.
2. 자체 이름(예: `failprof-ai`)과 일치하는 바이너리를 노출하여 모든 인수를 `failproofai` 바이너리로 전달합니다.

프록시는 두 줄짜리 Node 스크립트이며, 별도의 로직, 네트워크 호출, `failproofai` 자체 외의 데이터 수집은 전혀 없습니다.
