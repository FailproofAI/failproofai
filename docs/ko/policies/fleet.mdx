플릿 커버리지는 Cloud가 할당한 내용과 각 머신이 마지막으로 적용한 내용을 비교합니다.

## 머신 확인

```bash
failproofai config --status
failproofai flush --wait --timeout 120
```

Cloud에서 확인:

```bash
fp fleet list
fp fleet diff
fp fleet show <machine-id>
```

`fp fleet`은 API 키가 아닌 로그인된 세션이 필요합니다.

| 명령어 | 설명 |
| --- | --- |
| `fp fleet list` | 머신 목록과 배포 상태 표시 |
| `fp fleet show <machine>` | 특정 머신의 정책 세트 표시 |
| `fp fleet deploy <machine> --add <ref>` | 정책 추가 또는 업데이트 |
| `fp fleet deploy <machine> --remove <id>` | 정책 제거 |
| `fp fleet deploy <machine> --set <ref>...` | 전체 정책 세트 교체 |
| `fp fleet diff [machine]` | 의도된 버전과 적용된 버전 비교 |
| `fp fleet history <machine>` | 배포 생성 이력 목록 표시 |
| `fp fleet rollback <machine> <generation>` | 특정 생성 시점으로 복원 |
| `fp fleet rename <machine> "<label>"` | Cloud 레이블 변경 |

<Warning>
  `--set`은 전체 정책 세트를 교체합니다. `--add <id>`만 단독으로 사용하면 새 정책이 즉시 적용됩니다. 섀도 롤아웃을 위해서는 `--add <id>:observe`를 사용하세요.
</Warning>

## 관찰 후 적용

```bash
fp fleet deploy ci-runner-01 --add prod-guard:observe
fp guardrails summary --since 24h --machine ci-runner-01
fp fleet deploy ci-runner-01 --add prod-guard:enforce
```

관찰 모드는 실제 정책을 평가하고 에이전트를 차단하지 않으면서 allow가 아닌 결정을 기록합니다.

## 머신 식별

머신 ID는 고정되어 있으며 해당 머신을 식별합니다. 레이블은 표시 전용으로 변경할 수 있습니다:

```bash
failproofai config --machine-label checkout-runner-03
fp fleet rename <machine-id> "Checkout runner 03"
```

레이블을 변경해도 머신의 재연결이나 키 재발급은 이루어지지 않습니다.
