scope를 사용하여 로컬 정책을 적용할 대상을 결정하세요:

| Scope | 적용 대상 |
| --- | --- |
| `user` | 이 머신에서 지원되는 모든 에이전트 |
| `project` | 이 프로젝트에서 실행 중인 에이전트 |
| `local` | 로컬 프로젝트 설정의 Claude만 해당 |
| `all` | 제거 전용 |

```bash
failproofai policies add block-sudo --scope user
failproofai policies add block-rm-rf --scope project
```

Hermes와 OpenClaw는 user scope만 지원합니다. 대부분의 다른 하네스는 user 및 project를 지원합니다. Claude는 local scope도 지원합니다. [Harnesses](/ko/reference/harnesses)를 참조하세요.

## 정책 매개변수

정책 설정은 해당 scope의 `policies-config.json`에 저장됩니다. 가능하면 로컬 대시보드의 **Policies → Configure** 화면을 사용하세요.

매개변수는 하나의 정책에 속하며 해당 정책의 결정 방식을 변경합니다. 예를 들어, 허용 목록(allow-list)을 사용하면 차단 정책이 안전하다고 알려진 명령어나 경로를 허용하도록 설정할 수 있습니다.

커스텀 정책 파일은 `.failproofai/policies/`에서 자동으로 불러오거나, 명시적으로 지정할 수 있습니다:

```bash
failproofai policies -i -c ./guards.mjs --scope project
```

명시적으로 지정된 경로를 제거하려면:

```bash
failproofai policies -u -c
```

## 파일

| 파일 | 용도 |
| --- | --- |
| `~/.failproofai/config.json` | 머신 및 콜렉터 설정 |
| `policies-config.json` | scope별 활성화된 정책 및 매개변수 |
| `.failproofai/policies/*policies.mjs` | 컨벤션에 따라 자동 로드되는 정책 |
| `~/.failproofai/policies/packs/installed.json` | 설치된 팩 및 선택 항목 |

설치된 팩의 아티팩트를 직접 수정하지 마세요. 수정이 필요하면 재설치하거나 수정된 릴리스를 배포하세요.
