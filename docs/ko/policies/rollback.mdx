롤백은 배포된 버전을 변경하거나 정책 할당을 제거합니다. 인시던트를 설명하는 결정 이력은 삭제되지 않습니다.

## 머신 롤백

<Tabs>
  <Tab title="대시보드">
    1. **Admin → enforcement**로 이동하여 영향받은 머신을 펼치고, 마지막으로 정상 작동하던 정책 세트를 확인합니다.
    2. **edit**을 선택하고 해당 버전과 효과를 복원한 뒤 새 배포를 적용합니다.
    3. 머신 체크인을 기다린 후 보고된 배포를 확인합니다.
    4. **Observe → policy**와 영향받은 세션을 열어 유효한 작업이 더 이상 차단되지 않는지 확인합니다.

  </Tab>
  <Tab title="CLI">
    되돌릴 세대를 찾아 복원한 후 적용되었는지 확인합니다:

    ```bash
    fp fleet history ci-runner-01
    fp fleet rollback ci-runner-01 3
    fp fleet diff ci-runner-01
    failproofai config --status
    ```

    `fp fleet rollback`은 카운터를 되감는 것이 아니라 이전 세트를 포함하는 **새로운** 세대를 생성합니다. 따라서 이력은 항상 추가 전용으로 유지됩니다. 해당 세대가 이미 비활성화되거나 삭제된 정책을 참조하는 경우 실행을 거부하며, 제공할 수 없는 세트를 복원하는 대신 서버가 이를 명시적으로 알려줍니다.

    `fp fleet diff`는 의도된 상태와 실제 전달 상태를 비교해 보여줍니다. 머신이 다음 폴링 전까지는 드리프트 상태로 표시되므로, 롤백이 적용되지 않았다고 결론 내리기 전에 diff를 확인하세요. `failproofai config --status`는 머신 자체에서 상태를 확인합니다.
  </Tab>
</Tabs>

## 일시 중지는 롤백이 아닙니다

일시 중지는 **하나의 세션** 동안 로컬에 설치된 모든 정책을 중단하며, 항상 자동으로 만료됩니다. 팩, 커스텀 파일, 컨벤션 파일, 빌트인 모두 해당됩니다. Cloud 관리 정책과 항상 활성화된 `block-failproofai-commands` 가드만 계속 적용됩니다. 따라서 일시 중지는 잘못된 Cloud 배포에 대한 임시 방편이 될 수 없으며, 실제로 보이는 것보다 훨씬 넓은 영향 범위를 가집니다. 팩은 사실상 모든 로컬 적용의 핵심이며, 일시 중지 기간 동안 팩 fail-closed 가드도 건너뜁니다.

| 명령어 | 효과 |
|---|---|
| `failproofai config --pause` | 이 디렉터리의 최신 에이전트 세션을 30분간 일시 중지 |
| `failproofai config --pause 10m` | 지정한 시간 동안. 최대 8시간; `s`/`m`/`h` 접미사 사용 가능, 숫자만 입력 시 분 단위 |
| `failproofai config --pause --session <id>` | 특정 세션을 대상으로 지정 |
| `failproofai config --resume` | 일시 중지 조기 종료 |
| `failproofai config --resume --all` | 모든 활성 일시 중지 종료 |
| `failproofai config --status` | 일시 중지된 항목과 해제 시간 확인 |

## 롤백이 필요한 경우

- 정책이 예상된 프로덕션 작업을 차단할 때.
- 매치 볼륨이 관찰된 롤아웃 예측보다 현저히 높을 때.
- 정책이 통합에서 제공하지 않는 필드에 의존할 때.
- 새 버전이 의도된 실패 모드 외의 동작을 변경할 때.

롤백 후 영향받은 세션을 열고 오탐을 유발한 조건을 파악합니다. 새 버전을 생성하고 안전하지 않은 케이스와 정상적인 케이스 모두 로컬에서 테스트한 뒤, 다시 적용하기 전에 observe 과정을 거칩니다:

```bash
fp policies test ./policy.mjs --tool Bash --command '<the legitimate case>' --expect allow
fp policies publish my-policy ./policy.mjs
fp fleet deploy ci-runner-01 --add my-policy:observe
fp guardrails summary --since 24h --machine ci-runner-01
```

`:observe`가 이를 섀도우 롤아웃으로 만드는 요소입니다. `fp fleet deploy ... --add my-policy`를 단독으로 사용하면 **즉시 적용**됩니다. 효과를 생략하면 이미 배포된 효과로 해석되고, 그다음 `enforce`로 해석되는데, 방금 롤백한 정책에서는 인시던트를 재발시키는 것을 의미합니다. Observe 모드는 여전히 정책을 실제로 평가하고 allow가 아닌 모든 판정을 기록합니다. 적용만 보류되므로, `fp guardrails summary`는 이전 버전에서 문제가 발생했던 동일한 트래픽에 대해 새 버전을 측정합니다. 수치가 충분하다고 판단되면 `--add my-policy:enforce`로 승격합니다.

<Warning>
  인시던트 중에 적용을 일시 중지하는 것이 적절할 수 있지만, 해당 범위 내의 모든 활성 정책에 대한 노출이 넓어집니다. 가능하면 특정 정책 버전을 롤백하는 방법을 선택하세요.
</Warning>
