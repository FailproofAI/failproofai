`fp`를 사용하여 Cloud 텔레메트리를 검사하고 감사(audit), 발견 사항(finding), 이슈, 알림, 키, 사용자, 쿼리, 설정을 관리하세요. 로컬 훅, 정책, 캡처, 머신 등록에는 [`failproofai`](/ko/reference/failproof-cli)를 사용하세요.

릴리스된 Cloud CLI를 독립 도구로 설치하세요:

```bash
uv tool install fp-cli
fp version
```

## 로그인

```bash
fp login
fp whoami
```

## 문법

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

글로벌 옵션은 명령어 앞에 작성해야 합니다:

```bash
fp --json sessions --since 24h
```

터미널 도움말은 `fp COMMAND --help` 또는 `fp COMMAND SUBCOMMAND --help`를 실행하세요.


### 이벤트

```text
fp events [OPTIONS]
```

개별 에이전트 이벤트를 나열합니다. 기본 경량 피드는 원시 페이로드를 제외합니다. `--full`은 범위가 한정된 조사에만 사용하세요.

| 옵션 | 설명 |
| --- | --- |
| `--limit`, `-n <n>` | 최대 전체 행 수. 기본값: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h`, 또는 `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | ISO 8601 UTC 범위; `--since`를 덮어씁니다. |
| `--env <value>` | 환경 필터; 반복하거나 쉼표로 구분된 값 사용. |
| `--event-type <value>` | 이벤트 유형 필터; 반복하거나 쉼표로 구분된 값 사용. |
| `--agent-id <value>` | 에이전트 필터; 반복하거나 쉼표로 구분된 값 사용. |
| `--session-id <value>` | 세션 필터; 반복하거나 쉼표로 구분된 값 사용. |
| `--search <text>` | 페이로드 텍스트 검색; 반복 가능하며 조건 중 하나라도 일치하면 반환. |
| `--order asc\|desc` | 시간 정렬 순서. 기본값: 최신 항목 먼저. |
| `--all` | `--limit`까지 자동 페이지네이션. |
| `--cursor <token>` | 불투명 커서에서 재개. |
| `--page-size <n>` | `--all` 사용 시 요청당 행 수; 최대 `200`. |
| `--full` | 더 무거운 이벤트 엔드포인트를 통해 원시 페이로드 포함. |
| `--fields <csv>` | 선택한 필드만 반환; `payload` 요청 시 전체 모드 활성화. |

```bash
fp events --session-id <session-id> --order asc --all
fp --json events --full --session-id <session-id> --all
```

#### 감사 생성 옵션

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| 옵션 | 설명 |
| --- | --- |
| `--file <path>` | JSON을 기반으로 정의하거나 stdin에는 `-` 사용. 명시적 플래그가 파일 값을 덮어씁니다. |
| `--description <text>` | 실패 질문 또는 목적 기술. |
| `--enabled` / `--disabled` | 스케줄링을 활성 또는 비활성으로 시작. 기본값: 활성. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. 기본값: `86400`. |
| `--schedule-anchor <timestamp>` | ISO 8601 형식의 고정 UTC 단계. 기본값: 다음 09:00 UTC. |
| `--window-mode since_last\|fixed` | 마지막으로 완전히 분석된 윈도우 이후 계속하거나 롤링 윈도우를 반복적으로 검사. 기본값: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. 기본값: `604800`. |
| `--scope '<json>'` | `environments`, `agent_ids` 또는 기타 지원되는 범위 필드로 필터링. |
| `--ignore-error-type <type>` | 오류 유형 제외; 반복하거나 쉼표로 구분. |
| `--llm` / `--no-llm` | 에이전틱 분석 활성화 또는 비활성화. 기본값: 활성. |
| `--top-k <n>` | `1`–`500` 발견 사항 유지. 기본값: `50`. |
| `--sensitivity low\|medium\|high` | 보고 민감도 설정. 기본값: `medium`. |
| `--channels '<json>'` | 알림 채널 배열. |
| `--text <brief>` | 인라인 브리핑, 최대 8,192자. |
| `--text-file <path>` | 파일에서 브리핑 읽기; `--text`와 상호 배타적. |
| `--url <https-url>` | 공개 HTTPS 참조 추가; 최대 다섯 번 반복 가능. |

첫 번째 실행에 컨텍스트가 필요한 경우 생성 시 포함하세요. 생성은 대기열에 추가된 실행이 시작되기 전에 정의와 컨텍스트를 함께 커밋합니다.

<Note>
  `fp audits run`은 비동기입니다. 발견 사항을 읽기 전에 `fp audits runs NAME`을 폴링하여 최신 실행이 성공하거나 실패할 때까지 기다리세요.
</Note>

| `fp issues comment-add INCIDENT_ID` | 댓글 추가. | `--body`, `--file` 중 정확히 하나 |
| `fp issues comment-delete INCIDENT_ID COMMENT_ID` | 댓글 삭제. | `--yes`, `-y` |
| `fp issues subscribers INCIDENT_ID` | 구독자 목록. | — |
| `fp issues subscribe INCIDENT_ID` | 본인 또는 다른 운영자 구독. | `--email` |
| `fp issues unsubscribe INCIDENT_ID` | 구독 제거. | `--email` |

유효한 이슈 상태는 `firing`, `acknowledged`, `resolved`입니다. 독립 이슈 심각도는 `info`, `warning`, `critical`입니다.

## 글로벌 플래그

| 플래그 | 설명 |
| --- | --- |
| `--json` | 기계가 읽을 수 있는 JSON 출력. |
| `--base-url <url>` | 자체 호스팅 또는 개발 대시보드 사용. |
| `--org <slug>` | 이번 호출에 사용할 조직 선택. |
| `--token <token>` | 저장된 사용자 세션 토큰 재정의. |
| `--api-key <key>` | API 키로 자동화 인증; 저장되지 않음. |
| `--timeout <seconds>` | HTTP 타임아웃; 양수여야 함. 기본값: `30`. |
| `--quiet`, `-q` | stderr의 상태 출력 억제. |
| `--no-color` | 색상 출력 비활성화. |
| `--insecure` / `--secure` | TLS 인증서 검증 비활성화 또는 복원. |
| `--version` | 버전을 출력하고 종료. |
| `--help`, `-h` | 도움말 표시. |

`--api-key`는 자동화용입니다. 로그인, 조직 전환, 어시스턴트 명령어는 사용자 세션이 필요합니다.
