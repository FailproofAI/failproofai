AI 도구를 Failproof AI Cloud에 연결하고 에이전트 데이터를 활용하세요. 세션과 이벤트를 조회하고, 읽기 전용 SQL을 실행하고, 대시보드, 알림, 이슈, 감사 기록, 정책을 읽을 수 있습니다. 권한이 있다면 알림 생성이나 정책 배포와 같은 변경 작업도 가능합니다.

모든 호출은 **본인의** 권한으로 실행되며, 연결 시 선택한 **하나의** 조직 내에서만 동작합니다.

호스팅 및 자체 호스팅 여부에 관계없이 모두 동일한 주소를 사용합니다:

```text
https://gateway.befailproof.ai/mcp
```

## 클라이언트 연결

클라이언트에 위 주소를 추가하세요. 도구를 처음 사용할 때 브라우저가 열립니다. Failproof AI Cloud의 위치를 선택하고, 로그인한 후 조직 하나를 선택하고 **허용**을 클릭하세요. **취소**를 클릭하면 아무것도 연결되지 않습니다.

페이지에는 앱 이름과 반환 주소가 표시됩니다. 자체 웹 주소로 식별되지 않는 앱은 **미확인 앱**으로 표시되므로, 본인의 클라이언트에서 직접 시작한 경우에만 계속 진행하세요.

<Tabs>
  <Tab title="Claude">
    claude.ai 또는 Claude Desktop에서 **설정 → 커넥터 → 커스텀 커넥터 추가**로 이동하세요. 이름을 `Failproof AI`로 지정하고 주소를 입력한 후 **추가**를 선택한 다음 **연결**을 클릭하세요.

    Team 및 Enterprise 플랜에서는 먼저 소유자가 조직 전체를 위한 커넥터를 추가해야 합니다. 이후 각 구성원이 개인 계정을 연결합니다.
  </Tab>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http failproofai https://gateway.befailproof.ai/mcp
    ```

    그런 다음 Claude Code 내에서 `/mcp`를 실행하고 `failproofai`를 선택한 후 **인증**을 클릭하세요.
  </Tab>
  <Tab title="Cursor">
    `~/.cursor/mcp.json` 또는 프로젝트의 `.cursor/mcp.json`에 다음을 추가하세요:

    ```json
    {
      "mcpServers": {
        "failproofai": { "url": "https://gateway.befailproof.ai/mcp" }
      }
    }
    ```

    Cursor에서 서버 옆에 **로그인 필요**가 표시됩니다. 선택하여 로그인하세요.
  </Tab>
  <Tab title="Codex">
    `~/.codex/config.toml`에 다음을 추가하세요:

    ```toml
    [mcp_servers.failproofai]
    url = "https://gateway.befailproof.ai/mcp"
    ```

    그런 다음 `codex mcp login failproofai`를 실행하세요.
  </Tab>
  <Tab title="다른 클라이언트">
    OAuth를 사용한 Streamable HTTP 방식의 원격 MCP 서버를 지원하는 클라이언트라면 모두 사용 가능합니다. 위 주소를 입력하기만 하면 됩니다. 별도의 클라이언트 ID나 시크릿 설정은 필요 없습니다.
  </Tab>
</Tabs>

## 연결당 하나의 조직

하나의 연결은 선택한 조직 내에서만 동작합니다. 두 조직을 사용하려면 `failproofai-acme`, `failproofai-sandbox`와 같이 서로 다른 이름으로 서버를 두 번 추가하고 각각 해당 조직에 연결하세요.

데모 조직은 연결을 허용하지 않습니다. 직접 생성한 조직을 선택하세요.

## 권한

연결은 아래 범위 내에서 해당 조직에서 본인이 할 수 있는 작업을 수행할 수 있습니다. 현재 권한을 따르므로, 관리자가 권한을 추가하면 도구도 권한을 얻고, 권한을 제거하면 다음 호출 시 도구도 해당 권한을 잃습니다.

| 권한 | 도구가 할 수 있는 작업 |
| --- | --- |
| `events:read` | 이벤트 목록 조회, 세션 개요 확인, 에이전트 및 환경 목록 조회 |
| `evaluations:read` | 세션 목록 조회, 평가 결과 및 작업 확인 및 요약 |
| `evaluations:trigger` | 평가 생성, 새 버전 게시, 활성화/비활성화, 백필, 세션 재평가 |
| `dashboards:read`, `dashboards:write` | 대시보드 읽기, 또는 생성·이름 변경·쿼리 추가 |
| `queries:read`, `queries:write` | 저장된 쿼리 읽기, 또는 저장 및 편집 |
| `queries:run` | 읽기 전용 SQL 쿼리 하나 실행 및 쿼리 스키마 확인 |
| `alerts:read`, `alerts:write` | 알림 읽기, 또는 생성·수정·일시정지·삭제·테스트 |
| `issues:read` | 이슈 읽기, 확인 및 댓글 작성 |
| `issues:create` | 알림에 이슈 등록 |
| `issues:close` | 이슈 해결 및 종료 |
| `audits:read`, `audits:write` | 감사 기록·실행·결과 읽기, 또는 감사 생성·수정 및 실행 시작 |
| `code_fixes:read` | 이슈 수정 방법 확인 및 에이전트가 수정에 활용할 컨텍스트 가져오기 |
| `code_fixes:write` | Failproof AI Cloud에서 수정 작업 시작 (GitHub에 풀 리퀘스트 생성) |
| `policies:read`, `policies:write` | 정책·머신·배포 읽기, 또는 정책 게시·배포·롤백 |

세션 및 이벤트 링크 생성, 이 문서 검색 등 조직 데이터를 읽지 않는 도구는 별도 권한이 필요하지 않습니다.

AI 도구는 API 키, 사용자, 설정, 조직 관리에는 절대 접근할 수 없으며 이벤트를 전송할 수도 없습니다.

## 변경 사항 승인

클라이언트가 프롬프트를 표시할 수 있는 경우, 쓰기 작업을 수행하기 전에 먼저 확인을 요청합니다. 변경될 내용을 확인하고 **이 변경 사항 승인**을 선택하여 진행하세요. 거부하거나 약 4분 내에 응답하지 않으면 아무것도 변경되지 않습니다. 일부 클라이언트는 1분 후 대기를 중단하므로 신속하게 응답하세요.

<Warning>
  프롬프트를 지원하지 않는 클라이언트는 확인 요청 없이 클라이언트가 호출하는 즉시 쓰기 작업이 실행됩니다. 이 경우 클라이언트 자체의 확인이 유일한 보호 수단이므로, 쓰기 도구 사용 시 클라이언트 확인 기능을 반드시 활성화해 두세요.
</Warning>

## 연결된 앱 및 해지

**설정 → 통합 → MCP**에서 현재 조직의 연결된 앱 목록과 각 앱의 권한 및 마지막 사용 시간을 확인할 수 있습니다. **해지**를 클릭하면 즉시 앱 접근이 차단됩니다. 클라이언트에서 서버를 제거해도 연결이 해지됩니다.

조직당 최대 5개의 앱을 연결할 수 있습니다. 동일한 앱을 다시 연결하면 이전 연결이 교체됩니다.

## 자체 호스팅 배포

연결 시 **자체 호스팅 Failproof AI Cloud**를 선택하고 로그인에 사용하는 주소를 입력하세요. 배포 환경은 공개 HTTPS로 접근 가능해야 합니다.

도구 호출과 그 결과는 AI 도구와 배포 환경 사이를 오가며 호스팅된 Failproof AI 게이트웨이를 통해 전달됩니다. 게이트웨이는 이를 저장하지 않습니다.

## 데이터 처리 방침

결과는 연결된 AI 도구로 전달되며, 해당 도구 제공업체의 약관에 따라 처리됩니다. 각 도구 호출에 대해 Failproof AI는 도구 이름, 결과, 소요 시간, 조직 정보만 기록하며 인수나 결과 내용은 기록하지 않습니다. [개인정보 처리방침](https://befailproof.ai/privacy/)을 참고하세요.

## 문제 해결

| 표시되는 내용 | 해결 방법 |
| --- | --- |
| "다른 브라우저에서 시작됨" | 쿠키를 허용한 상태에서 클라이언트가 열었던 브라우저에서 로그인을 완료한 후 클라이언트에서 다시 시작하세요 |
| **허용** 후 오류 발생 | 링크는 한 번만 사용 가능하며 10분 후 만료됩니다. 클라이언트에서 다시 시작하세요 |
| 예상한 도구가 없음 | 해당 조직에서 해당 권한이 없는 것입니다. 관리자에게 문의하세요. 권한을 받은 후 재연결할 필요는 없습니다 |
| 클라이언트가 계속 로그인을 요청함 | 연결이 해지되었거나, 조직을 탈퇴했거나, 90일간 사용하지 않은 경우입니다. 다시 연결하세요 |
| "연결된 앱이 5개입니다" | **설정 → 통합 → MCP**에서 하나를 해지한 후 다시 연결하세요 |

그래도 해결되지 않으면 [support@befailproof.ai](mailto:support@befailproof.ai)로 이메일을 보내세요.
