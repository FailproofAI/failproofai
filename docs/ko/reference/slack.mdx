Slack에서 [Failproof Assistant](/ko/sessions/assistant)에게 질문하세요. 채널에서 앱을 멘션하거나, 다이렉트 메시지를 보내거나, `/failproof <질문>`을 사용하세요. 답변은 **본인의** Failproof AI 권한을 사용하고, 차트는 스레드에 전달되며, 무언가를 변경하는 작업은 먼저 승인을 요청합니다.

공식 앱은 하나입니다. Failproof AI Cloud가 호스팅 방식이든 셀프 호스팅 방식이든 동일하게 작동합니다.

<Note>
  답변은 AI 모델이 생성하므로 부정확할 수 있습니다. 중요한 내용은 반드시 연결된 원본 데이터와 대조하여 확인하세요.
</Note>

## 워크스페이스 연결

Failproof AI에서 `settings:write` 권한이 필요하고, Slack에서는 워크스페이스 관리자 또는 소유자이거나 앱을 추가하는 담당자여야 합니다.

<Tabs>
  <Tab title="Failproof AI에서 연결">
    1. **Settings → Integrations**으로 이동하여 **Add to Slack**을 선택합니다.
    2. Slack에서 앱을 승인합니다.
    3. Failproof AI로 돌아와 워크스페이스를 조직에 연결하는 것을 확인합니다.
  </Tab>
  <Tab title="Slack에서 연결">
    1. 앱을 추가한 후 **Home** 탭을 엽니다.
    2. **Continue with FailproofAI Cloud**를 선택하거나, **Use my own URL**을 선택하고 로그인 주소를 입력합니다.
    3. 계속 버튼을 선택하고, 로그인하여 조직을 선택한 후 확인합니다. 링크는 1회만 사용 가능하며 10분 후 만료됩니다.
  </Tab>
</Tabs>

워크스페이스 하나는 조직 하나에, 조직 하나는 워크스페이스 하나에 연결됩니다.

계정이 없으신가요? 먼저 [계정을 생성](https://app.befailproof.ai/login)한 후 연결하세요.

## Slack에서의 사용자 식별

처음 질문할 때 앱이 사용자를 다음과 같이 식별합니다.

- **이메일로 자동 식별**: 연결된 워크스페이스의 정식 멤버이고, Slack 이메일이 확인된 상태이며, 해당 이메일을 사용하는 조직 멤버가 정확히 한 명인 경우.
- **그 외**: 비공개 **Link your account** 버튼이 표시되며, 이를 통해 Failproof AI에서 Slack 계정과 본인 계정을 연결할 수 있습니다.

## 질문하기

| 위치 | 방법 |
| --- | --- |
| 채널 | 앱을 멘션. 이후 해당 스레드에서 멘션 없이 계속 대화 가능 |
| 다이렉트 메시지 | 앱에 메시지 전송 |
| 앱이 참여한 그룹 다이렉트 메시지 | 멘션 후 스레드에서 계속 대화 |
| Slack Connect 채널 | 앱을 멘션 |
| 앱이 참여한 모든 대화 | `/failproof <질문>`으로 스레드 시작 |
| `/failproof help` | 앱의 기능 확인 |
| `/failproof status` | 연결된 조직 및 연결된 계정 확인 |
| `/failproof link` | 연결된 Failproof AI 계정 확인 |

스레드 하나는 하나의 대화입니다. 동료들이 같은 스레드에서 앱을 멘션하면 각자의 권한으로 답변을 받을 수 있습니다. 스레드를 시작한 사람만 멘션 없이 대화를 이어갈 수 있습니다.

답변이 데이터인 경우, 앱은 차트 또는 표와 함께 Failproof AI에서 열 수 있는 링크를 게시합니다.

## 변경 사항 승인

어시스턴트가 수행하는 모든 변경 작업은 **Approve** 및 **Cancel** 버튼을 먼저 표시하며, **Approve**를 누르기 전에 Slack이 한 번 더 확인을 요청합니다. 버튼은 질문한 사람만 사용할 수 있고 5분 후 만료되며, 변경은 해당 사용자의 권한으로 적용됩니다.

Slack에서 어시스턴트는 권한이 있는 경우 저장된 쿼리 및 대시보드, 평가, 알림, 감사, 이슈, 정책을 변경하고 코드 수정을 제안할 수 있습니다. API 키, 사용자, 설정은 변경할 수 없습니다.

## 링크 미리보기

호스팅된 Failproof AI Cloud에서 Slack에 붙여넣은 Failproof AI 이슈, 세션, 평가 링크는 카드로 펼쳐집니다. 카드는 링크를 붙여넣은 사람에게 표시 권한이 있는 내용만 보여줍니다. 셀프 호스팅 주소의 링크는 미리보기가 표시되지 않지만, 어시스턴트가 직접 답변에 포함한 카드는 계속 표시됩니다.

## Slack Connect 채널

다른 워크스페이스의 사람들도 조직의 멤버이고 계정을 연결한 경우 앱을 사용할 수 있습니다. 답변은 대화의 모든 참여자에게 표시되므로(조직 멤버가 아닌 사람 포함), 모두가 볼 수 있는 환경임을 염두에 두고 질문하세요.

채널에 참여한 모든 다른 워크스페이스에서 적어도 한 명이 조직 계정과 연결해야만 앱이 답변합니다. 그 전까지는 질문한 사람에게 그 이유를 안내합니다.

## 앱이 요청하는 권한

| Slack 권한 | 용도 |
| --- | --- |
| `app_mentions:read` | 앱 멘션 감지 |
| `channels:history`, `groups:history`, `im:history`, `mpim:history` | 다이렉트 메시지 및 앱 스레드의 답글 수신. 앱은 다른 메시지를 무시하며 과거 대화를 읽지 않음 |
| `channels:read`, `groups:read`, `im:read`, `mpim:read` | 대화 유형 확인 및 답변 가시 범위 파악 |
| `chat:write` | 답변 및 승인 버튼 게시 |
| `commands` | `/failproof` 명령어 제공 |
| `files:write` | 차트 게시 |
| `links:read`, `links:write` | 붙여넣은 Failproof AI 링크 미리보기 표시 |
| `users:read`, `users:read.email` | Failproof AI 계정 매칭 및 이름 표시 |

## 연결 해제

**Settings → Integrations**으로 이동하여 **Disconnect**를 선택하거나, 앱의 **Home** 탭에서 **Disconnect**를 사용하거나, Slack에서 앱을 제거하세요.

이 중 어느 방법을 사용해도 워크스페이스 연결, 봇 토큰, 연결된 계정, 스레드 기록이 삭제됩니다. 과거 Slack 대화는 대시보드에서 계속 확인할 수 있습니다. 이후 조직은 즉시 다른 워크스페이스와 연결할 수 있습니다.

## 데이터 및 개인정보

질문과 답변은 스레드를 시작한 사람의 이름으로 조직 대시보드의 대화 기록에 저장됩니다. Slack 데이터는 AI 모델 학습에 사용되지 않습니다. 앱이 수신하는 데이터와 보관 기간에 대한 자세한 내용은 [개인정보 처리방침](https://befailproof.ai/privacy/)을 참조하세요.

## 문제 해결

| 표시 내용 | 해결 방법 |
| --- | --- |
| "This workspace isn't connected to a FailproofAI Cloud yet." | 워크스페이스 관리자가 앱의 **Home** 탭을 열고 Cloud를 선택 |
| "This link expired or was already used." | **Home** 탭에서 Cloud를 다시 선택하여 새 링크 발급 |
| "This org is already connected to a Slack workspace." | 먼저 설정에서 연결 해제 |
| "That Slack workspace is connected to another org." | 먼저 해당 조직에서 연결 해제 |
| "Link your account to use the assistant." | 버튼을 선택하고 Failproof AI에서 확인 |
| 그룹 다이렉트 메시지에서 앱이 응답하지 않음 | 그룹 권한 부여를 위해 Slack에서 앱을 다시 추가. 기존 연결은 유지됨 |
| "I won't post answers from your organization here" | 해당 워크스페이스의 조직 멤버 중 한 명이 앱을 멘션하고 계정을 연결 |

여전히 문제가 해결되지 않나요? [support@befailproof.ai](mailto:support@befailproof.ai)로 이메일을 보내주세요.
