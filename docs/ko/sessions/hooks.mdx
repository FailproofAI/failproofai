Hook은 에이전트가 Failproof AI에 결정을 요청하는 시점입니다. Hook 활동 기록에는 이벤트, 정책, 결과, 평가 시간이 포함됩니다.

## Hook 활동 조회

<Tabs>
  <Tab title="대시보드">
    **Observe → Hooks**로 이동하세요. 환경, 이벤트, 에이전트, 세션별로 필터링할 수 있습니다.

    ![Hook 이름과 트리거 이벤트별로 지연 시간이 그룹화된 Hooks 페이지.](/images/dashboard/hooks.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp guardrails summary --since 24h
    fp --json events --full --event-type hook_completed --session-id <session-id> --all --limit 500
    fp list hooks
    ```
  </Tab>
</Tabs>

기본적으로 모든 `deny` 및 `instruct` 결정은 전체 내용으로 전송됩니다. 반복되는 allow는 노이즈를 줄이기 위해 그룹화됩니다. `~/.failproofai/config.json`의 `collector.hooks_verbosity`를 `all`, `decisions`, `off` 중 하나로 설정할 수 있습니다.

<Warning>
  Hook 활동은 평가가 실행되었음을 증명하지만, 해당 이벤트를 harness가 차단할 수 있었음을 의미하지는 않습니다. [enforcement capability](/ko/reference/harnesses#enforcement-capability)를 참조하세요. 목록에 없는 harness-이벤트 쌍은 검증되지 않은 상태입니다.
</Warning>
