실시간 이벤트는 에이전트가 실행되는 동안 모델 호출, 도구, 오류, 사람의 입력, 훅, 정책 결정 등의 활동을 표시합니다.

## 활동 모니터링

**Observe → Live events**로 이동하거나 다음 명령어를 실행하세요:

```bash
fp events --since 1h
fp events --event-type tool_use,tool_result --since 1h
fp --json events --full --session-id <session-id> --all --limit 2000
```

페이로드 내용이 필요할 때는 `--full`을 사용하세요. 경량 피드는 더 빠르며 대부분의 필터링 용도에 충분합니다.

주요 이벤트 유형은 다음과 같습니다:

- `session_start` 및 `session_end`
- `model_request` 및 `model_response`
- `tool_use` 및 `tool_result`
- `hook_triggered` 및 `hook_completed`
- `error`
- `human_wait` 및 `human_input`
- `agent_pause` 및 `agent_resume`

## 이벤트가 나타나지 않을 때

```bash
failproofai flush --wait
failproofai config --status
failproofai backfill --since 30d --dry-run
```

기본 환경은 `local`입니다. `production`에 대한 필터는 환경 레이블을 변경하기 전까지 아무것도 반환하지 않습니다.

지원되는 하네스 외부의 에이전트의 경우 [Python SDK](/ko/reference/custom-agents)를 사용하세요.
