icon: "ruler"
---

메트릭은 단위가 있는 값을 위한 것이고, 평가(Evaluations)는 점수 및 판단을 위한 것입니다.

<Tabs>
  <Tab title="대시보드">
    1. **Observe → Metrics**로 이동합니다.
    2. **add series**를 선택하고 에이전트, 환경, 메트릭, 통계, 곡선을 선택합니다.
    3. 에이전트나 환경을 비교하기 위해 시리즈를 추가합니다. 단위가 다른 경우 별도의 축이 생성됩니다.
    4. 특정 지점을 선택하면 관련 평가 및 세션을 확인할 수 있고, **share**를 선택하면 현재 뷰를 복사할 수 있습니다.

    ![두 개의 출력 단위당 비용 시리즈를 시간 컨트롤, 집계 선택기, 곡선, 공유 액션과 함께 비교하는 메트릭 페이지.](/images/dashboard/metrics-series.png)
  </Tab>
  <Tab title="CLI">
    아직 규모 메트릭 전용 명령어는 없습니다. 사용 가능한 키를 확인하거나 세션 및 평가를 조회하려면 다음을 사용하세요:

    ```bash
    fp list score_filters
    fp --json evals --since 24h
    fp --json sessions --since 24h
    ```

    커스텀 메트릭 집계에는 `fp query`를 사용하세요.
  </Tab>
</Tabs>
