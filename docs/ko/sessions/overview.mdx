세션은 에이전트가 예상치 못한 동작을 보일 때 가장 좋은 출발점입니다. 하나의 실행에 속하는 모델 요청, 응답, 도구 호출, 사람의 상호작용, 오류, 평가, 정책 결정을 모두 통합하여 보여줍니다.

에이전트 실행의 목표부터 모델 호출, 도구 사용, 최종 응답까지 하나의 흐름으로 추적하세요.

## 세션 찾기

<Tabs>
  <Tab title="대시보드">
    1. 클라우드 사이드바에서 **Observe → Sessions**으로 이동합니다.
    2. 시간 범위를 설정한 후 환경, 상태, 에이전트, 또는 세션 ID로 필터링합니다.
    3. 품질, 비용, 토큰, 레이턴시 기준으로 조회할 때는 점수나 메트릭 범위를 추가합니다.
    4. 행을 선택하면 해당 트레이스가 열립니다. 세션 ID 옆의 복사 버튼을 사용해 공유하세요.

    ![환경, 에이전트, 상태, 평가 점수 필터와 함께 실행당 한 행씩 표시되는 세션 목록.](/images/dashboard/sessions-list.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp sessions --env production --since 24h
    fp sessions --status error,timeout --agent-id checkout-agent
    fp --json sessions --session-id <session-id>
    ```

    `--agents`를 추가하면 멀티 에이전트 실행을 펼쳐볼 수 있고, `--all`은 페이지네이션, `--fields`는 출력 컬럼을 선택합니다.
  </Tab>
</Tabs>

## 할 수 있는 작업

- 에이전트, 환경, 시간, 모델, 이벤트 유형, 오류 상태로 실행을 찾습니다.
- 특정 결과를 만들어낸 정확한 실행 순서를 추적합니다.
- 성공한 실행과 실패한 실행을 비교합니다.
- 감사 결과나 알림 인시던트에 사용된 근거를 확인합니다.
- 오프라인 기록이 필요할 때 세션을 내보냅니다.

## 체계적인 조사 순서

1. 세션 목표와 환경을 확인합니다.
2. 최종 실패만이 아니라 첫 번째 오류 또는 예상치 못한 결정을 찾습니다.
3. 그 직전의 모델 컨텍스트와 도구 입력을 검사합니다.
4. 재시도, 레이턴시, 사람의 개입을 확인합니다.
5. 평가 점수와 정책 결정을 검토합니다.
