---

정책 결정은 적용된 내용을 설명합니다. 이를 통해 롤아웃을 검증하고, 차단 비율을 측정하며, 보호되지 않은 활동을 파악할 수 있습니다.

<Tabs>
  <Tab title="대시보드">
    1. **Observe → policy**로 이동하여 시간 범위를 선택하고, 필요에 따라 특정 머신을 선택합니다.
    2. 평가된 액션, 차단, 차단 비율, Cloud 결정, 보호되지 않은 액션, 일시 중지 중의 활동을 검토합니다.
    3. 정책 매핑 테이블을 필터링하고 배포된 할당을 검사합니다.
    4. 차트의 특정 지점을 선택하면 해당 결정 및 세션을 확인할 수 있습니다.

    ![정책 페이지에 결정 총계, 머신 필터, 시간에 따른 적용 활동, 정책 매핑 테이블이 표시됩니다.](/images/dashboard/policy-observe.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp events --event-type hook_completed --env production --since 24h
    fp events --search "deny" --since 24h
    failproofai config --status
    ```

    머신의 로컬 적용 상태는 `failproofai`를 사용하고, Cloud 이벤트 조사는 `fp`를 사용합니다.
  </Tab>
</Tabs>
