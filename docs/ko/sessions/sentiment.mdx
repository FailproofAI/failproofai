Jev는 사용자가 에이전트에게 보낸 각 메시지에 대해 네 가지 감정 — **분노**, **불만**, **만족**, **혼란** — 과 에이전트 성능에 관한 세 가지 신호를 0에서 100 사이의 점수로 측정합니다:

- **수정 요청**: 사용자가 에이전트의 답변이 틀렸다고 지적하는 경우.
- **해결됨**: 사용자가 에이전트가 문제를 해결했다고 확인하는 경우.
- **의심**: 사용자가 에이전트의 답변이 사실인지, 또는 실제로 작업을 수행했는지 의문을 제기하는 경우.

감정 분석을 활용해 사용자가 인내심을 잃어가는 대화, 반복적으로 수정 요청을 받는 에이전트, 그리고 긍정적인 반응을 얻은 답변을 찾아보세요. 이 기능은 Jev에 내장된 점수 측정 방식으로, 별도로 평가를 작성할 필요가 없습니다. 직접 고정 답변 질문에 대한 평가를 만들고 싶다면 [Jev 평가 만들기](/ko/evaluations/jev)를 참고하세요.

<Note>
  감정 분석은 관리자가 조직 단위로 활성화하기 전까지 비활성화 상태입니다. Jev는 메시지당 하나의 점수 측정 요청을 수행하며, 해당 메시지와 그 직전의 에이전트 답변을 함께 수신합니다. 점수 측정에는 조직의 모델 예산이 사용됩니다.
</Note>

## 활성화 방법

1. **관리 → 설정**으로 이동합니다.
2. **사람의 입력 감정** 항목에서 스위치를 **켜기**로 전환하고 저장합니다.

먼저 지난 하루의 메시지부터 점수가 매겨집니다. 이후 새 메시지는 도착 후 1~2분 이내에 점수가 측정됩니다.

## 검토할 대화 찾기

**관찰 → 감정 분석**을 여세요. 시간, 환경, 에이전트, 세션 ID로 필터링할 수 있습니다. 헤더에는 메시지 및 세션 수, **플래그 처리된** 메시지 수, 그리고 주요 신호가 표시됩니다. 분노, 불만, 수정 요청, 혼란, 또는 의심 점수가 100점 만점 중 35점에 도달하면 해당 메시지에 플래그가 표시됩니다.

![메시지 및 세션 수, 플래그 처리된 메시지, 시간에 따른 Jev 점수를 보여주는 감정 분석 대시보드.](/images/dashboard/sentiment-overview.png)

**시간별 점수** 차트를 사용해 신호를 비교하세요. 표시할 점수를 선택한 뒤 특정 시점을 클릭하면 해당 시간대의 메시지를 확인할 수 있습니다. **에이전트별** 테이블에서는 특정 신호가 집중된 위치를 파악할 수 있습니다. **메시지** 목록에서는 가장 강한 부정적 점수 순으로 정렬하거나 단일 점수를 선택할 수 있습니다. 세션에서 메시지를 열어 주변 대화 내용을 읽고 무엇이 문제였는지 판단해 보세요.

## 점수가 측정되는 메시지

사람이 직접 작성한 메시지만 해당됩니다:

- SDK를 통해 사람의 입력으로 기록된 커스텀 에이전트 메시지.
- 세션 트랜스크립트가 전송될 때(기본값) Claude Code, Codex, OpenCode, pi, Hermes, OpenClaw에 직접 입력된 프롬프트. 예약된 작업, 주입된 지시사항, 서브 에이전트 핸드오프, 그 외 에이전트 런타임이 직접 작성한 텍스트는 점수 측정 대상이 아닙니다. `claude -p`, `codex exec`, `hermes -z`와 같은 비대화형 실행도 마찬가지입니다: 이러한 프롬프트는 사람이 아닌 스크립트가 작성한 것입니다.

점수 측정은 사람이 직접 쓴 말을 기준으로 판단합니다. "고쳐"와 같이 짧고 단도직입적인 지시는 분노로 집계되지 않으며, 질문을 하는 것 자체는 혼란으로 집계되지 않습니다. 새로운 요청은 수정 요청으로 보지 않으며, 단순한 감사 인사만으로는 해결됨으로 집계되지 않습니다.
