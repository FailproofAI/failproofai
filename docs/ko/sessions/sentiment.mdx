Jev는 사용자가 에이전트에게 보내는 각 메시지에 대해 네 가지 감정을 0~100점으로 채점합니다 — **분노(angry)**, **불만(frustrated)**, **만족(happy)**, **혼란(confused)** — 그리고 에이전트 성능을 나타내는 세 가지 신호도 함께 측정합니다:

- **수정 요청(Correcting)**: 사용자가 에이전트의 답변이 틀렸다고 지적하는 경우.
- **해결됨(Resolved)**: 사용자가 에이전트가 문제를 해결했다고 확인하는 경우.
- **의심(Doubtful)**: 사용자가 에이전트의 답변이 사실인지, 또는 작업을 실제로 완료했는지 의문을 제기하는 경우.

감정 분석을 활용하면 사용자가 인내심을 잃어가는 대화, 반복적으로 수정 요청이 발생하는 에이전트, 그리고 반응이 좋은 답변을 찾아낼 수 있습니다. 이는 Jev에 내장된 채점 기능으로, 별도로 평가를 작성할 필요가 없습니다. 직접 고정 답변 질문에 대한 평가를 만들고 싶다면 [Jev eval 생성하기](/ko/evaluations/jev)를 참고하세요.

<Note>
  감정 분석은 관리자가 조직 단위로 활성화하기 전까지 꺼져 있습니다. Jev는 메시지당 하나의 채점 요청을 보내며, 해당 메시지와 그 직전 에이전트 답변을 함께 받습니다. 채점은 조직의 모델 예산을 사용합니다.
</Note>

## 활성화 방법

1. **Administration → Settings**로 이동합니다.
2. **Human input sentiment** 항목에서 스위치를 **켜고** 저장합니다.

지난 하루 동안의 메시지가 먼저 채점됩니다. 이후 새 메시지는 도착 후 1~2분 내에 채점됩니다.

## 검토할 대화 찾기

**Observe → Sentiment**를 엽니다. 시간, 환경, 에이전트, 또는 세션 ID로 필터링할 수 있습니다. 헤더에는 메시지 및 세션 수, **플래그된** 메시지 수, 그리고 가장 두드러진 신호가 표시됩니다. 분노, 불만, 수정 요청, 혼란, 또는 의심 점수가 100점 중 35점에 도달하면 해당 메시지가 플래그됩니다.

![메시지 및 세션 수, 플래그된 메시지, 시간별 Jev 점수를 보여주는 감정 분석 대시보드.](/images/dashboard/sentiment-overview.png)

**Score over time** 차트를 활용해 신호를 비교하세요. 표시할 점수를 선택한 후 특정 시점을 클릭하면 해당 시간대의 메시지를 볼 수 있습니다. **By agent** 테이블은 신호가 집중된 에이전트를 보여줍니다. **Messages** 목록에서는 가장 강한 부정 점수 순으로 정렬하거나 특정 점수 하나를 선택할 수 있습니다. 메시지를 세션에서 열어 주변 대화를 읽고 무엇이 실패했는지 판단해 보세요.

![가장 강한 부정 점수 순으로 정렬된 감정 분석 메시지 목록과 각 소스 세션 링크.](/images/dashboard/sentiment-messages.png)

## 채점 대상 메시지

사람이 직접 작성한 메시지만 채점됩니다:

- SDK를 통해 사용자 입력으로 기록된 커스텀 에이전트 메시지.
- 세션 트랜스크립트가 전송될 때(기본값) Claude Code, Codex, OpenCode, pi, Hermes, OpenClaw에 직접 입력된 프롬프트. 예약된 작업, 주입된 지침, 서브 에이전트 핸드오프, 그 외 에이전트 런타임이 직접 작성하는 텍스트는 채점되지 않습니다. `claude -p`, `codex exec`, `hermes -z`와 같은 비대화형 실행도 채점 대상이 아닙니다 — 이러한 프롬프트는 사람이 아닌 스크립트가 작성한 것이기 때문입니다.

채점은 사용자 자신의 표현을 기준으로 판단합니다. "고쳐줘"와 같이 짧고 단도직입적인 지시는 분노로 간주하지 않으며, 질문을 하는 것 자체는 혼란으로 보지 않습니다. 새로운 요청은 수정 요청으로 보지 않으며, 단순한 감사 인사는 해결됨으로 간주하지 않습니다.
