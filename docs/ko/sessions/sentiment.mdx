Jev는 사용자가 에이전트에게 보내는 각 메시지에 대해 네 가지 감정을 0~100점으로 채점합니다 — **분노(angry)**, **불만(frustrated)**, **행복(happy)**, **혼란(confused)** — 그리고 에이전트 성능과 관련된 세 가지 신호도 분석합니다:

- **Correcting**: 사용자가 에이전트의 답변이 잘못되었다고 지적하는 경우.
- **Resolved**: 사용자가 에이전트가 문제를 해결했다고 확인하는 경우.
- **Doubtful**: 사용자가 에이전트의 답변이 사실인지, 또는 실제로 작업을 수행했는지 의심하는 경우.

감정 분석을 활용하면 사용자가 인내심을 잃어가는 대화, 반복적으로 수정을 요청받는 에이전트, 그리고 잘 전달되는 응답을 찾을 수 있습니다. 이 기능은 Jev에 내장된 채점 방식으로, 별도로 평가(evaluation)를 작성할 필요가 없습니다. 고정 답변 질문에 대한 평가를 직접 만들려면 [Jev eval 생성하기](/ko/evaluations/jev)를 참고하세요.

<Note>
  감정 분석은 관리자가 조직 단위로 활성화하기 전까지는 비활성 상태입니다. Jev는 메시지당 한 번의 채점 요청을 수행하며, 해당 메시지와 그 이전의 에이전트 응답을 함께 받아서 처리합니다. 채점에는 조직의 모델 예산이 사용됩니다.
</Note>

## 활성화 방법

1. **Administration → Settings**으로 이동합니다.
2. **Human input sentiment** 항목에서 스위치를 **켜고** 저장합니다.

가장 먼저 최근 하루치 메시지가 채점됩니다. 이후 새로운 메시지는 도착 후 1~2분 내에 채점됩니다.

## 검토할 대화 찾기

**Observe → Sentiment**를 엽니다. 시간, 환경, 에이전트 또는 세션 ID로 필터링할 수 있습니다. 헤더에는 메시지 및 세션 수, **플래그 처리된** 메시지 수, 그리고 가장 두드러진 신호가 표시됩니다. 분노, 불만, 수정, 혼란, 의심 점수 중 하나라도 100점 만점에 35점 이상에 도달하면 해당 메시지에 플래그가 표시됩니다.

![메시지 및 세션 수, 플래그 처리된 메시지, 시간에 따른 Jev 점수를 보여주는 감정 분석 대시보드.](/images/dashboard/sentiment-overview.png)

**Score over time** 차트를 사용하여 신호를 비교하세요. 표시할 점수를 선택한 다음, 특정 시간 구간을 클릭하면 해당 시간대의 메시지를 확인할 수 있습니다. **By agent** 테이블은 특정 신호가 집중된 에이전트를 보여줍니다. **Messages**에서는 가장 강한 부정 점수 순으로 정렬하거나 단일 점수 기준으로 필터링할 수 있습니다. 메시지를 클릭하면 해당 세션에서 전후 맥락을 읽고, 어떤 문제가 발생했는지 판단할 수 있습니다.

![가장 강한 부정 점수 순으로 정렬된 감정 분석 메시지 목록과 각 소스 세션 링크.](/images/dashboard/sentiment-messages.png)

## 채점 대상 메시지

사람이 직접 작성한 메시지만 채점됩니다:

- SDK를 통해 커스텀 에이전트가 사람의 입력으로 기록한 메시지.
- 세션 트랜스크립트가 전송될 때(기본값) Claude Code, Codex, OpenCode, pi, Hermes, OpenClaw에 직접 입력된 프롬프트. 예약된 작업, 주입된 지시문, 서브 에이전트 핸드오프 및 에이전트 런타임이 자체적으로 작성한 텍스트는 채점 대상이 아닙니다. `claude -p`, `codex exec`, `hermes -z`와 같은 비대화형 실행도 마찬가지입니다 — 이러한 프롬프트는 사람이 아닌 스크립트가 작성한 것입니다.

채점은 사람 본인의 표현을 기준으로 판단합니다. "고쳐줘"처럼 짧고 단호한 지시는 분노로 집계되지 않으며, 질문을 하는 것은 혼란으로 집계되지 않습니다. 새로운 요청은 수정(correction)으로 보지 않으며, 단순한 감사 표현만으로는 해결(resolved)로 집계되지 않습니다.
