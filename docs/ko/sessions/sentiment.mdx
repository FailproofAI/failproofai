Jev는 사용자가 에이전트에게 보내는 각 메시지를 네 가지 감정 — **분노**, **불만**, **행복**, **혼란** — 과 에이전트의 수행 상태를 나타내는 세 가지 신호에 대해 0에서 100점으로 채점합니다:

- **Correcting**: 사용자가 에이전트의 답변에 오류가 있다고 지적합니다.
- **Resolved**: 사용자가 에이전트가 문제를 해결했음을 확인합니다.
- **Doubtful**: 사용자가 에이전트의 답변이 사실인지, 또는 실제로 작업을 수행했는지 의심합니다.

감정 분석을 활용하면 사용자가 인내심을 잃어가는 대화, 반복적으로 교정이 필요한 에이전트, 그리고 반응이 좋은 답변을 찾을 수 있습니다. 이 기능은 Jev에 내장된 채점 방식으로, 별도로 평가를 작성할 필요가 없습니다. 직접 정의한 고정 답변 질문에 대한 평가가 필요하다면 [Jev eval 만들기](/ko/evaluations/jev)를 참고하세요.

<Note>
  감정 분석은 관리자가 조직 단위로 활성화하기 전까지는 비활성 상태입니다. Jev는 메시지 하나당 채점 요청을 한 번 보내며, 해당 메시지와 그 앞에 있는 에이전트 답변을 함께 수신합니다. 채점에는 조직의 모델 예산이 사용됩니다.
</Note>

## 활성화 방법

1. **Administration → Settings**로 이동합니다.
2. **Human input sentiment** 항목에서 **on**으로 전환하고 저장합니다.

가장 최근 하루치 메시지가 먼저 채점됩니다. 이후 새로 들어오는 메시지는 도착 후 1~2분 내에 채점됩니다.

## 검토할 대화 찾기

**Observe → Sentiment**를 엽니다. 시간, 환경, 에이전트, 세션 ID로 필터링할 수 있습니다. 상단 헤더에는 메시지 및 세션 수, **플래그 처리된** 메시지 수, 그리고 가장 두드러진 신호가 표시됩니다. 분노, 불만, 교정, 혼란, 또는 의심 점수가 100점 중 35점에 도달하면 해당 메시지에 플래그가 붙습니다.

![시간 경과에 따른 메시지 및 세션 수, 플래그 처리된 메시지, Jev 점수를 보여주는 감정 분석 대시보드.](/images/dashboard/sentiment-overview.png)

**Score over time**을 사용해 신호를 비교합니다. 표시할 점수를 선택한 후 특정 지점을 클릭하면 해당 시간대의 메시지를 확인할 수 있습니다. **By agent** 표에서는 특정 신호가 집중된 에이전트를 파악할 수 있습니다. **Messages**에서는 가장 강한 부정 점수 순으로 정렬하거나 개별 점수를 선택할 수 있습니다. 메시지를 열어 해당 세션 내 주변 대화를 읽고, 무엇이 잘못됐는지 판단해 보세요.

![가장 강한 부정 점수 순으로 정렬된 감정 분석 메시지 목록과 각 원본 세션으로의 링크.](/images/dashboard/sentiment-messages.png)

## 채점 대상 메시지

사람이 직접 작성한 메시지만 채점됩니다:

- SDK를 통해 커스텀 에이전트가 휴먼 입력으로 기록한 메시지.
- Claude Code, Codex, OpenCode, pi, Hermes, OpenClaw에서 직접 입력한 프롬프트 (세션 트랜스크립트가 전송되는 경우, 기본값). 스케줄된 작업, 주입된 지시사항, 하위 에이전트 핸드오프, 그 외 에이전트 런타임 자체가 작성한 텍스트는 채점되지 않습니다. `claude -p`, `codex exec`, `hermes -z`와 같은 비대화형 실행도 마찬가지입니다. 이러한 프롬프트는 사람이 아닌 스크립트가 작성한 것이기 때문입니다.

채점은 사람 본인의 표현을 기준으로 판단합니다. "fix it"처럼 짧고 단도직입적인 지시는 분노로 간주되지 않으며, 질문을 하는 것 자체가 혼란으로 집계되지 않습니다. 새로운 요청은 교정으로 보지 않으며, 단순한 감사 인사만으로는 해결됨으로 집계되지 않습니다.
