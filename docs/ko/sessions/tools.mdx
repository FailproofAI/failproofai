도구 페이지에서는 에이전트가 호출하는 항목, 호출 실패 빈도, 그리고 영향을 받는 세션을 확인할 수 있습니다.

도구 이름은 각 에이전트 하네스에서 가져오므로 동일한 기능이 서로 다른 이름으로 표시될 수 있습니다. 예를 들어, 셸 호출은 `Bash`, `exec`, `Shell`, `terminal`, 또는 `run_command`로 나타날 수 있습니다. 필터를 구성하기 전에 `fp list tools`를 실행하여 확인하세요.

<Tabs>
  <Tab title="대시보드">
    **Observe → Tools**로 이동합니다. 환경, 도구, 에이전트, 또는 세션으로 필터링할 수 있습니다.

    ![지연 시간, 성공 및 실패 분석, 도구 호출 분포를 보여주는 도구 페이지.](/images/dashboard/tools.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list tools
    fp events --event-type tool_use,tool_result --since 24h
    fp errors --event-type tool_result --since 24h
    fp --json events --full --event-type tool_use,tool_result --session-id <session-id> --all --limit 2000
    ```

    호출별 지속 시간과 같은 페이로드 필드가 필요할 때는 `--full`을 사용하세요.
  </Tab>
</Tabs>

이 페이지를 사용하여 반복적인 실패를 찾거나, 정상 실행과 실패 실행을 비교하거나, 정책 대상 도구가 실제로 사용되고 있는지 확인할 수 있습니다.
