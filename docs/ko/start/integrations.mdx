## 세 줄이면 충분합니다, 어떤 프레임워크든

<CodeGroup>
```bash LangGraph
pip install 'failproofai-sdk[langgraph]'
```

```bash CrewAI
pip install 'failproofai-sdk[crewai]'
```

```bash LlamaIndex
pip install 'failproofai-sdk[llamaindex]'
```

```bash Pydantic AI
pip install 'failproofai-sdk[pydantic-ai]'
```

```bash Custom agents
pip install failproofai-sdk
```
</CodeGroup>

```python
import failproofai_sdk

failproofai_sdk.configure(environment="production")
failproofai_sdk.instrument()          # 임포트된 프레임워크를 자동으로 감지

with failproofai_sdk.session():
    ...                               # 기존 에이전트 호출 코드 그대로 사용
```

함수에 데코레이터를 추가할 필요도, 호출에 콜백을 전달할 필요도, 코드 전반에 id를 넘길 필요도 없습니다. 달라지는 것은 세션 안의 호출뿐입니다:

<Tabs>
  <Tab title="LangGraph">
    ```python
    graph.invoke({"messages": [HumanMessage("...")]})
    ```
  </Tab>
  <Tab title="CrewAI">
    ```python
    Crew(agents=[analyst, writer], tasks=[gather, summarise]).kickoff()
    ```
  </Tab>
  <Tab title="LlamaIndex">
    ```python
    await agent.run("...")        # `async with failproofai_sdk.session():` 아래에서 사용
    ```
  </Tab>
  <Tab title="Pydantic AI">
    ```python
    agent.run_sync("...")
    ```
  </Tab>
  <Tab title="Custom agents">
    ```python
    with failproofai_sdk.agent("planner"):
        with failproofai_sdk.tool_call("search", input={"q": q}) as t:
            t.output = search(q)
    ```
  </Tab>
</Tabs>

추가 설치는 **프레임워크**를 위한 것입니다. 모든 어댑터는 기본 휠에 포함되어 있으므로, 이미 프레임워크를 설치한 프로젝트는 추가 설치가 전혀 필요 없습니다.

## 데이터가 도착했는지 확인하기

계측된 세션을 한 번 실행한 뒤, **Observe → Sessions**를 열고 환경을 선택하세요. 실행 결과가 재구성된 트레이스로 표시됩니다.

아무것도 도착하지 않는다면, `failproofai config --status`로 머신이 연결되어 있는지 확인하세요. [캡처 설정](/ko/start/setup)을 참고하세요.

<Warning>
  스풀 디렉토리를 확인하여 전달 여부를 판단하지 마세요. Failproof 데몬은 각 배치를 수 밀리초 안에 수집하고 삭제하므로, 디렉토리를 읽으면 수집기와 경쟁 상태가 발생해 실제 방출된 이벤트보다 훨씬 적은 수만 보이게 됩니다.
</Warning>
