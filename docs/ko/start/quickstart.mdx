이 빠른 시작 가이드는 하나의 머신에서 세션을 보고하고, 감사를 실행하고, 정책을 배포하는 과정을 안내합니다. 스킬을 사용하거나 수동 단계를 따라 Failproof AI를 설정하세요. Node.js 20.9 이상이 필요합니다.

<Tabs>
  <Tab title="스킬 사용">
    <Steps>
      <Step title="Failproof AI 스킬 설치">
        ```bash
        npx skills add FailproofAI/skills
        ```
      </Step>
      <Step title="에이전트에게 전체 설정을 요청하세요">
        ```text
        Set up Failproof AI for this project, connect this machine, install the right hooks and policies, and verify that a session arrives.
        ```

        에이전트가 프로젝트를 검사하고, 관련 통합을 선택한 후 설정을 수행하고 검증합니다. 개별 스킬과 고급 설치 옵션은 [FailproofAI skills repository](https://github.com/FailproofAI/skills)를 참조하세요.
      </Step>
    </Steps>
  </Tab>
  <Tab title="수동 설정">
    ## 시작하기 전에

1. [Failproof AI 대시보드](https://app.befailproof.ai)를 열고 계정을 만들거나 업무용 이메일로 로그인합니다.
2. **Administration → Keys**로 이동하여 `events:add`와 `policies:pull` 권한이 있는 키를 생성합니다.
3. 일회용 시크릿을 복사하고 대상 머신에 저장합니다.

```bash
export FAILPROOFAI_KEY="<one-time-secret>"
```

    ## 설치

<Steps>
  <Step title="Failproof AI 설치 및 연결">
    ```bash
    npm install -g failproofai
    failproofai config --connect https://app.befailproof.ai --token "$FAILPROOFAI_KEY"
    ```

    세션 트랜스크립트는 기본적으로 전송됩니다. `--no-transcripts`를 추가하면 트랜스크립트 내용 없이 훅 활동과 정책 결정만 보고합니다.

    이 머신에 이미 에이전트 히스토리가 있는 경우, 최근 7일치를 미리 보고 가져온 뒤 전송이 완료될 때까지 기다립니다. 새 머신에서는 이 단계를 건너뛰세요.

    ```bash
    failproofai backfill --since 7d --dry-run
    failproofai backfill --since 7d
    failproofai flush --wait
    ```

    Failproof AI의 **Sessions**를 열고 가져온 세션을 선택합니다.
  </Step>
  <Step title="에이전트 훅 및 정책 설치">
    이 단계에서는 Failproof AI를 에이전트 CLI에 연결하고 기본 제공 정책을 설치합니다. 이를 통해 로컬 정책 결정을 확인하고, Failproof AI가 세션을 감사하고 에이전트에 맞는 정책을 작성하기 전에 적용(enforcement)을 미리 시험해볼 수 있습니다.

    설치 프로그램이 에이전트 CLI를 자동으로 감지하도록 하거나, 직접 명시할 수 있습니다.

    ```bash
    failproofai policies --install --cli claude --scope user
    ```
  </Step>
  <Step title="동작 감사">
    [첫 번째 오류 검사 실행](/ko/start/first-audit)을 따라 진행합니다. "에이전트가 접근 방식을 변경하지 않고 실패한 툴을 재시도한 세션 찾기"와 같이 구체적인 목표를 사용하세요.
  </Step>
  <Step title="오류 방지">
    [정책으로 첫 번째 오류 방지](/ko/start/first-policy)를 따라 진행합니다. 관찰 모드로 시작하여 매칭 항목을 검사한 후, 검토된 버전을 적용합니다.
  </Step>
</Steps>

<Check>
  `failproofai config --status`를 실행하세요. 정상적으로 설정된 경우 클라우드 연결 상태, 데몬 상태, 그리고 적용(enforcement)이 일시 중지되었는지 여부를 보고합니다.
</Check>
