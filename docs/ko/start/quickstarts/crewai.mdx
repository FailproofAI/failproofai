첫 번째 CrewAI 트레이스를 확인하기까지 세 단계입니다. 각 이벤트의 데이터, 흐름, 문제 해결 방법은 [전체 가이드](/ko/start/integrations/crewai)를 참고하세요.

## 설치

```bash
pip install 'failproofai-sdk[crewai]'
```

## 계측

```python
import failproofai_sdk

failproofai_sdk.configure(environment="production")
failproofai_sdk.instrument()

with failproofai_sdk.session():
    Crew(agents=[analyst, writer], tasks=[gather, summarise]).kickoff()
```

크루, 에이전트, 태스크, 툴은 아무것도 변경할 필요가 없습니다. `instrument()`는 CrewAI의 모듈 레벨 이벤트 버스를 구독합니다.

## 도착 여부 확인

한 번 실행한 후 **Observe → Sessions**를 열고 환경을 선택하세요. 실행 결과가 재구성된 트레이스로 표시됩니다.

아무것도 표시되지 않는다면 `failproofai config --status`로 머신이 연결되어 있는지 확인하세요.
