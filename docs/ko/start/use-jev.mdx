Jev는 에이전트 실행의 두 시점에서 도움을 줍니다. 완료된 세션을 알려진 답변과 비교해 점수를 매기거나, 에이전트에게 요청한 작업의 맥락에서 도구 호출을 검토할 수 있습니다.

<Tabs>
  <Tab title="Jev 평가">
    완료된 세션을 "고객이 환불을 요청했나요? 예 또는 아니오로 답하세요."와 같이 몇 가지 알려진 답변이 있는 질문과 비교해 점수를 매길 수 있을 때 Jev 평가를 사용하세요. 여러 세션에서 패턴을 찾는 데 도움이 됩니다.

    ## 평가 만들기

    Cloud 대시보드에서 **분석 → 검사 → 새 검사** (또는 **새 평가**)를 엽니다. 고정된 답변이 있는 질문 하나를 설명하고, 초안으로 작성된 규칙을 검토한 뒤 **검사 방법**이 **decision model**, 즉 Jev로 설정되어 있는지 확인하세요. 실제 세션에서 [테스트](/ko/evaluations/test)한 후 활성화합니다.

    ![질문을 설명하고 초안을 검토하여 배포하는 공통 평가 작성 양식입니다. 이 스크린샷은 코드 초안을 보여주지만, Jev에는 고정 답변 질문을 사용하세요.](/images/dashboard/eval-authoring-draft.png)

    ## 점수 확인하기

    새 세션이 완료된 후 **분석 → 검사 → 평가**를 열고 해당 평가를 선택하거나, Cloud CLI를 사용하세요.

    ```bash
    fp evals --since 7d
    fp evals --aggregate --since 7d
    ```

    CLI는 점수를 읽어오며, Jev 평가 생성은 현재 대시보드에서만 가능합니다. 질문 유형과 예시는 [Jev 평가](/ko/evaluations/jev)를 참고하세요.
  </Tab>
  <Tab title="Jev 정책">
    문자열 매칭 정책이 도구 호출의 안전 여부를 판단하기 위해 요청의 맥락이 필요할 때 Jev 정책 검토를 사용하세요. **관찰** 모드로 시작하면 설치된 정책이 각 호출을 계속 처리하는 동안 Jev의 답변을 확인할 수 있습니다.

    Jev의 검사 항목은 팩에서 가져오며, Failproof AI는 기본 팩을 제공하지 않습니다. 설치 전까지는 Jev가 설정되어 있더라도 아무것도 확인하지 않습니다.

    ```bash
    failproofai policies add FailproofAI/jev-policies
    ```

    ## Cloud Jev 설정하기

    Cloud 대시보드에서 **설정 → API 키**를 열고 **새 키** 아래에서 **failproofai를 실행하는 머신**을 선택합니다. [빠른 시작](/ko/start/quickstart)에 나온 대로 `failproofai config`와 함께 사용하세요. 기존 Jev 설정이 없는 머신에서는 Cloud Jev가 관찰 모드로 활성화됩니다. 다음 명령어로 연결 상태를 확인하세요.

    ```bash
    failproofai jev status
    failproofai jev test
    ```

    ## 자체 엔드포인트 사용하기

    로컬 대시보드에서 **설정 → Jev**를 엽니다. 프로바이더를 선택하고 토큰을 붙여넣은 뒤 **관찰**을 선택하고 Jev를 켭니다.

    ![프로바이더, 토큰 입력란, 관찰 모드가 선택된 로컬 Jev 설정 패널입니다.](/images/dashboard/jev-settings.png)

    또는 터미널에서 엔드포인트를 설정하고 테스트할 수 있습니다.

    ```bash
    failproofai jev --url https://api.typesafe.ai/v1 --mode observe --key-stdin < ~/typesafe.key
    failproofai jev test
    ```

    훅이 연결된 에이전트에게 `README.md`에 대해 파일 읽기 도구를 사용하도록 요청하세요. 해당 도구 호출이 세션에 나타나는지 확인한 후, 로컬 대시보드의 **정책 → 활동**에서 검토하세요. 관찰 결과가 올바르게 보이면 [Jev 정책](/ko/policies/jev)에서 적용 시점을 확인할 수 있습니다. 프로바이더 세부 정보와 설정에 대해서는 [통합 레퍼런스](/ko/reference/jev)를 참고하세요.
  </Tab>
</Tabs>
