title: "Administração"
description: "Gerencie acesso, uso, organizações e segurança sem misturá-los ao fluxo de trabalho de confiabilidade."
icon: "settings-2"
---

Administração contém os controles necessários para operar o Failproof AI em uma equipe. A maioria dos usuários pode permanecer em Sessões, Auditorias e Políticas; os administradores utilizam esta seção para gerenciar acesso e limites operacionais.

<Tabs>
  <Tab title="Dashboard">
    Use a seção **Admin** da barra lateral do Cloud para acessar o **editor de políticas**, **aplicação**, **uso**, **chaves**, **usuários** e **configurações**. Um item bloqueado indica que sua conta não possui a permissão de leitura necessária.

    ![A seção Admin da barra lateral do Cloud com editor de políticas, aplicação, uso, chaves, usuários e configurações.](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    Coloque as opções globais antes do comando, por exemplo `fp --org reliability-team --json usage`.
  </Tab>
</Tabs>
