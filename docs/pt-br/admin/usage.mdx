Uso mostra o que a organização atual mediu durante sua janela atual de 30 dias. A janela é fixa e ancorada por organização, e o uso é somente leitura: não aplica nem exibe limites, cotas ou limiares de plano. Ambas as superfícies deixam isso claro — o painel da CLI exibe "uso somente leitura, sem limites aplicados".

## Revisar uso

<Tabs>
  <Tab title="Dashboard">
    1. Acesse **admin → usage**.
    2. Confirme a organização e a janela de medição — o cabeçalho mostra o início e o fim da janela, o dia dentro dela e quanto já decorreu.
    3. Leia o bloco principal: eventos ingeridos, sessões, agentes e ambientes.
    4. Leia os dois pipelines: avaliações (com pontuações e métricas) e auditorias (com problemas e alertas), cada um mostrando execuções concluídas em relação às iniciadas.
    5. Leia os blocos de workspace e acesso: consultas salvas, dashboards, alertas, problemas únicos, membros e chaves de API.

    Os valores são armazenados em cache, não são em tempo real. Use o controle de atualização no canto superior direito após uma alteração que você espera visualizar.

    ![A página de uso exibindo a janela de medição, eventos capturados, os pipelines de avaliação e auditoria, recursos do workspace, membros e chaves de API.](/images/dashboard/usage-overview.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp usage
    fp --json usage
    fp --org reliability-team --json usage
    ```

    `fp usage` requer `usage:read` e é executado sob uma chave de API, o que o torna o comando ideal para um cron de relatórios.

    Com `--json`, retorna a resposta do dashboard sem alterações: `org_id`, `billing_anchor`, `window`, `usage`, `calculated_at` e `stale_after`. `calculated_at` e `stale_after` são como você identifica a idade de um valor.

    `fp usage` não aceita flags próprias — apenas as globais `--json` e `--org`. Ele reporta apenas a janela atual e nada anterior, portanto mantenha seu próprio histórico executando o comando em um agendamento e armazenando o payload `--json`, em vez de esperar consultar uma janela anterior mais tarde.

    ```bash
    fp --json usage | jq '.usage.events_ingested'
    ```
  </Tab>
</Tabs>

### Chaves de métricas

Tudo que está sob `usage` no payload JSON, para que um script possa referenciar um campo pelo nome em vez de analisar um painel.

| Grupo | Chaves |
| --- | --- |
| Telemetria | `events_ingested`, `sessions`, `agents`, `environments` |
| Avaliações | `evaluation_runs`, `evaluation_finishes`, `evaluations`, `metrics` |
| Auditorias | `audit_runs`, `audit_finishes`, `issues_created`, `alerts_created` |
| Workspace | `queries_created`, `dashboards_created` |
| Acesso | `users_active`, `users_created`, `keys_active`, `keys_created` |

Cada pipeline reporta contagens de início e conclusão separadamente, portanto uma diferença entre `audit_runs` e `audit_finishes` indica trabalho que foi iniciado e não foi concluído — vale verificar antes de tirar conclusões a partir das contagens de problemas abaixo.

## Investigar uma mudança

O volume de ingestão é definido por máquina, não de forma centralizada. Comece pela organização e pela janela, depois verifique o que mudou nas máquinas que estão reportando para ela.

| Causa | Onde verificar | O que alterar |
| --- | --- | --- |
| Uma máquina está enviando transcrições de sessão | `collector.sessions` no arquivo `~/.failproofai/config.json` dessa máquina | Defina como `false` para enviar apenas decisões |
| A atividade de hook está sendo enviada na íntegra | `collector.hooks_verbosity` no mesmo arquivo | `decisions` agrega permissões por minuto; `off` interrompe completamente os eventos de hook |
| Um novo local de captura foi adicionado | `failproofai harness list` | Remova com `failproofai harness remove-path <harness> <path or label>` |
| O histórico foi reenviado | As execuções de `failproofai backfill` da máquina | Reenvios são deduplicados por hash de conteúdo e colapsados em linhas já existentes, portanto não geram dupla contagem |
| Uma nova integração começou a reportar | As contagens de `agents` e `environments`, e a lista de sessões | Configure os ajustes do coletor da nova máquina antes de implantá-la |

O uso não compara nada com um plano. Faça isso fora do produto.
