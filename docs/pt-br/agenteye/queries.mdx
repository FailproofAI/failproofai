Faça qualquer pergunta sobre os dados do seu agente e obtenha uma resposta em segundos. O Failproof AI Observability oferece uma biblioteca de queries salvas e prontas para executar sobre seus eventos e avaliações, para que você comece com um exemplo funcional em vez de um editor SQL em branco.

![A biblioteca de queries salvas: uma grade de queries reutilizáveis, incluindo presets integrados e personalizados](/agenteye/images/queries.png)

*Sua biblioteca de queries salvas em `/<org-slug>/queries`: presets integrados lado a lado com as queries que sua equipe salvou.*

## Comece com um preset, não com uma página em branco

Você não precisa memorizar nomes de tabelas nem escrever SQL do zero. A biblioteca abre com presets integrados para as perguntas mais comuns das equipes, exibidos ao lado das queries que sua própria equipe salvou e nomeou. Escolha uma que se aproxime do que você precisa e você já estará na maior parte do caminho até a resposta.

Cada query salva tem escopo de organização e é compartilhada, então as queries úteis que seus colegas criam também ficam disponíveis para você. Dê um nome e uma descrição a uma query uma única vez, e qualquer pessoa na sua organização poderá encontrá-la, executá-la ou fixar seus resultados em um dashboard posteriormente.

Acesse em `/<org-slug>/queries`.

## Ajuste e execute no compositor SQL

Abra qualquer query e ela será carregada no compositor SQL, onde você pode ajustá-la e ver a resposta imediatamente: sem exportação, sem idas e vindas, sem depender de outra pessoa.

![O compositor de queries SQL executando uma query salva, com uma barra lateral de esquema e uma grade de resultados ao vivo](/agenteye/images/query-lab.png)

*O compositor SQL: sua query à esquerda, uma barra lateral de esquema para que você nunca precise adivinhar um nome de coluna, e uma grade de resultados ao vivo abaixo.*

- **Uma barra lateral de esquema** exibe as tabelas de analytics e suas colunas, para que você possa formatar uma query sem precisar procurar nomes de campos.
- **Uma grade de resultados ao vivo** retorna as linhas no momento em que você executa, permitindo iterar em segundos em vez de ficar tentando e errando.
- **Somente leitura por design.** As queries são executadas no seu armazenamento de eventos e validadas no servidor: apenas instruções `SELECT` e `WITH` são permitidas, com timeout de instrução e limite de linhas. Uma query exploratória nunca pode modificar seus dados, e uma query que sair de controle é interrompida automaticamente.

Satisfeito com o resultado? Salve-o de volta na biblioteca para que toda a equipe herde, ou fixe sua saída em um dashboard como um bloco de linha, barra, área ou pizza.

## Execute pelo terminal ou deixe o assistente escrevê-las

As mesmas queries salvas acompanham você onde quer que você trabalhe:

- **Pelo terminal.** O CLI `agenteye` lista, executa e salva as mesmas queries, para que você possa inserir um resultado em um script, integrá-lo ao CI ou passá-lo para um agente de código.

```bash
agenteye query list                 # as mesmas queries salvas, pelo seu terminal
agenteye query run errs --arg prod  # execute uma e imprima as linhas (adicione --json para redirecioná-la)
```

  Veja [CLI e agentes](/pt-br/agenteye/cli-and-agents) para o conjunto completo de comandos.

- **Pelo assistente de IA.** Não tem certeza de como formular o SQL? Pergunte ao [assistente de IA](/pt-br/agenteye/assistant) integrado ao dashboard em linguagem natural e ele redigirá a query e a salvará na sua biblioteca.

A execução de uma query salva é controlada pela permissão `queries:run`, mantida separada das permissões para criar ou excluir queries, para que você possa conceder acesso de leitura sem permitir que todos reescrevam a biblioteca.
