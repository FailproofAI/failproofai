---
title: Visualizar sessões
description: "Inicie o painel para navegar pelas sessões do agente e gerenciar políticas"
---

```bash
failproofai
```

Inicia o painel web em `http://localhost:8020`.

## Opções

The dashboard takes no flags — `failproofai` rejects any it does not recognize. The port is fixed at `8020`.

Para apontar o painel para uma pasta de projeto Claude diferente da padrão, defina a variável de ambiente `CLAUDE_PROJECTS_PATH` ao iniciar.

## Exemplos

```bash
failproofai

# Usar um caminho de projetos Claude personalizado via variável de ambiente
CLAUDE_PROJECTS_PATH=~/my-claude-projects failproofai
```
