---
title: Visualizar sessões
description: "Abra o painel para navegar pelas sessões do agente e gerenciar políticas"
---

```bash
failproofai
```

Inicia o painel web em `http://localhost:8020`.

## Opções

| Flag | Descrição |
|------|-----------|
| `--port <number>` | Porta a ser usada (padrão: `8020`) |
| `--allowed-origins <origins>` | Hosts/IPs separados por vírgula com permissão de acesso aos recursos de desenvolvimento |

Para apontar o painel para uma pasta de projetos Claude diferente da padrão, defina a variável de ambiente `CLAUDE_PROJECTS_PATH` ao iniciar.

## Exemplos

```bash
# Iniciar em uma porta diferente
failproofai --port 9000

# Usar um caminho personalizado para projetos Claude via variável de ambiente
CLAUDE_PROJECTS_PATH=~/my-claude-projects failproofai
```
