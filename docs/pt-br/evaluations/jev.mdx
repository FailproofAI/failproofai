Uma avaliação Jev lê uma **sessão concluída** e atribui uma pontuação de 0 a 1. Use-a quando a resposta é conhecida com antecedência, como "O cliente expressou urgência?" ou "Qual o nível de frustração do cliente?". Ela ajuda a identificar padrões entre execuções; não interrompe uma chamada de ferramenta. Para decisões tomadas **antes** de uma ferramenta ser executada, use [políticas Jev](/pt-br/policies/jev).

## Crie uma no painel

1. Abra **Analisar → criação de avaliação** e selecione **nova avaliação**.
2. Descreva uma pergunta e suas possíveis respostas. Por exemplo: "O agente prometeu um reembolso antes de verificar a política de reembolsos? Responda sim ou não." Selecione **rascunho** e verifique se o resultado é uma pontuação de classificador.
3. [Teste-a](/pt-br/evaluations/test) em sessões recentes e, em seguida, [implante-a](/pt-br/evaluations/deploy). Novas sessões concluídas são pontuadas; utilize o [backfill](/pt-br/evaluations/deploy#score-sessions-you-already-have) caso precise também do histórico.

![O formulário compartilhado de criação de avaliação, onde você descreve uma pergunta de resposta fixa, revisa o rascunho e implanta após os testes. O exemplo exibido é uma avaliação de código; uma pergunta Jev utiliza o mesmo fluxo de criação.](/images/dashboard/eval-authoring-draft.png)

O assistente pode escolher entre código, classificação Jev e um [juiz](/pt-br/evaluations/judge). Verifique a escolha antes de implantar. O Jev fornece uma pontuação sem raciocínio em prosa; escolha um juiz quando precisar de uma explicação. Consulte a [referência de avaliações Jev](/pt-br/reference/jev-evaluations) para ver os tipos de perguntas e os limites de pontuação.

## Leia as pontuações

Abra **Observar → Avaliações** para visualizar o resultado por agente e por período. Em um terminal, a Cloud CLI pode ler os mesmos resultados:

```bash
fp evals --since 7d
fp evals --aggregate --since 7d
```

A Cloud CLI lê os resultados; a criação e a implantação acontecem no painel. Consulte a [referência da Cloud CLI](/pt-br/reference/cloud-cli#evaluations) para ver os filtros disponíveis.
