Uma avaliação Jev lê uma **sessão finalizada** e atribui uma pontuação de 0 a 1. Use-a quando a resposta é conhecida com antecedência, como "O cliente expressou urgência?" ou "Qual o nível de frustração do cliente?" Ela ajuda a identificar padrões entre execuções; não interrompe chamadas de ferramentas. Para decisões tomadas **antes** de uma ferramenta ser executada, use as [políticas Jev](/pt-br/policies/jev).

## Crie uma no dashboard

1. Abra **Analyze → eval authoring** e selecione **new eval**.
2. Descreva uma pergunta e suas possíveis respostas. Por exemplo: "O agente prometeu reembolso antes de verificar a política de reembolso? Responda sim ou não." Selecione **draft** e verifique se o resultado é uma pontuação de classificador.
3. [Teste](/pt-br/evaluations/test) em sessões recentes e, em seguida, [publique](/pt-br/evaluations/deploy). Novas sessões concluídas serão pontuadas; use o [backfill](/pt-br/evaluations/deploy#score-sessions-you-already-have) caso precise também do histórico.

![O formulário compartilhado de criação de avaliação, onde você descreve uma pergunta de resposta fixa, revisa o rascunho e publica após os testes. O exemplo exibido é uma avaliação de código; uma pergunta Jev usa o mesmo fluxo de criação.](/images/dashboard/eval-authoring-draft.png)

O assistente pode escolher entre código, classificação Jev e um [juiz](/pt-br/evaluations/judge). Verifique a escolha antes de publicar. O Jev fornece uma pontuação sem raciocínio em prosa; escolha um juiz quando precisar de uma explicação. Consulte a [referência de avaliações Jev](/pt-br/reference/jev-evaluations) para tipos de perguntas e limites de pontuação.

## Leia as pontuações

Abra **Observe → Evaluations** para visualizar o resultado por agente e por período. Em um terminal, o Cloud CLI pode ler os mesmos resultados:

```bash
fp evals --since 7d
fp evals --aggregate --since 7d
```

O Cloud CLI lê os resultados; a criação e a publicação ocorrem no dashboard. Consulte a [referência do Cloud CLI](/pt-br/reference/cloud-cli#evaluations) para filtros disponíveis.
