Use o escopo para decidir quem recebe uma política local:

| Escopo | Aplica-se a |
| --- | --- |
| `user` | Seus agentes compatíveis nesta máquina |
| `project` | Agentes em execução neste projeto |
| `local` | Claude apenas, nas configurações locais do projeto |
| `all` | Somente desinstalação |

```bash
failproofai policies add block-sudo --scope user
failproofai policies add block-rm-rf --scope project
```

Hermes e OpenClaw suportam apenas o escopo de usuário. A maioria dos outros harnesses suporta os escopos de usuário e projeto. Claude também suporta o escopo local. Consulte [Harnesses](/pt-br/reference/harnesses).

## Parâmetros de política

As configurações de política ficam em `policies-config.json` no escopo correspondente. Use a visualização **Policies → Configure** do painel local sempre que possível.

Um parâmetro pertence a uma política e altera a forma como essa política decide. Por exemplo, uma lista de permissões pode fazer uma política de bloqueio aceitar comandos ou caminhos conhecidos como seguros.

Arquivos de política personalizados podem ser carregados automaticamente a partir de `.failproofai/policies/`, ou explicitamente:

```bash
failproofai policies -i -c ./guards.mjs --scope project
```

Remova caminhos explícitos com:

```bash
failproofai policies -u -c
```

## Arquivos

| Arquivo | Finalidade |
| --- | --- |
| `~/.failproofai/config.json` | Configurações de máquina e coletor |
| `policies-config.json` | Políticas habilitadas e parâmetros para um escopo |
| `.failproofai/policies/*policies.mjs` | Políticas carregadas por convenção |
| `~/.failproofai/policies/packs/installed.json` | Pacotes instalados e seleções |

Não edite diretamente os artefatos de pacotes instalados. Reinstale ou publique uma versão corrigida.
