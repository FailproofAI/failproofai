Uma política observa uma ação do agente e retorna uma de três decisões:

- `allow` continua.
- `instruct` fornece orientação ao agente quando seu harness suporta.
- `deny` bloqueia a ação.

Use políticas para comportamentos conhecidos e repetíveis: exclusão de arquivos protegidos, exposição de segredos, push para a branch errada ou alterações em infraestrutura de produção.

## Adicionar políticas a esta máquina

A instalação não escolhe nenhum pacote de políticas. Adicione o pacote Failproof AI após a instalação:

```bash
failproofai config
failproofai policies add FailproofAI/policies
failproofai policies
```

O pacote não contém um pacote built-in privilegiado. O nosso é instalado da mesma forma que qualquer outro.

As políticas também podem vir de um arquivo local, de um pacote publicado ou de uma atribuição na Cloud:

| Origem | Como adicionar |
| --- | --- |
| Arquivo local | Coloque `*policies.{js,mjs,ts}` em `.failproofai/policies/` |
| Qualquer caminho de arquivo | `failproofai policies -i -c <path>` |
| Pacote publicado | `failproofai policies add <owner>/<repo>` |
| Cloud | Atribua no dashboard ou com `fp fleet deploy` |

`block-failproofai-commands` sempre é executado e não pode ser desativado. Ele impede que um agente desabilite sua própria aplicação de regras.

## Observar antes de aplicar

O modo de observação executa a política real e registra o que ela teria feito, mas não bloqueia o agente.

```bash
fp policies test ./checkout.policy.mjs --tool Bash --command "git push --force" --expect deny
fp fleet deploy ci-runner-01 --add checkout-guard:observe
fp guardrails summary --since 24h --machine ci-runner-01
fp fleet deploy ci-runner-01 --add checkout-guard:enforce
```

<Warning>
  Um `fp fleet deploy <machine> --add <id>` simples aplica a política imediatamente. Adicione `:observe` para um rollout em modo sombra.
</Warning>

Uma política que atinge timeout no modo de observação registra um allow, pois é isso que aconteceria durante a aplicação. Apenas decisões observadas diferentes de allow são registradas.

Para um pacote usado sem a Cloud, publique-o com `failproofai publish --effect observe`.
