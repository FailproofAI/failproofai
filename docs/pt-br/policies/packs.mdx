Um pacote de políticas é um conjunto versionado de políticas publicado como uma release pública no GitHub. O pacote em si não inclui nenhum pack próprio; instale o nosso como qualquer outro:

```bash
failproofai policies show FailproofAI/policies
failproofai policies add FailproofAI/policies
```

`show` lê o manifesto sem executar o código do pacote.

## Escolha o que instalar

```bash
failproofai policies add owner/repo --policy block-refunds
failproofai policies add owner/repo --category billing,git
failproofai policies add owner/repo --all
```

Sem nenhuma seleção, o pacote usa os padrões definidos pelo seu publicador. Adicionar novamente uma release mais recente mantém sua seleção existente.

Qualquer coisa com uma barra é uma fonte de pacote. Qualquer coisa sem barra é um nome de política.

## Fixar uma release

| Fonte | Resultado |
| --- | --- |
| `owner/repo` | Release mais recente, fixada após a resolução |
| `owner/repo@a1b2c3d4e5f6` | Release exata baseada em commit |
| `owner/repo@v2.1.0` | Release exata com nome |
| URL de release do GitHub | A release contida nessa URL |

Um pacote normalmente usa o SHA de commit de 12 caracteres com o qual foi gerado. Use `failproofai policies show owner/repo --releases` para ver a ordem das releases.

## Gerenciar pacotes instalados

```bash
failproofai policies
failproofai policies remove block-refunds
failproofai policies add block-refunds
failproofai policies remove owner/repo
```

Se dois pacotes instalados contiverem o mesmo nome de política, a CLI recusa o nome simples ambíguo. Selecione a política por meio de um dos pacotes ou desinstale o outro.

## Segurança e disponibilidade

Cada release contém um manifesto, o código das políticas empacotado e checksums. O Failproof AI verifica o digest registrado antes de carregá-lo. Os checksums provam que os bytes correspondem à release; eles não provam quem a publicou.

Um pacote selecionado que não consegue carregar falha de forma fechada para os eventos que declarou. Consulte [comportamento em caso de falha de política](/pt-br/policies/failure-behavior).

| Variável | Efeito |
| --- | --- |
| `FAILPROOFAI_NO_DOWNLOAD=1` | Recusa novos downloads; pacotes instalados continuam funcionando |
| `FAILPROOFAI_PACK_BASE_URL` | Usa um espelho |
| `FAILPROOFAI_PACK_DIR` | Move o diretório de armazenamento dos pacotes |

Explore pacotes no [Policy Hub](https://befailproof.ai/policy-hub/) ou [publique o seu próprio](/pt-br/policies/publish-a-pack).
