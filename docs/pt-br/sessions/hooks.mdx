---
title: "Hooks"
description: "Monitore atividade de hooks, gatilhos e latência separadamente dos resultados das políticas."
icon: "webhook"
---

Hooks exibe quando os hooks do ciclo de vida do agente são executados e quanto tempo levam. As decisões de políticas são apresentadas em uma visualização separada.

<Tabs>
  <Tab title="Dashboard">
    1. Acesse **Observe → Hooks**.
    2. Filtre por ambiente, nome do hook, evento de gatilho, agente ou ID de sessão.
    3. Revise a latência e a distribuição dos hooks.
    4. Selecione um ponto no gráfico ou um segmento de hook para abrir os eventos correspondentes.

    ![A página Hooks exibindo a latência agrupada por nome do hook e evento de gatilho.](/images/dashboard/hooks.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list hooks
    fp events --event-type hook_triggered,hook_completed --env production --since 24h
    fp events --search "PreToolUse" --since 24h
    ```
  </Tab>
</Tabs>
