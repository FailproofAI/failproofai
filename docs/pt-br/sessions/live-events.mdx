Eventos ao vivo exibe a atividade conforme os agentes executam: chamadas de modelo, ferramentas, erros, entrada humana, hooks e decisões de política.

## Acompanhar atividade

Acesse **Observe → Live events** ou execute:

```bash
fp events --since 1h
fp events --event-type tool_use,tool_result --since 1h
fp --json events --full --session-id <session-id> --all --limit 2000
```

Use `--full` quando precisar do conteúdo dos payloads. O feed leve é mais rápido e suficiente para a maioria dos filtros.

Os tipos de eventos mais comuns incluem:

- `session_start` e `session_end`
- `model_request` e `model_response`
- `tool_use` e `tool_result`
- `hook_triggered` e `hook_completed`
- `error`
- `human_wait` e `human_input`
- `agent_pause` e `agent_resume`

## Se os eventos não aparecerem

```bash
failproofai flush --wait
failproofai config --status
failproofai backfill --since 30d --dry-run
```

O ambiente padrão é `local`. Um filtro para `production` não retornará nada até que você altere o rótulo do ambiente.

Para um agente fora de um harness compatível, utilize o [SDK Python](/pt-br/reference/custom-agents).
