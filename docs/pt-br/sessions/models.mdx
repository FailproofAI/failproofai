Use Modelos para verificar se a confiabilidade ou o custo mudou com um modelo, agente, ambiente ou intervalo de tempo.

<Tabs>
  <Tab title="Dashboard">
    1. Acesse **Observe → Models**.
    2. Defina o intervalo de tempo e filtre por ambiente, modelo, agente ou ID de sessão.
    3. Analise latência, consumo de tokens, uso da janela de contexto e distribuição de modelos.
    4. Selecione um ponto no gráfico ou um segmento de distribuição para abrir os eventos correspondentes.

    ![A página Models exibindo visualizações de latência, percentil, tokens, custo, janela de contexto e distribuição de modelos.](/images/dashboard/models.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list models
    fp events --event-type model_request,model_response --env production --since 24h
    fp --json events --fields ts,agent_id,session_id,event_type,output_tokens,context_fill
    ```

    Use uma consulta salva para agregações no nível de modelo que não estão disponíveis como um comando dedicado na CLI.
  </Tab>
</Tabs>
