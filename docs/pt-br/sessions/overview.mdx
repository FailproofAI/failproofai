Uma sessão é uma execução de agente. Ela conecta o prompt, as chamadas ao modelo, as ferramentas, os erros, a entrada humana, as decisões de política e o resultado final.

## Onde as sessões ficam armazenadas

<Tabs>
  <Tab title="Local">
    Execute `failproofai` para abrir o dashboard em `http://localhost:8020`. O histórico de sessões permanece nesta máquina.
  </Tab>
  <Tab title="Cloud">
    Conecte a máquina e abra **Observe → Sessions**:

    ```bash
    export FAILPROOFAI_CLOUD_TOKEN="<key>"
    failproofai config
    ```

    Por padrão, o Cloud recebe transcrições completas. Para enviar apenas as decisões de política, conecte primeiro e defina `collector.sessions` como `false` em `~/.failproofai/config.json`. O sinalizador de configuração `--no-transcripts` atual não aplica essa definição.
  </Tab>
</Tabs>

As sessões chegam a partir dos 12 [harnesses de agente](/pt-br/reference/harnesses) suportados e de agentes instrumentados com o [Python SDK](/pt-br/reference/custom-agents).

## Encontrar uma sessão

No Cloud, filtre por tempo, ambiente, status, agente ou ID de sessão. Pela CLI:

```bash
fp sessions --since 24h
fp sessions --status error,timeout --agent-id checkout-agent
fp --json sessions --session-id <session-id>
```

Use `fp errors --since 24h` para falhas que nunca foram avaliadas. `fp sessions --status` utiliza o resultado da avaliação mais recente; portanto, uma sessão não avaliada não possui status.

## Analisar uma execução

1. Confirme o objetivo e o ambiente do agente.
2. Encontre o primeiro erro ou decisão inesperada.
3. Inspecione o contexto do modelo e a entrada da ferramenta imediatamente antes do ocorrido.
4. Verifique tentativas repetidas, latência e interrupções humanas.
5. Revise as avaliações e as decisões de política.

## Se uma sessão estiver faltando

```bash
failproofai flush --wait
failproofai config --status
failproofai backfill --since 30d --dry-run
```

Use `failproofai harness add-path <harness> [<label>=]<path>` quando as sessões estiverem fora do local habitual do harness, como outro perfil, home de contêiner ou diretório de equipe montado.
