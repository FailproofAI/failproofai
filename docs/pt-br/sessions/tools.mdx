---
title: "Ferramentas"
description: "Encontre ferramentas lentas, com falhas ou usadas em excesso entre sessões de agentes."
icon: "wrench"
---

Ferramentas agrupa chamadas de ferramentas entre sessões para que você possa comparar latência e distribuição de chamadas.

<Tabs>
  <Tab title="Dashboard">
    1. Acesse **Observe → Tools**.
    2. Filtre por ambiente, nome da ferramenta, agente ou ID de sessão.
    3. Revise a latência e a distribuição de ferramentas.
    4. Selecione um ponto no gráfico ou um segmento de ferramenta para abrir os eventos e sessões correspondentes.

    ![A página Tools exibindo latência, detalhamentos de sucesso e falha, e distribuição de chamadas de ferramentas.](/images/dashboard/tools.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list tools
    fp events --event-type tool_use,tool_result --env production --since 24h
    fp --json events --full --session-id <session-id> --all
    ```
  </Tab>
</Tabs>
