Este guia de início rápido configura uma máquina para reportar sessões, executa uma auditoria e implanta uma política. Use a skill para configurar o Failproof, ou siga os passos manuais. Você precisa do Node.js 20.9 ou superior.

<Tabs>
  <Tab title="Usar a skill">
    <Steps>
      <Step title="Instale as skills do Failproof AI">
        ```bash
        npx skills add FailproofAI/skills
        ```
      </Step>
      <Step title="Peça ao seu agente para configurar tudo">
        ```text
        Set up Failproof AI for this project, connect this machine, install the right hooks and policies, and verify that a session arrives.
        ```

        Seu agente inspeciona o projeto, escolhe a integração relevante, realiza a configuração e verifica o resultado. Consulte o [repositório de skills do FailproofAI](https://github.com/FailproofAI/skills) para ver skills individuais e opções avançadas de instalação.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Configuração manual">
    ## Antes de começar

1. Abra o [painel do Failproof AI](https://app.befailproof.ai) e crie uma conta ou entre com seu e-mail de trabalho.
2. Acesse **Administration → Keys** e crie uma chave com `events:add` e `policies:pull`.
3. Copie o segredo de uso único e armazene-o na máquina de destino:

```bash
export FAILPROOFAI_KEY="<one-time-secret>"
```

    ## Instalar

<Steps>
  <Step title="Instale e conecte o Failproof AI">
    ```bash
    npm install -g failproofai
    failproofai config --connect https://app.befailproof.ai --token "$FAILPROOFAI_KEY"
    ```

    Os transcritos de sessão são enviados por padrão. Adicione `--no-transcripts` para reportar atividade de hooks e decisões de políticas sem o conteúdo do transcrito.

    Se esta máquina já possui histórico de agente, visualize e importe os últimos sete dias, depois aguarde a conclusão da entrega. Pule este passo em uma máquina nova.

    ```bash
    failproofai backfill --since 7d --dry-run
    failproofai backfill --since 7d
    failproofai flush --wait
    ```

    Abra **Sessions** no Failproof AI e selecione uma sessão importada.
  </Step>
  <Step title="Instale hooks e políticas do agente">
    Isso conecta o Failproof AI ao CLI do seu agente e instala as políticas integradas. Use-as para visualizar decisões de políticas locais e testar a aplicação antes que o Failproof AI audite suas sessões e escreva políticas para seus agentes.

    Deixe o instalador detectar o CLI do seu agente automaticamente, ou especifique um explicitamente.

    ```bash
    failproofai policies --install --cli claude --scope user
    ```
  </Step>
  <Step title="Audite o comportamento">
    Siga [Execute sua primeira verificação de falhas](/pt-br/start/first-audit). Use um objetivo concreto, como "encontrar sessões em que o agente repetiu uma ferramenta com falha sem mudar sua abordagem."
  </Step>
  <Step title="Previna a falha">
    Siga [Previna sua primeira falha com uma política](/pt-br/start/first-policy). Comece no modo de observação, inspecione as correspondências e, em seguida, aplique a versão revisada.
  </Step>
</Steps>

<Check>
  Execute `failproofai config --status`. Uma configuração saudável reporta a conexão com a nuvem, o estado do daemon e se a aplicação está pausada.
</Check>
