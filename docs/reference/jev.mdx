Jev has two uses in Failproof AI:

| Use | When it runs | What it returns | Start here |
| --- | --- | --- | --- |
| Session evaluation | After a session finishes | A score for a fixed-answer question | [Jev evaluations](/evaluations/jev) |
| Tool-call policy review | Before a gated tool call runs | A verdict alongside the installed policies | [Jev policies](/policies/jev) |
