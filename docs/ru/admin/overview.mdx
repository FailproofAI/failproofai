Раздел администрирования содержит элементы управления, необходимые для работы Failproof AI в команде. Большинству пользователей достаточно разделов Sessions, Audits и Policies; администраторы используют этот раздел для управления доступом и операционными границами.

<Tabs>
  <Tab title="Dashboard">
    Используйте раздел **Admin** боковой панели Cloud для **редактора политик**, **enforcement**, **usage**, **keys**, **users** и **settings**. Заблокированный элемент указывает на отсутствие разрешения на чтение для вашей учетной записи.

    ![Раздел Admin боковой панели Cloud с редактором политик, enforcement, usage, keys, users и settings.](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    Поместите глобальные параметры перед командой, например `fp --org reliability-team --json usage`.
  </Tab>
</Tabs>
