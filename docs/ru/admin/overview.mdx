Администрирование содержит элементы управления, необходимые для работы Failproof AI в команде. Большинство пользователей могут оставаться в разделах Sessions, Audits и Policies; администраторы используют этот раздел для управления доступом и операционными границами.

<Tabs>
  <Tab title="Dashboard">
    Используйте раздел **Admin** в боковой панели Cloud для **редактора политик**, **принудительного применения**, **использования**, **ключей**, **пользователей** и **параметров**. Заблокированный элемент указывает на то, что вашей учётной записи не хватает разрешения на чтение.

    ![Раздел Admin в боковой панели Cloud с редактором политик, принудительным применением, использованием, ключами, пользователями и параметрами.](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    Поместите глобальные параметры перед командой, например `fp --org reliability-team --json usage`.
  </Tab>
</Tabs>
