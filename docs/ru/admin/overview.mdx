Администрирование содержит элементы управления, необходимые для работы Failproof AI в команде. Большинство пользователей работают с разделами Sessions, Audits и Policies; администраторы используют этот раздел для управления доступом и операционными границами.

<Tabs>
  <Tab title="Dashboard">
    Используйте раздел **Admin** в боковой панели Cloud для **редактора политик**, **применения**, **использования**, **ключей**, **пользователей** и **настроек**. Заблокированный элемент указывает на то, что у вашей учетной записи отсутствует разрешение на чтение.

    ![Раздел Admin в боковой панели Cloud с редактором политик, применением, использованием, ключами, пользователями и настройками.](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    Помещайте глобальные опции перед командой, например `fp --org reliability-team --json usage`.
  </Tab>
</Tabs>
