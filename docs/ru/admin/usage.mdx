В разделе «Использование» отображается потребление текущей организацией и её окна выставления счётов. Используйте его, чтобы понять, как производственное развёртывание, объём транскриптов, оценки и частота аудитов влияют на ваш план.

## Проверьте использование

<Tabs>
  <Tab title="Dashboard">
    1. Перейдите в **Administration → Usage**.
    2. Подтвердите организацию и окно подсчёта потребления.
    3. Проверьте приём данных, сеансы, оценки, метрики, аудиты, выводы, оповещения, пользователей и ключи.
    4. При неожиданном использовании аудита сравните начатые и завершённые работы аудита.

    ![Страница Usage, показывающая окно подсчёта потребления, захваченные события, конвейеры оценки и аудита, ресурсы рабочей области, участников и ключи API.](/images/dashboard/usage-overview.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp usage
    fp --json usage
    fp --org reliability-team --json usage
    ```
  </Tab>
</Tabs>

## Исследуйте изменение

1. Подтвердите активную организацию и окно.
2. Сравните прирост с объёмом сеансов по окружениям.
3. Проверьте, не началась ли новая интеграция отправлять транскрипты.
4. Проверьте изменения в частоте оценок и аудитов.
5. Сравните с лимитами текущего тарифного плана.

CLI возвращает то же резюме для скриптов.
