Использование показывает потребление ресурсов текущей организацией и её расчетными окнами. Используйте эту информацию, чтобы понять, как объем производственного развертывания, объем транскриптов, оценки и частота аудитов влияют на ваш тариф.

## Просмотр использования

<Tabs>
  <Tab title="Dashboard">
    1. Перейдите в **Administration → Usage** (Администрирование → Использование).
    2. Подтвердите организацию и окно измерений.
    3. Просмотрите данные о приеме, сеансах, оценках, метриках, аудитах, выводах, оповещениях, пользователях и ключах.
    4. Сравните начатую и завершенную работу аудита при неожиданном значении использования аудита.

    ![Страница Usage, показывающая окно измерений, захваченные события, конвейеры оценок и аудитов, ресурсы рабочей области, участников и ключи API.](/images/dashboard/usage-overview.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp usage
    fp --json usage
    fp --org reliability-team --json usage
    ```
  </Tab>
</Tabs>

## Исследование изменения

1. Подтвердите активную организацию и окно.
2. Сравните увеличение с объемом сеансов по окружениям.
3. Проверьте, начала ли новая интеграция отправлять транскрипты.
4. Просмотрите изменения в частоте оценок и аудитов.
5. Сравните с ограничениями текущего тарифного плана.

CLI возвращает тот же отчет для скриптов.
