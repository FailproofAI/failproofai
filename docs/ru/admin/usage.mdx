Использование показывает потребление текущей организации и её окна выставления счётов. Используйте это для понимания того, как развёртывание в production, объём транскриптов, оценки и частота аудитов влияют на ваш план.

## Просмотр использования

<Tabs>
  <Tab title="Dashboard">
    1. Перейдите в **Administration → Usage**.
    2. Подтвердите организацию и окно измерения.
    3. Просмотрите приём, сессии, оценки, метрики, аудиты, результаты, уведомления, пользователей и ключи.
    4. При неожиданном использовании аудитов сравните начатые и завершённые работы аудита.

    ![Страница Usage, показывающая окно измерения, полученные события, конвейеры оценок и аудитов, ресурсы рабочей области, участников и ключи API.](/images/dashboard/usage-overview.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp usage
    fp --json usage
    fp --org reliability-team --json usage
    ```
  </Tab>
</Tabs>

## Исследование изменения

1. Подтвердите активную организацию и окно.
2. Сравните увеличение с объёмом сессий по окружению.
3. Проверьте, не начала ли новая интеграция отправлять транскрипты.
4. Пересмотрите изменения в кадре оценивателей и аудитов.
5. Сравните с лимитами вашего текущего плана цен.

CLI возвращает ту же сводку для скриптов.
