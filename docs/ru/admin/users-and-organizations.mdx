Организации изолируют сеансы, оценки, аудиты, проблемы, оповещения, запросы, панели инструментов, пользователей и ключи. Перед изменением административных ресурсов убедитесь, что выбрана правильная организация.

## Управление членами и организациями

<Tabs>
  <Tab title="Dashboard">
    1. Используйте переключатель организаций в верхней части боковой панели Cloud для переключения между организациями.
    2. Перейдите в **Administration → Users**, чтобы найти членов или отфильтровать их по статусу активности и роли.
    3. Выберите **new user**, введите адрес электронной почты, выберите набор разрешений и при необходимости отрегулируйте исключения.
    4. Откройте пользователя позже, чтобы обновить выданные разрешения, отключить вход в систему или повторно активировать учётную запись.

    ![Страница Users с адресами электронной почты членов, наборами разрешений и элементами управления редактированием и отключением.](/images/dashboard/users.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp orgs list
    fp orgs switch reliability-team
    fp orgs current
    fp orgs perms

    fp users create engineer@example.com --permission-set standard
    fp users show engineer@example.com
    fp users update engineer@example.com --add audits:write
    fp users disable engineer@example.com
    fp users enable engineer@example.com
    ```
  </Tab>
</Tabs>

Администраторы могут создавать, обновлять, отключать и повторно активировать пользователей, а затем назначать им набор разрешений, соответствующий их роли. API использует операцию delete для отключения, но она не удаляет учётную запись или её запись о членстве.

<Warning>
  Отключение пользователя блокирует эту учётную запись от входа во все организации, а не только в текущей выбранной организации. Повторное активирование восстанавливает глобальный вход и разрешения члена в этой организации.
</Warning>

<Tip>
  Давайте служебным учётным записям описательные имена, связанные с рабочей нагрузкой и владельцем. Избегайте использования одного ключа несколькими организациями или между людьми и машинами.
</Tip>
