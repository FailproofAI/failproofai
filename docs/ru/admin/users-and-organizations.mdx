Организации изолируют сессии, оценки, аудиты, проблемы, оповещения, запросы, панели управления, пользователей и ключи. Подтвердите активную организацию перед изменением административных ресурсов.

## Управление членами и организациями

<Tabs>
  <Tab title="Dashboard">
    1. Используйте переключатель организации в верхней части боковой панели Cloud для переключения между организациями.
    2. Перейдите в **Administration → Users**, чтобы искать членов или фильтровать по статусу активности и роли.
    3. Выберите **new user**, введите адрес электронной почты, выберите набор разрешений и при необходимости отрегулируйте переопределения.
    4. Откройте пользователя позже, чтобы обновить права доступа, отключить вход или снова активировать учетную запись.

    ![Страница Users, показывающая адреса электронной почты членов, наборы разрешений, а также элементы управления редактированием и отключением.](/images/dashboard/users.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp orgs list
    fp orgs switch reliability-team
    fp orgs current
    fp orgs perms

    fp users create engineer@example.com --permission-set standard
    fp users show engineer@example.com
    fp users update engineer@example.com --add audits:write
    fp users disable engineer@example.com
    fp users enable engineer@example.com
    ```
  </Tab>
</Tabs>

Администраторы могут создавать, обновлять, отключать и повторно активировать пользователей, а затем назначать набор разрешений, соответствующий их роли. API использует операцию удаления для отключения, но это не удаляет учетную запись и её запись о членстве.

<Warning>
  Отключение пользователя блокирует эту учетную запись от входа во все организации, не только в текущей выбранной организации. Повторная активация восстанавливает глобальный вход и разрешения члена в этой организации.
</Warning>

<Tip>
  Называйте служебные учетные записи описательными именами, связанными с рабочей нагрузкой и владельцем. Избегайте совместного использования ключей между организациями или между людьми и машинами.
</Tip>
