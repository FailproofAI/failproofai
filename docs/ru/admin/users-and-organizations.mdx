Организации изолируют сеансы, оценки, аудиты, проблемы, оповещения, запросы, панели мониторинга, пользователей и ключи. Подтвердите активную организацию перед изменением административных ресурсов.

## Управление участниками и организациями

<Tabs>
  <Tab title="Dashboard">
    1. Используйте переключатель организаций в верхней части боковой панели Cloud для переключения между организациями.
    2. Перейдите в раздел **Administration → Users**, чтобы найти участников или отфильтровать их по статусу активности и роли.
    3. Выберите **new user**, введите адрес электронной почты, выберите набор разрешений и при необходимости отрегулируйте переопределения.
    4. Откройте пользователя позже, чтобы обновить привилегии, отключить вход в систему или повторно включить учетную запись.

    ![Страница Users, показывающая адреса электронной почты участников, наборы разрешений, а также элементы управления редактированием и отключением.](/images/dashboard/users.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp orgs list
    fp orgs switch reliability-team
    fp orgs current
    fp orgs perms

    fp users create engineer@example.com --permission-set standard
    fp users show engineer@example.com
    fp users update engineer@example.com --add audits:write
    fp users disable engineer@example.com
    fp users enable engineer@example.com
    ```
  </Tab>
</Tabs>

Администраторы могут создавать, обновлять, отключать и повторно включать пользователей, а затем назначать им набор разрешений, соответствующий их роли. API использует операцию удаления для отключения, но это не удаляет учетную запись или запись о членстве.

<Warning>
  Отключение пользователя блокирует данное удостоверение от входа в каждую организацию, а не только в выбранную в данный момент организацию. Повторное включение восстанавливает глобальный вход в систему и разрешения участника в этой организации.
</Warning>

<Tip>
  Присваивайте учетным записям обслуживания описательные имена, привязанные к рабочей нагрузке и владельцу. Избегайте совместного использования ключей между организациями или между людьми и машинами.
</Tip>
