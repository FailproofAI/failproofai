Весь ваш Failproof AI Observability deployment в одной команде. Проверьте production, создайте API ключ или подтвердите инцидент, не покидая терминал, затем используйте это в CI или позвольте агенту написанному на простом английском языке сделать это за вас.

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*CLI `agenteye` взаимодействует с вашей панелью управления. Это отдельный инструмент от сборщика, который отправляет события на сервер.*

## Весь ваш deployment в одной команде

Прекратите переключаться между вкладками, чтобы ответить на быстрый вопрос. CLI `agenteye` читает ваши данные и управляет вашей организацией из одного бинарника, поэтому проверка, которая раньше требовала кликов по панели управления, становится одной строкой, которую вы можете повторять, сохранять в alias или вставлять в runbook. Вы получите четыре инструмента:

- **Читайте ваши данные:** `sessions`, `events`, `evals` и `errors`, отфильтрованные по времени, агенту и окружению.
- **Управляйте вашей организацией:** `keys`, `users`, `settings`, `alerts` и `incidents`.
- **Запускайте аналитику:** сохранённые SQL запросы плюс ad-hoc `query` runner для ваших данных событий.
- **Спросите ассистента:** `agent ask` обращается к тому же read-only аналитику, с которым вы разговариваете в панели управления.

Установите один раз с помощью `pipx`, авторизуйтесь по 6-значному коду, отправленному по почте, и всё готово. Сессия длится около дня; переустановите `agenteye login` когда она истечёт. Используйте его для проверки production, создания ключа или сортировки срабатывающего инцидента, всё без открытия браузера:

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

Один совет: глобальные опции вроде `--json` идут перед командой. `agenteye --json sessions` верно; `agenteye sessions --json` неверно.

## Используйте в скриптах и интегрируйте в CI

Каждая команда поддерживает `--json`, и это всё меняет. Чистый JSON выводится в stdout, пока человеческие статусы и предупреждения идут в stderr, поэтому захват `--json` сразу передаётся в `jq` без посторонних строк. Это делает CLI одинаково полезным для вас в терминале и для агента, парсящего вывод:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

Она построена для работы без присмотра. Запросы на подтверждение автоматически пропускаются, когда нет терминала, поэтому ничто не зависает в pipeline, и каждая команда возвращает значимый exit code: `0` успех, `4` не авторизован, `5` отсутствует разрешение (сообщение указывает его, например `alerts:write`), `3` панель управления недоступна. Скрипт может ветвиться на `4` для переавторизации или на `5` чтобы сказать вам ровно что попросить у администратора вместо слепого отказа.

## Позвольте агенту управлять ей на простом английском

Ещё лучше, вам вообще не нужно помнить эти флаги. **CLI skill** это папка с небольшим Agent Skill названная `agenteye-cli`, которая учит агента написанного на коде, такого как Claude Code или Codex, управлять CLI из запросов на простом английском. Спросите «что-нибудь сломалось сегодня?» и агент выбирает команду, запускает её от вашего имени и отвечает прозой.

Для Claude Code, поместите папку `agenteye-cli` в `~/.claude/skills/` и она будет автоматически обнаружена. Failproof AI Observability предоставляет папку; ничего лишнего устанавливать не нужно, потому что она только управляет CLI, который вы уже установили. Авторизуйтесь сами: skill не может завершить логин с кодом отправленным по почте за вас.

Поскольку агент запускает CLI от вашего имени, он может делать всё, что позволяет ваша авторизация, чтение и запись включительно: создавать ключи, менять настройки, разрешать инциденты. Запрос подтверждения CLI не срабатывает для агента, поэтому skill написана чтобы указать точную команду и ждать вашего OK перед любым изменением. Вы шаг подтверждения.

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

Чтения остаются мгновенными, а каждая запись паузирует для вас:

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
