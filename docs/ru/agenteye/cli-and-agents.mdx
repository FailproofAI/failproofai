Всё управление Failproof AI Observability в одной команде. Проверьте production, создайте API ключ или подтвердите инцидент, не покидая терминал, затем автоматизируйте это в CI или дайте кодирующему агенту сделать это на простом английском.

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*CLI `agenteye` взаимодействует с вашей панелью управления. Это отдельный инструмент от сборщика, который отправляет события на сервер.*

## Всё управление в одной команде

Перестаньте прыгать между вкладками, чтобы ответить на быстрый вопрос. CLI `agenteye` читает ваши данные и управляет вашей организацией из одного бинарного файла, поэтому проверка, которая раньше требовала кликов по панели управления, становится одной строкой, которую вы можете переиспользовать, сохранить как alias или вставить в runbook. Вы получаете четыре интерфейса:

- **Читайте ваши данные:** `sessions`, `events`, `evals` и `errors`, отфильтрованные по времени, агенту и окружению.
- **Управляйте организацией:** `keys`, `users`, `settings`, `alerts` и `incidents`.
- **Запускайте аналитику:** сохранённый SQL плюс ad-hoc `query` для анализа ваших событий.
- **Спросите помощника:** `agent ask` обращается к тому же аналитику с правом только на чтение, с которым вы общаетесь в панели управления.

Установите один раз с помощью `pipx`, войдите с 6-значным кодом, отправленным по почте, и всё готово. Сессия длится около дня; переустановите `agenteye login` когда она истечёт. Используйте это для проверки production, подготовки ключей или анализа срабатывающего инцидента, всё без открытия браузера:

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

Одна важная привычка: глобальные опции вроде `--json` идут перед командой. `agenteye --json sessions` правильно; `agenteye sessions --json` неправильно.

## Автоматизируйте, интегрируйте в CI

Каждая команда поддерживает `--json`, и это меняет всё. Чистый JSON выводится в stdout, а информационные сообщения и предупреждения — в stderr, поэтому захват `--json` прямо передаётся в `jq` без лишних строк. Именно это делает CLI одинаково полезным как для вас в терминале, так и для кодирующего агента, парсящего вывод:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

Она построена для автоматического запуска. Запросы подтверждения автоматически пропускаются, когда терминал не подключен, поэтому ничего не зависает в pipeline, и каждая команда возвращает осмысленный код выхода: `0` успех, `4` не авторизирован, `5` отсутствует разрешение (сообщение называет его, например `alerts:write`), `3` панель управления недоступна. Скрипт может ветвиться на `4` для переаутентификации или на `5` чтобы точно сказать, на что попросить у администратора, вместо слепого отказа.

## Дайте кодирующему агенту управлять этим на простом английском

Ещё лучше — вам не нужно запоминать никакие флаги. **CLI skill** — это небольшая папка Agent Skill с именем `agenteye-cli`, которая учит кодирующего агента, такого как Claude Code или Codex, управлять CLI из запросов на простом английском. Спросите «что-то сломалось сегодня?» и агент выбирает команду, запускает её от вашего имени и отвечает прозой.

Для Claude Code просто поместите папку `agenteye-cli` в `~/.claude/skills/` и она будет автоматически обнаружена. Failproof AI Observability предоставляет папку; нет ничего лишнего для установки, потому что это только управляет CLI, который вы уже установили. Сначала войдите сами: skill не может завершить вход по коду, отправленному по почте.

Поскольку агент запускает CLI от вашего имени, он может делать всё, что позволяет ваш вход, читать и писать: создавать ключи, менять настройки, разрешать инциденты. Запрос подтверждения CLI не срабатывает для агента, поэтому skill написан, чтобы указать точную команду и ждать вашего ОК перед любым изменением. Вы — шаг подтверждения.

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

Чтения остаются мгновенными, и каждая запись паузирует для вас:

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
