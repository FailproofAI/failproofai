Всё развёртывание Failproof AI Observability в одной команде. Проверьте production, создайте API-ключ или подтвердите инцидент, не покидая терминала, а затем автоматизируйте любое из этих действий в CI или позвольте агенту это сделать на простом английском языке.

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*CLI `agenteye` взаимодействует с вашей панелью управления. Это отдельный инструмент от сборщика событий, который отправляет данные на сервер.*

## Всё развёртывание в одной команде

Прекратите прыгать между вкладками, чтобы ответить на быстрый вопрос. CLI `agenteye` читает ваши данные и администрирует организацию из одного бинарного файла, поэтому проверка, которая раньше требовала нескольких кликов на панели, становится одной строкой, которую вы можете переиспользовать, создать для неё алиас или вставить в runbook. Вам доступны четыре направления:

- **Чтение данных:** `sessions`, `events`, `evals` и `errors`, отфильтрованные по времени, агенту и окружению.
- **Управление организацией:** `keys`, `users`, `settings`, `alerts` и `incidents`.
- **Запуск аналитики:** сохранённый SQL и ad-hoc запросчик `query` над вашими данными событий.
- **Общение с ассистентом:** `agent ask` подключается к тому же аналитику только для чтения, с которым вы общаетесь на панели.

Установите один раз с помощью `pipx`, войдите с помощью 6-значного кода, отправленного по email, и всё готово. Сессия длится примерно день; переустановите `agenteye login` когда она истечёт. Используйте его для быстрой проверки production, создания ключа или решения проблемы с инцидентом, всё без открытия браузера:

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

Один важный момент: глобальные параметры вроде `--json` идут перед командой. `agenteye --json sessions` правильно; `agenteye sessions --json` неправильно.

## Автоматизируйте, интегрируйте в CI

Каждая команда поддерживает `--json`, и это меняет всё. Чистый JSON идёт в stdout, а статусы и предупреждения — в stderr, поэтому захват `--json` сразу передаётся в `jq` без лишних символов для удаления. Это делает CLI одинаково удобным и для вас в терминале, и для агента, анализирующего вывод:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

Он построен для автономного запуска. Подтверждающие запросы автоматически пропускаются, когда терминал не подключен, поэтому ничего не зависает в pipeline, и каждая команда возвращает осмысленный код выхода: `0` успех, `4` не залогинен, `5` недостаточно прав (сообщение укажет право, например `alerts:write`), `3` панель недоступна. Скрипт может разветвиться на `4`, чтобы переаутентифицироваться, или на `5`, чтобы точно сказать вам, что нужно попросить у администратора, вместо того чтобы молча упасть.

## Позвольте агенту управлять им на простом английском языке

Ещё лучше — вам не нужно помнить никакие флаги. **CLI skill** — это небольшая папка Agent Skill под названием `agenteye-cli`, которая учит агента-кодировщика (например Claude Code или Codex) управлять CLI с помощью запросов на простом английском. Спросите «что-то сломалось сегодня?» и агент выберет команду, запустит её от вашего имени и ответит прозой.

Для Claude Code перетащите папку `agenteye-cli` в `~/.claude/skills/` и она будет автоматически обнаружена. Failproof AI Observability предоставляет папку; не требуется ничего дополнительно устанавливать, потому что он только управляет CLI, который вы уже установили. Сначала войдите сами: skill не может завершить вход с кодом по email за вас.

Поскольку агент запускает CLI от вашего имени, он может делать всё, что позволяет ваш вход, как чтение, так и запись: создавать ключи, менять настройки, разрешать инциденты. Подтверждающий запрос CLI не срабатывает для агента, поэтому skill написан так, чтобы указать точную команду и ждать вашего ОК перед любым изменением. Вы — шаг подтверждения.

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

Чтения выполняются мгновенно, и каждая запись ждёт вас:

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
