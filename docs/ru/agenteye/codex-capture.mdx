Ваши инженеры уже ежедневно используют OpenAI Codex. Захват сессий Codex переносит эти сессии кодирования в AgentEye как обычные сессии и события, так что вы можете искать, воспроизводить и оценивать их наравне со всем остальным, что вы наблюдаете. Это дополняет [Python SDK](/ru/agenteye/python-sdk): SDK instrumentирует агентов, которых вы пишете, а это функция захватывает работу Codex, которую уже выполняет ваша команда — без каких-либо изменений в том, как они его используют.

Небольшой фоновый сборщик читает локальные транскрипты сессий Codex по мере их записи и отправляет их в AgentEye. Один сборщик на машину захватывает все локальные поверхности Codex одновременно — не требуется настройка для каждой поверхности.

Этот же сборщик захватывает и других агентов — см. [OpenClaw](/ru/agenteye/openclaw-capture) и [Hermes](/ru/agenteye/hermes-capture). Включите каждого, кого вы используете; один сборщик может захватывать несколько одновременно.

---

## Что он захватывает

Каждая поверхность Codex, работающая **локально**, создаёт одинаковые транскрипты сессий на диске, и сборщик захватывает все из них:

- **CLI** Codex и `codex exec`
- **расширение VS Code / IDE**
- **настольное приложение**, когда оно запускает сессию локально

Каждая сессия Codex становится [сессией](/ru/agenteye/sessions) AgentEye; её сообщения пользователя и помощника, рассуждение, вызовы инструментов, результаты инструментов и использование токенов становятся соответствующими [событиями](/ru/agenteye/event-stream). Поверхность, из которой пришла каждая сессия (CLI, IDE или настольное приложение), записывается, поэтому вы можете их различить.

> **Облачные сессии не захватываются.** Настольное приложение всё чаще запускает сессии в облаке Codex и хранит только их метаданные на машине — нет локального транскрипта для чтения. Захватываются только локально выполняемые сессии.

## Включение

Захват отключен по умолчанию. Установите сборщик с API-ключом, имеющим разрешение `events:add` (см. [API-ключи](/ru/agenteye/api-keys)), и включите захват Codex:

```bash
curl -fsSL https://raw.githubusercontent.com/FailproofAI/agenteye-collector/main/install.sh \
  | sh -s -- --key <YOUR_API_KEY> --codex-enabled
```

Это устанавливает сборщик, регистрирует его как фоновый сервис и запускает захват. Убедитесь, что он работает:

```bash
agenteye-collector health
```

При первом запуске ваши существующие сессии Codex будут заполнены один раз, а затем новая активность будет поступать в течение нескольких секунд. Файлы самого Codex только читаются — никогда не модифицируются, не перемещаются и не удаляются — и каждая сессия отправляется ровно один раз, даже при перезагрузке.

---

## Где это отображается

Захваченные сессии появляются в **Sessions**, а их события в потоке **Events**, как и у любого другого наблюдаемого агента — поэтому [воспроизведение сессий](/ru/agenteye/sessions), [поиск](/ru/agenteye/queries), [оценки](/ru/agenteye/evaluations) и [алерты](/ru/agenteye/alerts) работают с ними. Фильтруйте по агенту Codex, чтобы увидеть только их.

---

## Конфиденциальность

Транскрипты Codex содержат полную сессию — включая выводы команд, содержимое файлов и всё, что Codex прочитал или написал — и могут содержать секреты. Захваченные сессии отправляются как есть, поэтому включайте захват только на машинах и для команд, где централизация этого содержимого в AgentEye уместна, и предоставьте сборщику ключ с правами только на `events:add`. См. [Безопасность](/ru/agenteye/security), чтобы узнать, как ваши данные остаются изолированными.
