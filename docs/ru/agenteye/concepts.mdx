## Модель данных

**Event** (событие)
Наименьшая единица данных. Одно событие фиксирует один шаг, который выполнил ваш агент: `tool_use`, `model_request`, `hook_completed`, `error` и так далее. Ваш агент генерирует события через [Python SDK](/ru/agenteye/python-sdk); они отображаются в реальном времени на странице **Events**.

**Session** (сеанс)
Один запуск агента, идентифицируемый `session_id`. Сеанс — это все события с одинаковым идентификатором, объединённые в одну строку на странице **Sessions** и отображаемые в виде графа выполнения на странице деталей. Сеанс обычно начинается с `agent_start` и заканчивается с `agent_end`.

**Agent** (агент)
Именованный субъект внутри запуска, идентифицируемый `agent_id`. Запуск может включать несколько агентов: например, плановщик, который порождает подагента-суммаризатор. Подагенты имеют `parent_id`, что позволяет Failproof AI Observability отображать их на отдельных дорожках в графе выполнения.

**Environment** (среда)
Метка того, где произошёл запуск: `production`, `staging`, `dev`. Вы устанавливаете её один раз при конфигурировании SDK. Почти на всех страницах панели инструментов можно фильтровать по среде.

**Context-window fill** (заполнение контекстного окна)
Процент контекстного окна модели, который использовался в ответе. Failproof AI Observability добавляет эту метрику на события `model_response` для известных ей моделей, чтобы рост промпта и грядущая компакция были видны прямо в потоке событий.

## Качество

**Evaluation** (оценка)
Оценка качества завершённого сеанса, произведённая вашей службой оценки. Оценки опциональны: пока вы не подключите оценивающий сервис, сеансы записываются, но не оцениваются. Каждая оценка может включать несколько именованных показателей (например `helpfulness`, `factuality`, `tool_efficiency`), каждый с кратким комментарием. См. [Evaluation suite](/ru/agenteye/evaluation-suite).

**Score key** (ключ оценки)
Название одного аспекта, о котором сообщает оценивающий сервис, например `helpfulness`. Уведомления и аудиты могут отслеживать конкретный ключ оценки во времени.

**Evaluator** (оценивающий сервис)
Ваша служба оценки. Failproof AI Observability отправляет завершённый запуск вместе со стенограммой на ваш сервис и сохраняет возвращаемые оценки. Failproof AI не поставляет оценивающий сервис по умолчанию; логика оценки — ваша.

## Поиск и исправление ошибок

**Hook** (перехватчик)
Защитная мера или побочный эффект, который выполняет ваш фреймворк агентов на каждом шаге: проверка безопасности контента, редактирование PII, проверка бюджета. Хуки генерируют события `hook_triggered` / `hook_completed` с `outcome` (allow, deny, modify) и имеют собственную страницу наблюдения.

**Alert rule** (правило уведомления)
Правило, которое срабатывает, когда метрика пересекает установленный вами порог: коэффициент ошибок, p95 задержка, стоимость токенов или оценка оценивающего сервиса. Когда правило срабатывает, оно открывает инцидент и уведомляет выбранные вами каналы (email, Slack, webhook, внутридашборд). См. [Alerts](/ru/agenteye/alerts).

**Incident** (инцидент)
Открытая проблема, созданная при срабатывании правила уведомления. Инциденты имеют жизненный цикл (подтвердить, назначить, разрешить) и временную шкалу активности, которая записывает каждое действие. Вы также можете открыть инцидент вручную.

**Audit** (аудит)
Периодическое расследование (каждый час или неделю), которое анализирует ваши логи *между* сеансами в поиске шаблонов ошибок, которые вы ещё не описали правилом: кластеры ошибок, низкие оценки, выбросы задержки, циклы вызовов инструментов и незавершённые запуски. Где уведомление следит за метрикой, которую вы уже знаете, аудит подсказывает вам, на что обратить внимание дальше. См. [Audits](/ru/agenteye/audits).

**Finding** (вывод)
Один ранжированный, подкреплённый доказательствами результат запуска аудита. Вывод называет шаблон, ссылается на точные сеансы, которые за ним стоят, и имеет жизненный цикл сортировки (подтвердить, разрешить, скрыть, отклонить). Failproof AI Observability дедублирует выводы при каждом запуске аудита, так что известный шаблон обновляется вместо накопления.

**The AI assistant** (AI-помощник)
Чат внутри панели инструментов, который отвечает на вопросы об ваших агентах на обычном английском языке по вашим собственным данным. По умолчанию доступен только для чтения; что-либо, что он создаёт (сохранённый запрос, панель инструментов), требует одобрения, и он никогда ничего не удаляет. См. [AI assistant](/ru/agenteye/assistant).

## Запуск

**Organization (tenant)** (организация/тенант)
Изолированное рабочее пространство. Один экземпляр Failproof AI Observability может размещать много организаций, каждая со своими пользователями, ключами и данными. Каждый URL панели инструментов ограничен вашим слагом организации (`/<org-slug>/…`).

**Collector** (коллектор)
`agenteye-collector`, лёгкий демон, который работает на каждой машине агента, группирует события, которые SDK записывает на диск, и отправляет их на сервер.

**API key** (API-ключ)
Ограниченный токен, который аутентифицирует клиент на сервере. Ключи имеют детальные разрешения (например `events:add` для коллектора, области только для чтения для ключа панели инструментов). См. [API keys](/ru/agenteye/api-keys).

**Server** (сервер)
Служба приёма и API. Она принимает события, хранит операционное состояние в ваших базах данных и предоставляет панель инструментов и CLI.

**Dashboard** (панель инструментов)
Веб-интерфейс. Каждая страница ограничена организацией и осуществляет доступ через API сервера.
