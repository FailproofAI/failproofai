Превратите ваши данные агентов в реальном времени в единую картину, которую наблюдает вся команда. Закрепите нужные вам запросы в виде графиков, и каждый член команды видит одни и те же показатели с первого взгляда, без необходимости повторного запуска запросов.

![Панель мониторинга, созданная из сохраненных запросов: линейный график событий в час, столбчатая диаграмма ошибок по типам, график площади для задержки и разбор токенов по модели](/agenteye/images/dashboard-fleet.png)

*Одна панель, четыре сохраненных запроса: события в час, ошибки по типам, задержка и токены по модели.*

## Все видят одну истину

Прекратите делиться снимками экрана в чате и переставьте запускать один и тот же запрос по пять раз в день. Панель мониторинга — это общая, доступная для всей организации доска, которую любой член вашей команды может открыть и увидеть одно и то же представление. Когда базовые данные изменяются, графики обновляются вместе с ними, поэтому панель всегда актуальна и никто не спорит о устаревших цифрах.

Панель мониторинга выше — хорошая основа для повседневных операций:

- **линейный график событий в час**, чтобы вы могли отслеживать пропускную способность и заметить внезапное падение
- **столбчатая диаграмма ошибок по типам**, чтобы ваши основные категории сбоев выделялись
- **график площади задержки**, чтобы замедления появились до жалоб пользователей
- **разбор токенов по модели**, чтобы контролировать затраты

Ваши панели находятся по адресу `/<org-slug>/dashboards`.

## Закрепляйте уже сохраненные запросы

Каждая плитка начинается как сохраненный запрос. Постройте и сохраните нужный вам запрос в библиотеке [Запросы](/ru/agenteye/queries) (встроенные предустановки плюс ваши собственные по вашим событиям и оценкам), затем закрепите его на панели мониторинга в виде графика, который соответствует данным: **линия** для трендов во времени, **столбцы** для сравнения категорий, **область** для объема или **круг** для разбора доли.

Поскольку плитка — это просто ваш сохраненный запрос, отображаемый в виде графика, нет необходимости вручную что-то синхронизировать. Обновите запрос один раз, и каждая панель мониторинга, которая его использует, обновится автоматически.

## Следите за качеством, а не только за объемом

Объем показывает, что агенты работают. Качество показывает, что они действительно делают свою работу. Направьте панель мониторинга на ваши [оценки качества](/ru/agenteye/evaluations), и вы получите панель, которая отслеживает, насколько хорошо идут прогоны во времени, поэтому регрессия качества появится как падение на графике вместо неожиданного сюрприза от клиента.

![Панель мониторинга, ориентированная на качество, созданная из сохраненных запросов оценки](/agenteye/images/dashboard-quality.png)

*Панель качества держит оценки в центре внимания, прямо рядом с операционными показателями.*

Держите панель операций и панель качества рядом, и ваша команда получит одно место для ответа на оба вопроса: «это работает?» и «это хорошо?», без необходимости повторного запуска запросов.

## Связанное

- [Запросы](/ru/agenteye/queries): создавайте и сохраняйте запросы, которые становятся вашими плитками.
- [Оценки](/ru/agenteye/evaluations): оценивайте ваши прогоны, чтобы можно было отслеживать качество во времени.
- [Оповещения](/ru/agenteye/alerts): преобразуйте порог для любого из этих показателей в уведомление.
