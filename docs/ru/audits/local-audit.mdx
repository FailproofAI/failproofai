Локальная проверка читает историю агента, уже находящуюся на этой машине, и открывает результаты на `http://localhost:8020/audit`. Не требует учётной записи.

```bash
failproofai audit
```

Сканирование охватывает историю всех поддерживаемых harness-ей, найденных на машине. Оно переигрывает встроенный каталог из 39 политик этой версии; установленные пакеты и пользовательские политики не включаются.

## Чтение результата

Начните с наиболее частых находок, затем откройте затронутую сессию перед включением применения правил.

Три ограничения имеют значение:

- Проверка восстанавливает события инструментов, но не `Stop`, поэтому политики `require-*-before-stop` не появляются.
- Восемь проверок уровня "Только для аудита" выявляют неэффективные паттерны без точного совпадения с политикой.
- `warn-repeated-tool-calls` пропускается, потому что её переигрывание модифицировало бы состояние на стороне transcript.

Для применяемой находки используйте команду политики, показанную в результате. Перед использованием проверьте [поддержку применения правил harness-ем](/ru/reference/harnesses#enforcement-capability).

Кэшированный результат находится в `~/.failproofai/audit/dashboard.json` и истекает через семь дней.

## Планирование сканирований

```bash
failproofai audit --schedule 7
failproofai audit --status
failproofai audit --no-schedule
```

Интервал принимает значения от 1 до 90 дней и по умолчанию составляет 7 дней. Первоначальное планирование требует интерактивного входа. Фоновый сервис должен быть запущен.

### Что покидает машину

Интерактивная проверка не отправляет находки. Анонимная телеметрия CLI включена по умолчанию; отключите её с помощью `FAILPROOFAI_TELEMETRY_DISABLED=1`.

После согласия на планирование каждое запланированное сканирование отправляет ID машины, метку, платформу и окно сканирования. Если обнаружены вредоносные паттерны, оно также отправляет ограниченную сводку с количеством, временными метками и до трёх отредактированных примеров. Чистые сканирования не отправляют никаких находок и не отправляют письма.

<Warning>
  Результаты проверки — это доказательства для проверки, а не подтверждение того, что каждое отмеченное действие небезопасно. Проверьте сессию перед преобразованием находки в блокирующее применение правил.
</Warning>
