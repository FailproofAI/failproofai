Используйте локальный аудит для немедленного приватного анализа перед подключением машины к Failproof AI Cloud. Он сканирует истории агентов, уже сохраненные на вашей машине, воспроизводит активность инструментов через встроенные политики и открывает локальную панель результатов.

## Запустите интерактивный аудит

<Tabs>
  <Tab title="Dashboard">
    Локальный аудит запускается из CLI, так как он должен обнаружить истории на текущей машине. Выполните `failproofai audit`; после сканирования Failproof AI запустит встроенную панель и откроет **http://localhost:8020/audit**.

    В представлении аудита просмотрите количество сеансов, вызовов инструментов, проектов и срабатываний политик. Начните с часто встречающихся находок, затем проверьте затронутый проект и историю агента перед включением enforcement.

    <Info>Локальная панель аудита отделена от **Analyze → Audits** в Failproof AI Cloud. Локальные аудиты остаются на машине и не требуют учетной записи или подключения к сети.</Info>
  </Tab>
  <Tab title="CLI">
    ```bash
    npm install -g failproofai
    failproofai audit
    ```

    Команда выполняет полное сканирование каждой поддерживаемой истории, которую находит. Текущая команда не принимает фильтры вроде `--since`, `--cli`, `--project`, `--port` или `--no-open`.

    Держите процесс запущенным во время использования локальной панели. Нажмите <kbd>Ctrl</kbd>+<kbd>C</kbd> по завершении.
  </Tab>
</Tabs>

Текущие адаптеры аудита могут читать истории из Claude Code, Codex, GitHub Copilot CLI, Cursor, OpenCode, Pi, Hermes, OpenClaw, Factory, Devin, Antigravity и Goose. Сканируются только локально доступные истории.

## Планируйте повторяющиеся локальные аудиты

<Tabs>
  <Tab title="Dashboard">
    Откройте **Settings** в локальной панели, включите запланированные аудиты, выберите интервал и установите адрес электронной почты, на который должны приходить находки. Панель и CLI обновляют одну и ту же конфигурацию машины.
  </Tab>
  <Tab title="CLI">
    Включите еженедельный аудит и отправляйте находки на указанный адрес:

    ```bash
    failproofai audit --schedule 7 --email reliability@example.com
    failproofai audit --status
    ```

    Интервал принимает значения от 1 до 90 дней и по умолчанию равен 7, если не указано. При первой настройке требуется вход; `--email` предоставляет адрес отчета без запросов.

    Остановите расписание без удаления локальной истории аудита:

    ```bash
    failproofai audit --no-schedule
    ```
  </Tab>
</Tabs>

Демон запускает запланированные сканирования в фоновом режиме, обновляет кэшированный результат, используемый локальной панелью, и отправляет настроенный отчет по электронной почте. Используйте `failproofai audit`, когда хотите немедленно запустить интерактивное сканирование.

## Переход от локальных данных к облачным операциям

Локальный аудит — это быстрая базовая оценка. Подключите машину к Failproof AI Cloud, когда вам нужны общие трассировки, повторяющиеся аудиты популяции, находки и проблемы, оповещения, развертывание политик на уровне организации или управление парком машин.
