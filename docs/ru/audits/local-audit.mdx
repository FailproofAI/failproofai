Используйте локальный аудит для немедленной приватной проверки перед подключением машины к Failproof AI Cloud. Он сканирует истории агента, уже сохранённые на вашей машине, воспроизводит активность инструментов через встроенные политики и открывает локальную панель результатов.

## Запустите интерактивный аудит

<Tabs>
  <Tab title="Dashboard">
    Локальный аудит запускается из CLI, поскольку должен обнаружить истории на текущей машине. Выполните `failproofai audit`; после сканирования Failproof AI запустит встроенную панель и откроет **http://localhost:8020/audit**.

    В представлении аудита проверьте количество сеансов, вызовов инструментов, проектов и срабатываний политик. Начните с частых находок, затем проверьте затронутый проект и историю агента перед включением принудительного применения.

    <Info>Локальная панель аудита отделена от **Analyze → Audits** в Failproof AI Cloud. Локальные аудиты остаются на машине и не требуют учётной записи или сетевого подключения.</Info>
  </Tab>
  <Tab title="CLI">
    ```bash
    npm install -g failproofai
    failproofai audit
    ```

    Команда выполняет полное сканирование каждой найденной поддерживаемой истории. Текущая команда не принимает фильтры, такие как `--since`, `--cli`, `--project`, `--port` или `--no-open`.

    Оставляйте процесс работающим во время использования локальной панели. Нажмите <kbd>Ctrl</kbd>+<kbd>C</kbd> по завершении.
  </Tab>
</Tabs>

Текущие адаптеры аудита могут читать истории из Claude Code, Codex, GitHub Copilot CLI, Cursor, OpenCode, Pi, Hermes, OpenClaw, Factory, Devin, Antigravity и Goose. Сканируются только локально доступные истории.

## Планируйте повторяющиеся локальные аудиты

<Tabs>
  <Tab title="Dashboard">
    Откройте **Settings** в локальной панели, включите запланированные аудиты, выберите интервал и установите адрес электронной почты, который должен получать находки. Панель и CLI обновляют одну и ту же конфигурацию машины.
  </Tab>
  <Tab title="CLI">
    Включите еженедельный аудит и отправляйте находки на указанный адрес:

    ```bash
    failproofai audit --schedule 7 --email reliability@example.com
    failproofai audit --status
    ```

    Интервал принимает значения от 1 до 90 дней и по умолчанию равен 7, если не указан. Первая установка выполнит вход, если необходимо; `--email` предоставляет адрес отчёта без запроса.

    Остановите расписание без удаления локальной истории аудита:

    ```bash
    failproofai audit --no-schedule
    ```
  </Tab>
</Tabs>

Демон запускает запланированные сканирования в фоновом режиме, обновляет кэшированный результат, используемый локальной панелью, и отправляет сконфигурированный отчёт по электронной почте. Используйте `failproofai audit`, когда вы хотите запустить интерактивное сканирование сразу же.

## Перейдите от локальных доказательств к облачным операциям

Локальный аудит — это быстрая базовая оценка. Подключите машину к Failproof AI Cloud, когда вам нужны общие трассировки, повторяющиеся аудиты совокупности, находки и проблемы, оповещения, развёртывание политик на уровне организации или состояние флота.

<Warning>
  Выходные данные аудита — это доказательства для проверки, а не подтверждение того, что каждое отмеченное действие небезопасно. Подтвердите контекст перед тем, как превратить находку в принудительное применение.
</Warning>
