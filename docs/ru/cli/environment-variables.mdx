## Dashboard

| Переменная | Описание |
|----------|-------------|
| `PORT` | Порт dashboard (по умолчанию: `8020`) |
| `CLAUDE_PROJECTS_PATH` | Переопределить место, где находятся папки проектов Claude Code |
| `FAILPROOFAI_DISABLE_PAGES=policies,projects` | Страницы dashboard, разделённые запятыми, которые нужно скрыть |
| `FAILPROOFAI_ALLOWED_DEV_ORIGINS` | Хосты/IP-адреса, которым разрешен доступ к ресурсам разработки. Аналогично `--allowed-origins`. |

## Логирование

| Переменная | Описание |
|----------|-------------|
| `FAILPROOFAI_LOG_LEVEL=info\|warn\|error` | Уровень логирования сервера (по умолчанию: `warn`) |
| `FAILPROOFAI_HOOK_LOG_FILE` | Путь к пользовательскому файлу логов hook или `true` для стандартного (`~/.failproofai/logs/hooks.log`) |

## Телеметрия

failproofai по умолчанию отправляет анонимную телеметрию использования. Есть два способа отключить её, и будет применён более строгий из них — переменная окружения никогда не сможет переактивировать то, что был отключено в файле конфигурации.

| Переменная | Описание |
|----------|-------------|
| `FAILPROOFAI_TELEMETRY_DISABLED=1` | Отключить анонимную телеметрию использования для этого процесса |

Чтобы отключить её постоянно для машины, добавьте это в `~/.failproofai/config.toml`:

```toml
[telemetry]
enabled = false
```

<Note>
Файл конфигурации — это способ, который следует использовать, если вы запускаете **daemon failproofaid**.
Daemon — это системный сервис, и его окружение не включает переменные, экспортированные из вашей оболочки — поэтому `FAILPROOFAI_TELEMETRY_DISABLED` не сможет его достичь. `[telemetry] enabled = false` читается как CLI, так и daemon'ом.
</Note>

Daemon отправляет только свой **жизненный цикл**: что он запустился (и корректно ли завершился предыдущий запуск), что он остановился, когда был порожден или перезапущен его worker оценки, когда задача сборщика не удалась, и результат pull'а cloud-политики. Эти события содержат значения с низкой кардинальностью и счётчики — никогда путь к файлу, команду, политику, подсказку или что-либо прочитанное из транскрипта. Нет событий для каждого отдельного вызова инструмента.

## Аутентификация

| Переменная | Описание |
|----------|-------------|
| `FAILPROOF_API_URL` | Переопределить базовый URL api-сервера, используемый диалогом аутентификации dashboard. По умолчанию `https://api.befailproof.ai`; установите на `http://localhost:8080` (или где-либо ещё) при запуске локального api-сервера. |
| `FAILPROOFAI_AUTH_DIR` | Переопределить, где хранится `auth.json` (по умолчанию: `~/.failproofai`). В основном полезно для изолированных тестов. |

## Первый запуск

| Переменная | Описание |
|----------|-------------|
| `FAILPROOFAI_NO_FIRST_RUN=1` | Пропустить подсказку об установке политик при первом пустом вызове `failproofai` |

## LLM (для оценки политик)

| Переменная | Описание |
|----------|-------------|
| `FAILPROOFAI_LLM_BASE_URL` | Endpoint LLM API (по умолчанию: `https://api.openai.com/v1`) |
| `FAILPROOFAI_LLM_API_KEY` | Ключ API для политик на основе LLM |
| `FAILPROOFAI_LLM_MODEL` | Имя модели (по умолчанию: `gpt-4o-mini`) |
