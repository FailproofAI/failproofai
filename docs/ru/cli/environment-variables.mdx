## Dashboard

| Переменная | Описание |
|----------|-------------|
| `PORT` | Порт Dashboard (по умолчанию: `8020`) |
| `CLAUDE_PROJECTS_PATH` | Переопределить местоположение папок проектов Claude Code |
| `FAILPROOFAI_DISABLE_PAGES=policies,projects` | Разделённый запятыми список страниц Dashboard, которые нужно скрыть |
| `FAILPROOFAI_ALLOWED_DEV_ORIGINS` | Хосты/IP-адреса, разрешённые для доступа к ресурсам разработчика. Аналогично `--allowed-origins`. |

## Логирование

| Переменная | Описание |
|----------|-------------|
| `FAILPROOFAI_LOG_LEVEL=info\|warn\|error` | Уровень логирования сервера (по умолчанию: `warn`) |
| `FAILPROOFAI_HOOK_LOG_FILE` | Пользовательский путь к файлу логов hook, или `true` для пути по умолчанию (`~/.failproofai/logs/hooks.log`) |

## Телеметрия

failproofai по умолчанию отправляет анонимную телеметрию использования. Есть два способа отключить её, и применяется более строгий вариант — переменная окружения не может повторно включить то, что был отключено в файле конфигурации.

| Переменная | Описание |
|----------|-------------|
| `FAILPROOFAI_TELEMETRY_DISABLED=1` | Отключить анонимную телеметрию использования для этого процесса |

Чтобы отключить её навсегда для машины, добавьте это в `~/.failproofai/config.json`:

```json
{
  "telemetry": {
    "enabled": false
  }
}
```

<Note>
Файл конфигурации — это вариант, который нужно использовать, если вы запускаете **демон failproofaid**.
Демон — это системный сервис, и его окружение не включает переменные, экспортированные из вашей оболочки — поэтому `FAILPROOFAI_TELEMETRY_DISABLED` не может до него доходить. Параметр `[telemetry] enabled = false` читается и CLI, и демоном.
</Note>

Демон отправляет только свою **жизненный цикл**: что он запустился (и корректно ли завершилась предыдущая работа), что он остановился, когда был запущен или перезапущен его рабочий процесс оценки, когда задача сборщика не удалась, и результат получения облачной политики. Эти данные имеют низкую кардинальность значений и количества — никогда путь файла, команда, политика, подсказка или что-либо прочитанное из расшифровки. События по каждому вызову инструмента отсутствуют.

## Аутентификация

| Переменная | Описание |
|----------|-------------|
| `FAILPROOF_API_URL` | Переопределить базовый URL API-сервера, используемый диалогом аутентификации Dashboard. По умолчанию `https://api.befailproof.ai`; установите `http://localhost:8080` (или другой) при запуске локального api-сервера. |
| `FAILPROOFAI_AUTH_DIR` | Переопределить местоположение сохранения `auth.json` (по умолчанию: `~/.failproofai`). В основном полезно для изолированных тестов. |

## Приглашение при первом запуске

| Переменная | Описание |
|----------|-------------|
| `FAILPROOFAI_NO_FIRST_RUN=1` | Пропустить приглашение, которое предлагает установить политики при первом вызове `failproofai` |

## LLM (для оценки политик)

| Переменная | Описание |
|----------|-------------|
| `FAILPROOFAI_LLM_BASE_URL` | Endpoint LLM API (по умолчанию: `https://api.openai.com/v1`) |
| `FAILPROOFAI_LLM_API_KEY` | API ключ для политик, работающих на LLM |
| `FAILPROOFAI_LLM_MODEL` | Имя модели (по умолчанию: `gpt-4o-mini`) |
