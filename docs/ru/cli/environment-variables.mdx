## Dashboard

| Переменная | Описание |
|----------|-------------|
| `PORT` | Порт Dashboard (по умолчанию: `8020`) |
| `CLAUDE_PROJECTS_PATH` | Переопределить расположение папок проектов Claude Code |
| `FAILPROOFAI_DISABLE_PAGES=policies,projects` | Страницы dashboard, разделённые запятыми, которые нужно скрыть |
| `FAILPROOFAI_ALLOWED_DEV_ORIGINS` | Хосты/IP-адреса, которым разрешён доступ к ресурсам разработки. Аналогично `--allowed-origins`. |

## Логирование

| Переменная | Описание |
|----------|-------------|
| `FAILPROOFAI_LOG_LEVEL=info\|warn\|error` | Уровень логирования сервера (по умолчанию: `warn`) |
| `FAILPROOFAI_HOOK_LOG_FILE` | Пользовательский путь к файлу логов хуков или `true` для использования пути по умолчанию (`~/.failproofai/logs/hooks.log`) |

## Телеметрия

failproofai по умолчанию отправляет анонимную телеметрию использования. Существует два способа отключить её, и будет применено более ограничивающее значение — переменная окружения никогда не сможет повторно активировать функцию, которую отключил файл конфигурации.

| Переменная | Описание |
|----------|-------------|
| `FAILPROOFAI_TELEMETRY_DISABLED=1` | Отключить анонимную телеметрию использования для этого процесса |

Чтобы отключить её постоянно на компьютере, добавьте это в `~/.failproofai/config.toml`:

```toml
[telemetry]
enabled = false
```

<Note>
Файл конфигурации — это опция для использования, если вы запускаете **демон failproofaid**.
Демон является системным сервисом, и его окружение не включает переменные, экспортированные из вашей оболочки — поэтому `FAILPROOFAI_TELEMETRY_DISABLED` не может до него дойти. `[telemetry] enabled = false` читается как CLI, так и демоном.
</Note>

Демон отправляет только свой собственный **жизненный цикл**: что он запустился (и корректно ли завершился предыдущий запуск), что он остановился, когда был порожден или перезагружен его рабочий процесс оценки, когда задача сборщика не удалась, и результат загрузки облачной политики. Эти события несут низкомощные значения и счётчики — никогда пути к файлам, команды, политики, подсказки или что-либо из транскрипта. Не существует события для каждого вызова инструмента.

## Аутентификация

| Переменная | Описание |
|----------|-------------|
| `FAILPROOF_API_URL` | Переопределить базовый URL API-сервера, используемый диалогом аутентификации dashboard. По умолчанию `https://api.befailproof.ai`; установите `http://localhost:8080` (или другой адрес) при запуске локального api-сервера. |
| `FAILPROOFAI_AUTH_DIR` | Переопределить место хранения `auth.json` (по умолчанию: `~/.failproofai`). Главным образом полезно для изолированных тестов. |

## Приглашение при первом запуске

| Переменная | Описание |
|----------|-------------|
| `FAILPROOFAI_NO_FIRST_RUN=1` | Пропустить приглашение, которое предлагает установить политики при первом запуске команды `failproofai` без параметров |

## LLM (для оценки политик)

| Переменная | Описание |
|----------|-------------|
| `FAILPROOFAI_LLM_BASE_URL` | Конечная точка API LLM (по умолчанию: `https://api.openai.com/v1`) |
| `FAILPROOFAI_LLM_API_KEY` | Ключ API для политик на основе LLM |
| `FAILPROOFAI_LLM_MODEL` | Название модели (по умолчанию: `gpt-4o-mini`) |
