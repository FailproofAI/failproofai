---
title: Установка политик
description: "Включите политики, чтобы они выполнялись при каждом вызове инструмента агента"
---

```bash
failproofai policies --install [policy-names...] [options]
```

Записывает записи hook в файл настроек установленного CLI агента (Claude Code, OpenAI Codex или GitHub Copilot CLI _(beta)_), чтобы failproofai перехватывал вызовы инструментов.

Аббревиатуры: `failproofai p -i`

## Опции

| Флаг | Описание |
|------|----------|
| `--cli claude\|codex\|copilot` | CLI агента для установки; разделённые пробелом (напр. `--cli claude codex copilot`) или повторяющиеся. Опустите для автоматического обнаружения установленных CLI и подтверждения. |
| `--scope user` | Установить в файл настроек пользовательской области видимости (Claude: `~/.claude/settings.json`; Codex: `~/.codex/hooks.json`; Copilot: `~/.copilot/hooks/failproofai.json`). По умолчанию. |
| `--scope project` | Установить в файл настроек области видимости проекта (Claude: `<cwd>/.claude/settings.json`; Codex: `<cwd>/.codex/hooks.json`; Copilot: `<cwd>/.github/hooks/failproofai.json`). |
| `--scope local` | Только Claude — устанавливает в `<cwd>/.claude/settings.local.json`. Codex и Copilot не имеют область видимости `local`. |
| `--custom <path>` / `-c` | Путь к JS файлу, содержащему пользовательские политики hook |

## Поведение

- **Нет названий политик** - открывает интерактивный диалог для выбора политик
- **Конкретные названия** - включает эти политики (добавляет к уже включённым)
- **`all`** - включает все доступные политики

Установка является аддитивной: повторный запуск `--install` добавляет новые политики без удаления существующих.

## Примеры

```bash
# Установить все политики по умолчанию глобально (интерактивно)
failproofai policies --install

# Установить конкретные политики для текущего проекта
failproofai policies --install block-sudo sanitize-api-keys --scope project

# Включить все политики сразу
failproofai policies --install all

# Установить с пользовательским файлом политик
failproofai policies --install --custom ./my-policies.js

# Установить для OpenAI Codex (область видимости проекта)
failproofai policies --install --cli codex --scope project

# Установить для GitHub Copilot CLI (beta) для текущего проекта
failproofai policies --install --cli copilot --scope project

# Установить для всех трёх CLI одновременно
failproofai policies --install --cli claude codex copilot
```

Когда указан `--custom <path>`, файл проверяется сразу — он должен вызвать `customPolicies.add()` хотя бы один раз. Разрешённый путь сохраняется в `policies-config.json` как `customPoliciesPath`.
