Оценка Jev читает **завершённую сессию** и выставляет оценку от 0 до 1. Используйте её, когда ответ известен заранее, например «Выразил ли клиент срочность?» или «Насколько был разочарован клиент?» Это помогает найти закономерности в нескольких запусках; оценка не останавливает вызов инструмента. Для решений, принимаемых **до** запуска инструмента, используйте [Jev политики](/ru/policies/jev).

## Создать одну на панели управления

1. Откройте **Analyze → eval authoring** и выберите **new eval**.
2. Опишите один вопрос и его возможные ответы. Например: «Пообещал ли агент возврат средств перед проверкой политики возврата? Ответьте да или нет.» Выберите **draft** и проверьте, что результат — это оценка классификатора.
3. [Протестируйте её](/ru/evaluations/test) на недавних сессиях, затем [разверните](/ru/evaluations/deploy). Новые завершённые сессии будут оценены; [заполните историю](/ru/evaluations/deploy#score-sessions-you-already-have), если вам также нужна предыдущая история.

Ассистент может выбрать между кодом, классификацией Jev и [судьёй](/ru/evaluations/judge). Проверьте его выбор перед развёртыванием. Jev выставляет оценку без словесного обоснования; выберите судью, если вам нужно объяснение. Смотрите [справочник оценок Jev](/ru/reference/jev-evaluations) для типов вопросов и ограничений оценок.

## Прочитайте оценки

Откройте **Observe → Evaluations** для отображения результата по агенту и времени. Из терминала Cloud CLI может прочитать те же результаты:

```bash
fp evals --since 7d
fp evals --aggregate --since 7d
```

Cloud CLI читает результаты; разработка и развёртывание происходят на панели управления. Смотрите [справочник Cloud CLI](/ru/reference/cloud-cli#evaluations) для фильтров.
