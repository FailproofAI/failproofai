Jev-оценка читает **завершённую сессию** и выдаёт оценку от 0 до 1. Используйте её, когда ответ известен заранее, например "Выразил ли клиент срочность?" или "Насколько разочарован был клиент?" Это помогает найти закономерности между запусками; оценка не останавливает вызов инструмента. Для решений, принимаемых **до** запуска инструмента, используйте [Jev policies](/ru/policies/jev).

## Создайте оценку на панели

1. Откройте **Analyze → eval authoring** и выберите **new eval**.
2. Опишите один вопрос и его возможные ответы. Например: "Пообещал ли агент возврат средств перед проверкой политики возврата? Ответьте да или нет." Выберите **draft** и проверьте, что результат — это оценка классификатора.
3. [Протестируйте её](/ru/evaluations/test) на недавних сессиях, затем [разверните](/ru/evaluations/deploy). Новые завершённые сессии будут оценены; [заполните историю](/ru/evaluations/deploy#score-sessions-you-already-have), если вам также нужны прошлые данные.

Ассистент может выбирать между кодом, классификацией Jev и [судьёй](/ru/evaluations/judge). Проверьте его выбор перед развёртыванием. Jev выдаёт оценку без пространного обоснования; выбирайте судью, когда вам нужно объяснение. Сведения о типах вопросов и пределах оценок см. в [справочнике Jev-оценок](/ru/reference/jev-evaluations).

## Прочитайте оценки

Откройте **Observe → Evaluations** для отображения результата по агентам и времени. Из терминала Cloud CLI может прочитать те же результаты:

```bash
fp evals --since 7d
fp evals --aggregate --since 7d
```

Cloud CLI читает результаты; авторство и развёртывание происходят на панели. Сведения о фильтрах см. в [справочнике Cloud CLI](/ru/reference/cloud-cli#evaluations).
