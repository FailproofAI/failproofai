Jev evaluation анализирует **завершённую сессию** и выставляет оценку от 0 до 1. Используйте его, когда ответ известен заранее, например: «Выразил ли клиент срочность?» или «Насколько клиент был расстроен?» Это помогает найти закономерности между запусками; он не останавливает вызов инструмента. Для решений, принимаемых **до** запуска инструмента, используйте [Jev policies](/ru/policies/jev).

## Создание в панели управления

1. Откройте **Analyze → eval authoring** и выберите **new eval**.
2. Опишите один вопрос и его возможные ответы. Например: «Обещал ли агент возврат денег перед проверкой политики возврата? Ответьте да или нет.» Выберите **draft** и проверьте, что результат — это оценка классификатора.
3. [Протестируйте его](/ru/evaluations/test) на недавних сессиях, затем [разверните](/ru/evaluations/deploy). Новые завершённые сессии получат оценку; [заполните историю](/ru/evaluations/deploy#score-sessions-you-already-have), если вам также нужны прошлые данные.

![Форма авторинга общего eval, где вы описываете вопрос с фиксированным ответом, просматриваете черновик и развёртываете после тестирования. Показанный пример — это оценка кода; Jev вопрос использует тот же рабочий процесс авторинга.](/images/dashboard/eval-authoring-draft.png)

Ассистент может выбрать между кодом, классификацией Jev и [judge](/ru/evaluations/judge). Проверьте его выбор перед развёртыванием. Jev выставляет оценку без подробного обоснования; выбирайте judge, когда вам нужно объяснение. См. [справочник Jev evaluation](/ru/reference/jev-evaluations) по типам вопросов и пределам оценок.

## Просмотр оценок

Откройте **Observe → Evaluations**, чтобы отобразить результат по агенту и времени. Из терминала Cloud CLI может прочитать те же результаты:

```bash
fp evals --since 7d
fp evals --aggregate --since 7d
```

Cloud CLI читает результаты; авторинг и развёртывание происходят в панели управления. Для фильтров см. [справочник Cloud CLI](/ru/reference/cloud-cli#evaluations).
