Добавьте полный справочник Failproof AI в свой coding agent одной командой. Работает с Claude Code, Cursor, Windsurf и любым другим агентом, поддерживающим skills.

```bash
npx skills add https://docs.befailproof.ai
```

`npx skills` автоматически определяет, какие агенты установлены, и добавляет skill в правильном формате для каждого.

## Что включает skill

| Область | Содержимое |
|---------|-----------|
| Политики | Встроенные имена политик, типы событий, параметры, включение/отключение |
| Пользовательские политики | `customPolicies.add()`, фильтры соответствия, API `allow`/`deny`/`instruct` |
| Объект контекста | `ctx.eventType`, `ctx.toolName`, `ctx.toolInput`, `ctx.session` |
| Конфигурация | Структура `policies-config.json`, объединение scopes, `policyParams` |
| CLI | `failproofai policies --install`, `--uninstall`, `--custom`, scopes |
| Dashboard | Просмотр сессий, активность политик, переменные окружения |
| Архитектура | Поток обработчика hooks, коды выхода, контракт stdin/stdout |

## Skill полный?

Mintlify генерирует `llms.txt` из всех страниц в навигации. Документация Failproof AI охватывает полный API — каждая политика, опция и пример включены. Если вы найдёте что-то пропущенное, источник находится по адресу `https://docs.befailproof.ai/llms-full.txt`.

Для целевого контекста ссылайтесь непосредственно на конкретную страницу:

```bash
# Только API пользовательских политик
npx skills add https://docs.befailproof.ai/custom-policies

# Только встроенные политики
npx skills add https://docs.befailproof.ai/built-in-policies
```
