Добавьте полную справку Failproof AI в вашего кодирующего агента одной командой. Совместимо с Claude Code, Cursor, Windsurf и любыми другими агентами, поддерживающими skills.

```bash
npx skills add https://docs.befailproof.ai
```

`npx skills` автоматически определяет установленные у вас агенты и добавляет skill в правильном формате для каждого.

## Что включает skill

| Область | Содержимое |
|---------|-----------|
| Политики | Встроенные имена политик, типы событий, параметры, включение/отключение |
| Пользовательские политики | `customPolicies.add()`, фильтры совпадения, API `allow`/`deny`/`instruct` |
| Объект контекста | `ctx.eventType`, `ctx.toolName`, `ctx.toolInput`, `ctx.session` |
| Конфигурация | Структура `policies-config.json`, слияние областей, `policyParams` |
| CLI | `failproofai policies --install`, `--uninstall`, `--custom`, области |
| Панель управления | Просмотр сессий, активность политик, переменные окружения |
| Архитектура | Поток обработчика hook, коды выхода, контракт stdin/stdout |

## Полный ли skill?

Mintlify генерирует `llms.txt` со всех страниц навигации. Документация Failproof AI охватывает полный API — каждая политика, опция и пример включены. Если вы найдёте что-то отсутствующее, источник находится в `https://docs.befailproof.ai/llms-full.txt`.

Для целевого контекста ссылайтесь напрямую на конкретную страницу:

```bash
# Только API пользовательских политик
npx skills add https://docs.befailproof.ai/custom-policies

# Только встроенные политики
npx skills add https://docs.befailproof.ai/built-in-policies
```
