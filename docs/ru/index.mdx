Failproof AI помогает всем, кто запускает агентов, понять, что произошло, найти сбои и предотвратить их повторение.

Он работает с 12 распространенными окружениями для агентов, включая Claude Code, Codex, Hermes, OpenClaw и Goose. Агенты, построенные с использованием LangChain, CrewAI, LlamaIndex, Pydantic AI или собственной среды выполнения, могут отправлять отчеты через [Python SDK](/ru/reference/custom-agents).

## Запустите локально или подключитесь к облаку

<Columns cols={2}>
  <Card title="Локально, без учетной записи" icon="laptop" href="/ru/audits/local-audit">
    Откройте панель мониторинга на `localhost:8020` и запустите `failproofai audit`. История ваших агентов остается на этой машине.
  </Card>
  <Card title="Failproof AI Cloud" icon="cloud" href="/ru/start/setup">
    Просматривайте сеансы с разных машин и управляйте политиками для вашей команды.
  </Card>
</Columns>

Установка намеренно не выбирает пакет политик. Добавьте наш после установки:

```bash
failproofai policies add FailproofAI/policies
```

До этого момента работает только `block-failproofai-commands`. Она предотвращает отключение агентом Failproof AI.
