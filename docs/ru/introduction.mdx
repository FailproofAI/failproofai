Хуки и политики для **обработки ошибок AI**, **восстановления после сбоев** и **надёжности LLM**. Держите ваших AI агентов надёжными и работающими автономно через **Claude Code**, **OpenAI Codex**, **GitHub Copilot**, **Cursor Agent**, **OpenCode**, **Pi**, **Hermes**, **OpenClaw**, **Factory Droid**, **Devin CLI**, **Antigravity CLI** и **Agents SDK**.

AI агенты отказывают предсказуемым образом. Они выполняют деструктивные команды, раскрывают секреты, отвлекаются от задачи, застревают в циклах или толкают коммиты напрямую в main. Без присмотра небольшие ошибки перерастают в сбои, утечки учётных данных и потерю работы.

FailproofAI решает это благодаря **политикам**. Эти правила подключаются к каждому вызову инструмента агента для **обнаружения ошибок**, **их смягчения** (блокировка, инструкция, санитизация) и **оповещения вас**, когда что-то требует внимания. Локальная панель мониторинга позволяет просмотреть каждый вызов инструмента, ошибку агента и действие восстановления впоследствии.

Транскрипты и оценка политик остаются на вашей машине. Данные отправляются только когда вы явно используете онлайн-функцию, например аутентифицированные напоминания об аудите или приглашения.

## Быстрый старт

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # включить политики (или пропустить — `failproofai` предложит настроить их при первом запуске)
failproofai                      # запустить панель мониторинга
```

Смотрите руководство [Начало работы](/ru/getting-started) для полного пошагового руководства.
