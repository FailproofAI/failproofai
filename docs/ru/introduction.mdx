Хуки и политики для **обработки сбоев AI**, **восстановления после ошибок** и **надежности LLM**. Держите ваших AI агентов надежными и работающими автономно через **Claude Code**, **OpenAI Codex**, **GitHub Copilot**, **Cursor Agent**, **OpenCode**, **Pi**, **Hermes**, **OpenClaw**, **Factory Droid**, **Devin CLI**, **Antigravity CLI** и **Agents SDK**.

AI агенты выходят из строя предсказуемыми способами. Они выполняют деструктивные команды, раскрывают секреты, отвлекаются от задачи, застревают в циклах или отправляют напрямую в main. Без присмотра небольшие сбои могут привести к массовым отказам, утечкам учетных данных и потерям работы.

FailproofAI решает эту проблему с помощью **политик**. Эти правила подключаются к каждому вызову инструмента агента, чтобы **обнаруживать сбои**, **смягчать их** (блокировать, инструктировать, санировать) и **предупреждать вас**, когда требуется внимание. Локальная панель управления позволяет позже просмотреть каждый вызов инструмента, сбой агента и действия восстановления.

Транскрипты и оценка политик остаются на вашем компьютере. Данные отправляются только при явном использовании онлайн-функции, например аутентифицированных напоминаний об аудите или приглашений.

## Краткое начало

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # включить политики (или пропустить — `failproofai` предложит их установить при первом запуске)
failproofai                      # запустить панель управления
```

Полный пошаговый процесс см. в руководстве [Начало работы](/ru/getting-started).
