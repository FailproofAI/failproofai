Хуки и политики для **обработки сбоев AI**, **восстановления после ошибок** и **надёжности LLM**. Делайте ваши AI агенты надёжными и работающими автономно в **Claude Code**, **OpenAI Codex**, **GitHub Copilot**, **Cursor Agent**, **OpenCode**, **Pi**, **Hermes**, **OpenClaw**, **Factory Droid**, **Devin CLI**, **Antigravity CLI** и **Agents SDK**.

AI агенты дают сбой предсказуемым образом. Они выполняют деструктивные команды, раскрывают секреты, отклоняются от задачи, застревают в циклах или делают push прямо в main. Без контроля небольшие сбои превращаются в аварии, утечки учётных данных и потерю работы.

FailproofAI решает эту проблему с помощью **политик**. Эти правила встраиваются в каждый вызов инструмента агента, чтобы **обнаружить сбои**, **смягчить их** (заблокировать, указать, очистить) и **оповестить вас**, когда требуется внимание. Локальная панель управления позволяет просмотреть каждый вызов инструмента, сбой агента и действие восстановления впоследствии.

Стенограммы и оценка политик остаются на вашем компьютере. Данные отправляются только при явном использовании онлайн-функции, такой как напоминания об аудите с аутентификацией или приглашения.

## Быстрый старт

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # включить политики (или пропустить — `failproofai` предложит их настроить при первом запуске)
failproofai                      # запустить панель управления
```

Полное руководство см. в [Начало работы](/ru/getting-started).
