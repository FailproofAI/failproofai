## Официальный пакет

Основной пакет npm — это **`failproofai`**:

```bash
npm install -g failproofai
# или
bun add -g failproofai
```

---

## Почему мы владеем этими псевдонимами

Typosquatting — это распространённая атака на цепь поставок, при которой злоумышленник регистрирует имя пакета, которое отличается от популярного пакета на одно нажатие клавиши. Пользователи, которые случайно опечатаются при вводе команды установки, запускают код, контролируемый злоумышленником, с полным доступом к системе — именно такую угрозу призвана предотвращать Failproof AI.

Чтобы исключить эту уязвимость, **мы заблаговременно регистрируем все распространённые опечатки и варианты написания** `failproofai` на npm. Никакая третья сторона не может зарегистрировать эти имена. Каждое из них — это тонкий прокси, который устанавливает и делегирует работу реальному пакету `failproofai`.

## Зарегистрированные псевдонимы

**Варианты написания** — разные способы написания "failproof ai":

| Пакет | Статус |
|---------|--------|
| `failproof` | ✅ Опубликован |
| `failproof-ai` | ⏳ Ожидание поддержки npm |
| `fail-proof-ai` | ⏳ Ожидание поддержки npm |
| `failproof_ai` | ⏳ Ожидание поддержки npm |
| `fail_proof_ai` | ⏳ Ожидание поддержки npm |
| `fail-proofai` | ⏳ Ожидание поддержки npm |

**Опечатки `failprof*`** — отсутствует одна буква `o` в слове "proof":

| Пакет | Статус |
|---------|--------|
| `failprof` | ✅ Опубликован |
| `failprof-ai` | ✅ Опубликован |
| `failprofai` | ⏳ Ожидание поддержки npm |
| `fail-prof-ai` | ⏳ Ожидание поддержки npm |
| `failprof_ai` | ⏳ Ожидание поддержки npm |

**Опечатки `faliproof*`** — буквы `a` и `i` поменяны местами:

| Пакет | Статус |
|---------|--------|
| `faliproof` | ✅ Опубликован |
| `faliproof-ai` | ✅ Опубликован |
| `faliproofai` | ⏳ Ожидание поддержки npm |

> **Почему ожидание?** Политика npm по борьбе со спамом блокирует имена, которые нормализуются в одну и ту же строку с существующим пакетом после удаления пунктуации и проверки схожести. Мы обратились в поддержку npm для резервирования этих имён в целях защиты от typosquatting. Они будут активированы после одобрения.

Вы можете проверить, что любой опубликованный псевдоним принадлежит нам:

```bash
npm info failproof
# Найдите: "ExosphereHost Inc." в поле maintainers
```

## Как работают псевдонимы

Каждый пакет-псевдоним:

1. Указывает `failproofai` как зависимость — таким образом устанавливается реальный пакет и его бинарный файл становится доступным
2. Предоставляет бинарный файл с его собственным именем (например `failprof-ai`), который передаёт все аргументы бинарному файлу `failproofai`

Прокси — это двухстрочный скрипт Node.js; в нём нет никакой логики, сетевых вызовов и сбора данных сверх того, что делает сам `failproofai`.
