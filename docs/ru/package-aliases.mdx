## Официальный пакет

Канонический npm пакет — это **`failproofai`**:

```bash
npm install -g failproofai
# или
bun add -g failproofai
```

---

## Почему мы владеем альтернативными именами

Typosquatting (регистрация пакетов с похожими названиями) — это распространённая атака на цепочку поставок, при которой злоумышленник регистрирует имя пакета, отличающееся на один символ от популярного пакета. Невнимательные пользователи, которые ошибутся при вводе команды установки, случайно запустят контролируемый злоумышленником код с полным доступом к системе — именно такого рода угроз призвана защищать Failproof AI.

Чтобы устранить эту уязвимость, **мы проактивно владеем всеми распространёнными опечатками и вариантами форматирования** `failproofai` на npm. Никто из третьих лиц не может зарегистрировать эти имена. Каждое из них — это тонкий прокси, который устанавливает и делегирует работу настоящему пакету `failproofai`.

## Зарегистрированные альтернативные имена

**Варианты форматирования** — разные способы написания «failproof ai»:

| Пакет | Статус |
|---------|--------|
| `failproof` | ✅ Опубликован |
| `failproof-ai` | ⏳ Ожидает поддержки npm |
| `fail-proof-ai` | ⏳ Ожидает поддержки npm |
| `failproof_ai` | ⏳ Ожидает поддержки npm |
| `fail_proof_ai` | ⏳ Ожидает поддержки npm |
| `fail-proofai` | ⏳ Ожидает поддержки npm |

**Опечатки `failprof*`** — пропущена одна буква `o` в слове «proof»:

| Пакет | Статус |
|---------|--------|
| `failprof` | ✅ Опубликован |
| `failprof-ai` | ✅ Опубликован |
| `failprofai` | ⏳ Ожидает поддержки npm |
| `fail-prof-ai` | ⏳ Ожидает поддержки npm |
| `failprof_ai` | ⏳ Ожидает поддержки npm |

**Опечатки `faliproof*`** — перестановка букв `a` и `i`:

| Пакет | Статус |
|---------|--------|
| `faliproof` | ✅ Опубликован |
| `faliproof-ai` | ✅ Опубликован |
| `faliproofai` | ⏳ Ожидает поддержки npm |

> **Почему ожидание?** Политика npm по борьбе со спамом блокирует имена, которые после нормализации (удаления пунктуации и проверки схожести) совпадают с существующим пакетом. Мы обратились в поддержку npm для резервирования этих имен в целях защиты от typosquatting. Они будут активированы после одобрения.

Вы можете проверить, что любой опубликованный альтернативный пакет принадлежит нам:

```bash
npm info failproof
# Ищите: "ExosphereHost Inc." в поле maintainers
```

## Как работают альтернативные имена

Каждый альтернативный пакет:

1. Указывает `failproofai` в качестве зависимости — так что настоящий пакет устанавливается и его двоичный файл становится доступным
2. Предоставляет двоичный файл с именем, совпадающим с названием пакета (например, `failprof-ai`), который проксирует все аргументы к двоичному файлу `failproofai`

Прокси — это двухстрочный скрипт Node; здесь нет логики, сетевых запросов и сбора данных, выходящих за рамки того, что делает сам `failproofai`.
