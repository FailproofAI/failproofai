Разверните проверенную политику на одной машине за раз. Начните с режима наблюдения.

## Развертывание из CLI

```bash
fp policies test ./rule.mjs --tool Bash --command "git push --force" --expect deny
fp policies publish no-force-push ./rule.mjs
fp fleet deploy <machine> --add no-force-push:observe
fp guardrails summary --since 24h --machine <machine>
fp fleet deploy <machine> --add no-force-push:enforce
```

Режим наблюдения оценивает реальную политику и записывает решения, отличные от allow, но не блокирует агента.

<Warning>
  Простой `--add no-force-push` обеспечивает исполнение немедленно. Добавьте `:observe` для развертывания в тени.
</Warning>

Если исполнение вызывает проблемы:

```bash
fp fleet history <machine>
fp fleet rollback <machine> <generation>
```

## Развертывание из панели управления

1. Перейдите в **Admin → enforcement**.
2. Откройте целевую машину.
3. Добавьте версию политики с эффектом **observe**.
4. Примените развертывание.
5. Просмотрите результаты в разделе **Observe → policy**.
6. Повысьте уровень той же версии до **enforce**, когда совпадения будут правильными.

## Замена или предварительное размещение набора

- `--remove <id>` удаляет одну политику.
- `--set <ref>...` заменяет полный набор политик.
- `--create` подготавливает развертывание до первой регистрации машины.
- `fp fleet diff <machine>` сравнивает желаемое и применённое состояние.

<Note>
  Без Cloud опубликуйте пакет с помощью `failproofai publish --effect observe` и проверьте решения на локальной панели управления.
</Note>

Машинам необходимо `policies:pull` для получения развертываний и `events:add` для отчёта о решениях.
