Покрытие парка сравнивает то, что Cloud назначил, с тем, что каждая машина последний раз применила.

## Проверить машину

```bash
failproofai config --status
failproofai flush --wait --timeout 120
```

Из Cloud:

```bash
fp fleet list
fp fleet diff
fp fleet show <machine-id>
```

Для `fp fleet` требуется авторизованная сессия, а не API ключ.

| Команда | Что она делает |
| --- | --- |
| `fp fleet list` | Вывести список машин и статус развертывания |
| `fp fleet show <machine>` | Показать набор политик одной машины |
| `fp fleet deploy <machine> --add <ref>` | Добавить или обновить одну политику |
| `fp fleet deploy <machine> --remove <id>` | Удалить одну политику |
| `fp fleet deploy <machine> --set <ref>...` | Заменить весь набор |
| `fp fleet diff [machine]` | Сравнить предусмотренные и примененные версии |
| `fp fleet history <machine>` | Вывести список поколений развертывания |
| `fp fleet rollback <machine> <generation>` | Восстановить поколение |
| `fp fleet rename <machine> "<label>"` | Изменить метку в Cloud |

<Warning>
  `--set` заменяет полный набор политик. Простой `--add <id>` немедленно применяет новую политику. Используйте `--add <id>:observe` для теневого развертывания.
</Warning>

## Наблюдать, затем применить

```bash
fp fleet deploy ci-runner-01 --add prod-guard:observe
fp guardrails summary --since 24h --machine ci-runner-01
fp fleet deploy ci-runner-01 --add prod-guard:enforce
```

Режим наблюдения вычисляет реальную политику и записывает решения, отличные от разрешения, без блокировки агента.

## Идентификация машины

ID машины стабилен и идентифицирует машину. Метка предназначена только для отображения и может меняться:

```bash
failproofai config --machine-label checkout-runner-03
fp fleet rename <machine-id> "Checkout runner 03"
```

Изменение метки не переподключает и не переключает ключи машины.
