Используйте scope для определения получателей локальной политики:

| Scope | Применяется к |
| --- | --- |
| `user` | Ваши поддерживаемые агенты на этой машине |
| `project` | Агенты, работающие в этом проекте |
| `local` | Только Claude в локальных настройках проекта |
| `all` | Только для удаления |

```bash
failproofai policies add block-sudo --scope user
failproofai policies add block-rm-rf --scope project
```

Hermes и OpenClaw поддерживают только user scope. Большинство других harnesses поддерживают user и project. Claude также поддерживает local scope. См. [Harnesses](/ru/reference/harnesses).

## Параметры политик

Параметры политик находятся в файле `policies-config.json` в соответствующей области действия. По возможности используйте представление **Policies → Configure** локальной панели управления.

Параметр принадлежит одной политике и изменяет способ её принятия решения. Например, список разрешённых элементов может заставить блокирующую политику принять известные безопасные команды или пути.

Файлы пользовательских политик можно загружать автоматически из `.failproofai/policies/` или явно:

```bash
failproofai policies -i -c ./guards.mjs --scope project
```

Удалите явные пути с помощью:

```bash
failproofai policies -u -c
```

## Файлы

| Файл | Назначение |
| --- | --- |
| `~/.failproofai/config.json` | Параметры машины и сборщика |
| `policies-config.json` | Включённые политики и параметры для области действия |
| `.failproofai/policies/*policies.mjs` | Политики, загруженные по соглашению |
| `~/.failproofai/policies/packs/installed.json` | Установленные пакеты и выборки |

Не редактируйте артефакты установленных пакетов напрямую. Переустановите или опубликуйте исправленный релиз.
