Набор политик — это версионированный набор политик, опубликованный как открытый релиз GitHub. Пакет поставляется без собственного набора; установите наш как любой другой:

```bash
failproofai policies show FailproofAI/policies
failproofai policies add FailproofAI/policies
```

`show` читает манифест без запуска кода набора.

## Выбор того, что устанавливать

```bash
failproofai policies add owner/repo --policy block-refunds
failproofai policies add owner/repo --category billing,git
failproofai policies add owner/repo --all
```

Без выбора набор использует значения по умолчанию издателя. Повторная добавка более новой версии сохраняет существующий выбор.

Всё, что содержит слеш, — это источник набора. Всё, что без слеша, — это имя политики.

## Закрепление релиза

| Источник | Результат |
| --- | --- |
| `owner/repo` | Самая свежая версия, закреплена после разрешения |
| `owner/repo@a1b2c3d4e5f6` | Точный релиз на основе коммита |
| `owner/repo@v2.1.0` | Точный именованный релиз |
| URL релиза GitHub | Релиз по этому URL |

Набор обычно использует 12-символьный хеш коммита SHA, на основе которого он был собран. Используйте `failproofai policies show owner/repo --releases` для просмотра порядка релизов.

## Управление установленными наборами

```bash
failproofai policies
failproofai policies remove block-refunds
failproofai policies add block-refunds
failproofai policies remove owner/repo
```

Если два установленных набора содержат политику с одинаковым именем, CLI отказывает в использовании неоднозначного имени. Выберите политику через один набор или удалите другой набор.

## Безопасность и доступность

Каждый релиз содержит манифест, упакованный код политики и контрольные суммы. Failproof AI проверяет записанный дайджест перед загрузкой. Контрольные суммы доказывают совпадение байтов с релизом; они не доказывают, кто его опубликовал.

Выбранный набор, который не может загрузиться, отказывает для событий, которые он объявил. См. [поведение сбоя политики](/ru/policies/failure-behavior).

| Переменная | Эффект |
| --- | --- |
| `FAILPROOFAI_NO_DOWNLOAD=1` | Отказать в новых загрузках; установленные наборы продолжают работать |
| `FAILPROOFAI_PACK_BASE_URL` | Использовать зеркало |
| `FAILPROOFAI_PACK_DIR` | Переместить хранилище наборов |

Просмотрите наборы в [Policy Hub](https://befailproof.ai/policy-hub/) или [опубликуйте свой](/ru/policies/publish-a-pack).
