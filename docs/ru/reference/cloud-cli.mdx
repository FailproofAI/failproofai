Используйте `fp` для проверки телеметрии Cloud и управления аудитами, выводами, проблемами, оповещениями, ключами, пользователями, запросами и параметрами. Используйте [`failproofai`](/ru/reference/failproof-cli) для локальных хуков, политик, захвата и регистрации машин.

Установите выпущенный Cloud CLI как изолированный инструмент:

```bash
uv tool install fp-cli
fp version
```

## Вход в систему

```bash
fp login
fp whoami
```

## Синтаксис

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

Глобальные параметры должны предшествовать команде:

```bash
fp --json sessions --since 24h
```

Запустите `fp COMMAND --help` или `fp COMMAND SUBCOMMAND --help` для справки в терминале.


### События

```text
fp events [OPTIONS]
```

Список отдельных событий агента. Лёгкая лента по умолчанию исключает необработанные данные; используйте `--full` только для ограниченного расследования.

| Параметр | Описание |
| --- | --- |
| `--limit`, `-n <n>` | Максимальное количество строк. По умолчанию: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h` или `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | Диапазон ISO 8601 UTC; переопределяет `--since`. |
| `--env <value>` | Фильтр окружения; повторяйте или разделяйте запятыми значения. |
| `--event-type <value>` | Фильтр типа события; повторяйте или разделяйте запятыми значения. |
| `--agent-id <value>` | Фильтр агента; повторяйте или разделяйте запятыми значения. |
| `--session-id <value>` | Фильтр сеанса; повторяйте или разделяйте запятыми значения. |
| `--search <text>` | Поиск текста данных; повторяемый, совпадает любой термин. |
| `--order asc\|desc` | Временной порядок. По умолчанию: новейшие первыми. |
| `--all` | Автоматическая пагинация до `--limit`. |
| `--cursor <token>` | Возобновить с непрозрачного курсора. |
| `--page-size <n>` | Строк за запрос с `--all`; максимум `200`. |
| `--full` | Включить необработанные данные через более тяжёлую конечную точку событий. |
| `--fields <csv>` | Возвращать только выбранные поля; запрос `payload` включает полный режим. |

```bash
fp events --session-id <session-id> --order asc --all
fp --json events --full --session-id <session-id> --all
```

| Команда | Назначение | Параметры |
| --- | --- | --- |
| `fp keys list` | Список ключей организации. | `--show-id`; `--fields <csv>` |

#### Параметры create аудита

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| Параметр | Описание |
| --- | --- |
| `--file <path>` | Основать определение на JSON или использовать `-` для stdin. Явные флаги переопределяют значения файла. |
| `--description <text>` | Укажите вопрос отказа или цель. |
| `--enabled` / `--disabled` | Начать расписание включённым или выключённым. По умолчанию: включено. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. По умолчанию: `86400`. |
| `--schedule-anchor <timestamp>` | Фиксированная фаза UTC в формате ISO 8601. По умолчанию: следующий 09:00 UTC. |
| `--window-mode since_last\|fixed` | Продолжить после последнего полностью проанализированного окна или повторно проверить скользящее окно. По умолчанию: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. По умолчанию: `604800`. |
| `--scope '<json>'` | Фильтр по `environments`, `agent_ids` или другим поддерживаемым полям области. |
| `--ignore-error-type <type>` | Исключить типы ошибок; повторяйте или разделяйте запятыми. |
| `--llm` / `--no-llm` | Включить или отключить анализ агентом. По умолчанию: включено. |
| `--top-k <n>` | Сохранить `1`–`500` выводов. По умолчанию: `50`. |
| `--sensitivity low\|medium\|high` | Установить чувствительность отчётов. По умолчанию: `medium`. |
| `--channels '<json>'` | Массив канала уведомлений. |
| `--text <brief>` | Встроенное краткое описание, максимум 8192 символа. |
| `--text-file <path>` | Прочитать краткое описание из файла; взаимно исключающий с `--text`. |
| `--url <https-url>` | Добавить открытую справочную ссылку HTTPS; повторите до пяти раз. |

Включите контекст во время создания, если первый запуск его требует. Создание фиксирует определение и контекст вместе перед началом поставленного в очередь запуска.

<Note>
  `fp audits run` асинхронный. Опрашивайте `fp audits runs NAME` до тех пор, пока последний запуск не успеет или не завершится ошибкой перед чтением его выводов.
</Note>

## Глобальные флаги

| Флаг | Описание |
| --- | --- |
| `--json` | Выдать машиночитаемый JSON. |
| `--base-url <url>` | Использовать самостоятельно размещённую или развивающую панель управления. |
| `--org <slug>` | Выбрать организацию для этого вызова. |
| `--token <token>` | Переопределить сохранённый токен пользовательского сеанса. |
| `--api-key <key>` | Аутентифицировать автоматизацию с помощью ключа API; никогда не сохраняется. |
| `--timeout <seconds>` | Тайм-аут HTTP; должен быть положительным. По умолчанию: `30`. |
| `--quiet`, `-q` | Подавить выход статуса на stderr. |
| `--no-color` | Отключить цветной вывод. |
| `--insecure` / `--secure` | Отключить или восстановить проверку сертификата TLS. |
| `--version` | Напечатать развёрнутую версию и выйти. |
| `--help`, `-h` | Показать справку. |

`--api-key` предназначен для автоматизации. Вход, переключение организации и команды ассистента требуют пользовательский сеанс.

Явные флаги переопределяют переменные окружения, которые переопределяют сохранённую конфигурацию. В режиме ключа API явно выберите тенанта с помощью `--org` или `AGENTEYE_ORG`.

<Warning>
  Команды, которые удаляют, отзывают, подавляют, разрешают или заменяют конфигурацию, по умолчанию подсказывают. Используйте `--yes` только после проверки активной организации и цели.
</Warning>
