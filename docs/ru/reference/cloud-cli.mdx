Используйте `fp` для проверки облачной телеметрии и управления аудитами, находками, проблемами, оповещениями, ключами, пользователями, запросами и параметрами. Используйте [`failproofai`](/ru/reference/failproof-cli) для локальных hooks, политик, захвата и регистрации машин.

Установите выпущенный Cloud CLI как отдельный инструмент:

```bash
uv tool install fp-cli
fp version
```

## Вход в систему

```bash
fp login
fp whoami
```

## Синтаксис

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

Глобальные параметры должны предшествовать команде:

```bash
fp --json sessions --since 24h
```

Запустите `fp COMMAND --help` или `fp COMMAND SUBCOMMAND --help` для справки в терминале.


### События

```text
fp events [OPTIONS]
```

Выводит список отдельных событий агента. По умолчанию лёгкая лента исключает необработанные данные; используйте `--full` только для ограниченного расследования.

| Параметр | Описание |
| --- | --- |
| `--limit`, `-n <n>` | Максимальное количество строк. По умолчанию: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h` или `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | Диапазон ISO 8601 UTC; переопределяет `--since`. |
| `--env <value>` | Фильтр окружения; повторите или разделите запятыми. |
| `--event-type <value>` | Фильтр по типу события; повторите или разделите запятыми. |
| `--agent-id <value>` | Фильтр агента; повторите или разделите запятыми. |
| `--session-id <value>` | Фильтр сеанса; повторите или разделите запятыми. |
| `--search <text>` | Поиск текста в данных; повторяемо, совпадение любого термина. |
| `--order asc\|desc` | Порядок времени. По умолчанию: сначала новые. |
| `--all` | Автоматическая разбивка на страницы до `--limit`. |
| `--cursor <token>` | Продолжить с непрозрачного курсора. |
| `--page-size <n>` | Строк на запрос с `--all`; максимум `200`. |
| `--full` | Включить необработанные данные через более тяжёлую конечную точку событий. |
| `--fields <csv>` | Вернуть только выбранные поля; запрос `payload` включает полный режим. |

```bash
fp events --session-id <session-id> --order asc --all
fp --json events --full --session-id <session-id> --all
```

### Ключи API

| Команда | Назначение | Параметры |
| --- | --- | --- |
| `fp keys list` | Список ключей организации. | `--show-id`; `--fields <csv>` |
| `fp keys show NAME` | Показать один ключ и его разрешения. | — |
| `fp keys create NAME` | Создать ключ и показать его секрет один раз. | `--permission-set`; `--add`; `--remove` |
| `fp keys update NAME` | Заменить набор разрешений или отрегулировать разрешения. | `--permission-set`; `--add`; `--remove`; `--yes`, `-y` |

Токены разрешений используют формат `resource:action`, например `events:add`. Повторите `--add`, разделите запятыми токены или используйте точечные действия, такие как `events:read.add`.

#### Параметры создания аудита

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| Параметр | Описание |
| --- | --- |
| `--file <path>` | Основать определение на JSON или использовать `-` для stdin. Явные флаги переопределяют значения файла. |
| `--description <text>` | Укажите вопрос об отказе или назначение. |
| `--enabled` / `--disabled` | Начать планирование включённым или отключённым. По умолчанию: включено. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. По умолчанию: `86400`. |
| `--schedule-anchor <timestamp>` | Фиксированная фаза UTC в формате ISO 8601. По умолчанию: следующие 09:00 UTC. |
| `--window-mode since_last\|fixed` | Продолжить после последнего полностью проанализированного окна или повторно проверить скользящее окно. По умолчанию: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. По умолчанию: `604800`. |
| `--scope '<json>'` | Фильтр по `environments`, `agent_ids` или другим поддерживаемым полям области. |
| `--ignore-error-type <type>` | Исключить типы ошибок; повторите или разделите запятыми. |
| `--llm` / `--no-llm` | Включить или отключить анализ на основе агентов. По умолчанию: включено. |
| `--top-k <n>` | Сохранить `1`–`500` находок. По умолчанию: `50`. |
| `--sensitivity low\|medium\|high` | Установить чувствительность отчётности. По умолчанию: `medium`. |
| `--channels '<json>'` | Массив канала уведомлений. |
| `--text <brief>` | Встроенное краткое описание, максимум 8 192 символа. |
| `--text-file <path>` | Читать краткое описание из файла; взаимно исключает `--text`. |
| `--url <https-url>` | Добавить публичную справочную ссылку HTTPS; повторите до пяти раз. |

Включайте контекст при создании, когда первому запуску это требуется. Создание фиксирует определение и контекст вместе перед началом поставленного в очередь запуска.

<Note>
  `fp audits run` является асинхронной. Опрашивайте `fp audits runs NAME` до тех пор, пока последний запуск не завершится успешно или ошибкой, прежде чем читать его находки.
</Note>

## Глобальные флаги

| Флаг | Описание |
| --- | --- |
| `--json` | Выдать машиночитаемый JSON. |
| `--base-url <url>` | Использовать самостоятельно размещённую или разработчицкую панель управления. |
| `--org <slug>` | Выбрать организацию для этого вызова. |
| `--token <token>` | Переопределить сохранённый токен пользовательского сеанса. |
| `--api-key <key>` | Аутентифицировать автоматизацию с помощью ключа API; никогда не сохраняется. |
| `--timeout <seconds>` | Тайм-аут HTTP; должен быть положительным. По умолчанию: `30`. |
| `--quiet`, `-q` | Подавить вывод статуса на stderr. |
| `--no-color` | Отключить цветной вывод. |
| `--insecure` / `--secure` | Отключить или восстановить проверку TLS сертификата. |
| `--version` | Напечатать развёрнутую версию и выйти. |
| `--help`, `-h` | Показать справку. |

`--api-key` предназначена для автоматизации. Вход в систему, переключение организации и команды помощника требуют пользовательского сеанса.

Явные флаги переопределяют переменные окружения, которые переопределяют сохранённую конфигурацию. В режиме ключа API выберите тенанта явно с помощью `--org` или `AGENTEYE_ORG`.

<Warning>
  Команды, которые удаляют, отзывают, подавляют, разрешают или заменяют конфигурацию, по умолчанию запрашивают подтверждение. Используйте `--yes` только после проверки активной организации и цели.
</Warning>
