Подключите инструмент ИИ к Failproof AI Cloud и работайте с данными ваших агентов из него. Ваш инструмент может запрашивать сессии и события, выполнять доступные только для чтения SQL запросы, читать панели управления, оповещения, insights, аудиты и политики, а при наличии разрешения вносить изменения, такие как создание оповещения или развертывание политики.

Каждый вызов выполняется с **вашими собственными** разрешениями в **одной** организации, которую вы выбираете при подключении.

Существует один адрес для всех, размещенный или самостоятельно размещенный:

```text
https://gateway.befailproof.ai/mcp
```

## Подключите клиента

Добавьте адрес в ваш клиент. При первом использовании инструмента ваш браузер откроется. Выберите, где расположен ваш Failproof AI Cloud, войдите, выберите одну организацию и нажмите **Allow**. **Cancel** ничего не подключает.

На странице указаны название приложения и адрес возврата. Приложение, которое не идентифицируется по собственному веб-адресу, помечается как **unverified app**, поэтому продолжайте только если вы только что запустили это из своего клиента.

<Tabs>
  <Tab title="Claude">
    В claude.ai или Claude Desktop перейдите в **Settings → Connectors → Add custom connector**. Назовите его `Failproof AI`, введите адрес, нажмите **Add**, затем **Connect**.

    В планах Team и Enterprise владелец сначала добавляет соединитель для организации. Затем каждый человек подключает свой собственный аккаунт.
  </Tab>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http failproofai https://gateway.befailproof.ai/mcp
    ```

    Затем запустите `/mcp` внутри Claude Code, выберите `failproofai` и нажмите **Authenticate**.
  </Tab>
  <Tab title="Cursor">
    Добавьте это в `~/.cursor/mcp.json` или в ``.cursor/mcp.json` вашего проекта:

    ```json
    {
      "mcpServers": {
        "failproofai": { "url": "https://gateway.befailproof.ai/mcp" }
      }
    }
    ```

    Cursor отображает **Needs login** рядом с сервером. Выберите его для входа.
  </Tab>
  <Tab title="Codex">
    Добавьте это в `~/.codex/config.toml`:

    ```toml
    [mcp_servers.failproofai]
    url = "https://gateway.befailproof.ai/mcp"
    ```

    Затем запустите `codex mcp login failproofai`.
  </Tab>
  <Tab title="Other clients">
    Любой клиент, который поддерживает удаленные MCP серверы через потоковый HTTP с OAuth, работает. Укажите адрес выше. Нет идентификатора клиента или секрета для настройки.
  </Tab>
</Tabs>

## Одна организация на подключение

Подключение действует только в выбранной организации. Чтобы использовать две организации, добавьте сервер дважды под разными именами, такими как `failproofai-acme` и `failproofai-sandbox`, и подключите каждый к своей организации.

Демонстрационные организации не принимают подключения. Вместо этого выберите свою организацию.

## Разрешения

Подключение может выполнять то, что вы можете делать в организации, в пределах набора ниже. Оно следует вашим текущим разрешениям: если администратор дает вам больше, инструмент получает это, а если они что-то отнимают, инструмент теряет это при следующем вызове.

| Разрешение | Позволяет инструменту |
| --- | --- |
| `events:read` | Список событий, чтение обзора сессии, список агентов и окружений |
| `evaluations:read` | Список сессий, чтение и суммирование результатов оценки и заданий |
| `evaluations:trigger` | Создание оценок, публикация новых версий, включение и отключение, заполнение, переоценка сессии |
| `dashboards:read`, `dashboards:write` | Чтение панелей управления или создание, переименование и добавление запросов к ним |
| `queries:read`, `queries:write` | Чтение сохраненных запросов или их сохранение и редактирование |
| `queries:run` | Выполнение одного доступного только для чтения SQL запроса и чтение схемы запроса |
| `alerts:read`, `alerts:write` | Чтение оповещений или создание, редактирование, приостановка, удаление и тестирование их |
| `issues:read` | Чтение insights, подтверждение и комментирование их |
| `issues:create` | Открытие insight на оповещение |
| `issues:close` | Решение и закрытие insights |
| `audits:read`, `audits:write` | Чтение аудитов, запусков и результатов, или создание и редактирование аудитов и запуск запуска |
| `code_fixes:read` | Просмотр способа исправления insight и получение его контекста для вашего собственного агента для исправления |
| `code_fixes:write` | Запуск исправления в Failproof AI Cloud, которое открывает pull request на вашем GitHub |
| `policies:read`, `policies:write` | Чтение политик, машин и развертываний, или публикация, развертывание и откат политик |

Несколько инструментов не требуют разрешения, так как они не читают данные организации: создание ссылок сессии и события, поиск в этой документации.

Инструмент ИИ никогда не может трогать ключи API, пользователей, параметры или администрирование организации, и он не может отправлять события.

## Утверждение изменений

Запросы на запись сначала спрашивают вас, может ли ваш клиент показать подсказку. Вы видите, что изменится, и выбираете **Approve this change**, чтобы продолжить. Если вы откажетесь или не ответите в течение примерно 4 минут, ничего не изменится. Некоторые клиенты прекращают ожидание через минуту, поэтому ответьте быстро.

<Warning>
  Клиент, который не поддерживает подсказки, не спрашивается, и запись выполняется, как только клиент делает вызов. Там ваше собственное подтверждение клиента — единственное, поэтому держите его включенным для инструментов записи.
</Warning>

## Подключенные приложения и отзыв

**settings → integrations → MCP** перечисляет ваши подключенные приложения в текущей организации с их разрешениями и последним использованием. **Revoke** немедленно отключает приложение. Удаление сервера в вашем клиенте также отзывает подключение.

Вы можете иметь до 5 подключенных приложений на организацию. Подключение одного и того же приложения снова заменяет его предыдущее подключение.

## Самостоятельно размещенные развертывания

Выберите **Self-hosted Failproof AI Cloud** при подключении и введите адрес, по которому вы входите. Ваше развертывание должно быть доступно через общедоступный HTTPS.

Вызовы инструментов и их результаты передаются через размещенный шлюз Failproof AI на пути между вашим инструментом ИИ и вашим развертыванием. Шлюз их не хранит.

## Что происходит с вашими данными

Результаты переходят на подключенный вами инструмент ИИ, и провайдер этого инструмента обрабатывает их в соответствии со своими условиями. Для каждого вызова инструмента Failproof AI регистрирует имя инструмента, его результат, время выполнения и организацию, но никогда не аргументы или результаты. См. [политику конфиденциальности](https://befailproof.ai/privacy/).

## Устранение неполадок

| Что вы видите | Что делать |
| --- | --- |
| Started in another browser | Завершите вход в браузере, открытом клиентом, с разрешенными файлами cookie, и начните снова с клиента |
| Ошибка после **Allow** | Ссылка работает один раз и истекает через 10 минут, поэтому начните снова с клиента |
| Инструмент, который вы ожидали, отсутствует | У вас нет его разрешения в этой организации. Попросите администратора. Вам не нужно переподключаться, как только у вас есть оно |
| Клиент продолжает просить вас войти | Подключение было отозвано, вы покинули организацию или оно не использовалось 90 дней. Подключитесь снова |
| You have 5 connected apps | Отозовите один под **settings → integrations → MCP**, затем подключитесь снова |
