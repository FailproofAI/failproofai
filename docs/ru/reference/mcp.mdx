Подключите инструмент AI к Failproof AI Cloud и работайте с данными ваших агентов. Ваш инструмент может запрашивать сессии и события, выполнять read-only SQL запросы, читать дашборды, оповещения, проблемы, аудиты и политики, а также, если у вас есть соответствующее разрешение, вносить изменения, такие как создание оповещения или развёртывание политики.

Каждый вызов выполняется с **вашими собственными** разрешениями в **одной** организации, которую вы выбираете при подключении.

Есть один адрес для всех, как для размещённых, так и для самостоятельно размещённых развёртываний:

```text
https://gateway.befailproof.ai/mcp
```

## Подключение клиента

Добавьте адрес в ваш клиент. При первом использовании инструмента ваш браузер откроется. Выберите, где находится ваш Failproof AI Cloud, авторизуйтесь, выберите одну организацию и нажмите **Allow**. **Cancel** ничего не подключает.

На странице указаны имя приложения и адрес, на который оно вернётся. Приложение, которое не идентифицируется собственным веб-адресом, помечено как **unverified app**, поэтому продолжайте только если вы только что запустили это из вашего собственного клиента.

<Tabs>
  <Tab title="Claude">
    На claude.ai или Claude Desktop перейдите в **Settings → Connectors → Add custom connector**. Назовите его `Failproof AI`, введите адрес, выберите **Add**, затем **Connect**.

    На планах Team и Enterprise владелец сначала добавляет разъём для организации. Затем каждый человек подключает свой собственный аккаунт.
  </Tab>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http failproofai https://gateway.befailproof.ai/mcp
    ```

    Затем запустите `/mcp` внутри Claude Code, выберите `failproofai` и нажмите **Authenticate**.
  </Tab>
  <Tab title="Cursor">
    Добавьте это в `~/.cursor/mcp.json` или в `.cursor/mcp.json` вашего проекта:

    ```json
    {
      "mcpServers": {
        "failproofai": { "url": "https://gateway.befailproof.ai/mcp" }
      }
    }
    ```

    Cursor покажет **Needs login** рядом с сервером. Выберите его для входа.
  </Tab>
  <Tab title="Codex">
    Добавьте это в `~/.codex/config.toml`:

    ```toml
    [mcp_servers.failproofai]
    url = "https://gateway.befailproof.ai/mcp"
    ```

    Затем запустите `codex mcp login failproofai`.
  </Tab>
  <Tab title="Другие клиенты">
    Любой клиент, который поддерживает удалённые MCP серверы через потоковый HTTP с OAuth, будет работать. Укажите адрес выше. Нет никакого ID клиента или секрета для конфигурации.
  </Tab>
</Tabs>

## Одна организация на подключение

Подключение действует только в организации, которую вы выбрали. Чтобы использовать две организации, добавьте сервер дважды под разными именами, например `failproofai-acme` и `failproofai-sandbox`, и подключите каждый к своей организации.

Демо-организации не принимают подключения. Выберите вместо этого вашу собственную организацию.

## Разрешения

Подключение может делать то, что вы можете делать в организации, в пределах приведённого ниже набора. Оно следует вашим текущим разрешениям: если администратор даёт вам больше, инструмент получает это, а если они что-то отнимают, инструмент теряет это при следующем вызове.

| Разрешение | Позволяет инструменту |
| --- | --- |
| `events:read` | Список событий, чтение обзора сессии, список агентов и окружений |
| `evaluations:read` | Список сессий, чтение и суммирование результатов оценки и работ |
| `evaluations:trigger` | Создание оценок, публикация новых версий, включение/выключение, заполнение предыдущих данных и переоценка сессии |
| `dashboards:read`, `dashboards:write` | Чтение дашбордов или создание, переименование и добавление запросов к ним |
| `queries:read`, `queries:write` | Чтение сохранённых запросов или сохранение и редактирование их |
| `queries:run` | Выполнение одного read-only SQL запроса и чтение схемы запроса |
| `alerts:read`, `alerts:write` | Чтение оповещений или создание, редактирование, приостановка, удаление и тестирование их |
| `issues:read` | Чтение проблем, подтверждение их и комментирование |
| `issues:create` | Открытие проблемы на основе оповещения |
| `issues:close` | Разрешение и закрытие проблем |
| `audits:read`, `audits:write` | Чтение аудитов, запусков и результатов или создание и редактирование аудитов и запуск |
| `code_fixes:read` | Просмотр способа исправления проблемы и получение её контекста для вашего собственного агента |
| `code_fixes:write` | Запуск исправления в Failproof AI Cloud, которое открывает pull request на вашем GitHub |
| `policies:read`, `policies:write` | Чтение политик, машин и развёртываний или публикация, развёртывание и откат политик |

Несколько инструментов не требуют разрешения, потому что они не читают данные организации: создание ссылок на сессии и события, а также поиск в этой документации.

Инструмент AI никогда не может трогать API ключи, пользователей, параметры или администрирование организации, и не может отправлять события.

## Одобрение изменений

Записи сначала просят вас, если ваш клиент может показать приглашение. Вы видите, что изменится, и выбираете **Approve this change** для продолжения. Если вы отклоняете или не ответили в течение примерно 4 минут, ничего не изменяется. Некоторые клиенты перестают ждать после минуты, поэтому ответьте быстро.

<Warning>
  Клиент, который не поддерживает приглашения, не опрашивается, и запись выполняется сразу же после вызова клиентом. Там ваше собственное подтверждение клиента — это единственное, поэтому оставляйте его включённым для инструментов записи.
</Warning>

## Подключённые приложения и отзыв

**Settings → Integrations → MCP** отображает ваши подключённые приложения в текущей организации с их разрешениями и последним использованием. **Revoke** отключает приложение немедленно. Удаление сервера в вашем клиенте также отзывает подключение.

Вы можете иметь до 5 подключённых приложений на организацию. Повторное подключение того же приложения заменяет его более раннее подключение.

## Самостоятельно размещённые развёртывания

Выберите **Self-hosted Failproof AI Cloud** при подключении и введите адрес, на котором вы авторизуетесь. Ваше развёртывание должно быть доступно по публичному HTTPS.

Вызовы инструментов и их результаты проходят через размещённый шлюз Failproof AI между вашим инструментом AI и вашим развёртыванием. Шлюз не хранит их.

## Что происходит с вашими данными

Результаты переходят к инструменту AI, который вы подключили, и поставщик этого инструмента обрабатывает их в соответствии с его собственными условиями. Для каждого вызова инструмента Failproof AI логирует имя инструмента, его результат, время выполнения и организацию, но никогда аргументы или результаты. См. [политику конфиденциальности](https://befailproof.ai/privacy/).

## Решение проблем

| Что вы видите | Что делать |
| --- | --- |
| "Started in another browser" | Завершите вход в браузер, который открыл клиент, с разрешёнными файлами cookie, и начните снова с клиента |
| Ошибка после **Allow** | Ссылка работает один раз и истекает через 10 минут, поэтому начните снова с клиента |
| Инструмент, который вы ожидали, отсутствует | У вас нет его разрешения в этой организации. Попросите администратора. Вам не нужно переподключаться, как только вы его получите |
| Клиент продолжает просить вас войти | Подключение было отозвано, вы покинули организацию или оно не использовалось 90 дней. Подключитесь снова |
| "You have 5 connected apps" | Отзовите один под **Settings → Integrations → MCP**, затем подключитесь снова |
