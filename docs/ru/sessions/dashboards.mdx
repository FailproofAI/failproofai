Панели мониторинга объединяют сохраненные запросы в операционное представление. Создавайте их вокруг решений, которые, как вы ожидаете, кто-то будет принимать — а не вокруг каждой доступной метрики.

## Создание панели мониторинга

<Tabs>
  <Tab title="Панель мониторинга">
    1. Перейдите в **Analyze → Queries**, создайте или откройте сохраненный запрос и проверьте его результат.
    2. Выберите **add to dashboard**, затем выберите существующую панель или создайте новую в разделе **Analyze → Dashboards**.
    3. Откройте панель мониторинга, войдите в режим редактирования, расположите плитки и сохраните макет.
    4. Вернитесь к запросу, когда вам нужно изменить данные или фильтры за плиткой.

    ![Панель мониторинга, составленная из сохраненных запросов по объему событий, ошибкам, задержкам и использованию токенов модели.](/images/dashboard/dashboard-fleet.png)
  </Tab>
  <Tab title="CLI">
    CRUD операции на панелях мониторинга не предоставляются текущим Cloud CLI. Используйте CLI для построения и проверки сохраненного запроса, затем добавьте его на панель мониторинга в пользовательском интерфейсе.

    ```bash
    fp query schema
    fp query create "production error rate" --sql "SELECT ..."
    fp query run <query-id>
    ```
  </Tab>
</Tabs>

Полезные группы панелей мониторинга включают:

- **Models:** объем, задержка, использование токенов, частота ошибок и оценки оценивания.
- **Evaluations:** тенденции успешности и оценок по агентам или окружениям.
- **Tools:** объем вызовов, частота сбоев, длительность и повторные вызовы.
- **Hooks and policies:** решения, отказы и частота совпадений политик.
- **Custom workflow metrics:** результаты из собственных полей событий и SQL.

Начните с сохраненного запроса, проверьте его результат, затем добавьте его как плитку. Оставляйте фильтры для production и development явными, чтобы тестовый трафик не скрывал регрессию.

<Tip>
  Назначьте каждой панели мониторинга владельца и вопрос ответственности, такой как «Надежность checkout-agent хуже, чем на прошлой неделе?»
</Tip>
