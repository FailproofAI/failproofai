Онлайн-оценки применяют согласованные оценки к сеансам агентов. Используйте их для сигналов, которые должны измеряться постоянно, а не только расследоваться при аудите.

## Проверка качества оценки

<Tabs>
  <Tab title="Dashboard">
    1. Перейдите в **Observe → Evaluations**.
    2. Добавьте серию и выберите агента, окружение, оценку, статистику и кривую.
    3. Добавьте несколько серий для сравнения окружений, агентов или ключей оценок.
    4. Выберите результат, чтобы открыть соответствующие сеансы или поделиться отфильтрованным представлением. Используйте **Observe → Metrics** для задержки, токенов, стоимости и других значений величин.

    ![Панель качества, показывающая средние баллы оценки и тренды во времени.](/images/dashboard/dashboard-quality.png)

    Откройте сеанс из детализации, чтобы проверить рассуждения для каждой оценки:

    ![Представление деталей сеанса, показывающее баллы оценки и рассуждения рядом с полной трассировкой.](/images/dashboard/session-detail.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp evals --agent-id checkout-agent --aggregate
    fp evals --aggregate --env production --status error
    fp evals --score helpfulness:0.8.. --since 7d
    ```

    Добавьте глобальный флаг `--json` перед `evals` для автоматизации, например `fp --json evals --aggregate --env production`.
  </Tab>
</Tabs>

Оценивающая функция получает идентификацию сеанса, окружение, временные метки и упорядоченные события. Она может возвращать числовые ключи оценок с необязательными рассуждениями и резюме. Долгоживущие оценивающие функции могут возвращать отложенное задание и быть опрошены позже.

## Хорошие цели для оценки

- Завершение задачи или корректность
- Обоснованность и риск галлюцинаций
- Выбор инструмента и эффективность использования инструментов
- Соответствие политике или процессам
- Бюджеты стоимости и задержки
- Требуемое привлечение человека

## От оценки к ответу

Отображайте оценки на панелях для отслеживания тенденций. Создавайте оповещения для пороговых или комбинированных условий. Когда оценка снижается в популяции, выполните аудит, чтобы выяснить причину; когда причина — повторяемое действие, развёртывайте политику.
