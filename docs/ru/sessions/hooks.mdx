---
title: "Hooks"
description: "Measure hook activity, triggers, and latency separately from policy outcomes."
icon: "webhook"
---

Hooks показывает, когда запускаются lifecycle hooks агента и сколько времени они занимают. Решения по политикам отображаются отдельно.

<Tabs>
  <Tab title="Dashboard">
    1. Перейдите в **Observe → Hooks**.
    2. Фильтруйте по окружению, названию hook, событию триггера, агенту или идентификатору сессии.
    3. Проверьте latency hook и распределение.
    4. Выберите точку на графике или сегмент hook, чтобы открыть основные события.

    ![Страница Hooks, показывающая latency, сгруппированную по названию hook и событию триггера.](/images/dashboard/hooks.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list hooks
    fp events --event-type hook_triggered,hook_completed --env production --since 24h
    fp events --search "PreToolUse" --since 24h
    ```
  </Tab>
</Tabs>
