Hook — это точка, где агент запрашивает у Failproof AI решение. Запись активности hook содержит событие, политику, результат и время оценки.

## Исследуйте активность hook

<Tabs>
  <Tab title="Dashboard">
    Перейдите в **Observe → Hooks**. Отфильтруйте по окружению, событию, агенту или сеансу.

    ![Страница Hooks, показывающая задержку, сгруппированную по имени hook и событию триггера.](/images/dashboard/hooks.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp guardrails summary --since 24h
    fp --json events --full --event-type hook_completed --session-id <session-id> --all --limit 500
    fp list hooks
    ```
  </Tab>
</Tabs>

По умолчанию каждое решение `deny` и `instruct` отправляется полностью. Повторяющиеся разрешения группируются для сокращения шума. Установите `collector.hooks_verbosity` в `~/.failproofai/config.json` на значение `all`, `decisions` или `off`.

<Warning>
  Активность hook доказывает, что оценка выполнялась, но не гарантирует, что инструмент смог заблокировать это событие. См. [capability enforcement](/ru/reference/harnesses#enforcement-capability). Неперечисленная пара harness-event не проверена.
</Warning>
