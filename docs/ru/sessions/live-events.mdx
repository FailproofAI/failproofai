Live events показывает активность по мере работы агентов: вызовы моделей, инструменты, ошибки, пользовательский ввод, хуки и решения политик.

## Просмотр активности

Перейдите в **Observe → Live events** или выполните:

```bash
fp events --since 1h
fp events --event-type tool_use,tool_result --since 1h
fp --json events --full --session-id <session-id> --all --limit 2000
```

Используйте `--full`, когда вам нужно содержимое полезных нагрузок. Лёгкий поток работает быстрее и достаточен для большинства фильтраций.

Типичные типы событий включают:

- `session_start` и `session_end`
- `model_request` и `model_response`
- `tool_use` и `tool_result`
- `hook_triggered` и `hook_completed`
- `error`
- `human_wait` и `human_input`
- `agent_pause` и `agent_resume`

## Если события не отображаются

```bash
failproofai flush --wait
failproofai config --status
failproofai backfill --since 30d --dry-run
```

Окружение по умолчанию — `local`. Фильтр для `production` не возвращает результаты, пока вы не измените метку окружения.

Для агента вне поддерживаемой оболочки используйте [Python SDK](/ru/reference/custom-agents).
