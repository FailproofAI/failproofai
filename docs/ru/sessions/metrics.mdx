Метрики используются для значений с единицами измерения. Оценки используются для баллов и суждений.

<Tabs>
  <Tab title="Dashboard">
    1. Перейдите в **Observe → Metrics**.
    2. Выберите **add series** и укажите агента, окружение, метрику, статистику и кривую.
    3. Добавляйте серии для сравнения агентов или окружений; разные единицы измерения получают отдельные оси.
    4. Выберите точку, чтобы открыть соответствующие оценки и сессии, или выберите **share**, чтобы скопировать точный вид.

    ![Страница Metrics, сравнивающая две серии cost-per-output-unit с элементами управления временем, селекторами агрегации, кривыми и действием share.](/images/dashboard/metrics-series.png)
  </Tab>
  <Tab title="CLI">
    Пока отсутствует специальная команда для метрик величин. Обнаруживайте доступные ключи и просматривайте сессии или оценки:

    ```bash
    fp list score_filters
    fp --json evals --since 24h
    fp --json sessions --since 24h
    ```

    Используйте `fp query` для пользовательской агрегации метрик.
  </Tab>
</Tabs>
