Используйте раздел Модели, чтобы узнать, изменилась ли надёжность или стоимость при использовании определённой модели, агента, окружения или временного диапазона.

<Tabs>
  <Tab title="Панель управления">
    1. Перейдите в **Observe → Models**.
    2. Установите временной диапазон, затем отфильтруйте по окружению, модели, агенту или ID сессии.
    3. Просмотрите задержку, потребление токенов, использование контекстного окна и распределение моделей.
    4. Выберите точку на графике или сегмент распределения, чтобы открыть соответствующие события.

    ![Страница Models, показывающая представления задержки, процентиля, токенов, стоимости, контекстного окна и распределения моделей.](/images/dashboard/models.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list models
    fp events --event-type model_request,model_response --env production --since 24h
    fp --json events --fields ts,agent_id,session_id,event_type,output_tokens,context_fill
    ```

    Используйте сохранённый запрос для агрегатов на уровне моделей, которые недоступны как отдельная команда CLI.
  </Tab>
</Tabs>
