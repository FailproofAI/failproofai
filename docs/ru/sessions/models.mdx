Используйте Models для проверки того, изменились ли надёжность или затраты при переключении модели, агента, окружения или диапазона времени.

<Tabs>
  <Tab title="Dashboard">
    1. Перейдите в **Observe → Models**.
    2. Установите диапазон времени и отфильтруйте результаты по окружению, модели, агенту или ID сессии.
    3. Посмотрите задержку, потребление токенов, использование контекстного окна и распределение модели.
    4. Выберите точку на графике или сегмент распределения, чтобы открыть соответствующие события.

    ![Страница Models, показывающая задержку, процентили, токены, стоимость, контекстное окно и распределение моделей.](/images/dashboard/models.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list models
    fp events --event-type model_request,model_response --env production --since 24h
    fp --json events --fields ts,agent_id,session_id,event_type,output_tokens,context_fill
    ```

    Используйте сохранённый запрос для агрегатов на уровне модели, которые не представлены отдельной командой CLI.
  </Tab>
</Tabs>
