Сессия — это лучшая отправная точка, когда агент ведёт себя неожиданно. Она объединяет запросы модели, ответы, вызовы инструментов, взаимодействия с человеком, ошибки, оценки и решения политик, относящиеся к одному запуску.

Проследите один запуск агента от его цели через вызовы модели, инструменты и финальный ответ.

## Найдите сессию

<Tabs>
  <Tab title="Dashboard">
    1. На боковой панели Cloud перейдите в **Observe → Sessions**.
    2. Установите временное окно, затем отфильтруйте по окружению, статусу, агенту или ID сессии.
    3. Добавьте диапазоны оценок или метрик, когда вам нужен срез по качеству, стоимости, токенам или задержке.
    4. Выберите строку, чтобы открыть её трассировку. Используйте элемент копирования рядом с ID сессии при её передаче.

    ![Список Sessions, показывающий одну строку для каждого запуска с фильтрами по окружению, агенту, статусу и оценке результата.](/images/dashboard/sessions-list.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp sessions --env production --since 24h
    fp sessions --status error,timeout --agent-id checkout-agent
    fp --json sessions --session-id <session-id>
    ```

    Добавьте `--agents` для развёртывания запусков с несколькими агентами, `--all` для разбивки по страницам или `--fields` для выбора столбцов вывода.
  </Tab>
</Tabs>

## Что вы можете делать

- Найти запуск по агенту, окружению, времени, модели, типу события или состоянию ошибки.
- Проследить точную последовательность, которая привела к результату.
- Сравнить успешные и неудачные запуски.
- Открыть доказательства, использованные аудитом или инцидентом оповещения.
- Экспортировать сессию, когда вам нужна офлайн-запись.

## Надёжный порядок расследования

1. Подтвердите цель сессии и окружение.
2. Найдите первую ошибку или неожиданное решение — не только финальный отказ.
3. Проверьте контекст модели и входные данные инструмента непосредственно перед ним.
4. Проверьте повторные попытки, задержку и прерывания со стороны человека.
5. Просмотрите оценки результатов и решения политик.
