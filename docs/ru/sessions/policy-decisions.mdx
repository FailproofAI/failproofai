Решения политик показывают, что именно сделал механизм принудительного применения. Используйте это для проверки развертывания, измерения процента блокировок и выявления незащищенной активности.

<Tabs>
  <Tab title="Dashboard">
    1. Перейдите в **Observe → policy** и выберите диапазон времени и, при необходимости, один компьютер.
    2. Проверьте оцененные действия, блокировки, процент блокировок, облачные решения, незащищенные действия и активность во время паузы.
    3. Отфильтруйте таблицу сопоставления политик и проверьте развернутые назначения.
    4. Выберите точку на графике, чтобы открыть решения и их сеансы.

    ![Страница Policy, показывающая итоги решений, фильтр компьютера, активность принудительного применения во времени и таблицу сопоставления политик.](/images/dashboard/policy-observe.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp events --event-type hook_completed --env production --since 24h
    fp events --search "deny" --since 24h
    failproofai config --status
    ```

    Используйте `failproofai` для локального состояния применения на компьютере и `fp` для исследования облачных событий.
  </Tab>
</Tabs>
