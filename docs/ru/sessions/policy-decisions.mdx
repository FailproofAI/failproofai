Решения политик показывают, что сделал механизм принудительного применения. Используйте его для проверки развертывания, измерения коэффициента блокировок и поиска незащищенной деятельности.

<Tabs>
  <Tab title="Dashboard">
    1. Откройте **Observe → policy** и выберите временной диапазон и, опционально, одну машину.
    2. Просмотрите оцененные действия, блокировки, коэффициент блокировок, облачные решения, незащищенные действия и деятельность во время паузы.
    3. Отфильтруйте таблицу сопоставления политик и изучите развернутые назначения.
    4. Выберите точку на диаграмме, чтобы открыть решения и их сеансы.

    ![Страница политики, показывающая итоги решений, фильтр машин, деятельность принудительного применения во времени и таблицу сопоставления политик.](/images/dashboard/policy-observe.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp events --event-type hook_completed --env production --since 24h
    fp events --search "deny" --since 24h
    failproofai config --status
    ```

    Используйте `failproofai` для локального состояния принудительного применения на машине и `fp` для исследования облачных событий.
  </Tab>
</Tabs>
