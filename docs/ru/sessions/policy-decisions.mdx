Решения политик показывают, что сделало обеспечение. Используйте это для проверки развертывания, измерения уровня блокировки и поиска незащищенной активности.

<Tabs>
  <Tab title="Панель управления">
    1. Перейдите в **Observe → policy** и выберите временной диапазон и при необходимости одну машину.
    2. Проверьте оцененные действия, блокировки, уровень блокировки, облачные решения, незащищенные действия и активность во время паузы.
    3. Отфильтруйте таблицу сопоставления политик и проверьте развернутые назначения.
    4. Выберите точку на диаграмме, чтобы открыть решения и их сеансы.

    ![Страница Policy, показывающая общее количество решений, фильтр машины, активность обеспечения во времени и таблицу сопоставления политик.](/images/dashboard/policy-observe.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp events --event-type hook_completed --env production --since 24h
    fp events --search "deny" --since 24h
    failproofai config --status
    ```

    Используйте `failproofai` для локального состояния обеспечения машины и `fp` для исследования облачных событий.
  </Tab>
</Tabs>
