---
title: "Tools"
description: "Найдите медленные, неработающие или переиспользуемые инструменты в сеансах агента."
icon: "wrench"
---

Tools группирует вызовы инструментов в разрезе сеансов, позволяя вам сравнивать задержку и распределение вызовов.

<Tabs>
  <Tab title="Dashboard">
    1. Перейдите в **Observe → Tools**.
    2. Отфильтруйте по окружению, названию инструмента, агенту или ID сеанса.
    3. Просмотрите задержку и распределение инструментов.
    4. Выберите точку на диаграмме или сегмент инструмента, чтобы открыть соответствующие события и сеансы.

    ![Страница Tools, показывающая задержку, распределение успехов и ошибок, а также распределение вызовов инструментов.](/images/dashboard/tools.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list tools
    fp events --event-type tool_use,tool_result --env production --since 24h
    fp --json events --full --session-id <session-id> --all
    ```
  </Tab>
</Tabs>
