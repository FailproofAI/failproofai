---
title: "Инструменты"
description: "Найдите медленные, неработающие или чрезмерно используемые инструменты во время сеансов агентов."
icon: "wrench"
---

Инструменты группируют вызовы инструментов по сеансам, позволяя вам сравнивать задержку и распределение вызовов.

<Tabs>
  <Tab title="Dashboard">
    1. Перейдите в **Observe → Tools**.
    2. Отфильтруйте по среде, названию инструмента, агенту или ID сеанса.
    3. Просмотрите задержку и распределение инструментов.
    4. Выберите точку на графике или сегмент инструмента, чтобы открыть соответствующие события и сеансы.

    ![Страница Tools, показывающая задержку, разбивку успешных и неудачных вызовов, а также распределение вызовов инструментов.](/images/dashboard/tools.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list tools
    fp events --event-type tool_use,tool_result --env production --since 24h
    fp --json events --full --session-id <session-id> --all
    ```
  </Tab>
</Tabs>
