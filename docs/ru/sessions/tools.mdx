---
title: "Tools"
description: "Найдите медленные, ошибочные или перегруженные инструменты во всех сеансах агента."
icon: "wrench"
---

Tools группирует вызовы инструментов между сеансами, чтобы вы могли сравнивать задержку и распределение вызовов.

<Tabs>
  <Tab title="Dashboard">
    1. Перейдите в **Observe → Tools**.
    2. Фильтруйте по окружению, названию инструмента, агенту или ID сеанса.
    3. Проверьте задержку и распределение инструментов.
    4. Выберите точку на графике или сегмент инструмента, чтобы открыть соответствующие события и сеансы.

    ![Страница Tools, показывающая задержку, распределение успехов и ошибок, и распределение вызовов инструментов.](/images/dashboard/tools.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list tools
    fp events --event-type tool_use,tool_result --env production --since 24h
    fp --json events --full --session-id <session-id> --all
    ```
  </Tab>
</Tabs>
