Используйте политику только после того, как сможете описать небезопасное действие и легитимные действия, которые должны остаться разрешёнными.

<Tabs>
  <Tab title="Dashboard">
    <Steps>
      <Step title="Создайте политику">
        Перейдите в **Admin → policy editor**. Начните с демо-политики, проверьте или отредактируйте её исходный код, затем выберите **publish version**. Публикация создаёт неизменяемую версию, которую вы можете развернуть на машинах.

        ![Представление редактора политик с демо-политикой, готовой к публикации как неизменяемую версию.](/images/dashboard/policy-editor.png)
      </Step>
      <Step title="Разверните её на машине">
        Перейдите в **Admin → enforcement**, разверните целевую машину и выберите **edit this machine**. Добавьте опубликованную демо-политику, закрепите её версию, выберите **observe** и примените развёртывание.

        ![Редактор развёртывания машины с выбранной опубликованной версией политики в режиме наблюдения перед применением развёртывания.](/images/dashboard/enforcement-editor.png)
      </Step>
      <Step title="Проверьте политику">
        Запустите новый сеанс агента на этой машине, затем откройте **Observe → policy**. Выберите машину и подтвердите, что демо-политика отображается в распределении политик и временной шкале решений. Режим наблюдения записывает, что сделала бы политика, без блокировки действия.

        ![Страница Policy, отображающая итоги решений, активность применения политики с течением времени, а также локальные и облачно-управляемые распределения политик.](/images/dashboard/policy-observe.png)
      </Step>
    </Steps>
  </Tab>
  <Tab title="CLI">
    Создание облачных политик и развёртывание флота являются административными рабочими процессами. Используйте локальный CLI для проверки той же политики перед её публикацией:

    ```bash
    failproofai policies --install --custom ./payment-retry.policies.ts \
      --cli claude --scope project
    failproofai config --status
    ```

    Используйте `fp` для проверки решений по политикам, видимых облаком:

    ```bash
    fp events --event-type hook_completed --env production --since 24h
    fp sessions --env production --since 24h
    ```

    Cloud CLI не предоставляет маршруты развёртывания применения, доступные только root. Публикуйте версии из **Admin → policy editor** и развёртывайте их из **Admin → enforcement**.
  </Tab>
</Tabs>
