## Три строки, для любого фреймворка

<CodeGroup>
```bash LangGraph
pip install 'failproofai-sdk[langgraph]'
```

```bash CrewAI
pip install 'failproofai-sdk[crewai]'
```

```bash LlamaIndex
pip install 'failproofai-sdk[llamaindex]'
```

```bash Pydantic AI
pip install 'failproofai-sdk[pydantic-ai]'
```

```bash Custom agents
pip install failproofai-sdk
```
</CodeGroup>

```python
import failproofai_sdk

failproofai_sdk.configure(environment="production")
failproofai_sdk.instrument()          # определяет импортированные вами фреймворки

with failproofai_sdk.session():
    ...                               # ваш существующий вызов агента, без изменений
```

Никаких декораторов на ваших функциях, никаких callback'ов, передаваемых вашим вызовам, никаких id'ов, пронизывающих ваш код. Отличается только вызов внутри session:

<Tabs>
  <Tab title="LangGraph">
    ```python
    graph.invoke({"messages": [HumanMessage("...")]})
    ```
  </Tab>
  <Tab title="CrewAI">
    ```python
    Crew(agents=[analyst, writer], tasks=[gather, summarise]).kickoff()
    ```
  </Tab>
  <Tab title="LlamaIndex">
    ```python
    await agent.run("...")        # под `async with failproofai_sdk.session():`
    ```
  </Tab>
  <Tab title="Pydantic AI">
    ```python
    agent.run_sync("...")
    ```
  </Tab>
  <Tab title="Custom agents">
    ```python
    with failproofai_sdk.agent("planner"):
        with failproofai_sdk.tool_call("search", input={"q": q}) as t:
            t.output = search(q)
    ```
  </Tab>
</Tabs>

Дополнительная установка нужна для **фреймворка**. Каждый адаптер поставляется в базовом пакете, поэтому проекту, который уже имеет свой фреймворк, не нужна никаких дополнительных установок.

## Проверьте доставку

Запустите одну инструментированную сессию, затем откройте **Observe → Sessions** и выберите вашу среду. Запуск появится как восстановленная трассировка.

Если ничего не приходит, проверьте подключение машины с помощью `failproofai config --status`. Смотрите [Set up capture](/ru/start/setup).

<Warning>
  Не проверяйте директорию spool для подтверждения доставки. Daemon Failproof собирает и удаляет каждый пакет за миллисекунды, поэтому чтение директории может конкурировать с сборщиком и показывать намного меньше событий, чем было выпущено.
</Warning>
