## Перед началом

Два условия, которые предполагает этот путь, ни одно из которых код ниже не выполняет за вас:

| Требование | Причина |
| --- | --- |
| Python 3.10 или новее | Минимальная версия, заявленная SDK. |
| Машина настроена с помощью `failproofai config` | Эта команда устанавливает демон failproofaid, и только демон может отправить то, что пишет SDK. Без него пакеты накапливаются в директории spool и никогда не уходят. |

<Note>
  **Этот путь только записывает; он не применяет правила.** SDK захватывает то, что сделал ваш агент. Политики срабатывают из хука внутри CLI агента, поэтому применение правил к агенту платформы означает установку хука в ваш собственный runtime — см. [Policies](/ru/policies/overview).
</Note>

## Три строки, любая платформа

<CodeGroup>
```bash LangGraph
pip install 'failproofai-sdk[langgraph]'
```

```bash CrewAI
pip install 'failproofai-sdk[crewai]'
```

```bash LlamaIndex
pip install 'failproofai-sdk[llamaindex]'
```

```bash Pydantic AI
pip install 'failproofai-sdk[pydantic-ai]'
```

```bash Custom agents
pip install failproofai-sdk
```
</CodeGroup>

```python
import failproofai_sdk

failproofai_sdk.configure(environment="production")
failproofai_sdk.instrument()          # обнаруживает импортированные вами платформы

with failproofai_sdk.session():
    ...                               # ваш существующий вызов агента, без изменений
```

Никаких декораторов на ваших функциях, никаких обратных вызовов, передаваемых вашим вызовам, никаких идентификаторов, проходящих через ваш код. Отличается только вызов внутри сессии:

<Tabs>
  <Tab title="LangGraph">
    ```python
    graph.invoke({"messages": [HumanMessage("...")]})
    ```
  </Tab>
  <Tab title="CrewAI">
    ```python
    Crew(agents=[analyst, writer], tasks=[gather, summarise]).kickoff()
    ```
  </Tab>
  <Tab title="LlamaIndex">
    ```python
    await agent.run("...")        # под `async with failproofai_sdk.session():`
    ```
  </Tab>
  <Tab title="Pydantic AI">
    ```python
    agent.run_sync("...")
    ```
  </Tab>
  <Tab title="Custom agents">
    ```python
    with failproofai_sdk.agent("planner"):
        with failproofai_sdk.tool_call("search", input={"q": q}) as t:
            t.output = search(q)
    ```
  </Tab>
</Tabs>

Дополнительная установка — это **платформа**. Каждый адаптер поставляется в базовом пакете, поэтому проект, у которого уже есть его платформа, не нуждается в дополнительных установках вообще.

## Проверьте прибытие

Запустите одну инструментированную сессию, затем откройте **Observe → Sessions** и выберите вашу среду. Запуск появляется как восстановленная трассировка.

Если ничего не приходит, подтвердите, что машина настроена и подключена с помощью `failproofai config --status`. Если это не так, запустите `failproofai config`. См. [Choose your setup](/ru/start/setup).

<Warning>
  Не проверяйте директорию spool для подтверждения доставки. Демон Failproof собирает и удаляет каждый пакет в течение миллисекунд, поэтому чтение её приводит к гонке с коллектором и показывает намного меньше событий, чем было выдано.
</Warning>

Чтобы доказать, что SDK вообще пишет, сначала остановите демон, затем запустите вашу сессию и посмотрите в `~/.failproofai/custom-agents/events/`. С работающим демоном пустая директория — это здоровое состояние.

<CodeGroup>
```bash Linux
sudo systemctl stop failproofaid@$USER
```

```bash macOS
sudo launchctl bootout system/ai.failproof.failproofaid.$USER
```
</CodeGroup>

Запустите `failproofai config` после этого, чтобы вернуть его. Пока демон остановлен, события хука на этой машине не имеют оценщика и отклоняются, поэтому останавливайте его только столько, сколько занимает проверка.
