Этот быстрый старт подключает одну машину к отправке сеансов, запускает аудит и развёртывает политику. Используйте skill для настройки Failproof AI или выполните шаги вручную. Вам нужна Node.js версии 20.9 или новее.

<Tabs>
  <Tab title="Использовать skill">
    <Steps>
      <Step title="Установить skills Failproof AI">
        ```bash
        npx skills add FailproofAI/skills
        ```
      </Step>
      <Step title="Попросите агента настроить всё">
        ```text
        Set up Failproof AI for this project, connect this machine, install the right hooks and policies, and verify that a session arrives.
        ```

        Агент проверит проект, выберет подходящую интеграцию, выполнит настройку и проверит её. Ознакомьтесь с [репозиторием skills FailproofAI](https://github.com/FailproofAI/skills), чтобы узнать о других skills и расширенных вариантах установки.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Ручная настройка">
    ## Перед началом

1. Откройте [панель управления Failproof AI](https://app.befailproof.ai) и создайте аккаунт или войдите с помощью рабочей почты.
2. Перейдите в **Administration → Keys** и создайте ключ с разрешениями `events:add` и `policies:pull`.
3. Скопируйте одноразовый секрет и сохраните его на целевой машине:

```bash
export FAILPROOFAI_KEY="<one-time-secret>"
```

    ## Установка

<Steps>
  <Step title="Установить и подключить Failproof AI">
    ```bash
    npm install -g failproofai
    failproofai config --connect https://app.befailproof.ai --token "$FAILPROOFAI_KEY"
    ```

    Транскрипты сеансов отправляются по умолчанию. Добавьте `--no-transcripts`, чтобы отправлять активность hooks и решения политик без содержимого транскриптов.

    Если на этой машине уже есть история агента, просмотрите и импортируйте последние семь дней, затем дождитесь завершения доставки. Пропустите этот шаг на новой машине.

    ```bash
    failproofai backfill --since 7d --dry-run
    failproofai backfill --since 7d
    failproofai flush --wait
    ```

    Откройте **Sessions** в Failproof AI и выберите импортированный сеанс.
  </Step>
  <Step title="Установить hooks агента и политики">
    Это подключает Failproof AI к CLI вашего агента и устанавливает встроенные политики. Используйте их, чтобы увидеть локальные решения политик и попробовать принудительное применение перед тем, как Failproof AI проведёт аудит ваших сеансов и напишет политики для ваших агентов.

    Позвольте установщику определить ваш CLI агента или укажите его явно.

    ```bash
    failproofai policies --install --cli claude --scope user
    ```
  </Step>
  <Step title="Провести аудит поведения">
    Следуйте инструкциям в [Проведите первую проверку сбоев](/ru/start/first-audit). Используйте конкретную цель, например поиск сеансов, где агент повторил неудачный инструмент, не изменив свой подход.
  </Step>
  <Step title="Предотвратить сбой">
    Следуйте инструкциям в [Предотвратите первый сбой с помощью политики](/ru/start/first-policy). Начните в режиме наблюдения, проверьте совпадения, затем включите принудительное применение проверенной версии.
  </Step>
</Steps>

<Check>
  Выполните `failproofai config --status`. Здоровая конфигурация выведет информацию о подключении к облаку, состояние демона и включено ли принудительное применение.
</Check>
