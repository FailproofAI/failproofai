Этот быстрый старт настроит одну машину на отправку сеансов, запустит аудит и развернёт политику. Используйте умение для установки Failproof AI или следуйте ручным шагам.

**Какой путь для вас?** Если ваш агент работает в одной из 12 поддерживаемых [оболочек](/ru/reference/harnesses) — кодирующий CLI или шлюз типа Hermes или OpenClaw — следуйте шагам ниже; вам нужен Node.js 20.9 или позже. Если ваш агент не имеет оболочки, используйте [Python SDK](/ru/reference/python-sdk) для трассировки и аудитов, затем вернитесь к разделу [Запустите первую проверку сбоев](/ru/start/first-audit); для принудительного применения на этом пути требуется хук в вашей среде выполнения.

<Tabs>
  <Tab title="Использовать умение">
    <Steps>
      <Step title="Установите умения Failproof AI">
        ```bash
        npx skills add FailproofAI/skills
        ```
      </Step>
      <Step title="Попросите агента всё настроить">
        ```text
        Set up Failproof AI for this project, connect this machine, install the right hooks and policies, and verify that a session arrives.
        ```

        Ваш агент проверит проект, выберет нужную интеграцию, выполнит настройку и проверит её. Смотрите [репозиторий умений FailproofAI](https://github.com/FailproofAI/skills) для отдельных умений и продвинутых вариантов установки.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Ручная установка">
    ## Перед началом

1. Откройте [панель управления Failproof AI](https://app.befailproof.ai) и создайте аккаунт или войдите со своей рабочей почтой.
2. Перейдите в **Administration → Keys** и создайте ключ с правами `events:add` и `policies:pull`.
3. Скопируйте одноразовый секрет и сохраните его на целевой машине:

```bash
export FAILPROOFAI_KEY="<one-time-secret>"
```

    ## Установка

<Steps>
  <Step title="Установите и подключите Failproof AI">
    ```bash
    npm install -g failproofai
    failproofai config --connect https://app.befailproof.ai --token "$FAILPROOFAI_KEY"
    ```

    Транскрипты сеансов отправляются по умолчанию. Добавьте `--no-transcripts` для отправки активности хуков и решений политик без содержимого транскриптов.

    Если на этой машине уже есть история агента, просмотрите и импортируйте последние семь дней, затем дождитесь завершения доставки. Пропустите этот шаг на новой машине.

    ```bash
    failproofai backfill --since 7d --dry-run
    failproofai backfill --since 7d
    failproofai flush --wait
    ```

    Откройте **Sessions** в Failproof AI и выберите импортированный сеанс.
  </Step>
  <Step title="Установите хуки агента и политики">
    Это подключит Failproof AI к вашей оболочке и установит 40 встроенных политик. Используйте их для просмотра локальных решений политик и тестирования принудительного применения до того, как Failproof AI проведёт аудит ваших сеансов и напишет политики для ваших агентов.

    Позвольте установщику обнаружить вашу оболочку или укажите её явно. Каждая из 12 является допустимым значением `--cli` — `claude`, `codex`, `copilot`, `cursor`, `opencode`, `pi`, `hermes`, `openclaw`, `factory`, `devin`, `antigravity`, `goose`.

    ```bash
    failproofai policies --install --cli claude --scope user     # кодирующий CLI
    failproofai policies --install --cli hermes --scope user     # шлюз Slack/Telegram
    ```

    Блокирование вызова инструмента перед его запуском проверяется на всех 12. Врата конца хода проверяются на 8 — смотрите [возможность принудительного применения](/ru/reference/harnesses#enforcement-capability) для матрицы по оболочкам.
  </Step>
  <Step title="Проведите аудит поведения">
    Следуйте разделу [Запустите первую проверку сбоев](/ru/start/first-audit). Используйте конкретную цель, такую как "найти сеансы, где агент повторил неудачный вызов инструмента без изменения своего подхода."
  </Step>
  <Step title="Предотвратите сбой">
    Следуйте разделу [Предотвратите первый сбой с помощью политики](/ru/start/first-policy). Начните в режиме наблюдения, проверьте совпадения, затем примените проверенную версию.
  </Step>
</Steps>

</Check>
