Этот быстрый старт настроит одну машину на отправку сессий, запустит аудит и развернет политику. Используйте навык для установки Failproof AI или следуйте ручным шагам. Вам нужен Node.js версии 20.9 или выше.

<Tabs>
  <Tab title="Используйте навык">
    <Steps>
      <Step title="Установите навыки Failproof AI">
        ```bash
        npx skills add FailproofAI/skills
        ```
      </Step>
      <Step title="Попросите вашего агента все настроить">
        ```text
        Set up Failproof AI for this project, connect this machine, install the right hooks and policies, and verify that a session arrives.
        ```

        Ваш агент проинспектирует проект, выберет релевантную интеграцию, выполнит настройку и проверит её. Смотрите [репозиторий навыков FailproofAI](https://github.com/FailproofAI/skills) для отдельных навыков и опций расширенной установки.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Ручная установка">
    ## Перед началом

1. Откройте [панель управления Failproof AI](https://app.befailproof.ai) и создайте аккаунт или войдите со своей рабочей почтой.
2. Перейдите в **Administration → Keys** и создайте ключ с правами `events:add` и `policies:pull`.
3. Скопируйте одноразовый секрет и сохраните его на целевой машине:

```bash
export FAILPROOFAI_KEY="<one-time-secret>"
```

    ## Установка

<Steps>
  <Step title="Установите и подключите Failproof AI">
    ```bash
    npm install -g failproofai
    failproofai config --connect https://app.befailproof.ai --token "$FAILPROOFAI_KEY"
    ```

    Транскрипты сессий отправляются по умолчанию. Добавьте `--no-transcripts` для отправки активности хуков и решений политик без содержимого транскриптов.

    Если на этой машине уже есть история агента, предпросмотрите и импортируйте последние семь дней, затем дождитесь завершения доставки. Пропустите этот шаг на новой машине.

    ```bash
    failproofai backfill --since 7d --dry-run
    failproofai backfill --since 7d
    failproofai flush --wait
    ```

    Откройте **Sessions** в Failproof AI и выберите импортированную сессию.
  </Step>
  <Step title="Установите хуки агента и политики">
    Это присоединит Failproof AI к CLI вашего агента и установит встроенные политики. Используйте их, чтобы видеть локальные решения политик и попробовать принудительное применение до того, как Failproof AI проведет аудит ваших сессий и напишет политики для ваших агентов.

    Позвольте установщику автоматически обнаружить CLI вашего агента или укажите его явно.

    ```bash
    failproofai policies --install --cli claude --scope user
    ```
  </Step>
  <Step title="Проведите аудит поведения">
    Следуйте [Запустите первую проверку на сбои](/ru/start/first-audit). Используйте конкретную цель, такую как «найти сессии, где агент повторил попытку неудачного инструмента без изменения своего подхода».
  </Step>
  <Step title="Предотвратите сбой">
    Следуйте [Предотвратите первый сбой с помощью политики](/ru/start/first-policy). Начните в режиме наблюдения, проверьте совпадения, затем примените проверенную версию.
  </Step>
</Steps>

<Check>
  Запустите `failproofai config --status`. Здоровая установка сообщает о облачном подключении, состоянии демона и о том, приостановлено ли принудительное применение.
</Check>
