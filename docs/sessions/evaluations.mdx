Results from every evaluation, hosted or from your own worker, land in the same places.

## Compare scores over time

<Tabs>
  <Tab title="Dashboard">
    Go to **analyse → checks → evals** and open an evaluation. Its page gathers everything about that one evaluation:

    - KPI tiles for today, the last 7 days, and the last 30 days.
    - A chart of the score per day, split by environment or agent, for a statistic you choose: avg, p50, p75, p90, p95, p99, min, max, stddev, or mode.
    - **lowest scores today** (or **failed today** for a pass/fail evaluation), each with the evaluator's reasoning.
    - **latest runs**: score, agent, session, status, how long it took, and when it ran, failures included.

    ![The evaluations page: recent runs tagged customer, a score over time chart with reference lines at 0.5 and 0.8, and one series averaging finished_clean across all agents and environments.](/images/dashboard/evaluations-chart.png)

    The split, statistic, and range (7, 30, or 90 days, or a custom window) live in the URL, so whoever opens a copied link sees exactly the comparison you built.
  </Tab>
  <Tab title="CLI">
    ```bash
    fp evals --agent-id checkout-agent --aggregate
    fp evals --aggregate --env production --status error
    fp evals --score helpfulness:0.8.. --since 7d
    ```

    Add global `--json` before `evals` for automation, for example `fp --json evals --aggregate --env production`.
  </Tab>
</Tabs>

Switch between **avg** and **p90** to see whether a good average is hiding a bad tail, and split by agent or environment to compare production and staging on one axis. Costs, latencies, and token counts, which carry units, chart on the [metrics](/sessions/metrics) page (**analyse → checks → evals**, then **metrics**), one chart per unit.

## See why a session scored low

Open a session from **trace → sessions**; the grid carries each session's scores and filters by score range. The session's right rail leads with the evaluation summary, then a bar per score with the evaluator's reasoning under it.

![A session detail view showing evaluation scores and reasoning beside the complete trace.](/images/dashboard/session-detail.png)

## Ask the failproof agent

Ask about evaluation data in plain English: "tell me about some of the recent evaluations", or which agents' scores are slipping. The [failproof agent](/sessions/assistant) reads and analyzes the results and answers with tables you can follow up on, and a question worth keeping can become a [query](/sessions/queries) or a [dashboard](/sessions/dashboards).

![The evaluations page beside the failproof agent, which answers "tell me about some of the recent evaluations" with a summary of totals, statuses, and scores.](/images/dashboard/evaluations-assistant.png)

## Watch and act

- **Dashboards**, under **trace → dashboards**, trend the scores you feature, per agent and environment, for the whole organization.

  ![A quality dashboard showing average evaluation scores and trends over time.](/images/dashboard/dashboard-quality.png)

- **Alerts** notify you when a score crosses a threshold. See [alerts](/audits/alerts).
- When a score declines across many sessions, [run an audit](/audits/run) to find out why; when the cause is a repeatable action, [write a policy](/policies/editor).
