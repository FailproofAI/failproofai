A hook is a point where an agent asks Failproof AI for a decision. Hook activity records the event, policy, outcome, and evaluation time.

## Investigate hook activity

<Tabs>
  <Tab title="Dashboard">
    Go to **Observe → Hooks**. Filter by environment, event, agent, or session.

    ![The Hooks page showing latency grouped by hook name and trigger event.](/images/dashboard/hooks.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp guardrails summary --since 24h
    fp --json events --full --event-type hook_completed --session-id <session-id> --all --limit 500
    fp list hooks
    ```
  </Tab>
</Tabs>

By default, every `deny` and `instruct` decision is sent in full. Repeated allows are grouped to reduce noise. Set `collector.hooks_verbosity` in `~/.failproofai/config.json` to `all`, `decisions`, or `off`.

<Warning>
  Hook activity proves that evaluation ran, not that the harness could block that event. See [enforcement capability](/reference/harnesses#enforcement-capability). An unlisted harness-event pair is unverified.
</Warning>
