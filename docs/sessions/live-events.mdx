Live events shows activity as agents run: model calls, tools, errors, human input, hooks, and policy decisions.

## Watch activity

Go to **Observe → Live events**, or run:

```bash
fp events --since 1h
fp events --event-type tool_use,tool_result --since 1h
fp --json events --full --session-id <session-id> --all --limit 2000
```

Use `--full` when you need payload contents. The light feed is faster and enough for most filtering.

Common event types include:

- `session_start` and `session_end`
- `model_request` and `model_response`
- `tool_use` and `tool_result`
- `hook_triggered` and `hook_completed`
- `error`
- `human_wait` and `human_input`
- `agent_pause` and `agent_resume`

## If events do not appear

```bash
failproofai flush --wait
failproofai config --status
failproofai backfill --since 30d --dry-run
```

The default environment is `local`. A filter for `production` returns nothing until you change the environment label.

For an agent outside a supported harness, use the [Python SDK](/reference/custom-agents).
