Policy decisions explains what enforcement did. Use it to verify a rollout, measure block rate, and find unguarded activity.

<Tabs>
  <Tab title="Dashboard">
    1. Go to **fix → activity** and choose the time range and optionally one machine.
    2. Review checked, blocked, block rate, steered, would block, reporting machines, and unguarded machines.
    3. Review the row per policy. What each machine is set to run is under **fix → deploy policies**.
    4. Select a chart point or number to open the decisions and their sessions.

    ![The Policy page showing decision totals, a machine filter, enforcement activity over time, and the policy mapping table.](/images/dashboard/policy-observe.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp events --event-type hook_completed --env production --since 24h
    fp events --search "deny" --since 24h
    failproofai config --status
    ```

    Use `failproofai` for the machine's local enforcement state and `fp` for Cloud event investigation.
  </Tab>
</Tabs>
