title: "Tools"
description: "Find slow, failing, or overused tools across agent runs."
icon: "wrench"
---

Tools shows what agents call, how often calls fail, and which sessions they affect.

Tool names come from each agent harness, so the same capability may have different names. For example, a shell call can appear as `Bash`, `exec`, `Shell`, `terminal`, or `run_command`. Run `fp list tools` before building a filter.

<Tabs>
  <Tab title="Dashboard">
    Go to **Observe → Tools**. Filter by environment, tool, agent, or session.

    ![The Tools page showing latency, success and failure breakdowns, and tool-call distribution.](/images/dashboard/tools.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list tools
    fp events --event-type tool_use,tool_result --since 24h
    fp errors --event-type tool_result --since 24h
    fp --json events --full --event-type tool_use,tool_result --session-id <session-id> --all --limit 2000
    ```

    Use `--full` when you need payload fields such as per-call duration.
  </Tab>
</Tabs>

Use this page to find repeated failures, compare working and failing runs, or confirm that a policy-targeted tool is actually used.
