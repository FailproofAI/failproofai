An **audit** analyzes sessions for recurring failures. Alerts monitor known conditions;
audits search for patterns you have not configured in advance.

---

## Set one up

<Steps>

<Step title="Create it">
  Open **analyse → Audits** and create one. Give it a scope (which agents, which
  environment) and a cadence.

  From the terminal instead:

  ```bash
  agenteye audits create nightly-review --schedule-interval-secs 86400 \
                                        --schedule-anchor 2026-08-15T02:00:00Z
  ```
</Step>

<Step title="Pick a sensitivity">
  Choose **low**, **medium**, or **high**. Start with **medium**.
</Step>

<Step title="Set the schedule anchor, and know it is UTC">
  The schedule is `anchor + N × interval`. **Run now** does not change it.

  Anchors use UTC and do not adjust for daylight saving time.

  <Tip>
    Stagger audit anchors. Audits with the same anchor may queue.
  </Tip>
</Step>

<Step title="Run it now">
  Use **Run now** to start an additional run.
</Step>

</Steps>

---

## Read what it found

A run checks for these failure classes:

| It looks for | Which shows up as |
|---|---|
| **Error clusters** | the same failure repeating under one root cause |
| **Drift** | behaviour sliding away from a known-good window |
| **Goal failure** | runs that finished cleanly and never did the job |
| **Tool misuse** | the wrong tool, bad arguments, loops that burn calls |
| **Cost/quality trade-offs** | where you are overpaying for output you could get cheaper |
| **Coverage gaps** | behaviour no eval or alert is watching |

Findings include supporting sessions and the query that produced them. Review that evidence
before acting on a finding.

---

## Turn a finding into work

A finding can become an **issue** with a state, assignee, and timeline. Recurrence reopens
the issue.

You can also create a prefilled recurrence alert from a finding.

<Note>
  Set default alert recipients under **admin → Settings**. Failed audit runs notify this
  list even when the audit has no email channel.
</Note>

## No account yet? Score this machine in one command

To audit local transcripts without an account, run:

```bash
npx -y failproofai audit
```

The command serves a local report at `http://localhost:8020/audit`. It uploads nothing.
Unlike Cloud audits, it is one-shot and limited to one machine. [Local audit →](/audit)
