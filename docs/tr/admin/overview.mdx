Yönetim, Failproof AI'ı bir ekip genelinde çalıştırmak için gerekli kontrolleri içerir. Çoğu kullanıcı Oturumlar, Denetimler ve İlkeler bölümlerinde kalabilir; yöneticiler erişim ve işletme sınırlarını yönetmek için bu bölümü kullanır.

<Tabs>
  <Tab title="Pano">
    Cloud kenar çubuğunun **Yönetim** bölümünde **ilke editörü**, **zorlama**, **kullanım**, **anahtarlar**, **kullanıcılar** ve **ayarlar**'ı kullanın. Kilitli bir öğe, hesabınızın okuma izni eksik olduğunu gösterir.

    ![Cloud kenar çubuğunun ilke editörü, zorlama, kullanım, anahtarlar, kullanıcılar ve ayarlarıyla Yönetim bölümü.](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    Genel seçenekleri komuttan önce yerleştirin, örneğin `fp --org reliability-team --json usage`.
  </Tab>
</Tabs>
