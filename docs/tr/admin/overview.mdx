Yönetim, Failproof AI'ı bir ekip genelinde çalıştırmak için gereken kontrolleri içerir. Çoğu kullanıcı Oturumlar, Denetimler ve İlkeler bölümlerinde kalabilir; yöneticiler bu bölümü erişim ve işletme sınırlarını yönetmek için kullanır.

<Tabs>
  <Tab title="Dashboard">
    Cloud kenar çubuğunun **Admin** bölümünü **policy editor**, **enforcement**, **usage**, **keys**, **users** ve **settings** için kullanın. Kilitli bir öğe, hesabınızın okuma izni olmadığını gösterir.

    ![Cloud kenar çubuğunun Admin bölümü policy editor, enforcement, usage, keys, users ve settings ile.](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    Global seçenekleri komutu çalıştırmadan önce yazın, örneğin `fp --org reliability-team --json usage`.
  </Tab>
</Tabs>
