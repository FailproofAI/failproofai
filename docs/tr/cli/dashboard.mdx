---
title: Oturumları görüntüle
description: "Aracı oturumlarına göz atmak ve politikaları yönetmek için panoyu başlat"
---

```bash
failproofai
```

Web panosunu `http://localhost:8020` adresinde başlatır.

## Seçenekler

| Bayrak | Açıklama |
|------|-------------|
| `--port <number>` | Dinlenecek port (varsayılan: `8020`) |
| `--allowed-origins <origins>` | Dev kaynaklarına erişim izni verilen virgülle ayrılmış konaklar/IP'ler |

Panoyu varsayılan olmayan bir Claude proje klasörüne işaret etmek için, başlatırken `CLAUDE_PROJECTS_PATH` ortam değişkenini ayarlayın.

## Örnekler

```bash
# Farklı bir portta başlat
failproofai --port 9000

# Ortam değişkeni aracılığıyla özel bir Claude projeleri yolu kullan
CLAUDE_PROJECTS_PATH=~/my-claude-projects failproofai
```
