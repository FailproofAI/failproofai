## Dashboard

| Değişken | Açıklama |
|----------|----------|
| `PORT` | Dashboard portu (varsayılan: `8020`) |
| `CLAUDE_PROJECTS_PATH` | Claude Code proje klasörlerinin bulunduğu yeri geçersiz kıl |
| `FAILPROOFAI_DISABLE_PAGES=policies,projects` | Gizlenecek dashboard sayfaları (virgülle ayrılmış) |
| `FAILPROOFAI_ALLOWED_DEV_ORIGINS` | Dev kaynaklarına erişim izni verilen ana bilgisayarlar/IP'ler. `--allowed-origins` ile aynı. |

## Logging

| Değişken | Açıklama |
|----------|----------|
| `FAILPROOFAI_LOG_LEVEL=info\|warn\|error` | Sunucu günlük düzeyi (varsayılan: `warn`) |
| `FAILPROOFAI_HOOK_LOG_FILE` | Özel hook günlük dosyası yolu veya varsayılan için `true` (`~/.failproofai/logs/hooks.log`) |

## Telemetri

failproofai varsayılan olarak anonim kullanım telemetrisi raporlar. Bunu kapatmak için iki yol vardır ve en kısıtlayıcı olanı geçerli olur — bir ortam değişkeni, config dosyasının kapattığı bir şeyi asla yeniden etkinleştiremez.

| Değişken | Açıklama |
|----------|----------|
| `FAILPROOFAI_TELEMETRY_DISABLED=1` | Bu işlem için anonim kullanım telemetrisini devre dışı bırak |

Makine için kalıcı olarak devre dışı bırakmak için bunu `~/.failproofai/config.json` dosyasına ekleyin:

```json
{
  "telemetry": {
    "enabled": false
  }
}
```

<Note>
Config dosyası **failproofaid daemon** çalıştırıyorsanız kullanılacak seçenektir.
Daemon sistem kapsamında bir hizmettir ve ortamı shell'den dışa aktarılan
değişkenleri içermez — bu nedenle `FAILPROOFAI_TELEMETRY_DISABLED` ona ulaşamaz.
`[telemetry] enabled = false` hem CLI hem de daemon tarafından okunur.
</Note>

Daemon yalnızca kendi **yaşam döngüsünü** raportar: başladığı (ve önceki çalıştırma temiz bir şekilde çıkıp çıkmadığı), durduğu, değerlendirme çalışanı ne zaman oluşturulduğu veya yeniden başlatıldığı, bir toplayıcı görev başarısız olduğunda ve bulut politikası çekme sonucu. Bunlar düşük kardinaliteli değerler ve sayılar taşır — asla dosya yolu, komut, politika, istem veya transkriptten okunan herhangi bir şey değil. Her araç çağrısı için olay yoktur.

## Authentication

| Değişken | Açıklama |
|----------|----------|
| `FAILPROOF_API_URL` | Dashboard auth diyaloğu tarafından kullanılan api-server temel URL'sini geçersiz kıl. Varsayılan olarak `https://api.befailproof.ai`; yerel api-server çalıştırırken `http://localhost:8080` (veya başka bir yer) olarak ayarlayın. |
| `FAILPROOFAI_AUTH_DIR` | `auth.json` dosyasının saklandığı yeri geçersiz kıl (varsayılan: `~/.failproofai`). Çoğunlukla izole testler için faydalıdır. |

## İlk çalıştırma istemi

| Değişken | Açıklama |
|----------|----------|
| `FAILPROOFAI_NO_FIRST_RUN=1` | İlk bare `failproofai` çağrısında politikaları yüklemeyi teklif eden istemi atla |

## LLM (politika değerlendirmesi için)

| Değişken | Açıklama |
|----------|----------|
| `FAILPROOFAI_LLM_BASE_URL` | LLM API uç noktası (varsayılan: `https://api.openai.com/v1`) |
| `FAILPROOFAI_LLM_API_KEY` | LLM tarafından desteklenen politikalar için API anahtarı |
| `FAILPROOFAI_LLM_MODEL` | Model adı (varsayılan: `gpt-4o-mini`) |
