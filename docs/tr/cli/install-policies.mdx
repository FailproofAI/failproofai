---
title: Politikaları yükle
description: "Politikaları etkinleştirin, böylece her bir aracı çağrısında çalışsınlar"
---

```bash
failproofai policies --install [policy-names...] [options]
```

Yüklü aracı CLI'nızın (Claude Code, OpenAI Codex veya GitHub Copilot CLI _(beta)_) ayarlar dosyasına kanca girdileri yazarak failproofai'nin araç çağrılarını engellemesini sağlar.

Takma adlar: `failproofai p -i`

## Seçenekler

| Bayrak | Açıklama |
|------|-------------|
| `--cli claude\|codex\|copilot` | Yüklemek için aracı CLI(ler); boşlukla ayrılmış (örn. `--cli claude codex copilot`) veya tekrarlı. Yüklü CLI'ları algılamak ve istrompt göstermek için atlayın. |
| `--scope user` | Kullanıcı kapsamı ayarlar dosyasına yükle (Claude: `~/.claude/settings.json`; Codex: `~/.codex/hooks.json`; Copilot: `~/.copilot/hooks/failproofai.json`). Varsayılan. |
| `--scope project` | Proje kapsamı ayarlar dosyasına yükle (Claude: `<cwd>/.claude/settings.json`; Codex: `<cwd>/.codex/hooks.json`; Copilot: `<cwd>/.github/hooks/failproofai.json`). |
| `--scope local` | Yalnızca Claude — `<cwd>/.claude/settings.local.json` dosyasına yükle. Codex ve Copilot'ın `local` kapsamı yoktur. |
| `--custom <path>` / `-c` | Özel kanca politikalarını içeren JS dosyasının yolu |

## Davranış

- **Politika adı yok** - politika seçmek için etkileşimli istrompt açar
- **Belirli adlar** - bu politikaları etkinleştirir (zaten etkinleştirilmiş olanların üzerine eklenir)
- **`all`** - tüm mevcut politikaları etkinleştirir

Yükleme toplamalıdır: `--install` komutunu yeniden çalıştırmak mevcut olanları kaldırmadan yeni politikalar ekler.

## Örnekler

```bash
# Tüm varsayılan politikaları genel olarak yükle (etkileşimli)
failproofai policies --install

# Geçerli proje için belirli politikaları yükle
failproofai policies --install block-sudo sanitize-api-keys --scope project

# Tüm politikaları bir kerede etkinleştir
failproofai policies --install all

# Özel politikalar dosyasıyla yükle
failproofai policies --install --custom ./my-policies.js

# OpenAI Codex için yükle (proje kapsamı)
failproofai policies --install --cli codex --scope project

# GitHub Copilot CLI (beta) için geçerli proje için yükle
failproofai policies --install --cli copilot --scope project

# Üç CLI'nin tümü için bir kerede yükle
failproofai policies --install --cli claude codex copilot
```

`--custom <path>` sağlandığında, dosya hemen doğrulanır - en az bir kez `customPolicies.add()` çağrısı yapmalıdır. Çözümlenen yol `policies-config.json` dosyasına `customPoliciesPath` olarak kaydedilir.
