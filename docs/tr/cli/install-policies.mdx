---
title: İlkeleri yükle
description: "İlkeleri etkinleştirerek her agent araç çağrısında çalışmalarını sağlayın"
---

```bash
failproofai policies --install [policy-names...] [options]
```

Yüklü agent CLI'nizin (Claude Code, OpenAI Codex veya GitHub Copilot CLI _(beta)_) ayarlar dosyasına hook girdileri yazarak failproofai'nin araç çağrılarını kesintiye uğratmasını sağlar.

Takma adlar: `failproofai p -i`

## Seçenekler

| Bayrak | Açıklama |
|--------|----------|
| `--cli claude\|codex\|copilot` | Yükleneceği agent CLI'ler; boşlukla ayrılmış (ör. `--cli claude codex copilot`) veya tekrarlanan. Yüklü CLI'leri algılamak ve istemek için atla. |
| `--scope user` | Kullanıcı kapsamındaki ayarlar dosyasına yükle (Claude: `~/.claude/settings.json`; Codex: `~/.codex/hooks.json`; Copilot: `~/.copilot/hooks/failproofai.json`). Varsayılan. |
| `--scope project` | Proje kapsamındaki ayarlar dosyasına yükle (Claude: `<cwd>/.claude/settings.json`; Codex: `<cwd>/.codex/hooks.json`; Copilot: `<cwd>/.github/hooks/failproofai.json`). |
| `--scope local` | Yalnızca Claude — `<cwd>/.claude/settings.local.json` dosyasına yükle. Codex ve Copilot'un `local` kapsamı yoktur. |
| `--custom <path>` / `-c` | Özel hook ilkelerini içeren JS dosyasının yolu |

## Davranış

- **İlke adı yok** - ilkeleri seçmek için etkileşimli bir istem açar
- **Belirli adlar** - bu ilkeleri etkinleştirir (zaten etkinleştirilenlere eklenir)
- **`all`** - her kullanılabilir ilkeyi etkinleştirir

Kurulum toplamalıdır: `--install` komutunu yeniden çalıştırmak yeni ilkeler ekler ve mevcut olanları kaldırmaz.

## Örnekler

```bash
# Tüm varsayılan ilkeleri global olarak yükle (etkileşimli)
failproofai policies --install

# Mevcut proje için belirli ilkeleri yükle
failproofai policies --install block-sudo sanitize-api-keys --scope project

# Tüm ilkeleri bir kerede etkinleştir
failproofai policies --install all

# Özel ilkeler dosyası ile yükle
failproofai policies --install --custom ./my-policies.js

# OpenAI Codex için yükle (proje kapsamı)
failproofai policies --install --cli codex --scope project

# GitHub Copilot CLI (beta) için mevcut proje için yükle
failproofai policies --install --cli copilot --scope project

# Üç CLI için aynı anda yükle
failproofai policies --install --cli claude codex copilot
```

`--custom <path>` sağlandığında, dosya hemen doğrulanır - en az bir kez `customPolicies.add()` çağrısı yapmalıdır. Çözümlenen yol, `policies-config.json` dosyasına `customPoliciesPath` olarak kaydedilir.
