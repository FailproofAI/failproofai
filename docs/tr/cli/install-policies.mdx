---
title: Politikaları yükle
description: "Politikaları etkinleştir ve her agent araç çağrısında çalıştır"
---

```bash
failproofai policies --install [policy-names...] [options]
```

Yüklü agent CLI'nizin (Claude Code, OpenAI Codex veya GitHub Copilot CLI _(beta)_) ayarlar dosyasına hook girdileri yazar, böylece failproofai araç çağrılarını durdurur.

Takma adlar: `failproofai p -i`

## Seçenekler

| Bayrak | Açıklama |
|--------|----------|
| `--cli claude\|codex\|copilot` | Yüklü olacak Agent CLI'si(ları); boşlukla ayrılmış (örn. `--cli claude codex copilot`) veya tekrarlı. Yüklü CLI'leri algılamak ve seçim istemi göstermek için bırakın. |
| `--scope user` | Kullanıcı kapsamlı ayarlar dosyasına yükle (Claude: `~/.claude/settings.json`; Codex: `~/.codex/hooks.json`; Copilot: `~/.copilot/hooks/failproofai.json`). Varsayılan. |
| `--scope project` | Proje kapsamlı ayarlar dosyasına yükle (Claude: `<cwd>/.claude/settings.json`; Codex: `<cwd>/.codex/hooks.json`; Copilot: `<cwd>/.github/hooks/failproofai.json`). |
| `--scope local` | Yalnızca Claude — `<cwd>/.claude/settings.local.json` dosyasına yükler. Codex ve Copilot için `local` kapsamı yoktur. |
| `--custom <path>` / `-c` | Özel hook politikalarını içeren JS dosyasının yolu |

## Davranış

- **Politika adı yok** - politika seçmek için etkileşimli bir istem açar
- **Belirli adlar** - bu politikaları etkinleştirir (zaten etkinleştirilenlerle birlikte eklenir)
- **`all`** - kullanılabilir her politikayı etkinleştirir

Kurulum kümülatiftir: `--install` komutunu tekrar çalıştırmak yeni politikaları ekler ve mevcut olanları kaldırmaz.

## Örnekler

```bash
# Tüm varsayılan politikaları genel olarak yükle (etkileşimli)
failproofai policies --install

# Mevcut proje için belirli politikaları yükle
failproofai policies --install block-sudo sanitize-api-keys --scope project

# Tüm politikaları aynı anda etkinleştir
failproofai policies --install all

# Özel politikalar dosyasıyla yükle
failproofai policies --install --custom ./my-policies.js

# OpenAI Codex için yükle (proje kapsamı)
failproofai policies --install --cli codex --scope project

# GitHub Copilot CLI (beta) için mevcut proje için yükle
failproofai policies --install --cli copilot --scope project

# Üç CLI için de aynı anda yükle
failproofai policies --install --cli claude codex copilot
```

`--custom <path>` sağlandığında, dosya hemen doğrulanır — en az bir kez `customPolicies.add()` çağrı yapması gerekir. Çözümlenen yol, `policies-config.json` dosyasına `customPoliciesPath` olarak kaydedilir.
