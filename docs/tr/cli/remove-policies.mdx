---
title: İlkeleri kaldır
description: "Claude Code ayarlarından hook girdilerini kaldırın"
---

```bash
failproofai policies --uninstall [policy-names...] [options]
```

Claude Code'un `settings.json` dosyasından failproofai hook girdilerini kaldırır.

Takma adlar: `failproofai p -u`

## Seçenekler

| Bayrak | Açıklama |
|------|-------------|
| `--scope user` | Genel ayarlardan kaldırın (varsayılan) |
| `--scope project` | Proje ayarlarından kaldırın |
| `--scope local` | Yerel ayarlardan kaldırın |
| `--scope all` | Tüm kapsamlardan aynı anda kaldırın |
| `--custom` / `-c` | Yapılandırmadan `customPoliciesPath` kaldırın |

## Davranış

- **İlke adı yok** - ayar dosyasından tüm failproofai hook girdilerini kaldırır
- **Belirli adlar** - bu ilkeleri devre dışı bırakır ancak hook'ları yüklü tutar

## Örnekler

```bash
# Tüm hook'ları genel olarak kaldır
failproofai policies --uninstall

# Belirli bir ilkeyi devre dışı bırak (hook'ları yüklü tutar)
failproofai policies --uninstall block-sudo

# Hook'ları her kapsamdan kaldır
failproofai policies --uninstall --scope all

# Özel ilkeler yolunu kaldır
failproofai policies --uninstall --custom
```
