---
title: Politikaları Kaldır
description: "Claude Code'un ayarlarından hook girişlerini kaldırın"
---

```bash
failproofai policies --uninstall [policy-names...] [options]
```

failproofai hook girişlerini Claude Code'un `settings.json` dosyasından kaldırır.

Takma adlar: `failproofai p -u`

## Seçenekler

| Bayrak | Açıklama |
|------|-------------|
| `--scope user` | Genel ayarlardan kaldırın (varsayılan) |
| `--scope project` | Proje ayarlarından kaldırın |
| `--scope local` | Yerel ayarlardan kaldırın |
| `--scope all` | Tüm kapsamlardan aynı anda kaldırın |
| `--custom` / `-c` | Yapılandırmadan `customPoliciesPath` öğesini temizleyin |

## Davranış

- **Politika adı yok** - ayarlar dosyasından tüm failproofai hook girişlerini kaldırır
- **Belirli adlar** - bu politikaları devre dışı bırakır ancak hook'ları yüklü tutar

## Örnekler

```bash
# Tüm hook'ları genel olarak kaldırın
failproofai policies --uninstall

# Belirli bir politikayı devre dışı bırakın (hook'ları yüklü tutar)
failproofai policies --uninstall block-sudo

# Hook'ları her kapsamdan kaldırın
failproofai policies --uninstall --scope all

# Özel politikalar yolunu temizleyin
failproofai policies --uninstall --custom
```
