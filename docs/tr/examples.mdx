## Claude Code için hook'ları ayarlama

Failproof AI, Claude Code ile [hook'lar sistemi](https://docs.anthropic.com/en/docs/claude-code/hooks) aracılığıyla entegre olur. `failproofai policies --install` komutunu çalıştırdığınızda, Claude Code'un `settings.json` dosyasında her araç çağrısında tetiklenen hook komutları kaydedilir.

<Steps>
  <Step title="failproofai'yi yükleyin">
    ```bash
    npm install -g failproofai
    ```
  </Step>
  <Step title="Tüm yerleşik politikaları etkinleştirin">
    ```bash
    failproofai policies --install
    ```
  </Step>
  <Step title="Hook'ların kaydedildiğini doğrulayın">
    ```bash
    cat ~/.claude/settings.json | grep failproofai
    ```

    `PreToolUse`, `PostToolUse`, `Notification` ve `Stop` etkinlikleri için hook girdilerini görmelisiniz.
  </Step>
  <Step title="Claude Code'u çalıştırın">
    ```bash
    claude
    ```

    Politikalar artık her araç çağrısında otomatik olarak çalışır. Claude'a `sudo rm -rf /` komutunu çalıştırmasını söylemeyi deneyin - bloke edilecektir.
  </Step>
</Steps>

## Agents SDK için hook'ları ayarlama

[Agents SDK](https://docs.anthropic.com/en/docs/agents-sdk) ile geliştiriyorsanız, aynı hook sistemini programlı olarak kullanabilirsiniz.

<Steps>
  <Step title="failproofai'yi projenize yükleyin">
    ```bash
    npm install failproofai
    ```
  </Step>
  <Step title="Aracınızda hook'ları yapılandırın">
    Aracı işlemi oluştururken hook komutlarını iletin. Hook'lar, Claude Code'da olduğu gibi stdin/stdout JSON aracılığıyla tetiklenir:

    ```bash
    failproofai --hook PreToolUse   # her araçtan önce çağrılır
    failproofai --hook PostToolUse  # her araçtan sonra çağrılır
    ```
  </Step>
  <Step title="Aracınız için özel bir politika yazın">
    ```javascript
    import { customPolicies, allow, deny } from "failproofai";

    customPolicies.add({
      name: "limit-to-project-dir",
      description: "Keep the agent inside the project directory",
      match: { events: ["PreToolUse"] },
      fn: async (ctx) => {
        const path = String(ctx.toolInput?.file_path ?? "");
        if (path.startsWith("/") && !path.startsWith(ctx.session?.cwd ?? "")) {
          return deny("Agent is restricted to the project directory");
        }
        return allow();
      },
    });
    ```
  </Step>
  <Step title="Özel politikayı yükleyin">
    ```bash
    failproofai policies --install --custom ./my-agent-policies.js
    ```
  </Step>
</Steps>

## Yıkıcı komutları engelleme

En yaygın kurulum - aracıların geri döndürülemez hasara neden olmasını engellemek.

```bash
failproofai policies --install block-sudo block-rm-rf block-force-push block-curl-pipe-sh
```

Bunu ne yapar:
- `block-sudo` - tüm `sudo` komutlarını engeller
- `block-rm-rf` - özyinelemeli dosya silmeyi engeller
- `block-force-push` - `git push --force` komutunu engeller
- `block-curl-pipe-sh` - uzak betiklerin kabuğa aktarılmasını engeller

## Sır sızıntısını engelleme

Araçları araç çıktısında kimlik bilgilerini görmesinden veya sızmaktan koruma.

```bash
failproofai policies --install sanitize-api-keys sanitize-jwt sanitize-connection-strings sanitize-bearer-tokens
```

Bunlar `PostToolUse` etkinliğinde çalışır - bir araç çalıştıktan sonra, aracı görmeden önce çıktı temizlenir.

## Aracıların dikkat gerektirdiği durumlarda Slack uyarıları alın

Boşta uyarılarını Slack'e iletmek için bildirim hook'unu kullanın.

```javascript
import { customPolicies, allow, instruct } from "failproofai";

customPolicies.add({
  name: "slack-on-idle",
  description: "Alert Slack when the agent is waiting for input",
  match: { events: ["Notification"] },
  fn: async (ctx) => {
    const webhookUrl = process.env.SLACK_WEBHOOK_URL;
    if (!webhookUrl) return allow();

    const message = String(ctx.payload?.message ?? "Agent is waiting");
    const project = ctx.session?.cwd ?? "unknown";

    try {
      await fetch(webhookUrl, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({
          text: `*${message}*\nProject: \`${project}\``,
        }),
        signal: AbortSignal.timeout(5000),
      });
    } catch {
      // never block the agent if Slack is unreachable
    }

    return allow();
  },
});
```

Yükleyin:

```bash
SLACK_WEBHOOK_URL=https://hooks.slack.com/... failproofai policies --install --custom ./slack-alerts.js
```

## Araçları bir dalda tutma

Araçları dal değiştirmesinden veya korumalı dallara itme işlemini engelleme.

```javascript
import { customPolicies, allow, deny } from "failproofai";

customPolicies.add({
  name: "stay-on-branch",
  description: "Prevent the agent from checking out other branches",
  match: { events: ["PreToolUse"] },
  fn: async (ctx) => {
    if (ctx.toolName !== "Bash") return allow();
    const cmd = String(ctx.toolInput?.command ?? "");
    if (/git\s+checkout\s+(?!-b)/.test(cmd)) {
      return deny("Stay on the current branch. Create a new branch with -b if needed.");
    }
    return allow();
  },
});
```

## Commit'ten önce testleri zorunlu kılma

Araçları commit'ten önce testleri çalıştırması konusunda uyarma.

```javascript
import { customPolicies, allow, instruct } from "failproofai";

customPolicies.add({
  name: "test-before-commit",
  description: "Remind the agent to run tests before committing",
  match: { events: ["PreToolUse"] },
  fn: async (ctx) => {
    if (ctx.toolName !== "Bash") return allow();
    const cmd = String(ctx.toolInput?.command ?? "");
    if (/git\s+commit/.test(cmd)) {
      return instruct("Run tests before committing. Use `npm test` or `bun test` first.");
    }
    return allow();
  },
});
```

## Üretim deposunu kilitleme

Projenizin tüm geliştiricilerinin aynı politikaları alması için proje düzeyinde bir yapılandırma commit edin.

Deponuzda `.failproofai/policies-config.json` oluşturun:

```json
{
  "enabledPolicies": [
    "block-sudo",
    "block-rm-rf",
    "block-force-push",
    "block-push-master",
    "block-env-files",
    "sanitize-api-keys",
    "sanitize-jwt"
  ],
  "policyParams": {
    "block-push-master": {
      "protectedBranches": ["main", "release", "production"]
    }
  }
}
```

Sonra commit edin:

```bash
git add .failproofai/policies-config.json
git commit -m "Add failproofai team policies"
```

failproofai yüklü olan her ekip üyesi bu kuralları otomatik olarak alacaktır.

## Konvansiyon politikaları ile kuruluş genelinde kalite standardı oluşturma

En etkili kurulum: `.failproofai/policies/` dosyasını projenize commit edin ve projenize göre uyarlanmış politikalar ile. Her ekip üyesi bunları otomatik olarak alır — hiçbir yükleme komutu, yapılandırma değişikliği yok.

<Steps>
  <Step title="Dizini oluşturun ve politikalar ekleyin">
    ```bash
    mkdir -p .failproofai/policies
    ```

    ```js
    // .failproofai/policies/team-policies.mjs
    import { customPolicies, allow, deny, instruct } from "failproofai";

    // Enforce your team's preferred package manager
    // (or enable the built-in prefer-package-manager policy instead)
    customPolicies.add({
      name: "enforce-bun",
      match: { events: ["PreToolUse"] },
      fn: async (ctx) => {
        if (ctx.toolName !== "Bash") return allow();
        const cmd = String(ctx.toolInput?.command ?? "");
        if (/\bnpm\b/.test(cmd)) return deny("Use bun instead of npm.");
        return allow();
      },
    });

    // Remind the agent to run tests before committing
    customPolicies.add({
      name: "test-before-commit",
      match: { events: ["PreToolUse"] },
      fn: async (ctx) => {
        if (ctx.toolName !== "Bash") return allow();
        if (/git\s+commit/.test(ctx.toolInput?.command ?? "")) {
          return instruct("Run tests before committing.");
        }
        return allow();
      },
    });
    ```
  </Step>
  <Step title="Git'e commit edin">
    ```bash
    git add .failproofai/policies/
    git commit -m "Add team quality policies"
    ```
  </Step>
  <Step title="İyileştirmeye devam edin">
    Ekibiniz yeni hata modlarıyla karşılaştıkça, politika ekleyin ve itin. Herkes sonraki `git pull` işleminde güncellemeyi alır. Bu politikalar, ekibinizle birlikte büyüyen canlı bir kalite standardı haline gelir.
  </Step>
</Steps>
