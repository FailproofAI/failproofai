Failproof AI referansının tamamını kodlama ajanınıza tek komutla ekleyin. Claude Code, Cursor, Windsurf ve skill desteği olan diğer tüm ajanlarla çalışır.

```bash
npx skills add https://docs.befailproof.ai
```

`npx skills`, hangi ajanların yüklü olduğunu tespit eder ve her biri için skill'i otomatik olarak doğru formatta ekler.

## Skill'in kapsadığı alanlar

| Alan | İçerik |
|------|--------|
| Politikalar | Yerleşik politika adları, olay türleri, parametreler, etkinleştir/devre dışı bırak |
| Özel politikalar | `customPolicies.add()`, eşleştirme filtreleri, `allow`/`deny`/`instruct` API'si |
| Context nesnesi | `ctx.eventType`, `ctx.toolName`, `ctx.toolInput`, `ctx.session` |
| Konfigürasyon | `policies-config.json` yapısı, kapsam birleştirmesi, `policyParams` |
| CLI | `failproofai policies --install`, `--uninstall`, `--custom`, kapsamlar |
| Kontrol paneli | Oturum görüntüleyici, politika aktivitesi, ortam değişkenleri |
| Mimari | Hook handler akışı, çıkış kodları, stdin/stdout sözleşmesi |

## Skill tam mı?

Mintlify, navigasyondaki tüm sayfalardan `llms.txt` dosyasını oluşturur. Failproof AI dokümantasyonu tam API'yi kapsar - her politika, seçenek ve örnek dahildir. Eksik bir şey bulursanız, kaynak `https://docs.befailproof.ai/llms-full.txt` adresindedir.

Hedeflenmiş bağlam için doğrudan belirli bir sayfaya bağlantı verin:

```bash
# Yalnızca özel politikalar API'si
npx skills add https://docs.befailproof.ai/custom-policies

# Yalnızca yerleşik politikalar
npx skills add https://docs.befailproof.ai/built-in-policies
```
