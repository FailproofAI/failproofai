Failproof AI referansının tamamını kodlama ajanınıza tek bir komutla ekleyin. Claude Code, Cursor, Windsurf ve beceri destekleyen diğer tüm ajanlarla çalışır.

```bash
npx skills add https://docs.befailproof.ai
```

`npx skills`, hangi ajanların kurulu olduğunu algılar ve beceriyi her biri için otomatik olarak doğru biçimde ekler.

## Beceri neler kapsar

| Alan | İçerik |
|------|---------|
| İlkeler | Yerleşik ilke adları, olay türleri, parametreler, etkinleştir/devre dışı bırak |
| Özel ilkeler | `customPolicies.add()`, eşleşme filtreleri, `allow`/`deny`/`instruct` API'si |
| Bağlam nesnesi | `ctx.eventType`, `ctx.toolName`, `ctx.toolInput`, `ctx.session` |
| Konfigürasyon | `policies-config.json` yapısı, kapsam birleştirme, `policyParams` |
| CLI | `failproofai policies --install`, `--uninstall`, `--custom`, kapsamlar |
| Gösterge Paneli | Oturum görüntüleyici, ilke etkinliği, ortam değişkenleri |
| Mimari | Hook işleyici akışı, çıkış kodları, stdin/stdout sözleşmesi |

## Beceri eksiksiz mi?

Mintlify, `llms.txt` öğesini gezintideki tüm sayfalardan oluşturur. Failproof AI belgeleri tam API'yi kapsar - her ilke, seçenek ve örnek dahil edilmiştir. Eksik bir şey bulursanız, kaynak `https://docs.befailproof.ai/llms-full.txt` konumundadır.

Hedefli bağlam için doğrudan belirli bir sayfaya bağlantı verin:

```bash
# Yalnızca özel ilkeler API'si
npx skills add https://docs.befailproof.ai/custom-policies

# Yalnızca yerleşik ilkeler
npx skills add https://docs.befailproof.ai/built-in-policies
```
