Failproof AI referansının tamamını kodlama ajanınıza tek komutla ekleyin. Claude Code, Cursor, Windsurf ve beceri destekleyen diğer tüm ajanlarla çalışır.

```bash
npx skills add https://docs.befailproof.ai
```

`npx skills` yüklü olduğunuz ajanları tespit eder ve beceriyi her biri için otomatik olarak doğru formatta ekler.

## Becerinin kapsadığı alanlar

| Alan | İçerik |
|------|--------|
| Politikalar | Yerleşik politika adları, olay türleri, parametreler, etkinleştirme/devre dışı bırakma |
| Özel politikalar | `customPolicies.add()`, eşleşme filtreleri, `allow`/`deny`/`instruct` API'si |
| Bağlam nesnesi | `ctx.eventType`, `ctx.toolName`, `ctx.toolInput`, `ctx.session` |
| Yapılandırma | `policies-config.json` yapısı, kapsam birleştirme, `policyParams` |
| CLI | `failproofai policies --install`, `--uninstall`, `--custom`, kapsamlar |
| Gösterge Paneli | Oturum görüntüleyici, politika aktivitesi, ortam değişkenleri |
| Mimari | Hook işleyicisi akışı, çıkış kodları, stdin/stdout sözleşmesi |

## Beceri tamamlanmış mı?

Mintlify, `llms.txt` dosyasını gezintide yer alan tüm sayfalardan oluşturur. Failproof AI belgeleri tam API'yi kapsar - her politika, seçenek ve örnek dahil edilmiştir. Eksik bir şey bulursanız, kaynak `https://docs.befailproof.ai/llms-full.txt` adresindedir.

Hedeflenmiş bağlam için doğrudan belirli bir sayfaya bağlantı verin:

```bash
# Yalnızca özel politikalar API'si
npx skills add https://docs.befailproof.ai/custom-policies

# Yalnızca yerleşik politikalar
npx skills add https://docs.befailproof.ai/built-in-policies
```
