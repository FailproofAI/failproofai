**AI hata işleme**, **hata kurtarma** ve **LLM güvenilirliği** için kancalar ve ilkeler. AI agenlarınızı güvenilir ve **Claude Code**, **OpenAI Codex**, **GitHub Copilot**, **Cursor Agent**, **OpenCode**, **Pi**, **Hermes**, **OpenClaw**, **Factory Droid**, **Devin CLI**, **Antigravity CLI** ve **Agents SDK** genelinde özerk olarak çalışırken tutun.

AI agenları öngörülebilir şekillerde başarısız olur. Yıkıcı komutlar çalıştırırlar, gizli bilgileri sızdırırlar, görevden saparlar, döngülerde takılırlar veya doğrudan main'e itme yaparlar. Gözetimsiz bırakıldığında, küçük hatalar kesintilere, sızıntıya uğramış kimlik bilgilerine ve kaybedilen işlere dönüşebilir.

FailproofAI bunu **ilkeler** ile çözer. Bu kurallar, her agent araç çağrısında **hataları tespit etmek**, **onları azaltmak** (bloke etmek, yönlendirmek, temizlemek) ve **sizin bilginize sunmak** için kancaya bağlanırlar. Yerel bir pano, daha sonra her araç çağrısını, agent hatasını ve kurtarma işlemini incelemenizi sağlar.

Transcript'ler ve ilke değerlendirmesi makinenizde kalır. Veriler yalnızca kimliği doğrulanmış denetim anımsatıcıları veya davetler gibi çevrimiçi bir özelliği açıkça kullandığınızda gönderilir.

## Hızlı başlangıç

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # ilkeleri etkinleştir (veya atla — ilk çalıştırmada `failproofai` kurulum teklif edecektir)
failproofai                      # panoyu aç
```
