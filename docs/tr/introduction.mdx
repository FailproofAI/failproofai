**AI hata yönetimi**, **hata kurtarma** ve **LLM güvenilirliği** için hook'lar ve ilkeler. AI ajanlarınızı güvenilir tutun ve **Claude Code**, **OpenAI Codex**, **GitHub Copilot**, **Cursor Agent**, **OpenCode**, **Pi**, **Hermes**, **OpenClaw**, **Factory Droid**, **Devin CLI**, **Antigravity CLI** ve **Agents SDK** üzerinde otonom olarak çalışmalarını sağlayın.

AI ajanları öngörülebilir şekillerde başarısız olur. Yıkıcı komutlar çalıştırırlar, gizli bilgileri sızdırırlar, görevden sapıp kalırlar, döngülere takılırlar veya doğrudan ana dal'a push yaparlar. Gözetimsiz bırakıldığında, küçük hatalar kesintilere, sızdırılan kimlik bilgilerine ve kayıp işlere dönüşür.

FailproofAI bunu **ilkeler** ile çözer. Bu kurallar, her ajan araç çağrısına girerek **hataları tespit eder**, **onları azaltır** (engelle, yönlendir, temizle) ve dikkat gerektiren durumlarda **sizi uyarır**. Yerel bir pano, her araç çağrısını, ajan hatasını ve kurtarma eylemini daha sonra incelemenize olanak tanır.

Transkriptler ve ilke değerlendirmesi makinenizde kalır. Veriler, yalnızca doğrulanmış denetim hatırlatıcıları veya davetler gibi çevrimiçi özellikleri açıkça kullandığınızda gönderilir.

## Hızlı başlangıç

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # ilkeleri etkinleştir (veya atla — `failproofai` ilk çalıştırmada bunları ayarlamayı önerecek)
failproofai                      # panoyu başlat
```
