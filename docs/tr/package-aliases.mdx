## Resmi paket

Canonical npm paketi **`failproofai`**'dir:

```bash
npm install -g failproofai
# or
bun add -g failproofai
```

---

## Neden takma ad adlarına sahibiz

Typosquatting, kötü niyetli bir aktörün popüler bir paketin adından bir tuş farkında olan bir paket adını kaydettiği yaygın bir tedarik zinciri saldırısıdır. Kurulum komutunu yanlış yazan şüphelenmeyen kullanıcılar, saldırganın kontrol ettiği kodu tam sistem erişimiyle çalıştırır - tam olarak Failproof AI'nin savunması için tasarlandığı tehdit türü.

Bu riski ortadan kaldırmak için, **npm'de `failproofai`'nin tüm yaygın yazım hataları ve biçimlendirme varyantlarına ön emptif olarak sahibiz**. Bu adların hiçbiri üçüncü bir taraf tarafından kaydedilemiyor. Her biri, gerçek `failproofai` paketini yükleyen ve ona devreden ince bir proxy'dir.

## Kayıtlı takma adlar

**Biçimlendirme varyantları** - "failproof ai"yi yazmanın farklı yolları:

| Paket | Durum |
|---------|--------|
| `failproof` | ✅ Yayınlandı |
| `failproof-ai` | ⏳ npm desteği bekleniyor |
| `fail-proof-ai` | ⏳ npm desteği bekleniyor |
| `failproof_ai` | ⏳ npm desteği bekleniyor |
| `fail_proof_ai` | ⏳ npm desteği bekleniyor |
| `fail-proofai` | ⏳ npm desteği bekleniyor |

**`failprof*` yazım hataları** - "proof"tan bir `o` eksik:

| Paket | Durum |
|---------|--------|
| `failprof` | ✅ Yayınlandı |
| `failprof-ai` | ✅ Yayınlandı |
| `failprofai` | ⏳ npm desteği bekleniyor |
| `fail-prof-ai` | ⏳ npm desteği bekleniyor |
| `failprof_ai` | ⏳ npm desteği bekleniyor |

**`faliproof*` yazım hataları** - `a` ve `i` değiştirilmiş:

| Paket | Durum |
|---------|--------|
| `faliproof` | ✅ Yayınlandı |
| `faliproof-ai` | ✅ Yayınlandı |
| `faliproofai` | ⏳ npm desteği bekleniyor |

> **Neden bekleniyor?** npm'nin spam önleme ilkesi, noktalandırma şeridinden sonra ve benzerlik kontrollerinden sonra mevcut bir paketle aynı dizeye normalize olan adları engeller. Anti-squatting amaçlarıyla bu adları rezerve etmek için npm desteğiyle iletişime geçtik. Onaylandıktan sonra aktifleştirilecekler.

Yayınlanan herhangi bir takma adın bize ait olduğunu doğrulayabilirsiniz:

```bash
npm info failproof
# Ara: maintainers alanında "ExosphereHost Inc."
```

## Takma adlar nasıl çalışır

Her takma ad paketi:

1. `failproofai`'yi bir bağımlılık olarak listeler - böylece gerçek paket yüklenir ve ikili dosyası kullanılabilir hale gelir
2. Kendi adıyla eşleşen bir ikili dosyayı ortaya çıkarır (örn. `failprof-ai`) ve tüm argümanları `failproofai` ikilisine iletir

Proxy iki satırlık bir Node betiğidir; mantık, ağ çağrısı ve `failproofai`'nin kendisinin ötesinde veri toplamı yoktur.
