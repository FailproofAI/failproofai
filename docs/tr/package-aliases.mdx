## Resmi paket

Kanonik npm paketi **`failproofai`** dir:

```bash
npm install -g failproofai
# veya
bun add -g failproofai
```

---

## Neden takma ad adlarına sahip oluyoruz

Yazım hatası saldırısı, kötü niyetli bir aktörün popüler bir pakete bir tuş kadar yakın olan bir paket adını kaydettiği yaygın bir tedarik zinciri saldırısıdır. Kurulum komutunu yanlış yazanlayan farkında olmayan kullanıcılar, tam sistem erişimine sahip saldırgan kontrollü kodu çalıştırırlar - tam olarak Failproof AI'nin savunması için tasarlandığı tehdit türü.

Bu riski ortadan kaldırmak için, **npm üzerinde `failproofai` ın tüm yaygın yazım hatalarını ve biçimlendirme varyantlarına önceden sahip oluyoruz**. Bu adlardan hiçbiri üçüncü bir taraf tarafından kaydedilememektedir. Her biri, gerçek `failproofai` paketini yükleyen ve temsilci olan ince bir vekil uygulamasıdır.

## Kayıtlı takma adlar

**Biçimlendirme varyantları** - "failproof ai" yazmanın farklı yolları:

| Paket | Durum |

| `fail-proof-ai` | ⏳ npm desteği beklemede |
| `failproof_ai` | ⏳ npm desteği beklemede |
| `fail_proof_ai` | ⏳ npm desteği beklemede |
| `fail-proofai` | ⏳ npm desteği beklemede |

**`failprof*` yazım hataları** - "proof" den bir `o` eksik:

| Paket | Durum |
|---------|--------|
| `failprof` | ✅ Yayınlandı |
| `failprof-ai` | ✅ Yayınlandı |
| `failprofai` | ⏳ npm desteği beklemede |
| `fail-prof-ai` | ⏳ npm desteği beklemede |
| `failprof_ai` | ⏳ npm desteği beklemede |

**`faliproof*` yazım hataları** - `a` ve `i` yer değiştirmiş:

| Paket | Durum |
|---------|--------|
| `faliproof` | ✅ Yayınlandı |
| `faliproof-ai` | ✅ Yayınlandı |
| `faliproofai` | ⏳ npm desteği beklemede |

> **Neden beklemede?** npm'nin spam önleme politikası, noktalama işaretlerini çıkardıktan sonra ve benzerlik kontrolleri çalıştırıldıktan sonra mevcut bir pakettle aynı dizeye normalleştirilen adları engeller. npm desteğine bu adları yazım hatası saldırısı önleme amacıyla ayırması için başvurduk. Onay alındığında etkinleştirilecekler.

Herhangi bir yayınlanmış takma adın bize ait olduğunu doğrulayabilirsiniz:

```bash
npm info failproof
# Şunu arayın: "ExosphereHost Inc." bakımcılar alanında
```

## Takma adlar nasıl çalışır

Her takma ad paketi:

1. `failproofai` i bir bağımlılık olarak listeler - böylece gerçek paket yüklenir ve ikili dosyası kullanılabilir hale gelir
2. Kendi adıyla eşleşen bir ikili dosyayı (örn. `failprof-ai`) ortaya çıkarır ve tüm argümanları `failproofai` ikili dosyasına aktarır

Vekil, iki satırlık bir Node betiğidir; mantık, ağ çağrıları ve `failproofai` inin kendisinin ötesinde veri toplama yoktur.
