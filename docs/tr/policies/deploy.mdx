İncelenen bir politikayı bir seferde bir makineye dağıtın. Gözlem modunda başlayın.

## CLI'dan dağıtım yapın

```bash
fp policies test ./rule.mjs --tool Bash --command "git push --force" --expect deny
fp policies publish no-force-push ./rule.mjs
fp fleet deploy <machine> --add no-force-push:observe
fp guardrails summary --since 24h --machine <machine>
fp fleet deploy <machine> --add no-force-push:enforce
```

Gözlem modu gerçek politikayı değerlendirir ve allow olmayan kararları kaydeder, ancak aracıyı engellemez.

<Warning>
  Açık `--add no-force-push` hemen zorlama yapar. Gölge dağıtım için `:observe` ekleyin.
</Warning>

Zorlama sorunlara neden olursa:

```bash
fp fleet history <machine>
fp fleet rollback <machine> <generation>
```

## Panodan dağıtım yapın

1. **Admin → enforcement** adresine gidin.
2. Hedef makineyi açın.
3. Politika sürümünü **observe** etkisiyle ekleyin.
4. Dağıtımı uygulayın.
5. **Observe → policy** altında sonuçları gözden geçirin.
6. Eşleşmeler doğru olduğunda aynı sürümü **enforce** olarak yükseltin.

![Politika sürümleri, enforce ve observe etkileri ile uygulama dağıtımı eylemini gösteren makine dağıtımı düzenleyicisi.](/images/dashboard/enforcement-editor.png)

## Bir seti değiştirin veya ön aşama yapın

- `--remove <id>` bir politikayı kaldırır.
- `--set <ref>...` tam politika setini değiştirir.
- `--create` bir makine ilk kez kontrol etmeden önce dağıtımı hazırlar.
- `fp fleet diff <machine>` amaçlanan ve uygulanan durumu karşılaştırır.

<Note>
  Cloud olmadan, `failproofai publish --effect observe` ile bir paket yayınlayın ve yerel panoda kararları inceleyin.
</Note>

Makinelerin dağıtımları almak için `policies:pull` ve kararları bildirmek için `events:add` izinlerine ihtiyacı vardır.
