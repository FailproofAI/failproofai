Fleet kapsamı, Cloud'un atadığı ilkeleri her makinenin son olarak uyguladığı ilkelerle karşılaştırır.

## Bir makinenin durumunu kontrol etme

```bash
failproofai config --status
failproofai flush --wait --timeout 120
```

Cloud'dan:

```bash
fp fleet list
fp fleet diff
fp fleet show <machine-id>
```

`fp fleet` için oturum açılmış bir session gerekir, API anahtarı değil.

| Komut | İşlevi |
| --- | --- |
| `fp fleet list` | Makineleri ve dağıtım durumunu listele |
| `fp fleet show <machine>` | Bir makinenin ilke setini göster |
| `fp fleet deploy <machine> --add <ref>` | Bir ilkeyi ekle veya güncelle |
| `fp fleet deploy <machine> --remove <id>` | Bir ilkeyi kaldır |
| `fp fleet deploy <machine> --set <ref>...` | Tüm seti değiştir |
| `fp fleet diff [machine]` | Amaçlanan ve uygulanan sürümleri karşılaştır |
| `fp fleet history <machine>` | Dağıtım nesilleri listesini göster |
| `fp fleet rollback <machine> <generation>` | Bir nesili geri yükle |
| `fp fleet rename <machine> "<label>"` | Cloud etiketini değiştir |

<Warning>
  `--set` tüm ilke setini değiştirir. Tek başına `--add <id>` yeni bir ilkeyi hemen uygulamaya zorlayacaktır. Gölge başlatma için `--add <id>:observe` kullanın.
</Warning>

## Gözlemle, sonra uygula

```bash
fp fleet deploy ci-runner-01 --add prod-guard:observe
fp guardrails summary --since 24h --machine ci-runner-01
fp fleet deploy ci-runner-01 --add prod-guard:enforce
```

Gözlem modu, gerçek ilkeyi değerlendirir ve izin verilmeyen kararları ajan'ı engellemeden kaydeder.

## Makine kimliği

Makine ID'si sabit olup, makinenin kimliğini tanımlar. Etiket yalnızca görüntüleme amaçlı olup değişebilir:

```bash
failproofai config --machine-label checkout-runner-03
fp fleet rename <machine-id> "Checkout runner 03"
```

Etiketi değiştirmek makinenin yeniden bağlanmasını veya yeniden anahtarlanmasını gerektirmez.
