Yerel bir politikanın kime uygulanacağını belirlemek için scope kullanın:

| Kapsam | Uygulandığı yer |
| --- | --- |
| `user` | Bu makinedeki desteklenen ajanlarınız |
| `project` | Bu projede çalışan ajanlar |
| `local` | Yalnızca Claude, yerel proje ayarlarında |
| `all` | Yalnızca kaldırma işlemi için |

```bash
failproofai policies add block-sudo --scope user
failproofai policies add block-rm-rf --scope project
```

Hermes ve OpenClaw yalnızca user scope'unu destekler. Diğer çoğu harness user ve project scope'unu destekler. Claude ayrıca local scope'unu destekler. Bkz. [Harnesses](/tr/reference/harnesses).

## Politika parametreleri

Politika ayarları, eşleşen scope'taki `policies-config.json` dosyasında bulunur. Mümkün olduğunda yerel pano'nun **Policies → Configure** görünümünü kullanın.

Bir parametre bir politikaya ait olur ve o politikanın nasıl karar verdiğini değiştirir. Örneğin, bir izin listesi, engelleme politikasına bilinen güvenli komutları veya yolları kabul ettirmek için kullanılabilir.

Özel politika dosyaları `.failproofai/policies/` dizininden otomatik olarak yüklenebilir veya açıkça belirtilebilir:

```bash
failproofai policies -i -c ./guards.mjs --scope project
```

Açık yolları kaldırmak için:

```bash
failproofai policies -u -c
```

## Dosyalar

| Dosya | Amaç |
| --- | --- |
| `~/.failproofai/config.json` | Makine ve toplayıcı ayarları |
| `policies-config.json` | Etkinleştirilen politikalar ve bir scope için parametreler |
| `.failproofai/policies/*policies.mjs` | Kural tarafından yüklenen politikalar |
| `~/.failproofai/policies/packs/installed.json` | Yüklü paketler ve seçimler |

Yüklü paket yapılarını doğrudan düzenlemeyin. Yeniden kurun veya düzeltilmiş bir sürümü yayınlayın.
