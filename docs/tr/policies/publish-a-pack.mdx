Çalışan bir politika oluşturun, yerel ortamda test edin, ardından bir paket olarak yayınlayın.

## Oluşturma ve test etme

```bash
failproofai publish --init guards.mjs
failproofai policies -i -c ./guards.mjs
```

`--init`, `git push --force` işlemini zaten engelleyen bir politika yazar. Bunu düzenleyin, aracınızdan engellenen işlemi denemesini isteyin ve yerel panoda **Policies → Activity** bölümünü kontrol edin.

Bir paket politikası şunları içerebilir:

```js
import { customPolicies, allow, deny } from "failproofai";

customPolicies.add({
  name: "block-refunds",
  description: "Refunds above the limit need a human",
  category: "Billing",
  defaultEnabled: true,
  match: { events: ["PreToolUse"], toolNames: ["Bash"] },
  fn: async (ctx) => {
    // return allow(), instruct(), or deny()
  },
});
```

`defaultEnabled` varsayılan olarak `false` değerine sahiptir.

## Yayınlama

Dosyalarınızı kaydedin, ardından şunu çalıştırın:

```bash
failproofai publish
```

Yayınlama, politika dosyasını bulur, kurulum sırasında kullanılan aynı yükleyiciyle doğrular ve paket varlıklarını bir GitHub sürümüne yükler. `GITHUB_TOKEN`, `GH_TOKEN` veya `gh auth login` kullanır.

Depo genel olmalıdır çünkü kurulum anonim HTTPS kullanır.

Varsayılan sürüm, geçerli işlemin 12 karakterli SHA'sıdır. Yayınlama, `--version` sağlamadıkça kirli bir ağaç veya Git dışındaki bir dizini reddeder. `HEAD` üzerindeki bir etiket SHA'yı geçersiz kılar.

Kullanıcılar bunu şu şekilde yükler:

```bash
failproofai policies add owner/repo
```

## Gözlem modunda yayınlama

```bash
failproofai publish --effect observe
```

Gözlem modu, gerçek politikayı değerlendirir ve izin vermeyen kararları kaydeder ancak aracının devam etmesine izin verir. Zaman aşımı, izin verilir olarak kaydedilir.

Gözlemlenen eşleşmeler doğru olduğunda `--effect enforce` ile tekrar yayınlayın.

## Yararlı seçenekler

| Bayrak | Etki |
| --- | --- |
| `--init [file]` | Başlangıç politikası yaz |
| `--repo <owner>/<repo>` | Depoyu seç veya oluştur |
| `--version <version>` | İşleme dayalı sürümü geçersiz kıl |
| `--effect enforce|observe` | Paketin engelleyip engellemeyeceğini seç |
| `--dry-run` | Yayınlamadan derle ve doğrula |
| `--allow-private` | Gizli olarak yayınla, `policies add` bunu yükleyemeyeceğini bilerek |

```bash
failproofai publish --dry-run
failproofai publish ./guards.mjs --repo me/guards --version 2.0.0
```

<Note>
  Yayınladıktan sonra deponuza `failproofai-policies` GitHub başlığını ekleyin, böylece [Policy Hub](https://befailproof.ai/policy-hub/) paketi indeksleyebilir. CLI bunu sizin için ayarlamaz.
</Note>

<Warning>
  Bir politikayı yeniden adlandırmak mevcut seçimler için bir kırılma değişikliğidir. Sürümler arasında adları sabit tutun.
</Warning>
