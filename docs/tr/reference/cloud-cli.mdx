`fp` kullanarak Cloud telemetrisi inceleyebilir, bulut tarafından yönetilen uygulama (politikalar, filo dağıtımları, guardrail kararları) yönetebilir ve denetimler, bulgular, sorunlar, uyarılar, anahtarlar, kullanıcılar, sorgular ve ayarları yönetebilirsiniz. Yerel hook'lar, politikalar, yakalama ve makine kaydı için [`failproofai`](/tr/reference/failproof-cli) kullanın.

Yayınlanan Cloud CLI'yi bağımsız bir araç olarak yükleyin:

```bash
uv tool install fp-cloud-cli
fp version
```

## Oturum aç

```bash
fp login
fp whoami
```

## Sözdizimi

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

Global seçenekler komuttan önce gelmelidir:

```bash
fp --json sessions --since 24h
```

Terminal yardımı için `fp COMMAND --help` veya `fp COMMAND SUBCOMMAND --help` çalıştırın.

### Etkinlikler

```text
fp events [OPTIONS]
```

Bireysel agent etkinliklerini listeler. Varsayılan hafif beslenme ham yükleri hariç tutar; `--full` sadece sınırlı bir araştırma için kullanın.

| Seçenek | Açıklama |
| --- | --- |
| `--limit`, `-n <n>` | Maksimum toplam satır. Varsayılan: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h`, veya `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | ISO 8601 UTC aralığı; `--since` geçersiz kılar. |
| `--env <value>` | Ortam filtresi; değerleri tekrarlayın veya virgülle ayırın. |
| `--event-type <value>` | Etkinlik türü filtresi; tekrarlayın veya virgülle ayırın. |
| `--agent-id <value>` | Agent filtresi; tekrarlayın veya virgülle ayırın. |
| `--session-id <value>` | Oturum filtresi; tekrarlayın veya virgülle ayırın. |
| `--search <text>` | Yük metni araması; tekrarlanabilir, herhangi bir terim eşleşir. |
| `--order asc\|desc` | Zaman sırası. Varsayılan: en yeni ilk. |
| `--all` | `--limit`'e kadar otomatik sayfalandırma. |
| `--cursor <token>` | Opak imleçten devam edin. |
| `--page-size <n>` | `--all` ile istek başına satırlar; maksimum `200`. |
| `--full` | Daha ağır etkinlik uç noktası aracılığıyla ham yükleri ekleyin. |
| `--fields <csv>` | Yalnızca seçili alanları döndürün; `payload` istenmesi tam modu etkinleştirir. |

```bash
fp events --session-id <session-id> --order asc --all --limit 10000
fp --json events --full --session-id <session-id> --all --limit 10000
```

<Note>
  `--all` **`--limit`'e kadar** sayfalandırır; varsayılan olarak **50** — bu nedenle tek başına `--all` 50 satırda durur. Erken durduğunda yanıt devam etmek için bir `next_cursor` taşır; `"next_cursor": null` beslenmenin gerçekten tükendiği anlamına gelir.
</Note>

#### Denetim create seçenekleri

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| Seçenek | Açıklama |
| --- | --- |
| `--file <path>` | JSON'dan tanımı temel alın veya stdin için `-` kullanın. Açık bayraklar dosya değerlerini geçersiz kılar. |
| `--description <text>` | Hata sorusunu veya amacını belirtin. |
| `--enabled` / `--disabled` | Planlamayı açık veya kapalı başlatın. Varsayılan: etkin. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. Varsayılan: `86400`. |
| `--schedule-anchor <timestamp>` | ISO 8601 biçiminde sabit UTC fazı. Varsayılan: sonraki 09:00 UTC. |
| `--window-mode since_last\|fixed` | Son tam analiz edilen pencereden sonra devam edin veya hareketli pencerenin tekrar tekrar incelenmesi. Varsayılan: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. Varsayılan: `604800`. |
| `--scope '<json>'` | `environments`, `agent_ids` veya diğer desteklenen kapsam alanlarına göre filtreleyin. |
| `--ignore-error-type <type>` | Hata türlerini hariç tutun; tekrarlayın veya virgülle ayırın. |
| `--llm` / `--no-llm` | Agent analitik etkinleştirin veya devre dışı bırakın. Varsayılan: etkin. |
| `--top-k <n>` | `1`–`500` bulguyu tutun. Varsayılan: `50`. |
| `--sensitivity low\|medium\|high` | Raporlama duyarlılığını ayarlayın. Varsayılan: `medium`. |
| `--channels '<json>'` | Bildirim kanalı dizisi. |
| `--text <brief>` | Satır içi özet; maksimum 8.192 karakter. |
| `--text-file <path>` | Özeti dosyadan okuyun; `--text` ile karşılıklı olarak dışlayıcı. |
| `--url <https-url>` | Genel HTTPS referansı ekleyin; beş kez tekrarlayın. |

İlk çalıştırmanın buna ihtiyacı olduğunda oluşturma sırasında bağlam ekleyin. Oluşturma, kuyruğa alınan çalıştırma başlamadan önce tanımı ve bağlamı birlikte işler.

<Note>
  `fp audits run` asenkrondur. Bulguları okumadan önce en son çalıştırmanın başarılı veya başarısız olmasına kadar `fp audits runs NAME` üzerinde sorgu yapın.
</Note>

### Politikalar

Cloud tarafından yönetilen politika sürümleri. **Yalnızca oturum** — buradaki her komut, bu kökten yazma yolları olduğu için `/v1` içinde kasıtlı olarak bulunmadığından, API anahtarı altında `2` koduyla çıkılır.

| Komut | Amaç | Seçenekler |
| --- | --- | --- |
| `fp policies list` | Politika sürümlerini listeleyin. | `--json` |
| `fp policies show POLICY_ID` | Bir politikayı ve kaynağını gösterin. | — |
| `fp policies publish NAME PATH` | Yerel `.mjs` dosyasından bir sürüm oluşturun. | `--description`; `--no-verify` |
| `fp policies enable POLICY_ID` | Kaldırıldığı her dağıtıma geri ekleyin; her birinde yeni bir nesil oluşturun. | `--yes`, `-y` |
| `fp policies disable POLICY_ID` | Taşıdığı her dağıtımdan kaldırın; her birinde yeni bir nesil oluşturun. | `--yes`, `-y` |
| `fp policies delete POLICY_ID` | Bir politika sürümünü silin. | `--yes`, `-y` |

Açık bayraklar ortam değişkenlerini geçersiz kılar; ortam değişkenleri kaydedilmiş yapılandırmayı geçersiz kılar. API anahtarı modunda, `--org` veya `FP_ORG` ile kiracıyı açıkça seçin.

<Warning>
  Bu ortam değişkenlerinin `AGENTEYE_*` yazılışları **`fp` tarafından okunmaz** ve hiç olmadı — CLI `FP_*` (`fp_cli/app.py`) bildiriyor ve bilinmeyen bir değişken hata değildir. `AGENTEYE_DASHBOARD_URL` ayarlamak CLI'yi yeniden yönlendirmez; göz ardı edilir ve komut sessizce kaydedilmiş panoya karşı çalışır.

  `AGENTEYE_HOME` ve `AGENTEYE_ENVIRONMENT` hala mevcuttur, ancak bu CLI'ye değil **toplayıcı ve telemetri SDK'ya** aittir.
</Warning>

<Warning>
  Yapılandırmayı silen, iptal eden, bastıran, çözen veya değiştiren komutlar varsayılan olarak sor. `--yes` yalnızca etkin kuruluşu ve hedefi doğruladıktan sonra kullanın.
</Warning>
