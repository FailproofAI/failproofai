`fp` kullanarak Cloud telemetrisini inceleyin ve denetimler, bulgular, sorunlar, uyarılar, anahtarlar, kullanıcılar, sorgular ve ayarları yönetin. Yerel hook'lar, ilkeler, yakalama ve makine kaydı için [`failproofai`](/tr/reference/failproof-cli) kullanın.

Yayınlanan Cloud CLI'yi bağımsız bir araç olarak yükleyin:

```bash
uv tool install fp-cli
fp version
```

## Oturum aç

```bash
fp login
fp whoami
```

## Sözdizimi

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

Genel seçenekler komuttan önce gelmelidir:

```bash
fp --json sessions --since 24h
```

Terminal yardımı için `fp COMMAND --help` veya `fp COMMAND SUBCOMMAND --help` komutunu çalıştırın.

### Etkinlikler

```text
fp events [OPTIONS]
```

Bireysel agent etkinliklerini listeler. Varsayılan hafif feed ham yükleri hariç tutar; `--full` seçeneğini yalnızca sınırlı bir araştırma için kullanın.

| Seçenek | Açıklama |
| --- | --- |
| `--limit`, `-n <n>` | Maksimum toplam satır. Varsayılan: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h` veya `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | ISO 8601 UTC aralığı; `--since` parametresini geçersiz kılar. |
| `--env <value>` | Ortam filtresi; tekrarlayın veya virgülle ayırın. |
| `--event-type <value>` | Etkinlik türü filtresi; tekrarlayın veya virgülle ayırın. |
| `--agent-id <value>` | Agent filtresi; tekrarlayın veya virgülle ayırın. |
| `--session-id <value>` | Oturum filtresi; tekrarlayın veya virgülle ayırın. |
| `--search <text>` | Yük metni araması; tekrarlanabilir, herhangi bir terim eşleşir. |
| `--order asc\|desc` | Zaman sırası. Varsayılan: önce en yeniler. |
| `--all` | `--limit` değerine kadar otomatik sayfalandır. |
| `--cursor <token>` | Opak bir imlecden devam edin. |
| `--page-size <n>` | `--all` ile istek başına satırlar; maksimum `200`. |
| `--full` | Daha ağır etkinlik uç noktasından ham yükleri dahil edin. |
| `--fields <csv>` | Yalnızca seçili alanları döndürün; `payload` istenmesi tam modu etkinleştirir. |

```bash
fp events --session-id <session-id> --order asc --all
fp --json events --full --session-id <session-id> --all
```

#### Denetim oluşturma seçenekleri

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| Seçenek | Açıklama |
| --- | --- |
| `--file <path>` | Tanımı JSON'a dayandırın veya stdin için `-` kullanın. Açık bayraklar dosya değerlerini geçersiz kılar. |
| `--description <text>` | Başarısızlık sorusunu veya amacını belirtin. |
| `--enabled` / `--disabled` | Planlama başlatmayı açın veya kapatın. Varsayılan: etkinleştirilmiş. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. Varsayılan: `86400`. |
| `--schedule-anchor <timestamp>` | ISO 8601 biçiminde sabit UTC fazı. Varsayılan: sonraki 09:00 UTC. |
| `--window-mode since_last\|fixed` | Son tam olarak analiz edilen pencereden sonra devam edin veya tekrar tekrar kayan pencereyi inceleyin. Varsayılan: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. Varsayılan: `604800`. |
| `--scope '<json>'` | `environments`, `agent_ids` veya diğer desteklenen kapsam alanlarına göre filtreleyin. |
| `--ignore-error-type <type>` | Hata türlerini hariç tutun; tekrarlayın veya virgülle ayırın. |
| `--llm` / `--no-llm` | Agent analitiklerini etkinleştirin veya devre dışı bırakın. Varsayılan: etkinleştirilmiş. |
| `--top-k <n>` | `1`–`500` bulguyu saklayın. Varsayılan: `50`. |
| `--sensitivity low\|medium\|high` | Raporlama hassasiyetini ayarlayın. Varsayılan: `medium`. |
| `--channels '<json>'` | Bildirim kanalı dizisi. |
| `--text <brief>` | Satır içi özet, maksimum 8.192 karakter. |
| `--text-file <path>` | Özeti bir dosyadan okuyun; `--text` ile karşılıklı olarak özel. |
| `--url <https-url>` | Genel HTTPS referansı ekleyin; beş kez kadar tekrarlayın. |

Oluşturma sırasında ilk çalıştırmanın ihtiyacı olduğunda bağlam ekleyin. Oluşturma, sıraya alınan çalıştırma başlamadan önce tanımı ve bağlamı birlikte kaydeder.

<Note>
  `fp audits run` asenkrondur. Bulguları okumadan önce en son çalıştırma başarılı veya başarısız olana kadar `fp audits runs NAME` sorgusu yapın.
</Note>

## Genel Bayraklar

| Bayrak | Açıklama |
| --- | --- |
| `--json` | Makine tarafından okunabilir JSON yayın. |
| `--base-url <url>` | Kendi kendine barındırılan veya geliştirme panosunu kullanın. |
| `--org <slug>` | Bu çağırma için bir kuruluş seçin. |
| `--token <token>` | Kaydedilmiş kullanıcı oturumu token'ını geçersiz kılın. |
| `--api-key <key>` | Otomasyon kimlik doğrulamasını API anahtarı ile yapın; asla kaydedilmez. |
| `--timeout <seconds>` | HTTP zaman aşımı; pozitif olmalıdır. Varsayılan: `30`. |
| `--quiet`, `-q` | stderr üzerinde durum çıkışını bastırın. |
| `--no-color` | Renkli çıkışı devre dışı bırakın. |
| `--insecure` / `--secure` | TLS sertifikası doğrulamasını devre dışı bırakın veya geri yükleyin. |
| `--version` | Kutulamayan sürümü yazdırın ve çıkın. |
| `--help`, `-h` | Yardımı gösterin. |

`--api-key` otomasyon için tasarlanmıştır. Oturum açma, kuruluş değiştirme ve asistan komutları bir kullanıcı oturumu gerektirir.

## Ortam Değişkenleri

| Değişken | Eşdeğeri veya Amacı |
| --- | --- |
| `AGENTEYE_DASHBOARD_URL` | `--base-url` |
| `AGENTEYE_ORG` | `--org` |
| `AGENTEYE_CLI_TOKEN` | `--token` |
| `AGENTEYE_CLI_API_KEY` | `--api-key` |
| `AGENTEYE_CLI_JSON` | `--json` |
| `AGENTEYE_INSECURE` | `--insecure` |
| `AGENTEYE_HOME` | Geçerli CLI yapılandırma dizinini taşıyın. |

Açık bayraklar ortam değişkenlerini geçersiz kılar, bu da kaydedilmiş yapılandırmayı geçersiz kılar. API anahtarı modunda, `--org` veya `AGENTEYE_ORG` ile kiracıyı açıkça seçin.

<Warning>
  Silme, iptal etme, bastırma, çözme veya yapılandırmayı değiştiren komutlar varsayılan olarak sorar. `--yes` seçeneğini yalnızca etkin kuruluş ve hedefi doğruladıktan sonra kullanın.
</Warning>
