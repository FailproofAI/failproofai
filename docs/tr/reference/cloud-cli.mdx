`fp` aracılığıyla Cloud telemetrisi inceleyebilir, bulut tarafından yönetilen zorlama (politikalar, filo dağıtımları, guardrail kararları) yönetebilir, denetimler, bulgular, sorunlar, uyarılar, anahtarlar, kullanıcılar, sorgular ve ayarları yönetebilirsiniz. Yerel kancalar, politikalar, yakalama ve makine kaydı için [`failproofai`](/tr/reference/failproof-cli) kullanın.

Yayınlanan Cloud CLI'yi izole bir araç olarak yükleyin:

```bash
uv tool install fp-cloud-cli
fp version
```

## Oturum açma

```bash
fp login
fp whoami
```

## Söz dizimi

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

Küresel seçenekler komuttan önce gelmelidir:

```bash
fp --json sessions --since 24h
```

Terminal yardımı için `fp COMMAND --help` veya `fp COMMAND SUBCOMMAND --help` çalıştırın.

### Olaylar

```text
fp events [OPTIONS]
```

Bireysel aracı olaylarını listeler. Varsayılan hafif akış ham yükleri hariç tutar; `--full` seçeneğini yalnızca sınırlı bir araştırma için kullanın.

| Seçenek | Açıklama |
| --- | --- |
| `--limit`, `-n <n>` | Maksimum toplam satır. Varsayılan: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h` veya `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | ISO 8601 UTC aralığı; `--since` seçeneğini geçersiz kılar. |
| `--env <value>` | Ortam filtresi; değerleri tekrarlayın veya virgülle ayırın. |
| `--event-type <value>` | Olay türü filtresi; tekrarlayın veya virgülle ayırın. |
| `--agent-id <value>` | Aracı filtresi; tekrarlayın veya virgülle ayırın. |
| `--session-id <value>` | Oturum filtresi; tekrarlayın veya virgülle ayırın. |
| `--search <text>` | Yük metin araması; tekrarlanabilir, herhangi bir terim eşleştirilir. |
| `--order asc\|desc` | Zaman sırası. Varsayılan: en yeni önce. |
| `--all` | `--limit` değerine kadar otomatik sayfalandırma. |
| `--cursor <token>` | Opak imleçten devam edin. |
| `--page-size <n>` | `--all` ile istek başına satır; maksimum `200`. |
| `--full` | Daha ağır olay uç noktası aracılığıyla ham yükleri dahil edin. |
| `--fields <csv>` | Yalnızca seçili alanları döndürün; `payload` istemek tam modu etkinleştirir. |

```bash
fp events --session-id <session-id> --order asc --all --limit 10000
fp --json events --full --session-id <session-id> --all --limit 10000
```

<Note>
  `--all` **`--limit` değerine kadar** sayfalandırır, bu varsayılan olarak **50**'dir — bu nedenle `--all` yalnızca başında 50 satırda durur. Erken durduğunda yanıt, devam etmek için bir `next_cursor` içerir; `"next_cursor": null` akışın gerçekten tükendiği anlamına gelir.
</Note>

#### Denetim oluştur seçenekleri

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| Seçenek | Açıklama |
| --- | --- |
| `--file <path>` | Tanımı JSON'a dayandırın veya stdin için `-` kullanın. Açık bayraklar dosya değerlerini geçersiz kılar. |
| `--description <text>` | Hata sorusunu veya amacını belirtin. |
| `--enabled` / `--disabled` | Zamanlamayı açık veya kapalı şekilde başlatın. Varsayılan: etkin. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. Varsayılan: `86400`. |
| `--schedule-anchor <timestamp>` | ISO 8601 biçiminde sabit UTC fazı. Varsayılan: sonraki 09:00 UTC. |
| `--window-mode since_last\|fixed` | Son tam analiz edilen pencereden sonra devam edin veya tekrar tekrar bir kayan pencereyi inceleyin. Varsayılan: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. Varsayılan: `604800`. |
| `--scope '<json>'` | `environments`, `agent_ids` veya diğer desteklenen kapsam alanlarına göre filtreleyin. |
| `--ignore-error-type <type>` | Hata türlerini hariç tutun; tekrarlayın veya virgülle ayırın. |
| `--llm` / `--no-llm` | Aracı analizi etkinleştirin veya devre dışı bırakın. Varsayılan: etkin. |
| `--top-k <n>` | `1`–`500` bulgu saklayın. Varsayılan: `50`. |
| `--sensitivity low\|medium\|high` | Raporlama duyarlılığını ayarlayın. Varsayılan: `medium`. |
| `--channels '<json>'` | Bildirim kanalı dizisi. |
| `--text <brief>` | Satır içi özet, maksimum 8.192 karakter. |
| `--text-file <path>` | Özeti bir dosyadan okuyun; `--text` seçeneği ile karşılıklı olarak özel. |
| `--url <https-url>` | Genel HTTPS referansı ekleyin; beş kez tekrarlayın. |

İlk çalıştırmaya ihtiyacı olduğunda oluşturma sırasında bağlam ekleyin. Oluşturma, kuyruğa alınan çalıştırma başlamadan önce tanımı ve bağlamı birlikte kaydeder.

<Note>
  `fp audits run` eşzamansızdır. En son çalıştırma başarılı veya başarısız olana kadar `fp audits runs NAME` seçeneğini yoklayın, ardından bulgularını okuyun.
</Note>

### Politikalar

Bulut tarafından yönetilen politika sürümleri. **Yalnızca oturum** — buradaki her komut bir API anahtarı altında çıkış `2` verir, herhangi bir istekten önce, çünkü bunlar kasıtlı olarak `/v1` seçeneğinden yoksun olan yalnızca root yazma rotalarıdır.

| Komut | Amaç | Seçenekler |
| --- | --- | --- |
| `fp policies list` | Politika sürümlerini listeleyin. | `--json` |
| `fp policies show POLICY_ID` | Bir politikayı kaynağı ile gösterin. | — |
| `fp policies publish NAME PATH` | Yerel `.mjs` dosyasından bir sürüm oluşturun. | `--description`; `--no-verify` |
| `fp policies enable POLICY_ID` | Çıkarıldığı her dağıtıma geri ekleyin, her birinde yeni bir nesil oluşturun. | `--yes`, `-y` |
| `fp policies disable POLICY_ID` | Taşıdığı her dağıtımdan çıkarın, her birinde yeni bir nesil oluşturun. | `--yes`, `-y` |
| `fp policies delete POLICY_ID` | Bir politika sürümünü silin. | `--yes`, `-y` |
| `fp policies test PATH` | Sentetik bir bağlama karşı yerel olarak bir politika çalıştırın. Her politikanın `match` filtresini uygular, bu nedenle verilen olay/araç kapsamında yer almayan bir politika çalıştırılmak yerine `skipped` olarak rapor edilir. | `--event`; `--tool`; `--command`; `--file-path`; `--expect` |
| `fp policies compose PROMPT` | Asistan ile bir politika taslaklayın. `policies:write` gerekir. | — |

## Küresel bayraklar

| Bayrak | Açıklama |
| --- | --- |
| `--json` | Makine tarafından okunabilir JSON yayınlayın. |
| `--base-url <url>` | Kendi barındırılan veya geliştirme panosu kullanın. |
| `--org <slug>` | Bu çağırma için bir kuruluş seçin. |
| `--token <token>` | Kaydedilen kullanıcı oturumu jetonunu geçersiz kılın. |
| `--api-key <key>` | Otomasyon kimliğini API anahtarı ile doğrulayın; asla kaydedilmez. |
| `--timeout <seconds>` | HTTP zaman aşımı; pozitif olmalı. Varsayılan: `30`. |
| `--quiet`, `-q` | stderr üzerinde durum çıkışını bastırın. |
| `--no-color` | Renkli çıkışı devre dışı bırakın. |
| `--insecure` / `--secure` | TLS sertifikası doğrulamasını devre dışı bırakın veya geri yükleyin. |
| `--version` | Kutu açılmamış sürümü yazdırın ve çıkın. |
| `--help`, `-h` | Yardımı gösterin. |

`--api-key`, otomasyon için tasarlanmıştır. Oturum açma, kuruluş geçişi ve asistan komutları kullanıcı oturumu gerektirir.
