Bulut telemetrisini incelemek ve denetimler, bulgular, sorunlar, uyarılar, anahtarlar, kullanıcılar, sorgular ve ayarları yönetmek için `fp` kullanın. Yerel kancalar, politikalar, yakalama ve makine kaydı için [`failproofai`](/tr/reference/failproof-cli) komutunu kullanın.

Yayınlanan Bulut CLI'yi izole bir araç olarak yükleyin:

```bash
uv tool install fp-cloud-cli
fp version
```

## Oturum aç

```bash
fp login
fp whoami
```

## Söz dizimi

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

Global seçenekler komuttan önce gelmelidir:

```bash
fp --json sessions --since 24h
```

Terminal yardımı için `fp COMMAND --help` veya `fp COMMAND SUBCOMMAND --help` komutlarını çalıştırın.

### Olaylar

```text
fp events [OPTIONS]
```

Bireysel aracı olaylarını listeler. Varsayılan hafif akış ham yükleri hariç tutar; `--full` seçeneğini yalnızca sınırlı bir araştırma için kullanın.

| Seçenek | Açıklama |
| --- | --- |
| `--limit`, `-n <n>` | Maksimum toplam satır. Varsayılan: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h` veya `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | ISO 8601 UTC aralığı; `--since` seçeneğini geçersiz kılar. |
| `--env <value>` | Ortam filtresi; değerleri tekrar edin veya virgülle ayırın. |
| `--event-type <value>` | Olay türü filtresi; tekrar edin veya virgülle ayırın. |
| `--agent-id <value>` | Aracı filtresi; tekrar edin veya virgülle ayırın. |
| `--session-id <value>` | Oturum filtresi; tekrar edin veya virgülle ayırın. |
| `--search <text>` | Yük metni araması; tekrarlanabilir, herhangi bir terim eşleşir. |
| `--order asc\|desc` | Zaman sırası. Varsayılan: en yeniler önce. |
| `--all` | `--limit` ile otomatik sayfalandırma. |
| `--cursor <token>` | Opak imleyiciden devam edin. |
| `--page-size <n>` | `--all` ile istek başına satır; maksimum `200`. |
| `--full` | Daha ağır olay uç noktası aracılığıyla ham yükleri ekleyin. |
| `--fields <csv>` | Yalnızca seçilen alanları döndürün; `payload` istemek tam modu etkinleştirir. |

```bash
fp events --session-id <session-id> --order asc --all
fp --json events --full --session-id <session-id> --all
```

| Komut | Amaç | Seçenekler |
| --- | --- | --- |
| `fp keys list` | Kuruluş anahtarlarını listeleyin. | `--show-id`; `--fields <csv>` |

#### Denetim oluşturma seçenekleri

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| Seçenek | Açıklama |
| --- | --- |
| `--file <path>` | Tanımı JSON'a dayandırın veya stdin için `-` kullanın. Açık bayraklar dosya değerlerini geçersiz kılar. |
| `--description <text>` | Hata sorusunu veya amacı belirtin. |
| `--enabled` / `--disabled` | Planlamayı açık veya kapalı başlatın. Varsayılan: etkin. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. Varsayılan: `86400`. |
| `--schedule-anchor <timestamp>` | ISO 8601 biçiminde sabit UTC aşaması. Varsayılan: sonraki 09:00 UTC. |
| `--window-mode since_last\|fixed` | Son tam analiz edilen pencereden sonra devam edin veya tekrar tekrar haddeleme penceresini inceleyin. Varsayılan: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. Varsayılan: `604800`. |
| `--scope '<json>'` | `environments`, `agent_ids` veya diğer desteklenen kapsam alanlarına göre filtreleyin. |
| `--ignore-error-type <type>` | Hata türlerini hariç tutun; tekrar edin veya virgülle ayırın. |
| `--llm` / `--no-llm` | Aracı analizi etkinleştirin veya devre dışı bırakın. Varsayılan: etkin. |
| `--top-k <n>` | `1`–`500` bulguyu tutun. Varsayılan: `50`. |
| `--sensitivity low\|medium\|high` | Raporlama hassasiyetini ayarlayın. Varsayılan: `medium`. |
| `--channels '<json>'` | Bildirim kanalı dizisi. |
| `--text <brief>` | Satır içi özet, maksimum 8.192 karakter. |
| `--text-file <path>` | Özeti bir dosyadan okuyun; `--text` ile karşılıklı olarak birbirini dışlar. |
| `--url <https-url>` | Genel HTTPS referansı ekleyin; en fazla beş kez tekrarlayın. |

İlk çalıştırmaya ihtiyacı olduğunda oluşturma sırasında bağlam ekleyin. Oluşturma tanımı ve bağlamı kuyruğa alınan çalıştırma başlamadan önce birlikte kaydeder.

<Note>
  `fp audits run` asenkrondur. Bulgularını okumadan önce en son çalıştırmanın başarılı veya başarısız olmasını `fp audits runs NAME` ile yoklayın.
</Note>

## Genel bayraklar

| Bayrak | Açıklama |
| --- | --- |
| `--json` | Makine tarafından okunabilir JSON yayın. |
| `--base-url <url>` | Kendi barındırılan veya geliştirme panosunu kullanın. |
| `--org <slug>` | Bu çalıştırma için bir kuruluş seçin. |
| `--token <token>` | Kaydedilen kullanıcı oturumu tokenini geçersiz kılın. |
| `--api-key <key>` | Otomasyon ile kimlik doğrulayın bir API anahtarı ile; asla kaydedilmez. |
| `--timeout <seconds>` | HTTP zaman aşımı; pozitif olmalı. Varsayılan: `30`. |
| `--quiet`, `-q` | stderr'de durum çıktısını bastırın. |
| `--no-color` | Renkli çıktıyı devre dışı bırakın. |
| `--insecure` / `--secure` | TLS sertifika doğrulamasını devre dışı bırakın veya geri yükleyin. |
| `--version` | Kutulu sürümü yazdırın ve çıkın. |
| `--help`, `-h` | Yardımı gösterin. |

`--api-key` otomasyon için tasarlanmıştır. Oturum açma, kuruluş geçişi ve yardımcı komutları bir kullanıcı oturumu gerektirir.

</Warning>
