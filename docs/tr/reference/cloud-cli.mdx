Bulut telemetrisini incelemek, bulut tarafından yönetilen uygulamayı (politikalar, filo dağıtımları, korkuluk kararları) yönetmek ve denetimler, bulgular, sorunlar, uyarılar, anahtarlar, kullanıcılar, sorgular ve ayarları yönetmek için `fp` kullanın. Yerel hook'lar, politikalar, yakalama ve makine kaydı için [`failproofai`](/tr/reference/failproof-cli) kullanın.

Ayrıca barındırılan kod ve LLM-judge ile Jev değerlendiricileri yazabilir ve dağıtabilir, panoları yönetebilir, duyarlılığı inceleyebilir ve terminalden pano asistanını kullanabilirsiniz.

Yayınlanmış Cloud CLI'yi yalıtılmış bir araç olarak yükleyin:

```bash
uv tool install fp-cloud-cli
fp version
```

## Oturum açma

```bash
fp login
fp whoami
```

## Sözdizimi

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

Genel seçenekler komuttan önce gelmelidir:

```bash
fp --json sessions --since 24h
```

Terminal yardımı için `fp COMMAND --help` veya `fp COMMAND SUBCOMMAND --help` çalıştırın.

## CLI komutları

### Değerlendirici yazma

`fp evaluators` tanımları yazar; `fp evals` sonuçları okur. Etkin bir yönetilen örneği gereklidir (`fp evaluators instances`). Yazma için `evaluations:trigger` gereklidir; oturum test çalıştırmaları ve şema profili oluşturma için de `events:read` gereklidir.

Kod, kısıtlı bir Python ifadesidir. Bunu `error_free.py` olarak kaydedin:

```python
EvalResult(score=Score(1.0 if session.count("error") == 0 else 0.0), reasoning="Error-free session")
```

```bash
fp --json evaluators create --key error_free --name "Error free" --code error_free.py --dry-run-on run-001
fp --json evaluators dry-run --code error_free.py --session run-001
fp --json evaluators deploy error_free --code error_free.py --version 2 --dry-run-on run-001
fp --json evaluators list --key error_free --all
```

LLM yargıçı:

```bash
fp --json evaluators create --key relevance --name Relevance --judge --criteria "Grade relevance to the request" --threshold 0.7
fp --json evaluators deploy relevance --version 2 --judge --criteria "Grade relevance and completeness" --threshold 0.8
fp --json sessions re-evaluate run-001
fp --json sessions history run-001
```

Jev ikili ve notlu rubrik:

```bash
fp --json evaluators create --key resolution --name Resolution --jev noul --instructions "Was the request resolved?" --true "Resolved" --false "Unresolved"
fp --json evaluators dry-run --jev noul --instructions "Was the request resolved?" --true "Resolved" --false "Unresolved" --session run-001
fp --json evaluators deploy resolution --version 2 --jev score --instructions "Grade resolution quality" --level "Unresolved" --level "Partly resolved" --level "Fully resolved"
```

<Warning>
Oluşturma, değerlendiricinin etkinleştirilmesini sağlar. Dağıtım, yeni bir değişmez sürüm oluşturur, sonra daha eski etkin sürümleri devre dışı bırakır. Başarısız bir devamı yeni sürümü yayınlı bırakır: yeniden denemeden önce `evaluators list --all` kontrol edin.
Yargıç test çalıştırmaları Bulut tarafından reddedilir. Jev test çalıştırmaları model bütçesi harcar.
Geri doldurma kod, yargıç ve Jev değerlendiricilerini kapsar ve en fazla 90 gün kabul eder; yalnızca bir değerlendiricinin henüz puanlamadığı oturumları kuyruğa alır. Yargıç ve Jev geri doldurmalar model bütçesi harcar, bu nedenle önce `fp evaluators backfill --dry-run` çalıştırın.
İnsan çıktısı, oluşturmadan/dağıtmadan önce oturum başına test çalıştırması sonuçlarını gösterir.
Başarısız önizlemeler yazma işlemini durdurur; gözden geçirdikten sonra açıkça `--force` geçirmediğiniz sürece.
</Warning>

AI taslağı oluşturma `fp login` gerektirir ve create/deploy tarafından kabul edilen bir spec yazar:

```bash
fp --json evaluators draft "Measure error-free sessions with code" --kind code --out evaluator.json
# Taslağın anahtarını, kaynağını ve koşulunu oluşturmadan önce gözden geçirin.
fp --json evaluators create --file evaluator.json --dry-run-on run-001
fp --json evaluators dry-run --file evaluator.json
```

| Komut | Seçenekler / davranış |
| --- | --- |
| `fp evaluators list` | `--key`, `--all` |
| `fp evaluators show KEY[@VERSION]` | Tam kaynak/zarf |
| `fp evaluators create` | `--key`, `--name`, `--version`, tekrarlanan `--label`, `--condition EXPR\|@file`, bir kaynak, tekrarlanan `--dry-run-on`, `--disabled`, başarısız önizlemeler için açık `--force` |
| `fp evaluators deploy KEY` | Aynı kaynak seçenekleri; `--version`, `--backfill 7d` (herhangi bir tür, 1–90 gün), `--force`; sayısal sürümler otomatik artar; KEY eksik bir spec-file `eval_key` sağlar |
| `fp evaluators draft "intent"` | Oturum; `--kind code\|judge\|jev`, `--out` |
| `fp evaluators dry-run` | Kaynak seçenekleri veya `--file`, tekrarlanan `--session` (maksimum 10); hiçbiri = yalnızca derle |
| `fp evaluators enable\|disable KEY[@VERSION]` | Aç/kapat |
| `fp evaluators label KEY[@VERSION]` | Tekrarlanan `--add`, `--remove` |
| `fp evaluators instances\|schema\|jobs` | Yönetilen filo/şema/işleri incele |
| `fp evaluators backfill` | `--from`, `--to`, `--key`, `--dry-run`; kod, yargıç ve Jev |

Kod seçenekleri `--code FILE|-`, `--result-kind score|metric|assertion`, `--timeout S`'dir. Yargıç seçenekleri `--judge --criteria TEXT`, tekrarlanan `--step` ve `--threshold`'dır. Jev seçenekleri `--jev noul --instructions --true --false` veya `--jev score --instructions` ile 3–5 farklı `--level` değeridir, en kötüsü önce gelir.
Yargıç/Jev bir puan gerektirir; eşikler 0–1'dir. İkili yargıç adımları reddedilir.

Spec dosyaları tam olarak `eval_key`, `display_name`, `eval_version`, `result_kind`, `labels`, `condition_source`, `evaluator_source`, `timeout_seconds` içerir.
Yargıç/Jev `evaluator_source` bir JSON zarf dizesidir. Satır kimliklerini, etkin durumu veya AI akıl yürütme metaverilerini eklemeyin. `--file` ve ayrık spec seçenekleri birbirini dışlayan seçeneklerdir; dağıtım dosyanın sürümünü geçersiz kılabilir. Çıkış dosyaları asla üzerine yazılmaz.

### Yeni pano kontrolleri

Tüm komutlar genel `--json` kabul eder. Bilinmeyen rota 404'leri "bu FailproofAI Cloud sürümünde henüz mevcut değil" ile çıkış 6 yapar. Eksik kayıt 404'leri de çıkış 6 yapar ancak kaydın bulunmadığını bildirir. Oturum-yalnız komutlar HTTP'den önce anahtar modunu reddeder (çıkış 2).

Terminalde `fp login` bir bağlantı üzerinde başlar, tarayıcınız veya SSO ile oturum açmak için ve açar (SSH üzerinden veya görüntü olmadan yalnızca gösterir ve herhangi bir cihazdan çalışır); yetkilendirin ve terminal kendi başına biter. Bu terminal, oturum süresi dolana kadar tüm kuruluşlarınızda erişime sahip olur, bu nedenle yalnızca az önce istediğiniz bir bağlantıyı yetkilendirin. Login farklı bir ağda başladıysa, oturum var olduğunda e-posta alırsınız ve sayfa dağıtımın söyleyebileceği yeri uyarır. Bunun yerine e-posta ile 6 basamaklı bir kod için **Tab** tuşuna basın ve geri dönmek için yeniden basın. `--email`, `--json` ve terminali olmayan her şey kodu kullanır.

### Olaylar

```text
fp events [OPTIONS]
```

Bireysel aracı olaylarını listeler. Varsayılan hafif besleme ham yükleri hariç tutar; `--full` yalnızca sınırlı bir araştırma için kullanın.

| Seçenek | Açıklama |
| --- | --- |
| `--limit`, `-n <n>` | Maksimum toplam satır. Varsayılan: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h`, veya `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | ISO 8601 UTC aralığı; `--since` geçersiz kılar. |
| `--env <value>` | Ortam filtresi; değerleri tekrarlayın veya virgülle ayırın. |
| `--event-type <value>` | Olay türü filtresi; değerleri tekrarlayın veya virgülle ayırın. |
| `--agent-id <value>` | Aracı filtresi; değerleri tekrarlayın veya virgülle ayırın. |
| `--session-id <value>` | Oturum filtresi; değerleri tekrarlayın veya virgülle ayırın. |
| `--search <text>` | Yük metni araması; tekrarlanabilir, herhangi bir terim eşleşir. |
| `--order asc\|desc` | Saat sırası. Varsayılan: en yeniler önce. |
| `--all` | `--limit`'e kadar otomatik sayfalandırma. |
| `--cursor <token>` | Opak imleçten devam et. |
| `--page-size <n>` | `--all` ile istek başına satırlar; maksimum `200`. |
| `--full` | Daha ağır olay uç noktası aracılığıyla ham yükleri ekle. |
| `--fields <csv>` | Yalnızca seçili alanları döndür; `payload` isteme tam modu etkinleştirir. |

```bash
fp events --session-id <session-id> --order asc --all --limit 10000
fp --json events --full --session-id <session-id> --all --limit 10000
```

<Note>
  `--all` **`--limit`'e kadar** sayfalandırır, varsayılan olarak **50** — bu nedenle `--all` tek başına 50 satırda durur. Erken durdurunda yanıt devam etmek için `next_cursor` taşır; `"next_cursor": null` beslenmenin gerçekten tükendiği anlamına gelir.
</Note>

#### Denetim oluşturma seçenekleri

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| Seçenek | Açıklama |
| --- | --- |
| `--file <path>` | Tanımı JSON'a dayandır veya stdin için `-` kullan. Açık seçenekler dosya değerlerini geçersiz kılar. |
| `--description <text>` | Hata sorusunu veya amacını belirt. |
| `--enabled` / `--disabled` | Üzerinde veya kapalı planlamayı başlat. Varsayılan: etkin. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. Varsayılan: `86400`. |
| `--schedule-anchor <timestamp>` | ISO 8601 biçiminde sabit UTC fazı. Varsayılan: sonraki 09:00 UTC. |
| `--window-mode since_last\|fixed` | Sondan sonra devam et veya yinelemeli olarak bir kayan pencereyi incele. Varsayılan: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. Varsayılan: `604800`. |
| `--scope '<json>'` | `environments`, `agent_ids` veya diğer desteklenen kapsam alanları ile filtrele. |
| `--ignore-error-type <type>` | Hata türlerini hariç tut; tekrarlayın veya virgülle ayırın. |
| `--llm` / `--no-llm` | Aracı analizini etkinleştir veya devre dışı bırak. Varsayılan: etkin. |
| `--top-k <n>` | `1`–`500` bulguyu tut. Varsayılan: `50`. |
| `--sensitivity low\|medium\|high` | Raporlama duyarlılığını ayarla. Varsayılan: `medium`. |
| `--channels '<json>'` | Bildirim kanalı dizisi. |
| `--text <brief>` | Satır içi kısa özet, maksimum 8.192 karakter. |
| `--text-file <path>` | Kısa özeti dosyadan oku; `--text` ile karşılıklı olarak dışlayan. |
| `--url <https-url>` | Genel HTTPS referansı ekle; beş kereye kadar tekrarla. |

Kuyruğa alınan çalıştırma ihtiyaç duyduğunda oluşturma sırasında bağlam ekle. Oluşturma tanımı ve bağlamı, kuyruğa alınan çalıştırma başlamadan önce birlikte taahhüt eder.

<Note>
  `fp audits run` eşzamansızdır. Bulguların sonuçlarını okumadan önce son çalıştırma başarılı veya başarısız olana kadar `fp audits runs NAME` yokla.
</Note>
