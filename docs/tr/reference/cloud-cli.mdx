`fp` komutunu kullanarak Cloud telemetrisi inceleyebilir, bulut tarafından yönetilen yaptırımları (ilkeler, fleet dağıtımları, koruma kararları) yönetebilir ve denetim, bulgular, sorunlar, uyarılar, anahtarlar, kullanıcılar, sorgular ve ayarları yönetebilirsiniz. Yerel hook'lar, ilkeler, yakalama ve makine kaydı için [`failproofai`](/tr/reference/failproof-cli) komutunu kullanın.

Yayımlanmış Cloud CLI'yi izole bir araç olarak yükleyin:

```bash
uv tool install fp-cloud-cli
fp version
```

## Oturum aç

```bash
fp login
fp whoami
```

## Söz dizimi

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

Genel seçenekler komuttan önce gelmelidir:

```bash
fp --json sessions --since 24h
```

Terminal yardımı için `fp COMMAND --help` veya `fp COMMAND SUBCOMMAND --help` komutlarını çalıştırın.

### Olaylar

```text
fp events [OPTIONS]
```

Ayrı ayrı ajan olaylarını listeler. Varsayılan hafif akış ham yükleri hariç tutar; `--full` seçeneğini yalnızca sınırlı bir araştırma için kullanın.

| Seçenek | Açıklama |
| --- | --- |
| `--limit`, `-n <n>` | En fazla toplam satır. Varsayılan: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h` veya `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | ISO 8601 UTC aralığı; `--since` seçeneğini geçersiz kılar. |
| `--env <value>` | Ortam filtresi; değerleri tekrarlayın veya virgülle ayırın. |
| `--event-type <value>` | Olay türü filtresi; tekrarlayın veya virgülle ayırın. |
| `--agent-id <value>` | Ajan filtresi; tekrarlayın veya virgülle ayırın. |
| `--session-id <value>` | Oturum filtresi; tekrarlayın veya virgülle ayırın. |
| `--search <text>` | Yük metni araması; tekrarlanabilir, herhangi bir terim eşleşir. |
| `--order asc\|desc` | Zaman sırası. Varsayılan: en yeni ilk. |
| `--all` | `--limit` değerine kadar otomatik sayfalama. |
| `--cursor <token>` | Donuk imleçten devam edin. |
| `--page-size <n>` | `--all` seçeneğiyle istek başına satırlar; maksimum `200`. |
| `--full` | Daha ağır olay uç noktası aracılığıyla ham yükleri dahil edin. |
| `--fields <csv>` | Yalnızca seçili alanları döndürün; `payload` istemek tam modu etkinleştirir. |

```bash
fp events --session-id <session-id> --order asc --all --limit 10000
fp --json events --full --session-id <session-id> --all --limit 10000
```

<Note>
  `--all` **`--limit` değerine kadar** sayfalandırır, varsayılan olarak **50**'dir — bu nedenle `--all` tek başına 50 satırda durur. Erken durduğunda, yanıt `next_cursor` içerir; `"next_cursor": null` akışın gerçekten tükendiği anlamına gelir.
</Note>

#### Denetim oluşturma seçenekleri

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| Seçenek | Açıklama |
| --- | --- |
| `--file <path>` | Tanımı JSON'a dayandırın veya stdin için `-` kullanın. Açık bayraklar dosya değerlerini geçersiz kılar. |
| `--description <text>` | Başarısızlık sorusunu veya amacını belirtin. |
| `--enabled` / `--disabled` | Zamanlamayı açık veya kapalı başlatın. Varsayılan: etkin. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. Varsayılan: `86400`. |
| `--schedule-anchor <timestamp>` | ISO 8601 formunda sabit UTC fazı. Varsayılan: sonraki 09:00 UTC. |
| `--window-mode since_last\|fixed` | Son tam analiz edilen pencereden sonra devam edin veya yuvarlak pencereyi tekrarlayan şekilde inceleyin. Varsayılan: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. Varsayılan: `604800`. |
| `--scope '<json>'` | `environments`, `agent_ids` veya diğer desteklenen kapsam alanlarına göre filtreleyin. |
| `--ignore-error-type <type>` | Hata türlerini hariç tutun; tekrarlayın veya virgülle ayırın. |
| `--llm` / `--no-llm` | Ajansal analizi etkinleştirin veya devre dışı bırakın. Varsayılan: etkin. |
| `--top-k <n>` | `1`–`500` bulguyu koruyun. Varsayılan: `50`. |
| `--sensitivity low\|medium\|high` | Raporlama duyarlılığını ayarlayın. Varsayılan: `medium`. |
| `--channels '<json>'` | Bildirim kanalı dizisi. |
| `--text <brief>` | Satır içi özet, maksimum 8.192 karakter. |
| `--text-file <path>` | Özeti bir dosyadan okuyun; `--text` ile birbirini dışlar. |
| `--url <https-url>` | Genel HTTPS referansı ekleyin; beş kata kadar tekrarlayın. |

İlk çalışmanın buna ihtiyaç duyduğu zaman oluşturma sırasında bağlam ekleyin. Oluşturma, tanımı ve bağlamı sıraya alınan çalışma başlamadan önce birlikte taahhüt eder.

<Note>
  `fp audits run` asenkrondur. Bulguları okumadan önce en son çalışma başarı veya başarısız olana kadar `fp audits runs NAME` sorgulamasını yapın.
</Note>

### İlkeler

Bulut tarafından yönetilen ilke sürümleri. **Yalnızca oturum** — buradaki her komut bir API anahtarı altında `2` seçeneğiyle çıkılır, herhangi bir istekten önce, çünkü bunlar `/v1` içinde kasıtlı olarak yokluğu yazma yollarıdır.

| Komut | Amaç | Seçenekler |
| --- | --- | --- |
| `fp policies list` | İlke sürümlerini listeleyin. | `--json` |
| `fp policies show POLICY_ID` | Bir ilkeyi kaynağıyla gösterin. | — |
| `fp policies publish NAME PATH` | Yerel `.mjs` dosyasından bir sürüm alın. | `--description`; `--no-verify` |
| `fp policies enable POLICY_ID` | Kaldırıldığı her dağıtıma geri ekleyin, her birinde yeni bir nesil alın. | `--yes`, `-y` |
| `fp policies disable POLICY_ID` | Onu taşıyan her dağıtımdan kaldırın, her birinde yeni bir nesil alın. | `--yes`, `-y` |
| `fp policies delete POLICY_ID` | Bir ilke sürümünü silin. | `--yes`, `-y` |
| `fp policies test PATH` | Bir ilkeyi sentetik bir bağlama karşı yerel olarak çalıştırın. Her ilkenin `match` filtresini uygular, bu nedenle verilen olay/araç içermeyen biri çalıştırılmak yerine `skipped` olarak rapor edilir. | `--event`; `--tool`; `--command`; `--file-path`; `--expect` |

## Genel bayraklar

| Bayrak | Açıklama |
| --- | --- |
| `--json` | Makine tarafından okunabilir JSON yayınlayın. |
| `--base-url <url>` | Öz barındırılmış veya geliştirme panosunu kullanın. |
| `--org <slug>` | Bu çağırma için bir kuruluş seçin. |
| `--token <token>` | Kaydedilen kullanıcı oturumu belirtecini geçersiz kılın. |
| `--api-key <key>` | Otomasyon ile API anahtarı kimlik doğrulaması; asla kaydedilmez. |
| `--timeout <seconds>` | HTTP zaman aşımı; pozitif olmalı. Varsayılan: `30`. |
| `--quiet`, `-q` | Stderr'de durum çıktısını bastırın. |
| `--no-color` | Renkli çıktıyı devre dışı bırakın. |
| `--insecure` / `--secure` | TLS sertifikası doğrulamasını devre dışı bırakın veya geri yükleyin. |
| `--version` | Kutusuz sürümü yazdırın ve çıkın. |
| `--help`, `-h` | Yardımı gösterin. |

`--api-key` otomasyon için tasarlanmıştır. Oturum açma, kuruluş değiştirme ve asistan komutları kullanıcı oturumu gerektirir.

## Ortam değişkenleri

| Değişken | Eşdeğer veya amaç |
| --- | --- |
| `FP_DASHBOARD_URL` | `--base-url` |
| `FP_ORG` | `--org` |
| `FP_TOKEN` | `--token` |
| `FP_API_KEY` | `--api-key` |
| `FP_JSON` | `--json` |
| `FP_INSECURE` | `--insecure` |
| `FP_HOME` | CLI yapılandırma dizinini taşıyın (varsayılan `~/.failproofai/fpcli`). |
| `FP_ANALYTICS_DISABLED` veya `DO_NOT_TRACK` | Anonim CLI analitiğini devre dışı bırakın. |
| `NO_COLOR` | Renkli çıktıyı devre dışı bırakın. |

Açık bayraklar ortam değişkenlerini geçersiz kılar; ortam değişkenleri kaydedilmiş yapılandırmayı geçersiz kılar. API anahtar modunda, `--org` veya `FP_ORG` ile kiracıyı açıkça seçin.

<Warning>
  `AGENTEYE_*` yazımı **`fp` tarafından okunmaz** ve hiç okunmadı — CLI `FP_*` (`fp_cli/app.py`) bildirir, bilinmeyen bir değişken bir hata değildir. `AGENTEYE_DASHBOARD_URL` ayarlanması CLI'yi yeniden hedeflemez; yoksayılır ve komut sessizce kaydedilmiş pano yerine çalışır.

  `AGENTEYE_HOME` ve `AGENTEYE_ENVIRONMENT` hala mevcuttur, ancak bunlar **toplayıcı ve telemetri SDK'sı**'na aittir, bu CLI'ye değil.
</Warning>
