Cloud telemetrisini incelemek, bulut tarafından yönetilen uygulamayı (politikalar, filo dağıtımları, guardrail kararları) yönetmek ve denetim, bulgular, sorunlar, uyarılar, anahtarlar, kullanıcılar, sorgular ve ayarları yönetmek için `fp` kullanın. Yerel hook'lar, politikalar, yakalama ve makine kaydı için [`failproofai`](/tr/reference/failproof-cli) kullanın.

Yayınlanan Cloud CLI'yı izole bir araç olarak yükleyin:

```bash
uv tool install fp-cloud-cli
fp version
```

## Oturum aç

```bash
fp login
fp whoami
```

## Sözdizimi

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

Genel seçenekler komuttan önce gelmelidir:

```bash
fp --json sessions --since 24h
```

Terminal yardımı için `fp COMMAND --help` veya `fp COMMAND SUBCOMMAND --help` komutunu çalıştırın.

### Olaylar

```text
fp events [OPTIONS]
```

Bireysel ajan olaylarını listeler. Varsayılan hafif akış ham yükleri dışlar; sınırlı bir araştırma için yalnızca `--full` kullanın.

| Seçenek | Açıklama |
| --- | --- |
| `--limit`, `-n <n>` | Maksimum toplam satırlar. Varsayılan: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h` veya `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | ISO 8601 UTC aralığı; `--since` seçeneğini geçersiz kılar. |
| `--env <value>` | Ortam filtresi; tekrarlayın veya virgülle ayırarak değerler girin. |
| `--event-type <value>` | Olay türü filtresi; tekrarlayın veya virgülle ayırarak değerler girin. |
| `--agent-id <value>` | Ajan filtresi; tekrarlayın veya virgülle ayırarak değerler girin. |
| `--session-id <value>` | Oturum filtresi; tekrarlayın veya virgülle ayırarak değerler girin. |
| `--search <text>` | Yük metin araması; tekrarlanabilir, herhangi bir terim eşleşme gösterir. |
| `--order asc\|desc` | Zaman sırası. Varsayılan: yeniden eski sırası. |
| `--all` | `--limit` kadar otomatik sayfalandırma. |
| `--cursor <token>` | Donuk imleçten devam edin. |
| `--page-size <n>` | `--all` ile istek başına satırlar; maksimum `200`. |
| `--full` | Ham yükleri daha ağır olay uç noktası üzerinden dahil edin. |
| `--fields <csv>` | Yalnızca seçilen alanları döndürün; `payload` talep etmek tam modu etkinleştirir. |

```bash
fp events --session-id <session-id> --order asc --all --limit 10000
fp --json events --full --session-id <session-id> --all --limit 10000
```

<Note>
  `--all` **`--limit` kadar** sayfalandırır, varsayılan olarak **50** satırdır — bu nedenle
  `--all` tek başına 50 satırda durur. Erken durduğunda yanıt `next_cursor`
  taşır; `"next_cursor": null` akışın gerçekten tükendiği anlamına gelir.
</Note>

#### Denetim oluştur seçenekleri

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| Seçenek | Açıklama |
| --- | --- |
| `--file <path>` | Tanımı JSON'a dayandırın veya stdin için `-` kullanın. Açık bayraklar dosya değerlerini geçersiz kılar. |
| `--description <text>` | Hata sorusunu veya amacını belirtin. |
| `--enabled` / `--disabled` | Zamanlamaya açık veya kapalı başlayın. Varsayılan: etkin. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. Varsayılan: `86400`. |
| `--schedule-anchor <timestamp>` | ISO 8601 formunda sabit UTC fazı. Varsayılan: sonraki 09:00 UTC. |
| `--window-mode since_last\|fixed` | Son tamamen analiz edilen pencereden sonra devam edin veya kayan pencereyi tekrar tekrar inceleyin. Varsayılan: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. Varsayılan: `604800`. |
| `--scope '<json>'` | `environments`, `agent_ids` veya diğer desteklenen kapsam alanlarına göre filtreleyin. |
| `--ignore-error-type <type>` | Hata türlerini hariç tutun; tekrarlayın veya virgülle ayırarak. |
| `--llm` / `--no-llm` | Ajan analizi etkinleştirin veya devre dışı bırakın. Varsayılan: etkin. |
| `--top-k <n>` | `1`–`500` bulgularını saklayın. Varsayılan: `50`. |
| `--sensitivity low\|medium\|high` | Raporlama hassasiyetini belirleyin. Varsayılan: `medium`. |
| `--channels '<json>'` | Bildirim kanalı dizisi. |
| `--text <brief>` | Satır içi özet, maksimum 8.192 karakter. |
| `--text-file <path>` | Özeti bir dosyadan okuyun; `--text` ile birbirini dışlar. |
| `--url <https-url>` | Genel HTTPS referansı ekleyin; beş kez tekrarlayabilirsiniz. |

İlk çalışma ona ihtiyaç duyduğunda oluşturma sırasında içerik ekleyin. Oluşturma, sıraya alınan çalışma başlamadan önce tanımı ve içeriği birlikte kaydeder.

<Note>
  `fp audits run` asenkrondur. En son çalışma başarılı olana veya başarısız olana kadar
  `fp audits runs NAME` çalıştırmasını oylamadan, bulgularını okumadan önce.
</Note>

### Politikalar

Bulut tarafından yönetilen politika versiyonları. **Yalnızca oturum** — buradaki her komut API anahtarı altında `2` çıkışı yapar, herhangi bir istek yapılmadan önce, çünkü bunlar `/v1` olarak kasıtlı olarak yoktur olan kök yazma yollarıdır.

| Komut | Amaç | Seçenekler |

| `fp policies list` | Politika versiyonlarını listeleyin. | `--json` |

| `fp policies publish NAME PATH` | Yerel `.mjs` dosyasından bir sürüm oluşturun. | `--description`; `--no-verify` |
| `fp policies enable POLICY_ID` | Kaldırıldığı her dağıtıma geri ekleyin, her birine yeni bir nesil basın. | `--yes`, `-y` |

## Genel bayraklar

| Bayrak | Açıklama |
| --- | --- |
| `--json` | Makine tarafından okunabilir JSON yayınlayın. |
| `--base-url <url>` | Kendi barındırılan veya geliştirme panosunu kullanın. |
| `--org <slug>` | Bu çağrı için bir kuruluş seçin. |
| `--token <token>` | Kaydedilmiş kullanıcı oturum jetonu geçersiz kılın. |
| `--api-key <key>` | Otomasyon ile API anahtarı kimlik doğrulaması; asla kaydedilmez. |
| `--timeout <seconds>` | HTTP zaman aşımı; pozitif olmalı. Varsayılan: `30`. |
| `--quiet`, `-q` | stderr'deki durum çıktısını gizleyin. |
| `--no-color` | Renkli çıktıyı devre dışı bırakın. |
| `--insecure` / `--secure` | TLS sertifika doğrulamasını devre dışı bırakın veya geri yükleyin. |
| `--version` | Kutulanmamış sürümü yazdırın ve çıkın. |
| `--help`, `-h` | Yardımı gösterin. |

`--api-key` otomasyon için tasarlanmıştır. Oturum açma, kuruluş değiştirme ve asistan komutları bir kullanıcı oturumu gerektirir.

## Ortam değişkenleri

| Değişken | Eşdeğer veya amaç |
| --- | --- |
| `FP_DASHBOARD_URL` | `--base-url` |
| `FP_ORG` | `--org` |
| `FP_TOKEN` | `--token` |
| `FP_API_KEY` | `--api-key` |
| `FP_JSON` | `--json` |
| `FP_INSECURE` | `--insecure` |
| `FP_HOME` | CLI yapılandırma dizinini yeniden konumlandırın (varsayılan `~/.failproofai/fpcli`). |
| `FP_ANALYTICS_DISABLED` veya `DO_NOT_TRACK` | Anonim CLI analitiğini devre dışı bırakın. |
| `NO_COLOR` | Renkli çıktıyı devre dışı bırakın. |

Açık bayraklar ortam değişkenlerini geçersiz kılar, bunlar kaydedilmiş yapılandırmayı geçersiz kılar. API anahtar modunda, `--org` veya `FP_ORG` ile kiracıyı açıkça seçin.

<Warning>
  `AGENTEYE_*` yazımları `fp` tarafından **okunmaz** ve hiçbir zaman okunmamıştır — CLI
  `FP_*` (`fp_cli/app.py`) bildirir ve bilinmeyen bir değişken hata değildir.
  `AGENTEYE_DASHBOARD_URL` ayarlaması CLI'yi yeniden hedeflemez; bunu yoksayar ve komut sessizce
  kaydedilmiş pano yerine çalışır.

  `AGENTEYE_HOME` ve `AGENTEYE_ENVIRONMENT` hala var, ancak **toplayıcı ve telemetri SDK'ya** ait,
  bu CLI'ye değil.
</Warning>

  Yapılandırmayı silen, iptal eden, bastıran, çözen veya değiştiren komutlar varsayılan
  olarak sorar. Etkin kuruluşu ve hedefi doğruladıktan sonra `--yes` kullanın.
</Warning>
