`npm install -g failproofai` ile yükleyin. Yerel panoyu açmak için `failproofai` komutunu argümansız çalıştırın.

## Temel komutlar

| Komut | Yaptığı şey |
| --- | --- |
| `failproofai config` | Ajanları, arka plan hizmetini ve isteğe bağlı Cloud bağlantısını ayarlayın |
| `failproofai config --token <key>` | Soru sormadan ayarlayın ve bağlanın |
| `failproofai config --status` | Bağlantı, hizmet sürümü ve duraklatma durumunu gösterin |
| `failproofai policies` | Politikaları ve açık olup olmadığını listeleyin |
| `failproofai policies add <name>` | Bir politikayı açın |
| `failproofai policies add <owner>/<repo>` | Bir politika paketini yükleyin |
| `failproofai policies remove <name-or-pack>` | Bir politikayı kapatın veya paketi kaldırın |
| `failproofai policies show <owner>/<repo>` | Bir paketi yüklemeden önce inceleyin |
| `failproofai publish` | Politikalarınızı bir paket olarak yayınlayın |
| `failproofai audit` | Yerel ajan geçmişini tarayın |
| `failproofai harness` | Ek oturum konumlarını yönetin |
| `failproofai flush` | Sıraya alınmış olayları şimdi gönderin |
| `failproofai backfill` | Eski ajan geçmişini yeniden okuyun |
| `failproofai update` | npm yükseltmesini tamamlayın ve hizmeti güncelleyin |
| `failproofai uninstall` | Hook'ları ve hizmeti kaldırın |

`policy`, `pack` ve `p` komutları `policies` için takma ad olarak kabul edilir, ancak belgeler `policies` kullanır.

## Makineyi ayarlayın

```bash
npm install -g failproofai
failproofai config
failproofai policies add FailproofAI/policies
failproofai config --status
```

Kurulum hiçbir politika paketi seçmez. Bir paket eklemeden önce, yalnızca `block-failproofai-commands` çalışır.

Katılımsız Cloud kurulumu için:

```bash
export FAILPROOFAI_CLOUD_TOKEN="<key>"
failproofai config
```

Transkriptler olmadan kararları göndermek için, önce bağlanın ve `~/.failproofai/config.json` dosyasında `collector.sessions` ayarını `false` olarak yapın. Mevcut `--no-transcripts` kurulum bayrağı ayrıştırılır ancak bu ayarı uygulamaz.

Makine bağlandıktan sonra `--machine-label <name>` kullanarak adını değiştirin. `--connect <url>`, zaten ayarlanmış bir makine için daha dar kayıt komutudur.

## Politikalar ve paketler

```bash
failproofai policies
failproofai policies add block-sudo
failproofai policies show owner/repo
failproofai policies add owner/repo --category git,database
failproofai policies remove owner/repo
```

Eğik çizgi içeren her şey bir paket kaynağıdır; eğik çizgi olmayan her şey bir politika adıdır.

Yararlı paket seçimi bayrakları:

| Bayrak | Kullanım |
| --- | --- |
| `--policy a,b` | Adlandırılmış politikaları seçin |
| `--category x,y` | Kategorileri seçin |
| `--all` | Hepsini seçin |
| `--cli <agents...>` | Adlandırılmış harness'lerle sınırlayın |

Herhangi bir yoldan özel bir politika yüklemek için `failproofai policies -i -c <path>` kullanın. `.failproofai/policies/` altındaki `*policies.{js,mjs,ts}` adlı kural dosyaları otomatik olarak yüklenir.

## Uygulamayı duraklatın

```bash
failproofai config --pause 10m
failproofai config --status
failproofai config --resume
```

Duraklatma, bir yerel oturuma uygulanır ve her zaman sona erer. Cloud tarafından yönetilen politikaları veya `block-failproofai-commands` duraksatmaz.

## Denetim ve teslimat

```bash
failproofai audit
failproofai audit --schedule 7 --email team@example.com
failproofai audit --status
failproofai flush --wait
failproofai backfill --since 30d --dry-run
```

`backfill` `~/.failproofai/config.json` dosyasını okur. Geçmişi yeniden göndermek için `--dry-run` çıkarın.

## Ek oturum konumları

```bash
failproofai harness list
failproofai harness add-path claude work=/srv/team/.claude/projects
failproofai harness remove-path claude work
```

Etiketler, iki kopyalanan ev dizininin oturumlarının aynı türetilmiş ajan kimliği altında birleşmesini önler.

Desteklenen harness'ler `claude`, `codex`, `copilot`, `cursor`, `opencode`, `pi`, `hermes`, `openclaw`, `factory`, `devin`, `antigravity` ve `goose`'dir. Kapsam desteği farklılık gösterir; bkz. [Harnesses](/tr/reference/harnesses).

## Yararlı ortam değişkenleri

| Değişken | Kullanım |
| --- | --- |
| `FAILPROOFAI_CLOUD_TOKEN` | Cloud makine anahtarı |
| `FAILPROOFAI_CLOUD_URL` | Cloud URL'sini geçersiz kılın |
| `FAILPROOFAI_HOME` | Yerel durum dizinini taşıyın |
| `FAILPROOFAI_NO_DOWNLOAD=1` | Paket ve hizmet indirmelerini reddedin |
| `FAILPROOFAI_DAEMON_BASE_URL` | Bir hizmet-ikili ayna kullanın |
| `FAILPROOFAI_PACK_BASE_URL` | Bir paket aynası kullanın |
| `FAILPROOFAI_NO_FIRST_RUN=1` | İlk çalıştırma istemlerini devre dışı bırakın |
| `FAILPROOFAI_TELEMETRY_DISABLED=1` | Anonim CLI telemetrisini devre dışı bırakın |
| `FAILPROOFAI_<HARNESS>_EXTRA_PATHS` | Bir harness için ek yolları değiştirin |
| `NO_COLOR` | Terminal rengini devre dışı bırakın |

## Kaldırma veya yükseltme

```bash
npm install -g failproofai@latest
failproofai update
```

Paketi kaldırmadan önce:

```bash
failproofai uninstall --dry-run
failproofai uninstall --yes
npm rm -g failproofai
```

<Warning>
  npm paketini kaldırmadan önce `failproofai uninstall` komutunu çalıştırın. npm yüklü hook'ları veya arka plan hizmetini kaldırmaz.
</Warning>

Yüklü sürümünüzdeki tam seçenekler için `failproofai help <command>` komutunu çalıştırın.
