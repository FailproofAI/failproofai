## Bir agent bağlayın ve verileri doğrulayın

<Tabs>
  <Tab title="Dashboard">
    1. **Administration → Keys** sayfasını açın, `events:add` ve `policies:pull` izinlerine sahip bir anahtar oluşturun ve gizli anahtarı kopyalayın.
    2. Entegrasyonu yukarıdaki eşleşen sayfayı kullanarak yapılandırın.
    3. **Observe → Events** sayfasını açarak olayların geldiğini doğrulayın, ardından **Observe → Sessions** sayfasını açarak tam çalışmaları oluşturduğunu doğrulayın.
    4. Entegrasyonun ortamına göre filtreleyin ve denetimler tarafından gereken model, tool, error ve policy alanlarının bulunduğu bir oturumu inceleyin.

    Anahtar bölmesi ile başlayın. Seçilen izinler, makinenin olayları gönderebildiğini ve Cloud tarafından yönetilen politikaları alabileceğini belirler.

    ![Etkinlik alımı ve politika teslimatı izinleri verilen yeni API anahtar çekmeceği.](/images/dashboard/key-create.png)

    Entegrasyonu bağladıktan sonra, olaylarının beklenen ortamda tam çalışmalara gruplandırıldığını doğrulamak için Sessions listesini kullanın.

    ![Yeni bağlanan bir entegrasyonun tam agent çalışmaları bildirdiğini doğrulamak için kullanılan Sessions listesi.](/images/dashboard/sessions-list.png)

    Entegrasyonu tamamlandığı için değerlendirmeden önce bu oturumlardan birini açın; izleme, denetimlerinizin ihtiyaç duyduğu model, tool, error ve policy kanıtlarını içermelidir.
  </Tab>
  <Tab title="CLI">
    Bir makine anahtarı oluşturun, Failproof daemon'ını bağlayın ve ilk oturumu doğrulayın.

    ```bash
    fp keys create agent-production \
      --add events:add \
      --add policies:pull

    failproofai config \
      --connect https://app.befailproof.ai \
      --token <machine-key>

    failproofai flush --wait
    fp sessions --since 1h --env production
    fp events --since 1h --env production --limit 20
    ```

    Başka bir araç sonucu tüketecek olduğunda `fp --json sessions ...` kullanın. `--json`, `--org` ve `--base-url` gibi global bayraklar komuttan önce gelmelidir.

    Yerel komutlar için [Failproof AI CLI referansını](/tr/reference/failproof-cli), `fp` komutları için [Failproof Cloud CLI referansını](/tr/reference/cloud-cli#cli-commands) görmek için bkz.
  </Tab>
</Tabs>
