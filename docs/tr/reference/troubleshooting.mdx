Şu komutlarla başlayın:

```bash
failproofai config --status
failproofai policies
```

## Bir ajan bağlı değil

Kurulumu tekrar çalıştırın:

```bash
failproofai config
```

Kurulum Linux ve macOS'u destekler. Hizmeti yüklemek için bir kez yönetici erişimine ihtiyaç duyar, ancak asla sudo şifresi istemez.

[Harnesses](/tr/reference/harnesses) bölümünde harness yollarını ve kapsamlarını kontrol edin.

## Bir oturum eksik

```bash
failproofai flush --wait
failproofai backfill --since 30d --dry-run
failproofai harness list
```

Eski geçmişi yeniden göndermek için `--dry-run` öğesini kaldırın. Başka bir transkript konumu eklemek için:

```bash
failproofai harness add-path <harness> [label=]<path>
```

İki konum aynı projenin kopyalarını içeriyorsa etiket kullanın.

## Her korunan işlem reddediliyor

Yapılandırılmış bir makinede, `failproofaid` tek değerlendiricisidir. Cevap veremezse, korunan işlemler kapalı halde başarısız olur.

```bash
failproofai config --status
systemctl status failproofaid@$USER        # Linux
sudo launchctl print system/ai.failproof.failproofaid.$USER  # macOS
```

Hizmeti onarmak veya yeniden yüklemek için `failproofai config` komutunu çalıştırın.

## Bir paket reddediyor

`failproofai policies` yüklenemeyen paketleri listeler. Seçilen bir paket kaybolan yerine kapalı halde başarısız olur.

Yaygın nedenler:

- Yapı yüklemeden sonra değişti.
- Manifest ve paketlenmiş politikalar uyuşmuyor.
- Dosya eksik veya içe aktarılamıyor.
- Paket desteklenmeyen bir olay, araç veya politika şekli kullanıyor.

Paketi kaldırın veya düzeltilmiş bir sürümü yükleyin:

```bash
failproofai policies remove owner/repo
failproofai policies add owner/repo@<release>
```

## Bulut bağlantısı kesildi

Anahtar için ortam değişkenini tercih edin:

```bash
export FAILPROOFAI_CLOUD_TOKEN="<key>"
failproofai config
failproofai config --status
```

Bir makine, politikaları bağımsız olarak çekebilir ve etkinlik gönderebilir. Durum her ikisini de raporlar.

## Bir politika engellemedu

Üç şeyi kontrol edin:

1. Politika açık: `failproofai policies`.
2. Olayı ve aracı işlemle eşleşiyor.
3. O harness olayı uygulayabiliyor.

Araç çağrısı reddi tüm 12 desteklenen harness üzerinde doğrulanır. Diğer olaylar farklılık gösterir. [Uygulama yeteneğine](/tr/reference/harnesses#enforcement-capability) bakın.

## İndirmeler engellendi

- `FAILPROOFAI_NO_DOWNLOAD=1` ağ indirmelerini reddeder.
- `FAILPROOFAI_DAEMON_BASE_URL` hizmet indirmelerini bir aynaya yönlendirir.
- `FAILPROOFAI_PACK_BASE_URL` paket indirmelerini bir aynaya yönlendirir.

Yüklü paketler, indirmeler devre dışı bırakıldığında uygulamaya devam eder.
