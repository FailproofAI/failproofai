Modeller aracılığıyla bir model, agent, ortam veya zaman aralığı ile güvenilirlik ya da maliyetin değişip değişmediğini görebilirsiniz.

<Tabs>
  <Tab title="Dashboard">
    1. **Observe → Models** bölümüne gidin.
    2. Zaman aralığını ayarlayın, ardından ortam, model, agent veya session ID'ye göre filtreleyin.
    3. Latens, token tüketimi, bağlam-penceresi kullanımı ve model dağılımını inceleyin.
    4. Eşleşen olayları açmak için bir grafik noktası veya dağılım segmentini seçin.

    ![Latens, yüzdelik dilim, token, maliyet, bağlam-penceresi ve model-dağılımı görünümlerini gösteren Models sayfası.](/images/dashboard/models.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list models
    fp events --event-type model_request,model_response --env production --since 24h
    fp --json events --fields ts,agent_id,session_id,event_type,output_tokens,context_fill
    ```

    Özel bir CLI komutu olarak sunulmayan model düzeyinde toplamalar için kaydedilmiş bir sorgu kullanın.
  </Tab>
</Tabs>
