## Hangi framework olursa olsun, üç satır

<CodeGroup>
```bash LangGraph
pip install 'failproofai-sdk[langgraph]'
```

```bash CrewAI
pip install 'failproofai-sdk[crewai]'
```

```bash LlamaIndex
pip install 'failproofai-sdk[llamaindex]'
```

```bash Pydantic AI
pip install 'failproofai-sdk[pydantic-ai]'
```

```bash Özel ajanlar
pip install failproofai-sdk
```
</CodeGroup>

```python
import failproofai_sdk

failproofai_sdk.configure(environment="production")
failproofai_sdk.instrument()          # içe aktardığın framework'leri algılar

with failproofai_sdk.session():
    ...                               # mevcut ajan çağrın, değişmez
```

Fonksiyonlarında hiçbir dekoratör yok, çağrılarına hiçbir callback geçilmiyor, kodunuz boyunca thread edilmiş hiçbir id yok. Sadece oturum içindeki çağrı farklı:

<Tabs>
  <Tab title="LangGraph">
    ```python
    graph.invoke({"messages": [HumanMessage("...")]})
    ```
  </Tab>
  <Tab title="CrewAI">
    ```python
    Crew(agents=[analyst, writer], tasks=[gather, summarise]).kickoff()
    ```
  </Tab>
  <Tab title="LlamaIndex">
    ```python
    await agent.run("...")        # `async with failproofai_sdk.session():` altında
    ```
  </Tab>
  <Tab title="Pydantic AI">
    ```python
    agent.run_sync("...")
    ```
  </Tab>
  <Tab title="Özel ajanlar">
    ```python
    with failproofai_sdk.agent("planner"):
        with failproofai_sdk.tool_call("search", input={"q": q}) as t:
            t.output = search(q)
    ```
  </Tab>
</Tabs>

Ekstra yükleme **framework**'ü kurar. Her adapter temel wheel'de gönderilir, bu nedenle framework'ü zaten olan bir proje hiçbir ekstra yüklemeye ihtiyaç duymaz.

## Varışını kontrol et

Bir işaretli oturumu çalıştır, ardından **Observe → Sessions** öğesini aç ve ortamını seç. Çalıştırma yeniden yapılandırılmış bir iz olarak görünür.

Hiçbir şey gelmezse, makinenin `failproofai config --status` ile bağlı olduğunu doğrula. Bkz. [Yakalamanın kurulumu](/tr/start/setup).

<Warning>
  Teslimi doğrulamak için spool dizinini kontrol etme. Failproof daemon'u her toplu işi milisaniye içinde toplar ve siler, bu nedenle onu okumak toplayıcı ile yarışır ve yayılan olaylardan çok daha azını gösterir.
</Warning>
