## Başlamadan önce

Bu yolun varsaydığı iki şey, ikisi de aşağıdaki kod tarafından sizin için yapılmaz:

| Gereksinim | Neden |
| --- | --- |
| Python 3.10 veya daha yeni | SDK'nın bildirdiği minimum sürüm. |
| `failproofai config` ile ayarlanmış bir makine | Bu komut failproofaid daemon'ını yükler ve daemon, SDK'nın yazdığı şeyi göndermek için gereken tek şeydir. Olmadan toplu işler spool dizininde birikir ve hiçbir zaman ayrılmaz. |

<Note>
  **Bu yol kaydeder; uygulamaz.** SDK ajanınızın ne yaptığını yakalar. İlkeler bir ajan CLI içindeki bir hook'tan ateşlenir, bu nedenle bir çerçeve ajanında uygulamak, kendi çalışma zamanınıza bir hook koymak anlamına gelir — bkz. [Policies](/tr/policies/overview).
</Note>

## Üç satır, hangi framework olursa olsun

<CodeGroup>
```bash LangGraph
pip install 'failproofai-sdk[langgraph]'
```

```bash CrewAI
pip install 'failproofai-sdk[crewai]'
```

```bash LlamaIndex
pip install 'failproofai-sdk[llamaindex]'
```

```bash Pydantic AI
pip install 'failproofai-sdk[pydantic-ai]'
```

```bash Custom agents
pip install failproofai-sdk
```
</CodeGroup>

```python
import failproofai_sdk

failproofai_sdk.configure(environment="production")
failproofai_sdk.instrument()          # içe aktardığınız çerçeveleri algılar

with failproofai_sdk.session():
    ...                               # var olan ajan çağrınız, değişmez
```

Fonksiyonlarınızda dekoratör yok, çağrılarınıza geçilen callback yok, kodunuzda iplik edilen id'ler yok. Sadece session içindeki çağrı farklı:

<Tabs>
  <Tab title="LangGraph">
    ```python
    graph.invoke({"messages": [HumanMessage("...")]})
    ```
  </Tab>
  <Tab title="CrewAI">
    ```python
    Crew(agents=[analyst, writer], tasks=[gather, summarise]).kickoff()
    ```
  </Tab>
  <Tab title="LlamaIndex">
    ```python
    await agent.run("...")        # `async with failproofai_sdk.session():` altında
    ```
  </Tab>
  <Tab title="Pydantic AI">
    ```python
    agent.run_sync("...")
    ```
  </Tab>
  <Tab title="Custom agents">
    ```python
    with failproofai_sdk.agent("planner"):
        with failproofai_sdk.tool_call("search", input={"q": q}) as t:
            t.output = search(q)
    ```
  </Tab>
</Tabs>

Ekstra yükleme **çerçeveyi** kurar. Her adapter temel wheel'de gönderilir, bu nedenle zaten çerçevesine sahip bir proje hiç ekstra ihtiyaç duymaz.

## Geldiğini kontrol edin

Enstrüman edilmiş bir session çalıştırın, ardından **Observe → Sessions** sayfasını açın ve ortamınızı seçin. Çalışma yeniden oluşturulmuş bir trace olarak görünür.

Hiçbir şey gelmezse, makinenin ayarlandığını ve `failproofai config --status` ile bağlı olduğunu doğrulayın. Değilse, `failproofai config` çalıştırın. Bkz. [Kurulumunuzu seçin](/tr/start/setup).

<Warning>
  Teslimatı doğrulamak için spool dizinini kontrol etmeyin. Failproof daemon her toplu işi milisaniyeler içinde toplayıp siler, bu nedenle onu okumak toplayıcı ile yarışır ve yayılan olaylardan çok daha azını gösterir.
</Warning>

SDK'nın hiç yazıp yazmadığını kanıtlamak için, daemon'u önce durdurun, session'ınızı çalıştırın ve `~/.failproofai/custom-agents/events/` klasörüne bakın. Daemon çalışırken, boş bir dizin sağlıklı bir durumdur.

<CodeGroup>
```bash Linux
sudo systemctl stop failproofaid@$USER
```

```bash macOS
sudo launchctl bootout system/ai.failproof.failproofaid.$USER
```
</CodeGroup>

Geri koymak için sonrasında `failproofai config` çalıştırın. Daemon durdurulduğu sürece, bu makinedeki hook etkinlikleri hiçbir değerlendirici olmadan reddedilir, bu nedenle sadece kontrol süresi kadar durdurun.
