Toàn bộ triển khai Failproof AI Observability của bạn, chỉ cách một lệnh. Kiểm tra môi trường production, tạo khóa API, hoặc xác nhận một sự cố mà không cần rời khỏi terminal của bạn, sau đó kịch bản hóa bất kỳ điều gì vào CI, hoặc để một agent mã hóa thực hiện nó cho bạn bằng tiếng Anh thường ngôn.

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*CLI `agenteye` giao tiếp với bảng điều khiển của bạn. Đó là một công cụ khác so với bộ thu thập, công cụ này gửi sự kiện đến máy chủ.*

## Toàn bộ triển khai của bạn, chỉ cách một lệnh

Ngừng chuyển đổi giữa các tab để trả lời một câu hỏi nhanh. CLI `agenteye` đọc dữ liệu của bạn và quản lý tổ chức của bạn từ một tệp nhị phân duy nhất, vì vậy một kiểm tra mà trước đây có nghĩa là nhấp qua bảng điều khiển sẽ trở thành một dòng mà bạn có thể chạy lại, tạo bí danh, hoặc dán vào runbook. Bạn nhận được bốn giao diện:

- **Đọc dữ liệu của bạn:** `sessions`, `events`, `evals`, và `errors`, được lọc theo thời gian, agent và môi trường.
- **Quản lý tổ chức của bạn:** `keys`, `users`, `settings`, `alerts`, và `incidents`.
- **Chạy phân tích:** SQL được lưu cộng với trình chạy `query` ad-hoc trên dữ liệu sự kiện của bạn.
- **Hỏi trợ lý:** `agent ask` tiếp cận cùng một nhà phân tích chỉ đọc mà bạn trò chuyện với trong bảng điều khiển.

Cài đặt nó một lần với `pipx`, đăng nhập bằng mã 6 chữ số được gửi qua email, và bạn đã sẵn sàng. Phiên khoảng kéo dài một ngày; chạy lại `agenteye login` khi nó hết hạn. Sử dụng nó để kiểm tra nhanh production, cấp phát khóa, hoặc phân loại một sự cố đang xảy ra, tất cả mà không cần mở trình duyệt:

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

Một thói quen cần biết: các tùy chọn toàn cục như `--json` đặt trước lệnh. `agenteye --json sessions` là đúng; `agenteye sessions --json` là sai.

## Kịch bản hóa nó, tích hợp vào CI

Mọi lệnh đều có `--json`, và điều đó thay đổi mọi thứ. JSON sạch đi stdout trong khi trạng thái con người và cảnh báo đi stderr, vì vậy bắt `--json` đi trực tiếp vào `jq` mà không có dòng lạ để xóa. Đó là điều làm cho CLI tốt như nhau cho bạn tại dấu nhắc và cho một agent mã hóa phân tích kết quả:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

Nó được xây dựng để chạy mà không giám sát. Lời nhắc xác nhận tự động bỏ qua khi không có terminal được kết nối, vì vậy không có gì treo trong pipeline, và mọi lệnh đều trả về mã thoát có ý nghĩa: `0` thành công, `4` chưa đăng nhập, `5` thiếu quyền (tin nhắn đặt tên nó, ví dụ `alerts:write`), `3` bảng điều khiển không thể tiếp cận. Một script có thể nhánh trên `4` để xác thực lại hoặc `5` để cho bạn biết chính xác cần yêu cầu admin điều gì, thay vì thất bại mà không rõ lý do.

## Để một agent mã hóa điều khiển nó bằng tiếng Anh thường ngôn

Tốt hơn nữa, bạn không nên phải nhớ bất kỳ cờ này. **CLI skill** là một thư mục Kỹ năng Agent nhỏ được đặt tên `agenteye-cli` dạy cho một agent mã hóa như Claude Code hoặc Codex cách điều khiển CLI từ các yêu cầu bằng tiếng Anh thường ngôn. Hỏi "có gì bị hỏng hôm nay không?" và agent chọn lệnh, chạy nó như bạn, và trả lời bằng chữ.

Đối với Claude Code, hãy thả thư mục `agenteye-cli` vào `~/.claude/skills/` và nó sẽ được tự động phát hiện. Failproof AI Observability cung cấp thư mục; không có gì thêm để cài đặt, vì nó chỉ điều khiển CLI mà bạn đã cài đặt. Đăng nhập chính mình trước: skill không thể hoàn thành login mã được gửi qua email cho bạn.

Vì agent chạy CLI như bạn, nó có thể làm mọi thứ mà login của bạn cho phép, cả đọc và ghi: tạo khóa, thay đổi cài đặt, giải quyết sự cố. Lời nhắc "bạn có chắc chắn không?" của CLI không kích hoạt cho một agent, vì vậy skill được viết để nêu lệnh chính xác và chờ OK của bạn trước bất kỳ thay đổi nào. Bạn là bước xác nhận.

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

Các lần đọc vẫn tức thì, và mọi lần ghi đều tạm dừng cho bạn:

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
