Toàn bộ triển khai Failproof AI Observability của bạn, chỉ cách một lệnh. Kiểm tra production, tạo một API key, hoặc xác nhận một sự cố mà không cần rời khỏi terminal của bạn, sau đó đưa bất kỳ lệnh nào vào CI, hoặc để một coding agent thực hiện nó cho bạn bằng tiếng Anh thông thường.

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*CLI `agenteye` kết nối với dashboard của bạn. Đây là một công cụ khác biệt với bộ collector, bộ collector gửi sự kiện đến máy chủ.*

## Toàn bộ triển khai của bạn, chỉ cách một lệnh

Dừng việc chuyển đổi giữa các tab để trả lời một câu hỏi nhanh. CLI `agenteye` đọc dữ liệu của bạn và quản lý tổ chức của bạn từ một file nhị phân duy nhất, vì vậy một kiểm tra mà trước đây có nghĩa là nhấp qua dashboard trở thành một dòng mà bạn có thể chạy lại, tạo bí danh hoặc dán vào một runbook. Bạn nhận được bốn giao diện:

- **Đọc dữ liệu của bạn:** `sessions`, `events`, `evals`, và `errors`, được lọc theo thời gian, agent và môi trường.
- **Quản lý tổ chức của bạn:** `keys`, `users`, `settings`, `alerts`, và `incidents`.
- **Chạy phân tích:** SQL đã lưu cộng với trình chạy `query` ad-hoc trên dữ liệu sự kiện của bạn.
- **Hỏi trợ lý:** `agent ask` truy cập cùng một nhà phân tích chỉ đọc mà bạn trò chuyện trong dashboard.

Cài đặt nó một lần với `pipx`, đăng nhập với mã 6 chữ số được gửi qua email, và bạn đã sẵn sàng. Phiên kéo dài khoảng một ngày; chạy lại `agenteye login` khi nó hết hạn. Sử dụng nó để kiểm tra production, cung cấp một key hoặc phân loại một sự cố đang xảy ra, tất cả mà không cần mở trình duyệt:

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

Một thói quen để biết: các tùy chọn toàn cục như `--json` đi trước lệnh. `agenteye --json sessions` là đúng; `agenteye sessions --json` là không đúng.

## Viết script nó, tích hợp vào CI

Mỗi lệnh đều hỗ trợ `--json`, và điều đó thay đổi mọi thứ. JSON sạch sẽ đi tới stdout trong khi trạng thái con người và cảnh báo đi tới stderr, vì vậy việc capture `--json` sẽ được pipe trực tiếp vào `jq` mà không có dòng nào để loại bỏ. Đó là điều làm cho CLI tốt như nhau cho bạn tại dòng lệnh và cho một coding agent phân tích đầu ra:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

Nó được xây dựng để chạy không có giám sát. Các lời nhắc xác nhận tự động bỏ qua khi không có terminal được gắn, vì vậy không có gì sẽ treo trong một pipeline, và mỗi lệnh trả về một mã thoát có nghĩa: `0` thành công, `4` chưa đăng nhập, `5` thiếu quyền (thông báo đặt tên nó, ví dụ `alerts:write`), `3` dashboard không thể tiếp cận. Một script có thể phân nhánh trên `4` để xác thực lại hoặc `5` để báo cho bạn chính xác những gì cần yêu cầu từ quản trị viên, thay vì thất bại mà không biết lý do.

## Để một coding agent điều khiển nó bằng tiếng Anh thông thường

Tốt hơn nữa, bạn không nên phải nhớ bất kỳ cờ nào cả. **CLI skill** là một thư mục Agent Skill nhỏ được đặt tên `agenteye-cli` dạy cho một coding agent như Claude Code hoặc Codex cách điều khiển CLI từ các yêu cầu bằng tiếng Anh thông thường. Hỏi "có điều gì bị hỏng hôm nay không?" và agent chọn lệnh, chạy nó như bạn, và trả lời bằng văn bản.

Đối với Claude Code, thả thư mục `agenteye-cli` vào `~/.claude/skills/` và nó sẽ được tự động phát hiện. Failproof AI Observability cung cấp thư mục; không có gì extra để cài đặt, bởi vì nó chỉ điều khiển CLI mà bạn đã cài đặt. Tự đăng nhập trước: skill không thể hoàn thành đăng nhập mã được gửi qua email cho bạn.

Vì agent chạy CLI như bạn, nó có thể làm mọi thứ mà đăng nhập của bạn cho phép, cả đọc và ghi: tạo keys, thay đổi cài đặt, giải quyết sự cố. Lời nhắc "bạn có chắc chứ?" của CLI không kích hoạt cho một agent, vì vậy skill được viết để nêu ra lệnh chính xác và đợi OK của bạn trước khi có bất kỳ thay đổi nào. Bạn là bước xác nhận.

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

Các lần đọc vẫn tức thì, và mỗi lần ghi tạm dừng cho bạn:

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
