Toàn bộ triển khai Failproof AI Observability của bạn, chỉ cách một lệnh. Kiểm tra production, tạo khóa API, hoặc xác nhận một sự cố mà không cần rời khỏi terminal, sau đó kịch bản hóa bất kỳ điều gì vào CI, hoặc để một coding agent thực hiện nó cho bạn bằng tiếng Anh thuần túy.

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*CLI `agenteye` giao tiếp với dashboard của bạn. Nó là một công cụ khác biệt với collector, công cụ gửi các sự kiện đến máy chủ.*

## Toàn bộ triển khai của bạn, chỉ cách một lệnh

Ngừng chuyển đổi giữa các tab để trả lời một câu hỏi nhanh. CLI `agenteye` đọc dữ liệu của bạn và quản lý tổ chức của bạn từ một tệp nhị phân duy nhất, vì vậy một kiểm tra mà trước đây có nghĩa là nhấp vào dashboard trở thành một dòng mà bạn có thể chạy lại, tạo bí danh hoặc dán vào runbook. Bạn nhận được bốn giao diện:

- **Đọc dữ liệu của bạn:** `sessions`, `events`, `evals`, và `errors`, được lọc theo thời gian, agent và môi trường.
- **Quản lý tổ chức:** `keys`, `users`, `settings`, `alerts`, và `incidents`.
- **Chạy phân tích:** SQL đã lưu cộng với trình chạy `query` ad-hoc trên dữ liệu sự kiện của bạn.
- **Hỏi trợ lý:** `agent ask` tiếp cận cùng một nhà phân tích chỉ đọc mà bạn trò chuyện trong dashboard.

Cài đặt một lần bằng `pipx`, đăng nhập bằng mã 6 chữ số được gửi qua email, và bạn đã sẵn sàng. Phiên kéo dài khoảng một ngày; chạy lại `agenteye login` khi nó hết hạn. Dùng nó để kiểm tra production, cấp một khóa, hoặc phân loại một sự cố đang xảy ra, tất cả mà không cần mở trình duyệt:

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

Một thói quen cần biết: các tùy chọn toàn cục như `--json` đứng trước lệnh. `agenteye --json sessions` là đúng; `agenteye sessions --json` là sai.

## Kịch bản hóa, tích hợp vào CI

Mỗi lệnh đều có `--json`, và điều đó thay đổi mọi thứ. JSON sạch đi đến stdout trong khi trạng thái human và cảnh báo đi đến stderr, vì vậy một bản ghi `--json` có thể piped thẳng vào `jq` mà không cần dòng lạ để loại bỏ. Đó là điều làm cho CLI cũng tốt cho bạn tại dấu nhắc và cho một coding agent phân tích đầu ra:

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

Nó được xây dựng để chạy không người giám sát. Các lời nhắc xác nhận tự động bỏ qua khi không có terminal được kết nối, vì vậy không có gì bị treo trong pipeline, và mỗi lệnh trả về một mã thoát có ý nghĩa: `0` thành công, `4` chưa đăng nhập, `5` thiếu một quyền (thông báo đặt tên, ví dụ `alerts:write`), `3` dashboard không thể tiếp cận. Một kịch bản có thể phân nhánh trên `4` để xác thực lại hoặc `5` để cho bạn biết chính xác những gì cần yêu cầu từ quản trị viên, thay vì thất bại mù quáng.

## Để một coding agent điều khiển nó bằng tiếng Anh thuần túy

Tốt hơn nữa, bạn không nên phải nhớ bất kỳ flags nào trong số này. **CLI skill** là một thư mục Skill Agent nhỏ có tên `agenteye-cli` dạy một coding agent như Claude Code hoặc Codex điều khiển CLI từ các yêu cầu tiếng Anh thuần túy. Hỏi "có điều gì bị hỏng hôm nay không?" và agent chọn lệnh, chạy nó dưới tên bạn, và trả lời bằng prose.

Đối với Claude Code, thả thư mục `agenteye-cli` vào `~/.claude/skills/` và nó được phát hiện tự động. Failproof AI Observability cung cấp thư mục; không có gì phải cài đặt thêm, vì nó chỉ điều khiển CLI mà bạn đã cài đặt. Đăng nhập chính bạn trước tiên: skill không thể hoàn thành đăng nhập mã email cho bạn.

Vì agent chạy CLI dưới tên bạn, nó có thể làm mọi thứ mà đăng nhập của bạn cho phép, đọc và viết cả hai: tạo khóa, thay đổi cài đặt, giải quyết sự cố. Lời nhắc "bạn có chắc không?" của CLI không kích hoạt cho một agent, vì vậy skill được viết để nêu lệnh chính xác và đợi OK của bạn trước bất kỳ thay đổi nào. Bạn là bước xác nhận.

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

Các bản đọc vẫn tức thì, và mỗi ghi tạm dừng cho bạn:

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
