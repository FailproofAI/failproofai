```bash
failproofai
```

Khởi động bảng điều khiển web tại `http://localhost:8020`.

## Các tùy chọn

The dashboard takes no flags — `failproofai` rejects any it does not recognize. The port is fixed at `8020`.

Để trỏ bảng điều khiển tới thư mục dự án Claude không phải mặc định, hãy đặt biến môi trường `CLAUDE_PROJECTS_PATH` khi khởi động.

## Ví dụ

```bash
failproofai

# Sử dụng đường dẫn dự án Claude tùy chỉnh thông qua biến môi trường
CLAUDE_PROJECTS_PATH=~/my-claude-projects failproofai
```
