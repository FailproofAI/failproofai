title: Xem các phiên
description: "Khởi chạy bảng điều khiển để duyệt các phiên agent và quản lý chính sách"
---

```bash
failproofai
```

Khởi chạy bảng điều khiển web tại `http://localhost:8020`.

## Tùy chọn

| Cờ | Mô tả |
|------|-------------|
| `--port <number>` | Cổng để lắng nghe (mặc định: `8020`) |
| `--allowed-origins <origins>` | Các máy chủ/địa chỉ IP được phép truy cập tài nguyên dev, cách nhau bằng dấu phẩy |

Để trỏ bảng điều khiển đến thư mục Claude project không phải mặc định, hãy đặt biến môi trường `CLAUDE_PROJECTS_PATH` khi khởi chạy.

## Ví dụ

```bash
# Khởi chạy trên một cổng khác
failproofai --port 9000

# Sử dụng đường dẫn Claude projects tùy chỉnh thông qua biến môi trường
CLAUDE_PROJECTS_PATH=~/my-claude-projects failproofai
```
