---
title: Cài đặt policies
description: "Bật các policies để chúng chạy trên mọi lệnh gọi tool của agent"
---

```bash
failproofai policies --install [policy-names...] [options]
```

Ghi các hook entries vào tệp settings của agent CLI đã cài đặt (Claude Code, OpenAI Codex, hoặc GitHub Copilot CLI _(beta)_) để failproofai có thể chặn các lệnh gọi tool.

Bí danh: `failproofai p -i`

## Tùy chọn

| Flag | Mô tả |
|------|-------|
| `--cli claude\|codex\|copilot` | CLI(s) agent để cài đặt cho; cách nhau bằng dấu cách (ví dụ: `--cli claude codex copilot`) hoặc lặp lại. Bỏ qua để phát hiện các CLI đã cài đặt và yêu cầu lựa chọn. |
| `--scope user` | Cài đặt vào tệp settings phạm vi người dùng (Claude: `~/.claude/settings.json`; Codex: `~/.codex/hooks.json`; Copilot: `~/.copilot/hooks/failproofai.json`). Mặc định. |
| `--scope project` | Cài đặt vào tệp settings phạm vi dự án (Claude: `<cwd>/.claude/settings.json`; Codex: `<cwd>/.codex/hooks.json`; Copilot: `<cwd>/.github/hooks/failproofai.json`). |
| `--scope local` | Chỉ Claude — cài đặt vào `<cwd>/.claude/settings.local.json`. Codex và Copilot không hỗ trợ phạm vi `local`. |
| `--custom <path>` / `-c` | Đường dẫn đến tệp JS chứa các hook policies tùy chỉnh |

## Hành vi

- **Không có tên policy** - mở một lời nhắc tương tác để chọn các policies
- **Tên cụ thể** - bật các policies đó (được thêm vào bất kỳ policies nào đã được bật)
- **`all`** - bật mọi policy có sẵn

Cài đặt có tính chất cộng dồn: chạy `--install` lại sẽ thêm các policies mới mà không xóa các policies hiện có.

## Ví dụ

```bash
# Cài đặt tất cả các default policies toàn cục (tương tác)
failproofai policies --install

# Cài đặt các policies cụ thể cho dự án hiện tại
failproofai policies --install block-sudo sanitize-api-keys --scope project

# Bật tất cả các policies một lần
failproofai policies --install all

# Cài đặt với một tệp policies tùy chỉnh
failproofai policies --install --custom ./my-policies.js

# Cài đặt cho OpenAI Codex (phạm vi dự án)
failproofai policies --install --cli codex --scope project

# Cài đặt cho GitHub Copilot CLI (beta) cho dự án hiện tại
failproofai policies --install --cli copilot --scope project

# Cài đặt cho cả ba CLI cùng một lúc
failproofai policies --install --cli claude codex copilot
```

Khi `--custom <path>` được cung cấp, tệp được xác thực ngay lập tức - nó phải gọi `customPolicies.add()` ít nhất một lần. Đường dẫn được giải quyết sẽ được lưu vào `policies-config.json` dưới dạng `customPoliciesPath`.
