---
title: Cài đặt policies
description: "Kích hoạt policies để chúng chạy trên mọi lần gọi tool của agent"
---

```bash
failproofai policies --install [policy-names...] [options]
```

Ghi các hook entries vào tệp settings của agent CLI được cài đặt (Claude Code, OpenAI Codex, hoặc GitHub Copilot CLI _(beta)_) để failproofai có thể chặn các lệnh gọi tool.

Alias: `failproofai p -i`

## Options

| Flag | Mô tả |
|------|-------------|
| `--cli claude\|codex\|copilot` | Agent CLI(s) để cài đặt cho; cách nhau bằng khoảng trắng (ví dụ `--cli claude codex copilot`) hoặc lặp lại. Bỏ qua để tự động phát hiện các CLI đã cài đặt và nhắc nhở. |
| `--scope user` | Cài đặt vào tệp settings phạm vi người dùng (Claude: `~/.claude/settings.json`; Codex: `~/.codex/hooks.json`; Copilot: `~/.copilot/hooks/failproofai.json`). Mặc định. |
| `--scope project` | Cài đặt vào tệp settings phạm vi dự án (Claude: `<cwd>/.claude/settings.json`; Codex: `<cwd>/.codex/hooks.json`; Copilot: `<cwd>/.github/hooks/failproofai.json`). |
| `--scope local` | Chỉ Claude — cài đặt vào `<cwd>/.claude/settings.local.json`. Codex và Copilot không có phạm vi `local`. |
| `--custom <path>` / `-c` | Đường dẫn tệp JS chứa các hook policies tùy chỉnh |

## Hành vi

- **Không có tên policy** - mở một lời nhắc tương tác để chọn policies
- **Tên cụ thể** - kích hoạt những policies đó (thêm vào bất kỳ cái nào đã được kích hoạt)
- **`all`** - kích hoạt mọi policy có sẵn

Việc cài đặt là tích lũy: chạy `--install` lần nữa sẽ thêm các policy mới mà không xóa những policy hiện có.

## Ví dụ

```bash
# Cài đặt tất cả default policies toàn cầu (tương tác)
failproofai policies --install

# Cài đặt các policies cụ thể cho dự án hiện tại
failproofai policies --install block-sudo sanitize-api-keys --scope project

# Kích hoạt tất cả policies cùng một lúc
failproofai policies --install all

# Cài đặt với tệp policies tùy chỉnh
failproofai policies --install --custom ./my-policies.js

# Cài đặt cho OpenAI Codex (phạm vi dự án)
failproofai policies --install --cli codex --scope project

# Cài đặt cho GitHub Copilot CLI (beta) cho dự án hiện tại
failproofai policies --install --cli copilot --scope project

# Cài đặt cho cả ba CLIs cùng một lúc
failproofai policies --install --cli claude codex copilot
```

Khi `--custom <path>` được cung cấp, tệp sẽ được xác thực ngay lập tức - nó phải gọi `customPolicies.add()` ít nhất một lần. Đường dẫn được giải quyết sẽ được lưu vào `policies-config.json` dưới dạng `customPoliciesPath`.
