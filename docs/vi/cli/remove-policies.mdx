---
title: Gỡ cài đặt policies
description: "Xóa hook entries từ settings của Claude Code"
---

```bash
failproofai policies --uninstall [policy-names...] [options]
```

Xóa failproofai hook entries từ `settings.json` của Claude Code.

Alias: `failproofai p -u`

## Options

| Flag | Mô tả |
|------|-------------|
| `--scope user` | Xóa từ global settings (mặc định) |
| `--scope project` | Xóa từ project settings |
| `--scope local` | Xóa từ local settings |
| `--scope all` | Xóa từ tất cả scopes cùng một lúc |
| `--custom` / `-c` | Xóa `customPoliciesPath` từ config |

## Hành động

- **Không có tên policy** - xóa tất cả failproofai hook entries từ file settings
- **Tên cụ thể** - vô hiệu hóa các policies đó nhưng giữ hooks đã cài đặt

## Ví dụ

```bash
# Xóa tất cả hooks globally
failproofai policies --uninstall

# Vô hiệu hóa một policy cụ thể (giữ hooks đã cài đặt)
failproofai policies --uninstall block-sudo

# Xóa hooks từ mọi scope
failproofai policies --uninstall --scope all

# Xóa custom policies path
failproofai policies --uninstall --custom
```
