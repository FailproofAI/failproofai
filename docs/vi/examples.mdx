## Thiết lập hooks cho Claude Code

Failproof AI tích hợp với Claude Code thông qua [hệ thống hooks](https://docs.anthropic.com/en/docs/claude-code/hooks) của nó. Khi bạn chạy `failproofai policies --install`, nó sẽ đăng ký các lệnh hook trong `settings.json` của Claude Code mà kích hoạt trên mỗi lệnh gọi công cụ.

<Steps>
  <Step title="Cài đặt failproofai">
    ```bash
    npm install -g failproofai
    ```
  </Step>
  <Step title="Bật tất cả các chính sách tích hợp sẵn">
    ```bash
    failproofai policies --install
    ```
  </Step>
  <Step title="Xác minh hooks đã được đăng ký">
    ```bash
    cat ~/.claude/settings.json | grep failproofai
    ```

    Bạn sẽ thấy các mục hook cho các sự kiện `PreToolUse`, `PostToolUse`, `Notification`, và `Stop`.
  </Step>
  <Step title="Chạy Claude Code">
    ```bash
    claude
    ```

    Các chính sách sẽ chạy tự động trên mỗi lệnh gọi công cụ. Hãy thử yêu cầu Claude chạy `sudo rm -rf /` - nó sẽ bị chặn.
  </Step>
</Steps>

## Thiết lập hooks cho Agents SDK

Nếu bạn đang xây dựng với [Agents SDK](https://docs.anthropic.com/en/docs/agents-sdk), bạn có thể sử dụng cùng hệ thống hook theo cách lập trình.

<Steps>
  <Step title="Cài đặt failproofai trong dự án của bạn">
    ```bash
    npm install failproofai
    ```
  </Step>
  <Step title="Cấu hình hooks trong agent của bạn">
    Truyền các lệnh hook khi tạo quy trình agent của bạn. Các hooks kích hoạt theo cách tương tự như trong Claude Code - thông qua JSON stdin/stdout:

    ```bash
    failproofai --hook PreToolUse   # được gọi trước mỗi công cụ
    failproofai --hook PostToolUse  # được gọi sau mỗi công cụ
    ```
  </Step>
  <Step title="Viết một chính sách tùy chỉnh cho agent của bạn">
    ```javascript
    import { customPolicies, allow, deny } from "failproofai";

    customPolicies.add({
      name: "limit-to-project-dir",
      description: "Giữ agent bên trong thư mục dự án",
      match: { events: ["PreToolUse"] },
      fn: async (ctx) => {
        const path = String(ctx.toolInput?.file_path ?? "");
        if (path.startsWith("/") && !path.startsWith(ctx.session?.cwd ?? "")) {
          return deny("Agent bị hạn chế trong thư mục dự án");
        }
        return allow();
      },
    });
    ```
  </Step>
  <Step title="Cài đặt chính sách tùy chỉnh">
    ```bash
    failproofai policies --install --custom ./my-agent-policies.js
    ```
  </Step>
</Steps>

## Chặn các lệnh phá hủy

Thiết lập phổ biến nhất - ngăn các agent thực hiện những tổn thất không thể đảo ngược.

```bash
failproofai policies --install block-sudo block-rm-rf block-force-push block-curl-pipe-sh
```

Điều này làm gì:
- `block-sudo` - chặn tất cả các lệnh `sudo`
- `block-rm-rf` - chặn xóa tệp đệ quy
- `block-force-push` - chặn `git push --force`
- `block-curl-pipe-sh` - chặn piping các script từ xa tới shell

## Ngăn chặn rò rỉ bí mật

Ngăn các agent nhìn thấy hoặc rò rỉ thông tin xác thực trong kết quả công cụ.

```bash
failproofai policies --install sanitize-api-keys sanitize-jwt sanitize-connection-strings sanitize-bearer-tokens
```

Những chính sách này kích hoạt trên `PostToolUse` - sau khi một công cụ chạy, chúng sẽ làm sạch kết quả trước khi agent nhìn thấy.

## Nhận cảnh báo Slack khi các agent cần chú ý

Sử dụng hook thông báo để chuyển tiếp cảnh báo ngơi ngách tới Slack.

```javascript
import { customPolicies, allow, instruct } from "failproofai";

customPolicies.add({
  name: "slack-on-idle",
  description: "Cảnh báo Slack khi agent đang chờ đầu vào",
  match: { events: ["Notification"] },
  fn: async (ctx) => {
    const webhookUrl = process.env.SLACK_WEBHOOK_URL;
    if (!webhookUrl) return allow();

    const message = String(ctx.payload?.message ?? "Agent đang chờ đợi");
    const project = ctx.session?.cwd ?? "không xác định";

    try {
      await fetch(webhookUrl, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({
          text: `*${message}*\nProject: \`${project}\``,
        }),
        signal: AbortSignal.timeout(5000),
      });
    } catch {
      // không bao giờ chặn agent nếu Slack không thể truy cập được
    }

    return allow();
  },
});
```

Cài đặt nó:

```bash
SLACK_WEBHOOK_URL=https://hooks.slack.com/... failproofai policies --install --custom ./slack-alerts.js
```

## Giữ các agent trên một nhánh

Ngăn các agent chuyển nhánh hoặc push tới các nhánh được bảo vệ.

```javascript
import { customPolicies, allow, deny } from "failproofai";

customPolicies.add({
  name: "stay-on-branch",
  description: "Ngăn agent check out các nhánh khác",
  match: { events: ["PreToolUse"] },
  fn: async (ctx) => {
    if (ctx.toolName !== "Bash") return allow();
    const cmd = String(ctx.toolInput?.command ?? "");
    if (/git\s+checkout\s+(?!-b)/.test(cmd)) {
      return deny("Ở lại nhánh hiện tại. Tạo một nhánh mới bằng -b nếu cần.");
    }
    return allow();
  },
});
```

## Yêu cầu kiểm tra trước khi commit

Nhắc nhở các agent chạy kiểm tra trước khi commit.

```javascript
import { customPolicies, allow, instruct } from "failproofai";

customPolicies.add({
  name: "test-before-commit",
  description: "Nhắc nhở agent chạy kiểm tra trước khi commit",
  match: { events: ["PreToolUse"] },
  fn: async (ctx) => {
    if (ctx.toolName !== "Bash") return allow();
    const cmd = String(ctx.toolInput?.command ?? "");
    if (/git\s+commit/.test(cmd)) {
      return instruct("Chạy kiểm tra trước khi commit. Sử dụng `npm test` hoặc `bun test` trước tiên.");
    }
    return allow();
  },
});
```

## Khóa kho lưu trữ sản xuất

Commit một cấu hình mức dự án để mỗi nhà phát triển trong nhóm của bạn nhận được các chính sách giống nhau.

Tạo `.failproofai/policies-config.json` trong kho của bạn:

```json
{
  "enabledPolicies": [
    "block-sudo",
    "block-rm-rf",
    "block-force-push",
    "block-push-master",
    "block-env-files",
    "sanitize-api-keys",
    "sanitize-jwt"
  ],
  "policyParams": {
    "block-push-master": {
      "protectedBranches": ["main", "release", "production"]
    }
  }
}
```

Sau đó commit nó:

```bash
git add .failproofai/policies-config.json
git commit -m "Add failproofai team policies"
```

Mỗi thành viên trong nhóm có cài đặt failproofai sẽ tự động áp dụng các quy tắc này.

## Xây dựng tiêu chuẩn chất lượng toàn tổ chức với chính sách quy ước

Thiết lập có tác động lớn nhất: commit `.failproofai/policies/` tới kho của bạn với các chính sách được điều chỉnh cho dự án của bạn. Mỗi thành viên trong nhóm đều có được chúng tự động — không có lệnh cài đặt, không có thay đổi cấu hình.

<Steps>
  <Step title="Tạo thư mục và thêm chính sách">
    ```bash
    mkdir -p .failproofai/policies
    ```

    ```js
    // .failproofai/policies/team-policies.mjs
    import { customPolicies, allow, deny, instruct } from "failproofai";

    // Thực thi trình quản lý gói ưa thích của nhóm bạn
    // (hoặc bật chính sách tích hợp sẵn prefer-package-manager thay thế)
    customPolicies.add({
      name: "enforce-bun",
      match: { events: ["PreToolUse"] },
      fn: async (ctx) => {
        if (ctx.toolName !== "Bash") return allow();
        const cmd = String(ctx.toolInput?.command ?? "");
        if (/\bnpm\b/.test(cmd)) return deny("Sử dụng bun thay vì npm.");
        return allow();
      },
    });

    // Nhắc nhở agent chạy kiểm tra trước khi commit
    customPolicies.add({
      name: "test-before-commit",
      match: { events: ["PreToolUse"] },
      fn: async (ctx) => {
        if (ctx.toolName !== "Bash") return allow();
        if (/git\s+commit/.test(ctx.toolInput?.command ?? "")) {
          return instruct("Chạy kiểm tra trước khi commit.");
        }
        return allow();
      },
    });
    ```
  </Step>
  <Step title="Commit tới git">
    ```bash
    git add .failproofai/policies/
    git commit -m "Add team quality policies"
    ```
  </Step>
  <Step title="Tiếp tục cải thiện">
    Khi nhóm của bạn gặp những chế độ hỏng hóc mới, hãy thêm các chính sách và push. Mọi người đều nhận được bản cập nhật trên `git pull` tiếp theo của họ. Các chính sách này trở thành một tiêu chuẩn chất lượng động lớn lên cùng với nhóm của bạn.
  </Step>
</Steps>

## Nhiều ví dụ hơn

Thư mục [`examples/`](https://github.com/failproofai/failproofai/tree/main/examples) trong kho chứa:

| Tệp | Điều nó cho thấy |
|------|---------------|
| `policies-basic.js` | Chính sách khởi động - chặn ghi sản xuất, force-push, piped scripts |
| `policies-notification.js` | Cảnh báo Slack cho thông báo ngơi ngách và kết thúc phiên |
| `policies-advanced/index.js` | Nhập transitive, async hooks, làm sạch kết quả PostToolUse, xử lý sự kiện Stop |
