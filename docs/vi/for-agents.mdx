Thêm tham chiếu Failproof AI đầy đủ vào agent lập trình của bạn chỉ bằng một lệnh. Hoạt động với Claude Code, Cursor, Windsurf và bất kỳ agent nào khác hỗ trợ kỹ năng.

```bash
npx skills add https://docs.befailproof.ai
```

`npx skills` tự động phát hiện các agent bạn đã cài đặt và thêm kỹ năng theo đúng định dạng cho từng agent.

## Kỹ năng bao gồm những gì

| Lĩnh vực | Nội dung bao gồm |
|---------|-----------------|
| Policies | Tên policy được tích hợp sẵn, các loại sự kiện, tham số, bật/tắt |
| Custom policies | `customPolicies.add()`, bộ lọc khớp, API `allow`/`deny`/`instruct` |
| Context object | `ctx.eventType`, `ctx.toolName`, `ctx.toolInput`, `ctx.session` |
| Configuration | Cấu trúc `policies-config.json`, hợp nhất scope, `policyParams` |
| CLI | `failproofai policies --install`, `--uninstall`, `--custom`, scopes |
| Dashboard | Trình xem phiên, hoạt động policy, các biến môi trường |
| Architecture | Luồng xử lý hook, mã thoát, hợp đồng stdin/stdout |

## Kỹ năng có hoàn chỉnh không?

Mintlify tạo `llms.txt` từ tất cả các trang trong điều hướng. Tài liệu Failproof AI bao gồm toàn bộ API - mọi policy, tùy chọn và ví dụ đều được bao gồm. Nếu bạn tìm thấy điều gì bị thiếu, nguồn nằm tại `https://docs.befailproof.ai/llms-full.txt`.

Để có bối cảnh cụ thể, hãy liên kết trực tiếp đến một trang cụ thể:

```bash
# Chỉ API custom policies
npx skills add https://docs.befailproof.ai/custom-policies

# Chỉ các built-in policies
npx skills add https://docs.befailproof.ai/built-in-policies
```
