Phạm vi bao phủ fleet so sánh những gì Cloud gán với những gì mỗi máy đã áp dụng lần cuối.

## Kiểm tra một máy

```bash
failproofai config --status
failproofai flush --wait --timeout 120
```

Từ Cloud:

```bash
fp fleet list
fp fleet diff
fp fleet show <machine-id>
```

`fp fleet` yêu cầu một phiên đăng nhập, không phải một API key.

| Lệnh | Công dụng |
| --- | --- |
| `fp fleet list` | Liệt kê các máy và trạng thái triển khai |
| `fp fleet show <machine>` | Hiển thị tập chính sách của một máy |
| `fp fleet deploy <machine> --add <ref>` | Thêm hoặc cập nhật một chính sách |
| `fp fleet deploy <machine> --remove <id>` | Xóa một chính sách |
| `fp fleet deploy <machine> --set <ref>...` | Thay thế toàn bộ tập hợp |
| `fp fleet diff [machine]` | So sánh các phiên bản dự định và được áp dụng |
| `fp fleet history <machine>` | Liệt kê các thế hệ triển khai |
| `fp fleet rollback <machine> <generation>` | Khôi phục một thế hệ |
| `fp fleet rename <machine> "<label>"` | Thay đổi nhãn Cloud |

<Warning>
  `--set` thay thế toàn bộ tập chính sách. Một `--add <id>` đơn thuần sẽ thực thi một chính sách mới ngay lập tức. Sử dụng `--add <id>:observe` cho một triển khai shadow.
</Warning>

## Quan sát, rồi thực thi

```bash
fp fleet deploy ci-runner-01 --add prod-guard:observe
fp guardrails summary --since 24h --machine ci-runner-01
fp fleet deploy ci-runner-01 --add prod-guard:enforce
```

Chế độ quan sát đánh giá chính sách thực tế và ghi lại các quyết định không phải allow mà không chặn agent.

## Danh tính máy

ID máy là ổn định và xác định máy. Nhãn chỉ để hiển thị và có thể thay đổi:

```bash
failproofai config --machine-label checkout-runner-03
fp fleet rename <machine-id> "Checkout runner 03"
```

Thay đổi nhãn không kết nối lại hoặc tạo lại khóa cho máy.
