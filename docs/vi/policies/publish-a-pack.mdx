Tạo một policy hoạt động, kiểm tra nó cục bộ, sau đó xuất bản nó dưới dạng một bộ.

## Tạo và kiểm tra

```bash
failproofai publish --init guards.mjs
failproofai policies -i -c ./guards.mjs
```

`--init` tạo một policy đã chặn `git push --force`. Chỉnh sửa nó, yêu cầu agent của bạn thử hành động bị chặn, và kiểm tra **Policies → Activity** trong dashboard cục bộ.

Một policy pack có thể bao gồm:

```js
import { customPolicies, allow, deny } from "failproofai";

customPolicies.add({
  name: "block-refunds",
  description: "Refunds above the limit need a human",
  category: "Billing",
  defaultEnabled: true,
  match: { events: ["PreToolUse"], toolNames: ["Bash"] },
  fn: async (ctx) => {
    // return allow(), instruct(), or deny()
  },
});
```

`defaultEnabled` mặc định là `false`.

## Xuất bản

Commit các tệp của bạn, sau đó chạy:

```bash
failproofai publish
```

Publish tìm tệp policy, xác thực nó bằng cùng một loader được sử dụng trong quá trình cài đặt, và tải các tài sản pack lên GitHub release. Nó sử dụng `GITHUB_TOKEN`, `GH_TOKEN`, hoặc `gh auth login`.

Repository phải là công khai vì cài đặt sử dụng HTTPS ẩn danh.

Phiên bản mặc định là SHA 12 ký tự của commit hiện tại. Publish từ chối một cây bẩn hoặc một thư mục ngoài Git trừ khi bạn cung cấp `--version`. Một tag trên `HEAD` được ưu tiên hơn SHA.

Người dùng cài đặt nó bằng:

```bash
failproofai policies add owner/repo
```

## Xuất bản ở chế độ observe

```bash
failproofai publish --effect observe
```

Chế độ observe đánh giá policy thực tế và ghi lại các quyết định không phải allow, nhưng cho phép agent tiếp tục. Một timeout được ghi lại là allow.

Xuất bản lại bằng `--effect enforce` khi các kết quả quan sát là chính xác.

## Các tùy chọn hữu ích

| Flag | Hiệu ứng |
| --- | --- |
| `--init [file]` | Viết một policy khởi đầu |
| `--repo <owner>/<repo>` | Chọn hoặc tạo repository |
| `--version <version>` | Ghi đè phiên bản dựa trên commit |
| `--effect enforce\|observe` | Chọn xem pack có chặn hay không |
| `--dry-run` | Xây dựng và xác thực mà không xuất bản |
| `--allow-private` | Xuất bản riêng tư, biết rằng `policies add` không thể cài đặt nó |

```bash
failproofai publish --dry-run
failproofai publish ./guards.mjs --repo me/guards --version 2.0.0
```

<Note>
  Thêm chủ đề GitHub `failproofai-policies` sau khi xuất bản để [Policy Hub](https://befailproof.ai/policy-hub/) có thể lập chỉ mục cho bộ. CLI không thiết lập nó cho bạn.
</Note>

<Warning>
  Đổi tên một policy là một thay đổi phá vỡ đối với các lựa chọn hiện có. Giữ tên ổn định trên các bản phát hành.
</Warning>
