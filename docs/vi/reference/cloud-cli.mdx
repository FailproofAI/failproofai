Sử dụng `fp` để kiểm tra telemetry trên Cloud, quản lý enforcement được quản lý bởi cloud (policies, fleet deployments, guardrail decisions), và quản lý audits, findings, issues, alerts, keys, users, queries, và settings. Sử dụng [`failproofai`](/vi/reference/failproof-cli) cho local hooks, policies, capture, và machine enrollment.

Cài đặt Cloud CLI được phát hành như một công cụ độc lập:

```bash
uv tool install fp-cloud-cli
fp version
```

## Đăng nhập

```bash
fp login
fp whoami
```

## Cú pháp

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

Global options phải đứng trước command:

```bash
fp --json sessions --since 24h
```

Chạy `fp COMMAND --help` hoặc `fp COMMAND SUBCOMMAND --help` để xem trợ giúp trên terminal.

### Events

```text
fp events [OPTIONS]
```

Liệt kê các agent events riêng lẻ. Feed light mặc định loại trừ raw payloads; chỉ sử dụng `--full` cho một cuộc điều tra bị giới hạn.

| Option | Mô tả |
| --- | --- |
| `--limit`, `-n <n>` | Tổng số hàng tối đa. Mặc định: `50`. |
| `--since <window>` | `all`, `15m`, `1h`, `6h`, `24h`, hoặc `7d`. |
| `--from <timestamp>` / `--to <timestamp>` | Dải ISO 8601 UTC; ghi đè `--since`. |
| `--env <value>` | Bộ lọc environment; lặp lại hoặc phân tách bằng dấu phẩy. |
| `--event-type <value>` | Bộ lọc event-type; lặp lại hoặc phân tách bằng dấu phẩy. |
| `--agent-id <value>` | Bộ lọc agent; lặp lại hoặc phân tách bằng dấu phẩy. |
| `--session-id <value>` | Bộ lọc session; lặp lại hoặc phân tách bằng dấu phẩy. |
| `--search <text>` | Tìm kiếm text payload; có thể lặp lại, bất kỳ thuật ngữ nào cũng khớp. |
| `--order asc\|desc` | Thứ tự thời gian. Mặc định: mới nhất trước. |
| `--all` | Tự động phân trang lên đến `--limit`. |
| `--cursor <token>` | Tiếp tục từ một cursor opaque. |
| `--page-size <n>` | Hàng trên mỗi yêu cầu với `--all`; tối đa `200`. |
| `--full` | Bao gồm raw payloads thông qua endpoint event nặng hơn. |
| `--fields <csv>` | Chỉ trả về các trường được chọn; yêu cầu `payload` bật chế độ đầy đủ. |

```bash
fp events --session-id <session-id> --order asc --all --limit 10000
fp --json events --full --session-id <session-id> --all --limit 10000
```

<Note>
  `--all` phân trang **lên đến `--limit`**, mặc định là **50** — vì vậy `--all` một mình dừng ở 50 hàng. Khi nó dừng sớm, phản hồi mang `next_cursor` để tiếp tục; `"next_cursor": null` nghĩa là feed thực sự đã cạn kiệt.
</Note>

#### Audit create options

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| Option | Mô tả |
| --- | --- |
| `--file <path>` | Dựa trên định nghĩa JSON, hoặc sử dụng `-` cho stdin. Các cờ rõ ràng ghi đè giá trị file. |
| `--description <text>` | Nêu rõ câu hỏi thất bại hoặc mục đích. |
| `--enabled` / `--disabled` | Bắt đầu lên lịch trên hoặc tắt. Mặc định: enabled. |
| `--schedule-interval-secs <n>` | `3600`–`604800`. Mặc định: `86400`. |
| `--schedule-anchor <timestamp>` | Pha UTC cố định ở dạng ISO 8601. Mặc định: 09:00 UTC tiếp theo. |
| `--window-mode since_last\|fixed` | Tiếp tục sau cửa sổ được phân tích đầy đủ cuối cùng hoặc lặp lại kiểm tra cửa sổ lăn động. Mặc định: `since_last`. |
| `--lookback-window-secs <n>` | `3600`–`7776000`. Mặc định: `604800`. |
| `--scope '<json>'` | Bộ lọc theo `environments`, `agent_ids`, hoặc các trường scope được hỗ trợ khác. |
| `--ignore-error-type <type>` | Loại trừ error types; lặp lại hoặc phân tách bằng dấu phẩy. |
| `--llm` / `--no-llm` | Bật hoặc tắt agentic analysis. Mặc định: enabled. |
| `--top-k <n>` | Giữ lại `1`–`500` findings. Mặc định: `50`. |
| `--sensitivity low\|medium\|high` | Đặt reporting sensitivity. Mặc định: `medium`. |
| `--channels '<json>'` | Mảng notification channel. |
| `--text <brief>` | Brief inline, tối đa 8.192 ký tự. |
| `--text-file <path>` | Đọc brief từ một file; loại trừ lẫn nhau với `--text`. |
| `--url <https-url>` | Thêm một tham chiếu HTTPS công khai; lặp lại lên đến năm lần. |

Bao gồm context trong quá trình tạo khi lần chạy đầu tiên cần nó. Creation commits định nghĩa và context cùng nhau trước khi lần chạy được xếp hàng đợi bắt đầu.

<Note>
  `fp audits run` là không đồng bộ. Poll `fp audits runs NAME` cho đến khi lần chạy mới nhất thành công hoặc thất bại trước khi đọc các findings của nó.
</Note>

Explicit flags ghi đè environment variables, cái nào ghi đè saved configuration. Trong API-key mode, chọn tenant rõ ràng với `--org` hoặc `FP_ORG`.

<Warning>
  Các cách viết `AGENTEYE_*` của những cái này **không được `fp` đọc** và không bao giờ được — CLI khai báo `FP_*` (`fp_cli/app.py`), và một unknown variable không phải là lỗi. Thiết lập `AGENTEYE_DASHBOARD_URL` không chuyển hướng CLI; nó bị bỏ qua và lệnh im lặng chạy so với saved dashboard thay vào đó.

  `AGENTEYE_HOME` và `AGENTEYE_ENVIRONMENT` vẫn tồn tại, nhưng chúng thuộc về **collector và telemetry SDK**, không phải CLI này.
</Warning>

<Warning>
  Các commands mà xóa, thu hồi, chặn, giải quyết, hoặc thay thế configuration nhắc theo mặc định. Sử dụng `--yes` chỉ sau khi xác minh active organization và target.
</Warning>
