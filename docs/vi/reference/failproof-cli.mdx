Cài đặt bằng `npm install -g failproofai`. Chạy `failproofai` mà không có tham số để mở bảng điều khiển cục bộ.

## Lệnh cơ bản

| Lệnh | Chức năng |
| --- | --- |
| `failproofai config` | Thiết lập các agent, dịch vụ nền và kết nối Cloud tùy chọn |
| `failproofai config --token <key>` | Thiết lập và kết nối mà không cần xác nhận |
| `failproofai config --status` | Hiển thị kết nối, phiên bản dịch vụ và trạng thái tạm dừng |
| `failproofai policies` | Liệt kê các chính sách và trạng thái hoạt động của chúng |
| `failproofai policies add <name>` | Bật một chính sách |
| `failproofai policies add <owner>/<repo>` | Cài đặt một gói chính sách |
| `failproofai policies remove <name-or-pack>` | Tắt một chính sách hoặc xóa một gói |
| `failproofai policies show <owner>/<repo>` | Kiểm tra một gói trước khi cài đặt |
| `failproofai publish` | Xuất bản các chính sách của bạn dưới dạng gói |
| `failproofai audit` | Quét lịch sử agent cục bộ |
| `failproofai harness` | Quản lý các vị trí phiên bản bổ sung |
| `failproofai flush` | Gửi các sự kiện đang chờ ngay bây giờ |
| `failproofai backfill` | Đọc lại lịch sử agent cũ hơn |
| `failproofai update` | Hoàn tất nâng cấp npm và cập nhật dịch vụ |
| `failproofai uninstall` | Xóa hook và dịch vụ |

`policy`, `pack` và `p` được chấp nhận làm bí danh cho `policies`, nhưng tài liệu sử dụng `policies`.

## Thiết lập máy

```bash
npm install -g failproofai
failproofai config
failproofai policies add FailproofAI/policies
failproofai config --status
```

Thiết lập không chọn gói chính sách nào. Trước khi thêm một gói, chỉ `block-failproofai-commands` chạy.

Để thiết lập Cloud không giám sát:

```bash
export FAILPROOFAI_CLOUD_TOKEN="<key>"
failproofai config
```

Để gửi quyết định mà không có bản ghi, hãy kết nối trước và đặt `collector.sessions` thành `false` trong `~/.failproofai/config.json`. Cờ thiết lập `--no-transcripts` hiện tại được phân tích cú pháp nhưng không áp dụng cài đặt đó.

Sử dụng `--machine-label <name>` sau khi máy được kết nối để đổi tên. `--connect <url>` là lệnh ghi danh hẹp hơn cho một máy đã được thiết lập.

## Chính sách và gói

```bash
failproofai policies
failproofai policies add block-sudo
failproofai policies show owner/repo
failproofai policies add owner/repo --category git,database
failproofai policies remove owner/repo
```

Bất cứ thứ gì có dấu gạch chéo là nguồn gói; bất cứ thứ gì không có là tên chính sách.

Cờ lựa chọn gói hữu ích:

| Cờ | Sử dụng |
| --- | --- |
| `--policy a,b` | Chọn các chính sách đặt tên |
| `--category x,y` | Chọn danh mục |
| `--all` | Chọn tất cả |
| `--cli <agents...>` | Giới hạn cho các harness được đặt tên |

Sử dụng `failproofai policies -i -c <path>` để tải một chính sách tùy chỉnh từ bất kỳ đường dẫn nào. Các file theo quy ước có tên `*policies.{js,mjs,ts}` dưới `.failproofai/policies/` tải tự động.

## Tạm dừng thực thi

```bash
failproofai config --pause 10m
failproofai config --status
failproofai config --resume
```

Tạm dừng áp dụng cho một phiên cục bộ và luôn hết hạn. Nó không tạm dừng các chính sách do Cloud quản lý hoặc `block-failproofai-commands`.

## Kiểm tra và gửi

```bash
failproofai audit
failproofai audit --schedule 7 --email team@example.com
failproofai audit --status
failproofai flush --wait
failproofai backfill --since 30d --dry-run
```

`backfill` đọc `~/.failproofai/config.json`. Bỏ `--dry-run` để gửi lại lịch sử.

## Các vị trí phiên bản bổ sung

```bash
failproofai harness list
failproofai harness add-path claude work=/srv/team/.claude/projects
failproofai harness remove-path claude work
```

Nhãn ngăn các phiên từ hai nhà được sao chép hợp nhất dưới cùng một ID agent dẫn xuất.

Các harness được hỗ trợ là `claude`, `codex`, `copilot`, `cursor`, `opencode`, `pi`, `hermes`, `openclaw`, `factory`, `devin`, `antigravity` và `goose`. Hỗ trợ phạm vi khác nhau; xem [Harnesses](/vi/reference/harnesses).

## Các biến môi trường hữu ích

| Biến | Sử dụng |
| --- | --- |
| `FAILPROOFAI_CLOUD_TOKEN` | Khóa máy Cloud |
| `FAILPROOFAI_CLOUD_URL` | Ghi đè URL Cloud |
| `FAILPROOFAI_HOME` | Di chuyển thư mục trạng thái cục bộ |
| `FAILPROOFAI_NO_DOWNLOAD=1` | Từ chối tải gói và dịch vụ |
| `FAILPROOFAI_DAEMON_BASE_URL` | Sử dụng nhị phân dịch vụ sao chép |
| `FAILPROOFAI_PACK_BASE_URL` | Sử dụng sao chép gói |
| `FAILPROOFAI_NO_FIRST_RUN=1` | Tắt nhắc lần chạy đầu tiên |
| `FAILPROOFAI_TELEMETRY_DISABLED=1` | Tắt telemetry CLI nặc danh |
| `FAILPROOFAI_<HARNESS>_EXTRA_PATHS` | Thay thế các đường dẫn bổ sung cho một harness |
| `NO_COLOR` | Tắt màu terminal |

## Xóa hoặc nâng cấp

```bash
npm install -g failproofai@latest
failproofai update
```

Trước khi xóa gói:

```bash
failproofai uninstall --dry-run
failproofai uninstall --yes
npm rm -g failproofai
```

<Warning>
  Chạy `failproofai uninstall` trước khi xóa gói npm. npm không xóa các hook đã cài đặt hoặc dịch vụ nền.
</Warning>

Chạy `failproofai help <command>` để xem các tùy chọn hoàn chỉnh trong phiên bản đã cài đặt của bạn.
