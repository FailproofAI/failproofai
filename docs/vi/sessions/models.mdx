Sử dụng Models để xem liệu độ tin cậy hoặc chi phí có thay đổi theo mô hình, agent, môi trường hoặc khoảng thời gian.

<Tabs>
  <Tab title="Dashboard">
    1. Đi tới **Observe → Models**.
    2. Đặt khoảng thời gian, sau đó lọc theo môi trường, mô hình, agent hoặc ID phiên.
    3. Xem xét độ trễ, tiêu thụ token, sử dụng cửa sổ ngữ cảnh và phân phối mô hình.
    4. Chọn một điểm biểu đồ hoặc phân đoạn phân phối để mở các sự kiện phù hợp.

    ![Trang Models hiển thị các chế độ xem độ trễ, phân vị, token, chi phí, cửa sổ ngữ cảnh và phân phối mô hình.](/images/dashboard/models.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list models
    fp events --event-type model_request,model_response --env production --since 24h
    fp --json events --fields ts,agent_id,session_id,event_type,output_tokens,context_fill
    ```

    Sử dụng một truy vấn đã lưu để tổng hợp ở cấp mô hình mà không được hiển thị dưới dạng lệnh CLI riêng biệt.
  </Tab>
</Tabs>
