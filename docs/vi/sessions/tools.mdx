icon: "wrench"

Tools nhóm các lệnh gọi công cụ trong các phiên làm việc để bạn có thể so sánh độ trễ và phân bố lệnh gọi.

<Tabs>
  <Tab title="Dashboard">
    1. Đi tới **Observe → Tools**.
    2. Lọc theo môi trường, tên công cụ, agent hoặc ID phiên làm việc.
    3. Xem xét độ trễ và phân bố công cụ.
    4. Chọn một điểm trên biểu đồ hoặc phân đoạn công cụ để mở các sự kiện và phiên làm việc phù hợp.

    ![Trang Tools hiển thị độ trễ, phân tích về thành công và thất bại, cũng như phân bố lệnh gọi công cụ.](/images/dashboard/tools.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list tools
    fp events --event-type tool_use,tool_result --env production --since 24h
    fp --json events --full --session-id <session-id> --all
    ```
  </Tab>
</Tabs>
