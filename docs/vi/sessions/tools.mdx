Tools nhóm các lệnh gọi tool trên các phiên làm việc để bạn có thể so sánh độ trễ và phân bố lệnh gọi.

<Tabs>
  <Tab title="Dashboard">
    1. Đi tới **Observe → Tools**.
    2. Lọc theo môi trường, tên tool, agent hoặc ID phiên làm việc.
    3. Xem xét độ trễ và phân bố tool.
    4. Chọn một điểm biểu đồ hoặc phân đoạn tool để mở các sự kiện và phiên làm việc phù hợp.

    ![Trang Tools hiển thị độ trễ, phân tích thành công và thất bại, cũng như phân bố lệnh gọi tool.](/images/dashboard/tools.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list tools
    fp events --event-type tool_use,tool_result --env production --since 24h
    fp --json events --full --session-id <session-id> --all
    ```
  </Tab>
</Tabs>
