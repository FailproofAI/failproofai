Công cụ hiển thị những gì các agent gọi, tần suất các lệnh gọi thất bại và các phiên nào bị ảnh hưởng.

Tên công cụ xuất phát từ mỗi agent harness, vì vậy cùng một khả năng có thể có các tên khác nhau. Ví dụ: một lệnh shell có thể xuất hiện dưới dạng `Bash`, `exec`, `Shell`, `terminal`, hoặc `run_command`. Chạy `fp list tools` trước khi xây dựng một bộ lọc.

<Tabs>
  <Tab title="Dashboard">
    Đi tới **Observe → Tools**. Lọc theo môi trường, công cụ, agent hoặc phiên.

    ![Trang Tools hiển thị độ trễ, độ trễ, phân tích thành công và thất bại, cũng như phân phối lệnh gọi công cụ.](/images/dashboard/tools.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list tools
    fp events --event-type tool_use,tool_result --since 24h
    fp errors --event-type tool_result --since 24h
    fp --json events --full --event-type tool_use,tool_result --session-id <session-id> --all --limit 2000
    ```

    Sử dụng `--full` khi bạn cần các trường payload như thời gian trên mỗi lệnh gọi.
  </Tab>
</Tabs>

Sử dụng trang này để tìm các lỗi lặp lại, so sánh các lần chạy hoạt động và không hoạt động, hoặc xác nhận rằng một công cụ được nhắm mục tiêu theo chính sách thực sự được sử dụng.
