Agent của bạn đã tạo ra mọi thứ đáng ghi lại — các lệnh gọi mô hình, các lệnh gọi công cụ, biên giới nút, chờ đợi con người, lỗi. Framework sẽ loại bỏ nó. SDK giữ lại nó.

## Trước khi bạn bắt đầu

Hai điều mà hướng dẫn này giả định, và mã dưới đây không thực hiện cho bạn:

| Yêu cầu | Lý do |
| --- | --- |
| Python 3.10 trở lên | Mức tối thiểu mà SDK khai báo. |
| Một máy được thiết lập với `failproofai config` | Lệnh đó cài đặt daemon failproofaid, và daemon là điều duy nhất vận chuyển những gì SDK ghi. Nếu không có nó, các batch sẽ tích tụ trong thư mục spool và không bao giờ rời đi. |

<Note>
  **Đường dẫn này ghi lại; nó không thực thi.** SDK ghi lại những gì agent của bạn đã làm. Policies kích hoạt từ một hook bên trong agent CLI, vì vậy thực thi trên framework agent có nghĩa là đặt một hook trong runtime của riêng bạn — xem [Policies](/vi/policies/overview).
</Note>

## Ba dòng, bất kỳ framework nào

<CodeGroup>
```bash LangGraph
pip install 'failproofai-sdk[langgraph]'
```

```bash CrewAI
pip install 'failproofai-sdk[crewai]'
```

```bash LlamaIndex
pip install 'failproofai-sdk[llamaindex]'
```

```bash Pydantic AI
pip install 'failproofai-sdk[pydantic-ai]'
```

```bash Custom agents
pip install failproofai-sdk
```
</CodeGroup>

```python
import failproofai_sdk

failproofai_sdk.configure(environment="production")
failproofai_sdk.instrument()          # detects the frameworks you imported

with failproofai_sdk.session():
    ...                               # your existing agent call, unchanged
```

Không có decorator trên các hàm của bạn, không có callback được truyền vào các lệnh gọi của bạn, không có id được luồng qua mã của bạn. Chỉ lệnh gọi bên trong session khác:

<Tabs>
  <Tab title="LangGraph">
    ```python
    graph.invoke({"messages": [HumanMessage("...")]})
    ```
  </Tab>
  <Tab title="CrewAI">
    ```python
    Crew(agents=[analyst, writer], tasks=[gather, summarise]).kickoff()
    ```
  </Tab>
  <Tab title="LlamaIndex">
    ```python
    await agent.run("...")        # under `async with failproofai_sdk.session():`
    ```
  </Tab>
  <Tab title="Pydantic AI">
    ```python
    agent.run_sync("...")
    ```
  </Tab>
  <Tab title="Custom agents">
    ```python
    with failproofai_sdk.agent("planner"):
        with failproofai_sdk.tool_call("search", input={"q": q}) as t:
            t.output = search(q)
    ```
  </Tab>
</Tabs>

Cài đặt thêm là **framework**. Mọi adapter được vận chuyển trong base wheel, vì vậy một dự án đã có framework của nó không cần bất cứ thứ gì thêm nào cả.

## Kiểm tra nó đã tới

Chạy một session được trang bị một lần, sau đó mở **Observe → Sessions** và chọn môi trường của bạn. Lần chạy xuất hiện dưới dạng một trace được tái tạo.

Nếu không có gì tới, hãy xác nhận rằng máy được thiết lập và kết nối với `failproofai config --status`. Nếu không phải, hãy chạy `failproofai config`. Xem [Choose your setup](/vi/start/setup).

<Warning>
  Không kiểm tra thư mục spool để xác nhận việc gửi. Daemon Failproof thu thập và xóa mỗi batch trong vòng vài millisecond, vì vậy đọc nó sẽ cạnh tranh với bộ sưu tập và hiển thị ít hơn nhiều sự kiện so với những gì được phát ra.
</Warning>

Để chứng minh SDK đang ghi dữ liệu, hãy dừng daemon trước, sau đó chạy session của bạn và nhìn vào `~/.failproofai/custom-agents/events/`. Với daemon chạy, thư mục trống là trạng thái lành mạnh.

<CodeGroup>
```bash Linux
sudo systemctl stop failproofaid@$USER
```

```bash macOS
sudo launchctl bootout system/ai.failproof.failproofaid.$USER
```
</CodeGroup>

Chạy `failproofai config` sau đó để đặt nó trở lại. Khi daemon bị dừng, các sự kiện hook trên máy này không có evaluator và bị từ chối, vì vậy hãy dừng nó chỉ trong thời gian kiểm tra.
