Agent của bạn đã tạo ra mọi thứ đáng ghi lại — các lệnh gọi mô hình, lệnh gọi công cụ, ranh giới nút, chờ đợi con người, lỗi. Framework loại bỏ nó. SDK giữ lại nó.

## Ba dòng, bất kỳ framework nào

<CodeGroup>
```bash LangGraph
pip install 'failproofai-sdk[langgraph]'
```

```bash CrewAI
pip install 'failproofai-sdk[crewai]'
```

```bash LlamaIndex
pip install 'failproofai-sdk[llamaindex]'
```

```bash Pydantic AI
pip install 'failproofai-sdk[pydantic-ai]'
```

```bash Custom agents
pip install failproofai-sdk
```
</CodeGroup>

```python
import failproofai_sdk

failproofai_sdk.configure(environment="production")
failproofai_sdk.instrument()          # phát hiện các framework bạn đã nhập

with failproofai_sdk.session():
    ...                               # lệnh gọi agent hiện tại của bạn, không thay đổi
```

Không có decorator trên các hàm của bạn, không có callback được truyền vào các lệnh gọi của bạn, không có id được luồng qua mã của bạn. Chỉ lệnh gọi bên trong session khác:

<Tabs>
  <Tab title="LangGraph">
    ```python
    graph.invoke({"messages": [HumanMessage("...")]})
    ```
  </Tab>
  <Tab title="CrewAI">
    ```python
    Crew(agents=[analyst, writer], tasks=[gather, summarise]).kickoff()
    ```
  </Tab>
  <Tab title="LlamaIndex">
    ```python
    await agent.run("...")        # dưới `async with failproofai_sdk.session():`
    ```
  </Tab>
  <Tab title="Pydantic AI">
    ```python
    agent.run_sync("...")
    ```
  </Tab>
  <Tab title="Custom agents">
    ```python
    with failproofai_sdk.agent("planner"):
        with failproofai_sdk.tool_call("search", input={"q": q}) as t:
            t.output = search(q)
    ```
  </Tab>
</Tabs>

Bước cài đặt bổ sung là **framework**. Mọi adapter được gửi trong wheel cơ sở, vì vậy một dự án đã có framework của nó không cần bất cứ điều gì thêm nào cả.

## Kiểm tra nó đã tới

Chạy một session được thiết bị một lần, sau đó mở **Observe → Sessions** và chọn môi trường của bạn. Lần chạy xuất hiện dưới dạng một dấu vết được tái tạo.

Nếu không có gì tới, hãy xác nhận máy được kết nối bằng `failproofai config --status`. Xem [Thiết lập capture](/vi/start/setup).

<Warning>
  Không kiểm tra thư mục spool để xác nhận gửi hàng. Daemon Failproof thu thập và xóa mỗi batch trong vòng mili giây, vì vậy đọc nó sẽ phải ganh đua với bộ sưu tập và hiển thị ít sự kiện hơn nhiều so với những gì đã được phát ra.
</Warning>

## Tiếp theo

Mỗi hướng dẫn bắt đầu nhanh ở trên liên kết đến hướng dẫn đầy đủ của nó — những gì được ghi lại, các tùy chọn, truyền phát, đặt tên span và những vấn đề mà mọi người thực sự gặp. Chúng nằm dưới **Trace Agents → Plug in your agent**.
