Thiết lập Failproof AI trên một máy, sau đó ở local hoặc kết nối Cloud.

Nếu agent của bạn chạy trong một [harness được hỗ trợ](/vi/reference/harnesses), hãy làm theo các bước sau. Đối với agent được xây dựng bằng LangChain, CrewAI, LlamaIndex, Pydantic AI, hoặc runtime của riêng bạn, hãy bắt đầu với [cấu hình agent của bạn](/vi/start/integrations).

## Để agent hướng dẫn bạn trong quá trình thiết lập

Cài đặt kỹ năng ô dù Failproof AI vào một agent tương thích:

```bash
npx skills add FailproofAI/skills
```

Điều này cài đặt kỹ năng ô dù và các kỹ năng chuyên biệt của nó. Sử dụng `--skill
failproofai` nếu bạn chỉ muốn kỹ năng ô dù. Nó hiểu thiết lập local và Cloud,
tình trạng daemon, phiên, kiểm tra, chính sách và khắc phục sự cố. Nó hướng dẫn công việc
và định tuyến các tác vụ chuyên biệt đến kỹ năng Failproof AI phù hợp; nó không thay thế
cài đặt CLI dưới đây.

## Thiết lập máy

<Steps>
  <Step title="Cài đặt và cấu hình Failproof AI">
    ```bash
    npm install -g failproofai
    failproofai config
    ```

    Thiết lập cài đặt dịch vụ nền và kết nối mọi agent được hỗ trợ mà nó tìm thấy. Nó có thể yêu cầu quyền truy cập quản trị viên một lần. Nó hỗ trợ Linux và macOS.
  </Step>

  <Step title="Chọn chính sách">
    Thiết lập không chọn gói chính sách nào. Thêm gói Failproof AI:

    ```bash
    failproofai policies add FailproofAI/policies
    failproofai policies
    ```

    Lệnh thứ hai hiển thị mọi chính sách trên máy này và cho biết nó có bật hay không. Cho đến khi bạn thêm một gói, chỉ có `block-failproofai-commands` chạy.
  </Step>

  <Step title="Kiểm tra máy">
    ```bash
    failproofai config --status
    ```

    Điều này báo cáo dịch vụ, kết nối Cloud và trạng thái tạm dừng.
  </Step>
</Steps>

## Chọn local hoặc Cloud

<Tabs>
  <Tab title="Ở local">
    Không cần tài khoản.

    ```bash
    failproofai
    failproofai audit
    ```

    Lệnh đầu tiên mở bảng điều khiển local tại `http://localhost:8020`. Lệnh thứ hai quét lịch sử agent đã có trên máy này.
  </Tab>

  <Tab title="Kết nối Cloud">
    Tạo khóa máy trong Failproof AI Cloud, sau đó chạy:

    ```bash
    failproofai config --token <machine-key>
    failproofai config --status
    ```

    Cloud nhận các quyết định chính sách và bản ghi phiên. Để chỉ gửi quyết định, hãy kết nối trước, sau đó đặt `collector.sessions` thành `false` trong `~/.failproofai/config.json`; cờ thiết lập `--no-transcripts` hiện tại không áp dụng cài đặt đó. Đối với shell được chia sẻ và CI, hãy sử dụng `FAILPROOFAI_CLOUD_TOKEN` thay vì đặt khóa trong lịch sử lệnh.
  </Tab>
</Tabs>

## Xác minh nó

Chạy một trong các agent của bạn và yêu cầu nó thực hiện một tác vụ bình thường. Sau đó:

Một từ chối gọi công cụ được xác minh trên tất cả 12 harness được hỗ trợ. Thực thi cuối lượt
được xác minh trên 8; các cặp harness-sự kiện khác có thể chỉ quan sát hoặc chưa được xác minh.

- Mở **Policies → Activity** trong bảng điều khiển local để xem các quyết định chính sách.
- Mở **Observe → Sessions** trong Cloud để xem lần chạy hoàn chỉnh.
- Chạy `failproofai audit` để tìm kiếm các mẫu rủi ro hoặc lãng phí.

<Warning>
  Sau khi thiết lập, dịch vụ `failproofaid` là bộ đánh giá. Nếu nó không thể trả lời, các hành động được bảo vệ sẽ bị từ chối. Chạy `failproofai config --status` khi một agent dừng bất ngờ.
</Warning>
