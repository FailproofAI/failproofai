---
title: "管理"
description: "管理访问权限、使用情况、组织和安全性，而不会将其混入可靠性工作流。"
icon: "settings-2"
---

管理部分包含在团队中运行 Failproof AI 所需的各项控制功能。大多数用户只需关注会话、审计和策略；管理员使用本部分来管理访问权限和操作边界。

<Tabs>
  <Tab title="控制台">
    使用云端侧边栏的 **Admin** 部分，可访问**策略编辑器**、**执行**、**用量**、**密钥**、**用户**和**设置**。带锁图标的项目表示您的账户缺少相应的读取权限。

    ![云端侧边栏的 Admin 部分，包含策略编辑器、执行、用量、密钥、用户和设置。](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    全局选项应放在命令之前，例如 `fp --org reliability-team --json usage`。
  </Tab>
</Tabs>
