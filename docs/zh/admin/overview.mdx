管理模块包含在团队中运行 Failproof AI 所需的各项控制功能。大多数用户可以留在会话、审计和策略页面；管理员使用本模块来管理访问权限和操作边界。

<Tabs>
  <Tab title="仪表板">
    使用云端侧边栏的 **Admin** 区域访问**策略编辑器**、**执行**、**使用情况**、**密钥**、**用户**和**设置**。若某项显示为锁定状态，表示您的账户缺少相应的读取权限。

    ![云端侧边栏的 Admin 区域，包含策略编辑器、执行、使用情况、密钥、用户和设置。](/images/dashboard/admin-navigation.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp whoami
    fp orgs current
    fp orgs perms
    fp usage
    ```

    全局选项需放在命令之前，例如 `fp --org reliability-team --json usage`。
  </Tab>
</Tabs>
