Failproof AI Cloud 会向维护团队发送**关于软件本身**的使用遥测数据，其中绝不包含您的智能体数据。在自托管安装中，遥测默认开启，您可以将其关闭。

## 收集的内容

每个事件携带五个维度，不包含任何个人识别信息：

| 维度 | 示例 | 含义 |
| --- | --- | --- |
| `product` | `agenteye` | 发送事件的产品 |
| `component` | `dashboard`, `server`, `cli` | 发送事件的产品组件 |
| `app_version` | `0.0.1-beta.81` | 您正在运行的构建版本 |
| `deployment_kind` | `self_hosted` | 标识这是客户安装、演示环境、QA 环境还是开发机器 |
| `org_id` | 一个 UUID | 操作发生所在的组织，以不透明标识符表示 |

在此基础上，事件还会记录**使用了什么，而非其中的内容**：查看了哪个页面（以路由模式表示，例如 `/:org/sessions/:id`，而非真实 URL）、应用了多少个何种类型的筛选条件、操作是否成功，以及耗时多长。

Slack 应用会记录工作区的连接与断开、账户关联、提问、图表发布、审批决策及按固定类别划分的失败情况，但绝不包含 Slack 工作区 ID、用户 ID、频道 ID、电子邮件、问题内容、答案、SQL 或令牌。

### 您的组织名称

除不透明的 `org_id` 外，我们会将您的组织名称、URL slug 和控制台地址记录一次，存储在组织记录中而非每个事件上。这样当我们分析使用趋势或排查您反馈的问题时，可以识别出某个模式属于哪个账户。这是产品发送的唯一一条关于您的可识别信息。

### 您的使用量统计

服务端会上报每个组织的计量使用量总计，与您在使用量页面看到的数字相同。这些均为纯计数数据：事件数、会话数、智能体数、环境数、评估运行次数、评分数、审计运行次数、已保存查询数、控制台数、告警数、问题数、API 密钥数和成员数，以及计量周期的日期范围。这些数据不包含任何标识符、名称或查询文本，且无论是否有人登录均会上报。

## 永不收集的内容

- **不收集提示词、模型响应或事件内容**，无论是原文、前缀还是哈希值
- **不收集会话、智能体或追踪标识符**
- **不收集评估器评分名称**
- **不收集错误消息、异常文本或响应正文**，仅收集状态码和来自固定列表的类别
- **不收集工具参数、SQL 或查询文本**
- **不收集已连接应用的详细信息**。连接或撤销 MCP 客户端时最多发送权限数量，不包含应用名称或任何令牌
- **不收集电子邮件地址**
- **不收集来源 URL 或查询字符串**
- **不进行屏幕录制、DOM 捕获或点击与光标追踪**

## 在自托管安装中关闭遥测

在控制台和服务端均设置 `DO_NOT_TRACK=1`。两者独立判断，因此仅在其中一个上设置会导致另一个继续上报。请重启服务端使更改生效。

您的版本 README 中描述了其他退出选项及确认遥测已关闭的方法。

## 退出时的一次性 ping

如果您通过产品设置而非 `DO_NOT_TRACK` 来退出遥测，控制台可能会发送**一次匿名 ping** 来记录此操作，概率为每次进程启动时千分之一。这用于统计有多少运营者关闭了遥测。该 ping 不包含任何标识符：无组织、用户、主机名、URL 或 IP，仅包含产品、组件、版本、部署类型和原因。已退出的服务端不会发送任何内容。

使用 `DO_NOT_TRACK` 时永远不会发送此 ping，因此如果您的策略禁止任何出站遥测，请使用该设置。

## 数据发往何处

通过 TLS 在 443 端口发送至 PostHog（`us.i.posthog.com`）。只有一个主机名，因此您也可以通过单条出站规则将其屏蔽。

有关我们如何更广泛地处理个人信息，请参阅[隐私政策](https://befailproof.ai/privacy/)。
