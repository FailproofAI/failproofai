Failproof AI Cloud 会向其维护者发送**关于软件自身**的使用遥测数据，其中绝不包含您的 Agent 数据。在自托管安装中，遥测默认开启，您可以将其关闭。

## 收集的内容

每个事件携带五个维度，不包含任何能够识别个人身份的信息：

| 维度 | 示例 | 含义 |
| --- | --- | --- |
| `product` | `agenteye` | 发送事件的产品 |
| `component` | `dashboard`、`server`、`cli` | 发送事件的产品组件 |
| `app_version` | `0.0.1-beta.81` | 您正在运行的版本 |
| `deployment_kind` | `self_hosted` | 标识这是客户安装、演示环境、QA 环境还是开发机器 |
| `org_id` | 一个 UUID | 操作发生所在的组织，以不透明标识符表示 |

在此基础上，事件记录**使用了什么，而非其中的内容**：浏览了哪个页面（以路由模式表示，例如 `/:org/sessions/:id`，而非真实 URL）、应用了多少个哪种类型的筛选器、操作是否成功，以及耗时多久。

Slack 应用记录工作区连接与断开、账户关联、提问、图表发布、审批决策及按固定类别划分的失败情况，绝不包含 Slack 工作区 ID、用户 ID、频道 ID、邮箱地址、问题内容、回答内容、SQL 语句或令牌。

### 您的组织名称

除不透明的 `org_id` 外，我们会记录您组织的名称、URL slug 和仪表板地址一次，存储在组织记录中而非每个事件上。这使我们在分析使用情况或调查您反馈的问题时，能够判断某个模式属于哪个账户。这是产品发送的唯一一条关于您的可识别信息。

### 您的用量统计

服务器会上报每个组织的计量用量统计，即您在用量页面上看到的相同数字。这些仅为计数：事件、会话、Agent、环境、评估运行、评分、审计运行、已保存查询、仪表板、告警、问题、API 密钥和成员，以及计量周期的起止日期。这些数据不含任何标识符、名称或查询文本，且无论是否有用户登录都会上报。

## 从不收集的内容

- **不收集提示词、模型响应或事件内容**，包括文本、前缀或哈希值
- **不收集会话、Agent 或追踪标识符**
- **不收集评估器评分名称**
- **不收集错误消息、异常文本或响应体**，仅收集状态码和来自固定列表的分类
- **不收集工具参数、SQL 或查询文本**
- **不收集已连接应用的详情**，连接或撤销 MCP 客户端时最多发送权限数量，不发送应用名称或任何令牌
- **不收集电子邮件地址**
- **不收集引用 URL 或查询字符串**
- **不进行屏幕录制、DOM 捕获或点击与光标追踪**

## 在自托管安装中关闭遥测

在仪表板和服务器上均设置 `DO_NOT_TRACK=1`。两者各自独立判断，因此仅在其中一个上设置会导致另一个仍在上报。重启服务器以使更改生效。

您的版本 README 中介绍了其他退出设置以及如何确认遥测已关闭。

## 退出时的一次 Ping

如果您通过产品设置而非 `DO_NOT_TRACK` 退出遥测，仪表板可能会发送**一次匿名 Ping** 来记录此操作，每次进程启动触发概率为千分之一。这用于统计有多少运营者关闭了遥测。该 Ping 不含任何标识符：没有组织、用户、主机名、URL 或 IP，仅包含产品名称、组件、版本、部署类型和原因。已退出的服务器不发送任何内容。

使用 `DO_NOT_TRACK` 时永远不会发送此 Ping，这就是为什么当您的策略禁止任何出站遥测时，应使用该设置。

## 数据发送至何处

通过 TLS 在 443 端口发送至 PostHog（`us.i.posthog.com`）。这是唯一一个主机名，因此您也可以通过单条出口规则将其屏蔽。

有关我们如何更全面地处理个人信息，请参阅[隐私政策](https://befailproof.ai/privacy/)。
