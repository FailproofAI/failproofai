Failproof AI Cloud 向维护者发送**关于软件本身**的使用遥测数据，不包含任何 Agent 数据。在自托管部署中，遥测默认开启，您可以将其关闭。

## 收集的内容

每个事件包含五个维度，不含任何可识别个人身份的信息：

| 维度 | 示例 | 说明 |
| --- | --- | --- |
| `product` | `agenteye` | 发送事件的产品 |
| `component` | `dashboard`, `server`, `cli` | 发送事件的产品组件 |
| `app_version` | `0.0.1-beta.81` | 您正在运行的版本 |
| `deployment_kind` | `self_hosted` | 该部署是客户安装、演示环境、QA 环境还是开发机器 |
| `org_id` | 一个 UUID | 操作发生所在的组织，以不透明标识符形式记录 |

在此基础上，事件还记录**使用了什么，而非其中包含什么**：查看了哪个页面（以路由模式表示，例如 `/:org/sessions/:id`，而非真实 URL）、应用了多少种类型的筛选条件、操作是否成功，以及耗时。

Slack 应用记录工作区的连接与断开、账户关联、提问、图表发布、审批决策及按固定分类的失败信息。不包含 Slack 工作区、用户或频道 ID、电子邮件、问题内容、答案、SQL 或令牌。

### 您的组织名称

除了不透明的 `org_id`，我们会记录您的组织名称、URL slug 和仪表盘地址一次，保存在组织记录中，而不是附加在每个事件上。这样当我们分析功能采用情况或排查您反馈的问题时，可以识别某个模式属于哪个账户。这是产品发送的唯一一条关于您的可识别信息。

### 您的使用量统计

服务器会上报每个组织的计量使用量总计，与您在使用量页面看到的数字相同。这些仅为计数：事件、会话、Agent、环境、评估运行、评分、审计运行、已保存查询、仪表盘、告警、问题、API 密钥和成员数量，以及计量周期的起止日期。不包含任何标识符、名称或查询文本，无论是否有用户登录，这些数据都会上报。

## 从不收集的内容

- **不收集提示词、模型响应或事件内容**，无论是明文、前缀还是哈希形式
- **不收集会话、Agent 或追踪标识符**
- **不收集评估器评分名称**
- **不收集错误消息、异常文本或响应正文**，仅记录状态码及固定分类中的类别
- **不收集工具参数、SQL 或查询文本**
- **不收集已连接应用的详情**——连接或撤销 MCP 客户端时，最多发送权限数量，不包含应用名称或任何令牌
- **不收集电子邮件地址**
- **不收集来源 URL 或查询字符串**
- **不进行屏幕录制、DOM 捕获或点击/光标追踪**

## 在自托管部署中关闭遥测

在仪表盘和服务器上同时设置 `DO_NOT_TRACK=1`。两者各自独立决策，仅在一方设置时，另一方仍会上报数据。修改后需重启服务器使其生效。

您的版本 README 中说明了其他退出设置及如何确认遥测已关闭。

## 退出时的一次性 ping

如果您通过产品设置（而非 `DO_NOT_TRACK`）选择退出，仪表盘可能会发送**一次匿名 ping** 记录该操作，触发概率为每次进程启动 1/1000。这帮助我们了解有多少运营者关闭了遥测。该 ping 不包含任何标识符：无组织、用户、主机名、URL 或 IP，仅包含产品、组件、版本、部署类型和原因。已退出的服务器不发送任何内容。

使用 `DO_NOT_TRACK` 时永远不会触发此 ping，因此如果您的策略禁止任何出站遥测，请使用该设置。

## 数据发送目标

通过 TLS 443 端口发送至 PostHog（`us.i.posthog.com`）。仅涉及一个主机名，因此您也可以通过单条出站规则将其屏蔽。

有关我们如何更广泛地处理个人信息，请参阅[隐私政策](https://befailproof.ai/privacy/)。
