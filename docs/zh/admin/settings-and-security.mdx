组织设置对该 Cloud 组织中的所有成员生效。可通过 **Admin → settings** 或 `fp settings` 命令进行修改。

```bash
fp settings list
fp settings set <key> <value>
```

## 数据处理

已连接的机器默认会发送策略决策和完整的会话记录。若只需发送决策数据，请在连接后将机器 `~/.failproofai/config.json` 中的 `collector.sessions` 设为 `false`。当前的 `--no-transcripts` 安装标志不会应用该设置。

凭据在上传前会在机器端进行脱敏处理，但脱敏只是安全底线，不能替代访问控制。

纯本地使用无需账号。会话历史和审计记录保存在本地机器上；但启用定时本地审计后，系统会发送机器身份标识和有限摘要信息。可通过设置 `FAILPROOFAI_TELEMETRY_DISABLED=1` 来禁用匿名 CLI 遥测。

## 凭据

机器令牌存储在 `~/.failproofai/` 目录下，并设置为仅所有者可读写权限，不会写入服务定义文件中。

请为人员、自动化流程和机器分别使用独立密钥。每个密钥只授予其所需的最小权限，在所有权变更时进行轮换，在机器或工作流退役时及时撤销。

## 检查清单

- 仅授予必要的最小权限。
- 在不需要完整内容的场景下，将 `collector.sessions` 设为 `false`。
- 审查哪些人员有权部署强制执行策略。
- 在正式执行前，先在观察模式下测试策略。
- 保持机器标签清晰，机器 ID 稳定。
- 修改连接设置后，执行 `failproofai config --status` 进行验证。

权限目录请参阅[密钥与权限](/zh/admin/keys-and-permissions)。
