用量页面展示当前组织的使用情况及其计费周期。通过该页面，您可以了解生产环境推出、会话记录量、评估和审计频率对套餐的影响。

## 查看用量

<Tabs>
  <Tab title="控制台">
    1. 前往 **Administration → Usage**。
    2. 确认组织和计量周期。
    3. 查看数据摄入量、会话数、评估数、指标、审计数、发现项、告警、用户及密钥。
    4. 当审计用量出现异常时，对比已启动和已完成的审计工作量。

    ![用量页面，展示计量周期、捕获的事件、评估和审计流水线、工作区资源、成员及 API 密钥。](/images/dashboard/usage-overview.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp usage
    fp --json usage
    fp --org reliability-team --json usage
    ```
  </Tab>
</Tabs>

## 排查用量变化

1. 确认当前生效的组织和计费周期。
2. 按环境对比会话量的增长情况。
3. 检查是否有新的集成开始发送会话记录。
4. 查看评估器和审计频率的变更记录。
5. 与当前定价套餐的配额限制进行对比。

CLI 同样会为脚本返回相同的汇总信息。
