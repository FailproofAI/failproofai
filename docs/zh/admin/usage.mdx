使用量页面展示当前组织及其计费周期的消耗情况。通过它可以了解生产环境的推广规模、转录记录量、评估次数以及审计频率对套餐的影响。

## 查看使用量

<Tabs>
  <Tab title="控制台">
    1. 进入 **Administration → Usage**。
    2. 确认组织和计量周期。
    3. 查看摄取量、会话数、评估次数、指标、审计、发现项、告警、用户数及密钥数。
    4. 当审计使用量出现异常时，比较已启动和已完成的审计工作量。

    ![使用量页面，展示计量周期、已捕获事件、评估与审计流水线、工作区资源、成员及 API 密钥。](/images/dashboard/usage-overview.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp usage
    fp --json usage
    fp --org reliability-team --json usage
    ```
  </Tab>
</Tabs>

## 排查使用量变化

1. 确认当前活跃的组织和计费周期。
2. 按环境对比会话量的增长情况。
3. 检查是否有新集成开始发送转录记录。
4. 查看评估器和审计频率是否发生变更。
5. 与当前定价套餐的限制进行对比。

CLI 会返回相同的汇总信息，便于在脚本中使用。
