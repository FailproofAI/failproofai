使用情况页面展示当前组织及其计费周期的资源消耗。通过它，您可以了解生产发布、转录量、评估及审计频率对套餐的影响。

## 查看使用情况

<Tabs>
  <Tab title="控制台">
    1. 前往 **管理 → 使用情况**。
    2. 确认组织及计量周期。
    3. 查看摄入量、会话数、评估数、指标、审计、发现项、告警、用户及密钥。
    4. 当审计用量出现异常时，对比已启动和已完成的审计工作量。

    ![使用情况页面，展示计量周期、捕获事件、评估与审计流水线、工作区资源、成员及 API 密钥。](/images/dashboard/usage-overview.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp usage
    fp --json usage
    fp --org reliability-team --json usage
    ```
  </Tab>
</Tabs>

## 排查用量变化

1. 确认当前活跃的组织和计费周期。
2. 按环境比较会话量的增长情况。
3. 检查是否有新集成开始发送转录数据。
4. 查看评估器和审计频率的变更情况。
5. 与当前定价套餐的限额进行对比。

CLI 也会为脚本返回相同的摘要信息。
