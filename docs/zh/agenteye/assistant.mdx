用自然语言向智能体数据提问，获取直接链接到证据的答案。无需编写 SQL，无需翻查仪表板——**Failproof AI Observability** 助手是团队成员获取智能体相关信息最快捷的方式。

![Failproof AI Observability 助手在仪表板中回答自然语言问题的界面，展示了实时智能体活动表、各智能体模型使用情况分类，以及书面摘要，并内联显示了所执行的查询](/agenteye/images/assistant.png)
*用自然语言提问，基于您自己的数据获得答案。此处它分析了哪些智能体最繁忙、它们使用了哪些模型，并展示了所执行的查询，便于您核实每一个数字。*

无需学习任何新技能。打开聊天窗口，输入您想了解的内容，点击返回的链接即可：

```
You:  which sessions errored today?
AI:   5 sessions errored today, newest first. Each one is linked:
      • checkout-agent   14:02   tool timeout
      • billing-agent    11:47   unhandled error
      • ...and 3 more

You:  summarize this session          (asked while viewing a run)
AI:   This run took 12 steps across 3 tools and failed near the end when a
      payment tool returned an error. It scored low on your "resolved" eval.
      Links: the session, the failing event, and that evaluation.
```

## 直接提问，即刻跳转到证据

无需猜测，无需编写查询。提问"本周生产环境的质量趋势如何？"、"今天哪些会话出现了错误？"或"总结这个会话"，几秒内即可获得直接答案，省去构建查询和自行解读的步骤。

每个答案都附有来源依据。助手会链接到它用于得出答案的确切会话、已保存查询和仪表板，您可以点击查看并自行确认，而不必盲目相信其结论。助手还具备**页面感知能力**：当您正在查看某个会话时提问"这个会话"，它已经知道您指的是哪次运行。随时可从历史切换器中重新打开之前的对话，继续上次的探索。

## 将好答案转化为已保存的查询或仪表板

当某个答案值得保留时，可以让助手将其保存。它会起草已保存查询的 SQL，或根据这些查询组装仪表板，然后向您展示**批准 / 拒绝**卡片。在您点击"批准"之前，不会写入任何内容，因此您既能享受"直接提问"的速度，又始终保有最终决定权。

在**查询**页面，助手更进一步，化身 SQL 创作者：描述您想要的查询（"显示过去 7 天各智能体的错误率"），它会将 SQL 直接流式输出到编辑器，并打开差异视图，供您在内容落地前**接受**或**拒绝**更改。

![Observability 查询页面及其 SQL 编辑器](/agenteye/images/query-lab.png)
*查询页面：此编辑器是助手流式输出草稿（只读查询）供您接受或拒绝的地方。*

在此通过提问来创作 SQL 使用的是 `queries:run` 权限，与编辑器的**运行**按钮所用权限相同。其他地方的聊天功能需要 `agent:use` 权限。

## 可放心开放给整个团队

您可以向所有人开放助手访问权限，无需担心它可能触及的内容：

- **仅读取您已有权限查看的内容。** 答案的范围限定在您自己的读取权限之内，因此它不会扩大您的数据访问面。
- **每次写入操作都需等待您的确认。** 已保存的查询和仪表板仅在您明确点击"批准"后才会创建，且没有任何设置可以关闭此确认步骤。
- **它永远无法删除任何内容。** 助手不具备删除工具，也没有删除权限。删除操作由您在仪表板中亲自完成。
- **它的活动范围仅限于您的组织。** 助手只能访问您当前正在查看的组织。
- **您的问题只属于您。** 提示词和答案存储在您自己的 Observability 数据库中；产品分析仅记录使用元数据，从不记录您的提示词内容。

## 如何找到它

助手显示在您组织下（`/<org-slug>/...`）每个页面的右侧边栏。点击侧边栏，或按 `⌘J` / `Ctrl+J`，可将其展开为完整的聊天面板；拖动其边缘可调整宽度，宽度设置将在重新加载后保留。使用助手需要 **`agent:use`** 权限，否则侧边栏将显示为灰色。如果您的部署尚未启用助手（需要 LLM 连接），您将看到一个静默的侧边栏，而非可用的聊天界面。
