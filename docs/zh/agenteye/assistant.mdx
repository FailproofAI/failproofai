用自然语言向 Agent 数据提问，直接获取链接到证据的答案。无需编写 SQL，无需翻遍仪表盘——**Failproof AI Observability** 助手是团队中任何人获取 Agent 相关信息的最快方式。

![Failproof AI Observability 助手在仪表盘内回答自然语言问题，显示实时 Agent 活动表、每个 Agent 的模型使用情况分解和文字要点，以及内联显示的执行查询](/agenteye/images/assistant.png)
*用自然语言提问，从你自己的数据中获取答案。这里它分析了哪些 Agent 最繁忙、它们使用了哪些模型，并展示了执行的查询，方便你核实每个数字。*

无需学习任何东西。打开对话，输入你想了解的内容，然后点击返回的链接：

```
You:  which sessions errored today?
AI:   5 sessions errored today, newest first. Each one is linked:
      • checkout-agent   14:02   tool timeout
      • billing-agent    11:47   unhandled error
      • ...and 3 more

You:  summarize this session          (asked while viewing a run)
AI:   This run took 12 steps across 3 tools and failed near the end when a
      payment tool returned an error. It scored low on your "resolved" eval.
      Links: the session, the failing event, and that evaluation.
```

## 直接提问，直达证据

你不再需要猜测，也不再需要编写查询。问"本周生产环境的质量趋势如何？"、"今天哪些会话出错了？"或"总结一下这个会话"，几秒钟内就能得到直接答案，而不必自己构建查询并逐一阅读。

每个答案都附有来源依据。助手会链接到它用于得出结论的具体会话、已保存的查询和仪表盘，让你可以点击验证，而不必全凭信任。它还具备**页面感知**能力：当你正在查看某个会话时问"这个会话"，它已经知道你指的是哪次运行。之后可以通过历史切换器重新打开任何之前的对话，从上次中断的地方继续。

## 将优质答案转化为已保存查询或仪表盘

当某个答案值得保留时，可以让助手保存它。它会起草一个已保存查询的 SQL，或基于这些查询组合一个仪表盘，然后显示一张**批准 / 拒绝**卡片。在你点击批准之前，什么都不会被写入，因此你既能享受"直接提问"的速度，又始终拥有最终决定权。

在**查询**页面，助手更进一步，成为 SQL 作者：描述你想要的查询（"显示过去 7 天每个 Agent 的错误率"），它会将 SQL 直接流式写入编辑器，并打开差异视图，让你在内容落地之前**接受**或**拒绝**更改。

![Observability 查询页面及其 SQL 编辑器](/agenteye/images/query-lab.png)
*查询页面：这个编辑器是助手流式生成草稿只读查询供你接受或拒绝的地方。*

在这里通过提问来编写 SQL 使用的是 `queries:run` 权限，与编辑器的**运行**按钮背后的权限相同。其他地方的对话则需要 `agent:use` 权限。

## 可以放心开放给整个团队

你可以放心地向所有人开放助手，无需担心它可能触及的内容：

- **它只读取你已有权限查看的内容。** 答案的范围仅限于你自己的读取权限，因此它不会扩大你的数据访问面。
- **每次写入操作都等待你确认。** 已保存的查询和仪表盘只有在你明确点击批准后才会创建，且没有任何设置可以关闭这道门槛。
- **它永远无法删除任何内容。** 没有暴露任何删除工具，助手也不持有删除权限。删除操作始终由你在仪表盘中完成。
- **它只在你的组织内运行。** 助手只会查看你当前正在浏览的组织。
- **你的问题属于你自己。** 提示词和答案保存在你自己的 Observability 数据库中；产品分析仅记录使用元数据，从不记录你的提示词文本。

## 如何找到它

助手固定在你的组织（`/<org-slug>/...`）每个页面的右侧边栏。点击边栏，或按下 `⌘J` / `Ctrl+J`，将其展开为完整的对话面板，拖动边缘可调整大小；你设置的宽度会在页面刷新后保留。使用它需要 **`agent:use`** 权限，否则边栏会显示为灰色。如果你的部署尚未启用该功能（需要 LLM 连接），你将看到一个静默的边栏而非可用的对话界面。
