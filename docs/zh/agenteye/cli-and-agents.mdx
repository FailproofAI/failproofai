您的整个 Failproof AI Observability 部署，一条命令即可搞定。无需离开终端，即可检查生产环境、生成 API 密钥或确认事件，还可将任意操作编写成脚本集成到 CI，或者用自然语言让编码智能体代劳。

```bash
pipx install agenteye
agenteye login --email you@example.com      # a 6-digit code lands in your inbox
agenteye --json sessions --since 24h         # every agent run from the last day, newest first
```

*`agenteye` CLI 与您的仪表板通信，是一个独立工具，与负责向服务器发送事件的采集器不同。*

## 您的整个部署，一条命令即可搞定

不用再在多个标签页之间跳来跳去来回答一个简单的问题了。`agenteye` CLI 通过单个二进制文件读取您的数据并管理您的组织，以前需要在仪表板中点来点去的检查，现在只需一行命令即可完成——您可以重复执行、设置别名，或粘贴到操作手册中。它提供四大功能模块：

- **读取数据：** `sessions`、`events`、`evals` 和 `errors`，支持按时间、智能体和环境过滤。
- **管理组织：** `keys`、`users`、`settings`、`alerts` 和 `incidents`。
- **运行分析：** 保存的 SQL 查询以及针对事件数据的临时 `query` 执行器。
- **询问助手：** `agent ask` 可访问与仪表板中相同的只读分析助手。

用 `pipx` 安装一次，通过邮件发送的 6 位验证码登录，即可开始使用。会话有效期约为一天；过期后重新运行 `agenteye login` 即可。无需打开浏览器，即可快速检查生产环境、配置密钥或处理触发中的事件：

```bash
agenteye errors --since 24h --aggregate      # what is breaking, grouped by error type
agenteye incidents list --state firing       # what is on fire right now
agenteye keys create ci --add events:add     # a key that can only push events, secret shown once
```

有一个使用习惯需要注意：像 `--json` 这样的全局选项需放在命令之前。`agenteye --json sessions` 是正确的，`agenteye sessions --json` 则不行。

## 编写脚本，集成到 CI

每条命令都支持 `--json`，这改变了一切。干净的 JSON 输出到 stdout，而人类可读的状态信息和警告则输出到 stderr，因此带 `--json` 的输出可以直接通过管道传给 `jq`，无需额外清理多余的行。这正是 CLI 既适合在命令提示符下交互使用，也适合让编码智能体解析输出的原因：

```bash
agenteye --json sessions --since 24h --status error | jq -r '.sessions[].session_id'
```

CLI 专为无人值守运行而设计。当没有终端连接时，确认提示会自动跳过，因此不会在管道中卡住；每条命令都会返回有意义的退出码：`0` 表示成功，`4` 表示未登录，`5` 表示缺少权限（错误信息会具体说明，例如 `alerts:write`），`3` 表示仪表板不可达。脚本可以根据 `4` 进行重新认证，或根据 `5` 明确知道需要向管理员申请哪项权限，而不是在一无所知的情况下失败。

## 让编码智能体用自然语言驱动它

更好的做法是，您根本不需要记住这些参数。**CLI skill** 是一个名为 `agenteye-cli` 的小型 Agent Skill 文件夹，它能教 Claude Code 或 Codex 等编码智能体根据自然语言请求来驱动 CLI。只需问"今天有什么异常吗？"，智能体就会选择合适的命令、以您的身份运行，并以自然语言回答。

对于 Claude Code，将 `agenteye-cli` 文件夹放入 `~/.claude/skills/` 即可自动发现。Failproof AI Observability 提供该文件夹；无需额外安装任何东西，因为它只是驱动您已经安装的 CLI。请先自行登录：该 skill 无法替您完成邮件验证码登录流程。

由于智能体以您的身份运行 CLI，它可以执行您的登录权限允许的一切操作，包括读取和写入：创建密钥、修改设置、解决事件。CLI 的"您确定吗？"提示不会针对智能体触发，因此该 skill 被设计为在执行任何变更之前，明确说明具体命令并等待您的确认。您就是那个确认步骤。

```text
you    Why did session run-001 fail?

agent  Running: agenteye --json events --session-id run-001 --all
       The checkout-agent hit a TimeoutError on its third tool call.
```

读取操作即时完成，所有写入操作都会暂停等待您确认：

```text
you    Give CI a key that can only push events.

agent  This creates an API key. I'll run:
         agenteye keys create ci --add events:add
       OK to proceed?

you    yes

agent  Done. Key "ci" created with events:add only. The secret is shown once, so store it now.
```
