您的工程师每天都在使用 OpenAI Codex。Codex 会话捕获功能将这些编程会话以普通会话和事件的形式引入 AgentEye，让您可以像查看其他所有观测数据一样对其进行搜索、回放和评估。它与 [Python SDK](/zh/agenteye/python-sdk) 相辅相成：SDK 用于对您自己编写的 Agent 进行插桩，而本功能则捕获您团队已有的 Codex 工作——无需改变他们的使用方式。

一个轻量级后台收集器会在 Codex 写入本地会话记录时实时读取，并将其发送至 AgentEye。每台机器部署一个收集器即可同时捕获所有本地 Codex 界面，无需逐一配置。

同一个收集器也可捕获其他 Agent——详见 [OpenClaw](/zh/agenteye/openclaw-capture) 和 [Hermes](/zh/agenteye/hermes-capture)。按需启用各项捕获，单个收集器可同时处理多个来源。

---

## 捕获内容

所有**本地**运行的 Codex 界面均会生成相同的磁盘会话记录，收集器会统一采集：

- Codex **CLI** 及 `codex exec`
- **VS Code / IDE 扩展**
- **桌面应用**（在本地运行会话时）

每个 Codex 会话会成为 AgentEye 中的一个[会话](/zh/agenteye/sessions)；其用户消息、助手消息、推理过程、工具调用、工具结果及 Token 用量将转化为对应的[事件](/zh/agenteye/event-stream)。每个会话的来源界面（CLI、IDE 或桌面）均会被记录，便于区分。

> **不捕获云端会话。** 桌面应用越来越多地在 Codex 云端运行会话，本地仅保留元数据，没有可供读取的本地记录。仅捕获本地执行的会话。

## 启用方式

捕获功能默认关闭，需手动启用。请使用具有 `events:add` 权限的 API 密钥（参见 [API 密钥](/zh/agenteye/api-keys)）安装收集器，并开启 Codex 捕获：

```bash
curl -fsSL https://raw.githubusercontent.com/FailproofAI/agenteye-collector/main/install.sh \
  | sh -s -- --key <YOUR_API_KEY> --codex-enabled
```

该命令将安装收集器、将其注册为后台服务并开始捕获。确认运行状态：

```bash
agenteye-collector health
```

首次运行时，现有 Codex 会话将被回填一次，此后新增活动将在数秒内实时上传。收集器仅读取 Codex 的原始文件，绝不修改、移动或删除；每个会话仅上传一次，即使重启也不会重复。

---

## 查看位置

捕获的会话将显示在 **Sessions** 中，其事件将出现在 **Events** 流中，与其他任何受监控的 Agent 完全一致——因此[会话回放](/zh/agenteye/sessions)、[搜索](/zh/agenteye/queries)、[评估](/zh/agenteye/evaluations)和[告警](/zh/agenteye/alerts)均可正常使用。通过筛选 Codex Agent 即可单独查看这些数据。

---

## 隐私说明

Codex 会话记录包含完整的会话内容——包括命令输出、文件内容以及 Codex 读写的所有信息——可能涉及敏感数据。捕获的会话将原样上传，因此请仅在适合将相关内容集中存储至 AgentEye 的机器和团队上启用捕获功能，并将收集器的 API 密钥权限限定为仅 `events:add`。有关数据隔离机制，请参阅[安全说明](/zh/agenteye/security)。
