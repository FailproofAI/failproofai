description: "将团队本地的 OpenAI Codex 会话以普通会话和事件的形式接入 AgentEye，无需改变他们运行 Codex 的方式。"

您的工程师每天都在使用 OpenAI Codex。Codex 会话捕获功能将这些编码会话作为普通会话和事件引入 AgentEye，让您可以与其他所有观测内容一起进行搜索、回放和评估。它与 [Python SDK](/zh/agenteye/python-sdk) 相辅相成：SDK 用于对您编写的 Agent 进行埋点，而此功能则捕获团队日常使用 Codex 的工作内容——无需改变任何使用方式。

一个轻量级的后台采集器会在 Codex 本地会话记录写入时实时读取并上传到 AgentEye。每台机器只需运行一个采集器，即可同时捕获所有本地 Codex 界面，无需针对每个界面单独配置。

同一个采集器也可捕获其他 Agent——详见 [OpenClaw](/zh/agenteye/openclaw-capture) 和 [Hermes](/zh/agenteye/hermes-capture)。按需启用各项功能，单个采集器可同时捕获多个来源。

---

## 捕获内容

所有**本地**运行的 Codex 界面都会生成相同的磁盘会话记录，采集器会统一读取：

- Codex **CLI** 及 `codex exec`
- **VS Code / IDE 扩展**
- **桌面应用**（在本地运行会话时）

每个 Codex 会话都会成为 AgentEye 的一个[会话](/zh/agenteye/sessions)；其中的用户与助手消息、推理过程、工具调用、工具结果及 Token 用量将转化为对应的[事件](/zh/agenteye/event-stream)。每个会话的来源（CLI、IDE 或桌面端）均会被记录，便于区分。

> **云端会话不会被捕获。** 桌面应用越来越多地在 Codex 云端运行会话，仅在本地保留元数据，没有本地记录可供读取。仅本地执行的会话会被捕获。

---

## 开启方式

捕获功能默认关闭，需手动启用。安装采集器时请使用具有 `events:add` 权限的 API 密钥（参见 [API 密钥](/zh/agenteye/api-keys)），并开启 Codex 捕获：

```bash
curl -fsSL https://raw.githubusercontent.com/FailproofAI/agenteye-collector/main/install.sh \
  | sh -s -- --key <YOUR_API_KEY> --codex-enabled
```

此命令将安装采集器、将其注册为后台服务并启动捕获。确认运行状态：

```bash
agenteye-collector health
```

首次运行时，已有的 Codex 会话将进行一次性历史回填，此后新活动将在数秒内实时上传。采集器只读取 Codex 的文件，不会对其进行修改、移动或删除，每个会话即使在重启后也只会上传一次。

---

## 查看位置

捕获的会话显示在**Sessions**中，其事件显示在 **Events** 流中，与其他任何观测的 Agent 完全一致——因此[会话回放](/zh/agenteye/sessions)、[搜索](/zh/agenteye/queries)、[评估](/zh/agenteye/evaluations)和[告警](/zh/agenteye/alerts)均可正常使用。通过筛选 Codex Agent 可单独查看这些内容。

---

## 隐私说明

Codex 会话记录包含完整的会话内容——包括命令输出、文件内容以及 Codex 读写的所有信息——可能涉及敏感凭证。捕获的会话将原样上传，因此请仅在适合将这些内容集中存储于 AgentEye 的机器和团队中启用此功能，并为采集器提供仅限 `events:add` 权限的密钥。数据隔离保护措施详见[安全说明](/zh/agenteye/security)。
