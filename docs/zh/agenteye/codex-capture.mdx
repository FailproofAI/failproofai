title: "Codex 会话捕获"
description: "将团队本地的 OpenAI Codex 会话以普通会话和事件的形式同步到 AgentEye，无需改变现有的 Codex 使用方式。"
---

你的工程师每天都在使用 OpenAI Codex。Codex 会话捕获功能可以将这些编码会话作为普通会话和事件引入 AgentEye，让你能够与其他所有被观测内容一起进行搜索、回放和评估。它与 [Python SDK](/zh/agenteye/python-sdk) 相辅相成：SDK 用于对你自己编写的 Agent 进行埋点，而此功能则捕获团队日常使用 Codex 产生的内容——无需改变任何使用方式。

一个轻量的后台采集器会在 Codex 写入本地会话记录时实时读取并上传至 AgentEye。每台机器只需部署一个采集器，即可覆盖所有本地 Codex 入口，无需逐个配置。

---

## 捕获内容

所有**本地**运行的 Codex 入口均会产生相同的磁盘会话记录，采集器会统一采集：

- Codex **CLI** 及 `codex exec`
- **VS Code / IDE 扩展**
- **桌面应用**（仅限本地运行会话时）

每个 Codex 会话将成为 AgentEye 中的一个[会话](/zh/agenteye/sessions)；其中的用户消息、助手消息、推理过程、工具调用、工具结果及 Token 用量将对应转化为[事件](/zh/agenteye/event-stream)。每个会话的来源（CLI、IDE 或桌面应用）均会被记录，便于区分。

> **云端会话不在捕获范围内。** 桌面应用越来越多地在 Codex 云端运行会话，本地仅保留元数据，不存在本地记录可供读取。仅本地执行的会话才会被捕获。

---

## 开启方式

捕获功能默认关闭，需手动启用。请使用具有 `events:add` 权限的 API 密钥（参见 [API 密钥](/zh/agenteye/api-keys)）安装采集器并开启 Codex 捕获：

```bash
curl -fsSL https://raw.githubusercontent.com/FailproofAI/agenteye-collector/main/install.sh \
  | sh -s -- --key <YOUR_API_KEY> --codex-enabled
```

该命令将安装采集器、将其注册为后台服务并立即开始捕获。确认运行状态：

```bash
agenteye-collector health
```

首次运行时，已有的 Codex 会话会被补录一次，此后的新活动将在数秒内实时上报。采集器仅读取 Codex 的本地文件，不会修改、移动或删除任何内容，且每个会话只会上传一次，即便服务重启也不会重复。

---

## 数据展示位置

捕获的会话将出现在 **Sessions** 中，对应事件出现在 **Events** 流中，与其他任何被观测的 Agent 完全一致——因此[会话回放](/zh/agenteye/sessions)、[搜索](/zh/agenteye/queries)、[评估](/zh/agenteye/evaluations)和[告警](/zh/agenteye/alerts)均可对其使用。通过筛选 Codex Agent 即可单独查看这些内容。

---

## 隐私说明

Codex 会话记录包含完整的会话内容，包括命令输出、文件内容以及 Codex 读写的所有数据，可能含有敏感信息。捕获的会话将原样上传，因此请仅在适合将相关内容集中存储于 AgentEye 的机器和团队中启用此功能，并将采集器的密钥权限限定为 `events:add`。数据隔离方式详见[安全说明](/zh/agenteye/security)。
