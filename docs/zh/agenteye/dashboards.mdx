## 让所有人看到同一份真相

不再需要把截图粘贴到聊天记录里，也不再需要每天重复运行同一个查询五次。仪表盘是一块面向全组织的共享面板，团队中任何人打开都能看到完全相同的视图。底层数据更新时，图表随之更新，面板始终保持最新状态，再也不会因为数据过期而产生争议。

上方的 Fleet 仪表盘是日常运维的一个良好起点：

- **每小时事件数**折线图，用于监控吞吐量并及时发现突然下降
- **按类型分类的错误**柱状图，让最主要的故障类别一目了然
- **延迟**面积图，在用户投诉之前就能发现性能下滑
- **按模型分类的 Token 用量**，让成本始终处于可视范围内

你可以在 `/<org-slug>/dashboards` 找到所有仪表盘。

## 固定已保存的查询

每块图表都从一个已保存的查询开始。在 [Queries](/zh/agenteye/queries) 库中（包含内置预设和你自定义的查询，覆盖事件与评估数据）构建并保存你关心的查询，然后以最适合数据的图表类型将其固定到仪表盘：用**折线图**展示趋势变化，用**柱状图**对比各类别，用**面积图**呈现数量规模，用**饼图**展示占比分布。

由于每块图表本质上就是已保存查询的图形化呈现，无需手动保持同步。只需更新一次查询，所有使用该查询的仪表盘都会自动更新。

## 关注质量，而不仅仅是数量

数量告诉你 Agent 正在忙碌运转，质量才能说明它们真正完成了任务。将仪表盘指向你的[评估分数](/zh/agenteye/evaluations)，即可获得一块随时间追踪运行质量的面板——质量下滑会直接体现为图表上的凹陷，而不是来自用户的突然投诉。

![由已保存评估查询构建的质量聚焦仪表盘](/agenteye/images/dashboard-quality.png)

*质量面板将评估分数置于核心位置，与运营数据并排展示。*

将运营面板与质量面板并排放置，团队就有了一个统一的地方，同时回答「系统是否正常运行？」和「运行效果是否良好？」这两个问题，无需任何人重复运行查询。
