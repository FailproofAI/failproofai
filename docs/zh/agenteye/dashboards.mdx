## 所有人看到同一份真相

不必再把截图粘贴到聊天框，也不必每天重复运行同一个查询五遍。仪表盘是一块团队共享的组织级面板，任何成员打开后看到的都是完全相同的视图。底层数据变化时，图表随之更新，面板始终保持最新状态，不再有人为陈旧数据争论不休。

上方的 Fleet 仪表盘是日常运营的理想起点：

- **每小时事件数**折线图，用于监控吞吐量并及时发现突然下降
- **按类型统计的错误**柱状图，让最主要的故障类别一目了然
- **延迟**面积图，在用户投诉之前发现性能下降
- **按模型统计的 Token**分布图，让成本始终在视野之内

您可以在 `/<org-slug>/dashboards` 找到您的面板。

## 固定已保存的查询

每个磁贴都源自一个已保存的查询。在 [Queries](/zh/agenteye/queries) 库（内置预设及您自定义的查询，覆盖事件和评估数据）中构建并保存您关注的查询，然后将其固定到仪表盘，选择最适合数据的图表类型：用**折线图**展示随时间变化的趋势、用**柱状图**比较不同类别、用**面积图**展示数据量，或用**饼图**展示占比分布。

由于磁贴本质上就是将已保存的查询渲染为图表，因此无需手动同步任何内容。更新一次查询，所有使用该查询的仪表盘都会自动更新。

## 关注质量，而不仅仅是数量

数量告诉你 Agent 正在忙碌运转，质量才能告诉你它们是否真正完成了工作。将仪表盘指向您的[评估分数](/zh/agenteye/evaluations)，即可获得一块追踪运行质量随时间变化的面板——质量下降会以图表上的凹陷呈现，而不是来自客户的意外反馈。

![由已保存评估查询构建的质量导向仪表盘](/agenteye/images/dashboard-quality.png)

*质量面板将评估分数置于核心位置，与运营数据并排显示。*

将运营面板与质量面板并排放置，团队就有了一个统一的地方来回答「它是否正常运行？」和「它是否运行良好？」这两个问题，无需任何人重新运行查询。
