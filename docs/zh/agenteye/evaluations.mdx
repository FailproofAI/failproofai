质量问题会主动找上你，而不是等到用户投诉你才知道。只需接入一次你自己的评分服务，Failproof AI Observability 就会自动为每一次完成的运行打分，帮助度下滑或幻觉激增等问题会自动浮现，在用户感知到之前就进入你的视野。

![Sessions 网格附带评分列：每次运行都有评估状态标签以及颜色编码的帮助度、事实准确性和工具效率徽章](/agenteye/images/sessions-list.png)

*Sessions 网格上的每次运行都带有其评分；红色、琥珀色和绿色徽章让表现较差的运行一目了然，无需打开任何一条对话记录。*

## 告别手动抽查

以前你只能抽查少数几次运行，然后寄希望于其余的都没问题。现在，每一次完成的会话在结束的瞬间即被评分，维度由你决定：帮助度、工具效率、事实准确性、安全性，或任何你的质量标准所要求的内容。你定义评分键；Failproof AI Observability 会存储、追踪趋势并展示评估器返回的所有结果。没有任何运行会漏评，你也不会再从支持工单中才得知系统已出现回退。

评分会随每行数据显示在 **`/<org-slug>/sessions`** 的 Sessions 网格中（侧边栏 → *observe* → *sessions*），每行一组徽章簇。只想查看不达标的运行？按评分范围筛选网格，例如帮助度低于 0.5，即可精准拉取值得细读的运行。查看评分需要 `evaluations:read` 权限。

## 了解运行评分偏低的原因

一个数字告诉你某次运行表现欠佳；会话详情页则告诉你原因。打开任意一次运行，右侧面板首先显示总体摘要，然后按维度展示进度条，每条下方附有你的评估器给出的推理说明，让你从"事实准确性评分 0.4"迅速定位到具体出错的内容。

![会话右侧面板：顶部为评估摘要，下方为各维度评分条（每条附有一行推理说明），旁边是完整的事件时间线](/agenteye/images/session-detail.png)

*会话详情视图：摘要、各维度评分条及每项评分背后的推理说明，与运行的事件时间线并排呈现。*

部署了更精准的评估器，或者想为崩溃前未能完成评分的运行重新打分？**重新评估**按钮（需要 `evaluations:trigger` 权限）会就地对会话重新评分，并将最新结果追加到时间线，历史评分仍然可见。你可以在 **`/<org-slug>/sessions/<session-id>`** 找到该按钮。

## 监控整体运行质量趋势

单次运行评分偏低是噪声；整批运行集体下滑才是信号。已保存的仪表板将你的评分转化为可一目了然的趋势：本周与上周的平均帮助度对比，可按 agent、按环境细分。

![质量仪表板：各评估维度的平均分柱状图，以及随时间变化的趋势线](/agenteye/images/dashboard-quality.png)

*已保存的质量仪表板追踪你关注的评分键趋势，让缓慢漂移在演变为事故之前便清晰可见。*

仪表板位于 **`/<org-slug>/dashboards`**（侧边栏 → *analyze* → *dashboards*），在整个组织内共享。每个卡片汇总对应的会话：数量、各特色评分的平均值，以及趋势迷你图。点击"在 Sessions 中打开"可直接跳转到任意数字背后的预筛选运行列表。查看需要 `dashboards:read` 和 `evaluations:read` 权限。

## 一次性接入评估器

评分为可选功能，在你向 Failproof AI Observability 指定评分器之前始终处于关闭状态。你只需搭建一个小型 HTTP 服务（Observability 提供了可直接复制使用的参考实现），在服务器上配置两个值，之后所有运行都将自动完成评分。完整的操作指南、评分协议和 SDK 均在详细指南中提供。

不确定该评估哪些维度？[evaluator agent skill](/zh/agenteye/evaluator-skill) 可让编码 agent 结合你自己的会话数据进行分析，并构建和部署评估服务。
