观测界面让你实时监控智能体的运行状态，并深入查看任意单次运行的详细信息。这里的一切都是实时的，按组织范围划分，并支持按日期范围、环境、智能体和会话进行筛选，让你能在几秒内从"感觉有点不对"定位到具体的运行记录。

![实时事件流，按类型进行颜色编码，并支持按环境、智能体和会话筛选](/agenteye/images/events-stream.png)

四个界面，各有独立页面：

- **[事件流](/zh/agenteye/event-stream)**：所有智能体每次运行的实时逐步记录，最新的排在最前面。这是你的组织首页，也是分诊排查的第一站。
- **[会话与执行图](/zh/agenteye/sessions)**：将事件汇总为每次运行一行的记录，并以类似 git 的可视化图展示每次运行的展开过程。
- **[性能指标](/zh/agenteye/telemetry)**：模型、工具和 hook 的延迟热力图及 p50/p95/p99 关键指标，让尾部延迟峰值从中位数中一眼凸显。
- **[错误追踪](/zh/agenteye/error-tracking)**：将所有出错内容汇聚在一个分诊界面，一键从触发的告警跳转到引发问题的运行记录。
