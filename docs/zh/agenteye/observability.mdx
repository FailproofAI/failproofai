观察界面用于实时查看 Agent 的运行状态，并深入分析任意单次运行的详情。此处的所有内容均为实时数据，按组织范围展示，可按日期范围、环境、Agent 和会话进行筛选，让你能在几秒内从"感觉有些不对劲"定位到具体的运行记录。

![实时事件流，按类型以不同颜色区分，可按环境、Agent 和会话进行筛选](/agenteye/images/events-stream.png)

共四个界面，每个界面对应独立页面：

- **[事件流](/zh/agenteye/event-stream)**：跨所有 Agent、所有运行的实时逐步追踪记录，最新内容置顶。这是你的组织主页，也是排查问题的第一站。
- **[会话与执行图](/zh/agenteye/sessions)**：将事件汇总为每次运行一行的视图，并以类似 git 的图形展示每次运行的执行过程。
- **[性能指标](/zh/agenteye/telemetry)**：针对模型、工具和 Hook 的延迟热力图及 p50/p95/p99 关键指标，让尾部延迟峰值从中位数中一眼凸显。
- **[错误追踪](/zh/agenteye/error-tracking)**：一站式排查所有异常，从触发的告警一键跳转至引发问题的运行记录。
