观测界面是您实时监控 Agent 行为并深入查看单次运行详情的地方。这里的所有内容均为实时数据，按组织范围展示，并支持按日期范围、环境、Agent 和会话进行筛选，让您能在几秒内从"感觉有些不对劲"定位到具体的运行记录。

![实时事件流，按类型用颜色区分，支持按环境、Agent 和会话筛选](/agenteye/images/events-stream.png)

共有四个界面，各有独立页面：

- **[事件流](/zh/agenteye/event-stream)**：每个 Agent 所有运行的实时逐步记录，最新的排在最前。这是您组织的主页，也是分流排查的第一站。
- **[会话与执行图](/zh/agenteye/sessions)**：将事件汇总为每次运行一行，并以类似 git 的图形展示每次运行的展开过程。
- **[性能指标](/zh/agenteye/telemetry)**：针对模型、工具和 hook 的延迟热图及 p50/p95/p99 关键指标，让尾部峰值从中位数中一目了然地凸显出来。
- **[错误追踪](/zh/agenteye/error-tracking)**：一个集中处理所有异常的分流界面，从触发的告警一键跳转到引发问题的运行记录。
