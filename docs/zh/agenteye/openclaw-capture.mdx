如果您的团队使用 [OpenClaw](https://docs.openclaw.ai)，OpenClaw 会话采集功能可将这些会话以普通会话和事件的形式接入 AgentEye，让您可以与其他所有观测数据一起搜索、回放和评估。它与 [Python SDK](/zh/agenteye/python-sdk) 相辅相成：SDK 用于为您编写的 Agent 插桩，而此功能则采集团队日常使用 OpenClaw 的工作内容——无需改变任何运行方式。

一个轻量后台采集器会在写入时读取 OpenClaw 的本地会话记录，并将其传送至 AgentEye。其工作方式与 [Codex 采集](/zh/agenteye/codex-capture) 相同，一个采集器即可同时采集两者。

---

## 采集内容

机器 OpenClaw 配置中的每个 Agent 均会被该机器的采集器采集——无需逐一配置。

每个 OpenClaw 会话在 AgentEye 中对应一个[会话](/zh/agenteye/sessions)；其中的用户与助手消息、工具调用及工具结果将转换为相应的[事件](/zh/agenteye/event-stream)。

---

## 开启采集

采集默认关闭，需手动启用。请使用具有 `events:add` 权限的 API 密钥（参见 [API 密钥](/zh/agenteye/api-keys)）安装采集器，并开启 OpenClaw 采集：

```bash
curl -fsSL https://raw.githubusercontent.com/FailproofAI/agenteye-collector/main/install.sh \
  | sh -s -- --key <YOUR_API_KEY> --openclaw-enabled
```

该命令将安装采集器、将其注册为后台服务并开始采集。运行以下命令确认服务正常：

```bash
agenteye-collector health
```

同一台机器上需采集多个 Agent？在同一命令中添加各自的标志即可，例如 `--openclaw-enabled --codex-enabled`。

首次运行时，现有 OpenClaw 会话将被回填一次，此后新活动将在数秒内实时传输。OpenClaw 的原始文件仅供读取——不会被修改、移动或删除——每个会话即便在采集器重启后也只会被传送一次。

---

## 数据展示位置

采集到的会话显示在 **Sessions** 中，对应事件显示在 **Events** 流中，与您观测的其他任何 Agent 完全一致——因此[会话回放](/zh/agenteye/sessions)、[搜索](/zh/agenteye/queries)、[评估](/zh/agenteye/evaluations)和[告警](/zh/agenteye/alerts)均可正常使用。通过筛选 OpenClaw Agent 可单独查看其会话。

---

## 隐私说明

OpenClaw 记录包含完整的会话内容——包括命令输出、文件内容以及 Agent 读取或写入的所有内容——可能含有敏感信息。采集到的会话将原样传送，因此请仅在适合将相关内容集中存储至 AgentEye 的机器和团队中启用采集，并为采集器配置仅限 `events:add` 范围的密钥。请参阅[安全说明](/zh/agenteye/security)了解数据隔离机制。
