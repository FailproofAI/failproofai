title: "OpenClaw 会话捕获"
description: "将团队本地的 OpenClaw 会话以普通会话和事件的形式同步到 AgentEye，无需更改 OpenClaw 的运行方式。"
---

如果你的团队使用 [OpenClaw](https://docs.openclaw.ai)，OpenClaw 会话捕获功能可以将这些会话作为普通会话和事件引入 AgentEye，让你能够在同一界面中搜索、回放并与其他所有观测内容一起评估。它与 [Python SDK](/zh/agenteye/python-sdk) 相辅相成：SDK 用于对你自己编写的 Agent 进行埋点，而此功能则捕获团队日常使用 OpenClaw 的工作内容——无需对运行方式做任何改动。

一个轻量级后台采集器会在 OpenClaw 本地会话记录写入时实时读取，并将其发送至 AgentEye。其工作方式与 [Codex 捕获](/zh/agenteye/codex-capture) 相同，一个采集器可同时捕获两者。

---

## 捕获内容

某台机器上 OpenClaw 配置中的每个 Agent 都会被该机器的采集器捕获——无需逐个 Agent 进行设置。

每个 OpenClaw 会话将成为 AgentEye 中的一个 [session](/zh/agenteye/sessions)；其用户消息、助手消息、工具调用和工具结果将成为对应的 [events](/zh/agenteye/event-stream)。

---

## 开启捕获

捕获功能默认关闭，需手动启用。使用具有 `events:add` 权限的 API 密钥安装采集器（参见 [API keys](/zh/agenteye/api-keys)），并开启 OpenClaw 捕获：

```bash
curl -fsSL https://raw.githubusercontent.com/FailproofAI/agenteye-collector/main/install.sh \
  | sh -s -- --key <YOUR_API_KEY> --openclaw-enabled
```

该命令将安装采集器，将其注册为后台服务，并开始捕获。确认运行状态：

```bash
agenteye-collector health
```

同一台机器上需要捕获多个 Agent？将各自的标志添加到同一条命令中，例如 `--openclaw-enabled --codex-enabled`。

首次运行时，现有的 OpenClaw 会话将被一次性回填，此后新活动将在数秒内实时流式传输。OpenClaw 的原始文件仅会被读取，绝不会被修改、移动或删除，且每个会话只会被发送一次，即便采集器重启也不例外。

---

## 查看位置

捕获的会话将出现在 **Sessions** 中，其事件出现在 **Events** 流中，与其他任何被观测的 Agent 完全一致——因此 [session replay](/zh/agenteye/sessions)、[search](/zh/agenteye/queries)、[evaluations](/zh/agenteye/evaluations) 和 [alerts](/zh/agenteye/alerts) 均可对其使用。通过筛选 OpenClaw Agent 可单独查看这些内容。

---

## 隐私说明

OpenClaw 记录包含完整的会话内容，包括命令输出、文件内容以及 Agent 读写的所有内容，可能含有敏感信息。捕获的会话将原样发送，因此请仅在适合将相关内容集中存储至 AgentEye 的机器和团队上启用捕获功能，并为采集器提供仅限 `events:add` 权限的密钥。关于数据隔离的详细说明，请参见 [Security](/zh/agenteye/security)。
