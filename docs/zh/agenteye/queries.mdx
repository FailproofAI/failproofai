向你的 Agent 数据提问，几秒内获得答案。Failproof AI 可观测性为你提供一个已保存的、开箱即用的查询库，覆盖你的事件与评估数据，让你从一个可直接运行的示例出发，而不是面对空白的 SQL 编辑器。

![已保存查询库：一个可复用查询的网格视图，包含内置预设和自定义查询](/agenteye/images/queries.png)

*位于 `/<org-slug>/queries` 的已保存查询库：内置预设与你的团队保存的查询并列显示。*

## 从预设出发，而非白纸一张

你无需记忆表名，也不用从头编写 SQL。查询库打开后就展示了内置预设，涵盖团队最常问的问题，紧挨着你的团队已保存并命名的查询。选一个接近你需求的，答案就已唾手可得。

每个已保存的查询都属于组织范围并对全员共享，因此你的队友写出的实用查询你也可以直接使用。为查询起个名字、添加一段描述，组织内的任何人都能找到它、运行它，或日后将其结果固定到仪表板上。

访问路径：`/<org-slug>/queries`。

## 在 SQL 编辑器中调整并运行

打开任意查询，它会在 SQL 编辑器中加载，你可以随即调整并立刻看到结果——无需导出，无需来回跳转，无需等待他人。

![SQL 查询编辑器运行已保存查询，左侧为 Schema 侧边栏，下方为实时结果表格](/agenteye/images/query-lab.png)

*SQL 编辑器：左侧是你的查询，Schema 侧边栏让你无需猜测列名，下方是实时结果表格。*

- **Schema 侧边栏** 列出所有分析表及其字段，让你无需四处查找字段名即可构建查询。
- **实时结果表格** 在你运行查询后立即返回数据行，让你以秒为单位迭代，而非反复猜测。
- **只读设计。** 查询在你的事件存储上运行，并在服务端进行验证：仅允许 `SELECT` 和 `WITH` 语句，同时设有语句超时和行数上限。探索性查询永远不会修改你的数据，失控的查询也会被自动终止。

对结果满意了？将其保存回查询库，让整个团队共同继承，或将输出以折线图、柱状图、面积图或饼图的形式固定到仪表板上。

## 在终端运行，或让助手来写

已保存的查询在你工作的任何地方都如影随形：

- **从终端运行。** `agenteye` CLI 可以列出、运行和保存完全相同的查询，因此你可以将结果输出到脚本中、集成到 CI 流程里，或交给编码 Agent 处理。

```bash
agenteye query list                 # the same saved queries, from your terminal
agenteye query run errs --arg prod  # run one and print the rows (add --json to pipe it)
```

  完整命令集请参阅 [CLI 与 Agents](/zh/agenteye/cli-and-agents)。

- **从 AI 助手运行。** 不确定如何编写 SQL？用自然语言向仪表板内的 [AI 助手](/zh/agenteye/assistant)提问，它会帮你起草查询并保存到你的查询库中。

运行已保存查询需要 `queries:run` 权限，该权限与创建或删除查询的权限相互独立，因此你可以授予只读访问权限，而不必担心所有人都能改写查询库。
