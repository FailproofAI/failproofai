向你的智能体数据提问，即刻获得答案。Failproof AI Observability 为你提供一个保存好的、即用型查询库，涵盖你的事件和评估数据，让你从现成的示例入手，而不是面对空白的 SQL 编辑器。

![保存的查询库：一个可复用查询的网格视图，包含内置预设和自定义查询](/agenteye/images/queries.png)

*你在 `/<org-slug>/queries` 的保存查询库：内置预设与团队保存的查询并排展示。*

## 从预设开始，而非空白页

你无需记住表名，也不必从头编写 SQL。查询库打开时即显示内置预设，涵盖团队最常提问的问题，与你的团队已保存并命名的查询并列展示。选一个最接近你需求的，你就已经离答案不远了。

每个保存的查询都属于组织级别并对成员共享，因此队友写的有用查询也会为你所用。为查询命名并添加一次描述，组织内的任何人都能找到它、运行它，或稍后将其结果固定到仪表板上。

在 `/<org-slug>/queries` 找到它。

## 在 SQL 编辑器中调整并运行

打开任意查询，它将在 SQL 编辑器中打开，你可以随时调整并立即看到结果：无需导出，无需来回切换，无需等待他人。

![SQL 查询编辑器正在运行一个保存的查询，带有结构侧边栏和实时结果表格](/agenteye/images/query-lab.png)

*SQL 编辑器：左侧是你的查询，结构侧边栏让你无需猜测列名，下方是实时结果表格。*

- **结构侧边栏** 列出了分析表及其列，让你无需四处寻找字段名即可构建查询。
- **实时结果表格** 在你运行查询的瞬间即返回数据行，让你在数秒内完成迭代，而无需反复猜测。
- **只读设计。** 查询针对你的事件存储运行，并在服务器端验证：仅允许 `SELECT` 和 `WITH` 语句，并设有语句超时和行数上限。探索性查询永远不会修改你的数据，失控的查询会被自动终止。

对结果满意？将其保存回查询库，让整个团队共享，或将其输出以折线图、柱状图、面积图或饼图磁贴的形式固定到仪表板上。

## 从终端运行，或让助手来编写

相同的已保存查询在你工作的任何地方都可使用：

- **从终端使用。** `agenteye` CLI 可以列出、运行和保存完全相同的查询，因此你可以将结果输出到脚本中、接入 CI 流程，或交给编程智能体使用。

```bash
agenteye query list                 # the same saved queries, from your terminal
agenteye query run errs --arg prod  # run one and print the rows (add --json to pipe it)
```

  完整命令集请参见 [CLI and agents](/zh/agenteye/cli-and-agents)。

- **从 AI 助手使用。** 不确定如何表达 SQL？用自然语言向仪表板内的 [AI 助手](/zh/agenteye/assistant) 提问，它会为你起草查询并保存到你的查询库中。

运行保存的查询需要 `queries:run` 权限，该权限与创建或删除查询的权限相互独立，因此你可以授予只读访问权限，而不必让所有人都能修改查询库。
