向你的 Agent 数据提问，秒级获得答案。Failproof AI Observability 为你提供一个已保存的、随时可运行的查询库，涵盖你的事件和评估数据，让你从一个可用的示例出发，而不是面对空白的 SQL 编辑器。

![已保存查询库：一个包含可复用查询的网格视图，既有内置预设，也有自定义查询](/agenteye/images/queries.png)

*你的已保存查询库，位于 `/<org-slug>/queries`：内置预设与团队保存的查询并排展示。*

## 从预设出发，而非从空白页开始

你无需记住表名，也不必从头编写 SQL。库中默认提供了内置预设，涵盖团队最常问的问题，与你自己团队保存并命名的查询并排放置。挑选一个接近你需求的预设，答案就已经近在咫尺。

每个已保存的查询都属于组织范围并对全员共享，因此队友写下的实用查询也会成为你的资源。为查询命名并添加描述后，组织内的任何人都能找到它、运行它，或在日后将其结果固定到仪表盘上。

访问路径：`/<org-slug>/queries`。

## 在 SQL 编辑器中调整并运行

打开任意查询，它会直接加载到 SQL 编辑器中，你可以在此调整并立即查看结果——无需导出、无需来回传递、无需等待他人。

![SQL 查询编辑器正在运行一个已保存的查询，左侧为 Schema 侧边栏，下方为实时结果网格](/agenteye/images/query-lab.png)

*SQL 编辑器：左侧是你的查询，Schema 侧边栏让你无需猜测列名，下方是实时结果网格。*

- **Schema 侧边栏** 列出了所有分析表及其列名，让你无需翻找字段名即可构建查询。
- **实时结果网格** 在你运行查询后立即返回数据行，让你可以在秒级内快速迭代，而非反复猜测。
- **只读设计。** 查询针对你的事件存储运行，并在服务器端进行校验：仅允许 `SELECT` 和 `WITH` 语句，并设有语句超时和行数上限。探索性查询永远不会修改你的数据，失控的查询也会自动被终止。

对结果满意？将其保存回查询库，让整个团队共享；或将其输出固定到仪表盘上，以折线图、柱状图、面积图或饼图的形式展示。

## 从终端运行，或让助手帮你编写

已保存的查询无论在哪里工作都能跟随你：

- **从终端使用。** `agenteye` CLI 可以列出、运行和保存完全相同的查询，因此你可以将结果导入脚本、接入 CI，或传递给编程 Agent。

```bash
agenteye query list                 # 在终端中查看相同的已保存查询
agenteye query run errs --arg prod  # 运行查询并打印数据行（添加 --json 可用于管道传输）
```

  完整命令集请参阅 [CLI 与 Agents](/zh/agenteye/cli-and-agents)。

- **从 AI 助手使用。** 不确定如何表达 SQL？用自然语言向内置的 [AI 助手](/zh/agenteye/assistant) 提问，它会为你起草查询并保存到你的查询库中。

运行已保存查询需要 `queries:run` 权限，该权限与创建或删除查询的权限分开管理，因此你可以授予只读访问权限，而不必让所有人都能改写查询库。
