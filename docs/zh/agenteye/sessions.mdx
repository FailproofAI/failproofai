## 一览所有运行

原始事件记录是每个步骤的真实依据，但当你面对数十次运行中的数千个步骤时，你需要的是整体视图，而不是单个步骤。会话页面将一次运行的所有事件汇总为一行，让一天的活动变成可快速扫描的列表，而不是应接不暇的数据流。

每一行都带有状态标签，让失败的运行在你点击之前就从正常运行中脱颖而出。可按日期范围、环境、Agent 或会话进行筛选，只需几次点击，即可从"全部"定位到"我关心的那次运行"。

连接评估器后，每次完成的运行都会自动获得评分，最新分数以徽章形式显示在对应行上。你可以按任意分数范围筛选，"显示本周所有低分生产运行"只是一个筛选条件，无需手动逐一审查。在配置评估器之前，会话仍会捕获完整的运行数据，只是暂时没有分数。

## 以图形读懂完整运行过程

![会话的类 git 执行图与事件时间线并排显示，右侧面板展示工具、模型和 Hook 的详细信息](/agenteye/images/session-detail.png)

*执行图（左侧）与事件时间线并排显示；右侧栏对该次运行所用的工具、模型、Hook 及 Token 消耗进行细分。*

点击任意会话，即可打开其执行图：这是一个类似 git 风格的视图，展示 Agent、工具、Hook 和模型调用随时间展开的过程。并行子 Agent 各自分支到独立通道，让你清楚看到哪些工作是并行执行的、哪个子 Agent 发生了停滞、运行在哪里偏离了预期——无需在脑海中从一堆日志里重新复盘。

右侧栏提供每次运行的详细拆分：运行了哪些工具和模型、触发了哪些 Hook、以及本次运行消耗的 Token 量。这就是"为什么这次运行成本这么高？"或"哪个工具最慢？"的答案，就显示在引发问题的图形旁边。

---

## 在哪里找到它

所有控制台页面均限定在你的组织范围内（`/<org-slug>/…`）。会话位于左侧边栏 **Observe** 下方，紧邻 Events，列表顶部有日期范围、环境、Agent 和会话筛选器。每一行只需点击一次即可查看完整执行图。

要开启分数徽章和分数范围筛选，请连接评估器：参见 [Evaluations](/zh/agenteye/evaluations)。
