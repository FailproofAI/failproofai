## 一览所有运行

原始事件流记录了每一步的真实情况，但当你面对数十次运行中的数千个步骤时，你需要的是运行级别的视图，而不是单步详情。会话页面将一次运行的所有事件汇总为一行，让一天的活动变成可快速浏览的列表，而非滚动不停的数据流。

每一行都有状态标签，失败的运行在你点击之前就会从正常运行中脱颖而出。通过日期范围、环境、代理或会话进行筛选，几次点击即可从"全部"定位到"我关心的那次运行"。

连接评估器后，每次已完成的运行都会自动打分，最新分数以徽章形式显示在对应行上。你可以按任意分数范围筛选，"显示本周所有低分生产运行"只需设置一个筛选条件，无需手动逐一查看。在配置评估器之前，会话依然会完整捕获每次运行，只是暂时不携带分数。

## 以图形方式读懂整次运行

![会话的类 git 执行图与事件时间轴并排展示，右侧面板列出工具、模型和 hook 的详细分布](/agenteye/images/session-detail.png)

*执行图（左侧）与事件时间轴并排显示；右侧栏列出本次运行涉及的工具、模型、hook 及 token 消耗。*

点击任意会话即可打开其执行图：这是一个类 git 风格的视图，展示代理、工具、hook 和模型调用随时间展开的过程。并行子代理各占一条泳道，让你清楚地看到哪些工作是并行进行的、哪个子代理出现了停滞、运行在哪里偏离了轨道，无需在一堆日志中反复回溯。

右侧栏提供每次运行的详细分解：运行了哪些工具和模型、触发了哪些 hook、以及本次运行消耗的 token 数量。"为什么这次运行这么贵？"或"哪个工具最慢？"的答案就紧挨着引发问题的执行图。

## 在哪里找到它

每个仪表板页面都限定在你的组织范围内（`/<org-slug>/…`）。会话位于左侧边栏 **Observe** 菜单下，紧邻 Events，列表顶部提供日期范围、环境、代理和会话筛选器。每一行点击一次即可进入完整的执行图。

要启用分数徽章和分数范围筛选，请连接评估器：参见 [Evaluations](/zh/agenteye/evaluations)。
