Agent 上下文用于告知审计每个 agent 的存在意义、必须产出的内容以及绝对禁止的行为。Failproof AI 将此上下文以每个 agent 一份合约的形式存储。

Agent 上下文归属于组织，而非某次审计。每个 agent 只需编写一次，所有涵盖该 agent 的模型驱动审计均可使用。

## 添加 agent 上下文

<Tabs>
  <Tab title="控制台">
    1. 前往 **Analyze → audits**，选择 **agents**，然后选择会话报告的 agent ID。
    2. 点击 **add content** 或 **edit**。
    3. 描述该 agent 的用途、必须产出的内容、"完成"的定义、运行频率以及绝对禁止的行为。
    4. 保存上下文，然后返回审计表单，确认所选 agent 已显示为已覆盖。

    ![审计 Agents 抽屉，用于为 agent 添加用途、节奏、产出物、完成条件和禁止行为。](/images/dashboard/agent-context.png)

    您也可以在创建或编辑审计时，通过 **agents** 抽屉添加或编辑 agent 上下文。上下文独立保存，并立即对所有适用的审计生效。
  </Tab>
  <Tab title="CLI">
    Cloud CLI 暂不支持合约命令。请使用具有 `audits:read` 和 `audits:write` 权限的密钥通过公共 API 操作：

    ```bash
    curl -X POST "https://app.befailproof.ai/v1/audits/contracts" \
      -H "Authorization: Bearer $FAILPROOFAI_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "agent_id": "nightly-reconciler",
        "enabled": true,
        "body": "# Purpose\nReconcile yesterday's payouts.\n\n## Outputs\nPublish a signed summary.\n\n## Must not\nNever modify ledger entries."
      }'
    ```

    使用 `GET /v1/audits/contracts` 列出所有合约；使用 `GET /v1/audits/contracts/{id}` 获取单个合约。使用 `PUT` 更新时为全量替换，须同时提供 `agent_id` 和 `body`。
  </Tab>
</Tabs>

## 编写有效的上下文

上下文请控制在 5,000 字符以内，并确保内容可测试。有效的上下文通常包含以下要素：

- **用途：** agent 存在的原因
- **产出物：** 必须产出的制品或执行的动作
- **完成条件：** 判断本次运行成功的标准
- **运行节奏：** 运行频率或时间安排
- **禁止事项：** 任何情况下均不可接受的行为和结果

```markdown
---
agent: nightly-reconciler
purpose: Reconcile yesterday's payouts and publish a signed summary.
cadence: Once daily after 02:00 UTC. Never more than once.
---

## Outputs
- A signed reconciliation summary in the finance channel.

## Done when
- Every payout is matched or explicitly flagged.

## Must not
- Modify ledger entries. Report discrepancies instead.
```

Agent 上下文描述的是预期行为，它无法指定分析应得出何种结论，也无法限制所检查的证据范围。未配置上下文的 agent 仍会被正常审计，但 Failproof AI 无法依据组织特定意图来评判其行为。

## 暂停或修改 agent 上下文

- 当审计应临时忽略某上下文时，可将其暂停。暂停操作可撤销。
- 当 agent 的职责发生变化时，编辑上下文。新内容将应用于后续运行。
- 若某个运行中的 agent 从未使用其上下文，请检查 **last matched**。通常原因是 agent ID 与遥测数据不匹配。
- 仅在需要永久删除文本时，才通过 API 执行删除操作。控制台有意提供暂停功能而非删除功能。

每次审计运行都会存储其所使用的 agent 上下文快照。编辑、暂停或删除当前合约资源，不会重写早期发现结论的依据。

<Info>
  读取合约需要 `audits:read` 权限；创建、编辑、暂停或删除合约需要 `audits:write` 权限。
</Info>
