## 打开审计

<Tabs>
  <Tab title="控制台">
    前往 **Analyze → Audits**。页面展示计划状态、未处理的发现、上次运行时间、下次运行时间、执行频率，以及审计是否包含简介或参考页面。点击卡片可查看设置和运行历史；点击 **new audit** 可新建审计。

    ![审计页面，显示定期审计及其计划、灵敏度和运行状态。](/images/dashboard/audits.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp audits list
    fp audits list --enabled-only --show-id
    fp audits show <audit-name>
    fp audits findings --status open --limit 20
    ```
  </Tab>
</Tabs>

当你需要回答以下总体性问题时，可使用审计：

- Agent 在哪些情况下放弃任务而未进行升级处理？
- 哪些工具故障会导致无效重试？
- Agent 是否访问了预期工作流之外的数据？
- 模型、提示词或工具发布后发生了哪些变化？

## 审计响应流程

```text
Session → Audit → Finding → Issue → Policy
                         ↘ Alert for recurrence
```

发现应指明故障模式并指向相应证据；Issue 负责跟进修复；Policy 用于阻止已知的异常操作模式；当无法通过策略预防或需要持续监控时，Alert 用于检测问题的复发。
