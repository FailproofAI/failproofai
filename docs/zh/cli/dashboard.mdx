---
title: 查看会话
description: "启动仪表板以浏览代理会话并管理策略"
---

```bash
failproofai
```

在 `http://localhost:8020` 启动 Web 仪表板。

## 选项

The dashboard takes no flags — `failproofai` rejects any it does not recognize. The port is fixed at `8020`.

若要将仪表板指向非默认的 Claude 项目文件夹，请在启动时设置 `CLAUDE_PROJECTS_PATH` 环境变量。

## 示例

```bash
failproofai

# 通过环境变量使用自定义 Claude 项目路径
CLAUDE_PROJECTS_PATH=~/my-claude-projects failproofai
```
