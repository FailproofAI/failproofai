---
title: 安装 policies
description: "启用 policies，使其在每次 agent 工具调用时运行"
---

```bash
failproofai policies --install [policy-names...] [options]
```

将 hook 条目写入已安装的 agent CLI 的设置文件（Claude Code、OpenAI Codex 或 GitHub Copilot CLI _（测试版）_），使 failproofai 能够拦截工具调用。

别名：`failproofai p -i`

## 选项

| 标志 | 描述 |
|------|------|
| `--cli claude\|codex\|copilot` | 要安装的 agent CLI，空格分隔（例如 `--cli claude codex copilot`）或重复指定。省略则自动检测已安装的 CLI 并提示选择。 |
| `--scope user` | 安装到用户级别的设置文件（Claude：`~/.claude/settings.json`；Codex：`~/.codex/hooks.json`；Copilot：`~/.copilot/hooks/failproofai.json`）。默认值。 |
| `--scope project` | 安装到项目级别的设置文件（Claude：`<cwd>/.claude/settings.json`；Codex：`<cwd>/.codex/hooks.json`；Copilot：`<cwd>/.github/hooks/failproofai.json`）。 |
| `--scope local` | 仅限 Claude — 安装到 `<cwd>/.claude/settings.local.json`。Codex 和 Copilot 不支持 `local` 作用域。 |
| `--custom <path>` / `-c` | 包含自定义 hook policies 的 JS 文件路径 |

## 行为

- **不指定 policy 名称** — 打开交互式提示以选择 policies
- **指定具体名称** — 启用对应的 policies（追加到已启用的 policies 之上）
- **`all`** — 启用所有可用 policies

安装是累加的：再次运行 `--install` 只会添加新的 policies，不会移除已有的。

## 示例

```bash
# 全局安装所有默认 policies（交互式）
failproofai policies --install

# 为当前项目安装特定 policies
failproofai policies --install block-sudo sanitize-api-keys --scope project

# 一次性启用所有 policies
failproofai policies --install all

# 使用自定义 policies 文件进行安装
failproofai policies --install --custom ./my-policies.js

# 为 OpenAI Codex 安装（项目作用域）
failproofai policies --install --cli codex --scope project

# 为 GitHub Copilot CLI（测试版）安装到当前项目
failproofai policies --install --cli copilot --scope project

# 同时为三个 CLI 安装
failproofai policies --install --cli claude codex copilot
```

当提供 `--custom <path>` 时，文件会立即进行验证 — 它必须至少调用一次 `customPolicies.add()`。解析后的路径将作为 `customPoliciesPath` 保存到 `policies-config.json` 中。
