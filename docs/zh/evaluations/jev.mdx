Jev 评估读取一个**已完成的会话**，并给出 0 到 1 之间的分数。适用于答案已知的场景，例如"客户是否表达了紧迫感？"或"客户的沮丧程度如何？"它帮助你发现多次运行中的规律，但不会阻止工具调用。如需在工具运行**之前**进行决策，请使用 [Jev 策略](/zh/policies/jev)。

## 在控制台中创建

1. 打开 **Analyze → eval authoring**，选择 **new eval**。
2. 描述一个问题及其可能的答案。例如："代理是否在检查退款政策之前承诺了退款？请回答是或否。"选择 **draft** 并确认结果为分类器分数。
3. 在近期会话上[测试](/zh/evaluations/test)，然后[部署](/zh/evaluations/deploy)。新完成的会话将自动评分；如需历史数据，可进行[回填](/zh/evaluations/deploy#score-sessions-you-already-have)。

![共享评估创作表单，你可以在其中描述一个固定答案的问题、查看草稿，并在测试后进行部署。图中示例为代码评估，Jev 问题使用相同的创作流程。](/images/dashboard/eval-authoring-draft.png)

助手可以在代码、Jev 分类和[裁判](/zh/evaluations/judge)之间进行选择。部署前请确认其选择。Jev 给出分数但不附带文字说明；如需解释，请选择裁判。请参阅 [Jev 评估参考文档](/zh/reference/jev-evaluations)了解问题类型和分数限制。

## 查看分数

打开 **Observe → Evaluations**，按代理和时间维度查看结果图表。在终端中，Cloud CLI 也可以读取相同的结果：

```bash
fp evals --since 7d
fp evals --aggregate --since 7d
```

Cloud CLI 用于读取结果，创作和部署均在控制台中完成。请参阅 [Cloud CLI 参考文档](/zh/reference/cloud-cli#evaluations)了解过滤器用法。
