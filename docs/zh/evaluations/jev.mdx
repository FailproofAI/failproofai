Jev 评估会读取**已完成的会话**，并给出 0 到 1 之间的分数。当答案已知时使用它，例如"客户是否表达了紧迫感？"或"客户的沮丧程度如何？"它帮助你发现多次运行中的规律；它不会阻止工具调用。对于在工具运行**之前**做出的决策，请使用 [Jev 策略](/zh/policies/jev)。

## 在仪表板中创建

1. 打开 **analyse → checks → new evaluation**，在 **how should it score?** 下选择 **decision model**。
2. 描述一个问题及其可能的答案。例如："在检查退款政策之前，客服是否承诺了退款？请回答是或否。"在 **review** 页面，检查**问题**以及 **yes means** 和 **no means** 的含义；decision model 始终会给出分数。
3. 在近期会话上[试用](/zh/evaluations/test)，然后[部署](/zh/evaluations/deploy)。新完成的会话将被评分；如果还需要历史数据，请[回填](/zh/evaluations/deploy#score-sessions-you-already-have)。

在起草时，failproofai 可以在**代码**、**decision model**（Jev）和 [**llm as judge**](/zh/evaluations/judge) 之间进行选择。在部署之前请检查其选择。Jev 给出分数但不提供文字说明；当需要解释时，请选择 judge。有关问题类型和分数限制，请参阅 [Jev 评估参考文档](/zh/reference/jev-evaluations)。

## 读取分数

打开 **analyse → checks → evals** 并选择评估，以按代理和时间维度查看结果图表。在终端中，Cloud CLI 可以读取相同的结果：

```bash
fp evals --since 7d
fp evals --aggregate --since 7d
```

在终端中，`fp evaluators` 用于创作和部署 Jev 评估，`fp evals` 用于读取其结果。两者的详细说明请参阅 [Cloud CLI 参考文档](/zh/reference/cloud-cli#evaluations)。
