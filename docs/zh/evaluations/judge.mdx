托管 Python 评估可以计数和比较：工具调用次数、错误次数、会话时长。但它无法判断答案是否*正确*、回复是否粗鲁，或智能体是否在执行操作前检查了策略。

**LLM 评判器**能做到这些。你用自然语言描述什么是好的结果，模型读取会话后返回一个 0 到 1 的分数，并附上推理说明。

<Note>
评判器每运行一个会话就消耗一次模型调用，而代码评估则完全免费。只有在需要*理解*对话内容时才使用评判器——并为其设置条件，使其只运行在真正相关的会话上。
</Note>

## 我该用哪种？

| 问题 | 使用 |
| --- | --- |
| 它是否调用了同一个工具两次？ | 代码 |
| 出现了多少个错误？ | 代码 |
| 会话是否在 30 秒内完成？ | 代码 |
| 客户是否表达了紧迫感？ | [分类器](/zh/evaluations/jev) |
| 客户有多沮丧？ | [分类器](/zh/evaluations/jev) |
| 答案实际上是否正确？ | **评判器** |
| 回复是否粗鲁或冷漠？ | **评判器** |
| 在承诺退款之前是否检查了退款政策？ | **评判器** |

经验法则：**可计数 → 代码，可提前列举的答案 → [分类器](/zh/evaluations/jev)，需要解释说明 → 评判器。** 评判器会以散文形式描述它所观察到的内容；当一个数字会让人追问"为什么"时，就应该使用它。

你不必提前做决定。描述你想要衡量的内容，助手会自动选择，然后告诉你选择了哪种方式以及原因。你可以随时切换。

## 创建评判器

1. 进入 **Analyze → eval authoring**，选择 **new eval**。
2. 描述你想要评判的内容，然后选择 **draft**。
3. 审查**标准**、**阈值**和**条件**，然后部署。

### 标准

一两句话，以要求而非问题的形式表述：

> 助手在未首先检查退款政策的情况下，不得承诺或批准退款。

具体说明什么情况会导致*不通过*。"回复好不好？"给你一个毫无意义的数字；而上面那句话给你一个可以据此采取行动的数字。

### 阈值

会话通过所需达到的最低分数。`0.7` 是一个合理的起点。完整的 0 到 1 分数始终会被存储，因此阈值仅决定通过/不通过——你可以查看分布情况并进行调整。

### 条件

与其他评估相同的 Python 条件，但这里它的作用更为关键。如果没有条件，评判器将在组织中的**每一个**会话上运行，每次都消耗一次模型调用：

```python
session.count("tool_use") > 0
```

```python
session.agent_id == "support-bot" and session.count("error") > 0
```

如果你在没有条件的情况下部署评判器，仪表盘会发出警告。有时这是合理的——比如你希望对低流量智能体进行完整评判——但这应该是有意为之，而非疏忽所致。

## 评判器看到什么

对话内容，按轮次呈现，若会话较长则最新内容优先展示：

- 用户说了什么
- 助手如何回复
- **智能体调用的每一个工具，以及该调用的返回结果，按顺序排列**

最后一点正是让"它是否在 Y *之前*执行了 X"成为合理问题的原因。失败的工具调用会显示为失败，因此"它是否从错误中优雅恢复"同样适用。

过长的会话会被截断以适应模型的上下文窗口。发生截断时，推理说明会明确指出——你永远不会看到基于部分会话做出的判断被伪装成基于完整会话的判断。

## 读取结果

评判器与其他评分评估一样产生**分数**，因此它同样支持图表展示、筛选和触发告警。除了数字之外，它还会存储评判器的**推理说明**——一段解释其所观察内容的文字。当分数出乎意料时，请先阅读这段说明；通常这要么说明这是一个确实值得关注的有趣会话，要么意味着标准需要进一步细化。

对于明确的情况，分数是稳定的，但并非逐位确定性的。将单个边界分数视为深入阅读该会话的提示，而非最终裁决。

## 限制

- **测试功能尚不可用。** 试运行没有对应的会话分配，而正是该分配授权使用你的模型预算——因此测试调用无法计费。请针对较窄的条件进行部署，并查看前几个结果。
- **回填功能不可用。** 对数月历史数据进行代码评估回填是免费的；而使用评判器进行回填则会在数分钟内耗尽你的全部预算。
- **编辑标准会发布新版本。** 新旧分数不可比较，因此它们会被分开保存，而不是混合在同一条趋势线中。
- **评判器始终产生分数**，不产生指标或断言。

## 预算耗尽时

评判器会消耗组织的模型预算。预算耗尽时，评判器评估会以明确的原因停止，而非静默失败，**代码评估则继续正常运行**。补充预算后，评判器将在下一个会话时恢复运行。
