托管的 Python 评估可以计数和比较：工具调用次数、错误数量、会话时长。但它无法判断答案是否*正确*、回复是否粗鲁，或者智能体在行动前是否检查了某项策略。

**LLM 评审**可以做到这些。你用自然语言描述好的标准，模型读取会话后返回 0 到 1 之间的分数及其推理过程。

<Note>
每次评审运行时都会消耗一次模型调用，而代码评估则不需要任何成本。仅在需要*理解*对话才能回答的问题时使用评审——并为其设置条件，使其只在相关会话上运行。
</Note>

## 我该选哪种？

| 问题 | 使用 |
| --- | --- |
| 是否两次调用了同一个工具？ | 代码 |
| 共有多少个错误？ | 代码 |
| 会话是否在 30 秒内完成？ | 代码 |
| 客户是否表达了紧迫感？ | [分类器](/zh/evaluations/jev) |
| 客户的沮丧程度如何？ | [分类器](/zh/evaluations/jev) |
| 答案是否真正正确？ | **评审** |
| 回复是否粗鲁或敷衍？ | **评审** |
| 在承诺退款之前是否检查了退款政策？ | **评审** |

经验法则：**可计数的 → 代码，可预先列举答案的 → [分类器](/zh/evaluations/jev)，需要解释的 → 评审。** 评审是那种会用文字描述所见内容的方式；当一个数字会让人追问"为什么"时，就应该使用评审。

你不必提前做决定。描述你想测量的内容，助手会自动选择，并告诉你它选择了哪种方式以及原因。你随时可以切换。

## 创建评审

1. 进入 **Analyze → eval authoring**，选择 **new eval**。
2. 描述你想评审的内容，选择 **draft**。
3. 审查**标准**、**阈值**和**条件**，然后部署。

### 标准

一到两句话，以要求而非问题的形式表述：

> 助手在未检查退款政策之前，不得承诺或批准退款。

明确说明什么情况会导致*不通过*。"回复是否良好？"只会给你一个毫无意义的数字；上面那句话则给你一个可以采取行动的依据。

### 阈值

会话在该分数及以上时视为通过。`0.7` 是一个合理的起始点。完整的 0 到 1 分数始终会被存储，因此阈值只决定通过或不通过——你可以查看分布情况并进行调整。

### 条件

与其他评估相同的 Python 条件，但这里更为重要。如果没有条件，评审将在你组织中的**每一个**会话上运行，每次都消耗一次模型调用：

```python
session.count("tool_use") > 0
```

```python
session.agent_id == "support-bot" and session.count("error") > 0
```

如果你部署了没有条件的评审，仪表板会发出警告。有时这是合理的——比如你希望对一个低流量智能体进行全面评审——但这应该是经过深思熟虑的决定，而不是意外疏忽。

## 评审所能看到的内容

对话内容按轮次呈现，如果会话较长则从最新的开始：

- 用户说了什么
- 助手如何回复
- **智能体调用的每个工具及其返回结果，按顺序排列**

最后一点正是使得"它是否在 Y 之前完成了 X"成为可以公平提问的原因。失败的工具调用会显示为失败，因此"它是否优雅地从错误中恢复"也是可以评审的问题。

非常长的会话会被截断以适应模型的上下文长度。当这种情况发生时，推理部分会明确说明——你永远不会看到基于部分会话的判断被当作基于完整会话的判断呈现。

## 解读结果

评审与其他评分评估一样产生**分数**，因此可以以相同方式生成图表、进行筛选和触发警报。除分数外，它还会存储评审的**推理**——即描述其所见内容的段落。当某个分数让你感到意外时，应该先阅读这段推理；通常这要么是一个真正有价值的会话，要么是标准需要进一步细化的信号。

对于明确的情况，分数是稳定的，但并非逐位确定性的。将单个边界分数视为一个提示，去读读那个会话，而不是将其视为最终判决。

## 限制

- **测试功能暂不可用。** 试运行没有背后的会话分配，而正是这个分配授权使用你的模型预算——因此测试调用没有可计费的对象。请针对较窄的条件进行部署，并查看最初几个结果。
- **回填功能不可用。** 对数月历史数据进行代码评估的回填是免费的；但使用评审进行回填会在几分钟内耗尽你的全部预算。
- **编辑标准会发布新版本。** 新旧分数不具可比性，因此它们会被分开存储，而不是混合在同一条趋势线中。
- **评审始终产生分数**，而不是指标或断言。

## 预算耗尽时

评审会消耗你组织的模型预算。当预算耗尽时，评审评估会以明确的原因停止，而不是静默失败，**代码评估则继续正常运行**。充值预算后，评审将在下一个会话时恢复。
