托管的 Python 评估可以计数和比较：调用了多少次工具、发生了多少错误、一次会话持续了多长时间。但它无法判断答案是否*正确*、回复是否粗鲁，或者智能体在行动前是否检查了相关策略。

**LLM 裁判**可以做到这些。你用自然语言描述什么是好的，模型会阅读会话并返回一个 0 到 1 的分数，同时附上推理过程。

<Note>
裁判对每个运行的会话消耗一次模型调用，而代码评估则不需要任何费用。只在需要*理解*对话的问题上使用裁判——并为其设置条件，让它仅在相关的会话上运行。
</Note>

## 我应该选哪种？

| 问题 | 使用 |
| --- | --- |
| 它是否两次调用了同一个工具？ | 代码 |
| 发生了多少错误？ | 代码 |
| 会话是否在 30 秒内完成？ | 代码 |
| 客户是否表达了紧迫感？ | [分类器](/zh/evaluations/jev) |
| 客户有多沮丧？ | [分类器](/zh/evaluations/jev) |
| 答案是否真的正确？ | **裁判** |
| 回复是否粗鲁或敷衍？ | **裁判** |
| 它在承诺退款前是否检查了退款政策？ | **裁判** |

经验法则：**可计数的 → 代码，可提前列出的答案 → [分类器](/zh/evaluations/jev)，需要解释的 → 裁判。** 裁判会对它所看到的内容写出说明文字；当数字本身会让人追问"为什么"时，就选用裁判。

你不必提前做决定。描述你想要衡量的内容，助手会自动选择，并告诉你它选了哪种以及原因。你可以随时切换。

## 创建一个裁判

1. 前往 **Analyze → eval authoring**，选择 **new eval**。
2. 描述你想要评判的内容，然后选择 **draft**。
3. 检查**标准**、**阈值**和**条件**，然后部署。

### 标准

一到两句话，以要求的形式而非问题的形式撰写：

> 助手在未先检查退款政策的情况下，不得承诺或批准退款。

具体说明什么情况会导致*失败*。"回复是否足够好？"这样的问题只会给你一个毫无意义的数字；而上面那句话给出的数字是你可以采取行动的依据。

### 阈值

会话通过所需的最低分数。`0.7` 是一个合理的起点。完整的 0 到 1 分数始终会被存储，因此阈值仅决定通过/失败——你可以查看分布情况并进行调整。

### 条件

与其他评估相同的 Python 条件，在这里它的重要性更为突出。如果不设置条件，裁判将对你组织中的**每一个**会话运行，每次消耗一次模型调用：

```python
session.count("tool_use") > 0
```

```python
session.agent_id == "support-bot" and session.count("error") > 0
```

如果你部署了一个没有条件的裁判，仪表盘会发出警告。有时这样做是合理的——比如一个你希望全面评判的低流量智能体——但这应该是有意为之，而不是疏忽大意。

## 裁判看到的内容

以轮次形式呈现的对话，如果会话较长则按最新在前的顺序排列：

- 用户说了什么
- 助手如何回复
- **智能体调用的每个工具以及该调用的返回结果，按顺序排列**

最后一点正是使"它是否在 Y *之前*做了 X"成为合理问题的关键。失败的工具调用会显示为失败状态，因此"它是否从错误中优雅地恢复"同样是可以问的问题。

非常长的会话会被截断以适应模型的上下文窗口。发生这种情况时，推理内容会明确说明——你不会看到基于部分会话的判断被当作基于完整会话的判断呈现出来。

## 阅读结果

裁判像其他评分评估一样产生一个**分数**，因此它同样可以在图表中展示、被筛选，以及触发告警。除了数字之外，它还存储了裁判的**推理**——一段解释其所见内容的文字。当某个分数令你意外时，先读这段推理；通常要么是一个真正值得关注的有趣会话，要么是标准需要进一步细化的信号。

对于明确的案例，分数是稳定的，但并非逐位确定性的。将单个边界分数视为去阅读该会话的提示，而非最终裁决。

## 限制

- **暂不支持测试。** 预演运行没有背后的会话分配，而正是这个分配授权了模型预算的消耗——因此测试调用没有可计费的对象。请针对较窄的条件进行部署，并阅读最初几个结果。
- **不支持回填。** 对数月的历史记录进行代码评估回填是免费的；用裁判来做则会在几分钟内耗尽你的全部预算。
- **编辑标准会发布新版本。** 旧分数和新分数不可比较，因此它们会被分开存储，而不是混入同一条趋势线中。
- **裁判始终产生分数**，不产生指标或断言。

## 预算耗尽时

裁判会消耗你组织的模型预算。当预算耗尽时，裁判评估会以明确的原因停止，而不是静默失败，**代码评估则继续正常运行**。补充预算后，裁判将在下一个会话时恢复运行。
