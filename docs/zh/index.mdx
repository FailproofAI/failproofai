Failproof AI 帮助团队了解 agent 的行为、找出失败原因，并在同样的问题再次发生之前部署防护措施。

**运行环境（harness）** 是指 agent 实际运行所在的容器或框架。Failproof AI 支持接入其中 12 种——包括 Claude Code、Codex 等编码 CLI，Hermes 等聊天网关，OpenClaw 等自托管助手——所有环境共享相同的事件、策略和会话历史。没有运行环境的 agent 可通过 [Python SDK](/zh/reference/custom-agents) 接入，该 SDK 提供追踪与审计功能；若要在该环境中执行策略，则需要在你自己的运行时中添加 hook。

> **会话 → 审计 → 发现 → Issue → 策略**<br />
> 追踪发生了什么，找出失败原因，管理应对措施，然后防止相同行为在后续运行中重现。

## 从这里开始

如果你正在部署第一个插桩 agent，请从[快速入门](/zh/start/quickstart)开始。如果数据已经在上报，请打开[会话（Sessions）](/zh/sessions/overview)页面，先检查一次真实的运行记录，再配置审计或策略。
