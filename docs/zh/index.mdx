Failproof AI 帮助团队了解智能体的行为，找出失败的原因，并在同样的问题再次发生之前部署防护措施。

<Columns cols={2}>
  <Card title="配置 Failproof" icon="wand-sparkles" href="/zh/start/quickstart">
    使用技能对你的项目进行埋点、连接并验证智能体日志是否成功接收。
  </Card>
  <Card title="使用 Failproof 助手" icon="message-square-text" href="/zh/sessions/assistant">
    用自然语言分析、查询、构建仪表盘，并对智能体日志进行审计。
  </Card>
</Columns>

<Columns cols={3}>
  <Card title="查看智能体的行为" icon="route" href="/zh/sessions/overview">
    在一个会话中追踪模型调用、工具使用、错误、用户输入、延迟及策略决策。
  </Card>
  <Card title="系统化地发现故障" icon="scan-search" href="/zh/audits/overview">
    对一组指定会话进行审计，查看有据可查的发现，并将其作为问题追踪修复进度。
  </Card>
  <Card title="防止问题复现" icon="shield-check" href="/zh/policies/overview">
    将已知的失败模式转化为策略，观察其效果，并在整个部署环境中推广。
  </Card>
</Columns>

> **会话 → 审计 → 发现 → 问题 → 策略**<br />
> 追踪发生了什么，找到失败原因，管理应对措施，然后防止同样的行为在未来再次出现。

## 从这里开始

如果你正在部署第一个自定义智能体，请从[快速开始](/zh/start/quickstart)入手。如果数据已经开始接收，请打开[会话](/zh/sessions/overview)并检查一次真实运行记录，然后再配置审计或策略。
