Failproof AI 帮助所有运行 Agent 的人了解发生了什么、发现故障，并防止其重复出现。

它支持 12 种常见的 Agent 环境，包括 Claude Code、Codex、Hermes、OpenClaw 和 Goose。基于 LangChain、CrewAI、LlamaIndex、Pydantic AI 或你自己的运行时构建的 Agent，可以通过 [Python SDK](/zh/reference/custom-agents) 接入上报。

## 本地启动或连接云端

<Columns cols={2}>
  <Card title="本地模式，无需账号" icon="laptop" href="/zh/audits/local-audit">
    在 `localhost:8020` 打开仪表盘，运行 `failproofai audit`。你的 Agent 历史记录保留在本机。
  </Card>
  <Card title="Failproof AI Cloud" icon="cloud" href="/zh/start/setup">
    跨机器查看会话，并为你的团队管理策略。
  </Card>
</Columns>

默认设置不会选择任何策略包。完成设置后可添加我们的策略包：

```bash
failproofai policies add FailproofAI/policies
```

在此之前，只有 `block-failproofai-commands` 处于运行状态，它会阻止 Agent 禁用 Failproof AI。
