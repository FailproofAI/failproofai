Failproof AI 帮助团队了解 agent 的行为、找出失败原因，并在同样的问题再次发生前部署防护措施。

**harness** 是 agent 实际运行的环境。Failproof AI 支持接入其中 12 种——包括 Claude Code 和 Codex 等编码 CLI、Hermes 等聊天网关、OpenClaw 等自托管助手——所有事件、策略和会话历史对每种环境一视同仁。没有 harness 的 agent 可通过 [Python SDK](/zh/reference/python-sdk) 上报，该 SDK 提供追踪与审计能力；在自有运行时中执行策略则需要在你的代码中添加 hook。

> **会话 → 审计 → 发现 → Issue → 策略**<br />
> 追踪发生了什么，找出故障，管理响应，然后防止同样的行为在未来的运行中重现。

如果你正在部署第一个插桩 agent，请从 [快速入门](/zh/start/quickstart) 开始。如果数据已经在上报，请打开 [Sessions](/zh/sessions/overview)，先检查一次真实运行，再配置审计或策略。
