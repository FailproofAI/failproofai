Failproof AI 帮助团队了解智能体的行为、定位故障发生的位置，并在相同行为再次出现之前部署防护措施。

<Columns cols={2}>
  <Card title="配置 Failproof" icon="wand-sparkles" href="/zh/start/quickstart">
    使用该技能对项目进行插桩、完成连接，并验证智能体日志是否正常送达。
  </Card>
  <Card title="使用 Failproof 助手" icon="message-square-text" href="/zh/sessions/assistant">
    用自然语言对智能体日志进行分析、查询、构建仪表盘和执行审计。
  </Card>
</Columns>

<Columns cols={3}>
  <Card title="查看智能体的操作记录" icon="route" href="/zh/sessions/overview">
    在单个会话中追踪模型调用、工具使用、错误、人工输入、延迟及策略决策。
  </Card>
  <Card title="系统性地发现故障" icon="scan-search" href="/zh/audits/overview">
    对指定的会话集合进行审计，查看有据可查的发现，并以问题形式跟踪修复进展。
  </Card>
  <Card title="防止故障重演" icon="shield-check" href="/zh/policies/overview">
    将已知的故障模式转化为策略，观察其效果，并在整个系统中统一部署。
  </Card>

> **会话 → 审计 → 发现 → 问题 → 策略**<br />
> 追踪已发生的事情，定位故障，管理应对措施，然后在未来的运行中防止相同行为再次出现。

## 从这里开始

如果你正在部署第一个已插桩的智能体，请从[快速入门](/zh/start/quickstart)开始。如果数据已经开始接收，请打开[会话](/zh/sessions/overview)页面，先查看一次真实的运行记录，再配置审计或策略。
