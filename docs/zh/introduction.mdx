专为 **AI 故障处理**、**错误恢复** 和 **LLM 可靠性** 设计的 Hooks 与策略。让你的 AI 智能体在 **Claude Code**、**OpenAI Codex**、**GitHub Copilot**、**Cursor Agent**、**OpenCode**、**Pi**、**Hermes**、**OpenClaw**、**Factory Droid**、**Devin CLI**、**Antigravity CLI** 以及 **Agents SDK** 上稳定运行、自主执行。

AI 智能体的失败方式往往是可以预见的——执行破坏性命令、泄露密钥、偏离任务、陷入循环，或直接推送到主分支。一旦无人看管，小问题就会滚雪球般演变为服务中断、凭证泄露和数据丢失。

FailproofAI 通过**策略**解决这一问题。这些规则介入每一次智能体工具调用，**检测故障**、**采取缓解措施**（block、instruct、sanitize），并在需要关注时**及时提醒你**。本地仪表盘让你可以事后回溯每一次工具调用、智能体故障和恢复操作。

所有对话记录和策略评估结果均保留在本地机器上。只有在你明确使用在线功能时（例如已认证的审计提醒或邀请功能），数据才会被发送出去。

## 快速开始

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # enable policies (or skip — `failproofai` will offer to set them up on first run)
failproofai                      # launch the dashboard
```

完整操作流程请参阅[入门指南](/zh/getting-started)。
