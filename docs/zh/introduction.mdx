用于 **AI 故障处理**、**错误恢复**和 **LLM 可靠性**的 Hooks 与策略。让您的 AI 智能体在 **Claude Code**、**OpenAI Codex**、**GitHub Copilot**、**Cursor Agent**、**OpenCode**、**Pi**、**Hermes**、**OpenClaw**、**Factory Droid**、**Devin CLI**、**Antigravity CLI** 以及 **Agents SDK** 上保持稳定、自主运行。

AI 智能体的失效方式是可以预见的：执行破坏性命令、泄露密钥、偏离任务目标、陷入循环，或直接推送到主分支。一旦无人看管，小故障就会接连引发服务中断、凭证泄露和数据丢失。

FailproofAI 通过**策略**来解决这些问题。这些规则挂钩到每一次智能体工具调用，负责**检测故障**、**进行缓解**（阻止、指令纠正、数据脱敏），并在需要关注时**及时提醒您**。本地仪表盘让您事后可以查看每一次工具调用、智能体故障及恢复操作。

对话记录和策略评估均保存在本地。只有在您明确使用在线功能（例如经身份验证的审计提醒或邀请）时，才会发送数据。

## 快速开始

<CodeGroup>

```bash npm
npm install -g failproofai
```

```bash bun
bun add -g failproofai
```

</CodeGroup>

```bash
failproofai policies --install   # enable policies (or skip — `failproofai` will offer to set them up on first run)
failproofai                      # launch the dashboard
```

完整操作流程请参阅[快速入门](/zh/getting-started)指南。
