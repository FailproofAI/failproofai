Fleet 覆盖率会对比 Cloud 分配的内容与每台机器上次应用的内容。

## 检查机器状态

```bash
failproofai config --status
failproofai flush --wait --timeout 120
```

从 Cloud 端执行：

```bash
fp fleet list
fp fleet diff
fp fleet show <machine-id>
```

`fp fleet` 需要已登录的会话，而非 API 密钥。

| 命令 | 功能说明 |
| --- | --- |
| `fp fleet list` | 列出机器及其部署状态 |
| `fp fleet show <machine>` | 显示某台机器的策略集 |
| `fp fleet deploy <machine> --add <ref>` | 添加或更新单条策略 |
| `fp fleet deploy <machine> --remove <id>` | 移除单条策略 |
| `fp fleet deploy <machine> --set <ref>...` | 替换整个策略集 |
| `fp fleet diff [machine]` | 对比预期版本与已应用版本 |
| `fp fleet history <machine>` | 列出部署历史版本 |
| `fp fleet rollback <machine> <generation>` | 还原到指定历史版本 |
| `fp fleet rename <machine> "<label>"` | 修改 Cloud 中的显示标签 |

<Warning>
  `--set` 会替换完整的策略集。单独使用 `--add <id>` 会立即强制执行新策略。如需灰度发布，请使用 `--add <id>:observe`。
</Warning>

## 先观察，再强制执行

```bash
fp fleet deploy ci-runner-01 --add prod-guard:observe
fp guardrails summary --since 24h --machine ci-runner-01
fp fleet deploy ci-runner-01 --add prod-guard:enforce
```

观察模式会评估实际策略并记录非 allow 决策，但不会阻断 Agent 的执行。

## 机器标识

机器 ID 是固定不变的，用于唯一标识该机器。标签仅用于显示，可以随时更改：

```bash
failproofai config --machine-label checkout-runner-03
fp fleet rename <machine-id> "Checkout runner 03"
```

修改标签不会重新连接机器或重置其密钥。
