使用 scope 来决定本地策略应用于哪些对象：

| Scope | 应用于 |
| --- | --- |
| `user` | 本机上所有受支持的 Agent |
| `project` | 在当前项目中运行的 Agent |
| `local` | 仅 Claude，位于本地项目设置中 |
| `all` | 仅用于卸载 |

```bash
failproofai policies add block-sudo --scope user
failproofai policies add block-rm-rf --scope project
```

Hermes 和 OpenClaw 仅支持 user scope。大多数其他 harness 支持 user 和 project。Claude 还支持 local scope。详见 [Harnesses](/zh/reference/harnesses)。

## 策略参数

策略设置存储在对应 scope 下的 `policies-config.json` 中。建议尽量使用本地控制台的 **Policies → Configure** 视图进行配置。

参数归属于某一条策略，用于改变该策略的判断逻辑。例如，一个允许列表可以让拦截型策略放行已知安全的命令或路径。

自定义策略文件可以从 `.failproofai/policies/` 自动加载，也可以显式指定：

```bash
failproofai policies -i -c ./guards.mjs --scope project
```

移除显式路径：

```bash
failproofai policies -u -c
```

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `~/.failproofai/config.json` | 机器及数据收集器设置 |
| `policies-config.json` | 某个 scope 下已启用的策略及其参数 |
| `.failproofai/policies/*policies.mjs` | 按约定自动加载的策略文件 |
| `~/.failproofai/policies/packs/installed.json` | 已安装的策略包及其选择项 |

请勿直接编辑已安装策略包的产物文件。如需修改，请重新安装或发布修正版本。
