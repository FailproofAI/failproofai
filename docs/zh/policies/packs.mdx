策略包是以公开 GitHub Release 形式发布的版本化策略集合。该软件包本身不附带任何策略包；你可以像安装其他包一样安装我们的策略包：

```bash
failproofai policies show FailproofAI/policies
failproofai policies add FailproofAI/policies
```

`show` 命令会读取清单文件，但不会执行包中的代码。

## 选择要安装的内容

```bash
failproofai policies add owner/repo --policy block-refunds
failproofai policies add owner/repo --category billing,git
failproofai policies add owner/repo --all
```

若未指定选项，将使用发布者的默认配置。重新添加较新版本时，会保留你当前的选择。

包含斜杠的内容视为包来源，不含斜杠的内容视为策略名称。

## 锁定版本

| 来源 | 结果 |
| --- | --- |
| `owner/repo` | 最新 Release，解析后锁定 |
| `owner/repo@a1b2c3d4e5f6` | 基于精确 commit 的 Release |
| `owner/repo@v2.1.0` | 精确命名的 Release |
| GitHub Release URL | 该 URL 对应的 Release |

策略包通常使用构建时的 12 位 commit SHA 标识。使用 `failproofai policies show owner/repo --releases` 可查看 Release 顺序。

## 管理已安装的包

```bash
failproofai policies
failproofai policies remove block-refunds
failproofai policies add block-refunds
failproofai policies remove owner/repo
```

若两个已安装的策略包包含同名策略，CLI 将拒绝使用该模糊的裸名称。请通过指定包名来选择策略，或卸载其中一个包。

## 安全性与可用性

每个 Release 包含清单文件、打包后的策略代码以及校验和。Failproof AI 在加载前会验证记录的摘要。校验和证明字节内容与 Release 一致，但不证明发布者身份。

若已选中的策略包无法加载，则对其声明的事件采取关闭失败策略。详见[策略失败行为](/zh/policies/failure-behavior)。

| 变量 | 作用 |
| --- | --- |
| `FAILPROOFAI_NO_DOWNLOAD=1` | 拒绝新的下载；已安装的包继续运行 |
| `FAILPROOFAI_PACK_BASE_URL` | 使用镜像源 |
| `FAILPROOFAI_PACK_DIR` | 更改包存储目录 |

在 [Policy Hub](https://befailproof.ai/policy-hub/) 中浏览策略包，或[发布你自己的策略包](/zh/policies/publish-a-pack)。
