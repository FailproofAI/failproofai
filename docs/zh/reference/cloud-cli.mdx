使用 `fp` 检查 Cloud 遥测数据、管理云端执行策略（策略、机群部署、护栏决策），以及管理审计、发现项、问题、告警、密钥、用户、查询和设置。使用 [`failproofai`](/zh/reference/failproof-cli) 处理本地钩子、策略、捕获和机器注册。

以独立工具方式安装已发布的 Cloud CLI：

```bash
uv tool install fp-cloud-cli
fp version
```

## 登录

```bash
fp login
fp whoami
```

## 语法

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

全局选项必须放在命令之前：

```bash
fp --json sessions --since 24h
```

运行 `fp COMMAND --help` 或 `fp COMMAND SUBCOMMAND --help` 查看终端帮助。

### 事件

```text
fp events [OPTIONS]
```

列出单个 Agent 事件。默认轻量数据流不包含原始载荷；仅在有限范围的调查中使用 `--full`。

| 选项 | 描述 |
| --- | --- |
| `--limit`, `-n <n>` | 最大总行数。默认值：`50`。 |
| `--since <window>` | `all`、`15m`、`1h`、`6h`、`24h` 或 `7d`。 |
| `--from <timestamp>` / `--to <timestamp>` | ISO 8601 UTC 时间范围；覆盖 `--since`。 |
| `--env <value>` | 环境过滤器；可重复或以逗号分隔多个值。 |
| `--event-type <value>` | 事件类型过滤器；可重复或以逗号分隔多个值。 |
| `--agent-id <value>` | Agent 过滤器；可重复或以逗号分隔多个值。 |
| `--session-id <value>` | 会话过滤器；可重复或以逗号分隔多个值。 |
| `--search <text>` | 载荷文本搜索；可重复，任意词条匹配即可。 |
| `--order asc\|desc` | 时间排序。默认：最新优先。 |
| `--all` | 自动分页，最多获取 `--limit` 条数据。 |
| `--cursor <token>` | 从不透明游标处继续。 |
| `--page-size <n>` | 使用 `--all` 时每次请求的行数；最大 `200`。 |
| `--full` | 通过较重的事件端点包含原始载荷。 |
| `--fields <csv>` | 仅返回选定字段；请求 `payload` 时启用完整模式。 |

```bash
fp events --session-id <session-id> --order asc --all --limit 10000
fp --json events --full --session-id <session-id> --all --limit 10000
```

<Note>
  `--all` 分页获取的数据**最多不超过 `--limit`**，该值默认为 **50** — 因此单独使用 `--all` 会在 50 行时停止。提前停止时，响应中会携带 `next_cursor` 以供继续获取；`"next_cursor": null` 表示数据流已真正耗尽。
</Note>

#### 审计创建选项

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| 选项 | 描述 |
| --- | --- |
| `--file <path>` | 基于 JSON 定义，或使用 `-` 从 stdin 读取。显式标志覆盖文件中的值。 |
| `--description <text>` | 说明故障问题或目的。 |
| `--enabled` / `--disabled` | 启动时开启或关闭调度。默认：启用。 |
| `--schedule-interval-secs <n>` | `3600`–`604800`。默认值：`86400`。 |
| `--schedule-anchor <timestamp>` | ISO 8601 格式的固定 UTC 相位。默认：下一个 09:00 UTC。 |
| `--window-mode since_last\|fixed` | 从上次完整分析窗口后继续，或反复检查滚动窗口。默认：`since_last`。 |
| `--lookback-window-secs <n>` | `3600`–`7776000`。默认值：`604800`。 |
| `--scope '<json>'` | 按 `environments`、`agent_ids` 或其他支持的范围字段过滤。 |
| `--ignore-error-type <type>` | 排除错误类型；可重复或以逗号分隔。 |
| `--llm` / `--no-llm` | 启用或禁用 Agentic 分析。默认：启用。 |
| `--top-k <n>` | 保留 `1`–`500` 条发现项。默认值：`50`。 |
| `--sensitivity low\|medium\|high` | 设置报告敏感度。默认：`medium`。 |
| `--channels '<json>'` | 通知渠道数组。 |
| `--text <brief>` | 内联简报，最多 8,192 个字符。 |
| `--text-file <path>` | 从文件读取简报；与 `--text` 互斥。 |
| `--url <https-url>` | 添加公开 HTTPS 参考链接；最多重复五次。 |

首次运行需要上下文时，请在创建时一并提供。创建操作会在排队运行开始前将定义和上下文一起提交。

<Note>
  `fp audits run` 是异步操作。在读取发现项之前，请轮询 `fp audits runs NAME`，直到最新一次运行成功或失败。
</Note>

### 策略

云端管理的策略版本。**仅限会话** — 此处每个命令在 API 密钥下都会在发起任何请求之前以退出码 `2` 退出，因为这些是根专属写入路由，故意不在 `/v1` 中暴露。

| 命令 | 用途 | 选项 |
| --- | --- | --- |
| `fp policies list` | 列出策略版本。 | `--json` |
| `fp policies show POLICY_ID` | 显示一个策略及其源代码。 | — |
| `fp policies publish NAME PATH` | 从本地 `.mjs` 文件铸造一个版本。 | `--description`; `--no-verify` |
| `fp policies enable POLICY_ID` | 将其重新添加到所有已移除它的部署中，每次都铸造新的生成版本。 | `--yes`, `-y` |
| `fp policies disable POLICY_ID` | 从所有携带它的部署中移除，每次都铸造新的生成版本。 | `--yes`, `-y` |
| `fp policies delete POLICY_ID` | 删除策略版本。 | `--yes`, `-y` |
| `fp policies test PATH` | 针对合成上下文在本地运行策略。应用每个策略的 `match` 过滤器，因此不覆盖给定事件/工具的策略将报告为 `skipped` 而非运行。 | `--event`; `--tool`; `--command`; `--file-path`; `--expect` |
| `fp policies compose PROMPT` | 使用助手草拟策略。需要 `policies:write` 权限。 | — |

| `--token <token>` | 覆盖已保存的用户会话令牌。 |
| `--api-key <key>` | 使用 API 密钥对自动化进行身份验证；不会被保存。 |
| `--timeout <seconds>` | HTTP 超时；必须为正数。默认值：`30`。 |
| `--quiet`, `-q` | 抑制 stderr 的状态输出。 |
| `--no-color` | 禁用彩色输出。 |
| `--insecure` / `--secure` | 禁用或恢复 TLS 证书验证。 |
| `--version` | 打印版本信息并退出。 |
| `--help`, `-h` | 显示帮助。 |

`--api-key` 用于自动化场景。登录、切换组织和助手命令需要用户会话。

## 环境变量

| 变量 | 等效选项或用途 |
| --- | --- |
| `FP_DASHBOARD_URL` | `--base-url` |
| `FP_ORG` | `--org` |
| `FP_TOKEN` | `--token` |
| `FP_API_KEY` | `--api-key` |
| `FP_JSON` | `--json` |
| `FP_INSECURE` | `--insecure` |
| `FP_HOME` | 重定位 CLI 配置目录（默认 `~/.failproofai/fpcli`）。 |
| `FP_ANALYTICS_DISABLED` 或 `DO_NOT_TRACK` | 禁用匿名 CLI 分析。 |
| `NO_COLOR` | 禁用彩色输出。 |

显式标志优先于环境变量，环境变量优先于已保存的配置。在 API 密钥模式下，请使用 `--org` 或 `FP_ORG` 显式选择租户。

<Warning>
  这些变量的 `AGENTEYE_*` 写法**不会被 `fp` 读取**，从来如此 — CLI 声明的是 `FP_*`（`fp_cli/app.py`），未知变量不会报错。设置 `AGENTEYE_DASHBOARD_URL` 不会重定向 CLI；它会被忽略，命令将静默地对已保存的仪表板执行。

  `AGENTEYE_HOME` 和 `AGENTEYE_ENVIRONMENT` 确实仍然存在，但它们属于**收集器和遥测 SDK**，而非本 CLI。
</Warning>

<Warning>
  删除、吊销、抑制、解决或替换配置的命令默认会提示确认。请在验证当前活跃组织和目标后再使用 `--yes`。
</Warning>
