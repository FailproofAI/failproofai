使用 `fp` 检查云端遥测数据，管理审计、发现项、问题、告警、密钥、用户、查询和设置。使用 [`failproofai`](/zh/reference/failproof-cli) 处理本地钩子、策略、捕获和机器注册。

以隔离工具的方式安装已发布的 Cloud CLI：

```bash
uv tool install fp-cli
fp version
```

## 登录

```bash
fp login
fp whoami
```

## 语法

```text
fp [GLOBAL_OPTIONS] COMMAND [SUBCOMMAND] [ARGUMENTS] [OPTIONS]
```

全局选项必须位于命令之前：

```bash
fp --json sessions --since 24h
```

运行 `fp COMMAND --help` 或 `fp COMMAND SUBCOMMAND --help` 获取终端帮助。

### 事件

```text
fp events [OPTIONS]
```

列出各个 Agent 事件。默认轻量数据流不包含原始载荷；仅在有边界的调查中使用 `--full`。

| 选项 | 说明 |
| --- | --- |
| `--limit`, `-n <n>` | 最大总行数。默认：`50`。 |
| `--since <window>` | `all`、`15m`、`1h`、`6h`、`24h` 或 `7d`。 |
| `--from <timestamp>` / `--to <timestamp>` | ISO 8601 UTC 时间范围；覆盖 `--since`。 |
| `--env <value>` | 环境过滤器；可重复或以逗号分隔多个值。 |
| `--event-type <value>` | 事件类型过滤器；可重复或以逗号分隔多个值。 |
| `--agent-id <value>` | Agent 过滤器；可重复或以逗号分隔多个值。 |
| `--session-id <value>` | 会话过滤器；可重复或以逗号分隔多个值。 |
| `--search <text>` | 载荷文本搜索；可重复，任意词匹配。 |
| `--order asc\|desc` | 时间排序。默认：最新优先。 |
| `--all` | 自动分页，最多 `--limit` 条。 |
| `--cursor <token>` | 从不透明游标处继续。 |
| `--page-size <n>` | 配合 `--all` 时每次请求的行数；最大 `200`。 |
| `--full` | 通过更重量级的事件端点包含原始载荷。 |
| `--fields <csv>` | 仅返回选定字段；请求 `payload` 会启用完整模式。 |

```bash
fp events --session-id <session-id> --order asc --all
fp --json events --full --session-id <session-id> --all
```

#### 审计创建选项

```bash
fp audits create checkout-reliability \
  --description "Find checkout failures that agents do not recover from" \
  --scope '{"environments":["production"],"agent_ids":["checkout-agent"]}' \
  --schedule-interval-secs 86400 \
  --window-mode since_last \
  --sensitivity medium \
  --text-file ./checkout-audit-brief.txt \
  --url https://runbooks.example.com/checkout
```

| 选项 | 说明 |
| --- | --- |
| `--file <path>` | 基于 JSON 定义，或使用 `-` 从 stdin 读取。显式标志会覆盖文件中的值。 |
| `--description <text>` | 说明失败问题或目的。 |
| `--enabled` / `--disabled` | 启动时是否开启调度。默认：启用。 |
| `--schedule-interval-secs <n>` | `3600`–`604800`。默认：`86400`。 |
| `--schedule-anchor <timestamp>` | ISO 8601 格式的固定 UTC 时间基准。默认：下一个 09:00 UTC。 |
| `--window-mode since_last\|fixed` | 从上次完整分析的窗口后继续，或反复检查滚动窗口。默认：`since_last`。 |
| `--lookback-window-secs <n>` | `3600`–`7776000`。默认：`604800`。 |
| `--scope '<json>'` | 按 `environments`、`agent_ids` 或其他支持的范围字段过滤。 |
| `--ignore-error-type <type>` | 排除错误类型；可重复或以逗号分隔。 |
| `--llm` / `--no-llm` | 启用或禁用智能体分析。默认：启用。 |
| `--top-k <n>` | 保留 `1`–`500` 个发现项。默认：`50`。 |
| `--sensitivity low\|medium\|high` | 设置报告灵敏度。默认：`medium`。 |
| `--channels '<json>'` | 通知渠道数组。 |
| `--text <brief>` | 内联简介，最多 8,192 个字符。 |
| `--text-file <path>` | 从文件读取简介；与 `--text` 互斥。 |
| `--url <https-url>` | 添加公开 HTTPS 参考链接；最多重复五次。 |

在创建时包含上下文，以便首次运行可以使用它。创建操作会在排队运行开始之前将定义和上下文一并提交。

<Note>
  `fp audits run` 是异步操作。请轮询 `fp audits runs NAME`，等待最新一次运行成功或失败后再读取其发现项。
</Note>

## 全局标志

| 标志 | 说明 |
| --- | --- |
| `--json` | 输出机器可读的 JSON。 |
| `--base-url <url>` | 使用自托管或开发环境的控制台。 |
| `--org <slug>` | 为本次调用选择组织。 |
| `--token <token>` | 覆盖已保存的用户会话令牌。 |
| `--api-key <key>` | 使用 API 密钥进行自动化身份验证；不会被保存。 |
| `--timeout <seconds>` | HTTP 超时时间；必须为正数。默认：`30`。 |
| `--quiet`, `-q` | 抑制 stderr 上的状态输出。 |
| `--no-color` | 禁用彩色输出。 |
| `--insecure` / `--secure` | 禁用或恢复 TLS 证书验证。 |
| `--version` | 打印版本号并退出。 |
| `--help`, `-h` | 显示帮助。 |

`--api-key` 适用于自动化场景。登录、组织切换和助手命令需要用户会话。

<Warning>
  执行删除、吊销、抑制、解决或替换配置的命令默认会提示确认。请在验证活跃组织和目标之后再使用 `--yes`。
</Warning>
