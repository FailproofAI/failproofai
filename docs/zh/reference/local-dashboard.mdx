不带参数运行 `failproofai` 即可在 `http://localhost:8020` 启动内置仪表板。它直接从本机读取本地代理历史记录、策略配置、审计结果和钩子活动。

本地仪表板与 Failproof AI Cloud 相互独立。无需 Cloud 账户即可使用，且无法证明事件已传递至您的组织。

## 仪表板区域

| 区域 | 可执行的操作 |
| --- | --- |
| Policies → Activity | 检查本地 allow、instruct 和 deny 决策；按决策、事件、CLI、工具、来源、策略和会话进行筛选。 |
| Policies → Configure | 启用内置策略、编辑支持的参数、切换已发现的自定义策略，以及选择目标测试环境。 |
| Projects | 浏览所有受支持代理历史记录中已发现的项目，并比较其最近的会话。 |
| Project sessions | 打开一个本地转录文件，查看原始有序条目和子代理，下载文件，并关联策略活动。 |
| Audit | 查看最近一次离线扫描结果、风险模式、优势、受影响项目以及建议的内置策略。 |
| Settings | 在守护进程/平台支持的情况下，配置计划本地扫描和通过电子邮件发送审计报告。 |

## 查看策略活动

<Tabs>
  <Tab title="Dashboard">
    1. 打开 **Policies → Activity**，设置决策和来源筛选条件。
    2. 按事件、测试环境、工具或策略名称进一步缩小范围。
    3. 展开某一行以检查其原因、匹配的策略、来源、执行模式和持续时间。
    4. 点击会话链接，在转录上下文中查看该决策的位置。

    对于不支持阻断裁决的测试环境/事件对，看起来被拒绝的行仍可能只是观察性的。详情视图会标注已验证的强制执行能力。
  </Tab>
  <Tab title="CLI">
    ```bash
    failproofai config --status
    failproofai policies
    failproofai
    ```

    本地活动存储在 `~/.failproofai/hook-activity` 目录下。请使用仪表板，而非直接编辑这些文件。
  </Tab>
</Tabs>

## 本地配置策略

<Tabs>
  <Tab title="Dashboard">
    1. 打开 **Policies → Configure**，选择测试环境和配置范围。
    2. 启用内置策略或已发现的自定义策略。
    3. 对于带参数的内置策略，打开其配置控件并保存支持的值。
    4. 返回 Activity，执行匹配和不匹配的操作。

    约定策略会显示其项目或用户来源。显式自定义路径的更改可能需要重新运行 CLI 配置，以便记录所选路径。
  </Tab>
  <Tab title="CLI">
    ```bash
    failproofai policy add block-sudo --scope project
    failproofai policies --install --custom ./security.policies.ts --scope project
    failproofai policies
    ```
  </Tab>
</Tabs>

## 浏览项目和会话

Projects 页面整合了所有受支持的本地历史存储。选择一个项目以列出其会话，然后打开某个会话，即可使用原始日志查看器、子代理分段、下载操作以及会话范围的策略活动功能。

如果某个项目或会话缺失，请确认该测试环境使用的是其默认历史记录位置，或使用 `failproofai harness add-path` 注册额外的根目录。

## 计划离线审计

<Tabs>
  <Tab title="Dashboard">
    打开 **Settings**，启用计划扫描，选择支持的时间间隔，并在可用时配置报告投递方式。该页面会显示下次运行时间、上次运行时间、退出代码，以及当前平台是否支持后台守护进程。
  </Tab>
  <Tab title="CLI">
    ```bash
    failproofai audit --schedule 7 --email reliability@example.com
    failproofai audit --status
    ```

    修改天数可设置不同的时间间隔（1–90 天）。使用 `failproofai audit --no-schedule` 可禁用定期扫描；运行 `failproofai audit` 可立即执行交互式扫描。
  </Tab>
</Tabs>

<Warning>
  本地仪表板可能会显示来自本地代理历史记录的提示词、工具输入、文件内容和终端输出。请仅将其绑定到受信任的接口，并在审查完成后停止该进程。
</Warning>
