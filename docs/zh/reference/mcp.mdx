将 AI 工具连接至 Failproof AI Cloud，并通过它处理 Agent 的数据。您的工具可以查询会话和事件、执行只读 SQL、查看仪表盘、告警、问题、审计和策略；如果您拥有相应权限，还可以进行更改操作，例如创建告警或部署策略。

每次调用都以**您自己的**权限运行，在您连接时选择的**某一个**组织中执行。

所有人共用同一个地址，无论是托管版还是自托管版：

```text
https://gateway.befailproof.ai/mcp
```

## 连接客户端

将该地址添加到您的客户端。第一次使用工具时，浏览器会自动打开。选择您的 Failproof AI Cloud 所在位置，登录账号，选择一个组织，然后点击**允许**。点击**取消**则不会连接任何内容。

页面会显示应用名称及其回调地址。未通过自身网址标识的应用会被标记为**未验证应用**，请仅在您是从自己的客户端发起连接时才继续操作。

<Tabs>
  <Tab title="Claude">
    在 claude.ai 或 Claude Desktop 中，进入**设置 → 连接器 → 添加自定义连接器**。将其命名为 `Failproof AI`，输入地址，点击**添加**，再点击**连接**。

    在团队版和企业版计划中，需由所有者先为组织添加连接器，之后每位成员再各自连接自己的账号。
  </Tab>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http failproofai https://gateway.befailproof.ai/mcp
    ```

    然后在 Claude Code 中运行 `/mcp`，选择 `failproofai`，并点击**验证**。
  </Tab>
  <Tab title="Cursor">
    将以下内容添加到 `~/.cursor/mcp.json`，或您项目的 `.cursor/mcp.json` 中：

    ```json
    {
      "mcpServers": {
        "failproofai": { "url": "https://gateway.befailproof.ai/mcp" }
      }
    }
    ```

    Cursor 会在该服务器旁显示**需要登录**。点击它即可登录。
  </Tab>
  <Tab title="Codex">
    将以下内容添加到 `~/.codex/config.toml`：

    ```toml
    [mcp_servers.failproofai]
    url = "https://gateway.befailproof.ai/mcp"
    ```

    然后运行 `codex mcp login failproofai`。
  </Tab>
  <Tab title="其他客户端">
    任何支持通过 Streamable HTTP 和 OAuth 连接远程 MCP 服务器的客户端均可使用。将上述地址提供给客户端即可，无需配置任何客户端 ID 或密钥。
  </Tab>
</Tabs>

## 每个连接对应一个组织

一个连接只能在您选择的组织中操作。如需使用两个组织，请以不同名称（例如 `failproofai-acme` 和 `failproofai-sandbox`）添加两次服务器，并分别连接至各自的组织。

演示组织不接受连接，请改为选择您自己的组织。

## 权限

连接可执行的操作取决于您在该组织中拥有的权限，且限于以下权限范围之内。连接会跟随您当前的权限：若管理员为您增加了权限，工具随之获得；若管理员撤销了某项权限，工具在下次调用时即会失去该权限。

| 权限 | 允许工具执行的操作 |
| --- | --- |
| `events:read` | 列出事件、查看会话概览、列出 Agent 和环境 |
| `evaluations:read` | 列出会话，查看和汇总评估结果及任务 |
| `evaluations:trigger` | 创建评估、发布新版本、启用或禁用评估、回填数据，以及重新评估某个会话 |
| `dashboards:read`、`dashboards:write` | 查看仪表盘，或创建、重命名仪表盘并向其添加查询 |
| `queries:read`、`queries:write` | 查看已保存的查询，或保存和编辑查询 |
| `queries:run` | 执行一条只读 SQL 查询并查看查询模式 |
| `alerts:read`、`alerts:write` | 查看告警，或创建、编辑、暂停、删除和测试告警 |
| `issues:read` | 查看问题、确认问题并对其进行评论 |
| `issues:create` | 在告警上创建问题 |
| `issues:close` | 解决并关闭问题 |
| `audits:read`、`audits:write` | 查看审计、运行记录和发现项，或创建、编辑审计并启动运行 |
| `code_fixes:read` | 查看如何修复某个问题，并获取其上下文供您自己的 Agent 进行修复 |
| `code_fixes:write` | 在 Failproof AI Cloud 中启动修复，这将在您的 GitHub 上发起一个 Pull Request |
| `policies:read`、`policies:write` | 查看策略、机器和部署，或发布、部署和回滚策略 |

少数工具不需要任何权限，因为它们不读取任何组织数据：构建会话和事件链接，以及搜索本文档。

AI 工具无法访问 API 密钥、用户、设置或组织管理相关内容，也无法发送事件。

## 审批变更

如果客户端支持显示提示，写入操作会先向您确认。您可以查看将要发生的变更，点击**批准此变更**后操作才会执行。如果您拒绝或在约 4 分钟内未响应，则不会产生任何变更。部分客户端等待时间不足一分钟，请及时响应。

<Warning>
  不支持提示的客户端不会收到确认请求，写入操作将在客户端发起调用后立即执行。在此情况下，您的客户端自身的确认是唯一的保障，请务必为写入工具保持开启状态。
</Warning>

## 已连接的应用及撤销

**设置 → 集成 → MCP** 会列出当前组织中所有已连接的应用，包括其权限和最近使用时间。点击**撤销**可立即断开某个应用的连接。在您的客户端中移除服务器同样会撤销连接。

每个组织最多可连接 5 个应用。重新连接同一个应用会替换其之前的连接。

## 自托管部署

连接时选择**自托管 Failproof AI Cloud**，并输入您登录时使用的地址。您的部署环境必须可通过公共 HTTPS 访问。

工具调用及其结果在您的 AI 工具与您的部署之间传输时，会经过托管的 Failproof AI 网关。网关不会存储这些数据。

## 数据处理方式

结果会发送至您连接的 AI 工具，由该工具的服务提供商依据其自身条款进行处理。对于每次工具调用，Failproof AI 仅记录工具名称、调用结果、耗时和所属组织，从不记录参数或结果内容。详见[隐私政策](https://befailproof.ai/privacy/)。

## 故障排除

| 您看到的提示 | 处理方式 |
| --- | --- |
| "已在另一个浏览器中启动" | 在客户端打开的浏览器中完成登录（需允许 Cookie），然后从客户端重新开始 |
| 点击**允许**后出现错误 | 该链接仅可使用一次，且在 10 分钟后过期，请从客户端重新开始 |
| 预期中的工具不见了 | 您在该组织中没有对应权限，请联系管理员。获得权限后无需重新连接 |
| 客户端反复要求登录 | 连接已被撤销、您已离开该组织，或连接超过 90 天未使用。请重新连接 |
| "您已有 5 个已连接应用" | 在**设置 → 集成 → MCP** 下撤销一个，然后重新连接 |
