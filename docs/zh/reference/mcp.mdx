将 AI 工具连接到 Failproof AI Cloud，并通过它处理 agent 的数据。您的工具可以查询会话和事件、运行只读 SQL、读取仪表板、告警、问题、审计和策略，如果您拥有相应权限，还可以进行更改，例如创建告警或部署策略。

每次调用都以**您自己的**权限运行，在您连接时选择的**某一个**组织中执行。

所有人共用同一个地址，无论是托管版还是自托管版：

```text
https://gateway.befailproof.ai/mcp
```

## 连接客户端

将地址添加到您的客户端。首次使用工具时，浏览器会自动打开。选择您的 Failproof AI Cloud 所在位置，登录，选择一个组织，然后点击**允许**。点击**取消**则不会连接任何内容。

页面会显示应用名称及其回调地址。未通过自有网址识别身份的应用会被标记为**未验证应用**，只有在您刚从自己的客户端发起连接的情况下才继续操作。

<Tabs>
  <Tab title="Claude">
    在 claude.ai 或 Claude Desktop 中，前往**设置 → 连接器 → 添加自定义连接器**。将其命名为 `Failproof AI`，输入地址，点击**添加**，然后点击**连接**。

    在团队版和企业版套餐中，所有者需先为组织添加连接器，之后每位成员再各自连接自己的账户。
  </Tab>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http failproofai https://gateway.befailproof.ai/mcp
    ```

    然后在 Claude Code 中运行 `/mcp`，选择 `failproofai`，并点击**验证身份**。
  </Tab>
  <Tab title="Cursor">
    将以下内容添加到 `~/.cursor/mcp.json`，或项目的 `.cursor/mcp.json` 中：

    ```json
    {
      "mcpServers": {
        "failproofai": { "url": "https://gateway.befailproof.ai/mcp" }
      }
    }
    ```

    Cursor 会在服务器旁边显示**需要登录**，点击即可登录。
  </Tab>
  <Tab title="Codex">
    将以下内容添加到 `~/.codex/config.toml`：

    ```toml
    [mcp_servers.failproofai]
    url = "https://gateway.befailproof.ai/mcp"
    ```

    然后运行 `codex mcp login failproofai`。
  </Tab>
  <Tab title="其他客户端">
    任何支持通过 Streamable HTTP 与 OAuth 访问远程 MCP 服务器的客户端均可使用。提供上述地址即可，无需配置客户端 ID 或密钥。
  </Tab>
</Tabs>

## 每个连接对应一个组织

一个连接只能在您选择的组织中操作。如需使用两个组织，请以不同名称（例如 `failproofai-acme` 和 `failproofai-sandbox`）添加服务器两次，并分别连接到各自的组织。

演示组织不接受连接，请选择您自己的组织。

## 权限

连接可执行的操作与您在该组织中可执行的操作一致，范围限于下表所列内容。它会跟随您当前的权限变化：管理员为您赋予更多权限时，工具随之获得；管理员收回权限时，工具在下次调用时即失去该权限。

| 权限 | 允许工具执行 |
| --- | --- |
| `events:read` | 列出事件、读取会话概览、列出 agent 和环境 |
| `evaluations:read` | 列出会话，读取并汇总评估结果和任务 |
| `evaluations:trigger` | 创建评估、发布新版本、开启或关闭评估、回填数据，以及重新评估某个会话 |
| `dashboards:read`、`dashboards:write` | 读取仪表板，或创建、重命名仪表板及向其添加查询 |
| `queries:read`、`queries:write` | 读取已保存的查询，或保存和编辑查询 |
| `queries:run` | 运行一条只读 SQL 查询并读取查询 schema |
| `alerts:read`、`alerts:write` | 读取告警，或创建、编辑、暂停、删除和测试告警 |
| `issues:read` | 读取问题、确认问题并添加评论 |
| `issues:create` | 针对告警创建问题 |
| `issues:close` | 解决并关闭问题 |
| `audits:read`、`audits:write` | 读取审计、运行记录和发现项，或创建、编辑审计并启动运行 |
| `code_fixes:read` | 查看问题的修复方案，并获取上下文以供您自己的 agent 修复 |
| `code_fixes:write` | 在 Failproof AI Cloud 中发起修复，该操作会在您的 GitHub 上创建 Pull Request |
| `policies:read`、`policies:write` | 读取策略、机器和部署信息，或发布、部署和回滚策略 |

少数工具无需权限，因为它们不读取任何组织数据：构建会话和事件链接，以及搜索本文档。

AI 工具无法访问 API 密钥、用户、设置或组织管理功能，也无法发送事件。

## 审批变更

如果您的客户端支持显示提示，写入操作会事先向您确认。您可以查看将要发生的更改，并点击**批准此变更**以继续。如果您拒绝或在约 4 分钟内未作回应，则不会有任何变更。部分客户端在等待 1 分钟后会停止，请及时响应。

<Warning>
  不支持提示的客户端不会被询问，写入操作会在客户端发起调用后立即执行。在此类情况下，客户端自身的确认是唯一的防线，因此请务必为写入工具保持该功能开启。
</Warning>

## 已连接的应用及撤销

**设置 → 集成 → MCP** 列出了您在当前组织中已连接的应用，包括其权限和最近使用时间。点击**撤销**可立即断开某个应用的连接。在客户端中移除服务器同样会撤销连接。

每个组织最多可连接 5 个应用。再次连接同一应用会替换其之前的连接。

## 自托管部署

连接时选择**自托管 Failproof AI Cloud**，并输入您的登录地址。您的部署必须可通过公共 HTTPS 访问。

工具调用及其结果在您的 AI 工具和您的部署之间传输时，会经过托管的 Failproof AI 网关中转。网关不会存储这些数据。

## 数据处理说明

结果会发送给您连接的 AI 工具，该工具的提供商将依据其自身条款处理相关数据。对于每次工具调用，Failproof AI 仅记录工具名称、调用结果、耗时和所属组织，不会记录参数或结果内容。请参阅[隐私政策](https://befailproof.ai/privacy/)。

## 故障排除

| 您看到的内容 | 处理方式 |
| --- | --- |
| "在另一个浏览器中启动" | 在客户端打开的浏览器中完成登录（需允许 Cookie），然后从客户端重新发起连接 |
| 点击**允许**后出现错误 | 该链接仅可使用一次，且在 10 分钟后过期，请从客户端重新发起连接 |
| 预期的工具不见了 | 您在该组织中没有对应权限，请联系管理员。获得权限后无需重新连接 |
| 客户端反复要求您登录 | 连接已被撤销、您已离开该组织，或连接超过 90 天未使用。请重新连接 |
| "您已有 5 个已连接应用" | 在**设置 → 集成 → MCP** 中撤销一个应用，然后重新连接 |
