## 连接 Agent 并验证数据

<Tabs>
  <Tab title="仪表板">
    1. 打开 **Administration → Keys**，创建一个具有 `events:add` 和 `policies:pull` 权限的密钥，并复制密钥值。
    2. 参照上方对应页面配置集成。
    3. 打开 **Observe → Events** 确认事件正常到达，然后打开 **Observe → Sessions** 确认事件已组成完整的运行记录。
    4. 按集成所在环境过滤，并检查某个会话中审计所需的模型、工具、错误及策略字段。

    从密钥抽屉开始操作。所选授权决定了该机器能否发送事件及接收云端管理的策略。

    ![用于授予事件摄入和策略下发权限的新建 API 密钥抽屉。](/images/dashboard/key-create.png)

    连接集成后，使用会话列表确认其事件已按预期环境归组为完整的运行记录。

    ![用于验证新接入集成是否正常上报完整 Agent 运行记录的会话列表。](/images/dashboard/sessions-list.png)

    在确认集成完成前，请打开其中一个会话；Trace 中应包含审计所需的模型、工具、错误和策略相关信息。
  </Tab>
  <Tab title="CLI">
    创建机器密钥，连接 Failproof 守护进程，并验证第一个会话。

    ```bash
    fp keys create agent-production \
      --add events:add \
      --add policies:pull

    failproofai config \
      --connect https://app.befailproof.ai \
      --token <machine-key>

    failproofai flush --wait
    fp sessions --since 1h --env production
    fp events --since 1h --env production --limit 20
    ```

    当其他工具需要消费输出结果时，请使用 `fp --json sessions ...`。`--json`、`--org`、`--base-url` 等全局标志必须置于子命令之前。

    本地命令请参阅 [Failproof AI CLI 参考文档](/zh/reference/failproof-cli)，`fp` 命令请参阅 [Failproof Cloud CLI 参考文档](/zh/reference/cloud-cli#cli-commands)。
  </Tab>
</Tabs>
