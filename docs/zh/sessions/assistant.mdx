使用自然语言向 Failproof Assistant 发出任意指令，无需将任务转化为产品界面操作或 CLI 命令。它可以分析会话和故障、执行查询、构建仪表板、调查评估和告警，以及帮助创建和运行审计。

```text
Why did production checkout agents regress this week?
Build a dashboard for tool failures, latency, and evaluation scores.
Create an audit that finds agents retrying the same failed action without changing approach.
Show me the sessions behind the most common audit finding.
```

助手在当前组织的数据和权限范围内工作。在应用可能影响其他用户或 Agent 的操作之前，请先审查其提供的证据和建议变更。

## 向助手提问

<Tabs>
  <Tab title="仪表板">
    1. 选择 **Open agent chat**，描述您想了解、创建或操作的内容。
    2. 在助手工作过程中，查看其工具调用、数据表和查询结果。
    3. 打开引用的会话、告警或查询，对照源数据验证结果。
    4. 针对不同的调查开启新对话，或通过聊天记录继续同一条分析线索。

    ![The Cloud assistant answering an observability question with supporting analysis and queries.](/images/dashboard/assistant.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp agent health
    fp agent models
    fp agent ask "Which production checkout agents had the most tool errors in the last 24 hours?"
    fp agent chats
    fp agent show <chat-id>
    fp agent ask "Open representative sessions" --chat <chat-id>
    ```

    使用 `fp agent rename <chat-id> --title <title>` 为调查设置便于识别的名称，使用 `fp agent delete <chat-id>` 将其删除。
  </Tab>
</Tabs>

## 高效使用助手的建议

- 优先说明目标；当边界条件重要时，再补充环境、工作流或时间范围。
- 将生成的 SQL 和摘要视为调查辅助工具，而非最终证据。
- 在创建审计、问题、告警或策略之前，先打开具有代表性的会话进行核查。
- 明确指定组织、环境和时间过滤条件。
- 将有价值的 SQL 保存为查询，以便其他运维人员复现结果。

<Warning>
  助手只能读取当前用户有权访问的内容。请勿为了让某个问题生效而扩大权限；应请有权限的运维人员代为执行调查。
</Warning>
