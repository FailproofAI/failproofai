仪表盘将已保存的查询整合为一个操作视图。围绕某个预期需要做出的决策来构建仪表盘，而不是堆砌所有可用指标。

## 创建仪表盘

<Tabs>
  <Tab title="仪表盘">
    1. 前往 **Analyze → Queries**，创建或打开一个已保存的查询，并验证其结果。
    2. 选择 **add to dashboard**，然后选择现有仪表盘，或在 **Analyze → Dashboards** 下新建一个。
    3. 打开仪表盘，进入编辑模式，排列图块，然后保存布局。
    4. 需要修改图块背后的数据或筛选条件时，返回对应查询进行调整。

    ![由已保存查询组成的仪表盘，涵盖事件量、错误、延迟和模型 token 用量。](/images/dashboard/dashboard-fleet.png)
  </Tab>
  <Tab title="CLI">
    当前 Cloud CLI 未提供仪表盘的增删改查功能。请使用 CLI 构建并验证已保存的查询，然后在 UI 中将其添加到仪表盘。

    ```bash
    fp query schema
    fp query create "production error rate" --sql "SELECT ..."
    fp query run <query-id>
    ```
  </Tab>
</Tabs>

常用的仪表盘分组包括：

- **Models：** 请求量、延迟、token 用量、错误率和评估分数。
- **Evaluations：** 按 Agent 或环境划分的成功率与分数趋势。
- **Tools：** 调用量、失败率、耗时和重复调用情况。
- **Hooks and policies：** 决策记录、拒绝次数和策略匹配率。
- **自定义工作流指标：** 来自自定义事件字段和 SQL 的计算结果。

从一个已保存的查询出发，验证其结果，再将其添加为图块。务必明确区分生产环境和开发环境的筛选条件，避免测试流量掩盖线上回归问题。

<Tip>
  为每个仪表盘指定一位负责人，并明确其需要回答的问题，例如"checkout-agent 的可靠性是否比上周更差？"
</Tip>
