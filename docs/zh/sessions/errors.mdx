错误视图以失败为中心，呈现各会话的错误情况。可按错误类型、智能体、环境、模型、工具或时间窗口进行分组，以发现反复出现的操作问题。

## 调查错误

<Tabs>
  <Tab title="仪表板">
    1. 前往 **Observe → Errors**。
    2. 按环境、事件类型、错误类型、智能体、会话 ID 或搜索文本进行筛选。
    3. 展开某个分组错误以查看其出现记录。选择某一行可在对应会话中打开该精确事件。
    4. 在某个代表性错误上选择铃铛控件，可针对类似错误创建告警。

    ![错误页面，显示失败频率直方图、分组错误以及创建告警的控件。](/images/dashboard/errors.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp errors --env production --since 24h
    fp errors --error-type TimeoutError --agent-id checkout-agent
    fp errors --aggregate --env production --since 7d
    ```

    如需查看某个错误汇总背后的原始数据，请使用 `fp events --full --session-id <id>`。
  </Tab>
</Tabs>

## 适用场景

- 查找生产环境中出现频率最高的错误类型。
- 判断是否由某个工具或模型引发了错误峰值。
- 从聚合计数直接跳转到具有代表性的会话。
- 为错误的重复出现创建告警。
- 在审计中统计受影响的范围。

错误是一个被观测到的事件；评估失败是一种质量判断；审计发现是一种经过调查的失败模式。在决定采用哪种响应工作流时，请注意区分这三者。
