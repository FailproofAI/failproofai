在线评估对 Agent 会话进行一致性判断。适用于需要持续测量而非仅在审计时才进行调查的信号。

## 查看评估质量

<Tabs>
  <Tab title="控制台">
    1. 前往 **Observe → Evaluations**。
    2. 添加数据系列，选择 Agent、环境、评估分数、统计指标和曲线。
    3. 添加多个数据系列以比较不同环境、Agent 或分数键。
    4. 选择某个结果以打开匹配的会话或分享过滤后的视图。使用 **Observe → Metrics** 查看延迟、Token、成本及其他量化指标。

    ![显示平均评估分数和随时间变化趋势的质量控制面板。](/images/dashboard/dashboard-quality.png)

    从下钻视图中打开会话，查看各分项的评估推理过程：

    ![会话详情视图，在完整追踪记录旁边显示评估分数和推理说明。](/images/dashboard/session-detail.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp evals --agent-id checkout-agent --aggregate
    fp evals --aggregate --env production --status error
    fp evals --score helpfulness:0.8.. --since 7d
    ```

    在 `evals` 前添加全局 `--json` 选项可用于自动化处理，例如 `fp --json evals --aggregate --env production`。
  </Tab>
</Tabs>

评估器接收会话标识、环境、时间戳和有序事件。它可以返回带有可选推理说明和摘要的数值分数键。长时间运行的评估器可以返回待处理的任务，并在稍后进行轮询。

## 适合评估的目标

- 任务完成度或正确性
- 事实依据性和幻觉风险
- 工具选择和工具使用效率
- 政策或流程合规性
- 成本和延迟预算
- 必要的人工升级介入

## 从分数到响应

在控制面板中展示分数以跟踪趋势。针对阈值或复合条件创建告警。当某个分数在群体中持续下降时，运行审计以调查原因；当原因是可重复的操作时，部署相应策略。
