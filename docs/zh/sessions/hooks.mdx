Hook 是 Agent 向 Failproof AI 请求决策的节点。Hook 活动记录了事件、策略、结果及评估时间。

## 查看 Hook 活动

<Tabs>
  <Tab title="仪表盘">
    前往 **Observe → Hooks**，可按环境、事件、Agent 或会话进行筛选。

    ![Hooks 页面展示了按 Hook 名称和触发事件分组的延迟数据。](/images/dashboard/hooks.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp guardrails summary --since 24h
    fp --json events --full --event-type hook_completed --session-id <session-id> --all --limit 500
    fp list hooks
    ```
  </Tab>
</Tabs>

默认情况下，所有 `deny` 和 `instruct` 决策都会完整上报。重复的 allow 决策会被合并以减少噪音。可在 `~/.failproofai/config.json` 中设置 `collector.hooks_verbosity` 为 `all`、`decisions` 或 `off`。

<Warning>
  Hook 活动只能证明评估已执行，并不代表 Harness 能够拦截该事件。详见[执行能力](/zh/reference/harnesses#enforcement-capability)。未列出的 Harness-事件组合均未经验证。
</Warning>
