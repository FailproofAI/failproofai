Hooks 页面显示 agent 生命周期 hook 的运行时间及耗时。策略决策为独立视图。

<Tabs>
  <Tab title="控制台">
    1. 前往 **Observe → Hooks**。
    2. 按环境、hook 名称、触发事件、agent 或会话 ID 进行筛选。
    3. 查看 hook 延迟及分布情况。
    4. 选择图表中的某个点或 hook 片段，以打开对应的底层事件。

    ![Hooks 页面，显示按 hook 名称和触发事件分组的延迟信息。](/images/dashboard/hooks.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list hooks
    fp events --event-type hook_triggered,hook_completed --env production --since 24h
    fp events --search "PreToolUse" --since 24h
    ```
  </Tab>
</Tabs>
