实时事件会在 Agent 运行时显示其活动：模型调用、工具调用、错误、人工输入、hooks 以及策略决策。

## 查看活动

前往 **Observe → Live events**，或执行以下命令：

```bash
fp events --since 1h
fp events --event-type tool_use,tool_result --since 1h
fp --json events --full --session-id <session-id> --all --limit 2000
```

需要查看负载内容时，请使用 `--full` 参数。轻量数据流速度更快，对于大多数过滤场景已经足够。

常见事件类型包括：

- `session_start` 和 `session_end`
- `model_request` 和 `model_response`
- `tool_use` 和 `tool_result`
- `hook_triggered` 和 `hook_completed`
- `error`
- `human_wait` 和 `human_input`
- `agent_pause` 和 `agent_resume`

## 如果事件未显示

```bash
failproofai flush --wait
failproofai config --status
failproofai backfill --since 30d --dry-run
```

默认环境为 `local`。若筛选器设置为 `production`，在修改环境标签之前将不会返回任何结果。

对于不在受支持运行框架内的 Agent，请使用 [Python SDK](/zh/reference/custom-agents)。
