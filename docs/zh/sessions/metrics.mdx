---
title: "指标"
description: "绘制延迟、成本和 Token 用量等量级指标。"
icon: "ruler"
---

指标用于带单位的数值，评估用于评分和判断。

<Tabs>
  <Tab title="控制台">
    1. 前往 **Observe → Metrics**。
    2. 选择 **add series**，然后选择 Agent、环境、指标、统计量和曲线。
    3. 添加多个系列以比较不同 Agent 或环境；不同单位的指标将使用独立坐标轴。
    4. 选择某个数据点以查看对应的评估和会话，或选择 **share** 复制当前视图。

    ![指标页面，展示两条每输出单位成本系列的对比，包含时间控制、聚合选择器、曲线和分享操作。](/images/dashboard/metrics-series.png)
  </Tab>
  <Tab title="CLI">
    目前尚无专用的量级指标命令。可通过以下方式查看可用的键并检索会话或评估：

    ```bash
    fp list score_filters
    fp --json evals --since 24h
    fp --json sessions --since 24h
    ```

    使用 `fp query` 进行自定义指标聚合。
  </Tab>
</Tabs>
