使用「模型」页面，查看可靠性或成本是否随模型、Agent、环境或时间范围的变化而改变。

<Tabs>
  <Tab title="仪表板">
    1. 前往 **Observe → Models**。
    2. 设置时间范围，然后按环境、模型、Agent 或会话 ID 进行筛选。
    3. 查看延迟、Token 消耗、上下文窗口使用情况和模型分布。
    4. 选择图表中的某个数据点或分布区段，以打开对应的事件。

    ![模型页面，展示延迟、百分位、Token、成本、上下文窗口和模型分布视图。](/images/dashboard/models.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list models
    fp events --event-type model_request,model_response --env production --since 24h
    fp --json events --fields ts,agent_id,session_id,event_type,output_tokens,context_fill
    ```

    对于未作为独立 CLI 命令公开的模型级聚合数据，可使用已保存的查询。
  </Tab>
</Tabs>
