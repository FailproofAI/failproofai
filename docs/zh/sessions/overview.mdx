会话代表一次完整的智能体运行。它将提示词、模型调用、工具使用、错误信息、人工输入、策略决策和最终结果串联在一起。

## 会话存储位置

<Tabs>
  <Tab title="本地">
    运行 `failproofai` 即可在 `http://localhost:8020` 打开控制台。会话历史记录保存在本机。
  </Tab>
  <Tab title="云端">
    连接机器后，打开 **Observe → Sessions**：

    ```bash
    export FAILPROOFAI_CLOUD_TOKEN="<key>"
    failproofai config
    ```

    默认情况下，云端会接收完整的会话记录。如果只想上传策略决策数据，请先完成连接，然后在 `~/.failproofai/config.json` 中将 `collector.sessions` 设置为 `false`。当前的 `--no-transcripts` 配置标志不会应用该设置。
  </Tab>
</Tabs>

会话数据来自 12 种受支持的[智能体运行环境](/zh/reference/harnesses)，以及通过 [Python SDK](/zh/reference/custom-agents) 接入的自定义智能体。

## 查找会话

在云端，可按时间、环境、状态、智能体或会话 ID 进行筛选。通过命令行操作：

```bash
fp sessions --since 24h
fp sessions --status error,timeout --agent-id checkout-agent
fp --json sessions --session-id <session-id>
```

使用 `fp errors --since 24h` 可查看从未经过评估的失败记录。`fp sessions --status` 基于最新的评估结果进行过滤，因此未经评估的会话不会显示状态。

## 分析一次运行

1. 确认智能体的目标和运行环境。
2. 找到第一个错误或异常决策。
3. 检查该事件发生前的模型上下文和工具输入。
4. 查看重试次数、延迟情况和人工中断记录。
5. 审查评估结果和策略决策。

## 会话缺失时的处理方法

```bash
failproofai flush --wait
failproofai config --status
failproofai backfill --since 30d --dry-run
```

当会话文件不在运行环境的默认路径下（例如存储在其他用户配置目录、容器 home 目录或团队共享挂载目录中）时，请使用 `failproofai harness add-path <harness> [<label>=]<path>` 手动指定路径。
