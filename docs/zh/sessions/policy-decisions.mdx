---
title: "策略决策"
description: "查看已评估、阻止、指导或允许的策略。"
icon: "shield-check"
---

策略决策说明了执行操作的具体内容。使用它来验证部署情况、衡量阻止率，并发现未受保护的活动。

<Tabs>
  <Tab title="控制台">
    1. 前往 **Observe → policy**，选择时间范围，并可选择筛选某台机器。
    2. 查看已评估的操作、阻止次数、阻止率、云端决策、未受保护的操作以及暂停期间的活动。
    3. 筛选策略映射表并检查已部署的分配情况。
    4. 选择图表上的某个数据点，打开对应的决策及其会话详情。

    ![策略页面，显示决策总计、机器筛选器、随时间变化的执行活动以及策略映射表。](/images/dashboard/policy-observe.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp events --event-type hook_completed --env production --since 24h
    fp events --search "deny" --since 24h
    failproofai config --status
    ```

    使用 `failproofai` 查看机器的本地执行状态，使用 `fp` 进行云端事件排查。
  </Tab>
</Tabs>
