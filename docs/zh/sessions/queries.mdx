查询是仪表板、审计和调查的底层灵活工具。使用临时 SQL 验证想法，当它成为常规工作流程的一部分时，保存该查询。

## 创建并运行查询

<Tabs>
  <Tab title="仪表板">
    1. 前往 **分析 → 查询**，选择 **新建查询**。
    2. 打开模式浏览器，从事件、会话或评估数据中选择字段。
    3. 编写 SQL，按需添加参数，然后运行查询。
    4. 用清晰的名称和描述保存查询，若需要监控结果，点击 **添加到仪表板**。

    查询编辑器集成了事件模式、SQL、参数和结果预览，让你在保存前就能验证查询逻辑是否正确。

    ![带有模式浏览器和实时结果网格的 SQL 查询编辑器。](/images/dashboard/query-lab.png)

    保存后的查询将出现在共享库中，团队成员可以重新运行它们，或将其结果添加到仪表板。

    ![包含可复用内置查询和自定义查询的查询库。](/images/dashboard/queries.png)

    使用清晰的名称和描述，确保不重新打开 SQL 也能理解查询结果。
  </Tab>
  <Tab title="CLI">
    ```bash
    fp query schema
    fp query create "retry loops" --sql "SELECT ..."
    fp query run <query-id>
    fp query show <query-id>
    fp query update <query-id> --sql "SELECT ..."
    ```

    使用 `fp query list` 查找 ID，使用 `fp query delete <query-id>` 删除已保存的查询。
  </Tab>
</Tabs>

## 常见用途

- 查找对同一工具进行重复调用的会话。
- 跨模型或环境比较评估分数。
- 测量人工等待与恢复之间的时间间隔。
- 识别策略拒绝后成功采用替代方案的情况。
- 为审计构建用户群组。

在对不熟悉的字段编写查询前，先打开 **查询 → 模式** 查看结构。建议使用明确的时间和环境过滤条件，并在探索阶段限制结果数量。

<Warning>
  查询可以识别可疑模式，但仅凭查询本身无法确定故障模式。在将结果转化为策略之前，请先打开具有代表性的 traces 或运行审计。
</Warning>
