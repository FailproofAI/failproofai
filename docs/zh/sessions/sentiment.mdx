Jev 对用户发送给智能体的每条消息进行评分，分值范围为 0 到 100，涵盖四种情绪——**愤怒**、**沮丧**、**开心**和**困惑**——以及三种反映智能体表现的信号：

- **纠错**：用户指出智能体的回复有误。
- **已解决**：用户确认智能体解决了他们的问题。
- **质疑**：用户对智能体回答的真实性，或智能体是否真正完成了任务表示怀疑。

借助情绪分析，你可以找到用户逐渐失去耐心的对话、频繁被纠错的智能体，以及反响良好的回复。这是 Jev 内置的评分功能，无需自行编写评估。如需针对固定答案的问题创建评估，请[创建 Jev 评估](/zh/evaluations/jev)。

<Note>
  情绪分析默认关闭，需由管理员在组织层面开启。Jev 对每条消息发起一次评分请求，并在评分时同时接收该消息及其前一条智能体回复。评分会消耗组织的模型预算。
</Note>

## 开启情绪分析

1. 前往 **Administration → Settings**。
2. 在 **Human input sentiment** 下，将其切换为**开启**并保存。

系统会优先对最近一天的消息进行评分。此后，新消息通常在到达后一两分钟内完成评分。

## 找到需要查看的对话

打开 **Observe → Sentiment**，可按时间、环境、智能体或会话 ID 进行筛选。顶部区域显示消息和会话的数量、**已标记**消息的数量，以及当前最突出的信号。当愤怒、沮丧、纠错、困惑或质疑的评分达到 100 分中的 35 分时，该消息将被标记。

![情绪仪表盘，显示消息和会话数量、已标记消息及随时间变化的 Jev 评分。](/images/dashboard/sentiment-overview.png)

使用 **Score over time** 图表对比各项信号。选择要显示的评分维度，点击某个时间点即可查看该时间段内的消息。**By agent** 表格展示了某一信号的集中分布情况。在 **Messages** 视图中，可按最强负面评分排序，或筛选单一评分维度。点击消息可在其所属会话中查看上下文，从而判断具体是哪个环节出了问题。

![按最强负面评分排序的情绪消息列表，并附有指向原始会话的链接。](/images/dashboard/sentiment-messages.png)

## 哪些消息会被评分

仅对用户本人编写的消息评分，包括：

- 通过 SDK 将人类输入记录到自定义智能体的消息。
- 在 Claude Code、Codex、OpenCode、pi、Hermes 和 OpenClaw 中输入的提示词（在会话记录被发送时，即默认情况下）。定时任务、注入的指令、子智能体交接以及智能体运行时自身生成的文本不在评分范围之内。非交互式运行也不会被评分，例如 `claude -p`、`codex exec` 和 `hermes -z`：这些提示词是由脚本生成的，并非真人输入。

评分仅针对用户自身的表达措辞。简短、直接的指令（如"修一下"）不会被判定为愤怒，提问也不会被判定为困惑。提出新请求不算纠错，单纯的感谢也不算已解决。
