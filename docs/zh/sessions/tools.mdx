---
title: "工具"
description: "发现 agent 运行中缓慢、失败或过度调用的工具。"
icon: "wrench"
---

工具页面展示了 agent 的调用情况、调用失败频率以及受影响的会话。

工具名称来源于各个 agent 框架，因此相同的功能可能有不同的名称。例如，一次 shell 调用可能以 `Bash`、`exec`、`Shell`、`terminal` 或 `run_command` 的形式出现。在构建过滤器之前，请先运行 `fp list tools`。

<Tabs>
  <Tab title="仪表板">
    前往 **Observe → Tools**，按环境、工具、agent 或会话进行筛选。

    ![工具页面，展示延迟、成功与失败分布以及工具调用分布情况。](/images/dashboard/tools.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list tools
    fp events --event-type tool_use,tool_result --since 24h
    fp errors --event-type tool_result --since 24h
    fp --json events --full --event-type tool_use,tool_result --session-id <session-id> --all --limit 2000
    ```

    当需要获取每次调用的耗时等 payload 字段时，请使用 `--full`。
  </Tab>
</Tabs>

使用此页面可发现重复失败的工具、对比正常与失败的运行记录，或确认某个策略所针对的工具是否确实被使用。
