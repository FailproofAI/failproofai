---
title: "工具"
description: "在代理会话中发现速度慢、失败或过度使用的工具。"
icon: "wrench"
---

工具页面汇总各会话中的工具调用，让你能够对比延迟和调用分布情况。

<Tabs>
  <Tab title="仪表盘">
    1. 前往 **Observe → Tools**。
    2. 按环境、工具名称、代理或会话 ID 进行筛选。
    3. 查看延迟和工具分布情况。
    4. 点击图表中的某个数据点或工具分段，以打开对应的事件和会话。

    ![工具页面，显示延迟、成功与失败细分，以及工具调用分布情况。](/images/dashboard/tools.png)
  </Tab>
  <Tab title="CLI">
    ```bash
    fp list tools
    fp events --event-type tool_use,tool_result --env production --since 24h
    fp --json events --full --session-id <session-id> --all
    ```
  </Tab>
</Tabs>
