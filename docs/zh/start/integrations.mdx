## 无论哪种框架，三行代码搞定

<CodeGroup>
```bash LangGraph
pip install 'failproofai-sdk[langgraph]'
```

```bash CrewAI
pip install 'failproofai-sdk[crewai]'
```

```bash LlamaIndex
pip install 'failproofai-sdk[llamaindex]'
```

```bash Pydantic AI
pip install 'failproofai-sdk[pydantic-ai]'
```

```bash Custom agents
pip install failproofai-sdk
```
</CodeGroup>

```python
import failproofai_sdk

failproofai_sdk.configure(environment="production")
failproofai_sdk.instrument()          # 自动检测你已导入的框架

with failproofai_sdk.session():
    ...                               # 你现有的 Agent 调用，无需任何改动
```

无需在函数上添加装饰器，无需向调用传入回调，也无需在代码中穿插各种 ID。唯一的变化是将调用放在 session 内部：

<Tabs>
  <Tab title="LangGraph">
    ```python
    graph.invoke({"messages": [HumanMessage("...")]})
    ```
  </Tab>
  <Tab title="CrewAI">
    ```python
    Crew(agents=[analyst, writer], tasks=[gather, summarise]).kickoff()
    ```
  </Tab>
  <Tab title="LlamaIndex">
    ```python
    await agent.run("...")        # 在 `async with failproofai_sdk.session():` 内部
    ```
  </Tab>
  <Tab title="Pydantic AI">
    ```python
    agent.run_sync("...")
    ```
  </Tab>
  <Tab title="Custom agents">
    ```python
    with failproofai_sdk.agent("planner"):
        with failproofai_sdk.tool_call("search", input={"q": q}) as t:
            t.output = search(q)
    ```
  </Tab>
</Tabs>

额外安装的是**框架**本身。所有适配器都已内置于基础安装包中，因此对于已安装框架的项目，无需任何额外依赖。

## 确认数据已到达

运行一次已接入监控的会话，然后打开 **Observe → Sessions** 并选择你的环境。该次运行将以重建后的 Trace 形式展示。

如果没有数据到达，请通过 `failproofai config --status` 确认机器已连接。详见[配置数据采集](/zh/start/setup)。

<Warning>
  请勿通过查看 spool 目录来确认数据是否已送达。Failproof 守护进程会在毫秒级别内收集并删除每批数据，因此读取 spool 目录会与收集器产生竞争，导致看到的事件数量远少于实际产生的数量。
</Warning>
